## 卡 1 · `#M043` 参数方程切点（本次唯一错点）

**正面**

```
x = t² + 1,  y = ln t，求 t = 2 处的切线方程。
（换数字复检：原题 t=1 已在 D031 做错，本题只换 t，题型不变）
```

**背面 · 五格**

| 格 | 内容 | 值 |
|:--:|:--|:--|
| 1 | dx/dt = 2t | t=2 → **4** |
| 2 | dy/dt = 1/t | t=2 → **1/2** |
| 3 | k = 格2 / 格1 | (1/2)/4 = **1/8** |
| 4 | **切点 (x, y)：只代原方程** | x = 2²+1 = **5**，y = **ln 2** ⇒ **(5, ln 2)** |
| 5 | 点斜式 → 化简 | y − ln2 = (1/8)(x − 5)，即 **y = x/8 + ln2 − 5/8** |

**理由（说不出口就不算过）**：切点是**位置**，来自 `x=φ(t), y=ψ(t)` 本身；斜率是**变化率**，来自 `dy/dx = (dy/dt)/(dx/dt)`。两条路各走各的，不共用任何中间数。

> ⚠️ **18:03 用户追问暴露的更深一层混淆**（讲这题前必须先拆）：用户问「为什么这里 y=0，ln t 导数不是 1/x 吗」，说明他以为**求导会把 `y = ln t` 改写掉**。
> 口径：求导是**旁边新增一列** `dy/dt = 1/t`，原方程 `y = ln t` 一个字没动、仍在等着代 t 求位置；两者并存。`ln 1 = 0` 只在 t=1 这一瞬间成立，不是 y 恒为 0。`(ln □)' = 1/□`，x / t 只是自变量名字。且 `1/t` 是 **dy/dt 不是 k**，还要 ÷ `dx/dt = 2` 才得 `k = 1/2`。
> 类比：海拔 0 米 / 爬升 1 米每秒 / 水平 2 米每秒 ⇒ 画面坡度 1/2。
> **处方**：把简写 `y = 1/t` 改回 `dy/dt = 1/t`。处方是改符号，不是改算法。

> **18:05 落地为草稿纸书写版式（以后每道参数方程切线题照抄）**：
> ① **位置栏** —— `x=φ(t)` / `y=ψ(t)` 只代值，写这栏时**盖住右栏**；
> ② **速度栏** —— `dx/dt` / `dy/dt` / `k`，这是求导**新增的一列**，原方程没被替换；
> ③ **点斜式** —— `y − □` 里的数只从左栏取，`k` 只从右栏取。两栏互不串门。
>
> A 题（t=2）的执行口径：右栏 `4` / `1/2` / `1/8` 由教练预先填好、故意摆在旁边做抗干扰，只留左栏 `y = ln 2` 与切点 `(5, ln 2)` 两处空；不要求写切线方程（下一格再上）。答对后才给 B 题（2026 单选 2 撤脚手架）。

> **18:13 实测（照片批改）**：右栏 3/3 全对、点斜式结构 / 展开 / 化简全对 ⇒ **抗干扰生效**，上一轮「就近抓数」的洞已堵住。但左栏 y 写成 `0`、切点 `(5,0)`、最终 `y = x/8 − 5/8`。
> **新错因 ≠ 上一轮**：手写「代入 t=1」而题目是 `t=2`，`x=5` 用 2、`y=0` 用 1 ⇒ **同一个点用了两个时刻**。归类为**答案迁移**（`ln1=0` 被背成默认切点纵坐标），不是计算错。
> ⚠️ **教练侧题面设计缺陷**：表格预填了 `x=5`，用户因此跳过「把 t=2 代进式子」这个动作，y 那格跟着没代值 ⇒ **以后左栏两格都留空，一个都不预填**。
> 新增自查：**写左栏前先把 t 的值抄进两行式子；两行代的数不一样，立刻停。**
> R2 当天重做缩小为三笔：划掉「代入 t=1」改 t=2、重写 `y = ln 2` 与切点 `(5, ln 2)`、补一句「为什么不是 4 / 1/2 / 0」。改对才发 B 题。

**三条判分点**
1. 格 4 的 y **不写成 1/2 或 4**（那是导数，不是坐标）—— D031 就是在这里把 `=1` 就近抓成了 y 坐标。

## 卡 2 · `#M045` 2.7 微分

**正面**（2026 单选第 2 题原题，撤脚手架）

```
已知函数 y = x³ + 1，则 dy|_{x=1} = （ ）
A. 5dx    B. 4dx    C. 3dx    D. 2dx
```

**背面**：f′(x) = 3x² ⇒ f′(1) = 3 ⇒ **dy|_(x=1) = 3dx，选 C**。

**理由**：dy = f′(x)·dx，dx = Δx；导数是微分的商（所以叫「微商」）。漏写 dx 等于只求了导数，没求微分 —— 这是该题唯一陷阱，四个选项都带 dx，专门钓「算对系数却漏写」的人。

**判分点**：答案必须带 dx；系数 3 来自 x³ 的导数，常数 1 导掉（不是 4）。

**正面**（30 秒判断，只回「能」或「不能」）：$f(x)=x^{3}$ 在 $x=0$ 处有 $f'(0)=0$，能不能据此判定 $x=0$ 是极值点？

**背面**：**不能**。$f'(x)=3x^{2}\ge 0$，$x=0$ 左右都不变号（左边也在增、右边也在增）——只是爬坡中途停了一下，不是山尖也不是谷底 ⇒ 不是极值点。$f'(x_0)=0$ 只说明是**驻点**，驻点不一定是极值点。

**为什么**：极值是「比左右邻居都高 / 都低」，属**局部比较**；$f'(x_0)=0$ 只是「这一瞬间不升不降」，两者不是一回事。所以要判极值，必须看 $f'$ 在 $x_0$ 左右两侧的符号有没有换边。

**怎么做**（第一充分条件，三行判据）：

| 左侧 $f'$ | 右侧 $f'$ | 判定 |
|:--:|:--:|:--|
| $+$ | $-$ | 极大值点 |
| $-$ | $+$ | 极小值点 |
| 不变号 | 不变号 | **不是**极值点 |

**判分点**：能答「不能」即可，理由由教练在讲解里补（沿用 18:30 用户选定的「讲 + 30 秒判断」模式，不要求写过程）。不许把 $f'(x_0)=0$ 直接当极值。
