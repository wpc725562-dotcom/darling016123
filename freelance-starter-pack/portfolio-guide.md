## 缺少的：需要补做的 Demo 项目

客户最想看到的是**你能做什么**。建议补 2 个小项目：

### 🔧 建议 Demo 1：To-Do List 网页应用

- 技术栈：HTML + CSS + JavaScript（纯前端）
- 功能：添加/删除/标记完成/todo 本地存储
- 为什么：这是前端最经典的"入门 demo"，客户看的是代码质量
- 时间：2 小时就能做完
- 放 GitHub 上，叫 `todo-app`

### 🔧 建议 Demo 2：URL 缩短器（Node.js）

- 技术栈：Node.js + Express + 简单存储（JSON 文件或 SQLite）
- 功能：输入长链接 → 生成短链接 → 跳转
- 为什么：展示后端能力，而且是完整的有用工具
- 时间：3-4 小时
- 放 GitHub 上，叫 `url-shortener`

> 这两个 demo 我可以帮你写，你想做的话告诉我，我直接生成代码。

## GitHub 整理步骤

1. 确保你的 GitHub 主页（github.com/wpc725562-dotcom）有头像和个人简介
2. 新建 2 个仓库放 demo 项目
3. 每个仓库都要有 README.md（英文），写清楚"这是什么、怎么运行、技术栈"
4. 将仓库 pin 在主页（Settings → Pinned → 选 2-3 个仓库）
5. 确保 Profile 里链接到 GitHub

### 仓库 README 模板

```markdown
# 项目名

A simple description of what this project does.

## Tech Stack
- HTML / CSS / JavaScript
- Node.js (Express)

## How to Run
1. Clone this repo
2. Open index.html in browser
3. ...

## Features
- Feature 1
- Feature 2

## Screenshots
(Screenshot link)
```
