### 真题编程题 ①：A/B 两队射箭比分比较

**题干（视频 t=49s 题面帧，逐字转录）**

> 有 A、B 两个队，队里分别为 5 名队员，A 和 B 射箭比赛，分数用数组存储。第一个 A 队队员分数和第一个 B 队队员的分数比较，依次比较。假设 A 队赢了一局就记录 A 队赢了一场，B 队赢了一局就记录 B 队赢了一场，双方相同则平局。

**题目数据（视频 t=97s / t=173s 表格帧）**

| | 1 | 2 | 3 | 4 | 5 |
|:---|:---:|:---:|:---:|:---:|:---:|
| **A 队** | 15 | 7 | 20 | 22 | 21 |
| **B 队** | 16 | 5 | 20 | 22 | 14 |

**视频给出的答案（t=331s 结果帧）**：A win **2** · B win **1** · draw **2**

**参考代码**

```c
#include <stdio.h>

int main(void)
{
    int a[5] = {15, 7, 20, 22, 21};
    int b[5] = {16, 5, 20, 22, 14};
    int a_win = 0, b_win = 0, draw = 0;
    int i;

    for (i = 0; i < 5; i++) {
        if (a[i] > b[i]) {
            a_win++;
        } else if (b[i] > a[i]) {
            b_win++;
        } else {
            draw++;
        }
    }

    printf("A win %d, B win %d, draw %d\n", a_win, b_win, draw);
    return 0;
}
```

> **考点**：数组遍历 + 三路分支（`if / else if / else`）+ 计数变量初始化。
> **易错**：只写 `if...else` 两路，把平局算进 B 赢；或三个计数器忘了初始化为 0。

### 真题编程题 ②：停车场七天最大台数（**要求用指针实现**）

**题干（视频 t=597s 题面帧，逐字转录）**

> 停车场连续七天记录每晚停车的台数，要求找出一周内停车的最多为多少台，用指针实现。

**题目数据（视频 t=710s / t=782s 表格帧）**

| 值 | 28 | 17 | 19 | 43 | 22 | 85 | 8 |
|:---|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 下标 | 0 | 1 | 2 | 3 | 4 | 5 | 6 |

**视频给出的答案**：max = **85**

**参考代码**

```c
#include <stdio.h>

int main(void)
{
    int park[7] = {28, 17, 19, 43, 22, 85, 8};
    int *p = park;          /* p 指向数组首元素 */
    int max = *p;           /* 先假设第一个就是最大 */
    int i;

    for (i = 1; i < 7; i++) {
        if (*(p + i) > max) {
            max = *(p + i);
        }
    }

    printf("max = %d\n", max);
    return 0;
}
```

> **考点**：**指针访问数组**（`*(p+i)` 等价于 `p[i]` 等价于 `a[i]`）+ 求最大值模板。
> **⚠️ 本题的关键是「用指针实现」——如果写成 `park[i]` 会扣分**，必须出现指针变量和解引用 `*`。
> **易错**：`max` 初始化为 0（若数组全为负数就错）；循环从 0 开始（会把自己比一次，虽不影响结果但不规范）。

### 真题编程题 ③：结构体 staff 的输入输出

**题干（视频 t=1074s / t=1601s 题面帧，逐字转录）**

> 定义一个结构体 staff，里面记录了员工的姓名、id、入职年份和薪资。然后输入一条数据，并且打印出该信息，用结构体编程实现。

**参考代码**

```c
#include <stdio.h>

struct staff {
    char  name[20];
    int   id;
    int   year;
    float salary;
};

int main(void)
{
    struct staff s;

    scanf("%s %d %d %f", s.name, &s.id, &s.year, &s.salary);
    printf("name: %s\n", s.name);
    printf("id: %d\n", s.id);
    printf("year: %d\n", s.year);
    printf("salary: %.2f\n", s.salary);

    return 0;
}
```

> **考点**：结构体定义 + 结构体变量 + 成员访问（`s.name`）+ `scanf` 取地址。
> **易错**（这题三个坑）：
> 1. `s.name` 是**数组名**，`scanf` 里**不加 `&`**；其余成员**必须加 `&`**
> 2. `salary` 若定义成 `float`，`scanf` 用 `%f`、`printf` 也用 `%f`；若定义成 `double` 则 `scanf` 要用 `%lf`
> 3. 结构体定义末尾**必须有分号** `};`

## 一、C 语言同题型复盘

### 1. 表达式 `7 / 2 + 7 % 2` 的值是（ ）

A. 3　　B. 3.5　　C. 4　　D. 4.5

**答案：C** · 考点 [[1.2 数据的存储与运算]]
> 两个操作数都是整数，`7 / 2 = 3`，`7 % 2 = 1`，结果 4。C 语言整数除法直接舍去小数，不四舍五入。

### 2. 执行下面程序段后，变量 `x` 的值是（ ）

```c
int x = 2;
x += x++ + 1;
```

A. 5　　B. 6　　C. 7　　D. 结果未定义

**答案：D** · 考点 [[1.2 数据的存储与运算]]
> 同一完整表达式中 `x` 被多次修改且求值顺序无保证，行为未定义。考试不要用"从左到右"强行手推。

### 3. 若有 `char s[] = "Guangdong";`，则 `strlen(s)` 的值是（ ）

A. 8　　B. 9　　C. 10　　D. 取决于编译器

**答案：B** · 考点 [[1.6 数组]]
> `"Guangdong"` 含 9 个可见字符，`strlen` 不计算末尾 `'\0'`。区分：`strlen(s)=9`，`sizeof(s)=10`。

### 4. 已知 `int a[5] = {1, 2, 3};`，则 `a[4]` 的值是（ ）

A. 0　　B. 3　　C. 随机值　　D. 越界

**答案：A** · 考点 [[1.6 数组]]
> 数组只给部分初值时，剩余元素自动初始化为 0，数组为 `{1,2,3,0,0}`。

### 5. 下列函数声明中，能够交换调用者两个整型变量的是（ ）

A. `void swap(int a, int b)`　　B. `void swap(int *a, int *b)`　　C. `int swap(int a)`　　D. `void swap(const int a, const int b)`

**答案：B** · 考点 [[1.7 函数]] · [[1.8 指针]]
> C 参数值传递。要修改调用者变量必须传地址，函数内通过指针解引用完成交换。

### 6. 执行下面程序段，输出结果是（ ）

```c
int i, sum = 0;
for (i = 1; i <= 5; i++) {
    if (i == 3) continue;
    sum += i;
}
printf("%d", sum);
```

A. 9　　B. 12　　C. 15　　D. 18

**答案：B** · 考点 [[1.5 循环结构程序设计]]
> `i==3` 跳过本轮，`sum=1+2+4+5=12`。`continue` 只跳过当前循环，`break` 才结束循环。

### 7. 设 `int x=10; int *p=&x;`，执行 `(*p)++;` 后（ ）

A. `p` 的地址加 1　　B. `x` 变为 11　　C. `p` 指向空地址　　D. 语法错误

**答案：B** · 考点 [[1.8 指针]]
> 括号保证先 `*p` 得 `x` 再自增，`x` 变 11。区分：`(*p)++` 改指向的值，`p++` 改指针本身。

### 8. 关于编译错误与运行错误，下列说法正确的是（ ）

A. 数组越界一定能在编译阶段发现　　B. 缺少分号通常属于编译错误　　C. 除以 0 一定属于链接错误　　D. 函数声明不匹配一定不会报警

**答案：B** · 考点 [[1.11 程序运行环境与调试]]
> 缺少分号破坏语法，由编译器报告。数组越界/除以 0 多在运行阶段暴露；链接错误常见于符号找不到定义。**2026 考纲新增重点**。

## 二、数据结构同题型复盘

### 9. 长度为 $n$ 的顺序表，在表头插入一个元素的时间复杂度是（ ）

A. $O(1)$　　B. $O(\log n)$　　C. $O(n)$　　D. $O(n^2)$

**答案：C** · 考点 [[2.2 线性表]]
> 表头插入需把原有 $n$ 个元素全部后移一位，时间复杂度 $O(n)$。

### 10. 栈的操作原则是（ ）

A. 先进先出　　B. 后进先出　　C. 随机存取　　D. 按关键字有序

**答案：B** · 考点 [[2.3 栈和队列]]
> 栈是后进先出（LIFO）的受限线性表，只允许栈顶插入删除。

### 11. 循环队列中，队头 `front`、队尾 `rear`、数组长度 `m`，常用队满条件是（ ）

A. `front == rear`　　B. `(rear + 1) % m == front`　　C. `rear == m`　　D. `front == 0`

**答案：B** · 考点 [[2.3 栈和队列]]
> 牺牲一个存储单元时，`front==rear` 队空，`(rear+1)%m==front` 队满。

### 12. 一棵具有 7 个结点的完全二叉树，其叶子结点数是（ ）

A. 2　　B. 3　　C. 4　　D. 7

**答案：C** · 考点 [[2.5 树和二叉树]]
> 7 个结点恰构成三层满二叉树，第三层 4 个结点都是叶子。

### 13. 对二叉搜索树进行哪一种遍历可以得到递增序列（ ）

A. 先序遍历　　B. 中序遍历　　C. 后序遍历　　D. 层序遍历

**答案：B** · 考点 [[2.5 树和二叉树]]
> 二叉搜索树满足"左小右大"，中序遍历（左—根—右）结果递增。

### 14. 含 $n$ 个顶点的无向连通图，至少有多少条边（ ）

A. $n-1$　　B. $n$　　C. $n+1$　　D. $2n$

**答案：A** · 考点 [[2.6 图]]
> 无向连通图的极小连通结构是生成树，树有 $n-1$ 条边。

### 15. 对长度为 $n$ 的有序表进行折半查找，平均时间复杂度是（ ）

A. $O(1)$　　B. $O(\log n)$　　C. $O(n)$　　D. $O(n\log n)$

**答案：B** · 考点 [[2.7 查找]]
> 每次比较排除一半区间，比较次数与 $\log_2 n$ 同阶。前提：表有序 + 随机访问。

### 16. 下列排序算法中，平均时间复杂度 $O(n\log n)$ 且通常需额外 $O(n)$ 空间的是（ ）

A. 冒泡排序　　B. 直接插入排序　　C. 归并排序　　D. 简单选择排序

**答案：C** · 考点 [[2.8 排序]]
> 归并排序分治二分再辅助数组归并，平均/最坏均为 $O(n\log n)$。

### 应用题 1（10 分）射箭比赛 —— 数组遍历 + 计数

**题目**：A、B 两个小队，各 5 名队员，分数用数组存储。第 1 名 A 队员与第 1 名 B 队员比较，
第 2 名与第 2 名比较，依此类推。A 队高则记 A 胜一局，B 队高则记 B 胜一局，相等记平局。
统计 A 队胜、B 队胜、平局各多少次。

**参考解**（讲解用示例数据，非原题数据：A = {15,7,20,20,22}，B = {16,5,20,20,14}）
```c
#include <stdio.h>
int main() {
    int A[5] = {15, 7, 20, 20, 22};
    int B[5] = {16, 5, 20, 20, 14};
    int a_win = 0, b_win = 0, draw = 0, i;

    for (i = 0; i < 5; i++) {
        if (A[i] > B[i])       a_win++;
        else if (B[i] > A[i])  b_win++;
        else                   draw++;
    }
    printf("A胜%d局 B胜%d局 平局%d次\n", a_win, b_win, draw);
    return 0;   /* 输出：A胜2局 B胜1局 平局2次 */
}
```
> **考点**：一维数组遍历（C6）+ 三路分支（C4）+ 三个计数器初始化。
> **失分点**：① 三个计数器忘记初始化为 0；② 用 `if / if / if` 而非 `if / else if / else`，
> 导致平局被重复计数；③ 循环边界写成 `i<=5`（越界）。

### 应用题 2（10 分）停车场统计 —— 数组 + 指针（题目明确要求用指针）

**题目**：停车场连续 7 天记录每晚停车的台数，要求找出这一周内停车最多的台数，**用指针实现**。

**参考解**（示例数据：28, 17, 19, 43, 22, 85, 8）
```c
#include <stdio.h>
int main() {
    int car[7] = {28, 17, 19, 43, 22, 85, 8};
    int *p = car;          /* 数组名 = 首元素地址 */
    int max = *p;          /* 假设第 0 天最大 */
    int i;

    for (i = 1; i < 7; i++) {
        p++;               /* 指针后移一个元素 */
        if (*p > max) max = *p;
    }
    printf("max=%d\n", max);   /* 85 —— 必须输出 max，不是 *p */
    return 0;
}
```
> **考点**：数组名即首元素地址、`p++` 指针算术、`*p` 解引用（C6 + C8）。
> **本题最大的坑**：最后 `printf` 里若写成 `*p`，输出的是**最后一个元素 8**，不是最大值 85——
> 因为循环结束时 `p` 已经移到末尾。**要输出 `max`。**
> 等价写法：`if (car[i] > max) max = car[i];`（不用指针也行，但题目要求用指针，写数组下标会扣分）。

### 应用题 3（10 分）结构体录入与输出 —— 结构体定义 + scanf/printf

**题目**：定义一个结构体类型 `STAFF`，记录员工的姓名、id、入职年份、薪资；
通过输入方式录入一条数据，并打印出这些信息。

**参考解**
```c
#include <stdio.h>
struct STAFF {
    char  name[20];   /* 姓名：字符数组 */
    int   id;         /* 工号 */
    int   year;       /* 入职年份 */
    float salary;     /* 薪资 */
};
int main() {
    struct STAFF s;

    printf("输入姓名：");   scanf("%s",  s.name);    /* 数组名本身就是地址，不加 & */
    printf("输入id：");     scanf("%d",  &s.id);      /* 基本类型必须加 & */
    printf("输入年份：");   scanf("%d",  &s.year);
    printf("输入薪资：");   scanf("%f",  &s.salary);

    printf("\n员工信息如下\n");
    printf("姓名：%s\n", s.name);
    printf("id：%d\n",   s.id);
    printf("入职年份：%d\n", s.year);
    printf("薪资：%.2f\n", s.salary);
    return 0;
}
```
> **考点**：结构体类型声明（C9）+ 成员访问 `.` + `scanf` 取地址规则。
> **三个高频失分点**：
> ① `scanf("%s", &s.name)` —— **多写了 `&`**。`s.name` 是数组名，本身即地址，加 `&` 是画蛇添足；
> ② `scanf("%d", s.id)` —— **漏了 `&`**（基本类型必须取地址）；
> ③ 结构体定义末尾漏分号 `};`。
>
> **老师的加分建议**：若题目没限定 id 类型，**把 `id` 定义成 `char id[20]` 比 `int` 更稳妥**——
> 工号可能是 `"001"`、可能含字母，用 `int` 会把前导零吃掉。

## 考点分布与复习策略

### 2026 考纲复习优先级

| 优先级 | 模块 | 复习目标 |
|:---|:---|:---|
| ⭐⭐⭐ | 控制结构、数组、函数、指针 | 能独立手推和编写完整程序 |
| ⭐⭐⭐ | 线性表、栈、队列、树、图 | 掌握定义、性质和基本操作 |
| ⭐⭐ | 查找、排序、复杂度 | 会写过程、会比较算法 |
| ⭐⭐ | 字符串、结构体、文件 | 掌握常用函数和代码模板 |
| ⭐ | 编译、链接、调试 | 能判断错误发生阶段 |

### 易错点清单

1. **整数运算规则**：`5/2` 是 2，`5/2.0` 才是 2.5。
2. **数组边界**：长度为 $n$ 的数组，合法下标 0 到 $n-1$。
3. **指针与地址**：`p`、`*p`、`&p` 表示的对象完全不同。
4. **字符串结尾**：手动构造字符串必须补 `'\0'`。
5. **树的层数**：第 $k$ 层最多 $2^{k-1}$ 个结点。
6. **复杂度只保留最高阶**：$3n^2+2n+1$ 记为 $O(n^2)$。

### 备考建议

1. **C 语言与数据结构不要偏科**——两部分都可能出现在客观题、简答题和综合题。
2. **程序阅读必须逐行记录变量**——循环题画 `i`、条件、执行语句、结果四列。
3. **应用题先写步骤再写代码**——输入、处理、输出三部分清楚，减少漏条件。
4. **数据结构先画图**——栈、队列、树、图和排序过程用图表示更可靠。
5. **考前限时完成整卷**——前 100 分客观题控制时间，为简答、计算和应用题留足书写时间。
