## ② 🗣️ 零基础大白话

**线性表 = 排成一队的人。** 每个人（元素）有前一个和后一个。

**两种排法：**

| | 顺序表 | 链表 |
|:---|:---|:---|
| 像什么 | 电影院的**连号座位** | 一群人**手拉手** |
| 怎么找第 i 个 | 直接算地址，**O(1)** | 从头一个个数，**O(n)** |
| 中间插入一个 | 后面的人**全部往后挪**，**O(n)** | 解开两只手，插进去，**O(1)** |
| 存储空间 | 连续，可能浪费 | 不连续，多存一个指针 |

**关键记忆**：**顺序表查得快，链表插删快。**

---

## ③ ⚠️ 高频扣分坑（真题验证过）

| # | 陷阱 | 正确结论 |
|:---:|:---|:---|
| 1 | 顺序表在第 i 个位置插入元素的复杂度 | **O(n)**（后面所有元素都要后移） |
| 2 | 顺序表按下标取元素的复杂度 | **O(1)**（直接算地址） |
| 3 | 带头结点单链表为空的判断 | **`head->next == NULL`**（不是 `head == NULL`） |
| 4 | 不带头结点单链表为空的判断 | `head == NULL` |
| 5 | 在 p 之后插入 s 的语句 | `s->next = p->next; p->next = s;` —— **顺序不能反** |
| 6 | 删除 q 所指结点（p 是 q 的前驱） | `p->next = q->next; free(q);` |
| 7 | 单链表能否"随机访问" | **不能**，必须从头顺序找 |
| 8 | 线性表每个元素都有前驱和后继 | **错**。**首元素无前驱，尾元素无后继** |
| 9 | 链表操作必须找到的结点 | **表头结点**（否则无法遍历） |
| 10 | 链式存储的空间组成 | 分两部分：**数据域**（存值）+ **指针域**（存后继地址） |
| 11 | 取第 i 个结点及其前驱，最省时间的存储 | **顺序表**（或双链表）；单链表要遍历两次 |

## ④ 🧪 专项练习

### A 组 · 单选题（每题 3 分，共 30 分）

**A1** 长度为 n 的顺序表，在第 i 个元素之后插入一个新元素，其时间复杂度为（　）
A. O(0)　B. O(1)　C. O(n)　D. O(n²)

**A2** 带头结点的单链表，头指针为 `head`，则单链表为空的判断条件是（　）
A. `head == NULL`　B. `head != NULL`
C. `head->next == NULL`　D. `head->next == head`

**A3** 在单链表中，要将 `s` 所指结点插入到 `p` 所指结点之后，正确的语句是（　）
A. `s->next = p + 1; p->next = s;`
B. `(*p).next = s; (*s).next = (*p).next;`
C. `s->next = p->next; p->next = s->next;`
D. `s->next = p->next; p->next = s;`

**A4** 若有指针 `p` 指向链表中的结点 `q` 的前驱，要将 `q` 所指结点从链表中删除并释放，正确的语句是（　）
A. `p = q; free(q);`
B. `(*p).next = *(*q).next; free(p);`
C. `p->next = q->next; free(q);`
D. `p = q->next; free(q);`

**A5** 对链表进行操作时，必须找到的结点是（　）
A. 中间结点　B. 表层结点　C. 任意结点　D. 表头结点

**A6** 链式存储的存储结构所占空间（　）
A. 分两部分，一部分存放结点值，另一部分存放表示结点间关系的指针
B. 只有一部分存放结点值
C. 只有一部分存放结点间关系的指针
D. 分两部分，一部分存放结点值，另一部分存放结点所占单元数

**A7** 如果常用的操作是取第 i 个结点及其前驱，最省时间的存储方式是（　）
A. 单链表　B. 双链表　C. 顺序表　D. 循环链表

**A8** 关于线性表 `L = (a₁, a₂, ..., aₙ)`，下列说法正确的是（　）
A. 每个元素都有且仅有一个直接前驱和一个直接后继
B. 首元素无直接前驱，尾元素无直接后继
C. 所有元素都没有直接前驱
D. 所有元素都没有直接后继

**A9** 顺序表与链表相比，其优点是（　）
A. 插入删除效率高
B. 可以随机访问，存储密度高
C. 不需要预先分配空间
D. 存储空间一定更省

**A10** 在单链表中，若要在结点 `p` 之前插入结点 `s`，在只知道 `p` 的情况下，可行的方法是（　）
A. 直接修改 `p->next = s`
B. 无法实现
C. 先在 `p` 之后插入 `s`，再交换 `p` 与 `s` 的数据域
D. 必须先遍历整个链表

### B 组 · 判断题（每题 2 分，共 8 分）

**B1** 顺序表可以随机访问，链表只能顺序访问。（　）

**B2** 在单链表中删除一个结点，必须知道该结点的前驱。（　）

**B3** 线性表中每个元素都有一个直接前驱和一个直接后继。（　）

**B4** 链式存储的结点一定存放在连续的内存单元中。（　）

### C 组 · 简答题（10 分）

**C1** 简述顺序表存储结构的优缺点。

### D 组 · 计算题（10 分）

**D1** 已知单链表结点结构为 `struct node { int data; struct node *next; };`，头指针为 `head`（带头结点）。写出以下两个操作的关键语句：
（1）统计链表中数据值大于 50 的结点个数（用变量 `count` 计数）；
（2）删除链表中第一个数据值为 `x` 的结点。

## ⑤ ✅ 答案与解析

::: details A 组 · 单选题答案
**A1 → C（O(n)）** 在第 i 个位置之后插入，需要把 i 之后的所有元素后移一位，平均移动 n/2 个，量级为 O(n)。

**A2 → C（`head->next == NULL`）** **带头结点**时，头结点本身不为空，判空看头结点的 `next`。若无头结点则为 `head == NULL`。

**A3 → D** 正确顺序：**先接后断**。
1. `s->next = p->next;`（让 s 先指向 p 原来的后继）
2. `p->next = s;`（再让 p 指向 s）

A 是地址算术错误；B 先改 `p->next` 会丢失原后继；C 把 `s->next` 又指回 `p->next`（此时已是 s 自己），形成自环。

**A4 → C** 删除 q：让 p 跳过 q，指向 q 的后继，然后释放 q。

**A5 → D（表头结点）** 链表只能从头开始遍历，找不到表头就无法访问任何结点。

**A6 → A** 链式存储结点分**数据域**和**指针域**两部分。

**A7 → C（顺序表）** 顺序表按公式 `Loc(a_i) = Loc(a_1) + (i-1)×L` 直接定位，取第 i 个和它的前驱都是 O(1)。

**A8 → B** 线性表首元素无前驱、尾元素无后继。A 错在"每个元素"。

**A9 → B** 顺序表优点：**随机访问 + 存储密度高**（不需要额外指针域）。缺点是插入删除慢、需预先分配连续空间。

**A10 → C** 经典技巧：在 `p` 之后插入 `s`，然后**交换 p 与 s 的数据域**，逻辑上等价于在 p 之前插入。这是 O(1) 的解法。
:::

::: details B 组 · 判断题答案
**B1 → ✓ 对** 顺序表支持随机访问（O(1)），链表只能顺序访问（O(n)）。

**B2 → ✓ 对** 单链表删除结点需要修改前驱的 `next` 指针，因此必须知道前驱。

**B3 → ✗ 错** 首元素无前驱，尾元素无后继。

**B4 → ✗ 错** 链式存储的结点通过指针链接，**物理上可以不连续**。
:::

::: details C 组 · 简答题参考答案
**顺序表的优点：**
1. **可以随机访问**。通过下标直接计算元素地址，时间复杂度 O(1)。
2. **存储密度高**。只需存储数据本身，不需要额外的指针域。
3. **存储空间利用率高**，且实现简单。

**顺序表的缺点：**
1. **插入和删除效率低**。平均需要移动约一半的元素，时间复杂度 O(n)。
2. **需要预先分配固定大小的连续空间**。估计过大浪费空间，估计过小会溢出。
3. **存储空间要求连续**。对内存碎片敏感。

> 💡 **答题要点**：优点 2–3 条 + 缺点 2–3 条，每条一句话说清"是什么 + 为什么"。这类题按点给分，**不要写成一大段**。
:::

::: details D 组 · 计算题参考答案
**（1）统计数据值大于 50 的结点个数**
```c
int count = 0;
struct node *p = head->next;    /* 带头结点，从头结点的后继开始 */
while (p != NULL)
{
    if (p->data > 50) count++;
    p = p->next;
}
```

**（2）删除第一个数据值为 x 的结点**
```c
struct node *p = head;
while (p->next != NULL && p->next->data != x)
    p = p->next;                 /* 找 x 的前驱 */
if (p->next != NULL)
{
    struct node *q = p->next;
    p->next = q->next;
    free(q);
}
```

> ⚠️ **三个易丢分点**：① 带头结点时必须从 `head->next` 开始，不是 `head`；② 循环条件必须先判 `p->next != NULL` 再访问 `p->next->data`（否则空指针）；③ 删除后要 `free(q)`，题目要求"释放"。
:::
