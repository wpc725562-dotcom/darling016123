## 二、三个必须先建立的判断

### 判断 1：C 语言是主战场，数据结构是副战场

网上流传「C 语言 45–50%、数据结构 50–55%」——**与真题严重不符**。两年实测：C 语言 138 / 120 分，数据结构 62 / 80 分。

### 判断 2：传统难点（树图查找排序）只占 9.75%

| 模块 | 实测分值 |
|:---|:---:|
| 树和二叉树 | 5.5 |
| 图 | 9.0 |
| 查找 | 3.0 |
| 排序 | 2.0 |
| **合计** | **19.5（9.75%）** |

而「循环 + 数组」两项就有 **64.5 分（32%）**。把时间砸在红黑树、图算法、快排优化上是**方向性错误**。

### 判断 3：数据结构部分考的是概念，不是算法实现

图只考 DFS/BFS 名称、有向图的度、连通图最少边数；树只考第 n 层结点数、完全二叉树叶子数。**不考最小生成树、最短路径、哈夫曼编码的算法细节。**

## 三、推荐刷题节奏

```
第 1 轮（每模块 1–2 天）  01 → 02 → 03 → 04     覆盖 97.5 分
第 2 轮（每模块 1 天）    05（四个中权重模块）   覆盖 49.0 分
第 3 轮（半天）           06（低频速查）         覆盖 53.5 分
第 4 轮                   整卷限时 150 分钟
第 5 轮                   错题三刷
```

> ⚠️ 每做完一个模块，把错题按「公式记错 / 计算失误 / 方法不会 / 读题失误」四类归因，不要只记题目。
