## ② 🗣️ 零基础大白话

**循环 = 重复做同一件事。** 三种写法：

| 写法 | 特点 | 什么时候用 |
|:---|:---|:---|
| `for` | 知道要循环几次 | 最常见，考试主力 |
| `while` | 先判断再执行，可能一次都不执行 | 次数不确定 |
| `do-while` | 先执行再判断，**至少执行一次** | 至少要做一次 |

**两个跳出循环的开关：**
- `break` = **直接砸门走人**，循环彻底结束
- `continue` = **跳过这一轮，回去做下一轮**

## ③ ⚠️ 高频扣分坑（真题验证过）

| # | 陷阱 | 正确结论 |
|:---:|:---|:---|
| 1 | `for(int i=1; i++<4; );` 循环几次 | **3 次**。`i++` 先用后变：判断时 i=1（真，i变2）、i=2（真，i变3）、i=3（真，i变4）、i=4（假，i变5） |
| 2 | `for(int i=1; ++i<4; );` 循环几次 | **2 次**。`++i` 先变后用 |
| 3 | `while(a<4) printf("%d", a++);` 输出 | 输出 `123`（a 从 1 开始，先输出后自增） |
| 4 | `while(a<4) printf("%d", ++a);` 输出 | 输出 `234`（先自增后输出） |
| 5 | `while` 只能用 `break` 退出 | **错**。条件不成立自然退出，`return` 也可退出 |
| 6 | `do-while` 的循环体执行次数 | **至少 1 次**，即使条件一开始就为假 |
| 7 | `continue` 在 `while` 中跳过什么 | 跳过**循环体内剩余语句**，但**仍执行** `while` 的条件判断 |
| 8 | 循环累加的初值 | `sum` 必须初始化为 `0`，否则是随机值 |
| 9 | `for(;;)` 是死循环 | 是。三个表达式全省略 = 无限循环 |
| 10 | 嵌套循环的总次数 | 外层 `n` 次 × 内层 `m` 次 = `n×m` 次，时间复杂度 `O(n×m)` |

## ⑤ ✅ 答案与解析

::: details A 组 · 单选题答案
**A1 → A（3 次）** 关键在 `i++` 是**先用后变**：
- i=1：`1<4` 真 → i 变 2（第 1 次）
- i=2：`2<4` 真 → i 变 3（第 2 次）
- i=3：`3<4` 真 → i 变 4（第 3 次）
- i=4：`4<4` 假 → 退出，i 变 5

共 **3 次**。

**A2 → B（123）** `a++` 先用后变：输出 1、2、3，输出后 a 变 4，条件 `4<4` 假退出。

**A3 → C（234）** `++a` 先变后用：a 变 2 输出 2，变 3 输出 3，变 4 输出 4，`4<4` 假退出。

**A4 → B** `break` 结束整个循环；`continue` 只跳过本次循环的剩余语句。

**A5 → C（do-while）** 先执行后判断，至少一次。

**A6 → B（O(n²)）** 双重循环各 n 次，总执行 n² 次。

**A7 → B（15）** 1+2+3+4+5 = 15。

**A8 → C（7）** 0~9 共 10 个数，其中 `%3==0` 的有 0、3、6、9 共 4 个被 `continue` 跳过，剩 10−4 = **6**。

> ⚠️ **易错点**：这里 `0 % 3 == 0` 也成立，很多人漏掉 i=0 这一轮。正确答案是 **6**。

**A9 → A（012）** i=0 输出 0，i=1 输出 1，i=2 输出 2，i=3 时 `i>=3` 成立 break。

**A10 → C** 三个表达式全省略，条件恒为真，是无限循环。
:::

::: details B 组 · 判断题答案
**B1 → ✗ 错** 条件不成立时自然退出；`return` 也可退出；`goto` 也可。

**B2 → ✓ 对** `do-while` 先执行循环体再判断条件。

**B3 → ✗ 错** `continue` 只跳过本次循环剩余语句，不终止整个循环。终止整个循环的是 `break`。
:::

::: details C 组 · 计算题答案
**C1**
（1）**`n = 5`**

数组 6 个成绩：78、80、95、59、69、84。只有 **59** 小于 60，被 `continue` 跳过。其余 5 个累加，`n = 5`。

（2）两行输出：
```
5
81.20
```
`sum = 78+80+95+69+84 = 406`，`average = 406 / 5 = 81.2` → 格式化 `%.2f` 输出 `81.20`。

> ⚠️ **两个易错点**：① 忘记 `59` 被跳过，算成 `n=6`；② 除法用整数运算。这里 `sum` 是 `float`，`n` 是 `int`，`float / int` 结果为 `float`，**不会**截断。但如果 `sum` 声明为 `int`，`406/5` 就得 `81` 而非 `81.2`。

**C2**
（1）**第一行输出 `21`**

`sub(6) = 6 + sub(5) = 6 + 5 + sub(4) = ... = 6+5+4+3+2+1 = 21`。

（2）**第二行输出 `6`**

`main` 中的 `i` 是**值传递**，`sub` 函数内的 `n` 是副本。`i` 全程未被修改，仍为 **6**。

> 💡 **本题是"值传递"的经典考法**：函数内修改形参不影响实参。
:::

::: details D 组 · 应用题参考代码
**D1**
```c
#include <stdio.h>
int main()
{
    int i, odd = 0, even = 0;
    for (i = 1; i <= 300; i++)
    {
        if (i % 2 == 0)
            even += i;
        else
            odd += i;
    }
    printf("odd=%d, even=%d\n", odd, even);
    return 0;
}
```
结果：奇数之和 `22500`，偶数之和 `22650`。

**D2**
```c
#include <stdio.h>
int main()
{
    int n, i, j;
    long fact, sum = 0;
    scanf("%d", &n);
    for (i = 1; i <= n; i++)
    {
        fact = 1;
        for (j = 1; j <= i; j++)
            fact *= j;
        sum += fact;
    }
    printf("sum=%ld\n", sum);
    return 0;
}
```

> ⚠️ **阶乘必须用 `long`**：`10! = 3628800`，若用 `int` 在部分环境下会溢出。这是评分点。
