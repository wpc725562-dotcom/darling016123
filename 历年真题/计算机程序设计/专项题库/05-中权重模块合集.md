## ② ⚠️ 高频扣分坑

### 2.1 数据运算

| # | 陷阱 | 正确结论 |
|:---:|:---|:---|
| 1 | 整数除法 `5/2` | **2**（截断，非四舍五入） |
| 2 | 取余 `%` 的操作数 | **两边必须都是整型** |
| 3 | `17 - 14 % 10` | `14 % 10 = 4`，`17 - 4 = 13`（`%` 优先级高于 `-`） |
| 4 | `a++` 与 `++a` | `a++` 先用后变；`++a` 先变后用 |
| 5 | 逗号表达式 `(a, b)` | 值是**最后一个表达式的值**，即 `b` |
| 6 | `10 != 9` 的值 | **1**（关系运算结果为 1 或 0） |
| 7 | `!a` 当 `a=4` | **0**（非零取反为 0） |
| 8 | 字符常量与字符串常量 | `'A'` 是字符常量（1 字节）；`"A"` 是字符串常量（2 字节，含 `\0`） |
| 9 | 标识符规则 | 只能由**字母、数字、下划线**组成，**不能以数字开头**，不能用关键字。`&a` 非法 |
| 10 | `a > b > c` 的含义 | 先算 `a > b` 得 0 或 1，再与 c 比较。**不是数学上的连比** |

### 2.2 函数

| # | 陷阱 | 正确结论 |
|:---:|:---|:---|
| 1 | 值传递对实参的影响 | **不影响**。形参是实参的副本 |
| 2 | 递归的必要条件 | 必须有**终止条件**，否则无限递归 |
| 3 | 不同函数中同名变量 | **合法**，作用域独立 |
| 4 | 复合语句中定义的变量 | 只在**该复合语句内**有效 |
| 5 | C 程序能否嵌套调用 | **能**（可以调用其他函数），但**不能嵌套定义** |
| 6 | 递归的优缺点 | 优点：代码简洁、逻辑清晰；缺点：**效率低、占内存（栈开销大）、可能栈溢出** |

### 2.3 结构体

| # | 陷阱 | 正确结论 |
|:---:|:---|:---|
| 1 | 结构体变量成员是否常驻内存 | **所有成员一直驻留在内存中**（两年都考） |
| 2 | 成员访问的两种写法 | `变量名.成员名` 或 `指针->成员名` 或 `(*指针).成员名` |
| 3 | 结构体类型能否嵌套定义 | **能** |
| 4 | 结构体是否是系统直接提供的类型 | **不是**，是用户自定义的**构造类型** |
| 5 | 结构体各成员的数据类型 | **可以不同** |
| 6 | `typedef` 的作用 | 给已有类型起别名，**不创建新类型** |

### 2.4 选择结构

| # | 陷阱 | 正确结论 |
|:---:|:---|:---|
| 1 | `switch` 的 case 穿透 | 无 `break` 会**继续执行后续 case** |
| 2 | `switch` 的表达式类型 | 必须是**整型或字符型**，不能是浮点型 |
| 3 | 悬空 `else` | 与**最近的未匹配 if** 配对 |
| 4 | `if(表达式)` 中表达式类型 | 可以是**任意表达式**（不限于逻辑表达式） |
| 5 | 逻辑短路 | `a && b`：a 为假则不算 b；`a \|\| b`：a 为真则不算 b |
| 6 | `==` 与 `=` | `if(a = 5)` 是**赋值**，恒为真（除非赋 0） |

**D1** 分析下列程序，回答问题。
```c
#include <stdio.h>
int main()
{
    int a, b, c, i;
    for (i = 100; i <= 999; i++)
    {
        a = i % 10;
        b = (i % 100) / 10;
        c = i / 100;
        if (i == a*a*a + b*b*b + c*c*c)
            if (i == 153)
                printf("i=%d,a=%d,b=%d", i, a, b);
    }
    return 0;
}
```
若最终输出 `i=153`，则
（1）`a` 的值是多少？
（2）`b` 的值是多少？

## ④ ✅ 答案与解析

::: details A 组 · 单选题答案
**A1 → B（13）** `%` 优先级高于 `-`：先算 `14 % 10 = 4`，再算 `17 - 4 = 13`。

**A2 → D（`a && b || c`）**
- A `!a` = `!4` = **0**（假）
- B `b && !c` = `3 && !2` = `1 && 0` = **0**（假）
- C `a > b > c` = `(4>3) > 2` = `1 > 2` = **0**（假）
- D `a && b || c` = `(4 && 3) || 2` = `1 || 1` = **1**（真）✓

**A3 → B（206）** 逗号表达式的值是**最后一个表达式的值**，即 `b` = 206。

**A4 → C** 字符串常量必须用**双引号**。A、B 是标识符，D 是非法字符。

**A5 → C（`&a`）** 标识符只能由字母、数字、下划线组成，且不能以数字开头。`&` 不是合法字符。

**A6 → B** 结构体是**用户自定义**的构造类型，不是系统直接提供的。

**A7 → A** 结构体变量的所有成员在程序执行期间**一直驻留内存**（**两年都考这个点**）。

**A8 → C** `if` 后的表达式可以是**任意合法表达式**，非零即真。这是判断题的高频陷阱。

**A9 → A（`75 1`）** `s/60 = 75/60 = 1`（整数除法），匹配 `case 1`：输出 `75`，`n++` 使 n 变 1，`break` 跳出。最后输出 ` 1`。总共 `75 1`。

**A10 → C** 递归**会**增加内存开销（每层调用都要在栈上保存现场）。
:::

::: details B 组 · 判断题答案
**B1 → ✗ 错** 可以是任意表达式，非零即真。

**B2 → ✗ 错** 注释可出现在程序的任何位置。

**B3 → ✓ 对** 不同函数中的变量作用域独立，同名互不影响。

**B4 → ✗ 错** 复合语句中定义的变量只在该**复合语句**内有效，作用域比"函数内部"更小。表述不准确，判错。

**B5 → ✓ 对** C 程序可以嵌套调用函数（但**不能嵌套定义**）。
:::

::: details C 组 · 简答题参考答案
**递归**：如果一个函数在它的函数体内**直接或间接地调用自身**，这种调用方式称为递归调用，这样的函数称为递归函数。

**递归的优点：**
1. **代码简洁**，逻辑清晰，能把复杂问题分解为同类子问题。
2. 与数学定义的形式接近，**可读性强**，适合处理树、图的遍历和分治类问题。

**递归的缺点：**
1. **效率较低**。每次调用都要进行参数传递、现场保存与恢复。
2. **占用较多内存**。每层递归都要在栈上分配空间，递归深度过大会导致**栈溢出**。
3. 若终止条件设置不当，会造成**无限递归**。

> 💡 **答题要点**：必须点出"终止条件"和"栈开销"两个关键词。
:::

::: details D 组 · 计算题答案
**（1）`a = 3`**
**（2）`b = 5`**

`a = i % 10` 取个位 → `153 % 10 = 3`。
`b = (i % 100) / 10` 取十位 → `153 % 100 = 53`，`53 / 10 = 5`（整数除法）。

> ⚠️ **本题考的是整数除法与取余的组合用法**——这是"拆分数字的各位"的标准套路，应用题里也常用。
:::
