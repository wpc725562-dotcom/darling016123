# §1 总流程（**7 步**）

```
① 定位科目与考点
     ↓
② 【B站优先】检索 + 提取网课视频          ← 主素材
     ↓
③ 结合 studio / 笔记站已有内容            ← 补充素材
     ↓
④ 若缺素材 ⇒ 主动抓取（B站搜索 / 网页）
     ↓
⑤ 对比分析（提取讲法 + 找冲突/互补）
     ↓
⑥ 按对比结果讲 + 先问「哪条不懂」
     ↓
⑦ 学生确认理解后 ⇒ 出题 + 落账
```

# §3 🔴 对比分析的**评判标准**

## 3.1 素材提取：怎么判断「一个源好不好」

| 维度 | 好 | 差 |
|:--|:--|:--|
| **分P标题** | **规整**（如 `【第X章】Y.Z 知识点名`） | 只有 `Practice 1`（**要靠字幕内容判断**） |
| **有方法论综述集** | ✅（如完形的「知识综述」） | ❌ |
| **有完整可跑的例子** | ✅（如讲义例 7.1） | 只有零散片段 |
| **挂真题** | ✅（笔记站每节标题号） | ❌ |
| **讲法适合零基础** | 有类比 / 从「为什么」讲 | 直接上定义 |

## 3.2 🔴 对比分析：**找什么**（**4 种关系**）

| # | 关系 | 例子（实测） | 处理 |
|:--:|:--|:--|:--|
| **1** | **一方有、一方没有** | 「3 种函数调用方式」**只有精编讲义有** | **补进讲法** ✅ |
| **2** | **视角不同** | 「值传递」：讲义用**内存视角** · 笔记站用**类比视角** | **两个都讲** ✅ |
| **3** | **深度不同** | 「声明」：讲义**藏在例子里** · 鹏哥**单独两集** | **单独讲**（按鹏哥的深度） ✅ |
| **4** | **顺序不同 / 有依赖** | 「数组传参」三源都在函数章内，但**依赖指针** | **延后**（等 1.8） ✅ |

## 3.3 🔴 判断标准（**一句话**）

> **同一个知识点，如果两个源讲得【不一样】—— 那就是本次讲课的重点。**
> **如果所有源都一样 —— 那说明这个点简单，可以快速过。**

# §4 最终教学内容的**呈现形式**

## 4.1 交付物（**每次开课 3 份**）

| # | 文件 | 模板 |
|:--:|:--|:--|
| **1** | `备考计划/多源讲法对比-<科目><章节>-<日期>.md` | **① 各源怎么讲 ② 对比表 ③ 冲突/互补 ④ 重梳要点 ⑤ 与上版的差异** |
| **2** | `备考计划/讲解覆盖表/<日期>-<块号>-<主题>.md` | **① 规则清单 ② 应试深度 ③ 前置技能（本课+跨科两栏）④ 四要素自检 ⑤ 三张清单** |
| **3** | **（可选）** `编程技能/零基础教程/gcc-<章节>/*.c` | **可跑代码（gcc 验证）** |

## 4.2 讲课的**呈现结构**（**固定 5 段**）

```
① 本课要点清单（几条，编号）
     ↓
② 逐条讲（每条：定义 + 例子 + 易错）
     ↓
③ ⏸️ 暂停 —— 问「哪条还不懂」（不出题）
     ↓
④ 学生指出不懂的 ⇒ 当场补（可换讲法）
     ↓
⑤ 确认理解 ⇒ 出题（填空/选择，不用逐词口述）
```

## 4.3 🔴 三条呈现纪律

| # | 纪律 |
|:--:|:--|
| **1** | **做题材料给【干净版】**（题面无答案标记） |
| **2** | **配对类题用【填空式】**（不用「逐词口述」） |
| **3** | **讲法标注来源**（「讲义原话」「笔记站说」「陶然老师说」） |

# §6 ⚠️ 反面清单（**不许做**）

| # | 不许 | 为什么 |
|:--:|:--|:--|
| **1** | **只用一个源就开讲** | 会漏掉别的源的独有内容 |
| **2** | **讲完立刻出题** | 学生没消化 ⇒ 全错（实测 3 题全错） |
| **3** | **做题材料带答案标记** | 等于边做边看答案 |
| **4** | **用「逐词口述」考配对** | 会错位 ⇒ 误判成「不懂」 |
| **5** | **说「XX 随便」不带后半句** | 学生会以为「和别的无关」 |
| **6** | **用没讲过的符号出题** | `void` 那次，学生直接问「这是什么」 |
| **7** | **跳过「查已有素材」直接抓取** | **已有 141 个 BV，先查再抓** |
