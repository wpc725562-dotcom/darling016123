## 三、今天唯一真正拿下的

**函数里「有类型名 = 新盒子」**

```c
void f() { n = n + 1; }      // 没类型名 → 改外面那个
void g() { int n = 100; }    // 有类型名 → 新盒子，外面不变
```

配套记住的：

- `void` = 这个函数不返回任何值
- `static` 局部变量：初始化只一次，函数结束不销毁（这题一次就过了）
- 字节表：`char` 1 · `short` 2 · `int` 4 · `double` 8 · 指针 8
