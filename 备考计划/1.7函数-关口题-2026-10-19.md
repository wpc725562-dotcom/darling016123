## 一、读程序写输出（4 题）

**1.**（考点：值传递）

```c
#include <stdio.h>
void swap(int a, int b) { int t = a; a = b; b = t; }
int main() {
    int x = 1, y = 2;
    swap(x, y);
    printf("%d,%d", x, y);
    return 0;
}
```

输出：__________

<details><summary>答案</summary>

**`1,2`**

`swap` 收到的是 x、y 的**副本**，函数里交换的是副本，原变量没动。这就是「复印不是原件」。

要真交换，形参得写成 `int *a, int *b`，调用写 `swap(&x, &y)`，函数体里交换 `*a`、`*b`。

</details>

---

**2.**（考点：return 的返回值）

```c
int f(int a, int b) { return a, b; }
```

`f(1, 2)` 的返回值是：__________

<details><summary>答案</summary>

**`2`**

`return a, b;` 里 `a, b` 是**逗号表达式**，整个表达式的值取最后一个，也就是 `b`。

所以「return 一次只能带回一个值」这条铁律成立 —— 写成 `return a, b;` 不是返回两个，是丢掉 a 只返回 b。

</details>

---

**3.**（考点：作用域 / 同名变量）

```c
#include <stdio.h>
int a = 10;
void f() { int a = 20; printf("%d ", a); }
int main() { f(); printf("%d", a); return 0; }
```

输出：__________

<details><summary>答案</summary>

**`20 10`**

`f()` 里的 `a` 是**局部变量**，把全局的 `a` 遮住了（就近原则），所以打印 20，但只影响函数内部。

回到 `main`，全局 `a` 还是 10。

⚠️ 常见错答：`20 20`（以为函数里改了全局）。

</details>

---

**4.**（考点：static 局部变量）

```c
#include <stdio.h>
void f() { static int n = 0; n++; printf("%d", n); }
int main() { f(); f(); f(); return 0; }
```

输出：__________

<details><summary>答案</summary>

**`123`**

`static` 局部变量**只初始化一次**，函数返回后不销毁，下次进来还是上次的值。

如果去掉 `static`（写成 `int n = 0;`），输出是 `111` —— 每次进来都重新初始化。

</details>

## 二、填空 / 计算（2 题）

**5.**（考点：递归）

```c
int f(int n) { return n <= 1 ? 1 : n * f(n - 1); }
```

`f(4)` = __________

<details><summary>答案</summary>

**`24`**

展开：`f(4) = 4 × f(3) = 4 × 3 × f(2) = 4 × 3 × 2 × f(1) = 4 × 3 × 2 × 1 = 24`

这是阶乘。⚠️ 陷阱：如果写成 `n + f(n-1)` 就是求和（答案 10），别混。

</details>

---

**6.**（考点：嵌套调用）

```c
int f(int x) { return x * 2; }
int g(int x) { return f(x) + 1; }
```

`g(3)` = __________

<details><summary>答案</summary>

**`7`**

先算 `f(3) = 3 × 2 = 6`，再 `+1` 得 7。

嵌套调用的顺序是「**由内向外**」：先算最里层，把结果当外层实参。

</details>

## 三、判断（2 题，写「对」或「错」，错的要改对）

**7.**（考点：函数声明）

> 函数声明时，形参的名字必须写出来。

判断：__________

<details><summary>答案</summary>

**错。**

声明只需要类型，可以不写形参名：`int f(int, int);` 完全合法。

定义时必须写形参名（因为函数体要用）。

一句话记：**声明给编译器看「长什么样」，定义给编译器看「怎么干」** —— 前者只关心类型。

</details>

---

**8.**（考点：数组传参）

> 在 64 位系统下，下面这个函数里 `sizeof(a)` 的值是 40（假设 int 占 4 字节、数组有 10 个元素）。

```c
void f(int a[10]) { printf("%d", sizeof(a)); }
```

判断：__________

<details><summary>答案</summary>

**错。**

`a` 在这里已经**退化成指针**（`int *`），`sizeof(a)` 是指针的大小，64 位下是 **8**，不是 40。

这是数组传参最大的坑：**形参写成 `int a[10]` 里的 `10` 编译器根本不看**，它等价于 `int *a`。

要在函数里知道数组长度，必须额外传一个长度参数。

</details>
