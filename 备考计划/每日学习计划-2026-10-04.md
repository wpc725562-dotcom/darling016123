/* 复检① a++ 落地时机（#C003 已销，防回生） */

printf("[%d]", (a++, a * 2));

- **gcc 对账**（我跑，你不用管）：复检① 输出 `[12] a=6`；复检② 输出 `[3和9]`。
- **卡住了怎么办**：回到一句话——「**`a++` 单独出现时就是 `a = a + 1`；逗号表达式从左到右算，**取最后一个**」。

**步骤 2（20 min）1.8-③ 关口题 —— 指针作函数参数**（09-30 已讲、待出题）

> 📕 位置：**8.2.4 指针变量作为函数参数 · 书 p243（物理 p260）**

先**自己说预期输出**（不许先跑），说完再让我 gcc 对账：

```c
/* 题① */
void swap_ok(int *p1, int *p2) { int t = *p1; *p1 = *p2; *p2 = t; }
int a = 3, b = 7;  swap_ok(&a, &b);      printf("① a=%d b=%d\n", a, b);

/* 题② */
void swap_bad(int *p1, int *p2) { int *p; p = p1; p1 = p2; p2 = p; }
int a = 3, b = 7;  swap_bad(&a, &b);     printf("② a=%d b=%d\n", a, b);

/* 题③ */
void by_value(int x) { x = 999; }
int a = 3;  by_value(a);                 printf("③ a=%d\n", a);
```

- **✅ gcc 实测凭据**（本次实跑，`D:/_c-tmp/plan1004.c`，GCC 16.2.0）：
  - ① `a=7 b=3`（换成功）
  - ② `a=3 b=7`（**没变** —— 只换了两个"形参指针"自己）
  - ③ `a=3`（**没变** —— 值传递 = 复印）
- **判据**：三问**都要说出「为什么」**，且答案栏与理由栏**必须互证**（互相矛盾 = 按未过）。
- **关键一问（必须答）**：题①和题②**都是"交换"**，为什么一个成功一个失败？—— 标准说法：**题①换的是"指针指向的格子里的数"，题②换的只是"形参指针自己"**（形参是副本，函数结束就释放）。
- **卡住了怎么办**：只给一个画面 —— **「指针 = 快递柜钥匙」**。`swap_ok` 是**打开柜子、把两柜东西对调**；`swap_bad` 是**把两把钥匙的标签换了**，柜子里的东西根本没动。
- **报分量**：指针是 C 语言**分值最重**的一章（4 年 8 题 / 约 15 分）；2021 简答题直接考「指针 vs 指针变量」。

**步骤 3（5 min）报位置**：下一课 = **1.8-④ 字符串指针（字符指针 vs 字符数组）· 书 p267 / p269（物理 p284 / p286）**。
