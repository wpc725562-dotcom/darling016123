## §2 第一件：升级 Anki（26.9 → 26.09.2）

### 2.1 为什么值得升

| 变化 | 对你的意义 |
|:--|:--|
| FSRS 默认开启、参数自动优化 | 你现在**手动开 FSRS** 的步骤可以省掉，且权重由软件按你的 6183 条记录自动算 |
| 复习队列算法改进 | 直接缓解「每天欠 265 张」 |
| 同步协议改进 | 手机同步更稳 |

### 2.2 操作步骤

```
1. 完全退出 Anki（托盘图标也要退，不是最小化）
2. 运行安装包：anki-26.09.2-win-x64.msi
3. 一路「下一步」——它会覆盖安装，不删数据
4. 重新打开 Anki，确认左下角版本号变成 26.09.2
```

### 2.3 安全网（我会先做）

- **安装包已下载**到：`C:\Users\Administrator\Downloads\anki-update\anki-26.09.2-win-x64.msi`

- **我会额外手动备份一份** `collection.anki2`（含 `-wal` / `-shm`），放在同目录下带日期后缀

> ⚠️ **风险说明**：覆盖安装通常无损，但**如果升级中途断电或安装包损坏**，可能出现数据库需要恢复的情况。
> 有备份 + Anki 自带备份，可完全恢复。**确认后我就执行。**

## §3 第二件：创建 AnkiWeb 账户

### 3.1 注册（你自己做，3 分钟）

```
1. 浏览器打开：https://ankiweb.net/account/signup
2. 填 邮箱 + 密码（密码至少 8 位，别用你其他账号的密码）
3. 提交 → 去邮箱点验证链接
4. 注册完成
```

> 📌 **AnkiWeb 是免费的**，2,292 张卡完全在免费额度内（免费版限制是媒体文件 100 MB，你目前**没有媒体文件**）。

### 3.2 在电脑端登录（你自己做，2 分钟）

```
Anki 里点右上角「同步」（或按 Y）
→ 弹出登录框 → 填刚注册的邮箱密码
→ 登录成功
```

### 3.3 🔴🔴 最关键的一步：**首次同步的方向**

登录后 Anki 会问你：

> **「你的本地数据要上传到 AnkiWeb，还是从 AnkiWeb 下载？」**

| 选项 | 后果 | 你该选 |
|:--|:--|:--|
| **上传到 AnkiWeb** | 本机 2,292 张卡 + 6,183 条复习记录 → 云端 | ✅ **选这个** |
| **从 AnkiWeb 下载** | 云端（**空的**）覆盖本机 → **2,292 张卡全没了** | 🔴 **绝对不要** |

> ## ⚠️ 警告
> **AnkiWeb 现在是空的。如果你选「下载」，本机的 2,292 张卡会被清空。**
> 因为 Anki 的同步是**整库覆盖**，不是合并。
>
> **选之前确认这句**：本机有 2,292 张卡 → 要**传上去**，不是**拿下来**。

## §4 第三件：同步到手机

### 4.1 先看你是哪种手机

| 系统 | 装什么 | 价格 |
|:--|:--|:--|
| **Android** | **AnkiDroid** | ✅ **免费** |
| **iPhone / iPad** | **AnkiMobile** | 💰 **付费**（约 ¥180，官方唯一 iOS 客户端） |

> 📌 AnkiMobile 收费是因为它是**官方**应用、收入用于支持 Anki 开发。
> 你如果是 iPhone 且不想买，**替代方案**：手机浏览器打开 `ankiweb.net` 用**网页版复习**（功能少，但免费）。

### 4.2 手机端步骤（Android · AnkiDroid）

```
1. 应用商店搜「AnkiDroid」→ 安装
2. 打开 → 点「登录 AnkiWeb」
3. 填同一个邮箱密码
4. 同步 → 会问你「用哪边覆盖」
   ⚠️ 手机是空的 → 选「从 AnkiWeb 下载 / 用云端数据覆盖本机」
   （方向刚好和电脑端相反！手机是空的，所以要「下载」）
5. 等同步完成 → 8 个牌组全部出现
```

### 4.3 手机端步骤（iOS · AnkiMobile）

```
1. App Store 搜「AnkiMobile Flashcards」→ 购买安装
2. 打开 → Sync → 登录同一个 AnkiWeb 账户
3. 选「下载 / 覆盖本机」→ 等同步完成
```

### 4.4 同步方向速查（别记反）

| 设备 | 本机数据 | 该选 |
|:--|:--|:--|
| **电脑** | 2,292 张卡（有货） | **上传** ⬆️ |
| **手机** | 0 张卡（空的） | **下载** ⬇️ |

> 口诀：**谁有货，谁上传。**

## §5 同步之后：日常怎么用

| 场景 | 做法 |
|:--|:--|
| 电脑学完 | 点「同步」（或按 Y）→ 上传 |
| 手机上背 | 打开 AnkiDroid → 自动同步 → 背 |
| 手机背完回家 | 电脑打开 Anki → 自动同步（`autoSync` 已开）→ 拿到手机上的进度 |
| ⚠️ 同时改 | **别在电脑和手机同时改同一张卡** —— 会冲突 |

> 📌 你的 `autoSync = true` 已经开着，所以**大部分时候不用手动点**。
> 但**手机背完必须让它同步一次**，否则电脑端看不到进度。

## §7 常见问题

| 问题 | 原因 | 解决 |
|:--|:--|:--|
| 同步卡住不动 | 首次上传 2,292 张卡，数据量大 | 等 2–5 分钟，别重复点 |
| 提示「需要完整同步」 | 两边数据库结构不一致 | 点「完整同步」，按 §3.3 选方向 |
| 手机上少了几张卡 | 同步未完成 | 手动再同步一次 |
| 同步后电脑上的进度倒退 | 选了「下载」 | 🔴 从 `backups/` 恢复，见 §2.3 |
| AnkiWeb 提示存储不足 | 免费额度 100 MB 媒体 | 你没媒体文件，**不会遇到** |
