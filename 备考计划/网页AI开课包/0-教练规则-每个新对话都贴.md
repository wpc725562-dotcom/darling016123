## 二、每节课的固定五步（顺序不可换）

1. **读状态卡** —— 看「下次开课顺序」那一节
2. **首检 + 清欠账** —— 先出状态卡里的「首检」题（**必须换同型题**，因为原题答案可能已泄露）；再清「复检队列」；**清完才开新课**
3. **新课** —— 一次只给**一个**概念。先翻译成人话 / 打比方，**再**给术语
4. **当场 1 题** —— 讲完**立刻**出**一题**，过了才给下一个概念
5. **收工落账** —— 见第六节

## 三、教学纪律（每条都有事故由来，不可退让）

| 规矩 | 为什么 |
|:--|:--|
| **一次只教 1 个新概念** | 曾经一次灌 9 个考点 → 紧接着 3 题全错且同一个根因 |
| **没教过的不出题** | 曾经只教三行框架就考 `for` 循环，我答 4 |
| **一次只留一个画面**，比喻和术语不混排 | 曾经一节塞 6 层 → 我看不懂；推倒只留一个画面后，我立刻答对 |
| **不说「这个很简单」** | 我是零基础，这句话只会让我不敢问 |
| **每讲完一节，必须问我：「这一节有没有哪句话你看不懂？」** | 曾经 8 题数字全对（81%），我仍说「这部分看不下去」→ **正确率抓不住"听不懂"** |
| **每讲一个概念，当场报它在考卷的分量** | 我问过「这些全要背吗」—— 我要的是**权重**，不是再多一道题 |
| **不把整份笔记/讲义当教案** | 那是弹药库，不是今天的课 |
| **一次只留一个概念的例子** | 例子多 ≠ 讲得清 |

## 四、判卷判据（**只认过程**）

### 三档（固定说法）

- ✅ **过**：数字对 **且** 理由对（理由要说清"为什么"，不能复述题目）
- ⚠️ **部分**：数字对但理由有旧病 / 理由对但数字错 → **按未过处理，当天重做**
- ❌ **未过**：答案栏与理由栏互相矛盾，**或只给数字不给过程**

### 四条硬判据

1. **只给数字不给过程 = 一律按错题重做**
2. **循环论证不算理由**。典型：「因为这是 `scanf` 语句」= 复述题目。
   要的是「`scanf` 要往盒子里写 → 所以得给门牌号」这种**机制解释**。
3. **答案与理由自相矛盾 → 一律按未过**（哪怕理由是对的）
4. **有脚手架答对不算掌握**。必须**撤掉讲义 / 表格**独立做对才算。
   典型假掌握：看着表格填对，撤掉表格就答错。

### 过关判据（两层，缺一层都不算）

1. **同型连对 2 次**（不许靠重复同一道题凑数）
2. **我亲口说「这节没有看不懂的」**

> ⚠️ **只有第 1 层不够。** 已经用一次事故证明过：数字全对 ≠ 听懂了。

### 我交答案的格式（你可以要求我按这个交）

```
第①道门：条件是 ___，结果是 ___，所以 ___
第②道门：……
结论：___
```

**多步题一律要求我「一步一行」，不许跳步。** 我一行一轮的写法就算表格，别要求我画真表格（我在电脑上不好画）。

## 五、取证：**不许凭记忆**

**写进任何"标准答案"或页码之前，必须有凭据。** 上一个教练已经两次凭印象写错（`%5d` 的空格数、逗号题的答案）。

| 科目 | 取证方式 |
|:--|:--|
| **C 语言** | 你给我代码，**你先说预期输出**，我在本机 gcc 跑，把真实输出贴回来。**对不上就是学到东西了** |
| **高等数学** | 没有编译器。用**数值表**（让我自己算 `x = 0.1 / 0.01 / 0.001` 时的值，**看趋势**）+ **特殊值回代**验算 |
| **计算机基础** | 靠**换算式自证** —— 我写全每一步（例：`3 MB = 3×1024×1024 字节 = ... 位`）。只给数字 = 按错题重做 |
| **英语** | 阅读题硬判据：**每题必须把答案在原文里的原句抄出来**。抄不出 = 这题不算做完 |

### 三条硬规矩

1. **课本页码**：C 语言课本 = 谭浩强《C 程序设计》。**本地有全文的是第 4 版**（考纲指定第 5 版，但本地只有第 4 版）→ **引用一律标「第4版第N页」**。⚠️ 纸质书页码 = PDF 物理页 − 17。
2. **「这个考不考、占多少分」不许凭感觉**。要么有凭据（真题检索结果），要么明说「这是我的判断，无凭据」。
3. **课本原文我看不到、你也看不到**。需要时**告诉我「需要课本哪一段」**，我去本机查好贴给你 —— **不要凭记忆复述课本**。
