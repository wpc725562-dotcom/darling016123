## 二、🔴 首检（**第一件事，不可跳，这笔不销不开新考点**）

### `x→0` 分岔口

原题 `lim(x→0) 1/x` 的答案已在本话题演示中泄露 → **换同型题重考**。

**主考这道**：

```
lim(x→2)  1/(x-2)  = ?
```

**正确答案**：**极限不存在**。

**理由必须说清（这是判据）**：
- `x→2⁻` 时 `x-2 → 0⁻`，所以 `1/(x-2) → −∞`
- `x→2⁺` 时 `x-2 → 0⁺`，所以 `1/(x-2) → +∞`
- **左右趋近结果不一致 → 极限不存在**

**node 实测数值表（凭据，可贴给他看）**：

```
x=1.9    → -10          x=2.1    → +10
x=1.99   → -100         x=2.01   → +100
x=1.999  → -1000        x=2.001  → +1000
x=1.9999 → -10000       x=2.0001 → +10000
```

（让他自己跑更好：`node -e "for(const x of [1.9,1.99,1.999,2.001,2.01,2.1]) console.log(x, 1/(x-2))"`）

**❌ 如果答 `0`** = 把 `x→∞` 的规则硬套过来了 → **回炉重讲「趋向哪里决定去哪」**，别往下走。

### 🔍 追问（**只有在上面答对后才出**）

```
lim(x→0)  1/x²  = ?
```

**答案**：**极限不存在**（是 `+∞`）。

⚠️ **但这道题的判据不同，别搞错**：`x→0⁺` 和 `x→0⁻` 时 `x²` **都 → `0⁺`**，所以 `1/x²` **两侧都 → `+∞`** ——
**左右是一致的**，不存在的理由是「**无界（无穷大）**」，**不是**「左右不一致」。

> 📌 **出题时请把这两道分开用**：`1/(x-2)` 考「左右不一致」，`1/x²` 考「左右一致但无界」。
> 两道都对才算这格稳。

### 📎 对照（他已过关的那格，可用来对比）

```
lim(x→∞) 1/x = 0
```
实测：`x=10 → 0.1`、`x=1000 → 0.001`、`x=1000000 → 0.000001` → **趋向 0**。

> 💡 **对比点（这是这节课的核心）**：
> **同一个 `1/x`，`x→∞` 时趋向 0；换成 `x→0` 就爆掉。**
> **「趋向哪」比「式子长什么样」更重要。**
