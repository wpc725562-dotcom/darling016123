# §1 🔴 本月唯一的主线：**Jev / System One 决策模型**

> **不先讲这个，后面一半仓库名你都会看不懂**（`laya` / `kev` / `NanoJev` / `jevgrep` / `SemIf-OpenJev` / `jev-guard`…）

## 1.1 Jev 是什么

**一句话**：**它不是聊天模型，是一个「带类型的决策层」。**

| 维度 | 普通 LLM | **Jev** |
|:--|:--|:--|
| 输入 | 自然语言 | **非结构化状态 + 一个「带类型的问题」** |
| 输出 | 一段文本 | **一个「带类型的决策」**：**选项 / 分数 / 是-否**，**每个都带置信度** |
| 定位 | 通用对话 | **嵌进软件里的判定模块** |

**⇒ 用途**：**分类 · 路由 · 评分 · 验证 · Agent 护栏**。

**来源**：TypeSafe AI 的 System One 模型（`typesafe.ai/blog/introducing-system-one-models-and-jev`）。
