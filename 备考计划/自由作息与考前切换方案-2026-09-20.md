# 🌙 自由作息 + 考前切换方案 · 2026-09-20

> **一句话**：自由期用「**锚点**」不用「**钟表**」（不固定时刻，固定顺序与间隔）；
> 考前 4 周按**每周前移 1–1.5 小时**切到固定作息。

**适用前提**（用户 2026-09-20 明确）：日常凌晨 3–4 点入睡，作息不固定。

## 零、先立三个前提

### 0.1 考试锚点：上午 9:00 开考

查到的官方数据（广东省教育考试院 2026 年规定，深圳本地宝转载）：

| 项 | 内容 |
|:--|:--|
| 考试日期 | **2026-03-28（周六）至 03-29（周日）**，两天 |
| 科目数 | **4 门**：2 门公共课（政治理论、英语）+ 1 门专业基础课（高等数学）+ 1 门专业综合课（计算机） |
| 时长/分值 | 公共课与专业基础课 **120 分钟 / 100 分**；专业综合课 **150 分钟 / 200 分** |
| 总分 | **500 分**（100×3 + 200） |
| 时段 | 上午场按历年惯例 **9:00 开考**（⚠️ 表格未抓到原文，以准考证为准） |

> 🔧 **两处修正**（我之前的说法有误）：
> 1. 是 **4 科 500 分**，不是 5 科 —— **计算机专业综合课占 200 分（40%）**，比另外三科各 100 分重一倍。
> 2. **2027 年考试大概率在 3 月最后一个周末（03-27/28）**，而项目倒计时基准用的是 `2027-03-01` —— 比实际**早约 26 天**。
>    **不建议改基准**（保守不是坏事，且改动会波及大量文件），但你要知道：**实际可能多出约 26 天缓冲**。

**为什么这条决定作息**：上午 9:00 开考 → 至少 07:00 起床 → **你的生物钟必须从「3:30 睡」前移到「23:00 睡」**。这不是偏好问题，是硬约束。

### 0.2 完全自由不行 —— 但原因不是「不自律」

**社会时差（social jetlag）**：如果每天入睡时刻随意浮动，相当于**每周跨一次时区**。
后果是持续性的：白天注意力下降、记忆巩固打折、Anki 的「困难」率上升。

所以本方案的「自由」= **时刻自由，但浮动有上限**：
> 🔒 **起床时刻每日浮动 ≤ 2 小时。** 这是唯一一条不能松的约束。

### 0.3 一个前提性提醒

你现在（09-20 01:04）还在工作。这份方案的第一条执行项就是**今晚先睡**。

## 一、自由期作息（2026-09-20 ~ 2027-01-31）

### 1.1 三条硬约束

| # | 约束 | 为什么 |
|:--:|:--|:--|
| 1 | **起床时刻每日浮动 ≤ 2 小时** | 超过就是社会时差，见 §0.2 |
| 2 | **起床后 30 分钟内见强光**（拉开窗帘 / 出门） | 这是校准生物钟**最强**的信号，比任何 App 都有效 |
| 3 | **睡前 60 分钟不学新内容** | 只做回顾、落账、看错题。新内容会推迟入睡 |

### 1.2 锚点式时段表

**T0 = 你当天的起床时刻**（自由定）。全表跟着 T0 平移，**不看钟表**。

| 偏移 | 块 | 时长 |
|:--|:--|:--:|
| T0 + 0:00 | 开机：读昨日落账 + 写下今日 **3 条**目标 | 30 min |
| T0 + 0:30 | **块 A · 高数新内容** | 90 min |
| T0 + 2:00 | 短休（**离开座位**） | 10 min |
| T0 + 2:10 | **块 B · C 语言新内容** | 90 min |
| T0 + 3:40 | 正餐 + 完全离桌 | 90 min |
| T0 + 5:10 | 块 C · Anki | 45 min |
| T0 + 5:55 | 块 D · 英语专项 | 60 min |
| T0 + 6:55 | 块 E · 复检 | 45 min |
| T0 + 7:40 | 落账（看板 / 日志 / 错题本 / 开场卡） | 30 min |
| T0 + 8:10 起 | 自由时间 / 可选二次块 | — |
| **睡前 60 min** | 只回顾，不学新内容 | — |

**举例**（若某天 T0 = 11:00，即凌晨 3:30 睡、睡足 7.5h）：

```
11:00  开机          13:10  C 语言新内容
11:30  高数新内容     14:40  正餐 + 离桌
13:00  短休          16:10  Anki → 16:55 英语 → 18:10 复检 → 18:55 落账
13:10  （接上）       19:25  自由
```

### 1.3 峰值自测 —— 「自由」的关键在这一步

不固定时刻的真正意义，是**把最难的内容放到你自己的精力峰值**，而不是别人说的「早上」。

**做法**（连做 3 天，纸笔记，不用任何工具）：

- 每小时记一次：**「现在能啃下最难的东西吗？」** 1–5 分
- 3 天后找出**两个峰值窗口**（通常一个是起床后 1–4 小时，另一个在睡前 3–6 小时）

然后：

- **峰值窗口 1 → 块 A（高数，最难）**
- **峰值窗口 2 → 块 B（C 语言，次难）**
- 低谷 → 排 Anki、英语、复检这类不需要深度思考的块

> 📌 如果你是典型的夜猫子，峰值大概率在**晚上 21:00–01:00**，那就把块 A 挪到那里 ——
> 本方案不禁止这件事，只要**起床时刻浮动 ≤2h** 和**睡前 60 min 不学新内容**两条不破。

## 二、过渡期（2027-02-01 ~ 02-28，共 4 周）

### 2.1 四周前移表

**目标**：`03:30 睡 / 11:00 起` → `23:00 睡 / 07:00 起`（前移 **4.5 小时**）

| 周 | 日期 | 就寝目标 | 起床目标 | 本周前移 | 备注 |
|:--:|:--|:--:|:--:|:--:|:--|
| **1** | 02-01 ~ 02-07 | **02:30** | 10:00 | 1.0 h | **只提前起床**，不强迫提前睡 |
| **2** | 02-08 ~ 02-14 | **01:30** | 09:00 | 1.0 h | |
| **3** | 02-15 ~ 02-21 | **00:00** | 08:00 | 1.5 h | 开始每周 2 次**考试时段模拟** |
| **4** | 02-22 ~ 02-28 | **23:00** | 07:00 | 1.0 h | 全周按考试作息走 |

> ⚠️ **为什么每周只前移 1–1.5 小时**：生物钟**前移比后移难得多**（后移可以一次跳 3 小时，前移不行）。
> 每周 1–1.5 小时是安全上限，再快会变成「躺下睡不着 → 白天补觉 → 晚上更精神」的死循环。

> 💡 **如果实际考试是 3 月下旬**（见 §0.1），这整张表可以**整体后移 3 周**，节奏更宽松。

### 2.2 过渡期八条要点

| # | 要点 | 具体做法 |
|:--:|:--|:--|
| 1 | **靠提前起床前移，不靠硬躺** | 睡不着就起来，别在床上焦虑。早上提前 30 min 起，晚上自然会困得早 |
| 2 | **起床后立刻见强光** | 拉窗帘 / 出门走 10 分钟。这是前移的最强信号 |
| 3 | **睡前 2 小时避强光** | 屏幕调到最暗，或改用纸笔复习 |
| 4 | **咖啡因截止** | = 目标就寝时刻 **前 8 小时**（第 4 周即 15:00 后不喝） |
| 5 | **午睡 ≤30 min，且 15:00 前** | 睡太久会削掉晚上的睡意 |
| 6 | **不用补觉追** | 周末睡到中午 = 抹掉一整周的成果，这是最常见的失败原因 |
| 7 | **过渡期有 3–5 天低效期，提前排成复习期** | 第 1–2 周**不排新模块**，只做复检 + 错题 + 政治背诵 |
| 8 | **每周 2 次「考试时段模拟」** | 上午 **9:00–11:00** 整块做真题，让大脑习惯那个时段高强度输出 |

### 2.3 过渡期最容易踩的坑

**「第 1 周就崩」的典型路径**：

> 第 1 天硬逼自己 23:00 上床 → 躺到 02:00 睡不着 → 焦虑 → 第 2 天补觉到 12:00 → 前功尽弃 → 放弃

**正确路径**：第 1 周**只动起床时间**（11:00 → 10:00），入睡时间**不管**。
靠「睡眠债」自然让你提前困 —— 这比意志力可靠得多。

## 三、切换完成后的固定作息（2027-03-01 起）

| 时刻 | 事项 |
|:--|:--|
| 07:00 | 起床 + **立刻见强光** |
| 07:30 | 早餐（不喝咖啡，或只喝一小杯） |
| 08:00–08:30 | 轻量回顾（看错题本，不学新内容） |
| **09:00–11:00** | **考试时段**：做真题 / 模考（让大脑在这个时段最兴奋） |
| 11:00–14:00 | 午饭 + 休息（午睡 ≤30 min） |
| 14:00–15:00 | 轻量复习 |
| 15:00–17:00 | 第二场模考（若当天模拟专业课） |
| 17:00–19:00 | 晚饭 + 散步 |
| 19:00–21:00 | 错题回顾、政治背诵 |
| 21:00–22:00 | 放松（**不学新内容**） |
| 22:00 | 洗漱、避光 |
| **23:00** | 就寝 |

> 📌 **固定期最重要的不是「几点睡」，是「09:00–11:00 大脑最清醒」这件事被训练出来。**
> 所以第 3–4 周起，每周至少 2 次把最难的题放在 9:00–11:00 做。

## 四、这套方案的风险

| 风险 | 表现 | 应对 |
|:--|:--|:--|
| **过渡期拖期** | 第 1 周没执行 → 后面压缩 | 过渡期只准后移、不准压缩（压缩 = 失眠） |
| **考试时段与假设不符** | 若下午场为主，起床时间可放宽 | 拿到准考证后按实际时段**微调**，不用重排 |
| **社会时差** | 自由期起床浮动超 2h | 这是自由期唯一的红线 |
| **把作息当成绩** | 作息调得很漂亮，推进日密度还是 23% | 见 [高强度学习方案](./高强度学习方案-2026-09-20.md)：**密度才是主指标** |
