## 第二部分 · 离线 AI 学习工作流（核心）

### §4 先说清楚：AI 在你的学习链里干了什么

把现在的流程拆开，看**哪一步真的离不开 AI**：

| 步骤 | 干什么 | 非 AI 不可？ |
|:--:|:--|:--|
| ① 取字幕 | `bili_fetch_subs.py` 下载字幕 | ❌ 纯脚本 |
| ② **切单元** | 把一集字幕切成知识点单元 | ❌ **可用规则**（按小标题/时长切） |
| ③ **提炼卡片** | 单元 → 要点/关键概念/相互关系 | ✅ **这一步是 AI** |
| ④ 合并去重 | 跨课合并同义知识点 | 🟡 半自动（相似度可做，语义需 AI） |
| ⑤ 落站 | `bili_build_knowledge_map.py` | ❌ 纯脚本 |
| ⑥ 讲 / 出题 / 判卷 | 教学 | ✅ AI（但可退化为「照已有地图讲」） |

> **⇒ 结论：整条链里，只有第 ③ 步「提炼」和第 ⑥ 步「教学」真正依赖 AI。**
> **其余全是脚本。所以离线方案的靶心是：把 ③⑥ 两步从 API 搬到网页版。**

### §5 三级降级链（这是解决方案的骨架）

```
L1 有 API（现在）
   └─ 全自动：脚本 + API 提炼 → 地图自动生长

L2 没有 API，但有网页版免费 AI（你要的）
   └─ 半自动：脚本「打包资料」→ 人工粘进网页 AI → 粘贴结果回来 → 脚本落站
   └─ 关键：把「复制粘贴」标准化，一次只搬一个单元

L3 完全没有 AI（极端情况）
   └─ 纯手工：用「读原文 + 套已有地图的句式」自己写卡片
   └─ 关键：已有 4172 条知识点当地图参照，你是在「补」不是在「造」
```

### §6 L2 详细流程：网页 AI 版（你要的那条）

**核心设计原则：把「一次对话」压缩成「一次复制 + 一次粘贴」。**

#### 6.1 打包（脚本做，不用你手动拼）

我写了个工具 `scripts/offline-pack.py`：

```bash
# 打包一集字幕 + 提示词 → 一个文件，整段复制进网页 AI
python scripts/offline-pack.py --bv BV1QKbZ6xEea --p 4 --task extract

# 多源对比打包（同考点取 2-3 源）
python scripts/offline-pack.py --bv BV1QKbZ6xEea:4,BV1Do4y1h7om:1 --task compare

# 出题打包
python scripts/offline-pack.py --bv BV1QKbZ6xEea --p 4 --task quiz
```

产物落在 `data/offline-feed/<名字>.md`，**打开就是「提示词 + 语料」的完整一段**，全选复制即可。

#### 6.2 四种固定任务（模板固定，你不用每次想怎么问）

| `--task` | 用途 | 输出格式 |
|:--|:--|:--|
| `extract` | 提炼知识点卡片 | 严格照知识地图的「要点/关键概念/相互关系」三行格式 |
| `compare` | 多源讲法对比 | 冲突表 + 合并讲法 |
| `quiz` | 出题 | 题 + 答案 + 依据（不给出题理由以外的废话） |
| `explain` | 讲解 | 按你的水平讲（零基础、结论先行） |

> **为什么模板要固定**：网页 AI 每次输出格式不一样，粘回来就没法落站。**固定格式 = 可以脚本化落站。**

#### 6.3 回填（脚本做）

AI 的输出粘进 `data/offline-feed/out-<名字>.md`，然后：

```bash
# 校验格式 + 合并进地图源 + 重新落站
python scripts/offline-merge.py --in data/offline-feed/out-xxx.md --subject english
```

> ⚠️ `offline-merge.py` 我**这轮没写**（怕你还没定格式就先造工具，属「完善工具式伪勤奋」）。
> **先把 `offline-pack.py` 用起来，格式跑顺了再补 merge。**

#### 6.4 每次的成本（诚实估算）

| 项 | 量 |
|:--|:--|
| 一集字幕 | 约 2,000–4,000 字（如娜娜 P4 = 2054 行） |
| 网页 AI 单次可吃 | 通常够（Kimi / 豆包 / 通义 都支持长文） |
| 单次耗时 | 复制 10 秒 + 粘贴 5 秒 + AI 生成 30–60 秒 ≈ **1–2 分钟** |
| 一个源（18 集） | 约 **30 分钟** |

> **⇒ 结论：L2 的代价是「一个源半小时」。这完全可接受** —— 你本来一个源就要看好几小时。

### §7 L3 兜底：完全没有 AI 怎么办

**不慌，因为「地图」已经在硬盘上了。**

| 场景 | 做法 |
|:--|:--|
| 要**讲**一个知识点 | 打开 `knowledge-map/` 对应页 → **按已有条目的「要点」自己复述**（费曼） |
| 要**查**某考点考不考 | 用 `真题词频表.json` + 我加的「真题依据」（**纯统计，不用 AI**） |
| 要**出题** | 真题原卷（`历年真题/真题txt/`）就是最好的题库 —— **直接做真题，比 AI 出的题准** |
| 要**判卷** | 对答案 + 自己写「错因」（比 AI 判卷更清楚你错在哪） |
| 要**补新源进地图** | 读原文 → 照已有卡片的**三行格式**自己写（有 4172 条样例可抄） |

> **一句话：AI 是加速器，不是发动机。** 发动机是「真题 + 已有地图 + 你自己的脑子」。

## §10 🆕 本轮额外发现并修复：地图里有一节**过时内容**

| 项 | 内容 |
|:--|:--|
| **位置** | `docs/guide/knowledge-map/english/grammar.md` 末节「试卷结构与命题特征」 |
| **问题** | 该节来自**乐贯中西（2021 年真题课）**，讲的是**改革前**结构：<br>「`Part One vocabulary and structure` 占 30%，30 道四选一语法单选」 |
| **事实** | **2022 年题型改革已取消该题型** ⇒ 现结构是「语法填空 15 + 七选五 10」 |
| **危害** | 你按地图复习会去练一个**已经不考的题型**（30 分的大题！） |
| **为什么不删正文** | 那是**那门课的真实内容**，删了就丢了「当年考什么」的事实 —— 正确做法是**分层标注**（同高数考纲的处理） |
| **修法** | 在生成器 `bili_build_knowledge_map.py` 里加 `STALE_NOTES`，**重跑脚本也会保留**（之前只在页面手加警告，一重跑就没了） |
| **验证** | 重跑后 `diff` 确认**只有这一个文件变**，且只多出 4 行警告 |

> **⇒ 这条是「优化知识地图」最实在的一笔**：不是加内容，是**挡住一个会让你白练的坑**。
