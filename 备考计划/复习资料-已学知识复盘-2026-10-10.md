## 一、C 语言（1.1 – 1.8 已学）

### 1.1 程序设计与 C 语言基本概念 ✅ 已过

- 程序＝一组计算机能识别和执行的指令
- C 程序结构：`#include` 预处理 → `int main()` 主函数 → 花括号 → `return 0`
- **最小框架默写 20/20 过关**（唯一「全对」的一格）
- 运行链：源程序 → 编译 → 连接 → 可执行文件
- 算法五特性：有穷性 · 确定性 · 有零个或多个输入 · 有一个或多个输出 · 有效性

### 1.2 数据的存储与运算 🟡 已过·有回生

- 变量＝盒子；`=` 是「**塞**」不是「相等」
- 基本类型：`int` · `float` · `double` · `char`
- **整数除法截断**：`7/2 = 3` —— 砍小数的刀在**除法那一刻**，不在 printf
- 取余 `%`：`7%2 = 1`（是求余，不是百分号）
- `a++` / `++a`：加号站哪边，哪边先做事（`a++` 递旧值，`++a` 递新值）
- **字符 `'7'` 的编号不是 7**（ASCII 55）
- 标识符规则；逗号表达式取最右
- 优先级：算术 > 关系 > 赋值

### 1.3 顺序程序设计 ✅ 整节完结

- **printf 坑位数**：格式串里有几个 `%`，就要几个参数
- 逗号的两副面孔：分隔符 / 逗号运算符（`(a,7)` 取 7）
- `%5d` = 至少占 5 格；`%f` 默认 6 位小数；格式串里的普通字符原样印
- **scanf 要 `&`，printf 不要** —— 理由不能说成「因为这是 scanf 语句」（循环论证）
- **scanf 吃换行符**：修法只记一种 —— `scanf(" %c", &ch)`（那个空格＝清洁工命令）
- `getchar()` 逮谁算谁；格式串里有逗号，输入必须打逗号

### 1.4 选择结构程序设计 ✅ 六课全完结

- **条件＝门卫**：只有 0 是假，非 0 全为真（`if(-8)` 会进去）
- `if-else` 两条路；`=` 塞 vs `==` 问：`if(a=3)` 合法、程序不报错、把 3 塞进 a
- `else if` 阶梯：从上往下问，只进第一个说「是」的门；**门槛必须从大到小排**
- 嵌套 if：`else` 配**最近的未配对** `if`；大括号能把 `else` 拉到外层
- 逻辑运算符 `&&` `||` `!`：表达式有值；注意短路求值
- **switch**：括号里放的是**值**；匹配完**不会自动停**（穿透）；`default` 是标号、**也会穿透**；穿透按**物理顺序**，不按 case 数值

### 1.5 循环结构程序设计 ✅ 六课全完结

- **while**：先判断后执行；三件套（初值 / 条件 / 更新）缺一就死循环；末尾**不加**分号
- **do-while**：先执行后判断；末尾**必须**加分号
- **for 三件套** + 末尾分号陷阱：多一个分号，大括号就掉到循环外
- `break` 跳出整个循环 / `continue` 跳过本次
- **循环结束后循环变量多走一步**（`break` 出去不是多走一步）
- **累加器必须先初始化**；计数器 vs 累加器是两个盒子
- 嵌套循环：内层上限可以跟着外层变
- 不在花括号里的行只跑 1 次；`while` 里 `continue` 写在 `i++` 之前会卡死

### 1.6 用数组处理批量数据 ✅ 整节完结

- **数组＝一排格子**；下标从 0 开始 ——「第几格」和「下标几」不是一回事
- 方括号前**有类型名＝定义**，**没有＝引用**
- 初始化：写不满补 0；清零写 `= {0}`；**不给初值是随机值**
- 字符数组：`char c[]="abc"` 占 **4 格**（自动加 `\0`）；`char e[]={'a','b'}` 只有 2 格、**没有 `\0`**（危险写法）
- **sizeof 数格子（含 `\0`），strlen 数字符（不含 `\0`）**，差的正好是 1
- **二维数组按行存放**：先第 1 行再第 2 行；`a[3][4]` 的第 5 个是 `a[1][0]`
- 二维数组＝数组的数组 ⇒ `x` 和 `x[0]` 都是 `x[0][0]` 的地址（2024 第 26 题）
- 字符串函数：`strcpy` / `strcat` / `strcmp` / `gets` / `puts`；字符数组 I/O：`%c` vs `%s`

### 1.7 用函数实现模块化程序设计 ✅ 四课全完结

- 定义 / 声明 / 调用；**形参＝形式占位（定义里）· 实参＝实际的值（调用里）**
- **值传递＝复印**：函数改不了外面的普通变量；**但数组传参会变**（传的是地址）
- `return` 规则；3 种调用方式（语句 / 表达式 / 实参）；嵌套调用
- **作用域** + `static`（＝静止的）：同一函数内同名会**遮蔽**，不同函数间**完全独立**
- **递归**（五星必考）：2023 计算题必考
- 库函数 vs 自定义函数

### 1.8 地址与指针 ★ 分值最重 🟡 7 课已讲·待巩固

## 二、重点解析 · 指针三缺口（C 语言）

> 首测背景：1.8 此前**讲了 7 课、零练习**，首测 **0/10**。

**① `p` 与 `*p` 不能对调**  
`p` 里存的是**地址**，`*p` 才是**内容**。`p` 是指针变量本身，`*p` 是它指向的那个格子。

**② `sizeof` 是运算符不是函数**  
问的是「占多少字节」，**编译期**就算好。数组名一旦参与运算就**降级成指针**：`sizeof(a)`=20 而 `sizeof(a+0)`=8。

**③ 二维数组：「层」与「间」**  
`a` 管「层」（一行 20 字节），`a[0]` 管「间」（一个元素 4 字节）。传参时形参真实类型是 `int (*)[5]`，**不是 `int**`**。

**🔴 未过关残留：C 下标从 0 数**（4/7）  
n 个元素 ⇒ 下标 **0 ~ n−1**；`a[n]` 就是**越界**。`int a[5]` 是 5 个、下标 0~4。  
`strlen("Hello")` = **5**（不数 `\0`）｜`sizeof(s)` = **6**（数 `\0`）。

### 重点解析 · 五条核心判据

**① 趋向哪，比式子长什么样更重要**  
同一个 `1/x`：`x→∞` 时趋向 0；换成 `x→0` 就爆掉。**先看趋向，再选方法。**

**② `x→∞`：抓大头**  
只留最高次项，答案＝最高次**系数比**。例：`(3x²+2x)/(x²−1) → 3`。

**③ `x→0` 分岔口：左右一致还是不一致**  
偶次方（`(x−2)²`）⇒ 消符号 ⇒ 左右一致 ⇒ `+∞`；奇次方（`(x−2)³`）⇒ 保留符号 ⇒ 左右反号 ⇒ **不存在**。  
⚠️ 两种「不存在」要分清：`1/(x−2)` 是**左右不一致**；`1/x²` 是**左右一致但无界**。

**④ `0/0` 型三条路**  
约分 → 有理化（同乘共轭式 + 平方差）→ 等价无穷小替换。  
等价无穷小：`sin(3x) ~ 3x`；`1−cos x ~ x²/2`。

**⑤ 判连续要三个相等**  
**左极限 = 右极限 = 函数值**。间断点先找「使分母为零的点」（最高频考法）。  
跳跃间断点＝左右极限存在但不等；可去间断点＝左右极限相等。
