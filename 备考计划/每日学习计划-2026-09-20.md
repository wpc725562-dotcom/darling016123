### 块 A · 高数：$\frac{0}{0}$ 型极限第一课（75 min）★

**为什么排第一**：高数断档 **10 天**（最后 09-10），是全项目挂最久的一科；且高数 100 分、目标 85 分，**得分率要求最高**，却是"最容易靠刷题提分"的一科。高强度方案 §1.2 也写了：**块 A / 块 B 不可被挤掉**。

**⚠️ 高数无课本全文** → 讲解一律标 ⚠️ 推算，取证用 **node 数值表**。

**只教一个概念（不许加第二个）**：

> **代入得 $\frac{0}{0}$，说明分子分母里有共同的「零因子」—— 约掉它，再代入。**

就这一句。**不教**洛必达、不教等价无穷小替换（那是另一课）、不教有理化。

**步骤**：

1. **先看现象**（5 min）—— 让他自己跑，不靠讲：
   ```bash
   node -e "for(const x of [1.9,1.99,1.999,2.001,2.01,2.1]) console.log(x, ((x*x-4)/(x-2)).toFixed(6))"
   ```
   ✅ **实测输出（2026-09-20 14:46，本次已跑）**：

   | x | (x²−4)/(x−2) | 从哪边来 |
   |:--|:--|:--|
   | 1.9 | **3.900000** | 左 |
   | 1.99 | **3.990000** | 左 |
   | 1.999 | **3.999000** | 左 |
   | 2.001 | **4.001000** | 右 |
   | 2.01 | **4.010000** | 右 |
   | 2.1 | **4.100000** | 右 |

   → **两边一起奔向 4** ⇒ 极限存在，等于 **4**。

2. **讲概念**（10 min）：为什么不能直接把 $x=2$ 代进去？—— 代进去是 $\frac{0}{0}$，**不是数**，写 $\frac00$ 当答案 = 0 分。
   但表里明明有个数（4），说明 **$\frac00$ 只是"形式上的"，底下藏着一个真答案**。

3. **题 1**（15 min）：
   $$\lim_{x \to 2}\frac{x^2-4}{x-2}$$
   - 约分：$x^2-4=(x+2)(x-2)$ → $\dfrac{(x+2)(x-2)}{x-2}=x+2$ → 代 $x=2$ → **4**
   - **必须写过程**，不能只写 4（硬判据：只给数字不给过程 = 按错题重做）
   - 与上一步的数值表对账：**对上了才算过**

4. **题 2**（15 min）—— **答案刻意错开**（抓"搬上一题答案"）：
   $$\lim_{x \to 3}\frac{x^2-9}{x-3}$$
   - 正确 **6**（不是 4）
   - ✅ **node 实测（14:46）**：2.9→**5.900000**、2.999→**5.999000**、3.001→**6.001000**、3.1→**6.100000**
   - ⚠️ 答 4 = 直接搬上一题 → 当场指出，按未过处理

5. **干扰项**（10 min，选做，只为破"套公式"）：
   $$\lim_{x \to 2}\frac{x-2}{x^2-4}$$
   - ✅ **node 实测（14:46）**：1.9→0.256410、1.99→0.250627、2.01→0.249377、2.1→0.243902 → 收敛到 **0.25 = 1/4**
   - 这题是"上下颠倒"，专门治"看见 $x^2-a^2$ 就条件反射约成 $x+a$"

**判据**：独立算出 **且** 说清「为什么不能直接代入」。只给数字不给理由 = 按未过。

**卡住了怎么办**：
- 约分想不起来 → 回初中：$(a+b)(a-b)=a^2-b^2$，用 $x=3$ 验算 $(3+2)(3-2)=5\times1=5$ 而 $3^2-4=5$ ✅
- 还卡 → 退回**只做数值表**（不要求约分），今天只完成"看出趋势"这一步，把约分记进欠账

### 块 B · C 语言：1.5 循环结构第一课 `while`（75 min）★

**课本锚点**：**书 p132（物理 p149）**，5.1 节。已实查原文：
> 「当表达式为非 0 值（代表逻辑值"真"）时，执行 while 语句中的内嵌语句……**while 循环的特点是：先判断表达式，后执行循环体**。」
> 「循环体如果包含一个以上的语句，应该用大括号括起来……**如果不加大括号，则 while 语句的范围只到 while 后面第一个分号处**。」

**只教一个概念**：

> **`while (条件) { 要做的事 }` —— 回来问一次条件，真就再做一遍，做完再回来问，直到条件假为止。**

一个画面：**门口保安反复验票**（对比 1.4 的 `if` = 保安只验一次就放行/拦下）。

**⚠️ 前置检查（出题前必做，这是纪律）**：题面里每个符号都要在「已过关」清单里点一遍。
本题面只用到：`int` / `while` / `<=`（09-20 已补关系运算符全表）/ `printf` / `%d`（已过）/ `i++`（#C003 已销）。**全部教过 ✅**

**步骤**：

1. **讲概念**（15 min）：先讲课本原文那两句 + 「先判断、后执行」。
   **讲完必问一句**：「这一节有没有哪句话你看不懂？」—— 他答了才继续（09-14 事故立的规矩：正确率抓不住"听不懂"）。

2. **题 1**（20 min，人肉编译 → 再 gcc 对账）：
   ```c
   int i = 1;
   while (i <= 3) {
       printf("%d", i);
       i++;
   }
   ```
   - ✅ **gcc 实测（2026-09-20 14:47）**：输出 **`123`**
   - **必须交过程**（一行一轮，这就是"表格"，别再被格式卡住）：
     | 轮 | 进门前 `i` | 条件 `i<=3` | 印出 | 出门后 `i` |
     |:--:|:--:|:--:|:--:|:--:|
     | 1 | 1 | 真 | `1` | 2 |
     | 2 | 2 | 真 | `2` | 3 |
     | 3 | 3 | 真 | `3` | 4 |
     | 4 | 4 | **假** | 停 | 4 |

3. **题 2**（20 min，**过了题 1 才给**）—— **答案刻意错开**：
   ```c
   int j = 1;
   while (j <= 5) {
       printf("%d", j);
       j = j + 2;
   }
   ```
   - 正确 **`135`**（不是 `123`）
   - ✅ **gcc 实测（14:47）**：输出 **`135`**
   - ⚠️ 答 `123` = 搬上一题 → 按未过，当场指出

4. **陷阱判断题**（15 min，**只判断，不许真跑**）：
   ```c
   int k = 1;
   while (k <= 3)
       printf("%d", k);
       k++;
   ```
   问：这段输出什么？
   - 正解：**会无限打印 `1`，永远停不下来**。因为 `k++` 不在循环体里 —— 没加大括号时，`while` 的范围**只到第一个分号**。
   - 🚫 **警告：绝对不要真跑这段**（今天教练自己跑它，输出灌了 1.9GB 日志、进程被强杀）→ **先判断，再讲原理**。
   - ✅ **对照凭据（安全版，14:47 实测）**：
     ```c
     int k = 1;
     while (k <= 3)
         printf("%d", k++);
     printf(" | k=%d", k);
     ```
     输出 **`123 | k=4`** —— 单语句时大括号可以省，但**只要多一句就必须加**。
   - 📌 这条是 1.3a 讲义「花括号管到哪一行」的**同型迁移**（已教过，不是新概念）。

**判据**：数字对 **且** 理由对（理由要能说"为什么"，复述题目 = 循环论证 = 按未过）。
**答案栏与理由栏互相矛盾 = 一律按未过**（#C006 立的判据）。

**卡住了怎么办**：
- 不会填表 → 提醒「一行一轮的写法就算表格」（09-13 已确认，别再被格式卡住）
- 分不清 `i` 和 `s`（累计器 / 计数器混淆是 09-10 的老病）→ 这题只有一个变量 `i`，不存在混淆；若他仍混乱，**退回最小版** `int i=1; while(i<=2){printf("A"); i++;}`（gcc 应输出 `AA`）
- 超过 10 分钟没动笔 → 照抄解答一遍 → 合上默写（零基础正确用法，不要硬憋）

### 块 E · 高数复检：左右分岔口换同型题（10 min）

**为什么复检这个**：09-19 刚销账（挂了 9 天），`n=1` 最易回生。这是"跨日"的第二次测量。

**题（换同型，不用原题）**：
$$\lim_{x \to 4}\frac{1}{x-4}$$

- ✅ **node 数值表自己跑**（让他跑，不靠讲）：
  ```bash
  node -e "for(const x of [3.9,3.99,3.999,4.001,4.01,4.1]) console.log(x, 1/(x-4))"
  ```
  → 左边（3.9/3.99/3.999）应得 **−10 / −100 / −1000**；右边（4.001/4.01/4.1）应得 **+1000 / +100 / +10**
- **正解**：**不存在**（左奔 $-\infty$、右奔 $+\infty$，两边终点不同）
- **判据**：结论 + **说清左右各奔向哪里**。只写"不存在"不给理由 = 按未过。
- ⚠️ **常见错误**：答 `0` = 把 $x\to\infty$ 的规则硬套 → 回炉 [1.11 讲义第四节](/posts/math/notes/1.11-极限求值零基础-抓大头)
- 📌 **顺带防回生**：上轮打掉的隐患是"判据是**两边终点是否相同**，不是**符号是否相同**"。若他答"因为符号不同所以不存在"，追问一句：$\lim_{x\to2}(x-2)$ 两边符号也不同，为什么那个存在？
