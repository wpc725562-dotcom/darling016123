## §1 各源**怎么讲**

### ① 鹏哥 p115（**字符指针**）

> 📁 **可回溯定位**：`BV17a7K64ELH`（UP 主「鹏哥C语言」）**P115「115.【指针】字符指针」**
> → `data/bili-analyze/BV17a7K64ELH/subtitle_p115.txt`

**两种用法**：
```c
char ch = 'w';
char *pc = &ch;        // 用法1（学过）：指向一个字符
char *ps = "abcdef";   // 用法2（新）：指向常量字符串
```

**🔴 关键**：赋给 `ps` 的**不是字符串本身**，而是**首字符 `'a'` 的地址**。

```c
printf("%c", *ps);   // a      —— 解引用，取「一个」字符
printf("%s", ps);    // abcdef —— %s 要的是「起始地址」，不要解引用
```

**🔴 常量字符串不可改**：
```c
char *ps = "abcdef";
*ps = 'w';       // ❌ 程序「运行」崩溃（不是编译错误！）
const char *ps = "abcdef";
*ps = 'w';       // ✅ 编译期就报错 —— 提前扼杀
```
> 鹏哥原话：「把常量字符串的地址，交给一个**靠谱的**（const）指针变量。」

**🔴🔴 见招offer 题（= 2026 真题同款）**：
```c
char str1[] = "hello bit.";
char str2[] = "hello bit.";
const char *str3 = "hello bit.";
const char *str4 = "hello bit.";
```
- `str1 == str2`：**两个独立数组**，起始地址不同 ⇒ **not same**
- `str3 == str4`：两个指针**都指向同一份常量字符串** ⇒ **same**
  - 为什么：**常量字符串内容相同且谁都改不了** ⇒ 编译器只存一份，两人共享
- ⇒ 鹏哥实机打印结果 = **位置 2（not same）+ 位置 3（same）**

**指针数组存字符串**：
```c
const char *ps[3] = {"张三", "李四", "王五"};
for (int i = 0; i < 3; i++) printf("%s\n", ps[i]);   // ps[i] 本身就是起始地址
```

### ② 鹏哥 p116（**数组指针**）

> 📁 **可回溯定位**：**P116「116.【指针】数组指针」**
> → `data/bili-analyze/BV17a7K64ELH/subtitle_p116.txt`

**🔴🔴 辨析（审计列为 P1 优先级）**：

| 写法 | 是什么 | 读法 |
|:---|:---|:---|
| `int *p[10]` | **指针数组** —— 是**数组** | 10 个格子的数组，每格一个 `int*` |
| `int (*p)[10]` | **数组指针** —— 是**指针** | 一个指针，指向「含 10 个 int 的数组」 |

**判据**：**`[]` 优先级高于 `*`**
- `*p[10]` → 先 `p[10]`（数组）再 `*` ⇒ **数组**
- `(*p)[10]` → 括号强制 `*` 先结合 ⇒ **指针**

**🔴 命名逻辑（鹏哥的类比）**：
> 「**好孩子**」的主语是**孩子**（好是修饰语）；「**数组指针**」的主语是**指针**（数组是修饰语）。
> 整形指针 → 指向整形变量 · 字符指针 → 指向字符变量 · **数组指针 → 指向数组**

**怎么写**：要「是指针」⇒ 旁边得有 `*`；要「不和 `[]` 先结合」⇒ 加括号。
```c
int (*p)[10];    // p 是指针 → 指向「10 个 int 的数组」
char (*p2)[5];   // p2 是指针 → 指向「5 个 char 的数组」
```
**初始化**：`int a[10]; int (*p)[10] = &a;` —— 要**整个数组的地址**（`&a`），不是首元素地址（`a`）。
🔴 **长度必须匹配**（鹏哥答学生问：「必须得一样，写就写准确嘛」）。

### ③ 鹏哥 p117（**二维数组传参的本质**）

> 📁 **可回溯定位**：**P117「117.【指针】二维数组传参的本质」**
> → `data/bili-analyze/BV17a7K64ELH/subtitle_p117.txt`

**🔴 核心**：二维数组名 `arr` = 首元素的地址，而**二维数组的首元素是「第一行」**（一个一维数组）。
⇒ `arr` 的类型是 **`int (*)[5]`**（数组指针），**不是 `int**`**。

**三种等价形参**（`int arr[3][5]`）：
```c
void f(int arr[3][5], int r, int c);   // 常规
void f(int arr[][5],  int r, int c);   // 行数可省（列数不可省）
void f(int (*arr)[5], int r, int c);   // 本质 —— 数组指针
```

**🔴 推导链**：`arr[i][j] ≡ *(*(arr+i)+j)`
| 步骤 | 表达式 | 得到什么 |
|:--:|:---|:---|
| ① | `arr + i` | 跳过 i 行，指向第 i 行 |
| ② | `*(arr+i)` | 第 i 行的**数组名**（= 第 i 行首元素地址） |
| ③ | `*(arr+i) + j` | 第 i 行第 j 个元素的**地址** |
| ④ | `*(*(arr+i)+j)` | 该元素的**值** |

**🔴 最大易错**：`arr + 1` 跨**一整行**（5×4 = 20 字节）；`arr[0] + 1` 只跨**一个元素**（4 字节）。
🔴 **`int **pp` 不能接二维数组名**（类型不匹配）。
