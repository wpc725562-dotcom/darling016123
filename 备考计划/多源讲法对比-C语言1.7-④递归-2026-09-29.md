### ① 笔记站 3.8（**五星必考**）

**⇒ 直接给「两个要素」**：

> **递归的两个要素**：
> **1. 递归出口**（终止条件）
> **2. 递归表达式**（问题规模缩小）

**⇒ 经典例子**：
```c
int fact(int n) {
    if (n <= 1) return 1;       // 递归出口
    return n * fact(n - 1);     // 递归表达式
}
```
