## 3. 教学点（可直接用，不依赖自动化）

这四条是四次运行里实跑 gcc 验出来的，属于硬资产。

### 3.1 数组形参降级 —— 一个数就能说清

```c
void f(int arr[10]) { printf("%zu\n", sizeof(arr)); }   // 8
int main() { int a[5]; printf("%zu\n", sizeof(a)); }    // 20
```

主函数 `sizeof(a)=20`，函数内 `sizeof(arr)=8`。**数组作为参数会退化成指针**。

gcc 会主动报 `-Wsizeof-array-argument` —— 编译器自己都认为「函数里的数组名不是数组」，这个警告可以直接给人看。

### 3.2 二维数组的 sizeof 链

`int m[3][5]` → `sizeof(m)=60`、`sizeof(m[0])=20`、`sizeof(m[0][0])=4`。

### 3.3 字符串比较的坑

`s1 == s2` → `0`（比地址），`strcmp(s1,s2)` → `0`（比内容）。两个都返回 0，含义完全不同。

### 3.4 `m == m[0]` 在严格标准下是 error

`int m[3][5]` 里 `m` 是 `int(*)[5]`，`m[0]` 是 `int*`。默认编译只有 warning，`gcc -pedantic-errors` 直接 **error**。

归入 #C008 同族：**编译器不拦你 ≠ 标准允许**。

### 3.5 破译了一个占位符

看板里留了一串 `XX-YZ 读程题`，没有题面。按同型重建：

```c
for (char c = 'X'; c <= 'Z'; c++) { printf("%c", c); if (c == 'X') printf("-"); }
```

gcc 输出正好是 `X-YZ`。这串字符就是这么来的，可以直接当待验证题用。

## 4. 有效的方法论（值得保留，与自动化无关）

四次运行里，这些规则被证明是有效的，建议不管用不用自动化都留着：

**科目交错**：必做块按 `C → 高 → 英 → C → 计 → C → 自述 → 落账` 排，相邻两段科目必不同。防止单科疲劳。

**英语不排最后**：卡在中段（比如 22:05–22:55）而不是末尾，专门防"时间不够先砍英语"。这条是踩过坑才立的。

**缺口如实记账、不挪明天**：窗口不够就少排，缺口写清楚，不往后堆。堆到第二天会让第二天必然失败。

**不排 0 点后**：`记忆巩固机制.md` R6.5 疲劳窗口。10-13 凌晨 02:15 那次已经证明疲劳会放大错误。

**断档双口径**：`date` 字段看"日志最后一条"，mtime 看"实际最后一次动手"。10-18 那次 `date` 显示断档 1 天，mtime 显示昨晚学到 04:32 —— 按 `date` 判档位（不到 3 天门槛），按 mtime 重排执行窗口。

**三档配额**：断档 ≥3 天 → 2h 恢复日；否则 4–5h 正常档。不因为"今天状态不好"就自行降级。

**周日闭卷自述**（R5）：每周日必做，不排新课。

**单科限课**（R6.4）：某科 D+1 复检失败，该科当日限 2 课。
