# 手指法：$n_0 = n_2 + 1$ 到底在说什么

> 配图：`图解-树的分叉与叶子.svg`（同目录）

## 一句话

**叶子永远比分叉多一片。多出来的那一片，是最初那根树干。**

## 规则只有一条

树从土里长出一根树干。往上长，到一个地方，**分成两根**。

分出来的每一根可以继续分，也可以停下变叶子。

规矩：**每次分，必须正好分成两根。**

## 用手做

1. 伸 1 根手指 —— 这是树干顶上那根
2. 分一次叉：1 根变 2 根
3. 再分一次：挑一根，1 根变 2 根 —— 现在 3 根
4. 再分一次 —— 现在 4 根

停下来。**手上有 4 根手指 = 4 片叶子；分了 3 次 = 3 个分叉。**

$$4 = 3 + 1$$

## 为什么恒成立（比水管更硬的证据）

把一片叶子掰开，变成一个分叉。这一步发生了什么：

- 那片叶子没了 → 叶子 **−1**
- 多了一个分叉 → 分叉 **+1**
- 冒出两片新叶子 → 叶子 **+2**

净变化：**叶子 +1，分叉 +1**。

两边**同时**加 1，差值被固定住。

起点是「1 片叶子、0 个分叉」，差值 1。之后每次操作两边一起加 1，差值永远是 1。

$$\boxed{n_0 - n_2 = 1}$$

**关键：没有一种操作能只动一边。** 这就是它恒成立的原因，不是巧合。

## 换成考试的词

| 树上说的 | 考试说的 | 符号 |
|:--|:--|:--|
| 分叉的地方 | 度为 2 的结点 | $n_2$ |
| 叶子 | 度为 0 的结点 | $n_0$ |
| 那根最初的树干 | 常数 1 | $1$ |

## 推广：三叉树

每个分叉净增 **2** 条路（1 进 3 出）：

$$n_0 = 1 + 2n_3 + n_2$$

一般式：

$$n_0 = 1 + \sum_{i \ge 2}(i-1)\,n_i$$

那个 **1 永远是根**。

## 完全二叉树 = 排队

小朋友一排一排站：第一排站满站第二排，从左往右挨着站，**中间不许留空**。

最后一个人如果自己站在最后一排、左边没人陪，他就是「落单」的。**落单的人最多一个。**

$$n_1 \in \{0,\ 1\}$$

口诀：**结点总数奇数 → 没人落单（$n_1=0$）；偶数 → 落单一个（$n_1=1$）。**

## 用法三例

**已知 $n_2$ 求 $n_0$**：$n_0 = n_2 + 1$，一步。

**已知 $n_2$、$n_1$ 求总数**：先补 $n_0 = n_2+1$，再 $n = n_0+n_1+n_2$。

**已知 $n_0$ 求 $n_2$**：$n_2 = n_0 - 1$。**题目多给的总数是干扰项，公式里没有 $n$。**

**完全二叉树真题套路**：判奇偶 → 定 $n_1$ → 解 $2n_2 + 1 + n_1 = n$ → 得 $n_2$ → 得 $n_0$。
