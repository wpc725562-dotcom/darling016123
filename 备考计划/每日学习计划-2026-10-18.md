### 块1 · C语言：`do-while` 的「循环之后那句」（30 min）

**位置**：1.5 循环结构 → `do-while`，课本 **书 p133（物理 p150）**（`--page 150` 页脚实测 `133`）。
**上一块**：1.5-⑤ 嵌套循环（🟢 09-24）· **下一块**：1.6 数组（已完结，不回头）。

**病根（10-17 实录）**：首答 `D`（应 `|D`），变式答 `BC`（应 `BCD`）—— **连续两次都漏读循环结束后那句 `printf`**。不是不会 `do-while`，是**视线停在循环体里**。

**今天只固化一个机械动作**（不是"注意一下"）：

> 拿到任何带循环的读程题 —— **第一步数 `printf` 有几个**（数出来是 2，答案就必须分 2 段）；
> 第二步在代码上逐行标 `L`（循环内）/ `A`（循环后）；第三步才动笔算。

**T1（gcc 实测，两标准均通过）**：

```c
int k = 1;
do {
    printf("<%d>", k);
    k += 3;
} while (k < 9);
printf("[k=%d]", k);
```

- **判据**：输出 **`<1><4><7>[k=10]`**，并且说出三件事 —— ① `printf` 共 2 个 ⇒ 答案两段 ② 循环跑 3 轮（k=1,4,7）③ 出循环时 k=10（**判断失败那一轮没有 `k+=3`**）
- **只写 `<1><4><7>` 不给 `[k=10]` = 未过**（这正是要治的那一刀）
- **答案错开**：10-17 那两题是 `D`/`|D` 与 `BC`/`BCD`，本题是 `<1><4><7>[k=10]`，形态完全不同 ✅

**T2 变式（同条件对照，gcc 实测）**：

```c
int i = 5;
while (i < 3) { printf("W%d", i); i++; }
printf("|w=%d", i);

int j = 5;
do { printf("D%d", j); j++; } while (j < 3);
printf("|d=%d", j);
```

- **判据**：输出 **`|w=5`** 与 **`D5|d=6`**，并说出「同一个条件 `i<3`、同一个初值 5，`while` 一次都不跑，`do-while` **必跑一次**」
- ⚠️ 两段答案故意不同（前者循环体 0 次、后者 1 次）—— 这是防"搬上一段答案"的探针

**T3 累计题（T1/T2 都过后加做，gcc 实测）**：

```c
int n = 0, s = 0;
do { n += 2; s += n; } while (n < 6);
printf("n=%d s=%d", n, s);
```

- **判据**：**`n=6 s=12`**，且交逐轮表（n=2/s=2 → n=4/s=6 → n=6/s=12）
- **只给 `6 12` 不给表 = 按未过**（`记忆巩固机制.md` R7）

**卡住了怎么办**：把 `k` 每一轮写成三行（轮次 / 打印什么 / 打印完 k 是几），一直填到 `k=10`。填表算过程，不扣分。

**过关即建卡**：`do-while 读程题第一步做什么？` → `先数 printf 个数；循环结束后那句单独算一段`。

### 块2 · 高数：1.12 间断点两大类四种（D0 重修，50 min）

**位置**：第 1 章 → 1.12 函数的连续性与间断点分类。**高数无课本全文，本节全部内容标 ⚠️ 推算**（依据：09-27 石头老师 p016 讲法 + 本节 node 数值表实测，非课本原文）。

**病根（10-17 实录）**：4 小问只过 1 问（高阶无穷小），(b)(c)(d) **全空白**。原话级诊断：**只知道「分母为 0 = 无定义 = 断点」，不知道「第几类」要算左右极限**。
⚠️ 10-10 同一块曾 **15/15 全过** —— 17 天后整块掉落，属**没建卡 + 没排复检**，不是笨。

**今天只讲一条**：

> **「分母为 0」只是嫌疑人，不是罪名。**
> 定罪要靠**左右极限各算一次**：两边都抓得住（都是有限数）→ **第一类**；有一边抓不住（跑向 ∞ 或乱跳）→ **第二类**。

**判断三步（写死在纸上）**：

| 步 | 做什么 | 输出 |
|:--:|:--|:--|
| ① | 找可疑点：分母为 0 的点 / 分段点 / 绝对值与偶次根号的点 | 一个 x₀ |
| ② | 在 x₀ 处**分别**算 $\lim\limits_{x\to x_0^-}$ 与 $\lim\limits_{x\to x_0^+}$ | 两个结果（数 / ∞ / 不存在） |
| ③ | 分类：两个都有限 → **第一类**（相等=可去，不等=跳跃）；至少一个不是 → **第二类**（∞=无穷，乱跳=振荡） | 一个类别名 |

**四道题（node 数值表实测，答案两两不同）**：

| # | 函数与点 | 左右极限（实测值） | 正确答案 |
|:--:|:--|:--|:--|
| T1 | $f(x)=\dfrac{x^2-1}{x-1}$，$x_0=1$ | 左 `1.999 → 1.999999` / 右 `2.001 → 2.000001` | **第一类 · 可去**（左右都 = 2） |
| T2 | $f(x)=\dfrac{\lvert x\rvert}{x}$，$x_0=0$ | 左恒 **−1** / 右恒 **+1** | **第一类 · 跳跃**（都存在但不等） |
| T3 | $f(x)=\dfrac{1}{x^2}$，$x_0=0$ | 左 `1e6 → 1e12` / 右 `1e6 → 1e12` | **第二类 · 无穷**（两边都 → $+\infty$） |
| T4 | $f(x)=\sin\dfrac{1}{x}$，$x_0=0$ | 左 `0.826880 / 0.753407` / 右 `−0.826880 / −0.753407` | **第二类 · 振荡**（在 $[-1,1]$ 乱跳） |

- **判据**：**类别名 + 左右极限各是多少，两样都写才过**。只写「第二类」不写左右极限 = **按未过**（这正是 10-17 漏掉的那一步）。
- **T3 是陷阱**：两边**都**趋向 $+\infty$（左右一致），但**依然算第二类** —— 判据是「极限是不是有限数」，**不是「左右是否一致」**。
- **答案错开自检**：2 / 跳跃 / ∞ / 振荡 —— 四题四种，逐个比对 ✅。T1 特意**保留** `(x²−1)/(x−1)` 而不换成 `(x²−4)/(x−2)`，因为**明天跨日复检要用换数字那版**（§九）。

**卡住了怎么办**：先只做 T1、T2（左右都是有限数，好算）；T3、T4 允许直接抄数值表，但**必须自己说出「哪一边不是有限数」**。

**过关即建卡**：`判断间断点类型的第一步是什么？` → `在 x₀ 处分别算左右极限；分母为 0 只是候选点`。

### 块6 · C语言：`++` 两栏记账 + 读程 `X-YZ`（25 min）

**(A) `++` 两栏记账（15 min）** —— 10-17 的 `s` 位仍错（答 6，应 7），只独立做对 1 次，记 🟡。

```c
int a = 4;

int c = ++a;
int d = a++;
```

- **正确答案（gcc 实测）**：**`a=7 b=4 c=6 d=6`**
- **必须交两栏表**：变量名 / 这条语句跑之前是几 / 跑完是几。**只给四个数字 = 按未过**。
- **变式（同场加做，答案不同）**：

```c
int x = 10;
int y = ++x;
int z = x++;
int w = ++x;
```

→ **`x=13 y=11 z=11 w=13`**（gcc 实测）
- **判据**：两题都对 + 两栏表齐全。10-17 那题答案是 `6/5/6/6`，本题 `7/4/6/6`，**刻意错开** ✅

**(B) 读程题 `X-YZ`（10 min）** —— 看板 10-17 记的「`XX-YZ` 读程题」是**占位符**（全库 grep 只有一处、无题面）。按同型重建，gcc 实测输出正好 **`X-YZ`**，与占位吻合：

```c
char c;
for (c = 'X'; c <= 'Z'; c++) {
    printf("%c", c);
    if (c == 'X') printf("-");
}
```

- **判据**：输出 **`X-YZ`**（三字符 + 一个 `-`），且说出「`-` 只在 `c=='X'` 那轮打印一次」。
