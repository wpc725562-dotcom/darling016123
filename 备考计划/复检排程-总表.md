# 复检排程 · 总表

> **这张表补的是「计划总表」缺的那一环：知识点的回归。**
>
> 研究结论（2026-10-07，来自三个 GitHub 项目）：
> · **DeepTutor** 的学习闭环里有 *计划性重复（scheduled repetition）* —— 知识点按固定间隔回来重考；
> · **good-learning-skill** 的每日课程把「例题 → 变式 → 混合练习」写成固定结构；
> · **Study-Mate** 强调「按可运行证据核验」并「进度落文件、可继承」。
>
> 三者共同指向同一件事：**一个知识点只讲一次、只测一次，等于没学。**
> 原计划总表每个条目只出现一次就再也不回来 —— 这是最大的结构缺口。
>
> **间隔规则**：每条的复盘条目在 **D+1 / D+3 / D+7 / D+14 / D+30 / D+60** 各回来一次（与《自学习法-2026-10-03》§1⑤ 一致）。
> 到期当天**只重考、不重讲**：出同型题，撤掉讲义与表格，独立做对才算过。

## 怎么用

1. **每天早上**先看本表「今天要复检」那一节 —— 那是**必须**做的，排在学新内容之前。
2. 复检形式固定：**同型题 + 换数字 + 要求说出理由**（《自学习法》§1③ 三条反作弊探针）。
3. 过 → 在 `计划总表-v2.csv` 的「状态」列标 🟢；没过 → 标 🔴 并在次日再排一次。
4. 一天到期超过 4 条时：**先做 P0/P1**，P2/P3 可顺延（但顺延不超过 3 天）。
