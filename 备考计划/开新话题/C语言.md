> 🔧 **2026-09-17 换题（gcc 实测凭据，非凭印象）**：原写 `else if(a>3)` 是**判据弱题** ——
>
> | 代码 | 输出 | `a` |
> |:--|:--:|:--:|
> | `a=9; if(a=0)[A] else if(a>3)[B] else[C]` | `[C]` | 0 |
> | **把中间门整个删掉**：`if(a=0)[A] else[C]` | **`[C]`** | 0 |
>
> → **答对不能证明他看了中间那道门**，恰好漏掉 #C006 要抓的洞。改成 `else if(a<5)`：
>
> | 代码 | 输出 | `a` |
> |:--|:--:|:--:|
> | `a=9; if(a=0)[A] else if(a<5)[B] else[C]` | **`[B]`** | 0 |
> | 删掉中间门 | **`[C]`** | 0 |
>
> → **答案不同 = 能判别**。顺带还考「第①道门已把 `a` 改成 0，第②道门要用**新的** `a`」（`=` 塞那一课）。

**4.3 `switch`（09-20 01:25 → 01:50）**
- 画面：**电梯直达**（对比 `else if` 阶梯 = 一层一层敲门问）
- 两个核心点：① 括号里放的是**值**不是**条件** ② 跳进去**不会自动停，会一路下滑 —— `break` 就是刹车**
- gcc 凭据（`sw1.c` / `sw2.c` / `final.c`）：`x=2` 有 break → `B`；**`x=2` 无 break → `BCD`**；`x=3` 无 break → `CD`；**`x=1` 无 break → `ABCD`**；case 顺序打乱 `x=2` → `[R]`；无匹配走 `default`
- **六题战绩**：T1 ⚪（`default` 未教 → 判不计分）/ T2 ✅ / T3 ✅ / T4 ✅ / T5 ❌ 漏穿透 / T6 ✅
- 🔑 **本课最硬的一条结论**（学生自主实验 + gcc 实测）：**穿透跟的是「代码里写的物理顺序」，不是 `case` 数值大小顺序** —— `case` 倒着写 `7-4-1` 时，`n=7` → `[S][R][P]`
- ⭐ **学生自主设计对照实验**：他问「`default` 与 `case 7` 对调后，`case 4` 还会穿透到 `default` 吗」→ gcc 实测**不会**（`[R][S]`，被 `case 7` 的 `break` 截断）—— **推断正确**

**4.4 程序综合举例（09-20 14:27）**

- 🆕 补了一个**未教先考**的概念：**`leap` 标志变量**（先记结论、最后统一输出）—— 他当场说「**我看不懂这个题目**」，补讲后立刻全对

**4.5 条件表达式 `?:`（03:38 讲 → 14:27 答）**
