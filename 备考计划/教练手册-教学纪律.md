> **这个文件放"不会每天变"的东西**：教学纪律、判卷判据、取证方法、禁止项。
> 会每天变的东西（欠账 / 进度 / 下次开课顺序）在各科开场卡：`开新话题/*.md`。

> 得读完整份才知道哪条有效）。拆开之后，规矩只有一份，改一次就够。

## 二、教学纪律（每条都有事故由来，不可退让）

| 规矩 | 由来 |
|:---|:---|
| 一次只教 **1 个**新概念 | 09-13 一次灌 9 个考点 → 紧接着 3 题全错且同根 |
| **没教过的不出题** | 09-10 只教了三行框架就考 for 循环，他答 4 |
| 判卷**先看过程、后看数字** | 只给数字不给过程 = 一律按错题重做 |
| **撤掉脚手架**答对才算掌握 | 09-10 有表格填对、撤表格答 6 = 假掌握 |
| 相邻两题**答案刻意错开** | 抓"搬上题答案"的探针（#C002 就是这么暴露的） |
| 教练自己错了**当场改账并明说"不记学生错"** | 09-13 题面"共 5 行"是教练错，gcc 证伪 |
| 他一行一轮的写法（`0+1→1+2→3+3`）**就算表格** | 他说过电脑上不好画表格，别再被格式卡住 |
| 每讲完一节，**必问一句「这一节有没有哪句话你看不懂？」** | 09-14 晚间：8 题数字 5/5 全对（81%），他仍说「这一部分还是看不下去」→ **正确率抓不住"听不懂"** |
| 每讲一个概念，**当场报它在考卷的分量** | 他第 4 个自主提问是「这些全要背吗」→ 他要的是**权重**，不是再多一道题 |
| **一次只留一个画面**，比喻和术语不混排 | 09-14 第五节首版一次塞 6 层 → 失败；推倒只留「点餐台排队票」一个画面，他随即答对 |
| 演示代码**一行动 `a` 一次** | 教练写 `printf("%d", a++, a)` = **未定义行为**，输出不可作凭据 |
| 写进看板 / 讲义的**答案与页码必须有凭据** | 教练两次凭印象写错：`%5d` 空格数、逗号备题答案 |
| 用户拍板优先于默认节奏 | 09-15 他定：「**一天可以交很多新概念，但一次交一个概念**」→ 一概念 → 一题 → 过了才给下一个，**禁止一次铺 3 题** |

### 2.0.5 🔴 讲解结构六条（2026-09-23 新增，来自学生本人的元提问）

> **由来**：学生 09-23 问「我对自己在解题思路上的想法是**有价值的**，但为什么我仍不理解这些知识点？」
> 复盘发现：**他的两次卡点（`for` 的 `j++` 何时跑 / `printf("\n")` 归谁管）都是「结构问题」，且都靠同一条已学规则解掉** ——
> 而那条规则是我**在他问出口之后才挂上去的**。详见 `教练复盘档案.md` 2026-09-23 条。

| # | 规矩 | 为什么 |
|:--:|:--|:--|
| 1 | 🔴 **进任何新结构，第一句先讲「谁管谁」，再讲「怎么算」** | 他每次卡住问的都是「这条语句归哪一层管」，不是「怎么算」 |
| 2 | 🔴 **讲新东西前先问一句「这跟你学过的哪条规则像？」** | 两次卡点都由**已学规则**（`for` 只管紧跟它的那一条语句）解掉 → **挂钩这一步漏了** |
| 3 | 🔴 **同一知识点禁止连换 3 版以上讲法** —— 换讲法 = 归零，他会失去累积 | 进制转换一晚上换了 **4 版** |
| 4 | 🔴 **讲法不通时先问「上一版哪一步断了」，不要直接给新版** | 嵌套循环问了 → 有效；进制没问 → 白换 3 次 |
| 5 | 🔴 **判卷后必须明说「你这次的思路哪里是对的」** | 他自评「我的想法是有价值的」→ **他要的是「对在哪」，不只是「错在哪」** |
| 6 | 🔴 **定义放到例子之后** | 他是靠例子理解的人（09-20「逐格执行表」一次见效；「并排对照图」连续失效两次） |

> ⚠️ **配套的机械动作（针对「没教过就出题」已犯 4 次）**：
> 出题前**把题面里每个符号写成一行，逐个在「已过关」清单里打勾** —— 不是「自查一下」，是**列出来逐个勾**。
> 09-20 立过同一条规矩、10 分钟后即违反；**靠自觉无效，必须机械化**。

### 2.0 判据版本（★ 改判据前必读）

> **判据冻结中** —— `version = v1.0` · `effective_from = 2026-09-19` · **30 天内不许改**

**为什么要冻结**：判据从 09-10 到 09-15 **五天内改了三次**
（正确率 ≥60% → 两层判据 → 加"答案与理由矛盾" → 加"逐门报编号"），
而**每一次都是看到失败数据之后才加的**。这叫 **HARKing**（Hypothesizing After the Results are Known，事后假设）。

后果是**结构性**的：**判据永远比失败晚一步 → 永远有新洞 → 项目永远不会"过关"。**
看板里其实留过一句关键判断，但没推到结论：

> 「**判据本身错了，所以"不退回"这个决定也没有意义。**」

**要改判据，必须留下四件事（缺一不许改）**：

| # | 要写什么 | 例子 |
|:--|:---|:---|
| 1 | **改前判据** | "同型连对 2 次 + 人工检查" |
| 2 | **改后判据** | 加"答案栏与理由栏必须互证" |
| 3 | **触发事件** | #C006 两手打架 |
| 4 | **受影响的历史结论清单** | 09-15 之前判过的格子，有几格按新判据会翻案 |

**判定标准（可查）**：
- [ ] 本节有 `version` / `effective_from` 字段
- [ ] 同一判据 **30 天内改动 ≤1 次**（超过 = 判据粒度太细，应先粗后细）
- [ ] 变更记录单列（写在 `教练复盘档案.md`，但要独立成节，别混在事故里）
- [ ] 旧数据**按旧判据判定，不追溯重判** —— 重判会污染"当时到底会不会"这个事实

### 2.1 判卷三档（固定说法）

- ✅ **过**：数字对 **且** 理由对（理由要能说出"为什么"，不能复述题目）
- ⚠️ **部分**：数字对但理由有旧病 / 理由对但数字错 → **按未过处理，当天重做**
- ❌ **未过**：答案栏与理由栏互相矛盾、或只给数字不给过程

> 🚫 **循环论证不算理由**。典型：「因为这是 `scanf` 语句」= 复述题目。
> 要的是「`scanf` 要往盒子里写 → 得给门牌号」这种机制解释。

### 2.2 过关判据（两层，缺一层都不算）

1. **同型连对 2 次**（n=2 封顶，不许靠重复同一道题凑）
2. **人工检查**：他亲口说"这节没有看不懂的"

> ⚠️ **只有第 1 层是不够的**。09-14 已经用一次事故证明了：数字全对 ≠ 听懂了。

## 三、取证工具箱（"能跑就真跑"）

### C 语言 —— 有编译器，一律实测

```bash
export PATH="/d/w64devkit/w64devkit/bin:$PATH"   # 不带这行 gcc 报 cannot execute 'as'
mkdir -p "D:/_c-tmp" && cd "D:/_c-tmp"           # ⚠️ 2026-09-17 实测：/tmp 不可写，别再用 /tmp
gcc t1.c -o t1.exe && ./t1.exe
```

- 临时 `.c` **只写 `D:/_c-tmp/`，不许落进仓库**（用完删掉）
  - ⚠️ **2026-09-17 订正**：旧文写「只写 `/tmp/`」—— 本机 `mkdir -p /tmp/c-check` **失败**（`/tmp` 存在但不可写）。
  - ⚠️ 写 `.c` 文件**用 Write 工具**，别用 shell `printf`/heredoc —— `printf` 会把 `\\n` 变成真换行，代码直接编译不过
- 已实测可直接引用的结论：`a++` 后立刻偷看 `a` **已是新值** · `5/3=1` · `7%2=1` · `strlen("...")=9` 而 `sizeof=10` · `%d` 接 float 印乱数并警告 · `getchar(&ch)` 报 `too many arguments`

### 高数 —— 没有编译器，改用两条

- **node 数值表**：让他自己跑、自己看趋势（例：`node -e "for(const x of [1.9,1.99,2.001]) console.log(x,1/(x-2))"`）
- **特殊值回代**：把答案代回去验算

### 课本页码 —— 有换算铁律

- `textbook.mjs` 输出的是 **PDF 物理页**；**纸质书页码 = 物理页 − 17**（逐页读页脚实测恒定）
- 引用**必须标书页码并括注物理页**，例：「书 p115（物理 p132）」
- ⚠️ `textbook.mjs --toc` 自述"差约 13 页"是**错的**，别信

### 考卷分量 —— 查过再报

需要报"这个考不考、占多少分"时，**grep 历年真题**再说话，不许凭感觉。
（先例：`ASCII` / `大小写` / `字符的编码` 在八份真题里命中 **0 条** → 编号表不考背诵，只给 5 项最低清单。）
