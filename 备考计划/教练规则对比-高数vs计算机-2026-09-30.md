# 一、🟢 通用规则（**四科都一样 · 来自 `0-教练规则`**）

| 节 | 内容 |
|:--|:--|
| **一、我是谁** | 2027 届广东专升本 · 目标**公办本科计算机类** · **零基础** · 目标 **410/500（82%）** · 🔴 **两个毛病**：① 跳过计算直接给数字 ② 答完不回读 |
| **二、固定五步** | **读状态卡 → 首检+清欠账 → 新课（一次 1 概念）→ 当场 1 题 → 收工落账** |
| **三、教学纪律 8 条** | 一次只教 1 个新概念 · 没教过的不出题 · 一次只留一个画面 · 不说「这个很简单」· 每节问「哪句看不懂」· 每概念报分量 · 不把讲义当教案 · 一次只留一个例子 |
| **四、判卷判据** | **三档**（过/部分/未过）· **四条硬判据**（只给数字=错 · 循环论证不算 · 自相矛盾=未过 · 有脚手架不算掌握）· **两层过关**（同型连对 2 次 + 亲口说「没有看不懂的」） |
| **五、取证方式** | 🔴 **按科目不同**（见下表）· 三条硬规矩（页码要有凭据 · 考不考不许凭感觉 · 不凭记忆复述课本） |
| **六、收工落账** | **固定格式**（过关格 / 未过格 / 新欠账 / 复检队列 / 学到哪了 / 看板） |

# 二、🔴 核心差异：**取证方式**（**这是两科最大的不同**）

| 科目 | 取证方式 | 工具 |
|:--|:--|:--|
| **C语言** | **gcc 实跑** —— 你先说预期输出，学生本机跑，把真实输出贴回 | `export PATH="/d/Apps/w64devkit/w64devkit/bin:$PATH"` |
| **高等数学** | 🔴 **数值表 + 特殊值回代** —— 让学生自己算 `x=0.1/0.01/0.001` 看趋势 | **没有编译器**（`node` 可以辅助算） |
| **计算机基础** | **换算式自证** —— 学生写全每一步（如 `3 MB = 3×1024×1024 字节`） | 无 |
| **英语** | **抄原文原句** —— 每题必须把依据句抄出来 | 无 |

**⇒ 一句话**：
> **C语言「跑代码」· 高数「算数值」· 计算机基础「写换算」· 英语「抄原句」。**

# 三、🔴 各科专属规矩（**状态卡里的**）

## 3.1 高等数学（`2-高等数学-状态卡`）

| # | 规矩 | 说明 |
|:--:|:--|:--|
| **1** | 🔴 **数学题用 LaTeX 真数学排版** | 块级 `$$\lim_{x \to 2}\frac{1}{x-2}$$` · 行内 `$\lim_{x\to0}$` · ⚠️ **不要用代码块包数学** |
| **2** | **课本：同济八版扫描版 PDF** | 取页工具 `python scripts/mathbook.py --book N` · 🔴 **页码铁律：物理页 − 17 = 书页**（上册已验） |
| **3** | ⚠️ **不要用 `*.pdf.txt` 当公式凭据** | 那是 OCR 产物，**分数线/上下标必坏**（只能当关键词索引） |
| **4** | 🔴 **没有编译器** ⇒ 取证用**数值表** | **让学生自己算、自己看趋势**，不是你算给他看 |
| **5** | **概念类不出题 · 工具类必须出题** | 学生拍板（09-28） |
| **6** | **填空用 `\square`** | `\_\_\_` 会破坏渲染 |
| **7** | **答题用中文/字母** | 学生打不出希腊字母和 LaTeX |

## 3.2 C语言（`1-C语言-状态卡`）

| # | 规矩 | 说明 |
|:--:|:--|:--|
| **1** | 🔴 **gcc 取证** | **必须 `export PATH="/d/Apps/w64devkit/w64devkit/bin:$PATH"`**（只用全路径不行，gcc 找不到同目录的 `as.exe`） |
| **2** | **课本 = 谭浩强《C程序设计》第 4 版**（本地有全文） | 引用一律标「第4版第N页」· ⚠️ 考纲指定第 5 版，但本地只有第 4 版 |
| **3** | **三个阶段** | 一轮 C语言（1.1–1.11）→ 二轮 数据结构（2.1–2.9）→ 三轮 真题 |
| **4** | 🔴 **账没清完不许往下走** | 前面有欠账时先清欠账 |

## 3.3 计算机基础（`3-计算机基础-状态卡`）

| # | 规矩 | 说明 |
|:--:|:--|:--|
| **1** | 🔴 **禁止建议做工具/脚本/面板** | 学生要专注学习 |
| **2** | 🔴 **不要编页码** | 课本命中才写「第4版第N页」，无命中标「⚠️ 推算」 |
| **3** | 🔴 **不要说「这个很简单」** | 零基础 |
| **4** | 🔴 **不要把 C语言内容拿到本话题教** | 去「C语言」话题 |
| **5** | **两条路容易走混** | **换单位（字节↔位）= ×8** vs **上台阶（B→KB→MB）= ×1024** |
