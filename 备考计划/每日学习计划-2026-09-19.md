## 3. 逐块可执行步骤

### 块① C 语言首检（25 min）

**为什么先做这个**：`#C006` 是"漏看中间那道 `else if`"，`n=1` 最易回生，看板写明"下次开课首检第一题"。

**步骤**：

1. **首检题**（换同型，**不要用原题**）：
   ```c
   int a = 9;
   if (a = 0)      printf("[A]");
   else if (a < 5) printf("[B]");
   else            printf("[C]");
   ```
   - ✅ **gcc 已跑完对账（2026-09-19 16:24 实测）**：输出 **`[B]  a=0`**
     - 门① `a = 0` 是**赋值**不是比较 → `a` 被改成 **0**，0 为假 → 不打印 `[A]`
     - 门② 用**新的** `a`（=0）比 `0 < 5` → 真 → 打印 `[B]`
     - 门③ `else` 不进（门②已通过）
     - 🔑 **判别力已验证**：把中间那道门删掉 → 得 `[C]`，**与 `[B]` 不同** ⇒ 答对就证明他真看了中间那道门（原写 `a>3` 是弱题，删门也是 `[C]`，已废弃）
   - **要求**：一道门一道门报编号，再下结论。**答案栏和理由栏必须互证。**
2. **复检 09-15 三课**（各 1 题，`n=1` 不算稳）—— ✅ **gcc 已实测（16:24）**：
   - 非 0 即真：`if (-8)` 进不进？ → **进门了**（-8 非 0 即为真）
   - `=` 塞 vs `==` 问：`if (a = 3)` 之后 `a` 是几？ → **进门了，a=3**（赋值结果 3 非 0 为真，且 `a` 已被改写）
   - 阶梯门槛从大到小：给一段**倒序代码**让他找错（比让他算更能验真假）
   - 📌 对照：`if (b = 0)` → **没进，b=0**（这是唯一"赋值后不进"的情况，与上一条形成对照）
3. 全过 → 进 **1.4 第四课：嵌套 `if` 与 `else` 配最近的 `if`**（书 p115）

**判据**：数字对 **且** 理由对。理由循环论证（复述题目）按未过。

### 块③ 高数破冰（20 min）

**为什么今天必须做**：$x\to0$ 分岔口**已经挂了 9 天**（09-10 → 09-19），是当前挂最久的一笔。

**步骤**：

1. **同型题**（原题 $\lim_{x\to0}\frac1x$ 答案已泄露，**必须换题**）：
   $$\lim_{x \to 2}\frac{1}{x-2}$$
   - 🔧 **2026-09-19 订正**：原备选 `lim(x→0) 1/x²` **已废弃** —— node 实测左右**都**趋向 $+\infty$（数值表见下），**左右一致**，考不出「左右不一致 → 极限不存在」。它考的是「趋于无穷」，是**另一道题**。今天必须用 $x\to2$ 这道。
2. **先用 node 数值表看趋势**（自己跑，不靠讲）：
   ```bash
   node -e "for(const x of [1.9,1.99,1.999,2.001,2.01,2.1]) console.log(x, 1/(x-2))"
   ```
   ✅ **实测输出（16:24）**：

   | x | 1/(x−2) | 从哪边来 |
   |:--|:--|:--|
   | 1.9 | **−10** | 左边 |
   | 1.99 | **−100** | 左边 |
   | 1.999 | **−1000** | 左边 |
   | 2.001 | **+1000** | 右边 |
   | 2.01 | **+100** | 右边 |
   | 2.1 | **+10** | 右边 |

   看 `x` 从左边来和从右边来，结果**符号是否一致** → **不一致：左 −∞，右 +∞**。
3. **写出结论 + 理由**：须说清「**左右趋近结果不一致 → 极限不存在**」
   - 答 `0` = 把 $x\to\infty$ 的规则硬套 → 回炉 [1.11 讲义第四节](/posts/math/notes/1.11-极限求值零基础-抓大头)
   - ⚠️ 别让他猜：**这张表要他自己在命令行跑一遍**，看到 `−10 → −100 → −1000` 和 `+1000 → +100 → +10` 两组反向数字，比讲十句有用

**判据**：独立算出 **且** 说清左右极限。只给数字不给理由 = 按未过。

> ⚠️ 高数**无课本全文**，讲解须标 ⚠️ 推算；取证用 node 数值表。
