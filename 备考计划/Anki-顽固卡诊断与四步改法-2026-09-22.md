## 0. 先纠正一个认知：**数据里没有「记不住」的卡**

你说「有很多单词反复记都记不下来」。我把全库 2230 张卡的失败次数（`lapses`）拉出来：

| 失败次数 | 张数 |
|:---|:---:|
| **≥ 10 次** | **0** |
| **5–9 次** | **0** |
| 3–4 次 | **1** |
| 1–2 次 | 146 |
| 从未失败 | 2083 |

**整个库里没有任何一张卡失败超过 5 次。** 只有 1 张到过 3–4 次。

所以「反复记都记不下来」**不是事实，是感受**。而感受的成因，数据里也写得很清楚 —— 见下。

## 1. 真凶：**你今天 58% 的复习按了「Hard」**

今天（09-22）你已复习 402 次，按钮分布：

| 按钮 | 次数 | 占比 | 含义 |
|:---|:---:|:---:|:---|
| **Hard（难）** | **232** | **57.7%** | ⚠️ **问题在这里** |
| Good（会） | 127 | 31.6% | |
| Easy（秒） | 31 | 7.7% | |
| Again（全忘） | 12 | 3.0% | 真的忘了只有 3% |

**为什么按 Hard 会造成「我记不住」的错觉：**

Anki 的 `Hard` **不是**「我有点不确定」。它是**指令**：「这张卡我记得很吃力，**请把下次间隔压短**」。

后果是一条链：

```
按 Hard → 间隔涨得极慢（甚至不涨）
      → 卡片几天内又出现
      → 你心想「怎么又是它，我果然记不住」
      → 更不敢按 Good，继续按 Hard
      → 死循环
```

**证据**：你的复习卡间隔分布里，**303 张卡卡在 4 天内**（0–1 天 81 张 + 2–4 天 222 张）。这些就是被 Hard 摁住、反复出现的那批。

**✅ 改法（最高杠杆，今天就能改）：**

| 按钮 | 什么时候按 | 判断标准 |
|:---|:---|:---|
| **Again** | 完全想不起来，或者想错了 | **想不出** |
| **Hard** | 想起来了，但**差点没想起来** / 答错了关键部分 | 想出来了，但**惊险** |
| **Good** | 想起来了，**中间犹豫了几秒** | **想起来了** ← **90% 的情况按这个** |
| **Easy** | 秒答，毫无犹豫 | 无犹豫 |

> **一句话判据**：问自己「**我想起来了吗？**」
> **想起来了 → Good。** 「犹豫」不等于「难」。
>
> 你现在把「犹豫」全记成了 Hard —— 这一条改掉，两周内到期量会明显下降。

## 2. 卡片设计：**你的高频词卡是「裸词卡」**

我抽了 12 张 `专升本英语-高频词` 的卡，格式是这样的：

```
正面：pile            背面：堆
正面：pray            背面：祈祷
正面：privilege       背面：特权、优先权
```

**只有 2 个字段：英文 + 中文。** 没有例句、没有音标、没有词性、没有搭配、没有发音。

### 为什么裸词卡记不住（记忆科学）

| 缺什么 | 后果 |
|:---|:---|
| **无语境** | 记忆是孤岛的。大脑靠「挂钩点」提取 —— 一个孤零零的词没有挂钩 |
| **无发音** | 少了听觉编码通道（人的记忆对声音很敏感） |
| **无搭配** | 只能"认"，不能"用"。而专升本考的是**在句子里识别** |
| **中文释义过简** | 一词多义时无法区分（`privilege` 只有一个释义？） |

### ⭐ 你已经有正确范本了 —— 你自己 09-19 建的卡

```
正面：While there are amazing stories of ___ ___, for most of us the changes are gradual.
      （瞬间的转变）
背面：instant transformation —— 瞬间的转变
```

**这是语境卡**：句子 + 中文提示 + 答案 + 解释。**质量比 2230 张高频词卡高一个档次。**

**✅ 改法（不要一次改 2230 张）：**

1. **只改正在学的** —— 从今天起，新卡一律按 09-19 那种格式建
2. **老卡不动** —— 2230 张重做是自杀式工作量。它们靠改按钮习惯 + FSRS 就能跑顺
3. **改造模板（一次搞定，不用逐张改）**：
   - 给「问答题」模板的**背面**加一行：`<div class="ex">例句…</div>`
   - 加**发音**：模板里插 `{{tts en_US:正面字段}}` → Anki 自动朗读
   - 这样 2230 张卡**自动获得发音**（例句仍需逐张补，但只补你正在学的那批）

## 3. 复习设置：三处必改

### 3.1 开 FSRS（**09-10 就建议了，12 天没执行**）

`备考计划/Anki-FSRS开关-怎么开与代价.md` 是 09-10 写的，当时实查结论：**FSRS 已内置但没开**。今天复查，**仍然没开**（`cards.data` 全空）。

**开法**：牌组列表 → `专升本英语-高频词` 右边的 **⚙** → **显示设置** → 拉到底 → **高级** → 勾 **「使用 FSRS 调度器」** → 期望保留率**保持 0.9**。

**三个牌组都要点**（高频词 / `专升本::C语言` / `专升本::高数`）。

**对你的直接价值**：同保留率下复习量**降 20–30%**。你现在 1196 张积压 —— 这是最直接的解药。

### 3.2 每日复习上限：设 **200**

现在 1196 张全部到期，不设上限会崩。设 200 之后：
- 每天固定清 200 张，压力可控
- 剩下的顺延（**Anki 不会丢**，只是排队）
- 配合 FSRS + 改按钮习惯，2–3 周内收敛

### 3.3 每日新卡上限：设 **10**（不是 20、不是 50）

你有 **1034 张新卡从未开课**（08-11 导入，占 46%）。

**为什么不能贪**：每张新卡在未来一年会带来 **8–10 次复习**。每天开 50 张 = 一个月后每天多 400 次复习。你现在已经积压 1196 张了。

**10 张/天** → 1034 张需要 103 天（约 3.5 个月）。到 2027-03 考试，**刚好走得完一轮**。这比"开一半就崩"强。

## 4. 到期量管理：一个明确的排法

| 优先级 | 做什么 | 数量 |
|:--:|:---|:---|
| **1** | 清当日到期复习卡 | **上限 200 张** |
| **2** | 新卡 | **10 张/天**（用新格式建） |
| **3** | 积压的 1034 张 | **先冻着**，等复习卡收敛后再开 |
| **4** | 语法卡 / 写题词汇卡（21 张） | 优先级最高 —— 它们**直接对着真题** |

**⚠️ 一个反直觉但重要的点**：**不要为了"清完积压"而一天刷 500 张。**

一次刷太多 → 大量卡被按 Again → 第二天全部回来 → 雪球更大。**宁可每天 200 张稳稳清，也不要一天 500 张然后三天不敢开。**

## 5. 记忆技巧（针对具体记不住的词）

### 5.1 词根词缀（对你这批词最有效）

你的词表里有一大批可拆的：

| 词 | 拆法 |
|:---|:---|
| `qualification` 资格 | `qualify`（使合格）+ `-cation`（名词后缀） |
| `privilege` 特权 | `privi-`（私人）+ `leg-`（法律）→ 私人的法律 → 特权 |
| `unimaginable` 无法想象的 | `un-`（不）+ `imagine` + `-able`（能…的） |

### 5.2 语境优先（你已经在做的，继续）

一个词**在句子里见过**，比孤立背十遍强。你的语法填空材料就是现成的语境库 —— 做完题把生词连句子一起建卡。

### 5.3 主动回忆 > 重复阅读

Anki 本身就是主动回忆工具。但**建卡时**要注意：正面**不要**给太多提示，否则你是在"认答案"不是"回忆"。

### 5.4 一词一卡，不要一词多义挤一张

`privilege` 如果考纲里有 2 个义项 → **建 2 张卡**。挤一张会导致"每次想起的是另一个义项"。
