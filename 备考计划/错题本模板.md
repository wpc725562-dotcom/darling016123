# ❌ 错题本

> 错题是**最宝贵的复习资料**！每道错题都代表一个知识漏洞。
> 使用方法：做错一道题，就记录一道。考前只看错题本！

> 🔬 **自动统计**：填完错题后运行 `node scripts/mistake-stats.mjs`，
> 自动统计薄弱知识点和错误原因分布（也支持 `--file` 指定其他错题文件、`--json` 输出）。

### 错题 #C001

- **日期**：2026-09-09
- **题目来源**：AI 教练第三课·赋值连续运算（人肉编译）
- **题目**：逐行写出 `a` 的最终值
  ```c
  int a = 3;
  a = a + 2;
  a = a * 2;
  printf("%d\n", a);
  ```
- **我的错误答案**：`6`
- **正确答案**：`10`（第一行后 a=5，第三行用的是**新的 5**，不是最初的 3）
- **错误原因**：☑ 概念不清 —— 忘了 `=` 是"往盒子里塞"，上一行已经把 `a` 覆盖掉，还在用开头的旧值
- **知识点**：变量的覆盖性赋值；`=` 从右往左读；连续赋值必须逐行更新盒子里的值
- **⚠️ 元认知警报**：**同一晚**「填表格版」的 `1+2=3 → 3+3=6 → 6+4=10` 我做对了，但**撤掉表格自己独立做**这题就错。这叫"有脚手架会、没脚手架错"＝**假掌握**，不能算过关。
- **复习记录**：
  - 第1次复习：**2026-09-10 ✅ 答 10**（合上讲义、无表格独立做对 → 假掌握警报**解除**）
  - 同型连对：第2次 ✅ `x=10; x=x-4; x=x+1; x=x*2;` 答 **14**（10→6→7→14，三行连续赋值全对）
  - **判定：「赋值覆盖 / `=` 从右往左」这一格正式过关**（连对 2 次，符合看板判据）
  - 第3次复习：待 09-12 前抽查（防遗忘）
- **配套讲义**：[1.3a 变量与赋值·零基础](/posts/computer/notes/1.3a-变量与赋值-零基础)

### 错题 #C002

- **日期**：2026-09-10
- **题目来源**：AI 教练·人肉编译（`for (i=1; i<=3; i++) s = s + i;`）
- **题目**：`int i, s = 0;` 然后 `for (i = 1; i <= 3; i++) { s = s + i; }`，`printf` 打印几？
- **我的错误答案**：`10` ← 而且**没画表格**
- **正确答案**：`6`（`s = 0+1 = 1` → `1+2 = 3` → `3+3 = 6`，循环只跑 **3 轮**）
- **错误原因**：☑ 思路不对 —— 不是算错，是**根本没算**。上一题 `i<=4` 的答案正好是 10，这次把 **10 直接搬过来了**（背邻居题的答案，人肉编译最危险的假象）
- **知识点**：`i<=3` 和 `i<=4` 是**两道不同的题**；`1+2+3 = 6`，`1+2+3+4 = 10`，少一轮差 4
- **🔑 教训（决定考场能不能拿分）**：**答案不能从上一题借**。判据不是"答对"，而是"**画出表格 + 答对**"；只给数字不给过程的，一律按错题重做
- **复习记录**：
  - 第1次复习：**2026-09-13 ✅ 答 6**（第三次重做，自交过程 `0+1→1+2→3+3`，**没再搬上题的 10**）→ **已销账**
  - 硬判据长期保留：只给数字不给过程 = 按错题重做
  - 第2次复习：____-__-__  ✅/❌（防遗忘抽查，随下次 C 语言小测夹入）
- **配套讲义**：[1.3a 变量与赋值·零基础](/posts/computer/notes/1.3a-变量与赋值-零基础) 第四节

### 错题 #C003

- **日期**：2026-09-13
- **题目来源**：AI 教练·`a++` 落地时机 / `%d` 坑位数 / 逗号表达式取末值 三连测 **0/3**
- **题目**：
  ```c
  int a = 5;
  int b = a++;      /* b 是几？a 是几？ */
  ```
- **我的错误答案**：`b=6, a=5`（09-13 及 09-14 首答均反了）
- **正确答案**：`b=5, a=6`
- **错误原因**：☑ 概念不清 —— 把 `a++` 理解成"**延迟加**"（以为这一行还没加，下一行才补）。实际是**同一瞬间两件事**：`交出旧值 + 盒子立刻改新值`
- **知识点**：课本 **p61**「`++i` 是先执行 i=i+1 后再使用 i 的值；`i++` 是先使用 i 的值后再执行 i=i+1」
- **三句规则（本人生成，非背诵）**：
  1. `a++` 递出去的是**旧数字**，但盒子随后**自己变成新数字**
  2. `++a` 递出去的是**新数字**（加号在前 → 先做）
  3. **单独一行只写 `a++;`** 时没有"递给谁"，`a++` 与 `++a` 效果完全一样，就是"盒子 +1"
     → 他 09-14 自己答「单纯a+1」复述出这条，不是抄的
- **gcc 实测**：`a=3; b=a++; c=++a;` → `a=5 b=3 c=5`（第2行之后 `b=3 a=4` 同时成立，证明"先汇报"≠"还没加"）
- **复习记录**：
  - 第1次：**2026-09-14 首答 ❌**（`6 5`，仍是延迟加模型，且没标哪个是 b）→ 当场重教一条规律「加号站哪边，哪边先做事」
  - 第2次：**2026-09-14 ✅** `a=5` 三题组（`b=a++`→5/6、`b=++a`→6/6、单独 `a++`→6+「单纯a+1」）**全对并交过程**
  - 第3次：**2026-09-14 ✅ 同型换名换序 + 跨行依赖**：`x=7; p=++x; q=x++;` → `p=8 理由:先7+1再递8` / `q=8 理由:先递8再让盒子变9` / `x=9` 全对，并自己踩中"上一行已把 x 改过"的陷阱
  - **判定：`a++` 落地时机过关**（同型连对 2 次，第 2 次为无脚手架独立作答）；⚠️ 封顶 n=2，**约 09-17 复检一次**防遗忘
- **⚠️ 教练侧两笔自记（不记学生错）**：
  1. 09-14 演示时写了 `printf("%d", a++, a)` —— 同行内既改又读同一变量属**未定义行为**，输出不可作凭据，已当场划掉并补规矩「一行动 a 一次」
  2. 09-14 收尾时把 `int x=(a++,a++,a++);` 的答案 **5 直接说破了** → 逗号表达式这一题**答案已泄露**，判据失效，下次须**换同型题重考**（不得再用原题）
- **配套讲义**：[1.3a 变量与赋值·零基础](/posts/computer/notes/1.3a-变量与赋值-零基础)

### 错题 #C004

- **日期**：2026-09-13（09-14 补登）
- **题目来源**：AI 教练·1.3 顺序程序设计第一课（printf 坑位数 / 逗号两副面孔）
- **题目**：`printf("%d %d\n", 3 + 4, 7);` 问几个坑、几个客人、印出什么
- **我的错误答案**：「1 个坑、2 个客人」（上一场同类题答"4 和 5"）
- **正确答案**：**2 个坑、2 个客人**，输出 `7 7`
- **错误原因**：☑ 概念不清 —— 数坑时漏数 `%d`；并且**把「逗号表达式取最右」错搬到 printf 的参数分隔逗号上**
- **知识点**：课本 **p94**「格式声明由 `%` 开始，普通字符原样输出」。**逗号的两副面孔**：

  | 写法 | 逗号身份 | 行为 |
  |:---|:---|:---|
  | `(1, 2, 99)` 被圆括号整体包着 | **逗号运算符** | 从左到右逐个执行，**整串取最右** → 99 |
  | `printf("%d", 7, 99)` | **参数分隔符**（顿号） | 全部交给 printf，**有几个坑用几个客人，多的扔掉**（gcc 警告 too many arguments） |

- **🔑 他的主动提问（本日最有价值）**：「为什么 `printf("%d",3+4,99)` 只印 7 不印 99？我记得有一个是看最右边的」→ 说明 09-13 逗号题答错的**真根因**是"不知道两种逗号不是一回事"，**不是记不住规则**
- **⚠️ 同日连带发现（挂 1.2 回炉）**：`printf("%d", 7/2)` 他答 3 ✅ 但理由是"`%d` 不显示 .5" —— **模型错**。`7/2` 在除法那一刻**已经是 3**，砍小数的刀在除法、不在 printf。gcc 对照：`7/2.0` 用 `%f` → `3.500000`
- **复习记录**：
  - 第1次：**2026-09-14 首考 ❌ 1/3**（① 数坑错 ② 漏印"结果是"三字 ③ 数字对但理由错）
  - 第2次：**2026-09-14 同日重做 ✅ 3/3**：`printf("%d%d",1,2)` → 2 坑 / 2 客人 / 印 `12`；`printf("我%d今年%d岁",3,20)` → 连字写全 `我3今年20岁` + 2 坑；`int x=(5,8,2)` → **x=2，且自己答出"这里的逗号是取最右"**
  - 第3次：待 09-15~09-17 用**带变量的混合题**复检（gcc 已备探针：`printf("[%d和%d]", (a,7), a+1)` → 输出 `[7和3]`）
- **配套讲义**：**`docs/posts/computer/notes/1.3b-格式化输入输出-零基础.md`** 第一、二节（坑位数 / 逗号两副面孔）+ `1.3-顺序程序设计.md` 第二节

### 错题 #C005

- **日期**：2026-09-14
- **题目来源**：AI 教练·1.3 第三、四节（`&` 方向性 + scanf 吃换行符）
- **题目**：`int a; char ch; scanf("%d",&a); scanf("%c",&ch);` 键盘敲 `5⏎` 再 `Y⏎`，问 `a`、`ch` 各收到什么
- **我的错误答案**：**首版整题没答**（原话「这一部分还是看不下去，讲得简单点」）；重讲后数字对了，但**理由仍有两处不实**：
  1. `ch=回车` 的病根说成"`%c` 前面没有空格" → 那是**修法**，不是**原因**
  2. 问"为什么 scanf 要 `&`"→ 答「**因为这是 scanf 语句**」 → **循环论证**，等于没答
- **正确答案**：`a = 5`、`ch = 换行符`。病根**两条同时成立**：`%d` 只收数字 → 回车不收、留在台上 ＋ `%c` 什么都不挑 → 台上第一张捡什么。`&` 的理由是**方向**：scanf 要**往盒子里写**，得给门牌号；printf 是**往外读**，不用
- **错误原因**：☑ 主因在**教学侧**（一次给太多层：比喻+术语+页码+两种修法混排 → 他"看不下去"）；☑ 辅因是 `&` 方向性概念未清
- **知识点**：课本 **p98**「`&a` 指变量 a 在内存中的地址」、**p99**「格式控制后面应当是变量**地址**，不是变量名」、**p101**（`%d%c%f` 连读例：`%c` 逮谁算谁，输入中间**不需要**空格）
- **🔑 两条判卷新规（本题暴露）**：
  1. **理由循环 = 按未过**（复述题目的话不算理由）
  2. **做题正确率抓不住"听不懂"** —— 同日 8 题数字全对却仍看不懂一节。**只有他亲口说"看不懂"才算真实反馈** → 今后每节讲完必须主动问「这一节有没有哪句话你看不懂？」
- **🎯 他的第 4 个自主提问是「考点权重」**：「这些全要背吗？这么多含义」→ **今后每讲一个概念，当场报它在考卷的分量**，不给 = 给他留焦虑。**实查证据**：`grep` 历年真题 2018/19/20/21/22/23/24/26 搜「ASCII / 大小写 / 字符的编码」→ **命中仅 1 条且为数据结构"串"的定义，与 ASCII 无关**；`getchar` 十年仅 1 次（2022 第 15 题，答案 D）。→ **ASCII 编号表不要求背**，只背 5 个：`'\n'` 换行、`'\t'` Tab、空格 32、`'A'` 65、`'a'` 97（大小写差 32）
- **⚠️ 考场书写规范**：字符常量**必须带单撇号**，换行在答题纸上写 `'\n'`；**绝不能真按回车**（会跑到下一行去）
- **复习记录**：
  - 第1次：**2026-09-14 ✅ 重讲后答对**（改用「点餐台排队票」单一画面，删编号/页码/第二种修法）→ `a=5 / ch=回车`
  - 第2次：**2026-09-15 ✅ 销账**（换同型题 `float a; char p,q; scanf("%f",&a); p=getchar(); q=getchar();` 喂 `2.5⏎X⏎` → 答对 `a=2.5 / p=回车 / q=X`，并自己说出「`getchar` 一次只抱一张票」；`&` 方向性当场答「**printf 是向外取出来，不用 `&`**」= 真理由，非循环论证）
  - 第3次：____-__-__  ✅/❌（约 09-17 随口复查一次防回生）
- **配套讲义**：**`docs/posts/computer/notes/1.3b-格式化输入输出-零基础.md`**（第四、五节：`&` 方向 / 吃换行符）

### 错题 #C006

- **日期**：2026-09-15
- **题目来源**：AI 教练·1.4 第三课综合题（阶梯 + `=` 塞 `==` 问 混考）
- **题目**：`int a = 7; if (a = 0) printf("[A]"); else if (a > 5) printf("[B]"); else printf("[C]");` 问印什么
- **我的错误答案**：**答案栏写 `[A]`，理由栏却推出"为假、不打印、走其余路线打印 `[C]`"** → 两只手打架。第一道门（`=` 是塞）他说对了，但**完全漏看中间那道 `else if (a > 5)`**，直接从第一道门跳到了 `else`
- **正确答案**：**`[C]`**。三步：① `a = 0` 一个等号 → 把 0 塞进 `a`，式子值 0 → 假；② **`a` 此时已是 0**，第二道门问 `a > 5` → `0 > 5` 不成立 → 假；③ 兜底 `else` → `[C]`（gcc 实测 `[C]`、`a 现在是 0`）
- **错误原因**：☑ **不是不懂规则，是"人肉编译没走完一遍"** —— 阶梯题只检查第一道门就下结论，中间的 `else if` 当成空气。属**流程纪律**问题，非概念问题
- **知识点**：`else if` 阶梯**从上往下逐道问**，每道门都得问完才能到 `else`；且**前一道门的赋值会改变后一道门看到的值**
- **🔑 判卷实录**：首答 `[A]` + 正确理由 → **当场按未过处理，重答三问**（第一道门把 a 改成几？`a>5` 成立吗？最后印什么？）→ 他重答「0 / 不成立 还是假 / 最后打 `[C]`」**三问全对 ✅**，从错到对**只用了 1 轮**，说明是漏看不是不会
- **复习记录**：
  - 第1次：**2026-09-15 ✅ 同日重做答对**（但 n=1，且错因是"漏看"，最易回生）
  - 第2次：____-__-__  ✅/❌ → **下次「继续 C 语言」首检第一题**：换同型、把中间那道门改成 `else if (a > 3)`、数字换成 `int a = 9;`，**要求他"一道门一道门报编号"再下结论**
  - 第3次：____-__-__  ✅/❌
- **配套讲义**：**`docs/posts/computer/notes/1.4a-选择结构-if语句-零基础.md`**（第六节"综合：三个知识点混在一起怎么拆"）

## 💡 错题本使用原则

### 什么时候记错题？
1. **做错的题** — 必须记
2. **蒙对的题** — 也记，说明你还没完全掌握
3. **不会做但看了答案会的题** — 记！这是进步空间
4. **经典好题** — 即使做对了也可以记下来

### 怎么复习错题？
1. **第1次复习**：当天晚上，重做一遍
2. **第2次复习**：3天后，再重做一遍
3. **第3次复习**：1周后，再做一遍
4. 连续3次做对 → 标记为「已掌握」

### 考前冲刺看什么？
> **只看错题本！** 把错题本从头到尾过一遍，确保每道题都会做。
