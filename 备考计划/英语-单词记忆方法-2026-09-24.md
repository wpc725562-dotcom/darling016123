> 📌 **真的「记不住」长什么样**：会有几十张卡反复失败 5 次以上，形成一条长尾。

## §2 不靠死记硬背的四种方法

> **底层逻辑**：**「记住」不是靠反复看，是靠反复「取」。**
> 每一条都能对应到 `docs/posts/resources/科学学习方法.md` 的九条原理。

### 方法一 · 语境记忆：**只收「在文章里挡住你的词」**

| | |
|:--|:--|
| **适用场景** | **所有词，尤其抽象词**（`available` / `require` 这类没有画面的） |
| **原理** | **生成效应 + 编码特异性** —— 在语境里编码，才能在同一类语境里取出来 |
| **具体做法** | ① 不做「孤立单词表」；② 每张卡的正面用**原句挖空**，不是光秃秃一个词<br>③ **你已经在做了** —— 09-21 的 2015 篇生词卡（choking smog / limestone / dawn…）就是原句来的 |
| **反例** | ❌ 打开词表从 A 背到 Z —— 这是「反复看」，不是「取」 |

**示例**（对比两种卡的差别）：

```
❌ 差：正面 = 「destination」      背面 = 「目的地」
✅ 好：正面 = 「Beijing is a popular ___ for tourists.」  背面 = 「destination 目的地（原句出自 2015 阅读第 2 篇）」
```

### 方法二 · 词根词缀拆解：**把「记一个整体」变成「记几个零件」**

| | |
|:--|:--|
| **适用场景** | **长词、学术词**（专升本阅读里最常见的丢分点） |
| **原理** | **认知负荷控制** —— 工作记忆装不下长串字母，但装得下几个零件 |
| **具体做法** | 见到长词先问「能不能拆」。常见零件：<br>· 前缀 `un-` `re-` `pre-` `dis-` `inter-`<br>· 后缀 `-tion` `-able` `-ness` `-ment` `-ity`<br>· 词根 `spect`（看）· `port`（搬）· `dict`（说）· `form`（形）· `struct`（建） |
| **示例** | `un + predict + able` = 不能预测的 → **unpredictable**<br>`re + construct + ion` = 重新建造（的过程）→ **reconstruction** |
| **⚠️ 注意** | **不是所有词都能拆**，别硬拆。拆不动就用方法一 |

### 方法三 · 主动回忆：**先想，再看 —— 不要「读」**

| | |
|:--|:--|
| **适用场景** | **所有词**（这是 Anki 的本职） |
| **原理** | **检索练习** —— 从脑子里「取出」比「再读一遍」加固得多 |
| **具体做法** | ① 看正面 → **先在脑子里逼出答案** → 再翻背面<br>② **翻之前的那 3 秒才是记忆发生的地方** |
| **🔴 配套：把按钮用对** | **这是你 42% 按「困难」要改的地方**：<br>· **想不起来** → `Again`（重来）<br>· **想起来了，但有点费劲** → **`Good`**（这就是「合意困难」，正是有效的时候）<br>· **一眼就会** → `Easy`<br>· **「困难」几乎不用** —— 它只用来把某张特别卡的间隔压短 |

### 方法四 · 造句 / 用出去：**新词当天造一个句子**

| | |
|:--|:--|
| **适用场景** | **写作会用到的词**（专升本写作 15 分，**要手拼出来，Anki 帮不上**） |
| **原理** | **生成效应 + 自我解释** —— 自己「造」出来的比看到的记得深 |
| **具体做法** | 每天挑 **3 个**新词，各造一个短句（**5 个词以内也行**）<br>句子必须**和你自己有关**（写你自己、你的事） |
| **示例** | `available` → `My notes are available on GitHub.`<br>`require` → `This question requires two steps.` |

> 📌 这条同时补上你开场卡里写的那个洞：「**写作要手拼，Anki 帮不上**」。

## §3 可以长期坚持的流程

### 3.1 每天（15–20 分钟，**时间盒，到点就收**）

| 顺序 | 做什么 | 时长 | 为什么这个顺序 |
|:--:|:--|:--:|:--|
| 1 | **清复习卡**（用对按钮：想不起来 Again / 有点费劲 **Good**） | 10 min | 先还债，复习优先于新卡 |
| 2 | **新卡 15 张**（不是 40） | 5 min | 1034 张存量，40/天 会把复习量挤爆 |
| 3 | **造句 3 个**（方法四） | 3 min | 生成效应，且补写作 |
| 4 | **收手** | — | **20–30 张封顶**（你的开场卡就写着这条） |

### 3.2 睡前 10 分钟（**睡眠巩固**）

把今天**新学的 15 个词**再过一遍（只看正面，逼自己回忆）。
**睡眠期间大脑会把短期记忆转成长期记忆** —— 睡前过一遍的性价比远高于白天多刷 10 分钟。

### 3.3 每周日（20 分钟）

| 做什么 | 目的 |
|:--|:--|
| 看一次**失败次数分布**（`lapses`） | 判断「记不住」真假 —— **如果出现失败 5 次以上的卡，才说明真的难** |
| 看一次**按钮分布** | 自查有没有又狂按「困难」 |
| 挑 5 个**反复失败**的卡 | 单独拎出来，用方法一改成「原句挖空」 |

### 3.4 每月（10 分钟）

看**间隔中位数**有没有涨。**涨 = 记忆真的在变牢**；不涨 = 该查按钮习惯或卡片质量。
