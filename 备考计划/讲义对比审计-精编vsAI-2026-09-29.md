## 维度 ④ 表述清晰度

**⇒ 抽样对比（同一个知识点：值传递）**：

### 精编讲义的写法（**纯文字段落**）

> 「在定义函数中指定的形参，在未出现函数调用时，它们并不占内存中的存储单元。在发生函数调用时，
> 函数 `max` 的形参被临时分配内存单元。将实参的值传递给形参。在执行 `max` 期间，比较形参的值，
> 把较大的值赋给 `z`。用 `return` 语句将函数的返回值带回到主函数。调用结束，形参单元被释放。
> 实参单元仍保留并维持原值，没有改变。」

### AI 讲义的写法（**表格 + 代码 + 易错点**）

| 区别 | 形参 | 实参 |
|:--|:--|:--|
| 定义位置 | 函数定义时 | 函数调用时 |
| 有无值 | **定义时没有值** | 有确定的值 |
| 关系 | 形参是实参的**拷贝** | 实参→形参单向传值 |

**⚠️ 易错点**：**实参到形参是单向值传递！**
```c
void swap(int x, int y) {    // ❌ 交换不了！
    int temp = x; x = y; y = temp;
}
```
**想交换怎么办？用指针（见 1.8 节），这就是「地址传递」。**

# 三、🔑 漏洞的【原因分析】

| # | 原因 | 说明 |
|:--:|:--|:--|
| **1** | 🔴 **「课本精编」的定位限制** | 它精编的是 **谭浩强《C程序设计》** —— **那本书本身就只有 C语言，没有数据结构** ⇒ **讲义继承了课本的边界** |
| **2** | 🔴 **科目名 vs 内容的错配** | 科目叫《**计算机基础与程序设计**》—— **「程序设计」= C语言（一半）·「计算机基础」= 数据结构 + 基础理论（一半）** ⇒ **讲义只做了前半** |
| **3** | 🟡 **PDF 转文字的损耗** | **表格/图片/排版全丢** ⇒ **「状态表」变纯文字段落** ⇒ **表述清晰度下降** |
| **4** | 🟡 **沿用了课本的「年代感」** | 谭浩强课本首版 **1991 年** ⇒ **Turbo C / VC6 / `gets()` 都是那个年代的产物** |
| **5** | 🟡 **没有「真题视角」** | 讲义是「知识导向」，**不是「考点导向」** ⇒ **不知道「哪些必考、怎么考」** |
