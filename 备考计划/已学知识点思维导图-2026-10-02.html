1.1 函数的概念
一个 x 对应唯一 y · 分段函数 · 四大特性（有界/单调/奇偶/周期）· 反函数 · 复合函数 · 基本初等函数。考点：求定义域。
1.2 数列的极限
数列 x_n 无限接近某个数 A。直观：庄子「日取半棰」（1/2, 1/4, 1/8… → 0）· 刘徽割圆术。关键：「任取 ε>0」是严谨定义的核心。
1.3 函数的极限
两种情形：x→a（趋近一个点）· x→∞（趋向无穷）。易错：趋向哪决定结果 —— 同一个 1/x，x→∞ 时 →0，x→0 时爆掉。
1.4 无穷小与无穷大
无穷小 = 极限为 0 的量；无穷大 = 绝对值无限增大。关系：无穷小的倒数是无穷大（反之亦然）。六个易混式子要分清。
1.5 极限运算法则
和差积商的极限 = 极限的和差积商。前提：各自极限都存在，且分母极限 ≠ 0。
1.6 两个重要极限
① lim(x→0) sin x / x = 1　② lim(x→∞) (1+1/x)^x = e。工具：用夹逼准则证明。
1.7 左右极限与极限存在判定 09-19 销账
判据：左极限 = 右极限 ⇒ 极限存在。⚠️ 关键：「有没有断点」不是判据，「左右方向是否一致」才是。
1.8 抓大头 ⚠️ 09-30 复检忘了
x→∞ 时，多项式分式只看最高次项 ⇒ 系数比。例：(3x²+2x)/(x²-1) → 3。
1.9 初等函数的连续性
初等函数在其定义区间内处处连续 ⇒ 求极限可直接代入。
1.10 极限计算三法决策树
三步决策：① 先代入（能算就直接算）② 遇 0/0 就约分/有理化 ③ x→∞ 用抓大头。
1.11 极限求值零基础·抓大头
抓大头的零基础版讲义（同一考点的入门材料）。
1.12 函数的连续性与间断点分类
两大类四种：第一类（可去 / 跳跃）· 第二类（无穷 / 振荡）。方法：分开求左右极限。
1.13 函数的连续性
判据：lim(x→a) f(x) = f(a)（极限值 = 函数值）。
1.14 闭区间上连续函数的性质
三条：有界性 · 最值定理 · 介值定理（含零点定理）。
1.15 无穷小的比较
四档：高阶 / 低阶 / 同阶 / 等价（α~β 当 lim β/α = 1）。用途：等价无穷小替换。

▶ ② 数据在计算机中的表示 🟢 进制已通
字节与位
1 B = 8 bit（1 字节 = 8 位）。画面：把一个大箱子拆成 8 个小格。
1 字节能表示 256 种 / 最大 255
8 位 ⇒ 2^8 = 256 种组合 ⇒ 从 0 到 255。
进制转换 09-24 全通
转出去：除几取余（十→二：除 2 取余）· 转回来：乘几次方（二→十：乘 2 的幂）。「几进制」里的那个数就是底数。
为什么用二进制
物理原理：电子元件只有两个稳定状态（通 / 断），所以用 0/1 最可靠。
单位换算（×8 vs ×1024） 待复检
两条路：换单位（字节 ↔ 位）= ×8（同一层换个说法）· 上台阶（B→KB→MB）= ×1024（跨一层）。⚠️ 易混：5 KB = 5×1024 字节（不是 40）。
编码（ASCII · 原码/反码/补码）
ASCII（字符 ↔ 数字）· 原码 / 反码 / 补码（负数怎么存）。
