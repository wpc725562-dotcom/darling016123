## §4 你实际走的路线 vs 课本路线

**课本路线（顺序）**：
```
映射与函数 → 数列极限 → 函数极限 → 无穷小/大 → 极限运算法则
→ 两个重要极限 → 无穷小比较 → 连续性/间断点 → 连续函数运算 → 闭区间性质
```

**你走的路线（我带的）**：
```
函数极限（1-① x→∞ 抓大头 / 1-② x→0 分岔口 / 1-③ 无界）
→ 极限运算法则（1-④ 约分 / 1-④b 有理化）← 现在在这
```

**⇒ 差别**：**跳过前面的 1-1 / 1-2（基础概念），也还没到后面的 1-6 ~ 1-10。**

**为什么这么走（当时的判断）**：
- 你的**起点是「会读符号、不会算结果」** → 所以**直接从「算」入手**（极限求值），跳过了「定义/概念」那几节
- 而**极限求值正是真题计算题第 1 题**（每年必考 6 分）→ 先打这个

**⇒ 这个选择在当时是合理的**，但**确实造成两个后果**：
1. **前面的 1-1 / 1-2 没打底**（映射、函数、数列极限的定义）
2. **后面的 1-6 ~ 1-10 全空**（而其中 4 个方向是真题考点）
