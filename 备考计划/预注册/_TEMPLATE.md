## 课后（如实填，不许改上面）

- **实际结果**：
- **假设命中？** ✅ 命中 / ❌ 未命中
- **若未命中，原因归类**（四选一，别写"他粗心"）：
  - [ ] **假设错** —— 我对他的估计本身错了
  - [ ] **判据错** —— 判据没抓住我想抓的东西
  - [ ] **执行偏差** —— 我讲的方式有问题（超纲 / 一次多概念 / 画面混排）
  - [ ] **意外因素** —— 状态、环境、时间
- **判据需要改吗？** 不需要 / 需要
  - 若需要 → **必须走 [教练手册 §2.0](../教练手册-教学纪律.md) 的四件事流程**（改前判据 / 改后判据 / 触发事件 / 受影响的历史结论清单）
