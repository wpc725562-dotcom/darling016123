## §1 各源**怎么讲**

### ① 鹏哥 p112（**冒泡排序**）

> 📁 **可回溯定位**：`BV17a7K64ELH`（UP 主「鹏哥C语言」）**P112「112.【指针】冒泡排序」**
> → `data/bili-analyze/BV17a7K64ELH/subtitle_p112.txt`

**核心**：**两两相邻比较，不满足顺序就交换**。

**两个关键数字**：
| 项 | 规律 |
|:---|:---|
| **总趟数** | **N − 1 趟** |
| **第 i 趟比较对数** | **N − 1 − i 对** |

**🔴 两个坑（鹏哥现场让学生试出来的）**：
| # | 坑 | 现象 |
|:--:|:---|:---|
| **1** | **内层 `j` 不能从 `i` 开始** | 从 `i` 起 → 「**搞不定啊**」（结果错）—— 每趟必须**从下标 0 开始** |
| **2** | **外层必须写 `n-1-i`** | 写错会多比较/越界 |

**🔴 flag 优化**：
> 加一个 `flag` 标记，**一趟下来没发生任何交换 ⇒ 说明已经有序 ⇒ `break`**。
> 鹏哥实测：**已有序的数组，无 flag 要 9 趟，有 flag 只要 1 趟**。

### ② 鹏哥 p113（**二级指针**）

> 📁 **可回溯定位**：**P113「113.【指针】二级指针」**
> → `data/bili-analyze/BV17a7K64ELH/subtitle_p113.txt`

**核心**：`int **ppa` 存的是**一级指针的地址**。

```c
int a = 10;
int *pa = &a;     // pa 是一级指针，存 a 的地址
int **ppa = &pa;  // ppa 是二级指针，存 pa 的地址
```

**🔴 类型拆解口诀**：
> 「**最右那颗星说它是指针变量，前面合起来说它指向啥。**」
> `int **ppa` ⇒ 最右的 `*` 说明 `ppa` 是**指针变量**；前面的 `int *` 说明它指向的是 **`int*` 类型**。

**🔴 解引用两次**：
| 表达式 | 结果 | 说明 |
|:---|:---|:---|
| `*ppa` | `pa` | 解引用一次 → 得到一级指针 |
| `**ppa` | `a`（10） | 解引用两次 → 得到变量本身 |

**⇒ 三级指针存在，但「很少很少用了」**（鹏哥原话）。

### ③ 鹏哥 p114（**指针数组**）

> 📁 **可回溯定位**：**P114「114.【指针】指针数组」**
> → `data/bili-analyze/BV17a7K64ELH/subtitle_p114.txt`

**核心**：**存指针的数组**（类比「整形数组」「字符数组」——`int` 数组存 `int`，指针数组存指针）。

```c
int *parr[3];   // 一个数组，有 3 个元素，每个元素都是 int*
```

**用途 = 模拟二维数组**：
```c
int a[3] = {1, 2, 3};
int b[3] = {4, 5, 6};
int c[3] = {7, 8, 9};
int *parr[3] = {a, b, c};   // parr[i][j] 就能像二维数组一样访问
```

**🔴🔴 但本质上【不是】二维数组**（鹏哥原话）：
> 「**二维数组的每一行是连续的**；而这里 `a` `b` `c` 是**三个独立的一维数组**，它们在内存里**不一定挨着**。」

**⚠️ 预告下一个坑（第 7 课第一个坑）**：
```c
int *parr[3];    // 指针数组 —— 数组，存 3 个指针
int (*parr)[3];  // 数组指针 —— 指针，指向一个含 3 个 int 的数组
```
> **鹏哥放在 p116 讲，这是明天第 7 课的第一个坑。**

## §4 🧪 真题机器验算（2022 单选3 · 冒泡排序）

**题面**：对 `[49, 38, 65, 97, 76, 13, 27]` 用冒泡排序**升序**，**第一趟**结束后的结果是？

**验算代码**（Node）：
```js
function pass1(a){
  a = a.slice();
  for (let j = 0; j < a.length - 1; j++)
    if (a[j] > a[j+1]) { const t=a[j]; a[j]=a[j+1]; a[j+1]=t; }
  return a;
}
function bubble(a){
  a = a.slice(); const n = a.length; let passes = 0;
  for (let i = 0; i < n-1; i++){
    let sw = false;
    for (let j = 0; j < n-1-i; j++)
      if (a[j] > a[j+1]) { const t=a[j]; a[j]=a[j+1]; a[j+1]=t; sw = true; }
    passes++; if (!sw) break;
  }
  return {a, passes};
}
const init = [49, 38, 65, 97, 76, 13, 27];
```

**实测结果**：
```
一趟后    : 38, 49, 65, 76, 13, 27, 97
D 匹配    : true      ← 97 沉底，符合
完整排序  : 13, 27, 38, 49, 65, 76, 97
实际趟数  : 6
已有序数组（优化后）: 1 趟   ← 无 flag 时会是 9 趟
```

**⇒ 答案 = D**（特征：**最大值 97 沉到底**）。

**⚠️ 真题原文 B/C 选项文字一模一样**（都是 `38,49,65,27,13,76,97`）⇒ 扫描/转录问题，**用「97 沉底」特征选 D** 即可。
