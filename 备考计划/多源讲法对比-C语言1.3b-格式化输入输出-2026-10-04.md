## §1 4 个源**各自怎么讲**（原文提炼）

### ① 精编讲义（**完整小程序视角**）

- **例 1.1**（line 208）：屏幕印字程序骨架 —— 演示 `printf("...\n")` 最简形态。
- **例 1.2**（line 267）：求两整数之和 —— `scanf("%d%d", &a, &b)` 两坑位连写。
- **例 1.3**（line 280）：求两整数较大者 —— **`scanf("%d, %d", &a, &b)` 两个 `%d` 中间有逗号**，是「格式串含标点」的真题级形态。

**⇒ 关键判断**：精编讲义**把 printf/scanf 当"能跑就行"的工具**，重点是**程序骨架**（`#include` / `main` / 函数声明），不系统讲格式符。

### ② 黄金知识汇编（**规则视角 · 考试口径**）

**考点 15**（line 412）：
- `putchar(c)` 输出一个字符；`getchar()` 输入一个字符 —— 一般形式。

**考点 16**（line 419-451）：
- `printf(格式控制, 输出表列)` —— 格式控制 = **格式声明 + 普通字符**。
- **6 个基本格式符**（line 429-445）：

| 格式符 | 作用 | 备注 |
|:--|:--|:--|
| `%d` | 十进制整型，按**实际长度**输出 | |
| `%i` | **与 `%d` 相同** | 考试爱考「哪个和 d 一样」 |
| `%c` | 输出一个字符 | `char ch='a'; printf("%c", ch)` |
| `%s` | 输出一个字符串 | `printf("%s", "CHINA")` |
| `%f` | 输出实数，**小数形式** | ★ `float` 只保证 **6~7 位**有效数字；`double` 保证 **15~16 位** |
| `%e` | **指数形式**输出实数 | |

- `scanf(格式控制, 地址表列)` —— 地址表列 = **变量地址（`&` 取地址符）或字符串首地址**。
- 例：`scanf("a=%db=%dc=%d", &a, &b, &c)` —— **格式串里写什么，输入就打什么**。

**⇒ 关键判断**：黄金汇编讲「**有哪些格式符 + 考试口径**」。它是**规则清单**，能补零基础笔记漏掉的「格式符全集」。

### ③ 鹏哥 p04-p22（**生活化比喻 · 口语化**）

- **p04-p05**：「库函数」= **放在库里的函数** —— `printf` / `scanf` 都是**库里拿来的**，不是 C 语言自带的关键字。
- **p22**：printf/scanf 实战范例。

**⇒ 关键判断**：鹏哥给的是**「库函数」这个概念锚点**，让「为什么 `printf` 不是关键字」变得直觉化。

### ④ 笔记站 1.3 普通版（**跨章 · 概览**）

`docs/posts/computer/notes/1.3-顺序程序设计.md` —— printf 概览 / scanf 概览 / 例题 4 道。

**⇒ 关键判断**：**框架完整但零基础读者看不懂**（假设你已懂变量与指针）。它提供的价值 = **例题池**。

### ⑤ ★ 黄金知识汇编 考点 17（**本次新增 · 较复杂的格式控制**）

line 452-466 原文要点：

| 格式 | 作用 | 原文例 |
|:--|:--|:--|
| `%md` | 指定输出**宽度 m**，位数不足**左端补空格**，超出按实际 | `printf("%4d,%4d", 123, 12345)` |
| `%ld` | 长整型输出，`d` 前加 `l` | （int 占 2 字节的系统） |
| `%m.nf` | 实数**共占 m 列、其中 n 位小数**，不足左端补空格 | |
| `%-m.nf` | 同 `%m.nf`，但**左端靠（右补空格）** | |
| `%3d%3d` | **输入**时系统**自动按列截取**：输 `123456` → `a=123`、`b=456` | `scanf("%3d%3d", &a, &b)` |
