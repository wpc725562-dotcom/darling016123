### 第 3 层 · 推导关系（谁能推出谁）

#### 推导链 A：**第一个重要极限 → 等价无穷小表**（核心链）

```
lim(x→0) sin x / x = 1        ← 1-6 的第一个重要极限（书 p46）
        ↓ 变形
sin x = x + o(x)              ← 书 p52 例 2 原文
        ↓ 记作
sin x ~ x                     ← 1-7 的等价（书 p52）
        ↓ 用半角公式 / 换元
1 − cos x ~ x²/2  ·  tan x ~ x  ·  arcsin x ~ x
        ↓ 用二项式展开
(1+x)^a − 1 ~ ax              ← 书 p52 例 1
```

**⇒ 这条链说明**：**等价表不是死记的 6 条公式，是同一条极限的 6 个变形。**

#### 推导链 B：**0/0 型极限的三种解法**（工具汇合点）

```
             0/0 型极限
                 │
     ┌───────────┼───────────┐
     ↓           ↓           ↓
 ① 约分      ② 有理化     ③ 等价替换
 (因式分解)  (同乘共轭式)   (用等价表)
     │           │           │
     └───── 1-5 ─┘           └── 1-7 ──┐
       (运算法则的推论)        (比较的推论)
                                        │
                                   ← 依赖 1-6
```

**⇒ 三条路各有适用场景**：
- **① 约分** —— 分子分母能**因式分解**时（如 $\frac{x^2-4}{x-2}$）
- **② 有理化** —— 出现**根号差**时（如 $\frac{\sqrt{x+4}-2}{x}$）
- **③ 等价替换** —— 出现 $\sin$ / $\cos$ / $\tan$ / $\ln$ 时（如 $\frac{1-\cos 2x}{x^2}$）

#### 推导链 C：**极限 → 连续 → 闭区间性质**

```
lim f(x) = f(x₀)              ← 1-3 的极限（书 p26）
        ↓ 加上「等于函数值」这个条件
f 在 x₀ 处连续                 ← 1-8 的定义（书 p54）
        ↓ 四则运算 + 复合
初等函数在其定义区间内连续      ← 1-9 的结论（书 p61）
        ↓ 限制到闭区间 [a,b]
最值定理 / 零点定理 / 介值定理  ← 1-10（书 p64-65）
```

## 四、⚠️ 两个「跳跃点」（容易卡住的地方）

| # | 跳跃点 | 为什么容易卡 | 怎么绕 |
|:--:|:--|:--|:--|
| **1** | **1-6 → 1-7** | **等价表的依据是「第一个重要极限」，但学生常常直接背表、不知道它从哪来** —— 于是「为什么 $\sin x \sim x$」答不上 | 讲 1-7 之前**必须先讲 1-6 的 $\lim\frac{\sin x}{x}=1$** |
| **2** | **1-3 → 1-8** | **连续的定义里有极限** —— 但学生常把「连续」当成「图像不断」的直观，**不知道它是个极限式** | 讲 1-8 时**先把定义写成 $\lim_{x\to x_0}f(x)=f(x_0)$** |

**⇒ 这两处正是「前后依赖」最容易被忽略的地方。**
