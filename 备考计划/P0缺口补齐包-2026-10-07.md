### 要讲什么（3 条，按逐字拆解法）

**第 1 条 —— 括号包住谁，就先算谁**

```c
(double)(5 / 2)   →  先整除得 2  →  再转 double  →  2.0
(double)5 / 2     →  先把 5 转成 5.0  →  再除  →  2.5
```

逐字拆解：

```
(double)  (5 / 2)
   ↑          ↑
 转型符    括号里是一个整体
            → 先算完 5/2 = 2，再把 2 转成 2.0
```

```
(double)  5  /  2
   ↑      ↑     ↑
 只转 5   5.0   2 被自动提升成 2.0 → 浮点除法
```

**第 2 条 —— 为什么 `(double)sum / n` 是对的**

`(double)sum` 先变成浮点，再与 `n` 相除时 **`n` 被自动提升为浮点** ⇒ 除法变成浮点除法。
这叫**隐式类型提升**，不是「C 语言猜的」，是标准规定的。

**第 3 条 —— 一句话记住**

> **想让除法出小数，必须让 `/` 之前就已经是浮点。**

### 自测（闭卷，5 题）

已知 `int sum = 403, n = 5;`

1. `(double)(sum / n)` 的值是？　　__________
2. `(double)sum / n` 的值是？　　__________
3. `(double)(7 / 2) + 0.5` 的值是？　　__________
4. `(double)7 / 2 + 0.5` 的值是？　　__________
5. 写一个表达式，让 `sum / n` 的结果保留小数。　　__________

<details>
<summary>答案（已用 gcc 16.2.0 验算）</summary>

1. **80.00** —— 先整除 `403/5 = 80`，小数已丢，再转 double 也救不回来
2. **80.60** —— `(double)403 = 403.0`，`403.0/5` 是浮点除法 = 80.6
3. **3.5** —— `7/2 = 3`（截断），转 `3.0`，`+0.5 = 3.5`
4. **4.0** —— `(double)7 = 7.0`，`7.0/2 = 3.5`，`+0.5 = 4.0`
5. `(double)sum / n`（**不是** `(double)(sum/n)`）

> 📌 第 1 与第 2 题只差一对括号，答案从 80.00 变 80.60 —— **这就是 2022 真题的考点**。

</details>

| 题型 | 动作 | 依据 |
|:--|:--|:--|

### 自测（代词指代追踪）

给下面 5 句，写出每个粗体代词指代什么：

1. `Tom bought a new phone, but **it** didn't work.`
2. `**It** is necessary to finish the work today.`
3. `Mary reminded **herself** of the promise.`
4. `The company changed **its** policy.`
5. `I found **it** difficult to answer.`

<details>
<summary>答案</summary>

1. **it** → `a new phone`（指代前文事物）
2. **It** → **形式主语**，真主语是 `to finish the work today`
3. **herself** → `Mary`（反身代词，主语和宾语同指）
4. **its** → `The company`（物主代词，单数）
5. **it** → **形式宾语**，真宾语是 `to answer`

> 📌 第 2、5 题是「假指代」——**它们没有指代对象**，是形式主语/宾语。这是最容易错的一类。

</details>

### 要讲什么

**5.6 几种循环的比较**（书 p145）

三种循环 **可以互相替换**：

```c
// 同一个任务：求 1+2+...+100

// 用 while
int i = 1, sum = 0;
while (i <= 100) { sum += i; i++; }

// 用 do-while
int i = 1, sum = 0;
do { sum += i; i++; } while (i <= 100);

// 用 for
int sum = 0;
for (int i = 1; i <= 100; i++) sum += i;
```

**核心区别**：

| | 判断时机 | 最少执行次数 |
|:--|:--|:--:|
| `while` | **先判断，后执行** | **0 次** |
| `do-while` | **先执行，后判断** | **1 次** |
| `for` | **先判断，后执行** | **0 次** |

**5.8.1 `while` 和 `do-while` 的比较**（书 p150）

**唯一区别就在「第一次条件就不成立」时**：

```c
int i = 10;
while (i < 5)  printf("while: %d\n", i);   // 一次都不执行
do { printf("do-while: %d\n", i); } while (i < 5);  // 执行 1 次
```

⇒ **`do-while` 至少执行一次** —— 这是它们唯一实质差别。

**5.8.2 `for` 语句的各种形式**（书 p152）

`for` 的三个表达式**都可以省略**（但两个分号不能省）：

| 形式 | 写法 | 效果 |
|:--|:--|:--|
| 标准 | `for (i = 1; i <= 100; i++)` | 正常 |
| 省表达式1 | `for (; i <= 100; i++)` | 初值在循环外给 |
| 省表达式3 | `for (i = 1; i <= 100; ) { ...; i++; }` | 增量写在循环体内 |
| **省表达式2** | `for (i = 1; ; i++)` | **条件恒真 ⇒ 死循环**（需 `break` 退出） |
| 全部省略 | `for (;;)` | **等价于 `while (1)`**，标准死循环写法 |

**表达式可以是逗号表达式**：

```c
for (i = 0, j = 100; i < j; i++, j--) { ... }   // 双向逼近
```
