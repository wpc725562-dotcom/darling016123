## §1 4 个源**各自怎么讲**（原文提炼）

### ① 精编讲义（**完整小程序视角**）

- **例 4.1**（line 2205）：输入两学生成绩，输出高的那个 —— `if (a>=b) max=a; else max=b;` 的最简形态。
- **例 4.2**（line 2242）：输入 3 个成绩按由高到低输出 —— 嵌套 `if` 的第一道真题级题。

**⇒ 关键判断**：精编讲义用**完整程序**教 `if`，但**不讲优先级、不讲边界**（`a==b` 怎么办）。

### ② 黄金知识汇编（**规则视角 · 考试口径**）

**考点 18「条件判断」**（line 473-543）：
- **6 种关系运算符**（line 478-492）—— ★ 分两组：
  - `<` `<=` `>` `>=` —— **优先级相同（高）**
  - `==` `!=` —— **优先级相同（低）**
- **优先级阶梯**（line 493-498）：**算术 > 关系 > 赋值**。
- **关系表达式**（line 499-509）：值是逻辑值（1 真 / 0 假）；例 `a>b` = 1、`(a>b)==c` = 1、`b+c<a` = 0。
- **逻辑运算符**（line 510-523）：`&&` / `||` / `!`；`&&` `||` 双目，`!` 一目；**优先级 `!` → `&&` → `||`**。
- **各类运算优先级总表**（line 529 + 561-566）：算术 → 关系 → `&&`/`||` → 赋值。
- **闰年判断**（line 539-543）：`(year%4==0 && year%100!=0) || (year%400==0)`。

**考点 19「用 if 语句实现选择结构」**（line 544-600）：
- 例 4.1 的**两个版本**（程序一「两个独立 if」line 549-559 / 程序二「if-else」line 572-582）。
- **if 语句 3 种一般形式**（line 583-599）：
  1. `if (表达式) 语句`
  2. `if (表达式) 语句1 else 语句2`
  3. `if( ) if( ) 语句1 else 语句2 else if( ) 语句3 else 语句4`
- line 599：「**表达式可以是数值表达式、关系表达式或者逻辑表达式**；语句可以是简单语句也可以是复合语句。」

**⇒ 关键判断**：黄金汇编是**考试口径的权威**——优先级、运算符分组、if 形式定义都在这里。

### ③ 鹏哥 p23-p26（**生活化比喻**）

- 「条件就是问一句是 / 否」——把 `if` 讲成**门卫问话**。
- 实战 if 用例。

**⇒ 关键判断**：鹏哥给的是**直觉锚点**，不补规则。

### ④ 笔记站 1.4 普通版（**跨章 · 概览**）

关系运算符对照表 / if-else 语法 / 例题。

**⇒ 关键判断**：**框架完整但跳过零基础坎**（`=` vs `==`）。
