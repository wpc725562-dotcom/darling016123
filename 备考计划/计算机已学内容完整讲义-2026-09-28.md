## 1.2 数据的存储与运算 🔴 **真题 12 题**

**📍 书 p36-73 · 笔记站 818 行**

### 核心概念

**① 二进制存储**

| 单位           | 换算              |
| :----------- | :-------------- |
| **位（bit）**   | 最小单位            |
| **字节（Byte）** | **1 B = 8 bit** |
| **字（word）**  | 与机器有关           |

**② 三种整数表示**

| 名称     | 规则                              |
| :----- | :------------------------------ |
| **原码** | 最高位符号位（0 正 1 负）                 |
| **反码** | 负数：符号位不变，其余取反                   |
| **补码** | **负数：反码 + 1** —— **计算机内部用补码存储** |

**③ 数据类型与长度**

| 类型       |  长度（典型） | 范围                  |
| :------- | :-----: | :------------------ |
| `char`   | **1 B** | $-128 \sim 127$     |
| `short`  |   2 B   | $-32768 \sim 32767$ |
| `int`    | **4 B** | 约 $\pm21$ 亿         |
| `float`  |   4 B   | 约 6-7 位有效数字         |
| `double` |   8 B   | 约 15-16 位有效数字       |

**④ 运算符**

| 类别       | 运算符                          |
| :------- | :--------------------------- |
| **算术**   | `+` `-` `*` `/` `%`          |
| **赋值**   | `=` `+=` `-=` `*=` `/=` `%=` |
| **自增自减** | `++` `--`（**前缀先变后用，后缀先用后变**） |
| **关系**   | `>` `<` `>=` `<=` `==` `!=`  |
| **逻辑**   | `&&` `\|\|` `!`              |
| **位运算**  | `&` `\|` `^` `~` `<<` `>>`   |

### 典型题型

| 题               | 答案                                            | 说明          |
| :-------------- | :-------------------------------------------- | :---------- |
| **2021 第 18 题** | 十进制 630 → 二进制 = **1001110110**                | 选择 3 分      |
| **2022 第 39 题** | 十进制 2022 → 二进制 **11111100110** + 十六进制 **7E6** | **简答 10 分** |
| **2023 第 31 题** | `char` 占 **1** 字节                             | 填空 4 分      |

### 常见易错点

|   #   | 易错                   | 纠正                                    |
| :---: | :------------------- | :------------------------------------ |
| **1** | 🔴 **整数除法截断**        | **`7/2 = 3`（不是 3.5）** —— 两个整数相除，结果是整数 |
| **2** | 🔴 **`%` 的符号**       | **`%` 的结果符号跟【被除数】相同**（`-7%3 = -1`）    |
| **3** | **`++i` 和 `i++` 混用** | **前缀：先加后用；后缀：先用后加**                   |
| **4** | **`==` 写成 `=`**      | **`=` 是赋值，`==` 是判断**                  |
| **5** | **浮点数比较用 `==`**      | **浮点数不能直接比相等**（精度问题）                  |

**🔴 石头老师式的「具体数字」验证**：

```c
printf("%d\n", 7/2);     // 3   ← 不是 3.5
printf("%d\n", -7%3);    // -1  ← 跟被除数符号
printf("%d\n", 7%-3);    // 1
```

int a = 3;          // 定义 + 初始化

### 典型题型

# 🟩 第二部分 · C语言核心（1.4 - 1.6）

## 1.4 选择结构程序设计

**📍 书 p102-147 · 笔记站 260 + 338 + 461 行（含 2 篇零基础）· ✅ 全完结（09-20）**

### 核心概念

**① `if` 语句**

```c
if (条件) 语句1;
if (条件) 语句1; else 语句2;
if (条件1) 语句1;
else if (条件2) 语句2;
else 语句3;
```

**② `switch` 语句**

```c
switch (表达式) {
    case 常量1: 语句; break;
    case 常量2: 语句; break;
    default:    语句;
}
```

### 🔴 核心规则

|   #   | 规则                | 说明                                   |
| :---: | :---------------- | :----------------------------------- |
| **1** | **条件的真假**         | **0 = 假，非 0 = 真**（「门卫只认 0」）          |
| **2** | **`else` 配对**     | **`else` 总是与它上面【最近的、未配对的】`if` 配对**   |
| **3** | **`switch` 的穿透**  | **没有 `break` 会往下穿透**（继续执行后面的 `case`） |
| **4** | **`switch` 的表达式** | **只能是整型 / 字符型**（不能是浮点或字符串）           |
| **5** | **`case` 后面**     | **只能是常量，不能是变量**                      |

### 典型题型

1. **判断程序输出**（含嵌套 `if` 的配对）
2. **`switch` 穿透**（少了 `break` 的结果）
3. **改错题**（`else` 配对错、`switch` 缺 `break`）

### 常见易错点

|   #   | 易错                         | 纠正                           |
| :---: | :------------------------- | :--------------------------- |
| **1** | 🔴 **`else` 配对搞错**         | **找【最近的、未配对的】`if`**          |
| **2** | 🔴 **`switch` 忘了 `break`** | **会穿透到下一个 `case`**           |
| **3** | **`if (a = 5)`**           | **那是赋值（永远真）** —— 应该 `a == 5` |
| **4** | **`switch` 里用浮点**          | **只能整型/字符型**                 |

## 1.5 循环结构程序设计 🔴 **真题 7 题**

**📍 书 p148-175 · 笔记站 284 行 · ✅ 全完结（09-25 六课）**

### 核心概念

**三种循环**

| 循环             | 特点                          |
| :------------- | :-------------------------- |
| **`while`**    | **先判断，后执行**（可能一次都不执行）       |
| **`do-while`** | **先执行，后判断**（**至少执行一次**）     |
| **`for`**      | **三件套**：`for (初始化; 条件; 更新)` |

**两个跳出**

| 语句             | 作用             |
| :------------- | :------------- |
| **`break`**    | **跳出整个循环**     |
| **`continue`** | **跳过本次，继续下一次** |

### 🔴 核心规则

|   #   | 规则                | 说明                                            |
| :---: | :---------------- | :-------------------------------------------- |
| **1** | 🔴 **计数器 vs 累计器** | **`i` 是计数器（数轮数），`s` 是累计器（加总和）** —— **两个盒子别混** |
| **2** | **`for` 末尾的分号**   | **`for(...);` ⇒ 循环体是空语句**（陷阱！）                |
| **3** | **循环体次数**         | **`for(i=1;i<=4;i++)` 跑 4 次**（不是 5 次）         |
| **4** | **循环变量最终值**       | **`for(i=1;i<=4;i++)` 结束时 `i=5`**（多跑一次判断）     |

### 典型题型

1. **手跑循环，写出输出**（**必须自己跑一遍**）
2. **求「循环体执行了几次」**
3. **求「循环变量最终是几」**
4. **改错题**（分号陷阱 / 边界错）

### 常见易错点

|   #   | 易错                             | 纠正                                    |
| :---: | :----------------------------- | :------------------------------------ |
| **1** | 🔴🔴 **`i` 和 `s` 混**（把计数器当累计器） | **两个盒子分开记** —— **09-10 曾答「4」（正确 10）** |
| **2** | 🔴 **`for` 末尾多写分号**            | **`for(...);` 后面那句【不在循环里】**           |
| **3** | **边界搞错**（`<` vs `<=`）          | **数清楚跑几次**                            |
| **4** | **`do-while` 忘了末尾分号**          | **`while(...);` 有分号**                 |

**🔧 机械规则（从今天的费曼复盘沉淀）**：

> **凡不确定循环跑几次 —— 【手跑一遍】，把每轮的 `i` 和 `s` 列出来。不许「看形式猜」。**

## 1.6 用数组处理批量数据 🔴🔴 **真题 14 题（最高）**

**📍 书 p158-189 · 笔记站 733 + 364 行 · ✅ 全完结（09-26）**

### 核心概念

**① 数组 = 一排格子**

```c
int a[5];           // 5 个格子，下标 0~4
a[0] = 10;          // 第 1 个格子
```

| 要点                | 说明                        |
| :---------------- | :------------------------ |
| **下标从 0 开始**      | **`a[5]` 的下标是 0,1,2,3,4** |
| **方括号前有类型名 = 定义** | **`int a[5];`**           |
| **方括号前没类型名 = 引用** | **`a[0]`**                |
| **数组名是地址**        | **`a` 就是 `a[0]` 的地址**     |

**② 一维数组初始化**

```c
int a[5] = {1,2,3};      // 后两个自动补 0
int a[5] = {0};          // 全部清零 ← 常用
int a[5];                // ⚠️ 不给初值 = 随机值
```

**③ 二维数组**

```c
int a[3][4];         // 3 行 4 列
a[0][0]              // 第 1 行第 1 列
```

**④ 字符数组**

```c
char c1[] = "China";         // 占 6 个格子（含 '\0'）
char c2[] = {'C','h','i','n','a'};   // 占 5 个格子（无 '\0'）
```

### 🔴 字符串函数（**高频**）

| 函数                   | 作用                      | 注意            |
| :------------------- | :---------------------- | :------------ |
| **`strlen(s)`**      | 求**字符串长度**（**不含 `\0`**） | 遇到 `\0` 就停    |
| **`strcpy(s1, s2)`** | **把 s2 复制到 s1**         | **s1 要有足够空间** |
| **`strcat(s1, s2)`** | **把 s2 接到 s1 后面**       | **s1 要有足够空间** |
| **`strcmp(s1, s2)`** | **比较**（返回负数/0/正数）       | **不改变任何字符串**  |
| **`sizeof`**         | 求**占用字节数**              | **包含 `\0`**   |

### 典型题型

| 题              | 答案                       | 说明       |
| :------------- | :----------------------- | :------- |
| **2024 单选 12** | 顺序表插入 $O(n)$             | （数据结构）   |
| **2023 应用题**   | 数组 + 循环 + 查找 + `break`   | **10 分** |
| **2024 应用题**   | 二维数组                     | **10 分** |
| **字符数组简答题**    | **2023 有 10 分简答整道考字符数组** | ——       |

### 常见易错点

|   #   | 易错                           | 纠正                                                              |
| :---: | :--------------------------- | :-------------------------------------------------------------- |
| **1** | 🔴 **`a[5]` 的下标**            | **下标是 0~~4，不是 1~~5**                                            |
| **2** | 🔴 **`strlen` 和 `sizeof` 混** | **`strlen` 不含 `\0`，`sizeof` 含**                                 |
| **3** | 🔴 **`strcat` 空间不够**         | **错题 #C008**：`char s[5]="ab"; strcat(s,"cde")` ⇒ **需要 6 格，会越界** |
| **4** | **字符串赋值用 `=`**               | **`char s[10]; s = "abc";` 是错的** ⇒ **要用 `strcpy`**              |
| **5** | **`strcmp` 返回值当布尔**          | **返回的是【差值】，不是 1/0**                                             |

## 2.2 线性表 🔴 **真题 12-15 题（并列最高）**

**📍 笔记站 650 行 · 🟡 已上 2 课（概念层）**

### 核心概念

**① 线性表 = 有限个元素的【有序序列】**

$(a_1,\ a_2,\ a_3,\ \cdots,\ a_n)$

| 特点      | 说明                         |
| :------ | :------------------------- |
| **有限**  | $n\ge0$（$n=0$ 时是空表）        |
| **有序**  | 🔴 **指【位置有先后】，不是【值的大小排序】** |
| **同类型** | 所有元素类型相同                   |

**⇒ 记忆**：**首元无前驱，终元无后继，中间元素各有一个前驱和后继**

**② 两种存储方式**

|            | **顺序表（电影院连坐）**      | **链表（手拉手）**            |
| :--------- | :------------------ | :--------------------- |
| **找第 5 个** | **直接走 5 号座** $O(1)$ | **从头数** $O(n)$         |
| **中间插入**   | **后面全挪** $O(n)$     | **改两根指针** $O(1)$（已知位置） |
| **存储密度**   | 高（=1）               | 低（<1，有指针开销）            |
| **适用**     | **读多写少**            | **读少写多**               |

**③ 复杂度（**&#x32;024 单选12 / 2026 单选9 必&#x8003;**）**

| 操作          |  移动元素个数 |     复杂度    |
| :---------- | :-----: | :--------: |
| 第 $i$ 个位置插入 | $n-i+1$ | **$O(n)$** |
| 删除第 $i$ 个   |  $n-i$  | **$O(n)$** |
| **表头插入**    | **$n$** | **$O(n)$** |
| **表尾插入**    | **$0$** | **$O(1)$** |

**④ 链表（**&#x5DF2;上第 2 &#x8BFE;**）**

| 概念             | 要点                                                                        |
| :------------- | :------------------------------------------------------------------------ |
| **结点**         | **数据域 + 指针域**（**2024 单选16**）                                              |
| **头指针 vs 头结点** | **头指针必须有；头结点可选**                                                          |
| **带头结点判空**     | **`head->next == NULL`**（**2024 单选17**）                                   |
| **插入顺序**       | **先挂后连**：先 `s->next = p->next`，再 `p->next = s`（**2024 单选20 / 2021 单选19**） |
| **循环链表尾结点**    | **`p->next == head`**（**2021 单选10**）                                      |


### 典型题型

| 真题 | 题面 | 答案 |
|:--|:--|:--|
| **2024 判断10** | 「除第一个元素外，每个元素有且只有一个直接前驱」 | **对（√）** |
| **2024 单选12** | 第 $i$ 个元素后插入的复杂度 | **$O(n)$** |
| **2026 单选9** | 表头插入的复杂度 | **$O(n)$** |
| **2024 单选16** | 结点由哪两部分组成 | **数据域 + 指针域** |
| **2024 单选17** | 带头结点单链表判空 | **`head->next == NULL`** |
| **2024 单选20** | 插入语句顺序 | **先挂后连** |
| **2021 单选10** | 循环链表尾结点 | **`p->next == head`** |
| **2024 简答3** | 简述顺序表存储结构的优缺点 | **10 分** |

### 常见易错点

| # | 易错 | 纠正 |
|:--:|:--|:--|
| **1** | 🔴 **「顺序表」当成「顺序存取」** | **顺序表是【随机】存取**（名字像，但说的不是一回事） |
| **2** | 🔴 **「$O(1)$」当成「表尾」** | **条件是【已知位置】**，不是表尾 |
| **3** | **判空条件三个混** | **`head==NULL`**（不带头结点）· **`head->next==head`**（循环）· **`head->next==NULL`**（带头结点）✅ |
| **4** | **插入顺序反了** | **反了会丢链**（先挂后连） |
