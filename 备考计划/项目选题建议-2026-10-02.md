# §1 题 1 · `exam-trainer` —— 真题「考点 → 掌握度 → 出题」决策引擎

> **按「考点正确率 + 遗忘曲线」排序** —— **不要一上来就上 IRT**。

# §3 题 3 · `notes-qa` —— 你自己的笔记问答（本地 RAG）

## 是什么

问「**第一章间断点怎么判**」⇒ 它从**你自己的笔记**里检索并回答 ⇒ **答案带「文件 + 行号」引用**。

## 起点（**依赖项你全都已经有了**）

| 资产 | 位置 |
|:--|:--|
| **笔记库（几万行）** | `D:\deeepseek\zhuan-sheng-ben-notes`（Obsidian + VitePress） |
| **本地大模型** | **Ollama** —— P1 `yu-ai-agent` 已经配过离线化方案 |
| **现成的检索面** | 该库已有 `scripts/` 下的文本工具 |

## 🔴 MVP：**先用 grep，不上向量库**

```
问句 → 关键词切分 → grep 笔记库 → 取上下文 → Ollama 总结 → 带引用输出
```

**⇒ 跑通了再换 embedding / 向量库。**

## 共生点（**这一条最特别**）

1. **复习时不用翻文件** —— 直接问
2. 🔴 **它会逼你把笔记写得更结构化** —— **检索效果差 = 笔记结构差的信号**

## 作品集价值

🟢 **高** —— **RAG + 检索 + Agent**，正好是你的兴趣方向，也是赴日 IT 的热门。

## 🔴 停手信号

> **开始折腾「向量数据库选型」⇒ 砍掉，先让 grep 版跑起来。**
