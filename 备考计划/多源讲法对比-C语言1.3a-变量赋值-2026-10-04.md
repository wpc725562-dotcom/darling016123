## §1 4 个源**各自怎么讲**（原文提炼）

### ① 精编讲义（**程序骨架视角 · 默认你懂变量**）

**1.3 节**讲的是「简单的 C 语言程序」（程序骨架），**不讲"变量是什么"**：

- 例 1.1（hello world）：没出现变量
- 例 1.2（注释）：没出现变量
- **例 1.3**（求两个整数较大者）**第一次出现变量**：

```c
int a, b, c;           // 讲义直接出现，没解释 int 是什么
declare int max(int x, int y);   // 函数声明，也没解释
c = max(a, b);          // 讲赋值动作，但不讲 = 是什么
```

**⇒ 关键判断**：精编讲义**把"变量 / 赋值 / 表达式"假设为前置知识**，1.3 章节名是"简单的 C 语言程序"——重点是"程序由函数构成、main 函数、注释"这些**结构**事实。

**结论部分**（line 367-394）给了 6 条「C 程序特征」，**完全没有提到变量 / 赋值怎么用**。

### ② 黄金知识汇编（**规则视角 · 硬规则集**）

**考点 5「整型数据的运算与分析」**（line 108-150）—— **讲义里讲变量最系统的一节**：

- **定义变量的一般形式**：`类型名 变量名;`
- **硬规则**：「变量必须『先定义，后使用』」
- **常量和变量定义**：常量 = 值不能变；变量 = 值可以变
- **5 条标识符取名规则**（line 121-128）：

| # | 规则 | 例子 |
|:--:|:--|:--|
| 1 | 首字符必须是字母或下划线，其后必须是字母 / 数字 / 下划线 | `sum, _total, Class, day` |
| 2 | 大小写字母代表不同字符（一般变量用小写） | `Class ≠ class` |
| 3 | 长度不是无限的 | (没给具体上限) |
| 4 | 简单易记、见名知意 | — |
| 5 | 同一程序或函数中不同变量不能同名 | — |

**⇒ 关键判断**：黄金汇编讲"**规则**"，不讲"**怎么用**"。是考试规则清单，**不能教会你变量是什么**。

### ③ 鹏哥 p22（**初始化 vs 赋值视角 · 口语化反复讲**）

整集围绕「**= 是赋值运算符**」，原文片段（line 1-66）：

> 「**注意这个地方的啊，等号叫不叫负值呢？不叫。这叫什么叫初始化啊。这叫**初始化方法**。这叫初始化，就在创建一个变量的同时给它一个值，这叫初始化好。那我们已经有 A 了，现在 A 我觉得哎呀十不满意，我想把它改成 20，**注意这个叫什么叫赋值啊？这个叫赋值**。明白吗？这叫初始化，这叫赋值，OK 大家要知道赋值。**那我们在赋值的过程中用的这个等号就叫赋值运算符**。」

> 「**它是从右向左使用的。右边赋给左边，把右边的赋给左边，就这么个道理**。这跟我们的数学里面是恰好相反的。」

> 「**赋值里边还有个叫连续赋值，就我们 C 语言是支持这种连续复制的，但是这种连续赋值啊是我们不推崇的**。」

**⇒ 关键判断**：鹏哥这一集核心就讲三件事：
1. **初始化 ≠ 赋值**（关键区分！）
2. `=` 从右向左（与数学相反）
3. 连续赋值存在但不推崇（**考试要避免**）

**⚠️ 这三件事其他 3 个源都没讲**！
