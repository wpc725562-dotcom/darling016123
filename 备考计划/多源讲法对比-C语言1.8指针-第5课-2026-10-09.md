## §1 各源**怎么讲**

### ① 鹏哥 p109（**数组名的理解**）

> 📁 **可回溯定位**：`BV17a7K64ELH`（UP 主「鹏哥C语言」）**P109「109.【指针】数组名的理解」**（分P标题实测）
> → `data/bili-analyze/BV17a7K64ELH/subtitle_p109.txt`

**核心结论**：**数组名 = 首元素地址**（`a` ≡ `&a[0]`）。

**鹏哥给了「三重证明」**：
| # | 证明 | 现象 |
|:--:|:---|:---|
| 1 | `printf("%p", a)` 与 `printf("%p", &a[0])` | **打印出的地址值完全相同** |
| 2 | `int *p = a;` | 能直接赋值（类型匹配 `int*`） |
| 3 | `*a` | 取出的正是 `a[0]` 的值 |

**🔴🔴 但有两个例外**（数组名单独出现时**不再**是首元素地址）：
| # | 写法 | 含义 | 值 |
|:--:|:---|:---|:---|
| **1** | `sizeof(arr)` | **整个数组的字节数** | `int a[10]` → **40** |
| **2** | `&arr` | **整个数组的地址** | 类型是 `int(*)[10]` |

### ② 鹏哥 p110（**使用指针访问数组**）

> 📁 **可回溯定位**：**P110「110.【指针】使用指针访问数组」**
> → `data/bili-analyze/BV17a7K64ELH/subtitle_p110.txt`

**🔴 值一样但效果不同（本课最大陷阱）**：

```c
int a[10];
int *p = a;

a + 1     // +4   —— 跳过 1 个 int
&a + 1    // +40（0x28）—— 跳过整个数组
```

**鹏哥现场算十六进制**：
> 「`&a + 1` 加了 **0x28** —— `8 × 16⁰ + 2 × 16¹ = 8 + 32 = 40`。**40 字节 = 10 个 int**。因为 `&a` 的类型是 `int(*)[10]`，它把整个数组当成一个元素。」

**⇒ 差在「指针类型」**：`a` 是 `int*`，`&a` 是 `int(*)[10]`。**类型不同，`+1` 跳的步长就不同。**

**🔴 等值链（必背）**：
```
a[i] ≡ *(a+i) ≡ *(p+i) ≡ p[i] ≡ *(i+a) ≡ i[a]
```
- 依据：**加法交换律** ⇒ `i[a]` 语法合法（鹏哥：「**不推荐，只讲原理**」）
- 🔴 **「方块 `[]` 只是一个操作符」** —— 不是数组专属语法

### ③ 鹏哥 p111（**一维数组传参的本质**）

> 📁 **可回溯定位**：**P111「111.【指针】一维数组传参的本质」**
> → `data/bili-analyze/BV17a7K64ELH/subtitle_p111.txt`

**🔴 数组降级（array decay）**：

```c
int main() {
    int a[10];
    printf("%d\n", sizeof(a) / sizeof(a[0]));  // 10  ← 主函数里是 10
}
void func(int arr[]) {
    printf("%d\n", sizeof(arr) / sizeof(arr[0]));  // 2  ← 函数里是 2！
}
```

**为什么函数里是 2？**
> `sizeof(arr)` = **8**（64 位下指针大小）÷ `sizeof(arr[0])` = 4 ⇒ **2**
> ⇒ **8 就是「指针的大小」** ⇒ **形参本质上是指针**！

**三种形参写法完全等价**：
```c
void func(int arr[]);    // ✅
void func(int arr[10]);  // ✅ 写的 10 没用（会被忽略）
void func(int *arr);     // ✅ 最本质
```

**⇒ 精编讲义 8.3.3 的精炼句（原文）**：
> 「**实参数组名是指针常量，但形参数组名是按指针变量处理。**」

**🔴🔴 例 8.7（反例！高频陷阱）**：
> 原文：「程序**输出结果错误**！第一个 `for` 循环执行完后，**指针 `p` 指向数组的末尾了**……」

```c
int a[10], *p;
for (p = a; p < a + 10; p++)   // 循环后 p 已指向 a+10
    printf("%d", *p);
for (int i = 0; i < 10; i++)
    printf("%d", *(p + i));    // ❌ p 已越界，结果全错！
// 修法：p = a;  ← 复位
```

**⇒ 这与鹏哥 p109 的实机演示是「同款题」，双源印证。**
