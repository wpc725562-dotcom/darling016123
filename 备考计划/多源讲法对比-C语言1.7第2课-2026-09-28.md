## §1 四个源**各自怎么讲**

### ① 精编讲义（**本课最全**）

**7.2.3 怎样调用函数** —— **两条格式**：
```
无参：函数名()          如 print_star()
有参：函数名(实参表列)   如 max(a,b)
```

**🔴 而且有「值传递」的【完整 5 步流程】**（比第 1 课更细）：
> 「在定义函数中指定的**形参，在未出现函数调用时，它们并不占内存中的存储单元**。
> 在发生函数调用时，函数 max 的**形参被临时分配内存单元**。**将实参的值传递给形参**。
> 在执行 max 期间，比较形参的值，把较大的值赋给 z。
> **用 `return` 语句将函数的返回值带回到主函数**。
> **调用结束，形参单元被释放**。
> **实参单元仍保留并维持原值，没有改变**。」

**⇒ 5 步**：形参不占 → 调用时分配 → 传值 → **`return` 带回** → **形参释放（实参不变）**

**🔴 而且有「3 种函数调用方式」**（**这是新内容**）：
| # | 方式 | 例子 | 说明 |
|:--:|:--|:--|:--|
| **1** | **函数语句** | `print_star();` | **单独成句**（调用没返回值的函数） |
| **2** | **函数表达式** | `c = 2 * max(a, b);` | 函数出现在**表达式**里 |
| **3** | **函数参数** | `printf("%d", max(a,b));` | 函数调用**作为另一个函数的实参** |

**7.2.4 声明和原型** —— **三个条件**：
> 「（1）被调用函数必须是**已经定义**的
> （2）如果使用**库函数**，应该在本文件开头加相应的 `#include` 指令
> （3）如果使用**自己定义的函数**，而该函数的位置**在调用它的函数后面**，应该**进行函数声明**」

**7.3.1 嵌套调用** —— **定义**：
> 「**调用一个函数的过程中，又可以调用另一个函数，称为函数的嵌套调用**」
> **例 7.3**：`max_4` 里多次调用 `max`

### ④ 笔记站

**3.4 函数的声明**：
> 「C语言是**从上到下编译**的 —— 如果函数定义在调用之后，需要先声明」
> **声明时的形参名可以省略**：`int add(int, int);` ✅

**3.6 嵌套调用**（**2023 判断6**）：
```c
int max3(int a, int b, int c) {
    return max(max(a, b), c);   // 嵌套调用
}
```
> **执行顺序**：`main() → max3(3,7,5) → max(3,7) → 返回7 → max(7,5) → 返回7 → main()`

**🔴 而且有关键提醒**：
> **「不允许嵌套定义」** —— C语言中**不能**在一个函数内部定义另一个函数
> **2023 判断6**：「C 语言可以嵌套**调用**（对）—— **调用可嵌套，定义不可嵌套**」

### 冲突 2：**`return` 规则，哪个源讲得最清？**

| 源 | 讲法 |
|:--|:--|
| **① 精编讲义** | **融在流程里**（「用 `return` 语句将返回值带回」）—— **没单独列规则** |
| **③ 鹏哥** | **p57 单独 32 分**（**说明内容多**） |
| **④ 笔记站** | **3.3 + 「易错点」小节** |

**⇒ 结论**：**`return` 要单独讲**（**讲义的「流程」视角不够**）——
**⇒ 该补「3 条规则」**：① 一次只能返回一个值 ② `return` 后面不执行 ③ 返回值类型要匹配 ✅

| 源 | 讲法 |
