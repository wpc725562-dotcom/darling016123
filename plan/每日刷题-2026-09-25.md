**完整解答（照着抄一遍，然后合上默写）**：

分子最高次项为 $x^2$，分母最高次项为 $x^3$，分母次数更高，极限为 $0$：

### 6. 【计算机】【C语言部分】 ★ 基础

以下程序定义了一个函数，它实现的是（ ）

```c
int f(int n) {
    if (n <= 1) return 1;
    return n * f(n - 1);
}
```

A. 斐波那契数列　　B. 阶乘　　C. 累加和　　D. 幂运算

> 🧭 **先想 30 秒**：这题是基础题，直接照抄解答再默写一遍即可。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**答案**：B

**解析**：

这是一个递归函数。`f(3) = 3 * f(2) = 3 * 2 * f(1) = 3 * 2 * 1 = 6`，正是 3!（阶乘）。

递归就像"俄罗斯套娃"——想算 5!，先算 4!，再算 3!……直到最小的娃娃（n=1）。然后一路乘回来。递归必须要有"出口"（`n <= 1` 返回1），否则会无限套娃导致栈溢出。


</details>

### 15. 【计算机】【数据结构高频简答题】 ★ 基础

什么是完全二叉树？什么是满二叉树？

> 🧭 **先想 30 秒**：这题是基础题，直接照抄解答再默写一遍即可。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

**满二叉树**：
- 一棵深度为 k 且含有 2^k - 1 个结点的二叉树。
- 每一层上的结点数都是最大结点数。
- 只有最后一层有叶子结点，且叶子结点都在最底层。

**完全二叉树**：
- 深度为 k 的二叉树，除第 k 层外，其他各层结点数达到最大。
- 第 k 层结点从左到右连续排列，缺少的结点只能在右边。
- 满二叉树一定是完全二叉树，完全二叉树不一定是满二叉树。

**关系**：满二叉树是特殊的完全二叉树。


</details>
