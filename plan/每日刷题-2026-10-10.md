### 9. 【计算机】【数据结构高频简答题】 ★ 基础

<details>
<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

**原理**：
- 重复地遍历待排序序列，依次比较相邻两个元素，如果顺序错误则交换它们。
- 每一轮遍历将最大（或最小）的元素"冒泡"到序列的末尾。
- 共进行 n-1 轮，每轮比较次数递减。

**时间复杂度**：
- 平均情况：O(n²)
- 最坏情况（逆序）：O(n²)
- 最好情况（已有序，优化后）：O(n)
- 空间复杂度：O(1)
- 稳定性：稳定


</details>

### 11. 【计算机】【C语言部分】 ★ 基础

以下程序输出是（ ）

```c
int arr[] = {1, 2, 3, 4, 5};
int *ptr = arr;
ptr++;
printf("%d", *ptr);
```

A. 1　　B. 2　　C. 3　　D. 地址值

> 🧭 **先想 30 秒**：这题是基础题，直接照抄解答再默写一遍即可。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**答案**：B

**解析**：

`ptr` 初始指向数组首元素（`arr[0]`=1）。`ptr++` 使指针向后移动一个 `int` 大小（4字节），指向 `arr[1]`，所以 `*ptr` 为 2。

指针就像游戏里的"角色箭头"——一开始指向第1个人，`ptr++` 就是"箭头向右移一位"，指向第2个人。移动的距离取决于指向的东西有多大（`int` 占4个位置）。

### 12. 【C语言】 ★★ 中档

「传值调用」为什么改不了外面的变量？

> 🧭 **先想 30 秒**：这题不用算，只需要把概念用自己的话说一遍。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

C 语言函数参数默认**复印一份**：函数里改的是复印件，原件不动。

```c
void swap(int x, int y) { int t = x; x = y; y = t; }  // 改了个寂寞
```

要真改，必须**传地址**（把原件的门牌号给函数）：
```c
void swap(int *x, int *y) { int t = *x; *x = *y; *y = t; }
swap(&a, &b);   // ✅ 调用时加 &
```

⚠️ 这是 09-07 题 1/2 类错题的核心原因，也是改错题第一高频考点。


</details>

### 13. 【计算机】【数据结构部分】 ★★ 中档

一个栈的入栈序列是 1, 2, 3, 4，出栈序列不可能的是（ ）

A. 4, 3, 2, 1　　B. 1, 2, 3, 4　　C. 4, 3, 1, 2　　D. 2, 1, 4, 3

> 🧭 **先想 30 秒**：先在草稿上画出结构，再算 —— 这科靠画不靠想。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**答案**：C

**解析**：

栈是 LIFO（后进先出）。对于 C 选项：4 先出说明 1,2,3,4 全部入栈，此时栈顶是 3，出栈顺序应该是 4,3,2,1，不可能先出 4,3 后出 1,2（因为 2 在 1 上面）。

栈就像一摞盘子——你只能从最上面拿。如果 4 先出，说明 1,2,3,4 都摞好了，那接下来只能拿 3，不能跳过 3 拿 1 或 2。


</details>
