**完整解答（照着抄一遍，然后合上默写）**：

**原理**：
- 每一轮从未排序序列中找到最小（或最大）元素，将其放到已排序序列的末尾。
- 共进行 n-1 轮，每轮选择最小元素与当前位置交换。

**时间复杂度**：
- 平均情况：O(n²)
- 最坏情况：O(n²)
- 最好情况：O(n²)
- 空间复杂度：O(1)
- 稳定性：**不稳定**（例如 [5, 5, 3] 中，第一个5会和3交换，破坏稳定性）

<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

直接使用幂函数积分公式：

$$
\begin{aligned}
\int (3x^2 - 2x + 1) \, dx
&= 3 \cdot \frac{x^3}{3} - 2 \cdot \frac{x^2}{2} + x + C \\
&= x^3 - x^2 + x + C
\end{aligned}
$$

**这题在考什么**：

$\int x^n \, dx = \frac{x^{n+1}}{n+1} + C \quad (n \neq -1)$

`=` 和 `==` 的区别？为什么这是最经典的扣分点？

<details>
<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

- `=` **赋值**：把右边的值放进左边（"令 x 等于 5"）
- `==` **判断相等**：返回真(1)或假(0)

在 `if` 里误写 `=`：`if (x = 5)` **不是判断 x 是否为 5**，而是"把 5 塞给 x，然后 5 为真，所以永远进 if"。

编译通常**不报错**，逻辑全错 —— 这就是改错题最爱埋的雷。


</details>

### 13. 【C语言】 ★ 基础

`i++` 和 `++i` 有什么区别？

> 🧭 **先想 30 秒**：这题是基础题，直接照抄解答再默写一遍即可。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

都是"i 加 1"。区别只在**用在表达式里时**：
- `i++` **先用当前值**，再加 1
- `++i` **先加 1**，再用新值

```c
int i = 5, a = i++;   // a = 5, i 变成 6
int j = 5, b = ++j;   // b = 6, j 变成 6
```

单独一行写 `i++;` 和 `++i;` 效果完全一样。


</details>

### 15. 【C语言】【改错题】 ★ 基础

交换两个数（找出并改正下面代码中的错误）

```c
#include <stdio.h>

void swap(int a, int b)   /**** 错误 1 ****/
{
    int temp;
    temp = a;
    a = b;
    b = temp;
}

int main()
{
    int x = 3, y = 5;
    swap(x, y);
    printf("%d, %d\n", x, y);
    return 0;
}
```

> 🧭 **先想 30 秒**：这题是基础题，直接照抄解答再默写一遍即可。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**答案**：`void swap(int a, int b)` → `void swap(int *a, int *b)`

**解析**：

C 语言传值调用，形参改变不影响实参。必须用指针传递地址才能真正交换。


</details>
