### 3. 【高等数学】【不定积分·直接积分法】 ★ 基础

> 🧭 **先想 30 秒**：这题是基础题，直接照抄解答再默写一遍即可。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

$$
\begin{aligned}
\int \left(\frac{1}{x} + \cos x - e^x\right) \, dx
&= \int \frac{1}{x} \, dx + \int \cos x \, dx - \int e^x \, dx \\
&= \ln |x| + \sin x - e^x + C
\end{aligned}
$$

**这题在考什么**：

基本积分公式 $\int \frac{1}{x} dx = \ln |x| + C$，$\int \cos x \, dx = \sin x + C$，$\int e^x \, dx = e^x + C$


</details>

函数图像上**断开、跳一下、或压根没定义**的那个点，就叫间断点。

常见三类：
1. **可去间断点**：极限存在，但函数在那点没定义（补一个点就能接上）

```c
char s1[] = "abc";

```

A. 0　　B. 1　　C. -1　　D. 随机值

**答案**：A

**解析**：

`strcmp` 比较两个字符串的内容是否相等。因为 `s1` 和 `s2` 的内容都是 `"abc"`，所以返回 0（相等）。

<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

**原理**：
- 将待排序序列分为已排序和未排序两部分，初始时第一个元素为已排序。
- 每次从未排序部分取出第一个元素，在已排序部分中找到合适位置插入。
- 类似打扑克牌时整理手牌的过程。

**时间复杂度**：
- 平均情况：O(n²)
- 最坏情况（逆序）：O(n²)
- 最好情况（已有序）：O(n)
- 空间复杂度：O(1)
- 稳定性：稳定

### 15. 【C语言】【改错题】 ★ 基础

数组求最大值（找出并改正下面代码中的错误）

```c
#include <stdio.h>

int findMax(int a[], int n)
{
    int i, max = 0;   /**** 错误 1 ****/
    for (i = 1; i < n; i++)
        if (a[i] > max)
            max = a[i];
    return max;
}

int main()
{
    int arr[5] = {-3, -1, -5, -2, -4};
    printf("%d\n", findMax(arr, 5));
    return 0;
}
```

> 🧭 **先想 30 秒**：这题是基础题，直接照抄解答再默写一遍即可。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<summary>💡 看完整解答与讲解</summary>

**答案**：`max = 0` → `max = a[0]`，且循环从 `i = 1` 开始（或 `max = a[0]; for(i=0; i<n; i++)`）
