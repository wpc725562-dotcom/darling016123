数据：`{64,25,90,12,7}`

```c
int main() {
    int a[5] = {64,25,90,12,7}, i, j, t;
    for (i = 0; i < 4; i++)            /* 外层：趟数 n-1 */
        for (j = 0; j < 4-i; j++)      /* 内层：每趟少比一次 */
```

**完整解答（照着抄一遍，然后合上默写）**：

**原理**：
- 将待排序序列分为已排序和未排序两部分，初始时第一个元素为已排序。

### 6. 【计算机】【C语言部分】 ★ 基础

以下程序输出是（ ）

```c
int a = 5, b = 10;
int *pa = &a, *pb = &b;
*pa = *pb;
printf("%d %d", a, b);
```

A. 5 10　　B. 10 10　　C. 10 5　　D. 5 5

> 🧭 **先想 30 秒**：这题是基础题，直接照抄解答再默写一遍即可。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**答案**：B

**解析**：

`*pa = *pb` 表示把 `pb` 指向的值（`b=10`）赋值给 `pa` 指向的变量（`a`），所以 `a` 变成 10，`b` 不变。

`pa` 指向 `a`（就像门牌号写着"a的家"），`pb` 指向 `b`（"b的家"）。`*pa = *pb` 就是"去b的家看看值多少钱，然后去a的家也改成这个数"——a的值变了，但b没变，pa和pb指向的地址也没变。


</details>

算法的五大特点：
1. **有穷性**：算法必须在执行有限步后结束。

4. **输入**：算法有零个或多个输入。
5. **输出**：算法有一个或多个输出，没有输出的算法无意义。

### 10. 【高等数学】【不定积分·直接积分法】 ★ 基础

求不定积分 $$\int (3x^2 - 2x + 1) \, dx$$

> 🧭 **先想 30 秒**：这题是基础题，直接照抄解答再默写一遍即可。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

直接使用幂函数积分公式：

$$
\begin{aligned}
\int (3x^2 - 2x + 1) \, dx
&= 3 \cdot \frac{x^3}{3} - 2 \cdot \frac{x^2}{2} + x + C \\
&= x^3 - x^2 + x + C
\end{aligned}
$$

**这题在考什么**：

$\int x^n \, dx = \frac{x^{n+1}}{n+1} + C \quad (n \neq -1)$

### 14. 【C语言】 ★ 基础

`%` 是什么运算符？`7 % 3` 等于？它有什么用？

> 🧭 **先想 30 秒**：这题是基础题，直接照抄解答再默写一遍即可。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

`%` 是**取余（模）**运算符，`7 % 3 = 1`（7 除以 3 余 1）。

**只能是整数**，`7.0 % 3` 编译报错。

最大用途：**判断整除** 和 **取末尾**：
- `i % 2 == 0` → i 是偶数
- `i % 2 == 1` → i 是奇数
- `n % 10` → 取 n 的个位数
- `n / 10 % 10` → 取十位数


</details>
