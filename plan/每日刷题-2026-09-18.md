### 9. 【C语言】【编程题】 ★★ 中档

10 个成绩，求平均分并统计高于平均分的人数

数据：`{90,85,76,65,54,88,92,73,81,70}`

```c
int main() {
    int a[10] = {90,85,76,65,54,88,92,73,81,70};
    int i, count = 0;
    double sum = 0, avg;
    for (i = 0; i < 10; i++) sum += a[i];
    avg = sum / 10;                    /* 77.4 */
    for (i = 0; i < 10; i++)
        if (a[i] > avg) count++;
    printf("平均分=%.1f 高于平均分%d人\n", avg, count);
    return 0;
}
```

**解析**：

### 11. 【高等数学】 ★ 基础

<details>
<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

这是**分式**：分子 3、分母 5，就是分数 3/5。

花括号 `{}` 的作用是**划清边界**：`\frac{a+b}{c+d}` 里分子是 `a+b` 整体。不写花括号 `\frac{a+b}{c}` 会变成 `((a+b))/c`——分子只认一个字符。

⚠️ 刷题时看到 `\frac` 别慌，它就是一个分数，读作「多少分之多少」。


</details>

### 13. 【计算机】【C语言部分】 ★ 基础

以下程序输出结果是（ ）

```c
printf("%d", x-- - --x);
```

A. 0　　B. 1　　C. 2　　D. 未定义行为

**答案**：D
