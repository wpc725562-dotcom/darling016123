### 2. 【高等数学】【连续性·参数确定】 ★ 基础

设函数 $f(x) = \begin{cases} e^{2x}, & x < 0 \\ a + x, & x \ge 0 \end{cases}$ 在 $x = 0$ 处连续，求常数 $a$ 的值。

> 🧭 **先想 30 秒**：这题是基础题，直接照抄解答再默写一遍即可。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

连续性条件：$\lim_{x \to 0^-} f(x) = \lim_{x \to 0^+} f(x) = f(0)$。

左极限：
$$
\lim_{x \to 0^-} f(x) = \lim_{x \to 0^-} e^{2x} = e^{0} = 1
$$

右极限与函数值：
$$
\lim_{x \to 0^+} f(x) = f(0) = a + 0 = a
$$

由连续性得 $a = 1$。

**这题在考什么**：

分段函数连续性的判断，左极限 = 右极限 = 函数值


</details>

### 3. 【计算机】【C语言高频简答题】 ★ 基础

> 🧭 **先想 30 秒**：这题是基础题，直接照抄解答再默写一遍即可。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

**递归函数**是指在函数体内直接或间接调用自身的函数。递归包含两个要素：递归终止条件（边界条件）和递归表达式。

**优点**：
- 代码简洁，逻辑清晰，易于理解。
- 适合解决具有递归性质的问题（如树的遍历、汉诺塔、斐波那契数列）。

**缺点**：
- 每次递归调用都需要额外的栈空间保存现场，空间开销大。
- 递归层次过深可能导致栈溢出。
- 与循环相比，递归的执行效率通常较低。


</details>

### 12. 【计算机】【C语言部分】 ★ 基础

以下程序输出是（ ）

```c
int a = 5, b = 10;
int *pa = &a, *pb = &b;
*pa = *pb;
printf("%d %d", a, b);
```

A. 5 10　　B. 10 10　　C. 10 5　　D. 5 5

> 🧭 **先想 30 秒**：这题是基础题，直接照抄解答再默写一遍即可。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**答案**：B

**解析**：

`*pa = *pb` 表示把 `pb` 指向的值（`b=10`）赋值给 `pa` 指向的变量（`a`），所以 `a` 变成 10，`b` 不变。

`pa` 指向 `a`（就像门牌号写着"a的家"），`pb` 指向 `b`（"b的家"）。`*pa = *pb` 就是"去b的家看看值多少钱，然后去a的家也改成这个数"——a的值变了，但b没变，pa和pb指向的地址也没变。


</details>

### 15. 【C语言】【编程题】 ★ 基础

判断一个数是否为素数

```c
int main() {
    int n, i, flag = 1;
    scanf("%d", &n);
    for (i = 2; i * i <= n; i++)    /* 只需试到 √n */
        if (n % i == 0) { flag = 0; break; }
    if (flag && n > 1) printf("是素数\n");
    else               printf("不是素数\n");
    return 0;
}
```
