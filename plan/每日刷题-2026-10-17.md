算法的五大特点：

4. **输入**：算法有零个或多个输入。
5. **输出**：算法有一个或多个输出，没有输出的算法无意义。

### 8. 【计算机】【C语言部分】 ★ 基础

以下程序定义了一个函数，它实现的是（ ）

```c
int f(int n) {
    if (n <= 1) return 1;
    return n * f(n - 1);
}
```

A. 斐波那契数列　　B. 阶乘　　C. 累加和　　D. 幂运算

> 🧭 **先想 30 秒**：这题是基础题，直接照抄解答再默写一遍即可。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**答案**：B

**解析**：

这是一个递归函数。`f(3) = 3 * f(2) = 3 * 2 * f(1) = 3 * 2 * 1 = 6`，正是 3!（阶乘）。

递归就像"俄罗斯套娃"——想算 5!，先算 4!，再算 3!……直到最小的娃娃（n=1）。然后一路乘回来。递归必须要有"出口"（`n <= 1` 返回1），否则会无限套娃导致栈溢出。


</details>

### 9. 【高等数学】【连续性·参数确定】 ★ 基础

设函数 $f(x) = \begin{cases} e^{2x}, & x < 0 \\ a + x, & x \ge 0 \end{cases}$ 在 $x = 0$ 处连续，求常数 $a$ 的值。

> 🧭 **先想 30 秒**：这题是基础题，直接照抄解答再默写一遍即可。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

连续性条件：$\lim_{x \to 0^-} f(x) = \lim_{x \to 0^+} f(x) = f(0)$。

左极限：
$$
\lim_{x \to 0^-} f(x) = \lim_{x \to 0^-} e^{2x} = e^{0} = 1
$$

右极限与函数值：
$$
\lim_{x \to 0^+} f(x) = f(0) = a + 0 = a
$$

由连续性得 $a = 1$。

**这题在考什么**：

分段函数连续性的判断，左极限 = 右极限 = 函数值


</details>

### 13. 【C语言】【编程题】 ★★ 中档

辗转相除求最大公约数与最小公倍数

输入：24 和 36

```c
int main() {
    int m, n, r, m0, n0;
    scanf("%d %d", &m, &n);
    m0 = m; n0 = n;
    while (n != 0) {           /* 辗转相除 */
        r = m % n;
        m = n;
        n = r;
    }
    printf("最大公约数=%d\n", m);
    printf("最小公倍数=%d\n", m0 * n0 / m);
    return 0;
}
```

> 🧭 **先想 30 秒**：先默写最小框架 #include + int main + return 0，再往里填循环。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**答案**：最大公约数 **12**，最小公倍数 **72**（24×36/12）

**解析**：

24%36=24 → (36,24)；36%24=12 → (24,12)；24%12=0 → (12,0)，n=0 时 m 即最大公约数。

循环开始前不备份 m0、n0，最后算最小公倍数时 m、n 已被改掉。

**完整解答（照着抄一遍，然后合上默写）**：

用于 `∞/∞` 型极限：**分子分母都只保留次数最高的那一项，其余全扔掉**。
