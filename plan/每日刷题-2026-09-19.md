<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

**原理**：
- 重复地遍历待排序序列，依次比较相邻两个元素，如果顺序错误则交换它们。
- 每一轮遍历将最大（或最小）的元素"冒泡"到序列的末尾。
- 共进行 n-1 轮，每轮比较次数递减。

**时间复杂度**：
- 平均情况：O(n²)
- 最坏情况（逆序）：O(n²)
- 最好情况（已有序，优化后）：O(n)
- 空间复杂度：O(1)
- 稳定性：稳定

### 6. 【高等数学】【不定积分·直接积分法】 ★ 基础

求不定积分 $$\int \left(\frac{1}{x} + \cos x - e^x\right) \, dx$$

> 🧭 **先想 30 秒**：这题是基础题，直接照抄解答再默写一遍即可。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

$$
\begin{aligned}
\int \left(\frac{1}{x} + \cos x - e^x\right) \, dx
&= \int \frac{1}{x} \, dx + \int \cos x \, dx - \int e^x \, dx \\
&= \ln |x| + \sin x - e^x + C
\end{aligned}
$$

**这题在考什么**：

基本积分公式 $\int \frac{1}{x} dx = \ln |x| + C$，$\int \cos x \, dx = \sin x + C$，$\int e^x \, dx = e^x + C$


</details>

**答案**：B

**解析**：

### 12. 【C语言】【编程题】 ★★ 中档

辗转相除求最大公约数与最小公倍数

输入：24 和 36

```c
int main() {
    int m, n, r, m0, n0;
    scanf("%d %d", &m, &n);
    m0 = m; n0 = n;
    while (n != 0) {           /* 辗转相除 */
        r = m % n;
        m = n;
        n = r;
    }
    printf("最大公约数=%d\n", m);
    printf("最小公倍数=%d\n", m0 * n0 / m);
    return 0;
}
```

> 🧭 **先想 30 秒**：先默写最小框架 #include + int main + return 0，再往里填循环。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**答案**：最大公约数 **12**，最小公倍数 **72**（24×36/12）

**解析**：

24%36=24 → (36,24)；36%24=12 → (24,12)；24%12=0 → (12,0)，n=0 时 m 即最大公约数。

<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

「**当 x 趋向于 0 时，sin x 除以 x 的极限等于 1**」。

这是高数第一个重要极限，专升本必考。记住它的形状：**分子是 sin，分母是同一个东西**，两者都趋 0，结果就是 1。

如果分母变成 `2x`，结果就不是 1 而是 1/2 —— 因为凑不成"同一个东西"。


</details>

```c
#include <stdio.h>

int findMax(int a[], int n)
{
    int i, max = 0;   /**** 错误 1 ****/
    for (i = 1; i < n; i++)
        if (a[i] > max)
            max = a[i];
    return max;
}

int main()
{
    int arr[5] = {-3, -1, -5, -2, -4};
    printf("%d\n", findMax(arr, 5));
    return 0;

```
