### 9. 【计算机】【数据结构高频简答题】 ★ 基础

什么是完全二叉树？什么是满二叉树？

> 🧭 **先想 30 秒**：这题是基础题，直接照抄解答再默写一遍即可。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

**满二叉树**：
- 一棵深度为 k 且含有 2^k - 1 个结点的二叉树。
- 每一层上的结点数都是最大结点数。
- 只有最后一层有叶子结点，且叶子结点都在最底层。

**完全二叉树**：
- 深度为 k 的二叉树，除第 k 层外，其他各层结点数达到最大。
- 第 k 层结点从左到右连续排列，缺少的结点只能在右边。
- 满二叉树一定是完全二叉树，完全二叉树不一定是满二叉树。

**关系**：满二叉树是特殊的完全二叉树。


</details>

### 13. 【C语言】【编程题】 ★★ 中档

数组逆置（首尾交换，要求原地完成）

数据：`{1,2,3,4,5,6}` → 输出 `6 5 4 3 2 1`

```c
int main() {
    int a[6] = {1,2,3,4,5,6}, i, t;
    for (i = 0; i < 6 / 2; i++) {      /* 交换 n/2 次即可 */
        t = a[i]; a[i] = a[5-i]; a[5-i] = t;
    }
    for (i = 0; i < 6; i++) printf("%d ", a[i]);
    return 0;
}
```

### 15. 【计算机】【C语言部分】 ★ 基础

以下程序输出结果是（ ）

```c
int a[5] = {1, 2, 3, 4, 5};
printf("%d", *(a + 3));
```

A. 1　　B. 2　　C. 3　　D. 4

> 🧭 **先想 30 秒**：这题是基础题，直接照抄解答再默写一遍即可。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**答案**：D

**解析**：

`a` 是数组首地址，`a + 3` 指向第4个元素（下标从0开始），`*(a + 3)` 取出该元素的值，即 4。`a[3]` 和 `*(a + 3)` 是完全等价的。

数组就像一排门牌号的房子。`a` 是1号门，`a+3` 是4号门，`*(a+3)` 就是敲4号门看里面住谁。`a[3]` 是同样的意思——只是写法不同。


</details>
