**答案**：B

**解析**：

### 11. 【计算机】【数据结构高频简答题】 ★ 基础

什么是树的路径长度？什么是树的带权路径长度？

<details>
<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

- **树的路径长度**：从树根到每个结点的路径长度（经过的边数）之和。对于一棵二叉树，路径长度 = 每个结点所在层数减1之和。
- **树的带权路径长度（WPL, Weighted Path Length）**：树中所有叶子结点的带权路径长度之和。每个叶子结点的带权路径长度 = 该结点的权值 × 该结点到根结点的路径长度。

**公式**：WPL = ∑(wᵢ × lᵢ)，其中 wᵢ 为第 i 个叶子结点的权值，lᵢ 为其路径长度。


</details>

### 12. 【高等数学】【连续性·参数确定】 ★ 基础

设函数 $f(x) = \begin{cases} e^{2x}, & x < 0 \\ a + x, & x \ge 0 \end{cases}$ 在 $x = 0$ 处连续，求常数 $a$ 的值。

> 🧭 **先想 30 秒**：这题是基础题，直接照抄解答再默写一遍即可。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

连续性条件：$\lim_{x \to 0^-} f(x) = \lim_{x \to 0^+} f(x) = f(0)$。

左极限：
$$
\lim_{x \to 0^-} f(x) = \lim_{x \to 0^-} e^{2x} = e^{0} = 1
$$

右极限与函数值：
$$
\lim_{x \to 0^+} f(x) = f(0) = a + 0 = a
$$

由连续性得 $a = 1$。

**这题在考什么**：

分段函数连续性的判断，左极限 = 右极限 = 函数值

**完整解答（照着抄一遍，然后合上默写）**：

```c
#include <stdio.h>
int main() {
    int i;
    for (i = 1; i <= 10; i++) {
        printf("%d\n", i);
    }
    return 0;
}
```

`for (起点; 继续条件; 每轮之后干什么)`：
- `i = 1` 从 1 开始
- `i <= 10` 只要 i 不超过 10 就继续 ← **`<=` 而不是 `<`**，写成就只输出到 9
- `i++` 每轮结束 i 加 1
