### 2. 【高等数学】【连续性·参数确定】 ★ 基础

设函数 $f(x) = \begin{cases} e^{2x}, & x < 0 \\ a + x, & x \ge 0 \end{cases}$ 在 $x = 0$ 处连续，求常数 $a$ 的值。

> 🧭 **先想 30 秒**：这题是基础题，直接照抄解答再默写一遍即可。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

连续性条件：$\lim_{x \to 0^-} f(x) = \lim_{x \to 0^+} f(x) = f(0)$。

左极限：
$$
\lim_{x \to 0^-} f(x) = \lim_{x \to 0^-} e^{2x} = e^{0} = 1
$$

右极限与函数值：
$$
\lim_{x \to 0^+} f(x) = f(0) = a + 0 = a
$$

由连续性得 $a = 1$。

**这题在考什么**：

分段函数连续性的判断，左极限 = 右极限 = 函数值

### 12. 【高等数学】【极限·等价无穷小替换】 ★ 基础

**完整解答（照着抄一遍，然后合上默写）**：

### 13. 【计算机】【C语言部分】 ★ 基础

以下程序定义了一个函数，它实现的是（ ）

```c
int f(int n) {
    if (n <= 1) return 1;
    return n * f(n - 1);
}
```

A. 斐波那契数列　　B. 阶乘　　C. 累加和　　D. 幂运算

> 🧭 **先想 30 秒**：这题是基础题，直接照抄解答再默写一遍即可。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**答案**：B

**解析**：

这是一个递归函数。`f(3) = 3 * f(2) = 3 * 2 * f(1) = 3 * 2 * 1 = 6`，正是 3!（阶乘）。

递归就像"俄罗斯套娃"——想算 5!，先算 4!，再算 3!……直到最小的娃娃（n=1）。然后一路乘回来。递归必须要有"出口"（`n <= 1` 返回1），否则会无限套娃导致栈溢出。


</details>

<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

函数图像上**断开、跳一下、或压根没定义**的那个点，就叫间断点。

常见三类：
1. **可去间断点**：极限存在，但函数在那点没定义（补一个点就能接上）
2. **跳跃间断点**：左右极限都存在但不相等（图像跳了一格）
3. **第二类（无穷）间断点**：左右至少有一个是 ∞（图像冲上天）


</details>
