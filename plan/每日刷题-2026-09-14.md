### 9. 【C语言】【编程题】 ★★ 中档

辗转相除求最大公约数与最小公倍数

输入：24 和 36

```c
int main() {
    int m, n, r, m0, n0;
    scanf("%d %d", &m, &n);
    m0 = m; n0 = n;
    while (n != 0) {           /* 辗转相除 */
        r = m % n;
        m = n;
        n = r;
    }
    printf("最大公约数=%d\n", m);
    printf("最小公倍数=%d\n", m0 * n0 / m);
    return 0;
}
```

> 🧭 **先想 30 秒**：先默写最小框架 #include + int main + return 0，再往里填循环。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**答案**：最大公约数 **12**，最小公倍数 **72**（24×36/12）

**解析**：

24%36=24 → (36,24)；36%24=12 → (24,12)；24%12=0 → (12,0)，n=0 时 m 即最大公约数。

循环开始前不备份 m0、n0，最后算最小公倍数时 m、n 已被改掉。

<details>
<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

**二叉树**是每个结点最多有两个子树的树结构，子树有左右之分，次序不能颠倒。

**二叉树的五种基本形态**：
1. **空二叉树**：没有任何结点。
2. **只有一个根结点**：左右子树均为空。
3. **只有左子树**：根结点有左子树，右子树为空。
4. **只有右子树**：根结点有右子树，左子树为空。
5. **左右子树都不为空**：根结点既有左子树又有右子树。


</details>
