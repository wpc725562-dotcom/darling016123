**完整解答（照着抄一遍，然后合上默写）**：

**图（Graph）** 是由顶点集合 V 和边集合 E 组成的数据结构，记为 G = (V, E)。图分为有向图和无向图。

**图的存储方式**：
1. **邻接矩阵**：用二维数组存储顶点间的邻接关系。空间复杂度 O(n²)，适合稠密图。
2. **邻接表**：为每个顶点建立一个单链表，存储其邻接顶点。空间复杂度 O(n + e)，适合稀疏图。
3. **十字链表**：有向图的一种链式存储，同时存储入弧和出弧。
4. **邻接多重表**：无向图的一种链式存储，每条边只存储一次。

算法的五大特点：
1. **有穷性**：算法必须在执行有限步后结束。

**答案**：D

**解析**：

`a` 是数组首地址，`a + 3` 指向第4个元素（下标从0开始），`*(a + 3)` 取出该元素的值，即 4。`a[3]` 和 `*(a + 3)` 是完全等价的。

数组就像一排门牌号的房子。`a` 是1号门，`a+3` 是4号门，`*(a+3)` 就是敲4号门看里面住谁。`a[3]` 是同样的意思——只是写法不同。

### 7. 【C语言】【编程题】 ★★ 中档

辗转相除求最大公约数与最小公倍数

输入：24 和 36

```c
int main() {
    int m, n, r, m0, n0;
    scanf("%d %d", &m, &n);
    m0 = m; n0 = n;
    while (n != 0) {           /* 辗转相除 */
        r = m % n;
        m = n;
        n = r;
    }
    printf("最大公约数=%d\n", m);
    printf("最小公倍数=%d\n", m0 * n0 / m);
    return 0;
}
```

**答案**：最大公约数 **12**，最小公倍数 **72**（24×36/12）

**解析**：

### 15. 【C语言】 ★ 基础

`=` 和 `==` 的区别？为什么这是最经典的扣分点？

> 🧭 **先想 30 秒**：这题是基础题，直接照抄解答再默写一遍即可。　👉 想满 30 秒还不动，就展开下面的解答照抄一遍，合上再默写。

<details>
<summary>💡 看完整解答与讲解</summary>

**完整解答（照着抄一遍，然后合上默写）**：

- `=` **赋值**：把右边的值放进左边（"令 x 等于 5"）
- `==` **判断相等**：返回真(1)或假(0)

在 `if` 里误写 `=`：`if (x = 5)` **不是判断 x 是否为 5**，而是"把 5 塞给 x，然后 5 为真，所以永远进 if"。

编译通常**不报错**，逻辑全错 —— 这就是改错题最爱埋的雷。


</details>
