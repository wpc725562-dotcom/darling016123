# 雅思核心知识点清单 ✅

> **这是一份「勾选式」自测清单，不是教程。**
> 用法：**先拿一套剑桥真题完整做一遍**，然后对着本清单逐条打勾 —— **打不上勾的，就是你的缺口**。
>
> 📝 **真题从哪买、哪些剑号值得做、怎么刷** → [雅思真题 · 怎么找、怎么用](./ielts-past-papers)
>
> 📖 **来源强度**：题型清单**来自官方**（ielts.org，阅读 11 种 / 听力 6 种，均照抄题型原名）；
> 自测方法与顺序建议是 **⚙️ 体系自编**。本页**不提供答案与技巧套路** —— 那些要在真题里自己总结。

---

## 〇、先做一次定位测（不要跳过）

::: tip 顺序很重要：先测，再清单，最后计划
1. **完整做一套剑桥真题**（听力 30 min + 阅读 60 min + 写作 60 min，**严格计时，一次做完**）
2. **按[分数段页](./ielts-score-bands)的官方换算表**，把答对题数换成 band，看清四项各在哪一档
3. **再回本页逐条勾选**，把「打不上勾的」抄成一份缺口表
4. 最后才去[执行手册](./ielts-video-route-plan)排期

> ⚠️ **不要「先背两个月单词再测」。** 不测就不知道四项各在哪一档，后面的计划全是空转。
:::

## 一、听力 Listening

**结构**：4 部分 / 40 题 / 约 30 分钟 / **录音只放一遍** / 口音含英、澳、新、北美

### 1.1 六个题型，逐个自问「我认得吗」

| ☐ | 题型（官方原名） | 自问 |
|:--:|:--|:--|
| ☐ | **Multiple choice** | 三选一 / 句尾三选一；有时要**选多个** —— 我会先看题目要求选几个吗？ |
| ☐ | **Matching** | 把录音内容匹配到选项清单 —— 我跟得上「两个人分别说了什么」吗？ |
| ☐ | **Plan / map / diagram labelling** | 地图题：**方位词**（直走、穿过远端的门…）我听得出来吗？ |
| ☐ | **Form / note / table / flow chart completion** | 填表题 —— 我注意到 **"NO MORE THAN TWO WORDS AND/OR A NUMBER"** 这类字数限制了吗？ |
| ☐ | **Sentence completion** | 补全句子 —— 我能识别**因果、转折**关系吗？ |
| ☐ | **Short-answer questions** | 简短回答 —— 地点、价格、时间这类**事实信息**我抓得住吗？ |

### 1.2 硬规则（失分重灾区）

| ☐ | 项目 | 说明 |
|:--:|:--|:--|
| ☐ | **字数限制** | 超字数**直接不给分**。`they're` 这类缩写不会被考；**连字符词（check-in）算一个词** |
| ☐ | **只放一遍** | 没有第二次机会 —— 漏了就放弃、跟上后面的题，**别纠缠** |
| ☐ | **题序 = 录音顺序** | 第 1 题答案必在第 2 题之前，可用来定位 |
| ☐ | **场景分工** | P1 两人日常 / P2 一人日常 / P3 两人学术 / P4 一人学术 |
| ☐ | **拼写** | 答案要**拼对**才算分（这是中国考生最常丢的"冤枉分"） |

## 二、阅读 Reading

**结构**：3 篇 / **总长 2150–2750 词** / 40 题 / 60 分钟
**来源**：书、期刊、杂志、报纸、网络资源，**面向非专业读者**；**至少一篇含详细逻辑论证**

### 2.1 十一个题型，逐个自问「我认得吗」

| ☐ | 题型（官方原名） | 自问 |
|:--:|:--|:--|
| ☐ | **Multiple choice** | 四选一 —— 我能排除**"文中提过但没回答本题"**的干扰项吗？ |
| ☐ | **Identifying information（True / False / Not given）** | **关键**：`False` = 与原文**矛盾**；`Not given` = 原文**既不同意也不矛盾** |
| ☐ | **Identifying writer's views（Yes / No / Not given）** | 同上逻辑，但对象是**作者的观点/主张**，不是事实 |
| ☐ | **Matching information** | 找特定信息在哪段 —— 注意「某段可能用多次 / 某段不用」 |
| ☐ | **Matching headings** | 标题数**总是多于段落数**；考的是**主旨 vs 支撑细节**的区分 |
| ☐ | **Matching features** | 把陈述匹配到特征清单（如"发明→发明者"） |
| ☐ | **Matching sentence endings** | 句子前半在文中**有序**；结尾选项多于前半 |
| ☐ | **Sentence completion** | 从原文取词填空，注意字数限制 |
| ☐ | **Summary / note / table / flow chart completion** | 答案**可能不按原文顺序**，但通常**集中在原文某一段** |
| ☐ | **Diagram label completion** | 图表标注 —— 把文字描述映射到图示 |
| ☐ | **Short-answer questions** | 用原文的词/数字作答，**答案按原文顺序** |

### 2.2 三条最常被搞错的事

::: danger 阅读的失分几乎都在这三条
1. **`False` 与 `Not given` 的区别**（以及 `No` 与 `Not given`）：
   **矛盾 → False/No；没说 → Not given。**
   官方明确警告：**不要用你原本知道的背景知识作答**，只能依据原文。
2. **`Matching headings` 的标题永远用不完** —— 这是官方明说的，不要强行把每个标题都用上。
3. **G 类阅读换算更严**：同为 7 分，学术类 30/40、**G 类 35/40**（见[分数段页](./ielts-score-bands)换算表）。
:::

## 三、写作 Writing

**结构**：60 分钟 / **2 篇** / **Task 2 分值 = Task 1 的两倍**

### 3.1 Task 1（≥150 词，约 20 分钟）

| ☐ | 项目 |
|:--:|:--|
| ☐ | 我能描述**一或多个**图表 / 表格 / 图表（graph, chart, table） |
| ☐ | 我能描述**过程图 / 示意图 / 事件序列**（diagram of an object, device, process or event） |
| ☐ | 我会写**概述（overview）** —— 先给最重要的整体趋势，而不是逐点罗列 |
| ☐ | 我会做**数据比较**（对比、极值、变化趋势） |
| ☐ | 我用的是**学术 / 半正式中立**语体，不是口语 |
| ☐ | 我**没有写成要点符号**（必须成篇连贯文字） |

### 3.2 Task 2（≥250 词，约 40 分钟）

| ☐ | 项目 |
|:--:|:--|
| ☐ | 我能**就题目限定的那个方面**作答（不是泛泛谈整个话题） |
| ☐ | 我会**提出解决方案** / **论证并支持观点** / **比较对照证据** / **评估与质疑论点** |
| ☐ | 我能用**例子或证据**支撑观点（可用自身经验） |
| ☐ | 我的结构清晰：立场 → 论证 → 例证 → 结论 |

### 3.3 四项评分维度（官方，逐条自问）

| ☐ | 维度 | 自问 |
|:--:|:--|:--|
| ☐ | **Task achievement / Task response** | 我**切题**了吗？字数够吗？（T1 150 / T2 250） |
| ☐ | **Coherence and cohesion** | 逻辑顺序清楚吗？连接词、代词、连词用得**恰当**吗（不是堆砌）？ |
| ☐ | **Lexical resource** | 词汇有**广度**吗？用词**准确得体**吗？ |
| ☐ | **Grammatical range and accuracy** | 句式有**变化**吗？语法**准确**吗？ |

## 四、口语 Speaking

**结构**：11–14 分钟 / **3 部分** / **面对面** / 全程录音

| ☐ | 部分 | 时长 | 内容 | 自问 |
|:--:|:--|:--:|:--|:--|
| ☐ | **Part 1** | 4–5 min | 自我介绍 + 熟悉话题（家、家庭、工作、学习、兴趣） | 我能**自然地**给信息和观点吗（不是背答案）？ |
| ☐ | **Part 2** | 3–4 min | 个人长陈述：**1 分钟准备**（可写笔记）→ **讲 2 分钟** | 我能**讲满 2 分钟**且有条理吗？ |
| ☐ | **Part 3** | 4–5 min | 就 Part 2 话题做**更抽象、更深入**的讨论 | 我能**分析、推测、讨论**而非描述吗？ |

### 四项评分维度（官方）

| ☐ | 维度 | 自问 |
|:--:|:--|:--|
| ☐ | **Fluency and coherence** | 语速正常、停顿不过多吗？观点有条理吗？ |
| ☐ | **Lexical resource** | 词汇够用吗？**想不起某个词时能换个说法**吗？ |
| ☐ | **Grammatical range and accuracy** | 句式有变化吗？准确吗？ |
| ☐ | **Pronunciation** | 别人**不用费力**就能听懂吗？ |

> ⚠️ **Part 3 是模板失灵的地方** —— 它是为「6.5→7.0 断层」设的（见[分数段页](./ielts-score-bands)）。

## 五、词汇

| ☐ | 项目 | 自问 |
|:--:|:--|:--|
| ☐ | **同义替换（paraphrase）** | 阅读/听力考的**核心能力**：题干的词在原文里换了说法，我认得出吗？ |
| ☐ | **学术词汇** | 阅读文章面向非专业读者，但**学术高频词**是基础门槛 |
| ☐ | **拼写** | 听力答案拼错 = 不给分。**这是我丢分最多的地方吗？** |
| ☐ | **场景词汇** | 听力 P1/P2 是租房、订票、设施介绍等**生活场景**，相关词熟吗？ |
| ☐ | **话题词汇（写作/口语）** | 常见话题（教育、环境、科技、健康…）我能写出/说出**准确搭配**吗？ |

> ⚠️ **别把「背完某本词书」当进度**。唯一可靠的进度标尺是**真题答对题数**（见[分数段页](./ielts-score-bands)）。

## 六、语法

| ☐ | 项目 | 自问 |
|:--:|:--|:--|
| ☐ | **时态** | 写作 T1 描述图表需要准确时态；T2 论证需要一般现在时为主 |
| ☐ | **主谓一致 / 名词单复数** | 中国考生最高频的笔误来源 |
| ☐ | **从句（定语/状语/名词性）** | "Grammatical range" 靠它体现 —— 但**准确优先于复杂** |
| ☐ | **被动语态** | 过程图（process）描述几乎必用 |
| ☐ | **比较结构** | T1 数据对比的核心工具 |
| ☐ | **连接词的正确使用** | 官方强调 **appropriately** —— **堆砌连接词不加分** |

## 七、自测方法（⚙️ 体系自编）

::: tip 三种能自己做的检验
1. **真题答对题数 → 官方换算表 → band**
   最硬的标尺。记录每次的**分项题数**（不是只记总分），才能看出哪一科在动。

2. **写作/口语：录音或留稿，隔一天自己回看**
   当天看不出问题；隔一天再看，**卡顿、重复用词、结构松散**会很明显。
   ⚠️ 但**自己批改有天花板** —— 写作是四项里唯一**没有标准答案可对照**的，突破需要外部反馈。

3. **错题归类，而不是只记答案**
   把错题按**题型**归类（如 T/F/NG 错了 5 道）—— 题型级缺口才是可执行的信息，单题对错不是。
:::
