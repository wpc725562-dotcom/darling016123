# 日语动词与形容词：分类判断和变形总览

核心词汇中的 `动1／动2／动3` 和 `形1／形2` 不是难度等级，而是**变形方式的分类**。同样要表达否定、过去、请求或可能，不同类别需要用不同方法改变词尾。

> **先记结论：** 动1主要是“换词尾”，动2主要是“去掉る再接”，动3需要单独记；形1改变结尾的 `い`，形2在词干后接 `だ／です／な／に` 等形式。

[[toc]]

## 一、五类标记分别表示什么

| 本书标记 | 常见名称 | 最重要的特点 | 代表词 |
| --- | --- | --- | --- |
| `动1` | 一类动词、五段动词 | 最后一个假名会换到不同元音行 | 書く、読む、話す、帰る |
| `动2` | 二类动词、一段动词 | 绝大多数变形都是去掉词尾 `る` 再接形式 | 食べる、見る、起きる |
| `动3` | 三类动词、不规则动词 | 不能套用前两类规则，需要单独记 | する、来る |
| `形1` | 一类形容词、い形容词 | 改变词尾 `い` | 高い、寒い、おいしい |
| `形2` | 二类形容词、な形容词、形容动词 | 本身不按 `い` 变化，修饰名词时接 `な` | 静か、便利、きれい |

### 为什么动1叫“五段动词”

以 `書く` 为例，词尾 `く` 会随着语法需要在五个元音段之间移动：

- **あ段**：書**か**ない
- **い段**：書**き**ます
- **う段**：書**く**
- **え段**：書**け**ば／書**け**る
- **お段**：書**こ**う

动2的词干基本不动：`食べる → 食べます／食べない／食べて／食べよう`，所以学习时可以理解为“保留 `食べ`，更换后面的零件”。

## 二、怎样判断动1、动2、动3

### 第一步：先找动3

- `する` 以及以 `する` 结尾的复合动词：勉強する、運動する、確認する。
- `来る（くる）`。

这两组属于动3。虽然复合动词很多，真正需要记住的变化核心只有 `する` 和 `来る`。

### 第二步：不以「る」结尾的动词通常是动1

例如：

- 買う、書く、泳ぐ、話す、待つ
- 死ぬ、遊ぶ、読む

这些动词的辞书形分别以 `う、く、ぐ、す、つ、ぬ、ぶ、む` 结尾，都属于动1。

### 第三步：以「る」结尾时再判断

1. `る` 前面的假名在 **い段或え段**，通常是动2：見る、起きる、食べる、寝る。
2. `る` 前面的假名在 **あ段、う段或お段**，通常是动1：分かる、作る、取る。
3. “い段／え段 + る”仍有一批常用动1，必须作为例外记忆。

常见例外：

| 动1例外 | 读音与含义 | 容易混淆的词 |
| --- | --- | --- |
| 帰る | かえる，回去 | 変える（かえる，改变，动2） |
| 入る | はいる，进入 | 居る（いる，在，动2） |
| 走る | はしる，跑 | — |
| 切る | きる，切 | 着る（きる，穿上衣，动2） |
| 要る | いる，需要 | 居る（いる，在，动2） |
| 知る | しる，知道 | — |
| 減る | へる，减少 | — |
| 滑る | すべる，滑 | — |
| 喋る | しゃべる，说话 | — |
| 握る | にぎる，握 | — |

> 判断口诀只能帮助初筛，不能代替词典。第一次学到一个以 `る` 结尾的动词时，最好把类别和单词一起记，例如“帰る・动1”“変える・动2”。

## 三、动1换词尾时使用的假名表

| 辞书形词尾 | あ段（否定等） | い段（ます形） | え段（可能、ば形、命令） | お段（意向形） |
| --- | --- | --- | --- | --- |
| う | わ | い | え | お |
| く | か | き | け | こ |
| ぐ | が | ぎ | げ | ご |
| す | さ | し | せ | そ |
| つ | た | ち | て | と |
| ぬ | な | に | ね | の |
| ぶ | ば | び | べ | ぼ |
| む | ま | み | め | も |
| る | ら | り | れ | ろ |

`う` 变到あ段时要写成 `わ`，不是 `あ`：`買う → 買わない`。

## 四、用四个代表词看完整动词变形

下面用 `書く（动1）`、`食べる（动2）`、`する（动3）` 和 `来る（动3）` 对照。先观察规则，不必一次背完所有横行。

| 形式 | 書く（动1） | 食べる（动2） | する（动3） | 来る（动3） |
| --- | --- | --- | --- | --- |
| 辞书形 | 書く | 食べる | する | 来る（くる） |
| ます形 | 書きます | 食べます | します | 来ます（きます） |
| ない形 | 書かない | 食べない | しない | 来ない（こない） |
| て形 | 書いて | 食べて | して | 来て（きて） |
| た形 | 書いた | 食べた | した | 来た（きた） |
| 可能形 | 書ける | 食べられる | できる | 来られる（こられる） |
| 意向形 | 書こう | 食べよう | しよう | 来よう（こよう） |
| ば形 | 書けば | 食べれば | すれば | 来れば（くれば） |
| 命令形 | 書け | 食べろ | しろ | 来い（こい） |
| 被动形 | 書かれる | 食べられる | される | 来られる（こられる） |
| 使役形 | 書かせる | 食べさせる | させる | 来させる（こさせる） |
| 使役被动形 | 書かせられる | 食べさせられる | させられる | 来させられる（こさせられる） |

### 1. ます形：礼貌叙述

- 动1：词尾换到い段，再接 `ます`。`読む → 読みます`。
- 动2：去掉 `る`，再接 `ます`。`見る → 見ます`。
- 动3：`する → します`；`来る → 来ます（きます）`。

`ます` 本身还会继续变化：

| 时间与肯否 | 読む的礼貌体 |
| --- | --- |
| 非过去肯定 | 読みます |
| 非过去否定 | 読みません |
| 过去肯定 | 読みました |
| 过去否定 | 読みませんでした |

去掉 `ます` 后留下的部分常叫“ます词干”：`読み、食べ、し、来（き）`。它可以接 `たい`、`ながら`、`やすい`，也可以用于 `Vに行く`。

### 2. ない形：否定的基础

- 动1：词尾换到あ段，再接 `ない`。`書く → 書かない`，`読む → 読まない`。
- 动1以 `う` 结尾：`う → わない`。`買う → 買わない`。
- 动2：去掉 `る`，再接 `ない`。`食べる → 食べない`。
- 动3：`する → しない`；`来る → 来ない（こない）`。

特殊词：`ある` 的否定是 `ない`，不说 `あらない`。

`ない形` 可以继续组成 `Vないでください`、`Vなければなりません`、`Vなくてもいい` 等表达。

### 3. て形与た形：按词尾分组记

动1的 `て形／た形` 不能只按五十音顺序换，需要记下面五组音变：

| 动1词尾 | て形 | た形 | 例子 |
| --- | --- | --- | --- |
| う、つ、る | って | った | 買う→買って／買った；帰る→帰って／帰った |
| む、ぶ、ぬ | んで | んだ | 読む→読んで／読んだ；遊ぶ→遊んで／遊んだ |
| く | いて | いた | 書く→書いて／書いた |
| ぐ | いで | いだ | 泳ぐ→泳いで／泳いだ |
| す | して | した | 話す→話して／話した |

唯一需要优先记住的高频例外：`行く → 行って／行った`，不说 `行いて／行いた`。

- 动2：去掉 `る`，接 `て／た`。`食べる → 食べて／食べた`。
- 动3：`する → して／した`；`来る → 来て（きて）／来た（きた）`。

`て形` 常用于连接动作、请求、进行、许可与禁止；`た形` 常用于过去、经历、列举和条件 `～たら`。

### 4. 可能形：表示“能做”

- 动1：词尾换到え段，再接 `る`。`書く → 書ける`，`読む → 読める`。
- 动2：去掉 `る`，接 `られる`。`食べる → 食べられる`。
- 动3：`する → できる`；`来る → 来られる（こられる）`。

口语中能听到 `食べれる`、`見れる`，这是省略 `ら` 的说法；正式写作和考试优先使用 `食べられる／見られる`。

### 5. 意向形：表示“来做吧／我打算做”

- 动1：词尾换到お段，再接 `う`。`書く → 書こう`。
- 动2：去掉 `る`，接 `よう`。`食べる → 食べよう`。
- 动3：`する → しよう`；`来る → 来よう（こよう）`。

礼貌提议使用 `～ましょう`；普通体意向形还可用于 `～と思う`：`日本へ行こうと思います`。

### 6. ば形与命令形

- 动1ば形：词尾换到え段，再接 `ば`。`書く → 書けば`。
- 动2ば形：去掉 `る`，接 `れば`。`食べる → 食べれば`。
- 动3ば形：`すれば／来れば（くれば）`。

动1的命令形直接换到え段；动2常用“去 `る` + `ろ`”；动3是 `しろ／来い`。命令形语气很强，日常对不熟悉的人不要随意使用，通常改用 `Vてください`。

### 7. 被动形与使役形

| 类别 | 被动形 | 使役形 |
| --- | --- | --- |
| 动1 | あ段 + `れる`：書かれる | あ段 + `せる`：書かせる |
| 动2 | 去 `る` + `られる`：食べられる | 去 `る` + `させる`：食べさせる |
| 动3 | される／来られる | させる／来させる |

动2的 `食べられる` 既可能是“能吃”，也可能是“被吃”；要结合助词和上下文判断。被动形、可能形、使役形变出来后，本身通常继续按动2变化：`書ける → 書けない／書けました`。

使役被动表示“被迫或不得不做”：动1用“あ段 + `せられる`”，动2用“去 `る` + `させられる`”，动3用 `させられる／来させられる`。口语中部分动1会缩约，如 `書かせられる → 書かされる`；初学和正式写作先使用完整形式。

## 五、先掌握普通体的四格

日语所说的“非过去”可以表示现在习惯、一般事实或将来，并不只等于中文的现在时。

| 词类 | 非过去肯定 | 非过去否定 | 过去肯定 | 过去否定 |
| --- | --- | --- | --- | --- |
| 动词 | 行く | 行かない | 行った | 行かなかった |
| 形1 | 高い | 高くない | 高かった | 高くなかった |
| 形2 | 静かだ | 静かではない | 静かだった | 静かではなかった |
| 名词 | 学生だ | 学生ではない | 学生だった | 学生ではなかった |

口语中 `では` 常缩成 `じゃ`：`静かじゃない／学生じゃなかった`。

## 六、怎样判断形1和形2

### 形1：词尾「い」会发生变化

形1通常以 `い` 结尾：高い、寒い、新しい、面白い。修饰名词时直接放在名词前：`高い山`。

但“以い结尾”不是绝对判断标准。`きれい（漂亮／干净）`、`嫌い（讨厌）` 虽然最后写着 `い`，却属于形2；`好き、上手、下手、元気、便利` 也都是形2。

### 形2：修饰名词时使用「な」

形2作句子谓语时说 `静かです／静かだ`，修饰名词时才加 `な`：`静かな町`。

- `静かです`：正确。
- `静かな町`：正确。
- `静かなです`：错误，因为 `な` 不能直接放在 `です` 前。

`好き` 在中文里像动词，但日语中属于形2，所以说 `音楽が好きです`，不说 `好きます`。

## 七、形1和形2的变形区别

### 形1：改变最后的「い」

以 `高い` 为例：

| 功能 | 形式 | 例子 |
| --- | --- | --- |
| 非过去肯定 | 保留 `い` | 高い／高いです |
| 非过去否定 | `い → くない` | 高くない／高くないです |
| 过去肯定 | `い → かった` | 高かった／高かったです |
| 过去否定 | `い → くなかった` | 高くなかった／高くなかったです |
| 修饰名词 | 直接接名词 | 高い山 |
| 修饰动词 | `い → く` | 高く売る |
| 并列、连接 | `い → くて` | 高くて便利です |
| 条件 | `い → ければ` | 高ければ買いません |
| 自然变化 | `い → くなる` | 高くなる |
| 人为改变 | `い → くする` | 音を大きくする |

也可以用更正式的否定：`高くありません／高くありませんでした`。

#### 特殊形1「いい」

`いい（好）` 的变形使用 `よい` 的词干：

- いい／よい
- よくない
- よかった
- よくて
- よければ

不能说 `いくない` 或 `いかった`。

### 形2：词干不变，后面接不同形式

以 `静か` 为例：

| 功能 | 普通体或连接形式 | 礼貌表达／例子 |
| --- | --- | --- |
| 非过去肯定 | 静かだ | 静かです |
| 非过去否定 | 静かではない | 静かではありません |
| 过去肯定 | 静かだった | 静かでした |
| 过去否定 | 静かではなかった | 静かではありませんでした |
| 修饰名词 | 静かな | 静かな町 |
| 修饰动词 | 静かに | 静かに話す |
| 并列、连接 | 静かで | 静かで便利です |
| 条件 | 静かなら／静かであれば | 静かなら住みたいです |
| 自然变化 | 静かになる | 町が静かになりました |
| 人为改变 | 静かにする | 部屋を静かにしてください |

形2和名词作谓语时很像：`静かだ／学生だ`。但修饰名词时不同：形2用 `な`（静かな町），名词通常用 `の`（学生の生活）。

## 八、根据想表达的意思选择形式

| 想表达的功能 | 使用的形式 | 例子 |
| --- | --- | --- |
| 礼貌叙述动作 | ます形 | 毎日勉強します |
| 普通叙述、接 `こと／前に` | 辞书形 | 寝る前に読みます |
| 否定、禁止、义务 | ない形 | 忘れないでください |
| 连接动作、请求、进行 | て形 | 座ってください |
| 过去、经历、建议 | た形 | 日本へ行ったことがあります |
| 能够做某事 | 可能形 | 日本語が話せます |
| 打算或提议 | 意向形 | 一緒に帰ろう |
| 假设条件 | ば形／たら形 | 安ければ買います |
| 动作承受者作主语 | 被动形 | 先生に褒められました |
| 让或允许别人做 | 使役形 | 子どもを遊ばせます |

## 九、最常见的变形错误

| 错误 | 正确 | 原因 |
| --- | --- | --- |
| 食べります | 食べます | 食べる是动2，要去掉 `る` |
| 書くない | 書かない | 动1否定要换到あ段 |
| 買あない | 買わない | `う` 的あ段变化使用 `わ` |
| 行いて | 行って | `行く` 是て形的高频例外 |
| 高いでした | 高かったです | 形1过去式要把 `い` 变成 `かった` |
| きれいくない | きれいではない | きれい是形2，不按形1变化 |
| 静かなです | 静かです | `な` 只在修饰名词时使用 |
| 好きます | 好きです | 好き是形2，不是动词 |
| 帰ます | 帰ります | 帰る是动1例外，ます形为帰ります |

## 十、自测练习

### 练习一：判断类别

判断下列词属于动1、动2还是动3：

`書く、食べる、見る、帰る、入る、起きる、する、勉強する、来る、できる、切る、着る`

### 练习二：完成动词变形

1. `飲む`：ます形、ない形、て形、た形。
2. `話す`：ます形、ない形、て形、可能形。
3. `買う`：ない形、て形、意向形。
4. `行く`：て形、た形、ば形。
5. `食べる`：ます形、ない形、可能形、意向形。
6. `来る`：ます形、ない形、て形、意向形。

### 练习三：完成形容词变形

1. `暑い`：否定、过去、连接形式。
2. `静か`：修饰名词、否定、修饰动词。
3. `いい`：否定、过去、条件形式。

## 十一、推荐的记忆顺序

1. 学一个动词时同时记“辞书形 + 类别”，例如 `帰る・动1`。
2. 先熟练 `ます形、ない形、て形、た形`，它们是后续语法的地基。
3. 再学习 `可能形、意向形、ば形`。
4. 最后集中掌握 `被动形、使役形、使役被动形`。
5. 每次变形都放进完整句子，不只背孤立词尾。
