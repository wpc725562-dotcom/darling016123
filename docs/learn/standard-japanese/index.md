# 标日同步语法与词汇手册 📚

这是一套面向中文母语者的三卷本日语学习笔记，沿用《新版中日交流标准日本语》从初级到高级的学习顺序，逐课整理语法骨架、核心词汇、原创例句和复习任务。

> 本手册是独立编写的配套复习资料，不收录或替代原教材的课文、录音、练习及完整生词表。不同印次的细节可能略有差异，学习时请与手中的正版教材对照。

::: warning ⚠️ 第二卷（中级）与第三卷（高级）的语法点与教材课次错位（2026-09-23 核实）
**这两卷的「语法地图」请勿直接照背 —— 它把某些课次的语法点安到了别的课上。**

已核实：**高级上第 1 课**教材讲的是 `これほど〜は、〜ない` 与「说明文与条目式写法」，

## 入门必读

### [日语动词与形容词：分类判断和变形总览](./conjugation-guide)

先弄懂 `动1／动2／动3` 与 `形1／形2` 的区别，再进入逐课学习。这里集中整理了判断方法、易错例外、`ます形／ない形／て形／た形／可能形／被动形／使役形` 等变形规则，以及两类形容词的完整活用对照。

## 三卷目录

### [第一卷：初级篇（第 1～48 课）](./elementary) ✅ 已核对无误

从判断句、指示词和基础助词开始，系统掌握动词变形、形容词、授受关系、条件、可能、被动、使役与初级敬语。学完后建立 N5～N4 的语法和生活词汇基础。

### [第二卷：中级篇（第 1～32 课）](./intermediate) ⚠️ 语法点错位

## 每课怎么学

1. 先读“语法地图”，确认这课解决什么表达问题。
2. 朗读原创例句，替换其中的人物、时间和对象。
3. 把核心词汇按搭配记忆，不孤立背中文释义。
4. 不看页面复述语法，并完成课末的一句话任务。
5. 每四课进行一次回顾，把容易混淆的表达放在一起比较。

## 配套材料怎么配合

站内日语内容有**三层**，本手册是**第一层**（最浓缩）：

| 层 | 页面 | 定位 | 每课信息量 |
|:--:|:--|:--|:--|
| **第三层** | [**标日深度笔记**](/course/japanese/deep/) | 逐条语法的接续 / 用法 / 例句 / 辨析 / 自测 | 40～60 行 |
| **第二层** | [**日语跟课笔记**](/course/japanese/) | 老师怎么讲、强调什么、哪里容易错 | 1 页 |
| **第一层（本手册）** | 本页 | 逐课语法清单 + 核心词汇（浓缩） | 4 行 |

三者是**递进**关系，不是替代关系：

- **本手册管「有哪些知识点」** —— 快速确认「第 N 课讲了什么」
- **跟课笔记管「课怎么上」** —— 按老师的讲解顺序记核心知识点 / 老师强调 / 易错 / 复习自测
- **深度笔记管「这个语法到底怎么接、怎么用、和谁容易混」** —— 最详细，也最可信

> ⚠️ **中级以后请直接看[深度笔记](/course/japanese/deep/)** —— 本手册第二、三卷的语法点与课次错位（见页首警示）。
> 本手册的**第一卷（初级）与入门必读**不受影响，可以放心用。
