**⇒ 原结论「B站上没有一条带字幕的日语视频讲到了 N1」成立**，而且现在有了全量证据，

::: warning 这个否定结论是复核过的，不是猜的
两道复核（2026-09-24）：
1. **用登录态 + 正确端点** —— 走 `x/player/wbi/v2`（非 wbi 版会返回**别家视频的字幕轨**），并先验 `nav.isLogin` 为真。研习社 P169–184 共 16 个分P 全部返回 `code:0` + 空轨列表 + `need_login=False`，是 **可信的否定**。
2. **跑了阳性对照** —— 同一轮里探阿飞 P3 / P4 / P6（**命中**）与 P5（**未定**，因轨 URL 不含 aid+cid）。
   对照通过，说明探针本身是好的。**若没有阳性对照，一个「0/N」是不可证伪的** —— 它可能是「真没字幕」，也可能是「凭据失效/端点用错」。

**这解释了两件事**：
- 阿飞的课因为**字幕覆盖到中级**，才能被整理成「先读笔记再听课」—— 这就是[跟课笔记](/course/japanese/)的来源。
- **N1 阶段没有这个条件**：研习社那 16 集既无字幕、又是 70 分钟长视频，只能实时看、自己记。
  这也是[深度笔记](/course/japanese/deep/)的 N1 部分标注为「教材体系」而非「视频提炼」的原因。
:::

### 7.1 顺带解决一处文档疑点

[执行手册](./japanese-video-route-plan) 的「诚实边界」里标注过一处不一致：说阿飞课程覆盖到「中级第 21 课」，但 `P200` 标题写着「后面课程搜索：新标日中级下」。

全量普查的逐分P 结果（`阿飞 P195–200`）：

| 分P | 标题 | 字幕 |
|:--:|:--|:--:|
| P195 | 中级第21课：单词 | ❌ |
| P196 | 中级第21课：语法 | ✅ |
| P197 | 中级第21课：课文1（上） | ✅ |
| P198 | 中级第21课：课文1（下） | ❌ |
| P199 | 中级第21课：课文2 | ❌ |
| P200 | 后面课程搜索：新标日中级下 | ❌ |

**结论：课程真实止于中级第 21 课；`P200` 只是一个指路的分P，不含教学内容。** 那处 ⚠️ 可以消掉了。

> 📎 说明：阿飞本门课此前记录为「153 有字幕」，本次全量普查为 **151 有字幕 + 45 无字幕 + 4 未定**。
> 差额来自那 4 个未定分P，**不是数据矛盾**。以本次全量为准。

### 7.2 复现方法

```bash
# 全量普查（本表就是这条命令跑出来的）
python scripts/bili_probe_courses.py --list courses.json --out result.json
# 单门课全量
python scripts/bili_probe_courses.py --bv BV14T4y1Y78G:研习社
# 指定范围
python scripts/bili_probe_parts.py --bv BV14T4y1Y78G --pages 169-184
```

⚠️ **两条必须遵守的前提**（否则结果无意义）：
1. **需要登录态** —— AI 字幕是登录门控的。脚本会先验 `nav.isLogin`，**未登录直接中止**（否则「未登录」会伪装成「没字幕」）。
2. **必须有阳性对照** —— 同一轮里至少探一个**已知有字幕**的分P，证明探针是好的。见 skill `bilibili-video-capture`。
