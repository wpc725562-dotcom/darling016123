# 零基础五十音入门 🌸

> **你是零基础？就从这里开始。** 五十音是日语的地基，本页把最需要的东西一次给你：完整假名表、发音要点、学习方法和免费资源。看完就能开始背。

| **さ行** | さ sa | し shi | す su | せ se | そ so |

## 四、长音 · 促音（发音要点）

- **长音**：拉长一拍。平假名 `おかあさん`(okaa-san)、片假名用 `ー`（如 `コーヒー` 咖啡）。
- **促音**：小 `っ`，停顿一拍再继续，如 `きって`(kitte 邮票)。
- **音拍**：日语每个假名（含 ん、长音、促音）都是一拍，节奏均匀，像节拍器。

## 五、怎么学（四步法）

1. **辨认**：看到 `き` 立刻反应读 ki，不要数笔划。
2. **发音**：跟着音频模仿，别用中文"ki=克一"代替。
3. **书写**：每行写 5 次，注意笔顺和形状。
4. **回忆**：遮住答案，听音写假名，再反着测（看假名读音）。

**计划**：每天 2 行平假名（约 4 天）→ 2 行片假名（约 4 天）→ 浊音/拗音 3 天 → 两周内见假名能读。

> 罗马音只在前几天辅助，**两周后关掉它**，不然大脑会一直绕过假名。

## 八、假名的来源：为什么「联想记忆」成立

「假名」的「假」是**假借**的意思 —— 每个假名都是从一个汉字变来的。平假名取汉字的**草书**（整字连笔），片假名取汉字的**某一部分**（偏旁或几笔）。

这一节是后面两张记忆表的地基：**字源负责解释「为什么长这样」，联想负责让你今天就记住。**

### 8.1 先理解结构，再背字形

五十音不是 50 个孤立符号：

- **5 段 × 若干行**：`あ い う え お` 是竖着的 5 段，每行 = 一个辅音 + 这 5 个元音。
- `か行 = k + あいうえお`、`な行 = n + あいうえお` —— **会读あ行 + 知道每行的辅音，剩下的音可以自己推出来**，不必逐字死记。
- 真正需要「记形状」的只有**字形**；发音是推出来的。
- **あ行是元音行，所有发音都由它派生。** 第一件事是把 5 个元音读准，第二件事是背 **あ段竖列**（`あ か さ た な は ま や ら わ`）。

### 8.2 记忆顺序（不要按 あいうえお 顺着背）

1. 先攻 **あ行** 5 个元音 —— 读准口型。
2. 再背 **あ段竖列** —— 整张表的骨架。
3. 按行推进：か行 → さ行 → た行 → な行；は行 → ま行 → や行 → ら行 → わ行 + ん。
4. **浊音 / 半浊音**（只是加两点或一个圈，不用重新学音）。
5. **拗音**（い段 + 小写 ゃゅょ，36 个）。
6. **长音 / 促音 / 声调** —— 放进单词里练，不要单独背。

> 🎬 阿飞老师课里第 1–6 讲正好是这个顺序，分P 对照见[入门篇笔记](/course/japanese/00-入门篇)。

## 十、片假名记忆法（课程里没有，本页补）

::: warning 先说清来源

### 10.1 记法核心：片假名比平假名更好记

1. **先记那 15 个「同形」的**：イ エ カ コ タ チ ト ニ ネ ノ ハ ホ ミ モ リ ル ロ —— 它们不需要联想，看一眼就是那个汉字。**一天就能过完。**

## 十一、易混假名辨析

这些是「单独看都认识、放一起就懵」的组合。每组给一条**可当场使用的判据**。

| 易混组 | 判据（一句话） |
|:--|:--|
| **シ vs ツ** | シ 的三点偏 **竖**（从上往下写）；ツ 的三点偏 **横**（从左往右写）。口诀：**「し」是竖的，「つ」是横的** |
| **ソ vs ン** | 同一条规律：ソ 两点偏 **竖**，ン 两点偏 **横**。ソ 从左上起笔往右下；ン 从下往上挑 |
| **ウ vs ワ vs フ** | ウ 上面 **多两点**（来自「宇」的宀）；ワ **没有点**（来自「和」）；フ **只有两笔**（来自「不」）。数点的个数 |
| **ク vs ケ vs ワ** | 都无点，靠 **撇的方向** 分：ク 撇向左下、ケ 撇向左上、ワ 是「和」的右部 |
| **ね vs れ vs わ** | 看右边：ね **有圈**、れ **没有圈**（一竖到底）、わ **是一勾**。从「圈 → 直 → 勾」 |
| **る vs ろ** | る **有圈**、ろ **没有圈**。就这一个差别，其他完全一样 |
| **ス vs ヌ** | ス 是「又」（一横一撇）；ヌ 比 ス **多一撇**。ヌ = ス + 一撇 |
| **チ vs テ** | チ（千）上面是一 **撇**；テ（天）上面是一 **横**。看最上面那一笔 |
| **ア vs マ** | ア（阿）有一竖弯到底；マ（万）是一横 + 一撇 + 一点 |
| **エ vs ユ vs ヨ** | エ 是「工」（两横一竖）；ユ 是「由」的下半（一横一竖钩）；ヨ 是「与」的右边（三横一竖） |
| **ラ vs う** | ラ 是**片假名**（「良」的上半）；う 是**平假名**（一点 + 一横弯）。混的是横竖结构 |
| **は vs ほ** | は 右边是「一竖 + 一横圈」；ほ 右边是「一竖 + **两横**」。数横的条数 |
| **め vs ぬ** | め 是「女」；ぬ 是「め **多一个圈**」（来自「奴」） |
| **ワ vs ネ vs レ** | ネ 有「礻」的横折、レ 是一竖一勾、ワ 是一竖一横折。**先把平假名的区分搞清，再映射过来** |

## 十二、发音难点汇总

下面每一条都是中国学生的实际高频错误。

| 假名 | 常见错误 | 正确做法 |
|:--|:--|:--|
| **う** | 像中文「乌」那样往外 **撅嘴** | 嘴唇要 **收回来**，不撅 |
| **あ / お** | 拉长读成「啊——」「哦——」 | 都是 **短音**，不要拖长 |
| **か** | 听着像 ga，就以为要读 ga | 就读 **ka**。听起来像 ga 是 **鼻浊音**，日本年轻人已不用，**不必学** —— 学了反而默写时分不清 k / g。原则：**写什么读什么** |
| **す** | 读成「苏」或纯「丝」 | 是 **苏与丝之间、略偏丝** 的音 |
| **し** | 按罗马音读「si」 | 读得像「**西**」 |
| **ち** | 按罗马音读「ti」 | 读得像「**qi**」（汉语拼音） |
| **つ** | 按罗马音读「tu」 | 读得像「**ci**」（汉语拼音） |
| **ふ** | 读成「夫」或「呼」 | 嘴唇 **留一条缝、把气吹出去**。罗马音写 fu，但和中文「夫」不一样 |
| **ら行** | 读成 r | **全部读 l**（日本人发不出 r）——「日本人」他们会说成「立本银」 |
| **を** | 读成 wo | 发音同 **お**；现代日语 **只作助词** |
| **は（作助词）** | 读 ha | 作助词时读 **wa**（第 1 课语法就会用到） |
| **长音** | 忽略不计，直接读短 | 必须读出 **「滑」的过程**：高到低要降下来、低到高要滑上去。差一个长音意思全变（おばあさん 奶奶 vs おばさん 阿姨） |
| **促音 っ** | 读成 tsu，或直接跳过 | 小っ **不发音**，作用是 **停顿一拍**，憋住气再冲出去。有促音 vs 没促音是两回事（おと 声音 vs おっと 丈夫） |
| **拗音 きゅ / しゅ** | 读成两个字（ki-ya） | **两个字读一拍**，一口气读出来。**不要用罗马音记拗音** —— 拿它读反而容易错 |

> 🎬 以上发音要点多数来自阿飞老师入门篇的「关键要点」块，逐条对照见[入门篇笔记](/course/japanese/00-入门篇)。

## 十三、14 天逐日安排

第五节给了「1–2 周」的粗略计划和四步法；这里把 14 天铺开，落到「第几天学哪几个字」。

**每天固定动作（不写进表里，但每天都要做）**：① 当天新字手写 5 遍；② 昨天的字默写 1 遍；③ 假名卡 10 分钟；④ 听音频跟读 3 遍。

| 天 | 学什么 | 当天动作 | 自测 |
|:--|:--|:--|:--|
| 1 | **あ行** あ い う え お + 结构认知 | 理解「5 段 × 行」；把 5 个元音读准；写 5 遍 | 不看表写出 あ行，说出每个的口型要点 |
| 2 | か行 + さ行（10 个） | 记「k + 元音」「s + 元音」；重点记 し（不是 si） | 看罗马字写出 10 个字 |
| 3 | た行 + な行（10 个） | 重点记 ち（qi）、つ（ci） | 看罗马字写出 10 个字 |
| 4 | **复习 あ → な 行** | 背 あ段竖列；默写全部 25 个 | 默写 25 个全对 |
| 5 | は行 + ま行（10 个） | 重点记 ふ 的口型、は 作助词读 wa | 看罗马字写出 10 个字 |
| 6 | や行 + ら行 + わ行 + ん（11 个） | 记「ら行全读 l」「を 只作助词」「ん 不属任何行」 | 说出哪两行不满 5 个音、为什么 |
| 7 | **平假名总复习** | 默写 46 个；练手写体（さ / き / も / ゆ / よ / り / れ 不连笔） | **平假名默写全对** |
| 8 | **片假名 ア → ナ 行**（25 个） | 用第十节字源表；先记「同形」的（イ エ カ コ タ チ ト ニ ネ ノ） | 看片假名读音，25 个全对 |
| 9 | **片假名 ハ → ン 行**（21 个） | 先记同形的（ハ ホ ミ モ リ ル ロ） | 看片假名读音，21 个全对 |
| 10 | **片假名总复习** | 默写 46 个；重点过第十一节的易混组 | **片假名默写全对** |
| 11 | **浊音 + 半浊音** | が / ざ / だ / ば 行 + ぱ 行；记「じ/ぢ 同音、ず/づ 同音」 | 默写 4 条浊音行 + 1 条半浊音行；说出哪两组同音 |
| 12 | **拗音 36 个** | い段 + 小写 ゃゅょ；练「两个字读一拍」；重点练 きゅ / しゅ / ちょ | 读出 36 个不卡壳 |
| 13 | **长音 + 促音** | 背 7 条长音规则；练停顿（きって / がっこう / おっと） | 判断 きゅう / しょう 里有没有长音、为什么 |
| 14 | **声调 + 总测** | 背两条铁律；学零型 / 一型 / 二型的区别 | **听写 10 个词，对 8 个以上** |

::: warning 第 14 天的四条验收线（全过才进初级）
1. 平假名 46 个：看罗马字写假名，**全对**。
2. 片假名 46 个：看假名读音，**全对**。
3. 拗音 33 个：能读出**不卡壳**。
4. 听写 10 个词：**对 8 个以上**。

**这四条任意一条没过，不要开始第 1 课。** 五十音不熟就往下走，后面每一课都会加倍还债。
:::

### 13.1 三种自测方法（不用等别人出题）

1. **双向默写**：① 看罗马字 → 写假名；② 看假名 → 写罗马音。**两个方向都要过** —— 只做一个方向会漏掉「会认不会写」。
2. **遮住答案听写**：随机播 10 个假名发音，写下假名。最接近实战的形式。
3. **放进单词里测**：单独认得出 ≠ 在词里认得出。用「おかあさん」「がっこう」这类词测 —— **能读对长音和促音才算真会**。

::: danger 两个最容易走偏的地方
1. **罗马音要尽早关掉。** 只在前几天辅助，两周后必须关 —— 不然大脑会一直绕过假名走罗马音，永远做不到「看到假名直接反应」。
2. **发音必须现在抓住。** 老师原话：不要想着考过 N2、N1 以后再去练发音，**那时候已经很难改回来了**。
:::
