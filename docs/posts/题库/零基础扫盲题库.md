## Part 1：高数符号扫盲（20题）

---

**Q1** `lim` 这三个字母是什么意思？中文怎么读？

**A1**
`lim` 是英文 **limit（极限）** 的缩写，中文读作「**极限**」。

看到 `lim` 就翻译成人话：**「当……慢慢靠近某个值时，结果趋向于多少」**。

它考的不是计算，是"无限靠近但可能到不了"这个概念。

---

**Q2** `x → 0` 怎么读？它表示 x 等于 0 吗？

**A2**
读作「**x 趋向于 0**」（箭头 → 就是"趋向、越来越靠近"）。

**不等于 0**。它说的是 x 在**无限靠近** 0 的路上：0.1、0.01、0.001、0.0001……

这就是极限最容易踩的坑：`x → 0` 时 x **永远不取 0**，所以式子里出现分母为 x 的东西也不会炸。

---

**Q3** `∞` 是什么？它算一个数吗？

**A3**
读作「**无穷大**」，英文 infinity。

**它不是一个数**，是一个"趋势描述"。`x → ∞` 意思是「x 一直变大，没有上限」。

所以你不能写 `∞ + 1 = ∞` 之类的算式去算它，考试里凡是把 ∞ 当普通数字代入的都是错的。

---

**Q4** 完整读法：`lim(x→0) sinx/x = 1` 用中文怎么说？

**A4**
「**当 x 趋向于 0 时，sin x 除以 x 的极限等于 1**」。

这是高数第一个重要极限，专升本必考。记住它的形状：**分子是 sin，分母是同一个东西**，两者都趋 0，结果就是 1。

如果分母变成 `2x`，结果就不是 1 而是 1/2 —— 因为凑不成"同一个东西"。

---

**Q5** `(x²)′` 右上角那个小撇 `'` 是什么意思？

**A5**
那个撇叫「**撇号**」，表示**求导**（derivative）。

`(x²)′` 读作「x 平方的导数」。所以 `(x²)′ = 2x` 不是"算出来的数"，而是**一个变换规则**：把 x² 这个函数，变成 2x 这个新函数。

几何含义：导数 = **曲线在该点的斜率**（切线有多陡）。

---

**Q6** 除了撇号，导数还有哪种写法？`dy/dx` 是什么？

**A6**
莱布尼茨写法：`dy/dx`，读作「**d y 比 d x**」或「y 对 x 的导数」。

`dy/dx` 和 `y′` 是**同一个东西的两种写法**，不是除法（虽然长得像）。

考题里两种会混着用，看到 `dy/dx` 别慌，它就是"y 求导"。

---

**Q7** `Σ` 是什么符号？`Σ(n=1到4) n` 等于多少？

**A7**
`Σ` 是希腊字母 sigma，表示**求和**（加起来的缩写）。

`Σ(n=1到4) n` = 1 + 2 + 3 + 4 = **10**。

读法：「n 从 1 加到 4 的 n 之和」。下面写起点，上面写终点，右边写"每一项长什么样"。

---

**Q8** `∫` 是什么符号？

**A8**
`∫` 是拉长的 S（英文 sum 的 s），表示**积分**。

它是求导的**逆运算**：已知导数 f′(x)，积分 ∫f′(x)dx 把它变回原来的 f(x)。

`dx` 不能漏，它表示「**对 x 积分**」——跟 `∫x²dt` 完全不是一回事。

---

**Q9** `f(x)` 里的括号是乘法吗？`f(x) = x² + 1` 中 `f(2)` 等于几？

**A9**
**不是乘法**。`f(x)` 读作「f  of x」，意思是「**函数 f 作用在 x 上**」。

可以理解成一台机器：`f( )` 是机器，把 `x²+1` 里的 x 换成你投进去的东西。

`f(2) = 2² + 1 = 5`。

---

**Q10** `≤`、`≥`、`≠`、`≈` 分别怎么读？

**A10**
- `≤` 小于等于（不超过）
- `≥` 大于等于（不低于）
- `≠` 不等于
- `≈` 约等于

考试里 `≤` 和 `<` 的差别就是**端点取不取**，写错直接扣分。

---

**Q11** `\frac{3}{5}` 是什么？为什么 LaTeX 里用花括号？

**A11**
这是**分式**：分子 3、分母 5，就是分数 3/5。

花括号 `{}` 的作用是**划清边界**：`\frac{a+b}{c+d}` 里分子是 `a+b` 整体。不写花括号 `\frac{a+b}{c}` 会变成 `((a+b))/c`——分子只认一个字符。

⚠️ 刷题时看到 `\frac` 别慌，它就是一个分数，读作「多少分之多少」。

---

**Q12** `x^2` 和 `a_n` 里的 `^` 与 `_` 分别表示什么？

**A12**
- `^` 表示**上标**，通常是乘方：`x^2` = x²（x 的平方）
- `_` 表示**下标**，通常是序号：`a_n` = aₙ（数列第 n 项）

`a_1` 是第 1 项，`a_2` 是第 2 项。它们不是 a 乘以 1。

---

**Q13** `\sqrt{x^2+1}` 怎么读、什么意思？

**A13**
读作「**根号下 x 平方加 1**」，即 √(x²+1)，表示"哪个非负数的平方等于 x²+1"。

根号**默认只取正的那个**（算术平方根），所以 √4 = 2 而不是 ±2。

如果题目要 ±，会写成 `±√4`。

---

**Q14** `x → 0⁺` 和 `x → 0⁻` 有什么区别？

**A14**
- `0⁺`：**从右边靠近 0**（比 0 大一点点），如 0.001
- `0⁻`：**从左边靠近 0**（比 0 小一点点），如 -0.001

区别在 `1/x` 上特别明显：`x→0⁺` 时 `1/x → +∞`；`x→0⁻` 时 `1/x → -∞`。

**左右极限不相等 → 极限不存在**，这是判断题最爱考的点。

---

**Q15** 「间断点」是什么意思？

**A15**
函数图像上**断开、跳一下、或压根没定义**的那个点，就叫间断点。

常见三类：
1. **可去间断点**：极限存在，但函数在那点没定义（补一个点就能接上）
2. **跳跃间断点**：左右极限都存在但不相等（图像跳了一格）
3. **第二类（无穷）间断点**：左右至少有一个是 ∞（图像冲上天）

---

**Q16** 什么是「不定型」（比如 `0/0` 型、`∞/∞` 型）？

**A16**
指分子分母各自都趋 0 或都趋 ∞，**光看形式无法确定结果**，必须变形才能算。

- `0/0` 型 → 通常用**约分**或**等价无穷小替换**
- `∞/∞` 型 → 通常用**抓大头**（只看最高次项）

⚠️ `0/0` **不等于 0，也不等于 1**，它是个问号，必须算。

---

**Q17** 「抓大头法则」是什么？什么时候能用？

**A17**
用于 `∞/∞` 型极限：**分子分母都只保留次数最高的那一项，其余全扔掉**。

例：`(3x³ + 2x² - 1)/(5x³ - 4x + 7)`，x→∞ 时抓大头 → `3x³/5x³ = 3/5`。

为什么能扔：x 巨大时，x³ 项把 x²、常数项完全淹没了。

---

**Q18** 「等价无穷小替换」是什么意思？举一个最常用的。

**A18**
当 x→0 时，有些式和 x 长得"几乎一样"（比值趋 1），可以**互相替换**简化计算。

最常用的记这几个（都只在 x→0 时成立）：
- `sin x ~ x`
- `tan x ~ x`
- `1 - cos x ~ x²/2`
- `ln(1+x) ~ x`
- `eˣ - 1 ~ x`

例：`lim(x→0) tan2x/sin3x` → 换成 `2x/3x = 2/3`。

⚠️ **只能在乘除里换，加减里换会错**（这是最经典的扣分点）。

---

**Q19** 幂函数求导公式是什么？`(x⁵)′` 等于？

**A19**
`(xᵃ)′ = a · x^(a-1)` —— **指数搬到前面当系数，指数减 1**。

`(x⁵)′ = 5x⁴`。

这就是 09-07 那道题的扣分原因：答案 `(x²)′ = 2x` 写对了，但**写不出"用了幂函数求导公式"**这个依据，考试照样给一半分。

---

**Q20** 常见函数的导数，先把这 5 个背下来。

**A20**
- `C′ = 0`（常数的导数是 0）
- `(xᵃ)′ = a·x^(a-1)`
- `(sin x)′ = cos x`
- `(cos x)′ = -sin x`  ← **负号必背**
- `(eˣ)′ = eˣ`  ← 唯一求导后不变的

## Part 2：C 语言符号与概念扫盲（20题）

---

**Q1** C 语言程序最小完整框架是什么？逐行说出作用。

**A1**
```c
#include <stdio.h>        // 引入输入输出库，这样才能用 printf
int main() {              // 程序入口，操作系统从这里开始执行
    // 这里写要做的事
    return 0;             // 告诉系统"程序正常结束"
}
```

四样**缺一不可**：`#include`、`int main()`、`{}`、`return 0`。

⚠️ 09-07 那道题你只写了 `#include <stdio.h>` 就没东西可写了 —— 现在照着上面这个抄一遍、默写一遍。

---

**Q2** 为什么每行代码后面要有分号 `;`？

**A2**
`;` 是**语句结束标记**，相当于中文的句号。C 语言靠它判断一句话到哪里结束。

漏写 → 编译报错，通常报在**下一行**（所以报错行号经常是假的，要往上找）。

---

**Q3** `printf` 和 `scanf` 分别干什么？`\n` 是什么？

**A3**
- `printf`：**打印输出**到屏幕（p 是 print）
- `scanf`：**读取输入**（从键盘读）
- `\n`：**换行符**。不加 `\n`，下一次输出会接在同一行后面。

`printf("%d\n", 5);` → 屏幕显示 `5` 然后换行。

---

**Q4** `int`、`float`、`double`、`char` 有什么区别？

**A4**
| 类型 | 存什么 | 举例 | 典型字节 |
|:---|:---|:---|:---|
| `int` | 整数 | `5`, `-3` | 4 |
| `float` | 单精度小数 | `3.5f` | 4 |
| `double` | 双精度小数（更准） | `3.5` | 8 |
| `char` | 单个字符 | `'a'` | 1 |

⚠️ 小数默认是 `double`；写 `float` 要加 `f` 后缀（`3.5f`）。`char` 用**单引号**，字符串用**双引号**。

---

**Q5** `=` 和 `==` 的区别？为什么这是最经典的扣分点？

**A5**
- `=` **赋值**：把右边的值放进左边（"令 x 等于 5"）
- `==` **判断相等**：返回真(1)或假(0)

在 `if` 里误写 `=`：`if (x = 5)` **不是判断 x 是否为 5**，而是"把 5 塞给 x，然后 5 为真，所以永远进 if"。

编译通常**不报错**，逻辑全错 —— 这就是改错题最爱埋的雷。

---

**Q6** `7 / 2` 在 C 语言里等于多少？想拿到 3.5 该怎么改？

**A6**
**等于 3**（不是 3.5）。两个 `int` 相除，结果还是 `int`，**小数部分直接砍掉**，不四舍五入。

想拿 3.5，**至少让一方是小数**，四种改法：
```c
7.0 / 2       // 7.0 是 double，结果是 3.5
7 / 2.0       // 同上
7.0 / 2.0     // 同上
(double)7 / 2 // 强制类型转换
```

⚠️ 写成 `(double)(7 / 2)` **仍然是 3.0** —— 因为括号里先算了整数除法。转换必须在**除法之前**发生。

---

**Q7** `%` 是什么运算符？`7 % 3` 等于？它有什么用？

**A7**
`%` 是**取余（模）**运算符，`7 % 3 = 1`（7 除以 3 余 1）。

**只能是整数**，`7.0 % 3` 编译报错。

最大用途：**判断整除** 和 **取末尾**：
- `i % 2 == 0` → i 是偶数
- `i % 2 == 1` → i 是奇数
- `n % 10` → 取 n 的个位数
- `n / 10 % 10` → 取十位数

---

**Q8** 完整写出用 for 循环输出 1 到 10（每行一个）的程序。

**A8**
```c
#include <stdio.h>
int main() {
    int i;
    for (i = 1; i <= 10; i++) {
        printf("%d\n", i);
    }
    return 0;
}
```

`for (起点; 继续条件; 每轮之后干什么)`：
- `i = 1` 从 1 开始
- `i <= 10` 只要 i 不超过 10 就继续 ← **`<=` 而不是 `<`**，写成就只输出到 9
- `i++` 每轮结束 i 加 1

⚠️ 这就是 09-07 题 1 的满分答案，必须能**默写**。

---

**Q9** `i++` 和 `++i` 有什么区别？

**A9**
都是"i 加 1"。区别只在**用在表达式里时**：
- `i++` **先用当前值**，再加 1
- `++i` **先加 1**，再用新值

```c
int i = 5, a = i++;   // a = 5, i 变成 6
int j = 5, b = ++j;   // b = 6, j 变成 6
```

单独一行写 `i++;` 和 `++i;` 效果完全一样。

---

**Q10** `&` 放在变量前面是什么意思？为什么 `scanf` 必须加它？

**A10**
`&` 是**取地址**运算符，`&x` = "变量 x 在内存里的门牌号"。

`scanf` 要**把读到的值写进你的变量**，所以必须告诉它写到哪 —— 给它地址：
```c
int n;
scanf("%d", &n);    // ✅ 对：把地址交给 scanf
scanf("%d", n);     // ❌ 错：把值当地址，程序崩溃
```
`printf` 不用 `&`，它只是**读**值来显示，不需要写回去。

---

**Q11** `%d`、`%f`、`%c`、`%s`、`%lf` 分别对应什么类型？

**A11**
| 格式符 | 对应类型 |
|:---|:---|
| `%d` | `int` 整数 |
| `%f` | `float` 小数 |
| `%lf` | `double` 小数（scanf 里必须用） |
| `%c` | `char` 单个字符 |
| `%s` | 字符串（char 数组） |

`%6.2f` = 占 6 位宽、保留 2 位小数。

⚠️ 用错格式符 → 输出乱码或 0，这是改错题高频埋雷点。

---

**Q12** `int a[5];` 是什么？数组下标从几开始？

**A12**
声明一个能放 5 个整数的数组：`a[0]` ~ `a[4]`。

**下标从 0 开始**，所以 5 个元素的最大下标是 **4**。

访问 `a[5]` 是**数组越界**（第 6 个不存在），编译不报错但结果是垃圾值 —— 考纲里的经典陷阱。

`int a[5] = {1, 2, 3, 4, 5};` 里 `a[0]=1, a[4]=5`。

---

**Q13** `int *p` 是什么？`*p` 又是什么？

**A13**
- `int *p`：声明 p 是一个**指针**，用来存 int 变量的地址
- `*p`：**解引用**，"顺着 p 存的地址去拿那个值"

```c
int a = 10;
int *p = &a;     // p 存 a 的地址
printf("%d", *p);  // 输出 10（顺着地址取值）
*p = 20;           // a 变成 20（顺着地址写值）
```

指针就是"写错了地址就崩"，所以 `p` 和 `*p` 长得很像但意思完全不同，必须看清。

---

**Q14** 函数声明 `int max(int a, int b)` 里，每个 `int` 分别是什么作用？

**A14**
- 最左边的 `int`：**返回值类型**（这个函数会还给你一个整数）
- 括号里的 `int a, int b`：**参数的类型**（调用时必须传两个整数进来）

如果函数什么都不还，写 `void max(...)`；如果没参数，写 `int max(void)`。

---

**Q15** 「传值调用」为什么改不了外面的变量？

**A15**
C 语言函数参数默认**复印一份**：函数里改的是复印件，原件不动。

```c
void swap(int x, int y) { int t = x; x = y; y = t; }  // 改了个寂寞
```

要真改，必须**传地址**（把原件的门牌号给函数）：
```c
void swap(int *x, int *y) { int t = *x; *x = *y; *y = t; }
swap(&a, &b);   // ✅ 调用时加 &
```

⚠️ 这是 09-07 题 1/2 类错题的核心原因，也是改错题第一高频考点。

---

**Q16** `while` 和 `do...while` 的区别？

**A16**
- `while (条件) {...}` → **先判断再执行**，条件不成立可以一次都不执行
- `do {...} while (条件);` → **先执行一次再判断**，**至少执行一次**（注意结尾有分号）

判断题高频："do-while 循环体至少执行一次" → **对**。

---

---

**Q17** `for` 和 `while` 能互相替换吗？什么时候必须用 while？

**A17**
能，`for(初始化; 条件; 步进)` 完全等价于：
```c
初始化;
while (条件) { 循环体; 步进; }
```

经验：**次数已知用 for**（如遍历数组），**次数未知用 while**（如"读到文件结尾为止"、"输入直到负数"）。

---

**Q18** `break` 和 `continue` 的区别？

**A18**
- `break` → **整个循环立刻结束**，跳出到循环外面
- `continue` → **本轮结束，跳到下一轮**（循环条件还会再判断）

```c
for (i = 1; i <= 10; i++) {
    if (i == 5) break;       // 输出 1 2 3 4，然后整个循环结束
    if (i == 5) continue;    // 跳过 5，输出 1 2 3 4 6 7 8 9 10
}
```

⚠️ `continue` 在 while 里容易死循环（跳过了 `i++`），考试爱考。

---

**Q19** `#include <stdio.h>` 和 `#include "my.h"` 有什么区别？

**A19**
- `<>` → 去**系统目录**找（编译器自带的库）
- `""` → **先找当前目录**，再找系统目录（自己写的头文件）

⚠️ 用错不会立刻报错，但找不到文件时报 `No such file or directory`。

**Q20** 编译报错、警告、运行时错误，分别是什么意思？

**A20**
| 阶段 | 表现 | 常见原因 |
|:---|:---|:---|
| **编译错误** | 不给运行，指出行号 | 漏分号、括号不配、拼错关键字、类型不符 |
| **警告 warning** | 能运行但提醒你 | 类型隐式转换、未初始化变量、`=` 当 `==` 用 |
| **运行时错误** | 跑起来才崩 | 数组越界、除 0、空指针、`scanf` 忘加 `&` |

⚠️ 2026 改革新增考点「程序运行环境与调试」，改错题就是考这三类的区分 —— 看到"能编译但结果不对"应判断为**逻辑错误**。
