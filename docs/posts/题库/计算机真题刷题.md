# 🖥️ 计算机真题刷题

> **这些题从哪来**：不是从别处搬的 —— 是把你本库 `历年真题/计算机程序设计/` 和
> `docs/posts/computer/` 里 **2018–2026 的真题**，按「题干 + A/B/C/D + 答案 + 解析 + 考点」
> 拆成了可刷的形式。
> **133 题 = 零基础热身 15 + 真题单选 98 + 真题判断 20**，
> 其中 **96 题带考纲考点**、**133 题全部带解析**。
>
> 📝 **其中 8 道是「站内补注」**：2021/2022 的 8 道数据结构选择题（图 / 查找 / 栈 / 线性表 / 算法）
> 原卷只有答案、没有解析 —— 已补上并逐条标注「（站内补注）」，与真题原文解析区分开。
> 这 8 道正好落在你进度 0% 的那门课上，没解析就等于没法学。
>
> **和之前有什么不同**：以前真题的答案就印在题干下面，你没法「先做再看」——
> 所以那些题你其实**从没真正刷过**，只是读过。现在可以先选、再对答案、再出错题清单。

## 四、怎么用

1. **第一遍：按考点刷**，别一上来刷 133 题。先挑 §二 那 8 个薄弱章，每章刷完看错题。
2. **第二遍：错题重做**。交卷后的「只重做错题」按钮就是干这个的 —— 隔一天再做一次。
3. **第三遍：整套刷**（§一），检验跨考点的反应速度。
4. **错题要回流**：交卷后的错题清单，抄进 Anki 或 `刷题计划卡.md`。
   **选择题刷得再熟，也不会自动变成手写能力。**

> 📌 **口径说明**：真题是**考生回忆版**（本库自己标注的 B 级资料），不是考试院原卷。
> 考点、数据、答案与考试高度一致，但个别措辞以你手头正版真题册为准。

## 五、维护方式

题目数据在 `docs/.vitepress/theme/components/quiz-computer.ts` —— **自动生成，不要手改**。

```bash
# 改了真题 md 之后重新生成题库（在仓库根目录执行）
python scripts/gen-computer-quiz.py

# 若又出现「有答案、无解析」的题，用这个脚本补（默认 dry-run，加 --apply 才落盘）
python scripts/add-missing-explain.py
```

源文件：`历年真题/计算机程序设计/*.md`、`docs/posts/computer/*.md`。

新增年份的真题时，只要按下面格式写，重跑脚本就会自动进题库：

```markdown
### 1. 题干（ ）
A. 选项一  B. 选项二  C. 选项三  D. 选项四
**答案：B** · 考点 [[1.2 数据的存储与运算]]
**解析**：这里写解析。
```

判断题同理，把 `**答案：B**` 换成 `**答案：√**`（或 `×`）即可。

**手写题（填空/简答/计算/应用）**走另一套：源是 `## 三/四/五/六、…` 小节，
按 `### N. 题干` + `**答案**` / `**参考答案**` 拆，生成 [手写题专项](/posts/题库/计算机手写题)。

```bash
# 改了真题 md 的手写部分之后重新生成
python scripts/gen-computer-written.py
```
