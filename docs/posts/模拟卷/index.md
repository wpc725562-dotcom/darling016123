## 二、三套卷的难度分工

| 卷次 | 难度配比 | 什么时候用 |
|:---|:---|:---|
| **卷一 · 基础巩固** | 基础 60% + 中档 30% + 拔高 10% | 一轮过完、刚开始做整套时 |
| **卷二 · 综合中档** | 基础 30% + 中档 50% + 拔高 20% | 章节题刷得差不多了，进入强化期 |
| **卷三 · 拔高冲刺** | 基础 20% + 中档 40% + 拔高 40% | 考前 4–6 周，练抗压和时间分配 |

## 三、怎么用（重要）

1. **必须限时**。不限时做整套卷，等于在做练习册，练不到考场最重要的那件事——**时间分配**。
2. **先闭卷做完，再看答案**。答案页按「题号 / 答案 / 考点 / 解析」排列，**看解析前先自己写一遍理由**。
3. **错题进错题本**。见 [错题记录模板](/posts/resources/错题记录模板) — 错题要记「当时怎么想的」，不只记正确答案。
4. **卷子不是越多越好**。一套卷做透（错题全部回炉）胜过三套卷各刷一遍。

> 💡 **别拿模拟卷替代真题**。真题告诉你「考什么」，模拟卷只帮你练「怎么在限时内做完」。两者不能互换。
