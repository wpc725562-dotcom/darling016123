## 五、计算题（每小题 10 分，共 30 分）

**40.** 写出以下程序的运行结果：

```c
#include <stdio.h>
int f(int n) {
    if (n <= 1) return 1;
    return n * f(n - 1);
}
int main() {
    printf("%d\n", f(4));
    return 0;
}
```

**41.** 写出以下程序的运行结果：

```c
#include <stdio.h>
#define N 5
int main() {
    int queue[N] = {0};
    int front = 0, rear = 0;
    // 入队
    queue[rear] = 10; rear = (rear + 1) % N;
    queue[rear] = 20; rear = (rear + 1) % N;
    queue[rear] = 30; rear = (rear + 1) % N;
    // 出队
    front = (front + 1) % N;
    // 入队
    queue[rear] = 40; rear = (rear + 1) % N;
    queue[rear] = 50; rear = (rear + 1) % N;
    printf("front=%d, rear=%d\n", front, rear);
    return 0;
}
```

**42.** 给定无向图 G 的邻接矩阵如下（顶点编号 1~5）：

```
  2 1 0 0 1 1
  3 1 0 0 0 1
  4 0 1 0 0 1
  5 0 1 1 1 0
```

请画出该图，并写出从顶点 1 出发的深度优先遍历序列（按编号升序访问邻接点）。
