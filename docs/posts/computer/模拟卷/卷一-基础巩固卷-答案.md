## 四、简答题（4 题 × 10 分 = 40 分）

### 36. `#include <stdio.h>` 的作用（10 分）

**评分要点**：
- 预处理指令（2 分）
- 将标准输入输出头文件的内容包含到当前源文件中（4 分）
- 使得 printf、scanf 等函数可用（4 分）

### 37. 传值调用和传址调用的区别（10 分）

**评分要点**：

| 对比项 | 传值调用 | 传址调用 |
|:---|:---|:---|
| 传递内容 | 实参的副本（值） | 实参的地址 |
| 形参改变是否影响实参 | 不影响（5 分） | 通过指针间接修改实参（5 分） |
| 示例 | `void f(int x)` | `void f(int *p)` |

### 38. 顺序表和链表的区别（10 分，至少 3 点）

**评分要点**（每点 3 分，答出 3 点满分）：
1. **存储结构**：顺序表连续存储，链表离散存储
2. **随机存取**：顺序表 O(1) 随机存取，链表需 O(n) 遍历
3. **插入删除**：顺序表 O(n)（需移动元素），链表 O(1)（仅改指针）
4. **空间分配**：顺序表静态分配（可能溢出），链表动态分配

### 39. 二叉树三种遍历的定义（10 分）

**评分要点**：
- 先序遍历：根 → 左子树 → 右子树（4 分）
- 中序遍历：左子树 → 根 → 右子树（3 分）
- 后序遍历：左子树 → 右子树 → 根（3 分）

## 六、应用题（3 题 × 10 分 = 30 分）

### 43. 求和及平均值（10 分）

**评分标准**：
- 框架 2 分：`#include <stdio.h>` + `int main()` + `return 0;`
- 数组/循环输入 3 分
- 求和逻辑 3 分
- 输出 2 分

**参考答案**：

```c
#include <stdio.h>
int main() {
    int a[10], i, sum = 0;
    float avg;
    printf("请输入10个整数：");
    for (i = 0; i < 10; i++) {
        scanf("%d", &a[i]);
        sum += a[i];
    }
    avg = sum / 10.0;
    printf("和 = %d，平均值 = %.2f\n", sum, avg);
    return 0;
}
```

### 44. 统计字符个数（10 分）

**评分标准**：
- 框架 2 分
- 字符串输入 2 分
- 分类判断逻辑 4 分
- 输出结果 2 分

**参考答案**：

```c
#include <stdio.h>
int main() {
    char str[100];
    int i, upper = 0, lower = 0, digit = 0;
    printf("请输入一个字符串：");
    gets(str);
    for (i = 0; str[i] != '\0'; i++) {
        if (str[i] >= 'A' && str[i] <= 'Z') upper++;
        else if (str[i] >= 'a' && str[i] <= 'z') lower++;
        else if (str[i] >= '0' && str[i] <= '9') digit++;
    }
    printf("大写字母：%d，小写字母：%d，数字：%d\n", upper, lower, digit);
    return 0;
}
```

### 45. 冒泡排序（10 分）

**评分标准**：
- 框架 2 分
- 数组定义和输入 2 分
- 冒泡排序核心逻辑 4 分（双重循环 + 交换）
- 输出结果 2 分

**参考答案**：

```c
#include <stdio.h>
int main() {
    int a[10] = {34, 67, 12, 89, 45, 23, 56, 78, 90, 11};
    int i, j, temp;
    // 冒泡排序
    for (i = 0; i < 9; i++) {
        for (j = 0; j < 9 - i; j++) {
            if (a[j] > a[j + 1]) {
                temp = a[j];
                a[j] = a[j + 1];
                a[j + 1] = temp;
            }
        }
    }
    printf("排序结果：");
    for (i = 0; i < 10; i++) {
        printf("%d ", a[i]);
    }
    printf("\n");
    return 0;
}
```
