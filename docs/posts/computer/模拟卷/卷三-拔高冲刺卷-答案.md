### 36. fprintf/fscanf 与 fwrite/fread 的区别（10 分）

|:---|:---|:---|

### 37. 循环队列的设计目的和方法（10 分）

**评分要点**：
- **目的**：解决顺序队列的"假溢出"问题，充分利用数组空间（4 分）
- **判空**：`front == rear`（3 分）
- **判满**：`(rear + 1) % MAXSIZE == front`（牺牲一个单元）（3 分）

### 38. 哈夫曼树的构造过程和应用（10 分）

**评分要点**：
- **构造过程**：每次从集合中选出两个权值最小的结点作为左右子树，构造新结点（权值为两者之和），将新结点放回集合，重复直到只剩一个结点（6 分）
- **应用**：哈夫曼编码（数据压缩）、最优判定树（4 分）

### 39. 哈希冲突解决方法（10 分）

**评分要点**：
1. **开放地址法**：发生冲突时按某种探测序列（如线性探测、平方探测）寻找下一个空位（5 分）
2. **链地址法**：每个哈希地址对应一个链表，冲突元素挂在链表中（5 分）

### 43. 递归求阶乘（10 分）

**评分标准**：
- 框架 2 分
- 递归函数定义 4 分（递归出口 + 递归公式各 2 分）

**参考答案**：

```c
#include <stdio.h>
int fact(int n) {
    if (n <= 1) return 1;
    return n * fact(n - 1);
}
int main() {
    int n;
    printf("请输入 n（1~20）：");
    scanf("%d", &n);
    printf("%d! = %d\n", n, fact(n));
    return 0;
}
```

### 44. 结构体与平均成绩（10 分）

**评分标准**：
- 结构体定义 2 分
- 输入 3 个学生信息 3 分
- 计算平均成绩 2 分
- 比较找最高分 2 分
- 输出 1 分

**参考答案**：

```c
#include <stdio.h>
struct Student {
    int id;
    char name[20];
    float score[3];
};
int main() {
    struct Student stu[3], max_stu;
    float avg[3], max_avg;
    int i, j;
    for (i = 0; i < 3; i++) {
        printf("请输入第 %d 个学生的学号、姓名、三门课成绩：", i + 1);
        scanf("%d %s %f %f %f", &stu[i].id, stu[i].name,
              &stu[i].score[0], &stu[i].score[1], &stu[i].score[2]);
        avg[i] = (stu[i].score[0] + stu[i].score[1] + stu[i].score[2]) / 3.0;
    }
    max_avg = avg[0];
    max_stu = stu[0];
    for (i = 1; i < 3; i++) {
        if (avg[i] > max_avg) {
            max_avg = avg[i];
            max_stu = stu[i];
        }
    }
    printf("平均成绩最高的学生：学号=%d，姓名=%s，平均成绩=%.1f\n",
           max_stu.id, max_stu.name, max_avg);
    return 0;
}
```

### 45. 直接插入排序（10 分）

**评分标准**：
- 框架 2 分
- 数组定义和输入 2 分
- 直接插入排序核心逻辑 4 分
- 输出 2 分

**参考答案**：

```c
#include <stdio.h>
int main() {
    int a[10], i, j, key;
    printf("请输入 10 个整数：");
    for (i = 0; i < 10; i++) {
        scanf("%d", &a[i]);
    }
    // 直接插入排序
    for (i = 1; i < 10; i++) {
        key = a[i];
        j = i - 1;
        while (j >= 0 && a[j] > key) {
            a[j + 1] = a[j];
            j--;
        }
        a[j + 1] = key;
    }
    printf("排序结果：");
    for (i = 0; i < 10; i++) {
        printf("%d ", a[i]);
    }
    printf("\n");
    return 0;
}
```
