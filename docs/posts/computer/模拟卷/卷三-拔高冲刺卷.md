## 五、计算题（每小题 10 分，共 30 分）

**40.** 写出以下程序的运行结果：

```c
#include <stdio.h>
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}
int main() {
    int x = 5, y = 10;
    int *p = &x, *q = &y;
    swap(p, q);
    printf("x=%d, y=%d\n", x, y);
    printf("*p=%d, *q=%d\n", *p, *q);
    return 0;
}
```
