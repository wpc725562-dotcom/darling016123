**评分要点**：

3. **参数变化**：每次递归调用时参数向终止条件靠近（3 分）

### 37. 结构体和共用体的区别（10 分）

## 五、计算题（3 题 × 10 分 = 30 分）

### 40. 递归函数运行结果（10 分）

**结果**：**24**（10 分）

**解析**：`f(4)` 递归展开：
- `f(4) = 4 × f(3)`
- `f(3) = 3 × f(2)`
- `f(2) = 2 × f(1)`
- `f(1) = 1`
- 回代：`f(2) = 2`，`f(3) = 6`，`f(4) = 24`

### 41. 循环队列运行结果（10 分）

**结果**：**front=1, rear=0**（10 分）

**解析**：
- 初始：front=0, rear=0，队列空
- 入队 10：rear=1
- 入队 20：rear=2
- 入队 30：rear=3
- 出队一次：front=1（10 出队）
- 入队 40：rear=4
- 入队 50：rear=0（循环回绕）
- 最终：front=1, rear=0

### 42. 邻接矩阵 → 图 → DFS 序列（10 分）

**图结构**：
```
1 — 2
|   | \
3 — 5 — 4
```

**DFS 序列（从顶点 1，升序访问邻接点）**：**1 → 2 → 4 → 5 → 3**（10 分）

**步骤**：
1. 访问 1，邻接点 2、3（升序，先 2）
2. 访问 2，邻接点 1、4、5（1 已访问，先 4）
3. 访问 4，邻接点 2、5（2 已访问，访问 5）
4. 访问 5，邻接点 2、3、4（2、4 已访问，访问 3）
5. 访问 3，邻接点 1、5（全部已访问，回溯结束）

## 六、应用题（3 题 × 10 分 = 30 分）

### 43. 求最大最小值（10 分）

**评分标准**：
- 框架 2 分
- 输入 n 和数组 2 分
- 找最大最小值逻辑 4 分
- 输出 2 分

**参考答案**：

```c
#include <stdio.h>
int main() {
    int n, i, a[20], max, min;
    printf("请输入整数个数 n（≤20）：");
    scanf("%d", &n);
    printf("请输入 %d 个整数：", n);
    for (i = 0; i < n; i++) {
        scanf("%d", &a[i]);
    }
    max = min = a[0];
    for (i = 1; i < n; i++) {
        if (a[i] > max) max = a[i];
        if (a[i] < min) min = a[i];
    }
    printf("最大值 = %d，最小值 = %d\n", max, min);
    return 0;
}
```

### 44. 字符串复制（10 分）

**评分标准**：
- 框架 2 分
- 输入字符串 2 分
- 复制逻辑 4 分（逐字符复制 + 结尾加 `\0`）
- 输出 2 分

**参考答案**：

```c
#include <stdio.h>
int main() {
    char src[100], dest[100];
    int i = 0;
    printf("请输入一个字符串：");
    gets(src);
    while (src[i] != '\0') {
        dest[i] = src[i];
        i++;
    }
    dest[i] = '\0';
    printf("复制后的字符串：%s\n", dest);
    return 0;
}
```

### 45. 结构体编程（10 分）

**评分标准**：
- 结构体定义 3 分
- 输入 3 个学生信息 3 分
- 比较找最高分 2 分
- 输出 2 分

**参考答案**：

```c
#include <stdio.h>
struct Student {
    int id;
    char name[20];
    float score;
};
int main() {
    struct Student stu[3], max_stu;
    int i;
    for (i = 0; i < 3; i++) {
        printf("请输入第 %d 个学生的学号、姓名、成绩：", i + 1);
        scanf("%d %s %f", &stu[i].id, stu[i].name, &stu[i].score);
    }
    max_stu = stu[0];
    for (i = 1; i < 3; i++) {
        if (stu[i].score > max_stu.score) max_stu = stu[i];
    }
    printf("成绩最高的学生：学号=%d，姓名=%s，成绩=%.1f\n",
           max_stu.id, max_stu.name, max_stu.score);
    return 0;
}
```
