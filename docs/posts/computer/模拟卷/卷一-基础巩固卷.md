## 五、计算题（每小题 10 分，共 30 分）

**40.** 写出以下程序的运行结果：

```c
#include <stdio.h>
int main() {
    int a = 5, b = 3, c;
    c = (a > b) ? a : b;
    printf("%d\n", c);
    return 0;
}
```

**41.** 写出以下程序的运行结果：

```c
#include <stdio.h>
int main() {
    int arr[5] = {10, 20, 30, 40, 50};
    int i, sum = 0;
    for (i = 0; i < 5; i++) {
        if (i % 2 == 0) sum += arr[i];
    }
    printf("%d\n", sum);
    return 0;
}
```
