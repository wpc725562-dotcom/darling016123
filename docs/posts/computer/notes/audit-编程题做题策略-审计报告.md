## 五、高频丢分陷阱

| 陷阱类型 | 具体表现 |
|:---|---|
| **忘记 return 0** | main 函数末尾没写 `return 0;` |
| **scanf 忘记 &** | `scanf("%d", a)` 数组名不用 &，但 `scanf("%d", &n)` 普通变量要 & |
| **数组下标越界** | 长度为 n 的数组，最多访问 `a[n-1]`，不是 `a[n]` |
| **字符串无 \0** | 字符数组初始化时忘记字符串结束符 |
| **指针参数传错** | 函数参数是 `int *x`，调用时传 `&a` 不是 `a` |
| **循环边界错误** | `for (i=0; i<=n; i++)` 多循环一次 |
