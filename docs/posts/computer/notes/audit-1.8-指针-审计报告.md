## 四、高频丢分陷阱清单

| 陷阱类型 | 具体表现 | 涉及真题 |
|:---|---|:---:|
| **指针初始化** | 指针只能初始化为地址/NULL/0，不能初始化为整数1 | 2021·单选6 |
| ***p++ 优先级** | `*p++`=先取*p再p++；`(*p)++`=取内容再自增；`*(p++)`=先取*p再p++ | 2023·单选9 |
| **指针运算合法性** | 指针可±整数，不可 *= /= /= &常数 | 2022·单选13 |
| **数组名是常量** | a++ 非法，但 p=a 后 p++ 合法 | 多处 |
| **sizeof(arr) 在函数内** | 数组传参退化为指针，sizeof(arr) 是4（指针大小） | 笔记已标记 |
| **不能返回局部变量地址** | 函数返回后局部变量销毁 | 笔记已标记 |
| **malloc 后必须 free** | 否则内存泄漏 | 笔记已标记 |
