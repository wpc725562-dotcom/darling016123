## 四、高频丢分陷阱清单

| 陷阱类型 | 具体表现 | 涉及真题 |
|:---|---|:---:|
| **深度从1开始还是从0开始** | 根为第1层（2^(k-1)）vs 根为第0层（2^k） | 2024·单选19 |
| **叶子数公式记反** | n₀ = n₂ + 1，不是 n₂ = n₀ + 1 | 2021·判断26 |
| **完全二叉树叶子数公式** | ⌈n/2⌉ 或 n - ⌊n/2⌋，结果相同 | 2022·单选17, 2023·单选12 |
| **树的深度 vs 度的最大值** | 深度 = 结点最大层数，不是度的最大值 | 2023·单选19 |
| **满二叉树→完全二叉树** | 满二叉树一定是完全二叉树，但反之不成立 | 2023·判断2 |
| **哈夫曼树高度** | 合并过程中层级定义容易混淆 | 2021·单选11 |
| **遍历序列还原** | 已知先序+中序→唯一确定；先序+后序→不能唯一确定 | 考纲高频 |
| **二叉排序树中序有序** | 中序遍历二叉排序树结果是递增序列 | 考纲高频 |
