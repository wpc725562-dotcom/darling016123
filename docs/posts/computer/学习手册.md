## C3 数据的存储与运算 ⭐⭐

**学什么**：整型/实型/字符型怎么存；运算符优先级——最容易失分。

**核心考点**：
- int 4 字节、float 4、double 8、char 1
- 自增自减：i++ 先用后加，++i 先加后用
- 整数除法：7/2=3（不是 3.5！）
- && 和 || 短路求值

**典型代码**：
```c
int a = 7;
printf("%d", a/2);   // 输出 3（整数除法）
int x = 3;
printf("%d", (x++)+x);
```

## C4 顺序程序设计

**学什么**：printf/scanf 格式控制——输出格式题必考。

**核心考点**：
- %d 整型、%f 浮点、%c 字符、%s 字符串
- scanf("格式", &变量) — 记得取地址符 &
- printf 默认右对齐，%-5d 左对齐

**典型代码**：
```c
int a, b;
scanf("%d%d", &a, &b);   // 记得 & 取地址
printf("%.2f", 3.14159); // 保留 2 位小数
```

## C5 选择结构程序设计 ⭐⭐

**学什么**：if/else、switch 分支逻辑。else 与最近的 if 配对。

**核心考点**：
- if(表达式) — 0 为假，非 0 为真
- switch 别忘了 break，否则"贯穿"
- 条件运算符：a>b?a:b

**典型代码**：
```c
// 判断闰年
int y; scanf("%d", &y);
if ((y%4==0 && y%100!=0) || y%400==0)
    printf("闰年");
else
    printf("平年");
```

## C6 循环结构程序设计 ⭐⭐⭐

**学什么**：for/while/do-while 循环——编程题核心，必考。

**核心考点**：
- for(初值;条件;步长) 三步
- break 跳出循环，continue 跳过本次
- 嵌套循环：外层走一次，内层走完一轮

**典型代码**：
```c
// 求 1+2+...+100
int sum = 0;
for (int i = 1; i <= 100; i++)
    sum += i;
printf("%d", sum);

// 输出 1-100 中所有偶数
for (int i = 1; i <= 100; i++)
    if (i % 2 == 0) printf("%d ", i);
```

## C7 数组 ⭐⭐⭐⭐⭐

**学什么**：数组 = 同类型数据的集合。字符串处理是必考大题。

**核心考点**：
- 定义：int a[10] 下标 0-9
- strlen 长度（不含结束符），sizeof 占字节数
- 字符串函数：strcpy/strcat/strcmp/strlen
- 数组名是首地址，不能整体赋值

**典型代码**：
```c
// 输入 10 个数求平均值
int a[10], sum = 0;
for (int i = 0; i < 10; i++) {
    scanf("%d", &a[i]);
    sum += a[i];
}
printf("%.2f", sum / 10.0);

char s[] = "abc";
strlen(s);   // 3（不含结束符）
sizeof(s);   // 4（含结束符）
```

## C8 函数 ⭐⭐⭐⭐⭐

**学什么**：模块化编程。递归和参数传递是必考。

**核心考点**：

- 值传递：函数内改形参不影响实参
- 递归：必须有终止条件
- 全局变量 vs 局部变量

**典型代码**：
```c

int fact(int n) {
    if (n <= 1) return 1;
    return n * fact(n - 1);
```

## C9 指针 ⭐⭐⭐⭐⭐

**学什么**：指针 = 存地址的变量。*p、p++ 的区分是头号考点。

**核心考点**：
- 声明 int *p = &a; — p 存 a 的地址，*p 取 a 的值
- (*p)++ 值加 1；p++ 地址加 1
- 指针做函数参数才能改实参
- 数组名 = 首元素地址

**典型代码**：
```c
// 指针实现两数交换
void swap(int *pa, int *pb) {
    int t = *pa;
    *pa = *pb;
    *pb = t;
}
int a = 3, b = 5;
swap(&a, &b);
```

**笔记**：[1.8 指针](/posts/computer/notes/1.8-指针)

## C10 结构体与共用体 ⭐⭐

**学什么**：自定义数据类型。union 共享空间是易错点。

**核心考点**：
- struct：成员各自占内存
- union：成员共享同一块内存（取最大的）
- typedef 起别名；枚举 enum
- 结构体变量用 . 访问成员

**典型代码**：
```c
struct Student {
    char name[20];
    int score;
};
struct Student s = {"小明", 90};
printf("%s %d", s.name, s.score);
```

## C11 文件操作

**学什么**：文件的打开/关闭/读写。

**核心考点**：
- fopen("路径","r/w/a") 返回 FILE*，失败返回 NULL
- fclose 必须配对；fprintf/fscanf、fgetc/fputc
- 路径中的 \ 要写成 \\（转义）

**典型代码**：
```c
FILE *fp = fopen("test.txt", "r");
if (fp == NULL) { printf("打开失败"); return; }
int ch = fgetc(fp);
fclose(fp);
```

## D2 线性表 ⭐⭐⭐⭐⭐

**学什么**：顺序表 vs 链表——大题高频。

**核心考点**：
- 顺序表：连续存储，随机存取 O(1)，插入删除 O(n)
- 链表：动态存储，插入删除 O(1)，查找 O(n)
- 单链表判空：head->next == NULL
- 头插法/尾插法建表

**典型代码**：
```c
// 单链表结点插入（在 p 后插入 s）
s->next = p->next;
p->next = s;
```

- 已知先序+中序还原二叉树（必考）
- 哈夫曼树：权值小的在深层，WPL 最小
