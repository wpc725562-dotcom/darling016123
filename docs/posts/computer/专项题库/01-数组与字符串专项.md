## ② 🗣️ 零基础大白话

**数组 = 一排储物柜。** 柜子编号从 **0** 开始（不是 1）。`a[0]` 是第一个，`a[4]` 是第五个。

**二维数组 = 超市货架。** 有行有列，`a[i][j]` 是第 i 行第 j 列。

**字符数组 = 一串字符排队。** `"Hello"` 其实是 **6 个格子**：`H e l l o \0`。最后那个隐藏的 `\0` 是"到此结束"的标志——`strlen` 就是靠它知道字符串多长。

## ③ ⚠️ 高频扣分坑（真题验证过）

| # | 陷阱 | 正确结论 |
|:---:|:---|:---|
| 1 | `strlen` 与 `sizeof` 混淆 | `strlen` **不含** `\0`；`sizeof` **含** `\0`。`char s[]="abc"` → `strlen(s)=3`，`sizeof(s)=4` |
| 2 | 二维数组初始化省略列数 | **列数不能省，行数可省**。`int a[][3]` 合法，`int a[2][]` 非法 |
| 3 | 数组下标从 1 开始 | **从 0 开始**。`int a[5]` 的合法下标是 `0~4` |
| 4 | 部分初始化 | 未赋值的元素**自动补 0**。`int a[5]={1,2,3}` → `a[3]=0, a[4]=0` |
| 5 | 字符串比较用 `==` | 必须用 `strcmp`。`==` 比较的是地址 |
| 6 | `x` 与 `x[0]` 的关系 | 对 `int x[3][4]`：`x` 与 `x[0]` 都表示 `x[0][0]` 的**地址**，值相同但类型不同 |
| 7 | `scanf("%d", a)` 与 `scanf("%d", &a[0])` | 数组名本身即地址，`scanf("%d", a)` 合法；`scanf("%d", &a)` 类型不符 |
| 8 | `strcpy` 的返回值 | 返回**目标串的首地址**，所以可嵌套：`strlen(strcpy(s1,s2))` = `strlen(s2)` |
| 9 | 字符串长度计算 | `"abcd"` 长度 **4**（不含 `\0`）；`'\0'` 是转义字符，算 1 个字符 |
| 10 | 数组名不能赋值 | 数组名是常量指针，`a = b` 非法 |

```c
A. int a[2][]   = {{1},{2}};

D. int a[2][3]  = {{1},{2},{3}};
```

```c
#include <stdio.h>
int main()

    for (i = j = 0; s[i] != '\0'; i++)
        if (s[i] != 'c')

}
```

## ⑤ ✅ 答案与解析

::: details A 组 · 单选题答案
**A1 → A（9）** `"Guangdong"` 有 9 个字符（G-u-a-n-g-d-o-n-g），`strlen` 不含 `\0`。

**A2 → B（0）** 部分初始化时，未赋值的元素自动补 0。

**A3 → B** `x` 是二维数组名，退化为指向行的指针；`x[0]` 是一维数组名，退化为指向元素的指针。**两者数值相同**（都是 `x[0][0]` 的地址），但类型不同。题目问"说法正确"，B 的"值相同"成立。

**A4 → B** 二维数组初始化**列数不可省，行数可省**。A 省了列数，C 全省，D 行数写 2 却给了 3 个初始化行。

**A5 → A（2）** `strcpy(s1,s2)` 把 `"de"` 复制到 `s1` 并**返回 s1 的首地址**，所以外层 `strlen` 算的是 `s1` 现在的长度 = `"de"` 的长度 = 2。

**A6 → C** 字符串内容比较必须用 `strcmp`，返回 0 表示相等。A 比较的是地址，B 是赋值。

**A7 → A** 数组名本身即首元素地址，`scanf("%d", a)` 合法。B 的 `a[5]` 越界且不是地址；C 的 `&a` 类型是数组指针；D 越界。

**A8 → A（3 和 2）** `char c[3]` 固定 3 字节；`"ab"` 长度为 2。

**A9 → B（strcat）** `strcat` 连接；`strcpy` 复制；`strcmp` 比较；`strlen` 求长。

**A10 → B（6）** 行优先存储，`a[i][j]` 的偏移 = `i × 列数 + j` = `1 × 4 + 2 = 6`。
:::

::: details B 组 · 判断题答案
**B1 → ✗ 错** 下标可以是整型**变量**或**表达式**，不要求是常量。`a[i]`、`a[i+1]` 都合法。

**B2 → ✓ 对** C 语言二维数组按行优先（行主序）存储。

**B3 → ✗ 错** 应为 **4 字节**：`a b c \0`。字符串常量末尾自动加 `\0`。

**B4 → ✗ 错** `==` 比较的是地址。内容比较必须用 `strcmp`。

**B5 → ✗ 错** 说反了。**列数不能省，行数可以省**。
:::

::: details C 组 · 填空题答案
**C1 → 7** `"program"` 共 7 个字符。

**C2 → 0** 展开为：
- `a[0] = {0, 0, 0}`
- `a[1] = {1, 0, 0}`
- `a[2] = {2, 0, 0}`

所以 `a[1][2] = 0`。
:::

::: details D 组 · 计算题答案
**（1）第一行输出 `9`**

`for` 循环的条件是 `s[i] != '\0'`，循环体执行完后 `i++`。字符串 `"abcdefcgh"` 长 9，下标 0~8。当 `i=9` 时 `s[9]=='\0'`，条件不成立退出循环。此时 `i` 已自增到 9，所以输出 **9**。

**（2）第二行输出 `abdefgh`**

循环体作用是：**删除所有字符 `'c'`**（`if (s[i] != 'c')` 时才复制）。原串 `abcdefcgh` 去掉两个 `c` 后为 `abdefgh`。`s[j]='\0'` 补上结束标志，`puts` 输出 `abdefgh`。

> 💡 **本题考法**：这是"字符串压缩/过滤"的经典模型，同时考 `for` 循环的边界（`i` 的终值）和数组原地修改。近两年反复出现同型题。
:::

::: details E 组 · 应用题参考代码
**E1**
```c
#include <stdio.h>
int main()
{
    int a[3][3], i, j, n = 201;
    for (i = 0; i < 3; i++)
        for (j = 0; j < 3; j++)
            a[i][j] = n++;          /* 按行依次赋值 */
    for (i = 0; i < 3; i++)
    {
        for (j = 0; j < 3; j++)
            printf("%d ", a[i][j]);
        printf("\n");
    }
    return 0;
}
```
输出：
```
201 202 203
204 205 206
207 208 209
```

**E2**
```c
#include <stdio.h>
int main()
{
    int a[10], i, max, pos = 0;
    for (i = 0; i < 10; i++)
        scanf("%d", &a[i]);
    max = a[0];
    for (i = 1; i < 10; i++)
        if (a[i] > max)
        {
            max = a[i];
            pos = i;
        }
    printf("max=%d, index=%d\n", max, pos);
    return 0;
}
```

> ⚠️ **手写编程的三个易丢分点**：① 忘写 `#include <stdio.h>`；② 循环边界写错（`i<=10` 越界）；③ `main` 的 `return 0;` 或 `void main()` 与题目要求不一致。
:::
