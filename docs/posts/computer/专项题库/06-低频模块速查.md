## ② 🔁 必背速查表（考前默写用）

### 2.1 图

- **DFS** = 深度优先搜索遍历　**BFS** = 广度优先搜索遍历
- 有向图的**度** = 出度 + 入度
- **n 个顶点的连通图最少需要 n−1 条边**（即一棵生成树）
- n 个顶点的**完全图**边数：无向 `n(n−1)/2`；有向 `n(n−1)`
- 图形结构：元素间**多对多**
- ⚠️ **不考**最小生成树、最短路径的算法细节

### 2.2 文件

- 按**数据组织形式**分：**文本文件（ASCII 文件）** 和 **二进制文件**
- 按**存储介质**分：磁盘文件、磁带文件等
- `fopen` 失败返回 **NULL**
- `fclose` 成功执行返回 **0**，失败返回 **EOF**
- `EOF` 的值是 **−1**
- 文件打开方式：`r`（读）、`w`（写，覆盖）、`a`（追加）、`r+`、`w+`、`a+`，加 `b` 表示二进制
- 判断文件结束用 **`feof(fp)`**，不是 `EOF`

### 2.3 串、数组和广义表

- 串 `"abcd"` 的长度 = **4**（不含 `\0`）
- 串的两种基本存储：**顺序存储** 和 **链式存储**
- **串是特殊的线性表**（元素限定为字符）
- **空串**长度 = 0；**空格串**长度 > 0
- **广义表的长度** = 最外层元素个数
- **广义表的深度** = 括号嵌套的最大层数
- 例：`(a,(b,c),d,e,((i,j),k))` → 长度 **5**，深度 **3**

### 2.4 算法概念与分析

- 算法五特性：**有穷性、确定性、可行性、输入、输出**
- 算法分析两方面：**时间复杂度 + 空间复杂度**
- 常见复杂度量级（小→大）：`O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ)`
- 双重循环 `for(i<n) for(j<n)` → **O(n²)**
- 空间复杂度大 **≠** 时间复杂度大
- **程序不一定是算法**（算法必须有穷）

### 2.5 栈和队列

| | 栈 | 队列 |
|:---|:---|:---|
| 特点 | **后进先出（LIFO）** | **先进先出（FIFO）** |
| 操作端 | 只在**栈顶**操作 | **队尾入队、队头出队** |
| 共同点 | **两者都是线性表** | |

- 出栈序列推理：入栈顺序固定，出栈顺序**不唯一**，但要满足栈的约束
- 例：1,2,3,4 依次入栈，若第一个出栈是 4，则**全部入栈后**才出栈

### 2.6 树和二叉树

- 二叉树**第 n 层最多有 2^(n−1)** 个结点（第 3 层 → 4 个）
- 深度为 k 的二叉树**最多有 2^k − 1** 个结点
- **完全二叉树** n 个结点 → 叶子结点数 = **⌈n/2⌉**（n=12 → 6 个）
- **满二叉树**是完全二叉树的**特殊情形**
- 三种遍历：**先序**（根左右）、**中序**（左根右）、**后序**（左右根）
- 树的深度 = 结点的最大层数 = 树的高度
- ⚠️ **不考**哈夫曼编码、平衡树的算法实现

### 2.7 顺序结构程序设计

- `scanf("%d", &a)` —— **必须加 `&`**（数组名除外）
- `scanf` 格式符：`int`→`%d`、`float`→`%f`、`double`→**`%lf`**、`char`→`%c`、字符串→`%s`
- `printf` 中 `float` 和 `double` **都可用 `%f`**
- `scanf("%d%d", &a, &b)` 与 `scanf("%d %d", &a, &b)` 效果相同（空格可匹配任意空白）

### 2.8 指针

- `&` 取地址，`*` 取值
- `int *p = &a;` → `*p` 等价于 `a`
- 指针算术：`p+1` 前进**一个元素的大小**（不是 1 字节）
- `int a[5], *p = a;` → `*(p+i)` 等价于 `a[i]`
- **数组名是常量指针**，不能赋值
- ⚠️ 独立分值低，但链表、结构体、数组题都依赖指针能力

### 2.9 查找

- **折半查找的前提**：必须是**键值有序的顺序表**（链表不行，无序不行）
- 折半查找最多比较次数 ≈ **⌈log₂n⌉ + 1**
- 顺序查找平均查找长度 = **(n+1)/2**

### 2.10 排序

| 排序方法 | 平均时间复杂度 | 最坏 | 空间 | 稳定性 |
|:---|:---:|:---:|:---:|:---:|
| 直接插入 | O(n²) | O(n²) | O(1) | **稳定** |
| 冒泡 | O(n²) | O(n²) | O(1) | **稳定** |
| 简单选择 | O(n²) | O(n²) | O(1) | 不稳定 |
| 快速排序 | O(n log n) | **O(n²)** | O(log n) | 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | **O(n)** | **稳定** |
| 堆排序 | O(n log n) | O(n log n) | O(1) | 不稳定 |

- 合并两个长度 5 和 9 的升序数组，**最少比较次数 = 5**（一个数组全部走完后另一个直接接上）

### 2.11 程序运行环境与调试（2026 新增）

- **编译错误**：语法错误，编译阶段发现（如漏分号、括号不匹配）
- **链接错误**：找不到函数定义、重复定义
- **运行错误**：逻辑错误或运行时异常（如数组越界、除零、死循环）
- ⚠️ **两年真题均未出现**，2027 需留意首次命题
