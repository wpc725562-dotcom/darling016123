### 第 1 题 · strlen 长度

`char a[10]=" wait "; printf("%d", strlen(a));` 结果（ ）

- **A.** 4
- **B.** 5
- **C.** 8
- **D.** 10

::: details 答案与解析

**答案：B 或 C（视空格）** · 考点 [1.6 数组](/posts/computer/notes/1.6-数组)
**解析**：字面量若为 `" wait "`（前 1 空格 + wait + 1 空格）长度 **6**；常见回忆 `"wait "` 为 5。以本地原卷空格为准，刷题重点：`strlen` **不含** `\0`、**含**空格。

### 第 43 题 · 图遍历与最小生成树

图遍历 + 最小生成树

**（1）** 从 1 开始 DFS，邻接点按编号升序，写出访问序列。

**（2）** 求最小生成树：写算法名并画出树。

::: details 答案与解析

**答案：见解析**

⚠️ **原卷的图在回忆版里丢了**，无法给出确定的序列。方法如下：

**DFS**：从顶点 1 出发，邻接点按编号升序，能走就走、走不通就回溯，直到所有顶点访问完。要写出序列，就在纸上把「第一次到达」的顺序记下来。

**最小生成树**：**Prim** —— 从顶点 1 起，每次在「一端在树内、一端在树外」的边里挑权最小的并入，共选 $n-1$ 条边；**Kruskal** —— 边按权升序，不成环就收，同样收到 $n-1$ 条。

:::

### 第 44 题 · 统计指定字符个数

统计指定字符个数

编写函数 `count_char(const char *s, char ch)`，返回字符串 `s` 中字符 `ch` 出现的次数。

::: details 答案与解析

**答案：见解析（参考实现见下）**

```c
int count_char(const char *s, char ch) {
  int c=0; for(;*s;s++) if(*s==ch) c++;
  return c;
}
```

### 第 45 题 · 选择排序

选择排序 30 个成绩

编写函数，用选择排序把 30 个成绩按升序排列。

::: details 答案与解析

**答案：见解析（参考实现见下）**

```c
void select_sort(int a[], int n) {
  for(int i=0;i<n-1;i++) {
    int k=i;
    for(int j=i+1;j<n;j++) if(a[j]<a[k]) k=j;
    if(k!=i) { int t=a[i]; a[i]=a[k]; a[k]=t; }
  }
}
```
