### 第 1 题 · 逻辑运算

已知整型 `a=2, b=3`，求 `!a || b` 的值（ ）

- **A.** 0
- **B.** 1
- **C.** 2
- **D.** 3

::: details 答案与解析

**答案：B** · 考点 [1.2 数据的存储与运算](/posts/computer/notes/1.2-数据的存储与运算)

### 第 41 题 · 指针与 switch

指针 + switch 读程

::: details 答案与解析

**答案：见解析**

```c
int j,a[]={1,3,5,7,9,11,13,15},*p=a+5;
for(j=4;j>0;j--) {
  switch(j) {
    case 1: case 2: printf("%d",*p); break;
    case 3: printf("%d",*(--p));
    case 4: printf("%d",*(--p));
  }
}
```
(1) 循环 **4** 次（j=4,3,2,1）
(2) 注意 case3 **贯穿** case4；逐步模拟输出（回忆版答案以本地演算为准）

### 第 42 题 · 邻接矩阵

无向图邻接矩阵（按图作答，图见原卷）


::: details 答案与解析

**答案：见解析**

⚠️ **原卷的图在回忆版里丢了**，无法给出确定的矩阵。做法记牢：
无向图的邻接矩阵是**对称阵**，`A[i][j]=1` 表示顶点 i、j 之间有边。
第 i 行的**行和** = 顶点 i 的度；矩阵中 1 的总数 = 边数的 **2 倍**。
若要求「按图作答」，把图里每对相邻顶点在对应格子填 1，其余填 0 即可。

### 第 45 题 · 最小生成树

Prim 最小生成树（以结点 1 为起点，过程见原图）


::: details 答案与解析

**答案：见解析**

⚠️ **原卷的图在回忆版里丢了**，只能给出方法。Prim 的步骤：
① 从起点 1 出发，把 1 放进已选集合 `U`；
② 在「一端在 U、一端不在 U」的所有边里挑**权最小**的那条，把它的外部端点并入 U；
③ 重复 ②，直到 U 含全部顶点 —— 共选 **n−1** 条边。
选边过程中**不许成环**（因为每次并入的都是新顶点，天然不成环）。
按图作答时把每次选中的边依次写出来，并画出最终的树。
