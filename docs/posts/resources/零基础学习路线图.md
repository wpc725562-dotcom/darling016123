## 一、公共英语（零基础→满分）

### 总路线

```
音标/发音 → 新概念1（打底词汇+基础语法）→ 新概念2（语法体系+阅读语感）
→ 考纲3000词 + 语法系统精讲 → 题型专项训练 → 历年真题 → 应用文写作模板冲刺
```

### 分阶段

| 阶段 | 周期 | 任务 | 材料 |
|:---|:---:|:---|:---|
| ① 发音与入门 | 2–4 周 | 音标、自然拼读；每天跟读 | 赖世雄美语从头学（语音弱才需要） |
| ② 新概念 1 | 1–2 个月 | 144 课精学，积累 2000 词 + 7 大时态 | 新概念英语 1 |
| ③ 新概念 2 | 2–3 个月 | 96 课精学，3500 词 + 10 大时态 + 阅读语感 | 新概念英语 2 |
| ④ 考纲词汇 + 语法系统 | 2 个月 | 3000 词滚动记忆；语法系统过一遍（时态语态/三大从句/非谓语/主谓一致/虚拟/倒装） | 课程标准词汇表 +《英语语法新思维》初级→中级 |
| ⑤ 题型专项 | 1–2 个月 | 阅读（7 项能力）、完形（词汇辨析+固定搭配）、语法填空（词性变换）、短文匹配（五选五） | 专项训练资料 |
| ⑥ 真题 | 1 个月 | 近 3 年真题全真模拟 | 库课真题汇编 |
| ⑦ 写作冲刺 | 考前 2 周 | 应用文模板默写（书信/通知/邮件） | 作文模板 |

### 知识点体系

- **词汇**：约 3000 词（官方词表 = 高职英语课程标准 2021 版附录）；真题高频词即重点词
- **语法**：时态语态、三大从句（定语/名词性/状语）、非谓语动词、主谓一致、虚拟语气、倒装
- **阅读**（30 分）：主旨、细节、词义推断、判断推理、结构、作者态度、快速定位 7 项能力
- **完形**（30 分）：词汇辨析 + 固定搭配 + 上下文逻辑 + 语法衔接
- **语法填空**（15 分）：词性变换与语法应用
- **短文匹配**（10 分）：类似高考七选五
- **写作**（15 分）：应用文，格式规范、内容切题、条理清晰、语法正确、表达得体

## 二、政治理论（零基础→满分）

### 考纲范围（2024—2026 有效）

> 只有两大部分：①《毛泽东思想和中国特色社会主义理论体系概论》（2023 年版，约 90%）②时事政治（上一年度全年，约 10%）。**不考**马原/纲要/思修整本。

### 总路线

```
通读教材 → 搭建体系 → 刷题强化 → 时政冲刺 → 真题限时模拟
```

### 分阶段

| 阶段 | 周期 | 任务 | 材料 |
|:---|:---:|:---|:---|
| ① 通读教材 | 1–2 个月 | 毛概 2023 版逐章精读：导论→11 章→结束语 | 毛概 2023 版（ISBN 9787040599039） |
| ② 搭建体系 | 2–3 周 | 按「中国化时代化两条主线」记忆知识树 | 本库政治笔记（19 篇） |
| ③ 刷题强化 | 1–2 个月 | 单选/多选（识记）、辨析/简答（理解）、论述/材料（应用+时政） | 历年真题 + 大题集 |
| ④ 时政冲刺 | 考前 3 个月 | 集中过上一年度全年时政（2026 考 2025 全年） | 时政资料 |
| ⑤ 真题限时模拟 | 考前 1 个月 | 近 3 年真题按 120 分钟/100 分全真演练 | 真题卷 |

### 知识点体系（毛概 2023 版目录）

| 章节 | 核心考点 |
|:---|:---|
| 导论 马克思主义中国化时代化 | 1938 年首提"马克思主义中国化"；"两个结合"；两次历史性飞跃 |
| 第一章 毛泽东思想及其历史地位 | 活的灵魂（实事求是、群众路线、独立自主） |
| 第二章 新民主主义革命理论 | 总路线；基本纲领；革命道路（农村包围城市）；三大法宝 |
| 第三章 社会主义改造理论 | 过渡时期总路线（"一化三改"） |
| 第四章 建设道路初步探索 | 《论十大关系》；《正确处理人民内部矛盾》 |
| 第五章 邓小平理论 | 社会主义本质论；初级阶段理论；基本路线；南方谈话 |
| 第六章 "三个代表" | 先进生产力/先进文化/最广大人民根本利益 |
| 第七章 科学发展观 | 第一要义发展、核心以人为本、基本要求全面协调可持续、根本方法统筹兼顾 |
| 第八章 习思想及其历史地位 | 新时代社会主要矛盾；"十个明确""十四个坚持" |
| 第九章 总任务 | 中国梦；两步走战略 |
| 第十章 "五位一体"总体布局 | 新发展理念、全过程人民民主、文化自信、保障民生、绿色发展 |
| 第十一章 "四个全面"战略布局 | 现代化、改革、法治、治党 |
| 结束语 | "两个确立"的决定性意义 |

## 三、高等数学（零基础→满分）

### 考纲范围（2024—2026 一致，12 章）

```
函数与极限 → 导数与微分 → 微分中值定理与导数的应用 → 不定积分 → 定积分
→ 定积分的应用 → 微分方程 → 向量代数与空间解析几何 → 多元函数微分法
→ 重积分 → 曲线积分与曲面积分 → 无穷级数
```

### 题型（100 分 / 120 分钟）

| 题型 | 题量 | 分值 |
|:---|:---:|:---:|
| 单选 | 5 | 15 分 |
| 填空 | 5 | 15 分 |
| 计算 | 8 | 48 分 |
| 综合 | 2 | 22 分 |

> 计算+综合 = 70 分，**刷题是核心**。

### 总路线

```
教材精读（概念+例题）→ 课后习题 → 题型专项（计算题 8 大方法）→ 真题限时 → 错题重刷
```

### 分阶段

| 阶段 | 周期 | 任务 | 材料 |
|:---|:---:|:---|:---|
| ① 教材精读 | 2–3 个月 | 同济八版逐章：概念 + 例题 + 课后习题 | 同济《高等数学》第八版上+下册 |
| ② 题型专项 | 1–2 个月 | 极限计算八大方法、泰勒公式、洛必达、换元/分部积分、二重积分计算等 | 专项题库 |
| ③ 真题限时 | 1 个月 | 近 3 年真题按 120 分钟/100 分模拟 | 真题卷 |
| ④ 错题重刷 | 考前 2 周 | 错题本回刷 + 公式速查 | 公式速查卡 |

### 章节重点提示

- **极限**：两个重要极限、无穷小比较、洛必达、泰勒公式——考试必考
- **导数**：复合/隐函数/参数方程求导、高阶导数
- **积分**：换元法、分部积分法——计算题重灾区
- **微分方程**：可分离/齐次/一阶线性/常系数
- **二重积分**：直角坐标与极坐标
- **级数**：审敛法、幂级数展开
