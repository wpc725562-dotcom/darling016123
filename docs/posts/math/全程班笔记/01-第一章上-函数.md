# 第一章（上）· 函数

> 来源：陈哥专升本《专升本高等数学全程班》P1–P12
> 本章地位：函数是初等数学与高等数学之间的过渡章节。老师原话——「函数是我们初等数学和高等数学，它是中间的一个过渡的章节，一个过渡的一个小结。我们要想学好高数，那么学好函数是必须的，是必要的」；「这是应该算，算是我们高等数学里面的第一个考点」；「这些函数在我们第二章导数、第三章积分都会用到」；隐函数部分「几乎是每个省、然后每年必考的一个知识点，就叫隐函数的导数」；奇偶性「很多省份呢，第一个选择或第二个选择都会考这种奇偶性的判断」。

---

## 一、大白话讲解

### 1. 函数就是一个「输入—输出」系统

老师用计算器打比方：丢一个数进去，机器吐一个数出来。

| 丢进去 | 吐出来 |
|:---|:---|
| 2 | 4 |
| 3 | 6 |
| 4 | 8 |

中间那个「乘以 2」的动作，就是**对应法则**。写成数学式子就是 $Y=2X$。左边是输入，右边是输出，中间是一套变化规则。

换成更一般的写法：$Y=f(X)$，去掉等号就是三块东西 $Y$、$f$、$X$——这就是**函数三要素**。

| 符号 | 名称 | 大白话 |
|:---|:---|:---|
| $X$ | 自变量 | 它会自己变（你喂它 2、3、4、5……都行） |
| $Y$ | 因变量 | 它因为 $X$ 而变 |
| $f$ | 对应法则 | $X$ 通过怎样的变化得到 $Y$，也叫**映射关系** |

### 2. 两个必须刻进脑子的关键词

- **定义域 = $X$ 的取值范围**（$X$ 能取哪些值）
- **值域 = $Y$ 的取值范围**（$Y$ 能取哪些值）

老师原话：「定义域就等于 $X$ 的取值范围。」这一句是后面抽象函数定义域的全部地基。

### 3. 求定义域的本质：把「不允许」的地方全部划掉

分式的分母不能为零；偶次根式根号下要大于等于零；对数的真数要大于零。就这三条，加上三角函数的几条例外，构成整章求定义域的骨架。

### 4. 抽象函数：只认括号，不认里面

老师给了两句话，他说「如果大家能够把这两句话给记住，并且能够做应用，那么就说明大家对抽象函数这个定义域就能理解了」：

1. **$f$ 括号里可以任意变化，但括号整体的取值范围一定不变。**
2. **定义域仅仅只是 $X$ 的取值范围。**

所以做题第一步永远是：**先求括号的范围**。

### 5. 函数的「形态」

函数有四种形态：单调性、有界性、奇偶性、周期性。老师明确说：「在我们高等数学的学习过程中，函数的这个周期性几乎不怎么考察……我们主要考察单调性、有界性以及奇偶性。」

### 6. 反函数为什么叫「反」

- 反的体现之一：**定义域和值域交换**（原函数的定义域 = 反函数的值域）。
- 反的体现之二：**图像关于 $Y=X$ 对称**。

### 7. 一句话贯穿全章

老师反复念叨的一句：「函数的表达形式和自变量的字母无关。」所以求出 $f(T)=\ln T+1$ 之后，直接改写成 $f(X)=\ln X+1$ 是完全合法的。

## 二、考点全爆破

### 1. 函数的定义与三要素

设 $X$、$Y$ 是两个变量，若对 $X$ 在其允许范围内的每一个值，按某种法则 $f$ 都有唯一的 $Y$ 与之对应，则称 $Y$ 是 $X$ 的函数，记作

$$Y=f(X)$$

三要素：**自变量 $X$、因变量 $Y$、对应法则 $f$**。

### 2. 定义域与值域

- **定义域**：$X$ 的取值范围，即 $f$ 有意义的 $X$ 的集合。
- **值域**：$Y$ 的取值范围，即所有函数值构成的集合。

### 3. 常见函数的定义域（必背）

| 函数类型 | 约束条件 | 例子 |
|:---|:---|:---|
| 分式 | 分母不为零 | $\dfrac{1}{X}$：$X\neq0$；$\dfrac{1}{X+1}$：$X\neq-1$ |
| 偶次根式 | 根号下 $\ge 0$ | $\sqrt[10]{X-1}$：$X\ge1$ |
| 奇次根式 | 无限制（$X\in\mathbb{R}$） | $\sqrt[3]{X}$：$X\in\mathbb{R}$ |
| 对数 | 真数 $>0$ | $\lg(X-1)$：$X>1$ |
| $\sin X$、$\cos X$ | $X\in\mathbb{R}$ | — |
| $\tan X$ | $X\neq\dfrac{\pi}{2}+k\pi,\ k\in\mathbb{Z}$ | 因 $\tan X=\dfrac{\sin X}{\cos X}$，$\cos X\neq0$ |
| $\arcsin X$、$\arccos X$ | $\lvert X\rvert\le 1$，即 $X\in[-1,1]$ | — |
| $\arctan X$ | $X\in\mathbb{R}$ | — |

补充两条底数规则：任何**非零数**的零次方等于 $1$；对数底数要求 $a>0$ 且 $a\neq1$。

### 4. 幂的运算

$$X^a\cdot X^b=X^{a+b},\qquad \frac{X^a}{X^b}=X^{a-b}$$

$$(X^a)^b=X^{ab},\qquad X^{-a}=\frac{1}{X^a}$$

$$X^{\frac{b}{a}}=\sqrt[a]{X^b},\qquad A^b\cdot C^b=(AC)^b$$

例：$8^{3/2}=(\sqrt{8})^3$，即先开二次根式再三次方。

### 5. 去绝对值

$$\lvert X\rvert\le a\ (a>0)\iff -a\le X\le a$$

例：$\lvert X-1\rvert\le2\iff-2\le X-1\le2$。

### 6. 取对数与取指数

这是本章反复出现的两个「动作」，后面求反函数、解不等式都要用。

**取对数**：把指数上的东西拿下来。

$$e^X=T\ \Longrightarrow\ X=\ln T$$

$$2^X=T\ \Longrightarrow\ X=\log_2 T$$

底数规则：取对数的底数，就是原来指数的底数。

**取指数**：把对数里的东西拿出去。

$$\ln X=T\ \Longrightarrow\ X=e^T$$

$$\log_2 X=T\ \Longrightarrow\ X=2^T$$

底数规则：取指数的底数，就是原来对数的底数。

### 7. 对数运算公式（必背）

| 公式 | 内容 |
|:---|:---|
| 积的对数 | $\ln(AB)=\ln A+\ln B$ |
| 商的对数 | $\ln\dfrac{A}{B}=\ln A-\ln B$ |
| 幂的对数 | $\ln A^B=B\ln A$ |
| 开方的对数 | $\ln\sqrt[N]{M}=\dfrac{1}{N}\ln M$ |
| 底真相同 | $\log_a a=1$，特别地 $\ln e=1$ |
| 真数为一 | $\log_a 1=0$，特别地 $\ln 1=0$ |
| 指数对数互逆 | $a^{\log_a X}=X$，特别地 $e^{\ln X}=X$ |

### 8. 具体函数定义域的求法

**口诀：各部分各自求，最后取交集。**

若函数由几部分通过加减乘除拼成，就把每部分的定义域分别求出，再取公共部分（交集）。最后结果**统一写成区间形式**。

### 9. 抽象函数定义域（两句话 + 一个流程）

- 第一句：$f$ 括号里可以任意变化，但括号整体的取值范围不变。
- 第二句：定义域只是 $X$ 的取值范围。

**解题流程**：

1. 由已知的定义域，求出**括号的范围**；
2. 把要求的括号整体丢进这个范围里，解不等式，得到新的 $X$ 范围。

### 10. 判断两个函数是否为同一函数

函数三要素是定义域、值域、对应法则。但判断时**只看两条**：

| 判断项 | 要求 |
|:---|:---|
| 定义域是否相同 | **不能化简**，必须从原式出发看 |
| 对应法则是否相同 | **必须化简**后再比较 |

**两条必须同时满足才是同一函数；只满足一条则不是。**

补充：若定义域和对应法则都相同，值域必然相同，所以值域不用单独求。

### 11. 函数表达式的求解（两大方法）

| 方法 | 做法 |
|:---|:---|
| **配凑法** | 在等式右边配出与括号内完全相同的整体，再整体代换 |
| **换元法** | 令括号内的整体为 $t$，反解出 $X$ 用 $t$ 表示，代回右边 |

收尾依据：**函数的表达形式和自变量的字母无关**，把 $t$ 换成 $X$ 即可。

### 12. 函数的四种表示形式

| 形式 | 特征 |
|:---|:---|
| **显函数** | 等号左边只有一个 $Y$，右边是关于 $X$ 的表达式，如 $Y=e^X+\cos X$ |
| **隐函数** | 由方程 $F(X,Y)=0$ 确定，$Y$ 隐藏在方程里，如 $X^2-YX+e^{XY}=0$ |
| **参数方程** | $X=f(t),\ Y=g(t)$，$X$ 与 $Y$ 无直接联系，靠中间变量 $t$ 联系 |
| **分段函数** | 定义域被分成若干段，每段各有自己的表达式 |

老师说：「这就是我们的函数的几种表现形式，就是我们后面会见到的函数所有的表现形式就这么几种，不会说再有其他的表现形式了。」

### 13. 隐函数的显化

把隐函数化成显函数 $Y=\cdots$ 的过程叫**隐函数的显化**。

例：$X^2+Y^2=1\Longrightarrow Y^2=1-X^2\Longrightarrow Y=\pm\sqrt{1-X^2}$。

注意：并非所有隐函数都能显化（如 $X^2-YX+e^{XY}=0$ 就拆不出来）。

隐函数求导在第二章，「几乎是每个省、每年必考」。

### 14. 参数方程

$$\begin{cases}X=f(t)\\Y=g(t)\end{cases}$$

- $X$ 与 $Y$ 之间**没有直接联系**；
- 二者通过**中间变量 $t$** 联系起来。

经典例子——**平摆线（摆线）**：

$$\begin{cases}X=a(t-\sin t)\\Y=a(1-\cos t)\end{cases}\qquad t\in[0,2\pi]$$

半径为 $a$ 的圆沿 $X$ 轴滚动，圆上一点画出的轨迹。滚一圈走过的长度就是圆的周长 $2\pi a$，中间点是 $\pi a$。

老师说明：摆线在专升本不要求掌握，但考研数学是重点要求掌握的。

### 15. 分段函数与三个常见分段函数

分段函数：定义域分成若干段，每段有自己的表达式。

**(1) 绝对值函数**

$$f(X)=\lvert X\rvert=\begin{cases}X, & X\ge0\\-X, & X<0\end{cases}$$

图像是两条射线拼成的「V」形，顶点 $(0,0)$ 称为**尖点**，且该点**不可导**。

**(2) 取整函数 $[X]$**

$[X]$ 表示**不超过 $X$ 的最大整数**。

例：$[1.9]=1$，$[2.1]=2$。

重要不等式：

$$X-1<[X]\le X$$

**(3) 符号函数**

$$\operatorname{sgn}X=\begin{cases}1, & X>0\\0, & X=0\\-1, & X<0\end{cases}$$

老师在专升本阶段强调：前两个重点掌握，符号函数知道有这个东西就行。

### 16. 单调性

在定义域内，对任意 $X_1<X_2$：

- 若恒有 $f(X_1)<f(X_2)$，则 $f(X)$ **单调递增**；
- 若恒有 $f(X_1)>f(X_2)$，则 $f(X)$ **单调递减**。

例：$Y=X^2$ 在左半支单调递减，右半支单调递增。

### 17. 有界性

若在定义域内存在常数 $m$、$M$，使得对任意 $X$ 都有

$$m\le f(X)\le M$$

则称 $f(X)$ 在定义域内**有界**。其中 $m$ 称为**下界**，$M$ 称为**上界**。

若上界或下界有一个不存在（为无穷），则函数**无界**。

例：$Y=X^2$ 有下界 $0$，但没有上界，故无界。

### 18. 常见有界函数（五个，必背）

$$\sin X,\qquad \cos X,\qquad \arctan X,\qquad \operatorname{arccot}X,\qquad \frac{1}{1+X^2}$$

老师强调：「请大家打个五角星，因为在我们的第三章积分，尤其是定积分那一块，会用到这些有界函数。」

**有界性的稳定性**：$X$ 换成任何形式，有界性都不变。如 $\sin\dfrac{1}{X}$、$\cos\dfrac{1}{X}$、$\arctan\dfrac{1}{X}$、$\sin f(X)$、$\cos e^X$、$\dfrac{1}{1+f^2(X)}$ 等，仍然是有界函数。

### 19. 奇偶性：前提与定义

**前提条件**：定义域必须**关于原点对称**。若定义域不关于原点对称，直接判为**非奇非偶**，不必再算。

在关于原点对称的定义域内，对任意 $X$：

| 条件 | 结论 |
|:---|:---|
| $f(-X)=f(X)$ | **偶函数** |
| $f(-X)=-f(X)$ | **奇函数** |
| 两个都不满足 | **非奇非偶函数** |

### 20. 奇偶性的图像特征

| 类型 | 图像 |
|:---|:---|
| 偶函数 | 关于 **$Y$ 轴**对称（左右翻折重合） |
| 奇函数 | 关于 **原点**对称（右半边绕原点逆时针旋转 $180^\circ$ 与左半边重合） |

### 21. 常见奇偶函数（必背）

| 偶函数 | 奇函数 |
|:---|:---|
| $\cos X$ | $\sin X$ |
| $\lvert X\rvert$ | $\tan X$ |
| $X^{2n}$（偶次方，如 $X^2,X^4,X^6$） | $X^{2n-1}$（奇次方，如 $X,X^3$） |
| 常数函数 $Y=A$（含 $Y=0$） | $\ln\left(X+\sqrt{X^2+1}\right)$（里面加减常数也对） |
| | $\arctan X$ |
| | $\arcsin X$ |

老师对这两栏都说「打三个星，非常的重要」。

### 22. 奇偶性的四则运算

| 运算 | 结果 |
|:---|:---|
| 奇 $\pm$ 奇 | 奇 |
| 奇 $\pm$ 偶 | 非奇非偶 |
| 偶 $\pm$ 偶 | 偶 |
| 奇 $\times\div$ 奇 | 偶 |
| 奇 $\times\div$ 偶 | 奇 |
| 偶 $\times\div$ 偶 | 偶 |

**特例**：两个**相同**的奇函数相减等于 $0$，而 $0$ 是常数函数，属偶函数。

老师建议：「完全是不建议大家死记硬背的……如果忘了，就去找一个奇函数 $X$ 和一个偶函数 $X^2$ 来做一下四则运算法则，就能很快推出结果。」

### 23. 复合函数的奇偶性：八个字

> **内偶则偶，内奇同外。**

- 最内层是**偶函数** $\Rightarrow$ 整个复合函数是**偶函数**（不管外层是什么）；
- 最内层是**奇函数** $\Rightarrow$ 整个函数的奇偶性**取决于最外层**（外层奇则整体奇，外层偶则整体偶）。

注意「最内层」的判定：如 $\ln(1+X^2)$ 中，$1$ 与 $X^2$ 是同一级，$1+X^2$ 整体才是内层（两个偶函数相加仍是偶函数）。

补充：任何函数都可以用定义 $f(-X)=\pm f(X)$ 判断奇偶性。四则运算法则和复合口诀只是**加快判断速度**。

### 24. 基本初等函数总览（反对幂指三）

**幂函数 → 对数函数 → 指数函数 → 三角函数 → 反三角函数**，老师记作「反对幂指三」，另加常数函数。

学习顺序不是按口诀来的，而是从最简单的幂函数开始，最后到反三角函数。

### 25. 幂函数 $Y=X^a$

必须掌握的五种特殊情形：

$$Y=\frac{1}{X}\ (a=-1),\quad Y=X\ (a=1),\quad Y=\sqrt{X}\ \left(a=\tfrac12\right),\quad Y=X^2\ (a=2),\quad Y=X^3\ (a=3)$$

| 项目 | 结论 |
|:---|:---|
| 定义域、值域 | 取决于 $a$ 的值（如 $a=1/2$ 时 $X\ge0$） |
| 必过点 | **一定经过 $(1,1)$**；不一定经过 $(0,0)$（如 $Y=X^{-1/2}$ 取不到 $0$） |
| 单调性 | 取决于 $a$ |
| 奇偶性 | 取决于 $a$ |
| 有界性 | **无界** |
| 周期性 | **无周期** |

### 26. 指数函数 $Y=a^X$（$a>0,\ a\neq1$）

| 项目 | 结论 |
|:---|:---|
| 图像 | $0<a<1$ 单调递减；$a>1$ 单调递增 |
| 必过点 | $(0,1)$ |
| 定义域 | $\mathbb{R}$，即 $(-\infty,+\infty)$ |
| 值域 | $(0,+\infty)$ |
| 单调性 | $a>1$ 单增；$0<a<1$ 单减 |
| 有界性 | **无界**，但有下界 $0$（取不到），无上界 |
| 奇偶性 | **非奇非偶** |
| 周期性 | **无周期** |

最重要的特例是 $Y=e^X$。其趋势（老师强调规范写法要用极限）：

$$\lim_{X\to-\infty}e^X=0,\qquad \lim_{X\to+\infty}e^X=+\infty$$

### 27. 对数函数 $Y=\log_a X$（$a>0,\ a\neq1$）

| 项目 | 结论 |
|:---|:---|
| 图像 | $0<a<1$ 单调递减；$a>1$ 单调递增 |
| 必过点 | $(1,0)$ |
| 定义域 | $(0,+\infty)$（真数大于零） |
| 值域 | $\mathbb{R}$ |
| 单调性 | $a>1$ 单增；$0<a<1$ 单减 |
| 有界性 | **无界** |
| 奇偶性 | **非奇非偶** |
| 周期性 | **无周期** |

两种简写：$a=e$ 时写作 $\ln X$；$a=10$ 时写作 $\lg X$。运算公式见第 7 条。

**读法**：$\log_{10}(X-1)$ 读作「log 以十为底，$X-1$ 为真数的对数」。老师强调不能读成「log 十 $X$ 减一」。

### 28. 三角函数

| 函数 | 定义域 | 值域 | 单调性 | 奇偶性 | 有界性 | 周期 |
|:---|:---|:---|:---|:---|:---|:---|
| $\sin X$ | $\mathbb{R}$ | $[-1,1]$ | 看图（$\left[-\frac{\pi}{2},\frac{\pi}{2}\right]$ 单增，$\left[\frac{\pi}{2},\frac{3\pi}{2}\right]$ 单减） | 奇 | 有界 | $2\pi$ |
| $\cos X$ | $\mathbb{R}$ | $[-1,1]$ | 看图 | 偶 | 有界 | $2\pi$ |
| $\tan X$ | $X\neq\dfrac{\pi}{2}+k\pi,\ k\in\mathbb{Z}$ | $\mathbb{R}$ | $\left(-\frac{\pi}{2},\frac{\pi}{2}\right)$ 单增（重点掌握这一段） | 奇 | 无界 | $\pi$ |

$\sin$ 与 $\cos$ 图像形状相同，只差一个平移。

### 29. 特殊三角函数值（必背到条件反射）

| 角度 | $0$ | $\dfrac{\pi}{6}$ | $\dfrac{\pi}{4}$ | $\dfrac{\pi}{3}$ | $\dfrac{\pi}{2}$ |
|:---|:---|:---|:---|:---|:---|
| $\sin$ | $0$ | $\dfrac{1}{2}$ | $\dfrac{\sqrt{2}}{2}$ | $\dfrac{\sqrt{3}}{2}$ | $1$ |
| $\cos$ | $1$ | $\dfrac{\sqrt{3}}{2}$ | $\dfrac{\sqrt{2}}{2}$ | $\dfrac{1}{2}$ | $0$ |
| $\tan$ | $0$ | $\dfrac{\sqrt{3}}{3}$ | $1$ | $\sqrt{3}$ | 不存在 |

记忆依据：直角三角形中 $\sin=\dfrac{\text{对边}}{\text{斜边}}$，$\cos=\dfrac{\text{邻边}}{\text{斜边}}$，$\tan=\dfrac{\text{对边}}{\text{邻边}}$。

### 30. 正割、余割、余切

$$\sec X=\frac{1}{\cos X},\qquad \csc X=\frac{1}{\sin X},\qquad \cot X=\frac{1}{\tan X}=\frac{\cos X}{\sin X}$$

老师说：这三个的图像不要求掌握，只需知道它们分别是 $\cos$、$\sin$、$\tan$ 的倒数即可。

### 31. 三角恒等公式（必背）

**平方关系**

$$\sin^2X+\cos^2X=1$$

$$1+\tan^2X=\sec^2X,\qquad 1+\cot^2X=\csc^2X$$

**倍角公式**

$$\sin 2X=2\sin X\cos X$$

$$\cos 2X=\cos^2X-\sin^2X=2\cos^2X-1=1-2\sin^2X$$

**降幂公式**（由 $\cos2X$ 的两个变形推出）

$$\cos^2X=\frac{1+\cos 2X}{2},\qquad \sin^2X=\frac{1-\cos 2X}{2}$$

老师说这些公式「在第三章一元函数积分学的时候，会用到的非常的多，希望大家能够把它给记下来」。

### 32. 反三角函数

| 函数 | 定义域 | 值域 | 单调性 | 有界性 | 奇偶性 |
|:---|:---|:---|:---|:---|:---|
| $\arctan X$ | $\mathbb{R}$ | $\left(-\dfrac{\pi}{2},\dfrac{\pi}{2}\right)$ | 单增 | 有界（上界 $\frac{\pi}{2}$，下界 $-\frac{\pi}{2}$） | 奇 |
| $\arcsin X$ | $[-1,1]$ | $\left[-\dfrac{\pi}{2},\dfrac{\pi}{2}\right]$ | 单增 | 有界 | 奇 |
| $\arccos X$ | $[-1,1]$ | $[0,\pi]$ | 单减 | 有界（上界 $\pi$，下界 $0$） | 非奇非偶 |

趋势（规范写法用极限）：

$$\lim_{X\to+\infty}\arctan X=\frac{\pi}{2},\qquad \lim_{X\to-\infty}\arctan X=-\frac{\pi}{2}$$

老师特别强调：「$\arctan X$ 是一个非常非常重要的函数……大家一定要把它全部记下来，一点都不能遗漏。」

### 33. 常数函数

$$Y=C\ (\text{横线}),\qquad X=C\ (\text{竖线})$$

两个特殊情况必须记住：

$$Y\text{ 轴}:X=0,\qquad X\text{ 轴}:Y=0$$

老师提醒：以后学二重积分画积分区域时，要能立刻写出边界的表达式。

### 34. 复合函数与简单函数

**复合函数**：$Y=f[u(X)]$，即把 $f$ 中的自变量 $X$ 换成一个函数 $u(X)$。

例：$\ln\dfrac{1}{\sin X}$、$e^{\cos X^2}$、$\tan(2+\sqrt{X})$。

**简单函数**（注意：这不是数学概念，只是方便理解）：

> 由**常数**和**基本初等函数**经过**四则运算**所构成的函数。

例：$Y=2+\sin X$、$Y=e^X+\cos X$。

### 35. 复合函数的拆分

**原则：由外向内层层分解，分解到简单函数（或基本初等函数）为止。每一层都要对应一个基本初等函数。**

| 原函数 | 拆分 |
|:---|:---|
| $\ln\sin\dfrac{1}{X}$ | $Y=\ln u,\quad u=\sin v,\quad v=\dfrac{1}{X}$ |
| $e^{\cos X^2}$ | $Y=e^u,\quad u=\cos v,\quad v=X^2$ |
| $\tan(2+\sqrt{X})$ | $Y=\tan u,\quad u=2+\sqrt{X}$（已是简单函数，停） |
| $\arctan^2(\ln\cos\sqrt{X})$ | $Y=u^2,\quad u=\arctan v,\quad v=\ln w,\quad w=\cos z,\quad z=\sqrt{X}$ |

老师说明：复合函数的**拆分**不会出考题，但**复合函数求导**必考，而求导建立在拆分之上，所以必须练熟。

### 36. 初等函数

由**基本初等函数**经过**有限次复合**或**四则运算**所构成的函数，称为初等函数。

例：

$$Y=8X^2+3X+1\ (\text{多项式函数})$$

$$Y=\ln(1+X^2)+\sin\sqrt{X}$$

$$Y=\arctan X+e^X,\qquad Y=\cos X+\ln X^2,\qquad Y=e^X-1-\cos e^X$$

### 37. 反函数的概念

把原函数 $Y=f(X)$ 的自变量与因变量**交换**，得到的新函数称为**反函数**。

- **定义上的反函数**：$X=f^{-1}(Y)$（字母不换）；
- **习惯上的反函数**：$Y=f^{-1}(X)$（把 $X$ 与 $Y$ 的字母对调）。

记号 $f^{-1}$ 只是一个**对应法则**、一个记号，表示联系 $X$ 与 $Y$ 的桥梁，不是 $f$ 的倒数。

### 38. 反函数的求法（两步）

1. **反解 $X$**：从 $Y=f(X)$ 中把 $X$ 解出来，用 $Y$ 表示；
2. **对调 $X$ 与 $Y$**：把上一步结果中的 $X$、$Y$ 互换，即得反函数。

注意：分段函数求反函数时，**每一段还要确定反函数的定义域**——它等于该段原函数的值域。

### 39. 反函数的两个特点

**特点一：定义域与值域交换**

$$\text{原函数的定义域}=\text{反函数的值域}$$

$$\text{原函数的值域}=\text{反函数的定义域}$$

**特点二：图像关于 $Y=X$ 对称**

函数与其反函数的图像关于直线 $Y=X$ 对称。

另外两条重要性质：

- **单调函数必定有反函数**；非单调函数可取单调部分求反函数；
- **原函数与反函数的单调性一致**（原来是增的，反函数还是增的）。

### 40. 三角函数与反三角函数的对应

三角函数的反函数是这样来的：在周期函数上**截取一段单调区间**，再求反函数。

| 原函数 | 截取区间（定义域） | 值域 | 对应反函数 | 反函数定义域 | 反函数值域 |
|:---|:---|:---|:---|:---|:---|
| $\tan X$ | $\left(-\dfrac{\pi}{2},\dfrac{\pi}{2}\right)$ | $\mathbb{R}$ | $\arctan X$ | $\mathbb{R}$ | $\left(-\dfrac{\pi}{2},\dfrac{\pi}{2}\right)$ |
| $\sin X$ | $\left[-\dfrac{\pi}{2},\dfrac{\pi}{2}\right]$ | $[-1,1]$ | $\arcsin X$ | $[-1,1]$ | $\left[-\dfrac{\pi}{2},\dfrac{\pi}{2}\right]$ |
| $\cos X$ | $[0,\pi]$ | $[-1,1]$ | $\arccos X$ | $[-1,1]$ | $[0,\pi]$ |

每一行都验证了「原函数定义域 = 反函数值域，原函数值域 = 反函数定义域」。

### 41. 反函数的重要恒等关系（重点）

把反函数代入原函数，结果还原为自变量：

$$f\bigl(f^{-1}(X)\bigr)=X,\qquad f^{-1}\bigl(f(X)\bigr)=X$$

具体到常用函数：

$$e^{\ln X}=X,\qquad \ln e^X=X$$

$$\sin(\arcsin X)=X,\qquad \arcsin(\sin X)=X\quad(X\in[-1,1])$$

$$\tan(\arctan X)=X,\qquad \arctan(\tan X)=X\quad\left(X\in\left(-\tfrac{\pi}{2},\tfrac{\pi}{2}\right)\right)$$

$$\cos(\arccos X)=X,\qquad \cot(\operatorname{arccot}X)=X$$

老师说明：这个结论在专升本真题中出现较少，但**考研数学考过很多次**，一定要记住。

## 三、例题精讲

### 例 1（P2）$Y=\sqrt{1-X^2}+\ln(1-2X)$

**解**：两部分分别求定义域。

偶次根式：$1-X^2\ge0\Longrightarrow X^2\le1\Longrightarrow -1\le X\le1$。

对数真数：$1-2X>0\Longrightarrow X<\dfrac{1}{2}$。

取交集（画数轴）：

$$\boxed{\left[-1,\ \tfrac{1}{2}\right)}$$

### 例 2（P2）$Y=\sqrt{3-X}+\arctan\dfrac{1}{X}$

**解**：偶次根式：$3-X\ge0\Longrightarrow X\le3$。

$\arctan$ 定义域是 $\mathbb{R}$，不用管；但内层有 $\dfrac{1}{X}$，分母不为零：$X\neq0$。

取交集：

$$\boxed{(-\infty,0)\cup(0,3]}$$

### 例 3（P2）$Y=\ln(4-X^2)+\arcsin\dfrac{X-1}{2}$

**解**：对数真数：$4-X^2>0\Longrightarrow X^2-4<0\Longrightarrow(X+2)(X-2)<0\Longrightarrow-2<X<2$。

$\arcsin$ 的括号整体要在 $[-1,1]$：

$$-1\le\frac{X-1}{2}\le1\Longrightarrow-2\le X-1\le2\Longrightarrow-1\le X\le3$$

取交集：

$$\boxed{[1,\ 2)}$$

### 例 4（P2）$Y=\sqrt{X^2-X-6}+\arcsin\dfrac{2X-1}{6}$

**解**：根号下 $\ge0$，先因式分解：

$$X^2-X-6=(X-3)(X+2)\ge0\Longrightarrow X\le-2\ \text{或}\ X\ge3$$

$\arcsin$：$-1\le\dfrac{2X-1}{6}\le1\Longrightarrow-6\le2X-1\le6\Longrightarrow-\dfrac{5}{2}\le X\le\dfrac{7}{2}$。

取交集：

$$\boxed{\left[-\tfrac{5}{2},\ -2\right]\cup\left[3,\ \tfrac{7}{2}\right]}$$

> 本题附带讲了**因式分解**：拆首尾 → 交叉相乘 → 验中间项。以 $X^2-X-6$ 为例，拆成 $X\cdot X$ 与 $-3\times2$，交叉相乘得 $2X-3X=-X$，正好等于中间项系数，故分解为 $(X-3)(X+2)$。

### 例 5（P2）$Y=\log_5(16-X^2)$

**解**：真数大于零：

$$16-X^2>0\Longrightarrow X^2-16<0\Longrightarrow(X+4)(X-4)<0\Longrightarrow-4<X<4$$

$$\boxed{(-4,\ 4)}$$

### 例 6（P2）$f(X)=\dfrac{\sqrt{1-2^X}}{X+3}$

**解**：根号下 $\ge0$：$1-2^X\ge0\Longrightarrow2^X\le1$。两边**取对数**（底数为 2）：

$$\log_2 2^X\le\log_2 1\Longrightarrow X\le0$$

分母不为零：$X+3>0\Longrightarrow X>-3$。

取交集：

$$\boxed{(-3,\ 0]}$$

### 例 7（P2）$f(X)=\sqrt{\ln(X-1)}$

**解**：根号下 $\ge0$：$\ln(X-1)\ge0$。两边**取指数**（底数为 $e$）：

$$e^{\ln(X-1)}\ge e^0\Longrightarrow X-1\ge1\Longrightarrow X\ge2$$

同时真数大于零：$X-1>0\Longrightarrow X>1$。

取交集：

$$\boxed{[2,\ +\infty)}$$

### 例 8（P3，抽象函数）已知 $f(X+2)$ 的定义域是 $[-3,1)$，求 $f(X)$ 与 $f(1-X)$ 的定义域

**解**：定义域是 $X$ 的取值范围，故 $X\in[-3,1)$。

**第一步：求括号的范围。**

$$-3\le X<1\Longrightarrow-1\le X+2<3$$

即括号范围为 $[-1,3)$。

**第二步：反求各定义域。**

求 $f(X)$ 的定义域：把括号里的 $X$ 丢进 $[-1,3)$，得

$$f(X)\ \text{的定义域为}\ [-1,\ 3)$$

求 $f(1-X)$ 的定义域：把 $1-X$ 丢进 $[-1,3)$：

$$-1\le1-X<3\Longrightarrow-3<-X\le1\Longrightarrow-2<X\le2$$

> 关键一步：两边乘（除以）负数，**不等号要变号**。

$$\boxed{f(1-X)\ \text{的定义域为}\ (-2,\ 2]}$$

### 例 9（P3，抽象函数）已知 $f(X)$ 的定义域为 $(0,1)$，求 $f(\ln X)$ 的定义域

**解**：$f(X)$ 定义域是 $(0,1)$，且括号里就一个 $X$，所以**括号范围为 $(0,1)$**。

把 $\ln X$ 丢进 $(0,1)$：

$$0<\ln X<1$$

两边取指数（底数为 $e$）：$e^0<X<e^1$，即

$$\boxed{(1,\ e)}$$

### 例 10（P3，抽象函数）已知 $f(2X-1)$ 的定义域为 $(0,1)$，求 $f(1-3X)$ 的定义域

**解**：$X\in(0,1)\Longrightarrow0<2X<2\Longrightarrow-1<2X-1<1$，括号范围为 $(-1,1)$。

把 $1-3X$ 丢进 $(-1,1)$：

$$-1<1-3X<1\Longrightarrow-2<-3X<0$$

两边乘 $-\dfrac{1}{3}$（变号）：

$$0<X<\frac{2}{3}$$

$$\boxed{\left(0,\ \tfrac{2}{3}\right)}$$

> 字幕说明：本例原题在讲解中被老师**现场修改**过内层函数（原题做不下去），最终得到 $[0,\tfrac{1}{2})$ 一类的答案。方法仍是「先求括号范围，再反求定义域」，此处只记方法。

### 例 11（P4）判断下列各组函数是否为同一函数

| 组 | $f(X)$ | $g(X)$ | 定义域 | 化简后对应法则 | 结论 |
|:---|:---|:---|:---|:---|:---|
| A | $\sqrt{X^2}$ | $X$ | 都是 $\mathbb{R}$ | $f=\lvert X\rvert$，$g=X$，**不同** | 否 |
| B | $\ln X^2$ | $2\ln\lvert X\rvert$ | 都是 $X\neq0$ | 相同 | **是** |
| C | $(\sqrt{X})^2$ | $X$ | $f$：$X\ge0$；$g$：$\mathbb{R}$，**不同** | — | 否 |
| D | $e^{\ln X}$ | $X$ | $f$：$X>0$；$g$：$\mathbb{R}$，**不同** | — | 否 |
| E | $\dfrac{X^2-1}{X-1}$ | $X+1$ | $f$：$X\neq1$；$g$：$\mathbb{R}$，**不同** | 相同 | 否 |
| F | $\sqrt{1-\cos^2X}$ | $\sin X$ | 都是 $\mathbb{R}$ | $f=\lvert\sin X\rvert$，**不同** | 否 |
| G | $1$ | $\sin^2X+\cos^2X$ | 都是 $\mathbb{R}$ | 都恒等于 $1$，相同 | **是** |

**关键提示**：

- 判断定义域时**不许化简**（B 组若把 $\ln X^2$ 直接化简成 $2\ln X$，定义域就从 $X\neq0$ 缩小成 $X>0$，错了，必须写成 $2\ln\lvert X\rvert$）；
- 判断对应法则时**必须化简**；
- 平方开根号等于绝对值：$\sqrt{A^2}=\lvert A\rvert$。

### 例 12（P5）已知 $f(e^X)=X+1$，求 $f(X)$

**解法一（配凑法）**：把右边配成含 $e^X$ 的形式。由 $\ln e^X=X$，

$$f(e^X)=\ln e^X+1$$

整体代换得 $f(T)=\ln T+1$，再由「表达形式与字母无关」写成

$$\boxed{f(X)=\ln X+1}$$

**解法二（换元法）**：令 $e^X=t$，两边取对数得 $X=\ln t$。代入原式：

$$f(t)=\ln t+1\Longrightarrow\boxed{f(X)=\ln X+1}$$

### 例 13（P5）已知 $f(\cos^2X)=\tan^2X$，求 $f(X)$

**解**：本题**换元不好做，用配凑**。

$$\tan^2X=\frac{\sin^2X}{\cos^2X}=\frac{1-\cos^2X}{\cos^2X}$$

令 $\cos^2X=T$，得

$$f(T)=\frac{1-T}{T}\Longrightarrow\boxed{f(X)=\frac{1-X}{X}}$$

### 例 14（P5）已知 $f\left(X-\dfrac{1}{X}\right)=X^2+\dfrac{1}{X^2}$，求 $f(X)$

**解**：用**配凑**（换元几乎做不动）。在右边凑完全平方：

$$X^2+\frac{1}{X^2}=X^2-2\cdot X\cdot\frac{1}{X}+\frac{1}{X^2}+2=\left(X-\frac{1}{X}\right)^2+2$$

令 $X-\dfrac{1}{X}=T$，得 $f(T)=T^2+2$，故

$$\boxed{f(X)=X^2+2}$$

> 老师提醒：这里**只能用减 2 来配**，用加 2 会配出 $X+\dfrac{1}{X}$，与括号内的 $X-\dfrac{1}{X}$ 对不上，必须重新配。

### 例 15（P5）已知 $f\left(X+\dfrac{1}{X}\right)=X^2+\dfrac{1}{X^2}$，求 $f(X)$

**解**：这次括号内是加号，所以**用加 2 配**：

$$X^2+\frac{1}{X^2}=X^2+2\cdot X\cdot\frac{1}{X}+\frac{1}{X^2}-2=\left(X+\frac{1}{X}\right)^2-2$$

令 $X+\dfrac{1}{X}=T$，得

$$\boxed{f(X)=X^2-2}$$

### 例 16（P8，用定义判断奇偶性）$f(X)=e^X-e^{-X}$

**解**：$e^X$ 与 $e^{-X}$ 都非奇非偶，不能直接套法则，**必须用定义**。

$$f(-X)=e^{-X}-e^{-(-X)}=e^{-X}-e^{X}=-\left(e^X-e^{-X}\right)=-f(X)$$

故 $f(X)$ 为**奇函数**。

### 例 17（P8）$f(X)=\ln\left(X+\sqrt{X^2+1}\right)$

**解**：直接代换看不出关系，需要**根式有理化**。

先把 $X$ 写成 $\sqrt{X^2}$，则 $X+\sqrt{X^2+1}$ 可看作「根号和」的形式。分子分母同乘 $\sqrt{X^2+1}-X$：

$$\frac{\left(\sqrt{X^2+1}+X\right)\left(\sqrt{X^2+1}-X\right)}{\sqrt{X^2+1}-X}=\frac{(X^2+1)-X^2}{\sqrt{X^2+1}-X}=\frac{1}{\sqrt{X^2+1}-X}$$

于是

$$f(-X)=\ln\left(\sqrt{X^2+1}-X\right)=\ln\left(\sqrt{X^2+1}+X\right)^{-1}=-\ln\left(\sqrt{X^2+1}+X\right)=-f(X)$$

故 $f(X)$ 为**奇函数**。

> 老师结论：见到 $\ln\left(X+\sqrt{X^2\pm1}\right)$ 这类形式，**直接背下来是奇函数**，不用每次推。

### 例 18（P8）$f(X)=\ln\dfrac{1-X}{1+X}$

**解**：取反后分子分母颠倒：

$$f(-X)=\ln\frac{1+X}{1-X}$$

用「颠倒相乘」的技巧（$1\div\dfrac{a}{b}=\dfrac{b}{a}$）：

$$\frac{1+X}{1-X}=\left(\frac{1-X}{1+X}\right)^{-1}$$

故

$$f(-X)=\ln\left(\frac{1-X}{1+X}\right)^{-1}=-\ln\frac{1-X}{1+X}=-f(X)$$

$f(X)$ 为**奇函数**。

### 例 19（P8）$f(X)=\dfrac{e^X-1}{e^X+1}$

**解**：分子分母同乘 $e^X$（消掉负指数）：

$$f(-X)=\frac{e^{-X}-1}{e^{-X}+1}=\frac{1-e^X}{1+e^X}$$

分子提负号：

$$=\frac{-\left(e^X-1\right)}{e^X+1}=-\frac{e^X-1}{e^X+1}=-f(X)$$

$f(X)$ 为**奇函数**。

### 例 20（P8）设 $G(X)=f(X)+f(-X)$，$H(X)=f(X)-f(-X)$，判断奇偶性

**解**：

$$G(-X)=f(-X)+f(X)=G(X)\Longrightarrow G(X)\ \text{为偶函数}$$

$$H(-X)=f(-X)-f(X)=-\left[f(X)-f(-X)\right]=-H(X)\Longrightarrow H(X)\ \text{为奇函数}$$

### 例 21（P11）求 $\arctan 1$

**解**：令 $A=\arctan 1$，两边取 $\tan$：

$$\tan A=\tan(\arctan 1)=1$$

（用到 $\tan(\arctan X)=X$。）

故 $A=\dfrac{\pi}{4}$，即

$$\boxed{\arctan 1=\frac{\pi}{4}}$$

> 作业（P11）：求 $\arcsin\dfrac{\sqrt{3}}{2}$ 与 $\arccos\dfrac{1}{2}$，两个答案都是 $\dfrac{\pi}{3}$。

### 例 22（P12）设 $f(X)$ 的反函数是 $G(X)$，求 $G(10)$

**解**：核心是「**原函数的定义域 = 反函数的值域，原函数的值域 = 反函数的定义域**」。

要求 $G(10)$，即反函数在 $X=10$ 处的值；这个 $10$ 落在 $G$ 的定义域里，也就是落在 $f$ 的**值域**里。

所以问题转化为：**求使 $f(X)=10$ 的 $X$**。解得 $X=2$，故

$$\boxed{G(10)=2}$$

> 字幕数值不清，此处只记方法：原函数的具体表达式在字幕中无法确认，但「把求反函数值的问题转化为解 $f(X)=$ 给定值」这一思路是本题的全部要点。

### 例 23（P12）求分段函数 $f(X)=\begin{cases}2X+2, & X<0\\ e^{2X}+1, & X\ge0\end{cases}$ 的反函数

**解**：分段处理，每段**先反解、再定范围、最后对调**。

**第一段**：$X<0$ 时 $Y=2X+2$。

由 $X<0$ 得 $2X<0$，故 $Y=2X+2<2$，即值域 $Y<2$。

反解：$X=\dfrac{Y-2}{2}=\dfrac{Y}{2}-1$。对调 $X$、$Y$：

$$Y=\frac{X}{2}-1\quad(X<2)$$

**第二段**：$X\ge0$ 时 $Y=e^{2X}+1$。

由 $X\ge0$ 得 $e^{2X}\ge1$，故 $Y\ge2$。

反解：$Y-1=e^{2X}$，两边取对数 $\ln(Y-1)=2X$，得 $X=\dfrac{1}{2}\ln(Y-1)$。对调：

$$Y=\frac{1}{2}\ln(X-1)\quad(X\ge2)$$

**综上**

$$\boxed{f^{-1}(X)=\begin{cases}\dfrac{X}{2}-1, & X<2\\[6pt]\dfrac{1}{2}\ln(X-1), & X\ge2\end{cases}}$$

### 例 24（P12）求分段函数（$X\le0$ 段与 $X>0$ 段）的反函数

**解**：

**第一段**：$X\le0$ 时 $Y=X^2+1$。

由 $X\le0$ 得 $X^2\ge0$，故 $Y\ge1$。

开根号（因 $X\le0$，去绝对值后取负号）：$\sqrt{Y-1}=\lvert X\rvert=-X$，即 $X=-\sqrt{Y-1}$。对调：

$$Y=-\sqrt{X-1}\quad(X\ge1)$$

**第二段**：$X>0$ 时 $Y=-X+1$。

由 $X>0$ 得 $Y<1$。

反解：$X=1-Y$。对调：

$$Y=1-X\quad(X<1)$$

**综上**

$$\boxed{f^{-1}(X)=\begin{cases}-\sqrt{X-1}, & X\ge1\\[4pt]1-X, & X<1\end{cases}}$$

> 字幕数值不清，此处只记方法：讲解中该段常数在 $1$ 与 $2$ 之间反复，最终按 $Y=X^2+1$ 处理。

### 例 25（P12）求 $Y=\dfrac{1}{2}\sin(X+2)-1$ 的反函数

**解**：

**第一步：反解 $X$。**

$$Y+1=\frac{1}{2}\sin(X+2)\Longrightarrow2(Y+1)=\sin(X+2)$$

两边同时取 $\arcsin$（用 $\arcsin(\sin u)=u$）：

$$X+2=\arcsin(2Y+2)\Longrightarrow X=\arcsin(2Y+2)-2$$

**第二步：确定 $Y$ 的范围。** 两种办法都行。

- 办法一：因 $\arcsin$ 的定义域是 $[-1,1]$，故 $-1\le2Y+2\le1$，解得 $-\dfrac{3}{2}\le Y\le-\dfrac{1}{2}$；
- 办法二：因 $\sin(X+2)\in[-1,1]$，由 $Y=\dfrac{1}{2}\sin(X+2)-1$ 得 $Y\in\left[-\dfrac{3}{2},-\dfrac{1}{2}\right]$。

**第三步：对调 $X$、$Y$。**

$$\boxed{Y=\arcsin(2X+2)-2,\qquad X\in\left[-\tfrac{3}{2},\ -\tfrac{1}{2}\right]}$$

### 例 26（P12）求 $Y=\dfrac{2X-1}{X+1}$ 的反函数

**解**：两边乘 $(X+1)$：

$$(X+1)Y=2X-1\Longrightarrow XY+Y=2X-1$$

合并同类项（含 $X$ 的移到一边）：

$$(Y-2)X=-1-Y$$

两边同乘 $-1$：$(2-Y)X=1+Y$，故

$$X=\frac{1+Y}{2-Y}$$

对调 $X$、$Y$：

$$\boxed{Y=\frac{1+X}{2-X}}$$

> 定义域讨论：原函数 $X\neq-1$，故反函数 $Y$ 取不到 $2$；老师说明本题涉及「无穷」，考试中一般不去纠缠定义域，把反函数求出来即可。

### 例 27（P12）求 $Y=\ln\left(X+\sqrt{X^2-1}\right)$ 的反函数

**解**：这是经典难题，需要**两次取指数 + 根式有理化 + 两式相加**。

**第一步：两边取指数。**

$$e^Y=e^{\ln\left(X+\sqrt{X^2-1}\right)}=X+\sqrt{X^2-1}\tag{1}$$

**第二步：造出第二个式子。** 两边取倒数（写成 $-1$ 次方），得

$$e^{-Y}=\frac{1}{X+\sqrt{X^2-1}}$$

对分母做**根式有理化**（分子分母同乘 $X-\sqrt{X^2-1}$）：

$$\frac{1}{X+\sqrt{X^2-1}}=\frac{X-\sqrt{X^2-1}}{\left(X+\sqrt{X^2-1}\right)\left(X-\sqrt{X^2-1}\right)}=\frac{X-\sqrt{X^2-1}}{X^2-(X^2-1)}=X-\sqrt{X^2-1}$$

即

$$e^{-Y}=X-\sqrt{X^2-1}\tag{2}$$

**第三步：$(1)+(2)$，根号抵消。**

$$e^Y+e^{-Y}=2X\Longrightarrow X=\frac{e^Y+e^{-Y}}{2}$$

**第四步：对调 $X$、$Y$。**

$$\boxed{Y=\frac{e^X+e^{-X}}{2}}$$

### 例 28（P12）求 $Y=\dfrac{e^X-e^{-X}}{2}$ 的反函数

**解**：与例 27 异曲同工，用**换元 + 一元二次方程求根公式**。

两边乘 $2$：$2Y=e^X-e^{-X}$。

两边同乘 $e^X$：

$$2Ye^X=e^{2X}-1\Longrightarrow\left(e^X\right)^2-2Y e^X-1=0$$

令 $T=e^X$（注意 $T>0$）：

$$T^2-2YT-1=0$$

把 $Y$ 当常数，用求根公式：

$$T=\frac{2Y\pm\sqrt{4Y^2+4}}{2}=Y\pm\sqrt{Y^2+1}$$

因为 $T=e^X>0$，而 $Y-\sqrt{Y^2+1}<0$（因 $\sqrt{Y^2+1}>\lvert Y\rvert$），故舍去，取

$$T=e^X=Y+\sqrt{Y^2+1}$$

两边取对数：

$$X=\ln\left(Y+\sqrt{Y^2+1}\right)$$

对调 $X$、$Y$：

$$\boxed{Y=\ln\left(X+\sqrt{X^2+1}\right)}$$

> 例 27 与例 28 的结果**互为反函数**，可以互相验证。

## 四、易错点警示

| ❌ 易错 | ✅ 正确 |
|:---|:---|
| 判断两个函数是否同一函数时，先把式子化简再看定义域 | 定义域必须**从原式**看，不许化简（如 $\ln X^2$ 的定义域是 $X\neq0$，不是 $X>0$） |
| 求定义域时把各部分的定义域「并」起来 | 各部分定义域要**取交集**（公共部分） |
| 只满足定义域相同（或只满足对应法则相同）就判为同一函数 | 必须**两条同时满足**才是同一函数 |
| $\sqrt{X^2}=X$ | $\sqrt{X^2}=\lvert X\rvert$；开偶次方后要加绝对值 |
| 不等式两边乘负数时不变号 | 两边乘（除以）负数，**不等号必须变号** |
| 抽象函数题一上来就去解 $X$ | 第一步永远是**先求括号的范围** |
| 求完反函数就完事，不管定义域 | 分段函数的反函数**必须逐段确定定义域**（等于该段原函数的值域） |
| 认为 $f^{-1}(X)=\dfrac{1}{f(X)}$ | $f^{-1}$ 是**反函数的记号**，不是倒数 |
| 认为 $e^X$、$e^{-X}$、$\ln X$ 是奇函数或偶函数 | 它们都是**非奇非偶**，判断这类组合必须用定义 |
| 复合函数奇偶性只看外层 | 口诀是「**内偶则偶，内奇同外**」——先看最内层 |
| 把 $1+X^2$ 中的 $X^2$ 当成最内层 | $1$ 与 $X^2$ 同级，**$1+X^2$ 整体**才是最内层 |
| 认为有界函数只有 $\sin$、$\cos$ | 五个：$\sin X$、$\cos X$、$\arctan X$、$\operatorname{arccot}X$、$\dfrac{1}{1+X^2}$ |
| 把 $\tan\dfrac{\pi}{2}$ 当成一个很大的数 | $\tan\dfrac{\pi}{2}$ **不存在**（不在定义域内） |
| 求 $Y=X^2\ (X\in[0,2])$ 的反函数时写成 $Y=\pm\sqrt{X}$ | 定义域限定了单调区间，反解时**不加绝对值、不加正负号** |

## 五、小结

| 考点 | 要点 |
|:---|:---|
| 函数三要素 | 自变量 $X$、因变量 $Y$、对应法则 $f$ |
| 定义域 | 就是 $X$ 的取值范围；分式分母 $\neq0$、偶次根式下 $\ge0$、对数真数 $>0$、$\tan X$ 有排除点 |
| 具体函数定义域 | 各部分分别求，**取交集**，结果写成区间 |
| 抽象函数定义域 | 两句话 + 一个流程：**先求括号范围，再反求定义域** |
| 同一函数 | 定义域（不化简）+ 对应法则（要化简），**两条同时满足** |
| 表达式求解 | 配凑法 / 换元法；收尾用「表达形式与字母无关」 |
| 表示形式 | 显函数、隐函数、参数方程、分段函数（只有这四种） |
| 隐函数 | 能显化的显化；隐函数求导是第二章必考 |
| 分段函数 | $\lvert X\rvert$、$[X]$、$\operatorname{sgn}X$；$[X]$ 满足 $X-1<[X]\le X$ |
| 单调性 | $X_1<X_2$ 时 $f(X_1)<f(X_2)$ 为增，$>$ 为减 |
| 有界性 | 存在上下界；五个常见有界函数要背；$X$ 换成任何形式有界性不变 |
| 奇偶性 | 前提：定义域关于原点对称；$f(-X)=\pm f(X)$ |
| 奇偶图像 | 偶函数关于 $Y$ 轴对称，奇函数关于原点对称 |
| 奇偶运算 | 奇 $\pm$ 奇 $=$ 奇；奇 $\times\div$ 奇 $=$ 偶；奇 $\times\div$ 偶 $=$ 奇；偶 $\times\div$ 偶 $=$ 偶 |
| 复合奇偶性 | **内偶则偶，内奇同外** |
| 基本初等函数 | 反对幂指三（幂、对、指、三、反三角）+ 常数函数 |
| 幂函数 | 五种必会；过 $(1,1)$；无界无周期；单调性、奇偶性看 $a$ |
| 指数函数 | 过 $(0,1)$；值域 $(0,+\infty)$；无界、非奇非偶、无周期 |
| 对数函数 | 过 $(1,0)$；定义域 $(0,+\infty)$；无界、非奇非偶、无周期；运算公式必背 |
| 三角函数 | $\sin$ 奇、$\cos$ 偶、$\tan$ 奇；$\tan$ 定义域有排除点；特殊值必背 |
| 三角公式 | $\sin^2+\cos^2=1$；倍角；降幂 |
| 反三角函数 | $\arctan$（$R\to(-\frac{\pi}{2},\frac{\pi}{2})$）、$\arcsin$（$[-1,1]\to[-\frac{\pi}{2},\frac{\pi}{2}]$）、$\arccos$（$[-1,1]\to[0,\pi]$） |
| 复合函数拆分 | 由外向内层层分解，每层对应一个基本初等函数 |
| 初等函数 | 基本初等函数经有限次复合或四则运算得到 |
| 反函数求法 | ① 反解 $X$ ② 对调 $X$、$Y$（分段函数还要定定义域） |
| 反函数特点 | 定义域值域交换；图像关于 $Y=X$ 对称；单调性一致 |
| 反函数恒等式 | $f(f^{-1}(X))=X$，$f^{-1}(f(X))=X$ |
