# 第七章 曲线积分

> 来源：陈哥专升本《专升本高等数学全程班》P105–P107
>
> 本章地位（原话，P106）：对弧长的曲线积分"大概率是不会考大题的，一般情况下是一个选择或填空"；而"咱们的这个第二节对坐标的曲线积分，考大题的概率是非常的高的，包括有一些省份，他几乎每年都会考大题"。
>
> 适用范围（原话，P106）：对坐标的曲线积分"仅仅只有这五个省份要考"——**河北（仅数学一，数学二不用看）、广东、河南、陕西、宁夏**；不在其中则"可以不用去学这曲线积分"。
>
> 与前一章的关系（原话，P107）："要考曲线积分，必定是要考二重积分的"；"考这一章的，考这个第七章的，那么第六章肯定也要做考察"。

## 一、大白话讲解

### 1. 从"拖箱子"到曲线积分

**水平拉箱子**：力 $F$ 与位移 $S$ 同方向，做功就是

$$W=F\cdot S$$

**斜着拉箱子**：人拎着箱子斜向上用力，力与运动方向有一个夹角 $\theta$。把力分解成水平分力与竖直分力：

- 水平分力 $F_1=F\cos\theta$
- 竖直分力 $F_2=F\sin\theta$

竖直那个力**不做功**（力向上、运动向右），真正做功的只有水平分力，所以

$$W=F\cos\theta\cdot S$$

> 老师原话（P106）："你蹲下，人变得这么矮，然后去水平的去拉这个箱子嘛，不可能，不可能这样的"——所以力与运动方向有夹角才是真实情形。

### 2. 真实世界：变力 + 曲线

理想状态是"从 A 到 B 走直线、力也是恒定的"。但真实状态是：

- 路径不一定是直线——"你低头玩手机，那么可能走着走着走着走偏离了这个方向"；
- 力也不一定是恒力——走快一点要花的力气就大，"力肯定也是一个变力"。

于是抽象成数学模型：**在变力场中，变力 $F$ 沿一条曲线 $L$ 从 $A$ 运动到 $B$，求这个力所做的功**。这就是对坐标的曲线积分。

### 3. 微元法：把曲线切成"很窄的直线段"

取曲线上非常窄的一段 $ds$，"窄到它可以被看作是一条近似的直线"（和以前讲面积、体积时取微元、把弯的近似看成长方形的做法完全一样）。在这一小段上：

- 力近似看作**恒力**；
- 把力分解为水平分力 $F_1$ 与竖直分力 $F_2$；
- 水平分力走的距离是 $dx$，竖直分力走的距离是 $dy$。

所以这一小段上的功是 $F_1\,dx+F_2\,dy$。把整条 $L$ 上所有小段的功**加起来**（就是积分），就得到

$$\int_L P\,dx+Q\,dy$$

> **注意与前一节的差别**（老师特意强调，P106）：水平拉箱子时竖直分力不做功，"但是在这里呢，向上的这个力是要对物体进行做功的"，因为物体是**沿着曲线**运动，不是只沿水平方向运动。

### 4. 物理意义与两个性质

**物理意义**：变力沿曲线 $L$ 做功。就这么简单。

**方向性**：把物体从 $A$ 拉到 $B$，和从 $B$ 拉回 $A$，做的功**互为相反数**。

**可加性**：从 $A$ 拉到 $C$ 歇一会儿，再从 $C$ 拉到 $B$，两段加起来就是从 $A$ 到 $B$ 的功——和定积分的分段积分是一个道理。

### 5. 积分与路径无关：从家到学校

> 老师原话（P107）："比如说你要去从你家到学校，不管是你是走直线，就是骑车走路，或者说是直接坐飞机，或者说你从美国绕了一圈回来到你的学校了，那么你所做的功都是一样的。"

只要起点是 $A$、终点是 $B$，中间怎么走都无所谓——这就是"积分与路径无关"。判断依据是两个偏导相等（见下）。

### 6. 格林公式：一座桥梁

> 老师原话（P107）："格林公式它就是一个桥梁，连接了曲线积分和二重积分的一个桥梁，就是把我们没有那么熟悉的曲线积分，转换成了我们比较熟悉的二重积分。"

前提是曲线 $L$ **封闭**、而且走的是**正向（逆时针）**。

### 7. 第一型曲线积分：把"积分范围"从直线段换成曲线

一元定积分的积分范围是一条**直线段**——$x$ 轴上的区间 $[a,b]$。现在把范围换掉：**不再是直线段，而是 $xOy$ 平面上的一条曲线 $L$**，函数定义在这条曲线上、对它做积分，这就是**曲线积分**。

| | 一元定积分 | 第一型曲线积分 |
|:---|:---|:---|
| 记号 | $\displaystyle\int_a^b f(x)\,\mathrm{d}x$ | $\displaystyle\int_L f(x,y)\,\mathrm{d}s$ |
| 微元 | $\mathrm{d}x$：宽度为 $\mathrm{d}x$ 的竖直小长条 | $\mathrm{d}s$：弧长为 $\mathrm{d}s$ 的一小段曲线 |

两者的累加思想**完全一样**：把无数个小微元加起来。区别只在**微元取自哪里**——一个取自直线段，一个取自曲线。

老师给的直观（P105）：$f(x,y)$ 是空间里的一张曲面，把 $L$ 上的一小段 $\mathrm{d}s$ 竖起来当"底边"、曲面高度当"高"，就得到一条小长条，面积是 $f\cdot\mathrm{d}s$；把整条 $L$ 上的小长条全部加起来，得到的是一个**柱面的侧面积**。

## 二、考点全爆破

### 1. 两种曲线积分的命名与考法定位

| 名称 | 别名 | 记号特征 | 考法（P106 原话） |
|:---|:---|:---|:---|
| 对弧长的曲线积分 | **第一型**曲线积分 | $\int_L f(x,y)\,ds$ | "大概率是不会考大题的，一般情况下是一个选择或填空"，"填空可能会考的多一些" |
| 对坐标的曲线积分 | **第二型**曲线积分 | $\int_L P\,dx+Q\,dy$ | "考大题的概率是非常的高的"，"包括有一些省份，他几乎每年都会考大题" |

（P105 讲第一型、P106/P107 讲第二型；两节的完整内容本笔记都已覆盖，见下面第 2–9 条。）

### 2. 从定积分到曲线积分：积分范围的变化（P105）

一元定积分与第一型曲线积分的对照：

| | 一元定积分 | 第一型曲线积分 |
|:---|:---|:---|
| 记号 | $\displaystyle\int_a^b f(x)\,\mathrm{d}x$ | $\displaystyle\int_L f(x,y)\,\mathrm{d}s$ |
| 积分范围 | 区间 $[a,b]$（**一条直线段**） | 路径 $L$（$xOy$ 平面上的**一条曲线**） |
| 微元 | $\mathrm{d}x$ | $\mathrm{d}s$（**弧微分**） |
| 被积函数 | 一元函数 $f(x)$ | $f(x,y)$，**可一元可二元** |
| 几何意义 | 曲边梯形面积 | 柱面侧面积 |

> 老师引入的原话（P105）：一元定积分"把这个积分的范围限制在了一个区间上，也就是限制在了一个直线的线段上"；"如果我们的积分范围并非为一条直线线段，而是某一条曲线，那么又该如何去理解呢？"

**第七章的定位**（P105）：多元微积分分三块——**第五章**多元函数微分学（微分）、**第六章**二重积分与**第七章**曲线积分（积分），三者合称"多元函数的微积分学"；有些教材把它们并成一章讲。老师提醒：三重积分"从来没有省份考过"。

> **适用省份的口径差异**：P105 说"目前应该只有这 **4** 个省份会考到"——陕西、河南、河北（"河北的数学一才能才会考这个第 7 章"）、广东；P106 讲第二型时则说"仅仅只有这**五个**省份要考"，在四省之外**多了一个宁夏**。两处口径不一致，本笔记照实记录，请以本省考纲为准。

### 3. 定义与记号

$$\int_L f(x,y)\,\mathrm{d}s$$

- $L$ —— **积分路径**（$xOy$ 平面上的一段曲线）
- $f(x,y)$ —— **被积函数**，"可能为二元函数，也可能为一元函数"（P105）
- $\mathrm{d}s$ —— **弧微分**，即积分路径上"非常非常窄的一段"弧
- 若 $L$ 是**封闭曲线**（围成一个封闭区域），记号中间加一个圈：$\displaystyle\oint_L f(x,y)\,\mathrm{d}s$

> ⚠️ **与第二型的关键差别：方向**。老师在 P105 开头把它与定积分类比时提到"从 $A$ 到 $B$ 和从 $B$ 到 $A$，它的积分的结果实际上是互为相反数的"。**"互为相反数"成立的是第二型（对坐标）曲线积分**；**对弧长的曲线积分（第一型）与方向无关**——$\mathrm{d}s$ 是弧长微元、恒为正，路径反向走弧长不变，所以

$$\int_{AB}f(x,y)\,\mathrm{d}s=\int_{BA}f(x,y)\,\mathrm{d}s$$

第二型的方向性 $\displaystyle\int_{AB}=-\int_{BA}$ 见下面第 10 条。

### 4. 几何意义：柱面侧面积（P105）

$f(x,y)$ 是空间中的一张曲面；在 $xOy$ 平面上取一条曲线 $L$ 作积分路径。把 $L$ 上每一小段 $\mathrm{d}s$ 竖直立起来、配上曲面高度 $f(x,y)$，就得到一条小长条，面积为 $f\cdot\mathrm{d}s$；沿 $L$ 全部累加，得到的是**柱面的侧面积**。

> 老师说这个几何意义"用的特别的少"，"如果大家不想记也可以"（P105）——不像一元定积分的几何意义（求面积）那样天天用。

### 5. 弧微分 $\mathrm{d}s$ 的推导（P105）

$\mathrm{d}s$ 是本节的**唯一新概念**，"我们以前是从来没有见过的"。推导只用勾股定理：

1. 取路径 $L$ 上一段极窄的弧 $\mathrm{d}s$；因为它**窄到可以近似看作直线段**，于是把它看成直角三角形的斜边；
2. 两条直角边分别是它在 $x$ 方向、$y$ 方向的增量 $\mathrm{d}x$、$\mathrm{d}y$；
3. 勾股定理：

$$\mathrm{d}s^2=\mathrm{d}x^2+\mathrm{d}y^2\quad\Longrightarrow\quad \mathrm{d}s=\sqrt{\mathrm{d}x^2+\mathrm{d}y^2}$$

4. 再把 $\mathrm{d}x$ 提出来（同除以 $\mathrm{d}x^2$ 再乘回 $\mathrm{d}x$，因为 $\mathrm{d}x>0$）：

$$\mathrm{d}s=\sqrt{\frac{\mathrm{d}x^2+\mathrm{d}y^2}{\mathrm{d}x^2}}\cdot\mathrm{d}x
=\sqrt{1+\left(\frac{\mathrm{d}y}{\mathrm{d}x}\right)^2}\cdot\mathrm{d}x
=\sqrt{1+y'^2}\,\mathrm{d}x$$

> 老师的定位（P105）：这一步"非常有用"，"我们后面都是基于这个去做相应的公式"——所有 $\mathrm{d}s$ 的变形都来自 $\mathrm{d}s=\sqrt{\mathrm{d}x^2+\mathrm{d}y^2}$ 这一个式子，"这个部分是雷打不动的"。

### 6. $\mathrm{d}s$ 的三种形式（★必背）

对 $\mathrm{d}s=\sqrt{\mathrm{d}x^2+\mathrm{d}y^2}$ 除以**不同的微分**，就得到三种形式——**取决于曲线怎么给**：

| $L$ 的给法 | 自变量 | $\mathrm{d}s=$ |
|:---|:---|:---|
| $y=f(x)$（**情况一**） | $x$ | $\sqrt{1+y'^2}\,\mathrm{d}x$ |
| $x=g(y)$（**情况二**） | $y$ | $\sqrt{1+x'^2}\,\mathrm{d}y$ |
| $\begin{cases}x=x(t)\\ y=y(t)\end{cases}$（**情况三**） | $t$ | $\sqrt{x'^2(t)+y'^2(t)}\,\mathrm{d}t$ |

记忆规则（P105）：**曲线的给法决定了自变量是谁，就除以谁的微分**——给 $y=f(x)$ 就除以 $\mathrm{d}x$，给 $x=g(y)$ 就除以 $\mathrm{d}y$，给参数方程就除以 $\mathrm{d}t$。

> 老师的要求（P105）："这个大家一定要把它记住"，"就不要说你在考场上面去现推导，这个肯定不行的"。

### 7. 第一型曲线积分的性质（P105）

与定积分的性质**一一对应**：

| 性质 | 式子 |
|:---|:---|
| **线性** | $\displaystyle\int_L k\,f\,\mathrm{d}s=k\int_L f\,\mathrm{d}s$；$\displaystyle\int_L(f\pm g)\,\mathrm{d}s=\int_L f\,\mathrm{d}s\pm\int_L g\,\mathrm{d}s$ |
| **可加性** | 把 $L$ 拆成 $L_1$、$L_2$ 两段：$\displaystyle\int_L f\,\mathrm{d}s=\int_{L_1}f\,\mathrm{d}s+\int_{L_2}f\,\mathrm{d}s$ |
| **★ 长度公式** | $\displaystyle\int_L 1\,\mathrm{d}s=L$ 的**长度** |

**长度公式**是本节**考得最多**的一条（P105）：被积函数为 $1$ 时，第一型曲线积分的结果就是**积分曲线的长度**——"这个考的会比较多一些"。（后面例 3、例 4 两道真题都是靠这一条一步得出答案。）

### 8. 第一型曲线积分的计算三步（P105）

**核心思路**：和二重积分"化为二次积分"一样，第一型曲线积分也要**化为定积分**——"把一个不熟悉的二重积分画成我们熟悉的定积分去做运算……在这里我们学习的曲线积分，也是要把它画成定积分"。

| 步骤 | 做什么 |
|:---|:---|
| **第一步** | **把曲线方程代入被积函数**，把二元函数化成**一元函数** |
| **第二步** | **画出 $L$ 的图像、定上下限**：代入后被积函数的自变量是 $x$ 就找 $x$ 轴上的范围 $[a,b]$；是 $y$ 就找 $y$ 轴上的范围 $[c,d]$；是 $t$ 就找 $t$ 的范围 $[t_0,t_1]$ |
| **第三步** | **把 $\mathrm{d}s$ 换成对应形式**（按第 6 条的三种情况） |

三处必须**保持一致**：曲线的给法 → 代入后的自变量 → $\mathrm{d}s$ 的形式 → 上下限取自哪根轴。

> 老师强调（P105）：代入后被积函数"它的变量是哪一个，你就去找哪一个这个轴上的这个范围"；参数方程情形"这个 $t$ 的取值范围都是给你的，大家放心"。

### 9. 第一型 vs 第二型：全面对照

| | 第一型（对弧长） | 第二型（对坐标） |
|:---|:---|:---|
| 记号 | $\displaystyle\int_L f\,\mathrm{d}s$ | $\displaystyle\int_L P\,\mathrm{d}x+Q\,\mathrm{d}y$ |
| 微元 | 弧长 $\mathrm{d}s$（**恒正**） | $\mathrm{d}x$、$\mathrm{d}y$（**可正可负**） |
| **方向** | **与方向无关** | $\displaystyle\int_{AB}=-\int_{BA}$ |
| 几何 / 物理意义 | 柱面侧面积（用得少） | 变力沿曲线做功 |
| 化为定积分 | $\mathrm{d}s\to\sqrt{1+y'^2}\,\mathrm{d}x$ 等 | $\mathrm{d}x$、$\mathrm{d}y$ 分别替换 |
| 考法 | 选择 / 填空 | 大题 |
| 常用技巧 | $\displaystyle\int_L1\,\mathrm{d}s=L$ 的长度 | 格林公式、积分与路径无关 |
### 10. 物理背景：变力沿曲线做功

$$\int_L P(x,y)\,dx+Q(x,y)\,dy$$

**物理意义**：变力沿曲线 $L$ 做功。

老师给的三步引入（P106）：

1. 恒力水平做功 $W=FS$；
2. 恒力斜向做功 $W=F\cos\theta\cdot S$（力的分解：水平 $F\cos\theta$，竖直 $F\sin\theta$，竖直分力不做功）；
3. 变力 + 曲线 → 取微元 $ds$，在微元上"近似为直线、近似为恒力"，功为 $F_1\,dx+F_2\,dy$，再沿 $L$ 累加（积分）。

### 11. 定义与记号

$\int_L P(x,y)\,dx+Q(x,y)\,dy$ 中：

- $L$ 是**积分路径**；
- $dx$ 前面的 $P(x,y)$、$dy$ 前面的 $Q(x,y)$ 是被积函数；
- 积分是两个方向分量的功之和，合起来对应一个变力。

> 老师原话（P106）："如果实在理解不了的，那么也可以也可以适当的放弃，因为我们重点关注的是什么呢？重点关注的是这个公式。"

### 12. 两条性质（P106 明确点名的两个）

**性质一：方向性**

$$\int_{AB}P\,dx+Q\,dy=-\int_{BA}P\,dx+Q\,dy$$

老师说这"和我们之前所学的定积分里面"的 $\int_a^b f(x)\,dx=-\int_b^a f(x)\,dx$ "意思的理解是完全一致的"。

**性质二：可加性**

$$\int_{AB}=\int_{AC}+\int_{CB},\qquad C\in \overline{AB}$$

（等价于定积分里的分段积分。）

> P106 复盘原话："第一个具有方向性，第二个具有可加性，还有计算，这几三种情况都非常的关键。"

### 13. 计算总纲：化为定积分

> P106 原话："它的主要方法是什么呢？主要方法是将其化成定积分。这和我们之前所讲的对弧长的曲线积分，是不是完全一致的？"

"我们的说这个积分的路径 $L$，它决定着我们化成定积分的一个具体的形式。$L$ 呢主要有下面的三种情况。"

### 14. 情况一：$L$ 为 $y=f(x)$，$x\in[a,b]$

$$\int_L P\,dx+Q\,dy=\int_a^b\Big[P\big(x,f(x)\big)+Q\big(x,f(x)\big)\,f'(x)\Big]\,dx$$

**三个动作**（老师逐步示范，P106）：

1. 把 $x$ 的取值范围 $[a,b]$ 直接写成**积分的下限、上限**（"请大家记住"）；
2. 把被积函数里的 $y$ **全部替换成 $f(x)$**（老师强调"这应该打个括号"）；
3. 把 $dy$ 换成 $y'\,dx$——"$dy$ 是微分，$dy=f'(x)\,dx$"，"这个 $y'$ 呢，实际上就是我们的积分路径的函数的 $y'$"。

> 老师提醒：这个 $f'(x)$ 就是路径 $L$ 的导数，"因为后面我们讲题的时候就给大家会涉及到的"。

### 15. 情况二：$L$ 为 $x=g(y)$，$y\in[c,d]$

$$\int_L P\,dx+Q\,dy=\int_c^d\Big[P\big(g(y),y\big)\,g'(y)+Q\big(g(y),y\big)\Big]\,dy$$

**三个动作**：

1. $y$ 的取值范围 $[c,d]$ 写成积分下限、上限；
2. 把 $x$ **全部替换成 $g(y)$**；
3. 把 $dx$ 换成 $x'\,dy$。

> 老师原话（P106）："其实这里大家一定要绕过来、转过弯来，因为我们以前所学的是写得最多的是这种形式，现在我们给他换了一下，就是交换了一下位置，$x$ 变成了 $y$，$y$ 变成了 $x$，$x$ 现在是一个因变量、$y$ 是自变量了。"
>
> 老师的举例：$y=x^2,\ x\in[0,1]$ 在第一象限，也可以写成 $x=\sqrt{y},\ y\in[0,1]$（因为 $x>0$，开方不用带绝对值）。

### 16. 情况三：$L$ 为参数方程 $x=x(t),\ y=y(t)$，$t\in[t_0,t_1]$

$$\int_L P\,dx+Q\,dy=\int_{t_0}^{t_1}\Big[P\big(x(t),y(t)\big)\,x'(t)+Q\big(x(t),y(t)\big)\,y'(t)\Big]\,dt$$

**三个位置要换**（老师总结，P106）：

1. 参数范围 $t_0\to t_1$ 写成积分下限、上限；
2. $x$、$y$ 用 $x(t)$、$y(t)$ 代入被积函数；
3. $dx$、$dy$ 换成 $x'(t)\,dt$、$y'(t)\,dt$。

> 老师顺带回顾（P106，属第二章内容）：参数方程的一阶导 $\dfrac{dy}{dx}=\dfrac{y'(t)}{x'(t)}$。

### 17. 积分与路径无关

**判别条件**：若

$$\frac{\partial P}{\partial y}=\frac{\partial Q}{\partial x}$$

则积分与路径无关，只与起点、终点有关。

**计算方法**：既然与路径无关，就**另选一条好算的路径**——通常取"一段横线 + 一段竖线"的折线（平行于坐标轴）。

> P107 原话："这个积分与路径无关，它的计算方法就是什么？选这个折线路径……不管你怎么去选，一般情况下就选一条横线，一条竖线，横线和竖线就可以了。"
>
> P107 原话（强调这是通法）："就说折线路径它是一个万能的方法，万能的一个方法，就是在积分与路径无关里面，它是一个万能方法。"

### 18. 格林公式

**条件**（P107）：

1. $L$ 是**封闭**曲线，围成平面区域 $D$；
2. $L$ 取**正向边界**，即**逆时针**方向（"不是顺时针，大家一定要搞清楚是逆时针路径"）；
3. $P(x,y)$、$Q(x,y)$ 在 $D$ 上具有**一阶连续偏导数**（"一般情况下这个条件就是会给我们的……不会说在这个条件上面给我们设置陷阱"）。

**公式**：

$$\oint_L P\,dx+Q\,dy=\iint_D\left(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y}\right)dx\,dy$$

**写法提醒**（老师反复强调，P107）：一定是 **$Q$ 对 $x$ 的偏导 减去 $P$ 对 $y$ 的偏导**，"一定要搞清楚这里是哪两个相减"。

**记号识别**（P107）："这个积分的中间有一个圈……就说明这个 $L$ 它是围成了一个封闭区域。如果他没有围成封闭区域，它是不可能用这个圈的。"

### 19. 格林公式的两类题型

**题型一：$L$ 直接围成封闭区域 → 直接用格林公式。**

**题型二：$L$ 不围成封闭区域（"缺线"）→ 补线后再用格林公式，最后减去补线上的曲线积分。**

> P107 原话："你补了一段，对吧，这一段本来就没有在这个里面的，是不是我们补了之后还要把它减去？"
>
> P107 原话（题型一的考频）："涉及到格林公式的题，百分之百都是考大题，很少去考选择或填空。"

## 三、例题精讲

### 例 1（P105）$y=x^2$ 上的第一型曲线积分·两种解法

$L$ 为抛物线 $y=x^2$ 上 $x\in\left[0,\sqrt2\right]$ 的一段，求 $\displaystyle\int_L x\,\mathrm{d}s$。

**解法一（情况一：$L$ 为 $y=f(x)$）**

被积函数只有 $x$，代入曲线方程后不变；自变量是 $x$，上下限取 $x$ 的范围 $\left[0,\sqrt2\right]$；$\mathrm{d}s=\sqrt{1+y'^2}\,\mathrm{d}x$，其中 $y'=2x$：

$$\int_0^{\sqrt2}x\sqrt{1+4x^2}\,\mathrm{d}x
=\frac{1}{8}\int_0^{\sqrt2}\left(1+4x^2\right)^{\frac12}\mathrm{d}\left(1+4x^2\right)
=\frac{1}{8}\cdot\frac{2}{3}\Bigl[\left(1+4x^2\right)^{\frac32}\Bigr]_0^{\sqrt2}$$

$$=\frac{1}{12}\left(9^{\frac32}-1\right)=\frac{1}{12}\left(27-1\right)=\frac{26}{12}=\frac{13}{6}$$

**解法二（情况二：把 $L$ 改写成 $x=g(y)$）**

因为 $x,y\ge0$，由 $y=x^2$ 得 $x=\sqrt y$，$y$ 的范围是 $[0,2]$；$x'=\dfrac{1}{2\sqrt y}$，故

$$\mathrm{d}s=\sqrt{1+x'^2}\,\mathrm{d}y=\sqrt{1+\frac{1}{4y}}\,\mathrm{d}y$$

$$\int_0^2\sqrt y\cdot\sqrt{1+\frac{1}{4y}}\,\mathrm{d}y
=\int_0^2\sqrt{y+\frac14}\,\mathrm{d}y
=\frac12\int_0^2\sqrt{4y+1}\,\mathrm{d}y$$

$$=\frac12\cdot\frac14\cdot\frac23\Bigl[\left(4y+1\right)^{\frac32}\Bigr]_0^2
=\frac{1}{12}\left(27-1\right)=\frac{13}{6}$$

> 两种解法结果相同（$\frac{13}{6}$）。老师说这道题"好像还是往年、这前几年广东省的一个考题"（P105）。

### 例 2（P105）参数方程情形

$L$ 为 $\begin{cases}x=4\cos t\\ y=4\sin t\end{cases}$，$t\in\left[0,\dfrac{\pi}{4}\right]$，求 $\displaystyle\int_L xy\,\mathrm{d}s$。

**解**：把参数方程代入被积函数，$xy=4\cos t\cdot4\sin t=16\sin t\cos t$；上下限取 $t$ 的范围 $\left[0,\dfrac{\pi}{4}\right]$；$x'(t)=-4\sin t$、$y'(t)=4\cos t$，故

$$\mathrm{d}s=\sqrt{16\sin^2t+16\cos^2t}\,\mathrm{d}t=4\,\mathrm{d}t$$

$$\int_0^{\frac{\pi}{4}}16\sin t\cos t\cdot4\,\mathrm{d}t
=64\int_0^{\frac{\pi}{4}}\sin t\cos t\,\mathrm{d}t
=64\cdot\frac12\Bigl[\sin^2t\Bigr]_0^{\frac{\pi}{4}}
=32\cdot\frac12=16$$

### 例 3（P105，真题·河南）封闭曲线 + 长度公式

$L$ 为圆周 $x^2-2x+y^2=1$（即 $(x-1)^2+y^2=2$），求 $\displaystyle\oint_L\left(x^2-2x+y^2\right)\mathrm{d}s$。

**解**：**把曲线方程整体代入被积函数**——曲线 $L$ 上处处有 $x^2-2x+y^2=1$，于是被积函数变成常数 $1$。用**长度公式**：

$$\oint_L1\,\mathrm{d}s=L\ \text{的长度}=2\pi r$$

圆心 $(1,0)$、$r^2=2$ ⇒ $r=\sqrt2$，所以

$$\oint_L\left(x^2-2x+y^2\right)\mathrm{d}s=2\pi\sqrt2=2\sqrt2\,\pi$$

> 老师说这道题"真的很简单"——"你把这个圆周曲线给它带进去……就等于 $1$ 了"，"这就整体，非常的巧妙"（P105）。

### 例 4（P105，真题·陕西）直线段 + 长度公式

$L$ 为直线段 $y=x-2$ 上 $x\in[0,2]$ 的一段，求 $\displaystyle\int_L(x-y)^2\,\mathrm{d}s$。

**解法一（用性质 + 长度公式）**

由 $y=x-2$ 得 $x-y=2$，故 $(x-y)^2=4$，被积函数是常数：

$$\int_L4\,\mathrm{d}s=4\cdot L\ \text{的长度}$$

$L$ 是从 $(0,-2)$ 到 $(2,0)$ 的线段，用勾股定理：

$$L\ \text{的长度}=\sqrt{2^2+2^2}=2\sqrt2$$

$$\int_L(x-y)^2\,\mathrm{d}s=4\cdot2\sqrt2=8\sqrt2$$

**解法二（老老实实化成定积分）**

自变量是 $x$，上下限 $[0,2]$；$(x-y)^2=2^2=4$；$y'=1$，$\mathrm{d}s=\sqrt{1+1^2}\,\mathrm{d}x=\sqrt2\,\mathrm{d}x$：

$$\int_0^2 4\sqrt2\,\mathrm{d}x=4\sqrt2\cdot(2-0)=8\sqrt2$$

> 两种解法都得到 $8\sqrt2$。老师说这两道真题"如出一辙"——"别看这个好像看起来挺难，但它还是比较巧妙的，它直接带入进去，还是得到的是一个常数"（P105）。

### 例 5（P106）三路径曲线积分

**题**：计算 $\displaystyle\int_L xy\,dx+(y-x)\,dy$，其中 $A(1,1)$、$D(2,1)$、$B(2,3)$，$L$ 分别为以下三条路径。

> 说明：本题被积表达式由老师板书的计算过程还原（先算 $x\cdot y$、再算 $(y-x)$），字幕未逐字念题。

#### (1) $L$ 为直线 $AB$

斜率 $k=\dfrac{3-1}{2-1}=2$，用点斜式（取 $A$ 点）：$y-1=2(x-1)$，得

$$L:\ y=2x-1,\qquad x\in[1,2]$$

这是**情况一**。$y'=2$，故 $dy=2\,dx$：

$$\int_1^2\Big[x(2x-1)+(2x-1-x)\cdot 2\Big]dx=\int_1^2\big(2x^2+x-2\big)dx=\frac{25}{6}$$

> 老师也交代了 $x$ 范围怎么看出来：直接看 $A$、$B$ 两点的横坐标 $1$ 与 $2$，"就是在这两个区间范围内"。

#### (2) $L$ 为抛物线

$$L:\ y=2x^2-4x+3,\qquad x\in[1,2]$$

（老师口述为"顶点式 $2(x-1)^2$ 加一个数"，字幕转写含糊；但老师随后给出的展开式与"$y-x=2x^2-5x+3$"以及最终答案 $\dfrac{10}{3}$ 完全自洽，故此处以展开式为准。）

仍是**情况一**。$y'=4x-4$，故 $dy=(4x-4)dx$：

$$\int_1^2\Big[x(2x^2-4x+3)+(2x^2-5x+3)(4x-4)\Big]dx=\frac{10}{3}$$

> 老师说："这里呢，实际上这个题呢，这个后续的计算是非常麻烦的……如果有兴趣的同学可以进行一下计算。我们在这呢就不给大家耽搁时间了。我主要去学一下他的一个计算的一个方法。"

#### (3) $L$ 为折线 $ADBA$

$$\int_{ADBA}=\int_{AD}+\int_{DB}+\int_{BA}$$

**$AD$ 段**：在直线 $y=1$ 上，$x\in[1,2]$，属**情况一**。$y'=0\Rightarrow dy=0$，后一半整体为零：

$$\int_1^2 x\cdot 1\,dx=\int_1^2 x\,dx=\frac{3}{2}$$

**$DB$ 段**：在直线 $x=2$ 上，$y\in[1,3]$，属**情况二**。$x'=0\Rightarrow dx=0$，前一半整体为零：

$$\int_1^3 (y-2)\,dy=0$$

**$BA$ 段**：用**方向性**，$\displaystyle\int_{BA}=-\int_{AB}=-\frac{25}{6}$。

**合计**：

$$\frac{3}{2}+0-\frac{25}{6}=\frac{9-25}{6}=-\frac{16}{6}=-\frac{8}{3}$$

> 老师原话（P106）："这个题呢稍微有点绕，它结合了我们的第一种和第二种类型。"
>
> 老师原话（P106，本小题的地位）："请大家一定要关注这个第三题，因为第三题呢是我们后面的这个积分与路径无关的一个铺垫。"

### 例 6（P107，2025 年河北省考题）两种解法

**题**：计算 $\displaystyle\int_L (x^2+y^2)\,dx+2xy\,dy$，其中 $L$ 为抛物线 $y=x^2$ 上从 $(0,0)$ 到 $(1,1)$ 的一段。

> 被积表达式据老师的逐步代入过程还原（$x^2+y^2$ 与 $2xy$）。

#### 解法一：直接代入（情况一）

$L:\ y=x^2,\ x\in[0,1]$，$y'=2x\Rightarrow dy=2x\,dx$：

$$\int_0^1\Big[(x^2+x^4)+2x\cdot x^2\cdot 2x\Big]dx=\int_0^1\big(x^2+5x^4\big)dx=\frac{1}{3}+1=\frac{4}{3}$$

#### 解法二：积分与路径无关

$P=x^2+y^2$，$Q=2xy$：

$$\frac{\partial P}{\partial y}=2y,\qquad \frac{\partial Q}{\partial x}=2y$$

两者相等 $\Rightarrow$ 积分与路径无关。改取折线 $OB+BA$：

- $OB$：$y=0$，$x:0\to1$，$dy=0$ $\Rightarrow \displaystyle\int_0^1 x^2\,dx=\frac{1}{3}$
- $BA$：$x=1$，$y:0\to1$，$dx=0$ $\Rightarrow \displaystyle\int_0^1 2y\,dy=1$

$$\frac{1}{3}+1=\frac{4}{3}$$

> 老师原话（P107）："我最开始看到这个题的时候，我就脑子里面就一下子看到，哎，这个应该是一个积分与路径无关的一个题。"
>
> 老师原话（P107，重要结论）："其实用这个积分与路径无关的这个方法，其实还没有我们直接给他带入进行计算……还要简单的。"
>
> 老师原话（P107）："如果他给了一个其他的稀奇古怪的路径，那么当然最好就用这个折线，就是选这个积分路径无关这个方法去进行计算。"

**同源练习**（P107）：老师另给了一道河北省（数学一）的同类题，让大家"两种方法都尝试一下"；该题在讲义上**未讲**，老师只补了答案：**结果为 $4$**。

### 例 7（P107，2020 年陕西省考题）格林公式·题型一

**题**：计算 $\displaystyle\oint_L P\,dx+Q\,dy$，其中 $L$ 为圆周 $x^2+y^2=2x$，方向为**逆时针（正向）**。

> $P$、$Q$ 的完整表达式字幕未念清，只保留老师实际算出的偏导结果。

**第一步：认清曲线。** 配方：

$$x^2-2x+y^2=0\ \Longrightarrow\ (x-1)^2+y^2=1$$

圆心 $(1,0)$、半径 $R=1$ 的圆，围成区域 $D$。

**第二步：求两个偏导。**

- $P$ 中含 $-\cos y$，对 $y$ 求偏导时含 $x$ 的部分全看作常数（求导为 $0$）：

$$\frac{\partial P}{\partial y}=\sin y$$

（老师逐步交代符号："$\cos y$ 求导是等于负的 $\sin$，那么负的 $\sin y$ 前面还有个负号，负负得正"。）

- $Q$ 中含 $x\sin y+4x$，对 $x$ 求偏导时 $y$ 看作常数（"$\sin y$ 它就是一个常数，你可以把它看作是一个 $C$"）：

$$\frac{\partial Q}{\partial x}=\sin y+4$$

**第三步：用格林公式。**

$$\oint_L P\,dx+Q\,dy=\iint_D\Big[(\sin y+4)-\sin y\Big]dx\,dy=\iint_D 4\,dx\,dy=4S_D$$

**第四步：常数被积函数的二重积分 = 常数 × 区域面积。**

$$4S_D=4\cdot\pi R^2=4\pi\cdot 1^2=4\pi$$

**答案：$4\pi$。**

> 老师原话（P107）："就说如果直接用这个格林公式，那么计算这个题呢就是还是比较容易的。"

### 例 8（P107）格林公式·题型二（补线型）

**题**：计算 $\displaystyle\int_L P\,dx+Q\,dy$，其中 $L$ 为上半圆周 $x^2+y^2=4$ 上的一段弧。

> $P$、$Q$ 的完整表达式字幕未念清；但老师念出的两个偏导、补线上的退化结果与最终答案互相自洽，据此记录。
>
> 起点/终点在字幕里被念成同一个"二〇"，方向表述也有出入，此处按老师实际使用的**补线段上 $x$ 从 $-2$ 到 $2$** 处理。

**第一步：判断"缺线"。** $L$ 只是上半圆周，**没有围成封闭区域**，所以积分号中间没有那个圈，不能直接用格林公式。

**第二步：补线。** 补上 $y=0$ 上从 $x=-2$ 到 $x=2$ 的线段，与 $L$ 一起围成上半圆区域 $D$。于是

$$I=\oint_{L+\text{补线}}-\int_{\text{补线}}$$

**第三步：对封闭部分用格林公式。**

- $P$ 中含 $ye^x$，对 $y$ 求偏导时 $e^x$ 看作常数：

$$\frac{\partial P}{\partial y}=e^x$$

- $Q$ 对 $x$ 求偏导：

$$\frac{\partial Q}{\partial x}=2+e^x$$

$$\iint_D\Big[(2+e^x)-e^x\Big]dx\,dy=\iint_D 2\,dx\,dy=2S_D=2\cdot\frac{1}{2}\pi\cdot 2^2=4\pi$$

**第四步：算补线上的积分，再减掉。**

补线在 $y=0$ 上，$y'=0\Rightarrow dy=0$；同时被积表达式退化为常数 $2$：

$$\int_{-2}^{2}2\,dx=8$$

**答案**：

$$I=4\pi-8$$

> 老师原话（P107）："补了这条线之后用这个格林公式，用了格林公式之后，我们是不是还要把这条线所对应的曲线积分给他减去？"

## 四、易错点警示

| ❌ 易错 | ✅ 正确 |
|:---|:---|
| 把 $\int_{BA}$ 直接当 $\int_{AB}$ 算 | 有**方向性**：$\int_{BA}=-\int_{AB}$，折线题最后一段尤其容易漏负号 |
| 化成定积分时上下限随便写 | 上下限就是路径参数的范围，且**必须与路径方向一致**（起点→终点） |
| 情况一只换 $y$，忘了换 $dy$ | 两个都要换：$y\to f(x)$，$dy\to y'\,dx$ |
| 情况二照抄情况一的公式 | 情况二是 $x=g(y)$：$x\to g(y)$，$dx\to x'\,dy$，上下限用 $y$ 的范围 |
| 参数方程只换上下限 | 三处都要换：① 上下限 $t_0\to t_1$；② $x,y$ 用 $x(t),y(t)$；③ $dx,dy$ 用 $x'(t)dt,y'(t)dt$ |
| 把 $\dfrac{\partial P}{\partial y}$ 与 $\dfrac{\partial Q}{\partial x}$ 看反 | 与路径无关的条件是 $\dfrac{\partial P}{\partial y}=\dfrac{\partial Q}{\partial x}$，不要与格林公式的减序混淆 |
| 格林公式写成 $\dfrac{\partial P}{\partial y}-\dfrac{\partial Q}{\partial x}$ | 是 $\dfrac{\partial Q}{\partial x}-\dfrac{\partial P}{\partial y}$，"一定要搞清楚这里是哪两个相减"（P107） |
| 不封闭的 $L$ 也直接用 $\oint$ 与格林公式 | 封闭才能用；"缺线"型要**补线**，且用完格林公式后**减去补线的积分** |
| 顺时针方向也用格林公式 | 必须**正向 = 逆时针**，顺时针要变号 |
| 求偏导时没有把另一个变量当常数 | 对 $y$ 求偏导时含 $x$ 的项全部视为常数（求导为 0），反之亦然 |
| 二重积分被积函数是常数还去硬算 | $\iint_D c\,dx\,dy=c\cdot S_D$，常数提出来乘**区域面积**即可 |
| 第一型曲线积分也去纠结方向 | 第一型（对弧长）**与方向无关**：$\int_{AB}=\int_{BA}$；有方向性的是**第二型** |
| 算 $\mathrm{d}s$ 时导数忘了平方、或整体忘了开根号 | $\mathrm{d}s=\sqrt{1+y'^2}\,\mathrm{d}x$——导数**要平方**、整体**要开根号** |
| 三种情况把 $\mathrm{d}s$ 用错 | 给 $y=f(x)$ 用 $\sqrt{1+y'^2}\mathrm{d}x$；给 $x=g(y)$ 用 $\sqrt{1+x'^2}\mathrm{d}y$；参数方程用 $\sqrt{x'^2+y'^2}\mathrm{d}t$ |
| 参数方程情形把 $\mathrm{d}s$ 当成 $\mathrm{d}t$ | 参数方程下 $\mathrm{d}s=\sqrt{x'^2(t)+y'^2(t)}\,\mathrm{d}t$，根号那一坨不能省 |
| 上下限取自错误的轴 | 代入后被积函数的自变量是谁，上下限就取自那根轴（$x$ / $y$ / $t$） |
| 被积函数代入曲线方程后成了常数，还去硬算定积分 | 用长度公式：$\int_L c\,\mathrm{d}s=c\cdot L$ 的长度 |
| 忘了 $\int_L1\,\mathrm{d}s$ 就是曲线的长度 | 这是第一型**考得最多**的一条；封闭曲线用周长，直线段用两点距离 |

| 考点 | 要点 |
|:---|:---|
| 名称对应 | 对弧长 = **第一型**；对坐标 = **第二型** |
| 考法定位 | 第一型：选择/填空；第二型：**大题**，部分省份每年必考 |
| 适用省份 | 河北（仅数学一）、广东、河南、陕西、宁夏 |
| 物理意义 | 变力沿曲线 $L$ 做功；竖直分力在曲线上**也做功**（与直线拉动不同） |
| 方向性 | $\int_{AB}=-\int_{BA}$ |
| 可加性 | $\int_{AB}=\int_{AC}+\int_{CB}$（$C\in\overline{AB}$） |
| 计算总纲 | 一律**化为定积分**，形式由 $L$ 的三种情况决定 |
| 情况一 $y=f(x)$ | 上下限取 $x$ 范围；$y\to f(x)$；$dy\to y'dx$ |
| 情况二 $x=g(y)$ | 上下限取 $y$ 范围；$x\to g(y)$；$dx\to x'dy$ |
| 情况三 参数方程 | 换三处：上下限、$x/y$、$dx/dy$ |
| 积分与路径无关 | 判别：$\dfrac{\partial P}{\partial y}=\dfrac{\partial Q}{\partial x}$；方法：改走**平行坐标轴的折线**（万能方法） |
| 格林公式条件 | $L$ 封闭 + **逆时针（正向）** + $P,Q$ 在 $D$ 上一阶连续偏导 |
| 格林公式 | $\oint_L P\,dx+Q\,dy=\iint_D\left(\dfrac{\partial Q}{\partial x}-\dfrac{\partial P}{\partial y}\right)dx\,dy$，是曲线积分与二重积分之间的桥梁 |
| 格林公式题型 | ① $L$ 封闭：直接用；② $L$ 缺线：**补线→格林→减去补线积分** |
| 与第六章的关系 | 考第七章必考第六章（二重积分），格林公式本身就要用到二重积分 |
| 第一型记号 | $\int_L f(x,y)\,\mathrm{d}s$；封闭曲线写作 $\oint_L$ |
| 第一型几何意义 | 柱面侧面积（用得极少，可不记） |
| 弧微分 | $\mathrm{d}s=\sqrt{\mathrm{d}x^2+\mathrm{d}y^2}$（勾股定理，一切变形的源头） |
| $\mathrm{d}s$ 三种形式 | $y=f(x)\to\sqrt{1+y'^2}\mathrm{d}x$；$x=g(y)\to\sqrt{1+x'^2}\mathrm{d}y$；参数方程 $\to\sqrt{x'^2+y'^2}\mathrm{d}t$ |
| 第一型性质 | 线性；可加性；**$\int_L1\,\mathrm{d}s=L$ 的长度**（考得最多） |
| 第一型计算三步 | ① 曲线方程代入被积函数 ② 画图定上下限（看自变量是谁）③ 换 $\mathrm{d}s$ |
| 第一型与方向 | **与方向无关**（与第二型的关键差别） |
