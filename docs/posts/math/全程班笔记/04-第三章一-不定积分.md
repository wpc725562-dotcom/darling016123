# 第三章（一）· 不定积分

> 来源：陈哥专升本《专升本高等数学全程班》P51–P62
> 本段地位：第三章开篇。陈哥原话：「一元函数积分学其实是和我们第二章一元函数微分学……那么大家能够把这个第二章导数学好的话，那么第三章的这个一元函数积分学，那么大家也会学的很不错，因为我们的导数和积分他们是一个互为逆运算」。他同时提醒：「积分学确实是比较有难度的一个章节……一杯茶，一包烟，一道积分算一天」，并要求「积分里面公式会比较多，下来的时候，大家一定要多花时间去背积分公式」。本段覆盖不定积分的概念（原函数、不定积分）、性质、公式表，以及两种计算方法——直接积分法与凑微分法（第一类换元法），是不定积分部分的地基；老师反复强调「凑微分也是我们后面这几种方法的一个基础」。

---

## 一、大白话讲解

### 1. 原函数：把求导"倒过来问"

第二章问的是"给你一个函数，求导得什么"；原函数问的是"求导之后等于它，那原来是谁"。

| 正向（求导） | 反向（求原函数） |
|:---|:---|
| $(x^2)'=2x$ | $x^2$ 是 $2x$ 的一个原函数 |
| $(\sin x)'=\cos x$ | $\sin x$ 是 $\cos x$ 的一个原函数 |

注意：$2x$ 是 $x^2$ 的**导函数**，$x^2$ 是 $2x$ 的**原函数**——「他们就是一个互利的一个过程」。

### 2. 为什么要加 $C$

常数求导等于 0，所以 $x^2$、$x^2+1$、$x^2+3$……求导都是 $2x$。于是：

- $x^2$ 是 $2x$ 的**一个**原函数；
- $x^2+C$ 是 $2x$ 的**全体**原函数。

> 一个原函数 + $C$ = 全体原函数。函数可以取非常多个，就体现在这个 $C$ 上。

### 3. 不定积分 = 求全体原函数

$$\int f(x)\,dx=F(x)+C$$

- 最前面那个符号（老师形容为「像一个铁球」「$F$ 里面不加一横」）叫**积分符号**；
- 里面的 $f(x)$ 叫**被积函数**；
- $dx$ 里的 $x$ 叫**积分变量**；
- 右边的 $F(x)+C$ 叫**积分结果**。

一句话：**求不定积分，就是求全体原函数**。所以「积分结果求导即为被积函数」。

### 4. 求导与积分互为逆运算

$$\sin x \xrightarrow{\ \text{求导}\ } \cos x \xrightarrow{\ \text{积分}\ } \sin x+C$$

反过来也成立：$\cos x$ 求导得 $-\sin x$，那么 $-\sin x$ 积分必得 $\cos x$。

### 5. 凑微分是什么

求导：知道 $y=f(x)$，求 $dy=f'(x)dx$。
凑微分：知道 $f'(x)dx$ 这一坨，反过来问"它原来是哪个函数的微分"。

> 比如给了 $\cos x\,dx$，你要能看出它 $=d\sin x$；给了 $\frac1x dx$，要能看出它 $=d\ln x$。

**凑微分的核心只有四个字：导数关系。** 被积函数里必须存在"一个是另一个的导数"的关系（哪怕差一个系数），才考虑用凑微分；找不到导数关系，就不要用凑微分。

### 6. 三个学习要求（老师的原话）

1. 第二章求导公式要熟——「你第二章导数公式学的比较好，那么在第三章学这个积分学起来也会比较快」。
2. 积分公式要背到"肌肉记忆"——「只有这些公式背的非常的熟练，在我们后面学不定积分的计算方法的时候才会游刃有余」。
3. 必须动笔——「纸上得来终觉浅，绝知此事要躬行」。

## 二、考点全爆破

### 1. 原函数与全体原函数

**定义**：若在区间 $I$ 上处处有 $F'(x)=f(x)$（等价写法 $dF(x)=f(x)dx$），则称 $F(x)$ 是 $f(x)$ 在区间 $I$ 上的一个原函数。

**结论**：若 $F(x)$ 是 $f(x)$ 的一个原函数，则 $F(x)+C$ 是 $f(x)$ 的全体原函数。

**两个"谁是谁"的关系**（选填题的核心）：

| 名称 | 关系 |
|:---|:---|
| 原函数 ↔ 直接函数 | 原函数求导 = 直接函数 |
| 一个原函数 → 全体原函数 | 加一个任意常数 $C$ |

老师说这类题「有点像语文里面的分析……谁是谁，抓主谓宾」：先找出谁是原函数，再对原函数求导。

### 2. 不定积分的定义与记号

$$\int f(x)\,dx=F(x)+C$$

| 部分 | 名称 |
|:---|:---|
| $\int$ | 积分符号 |
| $f(x)$ | 被积函数 |
| $dx$ 中的 $x$ | 积分变量 |
| $F(x)+C$ | 积分结果（= 全体原函数） |

读法：「对 $f(x)$ 的不定积分」「$f(x)$ 的积分」都可以。

**必加 $C$**：大题漏写 $C$ 一般扣 1–2 分；填空题漏写 $C$ **不给分**。

### 3. 不定积分的性质（六条，三、四是重点）

| 序号 | 表达式 | 口诀 |
|:---|:---|:---|
| ① 可拆性 | $\int[f(x)\pm g(x)]dx=\int f(x)dx\pm\int g(x)dx$ | 加减可拆开 |
| ② 数乘 | $\int k f(x)dx=k\int f(x)dx$（$k$ 为常数） | 常数提到积分号外 |
| ③ 先积后导 | $\left(\int f(x)dx\right)'=f(x)$ | **先积后导为本身** |
| ④ 先导后积 | $\int f'(x)dx=f(x)+C$ | **先导后积为本身加 $C$** |
| ⑤ 先积后微分 | $d\int f(x)dx=f(x)dx$ | 先积后微，注意 $dx$ |
| ⑥ 先微分后积分 | $\int dF(x)=F(x)+C$ | 先微后积为本身加 $C$ |

要点：

- ③④ 是「不定积分概念与性质」题的绝对主角——「不管他们怎么变形，本质上一定是三、四」。
- ⑤ 是"微分必带 $dx$"的来源：选项里出现 $d\int f(x)dx$ 却不带 $dx$，**直接判错**，都不用去算里面那坨对不对。
- ③ 的"本身"是**被积函数**；④ 的"本身"是**还没求导的那个原函数形式**（例：$\int(\cos x)'dx$ 的"本身"是 $\sin x$ 而不是 $\cos x$）。
- ⑤⑥ 与微分的两个方向对应：左→右是微分，右→左就是**凑微分**。

**一条硬规定（P52 原话）**：「被积函数中含有积分变量的式子，不能提到积分符号外」。所以 $\int e^x f(x)dx$ 里的 $e^x$ **不能**提到积分号外面去。

### 4. 基本积分公式表（背熟练）

**幂函数**

$$\int x^a dx=\frac{x^{a+1}}{a+1}+C\quad(a\neq-1)$$

- $\int 1\,dx=x+C$（把 1 看成 $x^0$ 套公式）
- $\int k\,dx=kx+C$
- $\int \frac{dx}{\sqrt x}=2\sqrt x+C$（即 $x^{-1/2}$ 型）
- $\int \frac{dx}{x^2}=-\frac1x+C$（即 $x^{-2}$ 型）
- $\int \frac{dx}{x}=\ln|x|+C$（$a=-1$ 的例外，积出来是对数，不是幂函数）

> 绝对值的由来：$\frac1x$ 的定义域是 $x\neq 0$。$x>0$ 时积出 $\ln x$；$x<0$ 时真数必须为正，只能写 $\ln(-x)$。两种情形合并即 $\ln|x|$，保证在整个定义域内都有原函数。

**指数函数**

$$\int a^x dx=\frac{a^x}{\ln a}+C,\qquad \int e^x dx=e^x+C$$

例：$\int 2^x dx=\frac{2^x}{\ln 2}+C$。

**三角函数（五组、十个公式）**

| 组 | 公式 |
|:---|:---|
| 一 | $\int \sin x\,dx=-\cos x+C$，$\int \cos x\,dx=\sin x+C$ |
| 二 | $\int \tan x\,dx=-\ln|\cos x|+C$，$\int \cot x\,dx=\ln|\sin x|+C$ |
| 三 | $\int \sec x\,dx=\ln|\sec x+\tan x|+C$，$\int \csc x\,dx=\ln|\csc x-\cot x|+C$ |
| 四 | $\int \sec^2 x\,dx=\tan x+C$，$\int \csc^2 x\,dx=-\cot x+C$ |
| 五 | $\int \sec x\tan x\,dx=\sec x+C$，$\int \csc x\cot x\,dx=-\csc x+C$ |

记忆提示（老师给的）：$\cos$ 的导数是 $\sec$ 开头的 $\sec\tan$，$\sin$ 的导数对应 $\csc$ 开头的 $\csc\cot$——「$C$ 对应 $C$，$S$ 对应 $S$」。

**反三角函数**

$$\int\frac{dx}{a^2+x^2}=\frac1a\arctan\frac xa+C,\qquad \int\frac{dx}{\sqrt{a^2-x^2}}=\arcsin\frac xa+C$$

取 $a=1$：$\int\frac{dx}{1+x^2}=\arctan x+C$，$\int\frac{dx}{\sqrt{1-x^2}}=\arcsin x+C$。

**两个"积出来是对数"的公式（易混，重点区分）**

$$\int\frac{dx}{x^2-a^2}=\frac{1}{2a}\ln\left|\frac{x-a}{x+a}\right|+C$$

$$\int\frac{dx}{\sqrt{x^2\pm a^2}}=\ln\left|x+\sqrt{x^2\pm a^2}\right|+C$$

配套注意：

- $\int\frac{dx}{a^2-x^2}$ 与上面的第一式**只差一个负号**（分母提个负号即可互化），两种写法都出现在不同辅导书上，都对。
- 老师提醒：**加号积出反三角，减号积出对数**——$\int\frac{dx}{x^2+a^2}=\frac1a\arctan\frac xa+C$（不是 $\frac{1}{2a}$），$\int\frac{dx}{x^2-a^2}=\frac{1}{2a}\ln|\cdot|+C$（系数是 $\frac{1}{2a}$）。他说自己背多了也会绕，「大家至少记得你是错的还是对的」，实在记不清就翻公式表。
- **对数函数本身没有固定积分公式**，$\int\ln x\,dx$ 要靠后面的分部积分法。

### 5. 直接积分法

思路：不玩技巧，只用下面这些**基本变形工具**把被积函数"变成熟悉的幂函数、指数函数、三角函数"，再用积分公式。

| 工具 | 内容 |
|:---|:---|
| 四则运算 | 加减乘除、通分、约分 |
| 幂指运算 | 同底数幂相乘：底数不变、指数相加；相除：指数相减；$(x^a)^b=x^{ab}$；同指数幂相乘：指数不变、底数相乘 |
| 平方差 | $a^2-b^2=(a+b)(a-b)$ |
| 完全平方 | $a^2\pm2ab+b^2$ |
| 立方和/差 | $x^3+1=(x+1)(x^2-x+1)$，$x^3-1=(x-1)(x^2+x+1)$ |
| 三角公式 | $\sin^2x+\cos^2x=1$；$\tan^2x+1=\sec^2x$；$\cot^2x+1=\csc^2x$；二倍角；降幂 |

**降幂公式**（偶次幂的救命公式）：

$$\sin^2 x=\frac{1-\cos 2x}{2},\qquad \cos^2 x=\frac{1+\cos 2x}{2}$$

**三种题型**：

1. **幂指函数类型**——被积函数是 $x$ 的方幂、根式、指数式的乘积，先化成同底数幂再逐项积分。
2. **假分式类型**——分子次数不低于分母，用"加 1 减 1""加项减项""平方差""立方和差""直接约分"把它拆成整式 + 简单分式。
3. **三角函数类型**——先化简（平方关系、二倍角、降幂、乘共轭），最后一步才套积分公式。

### 6. 凑微分法（第一类换元法）

**原理**：微分与凑微分是一对逆运算。

$$f'(x)\,dx \;\longrightarrow\; df(x)$$

**数学表达式（不用背，理解即可）**：

$$\int f[g(x)]\,g'(x)\,dx=\int f[g(x)]\,dg(x)\xlongequal{\text{令}u=g(x)}\int f(u)\,du=F(u)+C=F[g(x)]+C$$

**三个解释**：

1. 被积函数是一个比较复杂的函数，但其中**存在 $g(x)$ 与 $g'(x)$ 的导数关系**（这是关键）；
2. 利用凑微分把 $g'(x)dx$ 写成 $dg(x)$；
3. 换元后的 $\int f(u)du$ **非常容易积分**，用基本公式或直接积分法即可。

**解题步骤（五步）**：

1. 观察被积函数中**是否存在导数关系**；
2. 把其中一部分写成某函数的导数形式（**配系数**，使导数等式成立）；
3. **凑微分**，写成 $d(\ )$；
4. 把凑出来的整体**令成 $u$**（熟练后这一步可省，用整体思维代替）；
5. 积分后**回代**，把 $u$ 换回原来的表达式。

**两个补充结论**：

- $dF(x)=d[F(x)+C]$——微分里加常数不影响结果，所以凑微分时可以自由"补常数"（如 $2x\,dx=d(x^2)=d(x^2+1)$）。
- 凑微分本质上就是**求原函数**，只是大多数情况下"只写一个原函数"即可，不必每次加 $C$。

### 7. 凑微分的八种类型

| 类型 | 被积函数特征 | 凑成 |
|:---|:---|:---|
| ① | $f(ax+b)$，内层是 $ax+b$ | $\frac1a d(ax+b)$ |
| ② | 同时含 $x^a$ 与 $x^{a-1}$（幂次差 1） | 把低次幂凑成高次幂的微分，配 $\frac1a$ |
| ③ | 含 $e^x$ 与 $e^x$（本身即导数关系） | $d(e^x)$ |
| ④ | 含 $\sqrt x$ 与 $\frac{1}{\sqrt x}$ | $2\,d\sqrt x$ |
| ⑤ | 含 $\frac1x$ 与 $\frac{1}{x^2}$ | $-d\left(\frac1x\right)$ |
| ⑥ | 含 $\ln x$ 与 $\frac1x$ | $d\ln x$ |
| ⑦ | 三角函数（见下） | 六种方向之一 |
| ⑧ | 反三角函数 | $d(\arctan x)$、$d(\arcsin x)$ 等 |

**类型⑦（三角函数）的六种凑微分方向**：

| 出现 | 凑成 |
|:---|:---|
| $f(\sin x)\cos x$ | $d\sin x$ |
| $f(\cos x)\sin x$ | $-d\cos x$（求导出负号，要补负号抵消） |
| $f(\tan x)\sec^2x$ | $d\tan x$ |
| $f(\cot x)\csc^2x$ | $-d\cot x$ |
| $f(\sec x)\sec x\tan x$ | $d\sec x$ |
| $f(\csc x)\csc x\cot x$ | $-d\csc x$ |

**类型⑦内部的八种子题型（老师按方法分类）**：

1. 用凑微分**证明**基本三角积分公式（$\int\tan x\,dx$、$\int\cot x\,dx$、$\int\sec x\,dx$、$\int\csc x\,dx$ 等）；
2. 被积函数只有一项且为**奇次幂**：拆成"奇次 × 偶次"，奇次那部分凑微分，偶次用 $\sin^2+\cos^2=1$ 化过去；
3. 被积函数只有一项且为**偶次幂**：**降幂**；
4. 分母为 $1\pm\sin x$、$1\pm\cos x$：分子分母同乘**共轭**；
5. 分子分母**幂次差为偶数**：分子分母同除 $\cos^n x$，配 $d\tan x$（目的就是凑出 $\sec^2x\,dx$）；
6. 直接对**分母做三角变换**（降幂公式、倍角公式）；
7. **高次幂相乘**：拆出因子凑成某个 $d(\ )$（配出 $\sec^2x$ 或 $\sec x\tan x$）；
8. 分母为 $\cos x\pm\sin x$ 型的**经典题型**：用**待定系数法**——把分子写成 $A\times(\text{分母})+B\times(\text{分母的导数})$，解出 $A,B$ 后分别积分。

**类型⑧（反三角函数）的四种凑微分方向**：

| 出现 | 凑成 |
|:---|:---|
| $\arctan x$ 与 $\frac{1}{1+x^2}$ | $d(\arctan x)$ |
| $\operatorname{arccot}x$ 与 $\frac{1}{1+x^2}$ | $-d(\operatorname{arccot}x)$ |
| $\arcsin x$ 与 $\frac{1}{\sqrt{1-x^2}}$ | $d(\arcsin x)$ |
| $\arccos x$ 与 $\frac{1}{\sqrt{1-x^2}}$ | $-d(\arccos x)$ |

反三角函数的积分「在各种类型里面是相对比较简单的」，「在我们的考试题里面出现的频率相对比较低」。

### 8. 凑微分进阶题（抽象函数，选填高频）

题干给出 $\int f(x)dx=F(x)+C$（或"$f(x)$ 的原函数是 $G(x)$"）时，**必须先挖出两条信息**：

1. **积分信息**：$\int f(x)dx=F(x)+C$（原函数就是不定积分的结果）；
2. **求导信息**：$f(x)=F'(x)$（原函数求导 = 被积函数）。

然后再对所求积分做凑微分、换元。若所求是"先导后积"型（形如 $\int f'(x)\,dx$），直接用性质 ④：等于 $f(x)+C$。

## 三、例题精讲

### （一）原函数与不定积分概念（P51）

**例 1** 求 $\dfrac{1}{1+x^2}$ 的全体原函数。

**解**：找"谁求导等于 $\frac{1}{1+x^2}$"，回到第二章公式：$(\arctan x)'=\frac{1}{1+x^2}$，故

$$\int\frac{dx}{1+x^2}=\arctan x+C$$

老师强调：只写 $\arctan x$ 是错的——「为什么呢？因为还少了一个 $C$」。

**例 2** 已知 $e^{x^2}$ 是 $f(x)$ 的一个原函数，求 $f(x)$。

**解**：原函数求导 = 直接函数，

$$f(x)=(e^{x^2})'=2xe^{x^2}$$

**例 3** 已知 $f(x)$ 的一个原函数是 $\cos x$，求 $f'(x)$。

**解**：先由"原函数求导 = 直接函数"得 $f(x)=(\cos x)'=-\sin x$，再求导：

$$f'(x)=(-\sin x)'=-\cos x$$

**例 4**（不定积分的基本验证）

$$\int\cos x\,dx=\sin x+C,\qquad \int e^x dx=e^x+C,\qquad \int\frac{dx}{x}=\ln|x|+C,\qquad \int x\,dx=\frac12x^2+C$$

### （二）不定积分的性质（P52）

**例 5**（性质①②）$\int\left(x^2\pm\sin x\right)dx$

**解**：拆开再逐项积分

$$=\int x^2dx\pm\int\sin x\,dx=\frac13x^3\mp\cos x+C$$

**例 6**（性质②）$\int 3\cos x\,dx=3\int\cos x\,dx=3\sin x+C$

**例 7**（性质③，先积后导为本身）$\left(\int x\,dx\right)'$

**解**：先积后导等于被积函数本身：

$$\left(\int x\,dx\right)'=x$$

（也可实算：$\left(\frac12x^2+C\right)'=x$。）

**例 8**（性质④，先导后积为本身加 $C$）$\int (x^2)'dx$

**解**：

$$\int 2x\,dx=x^2+C$$

这里"本身"是 $x^2$（没求导前的那个形式），不是 $2x$。

**例 9**（真题·选择题）若 $f'(x)$ 连续，则下列等式成立的是

- A. $\int f'(x)dx=f(x)$
- B. $\int df(x)=f(x)$
- C. $\int f'(x)dx=f(x)+C$
- D. $\int df(x)=f(x)+C$

**解**：先导后积为本身加 $C$，先微分后积分也是本身加 $C$，所以 **C、D 都成立**；A 漏 $C$，B 漏 $C$。（老师借此题强调：判选项时先看**有没有 $dx$**，微分的式子不带 $dx$ 一定错。）

**例 10**（多层嵌套）$\int d\int df(x)$

**解**：从里往外拆。内层 $d\int df(x)$ 是"先微分后积分"（等于本身加 $C$）；换一个角度看，把 $df(x)$ 先积分得 $f(x)+C$，再微分仍是 $df(x)$；最后再积分：

$$\int d\int df(x)=f(x)+C$$

**例 11**（真题）已知 $\int f(x)dx=x\sin x+C$，求 $f(x)$。

**解**：两边同时求导，左边用"先积后导为本身"：

$$f(x)=(x\sin x)'=\sin x+x\cos x$$

**例 12**（真题·易错）已知 $\int e^x f(x)dx=e^x\sin x+C$，求 $\int f(x)dx$。

**解**：**不能**把 $e^x$ 提到积分号外面（被积函数中含积分变量的式子不能外提）。正确做法是两边求导：

$$e^xf(x)=(e^x\sin x)'=e^x\sin x+e^x\cos x$$

两边约去 $e^x$（此时才敢约）得 $f(x)=\sin x+\cos x$，再积分：

$$\int f(x)dx=\int(\sin x+\cos x)dx=-\cos x+\sin x+C$$

**例 13**（真题·选择题）已知 $\int df(x)=\int dg(x)$，则下列**不成立**的是

- A. $df(x)=dg(x)$
- B. $f(x)=g(x)$
- C. $f'(x)=g'(x)$
- D. $f(x)$ 与 $g(x)$ 的积分结果相同

**解**：两边都是"先微分后积分"，结果都是本身加 $C$，故 $f(x)+C_1=g(x)+C_2$，即 $f(x)$ 与 $g(x)$ **只差一个常数**。例如 $f(x)=x^2+1$、$g(x)=x^2+2$，求导都是 $2x$。所以导数相同成立、微分相同成立、积分结果相同成立，但 $f(x)=g(x)$ **不一定成立**，选 B。

### （三）积分公式（P53）

**例 14**（幂函数族）

$$\int x^a dx=\frac{x^{a+1}}{a+1}+C\ (a\neq-1)$$

验证思路：把结果求导，指数降 1 后正好约掉系数，回到 $x^a$。

- $\int 1\,dx=x+C$
- $\int\frac{dx}{\sqrt x}=2\sqrt x+C$（化为 $x^{-1/2}$）
- $\int\frac{dx}{x^2}=-\frac1x+C$（化为 $x^{-2}$）
- $\int\frac{dx}{x}=\ln|x|+C$

**例 15**（指数族）

$$\int 2^x dx=\frac{2^x}{\ln 2}+C,\qquad \int e^x dx=e^x+C$$

**例 16**（反三角特例）

$$\int\frac{dx}{2+x^2}=\int\frac{dx}{(\sqrt2)^2+x^2}=\frac{1}{\sqrt2}\arctan\frac{x}{\sqrt2}+C$$

**例 17**（对数型两公式的对照）

$$\int\frac{dx}{x^2-1}=\frac12\ln\left|\frac{x-1}{x+1}\right|+C,\qquad \int\frac{dx}{\sqrt{x^2-1}}=\ln\left|x+\sqrt{x^2-1}\right|+C$$

老师特别提醒这两个式子「看得非常的像」，一定要看清 $x^2$ 在前还是在后：「一个积出来是反三角函数，另外一个积出来是对数函数」。

### （四）直接积分法（P54）

**类型一：幂指函数**

**例 18** $\int x\cdot\sqrt[3]{x}\,dx$

**解**：化为同底数幂相乘，指数相加：

$$=\int x^{1+\frac13}dx=\int x^{4/3}dx=\frac{3}{7}x^{7/3}+C$$

**例 19** $\int\dfrac{x^2-4x+4}{x^{3/2}}dx$

**解**：分子用完全平方打开，再逐项化为幂函数（分母 $x\cdot x^{1/2}=x^{3/2}$）：

$$=\int\left(x^{1/2}-4x^{-1/2}+4x^{-3/2}\right)dx=\frac23x^{3/2}-8\sqrt x-\frac{8}{\sqrt x}+C$$

**例 20**（方法示例，字幕数值不清，此处只记方法）被积函数是两因式相乘的幂指式：先把两个因式相乘展开成同底数幂（同底数幂相乘指数相加），再逐项套幂函数公式。老师给的结果中出现 $x$、$\frac12x^2$、$2\sqrt x$ 等项。

**例 21**（含 $e^x\cdot e^{-x}=1$ 的化简；字幕数值不清，此处只记方法）被积函数化简时用两条幂指运算：同指数幂相乘（底数相乘）与同底数幂相乘（指数相加），其中 $e^x\cdot e^{-x}=e^0=1$，使分子只剩常数项；积分结果含指数函数项（系数为 $\frac{1}{\ln(3e)}=\frac{1}{\ln3+1}$，老师用对数的运算把它拆开）与 $2\arctan x$。

**例 22** $\int\left(\sqrt x+\dfrac{1}{\sqrt x}\right)^2dx$

**解**：完全平方打开：$x+2+\frac1x$，

$$=\frac12x^2+2x+\ln|x|+C$$

**类型二：假分式**

**例 23** $\int\dfrac{x}{x+2}dx$

**解**：分子加 2 减 2：

$$=\int\left(1-\frac{2}{x+2}\right)dx=x-2\ln|x+2|+C$$

**例 24** $\int\dfrac{x^2}{x-1}dx$（分子减 1 加 1）

**解**：$\frac{x^2-1+1}{x-1}=\frac{(x-1)(x+1)+1}{x-1}=x+1+\frac{1}{x-1}$，

$$=\frac12x^2+x+\ln|x-1|+C$$

**例 25** $\int\dfrac{x^4}{x^2+1}dx$

**解**：分子减 1 加 1：$\frac{x^4-1+1}{x^2+1}=x^2-1+\frac{1}{x^2+1}$，

$$=\frac13x^3-x+\arctan x+C$$

**例 26**（加项减项配凑；中间化简字幕不清，此处只记方法）被积函数为分母平方的分式，做法是**加项减项**把分子配出分母的一部分，约分后化为"幂函数项 $+$ $\frac{1}{1+x^2}$ 项"，最后分别积分。老师给出的最终结果含 $\frac23x^3$、$-x$ 与 $\arctan x$ 三项。

**例 27**（拆分约分；原式字幕不清，此处只记方法）把被积函数拆成两个因式分别约分：一部分约掉 $(1+x)$ 后剩 $\frac{1}{x^2}$（积出 $-\frac1x$），另一部分约掉 $x^2$ 后剩 $\frac{1+x}{x}$ 拆开（积出 $x$ 与 $\ln|1+x|$）。核心思想：「直接把分子拆开、约分，大道至简」。

**例 28** $\int\dfrac{e^{2x}-1}{e^x-1}dx$

**解**：分子用平方差：$e^{2x}-1=(e^x+1)(e^x-1)$，约去 $e^x-1$：

$$=\int(e^x+1)dx=e^x+x+C$$

**类型三：三角函数**

**例 29** $\int\sec x(\sec x-\tan x)dx$

**解**：乘开：$\sec^2x-\sec x\tan x$，

$$=\tan x-\sec x+C$$

**例 30** $\int\dfrac{\sin^2x}{\cos^2x}dx=\int\tan^2x\,dx=\int(\sec^2x-1)dx=\tan x-x+C$

**例 31** $\int\dfrac{dx}{\sin x\cos x}$

**解**：把分子 1 换成 $\sin^2x+\cos^2x$，拆开约分：

$$=\int\left(\tan x+\cot x\right)dx=-\ln|\cos x|+\ln|\sin x|+C$$

**例 32** $\int\dfrac{\cos 2x}{\cos^2x\sin^2x}dx$

**解**：分子取二倍角中"与分母约得动"的那一个：$\cos2x=\cos^2x-\sin^2x$，拆开约分：

$$=\int\left(\frac{1}{\sin^2x}-\frac{1}{\cos^2x}\right)dx=-\cot x-\tan x+C$$

**例 33** $\int\left(\cos\frac x2+\sin\frac x2\right)^2dx$

**解**：展开得 $\cos^2\frac x2+2\sin\frac x2\cos\frac x2+\sin^2\frac x2=1+\sin x$（逆用二倍角），

$$=x-\cos x+C$$

**例 34** $\int\dfrac{\cos 2x}{\cos x-\sin x}dx$

**解**：分子因式分解 $\cos^2x-\sin^2x=(\cos x+\sin x)(\cos x-\sin x)$，约分：

$$=\int(\cos x+\sin x)dx=\sin x-\cos x+C$$

**例 35** $\int\dfrac{dx}{1+\sin x}$

**解**：分子分母同乘共轭 $1-\sin x$：

$$=\int\frac{1-\sin x}{\cos^2x}dx=\int\left(\sec^2x-\sec x\tan x\right)dx=\tan x-\sec x+C$$

**例 36** $\int\dfrac{\cos^3x}{1+\cos 2x}dx$

**解**：分母用倍角：$1+\cos2x=2\cos^2x$，

$$=\int\frac{\cos^3x}{2\cos^2x}dx=\frac12\int\cos x\,dx=\frac12\sin x+C$$

### （五）凑微分法入门（P55）

**例 37**（典型例题）$\displaystyle\int\frac{dx}{x\,(2+3\ln x)}$

**解**：

1. **找导数关系**：被积函数里有 $\frac1x$，而 $\frac1x=(\ln x)'$，与内层的 $\ln x$ 构成导数关系；
2. **配系数**：$(2+3\ln x)'=\frac3x$，比原来的 $\frac1x$ 多一个 3，所以配 $\frac13$：

$$\frac1x=\frac13\,(2+3\ln x)'$$

3. **凑微分**：

$$=\frac13\int\frac{d(2+3\ln x)}{2+3\ln x}$$

4. **换元**：令 $u=2+3\ln x$，得 $\frac13\int\frac{du}{u}$；
5. **积分并回代**：

$$=\frac13\ln|2+3\ln x|+C$$

### （六）凑微分类型①②③（P56）

**类型①：$f(ax+b)$ 型**（配系数 $\frac1a$）

**例 38** $\displaystyle\int\frac{dx}{2x-1}=\frac12\ln|2x-1|+C$

**例 39** $\displaystyle\int e^{2-x}dx=-e^{2-x}+C$（$(2-x)'=-1$，故补负号）

**例 40** $\displaystyle\int\frac{dx}{\sqrt{2x+1}}=\sqrt{2x+1}+C$

**例 41** $\displaystyle\int(3x+2)^3dx=\frac1{12}(3x+2)^4+C$

**类型②：幂函数与幂函数的导数型**（幂次差 1）

**例 42** $\displaystyle\int x\sqrt{1-x^2}\,dx=-\frac13(1-x^2)^{3/2}+C$

**解**：$(1-x^2)'=-2x$，配 $-\frac12$，凑 $d(1-x^2)$，再套幂函数公式。

**例 43** $\displaystyle\int\frac{x}{1+x^2}dx=\frac12\ln(1+x^2)+C$

（因 $1+x^2>0$，绝对值可去掉，写成括号。）

**例 44** $\displaystyle\int x e^{-x^2}dx=-\frac12e^{-x^2}+C$

**例 45**（整体思维）$\displaystyle\int(-2x)\sin(1-x^2)\,dx=\cos(1-x^2)+C$

**解**：关键**不要**把 $2x$ 单纯看成 $x^2$ 的导数，而要把它看成**整体** $1-x^2$ 的导数，凑成 $d(1-x^2)$，令 $u=1-x^2$ 化为 $-\int\sin u\,du=\cos u+C$。

**例 46** $\displaystyle\int\frac{x^2}{1+x^3}dx$（一题两法，结果相同）

**解（法一）**：分子加 $x^3$ 减 $x^3$ 后拆项：

$$\frac{x+x^3-x^3}{x(1+x^3)}=\frac1x-\frac{x^2}{1+x^3}$$

$$=\ln|x|-\frac13\ln|1+x^3|+C$$

**解（法二）**：分子分母同乘 $x^2$，凑 $d(x^3)$，令 $u=x^3$，再用**裂项**：

$$\frac{1}{u(1+u)}=\frac1u-\frac1{1+u}$$

$$\Rightarrow \frac13\left(\ln|x^3|-\ln|1+x^3|\right)+C=\ln|x|-\frac13\ln|1+x^3|+C$$

（两法结果一致：$\frac13\ln|x^3|=\ln|x|$。）

**类型③：含 $e^x$ 型**

**例 47** $\displaystyle\int\frac{e^x}{1+e^x}dx=\ln(1+e^x)+C$

**解**：$e^x\,dx=d(e^x)=d(1+e^x)$，直接凑成 $\frac{du}{u}$。

**例 48** $\displaystyle\int\frac{dx}{1+e^x}=x-\ln(1+e^x)+C$

**解（法一）**：分子加 1 减 1，拆成 $1-\frac{e^x}{1+e^x}$，第二项凑 $d(1+e^x)$。

**解（法二）**：分子分母同乘 $e^{-x}$，得 $\int\frac{e^{-x}}{1+e^{-x}}dx=-\ln(1+e^{-x})+C$。两个答案看似不同，其实等价（差一个常数），用对数运算即可互化——老师借此说明「积分方法不一样，但最后的积分结果肯定是相同的」。

**例 49** $\displaystyle\int e^x\sqrt{1+e^x}\,dx=\frac23(1+e^x)^{3/2}+C$（字幕对根号内形式略含糊，方法同上：$e^x dx=d(1+e^x)$）

**例 50** $\displaystyle\int\frac{e^x}{\sqrt{1-e^{2x}}}dx=\arcsin(e^x)+C$

**解**：先认出它是 $\int\frac{du}{\sqrt{1-u^2}}$ 的形状，把 $e^x$ 凑成 $d(e^x)$，令 $u=e^x$。

**例 51** $\displaystyle\int\frac{dx}{e^x+e^{-x}}=\arctan(e^x)+C$

**解**：分子分母同乘 $e^x$，得 $\int\frac{e^x}{1+(e^x)^2}dx$，凑 $d(e^x)$ 后套 $\int\frac{du}{1+u^2}=\arctan u+C$。

**例 52** $\displaystyle\int\frac{dx}{e^x-e^{-x}}=\frac12\ln\left|\frac{e^x-1}{e^x+1}\right|+C$

**解**：同乘 $e^x$ 得 $\int\frac{e^x}{e^{2x}-1}dx$，令 $u=e^x$，套 $\int\frac{du}{u^2-1}=\frac12\ln\left|\frac{u-1}{u+1}\right|+C$。

### （七）凑微分类型④⑤⑥（P57）

**类型④：$f(\sqrt x)\cdot\frac{1}{\sqrt x}$ 型**（$(\sqrt x)'=\frac{1}{2\sqrt x}$，配系数 2）

**例 53** $\displaystyle\int\frac{\sin\sqrt x}{\sqrt x}dx=-2\cos\sqrt x+C$

**例 54** $\displaystyle\int\frac{e^{\sqrt x}}{\sqrt x}dx=2e^{\sqrt x}+C$（凑微分补系数 2 后得 $2\int e^u du$；老师口述结果时省略了系数 2）

**例 55** $\displaystyle\int\frac{\sec^2\sqrt x}{\sqrt x}dx=2\tan\sqrt x+C$

**例 56** $\displaystyle\int\frac{dx}{\sqrt x\,(1+x)}dx=2\arctan\sqrt x+C$

**解**：把 $x$ 看成 $(\sqrt x)^2$，分母变为 $1+(\sqrt x)^2$，配系数 2 凑 $d\sqrt x$，套 $\int\frac{du}{1+u^2}$。

**类型⑤：$f\left(\frac1x\right)\cdot\frac{1}{x^2}$ 型**（$\left(\frac1x\right)'=-\frac{1}{x^2}$，配负号）

**例 57** $\displaystyle\int\frac{\cos\frac1x}{x^2}dx=-\sin\frac1x+C$

**例 58** $\displaystyle\int\frac{e^{2-\frac1x}}{x^2}dx=e^{2-\frac1x}+C$

**解**：写成**整体**的导数 $\left(2-\frac1x\right)'=\frac{1}{x^2}$（$2$ 求导为 0，$\frac1x$ 求导为 $-\frac1{x^2}$，与前面的负号抵消），恰好与原有的 $\frac{1}{x^2}$ 完全匹配，**不用再补系数**，直接凑 $d\left(2-\frac1x\right)$。

**类型⑥：含 $\ln x$ 与 $\frac1x$ 型**（$(\ln x)'=\frac1x$）

**例 59**（内层为 $\ln x$ 的一次式；字幕对"1/2 倍"还是"2 倍"含糊，此处只记方法）

$$\int\frac{dx}{x\cdot 2\ln x}=\frac12\ln|2\ln x|+C$$

**解**：$\frac1x dx=d\ln x$；因 $(2\ln x)'=\frac2x$，比原式多一个 2，故配 $\frac12$，凑成 $\frac12\int\frac{d(2\ln x)}{2\ln x}$，再用 $\int\frac{du}{u}=\ln|u|+C$。

**例 60** $\displaystyle\int\frac{dx}{x(1+\ln^2x)}=\arctan(\ln x)+C$

**解**：$\frac1x dx=d\ln x$，化为 $\int\frac{du}{1+u^2}$（$u=\ln x$）。

**例 61**（往年真题）$\displaystyle\int\frac{1+\ln x}{(x\ln x)^2}dx=-\frac{1}{x\ln x}+C$

**解**：观察发现**分子恰是分母 $x\ln x$ 的导数**：$(x\ln x)'=\ln x+x\cdot\frac1x=1+\ln x$。于是凑成 $d(x\ln x)$，令 $t=x\ln x$，化为 $\int\frac{dt}{t^2}=-\frac1t+C$，回代即得。老师说这题「确实很有难度，至少对于 80% 的同学来说，其实很不容易去求解」。

**例 62**（套娃题）$\displaystyle\int\frac{dx}{x\ln x\cdot\ln\ln x}=\ln|\ln\ln x|+C$

**解**：三步走——

1. $\frac1x dx=d\ln x$，令 $u=\ln x$，得 $\int\frac{du}{u\ln u}$；
2. 再看出 $\frac1u du=d\ln u$，令 $t=\ln u$，得 $\int\frac{dt}{t}$；
3. $\int\frac{dt}{t}=\ln|t|+C$，回代两次：$t=\ln u=\ln\ln x$，故结果为 $\ln|\ln\ln x|+C$。

老师说这题「有点像套娃，我们换了两次元」，正说明「凑微分实际上就是第一类换元法」。

### （八）凑微分类型⑦：三角函数积分（P58–P60）

**子类型 1：用凑微分证明基本公式**

**例 63** 证明 $\int\cot x\,dx=\ln|\sin x|+C$。

**解**：$\cot x=\frac{\cos x}{\sin x}$，而 $\cos x=(\sin x)'$，凑 $d\sin x$：

$$=\int\frac{d\sin x}{\sin x}=\ln|\sin x|+C$$

**例 64** 证明 $\int\tan x\,dx=-\ln|\cos x|+C$。

**解**：$\tan x=\frac{\sin x}{\cos x}$，而 $(\cos x)'=-\sin x$，故 $\sin x=-(\cos x)'$，前面补负号：

$$=-\int\frac{d\cos x}{\cos x}=-\ln|\cos x|+C$$

**例 65** 证明 $\int\sec x\tan x\,dx=\sec x+C$。

**解**：$\sec x\tan x=\frac{1}{\cos x}\cdot\frac{\sin x}{\cos x}=\frac{\sin x}{\cos^2x}$，把 $\sin x$ 凑成 $-d\cos x$，化为 $-\int\frac{du}{u^2}=\frac1u+C=\sec x+C$。

**例 66** 证明 $\int\csc x\cot x\,dx=-\csc x+C$（同法，把 $\cos x$ 凑成 $d\sin x$）。

**例 67** 证明 $\int\csc x\,dx=\ln|\csc x-\cot x|+C$。

**解**：$\csc x=\frac{1}{\sin x}$，分母用平方关系化为 $1-\cos^2x$，分子 $\sin x$ 凑成 $-d\cos x$，令 $u=\cos x$，套 $\int\frac{du}{u^2-1}=\frac12\ln\left|\frac{u-1}{u+1}\right|+C$；再分子分母同乘 $\cos x-1$，用平方差把分母化成 $\sin^2x$，平方与 $\frac12$ 抵消，最后化为 $\ln\left|\frac{\cos x-1}{\sin x}\right|+C$，即 $\ln|\cot x-\csc x|+C$——绝对值内前后可互换。

**例 68** 证明 $\int\sec x\,dx=\ln|\sec x+\tan x|+C$（方法与上题完全一致：$\sec x=\frac1{\cos x}$，分母化 $1-\sin^2x$，$\cos x$ 凑 $d\sin x$，再同乘 $\sin x+1$ 用平方差）。

**子类型 1 的其他例题**

**例 69** $\displaystyle\int\frac{\cos x}{\sin^3x}dx=-\frac{1}{2\sin^2x}+C$（凑 $d\sin x$，化为 $\int u^{-3}du$，也可写成 $-\frac12\csc^2x+C$）

**例 70** $\displaystyle\int\frac{\sin x}{\cos^5x}dx=\frac{1}{4\cos^4x}+C$（凑 $-d\cos x$，化为 $-\int u^{-5}du$）

**例 71**（含二倍角的三角有理式；字幕对分母次数不清，此处只记方法）$\displaystyle\int\frac{2\sin x\cos x}{(1+\cos x)^2}dx$：分子用二倍角 $\sin2x=2\sin x\cos x$，把 $\sin x$ 凑成 $-d\cos x$，化为关于 $\cos x$ 的有理式，再用配系数/凑微分求积，结果为含 $\ln(1+\cos x)$ 的形式。

**子类型 2：单项奇次幂——拆成"奇次 × 偶次"**

**例 72** $\displaystyle\int\cos^3x\,dx=\sin x-\frac13\sin^3x+C$

**解**：拆成 $\cos^2x\cdot\cos x$，把 $\cos x$ 凑成 $d\sin x$，再把 $\cos^2x$ 用 $\sin^2x+\cos^2x=1$ 写成 $1-\sin^2x$：

$$=\int(1-\sin^2x)\,d\sin x=\sin x-\frac13\sin^3x+C$$

**例 73** $\displaystyle\int\sin^5x\,dx=-\cos x+\frac23\cos^3x-\frac15\cos^5x+C$

**解**：拆出 $\sin x$ 凑成 $-d\cos x$，其余 $\sin^4x$ 化为 $(1-\cos^2x)^2$，展开后用完全平方公式逐项积分。

**例 74** $\displaystyle\int\tan^3x\,dx=\frac12\tan^2x+\ln|\cos x|+C$

**解**：$\tan^3x=\tan x\cdot\tan^2x$，把 $\tan^2x$ 换成 $\sec^2x-1$：

$$=\int\tan x\sec^2x\,dx-\int\tan x\,dx=\frac12\tan^2x+\ln|\cos x|+C$$

（前一项凑 $d\tan x$；后一项用公式 $\int\tan x\,dx=-\ln|\cos x|+C$，负负得正。）

**例 75**（备注）$\int\sec^3x\,dx$ 属于同一类型，但**需要分部积分**才能求，本段暂不处理——「后面学了分部积分之后，回头再来做这个题是可以的」。

**子类型 3：单项偶次幂——降幂**

**例 76** $\displaystyle\int\cos^2x\,dx=\frac x2+\frac14\sin 2x+C$

**解**：用降幂公式 $\cos^2x=\frac{1+\cos2x}{2}$，拆成两项；后一项把 $2x$ 凑成 $d(2x)$ 并补 $\frac12$。

**例 77** $\displaystyle\int\tan^2x\,dx=\tan x-x+C$（换成 $\sec^2x-1$，不用降幂）

**例 78** $\displaystyle\int\sec^4x\,dx=\tan x+\frac13\tan^3x+C$

**解**：拆成 $\sec^2x\cdot\sec^2x$，一个 $\sec^2x$ 凑成 $d\tan x$，另一个用 $\sec^2x=1+\tan^2x$ 变形，令 $u=\tan x$ 化为 $\int(1+u^2)du$。

> 老师提醒：$\int 1\,d\tan x$ 积出来是 $\tan x$，**不是 $x$**——「因为你要观察到后面实际上是 $d\tan x$，并不是 $dx$」。

**子类型 4：分母为 $1\pm\sin x$、$1\pm\cos x$——乘共轭**

**例 79** $\displaystyle\int\frac{dx}{1-\cos x}=-\cot x-\csc x+C$

**解**：分子分母同乘 $1+\cos x$，分母化为 $\sin^2x$，拆成 $\csc^2x$ 与 $\frac{\cos x}{\sin^2x}$ 两项，后者凑 $-d\sin x$。

**例 80** $\displaystyle\int\frac{dx}{1+\sin x}=\tan x-\sec x+C$

**解**：同乘 $1-\sin x$，分母化为 $\cos^2x$，拆成 $\sec^2x$ 与 $\sec x\tan x$。

**例 81** $\displaystyle\int\frac{\sin x+\cos x}{1+\sin x}dx=\sec x-\tan x+2x+\cos x+C$

**解**：同乘 $1-\sin x$，分子展开后分母为 $\cos^2x$，拆成四项：$\frac{\sin x}{\cos^2x}$、$\tan^2x$、$1$、$\sin x$，分别用凑微分、$\tan^2x=\sec^2x-1$ 与基本公式。

**子类型 5：分子分母幂次差为偶数——同除 $\cos^n x$ 配 $d\tan x$**

**例 82** $\displaystyle\int\frac{dx}{\sin^2x+2\cos^2x}=\frac{1}{\sqrt2}\arctan\frac{\tan x}{\sqrt2}+C$

**解**：分子分母同除 $\cos^2x$：分母变成 $\tan^2x+2$，分子变成 $\sec^2x$，于是

$$=\int\frac{d\tan x}{\tan^2x+2}$$

令 $u=\tan x$，套 $\int\frac{du}{u^2+a^2}=\frac1a\arctan\frac ua+C$（这里 $a=\sqrt2$）。

**例 83**（同除 $\cos^4x$；原式字幕不清，此处只记方法）$\displaystyle\int=\frac12\tan^2x+\ln|\tan x|+C$：分子分母同除 $\cos^4x$，得到 $\sec^4x$ 与 $\tan x$ 的组合；把 $\sec^4x$ 拆成 $\sec^2x\cdot\sec^2x$，一个变形为 $\tan^2x+1$，另一个凑 $d\tan x$，令 $u=\tan x$ 化为 $\int\left(u+\frac1u\right)du$。

**例 84**（更复杂的一例，原式字幕不清，此处只记方法）结果为 $\displaystyle\frac12\arctan\left(\tan^2x\right)+C$：同除 $\cos^4x$ 后配 $d\tan x$，令 $u=\tan x$ 化为 $\frac{u}{1+u^4}$，再把 $u$ 凑成 $\frac12d(u^2)$，令 $t=u^2$ 化为 $\frac{1}{1+t^2}$ 型。老师说这题「确实是比较有难度」，「我们专升本其实考察这种题概率并不是特别高」，讲它是为以后考研打基础。

**子类型 6：直接对分母做三角变换**

**例 85** $\displaystyle\int\frac{dx}{1-\cos x}=-\cot\frac x2+C$

**解**：分母用倍角公式 $1-\cos x=2\sin^2\frac x2$，化为 $\frac12\int\csc^2\frac x2 dx$，把 $\frac12$ 拿到 $d$ 后面凑成 $d\left(\frac x2\right)$：

$$=\int\csc^2\frac x2\,d\left(\frac x2\right)=-\cot\frac x2+C$$

（与例 79 结果形式不同但等价。）

**例 86**（倍角 + 幂次差型；原式字幕不清，此处只记方法）$\displaystyle\int=\frac18\tan^2\frac x2+\frac14\ln\left|\tan\frac x2\right|+C$：分母提出公因式后，用倍角公式 $\cos x+1=2\cos^2\frac x2$、$\sin x=2\sin\frac x2\cos\frac x2$ 展开，整理成"$\sec$ 的四次方 ÷ $\tan$"的形式（即回到子类型 5），同除 $\cos^4\frac x2$，令 $\frac x2=T$ 后凑 $d\tan T$。

**例 87**（未讲完的一题，老师直接给出答案）$\displaystyle\int=\ln\left|1+\tan\frac x2\right|+C$，方法与例 86 完全一样，留作练习。

**子类型 7：高次幂相乘**

**例 88** $\displaystyle\int\sin^4x\cos^3x\,dx=\frac15\sin^5x-\frac17\sin^7x+C$

**解**：拆出 $\cos x$ 凑成 $d\sin x$，$\cos^2x$ 化为 $1-\sin^2x$，展开后逐项积分。

**例 89** $\displaystyle\int\tan^{10}x\sec^2x\,dx=\frac1{11}\tan^{11}x+C$（$\sec^2x$ 直接凑成 $d\tan x$）

**例 90** $\displaystyle\int\sec^3x\tan^3x\,dx=\frac13\sec^3x-\sec x+C$

**解**：拆成 $\sec x\tan x\cdot\tan^2x$，前者凑 $d\sec x$，后者用 $\tan^2x=\sec^2x-1$，化为 $\int(u^2-1)du$。

**例 91** $\displaystyle\int\sec^{10}x\tan x\,dx=\frac1{10}\sec^{10}x+C$（原式表述略含糊，思路：拆出 $\sec x\tan x$ 凑 $d\sec x$，剩下的 $\sec^9x$ 用幂函数公式）

**子类型 8：分母为 $\cos x\pm\sin x$ 型（经典题型，待定系数法）**

**例 92** $\displaystyle\int\frac{\sin x}{\cos x-\sin x}dx=-\frac12x-\frac12\ln|\cos x-\sin x|+C$

**解**：设

$$\sin x=A(\cos x-\sin x)+B(-\sin x-\cos x)$$

（第二项是分母的导数）比较 $\sin x$ 与 $\cos x$ 的系数：

$$\begin{cases}-A-B=1\\ A-B=0\end{cases}\Rightarrow A=B=-\frac12$$

于是原积分拆成两项：第一项 $A\int 1\,dx=-\frac12x$；第二项 $B\int\frac{(\text{分母})'}{\text{分母}}dx=-\frac12\ln|\cos x-\sin x|$。

老师说这题「是比较经典的」，「不仅在我们专升本考过，在我们考研的数学里面也出现过」，下面还有一题「解题过程完全一样，只是正负号、系数不一样」。

### （九）凑微分类型⑧：反三角函数（P61）

**例 93** $\displaystyle\int\frac{dx}{\sqrt{\arctan x}\,(1+x^2)}=2\sqrt{\arctan x}+C$

**解**：$( \arctan x)'=\frac{1}{1+x^2}$，把 $\frac{dx}{1+x^2}$ 凑成 $d(\arctan x)$，令 $u=\arctan x$，化为 $\int\frac{du}{\sqrt u}=2\sqrt u+C$。

**例 94** $\displaystyle\int\frac{\arcsin x}{\sqrt{1-x^2}}dx=\frac12(\arcsin x)^2+C$

**解**：把 $\frac{dx}{\sqrt{1-x^2}}$ 凑成 $d(\arcsin x)$，令 $u=\arcsin x$，化为 $\int u\,du$。

老师提醒平方的写法：$(\arcsin x)^2$ 的平方要写在括号外，否则会歧义成 $\arcsin(x^2)$——「如果你不清楚这个平方写在哪里，你给它括起来写，这个是总没错的」。

**例 95** $\displaystyle\int\frac{e^{\arccos x}}{\sqrt{1-x^2}}dx=-e^{\arccos x}+C$

**解**：$(\arccos x)'=-\frac{1}{\sqrt{1-x^2}}$，故 $\frac{dx}{\sqrt{1-x^2}}=-d(\arccos x)$，先在积分号前补一个负号，再凑微分，令 $u=\arccos x$ 得 $-\int e^u du$。

### （十）凑微分进阶练习题（P62，选择/填空高频）

**例 96** 已知 $\int f(x)dx=F(x)+C$，求 $\int f(\cos x)\sin x\,dx$。

**解**：把 $\sin x$ 凑成 $-d\cos x$，令 $u=\cos x$：

$$=-\int f(u)du=-F(\cos x)+C$$

（选项里写 $+C$ 即可，「你加一个常数和减一个常数没有区别」。）

**例 97** 已知 $\int f(x)dx=F(x)+C$，求 $\int f(e^{-x})e^{-x}dx$。

**解**：$(e^{-x})'=-e^{-x}$，故 $e^{-x}dx=-d(e^{-x})$，补负号后令 $u=e^{-x}$：

$$=-F(e^{-x})+C$$

**例 98** 已知 $\int f(x)dx=e^{x^2}+C$，求 $\int\frac{f(\sqrt x)}{\sqrt x}dx$。

**解**：凑 $2d\sqrt x$，令 $u=\sqrt x$：

$$=2\int f(u)du=2e^{u^2}+C=2e^{x}+C$$

**例 99**（题干函数式字幕不清，此处只记方法）已知某积分等式，求形如 $\int f'(-x)$ 的"先导后积"型积分。

**方法**：① 由题干两边求导，用"先积后导为本身"得到 $f(x)$；② 所求积分为先导后积型，等于本身加 $C$，把变量换成 $-x$ 后代入 $f$ 的表达式即可。老师说这类题「第一句话其实就让我们去判断出这两个信息，如果你得不到这两个信息是没有办法做题的」。

**例 100** 求 $\displaystyle\int x f(x^2)f'(x^2)\,dx$。

**解**：把 $x\,dx$ 凑成 $\frac12d(x^2)$，令 $u=x^2$：

$$=\frac12\int f(u)f'(u)\,du$$

再令 $t=f(u)$，则 $dt=f'(u)du$，得 $\frac12\int t\,dt=\frac14t^2+C$，回代：

$$=\frac14\left[f(x^2)\right]^2+C$$

**例 101** 若 $f(x)$ 的原函数是 $e^{-2x}$，求 $\displaystyle\int f(x)f'(x)\,dx$。

**解**：先挖出两条信息——

- 积分信息：$\int f(x)dx=e^{-2x}+C$；
- 求导信息：$f(x)=(e^{-2x})'=-2e^{-2x}$。

再把 $f'(x)dx$ 凑成 $df(x)$，令 $u=f(x)$：

$$\int f(x)f'(x)dx=\int u\,du=\frac12u^2+C=\frac12f^2(x)+C$$

代入 $f(x)=-2e^{-2x}$：

$$=\frac12\left(-2e^{-2x}\right)^2+C=\frac12\cdot4e^{-4x}+C=2e^{-4x}+C$$

（指数嵌套用 $(a^b)^c=a^{bc}$：$\left(e^{-2x}\right)^2=e^{-4x}$。）

## 四、易错点警示

| ❌ 易错 | ✅ 正确 |
|:---|:---|
| 不定积分结果不写 $C$ | 一律加 $C$：大题漏 $C$ 扣 1–2 分，**填空题漏 $C$ 不给分** |
| 微分结果只写 $2x$，不写 $dx$ | 微分必带 $dx$：$d(x^2)=2x\,dx$，填空题缺 $dx$ 绝对不给分 |
| 把被积函数中含积分变量的因子提到积分号外（如把 $e^x$ 从 $\int e^xf(x)dx$ 中提出） | 只有**常数**能提到积分号外；被积函数中含积分变量的式子不能外提 |
| $\int\frac{dx}{x}=\ln x+C$ | $=\ln|x|+C$（$x<0$ 时真数须为正） |
| 用幂函数公式算 $\int\frac{dx}{x}$（写成 $\frac{x^0}{0}$） | $a=-1$ 是例外，积出对数 $\ln|x|+C$ |
| 记成 $\left(\int f(x)dx\right)'=f(x)+C$ | 先积后导为**本身**（无 $C$）；$\int f'(x)dx=f(x)+C$（有 $C$） |
| $\int(\cos x)'dx$ 的"本身"当成 $\cos x$ | "本身"是**没求导前**的形式，即 $\sin x$ |
| 凑微分时忘记配系数 | 必须配系数使导数等式成立：$(2x+1)'=2$，故补 $\frac12$ |
| 把 $2x$ 单纯看成 $x^2$ 的导数（如 $\int 2x\sin(1-x^2)dx$ 里） | 用**整体思维**：看成 $(1-x^2)'$，凑 $d(1-x^2)$，否则换元后出现 $1-u$ 不好积分 |
| 混淆 $\int\frac{dx}{x^2-a^2}$ 与 $\int\frac{dx}{a^2-x^2}$ | 两者只差一个负号，看清 $x^2$ 在前还是在后 |
| 混淆 $\int\frac{dx}{x^2+a^2}=\frac1a\arctan\frac xa+C$ 与 $\int\frac{dx}{x^2-a^2}=\frac{1}{2a}\ln|\cdot|+C$ | 记住：**加号积出反三角，减号积出对数**；系数一个是 $\frac1a$、一个是 $\frac{1}{2a}$ |
| 由 $\int df(x)=\int dg(x)$ 推出 $f(x)=g(x)$ | 只能推出 $f$ 与 $g$ **只差一个常数** |
| 换元后忘记回代（结果里留着 $u$） | 最后一步必须把 $u$ 换回原变量 |
| 三角偶次幂硬凑微分（如 $\int\cos^2x\,dx$ 直接凑 $d\sin x$） | 偶次幂先**降幂**：$\cos^2x=\frac{1+\cos2x}{2}$ |
| $\int\sec^4x\,dx$ 里把 $\int 1\,d\tan x$ 积成 $x$ | 后面是 $d\tan x$ 不是 $dx$，积出来是 $\tan x$ |
| 分母 $1\pm\sin x$、$1\pm\cos x$ 直接凑微分 | 分子分母同乘**共轭**，化为 $\sin^2x$ 或 $\cos^2x$ 后拆项 |
| 遇到 $\sqrt x$ 就只补 $d\sqrt x$ 不配 2 | $(\sqrt x)'=\frac{1}{2\sqrt x}$，必须补系数 2 |
| 换元法写成"凑微分"以外的新方法 | 凑微分本质就是**第一类换元法**，换元后一定要"令成一个整体" |

## 五、小结

| 考点 | 要点 |
|:---|:---|
| 原函数 | $F'(x)=f(x)$ 则 $F$ 是 $f$ 的一个原函数；原函数求导 = 直接函数 |
| 全体原函数 | $F(x)+C$；一个原函数 + 任意常数 |
| 不定积分 | $\int f(x)dx=F(x)+C$，本质是求全体原函数；记号四要素要分清 |
| 必加 $C$ | 大题扣 1–2 分，填空不给分；微分必带 $dx$ |
| 六条性质 | 可拆性、数乘；**先积后导为本身**、**先导后积为本身加 $C$**；先积后微带 $dx$、先微后积为本身加 $C$ |
| 不能外提 | 被积函数中含积分变量的式子不能提到积分号外 |
| 积分公式 | 幂函数（$a\neq-1$）、指数、三角五组十个、反三角两个、对数型两个；$\int\frac{dx}{x}=\ln|x|+C$ |
| 直接积分法 | 三种变形工具（四则运算、幂指运算、乘法/三角公式）+ 三种题型（幂指函数、假分式、三角函数） |
| 凑微分核心 | 找**导数关系**，配系数化成导数等式，再凑 $d(\ )$ |
| 凑微分五步 | 找关系 → 配系数 → 凑微分 → 令 $u$ → 回代 |
| 类型①–⑧ | $f(ax+b)$；$x^a$ 与 $x^{a-1}$；含 $e^x$；$\sqrt x$ 与 $\frac1{\sqrt x}$；$\frac1x$ 与 $\frac1{x^2}$；$\ln x$ 与 $\frac1x$；三角函数；反三角函数 |
| 类型⑦ 八种子题型 | 证公式；单项奇次拆奇偶；单项偶次降幂；$1\pm\sin/\cos$ 乘共轭；幂次差偶同除 $\cos^nx$；分母做三角变换；高次幂相乘配微分；分母 $\cos x\pm\sin x$ 用待定系数法 |
| 类型⑧ 反三角 | $\arctan/\arccot$ 配 $\frac{1}{1+x^2}$；$\arcsin/\arccos$ 配 $\frac{1}{\sqrt{1-x^2}}$（后两者带负号） |
| 抽象函数题 | 先挖出"积分信息 + 求导信息"两条；所求多为凑微分型或先导后积型 |
| 方法选择 | 有导数关系 → 凑微分；没有 → 换别的方法；能化简就先化简（「大道至简」） |
| 学习要求 | 求导公式熟、积分公式背到熟、必须动笔做例题 |
