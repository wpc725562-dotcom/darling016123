# 第六章 二重积分

> 来源：陈哥专升本《专升本高等数学全程班》P98–P104
> 本章地位：第五章讲完多元函数的微分学之后，本章进入**多元函数的积分学**。老师说「第六章开始呢，包括后面的第七章，涉及到了这个二重积分和曲线积分，其实这些呢都是我们的多元函数的积分学部分」。其中**二重积分的计算**「在我们整个二重积分里面是非常非常重要的，就像定积分的计算在定积分中的作用一样」；**交换积分次序**是「一个非常重要的选填题的考点」；**极坐标系下的二重积分**「甚至比我们的直角坐标系下的二重积分出现的频率都要高，这是一个非常非常非常重要的一个考点」；**普通对称性**「在选择题和填空题，包括大题都有可能出现」，虽然「这并不是一个解题的方法，这算是一个解题的技巧」。

## 一、大白话讲解

### 1. 从一元到二元：从「面积」到「体积」（P98）

| | 一元函数定积分 | 二重积分 |
|:---|:---|:---|
| 分析维度 | 二维平面（$xOy$） | 三维空间 |
| 研究对象 | 平面中的一条曲线 | 空间中的一个面（曲面或平面） |
| 几何意义 | 曲边梯形的**面积** | 曲顶柱体的**体积** |

老师把积分理解成「一个行为，或者说是一个动作」：一元定积分就是把 $[a,b]$ 上无数个红色小长条的面积加起来；二重积分就是把积分区域 $D$ 上无数根「**小薯条**」（小圆柱体）的体积加起来。

**怎么造出小薯条**：在区域 $D$ 上取一小块面积 $\Delta\sigma_k$，在里面任取一点 $(\xi_k,\eta_k)$，把这一小块垂直向上「拉伸」到曲面 $z=f(x,y)$ 上，就得到一个近似的细柱体。它的

- 底面积 = $\Delta\sigma_k$
- 高 = 该点对应的函数值 $f(\xi_k,\eta_k)$
- 体积 = 底 × 高

把所有小薯条的体积累加、再让每块的面积趋于零，就得到整个曲顶柱体的体积。

### 2. 记号怎么读（P98）

$$\iint_D f(x,y)\,d\sigma$$

| 部分 | 名称 | 说明 |
|:---|:---|:---|
| $\iint$ | 二重积分号 | 两个积分号「挨在一起」 |
| $D$ | 积分区域（被积区域） | **一定在 $xOy$ 平面上** |
| $f(x,y)$ | 被积函数 | 二元函数 |
| $d\sigma$ | 面积微元 | 直角坐标系下 $d\sigma = dx\,dy$ |

### 3. 几何意义（P98）

> 顶为曲面 $z=f(x,y)$，底为 $xOy$ 面上的有界闭区域 $D$，二重积分就是它们围成的**曲顶柱体的体积**。

要注意区分两个「$f(x,y)$」：被积函数里的 $f(x,y)$ 是**曲面的表达式**；而某一点代入后算出来的那个值，是**该点对应的高**。

### 4. 直角坐标下的两条路（P99）

计算二重积分的思路只有一句话：**把不熟悉的化成熟悉的**——「我们不熟悉的东西，我们一定要把它转化为我们所熟悉的」。

$$\iint_D f(x,y)\,dx\,dy \;\longrightarrow\; \text{二次积分（两个定积分嵌套）}$$

看积分区域是「横着切」还是「竖着切」，就分成两种类型：

- **X 型**：上下是两条曲线、左右是两条直线（或点）→ 先对 $y$ 积、后对 $x$ 积 → **$dx$ 写在前面**
- **Y 型**：左右是两条曲线、上下是两条直线（或点）→ 先对 $x$ 积、后对 $y$ 积 → **$dy$ 写在前面**

记定限只需一个口诀：**后积先定线，线内划条线，先交写下限，后交写上限**。

### 5. 极坐标是干嘛的（P102）

老师用海面上一艘船找另一艘船来引入：海上没有参照点，建不了直角坐标系，只能说「在 A 的东偏北 $60^\circ$ 方向、$100$ 千米处」——**一个角度 + 一个距离**，就能唯一确定位置。极坐标就是这套思路：

- 固定两个元素：**极点**（原点）和**极轴**（与 $x$ 轴重合）
- 用一个**距离 $r$**（极径）和一个**夹角 $\theta$**（极角）描述点 $P$

$$\boxed{\,x=r\cos\theta,\qquad y=r\sin\theta,\qquad x^2+y^2=r^2\,}$$

这一组公式是「极其重要的转换公式」，老师要求「一定要把它打个三角形，或者打五个五角星」。

### 6. 对称性为什么能省事（P104）

一元函数定积分有「**偶倍奇零**」：奇函数在对称区间上积分为零，偶函数可以只算一半再乘 2。二元函数完全照搬这个思想：

> **关于哪个轴对称，就去判断另外一个变量的奇偶性。**

积分区域关于 $x$ 轴对称 → 判断 $f(x,y)$ 关于 $y$ 的奇偶性；关于 $y$ 轴对称 → 判断关于 $x$ 的奇偶性。是奇函数就直接写 $0$，是偶函数就把区域砍一半再乘 2。老师原话：「如果大家不知道这样一个技巧，还傻傻地把它看作是极坐标系下的二重积分进而进行运算，那么这种题呢就会变得非常的麻烦。」

## 二、考点全爆破

### 1. 二重积分的概念（P98）

$$\iint_D f(x,y)\,d\sigma = \lim_{\lambda\to 0}\sum_{k=1}^{n} f(\xi_k,\eta_k)\,\Delta\sigma_k$$

- $\Delta\sigma_k$：第 $k$ 小块区域的面积；$(\xi_k,\eta_k)$：该小块内任取的一点
- $\lambda$：所有小块直径的最大值，$\lambda\to 0$ 表示每小块都缩到极小
- 被积函数 $f(x,y)$ 给定后不会变，**决定积分结果的只有积分区域 $D$**

### 2. 二重积分的几何意义（P98）

$$\iint_D f(x,y)\,d\sigma = V_{\text{曲顶柱体}}$$

顶为曲面 $z=f(x,y)$，底为 $D$。

### 3. 二重积分的四条性质（P98）

与定积分性质类似：

| 序号 | 性质 | 式子 |
|:---|:---|:---|
| ① | 常数因子可提前 | $\iint_D k\,f\,d\sigma = k\iint_D f\,d\sigma$ |
| ② | 可拆项 | $\iint_D (f\pm g)\,d\sigma = \iint_D f\,d\sigma \pm \iint_D g\,d\sigma$ |
| ③ | 区域可加性 | $D=D_1\cup D_2 \Rightarrow \iint_D = \iint_{D_1} + \iint_{D_2}$ |
| ④ | **对 1 积分 = 面积** | $\iint_D 1\,d\sigma = S_D$（$D$ 的面积） |

性质③要求 $D_1$、$D_2$ **加起来正好是原来的 $D$**，相当于定积分的分段积分。

### 4. 对 1 积分等于区域面积（P98，有考点）

$f(x,y)\equiv 1$ 时，曲面 $z=1$ 是空间中的一个水平面，处处高度为 $1$，所以

$$V = S_D \times 1 = S_D$$

> 老师原话：「对一进行积分，那么最后的积分结果就是被积区域（的）面积。」

### 5. 平面区域的代数表示（P98，复习）

| 情形 | 表示 | 含义 |
|:---|:---|:---|
| 直线上方 | $y \ge kx+b$ | 曲线（直线）的**上方**区域 |
| 直线下方 | $y \le kx+b$ | 曲线（直线）的**下方**区域 |
| 圆内 | $x^2+y^2 \le R^2$ | 圆的**内部**区域（用得最多） |
| 圆外 | $x^2+y^2 \ge R^2$ | 圆的**外部**区域 |

只要把 $y$ 单独放在一边，大于号就是在曲线的上方，小于号就是在下方。

### 6. X 型区域与先 $y$ 后 $x$（P99）

**X 型区域**：上下为两条曲线 $y=y_1(x)$、$y=y_2(x)$，左右为两条直线（或两个点）：

$$D:\quad a\le x\le b,\qquad y_1(x)\le y\le y_2(x)$$

$$\iint_D f(x,y)\,dx\,dy=\int_a^b dx\int_{y_1(x)}^{y_2(x)} f(x,y)\,dy$$

**记忆**：X 型 → **$dx$ 一定写在前面，$dy$ 一定写在后面**。

**定限两步**：

1. **后积先定线**——后积的是外层 $x$，先定它的上下限。这两条线一定是**常数线**（两条竖直线），所以 $x$ 的上下限一定是**常数**：左端点写下限、右端点写上限。
2. **线内划条线**——在区域内部**从下往上**画一条带箭头的线，**先交写下限、后交写上限**：先碰到的曲线 $y_1(x)$ 写在下限，穿出去的曲线 $y_2(x)$ 写在上限。

### 7. Y 型区域与先 $x$ 后 $y$（P99）

**Y 型区域**：左右为两条曲线 $x=x_1(y)$、$x=x_2(y)$，上下为两条直线（或两个点）：

$$D:\quad a\le y\le b,\qquad x_1(y)\le x\le x_2(y)$$

$$\iint_D f(x,y)\,dx\,dy=\int_a^b dy\int_{x_1(y)}^{x_2(y)} f(x,y)\,dx$$

**记忆**：Y 型 → **$dy$ 一定写在前面，$dx$ 一定写在后面**。

**定限**：$y$ 的上下限一定是常数（两条水平线夹住）；再在区域内**从左往右**画带箭头的线，先交写下限、后交写上限。

> **关键细节**：Y 型里左右边界必须是**关于 $x$ 的函数**，所以要把 $y=f(x)$ 反解成 $x=\varphi(y)$。例如 $y=x^2\Rightarrow x=\sqrt{y}$（第一象限内不用加绝对值），$y=x\Rightarrow x=y$，$y=\frac1x\Rightarrow x=\frac1y$。

### 8. 二次积分怎么算（P99）

$$\int_a^b dx\int_{y_1(x)}^{y_2(x)} f(x,y)\,dy$$

1. **从后面往前积**：先算内层 $\int_{y_1(x)}^{y_2(x)} f(x,y)\,dy$，此时**积分变量是 $y$**，把 $x$ **当常数**对待；
2. 内层积出来的结果是一个**关于 $x$ 的函数**，把它「拿回」外层（这就是为什么写成嵌套形式，而不是两个积分相乘）；
3. 外层用牛顿–莱布尼茨公式代入上下限，剩下一个普通的一元定积分。

> 两个积分号看起来像「乘积关系」，其实**不是乘积**，只是把内层移到了后面书写。

### 9. 非初等函数积分与类型选择（P100）

有一类积分**「积不出来」**——它的原函数不能由初等函数表示，称为**非初等函数的积分**，也叫**超越积分**。老师要求「见到就背下来」，主要有：

| 形式 | 说明 |
|:---|:---|
| $\displaystyle\int e^{ax^2}dx$（$a\neq 0$） | 指数上带平方，如 $e^{x^2}$、$e^{-y^2}$ |
| $\displaystyle\int \frac{\sin x}{x}dx$ | 正弦比自变量 |
| $\displaystyle\int \frac{\cos x}{x}dx$ | 余弦比自变量 |
| $\displaystyle\int \sin(x^2)\,dx$ | 正弦里带平方 |
| $\displaystyle\int \cos(x^2)\,dx$ | 余弦里带平方 |

**（字幕只列举了这些，并说「包括不局限于这种」）**

**选择积分类型的判据**：先看非初等积分里**以谁为变量**。

- 若被积函数含 $e^{x^2}$（$x$ 为变量）→ 不能让积分变量是 $x$（那样积不出来）→ 只能让**积分变量是 $y$** → $dy$ 在后 → **只能选 X 型**。
- 若含 $\frac{\sin y}{y}$、$e^{-y^2}$（$y$ 为变量）→ 只能让积分变量是 $x$ → **只能选 Y 型**。

> 老师原话：「这种大家就不要去钻牛角尖了，不要想着他积不出来我就非要把它积出来。」

### 10. 交换积分次序（P101）

**研究对象**：二次积分（类型是明确的，看外层微分即可——$dx$ 在前是 X 型，$dy$ 在前是 Y 型）。

**本质**：把 X 型二次积分改成 Y 型二次积分，或反过来。

**五步流程**：

1. 由上下限写出**四条边界曲线**（外层积分变量 → 两条直线；内层积分变量 → 两条曲线）；
2. 在直角坐标系中画出积分区域 $D$；
3. 判断原来是什么型；
4. 换成另一种型；**如果换型后一个区域表达不出来，就把它横着切一刀，拆成两块分别写**；
5. 用「后积先定线 + 线内划条线，先交写下限、后交写上限」重新定限，最后**把两块加起来**。

> 老师强调：「以前我见到有些同学说，交换积分次序嘛，我把上限换到后面去、下限换到前面来……那肯定不行，这些不能想当然。」

**两条技巧**：

- 对数曲线不好画时用**取指数**：$x=\ln y \iff y=e^{x}$（两边同时取 $e$ 的幂）。
- 含圆的表达式要会反解成「左/右半」或「上/下半」：
  - $(x-1)^2+y^2=1$：上半 $y=\sqrt{2x-x^2}$，下半 $y=-\sqrt{2x-x^2}$；右半 $x=1+\sqrt{1-y^2}$，左半 $x=1-\sqrt{1-y^2}$
  - $x^2+y^2=1$：右半 $x=\sqrt{1-y^2}$，左半 $x=-\sqrt{1-y^2}$

### 11. 极坐标与直角坐标的转化（P102）

$$x=r\cos\theta,\qquad y=r\sin\theta,\qquad x^2+y^2=r^2$$

- $r\ge 0$；$\theta$ 一般取 $0\le\theta\le 2\pi$
- 极轴**下方**的角记作**负角**，例如 $-\frac{\pi}{6}$；若坚持用正角，则写作 $2\pi-\frac{\pi}{6}=\frac{11\pi}{6}$
- 遇到 $x^2+y^2$，**直接令它等于 $r^2$**，这是最常用的化简

### 12. 圆的极坐标方程（P102，必考）

| 直角坐标方程 | 圆心 / 半径 | 极坐标方程 |
|:---|:---|:---|
| $x^2+y^2=a^2$ | 圆心原点，半径 $a$ | $r=a$ |
| $x^2+y^2=2ax$ | 圆心 $(a,0)$，半径 $a$ | $r=2a\cos\theta$ |
| $x^2+y^2=2ay$ | 圆心 $(0,a)$，半径 $a$ | $r=2a\sin\theta$ |

- **等号**：表示圆的**边界曲线**；**小于等于**：表示**圆内区域**。
- $r\le a$ 就是圆内——因为「距离等于常数」的点的集合正是圆。

直线也可以转化，如 $y=x+1$：

$$r\sin\theta=r\cos\theta+1\;\Longrightarrow\; r=\frac{1}{\sin\theta-\cos\theta}$$

但老师说明：「专升本的考题里面其实很少涉及到直线的直角坐标方程转极坐标，**99% 的题型都是考察圆的转化**，一定要重点掌握。」

### 13. 三换：把 $\iint_D f\,dx\,dy$ 变成极坐标形式（P102）

| 换什么 | 怎么换 |
|:---|:---|
| ① 换**积分区域** | $x^2+y^2\le a^2 \;\Rightarrow\; r\le a$ |
| ② 换**被积函数** | $x\to r\cos\theta$，$y\to r\sin\theta$ |
| ③ 换**面积微元** | $dx\,dy \;\Rightarrow\; r\,dr\,d\theta$ |

$$\boxed{\;\iint_D f(x,y)\,dx\,dy=\iint_D f(r\cos\theta,\,r\sin\theta)\;r\,dr\,d\theta\;}$$

> **那个 $r$ 千万不要搞掉！** 老师说这是「固定的写法，没有什么其他的方式」，至于为什么会出现 $r$，字幕中未作推导，只要求记住。

### 14. 极坐标下二次积分的框架与定限（P102）

$$\iint_D f\,d\sigma=\int_{\alpha}^{\beta} d\theta\int_{r_1(\theta)}^{r_2(\theta)} f(r\cos\theta,r\sin\theta)\;r\,dr$$

**框架是唯一固定的**：$d\theta$ 一定在前面，$r\,dr$ 一定在后面（不像 X 型 / Y 型有两种形式）。

**定 $\theta$**：把极轴「钉」在原点，**逆时针旋转**：

- 刚接触积分区域 $D$ 时与极轴的夹角 $\alpha$ → **下限**
- 扫过整个 $D$、即将离开时的夹角 $\beta$ → **上限**
- $\theta$ 的上下限**一定是常数**

**定 $r$**：从极点出发画一条**射线**穿出 $D$：

- 先交到的边界曲线 $r_1(\theta)$ → **下限**
- 后交到的边界曲线 $r_2(\theta)$ → **上限**
- 若射线在**极点处就已经接触**区域，则下限为 $0$

**三种特殊区域**（务必掌握）：

| 情形 | $\theta$ 范围 | $r$ 范围 |
|:---|:---|:---|
| 原点在 $D$ **内部** | $0\to 2\pi$（扫一圈） | $0\to \varphi(\theta)$ |
| $D$ 跨在极轴**两侧** | $-\alpha\to\alpha$（下方角取负） | $0\to \varphi(\theta)$ |
| 原点在 $D$ 的**边界**上 | $\alpha\to\beta$ | $0\to \varphi(\theta)$ |

### 15. 什么时候用极坐标（P102、P103）

两种情况（满足其一就考虑）：

1. **积分区域是圆，或圆的一部分**（半圆、圆环、扇形都算）——遇到最多；
2. **被积函数含 $x^2+y^2$ 或 $\sqrt{x^2+y^2}$**。

### 16. 上下限都是常数时的拆分技巧（P103）

若二次积分的**四个上下限全是常数**，则可以把它拆成**两个定积分相乘**：

$$\int_a^b d\theta\int_{c}^{d} g(\theta)\,h(r)\,r\,dr=\left(\int_a^b g(\theta)\,d\theta\right)\left(\int_c^d h(r)\,r\,dr\right)$$

> 前提是**四个上下限都是常数**；只要有一端含变量（例如 $r$ 的上限是 $2a\cos\theta$），就**不能**这样拆，只能按部就班地积。

### 17. 二重积分的普通对称性（P104）

**情形一：积分区域 $D$ 关于 $x$ 轴对称** → 判断 $f(x,y)$ **关于 $y$** 的奇偶性

$$\iint_D f\,d\sigma=\begin{cases}0, & f(x,y)\ \text{关于 } y \text{ 为奇函数}\\[4pt] 2\iint_{D_1} f\,d\sigma, & f(x,y)\ \text{关于 } y \text{ 为偶函数}\end{cases}$$

其中 $D_1$ 是 $D$ 的**上半部分**。

**情形二：积分区域 $D$ 关于 $y$ 轴对称** → 判断 $f(x,y)$ **关于 $x$** 的奇偶性

$$\iint_D f\,d\sigma=\begin{cases}0, & f(x,y)\ \text{关于 } x \text{ 为奇函数}\\[4pt] 2\iint_{D_1} f\,d\sigma, & f(x,y)\ \text{关于 } x \text{ 为偶函数}\end{cases}$$

其中 $D_1$ 是 $D$ 的**右半部分**（左半部分也行，选一边即可）。

**判断方法**：判断关于 $y$ 的奇偶性时，把 **$x$ 当常数**（可代入具体数，如取 $x=1$ 帮助观察）；判断关于 $x$ 的奇偶性时，把 **$y$ 当常数**。

**奇偶性运算规则**（内偶则偶）：

| 运算 | 结果 |
|:---|:---|
| 奇 + 奇 | 奇 |
| 偶 + 偶 | 偶 |
| 奇 × 奇 | 偶 |
| 奇 × 偶 | 奇 |
| 奇 + 偶 | 非奇非偶 |

> 老师强调：「我们不能说 $f(x,y)$ 它是个奇函数，我们要说 $f(x,y)$ 是一个**关于 $y$ 的**奇函数。只说它是奇函数是没有意义的——二元函数实际上没有奇函数和偶函数这样的说法。」

**常用结论**：若 $f(x,y)$ 中一部分关于某变量为奇、另一部分为偶，可**拆项**，奇的那部分直接写 $0$，只算偶的那部分（再用偶倍性质砍一半）。

### 18. 轮换对称性（P104，了解）

二重积分有两个对称性：**普通对称性**（本视频重点）与**轮换对称性**。专升本考得不多，「主要去学这个普通对称性就可以了」；如果以后要学考研数学，轮换对称性是必学知识点。

## 三、例题精讲

### 例 1（P98）经典选择题：积分区域面积为 2

若 $\iint_D 1\,d\sigma = 2$，下列哪个区域是正确的？

| 选项 | 区域 | 面积 |
|:---|:---|:---|
| A | $\|x\|\le 1,\ \|y\|\le 1$ | $2\times 2 = 4$ |
| B | $\|x\|+\|y\|\le 1$ | $2$ ✔ |
| C | $0\le x\le 1,\ 0\le y\le 2x$ | $1$ |
| D | $x^2+y^2\le 2$ | $2\pi$ |

**B 的推导**：去掉绝对值分四种情况讨论：

- $x\ge 0,\ y\ge 0$：$x+y\le 1 \Rightarrow y\le -x+1$
- $x<0,\ y\ge 0$：$-x+y\le 1 \Rightarrow y\le x+1$
- $x\ge 0,\ y<0$：$x-y\le 1 \Rightarrow y\ge x-1$
- $x<0,\ y<0$：$-x-y\le 1 \Rightarrow y\ge -x-1$

四条直线围成中间的一个**斜放的正方形（菱形）**，顶点到原点距离为 $1$，边长 $\sqrt2$，

$$S=\sqrt2\times\sqrt2=2$$

**答案：B**。老师特别提醒：「$|x|+|y|\le 1$ 这个区域请大家一定要记住，后面还会有用途。」

### 例 2（P99）$\iint_D (2xy+1)\,dx\,dy$

$D$ 由 $y=x$、$x=1$ 与 $x$ 轴围成的三角形。

**第一步永远是画图**——这是一个既可看作 X 型、又可看作 Y 型的三角形。

**方法一（X 型）**：$0\le x\le 1$；从下往上穿线，先交 $x$ 轴（$y=0$）写下限，后交 $y=x$ 写上限：

$$\int_0^1 dx\int_0^{x}(2xy+1)\,dy=\int_0^1 \big[xy^2+y\big]_0^{x}dx=\int_0^1 (x^3+x)\,dx$$

$$=\left[\frac{x^4}{4}+\frac{x^2}{2}\right]_0^1=\frac14+\frac12=\frac34$$

**方法二（Y 型）**：$0\le y\le 1$；从左往右穿线，先交 $y=x$（即 $x=y$）写下限，后交 $x=1$ 写上限：

$$\int_0^1 dy\int_y^{1}(2xy+1)\,dx=\int_0^1\big[x^2y+x\big]_y^1 dy=\int_0^1(1-y^3)\,dy=\left[y-\frac{y^4}{4}\right]_0^1=\frac34$$

两种方法答案一致。

### 例 3（P99）$\iint_D \dfrac{3x}{y^2}\,dx\,dy$

$D$ 由 $xy=1$（即 $y=\frac1x$）、$y=x$、$x=2$ 围成。

**X 型**：$1\le x\le 2$；从下往上穿线，先交 $y=\frac1x$、后交 $y=x$：

$$\int_1^2 dx\int_{1/x}^{x}\frac{3x}{y^2}\,dy=\int_1^2 3x\left[-\frac1y\right]_{1/x}^{x}dx=\int_1^2 (3x^2-3)\,dx=\big[x^3-3x\big]_1^2=2-(-2)=4$$

**Y 型**：需要**横着切一刀拆成两块**（切在 $y=1$，即两曲线的交点高度处）：

- 下半块 $D_1$：$\frac12\le y\le 1$，$\frac1y\le x\le 2$
- 上半块 $D_2$：$1\le y\le 2$，$y\le x\le 2$

两块分别积分再相加，结果同样为 $4$。老师借此说明：「**一个区域既可以看成 X 型，也可以看成 Y 型**，以后根据自己的需要来选取合适的类型。」

### 例 4（P100）$\iint_D e^{x^2}\,dx\,dy$

$D$ 由 $x=1$、$y=0$、$y=x$ 围成的三角形。

**类型判断**：$e^{x^2}$ 以 $x$ 为变量，属于非初等函数积分。若选 Y 型，外层要积 $\int e^{x^2}dx$，**积不出来**；所以**只能选 X 型**。

**X 型**：$0\le x\le 1$，$0\le y\le x$：

$$\int_0^1 dx\int_0^{x} e^{x^2}dy=\int_0^1 e^{x^2}\cdot x\,dx=\frac12\int_0^1 e^{x^2}d(x^2)=\frac12\Big[e^{x^2}\Big]_0^1=\frac12(e-1)$$

### 例 5（P100）$\iint_D \dfrac{\sin y}{y}\,dx\,dy$

$D$ 由 $y=x$、$y=\sqrt{x}$ 围成（$y>0$）。

**类型判断**：$\frac{\sin y}{y}$ 以 $y$ 为变量，非初等积分 → 不能让积分变量是 $y$ → **只能选 Y 型**。

**Y 型**：交点 $(0,0)$、$(1,1)$，故 $0\le y\le 1$；从左往右穿线，先交 $y=\sqrt x$（即 $x=y^2$）写下限，后交 $y=x$（即 $x=y$）写上限：

$$\int_0^1 dy\int_{y^2}^{y}\frac{\sin y}{y}\,dx=\int_0^1\frac{\sin y}{y}(y-y^2)\,dy=\int_0^1(1-y)\sin y\,dy$$

$$=\int_0^1\sin y\,dy-\int_0^1 y\sin y\,dy$$

后一项用**分部积分**（把 $\sin y$ 凑到微分号后）：$\int_0^1 y\sin y\,dy=\big[-y\cos y\big]_0^1+\int_0^1\cos y\,dy=-\cos 1+\sin 1$

所以原式 $=(1-\cos 1)-(-\cos 1+\sin 1)=1-\sin 1$。

### 例 6（P100）$\iint_D x^2e^{-y^2}\,dx\,dy$

$D$ 由 $y=x$、$x=0$、$y=1$ 围成的三角形。

**类型判断**：$e^{-y^2}$ 以 $y$ 为变量，非初等积分 → **只能选 Y 型**。

**Y 型**：$0\le y\le 1$，$0\le x\le y$：

$$\int_0^1 dy\int_0^{y}x^2e^{-y^2}dx=\frac13\int_0^1 y^3e^{-y^2}dy$$

**凑微分 + 分部积分**（令 $t=y^2$，$y^3dy=y^2\cdot y\,dy=\frac12 t\,dt$）：

$$\frac13\int_0^1 y^3e^{-y^2}dy=\frac16\int_0^1 t\,e^{-t}dt=\frac16\Big[-(t+1)e^{-t}\Big]_0^1=\frac16\left(1-\frac{2}{e}\right)$$

> 老师点评此题「考得比较全面」：既要识别非初等函数、选对积分类型，又要会凑微分和分部积分。

### 例 7（P101）交换积分次序：$\displaystyle\int_1^2 dx\int_{1/x}^{x} f(x,y)\,dy$

**四条边界**：$x=1$、$x=2$、$y=\frac1x$、$y=x$。交点：$(1,1)$、$\left(2,\frac12\right)$、$(2,2)$。

原为 **X 型**；换成 **Y 型**时要横着切一刀（切在 $y=1$），拆成两块：

$$\int_1^2 dx\int_{1/x}^{x} f\,dy=\underbrace{\int_{1/2}^{1} dy\int_{1/y}^{2} f\,dx}_{D_1\ (\text{下块})}+\underbrace{\int_1^2 dy\int_{y}^{2} f\,dx}_{D_2\ (\text{上块})}$$

### 例 8（P101）交换积分次序：$\displaystyle\int_0^1 dx\int_{x^2}^{x} f(x,y)\,dy$

**四条边界**：$x=0$、$x=1$、$y=x^2$、$y=x$。交点 $(0,0)$、$(1,1)$。

**Y 型**：$0\le y\le 1$；从左往右穿线，先交 $y=x$（$x=y$）写下限，后交 $y=x^2$（$x=\sqrt y$）写上限：

$$\int_0^1 dy\int_{y}^{\sqrt{y}} f(x,y)\,dx$$

### 例 9（P101）计算 $\displaystyle\int_0^{\pi} dy\int_{\sqrt{y}}^{\sqrt{\pi}}\frac{\sin x^2}{x}\,dx$

**先判断**：内层被积函数 $\frac{\sin x^2}{x}$ 是**非初等函数积分**，直接积积不出来 → 必须先**交换积分次序**。

**四条边界**：$y=0$、$y=\pi$、$x=\sqrt y$（即 $y=x^2$）、$x=\sqrt\pi$。

**换成 X 型**：$0\le x\le\sqrt\pi$；从下往上穿线，先交 $x$ 轴（$y=0$）写下限，后交 $y=x^2$ 写上限：

$$\int_0^{\sqrt\pi}dx\int_0^{x^2}\frac{\sin x^2}{x}\,dy=\int_0^{\sqrt\pi}\frac{\sin x^2}{x}\cdot x^2\,dx=\int_0^{\sqrt\pi}x\sin x^2\,dx$$

$$=\frac12\int_0^{\sqrt\pi}\sin x^2\,d(x^2)=-\frac12\Big[\cos x^2\Big]_0^{\sqrt\pi}=-\frac12(\cos\pi-\cos 0)=1$$

### 例 10（P101）交换积分次序：$\displaystyle\int_1^{e} dy\int_0^{\ln y} f(x,y)\,dx$

**四条边界**：$y=1$、$y=e$、$x=0$、$x=\ln y$。

画 $\ln$ 曲线时用**取指数**：$x=\ln y\iff y=e^x$。

**换成 X 型**：$x$ 的范围 $0\to 1$（$y=e^x$ 与 $y=e$ 交于 $(1,e)$）；从下往上穿线，先交 $y=e^x$ 写下限，后交 $y=e$ 写上限：

$$\int_0^1 dx\int_{e^x}^{e} f(x,y)\,dy$$

### 例 11（P101）真题：计算 $\displaystyle I=\int_0^{1/2}dx\int_x^{2x}e^{y^2}dy+\int_{1/2}^{1}dx\int_x^{1}e^{y^2}dy$

**先判断**：两个积分都是 X 型，$e^{y^2}$ 为非初等积分，直接算不出来 → 先**交换积分次序**（题目没写「交换次序」，要自己看出来）。

**画图**：第一条的边界是 $x=0$、$x=\frac12$、$y=x$、$y=2x$；第二条的边界是 $x=\frac12$、$x=1$、$y=x$、$y=1$。两块拼起来正好是一个 **Y 型区域**。

**换成 Y 型**：$0\le y\le 1$；从左往右穿线，先交 $y=2x$（即 $x=\frac y2$）写下限，后交 $y=x$（即 $x=y$）写上限：

$$I=\int_0^1 dy\int_{y/2}^{y}e^{y^2}dx=\int_0^1 e^{y^2}\left(y-\frac y2\right)dy=\frac12\int_0^1 y\,e^{y^2}dy=\frac14\Big[e^{y^2}\Big]_0^1=\frac14(e-1)$$

### 例 12（P101）交换积分次序：$\displaystyle\int_1^2 dx\int_{\sqrt{2x-x^2}}^{2-x} f(x,y)\,dy$

**四条边界**：$x=1$、$x=2$、$y=\sqrt{2x-x^2}$、$y=2-x$。

**识别圆**：$y=\sqrt{2x-x^2}$ 两边平方并配方：

$$y^2=2x-x^2\;\Longrightarrow\;x^2-2x+1+y^2=1\;\Longrightarrow\;(x-1)^2+y^2=1$$

即圆心 $(1,0)$、半径 $1$ 的**上半圆**；$y=2-x$ 是一条斜向下的直线。

**换成 Y 型**：最高点 $y=1$，最低 $y=0$，故 $0\le y\le 1$；从左往右穿线，先交直线 $y=2-x$（即 $x=2-y$）写下限，后交圆的**右半部分**写上限。

把 $(x-1)^2+y^2=1$ 反解成 $x$ 的表达式：

$$(x-1)^2=1-y^2\;\Longrightarrow\;x-1=\pm\sqrt{1-y^2}\;\Longrightarrow\;x=1\pm\sqrt{1-y^2}$$

取右半（$+$），所以上限为 $1+\sqrt{1-y^2}$：

$$\int_0^1 dy\int_{2-y}^{\,1+\sqrt{1-y^2}} f(x,y)\,dx$$

> 老师总结：涉及圆的交换积分次序题，「**$y$ 的两个表达式代表圆的上下部分，$x$ 的两个表达式代表圆的左右部分**」，掌握这一点就能迎刃而解。

### 例 13（P101）交换积分次序：$\displaystyle\int_{-1}^{1} dx\int_0^{\sqrt{1-x^2}} f(x,y)\,dy$

区域是**单位圆的上半部分**。原为 X 型，换成 Y 型：$0\le y\le 1$；从左往右穿线，先交**左半圆** $x=-\sqrt{1-y^2}$，后交**右半圆** $x=\sqrt{1-y^2}$：

$$\int_0^1 dy\int_{-\sqrt{1-y^2}}^{\ \sqrt{1-y^2}} f(x,y)\,dx$$

### 例 14（P102）$\displaystyle\iint_D e^{-x^2-y^2}\,dx\,dy$

$D$ 为圆 $x^2+y^2=a^2$ 所围区域。

**三换**：被积函数 $e^{-(x^2+y^2)}=e^{-r^2}$；微元 $dx\,dy=r\,dr\,d\theta$；区域 $r\le a$。

**定限**：原点在圆内 → $\theta:0\to 2\pi$；射线从极点出发即接触区域 → $r:0\to a$。

$$\int_0^{2\pi}d\theta\int_0^{a}e^{-r^2}r\,dr=-\frac12\int_0^{2\pi}d\theta\int_0^{a}e^{-r^2}\,d(-r^2)=-\frac12\int_0^{2\pi}\Big[e^{-r^2}\Big]_0^{a}d\theta$$

$$=-\frac12(e^{-a^2}-1)\int_0^{2\pi}d\theta=\frac12(1-e^{-a^2})\cdot 2\pi=\pi\left(1-e^{-a^2}\right)$$

### 例 15（P103）$\displaystyle\iint_D x^2\,d\sigma$

$D:\ 1\le x^2+y^2\le 4$（圆环）。

**三换**：$x^2=r^2\cos^2\theta$，微元 $r\,dr\,d\theta$；区域 $1\le r\le 2$。

$$\int_0^{2\pi}d\theta\int_1^2 r^2\cos^2\theta\cdot r\,dr=\left(\int_0^{2\pi}\cos^2\theta\,d\theta\right)\left(\int_1^2 r^3dr\right)$$

> 四个上下限全是常数 → 可以拆成两个定积分相乘。

$$\int_0^{2\pi}\cos^2\theta\,d\theta=\pi,\qquad \int_1^2 r^3dr=\frac{16-1}{4}=\frac{15}{4}$$

$$\Rightarrow\ \text{原式}=\frac{15\pi}{4}$$

### 例 16（P103）$\displaystyle\iint_D \arctan\frac{y}{x}\,d\sigma$

$D$ 由 $1\le x^2+y^2\le 4$ 与 $y=x$、$y=\sqrt3x$ 在第一象限围成。

**三换**：$\arctan\frac{y}{x}=\arctan\frac{r\sin\theta}{r\cos\theta}=\arctan(\tan\theta)=\theta$（反三角函数里套三角函数，结果就是这个变量本身），微元 $r\,dr\,d\theta$；区域 $1\le r\le 2$。

**定 $\theta$**：$y=x$ 的倾斜角 $\frac{\pi}{4}$（$\tan\theta=1$）为下限；$y=\sqrt3x$ 的倾斜角 $\frac{\pi}{3}$（$\tan\theta=\sqrt3$）为上限。

$$\int_{\pi/4}^{\pi/3}d\theta\int_1^2 \theta\,r\,dr=\left(\int_{\pi/4}^{\pi/3}\theta\,d\theta\right)\left(\int_1^2 r\,dr\right)=\left[\frac{\theta^2}{2}\right]_{\pi/4}^{\pi/3}\cdot\frac32$$

$$=\frac12\left(\frac{\pi^2}{9}-\frac{\pi^2}{16}\right)\cdot\frac32=\frac12\cdot\frac{7\pi^2}{144}\cdot\frac32=\frac{7\pi^2}{192}$$

### 例 17（P103）真题：$\displaystyle\iint_D \ln(1+x^2+y^2)\,d\sigma$

$D:\ x^2+y^2\le 1$ 且 $x\ge 0,\ y\ge 0$（第一象限的 $\frac14$ 圆）。

$$\int_0^{\pi/2}d\theta\int_0^1 \ln(1+r^2)\cdot r\,dr=\frac{\pi}{2}\cdot\frac12\int_0^1\ln(1+r^2)\,d(1+r^2)$$

$$\overset{\text{分部积分}}{=}\frac{\pi}{4}\left\{\Big[(1+r^2)\ln(1+r^2)-(1+r^2)\Big]_0^1\right\}=\frac{\pi}{4}\Big[(2\ln2-2)-(0-1)\Big]=\frac{\pi}{4}(2\ln 2-1)$$

> 凑微分时刻意把 $r^2$ 凑成 $1+r^2$，就是为了配合 $\ln$ 的分部积分。

### 例 18（P103）选择题：极坐标二次积分 → 直角坐标

$$\int_0^{\pi/2}d\theta\int_0^{\cos\theta} f(r\cos\theta,\,r\sin\theta)\,r\,dr$$

**由区域反推**：$\theta\in\left[0,\frac{\pi}{2}\right]$（第一象限），$r\le\cos\theta$。两边同乘 $r$：

$$0\le r^2\le r\cos\theta \;\Longrightarrow\; 0\le x^2+y^2\le x \;\Longrightarrow\; \left(x-\frac12\right)^2+y^2\le\frac14$$

圆心 $\left(\frac12,0\right)$、半径 $\frac12$；配合第一象限，取**上半圆**。

**写成 X 型**：$x$ 从 $0$ 到 $1$；从下往上穿线，先交 $x$ 轴（$y=0$），后交上半圆。

圆方程 $x^2+y^2=x$ 反解：$y=\sqrt{x-x^2}$。

$$\int_0^1 dx\int_0^{\sqrt{x-x^2}} f(x,y)\,dy$$

**答案：D**。

### 例 19（P103）选择题：直角坐标 → 极坐标

$D:\ x^2+y^2\le 2y$，求极坐标下的二次积分。

**识别圆**：$x^2+y^2-2y\le 0 \Rightarrow x^2+(y-1)^2\le 1$，圆心 $(0,1)$、半径 $1$。

**换成极坐标方程**：$r^2\le 2r\sin\theta \Rightarrow r\le 2\sin\theta$。

**定限**：$\theta$ 从 $0$ 扫到 $\pi$（刚好扫半个圆）；$r$ 从 $0$ 到 $2\sin\theta$。

$$\int_0^{\pi}d\theta\int_0^{2\sin\theta} f(r\cos\theta,r\sin\theta)\,r\,dr$$

**答案：C**（D 选项少了一个 $r$，绝对不对）。

### 例 20（P103）真题：$\displaystyle\int_0^1 dx\int_0^{1-x} f(x,y)\,dy$ 化为极坐标

**区域**：$0\le x\le 1$，$0\le y\le 1-x$，即 $x+y\le 1$ 在第一象限的三角形。

**定 $\theta$**：$0\to\frac{\pi}{2}$。**定 $r$**：射线从极点出发即接触区域，下限 $0$；上限是直线 $y=1-x$。

化成极坐标：$r\sin\theta=1-r\cos\theta \Rightarrow r=\dfrac{1}{\sin\theta+\cos\theta}$。

$$\int_0^{\pi/2}d\theta\int_0^{\frac{1}{\sin\theta+\cos\theta}} f(r\cos\theta,r\sin\theta)\,r\,dr$$

> 老师提醒：虽然专升本很少考直线转极坐标，但「有些题他也可能出现那种直线」，要会。

### 例 21（P103）$\displaystyle\iint_D\sqrt{4-x^2-y^2}\,d\sigma$

$D$ 由 $x$ 轴与 $y=\sqrt{2x-x^2}$ 围成（即 $(x-1)^2+y^2\le 1$ 的上半圆，$y\ge 0$）。

**三换 + 定限**：被积函数 $\sqrt{4-r^2}$，微元 $r\,dr\,d\theta$；圆化为 $r=2\cos\theta$，因 $y\ge 0$ 只能取上半圆，$\theta:0\to\frac{\pi}{2}$，$r:0\to 2\cos\theta$。

$$\int_0^{\pi/2}d\theta\int_0^{2\cos\theta}\sqrt{4-r^2}\;r\,dr=-\frac13\int_0^{\pi/2}\Big[(4-r^2)^{3/2}\Big]_0^{2\cos\theta}d\theta=\frac13\int_0^{\pi/2}\Big[8-(4-4\cos^2\theta)^{3/2}\Big]d\theta$$

$$=\frac13\int_0^{\pi/2}\Big[8-8\sin^3\theta\Big]d\theta=\frac83\int_0^{\pi/2}(1-\sin^3\theta)\,d\theta$$

用**点火公式（华里士公式）**：$\int_0^{\pi/2}\sin^3\theta\,d\theta=\frac23$，故

$$=\frac83\left(\frac{\pi}{2}-\frac23\right)=\frac{4\pi}{3}-\frac{16}{9}$$

> 老师一开始把 $\theta$ 取成 $-\frac{\pi}{2}\to\frac{\pi}{2}$（含下半圆），随后自我纠正：因为 $y\ge 0$ 只能取上半圆，$\theta$ 应为 $0\to\frac{\pi}{2}$。他把这当作「一个潜在细节」的反面案例提醒大家。

### 例 23（P103）真题：被积函数中含「二重积分本身」

设 $\iint_D f(x,y)\,dx\,dy$ 为所求，其中 $f(x,y)=x^2+y^2+A$，$D:\ x^2+y^2\le 4$。

**关键**：二重积分的结果是一个**常数**，故令

$$A=\iint_D (x^2+y^2+A)\,dx\,dy$$

**拆项**（用性质②④）：

$$A=\iint_D(x^2+y^2)\,d\sigma+A\iint_D 1\,d\sigma$$

- $\iint_D(x^2+y^2)\,d\sigma=\int_0^{2\pi}d\theta\int_0^2 r^2\cdot r\,dr=2\pi\cdot\frac{16}{4}=8\pi$
- $\iint_D 1\,d\sigma=S_D=\pi\cdot 2^2=4\pi$

所以 $A=8\pi+4\pi A\Rightarrow A(1-4\pi)=8\pi$：

$$A=\frac{8\pi}{1-4\pi}$$

### 例 24（P104）$\displaystyle\iint_D\left(1+xy+x^2y^3\right)d\sigma$

$D$ 为单位圆的**右半圆**（$x\ge 0$）。

**观察对称性**：右半圆关于 $x$ 轴对称 → 判断 $f$ **关于 $y$** 的奇偶性（把 $x$ 当常数）。

- $1$：关于 $y$ 是偶函数（常数）
- $xy$：$x$ 当常数 → 变成「常数 $\times\,y$」，关于 $y$ 为**奇**
- $x^2y^3$：$x^2$ 当常数 → 变成「常数 $\times\,y^3$」，关于 $y$ 为**奇**

奇 + 奇 = 奇，所以后两项在整个 $D$ 上积分为 $0$：

$$I=\iint_D 1\,d\sigma=S_D=\frac12\cdot\pi\cdot 1^2=\frac{\pi}{2}$$

> 老师点评：「如果不知道这样一个技巧，把这一部分再傻傻地代入进行计算，就会让我们的这个积分变得非常的冗长麻烦。」

### 例 25（P104）真题：$\displaystyle\iint_D\left[\frac{1}{1+x^2+y^2}+\frac{xy}{1+x^2+y^2}\right]d\sigma$

$D$ 为单位圆的**右半圆**。

**拆项 + 判奇偶**：关于 $x$ 轴对称 → 判 $y$ 的奇偶性。

- $\dfrac{1}{1+x^2+y^2}$：$x$ 当常数 → 分母是「常数 $+y^2$」，关于 $y$ 为**偶**
- $\dfrac{xy}{1+x^2+y^2}$：分子含 $y$ 的一次、分母偶 → 关于 $y$ 为**奇**

奇的那一项积分为 $0$；偶的那一项用「偶倍」性质砍一半（只留第一象限的 $\frac14$ 圆，记作 $D_1$）：

$$I=2\iint_{D_1}\frac{1}{1+x^2+y^2}\,d\sigma=2\int_0^{\pi/2}d\theta\int_0^1\frac{1}{1+r^2}\cdot r\,dr$$

四个上下限全为常数 → 拆成两个定积分相乘：

$$=2\cdot\frac{\pi}{2}\cdot\frac12\int_0^1\frac{1}{1+r^2}\,d(1+r^2)=2\cdot\frac{\pi}{2}\cdot\frac12\Big[\ln(1+r^2)\Big]_0^1=\frac{\pi}{2}\ln 2$$

> 老师点评：这题「考的比较全面」，把**普通对称性**和**极坐标下的二重积分**揉在一起考，「这就是往后二重积分命题的一个方向——不会单纯去考一个考点」。

### 例 26（P104）真题：$\displaystyle\iint_D\left(xe^{y}+y\right)d\sigma$

$D$ 由 $y=x^2$、$y=4x^2$、$y=1$ 围成。

**观察对称性**：三条曲线围成的区域关于 **$y$ 轴**对称（$x^2$ 与 $4x^2$ 都是偶函数，$y=1$ 是水平线）→ 判断 $f$ **关于 $x$** 的奇偶性（把 $y$ 当常数）。

- $xe^y$：$e^y$ 当常数 → 变成「常数 $\times\,x$」，关于 $x$ 为**奇** → 积分为 $0$
- $y$：$y$ 当常数 → 偶函数

所以

$$I=\iint_D y\,d\sigma=2\iint_{D_1}y\,d\sigma$$

其中 $D_1$ 为右半块：$0\le y\le 1$；由 $y=4x^2\Rightarrow x=\frac{\sqrt y}{2}$、$y=x^2\Rightarrow x=\sqrt y$，故 $\frac{\sqrt y}{2}\le x\le\sqrt y$。

$$I=2\int_0^1 y\left(\sqrt y-\frac{\sqrt y}{2}\right)dy=2\int_0^1 y\cdot\frac{\sqrt y}{2}\,dy=\int_0^1 y^{3/2}dy=\left[\frac25y^{5/2}\right]_0^1=\frac25$$

## 四、易错点警示

| ❌ 易错 | ✅ 正确 |
|:---|:---|
| 把二次积分两个积分号当成乘积关系 | 不是乘积，只是把内层积分「拿到后面」书写，必须逐层代入 |
| X 型 / Y 型里 $dx$、$dy$ 的前后位置写反 | X 型 $dx$ 在前、$dy$ 在后；Y 型 $dy$ 在前、$dx$ 在后 |
| 外层积分的上下限写成含变量的式子 | 后积的（外层）上下限**一定是常数**；只有内层才是曲线表达式 |
| Y 型中左右边界仍写成 $y=f(x)$ | 必须反解成 $x=\varphi(y)$ 再填上限下限 |
| 内层积完后把变量代错位置 | 内层积分变量是 $y$，就把上下限代到 $y$ 里；是 $x$ 就代到 $x$ 里 |
| 拿到题直接硬算，不先看能不能积出来 | 先识别非初等函数积分，再决定选 X 型还是 Y 型 |
| 见到 $e^{x^2}$、$\frac{\sin y}{y}$ 还硬往积不出来的方向做 | 这类积分「积不出来」，要换积分次序或换类型；不要钻牛角尖 |
| 交换积分次序就是把上下限对调 | 必须**先画区域**再换型，必要时拆成两块相加 |
| 极坐标里把 $dx\,dy$ 直接写成 $dr\,d\theta$ | 必须是 $r\,dr\,d\theta$，那个 $r$ **千万不能丢** |
| $\theta$ 的上下限写成含 $r$ 的表达式 | $\theta$ 的上下限一定是常数，$r$ 的上下限才含 $\theta$ |
| 极轴下方的角直接写正角却按小角处理 | 极轴下方取负角（如 $-\frac{\pi}{6}$），或写 $2\pi-\frac{\pi}{6}$ |
| 只要上下限是常数就无脑拆成两个积分相乘 | 必须**四个**上下限全是常数才能拆 |
| 说「$f(x,y)$ 是奇函数」 | 必须说「关于 $x$（或 $y$）的奇函数」；二元函数没有孤立的奇偶性 |
| 判断 $y$ 的奇偶性时没把 $x$ 当常数 | 判 $y$ 的奇偶性就把 $x$ 视为常数，反之亦然 |
| 区域对称却判错了变量 | 关于 $x$ 轴对称判 $y$，关于 $y$ 轴对称判 $x$ |
| 用偶倍性质时忘了乘 2 或砍错半边 | 偶函数：区域取一半（上/右半），前面乘 2 |
| 区域是「半圆」却按整圆取 $\theta:0\to 2\pi$ | 如 $y\ge 0$ 的上半圆应取 $\theta:0\to\frac{\pi}{2}$（圆 $r=2a\cos\theta$ 时） |
| 圆方程转极坐标时漏掉「同乘 $r$」这一步 | $r\le\cos\theta$ 两边同乘 $r$ 才得 $r^2\le r\cos\theta$，进而化成 $x^2+y^2\le x$ |

## 五、小结

| 考点 | 要点 |
|:---|:---|
| 二重积分概念 | $\iint_D f\,d\sigma=\lim\limits_{\lambda\to0}\sum f(\xi_k,\eta_k)\Delta\sigma_k$；$D$ 一定在 $xOy$ 面上 |
| 几何意义 | 曲顶柱体的体积，顶为 $z=f(x,y)$、底为 $D$ |
| 四条性质 | 常数提前、可拆项、区域可加、**对 1 积分 = 面积** |
| 平面区域的表示 | $y\ge kx+b$ 在直线上方；$x^2+y^2\le R^2$ 在圆内 |
| X 型区域 | 上下曲线、左右直线；$a\le x\le b$，$y_1(x)\le y\le y_2(x)$；$dx$ 在前 |
| Y 型区域 | 左右曲线、上下直线；$a\le y\le b$，$x_1(y)\le x\le x_2(y)$；$dy$ 在前 |
| 定限口诀 | **后积先定线，线内划条线，先交写下限，后交写上限** |
| 二次积分计算 | 从后往前积；内层变量之外的字母全当常数；牛顿–莱布尼兹代入 |
| 非初等函数积分 | $e^{ax^2}$、$\frac{\sin x}{x}$、$\frac{\cos x}{x}$、$\sin x^2$、$\cos x^2$；按「以谁为变量」选型 |
| 交换积分次序 | 写四条边界 → 画区域 → 判型 → 换型（必要时拆两块）→ 重新定限相加 |
| 极坐标两要素 | 极点 + 极轴；$r\ge0$，$\theta$ 常取 $0\to2\pi$，下方角取负 |
| 转化公式 | $x=r\cos\theta$，$y=r\sin\theta$，$x^2+y^2=r^2$ |
| 圆的极坐标方程 | $r=a$；$r=2a\cos\theta$；$r=2a\sin\theta$；等号为边界、$\le$ 为圆内 |
| 三换 | 换区域、换被积函数、换微元 $dx\,dy\to r\,dr\,d\theta$（$r$ 不能丢） |
| 极坐标二次积分框架 | $\int_\alpha^\beta d\theta\int_{r_1(\theta)}^{r_2(\theta)}f\,r\,dr$，**唯一固定** |
| 极坐标定限 | $\theta$：极轴逆时针旋转，进 $\alpha$ 出 $\beta$（常数）；$r$：射线穿出，先交下限后交上限 |
| 三种特殊区域 | 原点在内部（$0\to2\pi$）、跨极轴两侧（$-\alpha\to\alpha$）、原点在边界（$\alpha\to\beta$） |
| 极坐标适用类型 | 区域是圆或圆的一部分；被积函数含 $x^2+y^2$ 或 $\sqrt{x^2+y^2}$ |
| 拆分技巧 | 四个上下限全为常数时，可拆成两个定积分相乘 |
| 普通对称性 | 关于 $x$ 轴对称判 $y$，关于 $y$ 轴对称判 $x$；奇 → $0$，偶 → $2\iint_{D_1}$ |
| 奇偶性判断 | 判某变量时另一变量当常数；内偶则偶，奇×奇=偶，奇×偶=奇 |
| 轮换对称性 | 专升本少考，考研必学（了解即可） |
