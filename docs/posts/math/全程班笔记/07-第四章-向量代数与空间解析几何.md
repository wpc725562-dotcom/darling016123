## 一、大白话讲解

### 1. 向量是什么

「既有大小又有方向的一个量，叫做矢量」，又称向量。用一个有向线段表示：起点 $A$、终点 $B$，记作 $\overrightarrow{AB}$；也可以用一个小写字母加箭头 $\vec a$，或者干脆把字母加粗 $\mathbf{a}$。

**关键：坐标怎么求？** 终点坐标减起点坐标。

$$\overrightarrow{AB}=B-A=(x_2-x_1,\ y_2-y_1,\ z_2-z_1)$$

> 好比从家走到学校：位移只跟「从哪出发」和「到哪结束」有关，跟你绕了多少路无关。所以永远是**终点减起点**。

### 2. 模、方向余弦、单位向量——三个「长度类」概念

| 概念 | 大白话 |
|:---|:---|
| 模 $\lvert\vec a\rvert$ | 向量有多长。坐标平方相加再开根号 |
| 方向角 $\alpha,\beta,\gamma$ | 向量与 $x$ 轴、$y$ 轴、$z$ 轴**正方向**的夹角，范围 $[0,\pi]$ |
| 方向余弦 $\cos\alpha,\cos\beta,\cos\gamma$ | 上面三个角的余弦，等于「对应坐标 ÷ 模长」 |
| 单位向量 $\vec e$ | 长度为 1 的向量。把任意向量除以自己的模长，就得到与它同向的单位向量 |

> **方向角不是锐角！** 老师专门提醒：方向角是 $0$ 到 $\pi$，可能大于 $90^\circ$，所以方向余弦**可能是负数**。这一点最容易想当然。

### 3. 点乘和叉乘——本章第一大分水岭

老师原话：「这个非常容易搞混淆」「多听几遍就会了，第一遍呢肯定听起来云里雾里了」。

| | 数量积（点乘）$\vec a\cdot\vec b$ | 向量积（叉乘）$\vec a\times\vec b$ |
|:---|:---|:---|
| 记号 | 中间一个**点** | 中间一个**叉** |
| 怎么算 | 对应坐标相乘再相加 | 摆成三阶行列式算 |
| 结果是 | **一个数** | **一个向量** |
| 几何意义 | $\lvert\vec a\rvert\lvert\vec b\rvert\cos\theta$ | $\lvert\vec a\rvert\lvert\vec b\rvert\sin\theta$，等于两向量张成的平行四边形面积 |
| 方向 | 没有方向 | 垂直于 $\vec a$ 也垂直于 $\vec b$，由**右手螺旋定则**确定 |

> 右手螺旋定则：手掌摊开，四指从 $\vec a$ 的方向握向 $\vec b$ 的方向，**大拇指所指的就是 $\vec c=\vec a\times\vec b$ 的方向**。所以 $\vec b\times\vec a$ 与 $\vec a\times\vec b$ 方向正好相反。

### 4. 平面和直线——「一个点 + 一个向量」就能定死

- **平面**：需要一个平面上的点，和一个**垂直于平面的法向量** $\vec n$。法向量像一根垂直插在桌面上的筷子。
- **直线**：需要一个直线上的点，和一个**平行于直线的方向向量** $\vec s$。方向向量像一支顺着直线摆的笔。

老师特别强调概念归属：「直线没有法向量，平面没有方向向量」——直线只配方向向量，平面只配法向量，别搞串。

### 5. 位置关系：全看向量

老师把整节浓缩成一句话：「所有的位置关系，都是通过判断向量的关系得到的」。

- 两条**直线**的关系 → 看两个**方向向量** $\vec s_1,\vec s_2$
- 两个**平面**的关系 → 看两个**法向量** $\vec n_1,\vec n_2$
- **直线与平面**的关系 → 看**方向向量与法向量**，而且结论是**反着来的**：向量垂直 ⇒ 线面平行；向量平行 ⇒ 线面垂直

> 直线和平面这一条最容易记反。心里默念一遍图：法向量是「垂直插在平面上」的，如果直线的方向向量也和法向量平行（都竖着），那这条直线当然就是垂直扎进平面的。

### 6. 夹角与距离

- 线线、面面夹角 → 用 $\cos\theta$，公式里**分子要加绝对值**（因为夹角取 $[0,\frac{\pi}{2}]$ 的锐角）
- 线面夹角 → 用 $\sin\theta$，分子也要加绝对值

> 为什么线面偏偏用 sin？老师用投影解释：光线从正上方照下来，直线在平面上有个**投影**，直线与它自己投影的夹角才是线面夹角。这个角 = $90^\circ$ 减去「方向向量与法向量的夹角」，所以 $\cos$ 变 $\sin$。

- 点到平面的距离 → 「把这个点代进平面方程，取绝对值；分母放法向量的模长」

## 二、考点全爆破

### 1. 向量的定义与表示

既有大小又有方向的量称为**向量**（矢量）。表示方式三种：$\vec a$、$\mathbf{a}$、$\overrightarrow{AB}$。零向量是模长为 $0$ 的向量，方向任意。

### 2. 向量的坐标表示

$$\overrightarrow{AB}=B-A=(x_2-x_1,\ y_2-y_1,\ z_2-z_1)$$

平面上若 $A(x_1,y_1)$、$B(x_2,y_2)$，则 $\overrightarrow{AB}=(x_2-x_1,\ y_2-y_1)$。

**反向量**：$\overrightarrow{AB}=-\overrightarrow{BA}$。向量前面加负号，方向取反。

### 3. 向量的模

$$\lvert\overrightarrow{AB}\rvert=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}\qquad(\text{平面})$$

$$\lvert\overrightarrow{AB}\rvert=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2+(z_2-z_1)^2}\qquad(\text{空间})$$

记住是「坐标平方相加再开根号」。两边加竖线是**取模**，不是绝对值。

### 4. 方向余弦（高频考点）

设向量 $\overrightarrow{AB}=(x,y,z)$，它与三条坐标轴正向的夹角 $\alpha,\beta,\gamma\in[0,\pi]$ 称为**方向角**，其余弦称为**方向余弦**：

$$\cos\alpha=\frac{x}{\lvert\overrightarrow{AB}\rvert},\qquad \cos\beta=\frac{y}{\lvert\overrightarrow{AB}\rvert},\qquad \cos\gamma=\frac{z}{\lvert\overrightarrow{AB}\rvert}$$

重要恒等式：

$$\cos^2\alpha+\cos^2\beta+\cos^2\gamma=1$$

### 5. 单位向量与向量的单位化

**单位向量**：模长为 $1$ 的向量。判断一个向量是不是单位向量，只要算它的模长是否等于 $1$。

**任意向量单位化**：

$$\vec e=\frac{\vec a}{\lvert\vec a\rvert}=\left(\frac{x}{\lvert\vec a\rvert},\ \frac{y}{\lvert\vec a\rvert},\ \frac{z}{\lvert\vec a\rvert}\right)$$

单位化得到的向量**与原来向量方向相同**（长度变成 $1$）。

### 6. 向量的夹角与相等

把两个非零向量的起点移到一起，它们方向所夹的角 $\theta\in[0,\pi]$ 称为夹角。

| 情形 | 夹角 |
|:---|:---|
| 两向量垂直 | $\theta=\dfrac{\pi}{2}$ |
| 两向量平行且反向 | $\theta=\pi$ |
| 两向量平行且同向 | $\theta=0$ |

**两向量相等**：大小相等 **且** 方向相同（缺一不可）。

### 7. 向量的加减法与数乘

- 加减法：**对应坐标分别相加减**
- 交换律：$\vec a+\vec b=\vec b+\vec a$
- 结合律：$(\vec a+\vec b)+\vec c=\vec a+(\vec b+\vec c)$
- 数乘：$\lambda\vec a=(\lambda x,\ \lambda y,\ \lambda z)$，即用这个数去乘**每一个坐标**

> 老师提醒：「向量里面没有乘，有乘；但是没有除」——向量有加减、有数乘、有点乘、有叉乘，但**没有除法**。

### 8. 数量积（点乘）★

$$\vec a\cdot\vec b=a_xb_x+a_yb_y+a_zb_z=\lvert\vec a\rvert\lvert\vec b\rvert\cos\theta$$

**四个必背结论**：

| 结论 | 内容 |
|:---|:---|
| 结果是数 | 数量积的结果是**一个常数**，不是向量 |
| 自身点乘 | $\vec a\cdot\vec a=\lvert\vec a\rvert^2$（夹角 $0$，$\cos 0=1$） |
| 垂直判定 | $\vec a\perp\vec b\iff\vec a\cdot\vec b=0$ |
| 分配律 | $(\vec a+\vec b)\cdot\vec c=\vec a\cdot\vec c+\vec b\cdot\vec c$ |

**投影**：$\lvert\vec b\rvert\cos\theta$ 称为 $\vec b$ 在 $\vec a$ 上的**投影**。

> 老师用「一束光从上面照下来」解释投影：$\cos\theta=\dfrac{\text{邻边}}{\text{斜边}}=\dfrac{K}{\lvert\vec b\rvert}$，所以 $K=\lvert\vec b\rvert\cos\theta$。

**夹角公式**（由数量积反解）：

$$\cos\theta=\frac{\vec a\cdot\vec b}{\lvert\vec a\rvert\lvert\vec b\rvert}$$

分母是**两个模长相乘**，不是两个绝对值相乘，中间有个点。

### 9. 向量积（叉乘）★

$$\vec a\times\vec b=\begin{vmatrix}\vec i&\vec j&\vec k\\ a_x&a_y&a_z\\ b_x&b_y&b_z\end{vmatrix}$$

**三阶行列式运算法则**：三条主对角线上的元素相乘再相加，减去三条副对角线上的元素相乘再相加。

**模长公式**：

$$\lvert\vec a\times\vec b\rvert=\lvert\vec a\rvert\lvert\vec b\rvert\sin\theta$$

**五个必背结论**：

| 结论 | 内容 |
|:---|:---|
| 结果是向量 | 叉乘的结果是**一个新向量**，不是数 |
| 方向 | $\vec c=\vec a\times\vec b$ **同时垂直于** $\vec a$ 和 $\vec b$（右手螺旋定则） |
| 几何意义 | $\lvert\vec a\times\vec b\rvert$ = 以 $\vec a,\vec b$ 为邻边的**平行四边形面积** |
| 自身叉乘 | $\vec a\times\vec a=\vec 0$ |
| 反交换律 | $\vec b\times\vec a=-\vec a\times\vec b$（交换要加负号） |

垂直特例：若 $\vec a\perp\vec b$，则 $\lvert\vec a\times\vec b\rvert=\lvert\vec a\rvert\lvert\vec b\rvert$（$\sin\frac{\pi}{2}=1$）。

分配律：$(\vec a+\vec b)\times\vec c=\vec a\times\vec c+\vec b\times\vec c$。

混合积：$(\vec a\times\vec b)\cdot\vec c=\vec a\cdot(\vec b\times\vec c)$。

> **重要提醒**：$(A+B)\times(A-B)$ **不能**用平方差公式！因为 $\vec a\times\vec b$ 与 $\vec b\times\vec a$ 不能抵消，展开后是 $-2(\vec a\times\vec b)$，不是 $\vec 0$。

### 10. 向量平行与垂直的判定（全章基石）

| 关系 | 等价条件 |
|:---|:---|
| $\vec a\parallel\vec b$ | $\vec a\times\vec b=\vec 0$，或**对应坐标成比例** $\dfrac{a_x}{b_x}=\dfrac{a_y}{b_y}=\dfrac{a_z}{b_z}$ |
| $\vec a\perp\vec b$ | $\vec a\cdot\vec b=0$，即 $a_xb_x+a_yb_y+a_zb_z=0$ |

老师给垂直这一条「打五角星」：「这个用的比较多……因为我们后面会涉及到很多很多向量的这个关系的判断」。

### 11. 平面的法向量

**法向量** $\vec n=(A,B,C)$：**垂直于平面的非零向量**。

两条性质：

1. 一个平面的法向量有**无数多个**，它们之间互相**平行**；
2. 法向量垂直于平面上的**任意一条直线**（因而垂直于平面内任意一个向量）。

### 12. 平面的点法式方程 ★

设 $\vec n=(A,B,C)$ 为平面法向量，$M_0(x_0,y_0,z_0)$ 为平面上一点，$M(x,y,z)$ 为平面上动点。因为 $\vec n\perp\overrightarrow{M_0M}$，所以 $\vec n\cdot\overrightarrow{M_0M}=0$：

$$A(x-x_0)+B(y-y_0)+C(z-z_0)=0$$

**一个法向量 + 一个点，唯一确定一个平面。**

### 13. 平面的一般式方程 ★

把点法式展开、把常数项合并记作 $D$，得：

$$Ax+By+Cz+D=0$$

**做题时一律化成一般式**。老师原话：「我们一般都要把它化成一般式方程」。

### 14. 一般式方程的特征：缺变量 / 剩变量 ★（选择题高频）

| 情况 | 方程形态 | 结论 |
|:---|:---|:---|
| $A=0$ | $By+Cz+D=0$ | 平面**平行于 $x$ 轴**（或与 $x$ 轴重合） |
| $B=0$ | $Ax+Cz+D=0$ | 平面**平行于 $y$ 轴**（或与 $y$ 轴重合） |
| $C=0$ | $Ax+By+D=0$ | 平面**平行于 $z$ 轴**（或与 $z$ 轴重合） |
| $A=B=0$ | $Cz+D=0$ | 平面**垂直于 $z$ 轴**（即平行于 $xOy$ 面） |
| $A=C=0$ | $By+D=0$ | 平面**垂直于 $y$ 轴**（即平行于 $xOz$ 面） |
| $B=C=0$ | $Ax+D=0$ | 平面**垂直于 $x$ 轴**（即平行于 $yOz$ 面） |

**口诀**：

- **缺**一个变量 → 平面**平行**于对应的轴
- **剩**一个变量 → 平面**垂直**于对应的轴

推导思路（以 $A=0$ 为例）：法向量变成 $(0,B,C)$，而 $x$ 轴方向向量可写作 $(a,0,0)$，两者点乘 $(0,B,C)\cdot(a,0,0)=0$，即法向量垂直于 $x$ 轴，故平面平行于 $x$ 轴。

> 另外记住：$D=0$ 表示平面**过原点**。

### 15. 直线的方向向量

**方向向量** $\vec s=(m,n,p)$：**平行于直线的非零向量**。也有无数多个，互相平行。

老师反复强调概念归属：「直线只有方向向量，是没有法向量的」「直线没有法向量，平面没有方向向量」。

### 16. 直线的点向式方程 ★

设 $\vec s=(m,n,p)$ 为方向向量，$M_0(x_0,y_0,z_0)$ 在直线上。因为 $\overrightarrow{M_0M}\parallel\vec s$，对应坐标成比例：

$$\frac{x-x_0}{m}=\frac{y-y_0}{n}=\frac{z-z_0}{p}$$

- **分母** $(m,n,p)$ = 方向向量
- **分子里被减的数** $(x_0,y_0,z_0)$ = 直线上一个点

### 17. 直线的参数式方程 ★

令点向式的公共比值为参数 $t$：

$$\frac{x-x_0}{m}=\frac{y-y_0}{n}=\frac{z-z_0}{p}=t$$

得

$$x=x_0+mt,\qquad y=y_0+nt,\qquad z=z_0+pt$$

$t$ 前面的系数就是方向向量。

### 18. 直线的一般式方程与方向向量求法 ★

两个平面联立，交线就是直线：

$$\begin{cases}A_1x+B_1y+C_1z+D_1=0\\ A_2x+B_2y+C_2z+D_2=0\end{cases}$$

**方向向量怎么求？** 因为方向向量同时垂直于两个法向量，所以

$$\vec s=\vec n_1\times\vec n_2=\begin{vmatrix}\vec i&\vec j&\vec k\\ A_1&B_1&C_1\\ A_2&B_2&C_2\end{vmatrix}$$

老师指出：「最容易出考题的应该是这一个一般式方程，因为一般式方程需要大家去计算对应的方向向量」。

### 19. 两条直线的位置关系

设两直线方向向量 $\vec s_1=(m_1,n_1,p_1)$，$\vec s_2=(m_2,n_2,p_2)$。

| 向量关系 | 直线关系 |
|:---|:---|
| $\vec s_1\parallel\vec s_2$（$\dfrac{m_1}{m_2}=\dfrac{n_1}{n_2}=\dfrac{p_1}{p_2}$） | 两直线**平行**（或重合） |
| $\vec s_1\perp\vec s_2$（$m_1m_2+n_1n_2+p_1p_2=0$） | 两直线**垂直** |

### 20. 两个平面的位置关系

设两平面法向量 $\vec n_1,\vec n_2$。

| 向量关系 | 平面关系 |
|:---|:---|
| $\vec n_1\parallel\vec n_2$（对应坐标成比例） | 两平面**平行**（或重合） |
| $\vec n_1\perp\vec n_2$（$\vec n_1\cdot\vec n_2=0$） | 两平面**垂直** |

### 21. 直线与平面的位置关系 ★（考得最多，也最容易错）

| 向量关系 | 线面关系 |
|:---|:---|
| $\vec s\perp\vec n$（$\vec s\cdot\vec n=0$） | 直线**平行于**平面，**或直线在平面上** |
| $\vec s\parallel\vec n$（对应坐标成比例） | 直线**垂直于**平面 |

注意是**反着来的**：向量垂直 → 线面平行；向量平行 → 线面垂直。

**平行与在平面上怎么区分？** 在直线上找一个点，代进平面方程：

- 代入**成立** → 直线**在平面上**
- 代入**不成立** → 直线**只是平行于平面**

**怎么找直线上的点？** 令点向式方程的**分子为零**，解出的 $(x_0,y_0,z_0)$ 就是直线上的一个点。

### 22. 求直线 / 平面方程的通法（P85 习题课核心）

老师给出的分析思路只有两步：

> 第一步：根据题干**画出空间图形**——把所求的直线（或平面）与已知平面、已知直线的**位置关系**画清楚，谁与谁平行、谁与谁垂直。
> 第二步：**标出所有向量**，找出向量之间的关系，再用**叉乘**求出需要的那个向量。

常用结论：

| 需要求的向量 | 怎么求 |
|:---|:---|
| 同时垂直于 $\vec a$、$\vec b$ 的向量 | $\vec a\times\vec b$ |
| 过三点 $M_1,M_2,M_3$ 的平面法向量 | $\overrightarrow{M_1M_2}\times\overrightarrow{M_1M_3}$ |
| 由两平面交线给出的直线方向向量 | $\vec n_1\times\vec n_2$ |
| 直线垂直于平面时的方向向量 | 直接取 $\vec s=\vec n$（法向量即方向向量） |

### 23. 两个平面的夹角

$$\cos\theta=\frac{\lvert\vec n_1\cdot\vec n_2\rvert}{\lvert\vec n_1\rvert\lvert\vec n_2\rvert},\qquad \theta\in\left[0,\frac{\pi}{2}\right]$$

分子**必须加绝对值**（夹角取锐角）。

### 24. 两条直线的夹角

$$\cos\theta=\frac{\lvert\vec s_1\cdot\vec s_2\rvert}{\lvert\vec s_1\rvert\lvert\vec s_2\rvert},\qquad \theta\in\left[0,\frac{\pi}{2}\right]$$

同样分子加绝对值。

### 25. 直线与平面的夹角 ★（唯一用 sin 的）

$$\sin\theta=\frac{\lvert\vec s\cdot\vec n\rvert}{\lvert\vec s\rvert\lvert\vec n\rvert},\qquad \theta\in\left[0,\frac{\pi}{2}\right]$$

**记忆口诀**：线线、面面用 $\cos$；线面用 $\sin$。

### 26. 点到平面的距离公式

点 $P(x_0,y_0,z_0)$ 到平面 $Ax+By+Cz+D=0$ 的距离：

$$d=\frac{\lvert Ax_0+By_0+Cz_0+D\rvert}{\sqrt{A^2+B^2+C^2}}$$

**分子**：把点代进平面方程取绝对值；**分母**：法向量的模长。

## 三、例题精讲

### 例 1（P81）求模长与方向余弦

已知空间两点确定向量 $\overrightarrow{M_1M_2}=(1,1,-2)$，求它的模长与方向余弦。

**解**：先求模长

$$\lvert\overrightarrow{M_1M_2}\rvert=\sqrt{1^2+1^2+(-2)^2}=\sqrt{6}$$

再逐个求方向余弦：

$$\cos\alpha=\frac{1}{\sqrt{6}}=\frac{\sqrt{6}}{6},\qquad \cos\beta=\frac{1}{\sqrt{6}}=\frac{\sqrt{6}}{6},\qquad \cos\gamma=\frac{-2}{\sqrt{6}}=-\frac{2}{\sqrt{6}}=-\frac{\sqrt{6}}{3}$$

（$\gamma$ 为钝角，所以方向余弦取负，符合方向角范围 $[0,\pi]$。）

### 例 2（P81）向量的单位化

已知 $\vec a=(1,2,3)$，求与 $\vec a$ 方向相同的单位向量 $\vec e$。

**解**：

$$\lvert\vec a\rvert=\sqrt{1^2+2^2+3^2}=\sqrt{14}$$

$$\vec e=\frac{\vec a}{\lvert\vec a\rvert}=\left(\frac{1}{\sqrt{14}},\ \frac{2}{\sqrt{14}},\ \frac{3}{\sqrt{14}}\right)$$

### 例 3（P81）数量积与夹角

已知两向量满足 $\vec a\cdot\vec b=-9$，$\lvert\vec a\rvert=\sqrt{1^2+1^2+4^2}=\sqrt{18}$，$\lvert\vec b\rvert=3$，求两向量的夹角。

**解**：

$$\cos\theta=\frac{\vec a\cdot\vec b}{\lvert\vec a\rvert\lvert\vec b\rvert}=\frac{-9}{\sqrt{18}\times 3}=\frac{-9}{3\sqrt{2}\times 3}=\frac{-9}{9\sqrt{2}}=-\frac{1}{\sqrt{2}}=-\frac{\sqrt{2}}{2}$$

因为 $\cos\theta$ 为负值，对应第二象限的角：

$$\theta=\pi-\frac{\pi}{4}=\frac{3\pi}{4}$$

> 老师的方法：忘了就**画 $\cos$ 的图像**，看 $- \frac{\sqrt{2}}{2}$ 落在哪里，一眼就能判断夹角是 $\frac{3\pi}{4}$。

### 例 4（P81）向量在向量上的投影

已知 $\lvert\vec a\rvert=\sqrt{6}$，$\lvert\vec b\rvert=5$，$\vec a\cdot\vec b=-5$，求 $\vec a$ 在 $\vec b$ 上的投影。

**解**：

$$\cos\theta=\frac{\vec a\cdot\vec b}{\lvert\vec a\rvert\lvert\vec b\rvert}=\frac{-5}{5\sqrt{6}}=-\frac{1}{\sqrt{6}}=-\frac{\sqrt{6}}{6}$$

投影 $=\lvert\vec a\rvert\cos\theta=\sqrt{6}\times\left(-\frac{\sqrt{6}}{6}\right)=-1$

### 例 5（P81）叉乘的计算

已知 $\vec a=(2,-3,1)$，$\vec b=(1,-1,3)$，求 $\vec a\times\vec b$。

**解**：

$$\vec a\times\vec b=\begin{vmatrix}\vec i&\vec j&\vec k\\ 2&-3&1\\ 1&-1&3\end{vmatrix}$$

$$=(-3\times 3-1\times(-1))\vec i-(2\times 3-1\times 1)\vec j+(2\times(-1)-(-3)\times 1)\vec k$$

$$=(-9+1)\vec i-(6-1)\vec j+(-2+3)\vec k=-8\vec i-5\vec j+\vec k$$

即

$$\vec a\times\vec b=(-8,\ -5,\ 1)$$

（该向量同时垂直于 $\vec a$ 和 $\vec b$，可自行用点乘验证。）

### 例 6（P81）判断两向量的关系

**（1）平行**：若 $\vec a$、$\vec b$ 的对应坐标之比都等于 $-\frac{1}{2}$，即

$$\frac{a_x}{b_x}=\frac{a_y}{b_y}=\frac{a_z}{b_z}=-\frac{1}{2}$$

则 $\vec a\parallel\vec b$。

**（2）垂直**：$\vec a=(1,0,-1)$，$\vec b=(2,3,2)$。

$$\vec a\cdot\vec b=1\times 2+0\times 3+(-1)\times 2=2+0-2=0$$

数量积为 $0$，所以 $\vec a\perp\vec b$。

**（3）夹角**：$\vec a=(1,-1,0)$，$\vec b=(1,0,-1)$。

$$\cos\theta=\frac{1\times 1+(-1)\times 0+0\times(-1)}{\sqrt{1^2+1^2}\times\sqrt{1^2+1^2}}=\frac{1}{\sqrt{2}\times\sqrt{2}}=\frac{1}{2}$$

$$\theta=\frac{\pi}{3}$$

### 例 7（P82）过一点且与已知向量垂直的平面

求过点 $(1,-2,0)$、且与已知向量垂直的平面方程。

**分析**：题目没有直接给法向量，但「与向量垂直」就意味着这个向量**可以被当作法向量**。

**解**：由题意知平面法向量 $\vec n=(A,B,C)$，平面上一点为 $(1,-2,0)$，代入点法式：

$$A(x-1)+B(y+2)+C(z-0)=0$$

展开整理即得平面的一般式方程。（字幕中该例法向量的具体数值前后反复修改，此处只记方法：**点 + 法向量 → 点法式 → 化成一般式**。）

### 例 8（P82）过三点求平面方程

求过三点 $M_1$、$M_2$、$M_3$ 的平面方程，其中 $M_1(1,-1,-2)$。

**解**：三点确定一个平面（「两点确定一条直线，三点确定一个平面」）。

法向量 $\vec n$ 同时垂直于 $\overrightarrow{M_1M_2}$ 和 $\overrightarrow{M_1M_3}$，所以用叉乘求：

$$\vec n=\overrightarrow{M_1M_2}\times\overrightarrow{M_1M_3}=(1,\ 6,\ -8)$$

取 $M_1(1,-1,-2)$ 代入点法式：

$$1\cdot(x-1)+6\cdot(y+1)-8\cdot(z+2)=0$$

化简得

$$x+6y-8z-11=0$$

> 这题在真题中考过，考查点就是：**知不知道三点确定一个平面**，以及**法向量可以用平面内两个向量叉乘得到**。

### 例 9（P82）过 $x$ 轴且过一点的平面

求过 $x$ 轴、且过点 $(2,4,1)$ 的平面方程。

**解**：

1. 过 $x$ 轴 ⇒ 过原点，所以 $D=0$；
2. 过 $x$ 轴 ⇒ 平面平行于 $x$ 轴 ⇒ **缺 $x$ 变量**，方程形如

$$By+Cz=0$$

3. 把点 $(2,4,1)$ 代入，得到 $B$ 与 $C$ 的一个比例关系，回代即得平面方程。

（字幕中该例代入后得到的 $B$、$C$ 关系与点的坐标不自洽，此处只记方法。老师建议把「过 $x$ 轴」换成「过 $y$ 轴」「过 $z$ 轴」自己再练一遍。）

### 例 10（P82）选择题：判断平面的特征

已知平面方程 $x-1=0$，判断下列说法。

**解**：

- 方程中**只剩下一个变量 $x$** ⇒ 平面**垂直于 $x$ 轴**；
- 把原点 $(0,0,0)$ 代入：$0-1=-1\neq 0$ ⇒ **不过原点**。

所以正确选项是「与 $x$ 轴垂直，但不过原点」。

### 例 11（P83）一般式化点向式与参数式

把直线

$$\begin{cases}2x-4y+z=0\\ 3x-y+2z+9=0\end{cases}$$

化为点向式方程和参数式方程。

**解**：

两个平面的法向量为 $\vec n_1=(2,-4,1)$，$\vec n_2=(3,-1,2)$。方向向量

$$\vec s=\vec n_1\times\vec n_2=\begin{vmatrix}\vec i&\vec j&\vec k\\ 2&-4&1\\ 3&-1&2\end{vmatrix}$$

再联立原方程组、令其中一个变量取特殊值（如令 $x=0$），解出 $y$、$z$，即得直线上的一个点 $(x_0,y_0,z_0)$。

有了「一点 + 方向向量」，点向式方程即为

$$\frac{x-x_0}{m}=\frac{y-y_0}{n}=\frac{z-z_0}{p}$$

令公共比值等于 $t$，即得参数式方程

$$x=x_0+mt,\qquad y=y_0+nt,\qquad z=z_0+pt$$

> 字幕中该例的叉乘结果与所求点不自洽（两处数值互相矛盾），故此处只记方法。**核心是这三者之间的互化链条**：一般式 $\xrightarrow{\ \vec s=\vec n_1\times\vec n_2\ }$ 点向式 $\xrightarrow{\ \text{令比值为}t\ }$ 参数式。

### 例 12（P84）判断直线与平面的位置关系（平行不重合）

已知直线与平面的方向向量、法向量满足 $\vec s\cdot\vec n=0$（数量积为零），且在直线上取到一点 $(3,-4,0)$，该点代入平面方程得 $20\neq 3$。

**解**：

- 数量积为 $0$ ⇒ $\vec s\perp\vec n$ ⇒ 直线**平行于平面，或在平面上**；
- 代入检验：$(3,-4,0)$ 不满足平面方程 ⇒ 该点不在平面上；
- 点在直线上却不在平面上 ⇒ **直线只与平面平行，不与平面重合**。

> 这就是「线面平行 vs 线在面上」的标准判别流程：**先算数量积定大方向，再取点代入定细节**。

### 例 13（P84）方向向量与法向量平行 ⇒ 线面垂直

若直线的方向向量 $\vec s$ 与平面的法向量 $\vec n$ 的**对应坐标成比例**（如都等于 $\frac{1}{2}$），则 $\vec s\parallel\vec n$。

**解**：$\vec s\parallel\vec n$ ⇒ **直线垂直于平面**。

> 老师提醒：考试不会把向量设得这么直白，通常会给你乘一个倍数（比如把 $(3,2,7)$ 写成 $(6,4,-14)$ 之类），需要你自己去比一下比例。

### 例 14（P84）直线在平面上

已知直线的方向向量 $\vec s=(3,1,-4)$，平面的法向量 $\vec n=(1,1,1)$。

**解**：

$$\vec s\cdot\vec n=3\times 1+1\times 1+(-4)\times 1=3+1-4=0$$

数量积为 $0$ ⇒ 直线平行于平面或在平面上。再取直线上一点代入平面方程，**代入成立**，故**直线在平面上**。

### 例 15（P85）过一点、与平面平行、又与直线垂直的直线

求过点 $(1,0,-2)$、且与已知平面平行、又与已知直线垂直的直线方程。

**分析（画图 + 找向量关系）**：

- 与平面**平行** ⇒ 所求直线的方向向量 $\vec s$ 与该平面法向量 $\vec n$ **垂直**；
- 与直线**垂直** ⇒ $\vec s$ 与已知直线方向向量 $\vec s_1$ **垂直**。

所以 $\vec s$ 同时垂直于两个已知向量，用叉乘求：

$$\vec s=\vec n\times\vec s_1=(8,\ -4,\ 8)$$

约简后 $\vec s\sim(2,-1,2)$。

**解**：由点 $(1,0,-2)$ 与方向向量 $(2,-1,2)$ 得点向式方程

$$\frac{x-1}{2}=\frac{y}{-1}=\frac{z+2}{2}$$

（字幕中 $\vec s_1$ 的具体数值转写不清，此处以叉乘结果为准。）

### 例 16（P85）过直线且与已知平面垂直的平面

已知平面法向量 $\vec n_1=(1,4,-3)$，已知直线方向向量 $\vec s=(5,2,4)$。求过该直线、且与已知平面垂直的平面方程。

**分析**：

- 所求平面**过这条直线** ⇒ 其法向量 $\vec n\perp\vec s$；
- 所求平面与已知平面**垂直** ⇒ 其法向量 $\vec n\perp\vec n_1$。

所以

$$\vec n=\vec s\times\vec n_1=\begin{vmatrix}\vec i&\vec j&\vec k\\ 5&2&4\\ 1&4&-3\end{vmatrix}=(-22,\ 19,\ 18)$$

**解**：再取直线上一点（令点向式分子为零）得 $(2,-1,2)$，代入点法式：

$$-22(x-2)+19(y+1)+18(z-2)=0$$

化简得

$$22x-19y-18z-27=0$$

### 例 17（P85）求直线与平面的交点坐标

已知直线化为参数式后为

$$x=3t-2,\qquad y=-2t+3,\qquad z=t$$

平面方程为 $x+2y+2z=5$，求交点坐标。

**解**：设 $t=t_0$ 时对应交点，把参数式代入平面方程：

$$(3t_0-2)+2(-2t_0+3)+2t_0=5$$

$$3t_0-2-4t_0+6+2t_0=5$$

$$t_0+4=5\ \Longrightarrow\ t_0=1$$

代回参数式得交点

$$(3\times 1-2,\ -2\times 1+3,\ 1)=(1,\ 1,\ 1)$$

> 方法要点：**求交点先把直线化成参数式，再整体代入平面方程**。直接联立点向式和平面式是算不动的。

### 例 18（P85）求点到平面的垂线方程与垂足

过点 $A(2,-1,3)$ 作平面 $x-2y-2z+11=0$ 的垂线，求垂线方程及垂足坐标。

**解**：

（1）垂线方向向量就是平面的法向量：

$$\vec s=\vec n=(1,-2,-2)$$

垂线方程（点向式）：

$$\frac{x-2}{1}=\frac{y+1}{-2}=\frac{z-3}{-2}$$

（2）化为参数式：$x=t+2,\ y=-2t-1,\ z=-2t+3$。

设 $t=t_0$ 时对应垂足，代入平面方程：

$$(t_0+2)-2(-2t_0-1)-2(-2t_0+3)+11=0$$

$$t_0+2+4t_0+2+4t_0-6+11=0$$

$$9t_0+9=0\ \Longrightarrow\ t_0=-1$$

代回参数式得垂足

$$(1,\ 1,\ 5)$$

### 例 19（P86）求直线与平面的夹角

已知直线由两平面相交给出，方向向量 $\vec s=\vec n_1\times\vec n_2$；平面法向量 $\vec n=(1,1,1)$。

**解**：用线面夹角公式（**正弦**）：

$$\sin\theta=\frac{\lvert\vec s\cdot\vec n\rvert}{\lvert\vec s\rvert\lvert\vec n\rvert}=0$$

所以

$$\theta=0$$

即直线与平面**平行**（也可能在平面上）。

> 老师说得很清楚：夹角为 $0$ 意味着直线的方向向量与平面法向量垂直，也就是 $\vec s\cdot\vec n=0$，「也不一定在平面上，可能和这个平面是平行关系的」。

### 例 20（P86）直线与平面夹角（完整计算）

已知 $\vec s=(2,3,2)$，$\vec n=(1,-1,1)$，求直线与平面的夹角。

**解**：

$$\sin\theta=\frac{\lvert 2\times 1+3\times(-1)+2\times 1\rvert}{\sqrt{2^2+3^2+2^2}\times\sqrt{1^2+1^2+1^2}}=\frac{\lvert 2-3+2\rvert}{\sqrt{17}\times\sqrt{3}}=\frac{1}{\sqrt{51}}$$

$$\theta=\arcsin\frac{1}{\sqrt{51}}$$

（也可写成 $\arcsin\dfrac{\sqrt{51}}{51}$。）

### 例 21（P86）求两平面的夹角

已知 $\vec n_1=(1,-4,1)$，$\vec n_2=(2,-2,-1)$，求两平面的夹角。

**解**：

$$\cos\theta=\frac{\lvert 1\times 2+(-4)\times(-2)+1\times(-1)\rvert}{\sqrt{1^2+(-4)^2+1^2}\times\sqrt{2^2+(-2)^2+(-1)^2}}=\frac{\lvert 2+8-1\rvert}{\sqrt{18}\times 3}=\frac{9}{3\sqrt{18}}$$

把 $\sqrt{18}=\sqrt{9\times 2}=3\sqrt{2}$ 代入：

$$\cos\theta=\frac{9}{3\times 3\sqrt{2}}=\frac{9}{9\sqrt{2}}=\frac{1}{\sqrt{2}}=\frac{\sqrt{2}}{2}$$

$$\theta=\frac{\pi}{4}$$

### 例 22（P86）求两直线的夹角

已知两直线的方向向量 $\vec s_1$、$\vec s_2$，用公式

$$\cos\theta=\frac{\lvert\vec s_1\cdot\vec s_2\rvert}{\lvert\vec s_1\rvert\lvert\vec s_2\rvert}$$

求得 $\cos\theta=\dfrac{\sqrt{2}}{2}$，故

$$\theta=\frac{\pi}{4}$$

（字幕中该例两个方向向量的具体数值转写不清，此处只记方法与结论。）

### 例 23（P86）点到平面的距离

求点 $(1,2,1)$ 到平面 $x+2y+2z-10=0$ 的距离。

**解**：

$$d=\frac{\lvert 1\times 1+2\times 2+2\times 1-10\rvert}{\sqrt{1^2+2^2+2^2}}=\frac{\lvert 1+4+2-10\rvert}{\sqrt{9}}=\frac{\lvert -3\rvert}{3}=1$$

即该点到平面的距离为 $1$。

## 四、易错点警示

| ❌ 易错 | ✅ 正确 |
|:---|:---|
| 求 $\overrightarrow{AB}$ 时用「起点减终点」 | 永远是**终点坐标减起点坐标** $\overrightarrow{AB}=B-A$ |
| 以为方向角是锐角、方向余弦一定为正 | 方向角范围是 $[0,\pi]$，方向余弦**可能为负** |
| 把方向余弦的 $\lvert\overrightarrow{AB}\rvert$ 当成绝对值 | 那是**取模**，两边加竖线表示模长 |
| 把点乘和叉乘的结果混在一起 | 点乘得**数**，叉乘得**向量**；中间是点还是叉，完全不同的运算 |
| 算夹角时把分母的 $\lvert\vec a\rvert\lvert\vec b\rvert$ 当成两个绝对值相乘 | 是**两个模长相乘**，中间有个点 |
| 对 $(A+B)\times(A-B)$ 套平方差公式 | 展开是 $-2(\vec a\times\vec b)$，因为 $\vec b\times\vec a=-\vec a\times\vec b$ **不能抵消** |
| 交换叉乘顺序不加负号 | $\vec b\times\vec a=-\vec a\times\vec b$，方向相反 |
| 求线面夹角时用 $\cos\theta$ | 线线、面面用 $\cos$；**线面必须用 $\sin$** |
| 求两平面 / 两直线夹角时分子不加绝对值 | 夹角取锐角，分子**必须加绝对值** |
| 只算 $\vec s\cdot\vec n=0$ 就断言「直线在平面上」 | 还要**在直线上取一点代入平面方程**检验；成立才在平面上，否则只是平行 |
| 记混「缺变量」和「剩变量」的结论 | **缺**一个变量 → 平行于对应轴；**剩**一个变量 → 垂直于对应轴 |
| 以为直线也有法向量、平面也有方向向量 | 直线只有方向向量，平面只有法向量，概念不通用 |
| 求交点时直接联立点向式与平面方程 | 先把直线**化成参数式**，再整体代入平面方程 |
| 求平面方程只算出法向量就收笔 | 还必须**再找平面上一个点**，法向量 + 一个点才能定平面 |
| 忘了 $D=0$ 的含义 | $D=0$ 表示平面**过原点** |

## 五、小结

| 考点 | 要点 |
|:---|:---|
| 向量的坐标 | 终点减起点；反向量加负号 |
| 向量的模 | 坐标平方相加再开根号（平面、空间同理） |
| 方向余弦 | $\cos\alpha=\dfrac{x}{\lvert\vec a\rvert}$ 等；$\cos^2\alpha+\cos^2\beta+\cos^2\gamma=1$ |
| 单位化 | $\vec e=\dfrac{\vec a}{\lvert\vec a\rvert}$，与原向量同向，模长为 $1$ |
| 数量积（点乘） | $\vec a\cdot\vec b=a_xb_x+a_yb_y+a_zb_z$，结果是**数** |
| 向量积（叉乘） | 三阶行列式，结果是**向量**，垂直于原两向量 |
| 平行判定 | 对应坐标成比例，或叉乘等于零向量 |
| 垂直判定 | 数量积等于零 |
| 向量夹角 | $\cos\theta=\dfrac{\vec a\cdot\vec b}{\lvert\vec a\rvert\lvert\vec b\rvert}$ |
| 平面点法式 | $A(x-x_0)+B(y-y_0)+C(z-z_0)=0$ |
| 平面一般式 | $Ax+By+Cz+D=0$，做题一律化到此式 |
| 一般式特征 | 缺一个变量→平行对应轴；剩一个变量→垂直对应轴；$D=0$→过原点 |
| 直线点向式 | $\dfrac{x-x_0}{m}=\dfrac{y-y_0}{n}=\dfrac{z-z_0}{p}$ |
| 直线参数式 | $x=x_0+mt,\ y=y_0+nt,\ z=z_0+pt$ |
| 直线一般式 | 两平面联立；$\vec s=\vec n_1\times\vec n_2$ |
| 两直线位置关系 | 看 $\vec s_1$ 与 $\vec s_2$：平行 / 垂直 |
| 两平面位置关系 | 看 $\vec n_1$ 与 $\vec n_2$：平行 / 垂直 |
| 线面位置关系 | $\vec s\perp\vec n$ → 平行或在面上；$\vec s\parallel\vec n$ → 垂直 |
| 在面上还是平行 | 取直线上一**点**代入平面方程检验 |
| 两点夹角公式 | $\cos\theta=\dfrac{\lvert\vec n_1\cdot\vec n_2\rvert}{\lvert\vec n_1\rvert\lvert\vec n_2\rvert}$（面面、线线同理） |
| 线面夹角 | $\sin\theta=\dfrac{\lvert\vec s\cdot\vec n\rvert}{\lvert\vec s\rvert\lvert\vec n\rvert}$ |
| 点到平面距离 | $d=\dfrac{\lvert Ax_0+By_0+Cz_0+D\rvert}{\sqrt{A^2+B^2+C^2}}$ |
| 解题总纲 | 画图定位置关系 → 标出向量 → 叉乘求所需向量 |
