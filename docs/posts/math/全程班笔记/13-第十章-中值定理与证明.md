# 第十章 中值定理与证明题

> 来源：陈哥专升本《专升本高等数学全程班》P128–P136
> 本章地位：老师开篇即说，证明专项并不是教科书中单独的一章，「其实在我们整个高等数学的教学体系里面呢，证明专项并非一个单独的章节，大家也可以去翻一下对应的一些高等数学的教科书里面，实际上也没有证明专项这样一个章节」。之所以放在第十章，是因为罗尔定理的辅助函数要用到第三章的一元函数积分学——「如果在讲第二章的时候就给大家讲罗尔定理，那么必然要涉及到第三章的一元函数积分学，但那个时候大家是不是还没有学第三章，所以说罗尔定理给大家讲了之后，大家就会听起来很懵」。老师统计：专升本证明题约十种类型，其中 90% 集中在**单调性、零点定理、罗尔定理、拉格朗日中值定理**四个考点上，「这四个里面比较难的，其实就是这两个，这两个就是罗尔和拉格朗日」。

## 一、大白话讲解

### 1. 证明题到底在干什么

老师给了一个贯穿全章的比喻——**修车**：

> 「比如说你的车坏了，你想要去修车，这个修车的这个行为呢就是对于我们的题，就是想要去证明某个结论……我们要去证明某个结论，是不是要用到一个定理，但是这个定理是不是需要条件的……我们是不是只有找到这个钥匙呀，找到这个钥匙，然后去打开锁，拿出工具，使用工具去修车。」

所以做证明题只有两步：**① 在题干里找出定理成立的条件（= 找钥匙）；② 用定理的结论（= 用工具）**。老师反复强调：「想要去完成证明题的一个关键，我们第一步要干嘛呢，是不是找到定理，然后第二步用定理的一个结论。」

### 2. 五个定理，一句话各自管什么

| 定理 | 一句话 | 用什么信号去认它 |
|:---|:---|:---|
| 单调性 | 移项造函数，导数定增减，端点定正负 | 要比较两个函数大小 / 证不等式 |
| 最值定理 | 闭区间连续必有最大值 $M$、最小值 $m$ | 题干出现「最大值」「最小值」 |
| 介值定理 | $m$ 与 $M$ 之间的任何数都能被取到 | 要证的数夹在 $m$ 与 $M$ 之间 |
| 零点定理 | 两端点异号，中间必有零点 | 证方程有根 / 曲线有交点 |
| 罗尔定理 | 两端点等高，中间必有水平切线 | 要证 $f'(\xi)=0$ 或含 $f'(\xi)$ 的等式 |
| 拉格朗日中值定理 | 弦的斜率 = 某点切线斜率 | 出现「函数相减 ÷ 自变量相减」 |

### 3. 一张图记住罗尔与拉格朗日的关系

罗尔定理要求 $f(a)=f(b)$，此时弦 $AB$ 是水平的，弦斜率 $=0$，于是「切线平行于弦」就退化成「切线水平」。

$$\underbrace{\frac{f(b)-f(a)}{b-a}=f'(\xi)}_{\text{拉格朗日}}\quad\xrightarrow{\;f(a)=f(b)\;}\quad\underbrace{f'(\xi)=0}_{\text{罗尔}}$$

老师原话：「拉格朗日中值定理实际上就是我们罗尔定理的一种推广形式，换句话说，罗尔定理是我们拉格朗日中值定理的一种特殊形式，特殊在哪里呢，特殊在两个端点的函数值相同。」

### 4. 证明专项里必须认得的三个希腊字母

老师专门花时间梳理了希腊字母表，并划重点：

> 「在我们里面重点需要大家去掌握哪几个呢？……掌握的是这个缪 $\mu$，然后是这个 $\xi$，还有一个一塔 $\eta$。大家重点掌握这三个就可以了，因为在我们的整个证明专项里面，这三个是用的比较多的。」

| 字母 | 读音 | 在本章的用途 |
|:---|:---|:---|
| $\xi$ | 克西（字幕转写作「cos / 可赛」） | 中值点，出现频率最高 |
| $\mu$ | 缪 | 介值定理中那个「介于 $m$ 与 $M$ 之间的函数值」 |
| $\eta$ | 伊塔（字幕转写作「一塔」） | 双中值题里的第二个中值点 |

## 二、考点全爆破

### 1. 单调性证不等式（★★★★）

**适用信号**：要证明两个函数在某个范围内的大小关系，例如「当 $x>0$ 时 $x>\ln(1+x)$」。

**标准四步**：

1. **移项造函数**：把不等式右边的项全部移到左边，令 $F(x)=$ 左 $-$ 右。
2. **求导**：算 $F'(x)$，通分、提取公因式，判断它在区间上的符号。
3. **定单调**：$F'(x)>0\Rightarrow F$ 单增；$F'(x)<0\Rightarrow F$ 单减。
4. **取端点值定正负**：算出区间端点的 $F$ 值（端点通常取不到，只作为极限位置的参照）。若 $F$ 单增且 $F(0)=0$，则 $x>0$ 时 $F(x)>F(0)=0$。

> 老师原话：「没有什么证明题比单调性用起来更简单。」

**进阶：一阶导号判不出来时，二次求导。** 若 $F'(x)$ 在区间上符号看不出来，就再求 $F''(x)$，由 $F''$ 的符号定 $F'$ 的单调性，再由 $F'$ 的最小值定 $F'$ 的正负，最后才回到 $F$ 的单调性。链条是：

$$F''>0\;\Rightarrow\;F'\text{ 单增}\;\Rightarrow\;F'>F'_{\min}\;\Rightarrow\;F\text{ 单增}\;\Rightarrow\;F>F_{\min}$$

### 2. 最值定理

设 $f(x)$ 在闭区间 $[a,b]$ 上连续，则 $f$ 在 $[a,b]$ 上必取到最大值 $M$ 与最小值 $m$，且对任意 $x\in[a,b]$：

$$m\le f(x)\le M$$

老师说这是**第一章**的内容（闭区间上连续函数的性质），「可能很多同学搞忘了」。注意：只要题目出现「最大值」「最小值」这两个词，第一反应就是它。

### 3. 介值定理

设 $f(x)$ 在 $[a,b]$ 上连续，$m$、$M$ 分别为最小值与最大值。若

$$m\le \mu\le M$$

则至少存在一点 $\xi\in[a,b]$，使得

$$f(\xi)=\mu$$

老师提示理解方式：「缪相当于是一个函数值，那么既然是函数值的话，那么我们必定可以找到一个对应的 $\xi$，使得 $f(\xi)$ 等于这个缪。」

**与最值定理的配合套路（本章反复出现）**：先用最值定理得到 $m\le f(x_1),f(x_2),\dots\le M$，把若干这样的不等式**左中右分别相加**，再除以项数，就得到一个夹在 $m$ 与 $M$ 之间的数——这个数就是 $\mu$，随后用介值定理。

### 4. 零点定理（★★★★）

设 $f(x)$ 在 $[a,b]$ 上连续，且

$$f(a)\cdot f(b)<0$$

则至少存在一点 $\xi\in(a,b)$，使得 $f(\xi)=0$。

**两个条件**：① 闭区间连续（题干必给）；② 两端点值异号（**唯一需要自己去找的条件**）。

> 老师原话：「连续的这个条件一定是给你的，请大家放心。我们只用干嘛呢，只用在题目去找这个两个端点之一就可以了。这是我们零点定理的唯一的一个点。」

注意结论说的是「**至少**存在一点」——右边那张图里同一区间内可以有三个零点，所以零点定理只能证**存在性**，不能证唯一性。

### 5. 零点定理的三种题型

| 题型 | 题干特征 | 方法 |
|:---|:---|:---|
| 题型一：方程至少有一个根 | 「至少有一个根」「至少有一个交点」 | 移项造 $F(x)$ → 找两端点异号 → 零点定理 |
| 题型二：方程有且仅有一个根 | 「有且仅有一个根」「唯一零点」 | **零点定理证存在性 + 单调性证唯一性** |
| 题型三：等式中含 $f(\xi)$ | 求证 $\exists\,\xi$ 使某等式成立 | 把 $\xi$ 换成 $x$，移项造 $F(x)$，零点定理 |

**题型一的两级翻译**（老师反复强调的基础功）：

$$\text{方程的根}\;\xrightarrow{\text{集中到一边}}\;\text{函数的零点}$$
$$\text{两曲线交点}\;\xrightarrow{\text{联立 }f=g}\;\text{方程的根}\;\xrightarrow{\text{移项}}\;\text{函数的零点}$$

> 老师原话：「其实我们最终都要把它回归到这个零点问题上。」

**题型二的道理**：零点定理只告诉你「有零点」，可能有好几个；要想只有一个，必须让函数**单调**——单增或单减的函数与 $x$ 轴最多交一次。所以存在性用零点定理，唯一性用单调性。

**题型三的战略意义**：老师指出这类题通常是大题的**第一问**，「一般情况下第一个题就要用零点定理……第二问呢，命题老师会设置一个要用罗尔定理去证明的一个等式」。

### 6. 罗尔定理

设 $f(x)$ 满足三个条件：

1. 在闭区间 $[a,b]$ 上连续；
2. 在开区间 $(a,b)$ 内可导；
3. $f(a)=f(b)$。

则至少存在一点 $\xi\in(a,b)$，使得

$$f'(\xi)=0$$

**几何意义**：两端点等高，曲线上至少有一点的切线是水平的（导数 = 切线斜率，斜率 $0$ 即水平）。

**三个条件的性质**——这是本章最关键的一句判断：

> 老师原话：「证明了题目中一二条件是绝对满足的……这两个条件如果不满足，我们是不可能去用罗尔定理，这个命题老师也不可能说出现一个题目，他这个 $f(x)$ 它是不连续的，或者说不可导的。但是条件三满足吗？其实条件三也就是我们这里这个 $f(a)$ 和 $f(b)$，那么这才是我们出题的一个重点。」

于是本章全部功夫都在一件事上：

> 老师原话：「其实我们学这个罗尔定理，其实本质上就是在学如何去找辅助函数。」

老师进一步强调：「所有的题目，99.999% 的题目，是不可能对 $f(x)$ 直接用罗尔定理的。我们后面都会要去找一个辅助函数，让辅助函数的两个端点值相等。」

**做题标准流程（后面所有题型共用）**：

1. 构造辅助函数 $F(x)$（不同题型方法不同）；
2. 写一句「有用的废话」：$F(x)$ 在 $[a,b]$ 连续、在 $(a,b)$ 可导；
   > 老师原话：「这是一句有用的废话……写上这句话呢，能够让这个阅卷老师对你的这个印象分非常的高一点，说不定你后面没有写对，但是他也会给你多加两分。」
3. 验证 $F(a)=F(b)$；
4. 由罗尔定理得 $F'(\xi)=0$，再把 $F'(\xi)=0$ 展开成要证的等式。

### 7. 罗尔定理题型一：根的存在性问题

**题干特征**：证明某方程在区间上至少有一个实根（方程里是 $f$ 或 $f'$ 无所谓，关键是「至少有一个根」）。

**辅助函数构造法（两步）**：

1. **移项**——把方程所有项移到等式左边，令成新函数 $\varphi(x)$；
2. **积分**——对 $\varphi(x)$ 直接积分，得到辅助函数 $F(x)$。

> 老师原话：「辅助函数的构造方法就是对方程移项，全部移到等式的左边……然后对其进行直接积分。就说我们这里呢出现了两个关键词，第一个是移项，第二个关键词是什么，进行积分。」

**为什么积分可行**：因为 $F'(x)=\varphi(x)$，所以 $F'(\xi)=0$ 等价于 $\varphi(\xi)=0$，而 $\varphi(\xi)=0$ 就是原方程。老师点评：「这类题有一个非常明显的特征，就是 $f(x)$ 它是某一个函数的导数。」

**积分不必加 $C$**：老师专门解释了这件事——若加上 $C$，则 $F(a)$ 与 $F(b)$ 都等于 $C$，两个端点值仍然相等，罗尔定理照样能用。

> 老师原话：「这个 $C$ 实际上是没有必要给他写上去的……你加 $C$ 和不加 $C$ 完全没有问题，但是我们习惯上是不加 $C$ 的。」

**出现概率**：老师估计这类题在罗尔定理四种题型里约占 15%–20%。

### 8. 罗尔定理题型二：含 $f'(\xi)$ 与 $f(\xi)$ 相乘的形式（可积分）

**题干特征**：要证的等式中出现 $f'(\xi)$ 与 $f(\xi)$ **相乘**，或 $f'(\xi)$ 加减一个只含 $\xi$ 的式子。

**辅助函数构造法（三步，与题型一完全一致）**：

1. 把 $\xi$ 换成 $x$；
2. 全部移项到等式左边；
3. **直接积分**。

**关键辨析（老师反复警告）**：

| 形式 | 能否直接积分 | 属于 |
|:---|:---|:---|
| $f'(\xi)\cdot f(\xi)$ 与含 $\xi$ 的式子相乘 | ✅ 能 | 题型二 |
| $f'(\xi)\pm f(\xi)$ 加减关系 | ❌ 不能 | 题型三 |

> 老师原话：「如果说被证明的等式中 $f'(\xi)$ 与 $f(\xi)$ 是加减相加减的一个关系，则不能直接进行积分，这种类型是属于第三种的。请大家一定要注意。」

**必背的凑微分**（题型二的核心工具）：

$$\int f(x)f'(x)\,dx=\frac{1}{2}f^2(x)$$

> 老师原话：「凑微分它是一个非常底层的一个方法，也是一个非常强大的一个方法，所以大家一定不要搞忘了，你其他的都可以忘，但是你不能忘这个凑微分。」

**分式先化整式**：若待证式两边是分式，先交叉相乘化成整式再移项积分。老师原话：「我们不可能对这个分式去做证明，我们一定要把它换成整式。」

### 9. 罗尔定理题型三：$f'(\xi)+g(\xi)f(\xi)=0$ 型（加减型）

**题干特征**：$f'(\xi)$ 与 $f(\xi)$ 是**加减**关系（不是相乘），无法直接积分。

**标准形式**：

$$f'(x)+g(x)\,f(x)=0$$

**辅助函数公式（本章最核心的一条）**：

$$\boxed{\;F(x)=e^{\int g(x)\,dx}\cdot f(x)\;}$$

**两条铁律**：

1. **$f'(x)$ 前面的系数必须化为 $1$**——不为 1 时，等式两边同除以该系数。
   > 老师原话：「保证它的系数为一，这是一个非常重要的内容。如果是不唯一的话，一定要把它化成一。」
2. **$g(x)$ 直接积分，写到 $e$ 的指数上；$f(x)$ 直接照写。**

**为什么是这个公式**（老师用一阶线性微分方程推导）：

把标准形式看作一阶**齐次**线性微分方程 $y'+P(x)y=0$，其解为 $y=Ce^{-\int P(x)dx}$。两边同乘 $e^{\int g(x)dx}$ 得

$$\left(e^{\int g(x)dx}f(x)\right)'=0$$

所以括号里那一整块就是辅助函数 $F(x)$，而 $C$ 就是它（$C$ 求导为零，正好对应罗尔定理的 $F'(\xi)=0$）。

> 老师原话：「大家嗯能够理解就理解，理解不了呢，就把这个方法就把这一个结果……或者说公式嘛把它背下来就行了。」

**基础型找辅助函数速查**：

| 标准形式 | $g(x)$ | 辅助函数 $F(x)$ |
|:---|:---|:---|
| $f'+2026f=0$ | $2026$ | $e^{2026x}f(x)$ |
| $f'-\dfrac{1}{1+x}f=0$ | $-\dfrac{1}{1+x}$ | $\dfrac{f(x)}{1+x}$ |
| $f'-\dfrac{1}{x-1}f=0$ | $\dfrac{1}{x-1}$ | $(x-1)f(x)$ |
| $f'+\dfrac{1}{x}f=0$ | $\dfrac{1}{x}$ | $xf(x)$ |
| $f'+xf=0$ | $x$ | $e^{x^2/2}f(x)$ |
| $f'+\tan x\,f=0$ | $\tan x$ | 见第四节存疑说明 |

**进阶形式一：$f$ 是复合函数。** 例如待证式中出现 $f'(\xi)-1+f(\xi)-\xi=0$ 这种「$\xi$ 混在里面」的形状，要**先配出一个复合函数的导数**：

$$f'(x)-1=\big(f(x)-x\big)'$$

于是原式变成

$$\big(f(x)-x\big)'+1\cdot\big(f(x)-x\big)=0$$

此时把方框 $u(x)=f(x)-x$ 当作整体，$g(x)=1$，辅助函数为 $F(x)=e^{x}\big(f(x)-x\big)$。

> 老师原话：「做这种题的一个步骤，就是首先要配出一个这个复合函数的导数，然后去加上 $g(x)$ 去乘以这个复合函数……这一部分是比较有难度的。」

**进阶形式二：$f'(\xi)+g(\xi)f(\xi)=P(\xi)$（非齐次）。** 辅助函数为

$$F(x)=e^{\int g(x)dx}\left[f(x)-\int e^{\int g(x)dx}P(x)\,dx\right]$$

老师指出这是进阶形式一的一般情形，「当 $P(x)=0$ 的时候，就是前面的那种形式」——即齐次型是它的特例。这类题只有浙江、河南、江苏等极个别省份考过。

**进阶形式三：高阶导数型。** 若待证式中 $f$ 出现两阶导数（如 $\xi f''(\xi)+(2\xi+1)f'(\xi)=0$），就把 $f'(x)$ 整体当作新的「$f$」，公式照用。老师原话：「它们的核心一定是一个函数与另外一个函数构成一阶导的一个关系。」

### 10. 罗尔定理题型四：反证法

**题干特征词**（老师点名的两个「特征描述语」）：

- 「**不可能**有三个不同的根」
- 「**至多**有一个零点 / 最多有两个根」

**与前三种题型的根本区别**：前三种证的都是「**至少**存在一点」，而反证法证的是「**至多**」。老师原话：「前面我们所学习的这种证明的题型都是会出现了什么，是不是至少呀……但是在有一些题型里面，它就不可能也不可能有三个不同的根，或者说至多有一个零点。」

**反证法三步**：

1. **否定结论**：把「至多有一个」否定成「有两个」，「不可能有三个」否定成「有三个」，并把否定后的结论**当作已知条件**假设下来；
2. **用已知方法往下推**：通常是构造辅助函数 + 多次罗尔定理，推出一个与题干矛盾的结果；
3. **下结论**：推出的结论与题干矛盾 $\Rightarrow$ 假设错误 $\Rightarrow$ 原结论成立。

> 老师原话：「反证法就是一条路我们走不通，我们走另外一条路，假设一个结论，然后证……这个条件是将这个结论否定掉，那么用假设的这个条件去做证明得到这样一个式子，但是这个得到的这个式和题干相反，进而就说明假设是错误的，假设是错误的，就说明什么，就说明原结论是正确的。」

**多次罗尔定理的标准手法**（本章反复使用）：若有三个零点 $x_0<x_1<x_2$，先在 $[x_0,x_1]$、$[x_1,x_2]$ 各用一次罗尔定理得到两个 $f'$ 的零点，再把 $f'(x)$ **看作一个新函数**，在两点之间用第三次罗尔定理得到 $f''$ 的零点。

### 11. 拉格朗日中值定理

设 $f(x)$ 满足两个条件（**注意只有两个，没有罗尔的第三个条件**）：

1. 在闭区间 $[a,b]$ 上连续；
2. 在开区间 $(a,b)$ 内可导。

则至少存在一点 $\xi\in(a,b)$，使得

$$f(b)-f(a)=f'(\xi)(b-a)$$

或者写成比值形式：

$$f'(\xi)=\frac{f(b)-f(a)}{b-a}$$

**几何意义**：曲线弧 $AB$ 上至少能找到一点，该点处的切线**平行于弦 $AB$**（两者斜率相等，都是 $\dfrac{f(b)-f(a)}{b-a}$）。

> 老师原话：「但凡一个函数它是闭区间连续开区间可导，我们就可以去使用这个拉格朗日中值定理。」

### 12. 拉格朗日题型一：不等式证明（占 60%–70%）

**题干特征**（老师的原话定义）：「有明显的两个函数相减，并且去除以自变量相减，就两个函数相减并且去除以其对应的自变量相减的那种形式呢，我们一般情况下就要考虑用拉氏中值定理。」

典型形状：$\dfrac{\sin b-\sin a}{b-a}$、$\dfrac{\ln b-\ln a}{b-a}$、$\dfrac{e^b-e^a}{b-a}$。

**四步套路**：

1. **配形**：从不等式**中间的那个函数**入手，通过除以 $(b-a)$、拆真数、通分等手段，把它配成 $\dfrac{f(b)-f(a)}{b-a}$；
2. **找自变量范围**：确定两个自变量谁小谁大，得到 $t$ 的区间 $[a,b]$；
3. **令 $F(t)=$ 那个函数**，用拉格朗日中值定理得 $\dfrac{f(b)-f(a)}{b-a}=f'(\xi)$；
4. **由 $\xi\in(a,b)$ 推出 $f'(\xi)$ 的范围**，回代成不等式。

**三个「凭空捏造」的技巧**（老师称之为「没有条件你给他创造条件」）：

- 只有一个 $\ln$ 时，**减去 $\ln 1$**（因为 $\ln 1=0$），把它变成两个对数相减；
- 只有一个 $\arctan$ 时，**减去 $\arctan 0$**（因为 $\arctan 0=0$）；
- 分母只有一个 $x$ 时，**写成 $x-0$**，凑成「自变量相减」。

> 老师原话：「大家可以看到我们的第一种题型，这方法做题的方法都完全一致的好……很多省份大家能够在真题里面看到的，考拉格朗日题型的第一种，一般都用这种方法去做，就没有任何问题的。」

> 老师原话（形容这套流程）：「完形填空……我们真的是把拉格朗日中值定理的这个解题的过程给大家写成了个完形填空，那只要去填对应的这个空就可以了。」

**不等号方向的常识**：不等式两边同乘/同除一个**正数**，不等号不变；同乘/同除**负数**才变号。本章经常要除以 $(b-a)$，因 $b>a$ 故为正数，放心除。

**分母越大反而越小**：要证 $\dfrac{1}{b}<\dfrac{1}{\xi}<\dfrac{1}{a}$（$0<a<\xi<b$），依据就是「分母越大的反而越小」。

### 13. 拉格朗日题型二：条件突破型（无固定形式）

**特点**：老师原话「第二种题型呢可能就比较多变，它没有一个定性的要证明的一个式子」。这类题必须**从题干条件里找突破口**，把区间劈成两段，在两段上各用一次拉格朗日中值定理，再把两个结论取绝对值、放缩、相加。

**两种最常用的突破口**：

| 题干给的条件 | 突破口 |
|:---|:---|
| 「在区间上至少有一个零点」 | 设零点为 $x_0$，$f(x_0)=0$，以 $x_0$ 为分界点劈区间 |
| 「在区间内取到极小值 / 极值」 | 用**费马引理**（极值必要条件）得 $f'(x_0)=0$，以 $x_0$ 为分界点劈区间 |
| 「$f(a)\cdot f(b)<0$」 | 用零点定理先得 $f(x_0)=0$，再劈区间 |

**必须补回的记忆点——费马引理（极值的必要条件）**：

若可导函数 $f(x)$ 在区间内某点 $x_0$ 取得极值，则

$$f'(x_0)=0$$

> 老师原话：「其实很多同学应该是搞忘了这个极值的必要条件，也是费马引理……如果一个可导函数在区间上取得极值，那么这个极值点的导数必定是等于零的。」

**标准四步**：

1. 找突破口，得到分界点 $x_0$；
2. 在 $[a,x_0]$ 与 $[x_0,b]$ 上各用一次拉格朗日中值定理；
3. **两边取绝对值**（因为要证的不等式带绝对值），并把乘积的绝对值拆成绝对值的乘积；
4. 用题干给的 $|f'|\le M$ 或 $|f''|\le M$ 放缩，再把两个不等式相加。

**放缩的两个依据**：

- $|x-x_0|<$ 区间长度（本题区间长度已知）；
- $|f'(\xi)|\le M$ 对区间内**任意** $\xi$ 都成立，所以取 $\xi=\xi_1$ 也成立。

### 14. 拉格朗日题型三：双中值（近几年压轴热点）

**题干特征**：要证的式子里出现**两个中值**（通常记作 $\xi$ 与 $\eta$）。

**核心方法**：把区间**分成两段**，在两段上分别用拉格朗日中值定理，得到两个中值。

> 老师原话：「双中值其实也和我们现在讲的这个题型比较类似，用两次拉格朗日中值定理就可以了。」

**最大的难点——分界点怎么找**。老师给了四种找法：

| 情形 | 分界点的来源 |
|:---|:---|
| 最简单的一类 | 直接取区间**中点**（如 $[0,1]$ 取 $\frac{1}{2}$） |
| 题干有第一问 | 用**第一问求出的那个点** $c$ 作分界点 |
| 题干给了「有最大值 $M$」 | 由最值定理取**最大值点** $x_0$ |
| 题干给了两个端点函数值 | 由最值定理 + 介值定理，先求出**函数值等于某数的点** $c$ |

> 老师原话：「双中值的题型里面比较有难点的一点是什么呢，就是去找这个终点……就是怎么去找一个分界点，我们要去用两次拉格朗日，其实就要去在区间上面去找到一个点。」

**最后一步的两种收尾**：

- 若结论是**相加**（如 $f'(\xi)+f'(\eta)=0$），把两个拉格朗日等式**相加**；
- 若结论是**相乘**（如 $f'(\xi)f'(\eta)=1$），把两个等式**相乘**，或先**取倒数**再相乘。

**一个常用的二次函数最值**（2025 山东题的关键一步）：

$$G(x)=x(1-x)\le G\!\left(\tfrac12\right)=\frac14,\qquad x\in[0,1]$$

由「分母越大反而越小」得

$$\frac{1}{x(1-x)}\ge 4$$

### 15. 构造辅助函数总表（本章精华）

| 待证等式的形状 | 题型 | 辅助函数 $F(x)$ |
|:---|:---|:---|
| 方程（根的存在性） | 罗尔·题型一 | 移项后**直接积分** |
| $f'(\xi)\cdot f(\xi)$ 与含 $\xi$ 式子相乘 | 罗尔·题型二 | 移项后**直接积分**（常用 $\int ff'=\frac12f^2$） |
| $f'(\xi)+g(\xi)f(\xi)=0$ | 罗尔·题型三 | $e^{\int g(x)dx}f(x)$ |
| $\big(f(x)-x\big)'+1\cdot\big(f(x)-x\big)=0$ | 罗尔·题型三进阶 | $e^{x}\big(f(x)-x\big)$ |
| $f'(x)-\lambda f(x)=0$ | 罗尔·题型三进阶 | $e^{-\lambda x}f(x)$ |
| $f''(x)+\left(2+\frac1x\right)f'(x)=0$ | 罗尔·题型三进阶 | $xe^{2x}f'(x)$ |
| 分式（两边都是分式） | 罗尔·题型二 | 先交叉相乘化整式，再积分 |
| $|f'(\xi)|+|f'(\eta)|\ge\cdots$ | 拉格朗日·题型二/三 | 不需辅助函数，劈区间用两次 |

## 三、例题精讲

### P128 单调性

#### 例 1 证明 $x>\ln(1+x)$（$x>0$）

**移项造函数**：令 $F(x)=x-\ln(1+x)$。

**求导**：

$$F'(x)=1-\frac{1}{1+x}=\frac{x}{1+x}$$

当 $x>0$ 时，分子、分母都为正，故 $F'(x)>0$，$F$ 在 $(0,+\infty)$ 上单增。

**取端点值**：

$$F(0)=0-\ln 1=0$$

因 $F$ 单增且 $x>0$，故 $F(x)>F(0)=0$，即 $x-\ln(1+x)>0$，**得证** $x>\ln(1+x)$。

> 老师的讲解要点：「就算我们在这里假设他是取得到的，那么取不到的时候他都等于零了，那么是不是整个 $F(x)$ 是不是大于 $F(0)$ 呀。」

#### 例 2 证明 $(1+x)\ln(1+x)\ge\arctan x$（$x\ge 0$）

**移项造函数**：原式即 $\ln(1+x)\ge\dfrac{\arctan x}{1+x}$（因 $1+x\ge1>0$，可放心乘过去）。令

$$F(x)=(1+x)\ln(1+x)-\arctan x$$

**求导**（乘法法则 + 通分）：

$$F'(x)=\ln(1+x)+1-\frac{1}{1+x^2}=\ln(1+x)+\frac{x^2}{1+x^2}$$

当 $x\ge0$ 时，$\ln(1+x)\ge0$ 且 $\dfrac{x^2}{1+x^2}\ge0$，故 $F'(x)\ge0$，$F$ 单增。

**取端点值**：$F(0)=1\cdot\ln1-\arctan 0=0$。

故 $x\ge0$ 时 $F(x)\ge F(0)=0$，即 $(1+x)\ln(1+x)\ge\arctan x$，**得证**。

#### 例 3 （字幕数值不清，此处只记方法）

老师说明此题「和我们的第一题和第二题是完全一样的」，是往年真题，**课堂上没有展开讲解**，只口头给了辅助函数的导数结果，字幕转写为「根号是 $\ln(1+\sqrt{1+x})$」，数值与形式均无法确认。此处只记方法：**移项造函数 → 求导 → 判单调 → 取端点值**。

#### 例 4 证明 $\dfrac{1-x}{1+x}<e^{-2x}$（$0<x<1$）

**移项造函数**：因 $1+x>1>0$，两边乘 $1+x$ 得 $1-x<(1+x)e^{-2x}$，再移项：

$$F(x)=(1+x)e^{-2x}+x-1>0$$

**一阶导**（乘法法则，提取公因式 $e^{-2x}$）：

$$F'(x)=e^{-2x}+(1+x)(-2)e^{-2x}+1=e^{-2x}(-1-2x)+1$$

$F'(0)=1\cdot(-1)+1=0$。但在 $0<x<1$ 上 $F'(x)$ 的符号**看不出来**——需要二次求导。

**二阶导**：

$$F''(x)=(-2)e^{-2x}(-1-2x)+e^{-2x}(-2)=4xe^{-2x}$$

当 $0<x<1$ 时，$e^{-2x}>0$、$4x>0$，故 $F''(x)>0$，于是 $F'$ 单增。

**链式推理**：

- $F'$ 单增 $\Rightarrow F'(x)>F'(0)=0$（一阶导的最小值为 $0$）；
- $F'>0\Rightarrow F$ 单增；
- $F(0)=(1+0)e^{0}+0-1=0$，故 $F(x)>F(0)=0$。

即 $(1+x)e^{-2x}+x-1>0$，整理得 $(1+x)e^{-2x}>1-x$，两边除以 $1+x$ 即得 $\dfrac{1-x}{1+x}<e^{-2x}$，**得证**。

> 老师对本题的总结：「这个题就比前面的这几个题要稍微难一点，因为他求两次导数，求两次导数之后，我们通过二阶导的正负去判断一阶导单调性，再通过一阶导的一个单调性去判断它大于零小于零，进而去判断原函数的一个单增或单减。」

### P129 最值定理与介值定理

#### 例 5 证明 $\exists\,\xi\in(1,4)$ 使 $f(\xi)=f(4)$

**题设**：$f(x)$ 可导，且 $f(1)+f(2)+f(3)=3f(4)$。

**证明**：

**第一步：可导 $\Rightarrow$ 连续。** 由 $f$ 可导知 $f$ 在 $[1,4]$ 上连续。

**第二步：用最值定理。** 设 $f$ 在 $[1,4]$ 上的最小值为 $m$、最大值为 $M$，则

$$m\le f(1)\le M,\quad m\le f(2)\le M,\quad m\le f(3)\le M$$

**第三步：三式左中右分别相加。** 得

$$3m\le f(1)+f(2)+f(3)\le 3M$$

两边除以 $3$：

$$m\le\frac{f(1)+f(2)+f(3)}{3}\le M$$

**第四步：用介值定理。** 记 $\mu=\dfrac{f(1)+f(2)+f(3)}{3}$，它落在 $m$ 与 $M$ 之间，故由介值定理，存在 $\xi\in(1,4)$ 使

$$f(\xi)=\mu=\frac{f(1)+f(2)+f(3)}{3}=\frac{3f(4)}{3}=f(4)$$

**得证**。

> 老师原话：「这个题呢实际上是还是比较有难度的，因为它结合着这个最值定理和这个介值定理，介值定理都要综合起来去做一定的考察。这个题并不要求大家在最开始拿到它的时候就有一定的思路，但是至少要保证我在给大家讲完之后，大家要能够听得懂。这个题带有些省份它是作为大题去考察过的。」

### P130 零点定理

#### 例 6（题型一·根的存在性）证明 $\sin x+x-1=0$ 在 $\left(0,\dfrac{\pi}{2}\right)$ 上至少有一个根

**移项造函数**：令 $F(x)=\sin x+x-1$，它在 $\left[0,\dfrac{\pi}{2}\right]$ 上连续（初等函数）。

**找两端点异号**：

$$F(0)=\sin 0+0-1=-1<0$$
$$F\!\left(\frac{\pi}{2}\right)=\sin\frac{\pi}{2}+\frac{\pi}{2}-1=1+\frac{\pi}{2}-1=\frac{\pi}{2}>0$$

故 $F(0)\cdot F\!\left(\dfrac{\pi}{2}\right)<0$。

**由零点定理**：至少存在一点 $\xi\in\left(0,\dfrac{\pi}{2}\right)$，使 $F(\xi)=0$，即

$$\sin\xi+\xi-1=0\;\Longrightarrow\;\sin\xi+\xi=1$$

所以方程在 $\left(0,\dfrac{\pi}{2}\right)$ 上至少有一个根，**得证**。

#### 例 7（题型一·曲线交点）证明两曲线至少有一个交点

**题设**：$f(x)$、$g(x)$ 在 $[a,b]$ 上连续，$f(a)>g(a)$，$f(b)<g(b)$。

**翻译**：两曲线交点 $\Leftrightarrow$ $f(x)=g(x)$ 有根 $\Leftrightarrow$ $F(x)=f(x)-g(x)$ 有零点。

**证明**：令 $F(x)=f(x)-g(x)$，它在 $[a,b]$ 上连续。计算端点值：

$$F(a)=f(a)-g(a)>0,\qquad F(b)=f(b)-g(b)<0$$

故 $F(a)\cdot F(b)<0$。由零点定理，存在 $\xi\in(a,b)$ 使 $F(\xi)=0$，即 $f(\xi)=g(\xi)$，**两曲线在 $(a,b)$ 内至少有一个交点**。

> 老师原话：「这就是咱们的这个题……实际上如果你不写的话，实际上要扣分的，就是我们最后一定要把要证明的这句话给它写下来。」

#### 例 8（题型二·唯一性）证明 $x^3-4x^2+1=0$ 在 $(0,1)$ 上有且仅有一个根

**第一步：零点定理证存在性。** 令 $F(x)=x^3-4x^2+1$，在 $[0,1]$ 上连续。

$$F(0)=0-0+1=1>0,\qquad F(1)=1-4+1=-2<0$$

故 $F(0)\cdot F(1)<0$，由零点定理，存在 $\xi\in(0,1)$ 使 $F(\xi)=0$。

**第二步：单调性证唯一性。**

$$F'(x)=3x^2-8x=x(3x-8)$$

当 $x\in(0,1)$ 时，$x>0$ 且 $3x-8<0$，故 $F'(x)<0$，$F$ 在 $(0,1)$ 上**单调递减**。单减函数与 $x$ 轴最多交一次，故零点唯一。

**综上**，$F(x)=x^3-4x^2+1$ 在 $(0,1)$ 上有且仅有一个零点，即原方程在 $(0,1)$ 上有且仅有一个根，**得证**。

> 老师解释为什么必须要单调性：「我们用零点定理只能证明这个方程的根的存在性问题……但是我们想要证明它只有一个根，是不是要用单调性呀。」

#### 例 9（题型二·练习题）函数连续且 $f(x)>0$，证方程有且仅有一个根

**方法**：构造含**变上限积分**的辅助函数，求导得 $f(x)+\dfrac{1}{f(x)}$，由题干 $f(x)>0$ 知该式恒正，故函数单增，再配合零点定理即得唯一性。

> 字幕中该题的具体函数表达式与积分上下限转写不清，**此处只记方法**：存在性用零点定理，唯一性用「求导后由 $f(x)>0$ 判出单增」。

#### 例 10（题型三）证明 $\exists\,\xi\in(0,1)$ 使 $f(\xi)=1-\xi$

**题设**：$f(x)$ 在 $[0,1]$ 上连续，$f(0)=0$，$f(1)=1$。

**移项造函数**（把 $\xi$ 换成 $x$）：令

$$F(x)=f(x)+x-1$$

**找两端点异号**：

$$F(0)=f(0)+0-1=0+0-1=-1<0$$
$$F(1)=f(1)+1-1=1+1-1=1>0$$

故 $F(0)\cdot F(1)<0$。

**由零点定理**：存在 $\xi\in(0,1)$ 使 $F(\xi)=0$，即

$$f(\xi)+\xi-1=0\;\Longrightarrow\;f(\xi)=1-\xi$$

**得证**。

#### 例 11（题型三）含 $f(\xi)$ 与 $f(\xi+\text{半区间})$ 的等式（字幕数值不清，此处只记方法）

> 字幕中该题的**区间（$0\sim2$ 还是 $0\sim1$）与端点函数值被老师当场反复更正**，结论式的表述也含混。此处只记方法：
>
> 令 $F(x)=f(x)-f(x+T)$（$T$ 为半区间长），利用题干给出的「两端点函数值相等」得到 $F$ 在两个端点的值**互为相反数**，再由零点定理得到结论。老师强调这类题「一般情况下第一个题就要用零点定理，用了零点定理，那么后面呢我们就可以第二个小问，可能就用罗尔定理了」。

### P131 罗尔定理（题型一、题型二）

#### 例 12（题型一）证明 $4ax^3+3bx^2+2cx=a+b+c$ 在 $(0,1)$ 上至少有一个实根

**第一步：移项。** 原方程即

$$4ax^3+3bx^2+2cx-a-b-c=0$$

**第二步：直接积分造辅助函数。**

$$F(x)=ax^4+bx^3+cx^2-(a+b+c)x$$

（幂函数逐项积分：$\int4ax^3dx=ax^4$，$\int3bx^2dx=bx^3$，$\int2cx\,dx=cx^2$，$\int(a+b+c)dx=(a+b+c)x$。）

**第三步：验证端点值相等。**

$$F(0)=0$$
$$F(1)=a+b+c-(a+b+c)=0$$

**第四步：罗尔定理。** $F$ 在 $[0,1]$ 连续、$(0,1)$ 可导、$F(0)=F(1)$，故存在 $\xi\in(0,1)$ 使 $F'(\xi)=0$，即

$$4a\xi^3+3b\xi^2+2c\xi-(a+b+c)=0$$

**得证**。

> 老师特别说明为什么不能对原函数直接用罗尔定理：「$F(0)=-a-b-c$，$F(1)=3a+2b+c$，你看一下两个端点的函数值相同吗？不相同，你就不能用罗尔定理。」

#### 例 13（题型一）证明方程 $f'(x)=\dfrac{1}{x}$ 在 $(1,e)$ 上至少有一个实根

**题设**：$f(x)$ 在 $[1,e]$ 上连续、$(1,e)$ 内可导，$f(1)=0$，$f(e)=1$。

**移项并积分**：对 $f'(x)-\dfrac{1}{x}=0$ 两边积分（$\int\dfrac{1}{x}dx=\ln x$，因 $x>0$ 不加绝对值），得辅助函数

$$F(x)=f(x)-\ln x$$

**验证端点值**：

$$F(1)=f(1)-\ln1=0-0=0$$
$$F(e)=f(e)-\ln e=1-1=0$$

**罗尔定理**：存在 $\xi\in(1,e)$ 使 $F'(\xi)=0$，即 $f'(\xi)-\dfrac{1}{\xi}=0$，故 $f'(\xi)=\dfrac{1}{\xi}$，**得证**。

#### 例 14（题型二）证明 $\exists\,\xi\in(0,1)$ 使 $f'(\xi)=2\xi+1$

**题设**：$f(x)$ 在 $[0,1]$ 连续、$(0,1)$ 可导，$f(0)=0$，$f(1)=2$。

**三步法**：① $\xi\to x$；② 移项：$f'(x)-2x-1=0$；③ 直接积分：

$$F(x)=f(x)-x^2-x$$

**验证端点值**：

$$F(0)=f(0)-0-0=0$$
$$F(1)=f(1)-1-1=2-1-1=0$$

**罗尔定理**：存在 $\xi\in(0,1)$ 使 $F'(\xi)=0$，即 $f'(\xi)-2\xi-1=0$，**得证**。

#### 例 15（题型二）证明 $\exists\,\xi\in(0,2)$ 使 $f'(\xi)=\dfrac{\xi}{f(\xi)}$

**题设**：$f(x)$ 在 $[0,2]$ 连续、$(0,2)$ 可导，$f(0)=0$，$f(2)=2$。

**先化整式**（分母带 $f(\xi)$ 不好处理）：两边乘 $f(\xi)$ 得 $f'(\xi)f(\xi)=\xi$，再移项：

$$f'(x)f(x)-x=0$$

**凑微分积分**：

$$F(x)=\frac{1}{2}f^2(x)-\frac{1}{2}x^2$$

（用 $\int f(x)f'(x)dx=\dfrac12f^2(x)$。）

**验证端点值**：

$$F(0)=\frac12f^2(0)-\frac12\cdot0=0$$
$$F(2)=\frac12f^2(2)-\frac12\cdot4=\frac12\cdot4-2=0$$

**罗尔定理**：存在 $\xi\in(0,2)$ 使 $F'(\xi)=0$，即 $f'(\xi)f(\xi)-\xi=0$，两边除以 $f(\xi)$ 得 $f'(\xi)=\dfrac{\xi}{f(\xi)}$，**得证**。

#### 例 16（题型二·分式型，较经典）证明 $\dfrac{f(b)-f(a)}{g(b)-g(a)}=\dfrac{f'(\xi)}{g'(\xi)}$

**题设**：$f(x)$、$g(x)$ 在 $[a,b]$ 上连续、$(a,b)$ 内可导，且 $g(x)\neq0$。

**交叉相乘化整式**：

$$\big(f(b)-f(a)\big)g'(x)-\big(g(b)-g(a)\big)f'(x)=0$$

**移项并积分**（关键：注意到 $\big(f(x)g(x)\big)'=f'(x)g(x)+f(x)g'(x)$，即乘积求导公式）：

$$F(x)=f(x)g(x)-g(b)f(x)-f(a)g(x)$$

**验证端点值**（巧妙之处在于交叉项自动约掉）：

$$F(a)=f(a)g(a)-g(b)f(a)-f(a)g(a)=-g(b)f(a)$$
$$F(b)=f(b)g(b)-g(b)f(b)-f(a)g(b)=-f(a)g(b)$$

两者相等。

**罗尔定理**：存在 $\xi\in(a,b)$ 使 $F'(\xi)=0$，整理即得结论。

#### 例 18（基础型）证明 $\exists\,\xi\in(0,1)$ 使 $(1+\xi)f'(\xi)=f(\xi)$

#### 例 20（基础型·含 $g(x)$ 的复合系数）证明 $2g'(\xi)f(\xi)+g(\xi)f'(\xi)=0$

**题设**：$f(x)$、$g(x)$ 在 $[a,b]$ 连续、$(a,b)$ 内可导，$f(a)=f(b)=0$，$g(x)\neq0$。

$$f'(\xi)+\frac{2g'(\xi)}{g(\xi)}f(\xi)=0$$

**套公式**（用凑微分 $\int\dfrac{2g'}{g}dx=2\ln|g(x)|$）：

$$F(x)=e^{2\ln|g(x)|}f(x)=g^2(x)f(x)$$

**验证端点值**：

$$F(a)=g^2(a)f(a)=0,\qquad F(b)=g^2(b)f(b)=0$$

**罗尔定理**：存在 $\xi\in(a,b)$ 使 $F'(\xi)=0$，即

$$2g(\xi)g'(\xi)f(\xi)+g^2(\xi)f'(\xi)=0$$

#### 例 21（进阶型一·复合函数）证明 $\exists\,\xi\in(0,1)$ 使 $f'(\xi)+f(\xi)-\xi=1$

**题设**：$f(x)$ 在 $[0,1]$ 连续、$(0,1)$ 内可导，$f(0)=0$，$f(1)=1$。

**配出复合函数的导数**（关键一步）：

$$f'(\xi)-1+f(\xi)-\xi=0\;\Longrightarrow\;\big(f(x)-x\big)'+1\cdot\big(f(x)-x\big)=0$$

把方框 $u(x)=f(x)-x$ 视为整体，$g(x)=1$。

**套公式**：

$$F(x)=e^{\int1\,dx}\big(f(x)-x\big)=e^{x}\big(f(x)-x\big)$$

**验证端点值**：

$$F(0)=e^{0}\big(f(0)-0\big)=1\cdot(0-0)=0$$
$$F(1)=e^{1}\big(f(1)-1\big)=e\cdot(1-1)=0$$

**罗尔定理**：存在 $\xi\in(0,1)$ 使 $F'(\xi)=0$，展开并约去 $e^{\xi}>0$ 得

$$\big(f(\xi)-\xi\big)+\big(f'(\xi)-1\big)=0$$

**得证**。

#### 例 22（进阶型一·两问综合）证明 $\exists\,c\in(0,1)$ 使 $f(c)=c$；再证 $\exists\,\xi\in(0,1)$ 使 $f'(\xi)-\lambda\big(f(\xi)-\xi\big)=1$

**题设**：$f(x)$ 在 $[0,1]$ 连续、$(0,1)$ 内可导，$f(0)=f(1)=0$，$f\!\left(\dfrac12\right)=1$，$\lambda$ 为任意实数。

$$F(0)=0-0=0,\quad F\!\left(\frac12\right)=1-\frac12=\frac12>0,\quad F(1)=0-1=-1<0$$

$$\big(f(x)-x\big)'-\lambda\big(f(x)-x\big)=0$$

即 $u(x)=f(x)-x$、$g(x)=-\lambda$，故

$$F(x)=e^{-\lambda x}\big(f(x)-x\big)$$

**验证端点值**（这里要用**第一问的结论**）：

$$F(0)=e^{0}\big(f(0)-0\big)=0$$
$$F(c)=e^{-\lambda c}\big(f(c)-c\big)=e^{-\lambda c}\cdot0=0$$

**罗尔定理**：在 $[0,c]$ 上存在 $\xi\in(0,c)\subset(0,1)$ 使 $F'(\xi)=0$，整理即得待证式。

#### 例 23（进阶型一·考研基础题）证明 $\exists\,\xi\in(0,1)$ 使 $\displaystyle\int_0^{\xi}f(t)\,dt+(\xi-1)f(\xi)=0$

$$u'(x)+\frac{1}{x-1}u(x)=0$$

故 $g(x)=\dfrac{1}{x-1}$。

$$F(x)=e^{\int\frac{1}{x-1}dx}u(x)=e^{\ln(x-1)}u(x)=(x-1)\int_0^x f(t)\,dt$$

**验证端点值**：

$$F(0)=(-1)\cdot0=0,\qquad F(1)=0\cdot\int_0^1f(t)\,dt=0$$

**罗尔定理**：存在 $\xi\in(0,1)$ 使 $F'(\xi)=0$，而

$$F'(x)=\int_0^xf(t)\,dt+(x-1)f(x)$$

故待证式成立，**得证**。

### P133 罗尔定理（题型四·反证法）

#### 例 26 证明在 $(a,b)$ 内至多有一个点 $\xi$ 使 $f(\xi)=0$

**题设**：$f(x)$、$g(x)$ 在 $[a,b]$ 连续、$(a,b)$ 内可导，且 $g'(x)f(x)-f'(x)\neq0$（字幕中该条件的转写较零碎，见第四节）。

**反证法第一步：否定结论。** 「至多有一个零点」的否定是「有两个零点」。假设 $f(x)$ 在 $[a,b]$ 上有两个零点 $x_0$、$x_1$（$x_0<x_1$），即

$$f(x_0)=f(x_1)=0$$

**第二步：构造辅助函数。** 把 $g'(x)f(x)-f'(x)\neq0$ 变形为 $f'(x)-g'(x)f(x)\neq0$，套公式（$g$ 取 $-g'$）：

$$F(x)=e^{-g(x)}f(x)$$

**第三步：验证端点值相等。**

$$F(x_0)=e^{-g(x_0)}f(x_0)=0,\qquad F(x_1)=e^{-g(x_1)}f(x_1)=0$$

**第四步：罗尔定理推出矛盾。** 存在 $\xi\in(x_0,x_1)\subset(a,b)$ 使 $F'(\xi)=0$，而

$$F'(x)=e^{-g(x)}\big[f'(x)-g'(x)f(x)\big]$$

因 $e^{-g(x)}>0$，故 $f'(\xi)-g'(\xi)f(\xi)=0$，即 $g'(\xi)f(\xi)-f'(\xi)=0$——**与题干「不等于零」矛盾**。

**结论**：假设错误，故在 $(a,b)$ 内至多有一个点使 $f(\xi)=0$，**得证**。

#### 例 27 证明方程 $e^x+x^2-ax-b=0$ 不可能有三个不同的根

**反证法第一步**：假设方程有三个不同的根 $x_0<x_1<x_2$。令 $F(x)=e^x+x^2-ax-b$，则

$$F(x_0)=F(x_1)=F(x_2)=0$$

**第二步：两次罗尔定理得两个 $F'$ 的零点。**

- 在 $[x_0,x_1]$ 上：存在 $\xi_1\in(x_0,x_1)$ 使 $F'(\xi_1)=0$；
- 在 $[x_1,x_2]$ 上：存在 $\xi_2\in(x_1,x_2)$ 使 $F'(\xi_2)=0$。

**第三步：把 $F'(x)$ 看作新函数，再用一次罗尔定理。** $F'(\xi_1)=F'(\xi_2)=0$，在 $[\xi_1,\xi_2]$ 上用罗尔定理，存在 $\xi\in(\xi_1,\xi_2)$ 使 $F''(\xi)=0$。

**第四步：算出 $F''$ 与题干矛盾。**

$$F'(x)=e^x+2x-a,\qquad F''(x)=e^x+2$$

由于 $e^x>0$，故 $F''(x)=e^x+2>2>0$ 恒成立，**不可能等于零**——与第三步的结论矛盾。

**结论**：假设错误，故方程不可能有三个不同的根，**得证**。

#### 例 28 证明：若 $f''(x)<0$，则方程 $f(x)=0$ 在 $[a,b]$ 上最多有两个根

**反证法**：假设 $f(x)=0$ 有三个根 $x_0<x_1<x_2$，则 $f(x_0)=f(x_1)=f(x_2)=0$。

两次罗尔定理得 $\xi_1\in(x_0,x_1)$、$\xi_2\in(x_1,x_2)$ 使 $f'(\xi_1)=f'(\xi_2)=0$；再把 $f'(x)$ 看作函数，在 $[\xi_1,\xi_2]$ 上用罗尔定理，得 $\xi$ 使

$$f''(\xi)=0$$

这与题干 $f''(x)<0$（恒负，不可能为零）**矛盾**，故假设错误，方程在 $[a,b]$ 上最多有两个根。

#### 例 29（2021 年河南真题·练习）证明至多有一个零点

**方法**：与例 26 完全一致——假设有两个零点，构造辅助函数，用罗尔定理推出与题干矛盾。

> 老师原话：「这个题呢和我们的前面的这些题相比，其实还是更简单一些，因为它至多有两个零点，你就可以假设……他让你证明的是至多有一个零点，你是不是可以假设有两个零点嘛，这个方法呢和前面是完全一致的。」

### P134 拉格朗日中值定理（一）·不等式证明

#### 例 30 证明 $\dfrac{b-a}{b}<\ln\dfrac{b}{a}<\dfrac{b-a}{a}$（$0<a<b$）

**第一步：配形。** 中间是 $\ln\dfrac{b}{a}=\ln b-\ln a$（对数商公式）。两边同除以正数 $b-a$：

$$\frac{1}{b}<\frac{\ln b-\ln a}{b-a}<\frac{1}{a}$$

此时中间已是「两个函数相减 ÷ 自变量相减」的标准形。

**第二步：令函数并定区间。**

$$F(t)=\ln t,\qquad t\in[a,b]$$

**第三步：用拉格朗日中值定理。** $F(t)=\ln t$ 在 $[a,b]$ 上连续、$(a,b)$ 内可导，故存在 $\xi\in(a,b)$ 使

$$\frac{\ln b-\ln a}{b-a}=F'(\xi)=\frac{1}{\xi}$$

**第四步：由 $\xi$ 的范围推不等式。** 因 $a<\xi<b$，由「分母越大反而越小」得

$$\frac{1}{b}<\frac{1}{\xi}<\frac{1}{a}$$

回代即得 $\dfrac{1}{b}<\dfrac{\ln b-\ln a}{b-a}<\dfrac{1}{a}$，两边同乘正数 $b-a$：

$$\frac{b-a}{b}<\ln\frac{b}{a}<\frac{b-a}{a}$$

**得证**。

#### 例 31 证明 $\dfrac{1}{1+x}<\ln\dfrac{1+x}{x}<\dfrac{1}{x}$（$x>0$）

**第一步：配形。** $\ln\dfrac{1+x}{x}=\ln(1+x)-\ln x$，把不等式写成

$$\frac{1}{1+x}<\frac{\ln(1+x)-\ln x}{(1+x)-x}<\frac{1}{x}$$

（分母「凭空捏造」成 $(1+x)-x$，恰好等于 $1$。）

**第二步：令函数。** 注意这里真正的自变量是 $t$，而 $x$ 只是参数（老师专门强调的易混点）：

$$F(t)=\ln t,\qquad t\in[x,x+1]$$

**第三步：拉格朗日中值定理。** 存在 $\xi\in(x,x+1)$ 使

$$\frac{\ln(1+x)-\ln x}{1}=\frac{1}{\xi}$$

**第四步：由 $x<\xi<x+1$ 得** $\dfrac{1}{x+1}<\dfrac{1}{\xi}<\dfrac{1}{x}$，即得待证不等式，**得证**。

> 老师原话（关于自变量与参数的区别）：「以前我们的一个定式思维，就是 $X$ 一定要被当做自变量的，在这里呢我们实际上把这个自变量给它念成 $T$，这里面的这个 $X$ 呢可以被当做一个常数去对待，就是参数……而不能当做函数的自变量。」

#### 例 32 证明 $\dfrac{x}{1+x}<\ln(1+x)<x$（$x>0$）

**配形**：只有一个 $\ln$，**凭空减去 $\ln 1$**（因 $\ln1=0$）：

$$\ln(1+x)=\ln(1+x)-\ln 1$$

分母配成 $(1+x)-1=x$，故中间写成 $\dfrac{\ln(1+x)-\ln 1}{(1+x)-1}$。

**令** $F(t)=\ln t$，$t\in[1,1+x]$。由拉格朗日中值定理，存在 $\xi\in(1,1+x)$ 使

$$\frac{\ln(1+x)-\ln 1}{x}=\frac{1}{\xi}$$

由 $1<\xi<1+x$ 得 $\dfrac{1}{1+x}<\dfrac{1}{\xi}<1$，两边乘正数 $x$：

$$\frac{x}{1+x}<\ln(1+x)<x$$

**得证**。

#### 例 33 证明 $\dfrac{x}{1+x^2}<\arctan x<x$（$x>0$）

**配形**：只有一个 $\arctan$，**凭空减去 $\arctan 0$**（因 $\arctan 0=0$）：

$$\arctan x=\arctan x-\arctan 0$$

分母配成 $x-0$。不等式两边同除以 $x>0$：

$$\frac{1}{1+x^2}<\frac{\arctan x-\arctan 0}{x-0}<1$$

**令** $F(t)=\arctan t$，$t\in[0,x]$。$F'(t)=\dfrac{1}{1+t^2}$，由拉格朗日中值定理，存在 $\xi\in(0,x)$ 使

$$\frac{\arctan x-\arctan 0}{x-0}=\frac{1}{1+\xi^2}$$

**由 $0<\xi<x$ 推范围**（这一步老师用了「先平方、再加一、再取倒数」三步）：

$$0<\xi<x\;\Rightarrow\;0<\xi^2<x^2\;\Rightarrow\;1<1+\xi^2<1+x^2\;\Rightarrow\;\frac{1}{1+x^2}<\frac{1}{1+\xi^2}<1$$

回代得 $\dfrac{1}{1+x^2}<\dfrac{\arctan x}{x}<1$，两边乘 $x$：

$$\frac{x}{1+x^2}<\arctan x<x$$

**得证**。

#### 例 34 证明 $na^{n-1}(b-a)<b^n-a^n<nb^{n-1}(b-a)$（$0<a<b$，$n>1$）

**配形**：不等式左中右同除以正数 $b-a$：

$$na^{n-1}<\frac{b^n-a^n}{b-a}<nb^{n-1}$$

**令** $F(x)=x^n$，$x\in[a,b]$。$F'(x)=nx^{n-1}$，由拉格朗日中值定理，存在 $\xi\in(a,b)$ 使

$$\frac{b^n-a^n}{b-a}=n\xi^{n-1}$$

**由 $a<\xi<b$ 及 $n>1$ 推范围**（$y=x^{n-1}$ 在 $x>0$ 上单增，且乘正数 $n$ 不变号）：

$$na^{n-1}<n\xi^{n-1}<nb^{n-1}$$

回代并两边乘 $(b-a)$ 即得，**得证**。

#### 例 35（练习）证明含 $\ln^2$ 的不等式

**方法**：与例 34 同构——令 $F(x)=\ln^2x$（注意是**平方**，别搞错），把 $b-a$ 除到中间，凑成「两个函数相减 ÷ 自变量相减」，再用拉格朗日中值定理。

> 老师原话：「这个题和前面几个题呢都完全一致的……这几个题都是完全一致的。」

### P135 拉格朗日中值定理（二）·条件突破型

#### 例 36 证明 $|f(0)|+|f(2)|\le 2M$

**题设**：$f(x)$ 在 $[0,2]$ 上可导，$|f'(x)|\le M$（$M$ 为常数，即 $f'$ 有界），且 $f$ 在 $[0,2]$ 上至少有一个零点。

**第一步：把零点用起来。** 设零点为 $x_0\in[0,2]$，即

$$f(x_0)=0$$

**第二步：在两个子区间上各用一次拉格朗日中值定理。**

在 $[0,x_0]$ 上：存在 $\xi_1\in(0,x_0)$ 使 $f(x_0)-f(0)=f'(\xi_1)(x_0-0)$，因 $f(x_0)=0$ 得

$$-f(0)=x_0f'(\xi_1)$$

在 $[x_0,2]$ 上：存在 $\xi_2\in(x_0,2)$ 使 $f(2)-f(x_0)=f'(\xi_2)(2-x_0)$，即

$$f(2)=(2-x_0)f'(\xi_2)$$

**第三步：两边取绝对值，并把乘积的绝对值拆开。**

$$|f(0)|=|x_0|\cdot|f'(\xi_1)|=x_0|f'(\xi_1)|\le Mx_0$$
$$|f(2)|=|2-x_0|\cdot|f'(\xi_2)|=(2-x_0)|f'(\xi_2)|\le M(2-x_0)$$

（因 $x_0\in[0,2]$，故 $x_0\ge0$、$2-x_0\ge0$，可直接去掉绝对值。）

**第四步：两式相加。**

$$|f(0)|+|f(2)|\le Mx_0+M(2-x_0)=2M$$

**得证**。

> 老师点评：「这个题呢不可谓没有难度……如果说你没有学过这一种方法，实际上绝大部分同学拿到这个题是没有一点思路的。」

#### 例 37 证明 $|f'(a)|+|f'(b)|\le M(b-a)$

**题设**：$f(x)$ 在 $[a,b]$ 上可导，$|f''(x)|\le M$，且 $f$ 在 $(a,b)$ 内取到极小值。

**第一步：用费马引理找突破口。** 因 $f$ 可导且在 $(a,b)$ 内取到极小值，由极值必要条件，存在极小值点 $x_0\in(a,b)$ 使

$$f'(x_0)=0$$

**第二步：对 $f'(x)$ 这个函数在两个子区间上用拉格朗日中值定理。**

在 $[a,x_0]$ 上：存在 $\xi_1\in(a,x_0)$ 使 $f'(x_0)-f'(a)=f''(\xi_1)(x_0-a)$，即

$$-f'(a)=f''(\xi_1)(x_0-a)$$

在 $[x_0,b]$ 上：存在 $\xi_2\in(x_0,b)$ 使 $f'(b)-f'(x_0)=f''(\xi_2)(b-x_0)$，即

$$f'(b)=f''(\xi_2)(b-x_0)$$

**第三步：取绝对值、放缩、相加。**

$$|f'(a)|=|f''(\xi_1)|(x_0-a)\le M(x_0-a)$$
$$|f'(b)|=|f''(\xi_2)|(b-x_0)\le M(b-x_0)$$

相加：

$$|f'(a)|+|f'(b)|\le M(x_0-a)+M(b-x_0)=M(b-a)$$

**得证**。

> 老师强调本题最大的难点：「这个题其实最大的一个难点，实际上应该是第一步，其实很多同学应该是搞忘了这个极值的必要条件，也是费马引理。」

#### 例 38 证明 $|f(x)|\le M$ 对任意 $x\in[0,1]$ 成立

**题设**：$f(x)$ 在 $[0,1]$ 上可导，$|f'(x)|\le M$，且 $f(0)\cdot f(1)<0$。

**第一步：零点定理找一个基准点。** 由 $f(0)\cdot f(1)<0$ 及 $f$ 连续，存在 $x_0\in(0,1)$ 使

$$f(x_0)=0$$

**第二步：对任意点 $x\in[0,1]$ 与 $x_0$ 之间用拉格朗日中值定理。** 存在 $\xi$ 介于 $x_0$ 与 $x$ 之间，使

$$f(x)-f(x_0)=f'(\xi)(x-x_0)\;\Longrightarrow\;f(x)=f'(\xi)(x-x_0)$$

**第三步：取绝对值。**

$$|f(x)|=|f'(\xi)|\cdot|x-x_0|$$

**第四步：两次放缩。**

- 第一次放缩：$x$ 与 $x_0$ 都在长度为 $1$ 的区间 $[0,1]$ 内，故 $|x-x_0|<1$；
- 第二次放缩：由题干 $|f'(\xi)|\le M$。

于是

$$|f(x)|\le M\cdot|x-x_0|<M\cdot1=M$$

**得证**。

> 老师原话：「这一点其实很多同学是想不到的，想不到的……我们一定要在区间上面去找到一个这样的 $X$ 点。」

#### 例 39 证明 $\exists\,\xi\in(1,4)$ 使 $f''(\xi)=0$

**题设**：$f(x)$ 在 $[1,4]$ 上二阶可导，且 $3f(2)=2f(1)+f(4)$。

**第一步：把已知等式拆成两个「相减 ÷ 自变量相减」的形式。**

由 $3f(2)=2f(1)+f(4)$ 得 $2f(2)-2f(1)=f(4)-f(2)$，两边除以 $2$：

$$f(2)-f(1)=\frac{f(4)-f(2)}{2}$$

左边写成 $\dfrac{f(2)-f(1)}{2-1}$，右边写成 $\dfrac{f(4)-f(2)}{4-2}$，于是

$$\frac{f(2)-f(1)}{2-1}=\frac{f(4)-f(2)}{4-2}$$

**第二步：在两个子区间上各用一次拉格朗日中值定理。**

在 $[1,2]$ 上：存在 $\xi_1\in(1,2)$ 使 $\dfrac{f(2)-f(1)}{2-1}=f'(\xi_1)$；

在 $[2,4]$ 上：存在 $\xi_2\in(2,4)$ 使 $\dfrac{f(4)-f(2)}{4-2}=f'(\xi_2)$。

由第一步的等式得

$$f'(\xi_1)=f'(\xi_2)$$

**第三步：把 $f'(x)$ 看作新函数，用罗尔定理。** 在 $[\xi_1,\xi_2]\subset(1,4)$ 上对 $f'(x)$ 用罗尔定理，存在 $\xi\in(\xi_1,\xi_2)\subset(1,4)$ 使

$$f''(\xi)=0$$

**得证**。

> 老师原话：「这个题考察的比较综合，它既考察了拉格朗日，还考察了罗尔定理。」并给出通用思路：「如果你能够找到两个一阶导等于零，那么我们把那个一阶导数看作是函数，那么进而就能够推出一定有一个 $\xi$ 属于 $\xi_1$ 和 $\xi_2$ 这个区间，然后使得 $f$ 的两阶导等于零。」

### P136 拉格朗日中值定理（三）·双中值

#### 例 40（基础）证明 $\exists\,\xi,\eta\in(0,1)$ 使 $f'(\xi)+f'(\eta)=0$

**题设**：$f(x)$ 在 $[0,1]$ 连续、$(0,1)$ 内可导，$f(0)=f(1)$。

**第一步：取中点分区间。** 取分界点 $\dfrac12$，把 $[0,1]$ 分成 $\left[0,\dfrac12\right]$ 与 $\left[\dfrac12,1\right]$。

**第二步：两段各用一次拉格朗日中值定理。**

存在 $\xi\in\left(0,\dfrac12\right)$ 使

$$f'(\xi)=\frac{f\!\left(\frac12\right)-f(0)}{\frac12-0}=2\left[f\!\left(\frac12\right)-f(0)\right]$$

存在 $\eta\in\left(\dfrac12,1\right)$ 使

$$f'(\eta)=\frac{f(1)-f\!\left(\frac12\right)}{1-\frac12}=2\left[f(1)-f\!\left(\frac12\right)\right]$$

**第三步：两式相加。**

$$f'(\xi)+f'(\eta)=2\left[f\!\left(\frac12\right)-f(0)+f(1)-f\!\left(\frac12\right)\right]=2\big[f(1)-f(0)\big]=0$$

（最后一步用了 $f(0)=f(1)$。）**得证**。

> 老师原话：「第一个题呢我们就考虑给它中点……因为这个题呢实在是最简单的一个了。」

#### 例 41（双中值·两问综合）证明 $f'(\xi)\cdot f'(\eta)=1$

**题设**：$f(x)$ 在 $[0,1]$ 连续、$(0,1)$ 内可导，$f(0)=0$，$f(1)=1$。

**第一问：证明 $\exists\,c\in(0,1)$ 使 $f(c)=1-c$。**

令 $F(x)=f(x)+x-1$，则

$$F(0)=0+0-1=-1<0,\qquad F(1)=1+1-1=1>0$$

由零点定理，存在 $c\in(0,1)$ 使 $F(c)=0$，即 $f(c)=1-c$。

**第二问：用 $c$ 作分界点。**

在 $[0,c]$ 上：存在 $\xi\in(0,c)$ 使

$$f'(\xi)=\frac{f(c)-f(0)}{c-0}=\frac{1-c}{c}$$

（用了 $f(c)=1-c$、$f(0)=0$。）

在 $[c,1]$ 上：存在 $\eta\in(c,1)$ 使

$$f'(\eta)=\frac{f(1)-f(c)}{1-c}=\frac{1-(1-c)}{1-c}=\frac{c}{1-c}$$

**两式相乘：**

$$f'(\xi)\cdot f'(\eta)=\frac{1-c}{c}\cdot\frac{c}{1-c}=1$$

**得证**。

> 老师原话：「第一个问就是第二个问的一个铺垫……这个 $C$ 点实际上就是我们第一个问得出来的。是巧合吗？哎不是巧合。」

#### 例 42（2025 年山东真题）证明 $|f'(\xi)|+|f'(\eta)|\ge 4M$

**题设**：$f(x)$ 在 $[0,1]$ 上连续、$(0,1)$ 内可导，$f(0)=f(1)=0$，且 $f$ 在 $[0,1]$ 上有最大值 $M>0$。

**第一步：用最值定理找分界点。** 因 $f$ 连续，存在 $x_0\in(0,1)$ 使

$$f(x_0)=M$$

（最大值点必在开区间内，因为端点处 $f(0)=f(1)=0<M$。）

**第二步：两段各用一次拉格朗日中值定理。**

在 $[0,x_0]$ 上：存在 $\xi\in(0,x_0)$ 使

$$f'(\xi)=\frac{f(x_0)-f(0)}{x_0-0}=\frac{M}{x_0}$$

在 $[x_0,1]$ 上：存在 $\eta\in(x_0,1)$ 使

$$f'(\eta)=\frac{f(1)-f(x_0)}{1-x_0}=\frac{-M}{1-x_0}$$

**第三步：取绝对值并相加。**

$$|f'(\xi)|+|f'(\eta)|=\frac{M}{x_0}+\frac{M}{1-x_0}=\frac{M}{x_0(1-x_0)}$$

**第四步：用二次函数最值放缩。** 令 $G(x)=x(1-x)=-x^2+x$，它是开口向下的抛物线，两根为 $x=0$ 与 $x=1$，故最大值在顶点 $x=\dfrac12$ 处：

$$G(x)\le G\!\left(\frac12\right)=\frac12\cdot\frac12=\frac14$$

由「分母越大反而越小」得

$$\frac{1}{x_0(1-x_0)}\ge\frac{1}{1/4}=4$$

两边乘 $M>0$：

$$|f'(\xi)|+|f'(\eta)|\ge 4M$$

**得证**。

> 老师原话：「这个题呢是相对比较有难度的……我觉得可能至少有 90% 的同学应该都拿不到满分。」他还专门花时间解释最后那步放缩：「分母小于一个数，那么整个式子它会大于什么呢……原来是小于是不是变成了大于等于，分母越大的反而越小。」

#### 例 43（黑龙江真题）证明 $\dfrac{1}{f'(\xi_1)}+\dfrac{1}{f'(\xi_2)}=2$

**题设**：$f(x)$ 在 $[0,1]$ 上可导（故连续），$f(0)=0$，$f(1)=1$。

**第一步：最值定理 + 介值定理找分界点 $c$。**

设 $f$ 在 $[0,1]$ 上的最小值为 $m$、最大值为 $M$，则

$$m\le f(0)\le M,\qquad m\le f(1)\le M$$

即 $m\le0\le M$ 与 $m\le1\le M$。两式左中右分别相加：

$$2m\le f(0)+f(1)=1\le 2M\;\Longrightarrow\;m\le\frac12\le M$$

由介值定理（取 $\mu=\dfrac12$），存在 $c\in(0,1)$ 使

$$f(c)=\frac12$$

**第二步：两段各用一次拉格朗日中值定理。**

在 $[0,c]$ 上：存在 $\xi_1\in(0,c)$ 使

$$f'(\xi_1)=\frac{f(c)-f(0)}{c-0}=\frac{1/2}{c}=\frac{1}{2c}\;\Longrightarrow\;\frac{1}{f'(\xi_1)}=2c$$

在 $[c,1]$ 上：存在 $\xi_2\in(c,1)$ 使

$$f'(\xi_2)=\frac{f(1)-f(c)}{1-c}=\frac{1/2}{1-c}=\frac{1}{2(1-c)}\;\Longrightarrow\;\frac{1}{f'(\xi_2)}=2(1-c)$$

**第三步：两式相加。**

$$\frac{1}{f'(\xi_1)}+\frac{1}{f'(\xi_2)}=2c+2(1-c)=2$$

**得证**。

> 老师原话：「这个题呢也是需要用到最值定理以及介值定理……现在呢这个专升本考试的这个证明题，还是比较有难度的。」最后总结：「双中值的题，我们一般情况下都要去找一个点，把这个区间给它分成两段，然后在两个区间上分别去用拉格朗日中值定理。」

## 四、易错点警示

| ❌ 易错 | ✅ 正确 |
|:---|:---|
| 用零点定理证出「至少有一个根」，就以为证完了唯一性 | 唯一性必须另用**单调性**：单增/单减函数与 $x$ 轴最多交一次 |
| 把零点定理的条件记成「两端点值同号」 | 是**异号**，即 $f(a)\cdot f(b)<0$，对应乘积**小于零** |
| 直接用题干给的 $f(x)$ 上罗尔定理 | 题干给的 $f(x)$ 几乎不可能满足 $f(a)=f(b)$；必须**构造辅助函数** |
| 忘写「$F$ 在 $[a,b]$ 连续、在 $(a,b)$ 可导」这句「有用的废话」 | 一定要写——它是验证罗尔定理前两个条件，能拿印象分甚至补分 |
| 见到 $f'(\xi)$ 与 $f(\xi)$ 就一律直接积分 | 只有**相乘**关系能直接积分；**加减**关系属于题型三，必须用 $e^{\int g\,dx}f(x)$ |
| 用题型三公式时，$f'(x)$ 的系数不是 $1$ 就套 | 必须先把 $f'(x)$ 的系数**化成 $1$**（两边同除以该系数），再取 $g(x)$ |
| 辅助函数积分后加常数 $C$ | 不必加。加 $C$ 后两端点值仍相等（都等于 $C$），罗尔定理照样能用；但习惯上不加 |
| 把 $|x-x_0|<1$ 与 $|f'(\xi)|\le M$ 忘了放缩 | 题型二的收尾全靠放缩：区间长度限制 + 题干给的界 |
| 在拉格朗日中值定理里把参数 $x$ 当成自变量 | 例 31、32、33 中真正的自变量应另设 $t$，$x$ 只是**参数** |
| 见「取到极小值」想不起来用费马引理 | 可导函数在区间内取极值 $\Rightarrow$ 该点 $f'=0$，这是题型二的常用突破口 |
| 反证法里忘了「否定结论」这一步，直接假设结论成立 | 反证法要**否定**结论（「至多一个」否定成「有两个」，「不可能有三个」否定成「有三个」），再当条件用 |
| 反证法推完矛盾就停笔 | 必须补上「故假设错误，即原结论成立」这句收尾 |
| 不等式两边除以 $(b-a)$ 时担心变号 | $b>a$ 故 $b-a>0$，除以正数**不变号**；只有除以负数才变号 |
| 算 $\dfrac{1}{b}<\dfrac{1}{\xi}<\dfrac{1}{a}$ 时把方向写反 | **分母越大的反而越小**，$a<\xi<b\Rightarrow\frac1b<\frac1\xi<\frac1a$ |
| 双中值题拿到就随便劈区间 | 分界点要**有依据**：中点 / 第一问的结论 / 最值点 / 介值定理给出的点 |
| 分式型待证等式直接移项积分 | 先**交叉相乘化整式**，再移项积分；分式不能直接积分 |
| 用 $\int f(x)f'(x)dx$ 时忘了系数 $\dfrac12$ | $\int ff'\,dx=\dfrac12f^2(x)$，系数容易漏 |
| 求 $f''$ 判号时忘记指数函数恒正 | $e^{x}>0$ 恒成立，故 $e^x+2>0$ 恒正，不可能为零——这是反证法例 27 的矛盾点 |

| 考点 | 要点 |
|:---|:---|
| 单调性（★★★★） | 移项造 $F$ → 求导 → 判增减 → 端点定正负；一阶导号看不出时二次求导 |
| 最值定理 | 闭区间连续必有 $M$、$m$，且 $m\le f(x)\le M$；题干出现「最大值」即用 |
| 介值定理 | $m\le\mu\le M\Rightarrow\exists\xi$ 使 $f(\xi)=\mu$；与最值定理配合（左中右相加再除项数） |
| 零点定理（★★★★） | 两条件：连续 + 两端点异号；结论只给**存在性**，唯一性要另用单调性 |
| 零点定理题型一 | 方程至少有一个根 / 两曲线有交点 → 翻译成函数零点 |
| 零点定理题型二 | 有且仅有一个根 = 零点定理（存在性）+ 单调性（唯一性） |
| 零点定理题型三 | 含 $f(\xi)$ 的等式 → $\xi$ 换 $x$、移项、造 $F$；常为大题第一问 |
| 罗尔定理 | 三条件：连续、可导、$f(a)=f(b)$；前两个题干必给，第三个靠自己构造 |
| 罗尔·题型一 | 根的存在性 → **移项 + 直接积分**（占 15%–20%） |
| 罗尔·题型二 | $f'(\xi)\cdot f(\xi)$ 相乘型 → 移项 + 直接积分（常用 $\int ff'=\frac12f^2$） |
| 罗尔·题型三 | $f'(\xi)+g(\xi)f(\xi)=0$ → $F(x)=e^{\int g(x)dx}f(x)$，$f'$ 系数必须化为 $1$ |
| 罗尔·题型三进阶 | $f$ 为复合函数时先配出复合函数的导数；非齐次型用含 $P(x)$ 的公式 |
| 罗尔·题型四（反证法） | 特征词「不可能」「至多」；否定结论 → 当条件 → 推矛盾 → 假设错误 |
| 拉格朗日中值定理 | 两条件：连续、可导；$f(b)-f(a)=f'(\xi)(b-a)$；罗尔是它的特例 |
| 拉格朗日·题型一 | 不等式证明（占 60%–70%）：配形 → 令 $F(t)$ → 用定理 → 由 $\xi$ 范围回代 |
| 拉格朗日·题型二 | 无固定形式，从条件找突破口（零点 / 极值点），劈区间用两次 + 取绝对值 + 放缩 |
| 拉格朗日·题型三 | 双中值：找分界点（中点 / 第一问结论 / 最值点 / 介值点），两段各用一次，再相加或相乘 |
| 辅助函数总表 | 相乘型→积分；加减型→$e^{\int g\,dx}f(x)$；分式型→先交叉相乘；高阶型→把 $f'$ 当新 $f$ |
| 阅卷要点 | 辅助函数写出来至少能拿三分之一的分；「有用的废话」一定要写；最后要把待证的式子抄一遍 |
| 命题趋势 | 近几年一个证明题常穿插多个定理（如零点定理 + 罗尔，拉格朗日 + 罗尔），不再只考单一套路 |
