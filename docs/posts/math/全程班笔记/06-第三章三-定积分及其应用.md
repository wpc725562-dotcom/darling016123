# 第三章（三）· 定积分及其应用

> 来源：陈哥专升本《专升本高等数学全程班》P70–P80
> 本段地位：老师开篇定调「定积分呢是一个全新的一个小节」（P70），收尾时又强调「定积分绝对是我们考试中的一个重点，也是一个难点」（P79）。本段从定积分的定义与几何意义起步，一路打通计算、变限积分、反常积分，最后落到面积应用；反常积分部分则提醒「绝大部分省份他只考无穷区间的反常积分」（P78）。

---

## 一、大白话讲解

### 1. 为什么要发明定积分

中学只学过长方形、正方形、三角形的面积公式，都是**规则图形**。给你一段曲线和 $x$ 轴围成的**不规则图形**，就没办法了。

老师的思路：**大问题分解为小问题**（P70）——把区间切成很多小条，每条近似当长方形算面积，再加起来。

### 2. 分割 → 求和 → 取极限

- 把 $[a,b]$ 分成 $n$ 个小区间，宽度记作 $\Delta x_1,\Delta x_2,\dots,\Delta x_n$
- 每个小区间里取一点 $\xi_i$，对应高度 $f(\xi_i)$
- 每个小长方形面积：$f(\xi_i)\Delta x_i$
- 累加：$\sum\limits_{i=1}^{n}f(\xi_i)\Delta x_i$
- 令**最大宽度** $\lambda=\max\{\Delta x_i\}\to 0$（最大宽度都趋于零，其他宽度自然也趋于零），小长方形的顶就和曲线**重合**了

这个极限就是**黎曼和极限**，数学家用它定义出了**定积分**：

$$\int_a^b f(x)\,\mathrm{d}x=\lim_{\lambda\to 0}\sum_{i=1}^{n}f(\xi_i)\Delta x_i$$

> 「这个考试肯定不会考那么重点……我们要学的是等式右边的这个东西」（P70）。

### 3. 定积分和不定积分的区别

| | 不定积分 | 定积分 |
|:---|:---|:---|
| 记号 | $\int f(x)\mathrm{d}x$ | $\int_a^b f(x)\mathrm{d}x$ |
| 本质 | 一个**函数**（带 $+C$） | 一个**数** |
| 上下限 | 没有 | $a$ 下限、$b$ 上限 |

> 老师反复强调这一点（P75、P76）：「定积分的本质是一个数」「定积分和这个不定积分的本质要清楚」——积分方程那一类题全靠这句话打开局面。

### 4. 定积分到底在算什么

> 「求定积分本质上就是在求面积」（P70）。

但这里的"面积"和以前学的面积不一样：**有正有负**。

- 曲线在 $x$ 轴**上方** → 积分值为**正**
- 曲线在 $x$ 轴**下方** → 积分值为**负**（是面积的相反数）
- 一块草地的面积是十平方米，不可能为负；但定积分求出来的面积可以为负

### 5. 积分是一个"动作"

老师用微元法解释为什么积分能算面积（P79）：

- 取一小段宽 $\mathrm{d}x$、高 $f(x)$，微元面积 $\mathrm{d}S=f(x)\,\mathrm{d}x$
- 而 $\int_a^b$ 这个符号**本身就是一个动作、一个行为**——「目的就是将这个 $A$ 到 $B$ 区间上所有的这种微小的长方形，就是这些微小的长条，好的面积的累加」
- 积分就是一个**连续的累加**

### 6. 反常积分：把"规矩"破坏掉

定积分的积分区间是**有限**的，上下限都是**常数**。反常积分就是把这两条规矩破坏掉（P77、P78）：

- **破坏区间有限性** → 无穷区间的反常积分（广义积分）
- **破坏被积函数有界性** → 无界函数的反常积分（**瑕积分**）

求法和普通定积分**完全一样**，只是最后多一步：把无穷或瑕点写成**极限**。

## 二、考点全爆破

### 1. 定积分的定义（黎曼和极限）

$$\int_a^b f(x)\,\mathrm{d}x=\lim_{\lambda\to 0}\sum_{i=1}^{n}f(\xi_i)\Delta x_i,\qquad \lambda=\max_{1\le i\le n}\{\Delta x_i\}$$

**三个步骤**：分割 → 求和 → 取极限（微元法/元素法思想）。

> 老师说明：这个定义「写的比较多」「非常的不容易理解」，初学者「大概知道我说的是一个什么东西……什么玩意儿就可以了」（P70）。

### 2. 记号与读法

| 符号 | 名称 | 含义 |
|:---|:---|:---|
| $a$ | 积分**下限** | 积分区间的左端点（积分起点） |
| $b$ | 积分**上限** | 积分区间的右端点（积分终点） |
| $f(x)$ | 被积函数 | 与不定积分中的角色相同 |
| $x$ | 积分变量 | 与不定积分中的角色相同 |

读法：**「$f(x)$ 在 $a$ 到 $b$ 的区间上做定积分」**（P70）。

**三个要点**（P70）：

1. $a$ 为积分下限，可理解为积分的**起点**
2. $b$ 为积分上限，可理解为积分的**终点**；$a$、$b$ **不能随意交换**
3. 积分结果**只与被积函数和积分区间有关**，与积分变量用什么字母**无关**：

$$\int_a^b f(u)\,\mathrm{d}u=\int_a^b f(t)\,\mathrm{d}t$$

### 3. 定积分的几何意义（三种情形）

| 情形 | 几何意义 | 积分值符号 |
|:---|:---|:---|
| $f(x)>0$ | 曲线 $y=f(x)$、直线 $x=a$、$x=b$ 与 $x$ 轴围成的**曲边梯形面积** | 正 |
| $f(x)<0$ | 同上，但曲边梯形在 $x$ 轴**下方**，积分值 = 面积的**相反数** | 负 |
| $f(x)$ 有正有负 | $x$ 轴**上方面积 减去** $x$ 轴**下方面积** | 可正可负 |

第三点老师提醒「其实不太好理解」「稍微有点绕」，「大家不用去管第三点，只需要把前两点给搞清楚就可以了」，学到后面回头看自然就清楚了（P70）。

一句话总结：**求定积分本质上就是在求面积，只不过这里的面积有正有负。**

### 4. 重要技巧一：1/4 圆面积、1/2 圆面积

由被积函数 $\sqrt{1-x^2}$ 反推出 $x^2+y^2=1$（上半圆，半径为 1），再用**几何意义**直接得结果，完全不用积分方法（P70）。

**重要结论一**

$$\int_0^a\sqrt{a^2-x^2}\,\mathrm{d}x=\frac{1}{4}\pi a^2\qquad(\text{1/4 圆面积})$$

$$\int_{-a}^{a}\sqrt{a^2-x^2}\,\mathrm{d}x=\frac{1}{2}\pi a^2\qquad(\text{1/2 圆面积})$$

**重要结论二**（被积函数是 $\sqrt{2ax-x^2}$，配方得 $(x-a)^2+y^2=a^2$，圆心 $(a,0)$、半径 $a$）

$$\int_0^a\sqrt{2ax-x^2}\,\mathrm{d}x=\frac{1}{4}\pi a^2,\qquad
\int_0^{2a}\sqrt{2ax-x^2}\,\mathrm{d}x=\frac{1}{2}\pi a^2$$

> 老师提醒：这类题**一定**是考圆面积技巧，不是让你真的用积分方法硬算——「本来这个题你可以 30 秒钟就搞定了，但是如果你用积分方法，你可能 5 分钟都搞不定」（P70）。
> 他还预告后面还有两个技巧：**华里士（点火）公式**，以及另一个名称字幕转写不清的技巧。

### 5. 定积分的两个规定

| 规定 | 内容 | 理解 |
|:---|:---|:---|
| 规定一 | $\displaystyle\int_a^a f(x)\,\mathrm{d}x=0$ | 上下限相同，起点终点重合，只剩**一条线**；一条线没有面积 |
| 规定二 | $\displaystyle\int_a^b f(x)\,\mathrm{d}x=-\int_b^a f(x)\,\mathrm{d}x$ | 上下限交换，结果变**相反数** |

### 6. 定积分的四条性质

| 编号 | 内容 | 几何理解 |
|:---|:---|:---|
| 性质一 | 当 $a<b$ 时，$\displaystyle\int_a^b 1\,\mathrm{d}x=b-a$ | 被积函数 $y=1$ 是水平直线，围成底 $b-a$、高 $1$ 的长方形 |
| 性质二 | $\displaystyle\int_a^b\bigl[k f(x)\pm l g(x)\bigr]\mathrm{d}x=k\int_a^b f(x)\mathrm{d}x\pm l\int_a^b g(x)\mathrm{d}x$ | 常数因子可提到积分号外，再分别积分 |
| 性质三 | $\displaystyle\int_a^b f(x)\mathrm{d}x=\int_a^c f(x)\mathrm{d}x+\int_c^b f(x)\mathrm{d}x$ | 区间拆成两段，面积相加 |
| 性质四 | 若 $f(x)\le g(x)$，则 $\displaystyle\int_a^b f\le\int_a^b g$ | 函数图像越高，积分值越大 |

老师说明：性质五、六涉及**积分中值定理**，「我们可以不用去学」（P70）；但前四条「一定要记得特别的牢固」「后面我们在学定积分的计算方法的时候，大家就会感觉到很会轻松很多」。

### 7. 牛顿-莱布尼茨公式

设 $F(x)$ 是 $f(x)$ 的一个原函数，则

$$\int_a^b f(x)\,\mathrm{d}x=\Bigl[F(x)\Bigr]_a^b=F(b)-F(a)$$

老师把它称为「我们这最重最重要的一个点」——前面所有凑微分、换元、分部积分都是不定积分里学过的方法，「在这里面我们最多再给大家加一个这种莱布尼兹公式」（P72）。代入时**先写原函数，再代入上限、代入下限作差**。

### 8. 定积分换元法（换元**必须**换线）

定积分换元与不定积分换元的差别只有一处：

$$\int_a^b f\bigl(\varphi(t)\bigr)\varphi'(t)\,\mathrm{d}t=\int_{\alpha}^{\beta} f\bigl(\varphi(t)\bigr)\varphi'(t)\,\mathrm{d}t$$

- 换元三步曲（简单根式代换）：**令新变量 → 求微分 → 换上下限**
- 「定积分中是不是要换元之后还要换线啊」「换元法一定涉及换元换线的」（P72）
- 上限下限要跟着新变量重新算，**一定不要搞混淆**（P72）

### 9. 定积分分部积分法

$$\int_a^b u\,\mathrm{d}v=\Bigl[uv\Bigr]_a^b-\int_a^b v\,\mathrm{d}u$$

即

$$\int_a^b u v'\,\mathrm{d}x=\Bigl[u v\Bigr]_a^b-\int_a^b u' v\,\mathrm{d}x$$

**与不定积分的差别**：$uv$ 相乘这一步就要**带上上下限**，后面 $\int v\,\mathrm{d}u$ 也照样带上限；如果把上下限去掉，「是不是就变成了我们的不定积分……对应的分部积分的公式」（P72）。

**凑微分顺序**：口诀「反、对、幂、指、三」——排在前面的设为 $u$，排在后面的凑到微分号后面去。

| 被积函数类型 | 设为 $u$ 的 | 凑到后面的 |
|:---|:---|:---|
| 幂 × 三角（$x\cos x$、$x\sec^2x$） | 幂函数 $x$ | 三角函数 |
| 幂 × 指数（$x e^{-x}$） | 幂函数 $x$ | 指数函数 |
| 对数 × 幂（$x\ln(1+x^2)$） | 对数 | 幂函数 |
| 单个反三角函数（$\arctan x$） | 直接用分部积分，**不用凑微分** | — |

> 老师提醒（P72）：系数「是跟着这个积分**整体**的」「千万不要我见过有些同学就是这个二呢，他只跟着前面而不跟着后面」。

### 10. 积分方程（小考点）

**核心切入点**：定积分是一个**数**，可以把它设成一个未知常数 $A$（P75）。

**解题三步**：

1. 把题中那个"定积分"整体设为常数 $A$，写出 $f(x)$ 的表达式
2. **两边同时在同一个区间上积分**，左边又出现同一个积分（= $A$），得到一个关于 $A$ 的方程
3. 解出 $A$，代回即得 $f(x)$

> 这种题「一般考选择填空，甚至大题都有可能考」（P75）。
> 进阶变形：如果题中同时出现"极限值"和"积分值"，就把它们分别设为 $A$、$B$，「相当于最后去解一个……二元一次的方程组」（P75）。

### 11. 变限积分函数及其导数（★重点）

**定义**：把定积分的上下限换成变量 $x$ 的函数，就得到**变限积分函数**

$$\Phi(x)=\int_{u(x)}^{v(x)} f(t)\,\mathrm{d}t$$

**关键认知**：

- 积分变量 $t$ 决定整个积分结果；除积分变量以外，积分式中出现的**任何其他参数或变量都一律当常数**
- 例如 $\int_0^T x\,\mathrm{d}x=\dfrac{T^2}{2}$（这里 $T$ 是常数），$\int T x\,\mathrm{d}x=T\cdot\dfrac{x^2}{2}+C$
- 变限积分函数求出来是**关于 $x$ 的函数**，「既然是函数，那必定可以求导」（P76）

**求导法则**

$$\boxed{\ \frac{\mathrm{d}}{\mathrm{d}x}\int_{u(x)}^{v(x)}f(t)\,\mathrm{d}t=f\bigl(v(x)\bigr)v'(x)-f\bigl(u(x)\bigr)u'(x)\ }$$

口述版：**上限代入被积函数中的 $t$ × 上限的导数 − 下限代入被积函数中的 $t$ × 下限的导数**（P76）。

**常用特例**

$$\frac{\mathrm{d}}{\mathrm{d}x}\int_0^x f(t)\,\mathrm{d}t=f(x)$$

> 上下限只要是**常数**，代入后求导就直接得 $0$。

**两条注意事项**（P76）：

1. 涉及变限积分函数的题目，**一定**是考察它的**导数**（专升本、考研都一样）
2. 被积函数 $f(t)$ 中**不能含有与上下限相关的变量**（如 $x$）

### 12. 被积函数含 $x$ 时的两种处理

这是最容易出错的题型（P76）。若 $f$ 中出现了与上下限同名的字母 $x$，**不能直接套求导法则**，必须先把 $x$ 从被积函数里"赶出去"。

| 情形 | 处理办法 |
|:---|:---|
| $x$ 与 $t$ 是**相乘**关系，如 $\int_0^x (x-t)f(t)\mathrm{d}t$ | 把 $x$ 提到积分号外，**拆成两项**，再用乘积求导法则 |
| $x$ 与 $t$ 是**加减或平方差**关系，如 $\int_0^x f(x-t)\mathrm{d}t$、$\int_0^x f(x^2-t^2)\mathrm{d}t$ | 用**换元法**（含换线）或先**凑微分**再换元 |

拆项示范：

$$\int_0^x (x-t)f(t)\,\mathrm{d}t=\int_0^x t f(t)\,\mathrm{d}t-x\int_0^x f(t)\,\mathrm{d}t$$

（此时 $x$ 对积分变量 $t$ 而言是常数，可以提到积分号外）

### 13. 含变限积分函数的极限（洛必达）

**流程**（P76）：

1. **先定型**：判断是不是七种未定式；不是就直接得结果
2. **先等价**：等价无穷小替换是"化简的方法"，能等价就先等价
3. **再洛必达**：洛必达是"公式"，分子分母同时求导；分子求导即用变限积分求导法则
4. 遇到 $1+\cos x$ 这类**非零因子**，可以先代入算出它的极限值再往下做

### 14. 由变限积分函数求 $f(x)$ 的表达式

常见于大题（老师估「80% 都是会考大题的」，P76）。

- 若式子里出现 $\dfrac{1}{x}\int_1^x f(t)\mathrm{d}t$ 这种带 $x$ 分母的形式，**两边同乘 $x$** 先把它化干净，再求导
- 求导后往往能约掉 $f(x)$ 项，解出 $f'(x)$，再**两边积分**得 $f(x)=\cdots+C$
- 常数 $C$ 靠**初始值**确定：回到原式，取一个让变限积分上下限相等的 $x$ 值（此时积分 = 0），即可算出 $f$ 在该点的值

### 15. 无穷区间的反常积分（广义积分）

设 $F(x)$ 是 $f(x)$ 的原函数（P77）：

$$\int_a^{+\infty}f(x)\,\mathrm{d}x=\lim_{b\to+\infty}\Bigl[F(x)\Bigr]_a^b=F(+\infty)-F(a)$$

$$\int_{-\infty}^{b}f(x)\,\mathrm{d}x=\lim_{a\to-\infty}\Bigl[F(x)\Bigr]_a^b$$

$$\int_{-\infty}^{+\infty}f(x)\,\mathrm{d}x=\int_{-\infty}^{c}f(x)\,\mathrm{d}x+\int_{c}^{+\infty}f(x)\,\mathrm{d}x$$

**写法要求（关键）**：无穷代入时**必须写成极限形式**，不能直接写 $F(+\infty)$。

$$\text{正确：}\ \lim_{x\to+\infty}\arctan x=\frac{\pi}{2}\qquad\text{不规范：}\ \arctan(+\infty)$$

> 「我们一定要给它写成极限的形式，而不是说单纯的把无穷给他带进去」（P77）。

**敛散性判别**

| 情形 | 结论 |
|:---|:---|
| 积分结果**存在**（极限为有限常数） | 反常积分**收敛** |
| 积分结果**不存在**（极限为无穷） | 反常积分**发散** |
| $\int_{-\infty}^{+\infty}$ 拆成两个 | **两个都收敛**才收敛；只要有一个发散，原积分就**发散** |

> 求解思路总结：「实际上依旧在考它不定积分的求解，只是在最后一步加了一个极限的运算」（P77）。

### 16. 无穷区间反常积分常用结论

$$\int_0^{+\infty}x^{n}e^{-x}\,\mathrm{d}x=n!$$

特别地：$\displaystyle\int_0^{+\infty}xe^{-x}\mathrm{d}x=1!=1$，$\displaystyle\int_0^{+\infty}x^2e^{-x}\mathrm{d}x=2!=2$。

> 老师提醒：这类结论在选择题、填空题里可以直接用——「选择题就是要做到快准狠」（P77）。

### 17. 瑕积分（无界函数的反常积分）

**瑕点**：被积函数**没有定义**的点（P78）。

| 函数 | 瑕点 |
|:---|:---|
| $\dfrac{1}{x}$ | $x=0$ |
| $\dfrac{1}{x-1}$ | $x=1$ |
| $\ln x$ | $x=0$ |

> 「瑕点实际上就是我们的函数没有定义的点」（P78）。

**三种情形**

| 情形 | 瑕点位置 | 处理 |
|:---|:---|:---|
| 一 | $x=a$，左端点 | $\displaystyle\int_a^b f(x)\mathrm{d}x=\lim_{x\to a^+}\Bigl[F(x)\Bigr]_a^b=F(b)-\lim_{x\to a^+}F(x)$ |
| 二 | $x=b$，右端点 | $\displaystyle\int_a^b f(x)\mathrm{d}x=\lim_{x\to b^-}\Bigl[F(x)\Bigr]_a^b=\lim_{x\to b^-}F(x)-F(a)$ |
| 三 | $x=c$，区间**内部** | 必须在 $c$ 处**拆成两个瑕积分**：$\int_a^c+\int_c^b$ |

**统一做法**：正常积分积出原函数 → 找出瑕点 → 把瑕点处代入写成**极限** → 求极限。

> 与无穷区间反常积分的唯一区别：那里 $x$ 趋于无穷，这里 $x$ 趋于**瑕点**（P78）。

**敛散性**：与无穷区间完全相同——结果存在则收敛，不存在则发散；拆成两个时，**两个都收敛**才收敛。

> 老师提醒：**绝大部分省份只考无穷区间的反常积分**，瑕积分「只有极个别的省份有要求」，一定要**对照自己省份的考纲**（P78）。

### 18. 微元法（元素法）与曲边梯形面积

在 $[a,b]$ 上取一小段，宽记作 $\mathrm{d}x$，该段上任取一点 $x$，对应高度 $f(x)$。因为 $\mathrm{d}x$ 非常窄，可把这一长条**近似看作长方形**：

$$\mathrm{d}S=f(x)\,\mathrm{d}x$$

（长 = $f(x)$，宽 = $\mathrm{d}x$）再把所有微元累加：

$$S=\int_a^b f(x)\,\mathrm{d}x$$

这就是定积分几何意义的**代数和的**版本——曲线在 $x$ 轴下方时该段贡献为负。

### 19. X 型平面图形

**判定方法**：作一条**竖直线**穿过图形，上下平移，如果**首尾始终只穿过 $f(x)$、$g(x)$ 各一次**（即上下曲线表达式不变），就是 X 型。

- **上下**：一般为**曲线**，有时也为直线
- **左右**：**一定**为直线（也可能收缩为一个点）

**面积公式**

$$S=\int_a^b\Bigl[f(x)-g(x)\Bigr]\mathrm{d}x=\int_a^b(\text{高}-\text{低})\,\mathrm{d}x$$

其中 $a$、$b$ 是图形在 $x$ 轴上的取值范围（由**交点**决定）。

**反例**：三条曲线围成的图形，若平移时"上面的曲线表达式从 $f(x)$ 过渡到 $g(x)$"，就**不是**一个 X 型，只能拆成**两个 X 型**分别算（P79）。

### 20. Y 型平面图形

**判定方法**：作一条**水平线**穿过图形，左右平移，如果**首尾始终只穿过 $F(y)$、$G(y)$ 各一次**，就是 Y 型。

**前提**：必须把曲线统一写成 **$x=F(y)$** 的形式（自变量是 $y$、因变量是 $x$），例如

$$x=e^{y}-1,\qquad x=y^2+1,\qquad x=\ln y$$

- **左右**：一般为**曲线**，有时也为直线
- **上下**：为**直线**（也可能收缩为一个点）

**面积公式**

$$S=\int_a^b\Bigl[F(y)-G(y)\Bigr]\mathrm{d}y=\int_a^b(\text{右}-\text{左})\,\mathrm{d}y$$

其中 $a$、$b$ 是图形在 $y$ 轴上的取值范围（由**交点的纵坐标**决定）。

### 21. X 型与 Y 型的互相转化

- 同一个图形**既可以看作 X 型，也可以看作 Y 型**（例如一个三角形），两者结果一定相同
- 选哪一种**取决于计算是否容易**——「这没有绝对的说法，都是根据我们的一个计算的一个容易度」（P79）
- 一个既不是 X 型也不是 Y 型的图形（如 $y=\dfrac{4}{x}$、$y=x$、$y=4x$ 围成的图形），可以**拆成两个 X 型**，也可以**拆成两个 Y 型**
- 后面学**二重积分**的积分区域还要用 X 型、Y 型这套判断，必须在这里就搞清楚

### 22. 华里士（点火）公式

$$\int_0^{\frac{\pi}{2}}\sin^nx\,\mathrm{d}x=\int_0^{\frac{\pi}{2}}\cos^nx\,\mathrm{d}x=
\begin{cases}
\dfrac{n-1}{n}\cdot\dfrac{n-3}{n-2}\cdots\dfrac{1}{2}\cdot\dfrac{\pi}{2}, & n\ \text{为偶数}\\[10pt]
\dfrac{n-1}{n}\cdot\dfrac{n-3}{n-2}\cdots\dfrac{2}{3}\cdot 1, & n\ \text{为奇数}
\end{cases}$$

记忆法：**从 $n$ 开始每次减 $1$ 一路连乘到 $1$**；$n$ 为**偶数**时末尾再乘 $\dfrac{\pi}{2}$，$n$ 为**奇数**时不乘。

**推广到 $0\to\pi$**（P73）：

| 积分 | 处理 |
|:---|:---|
| $\displaystyle\int_0^{\pi}\sin^nx\,\mathrm{d}x$ | 一律 $=2\displaystyle\int_0^{\frac{\pi}{2}}\sin^nx\,\mathrm{d}x$（**与奇偶无关**） |
| $\displaystyle\int_0^{\pi}\cos^nx\,\mathrm{d}x$ | $n$ 为**奇** ⇒ $0$；$n$ 为**偶** ⇒ $2\displaystyle\int_0^{\frac{\pi}{2}}\cos^nx\,\mathrm{d}x$ |

**为什么叫「点火公式」**（P73）：连乘出来的数字正是 $n,\ n-1,\ n-2,\ \ldots,\ 1$，像火箭发射前的倒计时——「十、九、八、七、六、五、四、三、二、一，**点火发射**」。

**本段早先用到的 $n=2$**：

$$\int_0^{\frac{\pi}{2}}\cos^2t\,\mathrm{d}t=\frac{1}{2}\cdot\frac{\pi}{2}=\frac{\pi}{4}$$

> 老师的要求（P73）：**第一个（$0\to\frac{\pi}{2}$）必须背熟**，「因为第一个它考的是最多的」；第二个（$0\to\pi$）「如果大家能够把它记住，在做题的时候，也会很快」；$0\to2\pi$ 上的情形「在我们专升本这部分呢就可以不用去掌握」。
### 23. 求面积题的标准步骤

1. **画图**（一定要画，才能判断类型）
2. **判断 X 型 / Y 型**
3. **联立曲线方程求交点**，确定积分区间（X 型看横坐标，Y 型看纵坐标）
4. **套公式**：X 型用"高 − 低"，Y 型用"右 − 左"
5. 化成普通定积分计算

### 24. 定积分的计算路线图（P71）

老师把整章的计算收在一句话里：**定积分的计算只有一个公式**——牛顿-莱布尼茨公式，「实际上我们的计算……就这么一个公式，就这么一个方法。后面所讲的都是对于这个公式的一个运用」（P71）。

所以定积分的计算实际上是**两步**：先求原函数（就是求不定积分），再上下限代入作差。按「用什么方法求出原函数」分类，只有三条路：

| 路线 | 被积函数的特征 | 关键动作 |
|:---|:---|:---|
| **直接积分法** | 能直接对表查出原函数 | 先积出来（当作不定积分做），再套牛-莱公式 |
| **凑微分法**（第一类换元） | 被积式里藏着「某函数 × 它的导数」 | 把导数部分凑进 $\mathrm{d}$ 后面，**不用换线** |
| **根式代换 / 三角代换**（第二类换元） | 含根号，凑微分救不了 | **换元必换线**，一步不能少 |

**直接积分例** $\displaystyle\int_0^{\frac{\pi}{2}}\cos x\,\mathrm{d}x=\Bigl[\sin x\Bigr]_0^{\frac{\pi}{2}}=1-0=1$。

**凑微分例** $\displaystyle\int_1^{e}\frac{\ln x}{x}\,\mathrm{d}x=\frac{1}{2}\Bigl[(\ln x)^2\Bigr]_1^{e}=\frac{1}{2}$。

**根式代换例** $\displaystyle\int_1^{3}\frac{\mathrm{d}x}{\sqrt{x}(1+x)}$，令 $\sqrt{x}=t$ 得 $\displaystyle 2\int_1^{\sqrt3}\frac{\mathrm{d}t}{1+t^2}=\frac{\pi}{6}$。

**代入的规矩**（P71）：上下限要分别代入**整个原函数**再作差。老师特别点名一种错法——「我见过有同学这样带的，他把 $1$ 给它带到这个里面去，把 $0$ 给它带到这个里面去，肯定是不对的」。

> 本章的定性（P71）：「求定积分实际上就是在求原函数……问题又回到了如何去求解不定积分」；不定积分的方法掌握得好，「那么我们在后面学这些定积分的计算的过程中，这个就会变得非常的容易」。

### 25. 凑微分的两种写法：换元换线 vs 看作整体（P71）

以 $\displaystyle\int_1^{e}\frac{\ln x}{x}\,\mathrm{d}x$ 为例，两种写法结果相同，**写法二老师更推荐**。

**写法一（换元并换线）**：令 $t=\ln x$，则 $\mathrm{d}t=\dfrac{\mathrm{d}x}{x}$。**只要真的引入了新变量 $t$，上下限就必须跟着换**：

$$x=1\ \Rightarrow\ t=\ln 1=0,\qquad x=e\ \Rightarrow\ t=\ln e=1$$

$$\int_1^{e}\frac{\ln x}{x}\,\mathrm{d}x=\int_0^{1}t\,\mathrm{d}t=\Bigl[\frac{1}{2}t^2\Bigr]_0^{1}=\frac{1}{2}$$

**写法二（看作整体，不引入新字母）**：直接把 $\ln x$ 当作一个整体：

$$\int_1^{e}\ln x\,\mathrm{d}(\ln x)=\Bigl[\frac{1}{2}(\ln x)^2\Bigr]_1^{e}=\frac{1}{2}\left(1^2-0^2\right)=\frac{1}{2}$$

上下限**照旧写 $1$ 和 $e$**，因为积分变量自始至终是 $x$。

**判据**（P71）：区分两种写法的唯一标准是**有没有令成新字母**——「只要你令成了一个新的变量之后，你这个积分上下限是一定要发生变化的」；写法二「我们并没有把它换成是一个新的变量……只是把它看作是一个新的整体」。

> **结论**：凑微分法**可以不写换元换线的过程**（写法二更简洁）；但**根式代换中「换元必换线」必不可少**，因为它必须真的引入新变量。另外，换元之后**不用回代**，直接代入新的上下限用牛-莱公式即可。

### 26. 根式代换与三角代换（P71）

第二类换元分两支，**两支都必须换线**。

**换元四步**（前三步是不定积分里的「换元三步曲」，第四步是定积分新加的）：

1. 令新变量（如 $\sqrt{x}=t$）
2. 解出 $x$（如 $x=t^2$）
3. 两边微分求 $\mathrm{d}x$（如 $\mathrm{d}x=2t\,\mathrm{d}t$）
4. **换线**：把原上下限代回第 1 步的式子，算出新变量的上下限

**（1）简单根式代换**：根号里是一次式（$\sqrt{x}$、$\sqrt{2x-1}$、$\sqrt{e^x-1}$），**令整个根号 $=t$**。

**（2）三角代换**：按根号下的形式选令法。

| 根号形式 | 令 |
|:---|:---|
| $\sqrt{a^2-x^2}$ | $x=a\sin t$，$t\in\left[-\dfrac{\pi}{2},\dfrac{\pi}{2}\right]$ |
| $\sqrt{a^2+x^2}$ | $x=a\tan t$，$t\in\left(-\dfrac{\pi}{2},\dfrac{\pi}{2}\right)$ |
| $\sqrt{x^2-a^2}$ | $x=a\sec t$ |

**开方不带绝对值的依据**：三角代换中 $t$ 的取值范围保证 $\cos t\ge0$，所以 $\sqrt{1-\sin^2t}=\cos t$（**不是** $|\cos t|$）；同理 $\sqrt{1+\tan^2t}=\sec t$（P71）。

**按分算账**（P71）：一道 8 分的根式代换题，「换元换线，这个应该在 **3 到 4 分**」——「请大家一定要重视这个换元换线，千万不要搞掉了，尤其是在我们的这个根式代换中」。

### 27. 对称区间上的「偶倍奇零」（P73）

**核心结论**：$f(x)$ 在**对称区间** $[-a,a]$ 上积分，结果**只有两种可能**：

$$\int_{-a}^{a}f(x)\,\mathrm{d}x=
\begin{cases}
0, & f(x)\ \text{为奇函数}\\[8pt]
2\displaystyle\int_0^{a}f(x)\,\mathrm{d}x, & f(x)\ \text{为偶函数}
\end{cases}$$

**为什么**（P73）：奇函数的左右两半「一个为正、一个为负」，面积数值**正负抵消**；偶函数左右两半面积**一样大**，只算一半再乘 2。

**实例对照**（P73 课堂演示）：

$$\int_{-1}^{1}x\,\mathrm{d}x=\Bigl[\frac{1}{2}x^2\Bigr]_{-1}^{1}=0,\qquad
\int_{-1}^{1}x^2\,\mathrm{d}x=2\int_0^1x^2\,\mathrm{d}x=2\cdot\frac{1}{3}=\frac{2}{3}$$

**★ 定式思维**：老师要求把「**对称区间**」和「**偶倍奇零**」**绑定**——「在我们的专升本的阶段，只要看到了对称区间，99% 的都考的是这个知识点」，「对称区间一定是想到偶倍奇零」。

**常见奇偶函数速查**

| 偶函数 | 奇函数 |
|:---|:---|
| $x^{2n}$（偶次幂）、$\cos x$、$\lvert x\rvert$、任意常数 | $x^{2n+1}$（奇次幂）、$\sin x$、$\tan x$、$\arctan x$、$\arcsin x$ |
| $f(x)+f(-x)$ | $f(x)-f(-x)$；$\ln\dfrac{1-x}{1+x}$ 型对数式 |

**复合函数口诀**（P73）：**内偶则偶，内奇同外**——内层是偶函数则整体必为偶；内层是奇函数则整体的奇偶性与外层相同。（例：$\cos(\sin x)$ 内奇外偶 ⇒ 偶；$\sin(\cos x)$ 内偶 ⇒ 偶；$\tan(\sin x)$ 内奇外奇 ⇒ 奇。）

**四则运算规律**（P73，记不住就取 $x$（奇）与 $x^2$（偶）当场试）：

| 运算 | 结果 |
|:---|:---|
| 偶 ± 偶、偶 × 偶、偶 ÷ 偶 | **偶** |
| 奇 ± 奇 | **奇** |
| 奇 × 奇、奇 ÷ 奇 | **偶** |
| 偶 × 奇、偶 ÷ 奇、奇 ÷ 偶 | **奇** |
| 偶 ± 奇 | **非奇非偶**（不能用偶倍奇零） |

> 老师的建议（P73）：「这些呢大家其实不用去背」——「如果搞忘了，那么就拿一个取一个例子，奇函数取 $x$，偶函数取 $x^2$，那么就可以把这一个奇偶函数的四则运算法则给推导出来」。

### 28. 分段函数的定积分（P74）

**工具**：定积分的**区间可加性**——若 $c\in[a,b]$，则

$$\int_a^b f(x)\,\mathrm{d}x=\int_a^c f(x)\,\mathrm{d}x+\int_c^b f(x)\,\mathrm{d}x$$

分段函数的积分**就是这条性质的直接应用**（P74）：「分段函数用的方法呢，实际上就是我们的这个定积分中的这个性质」。

**解题两步**：

1. **找分段点，看它在不在积分区间内**——在，就按分段点把积分区间切开
2. 每一段上**换成该段对应的表达式**，各自算完再相加

**★ 一类要特别小心的题**：被积函数里是 $f(\text{某个式子})$（如 $f(x-\pi)$、$f(1-x)$）时，**先做变量替换**把它变成 $f(t)$ 的标准形式，**再分段**。老师强调「拿到这个题的第一步，不是去分那个区间」，而是「把这一个部分给它看作是 $t$，做一个变量替换」（P74）。

**变量替换时的两个要点**（P74）：

- **换线**：把原上下限代进替换式，算出新变量的上下限
- **积分值与积分变量字母无关**：$\displaystyle\int_a^b f(u)\,\mathrm{d}u=\int_a^b f(x)\,\mathrm{d}x$，所以最后可以直接把 $u$ 写成 $x$，不必回代

> 老师的定性（P74）：「分段函数的积分，其实主要就考察这些」，「考试题的难度肯定是不会超过我讲的这个难度的」。

### 29. $\max$ 函数与绝对值函数（P74）

这两类**都先翻译成分段函数**，再套上一条的方法。

**（1）$\max\{a,b\}$ 型**：画出两条曲线，**取位置在上方的那一段**。

以 $\max\{1,e^x\}$ 为例，$e^x$ 与 $1$ 交于 $x=0$：

$$\max\{1,e^x\}=\begin{cases}1,&x\le0\\[4pt] e^x,&x>0\end{cases}$$

**（2）$\lvert f(x)\rvert$ 型**：先求**零点**（与 $x$ 轴的交点），把图像在 $x$ 轴下方的部分**翻到上方**；翻上去的那一段表达式**要加负号**。

以 $\lvert 2x-1\rvert$ 为例，零点 $x=\dfrac{1}{2}$：

$$\lvert 2x-1\rvert=\begin{cases}-(2x-1),&x<\dfrac{1}{2}\\[8pt] 2x-1,&x\ge\dfrac{1}{2}\end{cases}$$

**（3）带根号的隐蔽绝对值**（P74 强调，**考试高频**）：

$$\sqrt{(\cos x-\sin x)^2}=\lvert\cos x-\sin x\rvert\ \ne\ \cos x-\sin x$$

「一个数平方开根号，得到的结果应该是这个数的**绝对值**」——必须**再画图找出变号点**（$\cos x=\sin x$ 处），分区间去绝对值。老师说明这类题「很多省份都是有考过的，请大家一定要引起重视」。

### 30. 旋转体的体积（P80）

**总体框架**（P80）：「旋转体的体积呢，一共有**四个公式**，但是我们**常考的就两个**，剩下的那两个呢，实际上是可以通过这两个推导出来的」。两个常用公式**都建立在 X 型图形上**。

**（1）X 型绕 $x$ 轴旋转**——微元是「薄圆饼」，体积 = 底面积 × 高

$$\boxed{\ V_x=\pi\int_a^b f^2(x)\,\mathrm{d}x\ }$$

推导：取宽 $\mathrm{d}x$、高 $f(x)$ 的微元，绕 $x$ 轴转出一个小圆柱，**半径就是 $f(x)$**，所以 $\mathrm{d}V=\pi f^2(x)\,\mathrm{d}x$，再把所有微元累加（积分）。

**两条曲线**时外体积减内体积（中间是空心的）：

$$\boxed{\ V_x=\pi\int_a^b\Bigl[f^2(x)-g^2(x)\Bigr]\mathrm{d}x\ }$$

（$f$ 为上曲线、$g$ 为下曲线。）$g(x)\equiv0$ 时退化成第一条公式——「第一个公式实际上是下面一个公式的特例」（P80）。

**（2）X 型绕 $y$ 轴旋转**——**柱壳法**（老师写作「柱翘法」）

$$\boxed{\ V_y=2\pi\int_a^b x\,f(x)\,\mathrm{d}x\ }$$

推导（P80）：微元宽 $\mathrm{d}x$、高 $f(x)$，绕 $y$ 轴转出的是一圈「**木桶**」；沿母线劈一刀展开成长方体——

| 长方体 | 对应量 |
|:---|:---|
| 长 | 底周长 $2\pi x$（半径就是微元中心到 $y$ 轴的距离 $x$） |
| 宽 | 木桶厚度 $\mathrm{d}x$ |
| 高 | $f(x)$（展开不改变高） |

所以 $\mathrm{d}V=2\pi x\,f(x)\,\mathrm{d}x$，再积分。**两条曲线**时同样相减：

$$\boxed{\ V_y=2\pi\int_a^b x\Bigl[f(x)-g(x)\Bigr]\mathrm{d}x\ }$$

**另外两个公式**（P80 只给形式、不讲推导，让同学课后自己推）——**Y 型**图形：

$$V_y=\pi\int_c^d f^2(y)\,\mathrm{d}y\qquad(\text{Y 型绕 }y\text{ 轴})$$

$$V_x=2\pi\int_c^d y\,f(y)\,\mathrm{d}y\qquad(\text{Y 型绕 }x\text{ 轴})$$

> 老师明说这两个「用的非常少，几乎很少有省份这样去考」（P80）；考得最多的是 **X 型绕 $x$ 轴**。

**★ 解题定式**（P80）：「这种题没有其他的方法，第一步就**先画图**」，「没有说你图都画不出来，然后就把题做出来了，这种是不可能的」——画图 → 判 X 型 → 求交点定区间 → 套公式 → 算定积分。

> 本章收尾（P80）：「第三章的内容其实非常非常的多……因为后面有很多地方都要用到积分」，二重积分、曲线积分「这些地方都要用到积分」。

## 三、例题精讲

### （P70）几何意义与圆面积技巧

**例 1** 用几何意义求 $\displaystyle\int_0^1\sqrt{1-x^2}\,\mathrm{d}x$ 与 $\displaystyle\int_{-1}^1\sqrt{1-x^2}\,\mathrm{d}x$

**解**：令 $y=\sqrt{1-x^2}$，两边平方得 $x^2+y^2=1$，是半径 1 的圆。因为根号非负，$y\ge0$，所以 $y=\sqrt{1-x^2}$ 对应**上半圆**；又因 $x$ 是平方，它是**偶函数**，图像关于 $y$ 轴对称。

$$\int_0^1\sqrt{1-x^2}\,\mathrm{d}x=\frac{1}{4}\pi\cdot1^2=\frac{\pi}{4}$$

$$\int_{-1}^1\sqrt{1-x^2}\,\mathrm{d}x=\frac{1}{2}\pi\cdot1^2=\frac{\pi}{2}$$

**例 2** 求 $\displaystyle\int_0^1\sqrt{2x-x^2}\,\mathrm{d}x$ 与 $\displaystyle\int_0^2\sqrt{2x-x^2}\,\mathrm{d}x$

**解**：令 $y=\sqrt{2x-x^2}$，平方后移项配方：

$$x^2-2x+1+y^2=1\ \Longrightarrow\ (x-1)^2+y^2=1$$

圆心 $(1,0)$、半径 $1$。$y\ge0$ 取上半圆。$0\to1$ 是**左半**的 1/4 圆，$0\to2$ 是**整个上半圆**：

$$\int_0^1\sqrt{2x-x^2}\,\mathrm{d}x=\frac{1}{4}\pi,\qquad
\int_0^2\sqrt{2x-x^2}\,\mathrm{d}x=\frac{1}{2}\pi$$

**例 3**（老师现场补的练习）求 $\displaystyle\int_0^4\sqrt{4x-x^2}\,\mathrm{d}x$

**解**：对照 $\sqrt{2ax-x^2}$，此处 $2a=4$，故半径 $a=2$，积分上限 $4=2a$，是**直径**范围，用 1/2 圆面积公式：

$$\int_0^4\sqrt{4x-x^2}\,\mathrm{d}x=\frac{1}{2}\pi\cdot2^2=2\pi$$

> 老师原话：「如果说大家知道这样的一个公式之后……去求解这样的积分就非常容易。实际上这一个积分，如果我们真的要去用积分方法进行求解的时候呢，实际上是比较麻烦的」（P70）。

### （P72）定积分分部积分法

**例 1** 求 $\displaystyle\int_0^{\frac{\pi}{2}}x\cos x\,\mathrm{d}x$

**解**：幂 × 三角，幂函数设为 $u$，$\cos x$ 凑微分。

$$\int_0^{\frac{\pi}{2}}x\,\mathrm{d}(\sin x)=\Bigl[x\sin x\Bigr]_0^{\frac{\pi}{2}}-\int_0^{\frac{\pi}{2}}\sin x\,\mathrm{d}x$$

$$=\left(\frac{\pi}{2}\cdot1-0\right)+\Bigl[\cos x\Bigr]_0^{\frac{\pi}{2}}=\frac{\pi}{2}+(0-1)=\frac{\pi}{2}-1$$

**例 2** 求 $\displaystyle\int_0^1 xe^{-x}\,\mathrm{d}x$

**解**：凑微分 $\mathrm{d}\bigl(e^{-x}\bigr)=-e^{-x}\mathrm{d}x$，前面补负号。

$$\int_0^1 xe^{-x}\mathrm{d}x=-\int_0^1x\,\mathrm{d}\bigl(e^{-x}\bigr)=-\Bigl[xe^{-x}\Bigr]_0^1+\int_0^1e^{-x}\mathrm{d}x$$

$$=-\left(\frac{1}{e}-0\right)+\Bigl[-e^{-x}\Bigr]_0^1=-\frac{1}{e}+\left(1-\frac{1}{e}\right)=1-\frac{2}{e}$$

**例 3** 求 $\displaystyle\int_0^1 x\ln(1+x^2)\,\mathrm{d}x$

**解**：对数设为 $u$，幂函数凑微分，$x\,\mathrm{d}x=\dfrac{1}{2}\mathrm{d}(1+x^2)$。

$$\int_0^1x\ln(1+x^2)\mathrm{d}x=\frac{1}{2}\Bigl[(1+x^2)\ln(1+x^2)\Bigr]_0^1-\frac{1}{2}\int_0^1(1+x^2)\cdot\frac{2x}{1+x^2}\mathrm{d}x$$

$$=\frac{1}{2}\cdot2\ln2-\frac{1}{2}\Bigl[x^2\Bigr]_0^1=\ln2-\frac{1}{2}$$

**例 4** 求 $\displaystyle\int_0^{\frac{\pi}{4}}x\sec^2x\,\mathrm{d}x$

**解**：$x$ 设为 $u$，$\sec^2x$ 凑微分。

$$\int_0^{\frac{\pi}{4}}x\,\mathrm{d}(\tan x)=\Bigl[x\tan x\Bigr]_0^{\frac{\pi}{4}}-\int_0^{\frac{\pi}{4}}\tan x\,\mathrm{d}x=\frac{\pi}{4}-\Bigl[-\ln\cos x\Bigr]_0^{\frac{\pi}{4}}$$

$$=\frac{\pi}{4}+\ln\cos\frac{\pi}{4}-\ln\cos0=\frac{\pi}{4}+\ln\frac{\sqrt2}{2}$$

**例 5** 求 $\displaystyle\int_0^1\arctan x\,\mathrm{d}x$

**解**：只有一个函数，直接用分部积分（**不用凑微分**）。

$$\int_0^1\arctan x\,\mathrm{d}x=\Bigl[x\arctan x\Bigr]_0^1-\int_0^1\frac{x}{1+x^2}\mathrm{d}x$$

$$=\frac{\pi}{4}-\frac{1}{2}\Bigl[\ln(1+x^2)\Bigr]_0^1=\frac{\pi}{4}-\frac{1}{2}\ln2$$

### （P72）综合题：换元 + 分部积分

**例 6** 求 $\displaystyle\int_0^1 e^{-\sqrt x}\,\mathrm{d}x$

**解**：令 $\sqrt x=t$，则 $x=t^2$，$\mathrm{d}x=2t\,\mathrm{d}t$。换元换线：$x=0\to t=0$，$x=1\to t=1$。

$$\int_0^1e^{-\sqrt x}\mathrm{d}x=\int_0^1e^{-t}\cdot2t\,\mathrm{d}t=2\int_0^1te^{-t}\mathrm{d}t$$

由例 2 知 $\int_0^1te^{-t}\mathrm{d}t=1-\dfrac{2}{e}$，故原式 $=2\left(1-\dfrac{2}{e}\right)$。

**例 7**（山东往年真题）求 $\displaystyle\int_0^{\frac{\pi}{2}}e^{\sin x}\sin2x\,\mathrm{d}x$

**解**：先化二倍角：$\sin2x=2\sin x\cos x$。

$$\int_0^{\frac{\pi}{2}}e^{\sin x}\sin2x\,\mathrm{d}x=2\int_0^{\frac{\pi}{2}}e^{\sin x}\sin x\cos x\,\mathrm{d}x$$

再凑微分 $\cos x\,\mathrm{d}x=\mathrm{d}(\sin x)$，并换元令 $\sin x=t$（$x=0\to t=0$，$x=\frac{\pi}{2}\to t=1$）：

$$=2\int_0^1 te^{t}\,\mathrm{d}t=2\Bigl(\Bigl[te^t\Bigr]_0^1-\int_0^1e^t\mathrm{d}t\Bigr)=2\bigl(e-(e-1)\bigr)=2$$

**例 8** 求 $\displaystyle\int_0^1 xe^{\sqrt{1-x^2}}\,\mathrm{d}x$

**解**：三角换元，令 $x=\sin t$，$\mathrm{d}x=\cos t\,\mathrm{d}t$，$\sqrt{1-x^2}=\cos t$。换线：$x=0\to t=0$，$x=1\to t=\dfrac{\pi}{2}$。

$$\int_0^1xe^{\sqrt{1-x^2}}\mathrm{d}x=\int_0^{\frac{\pi}{2}}\sin t\,e^{\cos t}\cos t\,\mathrm{d}t$$

注意 $\mathrm{d}\bigl(e^{\cos t}\bigr)=-e^{\cos t}\sin t\,\mathrm{d}t$，故

$$=-\int_0^{\frac{\pi}{2}}\cos t\,\mathrm{d}\bigl(e^{\cos t}\bigr)
=-\Bigl[\cos t\,e^{\cos t}\Bigr]_0^{\frac{\pi}{2}}+\int_0^{\frac{\pi}{2}}e^{\cos t}\,\mathrm{d}(\cos t)$$

$$=-(0-e)+\Bigl[e^{\cos t}\Bigr]_0^{\frac{\pi}{2}}=e+(1-e)=1$$

### （P75）积分方程

**例 1** 设 $f(x)=x^2-\displaystyle\int_0^1 f(x)\,\mathrm{d}x$，求 $f(x)$

**解**：定积分是一个**数**，令

$$A=\int_0^1f(x)\,\mathrm{d}x$$

则 $f(x)=x^2-A$。两边在 $[0,1]$ 上积分：

$$A=\int_0^1(x^2-A)\mathrm{d}x=\Bigl[\frac{x^3}{3}\Bigr]_0^1-A\int_0^1\mathrm{d}x=\frac{1}{3}-A$$

$$2A=\frac{1}{3}\ \Longrightarrow\ A=\frac{1}{6}$$

$$\boxed{f(x)=x^2-\frac{1}{6}}$$

**例 2**（往年真题）设 $f(x)=\dfrac{1}{1+x^2}+A\sqrt{1-x^2}$，其中 $A=\displaystyle\int_0^1 f(x)\,\mathrm{d}x$，求 $f(x)$

**解**：令 $A=\int_0^1f(x)\mathrm{d}x$，则 $f(x)=\dfrac{1}{1+x^2}+A\sqrt{1-x^2}$。两边在 $[0,1]$ 上积分：

$$A=\int_0^1\frac{1}{1+x^2}\mathrm{d}x+A\int_0^1\sqrt{1-x^2}\,\mathrm{d}x$$

其中 $\int_0^1\dfrac{1}{1+x^2}\mathrm{d}x=\bigl[\arctan x\bigr]_0^1=\dfrac{\pi}{4}$，而后一项正是**重要技巧一**的 1/4 圆面积，半径 $1$，直接得 $\dfrac{\pi}{4}$：

$$A=\frac{\pi}{4}+A\cdot\frac{\pi}{4}\ \Longrightarrow\ A\Bigl(1-\frac{\pi}{4}\Bigr)=\frac{\pi}{4}\ \Longrightarrow\ A=\frac{\pi}{4-\pi}$$

$$\boxed{f(x)=\frac{1}{1+x^2}+\frac{\pi}{4-\pi}\sqrt{1-x^2}}$$

> 老师点评：「其实这就是个纸老虎，看起来他式子好像比较长，但实际上我们是有那种非常明确的解题方法的」（P75）。

### （P76）变限积分函数求导（六例）

**例 1** $F(x)=\displaystyle\int_0^x f(t)\,\mathrm{d}t$，求 $F'(x)$

$$F'(x)=f(x)\cdot(x)'-f(0)\cdot(0)'=f(x)$$

**例 2** $F(x)=\displaystyle\int_0^{x^2}f(t)\,\mathrm{d}t$，求 $F'(x)$

$$F'(x)=f(x^2)\cdot2x-0=2x\,f(x^2)$$

**例 3** $F(x)=\displaystyle\int_{x^2}^{e^x}f(t)\,\mathrm{d}t$，求 $F'(x)$

$$F'(x)=f\bigl(e^x\bigr)\cdot e^x-f\bigl(x^2\bigr)\cdot2x=e^xf\bigl(e^x\bigr)-2x f\bigl(x^2\bigr)$$

**例 4**（易错题）$F(x)=\displaystyle\int_0^x(x-t)f(t)\,\mathrm{d}t$，求 $F'(x)$

**解**：$x$ 对积分变量 $t$ 而言是**常数**，可以提出积分号外，**先拆开**：

$$F(x)=\int_0^x tf(t)\,\mathrm{d}t-x\int_0^x f(t)\,\mathrm{d}t$$

前一项用变限积分求导，后一项用**乘积求导法则**（前导后不导 + 后导前不导）：

$$F'(x)=xf(x)-\Bigl[\int_0^xf(t)\mathrm{d}t+x f(x)\Bigr]=-\int_0^xf(t)\,\mathrm{d}t$$

> ❗若直接把上限 $x$ 代入被积函数中的 $t$，会得到 $(x-x)f(x)=0$，这是错的——因为被积函数里含了与上限相关的字母 $x$。

**例 5** $F(x)=\displaystyle\int_0^x f(x-t)\,\mathrm{d}t$，求 $F'(x)$

**解**：换元，令 $x-t=u$，则 $t=x-u$，$\mathrm{d}t=-\mathrm{d}u$。换线：$t=0\to u=x$，$t=x\to u=0$。

$$F(x)=\int_x^0f(u)\cdot(-\mathrm{d}u)=\int_0^xf(u)\,\mathrm{d}u$$

（中间用了一次"上下限交换变相反数"的规定，负负得正。）于是

$$F'(x)=f(x)$$

**例 6** $F(x)=\displaystyle\int_0^x f(x^2-t^2)\,\mathrm{d}t$，求 $F'(x)$

**解**：先凑微分。因为 $t\,\mathrm{d}t=\dfrac{1}{2}\mathrm{d}(t^2)=-\dfrac{1}{2}\mathrm{d}(x^2-t^2)$（$x$ 视作常数），

$$F(x)=-\frac{1}{2}\int_0^xf(x^2-t^2)\,\mathrm{d}(x^2-t^2)$$

令 $u=x^2-t^2$，换线：$t=0\to u=x^2$，$t=x\to u=0$。

$$F(x)=-\frac{1}{2}\int_{x^2}^{0}f(u)\,\mathrm{d}u=\frac{1}{2}\int_0^{x^2}f(u)\,\mathrm{d}u$$

$$F'(x)=\frac{1}{2}\cdot f\bigl(x^2\bigr)\cdot2x=x\,f\bigl(x^2\bigr)$$

> 老师说明：例 6 在专升本阶段考得很少，只有个别省份个别年份出过，考研里则常见（P76）。

### （P76）含变限积分函数的极限（四例）

**例 1** 求 $\displaystyle\lim_{x\to0}\frac{\int_0^x t\sin t\,\mathrm{d}t}{x\sin x^2}$

**解**：$x\to0$ 时分子为 $0$（上下限相等），分母也为 $0$，**零比零型**。先等价：$\sin x^2\sim x^2$，分母 $\sim x\cdot x^2=x^3$。

洛必达（分子用变限积分求导，分母用乘积求导）：

$$\lim_{x\to0}\frac{x\sin x}{3x^2}\xlongequal{\sin x\sim x}\lim_{x\to0}\frac{x\cdot x}{3x^2}=\frac{1}{3}$$

**例 2** 求 $\displaystyle\lim_{x\to0}\frac{\int_0^{x^2}\sin t\,\mathrm{d}t}{4x^3}$

**解**：零比零型，直接洛必达：

$$\lim_{x\to0}\frac{\sin x^2\cdot2x}{4x^3}\xlongequal{\sin x^2\sim x^2}\lim_{x\to0}\frac{x^2\cdot2x}{4x^3}=\frac{1}{2}$$

**例 3** 求 $\displaystyle\lim_{x\to0}\frac{\int_0^{\tan x}e^{-t^2}\mathrm{d}t}{(1+\cos x)\ln(1+x)}$

**解**：分母中 $1+\cos x\to2$ 是**非零因子**，可先代入算出；$\ln(1+x)\sim x$，故分母 $\sim2x$。

$$\lim_{x\to0}\frac{e^{-\tan^2x}\cdot\sec^2x}{2}=\frac{1\cdot1}{2}=\frac{1}{2}$$

**例 4** 求 $\displaystyle\lim_{x\to0}\frac{\left(\int_0^x e^{t^2}\mathrm{d}t\right)^2}{\int_0^x te^{2t^2}\mathrm{d}t}$

**解**：零比零型。分子最外层是**平方**，按复合函数求导：$2\left(\int_0^xe^{t^2}\mathrm{d}t\right)\cdot e^{x^2}$；分母求导为 $xe^{2x^2}$。

$$\lim_{x\to0}\frac{2\left(\int_0^xe^{t^2}\mathrm{d}t\right)e^{x^2}}{xe^{2x^2}}$$

$e^{x^2}\to1$、$e^{2x^2}\to1$ 都是非零因子，先算掉：

$$=\lim_{x\to0}\frac{2\int_0^xe^{t^2}\mathrm{d}t}{x}$$

仍是零比零，再洛必达一次：

$$=\lim_{x\to0}\frac{2e^{x^2}}{1}=2$$

### （P76）求 $f(x)$ 的表达式

**例 5** 设 $x>0$ 时 $f(x)$ 可导，且 $f(x)=1+\dfrac{1}{x}\displaystyle\int_1^x f(t)\,\mathrm{d}t$，求 $f(x)$

**解**：两边同乘 $x$（把分母化掉）：

$$xf(x)=x+\int_1^xf(t)\,\mathrm{d}t$$

两边求导（左边用乘积求导，右边第二项用变限积分求导）：

$$f(x)+xf'(x)=1+f(x)\ \Longrightarrow\ xf'(x)=1\ \Longrightarrow\ f'(x)=\frac{1}{x}$$

两边积分：$f(x)=\ln|x|+C$。因 $x>0$，取 $f(x)=\ln x+C$。

**定 $C$**：回到原式，取 $x=1$ 使变限积分上下限相等（积分为 $0$）：

$$f(1)=1+\frac{1}{1}\int_1^1f(t)\,\mathrm{d}t=1+0=1$$

代入 $f(1)=\ln1+C=C=1$，得 $C=1$。

$$\boxed{f(x)=\ln x+1}$$

**例 6** 设 $f(x)=\displaystyle\int_1^{\sqrt x}e^{-t^2}\mathrm{d}t$，求 $\displaystyle\int_0^1\frac{f(x)}{\sqrt x}\,\mathrm{d}x$

**解**：先凑微分，$\dfrac{\mathrm{d}x}{\sqrt x}=2\,\mathrm{d}\bigl(\sqrt x\bigr)$，再用分部积分：

$$\int_0^1\frac{f(x)}{\sqrt x}\mathrm{d}x=2\int_0^1f(x)\,\mathrm{d}\bigl(\sqrt x\bigr)
=2\Bigl\{\Bigl[\sqrt x f(x)\Bigr]_0^1-\int_0^1\sqrt x\,f'(x)\,\mathrm{d}x\Bigr\}$$

由 $f(1)=\displaystyle\int_1^{1}e^{-t^2}\mathrm{d}t=0$，第一项为 $0$。再求 $f'(x)$：上限 $\sqrt x$，下限 $1$ 是常数，

$$f'(x)=e^{-(\sqrt x)^2}\cdot\frac{1}{2\sqrt x}-e^{-1}\cdot0=\frac{e^{-x}}{2\sqrt x}$$

代入：

$$=2\Bigl\{0-\int_0^1\sqrt x\cdot\frac{e^{-x}}{2\sqrt x}\mathrm{d}x\Bigr\}=-\int_0^1e^{-x}\mathrm{d}x=\Bigl[e^{-x}\Bigr]_0^1=\frac{1}{e}-1$$

### （P77）无穷区间的反常积分

**例 1** 求 $\displaystyle\int_0^{+\infty}\frac{2026}{1+x^2}\,\mathrm{d}x$

**解**：

$$=2026\Bigl[\arctan x\Bigr]_0^{+\infty}=2026\left(\lim_{x\to+\infty}\arctan x-\arctan0\right)=2026\cdot\frac{\pi}{2}=1013\pi$$

结果为常数，故该广义积分**收敛**。

**例 2** 求 $\displaystyle\int_2^{+\infty}\frac{\mathrm{d}x}{x\ln^2x}$

**解**：凑微分 $\dfrac{\mathrm{d}x}{x}=\mathrm{d}(\ln x)$，

$$=\int_2^{+\infty}\frac{\mathrm{d}(\ln x)}{\ln^2x}=\Bigl[-\frac{1}{\ln x}\Bigr]_2^{+\infty}=-\left(\lim_{x\to+\infty}\frac{1}{\ln x}-\frac{1}{\ln2}\right)=\frac{1}{\ln2}$$

收敛。

**例 3** 求 $\displaystyle\int_0^{+\infty}\frac{x}{(1+x)^3}\,\mathrm{d}x$

**解**：分子**加一减一**：$x=(x+1)-1$，拆项后约去 $(1+x)$：

$$\frac{x}{(1+x)^3}=\frac{1}{(1+x)^2}-\frac{1}{(1+x)^3}$$

$$\int_0^{+\infty}\left[\frac{1}{(1+x)^2}-\frac{1}{(1+x)^3}\right]\mathrm{d}x=\Bigl[-\frac{1}{1+x}+\frac{1}{2(1+x)^2}\Bigr]_0^{+\infty}$$

$$=\left(0+0\right)-\left(-1+\frac{1}{2}\right)=\frac{1}{2}$$

**例 4** 求 $\displaystyle\int_0^{+\infty}\frac{\mathrm{d}x}{\sqrt x\,(1+x)}$

**解**：不必换元，把 $\dfrac{\mathrm{d}x}{\sqrt x}$ 凑成 $2\,\mathrm{d}\bigl(\sqrt x\bigr)$：

$$\int_0^{+\infty}\frac{\mathrm{d}x}{\sqrt x(1+x)}=2\int_0^{+\infty}\frac{\mathrm{d}\bigl(\sqrt x\bigr)}{1+\bigl(\sqrt x\bigr)^2}=2\Bigl[\arctan\sqrt x\Bigr]_0^{+\infty}=2\cdot\frac{\pi}{2}=\pi$$

**例 5**（普通根式代换）求 $\displaystyle\int_2^{+\infty}\frac{\mathrm{d}x}{(x+7)\sqrt{x-2}}$

**解**：令 $\sqrt{x-2}=t$，则 $x=t^2+2$，$\mathrm{d}x=2t\,\mathrm{d}t$，$x+7=t^2+9$。换线：$x=2\to t=0$，$x\to+\infty\to t\to+\infty$。

$$\int_2^{+\infty}\frac{\mathrm{d}x}{(x+7)\sqrt{x-2}}=\int_0^{+\infty}\frac{2t\,\mathrm{d}t}{(t^2+9)t}=2\int_0^{+\infty}\frac{\mathrm{d}t}{t^2+9}$$

套公式 $\displaystyle\int\frac{\mathrm{d}u}{u^2+a^2}=\frac{1}{a}\arctan\frac{u}{a}+C$（此处 $a=3$）：

$$=2\cdot\frac{1}{3}\Bigl[\arctan\frac{t}{3}\Bigr]_0^{+\infty}=\frac{2}{3}\cdot\frac{\pi}{2}=\frac{\pi}{3}$$

**例 6**（三角代换）求 $\displaystyle\int_0^{+\infty}\frac{\mathrm{d}x}{(1+x^2)^2}$

**解**：令 $x=\tan t$，$\mathrm{d}x=\sec^2t\,\mathrm{d}t$，$1+x^2=\sec^2t$。换线：$x=0\to t=0$；$x\to+\infty$ 时 $\tan t\to+\infty$，而 $t$ 被限制在 $\left(-\frac{\pi}{2},\frac{\pi}{2}\right)$，故 $t\to\dfrac{\pi}{2}$。

$$\int_0^{+\infty}\frac{\mathrm{d}x}{(1+x^2)^2}=\int_0^{\frac{\pi}{2}}\frac{\sec^2t}{\sec^4t}\mathrm{d}t=\int_0^{\frac{\pi}{2}}\cos^2t\,\mathrm{d}t$$

用**华里士（点火）公式**：$=\dfrac{1}{2}\cdot\dfrac{\pi}{2}=\dfrac{\pi}{4}$。

**例 7** 求 $\displaystyle\int_0^{+\infty}xe^{-x}\,\mathrm{d}x$，并由此总结一般结论

**解**：凑微分 $\mathrm{d}\bigl(e^{-x}\bigr)=-e^{-x}\mathrm{d}x$，前面补负号，再分部积分：

$$=-\int_0^{+\infty}x\,\mathrm{d}\bigl(e^{-x}\bigr)=-\Bigl[xe^{-x}\Bigr]_0^{+\infty}+\int_0^{+\infty}e^{-x}\mathrm{d}x$$

第一项写成极限：$\displaystyle\lim_{x\to+\infty}\frac{x}{e^{x}}$ 是**无穷比无穷型**，洛必达得 $\displaystyle\lim_{x\to+\infty}\frac{1}{e^{x}}=0$；代入下限得 $0$，故第一项为 $0$。第二项 $\bigl[-e^{-x}\bigr]_0^{+\infty}=0-(-1)=1$。

$$\int_0^{+\infty}xe^{-x}\,\mathrm{d}x=1$$

**一般结论**：

$$\int_0^{+\infty}x^{n}e^{-x}\,\mathrm{d}x=n!$$

例如 $\displaystyle\int_0^{+\infty}x^2e^{-x}\mathrm{d}x=2!=2$，$\displaystyle\int_0^{+\infty}x^{2028}e^{-x}\mathrm{d}x=2028!$。

**例 8** 求 $\displaystyle\int_{-\infty}^{+\infty}\frac{\mathrm{d}x}{x^2+2x+2}$

**解**：分母配方：$x^2+2x+2=(x+1)^2+1$。凑微分 $\mathrm{d}x=\mathrm{d}(x+1)$，令 $u=x+1$：

$$=\int_{-\infty}^{+\infty}\frac{\mathrm{d}(x+1)}{(x+1)^2+1}=\Bigl[\arctan(x+1)\Bigr]_{-\infty}^{+\infty}$$

$$=\lim_{x\to+\infty}\arctan(x+1)-\lim_{x\to-\infty}\arctan(x+1)=\frac{\pi}{2}-\left(-\frac{\pi}{2}\right)=\pi$$

### （P78）瑕积分

**例 1** 求 $\displaystyle\int_{-2}^{1}\frac{\mathrm{d}x}{\sqrt{3-2x-x^2}}$

**解**：先找瑕点。$3-2x-x^2$ 在 $x=1$ 处为 $3-2-1=0$，而上限正是 $1$，故 $x=1$ 是**右端点瑕点**。

配方：$3-2x-x^2=4-(x+1)^2$，把 $3$ 写成 $4-1$ 再提出负号：

$$\int_{-2}^{1}\frac{\mathrm{d}x}{\sqrt{4-(x+1)^2}}=\int_{-1}^{2}\frac{\mathrm{d}u}{\sqrt{4-u^2}}\quad(u=x+1)$$

套公式 $\displaystyle\int\frac{\mathrm{d}u}{\sqrt{a^2-u^2}}=\arcsin\frac{u}{a}+C$（$a=2$）：

$$=\Bigl[\arcsin\frac{x+1}{2}\Bigr]_{-2}^{1}=\lim_{x\to1^-}\arcsin\frac{x+1}{2}-\arcsin\frac{-1}{2}=\frac{\pi}{2}-\left(-\frac{\pi}{6}\right)=\frac{2\pi}{3}$$

（$x=-2$ 代入得 $\arcsin\left(-\frac{1}{2}\right)=-\frac{\pi}{6}$，不是瑕点，可直接代。）

**例 2** 求 $\displaystyle\int_0^1\ln x\,\mathrm{d}x$

**解**：$x=0$ 处 $\ln x$ 无定义（趋于 $-\infty$），是**左端点瑕点**。只有一个函数，直接用分部积分：

$$\int_0^1\ln x\,\mathrm{d}x=\Bigl[x\ln x\Bigr]_0^1-\int_0^1x\cdot\frac{1}{x}\mathrm{d}x$$

第一项：$x=1$ 处为 $1\cdot\ln1=0$；$x=0$ 处写成极限 $\displaystyle\lim_{x\to0^+}x\ln x$，这是 **$0\cdot\infty$ 型**，化成分式 $\dfrac{\ln x}{1/x}$ 变**无穷比无穷型**，洛必达：

$$\lim_{x\to0^+}\frac{\ln x}{x^{-1}}\xlongequal{\text{洛}}\lim_{x\to0^+}\frac{1/x}{-x^{-2}}=\lim_{x\to0^+}(-x)=0$$

第二项：$\displaystyle\int_0^1\mathrm{d}x=1$。故

$$\int_0^1\ln x\,\mathrm{d}x=0-1=-1$$

结果为常数，该瑕积分**收敛**。

**例 3** 判断 $\displaystyle\int_{-1}^{1}\frac{\mathrm{d}x}{x}$ 的敛散性

**解**：$x=0$ 是**区间内部**的瑕点，必须在 $0$ 处拆成两个瑕积分：

$$\int_{-1}^{1}\frac{\mathrm{d}x}{x}=\int_{-1}^{0}\frac{\mathrm{d}x}{x}+\int_0^{1}\frac{\mathrm{d}x}{x}$$

$$\int_{-1}^{0}\frac{\mathrm{d}x}{x}=\Bigl[\ln|x|\Bigr]_{-1}^{0}=\lim_{x\to0^-}\ln|x|-\ln1=-\infty-0=-\infty$$

$$\int_0^{1}\frac{\mathrm{d}x}{x}=\Bigl[\ln|x|\Bigr]_0^{1}=\ln1-\lim_{x\to0^+}\ln|x|=0-(-\infty)=+\infty$$

两个积分**都发散**，故原积分**发散**。

### （P71）直接积分与凑微分（七例）

**例 1**（直接积分）$\displaystyle\int_0^{\frac{\pi}{2}}\cos x\,\mathrm{d}x$

**解**：先积出原函数 $\sin x$，再代入：

$$\Bigl[\sin x\Bigr]_0^{\frac{\pi}{2}}=\sin\frac{\pi}{2}-\sin 0=1-0=1$$

**例 2**（直接积分·反三角函数）$\displaystyle\int_{-1}^{\sqrt3}\frac{\mathrm{d}x}{1+x^2}$

**解**：

$$\Bigl[\arctan x\Bigr]_{-1}^{\sqrt3}=\arctan\sqrt3-\arctan(-1)=\frac{\pi}{3}-\left(-\frac{\pi}{4}\right)=\frac{7\pi}{12}$$

**反三角函数值的求法**（P71）：设 $\arctan\sqrt3=A$，两边取 $\tan$ 得 $\tan A=\sqrt3$，故 $A=\dfrac{\pi}{3}$。

**例 3**（凑微分）$\displaystyle\int_0^1xe^{x^2}\,\mathrm{d}x$

**解**：$\mathrm{d}(x^2)=2x\,\mathrm{d}x$，故补 $\dfrac{1}{2}$：

$$\int_0^1xe^{x^2}\mathrm{d}x=\frac{1}{2}\int_0^1e^{x^2}\mathrm{d}(x^2)=\frac{1}{2}\Bigl[e^{x^2}\Bigr]_0^1=\frac{1}{2}(e-1)$$

**例 4**（凑微分·两种解法）$\displaystyle\int_0^{\frac{\pi}{2}}\sin x\cos x\,\mathrm{d}x$

**解一**：把 $\cos x$ 凑进去：

$$\int_0^{\frac{\pi}{2}}\sin x\,\mathrm{d}(\sin x)=\frac{1}{2}\Bigl[\sin^2x\Bigr]_0^{\frac{\pi}{2}}=\frac{1}{2}(1-0)=\frac{1}{2}$$

**解二**（二倍角）：$\sin x\cos x=\dfrac{1}{2}\sin 2x$，

$$\frac{1}{4}\int_0^{\frac{\pi}{2}}\sin 2x\,\mathrm{d}(2x)=\frac{1}{4}\Bigl[-\cos 2x\Bigr]_0^{\frac{\pi}{2}}=\frac{1}{4}\left(1+1\right)=\frac{1}{2}$$

> 老师说积分题「**方法并不唯一**」，「积分呢，其实是比较灵活的，我们一定要选取自己熟悉的方法」（P71）。

**例 5**（凑微分）$\displaystyle\int_0^{\frac{\pi^2}{4}}\frac{\cos\sqrt{x}}{\sqrt{x}}\,\mathrm{d}x$

**解**：$\mathrm{d}(\sqrt{x})=\dfrac{1}{2\sqrt{x}}\mathrm{d}x$，故补 $2$：

$$2\int_0^{\frac{\pi^2}{4}}\cos\sqrt{x}\,\mathrm{d}(\sqrt{x})=2\Bigl[\sin\sqrt{x}\Bigr]_0^{\frac{\pi}{2}}=2\left(\sin\frac{\pi}{2}-\sin 0\right)=2$$

**例 6**（凑微分·二次凑）$\displaystyle\int_0^1\frac{\arctan\sqrt{x}}{(1+x)\sqrt{x}}\,\mathrm{d}x$

**解**：把 $\dfrac{1}{\sqrt{x}}$ 凑成 $\mathrm{d}(\sqrt{x})$ 并补 $2$；注意 $1+x=1+(\sqrt{x})^2$，于是

$$2\int_0^1\arctan\sqrt{x}\cdot\frac{\mathrm{d}(\sqrt{x})}{1+(\sqrt{x})^2}=2\int_0^1\arctan\sqrt{x}\,\mathrm{d}\left(\arctan\sqrt{x}\right)$$

$$=\Bigl[\left(\arctan\sqrt{x}\right)^2\Bigr]_0^1=\left(\frac{\pi}{4}\right)^2-0=\frac{\pi^2}{16}$$

> 老师说这一步「**很不容易想得到**」，「如果大家对这种凑微分掌握得不扎实的话，那么这个过程看起来还是没那么容易」（P71）。

**例 7**（凑微分）$\displaystyle\int_0^1\frac{x}{\sqrt{4-x^2}}\,\mathrm{d}x$

**解**：$\mathrm{d}(4-x^2)=-2x\,\mathrm{d}x$，故补 $-\dfrac{1}{2}$：

$$-\frac{1}{2}\int_0^1\frac{\mathrm{d}(4-x^2)}{\sqrt{4-x^2}}=-\frac{1}{2}\cdot 2\Bigl[\sqrt{4-x^2}\Bigr]_0^1=-\left(\sqrt3-2\right)=2-\sqrt3$$

### （P71）简单根式代换（三例）

**例 1** $\displaystyle\int_1^{3}\frac{\mathrm{d}x}{\sqrt{x}(1+x)}$

**解**：令 $\sqrt{x}=t$，则 $x=t^2$、$\mathrm{d}x=2t\,\mathrm{d}t$；**换线**：$x=1\Rightarrow t=1$，$x=3\Rightarrow t=\sqrt3$。

$$\int_1^{\sqrt3}\frac{2t\,\mathrm{d}t}{t\left(1+t^2\right)}=2\int_1^{\sqrt3}\frac{\mathrm{d}t}{1+t^2}=2\Bigl[\arctan t\Bigr]_1^{\sqrt3}=2\left(\frac{\pi}{3}-\frac{\pi}{4}\right)=\frac{\pi}{6}$$

**例 2** $\displaystyle\int_0^{\ln 2}\sqrt{e^x-1}\,\mathrm{d}x$

**解**：令 $\sqrt{e^x-1}=t$，两边平方得 $e^x=t^2+1$，取对数 $x=\ln\left(1+t^2\right)$，故

$$\mathrm{d}x=\frac{2t}{1+t^2}\mathrm{d}t$$

**换线**：$x=0\Rightarrow t=0$；$x=\ln 2\Rightarrow e^x=2\Rightarrow t=\sqrt{2-1}=1$。

$$\int_0^1t\cdot\frac{2t}{1+t^2}\mathrm{d}t=2\int_0^1\frac{t^2}{1+t^2}\mathrm{d}t=2\int_0^1\left(1-\frac{1}{1+t^2}\right)\mathrm{d}t$$

$$=2\Bigl[t-\arctan t\Bigr]_0^1=2\left(1-\frac{\pi}{4}\right)$$

（关键一步：$\dfrac{t^2}{1+t^2}=\dfrac{t^2+1-1}{1+t^2}=1-\dfrac{1}{1+t^2}$。）

**例 3** $\displaystyle\int_1^{5}\frac{x}{\sqrt{2x-1}}\,\mathrm{d}x$

**解**：令 $\sqrt{2x-1}=t$，则 $2x-1=t^2$，即 $x=\dfrac{t^2+1}{2}$，$\mathrm{d}x=t\,\mathrm{d}t$。

**换线**：$x=1\Rightarrow t=1$；$x=5\Rightarrow t=\sqrt{9}=3$。

$$\int_1^3\frac{\left(t^2+1\right)/2}{t}\cdot t\,\mathrm{d}t=\frac{1}{2}\int_1^3\left(t^2+1\right)\mathrm{d}t=\frac{1}{2}\Bigl[\frac{t^3}{3}+t\Bigr]_1^3=\frac{1}{2}\left(12-\frac{4}{3}\right)=\frac{16}{3}$$

### （P71）三角代换（两例）

**例 1** $\displaystyle\int_{\frac{\sqrt2}{2}}^{1}\frac{\sqrt{1-x^2}}{x^2}\,\mathrm{d}x$

**解**：含 $\sqrt{1-x^2}$，令 $x=\sin t$，$\mathrm{d}x=\cos t\,\mathrm{d}t$。**换线**：$x=\dfrac{\sqrt2}{2}\Rightarrow t=\dfrac{\pi}{4}$；$x=1\Rightarrow t=\dfrac{\pi}{2}$。

$$\int_{\frac{\pi}{4}}^{\frac{\pi}{2}}\frac{\cos t}{\sin^2t}\cdot\cos t\,\mathrm{d}t=\int_{\frac{\pi}{4}}^{\frac{\pi}{2}}\cot^2t\,\mathrm{d}t=\int_{\frac{\pi}{4}}^{\frac{\pi}{2}}\left(\csc^2t-1\right)\mathrm{d}t$$

$$=\Bigl[-\cot t-t\Bigr]_{\frac{\pi}{4}}^{\frac{\pi}{2}}=\left(0-\frac{\pi}{2}\right)-\left(-1-\frac{\pi}{4}\right)=1-\frac{\pi}{4}$$

（用到 $\sqrt{1-\sin^2t}=\cos t$ 不带绝对值；$\cot^2t=\csc^2t-1$。）

**例 2** $\displaystyle\int_1^{\sqrt3}\frac{\mathrm{d}x}{x^2\sqrt{1+x^2}}$

**解**：含 $\sqrt{1+x^2}$，令 $x=\tan t$，$\mathrm{d}x=\sec^2t\,\mathrm{d}t$。**换线**：$x=1\Rightarrow t=\dfrac{\pi}{4}$；$x=\sqrt3\Rightarrow t=\dfrac{\pi}{3}$。

$$\int_{\frac{\pi}{4}}^{\frac{\pi}{3}}\frac{\sec^2t}{\tan^2t\cdot\sec t}\mathrm{d}t=\int_{\frac{\pi}{4}}^{\frac{\pi}{3}}\frac{\sec t}{\tan^2t}\mathrm{d}t=\int_{\frac{\pi}{4}}^{\frac{\pi}{3}}\frac{\cos t}{\sin^2t}\mathrm{d}t$$

$$=\int_{\frac{\pi}{4}}^{\frac{\pi}{3}}\frac{\mathrm{d}(\sin t)}{\sin^2t}=\Bigl[-\frac{1}{\sin t}\Bigr]_{\frac{\pi}{4}}^{\frac{\pi}{3}}=-\frac{2}{\sqrt3}+\sqrt2=\sqrt2-\frac{2\sqrt3}{3}$$

（化简关键：$\dfrac{\sec t}{\tan^2t}=\dfrac{1/\cos t}{\sin^2t/\cos^2t}=\dfrac{\cos t}{\sin^2t}$。老师说「遇到这种呢，我们尽量把它画成我们所熟悉的 $\sin$ 和 $\cos$」。）

**课后练习**（老师公布答案，未讲过程）：$\ln\left(2+\sqrt3\right)-\dfrac{\sqrt3}{2}$。

### （P73）对称区间「偶倍奇零」（九例）

**例 1** $\displaystyle\int_{-1}^{1}\frac{x^2\sin x}{\cos x}\,\mathrm{d}x$

**解**：$x^2$（偶）× $\sin x$（奇）× $\dfrac{1}{\cos x}$（偶）= **奇函数**，对称区间上积分为 $0$。

**例 2** $\displaystyle\int_{-1}^{1}\left(x^2\tan x+5x^4\right)\mathrm{d}x$

**解**：拆成两项。$x^2\tan x$ 是奇函数 ⇒ 积分为 $0$；$5x^4$ 是偶函数 ⇒ 偶倍奇零：

$$\int_{-1}^{1}5x^4\,\mathrm{d}x=2\cdot 5\Bigl[\frac{x^5}{5}\Bigr]_0^1=2$$

**例 3** $\displaystyle\int_{-2}^{2}x\bigl[f(x)+f(-x)\bigr]\mathrm{d}x+\int_{-2}^{2}x^2\,\mathrm{d}x$

**解**：$f(x)+f(-x)$ 是**偶函数**（把 $x$ 换成 $-x$ 表达式不变），偶 × $x$（奇）= 奇 ⇒ 第一个积分为 $0$。第二个用偶倍奇零：

$$\int_{-2}^{2}x^2\,\mathrm{d}x=2\Bigl[\frac{x^3}{3}\Bigr]_0^2=2\cdot\frac{8}{3}=\frac{16}{3}$$

**例 4** $\displaystyle\int_{-1}^{1}\left(\frac{2}{1+x^2}+\frac{\sin x}{1+x^2}\right)\mathrm{d}x$

**解**：拆开。$\dfrac{\sin x}{1+x^2}$ 是奇函数（奇 ÷ 偶）⇒ 积分为 $0$。前一项是偶函数：

$$2\int_{-1}^{1}\frac{\mathrm{d}x}{1+x^2}\ \xrightarrow{\ \text{偶倍奇零}\ }\ 2\cdot 2\int_0^1\frac{\mathrm{d}x}{1+x^2}=4\Bigl[\arctan x\Bigr]_0^1=4\cdot\frac{\pi}{4}=\pi$$

> 老师说这类题「考选择，和填空，考的比较多」，「尤其是填空题，他给你一个很复杂的积分，让 you 去计算它的结果，但实际上你不用去进行计算」（P73）。

**例 5** $\displaystyle\int_{-1}^{1}\left(\sqrt{1-x^2}+x\right)^2\mathrm{d}x$

**解**：展开平方：

$$\left(\sqrt{1-x^2}\right)^2+2x\sqrt{1-x^2}+x^2=\left(1-x^2\right)+2x\sqrt{1-x^2}+x^2$$

$-x^2$ 与 $+x^2$ **正好抵消**，剩下 $1+2x\sqrt{1-x^2}$；其中 $2x\sqrt{1-x^2}$ 是奇函数 ⇒ 积分为 $0$：

$$\int_{-1}^{1}1\,\mathrm{d}x=1-(-1)=2$$

**例 6** $\displaystyle\int_{-\frac{\pi}{2}}^{\frac{\pi}{2}}\sin^2x\cos^2x\,\mathrm{d}x$

**解**：被积函数是偶函数（偶 × 偶）⇒ 偶倍奇零，变成 $0$ 到 $\dfrac{\pi}{2}$ 上的 $2$ 倍。把 $\cos^2x$ 写成 $1-\sin^2x$ 后拆开，两项都用华里士公式：

$$2\int_0^{\frac{\pi}{2}}\sin^2x\left(1-\sin^2x\right)\mathrm{d}x=2\left(\frac{1}{2}\cdot\frac{\pi}{2}-\frac{3}{4}\cdot\frac{1}{2}\cdot\frac{\pi}{2}\right)=2\left(\frac{\pi}{4}-\frac{3\pi}{16}\right)=\frac{\pi}{8}$$

**例 7** $\displaystyle\int_{-a}^{a}x\sqrt{a^2-x^2}\,\mathrm{d}x+\int_{-a}^{a}\sqrt{a^2-x^2}\,\mathrm{d}x$

**解**：第一项是奇函数（$x$）× 偶函数（$\sqrt{a^2-x^2}$）= 奇 ⇒ $0$。第二项是偶函数，且 $\displaystyle\int_0^{a}\sqrt{a^2-x^2}\,\mathrm{d}x$ 就是**四分之一圆面积**：

$$0+2\cdot\frac{\pi a^2}{4}=\frac{\pi a^2}{2}$$

**例 8** $\displaystyle\int_{-2}^{2}\left(x^3\cos x+\frac{1}{2}\sqrt{4-x^2}\right)\mathrm{d}x$

**解**：$x^3\cos x$ 是奇函数 ⇒ $0$；$\dfrac{1}{2}\sqrt{4-x^2}$ 是偶函数：

$$2\int_0^2\frac{1}{2}\sqrt{4-x^2}\,\mathrm{d}x=\int_0^2\sqrt{4-x^2}\,\mathrm{d}x=\frac{\pi\cdot 2^2}{4}=\pi$$

**例 9** $\displaystyle\int_{-1}^{1}\frac{x^2}{1+\sqrt{1-x^2}}\,\mathrm{d}x$

**解**：被积函数是偶函数 ⇒ 偶倍奇零，先化成 $2\displaystyle\int_0^1$。再用**分母有理化**（分子分母同乘 $1-\sqrt{1-x^2}$）：

$$\frac{x^2}{1+\sqrt{1-x^2}}\cdot\frac{1-\sqrt{1-x^2}}{1-\sqrt{1-x^2}}=\frac{x^2\left(1-\sqrt{1-x^2}\right)}{1-\left(1-x^2\right)}=\frac{x^2\left(1-\sqrt{1-x^2}\right)}{x^2}=1-\sqrt{1-x^2}$$

$$2\int_0^1\left(1-\sqrt{1-x^2}\right)\mathrm{d}x=2\left(1-\frac{\pi}{4}\right)$$

（$\displaystyle\int_0^1\sqrt{1-x^2}\,\mathrm{d}x=\frac{\pi}{4}$ 是四分之一圆面积。）老师说这题三角代换也能做，但有理化更快。

### （P73）华里士（点火）公式（五例）

**例 1** $\displaystyle\int_0^{\frac{\pi}{2}}\left(\sin^4x+\cos^3x\right)\mathrm{d}x$

**解**：$\sin^4x$ 是偶次 ⇒ $\dfrac{3}{4}\cdot\dfrac{1}{2}\cdot\dfrac{\pi}{2}=\dfrac{3\pi}{16}$；$\cos^3x$ 是奇次 ⇒ $\dfrac{2}{3}\cdot 1=\dfrac{2}{3}$。和为

$$\frac{2}{3}+\frac{3\pi}{16}$$

**例 2** $\displaystyle\int_0^{\pi}\left(\sin^2x+\cos^3x\right)\mathrm{d}x$

**解**：$0\to\pi$ 上的 $\sin^n$ 一律写成 $2\displaystyle\int_0^{\frac{\pi}{2}}$；$0\to\pi$ 上的 $\cos^n$ 要看奇偶，**奇次直接为 $0$**。所以

$$2\cdot\frac{1}{2}\cdot\frac{\pi}{2}+0=\frac{\pi}{2}$$

**例 3** $\displaystyle\int_0^{\pi}\left(\sin^3x+\cos^4x\right)\mathrm{d}x$

**解**：$\sin^3x$ 在 $0\to\pi$ 上写成 $2\displaystyle\int_0^{\frac{\pi}{2}}$：$2\cdot\dfrac{2}{3}\cdot 1=\dfrac{4}{3}$；$\cos^4x$ 是偶次，同样写成 $2\displaystyle\int_0^{\frac{\pi}{2}}$：$2\cdot\dfrac{3}{4}\cdot\dfrac{1}{2}\cdot\dfrac{\pi}{2}=\dfrac{3\pi}{8}$。和为

$$\frac{4}{3}+\frac{3\pi}{8}$$

**例 4** $\displaystyle\int_0^1x^4\sqrt{1-x^2}\,\mathrm{d}x$

**解**：令 $x=\sin t$，$\mathrm{d}x=\cos t\,\mathrm{d}t$；**换线** $x=0\Rightarrow t=0$，$x=1\Rightarrow t=\dfrac{\pi}{2}$；且 $\sqrt{1-\sin^2t}=\cos t$。

$$\int_0^{\frac{\pi}{2}}\sin^4t\cdot\cos t\cdot\cos t\,\mathrm{d}t=\int_0^{\frac{\pi}{2}}\sin^4t\left(1-\sin^2t\right)\mathrm{d}t$$

$$=\int_0^{\frac{\pi}{2}}\sin^4t\,\mathrm{d}t-\int_0^{\frac{\pi}{2}}\sin^6t\,\mathrm{d}t=\frac{3\pi}{16}-\frac{5\pi}{32}=\frac{\pi}{32}$$

**例 5** $\displaystyle\int_0^2\sqrt{2x-x^2}\,\mathrm{d}x$

**解**：先配方，$2x-x^2=1-(x-1)^2$，再令 $x-1=\sin t$——**这是三角代换的拓展形式**，「不是 $x$ 它就是一个数……实际上 $1$ 减去 $x$，任何一个形式，它都可以去做换元」（P73）。

**换线**：$x=0\Rightarrow t=-\dfrac{\pi}{2}$；$x=2\Rightarrow t=\dfrac{\pi}{2}$。

$$\int_{-\frac{\pi}{2}}^{\frac{\pi}{2}}\sqrt{1-\sin^2t}\cdot\cos t\,\mathrm{d}t=\int_{-\frac{\pi}{2}}^{\frac{\pi}{2}}\cos^2t\,\mathrm{d}t\ \xrightarrow{\ \text{偶倍奇零}\ }\ 2\int_0^{\frac{\pi}{2}}\cos^2t\,\mathrm{d}t=2\cdot\frac{1}{2}\cdot\frac{\pi}{2}=\frac{\pi}{2}$$

> 这与「**计算技巧一：四分之一圆面积**」的结论一致——$\displaystyle\int_0^2\sqrt{2x-x^2}\,\mathrm{d}x$ 就是**半径 1 的半个圆面积** $\dfrac{\pi}{2}$。老师特意做了两条路的对照：「既可以从几何的角度去推导这个答案，也可以从这种数学的推导过程来计算这个答案」（P73）。

### （P74）分段函数积分（八例）

**例 1** 设 $f(x)=\begin{cases}e^x,&x<1\\[4pt]\ln x,&x\ge1\end{cases}$，求 $\displaystyle\int_0^{e}f(x)\,\mathrm{d}x$

**解**：分段点 $x=1$ 在区间 $(0,e)$ 内，切开：

$$\int_0^1e^x\,\mathrm{d}x+\int_1^{e}\ln x\,\mathrm{d}x=(e-1)+1=e$$

（第二项分部积分：$\displaystyle\int_1^{e}\ln x\,\mathrm{d}x=\Bigl[x\ln x-x\Bigr]_1^{e}=(e-e)-(0-1)=1$。）

**例 2** 设 $f(x)=\begin{cases}\dfrac{1}{1+e^x},&x\le0\\[10pt]\dfrac{1}{1+x},&x>0\end{cases}$，求 $\displaystyle\int_{-1}^{1}f(x)\,\mathrm{d}x$

**解**：分段点 $x=0$ 在区间内，切开。

前半：$\dfrac{1}{1+e^x}=\dfrac{1+e^x-e^x}{1+e^x}=1-\dfrac{e^x}{1+e^x}$，故

$$\int_{-1}^{0}\left(1-\frac{e^x}{1+e^x}\right)\mathrm{d}x=\Bigl[x-\ln\left(1+e^x\right)\Bigr]_{-1}^{0}=-\ln 2+1+\ln\left(1+e^{-1}\right)$$

后半：$\displaystyle\int_0^1\frac{\mathrm{d}x}{1+x}=\Bigl[\ln(1+x)\Bigr]_0^1=\ln 2$。

相加，$-\ln 2$ 与 $+\ln 2$ **正好抵消**：

$$\int_{-1}^{1}f(x)\,\mathrm{d}x=1+\ln\left(1+e^{-1}\right)$$

**例 3** 设 $f(x)=\begin{cases}\dfrac{\sin x}{1+\cos^2x},&x\le0\\[10pt]x\sin^2x,&x>0\end{cases}$，求 $\displaystyle\int_0^{2\pi}x\,f(x-\pi)\,\mathrm{d}x$

**解**：**第一步不是分段，而是变量替换**。令 $u=x-\pi$，则 $x=u+\pi$、$\mathrm{d}x=\mathrm{d}u$；**换线**：$x=0\Rightarrow u=-\pi$，$x=2\pi\Rightarrow u=\pi$。

$$\int_0^{2\pi}x\,f(x-\pi)\,\mathrm{d}x=\int_{-\pi}^{\pi}f(u)\,\mathrm{d}u$$

现在分段点 $0$ 落在 $(-\pi,\pi)$ 内，切开：

$$\int_{-\pi}^{0}\frac{\sin u}{1+\cos^2u}\mathrm{d}u+\int_0^{\pi}u\sin^2u\,\mathrm{d}u$$

前半：把 $\sin u$ 凑进微分号（$\mathrm{d}(\cos u)=-\sin u\,\mathrm{d}u$）：

$$\int_{-\pi}^{0}\frac{\sin u}{1+\cos^2u}\mathrm{d}u=\Bigl[-\arctan(\cos u)\Bigr]_{-\pi}^{0}=-\frac{\pi}{4}-\frac{\pi}{4}=-\frac{\pi}{2}$$

后半：用降幂公式 $\sin^2u=\dfrac{1-\cos 2u}{2}$，

$$\int_0^{\pi}u\sin^2u\,\mathrm{d}u=\frac{1}{2}\int_0^{\pi}u\,\mathrm{d}u-\frac{1}{2}\int_0^{\pi}u\cos 2u\,\mathrm{d}u=\frac{\pi^2}{4}-0=\frac{\pi^2}{4}$$

（后一项分部积分后 $\Bigl[\dfrac{u\sin 2u}{2}+\dfrac{\cos 2u}{4}\Bigr]_0^{\pi}=0$。）结果：

$$\frac{\pi^2}{4}-\frac{\pi}{2}$$

**例 4** 设 $f(x)=\begin{cases}e^x,&x\le0\\[4pt]1+\sin x,&x>0\end{cases}$，求 $\displaystyle\int_{\frac12}^{2}f(1-x)\,\mathrm{d}x$

**解**：同样先换元。令 $u=1-x$，则 $\mathrm{d}x=-\mathrm{d}u$；**换线**：$x=\dfrac{1}{2}\Rightarrow u=\dfrac{1}{2}$，$x=2\Rightarrow u=-1$。

$$\int_{\frac12}^{2}f(1-x)\,\mathrm{d}x=\int_{-1}^{\frac12}f(u)\,\mathrm{d}u$$

（用 $\displaystyle\int_a^b=-\int_b^a$ 把上下限摆正。）分段点 $0$ 在 $\left(-1,\dfrac{1}{2}\right)$ 内：

$$\int_{-1}^{0}e^u\,\mathrm{d}u+\int_0^{\frac12}\left(1+\sin u\right)\mathrm{d}u=\left(1-e^{-1}\right)+\left[\frac{1}{2}-\cos\frac{1}{2}+1\right]=\frac{5}{2}-e^{-1}-\cos\frac{1}{2}$$

**例 5**（$\max$ 型）求 $\displaystyle\int_{-1}^{1}\max\left\{1,e^x\right\}\mathrm{d}x$

**解**：画图比较，$e^x$ 与 $1$ 交于 $x=0$，故

$$\max\left\{1,e^x\right\}=\begin{cases}1,&x\le0\\[4pt] e^x,&x>0\end{cases}\qquad\Longrightarrow\qquad
\int_{-1}^{0}1\,\mathrm{d}x+\int_0^1e^x\,\mathrm{d}x=1+(e-1)=e$$

**例 6**（$\lvert\cdot\rvert$ 型）求 $\displaystyle\int_{-1}^{1}\lvert 2x-1\rvert\,\mathrm{d}x$

**解**：零点 $x=\dfrac{1}{2}$，故

$$\int_{-1}^{\frac12}(1-2x)\,\mathrm{d}x+\int_{\frac12}^{1}(2x-1)\,\mathrm{d}x=\Bigl[x-x^2\Bigr]_{-1}^{\frac12}+\Bigl[x^2-x\Bigr]_{\frac12}^{1}=\frac{1}{4}+2+\frac{1}{4}=\frac{5}{2}$$

**例 7**（★ 高频）求 $\displaystyle\int_0^{\frac{\pi}{2}}\sqrt{1-\sin 2x}\,\mathrm{d}x$

**解**：$1=\cos^2x+\sin^2x$，$\sin 2x=2\sin x\cos x$，所以

$$1-\sin 2x=\cos^2x-2\sin x\cos x+\sin^2x=\left(\cos x-\sin x\right)^2$$

**开方必须加绝对值**：

$$\sqrt{1-\sin 2x}=\lvert\cos x-\sin x\rvert$$

画图找变号点：$\cos x=\sin x$ 在 $\left[0,\dfrac{\pi}{2}\right]$ 上只有 $x=\dfrac{\pi}{4}$。

- $x\in\left[0,\dfrac{\pi}{4}\right]$：$\cos x$ 在上，$\cos x-\sin x\ge0$
- $x\in\left[\dfrac{\pi}{4},\dfrac{\pi}{2}\right]$：$\sin x$ 在上，$\cos x-\sin x\le0$

$$\int_0^{\frac{\pi}{4}}\left(\cos x-\sin x\right)\mathrm{d}x-\int_{\frac{\pi}{4}}^{\frac{\pi}{2}}\left(\cos x-\sin x\right)\mathrm{d}x$$

$$=\Bigl[\sin x+\cos x\Bigr]_0^{\frac{\pi}{4}}-\Bigl[\sin x+\cos x\Bigr]_{\frac{\pi}{4}}^{\frac{\pi}{2}}=\left(\sqrt2-1\right)-\left(1-\sqrt2\right)=2\sqrt2-2$$

> 老师说这题「很多省份都是有考过的，请大家一定要引起重视」（P74）。

**例 8**（课后练习）老师留的第 6 题未讲过程，公布答案为 $\dfrac{8}{3}\left(2+\sqrt2\right)$。

### （P80）旋转体的体积（四例）

**例 1**（X 型绕 $x$ 轴·一条曲线）由 $y=e^x$、$x=1$ 及两条坐标轴围成的图形，绕 $x$ 轴旋转一周，求体积。

**解**：先画图——图形由 $x=0$（$y$ 轴）、$x=1$、$y=e^x$、$y=0$（$x$ 轴）围成，是 X 型且只有**一条**曲线，下曲线 $y=0$ 的平方为 $0$，故用 $V_x=\pi\displaystyle\int_a^bf^2(x)\mathrm{d}x$，积分区间 $[0,1]$：

$$V=\pi\int_0^1\left(e^x\right)^2\mathrm{d}x=\pi\int_0^1e^{2x}\mathrm{d}x=\frac{\pi}{2}\Bigl[e^{2x}\Bigr]_0^1=\frac{\pi}{2}\left(e^2-1\right)$$

（凑微分：$\mathrm{d}(2x)=2\mathrm{d}x$，补 $\dfrac{1}{2}$。）

**例 2**（X 型绕 $x$ 轴·两条曲线）求直线 $y=x$ 与抛物线 $x=y^2$ 所围图形绕 $x$ 轴旋转一周的体积。

**解**：画图后先**联立求交点**：$\begin{cases}y=x\\x=y^2\end{cases}$ 得 $(0,0)$ 与 $(1,1)$，积分区间 $[0,1]$。

**关键一步**：X 型的积分变量是 $x$，所以要把 $x=y^2$ 改写成 $y=\sqrt x$（**不能直接写 $y^2$**）。上曲线 $y=\sqrt x$，下曲线 $y=x$：

$$V=\pi\int_0^1\left[\left(\sqrt x\right)^2-x^2\right]\mathrm{d}x=\pi\int_0^1\left(x-x^2\right)\mathrm{d}x=\pi\left(\frac{1}{2}-\frac{1}{3}\right)=\frac{\pi}{6}$$

**例 3**（X 型绕 $y$ 轴·柱壳法）$y=\sin x$（$0\le x\le\pi$）与 $x$ 轴围成的图形绕 $y$ 轴旋转一周，求体积。

**解**：X 型绕 $y$ 轴，用柱壳法 $V_y=2\pi\displaystyle\int_a^bx\,f(x)\mathrm{d}x$：

$$V=2\pi\int_0^{\pi}x\sin x\,\mathrm{d}x$$

分部积分（幂 × 三角，$x$ 设为 $u$）：

$$\int_0^{\pi}x\sin x\,\mathrm{d}x=\Bigl[-x\cos x\Bigr]_0^{\pi}+\int_0^{\pi}\cos x\,\mathrm{d}x=\pi+0=\pi$$

所以

$$V=2\pi\cdot\pi=2\pi^2$$

**例 4**（X 型绕 $y$ 轴·两条曲线）由 $y=x^2$、$y=2-x^2$ 及 $y$ 轴（取 $x>0$）围成的图形绕 $y$ 轴旋转一周，求体积。

**解**：联立 $y=x^2$ 与 $y=2-x^2$ 得 $x^2=1$，交点为 $(\pm1,1)$；只取第一象限（$x>0$），积分区间 $[0,1]$。上曲线 $y=2-x^2$，下曲线 $y=x^2$：

$$V=2\pi\int_0^1x\left[\left(2-x^2\right)-x^2\right]\mathrm{d}x=2\pi\int_0^1x\left(2-2x^2\right)\mathrm{d}x=4\pi\int_0^1\left(x-x^3\right)\mathrm{d}x$$

$$=4\pi\left[\frac{x^2}{2}-\frac{x^4}{4}\right]_0^1=4\pi\left(\frac{1}{2}-\frac{1}{4}\right)=4\pi\cdot\frac{1}{4}=\pi$$

## 四、易错点警示

| ❌ 易错 | ✅ 正确 |
|:---|:---|
| 交换积分上下限，结果不变 | 交换上下限，结果要变成**相反数**：$\int_a^b=-\int_b^a$ |
| 认为 $\int_a^a f(x)\mathrm{d}x$ 还要算 | 上下限相同直接等于 $0$，与被积函数无关 |
| 定积分与不定积分混为一谈 | 定积分是一个**数**，不定积分是一个**函数**（带 $+C$） |
| 定积分结果与积分变量字母有关 | 只与被积函数和积分区间有关：$\int_a^b f(u)\mathrm{d}u=\int_a^b f(t)\mathrm{d}t$ |
| 反常积分直接把 $+\infty$ 代入原函数 | 必须写成**极限**形式：$\lim\limits_{x\to+\infty}F(x)$ |
| 瑕点在区间内部时，直接代入求值 | 必须在瑕点处**拆成两个瑕积分**分别计算 |
| 拆成两个反常积分后，只看其中一个收敛就判收敛 | **两个都收敛**才收敛；有一个发散即发散 |
| 分段函数/带绝对值函数直接整体积分求面积 | 求面积时用"高 − 低"，或分段加绝对值 |
| 变限积分求导，忘记乘上限（下限）的导数 | $\dfrac{\mathrm{d}}{\mathrm{d}x}\int_{u}^{v}f=f(v)v'-f(u)u'$ |
| 被积函数含 $x$ 时直接把上限代入（如 $\int_0^x(x-t)f(t)\mathrm{d}t$） | 先**拆项**或**换元**，把 $x$ 从被积函数中赶出去 |
| 定积分换元后不换上下限 | 换元必须**换线**，上下限跟着新变量重新算 |
| 分部积分时把系数只乘在前一项上 | 系数「是跟着这个积分**整体**的」，后面积分项也要乘 |
| 分部积分选错 $u$ | 按「反、对、幂、指、三」顺序，排前者设为 $u$ |
| 求面积忘记先求交点 | 交点决定积分区间，**必须先联立求交点** |
| 图形上下（左右）曲线表达式会变，仍当成一个 X 型（Y 型） | 说明它**不是**该类型，要拆成两个分别算 |
| 拿到图形不画图就硬套公式 | 必须先**画图**，再判断 X 型 / Y 型 |
| 看到对称区间还想硬算 | 对称区间 → 立刻想「**偶倍奇零**」；奇函数直接 $0$，偶函数变一半再乘 2 |
| 把「偶 ± 奇」也当成奇函数去判 $0$ | 偶 ± 奇是**非奇非偶**，不能用偶倍奇零；能判 $0$ 的是**偶 × 奇**（结果是奇函数） |
| 凑微分时引入了新字母 $t$ 却不换线 | 只要令了新变量就**必须换线**；不令新变量（看作整体）才可沿用原上下限 |
| 根式代换只换元不换线 | **换元必换线**，这一步在 8 分的题里值 3–4 分 |
| 三角代换开方后随手写 $\sqrt{1-\sin^2t}=\pm\cos t$ | 由 $t$ 的范围保证 $\cos t\ge0$，直接写 $\cos t$；但**一般式** $\sqrt{u^2}=\lvert u\rvert$ 的绝对值**不能丢** |
| 分段函数不看分段点在不在积分区间内就切 | 先确认 $c\in[a,b]$ 再切；不在区间内就不用切 |
| 被积函数是 $f(x-\pi)$ 这类复合形式就直接分段 | 先做变量替换化成 $f(u)$，**同时换线**，再分段 |
| $\lvert f(x)\rvert$ 去掉绝对值时不找零点 | 先求零点（与 $x$ 轴的交点），画图分区间，负段**加负号** |
| $\sqrt{(\cos x-\sin x)^2}$ 直接写成 $\cos x-\sin x$ | 必须写 $\lvert\cos x-\sin x\rvert$，再找变号点分段 |
| 旋转体绕 $y$ 轴时仍用 $\pi\int f^2\mathrm{d}x$ | 绕 $x$ 轴用 $\pi\int f^2(x)\mathrm{d}x$；绕 $y$ 轴用**柱壳法** $2\pi\int x f(x)\mathrm{d}x$ |
| 柱壳法把半径写成 $f(x)$ | 半径是**微元中心到旋转轴的距离**（绕 $y$ 轴时为 $x$），高才是 $f(x)$ |
| 两条曲线围成的旋转体忘记相减 | $V_x=\pi\int(f^2-g^2)\mathrm{d}x$、$V_y=2\pi\int x(f-g)\mathrm{d}x$ |
| 做旋转体题不画图 | 必须先**画图**——「图都画不出来，然后就把题做出来了，这种是不可能的」 |

## 五、小结

| 考点 | 要点 |
|:---|:---|
| 定积分定义 | 分割 → 求和 → 取极限，$\lambda=\max\{\Delta x_i\}\to0$ |
| 记号与读法 | $a$ 下限、$b$ 上限、$f(x)$ 被积函数、$x$ 积分变量；结果与变量字母无关 |
| 几何意义 | 上方为正、下方为负、有正有负则相减；本质是求面积 |
| 重要技巧一 | $\int_0^a\sqrt{a^2-x^2}=\frac14\pi a^2$，$\int_{-a}^a\sqrt{a^2-x^2}=\frac12\pi a^2$；$\sqrt{2ax-x^2}$ 同理 |
| 两个规定 | $\int_a^a=0$；$\int_a^b=-\int_b^a$ |
| 四条性质 | $\int_a^b1\,\mathrm{d}x=b-a$；线性；区间可加；保序（图像越高积分越大） |
| 牛顿-莱布尼茨公式 | $\int_a^b f(x)\mathrm{d}x=F(b)-F(a)$，**本段最核心的工具** |
| 定积分换元法 | 换元三步曲，**必须换线** |
| 定积分分部积分 | $\int_a^b u\,\mathrm{d}v=[uv]_a^b-\int_a^b v\,\mathrm{d}u$；凑微分顺序「反、对、幂、指、三」 |
| 积分方程 | 把定积分整体设为常数 $A$，两边积分得方程解出 $A$ |
| 变限积分函数求导 | $\left(\int_u^v f\right)'=f(v)v'-f(u)u'$；被积函数不能含上下限变量 |
| 含变限积分的极限 | 先定型 → 先等价 → 洛必达；非零因子可先代入 |
| 求 $f(x)$ 表达式 | 先化掉分母（如两边乘 $x$）再求导，$C$ 用初始值定 |
| 无穷区间反常积分 | 积出原函数 → 无穷处写极限 → 结果存在则收敛，否则发散 |
| 常用结论 | $\int_0^{+\infty}x^ne^{-x}\mathrm{d}x=n!$ |
| 瑕积分 | 找瑕点（无定义点）；端点瑕点写极限，内部瑕点拆两个 |
| 微元法 | $\mathrm{d}S=f(x)\mathrm{d}x$；积分就是连续累加 |
| X 型面积 | 竖线平移首尾各穿一次；$S=\int_a^b(\text{高}-\text{低})\mathrm{d}x$ |
| Y 型面积 | 横线平移首尾各穿一次；先把曲线写成 $x=F(y)$；$S=\int_a^b(\text{右}-\text{左})\mathrm{d}y$ |
| X 型 / Y 型选择 | 可互相转化，以**计算容易**为准 |
| 华里士（点火）公式 | $\int_0^{\pi/2}\cos^2t\,\mathrm{d}t=\frac12\cdot\frac\pi2=\frac\pi4$ |
| 求面积步骤 | 画图 → 判类型 → 求交点定区间 → 套公式 → 算定积分 |
| 计算路线图 | 求原函数 + 牛-莱公式；三条路：直接积分 / 凑微分 / 根式代换与三角代换 |
| 凑微分两种写法 | 引入新字母 ⇒ 换元必换线；看作整体 ⇒ 上下限照旧 |
| 根式代换 | 令整个根号 $=t$；四步：令 → 解 $x$ → 求 $\mathrm{d}x$ → 换线 |
| 三角代换 | $\sqrt{a^2-x^2}\to x=a\sin t$；$\sqrt{a^2+x^2}\to x=a\tan t$；$\sqrt{x^2-a^2}\to x=a\sec t$ |
| 偶倍奇零 | 对称区间：奇函数 $=0$，偶函数 $=2\int_0^a$；「对称区间」与「偶倍奇零」绑定 |
| 奇偶性判断 | 内偶则偶、内奇同外；偶 × 奇 = 奇（可判 $0$），偶 ± 奇 = 非奇非偶 |
| 分段函数积分 | 区间可加性；先看分段点在不在区间内，再逐段换表达式 |
| $f(\cdot)$ 复合型 | 先换元（同时换线）化成 $f(u)$，再分段 |
| $\max$ / 绝对值型 | 画图翻译成分段函数；交点 / 零点定分界 |
| 隐蔽绝对值 | $\sqrt{u^2}=\lvert u\rvert$，必须分段去绝对值 |
| 旋转体·X 型绕 $x$ 轴 | $V_x=\pi\int_a^b f^2(x)\mathrm{d}x$；两条曲线 $V_x=\pi\int_a^b(f^2-g^2)\mathrm{d}x$ |
| 旋转体·X 型绕 $y$ 轴 | 柱壳法 $V_y=2\pi\int_a^b x f(x)\mathrm{d}x$；两条曲线 $V_y=2\pi\int_a^b x(f-g)\mathrm{d}x$ |
| 旋转体·Y 型 | $V_y=\pi\int f^2(y)\mathrm{d}y$、$V_x=2\pi\int y f(y)\mathrm{d}y$（**考得极少**） |
| 旋转体步骤 | 画图 → 判 X 型 → 求交点定区间 → 套公式 → 算定积分 |
