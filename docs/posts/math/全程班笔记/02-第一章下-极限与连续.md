# 第一章（下）· 极限与连续

> 来源：陈哥专升本《专升本高等数学全程班》P13–P30
> 本章地位：老师原话——「数列极限在我们的高等数学的考试中考得相对比较少一些，我们的一个考试的重点是函数极限，函数极限一般情况下他会考一个选择、一个填空，甚至考一个大题都是有可能的」（P14）；「这一个小节（连续与间断）大概会有 5~10 分的一个分值的一个占比」（P29）；「我大概应该花了 20 多个小时的时间给大家讲第一章……目前市面上的一些机构对于第一章的时间定义可能在六个小时到八个小时左右，我几乎花了三倍这样的一个时间」（P30）。

## 一、大白话讲解

### 1. 数列极限：把 $n$ 一个一个往下推

数列就是"按顺序排好的一串数"，第 $n$ 项叫**通项** $a_n$。数列极限问的是：当 $n$ 越来越大、大到没边的时候，$a_n$ 会不会稳定地贴在某个数 $a$ 附近。贴住了就叫**收敛于 $a$**，$a$ 就是这个数列的极限；贴不住就叫**发散**。

它和函数极限只差一点：$n$ 只能取正整数，所以 $n\to\infty$ **特指正无穷**，不分左右——这是整个第一章里唯一"不用分左右"的极限。

### 2. 极限是一个"动作"，不是一个"等号"

$x\to x_0$ **不意味着** $x=x_0$，只是"无限接近"。老师反复强调：「极限它并不是一个等于的过程，极限只是一个细过程，而不是一个等于」（P14）。所以极限讨论的是"靠近"的最终趋势，与那一点上函数到底等于多少**无关**——这正是后面"间断"的根源。

### 3. 两种趋近方式，必须分开看

| 情形 | 大白话 |
|:---|:---|
| $x\to x_0$ | $x$ 从 $x_0$ 的**左、右两侧**分别靠近 |
| $x\to\infty$ | $x$ 往**正方向**或**负方向**无限走远，两条路要分别算 |

注意一个关键差别：**数列极限**的 $n\to\infty$ 只有正无穷一种（$n$ 是自然数），而**函数极限**的 $x\to\infty$ 泛指 $+\infty$ 或 $-\infty$ 两种。所以 $\lim\limits_{x\to\infty}e^x$ 要看 $x\to+\infty$（得 $+\infty$）和 $x\to-\infty$（得 $0$）——两个结果不同，极限就不存在。

### 4. 左右极限：走楼梯比喻

从左边走到第 3 级、从右边走到第 3 级，才敢说"你在第 3 级"。左边到 2、右边到 4，就只能说"没有确定的落点"。

> 老师原话：「请大家在这里打个五角星，因为这个实在是特别特别的重要」（P14）——指的就是**函数在一点处极限存在的充要条件：左右极限都存在且相等**。

### 5. 极限计算 = 先"定型"，再"挑工具"

拿到一个极限，第一步不是埋头算，而是**把趋近值代进去看它是什么型**：

- 不是七种未定式 → 想都别想，直接代值出结果；
- 是七种未定式 → 才去挑对应的化简工具（约分、通分、有理化、非零因子代入、等价无穷小、洛必达……）。

### 6. 无穷小与无穷大：一个"趋近于 0"，一个"趋近于 ∞"

无穷小**不是**"很小的数"，而是**在某一种趋向下趋于 0 的量**；无穷大就是趋于 ∞ 的量。所以「$f(x)$ 是无穷小」这句话本身**没有意义**，必须说清"在什么趋向下"。

这一节最值钱的一句话是**零乘有界等于零**：无穷小乘以有界变量，结果一定是无穷小。

### 7. 等价无穷小 = 给因式找"替身"

$x\to0$ 时 $\sin x$ 和 $x$ 趋于零的"速度一样"，所以可以互相顶替。它的本质是**一种更高级的化简方法**（P20 原话），但有两个铁律：**替身自身要趋于 0**、**替身必须和别的因式构成乘除关系**（加减关系里绝对不能换）。

### 8. 抓大头 = 只留"最大的一号人物"

分子分母都趋于无穷时，起决定作用的是**最高次项**（多项式）或**最大底数的指数项**（指数函数）；被有界函数（$\sin$、$\cos$、$\arctan$ 等）拖住的项，相对无穷来说"太小太小"，可以直接忽略。

### 9. 1 的无穷次方 = 一个公式打天下

只要是 $1^\infty$ 型，凑成 $(1+A)^B$ 后直接写 $e^{\lim A\cdot B}$。老师把它叫**万能方法**，并说「只要大家能够掌握好这种万能方法，那么所有的一的无穷次方形都可以解决」（P17）。

### 10. 连续与间断：一根绳子断没断

连续就是函数图像像一根**没断的绳子**；在某点断开，那个点就是**间断点**。判断方法只有一条主线：**算出该点的极限值，和该点的函数值比一比**。

## 二、考点全爆破

### 1. 数列、通项与数列极限（P13）

**数列**：按一定顺序排列的一列数，记作 $a_1,a_2,a_3,\dots,a_n,\dots$。第 $n$ 项 $a_n$ 叫**通项**（也叫一般项），整个数列简记作 $\{a_n\}$。

两个条件缺一不可：

- **按顺序**：$1,2,3$ 与 $2,1,3$ 不是同一个数列；
- **每一项都是数**：不能出现 $n$、$2n-1$ 这种带变量的"项"。

通项举例：$1,\dfrac12,\dfrac13,\dfrac14,\dots$ 的通项是 $a_n=\dfrac1n$；$1^2,2^2,3^2,\dots$ 的通项是 $a_n=n^2$。

**数列极限**：当 $n$ **无限增大**时，若 $a_n$ 无限趋近于一个常数 $a$，就称数列 $\{a_n\}$ **收敛于 $a$**，$a$ 称为该数列的**极限**，记作

$$\lim_{n\to\infty}a_n=a$$

- 记号取自英文单词 **limit** 的**前三个字母** LIM；
- ★ **$n\to\infty$ 特指正无穷**：数列只有第 1 项、第 2 项……没有"负一项"，$n$ 只能往正方向走。这一点与函数极限的 $x\to\infty$（含 $+\infty$ 与 $-\infty$，两条路要分开算）**不同**。

> 老师原话（P13）：「数列极限并不是我们最终考试的一个重点」，但**函数极限与数列极限的核心思想完全一致**，所以它是理解函数极限的入口。

### 2. 数列的收敛与发散：极限不存在的两种情况（P13）

**判据**：数列收敛还是发散，**完全取决于它的极限是否存在**。

| 情况 | 结论 |
|:---|:---|
| $\lim\limits_{n\to\infty}a_n$ 存在（等于一个常数） | 数列**收敛** |
| $\lim\limits_{n\to\infty}a_n$ 不存在 | 数列**发散** |

**极限不存在只有两种情况**（★ 老师要求必须掌握）：

| 情况 | 含义 | 例子 |
|:---|:---|:---|
| ① 极限结果为**无穷** | 求出来是 $\infty$ | $\lim\limits_{n\to\infty}2^n=\infty$ ⇒ 发散 |
| ② 极限值在某个范围内**波动** | 结果在两个值之间来回跳，定不下来 | $\lim\limits_{n\to\infty}(-1)^n$ 在 $-1$ 与 $1$ 之间跳；$\lim\limits_{n\to\infty}\cos n\pi$ 同样 |

- ★ 专升本与考研数学的约定：**极限结果为 $\infty$ 一律算"不存在"**。（部分专业书把 $\infty$ 当作"特殊的存在"，本考试不采纳这种说法。）
- 第二种情况的共同特征是**震荡**：$(-1)^n$（$n$ 偶得 $1$、$n$ 奇得 $-1$）、$\cos n\pi$（同上）都是典型。

> 老师原话（P13）：「这极限不存在的两种情况，大家一定要把它给掌握好，因为我们在后面呢，可能还会用到」——**函数极限中极限不存在也只有这两种情况**。

### 3. 函数极限的定义与记号

$x\to x_0$（或 $x\to\infty$）时 $f(x)\to A$，记作

$$\lim_{x\to x_0}f(x)=A,\qquad \lim_{x\to\infty}f(x)=A$$

记号来源：英文 limit（限制/有限）取前三个字母 LIM。

### 4. $x\to\infty$ 处极限存在的充要条件（★）

$$\lim_{x\to\infty}f(x)=A\iff \lim_{x\to+\infty}f(x)=\lim_{x\to-\infty}f(x)=A$$

若两个单侧极限都存在但不相等，则原极限**不存在**。

### 5. 两个必记的小极限

$$\lim_{x\to0}\frac{k}{x}=\infty\ (k\ne0),\qquad \lim_{x\to\infty}\frac{k}{x}=0\ (k\ \text{任意})$$

> 数列中同样成立（P13）：$\lim\limits_{n\to\infty}\dfrac kn=0$，$\lim\limits_{n\to0}\dfrac kn=\infty$（$k$ 为常数，后式要求 $k\ne0$）。两条都来自同一句话：**无穷分之常数得 $0$，$0$ 分之常数得无穷**。

### 6. $x\to x_0$ 处的左右极限与充要条件（★）

$$\lim_{x\to x_0}f(x)=A\iff \lim_{x\to x_0^-}f(x)=\lim_{x\to x_0^+}f(x)=A$$

记号：$x_0^-$ 表示从左（小于 $x_0$ 的一侧）趋近，$x_0^+$ 表示从右趋近。

### 7. 必须分左右极限的四种情形（★）

| 序号 | 情形 | 典型例子 |
|:---|:---|:---|
| ① | 指数型、反正切型在**定点**处 | $\lim\limits_{x\to0}e^{1/x}$、$\lim\limits_{x\to0}\arctan\frac1x$ |
| ② | $e^x$、$\arctan x$ 在**无穷**处 | $\lim\limits_{x\to\infty}e^x$、$\lim\limits_{x\to\infty}\arctan x$ |
| ③ | 分段函数在**分段点**处 | $f(x)=\begin{cases}x^2,&x<1\\3-x,&x>1\end{cases}$ 在 $x=1$ |
| ④ | 含**绝对值** | $\lim\limits_{x\to0}\dfrac{\vert x\vert}{x}$ |

除这四种外，一般函数的左右极限天然相等，**不必**每次都分左右。

### 8. 极限的四则运算法则

前提：$\lim f(x)=A$、$\lim g(x)=B$ **两个极限都存在**（都等于某个常数）。

$$\lim[f(x)\pm g(x)]=A\pm B,\quad \lim[f(x)g(x)]=AB,\quad \lim\frac{f(x)}{g(x)}=\frac AB\ (B\ne0),\quad \lim[c\,f(x)]=cA$$

**存在** = 极限等于一个数；**不存在** = 极限为无穷，或在某个范围内来回波动。

### 9. 拆极限的前提（易错）

若把一个极限拆成两个极限，则**这两个极限必须都存在**。只要其中一个为无穷（或两个都为无穷），就**不能拆**。

### 10. 七种未定式（★必背）

$$\frac00,\quad \frac{\infty}{\infty},\quad \infty-\infty,\quad 0\cdot\infty,\quad 1^{\infty},\quad \infty^{0},\quad 0^{0}$$

其中 $\frac00$ 与 $\frac{\infty}{\infty}$ 是**核心**，其余五种都能通过通分、有理化、取倒数、取对数等手段化成前两种。

**已定式**（非七种未定式）：直接代值出结果，例如 $0/1=0$、$\infty/2=\infty$、$0/\infty=0$、常数$/0=\infty$。

### 11. 极限解题三步

$$\text{定型}\ \longrightarrow\ \text{化简}\ \longrightarrow\ \text{用公式}$$

- **定型**：判断是不是七种未定式中的某一种；
- **化简**：分子分母约分、通分、非零因子代入、根式有理化、等价无穷小；
- **用公式**：洛必达法则（以及泰勒公式——专升本考纲里只有江苏、浙江两省要求了解，其他省份不要求）。

### 12. 第一重要极限及其广义化

$$\lim_{x\to0}\frac{\sin x}{x}=1\qquad(\tfrac00\ \text{型})$$

**广义化**：若在某种趋向下 $\varphi(x)\to0$，则

$$\lim\frac{\sin\varphi(x)}{\varphi(x)}=1$$

用它的唯一要求：**分子分母中被替换的部分形式必须一致，且整体趋于 0**。

### 13. 第二重要极限及其广义化

$$\lim_{x\to0}(1+x)^{\frac1x}=e,\qquad \lim_{x\to\infty}\left(1+\frac1x\right)^{x}=e$$

（$e\approx2.71828$，记到 $2.7$ 即可。）

两个关键点：① 类型必是 $1^\infty$；② 括号里的部分与指数部分**互为倒数**。

**广义化**：若 $\varphi(x)\to0$，则 $\lim(1+\varphi(x))^{\frac{1}{\varphi(x)}}=e$；若 $\varphi(x)\to\infty$，则 $\lim\left(1+\frac1{\varphi(x)}\right)^{\varphi(x)}=e$。

### 14. $1^\infty$ 型的万能公式（★★）

若极限类型为 $1^\infty$，且可化为 $(1+A)^B$ 的形式（其中 $A\to0$、$B\to\infty$，$A$、$B$ 是**函数**），则

$$\lim(1+A)^B=e^{\lim A\cdot B}$$

> 老师原话：「请大家把这个万能方法打个五角星……如果大家能够把这个万能方法掌握好并且能够运用，那么前面的这个找导数关系这种方法大家就可以完全不用管了」（P17）。

**注意**：这个公式只对 $1^\infty$ 型成立；$x$ 的趋向不固定（可以是 $0$，也可以是 $\infty$），只要类型是 $1^\infty$ 就能用。

### 15. 无穷小与无穷大（P18）

**定义（★ 必须带趋向）**

| 概念 | 定义 | 例子 |
|:---|:---|:---|
| **无穷小（量）** | 在**某一种趋向下**，$f(x)$ 无限趋近于 $0$ | $x$ 是 $x\to0$ 时的无穷小；$\dfrac1x$ 是 $x\to\infty$ 时的无穷小；$\ln(1+x)$ 是 $x\to0$ 时的无穷小 |
| **无穷大（量）** | 在**某一种趋向下**，$f(x)$ 无限趋近于 $\infty$ | $\dfrac1x$ 是 $x\to0$ 时的无穷大；$\ln(1+x)$ 是 $x\to-1$ 时的无穷大 |

- ★ **只说「$f(x)$ 是无穷小」没有意义**，必须说明**在什么趋向下**；
- ★ **$0$ 是特殊的无穷小量，也是唯一的常数无穷小**。函数只有在某趋向下才是无穷小，而 $0$ 无论怎么趋近都是 $0$。（有些省份考过这个判断题。）

**无穷小的三条性质**

| 性质 | 内容 | 备注 |
|:---|:---|:---|
| ① 有限个无穷小的和、差、积 | 仍是无穷小 | ★ 关键词是**有限个**；**商不一定**是无穷小 |
| ② 无穷小 × 有界变量 | 仍是无穷小 | ★★ 口诀「**零乘有界等于零**」，**选填高频** |
| ③ 倒数关系 | 无穷小的倒数 → 无穷大；无穷大的倒数 → 无穷小 | ★ 有前提，见下 |

**性质① 里"商"的反例**：$\lim\limits_{x\to0}\dfrac{\sin x}{x}$——分子 $\sin x$、分母 $x$ 都是 $x\to0$ 时的无穷小，商却是 $1$。所以**有限个无穷小的商不一定是无穷小**。

**性质③ 的陷阱**：「无穷小的倒数是无穷大」这句话**是错的**。因为 $0$ 是特殊的无穷小，而 $\dfrac10$ 没有意义。它成立的前提是：**分母必须是一个趋近于 $0$ 的变量，不能是确定的 $0$ 这个数**。

**常见有界函数**（做"零乘有界"题时必须能一眼认出）：$\sin x$、$\cos x$、$\arctan x$、$\dfrac1{1+x^2}$，以及它们的复合，如 $\sin\dfrac1x$、$\cos x^2$。

**★ 什么时候才把 $\sin$、$\cos$ 看作有界函数？**

| 场合 | $\sin x$ 的身份 | 理由 |
|:---|:---|:---|
| $\lim\limits_{x\to\infty}\dfrac{\sin x}{x}$ | **有界函数** | $\lim\limits_{x\to\infty}\sin x$ **不存在**（在 $[-1,1]$ 间震荡） |
| $\lim\limits_{x\to0}\dfrac{\sin x}{x}$ | **无穷小** | $\lim\limits_{x\to0}\sin x=0$，是无穷小，不看作有界 |

> 判据一句话：**极限不存在（震荡）才视为有界函数**；极限存在且为 $0$ 就是无穷小。

### 16. 无穷小比阶

设 $f(x)$、$g(x)$ 在同一趋向下都是无穷小，做比值求极限：

| $\lim\frac fg$ 的结果 | 结论 |
|:---|:---|
| $0$ | $f$ 是 $g$ 的**高阶**无穷小（$f$ 趋于 0 更快） |
| $\infty$ | $f$ 是 $g$ 的**低阶**无穷小 |
| $C\ (C\ne0,\ C\ne1)$ | **同阶**无穷小 |
| $1$ | **等价**无穷小，记 $f\sim g$（趋于 0 速度相同） |

本质上就是在求极限；**同阶无穷小比值必为常数且不为 1，等价无穷小比值必为 1**。

### 17. 等价无穷小的本质与两个前提（★★）

**本质**：一种更高级的**化简方法**。

两个前提条件**缺一不可**：

1. 被等价的整体必须**趋于 0**（注意：不是看 $x$ 趋于多少，而是看你想等价的那个整体趋于多少）；
2. 被等价的整体必须和其他因式构成**乘积（乘除）关系**，**不能是加减关系**。

### 18. 常用等价无穷小公式表（$x\to0$，★背熟）

| 组 | 公式 |
|:---|:---|
| 前六组（最重要） | $\sin x\sim x$，$\tan x\sim x$，$\arcsin x\sim x$，$\arctan x\sim x$，$e^x-1\sim x$，$\ln(1+x)\sim x$ |
| 第七 | $1-\cos x\sim\dfrac12x^2$ |
| 第八 | $(1+\alpha x)^{\beta}-1\sim\alpha\beta x$（若为 $1-\alpha x$ 的 $\beta$ 次方，则等价为 $-\alpha\beta x$） |
| 第九 | $x-\sin x\sim\dfrac16x^3$；$\tan x-x\sim\dfrac13x^3$ |
| 第十 | $x-\ln(1+x)\sim\dfrac12x^2$ |
| 第十一（选择性记忆） | $\arcsin x-x\sim\dfrac16x^3$，$x-\arctan x\sim\dfrac13x^3$，$\tan x-\sin x\sim\dfrac12x^3$，$\arcsin x-\arctan x\sim\dfrac12x^3$ |

> 老师原话：「这 11 个在我们能够解决我们 90% 以上的题目了」（P20）；「等价无穷小几乎是每年必考，只要考极限等价无穷小几乎必考」（P23）。

**符号交换规则**：把等号两边前后交换（如 $1-\cos x$ 换成 $\cos x-1$），等价结果前面加一个负号即可。

### 19. 等价无穷小的广义化

把基本公式里的 $x$ 换成"方框"（一个整体）：

$$\square\to0\ \Longrightarrow\ \sin\square\sim\square,\quad \ln(1+\square)\sim\square,\quad e^{\square}-1\sim\square,\quad 1-\cos\square\sim\tfrac12\square^2,\quad (1+\alpha\square)^{\beta}-1\sim\alpha\beta\square$$

> 老师原话（P20）：「并不关注这个前面的 $X$ 趋近于多少，他更关注的是你想等价的这个整体它趋近于多少」——只要它趋于 0，就能等价；不趋于 0，就不能等价。

### 20. 等价无穷小的两大误区（★★）

**误区一**：认为只有 $x\to0$ 时才能做等价。

- **纠正**：看的是"被等价的整体"是否趋于 0。例如 $\lim\limits_{x\to1}\dfrac{\sin(x-1)}{x-1}=1$、$\lim\limits_{x\to\infty}x\sin\frac1x=1$，都是 $x$ 不趋于 0 但整体趋于 0 的例子。

**误区二**：认为等价在任何时候都能用。

- **纠正**：被等价的因式必须与其他因式构成**乘除关系**。加减关系下强行等价会出错（典型反例见例题）。

### 21. 非零因子代入

只针对 $\dfrac00$ 型。若某个因式**不为零**（代入趋近值后结果是非零常数），且与其他因式构成**乘积关系**，则可以先把它的极限值算出来。

> 这是零比零型里出现最多的一个小技巧。

### 22. 夹逼定理（迫敛定理）

若 $a_n\le b_n\le c_n$，且 $\lim a_n=\lim c_n=A$，则 $\lim b_n=A$。

做法：对和式的**分母**做放缩，让所有分母都变成**第一项的分母**或**最后一项的分母**，分别求出放小、放大后的极限；两边相等即为所求。

**注意**：把每一项单独抓大头得 0 是错的——「有限个无穷小相加的结果才是无穷小」，无穷多个无穷小相加不一定为 0。

### 23. 洛必达法则（基础版）

**条件**：① 极限类型为 $\dfrac00$ 或 $\dfrac{\infty}{\infty}$（**只有这两种**）；② 去心邻域内分子分母可导（专升本题目基本都满足）。

**做法**：分子分母**同时求导**。每次求导后都要**重新判断类型**，仍是 $\dfrac00$ 或 $\dfrac{\infty}{\infty}$ 就继续求导，直到不再是未定式。求导过程中若出现可等价的形式，**要及时等价**以简化运算。

**可直接写结果的几种情况**：分子分母都是常数 → 比值；分母趋于 0、分子为非零常数 → $\infty$；分母为非零常数、分子趋于 0 → $0$。

### 24. 洛必达失效

典型：$\lim\limits_{x\to\infty}\dfrac{x+\sin x}{x-\cos x}$。用洛必达后得 $\dfrac{1+\cos x}{1+\sin x}$，这个极限**不存在**，但**不能**由此断定原极限不存在——这是经典错误。

正确思路有两条：① 抓大头（$\sin x$、$\cos x$ 有界，相对 $x$ 可忽略）；② 分子分母同除以 $x$，化为"零乘有界"。

### 25. 抓大头（$\dfrac{\infty}{\infty}$ 型主力方法）

**口诀：上大无穷，下大零，相同则为系数比。**

| 情况 | 做法 |
|:---|:---|
| 分子分母都是**多项式** | 找分子分母的**最高次方** |
| 分子分母都是**指数函数** | 找分子分母的**最大底数**（指数不同先化成相同再取系数比） |
| 含**根号**或**括号** | 把根号（括号）下**低于最高次方的部分全部去掉** |

**适用范围**：**只能用于 $\dfrac{\infty}{\infty}$ 型**，其他未定式一律不能用抓大头。

**标准形式**：分子分母都是**多项式函数**（幂函数累加而成）。记 $N$ 为**分子的最高次数**、$M$ 为**分母的最高次数**。

| 次数关系 | 结果 |
|:---|:---|
| $N>M$（分子次数高，"上大"） | $\infty$ |
| $N<M$（分母次数高，"下大"） | $0$ |
| $N=M$（"相同"） | 系数之比 $\dfrac{a_N}{b_M}$ |

**大题必须写过程**（口诀只能用于选填）：**分子分母同时除以它们"共有的最高次方"**（即 $\min(N,M)$ 次方），逐项约分后再代入趋近值。老师强调：「如果大家直接去写个答案，肯定就得不了分」（P16）。考频上这种题**约 90% 出现在选择填空**，大题出现概率只有 10% 左右，但一旦出就是 6～10 分。

**含根号 / 括号的秒杀技巧**：极限为 $\dfrac\infty\infty$ 型且分子分母含根号或括号时，**只保留根号（括号）下的最高次方**，低于最高次方的部分全部丢掉。★ 只能用于**选填**，大题仍走"同除共有最高次方"。

**指数形式的抓大头**（少数省份考过）：分子分母都是指数函数时，抓的**不是最高次方，而是最大底数**，口诀不变。★ 前提是先把指数统一——例如 $3^{x+1}=3\cdot3^x$、$e^{2/x}=(e^2)^{1/x}$，统一之后才能看清谁是最大底数、系数是多少。

### 26. $\infty-\infty$ 型的四种处理

| 类型 | 方法 | 考频 |
|:---|:---|:---|
| 含**分式** | 通分，化成 $\dfrac00$ | 最高（约 50%） |
| 含**根式** | 根式有理化，化成 $\dfrac{\infty}{\infty}$ | 次高（约 40%） |
| 需换元 | **倒代换**：令 $t=\dfrac1x$ | 低 |
| 自变量趋于负无穷 | **负代换**：令 $x=-t$（$t\to-\infty$ 时 $x\to+\infty$） | 低 |

### 27. $0\cdot\infty$ 型的处理

**取倒数下放**：把其中一个因子取倒数搬到分母上，化成 $\dfrac00$ 或 $\dfrac{\infty}{\infty}$。

- $x\ln x\ (x\to0^+)$ → 写成 $\dfrac{\ln x}{1/x}$（$\dfrac{\infty}{\infty}$）；
- $x\left(\arctan x-\dfrac\pi2\right)\ (x\to+\infty)$ → 写成 $\dfrac{\arctan x-\pi/2}{1/x}$（$\dfrac00$）。

有时也可先做简单变形（如把 $\tan$ 换成 $\sin/\cos$），不必死板下放。

### 28. $\infty^0$ 与 $0^0$ 型：幂指函数指数对数化

两个对数公式：$\ln a^b=b\ln a$，$e^{\ln x}=x$。

于是

$$u^{v}=e^{\ln u^{v}}=e^{v\ln u}\ \Longrightarrow\ \lim u^{v}=e^{\lim v\ln u}$$

化成指数上的极限后，再用 $\dfrac00$ 或 $\dfrac{\infty}{\infty}$ 的方法处理。**注意**：这两种类型考得很少，$\infty^0$ 绝不能用第二重要极限。

### 29. 连续的定义与充要条件（★）

$$\lim_{x\to x_0}f(x)=f(x_0)$$

即"该点的**极限值 = 函数值**"。图像上表现为曲线不断开。

**充要条件**：

$$\lim_{x\to x_0^-}f(x)=\lim_{x\to x_0^+}f(x)=f(x_0)$$

### 30. 左连续与右连续

| 名称 | 条件 |
|:---|:---|
| 左连续 | $\lim\limits_{x\to x_0^-}f(x)=f(x_0)$ |
| 右连续 | $\lim\limits_{x\to x_0^+}f(x)=f(x_0)$ |

### 31. 间断的定义与间断点的位置

若 $\lim\limits_{x\to x_0}f(x)\ne f(x_0)$（含极限不存在的情形），则 $f(x)$ 在 $x_0$ 处**间断**，$x_0$ 为**间断点**。

间断点只会出现在两处：

1. **初等函数的无意义点**——主要是分式中**分母为零的点**（约 60%）；
2. **分段函数的分段点**（约 40%）——分段点**不一定**是间断点，也可能是连续点，要具体算。

### 32. 间断点的分类（两类四种，★）

| 大类 | 共同特点 | 细分 | 判定 |
|:---|:---|:---|:---|
| **第一类** | 左右极限**都存在** | 可去间断点 | 左右极限存在且**相等** |
| | | 跳跃间断点 | 左右极限存在但**不相等** |
| **第二类** | 左右极限**至少一个不存在** | 无穷间断点 | 至少有一个极限为**无穷** |
| | | 震荡间断点 | 极限值在某区间内**震荡波动** |

> 老师原话：「震荡这种考的非常的少……我看了这么多年各个省份的专升本考试，关于间断点的一个考察，几乎没有出现过震荡间断点的这种情况」（P30）。前三种出现频率比较平均。

### 33. 判断间断点类型的标准流程

$$\text{找间断点}\ \longrightarrow\ \text{求该点处极限（必要时分左右）}\ \longrightarrow\ \text{按上表定类}$$

其中"必要时分左右"通常只有三种情况：$\arctan\dfrac1x$、$e^{1/x}$、分段函数。

### 34. 求连续区间

先找出全部间断点，把它们从数轴上"挖掉"，剩下的区间（开区间）就是连续区间。

## 三、例题精讲

### A 组｜数列极限（P13）

**例 1** $\lim\limits_{n\to\infty}\left(2+\dfrac1{n^2}\right)$

**解**：$n\to\infty$ 时 $\dfrac1{n^2}\to0$（**无穷分之常数得 $0$**），而 $2$ 与 $n$ 无关、原样留下，故极限为 $2$。

**例 2** $\lim\limits_{n\to\infty}\dfrac{n-1}{n+1}$

**解**：先感受一下——$n=100$ 时是 $\dfrac{99}{101}\approx1$，$n$ 越大分子分母差得越小。严格做法用抓大头：分子分母最高次方都是 $1$，取系数比 $\dfrac11=1$。故极限为 $1$。

**例 3** $\lim\limits_{n\to\infty}\left(\dfrac1{1\cdot2}+\dfrac1{2\cdot3}+\cdots+\dfrac1{n(n+1)}\right)$

**解**：**列项相消**。每一项拆成两项之差：

$$\frac1{k(k+1)}=\frac1k-\frac1{k+1}$$

于是和式 $=\left(1-\dfrac12\right)+\left(\dfrac12-\dfrac13\right)+\cdots+\left(\dfrac1n-\dfrac1{n+1}\right)=1-\dfrac1{n+1}$。

$n\to\infty$ 时 $\dfrac1{n+1}\to0$，故极限为 $1$。

> 老师提醒：列项技巧在**衔接课**里专门讲过，这里不展开；没掌握的要回去补数列基础。

**例 4** $\lim\limits_{n\to\infty}\left(\sqrt{n+2}-\sqrt n\right)$

**解**：**根式有理化**——分子分母同乘 $\sqrt{n+2}+\sqrt n$（平方差公式）：

$$=\lim_{n\to\infty}\frac{(n+2)-n}{\sqrt{n+2}+\sqrt n}=\lim_{n\to\infty}\frac{2}{\sqrt{n+2}+\sqrt n}$$

分母 $\to\infty$，分子是常数 $2$，故极限为 $0$。

> 老师原话（P13）：数列极限「考的并不是很多，很多省份都并不会特别去考」，会做上面这几道最基本的题就够了；真正的重头戏是下一节的**函数极限**。

### B 组｜认识函数极限（P14）

**例 5** $\lim\limits_{x\to2}\dfrac1x$

**解**：直接把 $2$ 代入，得 $\dfrac12$。

**例 6** $\lim\limits_{x\to\infty}\arctan x$

**解**：$\lim\limits_{x\to+\infty}\arctan x=\dfrac\pi2$，$\lim\limits_{x\to-\infty}\arctan x=-\dfrac\pi2$。两个单侧极限都存在但**不相等**，故原极限**不存在**。

**例 7** $\lim\limits_{x\to\infty}e^x$

**解**：$\lim\limits_{x\to+\infty}e^x=+\infty$，$\lim\limits_{x\to-\infty}e^x=0$。不相等，故原极限**不存在**。

**例 8** $f(x)=\begin{cases}x^2,&x<1\\3-x,&x>1\end{cases}$，求 $\lim\limits_{x\to1}f(x)$

**解**：$\lim\limits_{x\to1^-}f(x)=\lim\limits_{x\to1^-}x^2=1$；$\lim\limits_{x\to1^+}f(x)=\lim\limits_{x\to1^+}(3-x)=2$。左 $\ne$ 右，故极限**不存在**。

**例 9** $\lim\limits_{x\to0}e^{\frac1x}$

**解**：$x\to0^-$ 时 $\frac1x\to-\infty$，$e^{\frac1x}\to0$；$x\to0^+$ 时 $\frac1x\to+\infty$，$e^{\frac1x}\to+\infty$。故极限**不存在**。

**例 10** $\lim\limits_{x\to0}\arctan\dfrac1x$

**解**：$x\to0^-$ 时 $\frac1x\to-\infty$，得 $-\dfrac\pi2$；$x\to0^+$ 时 $\frac1x\to+\infty$，得 $\dfrac\pi2$。极限**不存在**。

**例 11**（进阶）$\lim\limits_{x\to1}\arctan\dfrac1{1-x}$

**解**：$x\to1^-$ 时 $1-x\to0^+$，$\frac1{1-x}\to+\infty$，得 $\dfrac\pi2$；$x\to1^+$ 时 $1-x\to0^-$，$\frac1{1-x}\to-\infty$，得 $-\dfrac\pi2$。极限**不存在**。

**例 12**（进阶）$\lim\limits_{x\to2}e^{\frac1{x-2}}$

**解**：$x\to2^-$ 时 $x-2\to0^-$，$\frac1{x-2}\to-\infty$，得 $0$；$x\to2^+$ 时得 $+\infty$。极限**不存在**。

**例 13** $\lim\limits_{x\to0}\dfrac{|x|}{x}$

**解**：$x\to0^-$ 时 $|x|=-x$，$\dfrac{-x}{x}=-1$；$x\to0^+$ 时 $|x|=x$，$\dfrac xx=1$。极限**不存在**。

**例 14**（含绝对值·进阶）$\lim\limits_{x\to1}\dfrac{x-1}{|1-x|}$

**解**：先去绝对值再分左右。$x\to1^-$ 时 $1-x>0$，$|1-x|=1-x$，分子分母相差一个负号，得 $-1$；$x\to1^+$ 时 $1-x<0$，$|1-x|=x-1$，得 $1$。左右不等，极限**不存在**。

> 字幕里该题左右极限的数值表述前后矛盾（既说两边都等于 $1$、又说左右不相等），此处只记方法：**去绝对值 → 分左右 → 不等即不存在**。

### C 组｜四则运算与解题三步（P15）

**例 15** $\lim\limits_{x\to0}(\sin x+e^x)$

**解**：两个极限都存在，可拆。$=\sin0+e^0=0+1=1$。

**例 16** $\lim\limits_{x\to0}\ln(1+x)\cdot\cos x$

**解**：$=0\times1=0$。

**例 17** $\lim\limits_{x\to2}\dfrac{x^2-4}{x-2}$

**解**：定型为 $\dfrac00$，不能直接把 $0/0$ 当 $1$。平方差因式分解：$\dfrac{(x-2)(x+2)}{x-2}=x+2\to4$。

**例 18** $\lim\limits_{x\to1}\dfrac{x^2+2x-3}{x-1}$

**解**：$\dfrac00$ 型，因式分解 $\dfrac{(x+3)(x-1)}{x-1}=x+3\to4$。

**例 19** $\lim\limits_{x\to\infty}\left(1+\dfrac1x\right)\left(2-\dfrac1{x^2}\right)$

**解**：$=1\times2=2$。

**例 20** $\lim\limits_{x\to0}\dfrac{\sqrt{1+x}-1}{x}$

**解**：$\dfrac00$ 型，根式有理化：分子分母同乘 $\sqrt{1+x}+1$，得 $\dfrac{x}{x(\sqrt{1+x}+1)}=\dfrac1{\sqrt{1+x}+1}\to\dfrac12$。

**例 21**（无穷减无穷雏形）$\lim\limits_{x\to1}\left(\dfrac1{1-x}-\dfrac3{1-x^3}\right)$

**解**：定型为 $\infty-\infty$。通分，分母用**立方差公式** $1-x^3=(1-x)(1+x+x^2)$，分子合并后再因式分解、约分，最后代入。

> 字幕中该题最终数值的前后表述不一致（推导中带负号、结论又说等于 $1$），此处只记方法：**通分 + 立方差公式 + 因式分解 + 约分**。

**例 22** $\lim\limits_{n\to\infty}\left(\dfrac12+\dfrac14+\cdots+\dfrac1{2^n}\right)$

**解**：等比数列前 $n$ 项和 $S_n=\dfrac{a_1(1-q^n)}{1-q}$，$a_1=\dfrac12$，$q=\dfrac12$，故 $S_n=1-\left(\dfrac12\right)^n\to1$。

### D 组｜抓大头（P16）

**例 23** $\lim\limits_{x\to\infty}\dfrac{x^2+2x-1}{2x^2+1}$

**解**：先定型——分子分母都趋于 $\infty$，是 $\dfrac\infty\infty$ 型。分子最高次方 $2$、分母最高次方 $2$，**相同则为系数比**，得 $\dfrac12$。

**大题写法**：分子分母同除以共有的最高次方 $x^2$：

$$\lim_{x\to\infty}\frac{1+\dfrac2x-\dfrac1{x^2}}{2+\dfrac1{x^2}}=\frac{1+0-0}{2+0}=\frac12$$

**例 24** $\lim\limits_{x\to\infty}\dfrac{7x^2+4x+2}{3x^3+5x^2-2}$

**解**：分子最高次方 $2$、分母最高次方 $3$，**下大零**，故极限为 $0$。

**大题写法**：同除共有的最高次方 $x^2$（取 $\min(2,3)=2$）：

$$\lim_{x\to\infty}\frac{7+\dfrac4x+\dfrac2{x^2}}{3x+5-\dfrac2{x^2}}$$

分母剩下 $3x+5\to\infty$，分子 $\to7$，$\dfrac{\text{常数}}{\infty}=0$，结果仍是 $0$。

**例 25**（含根号）$\lim\limits_{x\to+\infty}\dfrac{\sqrt{4x^2-x+1}}{\sqrt[3]{x^3+6}}$

**解**：**秒杀技巧**——只保留根号下的最高次方：分子留 $\sqrt{4x^2}$、分母留 $\sqrt[3]{x^3}$，于是

$$=\lim_{x\to+\infty}\frac{2x}{x}=2$$

**大题写法**：分子实际最高次方是 $x$（根号套着 $x^2$），分母也是 $x$（三次根号套着 $x^3$），共有最高次方为 $x$，同除 $x$；除的时候把 $x$ 写成 $\sqrt{x^2}$（配分子的二次根号）、或写成 $\sqrt[3]{x^3}$（配分母的三次根号），代入后分子 $\to\sqrt4=2$、分母 $\to\sqrt[3]1=1$，结果 $2$。

> ★ **趋近方向不能含糊**：这里必须是 $x\to+\infty$。因为 $\sqrt{4x^2}=2|x|$——$x\to+\infty$ 时它等于 $2x$，$x\to-\infty$ 时它等于 $-2x$，结果会是 $-2$。两者不等，所以**若真按双侧的 $x\to\infty$，原极限是不存在的**。老师板书同除 $x$ 时把 $x$ 写成 $\sqrt{x^2}$，本身也默认了 $x>0$。

**例 26**（★ 陷阱题）$\lim\limits_{n\to\infty}\dfrac{1+2+\cdots+n}{n^2}$

**解**：分子最高次方是 $1$、分母是 $2$，"下大零"直接写 $0$——**这正是本题的陷阱**。抓大头的前提是分子分母为**多项式**（有限项），而这里的分子是 $1$ 到 $n$ 的**无穷多项之和**。

先求等差数列前 $n$ 项和：$1+2+\cdots+n=\dfrac{(1+n)n}{2}$，于是

$$=\lim_{n\to\infty}\frac{\frac{(1+n)n}{2}}{n^2}=\lim_{n\to\infty}\frac{n^2+n}{2n^2}=\frac12$$

**例 27**（$\infty-\infty$ 型 + 根号）$\lim\limits_{n\to\infty}\left(n-\sqrt{n^2-n}\right)$

**解**：$n$ 写成 $\sqrt{n^2}$ 后即为两根式相减，用**根式有理化**：

$$=\lim_{n\to\infty}\frac{n^2-(n^2-n)}{n+\sqrt{n^2-n}}=\lim_{n\to\infty}\frac{n}{n+\sqrt{n^2-n}}$$

此时已化为 $\dfrac\infty\infty$ 型。分母用秒杀技巧只留最高次方：$\sqrt{n^2-n}\to n$，分母 $\to n+n=2n$，故

$$=\lim_{n\to\infty}\frac{n}{2n}=\frac12$$

**例 28**（含括号）$\lim\limits_{n\to\infty}\dfrac{n^{10}\cdot(2n)^{10}}{(2n^2)^{10}}$

**解**：括号里只留最高次方（本题已是），再用幂的运算法则：

- $(ab)^n=a^nb^n$：$(2n)^{10}=2^{10}n^{10}$；
- $(a^b)^c=a^{bc}$：$(2n^2)^{10}=2^{10}n^{20}$；
- 同底数幂相乘，底数不变、指数相加：$n^{10}\cdot n^{10}=n^{20}$。

$$=\frac{2^{10}n^{20}}{2^{10}n^{20}}=1$$

**例 29**（指数形式的抓大头）$\lim\limits_{x\to\infty}\dfrac{8^x}{8^x+5^x}$

**解**：分子分母都是指数函数，抓**最大底数**：分子最大底数 $8$、分母最大底数 $8$，**相同则为系数比**，系数都是 $1$，故极限为 $1$。

**例 30**（★ 指数形式的陷阱）$\lim\limits_{x\to+\infty}\dfrac{3^{x+1}}{3^x+2^x}$

**解**：若直接取"看得见的底数"，分子最大底数 $3$、分母也是 $3$，会误判成系数比 $\dfrac11=1$——**陷阱在于分子的系数并不是 $1$**。

先把指数统一：$3^{x+1}=3\cdot3^x$，于是

$$=\lim_{x\to+\infty}\frac{3\cdot3^x}{3^x+2^x}$$

此时最大底数都是 $3$，系数比为 $\dfrac31=3$，故极限为 $3$。

**例 31**（综合题·左右极限 + 指数型抓大头）$\lim\limits_{x\to0}\dfrac{1+e^{1/x}}{2+e^{2/x}}$

**解**：含 $e^{1/x}$，**必须分左右极限**。

**左极限**（$x\to0^-$）：$\dfrac1x\to-\infty$，故 $e^{1/x}\to0$、$e^{2/x}\to0$：

$$\lim_{x\to0^-}\frac{1+e^{1/x}}{2+e^{2/x}}=\frac{1+0}{2+0}=\frac12$$

**右极限**（$x\to0^+$）：$\dfrac1x\to+\infty$，故 $e^{1/x}\to+\infty$、$e^{2/x}\to+\infty$，化为 $\dfrac\infty\infty$ 型。用**指数形式的抓大头**——先把分母的底数统一：$e^{2/x}=\left(e^2\right)^{1/x}$，于是分子最大底数为 $e$、**分母最大底数为 $e^2$**，**下大零**：

$$\lim_{x\to0^+}\frac{1+e^{1/x}}{2+e^{2/x}}=0$$

左右极限都存在但**不相等**，故原极限**不存在**。

> 老师点评：这题的陷阱是"分母的最大底数看着是 $e$，其实是 $e^2$"——**必须先把指数位统一**才能抓最大底数。

### E 组｜第一重要极限（P17）

**例 32** $\lim\limits_{x\to0}\dfrac{\sin3x}{x}$

**解**：分母凑成 $3x$，外面补系数 $3$：$=3\cdot\lim\limits_{x\to0}\dfrac{\sin3x}{3x}=3$。

**例 33** $\lim\limits_{x\to\infty}x\sin\dfrac3x$

**解**：写成 $\dfrac{\sin\frac3x}{\frac1x}$，分母凑成 $\dfrac3x$ 需乘 $3$：$=3\lim\limits_{x\to\infty}\dfrac{\sin\frac3x}{\frac3x}=3$。

**例 34** $\lim\limits_{x\to0}\dfrac{1-\cos x}{x^2}$

**解**：用降幂公式 $1-\cos x=2\sin^2\dfrac x2$：

$$=\lim_{x\to0}\frac{2\sin^2\frac x2}{x^2}=2\cdot\lim_{x\to0}\left(\frac{\sin\frac x2}{\frac x2}\right)^2\cdot\frac14=\frac12$$

（学过等价无穷小后：$1-\cos x\sim\frac12x^2$，一步得 $\frac12$。）

> 本组配套公式：$\sin2x=2\sin x\cos x$；$\cos2x=2\cos^2x-1=1-2\sin^2x=\cos^2x-\sin^2x$；降幂 $\cos^2x=\dfrac{1+\cos2x}2$，$\sin^2x=\dfrac{1-\cos2x}2$。

### F 组｜第二重要极限与万能公式（P17）

**例 35** $\lim\limits_{x\to0}(1+x)^{\frac2x}$

**解**：配成 $(1+x)^{1/x\cdot2}$，得 $e^2$。万能公式：$e^{\lim x\cdot\frac2x}=e^2$。

**例 36** $\lim\limits_{x\to0}(1-2x)^{\frac1x}$

**解**：把 $-2x$ 看作整体 $A$，配 $\dfrac1{-2x}$ 后外面乘 $2$：$e^{\lim(-2x)\cdot\frac1x}=e^{-2}$。

**例 37** $\lim\limits_{x\to\infty}\left(1+\dfrac1{2x}\right)^{4x+3}$

**解**：万能公式 $e^{\lim\frac1{2x}(4x+3)}=e^{\lim\frac{4x+3}{2x}}=e^2$。

**例 38** $\lim\limits_{x\to\infty}\left(\dfrac{x+2}{x+1}\right)^{2x}$

**解**：括号内没有"$1+$"，**创造条件**：$\dfrac{x+2}{x+1}=1+\dfrac1{x+1}$。于是

$$=e^{\lim\frac1{x+1}\cdot2x}=e^2$$

### G 组｜无穷小与无穷大（P18）

**例 39**（无穷小的判定）说明下列函数在指定趋向下是无穷小：$f(x)=x\ (x\to0)$；$f(x)=\dfrac1x\ (x\to\infty)$；$f(x)=\ln(1+x)\ (x\to0)$

**解**：逐个验证"趋向下函数值是否趋于 $0$"：

- $x\to0$ 时 $x\to0$ ⇒ $x$ 是 $x\to0$ 时的无穷小；
- $x\to\infty$ 时 $\dfrac1x\to0$ ⇒ $\dfrac1x$ 是 $x\to\infty$ 时的无穷小；
- $x\to0$ 时 $\ln(1+x)\to\ln1=0$ ⇒ $\ln(1+x)$ 是 $x\to0$ 时的无穷小。

★ 三个例子都必须**带上趋向**才成立——单说"$f(x)$ 是无穷小"没有意义。

**例 40**（无穷大的判定）说明下列函数在指定趋向下是无穷大：$f(x)=\dfrac1x\ (x\to0)$；$f(x)=\ln(1+x)\ (x\to-1)$

**解**：

- $x\to0$ 时 $\dfrac1x\to\infty$ ⇒ 是无穷大（不区分正负，统一写作 $\infty$）；
- $x\to-1$ 时 $1+x\to0^+$，$\ln(1+x)\to-\infty$ ⇒ 是无穷大。这里严格说是**负**无穷，本课程统一写作 $\infty$。

> 无穷大的定义与无穷小完全相反：一个趋近于 $0$、一个趋近于 $\infty$，但**都必须说清趋向**。

**例 41**（性质①：有限个无穷小的和）证明 $f(x)=\sin x+x^2+\ln(1+x)$ 是 $x\to0$ 时的无穷小

**解**：$x\to0$ 时 $\sin x\to0$、$x^2\to0$、$\ln(1+x)\to0$，三者都是无穷小。由"**有限个**无穷小的和、差、积仍是无穷小"，$f(x)$ 是 $x\to0$ 时的无穷小。

★ 关键词是**有限个**。若是**无限个**无穷小相加，结果不一定是无穷小（可能是一个常数）。

**例 42**（性质① 里"商"的反例）$\lim\limits_{x\to0}\dfrac{\sin x}{x}$

**解**：$x\to0$ 时 $\sin x$ 与 $x$ 都是无穷小，但由第一重要极限，商等于 $1$，**不是无穷小**。所以"有限个无穷小的商仍是无穷小"是错的。

**例 43**（零乘有界）$\lim\limits_{x\to\infty}\dfrac{\sin x}{x}$

**解**：拆成 $\dfrac1x\cdot\sin x$。$x\to\infty$ 时 $\dfrac1x\to0$ 是无穷小；而 $\sin x$ 在 $x\to\infty$ 时**极限不存在**（在 $[-1,1]$ 间震荡），故把它看作**有界函数**。由"零乘有界等于零"，极限为 $0$。

> ★ 对比记忆（老师特意把两组对照着讲）：
>
> - $\lim\limits_{x\to\infty}\dfrac{\sin x}{x}=0$——$\sin x$ **有界**，靠"零乘有界"；
> - $\lim\limits_{x\to0}\dfrac{\sin x}{x}=1$——$\sin x$ 是**无穷小**，靠第一重要极限。
>
> 同一个 $\sin x$，身份不同、解法就不同。判据是：**极限不存在（震荡）才当有界函数**。

**例 44**（零乘有界）$\lim\limits_{x\to0}x\sin\dfrac1x$

**解**：$x\to0$ 时 $x$ 是无穷小；$\dfrac1x\to\infty$，故 $\sin\dfrac1x$ 是 $\sin\infty$ 型——同样**极限不存在、看作有界函数**。零乘有界，极限为 $0$。

**例 45**（零乘有界 + 抓大头）$\lim\limits_{x\to\infty}\dfrac{x}{x^2+1}\cos x^2$

**解**：拆成 $\dfrac{x}{x^2+1}\cdot\cos x^2$。

- 第一因子：分子最高次方 $1$、分母 $2$，**下大零**，故 $\dfrac{x}{x^2+1}\to0$；
- 第二因子：$\cos x^2$ 在 $x\to\infty$ 时震荡，**看作有界函数**。

零乘有界，极限为 $0$。

**例 46**（零乘有界）$\lim\limits_{x\to+\infty}\dfrac{\arctan x}{x}$

**解**：拆成 $\arctan x\cdot\dfrac1x$。$\arctan x$ 是有界函数（值域 $\left(-\dfrac\pi2,\dfrac\pi2\right)$），$\dfrac1x\to0$ 是无穷小。零乘有界，极限为 $0$。

> ★ 这一节的四组对比（例 43～例 46）在很多省份会**直接作为四个选项**出现，错误选项往往设成 $1$ 或 $0$，务必会分辨。

**判断辨析**（P18）："无穷小的倒数是无穷大"这句话对吗？

**答**：**错**。$0$ 是特殊的无穷小，而 $\dfrac10$ 没有意义。这句话成立的前提是**分母为趋近于 $0$ 的变量**，而不是确定的 $0$ 这个数。

### H 组｜无穷小比阶（P19）

**例 47** 判断 $\lim\limits_{x\to0}\dfrac{x^5}{x}$、$\lim\limits_{x\to0}\dfrac{x}{x^5}$、$\lim\limits_{x\to0}\dfrac{2x^2}{x^2}$、$\lim\limits_{x\to0}\dfrac{\sin x}{x}$

**解**：分别为 $0$、$\infty$、$2$、$1$，故依次为：$x^5$ 是 $x$ 的**高阶**无穷小；$x$ 是 $x^5$ 的**低阶**无穷小；$2x^2$ 与 $x^2$ **同阶**；$\sin x$ 与 $x$ **等价**。

**例 48** 当 $x\to0$ 时，判断某个"两项 $\sin$ 之差"是 $x^2$ 的什么无穷小

**解**：比值求极限 → 用四则运算**拆成两个极限**（前提是两个极限都存在）→ 其中一个凑成第一重要极限得 $3$，另一个凑成第一重要极限得 $2$ → 比值为 $3-2=1$，故为**等价无穷小**。

> 字幕中该题的函数形式听辨不清，此处只记方法：**比值 → 拆项 → 各凑第一重要极限 → 比值 = 1 即等价**。

**反例（拆极限的禁区）** $\lim\limits_{x\to0}\dfrac{1-\cos x}{x^2}$ **不能**拆成 $\lim\dfrac1{x^2}-\lim\dfrac{\cos x}{x^2}$，因为拆开后两部分都为 $\infty$。

### I 组｜等价无穷小基础运用（P20）

**例 49** $\lim\limits_{x\to0}\dfrac{1-\cos x}{x\sin x}$

**解**：$1-\cos x\sim\frac12x^2$，$\sin x\sim x$，故 $=\dfrac{\frac12x^2}{x\cdot x}=\dfrac12$。

**例 50** $\lim\limits_{x\to0}\dfrac{\sqrt[3]{1+x^2}-1}{\cos x-1}$

**解**：分子写成 $(1+x^2)^{1/3}-1\sim\frac13x^2$；分母 $\cos x-1\sim-\frac12x^2$。故 $=\dfrac{\frac13}{-\frac12}=-\dfrac23$。

**例 51** $\lim\limits_{x\to\infty}\dfrac{2x^2}{x+1}\sin\dfrac1x$

**解**：$x\to\infty$ 时 $\frac1x\to0$，故 $\sin\frac1x\sim\frac1x$。原式 $=\dfrac{2x^2}{x+1}\cdot\dfrac1x=\dfrac{2x}{x+1}\to2$（抓大头）。

**例 52** $\lim\limits_{x\to0}\dfrac{\sqrt{1+\sin x}-1}{x}$

**解**：$\sqrt{1+\sin x}-1\sim\frac12\sin x\sim\frac12x$，故 $=\dfrac12$。

**例 53** $\lim\limits_{x\to0}\dfrac{\sin x-\sin(\sin x)}{x^3}$

**解**：把 $\sin x$ 看成一个方框，用 $\square-\sin\square\sim\dfrac{\square^3}6$，得 $\dfrac{(\sin x)^3/6}{x^3}=\dfrac16$。

**例 54** $\lim\limits_{x\to0}\dfrac{\tan x-\sin x}{x^2\ln(1+x)}$

**解**：分子 $\tan x-\sin x\sim\frac12x^3$；分母 $x^2\ln(1+x)\sim x^2\cdot x=x^3$。故 $=\dfrac12$。

**例 55** $\lim\limits_{x\to0}\left(\dfrac1x-\dfrac{\ln(1+x)}{x^2}\right)$

**解**：通分得 $\lim\limits_{x\to0}\dfrac{x-\ln(1+x)}{x^2}$，分子 $\sim\frac12x^2$，故 $=\dfrac12$。

**例 56**（往年真题）$\lim\limits_{x\to\infty}\left[x-x^2\ln\left(1+\dfrac1x\right)\right]$

**解**：提 $x^2$ 得 $\lim\limits_{x\to\infty}x^2\left[\dfrac1x-\ln\left(1+\dfrac1x\right)\right]$。令 $\square=\dfrac1x\to0$，用 $\square-\ln(1+\square)\sim\dfrac{\square^2}2$：

$$=\lim_{x\to\infty}x^2\cdot\frac12\cdot\frac1{x^2}=\frac12$$

### J 组｜等价无穷小两大误区（P21）

**例 57**（误区一）$\lim\limits_{x\to1}\dfrac{\sin(x-1)}{x-1}=1$

**解**：$x\to1$ 不是 $0$，但被等价整体 $x-1\to0$，所以**可以**等价。同理 $\lim\limits_{x\to\infty}x\sin\dfrac1x=1$。

**例 58**（误区一）$\lim\limits_{x\to+\infty}x\ln\dfrac{x}{x-1}$

**解**：对数真数相除写成 $x\ln\left(1+\dfrac1x\right)$，整体 $\dfrac1x\to0$，故 $\ln(1+\frac1x)\sim\dfrac1x$，得 $\lim x\cdot\dfrac1x=1$。

**例 59**（误区一）$\lim\limits_{x\to2}\dfrac{\sin(x^2-4)}{x^2+x-6}$

**解**：分子整体 $x^2-4\to0$，故 $\sin(x^2-4)\sim x^2-4$。原式 $=\dfrac{(x+2)(x-2)}{(x+3)(x-2)}=\dfrac{x+2}{x+3}\to\dfrac45$。

**例 60**（误区二·反例）$\lim\limits_{x\to0}\dfrac{\tan x-\sin x}{x^3}$

- ❌ 错解：$\tan x\sim x$、$\sin x\sim x$，得 $\dfrac{x-x}{x^3}=0$。错在分子两项是**加减关系**，不能分别等价。
- ✅ 正确：$\tan x-\sin x\sim\dfrac12x^3$，得 $\dfrac12$。

**例 61**（误区二·反例）$\lim\limits_{x\to0}\dfrac{e^x-1-x}{x^2}$

- ❌ 错解：把 $e^x-1$ 等价为 $x$，得 $\dfrac{x-x}{x^2}=0$。
- ✅ 正确做法要用**洛必达**（见例 79）。

### K 组｜非零因子代入（P22）

**例 62** $\lim\limits_{x\to0}\dfrac{e^x-1}{x(1+\cos x)}$

**解**：$1+\cos x\to2$，是**非零因式**且与其余因式相乘，可先把它的极限值算出来：

$$=\frac{1}{2}\lim_{x\to0}\frac{e^x-1}{x}=\frac12\times1=\frac12$$

> 注意 $1+\cos x$ 处在**分母**上，它的极限值是 $2$，所以提到外面的是 $\dfrac12$。

**例 63** $\lim\limits_{x\to0}\dfrac{e^x-e^{\sin x}}{x^3}$

**解**：先提公因式 $e^{\sin x}$：

$$e^x-e^{\sin x}=e^{\sin x}\left(e^{x-\sin x}-1\right)$$

$e^{\sin x}\to1$ 是**非零因式**，可先算；再用广义化等价 $e^{\square}-1\sim\square$（$\square=x-\sin x\to0$）：

$$=1\cdot\lim_{x\to0}\frac{x-\sin x}{x^3}=1\cdot\frac16=\frac16$$

**例 64** $\lim\limits_{x\to0}\dfrac{\sqrt{1+\tan x}-\sqrt{1+\sin x}}{x\left(\sqrt{1+x^2}-1\right)}$

**解**：先看分母。$\sqrt{1+x^2}-1\sim\dfrac12x^2$，故分母 $\sim x\cdot\dfrac12x^2=\dfrac12x^3$。

再看分子，用**根式有理化**（分子分母同乘 $\sqrt{1+\tan x}+\sqrt{1+\sin x}$）：

$$\sqrt{1+\tan x}-\sqrt{1+\sin x}\ \longrightarrow\ \frac{(1+\tan x)-(1+\sin x)}{\sqrt{1+\tan x}+\sqrt{1+\sin x}}=\frac{\tan x-\sin x}{\sqrt{1+\tan x}+\sqrt{1+\sin x}}$$

此时 $\sqrt{1+\tan x}+\sqrt{1+\sin x}\to2$，它是**非零因式**且处于分母的乘积位置，先算它的值：分母整体 $\sim\dfrac12x^3\cdot2=x^3$。分子 $\tan x-\sin x\sim\dfrac12x^3$。故

$$=\frac{\frac12x^3}{x^3}=\frac12$$

### L 组｜等价无穷小习题课（P23）

**例 65** $\lim\limits_{x\to\infty}x\ln\dfrac{x+3}{x}$

**解**：写成 $x\ln\left(1+\dfrac3x\right)$，$\dfrac3x\to0$，得 $x\cdot\dfrac3x=3$。

**例 66** $\lim\limits_{x\to0}\dfrac{x-\tan x}{\left(e^{x^2}-1\right)\sin x}$

**解**：分子 $x-\tan x\sim-\dfrac13x^3$；分母 $e^{x^2}-1\sim x^2$，$\sin x\sim x$，分母 $\sim x^3$。故 $=-\dfrac13$。

**例 67** $\lim\limits_{x\to0}\dfrac{\sqrt{1+x\sin x}-1}{x^2\ln(1+x)}$

**解**：分子 $\sqrt{1+x\sin x}-1\sim\dfrac12x\sin x\sim\dfrac12x^2$；分母 $x^2\ln(1+x)\sim x^3$。故 $=\dfrac{1}{2x}\to\infty$。

> 老师提醒：极限题结果很少为无穷，一般是非零常数；但按正常计算得多少就是多少。

**例 68** $\lim\limits_{x\to0}\dfrac{\sin5x}{e^{\sin x}-1}$

**解**：分子 $\sin5x\sim5x$；分母 $e^{\sin x}-1\sim\sin x\sim x$。故 $=5$。

> 字幕中该题分母的具体形式听辨不清，此处只记方法：**分子用 $\sin\square\sim\square$、分母用 $e^{\square}-1\sim\square$ 分别等价后约分**。

**例 69**（含两个字母）形如 $\dfrac{n x^2}{2}\tan\dfrac{2\pi}{n}$，$n\to\infty$

**解**：只关注真正趋于极限的变量 $n$，另一个字母 $x$ **视为常数**。用 $\tan\square\sim\square$（$\square=\dfrac{2\pi}{n}\to0$）后约分，结果中保留 $x^2$。

> 字幕中该题的系数听辨不清，此处只记方法与"每次只考虑一个变量"的思想（求导、积分中同样适用）。

**例 70** $\lim\limits_{x\to0}\left(\dfrac{1+\sin x}{1+x}\right)^{\frac1{x^3}}$

**解**：$1^\infty$ 型。括号内加 $1$ 减 $1$ 后通分：

$$\frac{1+\sin x}{1+x}=1+\frac{\sin x-x}{1+x}$$

故 $A=\dfrac{\sin x-x}{1+x}$，$B=\dfrac1{x^3}$。

$$=e^{\lim\frac{\sin x-x}{1+x}\cdot\frac1{x^3}}=e^{\lim\frac{\sin x-x}{x^3}}=e^{-\frac16}$$

（其中 $1+x\to1$ 用**非零因子代入**先算出，$\sin x-x\sim-\dfrac16x^3$。）

**例 71** $\lim\limits_{x\to0}\left[\dfrac{x}{\ln(1+x)}\right]^{\frac1{\sin2x}}=e^{\frac14}$

**解**：括号内写成 $1+\dfrac{x-\ln(1+x)}{\ln(1+x)}$，$1^\infty$ 型用万能公式：

$$A\cdot B=\frac{x-\ln(1+x)}{\ln(1+x)\cdot\sin2x}\sim\frac{\frac12x^2}{x\cdot2x}=\frac14$$

**例 72** $\lim\limits_{x\to0}\dfrac1{x^2}\ln\dfrac{\sin x}{x}$

**解**：写成 $\dfrac1{x^2}\ln\left(1+\dfrac{\sin x-x}{x}\right)$。先判断整体 $\dfrac{\sin x-x}{x}\sim-\dfrac{x^2}6\to0$，故 $\ln(1+\square)\sim\square$：

$$=\lim_{x\to0}\frac1{x^2}\cdot\frac{\sin x-x}{x}=\lim_{x\to0}\frac{-\frac16x^3}{x^3}=-\frac16$$

**例 73** 当 $x\to0$ 时，$\ln(1+2x^3)$ 与 $x^n\sin x$ 是**同阶**无穷小，求 $n$

**解**：$\ln(1+2x^3)\sim2x^3$，$x^n\sin x\sim x^{n+1}$。同阶要求比值为非零常数，故 $3-(n+1)=0$，得 $n=2$。

**例 74** 当 $x\to0$ 时，$1-e^{\sin x}$ 是 $x^{1/3}$ 的什么阶无穷小

**解**：$\dfrac{1-e^{\sin x}}{x^{1/3}}=\dfrac{-\sin x}{x^{1/3}}\sim-x^{2/3}\to0$，故是**高阶**无穷小。

**例 75** 当 $x\to0$ 时，$\sqrt{1+ax^2}-1$ 与 $\sin^2x$ 是**等价**无穷小，求 $a$

**解**：$\sqrt{1+ax^2}-1\sim\dfrac a2x^2$，$\sin^2x\sim x^2$，比值 $\dfrac a2=1$，故 $a=2$。

**例 76** 当 $x\to0$ 时，下列无穷小中比其他三个**更高阶**的是：

$A.\ x^2$；$B.\ 1-\cos x$；$C.\ \sqrt{1-x^2}-1$；$D.\ x-\tan x$

**解**：全部化成同阶形式：$A\sim x^2$，$B\sim\dfrac12x^2$，$C\sim-\dfrac12x^2$，$D\sim-\dfrac13x^3$。$D$ 的阶数最高，选 **D**。

### M 组｜夹逼定理（P24）

**例 77** $\lim\limits_{n\to\infty}\left(\dfrac1{n^2+1}+\dfrac1{n^2+2}+\cdots+\dfrac1{n^2+n}\right)$

**解**：

- ❌ 错解：每项抓大头都等于 $0$，结果 $0$。错在"无穷多个无穷小相加不一定为 $0$"。
- ✅ 记原式为 $a_n$。**放小**（分母全换成最大的 $n^2+n$）：$b_n=\dfrac{n}{n^2+n}\to\dfrac12$；
  **放大**（分母全换成最小的 $n^2+1$）：$c_n=\dfrac{n}{n^2+1}\to\dfrac12$。

由 $b_n\le a_n\le c_n$ 且两端极限都是 $\dfrac12$，得原极限 $=\dfrac12$。

（其中 $1+2+\cdots+n=\dfrac{n(n+1)}2$。）

**例 78** $\lim\limits_{n\to\infty}\left(\dfrac1{n^2+n-1}+\dfrac1{n^2+n-2}+\cdots+\dfrac1{n^2+n-n}\right)$

**解**：第一项分母 $n^2+n-1$ 最大，最后一项分母 $n^2$ 最小。

- 放小（全换成最大分母）：$\dfrac{n}{n^2+n-1}\to0$；
- 放大（全换成最小分母）：$\dfrac{n}{n^2}= \dfrac1n\to0$。

故原极限 $=0$。

> 技巧：所有分母要么取**第一项的分母**，要么取**最后一项的分母**；务必判断这样换是放大还是放小。

### N 组｜洛必达法则基础（P25）

**例 79** $\lim\limits_{x\to0}\dfrac{e^x-1-x}{x^2}$

**解**：$\dfrac00$ 型，洛必达一次：$\dfrac{e^x-1}{2x}$，仍是 $\dfrac00$；把 $e^x-1$ 等价为 $x$：$\dfrac{x}{2x}=\dfrac12$。

**例 80** $\lim\limits_{x\to0}\dfrac{x-\sin x}{x^3}$

**解**：

- 等价法：$x-\sin x\sim\dfrac16x^3$，得 $\dfrac16$；
- 洛必达：$\dfrac{1-\cos x}{3x^2}\sim\dfrac{\frac12x^2}{3x^2}=\dfrac16$；也可继续洛必达两次：$\dfrac{\sin x}{6x}\to\dfrac16$。

**例 81** 分子为 $2x^2+6x$、分母为二次多项式（常数项为 $1$）的 $\dfrac\infty\infty$ 型

**解**：洛必达一次得 $\dfrac{4x+6}{2x}$，再洛必达得 $\dfrac42=2$。用抓大头更快（分子分母最高次方相同，取系数比 $2$）。

**例 82** $\lim\limits_{x\to+\infty}\dfrac{x^3}{e^x}$

**解**：$\dfrac\infty\infty$ 型，洛必达三次：$\dfrac{3x^2}{e^x}\to\dfrac{6x}{e^x}\to\dfrac6{e^x}$。$x\to+\infty$ 时 $e^x\to+\infty$，故 $=$ 常数$/\infty=0$。

**例 83**（洛必达失效）$\lim\limits_{x\to\infty}\dfrac{x+\sin x}{x-\cos x}$

- ❌ 洛必达得 $\dfrac{1+\cos x}{1+\sin x}$，极限不存在——但**不能**由此说原极限不存在。
- ✅ 方法一（抓大头）：$|\sin x|\le1$、$|\cos x|\le1$ 有界，相对 $x$ 可忽略，得 $\dfrac xx=1$。
- ✅ 方法二（同除 $x$）：$\dfrac{1+\frac{\sin x}{x}}{1-\frac{\cos x}{x}}$，两个"零乘有界"项都为 $0$，得 $1$。

### O 组｜零比零型系统训练（P26）

**例 84** $\lim\limits_{x\to1}\dfrac{x^2-3x+2}{x^2+2x-3}$

**解**：$\dfrac00$ 型，约分：$\dfrac{(x-1)(x-2)}{(x+3)(x-1)}=\dfrac{x-2}{x+3}\to\dfrac{-1}{4}=-\dfrac14$。

**例 85** $\lim\limits_{x\to0}\dfrac{e^x-e^{-x}}{\arctan x}$（两种解法）

**解**：$\arctan x\sim x$，原式 $=\lim\limits_{x\to0}\dfrac{e^x-e^{-x}}{x}$。

- 思路一：提 $e^{-x}$，得 $e^{-x}\left(e^{2x}-1\right)/x$。$e^{-x}\to1$ 是非零因式，$e^{2x}-1\sim2x$，结果 $2$。
- 思路二：分子加 $1$ 减 $1$ 拆成两个极限：$\lim\dfrac{e^x-1}{x}-\lim\dfrac{e^{-x}-1}{x}=1-(-1)=2$。

**例 86** $\lim\limits_{x\to2}\dfrac{x^2-4}{\sqrt x-\sqrt2}$

**解**：根式有理化（同乘 $\sqrt x+\sqrt2$）：$=\lim\limits_{x\to2}\dfrac{(x+2)(x-2)(\sqrt x+\sqrt2)}{x-2}=4\cdot2\sqrt2=8\sqrt2$。

**例 87** $\lim\limits_{x\to0}\dfrac{e^x-1+\sin x}{\ln(1+x)}$

**解**：分子是**加减关系**，不能直接等价，要**拆成两个极限**（两者都存在）：

$$=\lim_{x\to0}\frac{e^x-1}{\ln(1+x)}+\lim_{x\to0}\frac{\sin x}{\ln(1+x)}=1+1=2$$

> 字幕中分子的写法含混（听作"$e^x$ 加 $\sin x$"），但拆项后应为 $e^x-1+\sin x$，此处按拆分结果记录。

**例 88** $\lim\limits_{x\to0}\dfrac{3\sin x+x^2\cos\frac1x}{(1+\cos x)\ln(1+x)}$

**解**：$1+\cos x\to2$ 是非零因式先算，分母 $\to2x$。拆成两个极限：

$$=\frac12\left[\lim_{x\to0}\frac{3\sin x}{x}+\lim_{x\to0}x\cos\frac1x\right]=\frac12[3+0]=\frac32$$

（第二项是"零乘有界"$\to0$。）

**例 89** $\lim\limits_{x\to0}\dfrac{\ln\cos x}{x^2}$

**解**：括号里凑出 $1$：$\ln\cos x=\ln(1+(\cos x-1))$，整体 $\cos x-1\to0$，故 $\sim\cos x-1\sim-\dfrac12x^2$。得 $=-\dfrac12$。

**例 90** 已知 $x\to0$ 时 $\ln\cos\dfrac{2x}3\sim ax^k$，求 $a,k$

**解**：$\ln\cos\dfrac{2x}3\sim\cos\dfrac{2x}3-1\sim-\dfrac12\left(\dfrac{2x}3\right)^2=-\dfrac12\cdot\dfrac{4x^2}9=-\dfrac29x^2$。故 $a=-\dfrac29$，$k=2$。

### P 组｜无穷比无穷型（P27）

**例 91** 分子分母同为二次多项式的 $\dfrac\infty\infty$ 型

**解**：最高次方相同，取系数比，得 $\dfrac13$。

**例 92** $\lim\limits_{x\to\infty}\dfrac{x+\sin x}{x-\cos x}=1$（同例 83）

**例 93**（考研辅导书题）分子最高次项为 $2x^2$、分母最高次项为 $x^2$，另含 $x\cos x$ 项

**解**：$x\cos x$ 相对 $x^2$ 太小，可忽略；抓大头取系数比，得 $2$。用洛必达则会陷入失效。

**例 94** $\lim\limits_{n\to\infty}\dfrac{5^n+2^n}{5^n+\cdots}$（分子分母均为指数函数）

**解**：分子分母**最大底数都是 $5$**，系数比为 $\dfrac11=1$。

**例 95**（例 94 的变形）$\lim\limits_{n\to\infty}\dfrac{5^{n+1}+2^n}{5^n+2^n}$

**解**：先把 $5^{n+1}$ 拆成 $5\cdot5^n$，指数统一后再取系数比：$\dfrac{1}{5}$。

**例 96** 含根号的数列极限（分子 $\sqrt{4n^2+\cdots}+n$，分母 $\sqrt{9n^2+\cdots}$）

**解**：根号下低于最高次方的部分全部去掉：分子 $\to\sqrt{4n^2}+n=2n+n=3n$，分母 $\to\sqrt{9n^2}=3n$，结果 $1$。

**例 97**（往年真题·填空）$\lim\limits_{x\to\infty}\dfrac{(x+1)^{95}(ax+1)^5}{(x^2+1)^{50}}=32$，求 $a$

**解**：括号内只留最高次方：分子 $\to x^{95}\cdot a^5x^5=a^5x^{100}$，分母 $\to x^{100}$。故 $a^5=32$，得 $a=2$。

**例 98** 已知 $\lim\limits_{x\to\infty}\left(\dfrac{x^2}{x+1}-ax-b\right)=0$，求 $a,b$

**解**：通分得 $\dfrac{(1-a)x^2-(a+b)x-b}{x+1}$。分母最高次方为 $1$，要使极限为 $0$（"下大零"），分子最高次方必须降到 $0$ 次以下，故

$$1-a=0,\qquad a+b=0\ \Longrightarrow\ a=1,\ b=-1$$

> 字幕末句把 $b$ 记作 $1$，与前式 $a+b=0$ 矛盾，此处以推导结果为准。

### Q 组｜无穷减无穷型（P27）

**例 99**（含分式·考频最高）$\lim\limits_{x\to0}\left(\dfrac1{x^2}-\dfrac1{\sin^2x}\right)$

**解**：通分得 $\dfrac{\sin^2x-x^2}{x^2\sin^2x}$。分母 $\sin^2x\sim x^2$，故分母 $\sim x^4$；分子平方差：$(\sin x-x)(\sin x+x)$，其中 $\sin x-x\sim-\dfrac16x^3$，$\sin x+x\to2x$。故

$$=\lim_{x\to0}\frac{-\frac16x^3\cdot2x}{x^4}=-\frac13$$

**例 100**（含分式）$\lim\limits_{x\to0}\left(\dfrac1{\ln(1+x)}-\dfrac1x\right)$

**解**：通分得 $\dfrac{x-\ln(1+x)}{x\ln(1+x)}$，分子 $\sim\dfrac12x^2$，分母 $\sim x\cdot x=x^2$，得 $\dfrac12$。

**例 101**（含根式）$\lim\limits_{x\to+\infty}\left(\sqrt{x^2+4x+1}-x\right)$

**解**：根式有理化：$=\lim\limits_{x\to+\infty}\dfrac{4x+1}{\sqrt{x^2+4x+1}+x}$。根号下去掉低次项：$\dfrac{4x}{x+x}=2$。

**例 102**（往年真题）$\lim\limits_{x\to+\infty}\left[x-x^2\ln\left(1+\dfrac1x\right)\right]=\dfrac12$（见例 56）

**解一（倒代换）**：令 $t=\dfrac1x$（$x\to+\infty$ 时 $t\to0^+$），原式 $=\dfrac1t-\dfrac1{t^2}\ln(1+t)=\dfrac{t-\ln(1+t)}{t^2}\to\dfrac12$。

**解二（提 $x^2$）**：原式 $=x^2\left[\dfrac1x-\ln\left(1+\dfrac1x\right)\right]$，用广义化 $\square-\ln(1+\square)\sim\dfrac{\square^2}2$（$\square=\dfrac1x\to0$），得 $x^2\cdot\dfrac12\cdot\dfrac1{x^2}=\dfrac12$。

**例 103**（负代换）形如 $t\to-\infty$ 的 $\sqrt{\ }+t$ 型

**解**：令 $x=-t$，则 $t\to-\infty$ 时 $x\to+\infty$；根号内 $t^2=x^2$，$t=-x$，把"负无穷"化为"正无穷"。再用**根式有理化** + 去掉低次项 + 抓大头，得 $\dfrac12$。

> 字幕中该题的根号内各项符号听辨不清，此处只记方法：**负代换 → 根式有理化 → 去低次项 → 抓大头**。

### R 组｜零乘无穷型（P27）

**例 104** $\lim\limits_{x\to0^+}x\ln x$

**解**：定型为 $0\cdot\infty$。**取倒数下放**：$=\lim\limits_{x\to0^+}\dfrac{\ln x}{1/x}$，化为 $\dfrac\infty\infty$。洛必达：$\dfrac{1/x}{-1/x^2}=-x\to0$。

**例 105** $\lim\limits_{x\to+\infty}x\left(\arctan x-\dfrac\pi2\right)$

**解**：定型为 $\infty\cdot0$。下放：$=\lim\limits_{x\to+\infty}\dfrac{\arctan x-\frac\pi2}{1/x}$，化为 $\dfrac00$。洛必达（$(\arctan x)'=\dfrac1{1+x^2}$，$\left(\frac1x\right)'=-\dfrac1{x^2}$）：

$$=\lim_{x\to+\infty}\frac{\frac1{1+x^2}}{-\frac1{x^2}}=-\lim_{x\to+\infty}\frac{x^2}{1+x^2}=-1$$

**例 106** $\lim\limits_{x\to\frac\pi2}\left(\dfrac\pi2-x\right)\tan x$

**解**：定型为 $0\cdot\infty$。不必下放，先把 $\tan x$ 换成 $\dfrac{\sin x}{\cos x}$：$=\lim\limits_{x\to\frac\pi2}\dfrac{\left(\frac\pi2-x\right)\sin x}{\cos x}$。$\sin\frac\pi2=1$ 是**非零因式**先算，化为 $\dfrac{\frac\pi2-x}{\cos x}$（$\dfrac00$ 型）。洛必达：$\dfrac{-1}{-\sin x}=\dfrac1{\sin x}\to1$。

**例 107** $\lim\limits_{x\to+\infty}x\left[\ln(1+x)-\ln x\right]$

**解**：对数真数相除：$=x\ln\left(1+\dfrac1x\right)$，$\dfrac1x\to0$，等价得 $x\cdot\dfrac1x=1$。

### S 组｜七种未定式（下）：1 的无穷次方（P28）

**例 108** $\lim\limits_{x\to0}(1+\sin x)^{\frac1x}$

**解**：$1^\infty$ 型，$A=\sin x$，$B=\dfrac1x$。$=e^{\lim\frac{\sin x}{x}}=e^1=e$。

**例 109** $\lim\limits_{x\to0}\left(\dfrac{1+\sin x}{1+x}\right)^{\frac1{1-\cos x}}$

**解**：$1^\infty$ 型。括号内写成 $1+\dfrac{\sin x-x}{1+x}$，则

$$=e^{\lim\frac{\sin x-x}{1+x}\cdot\frac1{1-\cos x}}=e^{\lim\frac{\sin x-x}{1-\cos x}}=e^{\lim\frac{-\frac16x^3}{\frac12x^2}}=e^{0}=1$$

**例 110** $\lim\limits_{x\to0}\left(\dfrac{\sin x}{x}\right)^{\frac1{x^2}}$

**解**：括号 $\to1$（局部极限，只用于定型），指数 $\to\infty$，$1^\infty$ 型。写成 $1+\dfrac{\sin x-x}{x}$，则

$$=e^{\lim\frac{\sin x-x}{x}\cdot\frac1{x^2}}=e^{\lim\frac{\sin x-x}{x^3}}=e^{-\frac16}$$

**例 111** $\lim\limits_{x\to0}\left(e^{2x}+\sin x\right)^{\frac2x}$

**解**：括号 $\to1$，指数 $\to\infty$。写成 $1+(e^{2x}+\sin x-1)$，则

$$=e^{\lim\left(e^{2x}+\sin x-1\right)\cdot\frac2x}=e^{\left[\lim\frac{2(e^{2x}-1)}{x}+\lim\frac{2\sin x}{x}\right]}=e^{2\times2+2\times1}=e^6$$

**例 112**（专升本真题·大题）已知 $\lim\limits_{x\to\infty}\left(\dfrac{x+c}{x-c}\right)^{\frac x2}=3$，求 $c$

**解**：括号内抓大头 $\to1$，指数 $\to\infty$，$1^\infty$ 型。写成 $1+\dfrac{2c}{x-c}$，则

$$=e^{\lim\frac{2c}{x-c}\cdot\frac x2}=e^{\lim\frac{cx}{x-c}}=e^{c}$$

由 $e^c=3$，两边**取对数**：$c\ln e=\ln3$，得 $c=\ln3$。

**例 113**（2011 年考研数学一）$\lim\limits_{x\to0}\left(\dfrac{\ln(1+x)}{x}\right)^{\frac1{e^x-1}}$

**解**：括号 $\to1$，指数 $\to\infty$。写成 $1+\dfrac{\ln(1+x)-x}{x}$，则

$$=e^{\lim\frac{\ln(1+x)-x}{x}\cdot\frac1{e^x-1}}=e^{\lim\frac{\ln(1+x)-x}{x^2}}=e^{\lim\frac{-\frac12x^2}{x^2}}=e^{-\frac12}$$

**例 114**（2022 年考研填空）$\lim\limits_{x\to0}\left(\dfrac{1+e^x}{2}\right)^{\cot x}$

**解**：括号 $\to1$，$\cot x\to\infty$。写成 $1+\dfrac{e^x-1}{2}$，并把 $\cot x$ 换成 $\dfrac{\cos x}{\sin x}$：

$$=e^{\lim\frac{e^x-1}{2}\cdot\frac{\cos x}{\sin x}}=e^{\lim\frac{x}{2x}\cdot1}=e^{\frac12}$$

（$\cos x\to1$ 用非零因子代入。）

**例 115**（2003 年考研真题）$\lim\limits_{x\to0}(\cos x)^{\frac1{\ln(1+x^2)}}$

**解**：括号 $\to1$，指数 $\to\infty$。写成 $1+(\cos x-1)$，则

$$=e^{\lim\frac{\cos x-1}{\ln(1+x^2)}}=e^{\lim\frac{-\frac12x^2}{x^2}}=e^{-\frac12}$$

### T 组｜无穷的零次方与零的零次方（P28）

**例 116** $\lim\limits_{x\to0^+}x^{\sin x}$

**解**：$0^0$ 型，指数对数化：$=e^{\lim\sin x\ln x}$。先算 $\lim\limits_{x\to0^+}\sin x\ln x=\lim\dfrac{\ln x}{1/\sin x}$，等价 $\sin x\sim x$ 后为 $\lim x\ln x=0$（见例 104）。故 $=e^0=1$。

**例 117** $\lim\limits_{x\to+\infty}(1+x)^{\frac1x}$

**解**：$\infty^0$ 型（**不能**用第二重要极限）。指数对数化：$=e^{\lim\frac{\ln(1+x)}{x}}$。$\dfrac\infty\infty$ 型，抓大头不行、无根式，只能用洛必达：

$$\lim_{x\to+\infty}\frac{\frac1{1+x}}{1}=\lim_{x\to+\infty}\frac1{1+x}=0\ \Longrightarrow\ e^0=1$$

### U 组｜连续（P29）

**例 118** $f(x)=\begin{cases}x,&x\ne0\\1,&x=0\end{cases}$，讨论 $x=0$ 处的连续性

**解**：$\lim\limits_{x\to0^-}f(x)=\lim\limits_{x\to0^+}f(x)=0$，故 $\lim\limits_{x\to0}f(x)=0$（极限**存在**）；但 $f(0)=1$。极限值 $\ne$ 函数值，故**不连续**。

**例 119** 讨论 $f(x)=\begin{cases}x+1,&x\le0\\x-1,&x>0\end{cases}$ 在 $x=0$ 处的左、右连续性

**解**：$\lim\limits_{x\to0^-}f(x)=1=f(0)$ → **左连续**；$\lim\limits_{x\to0^+}f(x)=-1\ne f(0)$ → **非右连续**。

> 字幕中把右极限说成 $1$，与其"不右连续"的结论矛盾，此处按结论取 $-1$。

**例 120** 已知 $f(x)=\begin{cases}\lambda+\sin x,&x<0\\x^2\sin\dfrac1x,&x>0\end{cases}$ 在 $x=0$ 处连续，求 $\lambda$

**解**：左极限 $=\lambda$；右极限 $\lim\limits_{x\to0^+}x^2\sin\dfrac1x=0$（**零乘有界**）。由连续充要条件得 $\lambda=0$。

**例 121** 已知 $f(x)=(1+2x)^{\frac1{\sin x}}\ (x\ne0)$，$f(0)=K$，且 $f$ 在 $x=0$ 处连续，求 $K$

**解**：$x\to0$ 时括号 $\to1$、指数 $\to\infty$，$1^\infty$ 型。$A=2x$，$B=\dfrac1{\sin x}$：

$$\lim_{x\to0}f(x)=e^{\lim\frac{2x}{\sin x}}=e^2$$

由连续充要条件得 $K=e^2$。

**例 122** $f(x)=\begin{cases}\dfrac{\sqrt{1+x^2}-1}{x},&x<0\\[2mm]2\arctan\dfrac1x,&x>0\\[2mm]1,&x=0\end{cases}$，讨论 $x=0$ 处连续性

**解**：

- 左极限：$\sqrt{1+x^2}-1\sim\dfrac12x^2$，故 $\dfrac{\frac12x^2}{x}=\dfrac x2\to0$；
- 右极限：$x\to0^+$ 时 $\dfrac1x\to+\infty$，$\arctan\dfrac1x\to\dfrac\pi2$，故 $2\times\dfrac\pi2=\pi$；
- $f(0)=1$。

左极限 $\ne f(0)$，右极限 $\ne f(0)$，**既不左连续也不右连续**，故在 $x=0$ 处**不连续**。

**例 123** $K$ 为何值时 $f(x)=\begin{cases}\dfrac{2(1-\cos x)}{x^2},&x<0\\[2mm]\dfrac{e^x-1}{x},&x>0\\[2mm]K,&x=0\end{cases}$ 在定义域内连续

**解**：左极限 $=\dfrac{2\cdot\frac12x^2}{x^2}=1$；右极限 $=\dfrac{e^x-1}{x}\sim\dfrac xx=1$；$f(0)=K$。由连续充要条件得 $K=1$。

### V 组｜间断点（P30）

**例 124** 讨论 $f(x)=\dfrac{x^2-5x+6}{x^2-9}$ 的间断点及其类型

**解**：分母 $x^2-9=(x-3)(x+3)$，故间断点为 $x=3$、$x=-3$。

- $x=3$：$\dfrac{(x-2)(x-3)}{(x-3)(x+3)}=\dfrac{x-2}{x+3}\to\dfrac16$，极限存在 → **可去间断点**；
- $x=-3$：$\dfrac{x-2}{x+3}\to\dfrac{-5}{0}=\infty$ → **无穷间断点**。

**例 125** 讨论 $f(x)=\dfrac{x}{\sin x}$ 的间断点类型

**解**：间断点 $x=k\pi\ (k\in\mathbb Z)$。

- $k=0$：$\lim\limits_{x\to0}\dfrac{x}{\sin x}=1$ → **可去间断点**；
- $k\ne0$：$\lim\limits_{x\to k\pi}\dfrac{x}{\sin x}=\dfrac{k\pi}{0}=\infty$ → **无穷间断点**。

**例 126**（考研题）讨论 $f(x)=\dfrac1{e^{\frac{x}{x-1}}-1}$ 的间断点类型

**解**：先找间断点。内层分式要求 $x\ne1$；外层分母为零要求 $e^{\frac x{x-1}}=1$，即 $\dfrac x{x-1}=0$，即 $x=0$。故间断点为 $x=1$、$x=0$。

- $x=1$：$x\to1^-$ 时 $\dfrac x{x-1}\to-\infty$，$e^{\cdot}\to0$，分母 $\to-1$，$f\to-1$；$x\to1^+$ 时 $\dfrac x{x-1}\to+\infty$，$e^{\cdot}\to+\infty$，分母 $\to+\infty$，$f\to0$。左右极限都存在但不相等 → **跳跃间断点**。
  > 字幕把左极限记作 $1$，与推导 $1/(0-1)=-1$ 不符，此处以推导为准。
- $x=0$：$\dfrac x{x-1}\to0$，$e^0=1$，分母 $\to0$，分子为 $1$，$f\to\infty$ → **无穷间断点**。

**例 127** $f(x)=e^{\frac{|x|}{x}}$ 在 $x=0$ 处的间断点类型

**解**：$x=0$ 使分母为零，为间断点。这是 $1^\infty$ 型，用万能公式 $e^{\lim\frac{|x|}{x}}$：

- $x\to0^-$：$|x|=-x$，$\dfrac{|x|}{x}=-1$，得 $e^{-1}$；
- $x\to0^+$：$|x|=x$，$\dfrac{|x|}{x}=1$，得 $e$。

左右极限都存在但不相等 → **跳跃间断点**。

**例 128** 求 $f(x)=\dfrac{\cdots}{x(x-2)}$ 的连续区间

**解**：分母为零点为 $x=0$、$x=2$，二者为间断点。其余各点连续，故连续区间为

$$(-\infty,0)\cup(0,2)\cup(2,+\infty)$$

**例 129** 分段函数 $f(x)=(\cos x)^{\frac1{x^2}}\ (x\ne0)$，$f(0)=1$，判断 $x=0$ 处间断点类型

**解**：因 $x<0$ 与 $x>0$ 都是同一表达式，**不必**分左右极限。括号 $\to1$、指数 $\to\infty$，$1^\infty$ 型。写成 $1+(\cos x-1)$：

$$\lim_{x\to0}f(x)=e^{\lim\frac{\cos x-1}{x^2}}=e^{\lim\frac{-\frac12x^2}{x^2}}=e^{-\frac12}$$

而 $f(0)=1$，极限值 $\ne$ 函数值 → 是间断点；又左右极限存在且相等 → **可去间断点**。

## 四、易错点警示

| ❌ 易错 | ✅ 正确 |
|:---|:---|
| 认为 $x\to x_0$ 就是 $x=x_0$ | 极限是"无限接近"的过程，与那一点的值无关 |
| 算 $\lim\limits_{x\to\infty}f(x)$ 时只算 $x\to+\infty$ | 必须分别算 $+\infty$ 与 $-\infty$，两者相等才存在 |
| 数列极限 $n\to\infty$ 也分正负无穷 | $n$ 是自然数，只趋于 $+\infty$ |
| 所有极限都去分左右 | 只有四种情形必须分：$e^{1/x}$、$\arctan\frac1x$ 型定点，$e^x$、$\arctan x$ 型无穷点，分段点，含绝对值 |
| 拆极限时不管各部分是否收敛 | 拆开后任一部分为无穷就不能拆（如 $\frac{1-\cos x}{x^2}$） |
| 见到 $\frac00$ 就约分或认为等于 $1$ | $\frac00$ 是未定式，要先定型再挑方法（约分、通分、有理化、等价、洛必达） |
| 认为只有 $x\to0$ 才能用等价无穷小 | 看"被等价的整体"是否趋于 0，与 $x$ 趋向无关 |
| 在加减关系里用等价无穷小 | 被等价因式必须与其他因式构成**乘除**关系 |
| 把 $\cos x-1$ 也等价为 $\frac12x^2$ | 前后交换要加负号：$\cos x-1\sim-\frac12x^2$ |
| 把 $\tan x-\sin x$ 等价为 $\frac16x^3$ | 正确的是 $x-\sin x\sim\frac16x^3$，$\tan x-\sin x\sim\frac12x^3$ |
| 对非零因式也留在式子里硬算 | 非零因式且与其余因式相乘时，可先算出它的极限值 |
| 夹逼定理里把每项单独抓大头 | 无穷多个无穷小相加不一定为 0，必须整体放缩 |
| 洛必达用在 $\frac00$、$\frac{\infty}{\infty}$ 以外的类型 | 只有这两种类型能用洛必达 |
| 洛必达一次后不再判断类型 | 每次求导后都要重新定型，直到不再是未定式 |
| 洛必达后极限不存在就断定原极限不存在 | 洛必达失效时（如 $\frac{x+\sin x}{x-\cos x}$）要改用抓大头或"零乘有界" |
| $\infty^0$ 型用第二重要极限 | 第二重要极限只对 $1^\infty$ 型有效，$\infty^0$、$0^0$ 要用指数对数化 |
| 判断连续性只看左右极限相等 | 还要等于**该点的函数值**，三者缺一不可 |
| 认为分段点一定是间断点 | 分段点可能是连续点，必须算出极限值与函数值再比较 |
| 判断间断点类型时忘了分左右 | $\arctan\frac1x$、$e^{1/x}$、分段函数这三类必须分左右极限 |
| 把 $\lim\limits_{n\to\infty}2^n=\infty$ 当成"极限存在" | 极限结果为 $\infty$，本考试一律算**不存在**，数列发散 |
| 认为 $(-1)^n$ 的极限是 $1$ 或 $-1$ | 它在 $-1$ 与 $1$ 之间**震荡**，极限不存在 |
| 把 $\sin x$、$\cos x$ 在任何场合都当有界函数 | 只有 $\lim\sin x$ **不存在**（如 $x\to\infty$）时才当有界；$x\to0$ 时 $\sin x$ 是无穷小 |
| 说"无穷小的倒数是无穷大" | $0$ 是特殊无穷小，$\frac10$ 无意义；成立前提是分母为**趋近于 0 的变量** |
| 认为"有限个无穷小的商"仍是无穷小 | 商**不一定**是无穷小（$\frac{\sin x}{x}\to1$） |
| 用抓大头处理非 $\frac\infty\infty$ 型 | 抓大头**只能**用于 $\frac\infty\infty$ 型 |
| 把 $1+2+\cdots+n$ 直接抓大头 | 分子是**无穷多项之和**，要先求等差数列前 $n$ 项和，再抓大头 |
| 指数形式抓大头时直接取"看得见的底数" | 先统一指数（$3^{x+1}=3\cdot3^x$、$e^{2/x}=(e^2)^{1/x}$），再取**最大底数** |

## 五、小结

| 考点 | 要点 |
|:---|:---|
| 函数极限定义 | $x\to x_0$ 或 $x\to\infty$ 时 $f(x)\to A$；极限是过程不是等号 |
| $x\to\infty$ 极限存在 | 充要条件：$x\to+\infty$ 与 $x\to-\infty$ 的极限都存在且相等 |
| 两个小极限 | $\lim\limits_{x\to0}\frac kx=\infty\ (k\ne0)$；$\lim\limits_{x\to\infty}\frac kx=0$ |
| 左右极限 | 极限存在 $\iff$ 左极限 = 右极限 |
| 必须分左右的四种情形 | $e^{1/x}$、$\arctan\frac1x$ 型；$e^x$、$\arctan x$ 型；分段点；含绝对值 |
| 四则运算 | 前提是各部分极限**都存在** |
| 七种未定式 | $\frac00$、$\frac\infty\infty$、$\infty-\infty$、$0\cdot\infty$、$1^\infty$、$\infty^0$、$0^0$；核心是前两种 |
| 解题三步 | 定型 → 化简 → 用公式 |
| 第一重要极限 | $\lim\limits_{x\to0}\frac{\sin x}{x}=1$，广义化要求整体趋于 0 且形式一致 |
| 第二重要极限 | $\lim\limits_{x\to0}(1+x)^{1/x}=\lim\limits_{x\to\infty}(1+\frac1x)^x=e$；括号内与指数互为倒数 |
| $1^\infty$ 万能公式 | $\lim(1+A)^B=e^{\lim A\cdot B}$，所有 $1^\infty$ 型都能解决 |
| 无穷小比阶 | 比值 $0$ 高阶 / $\infty$ 低阶 / 非零常数同阶 / $1$ 等价 |
| 等价无穷小本质 | 一种高级的化简方法 |
| 等价的两个前提 | ① 被等价整体趋于 0；② 与其他因式构成乘除关系 |
| 常用等价公式 | 11 组，前五组（$\sin x,\tan x,\arcsin x,\arctan x,e^x-1,\ln(1+x)\sim x$ 与 $1-\cos x\sim\frac12x^2$）最重要 |
| 等价广义化 | 把 $x$ 换成整体"方框"，只要方框趋于 0 就能用 |
| 两大误区 | 不是只有 $x\to0$ 才能等价；加减关系里不能等价 |
| 非零因子代入 | 只用于 $\frac00$ 型；因式非零且与其余因式相乘时可先算 |
| 夹逼定理 | $a_n\le b_n\le c_n$ 且两端极限相同，则中间相同；对分母放缩 |
| 洛必达法则 | 只对 $\frac00$、$\frac\infty\infty$；分子分母同时求导，每次重新定型，能等价就等价 |
| 洛必达失效 | 求导后极限不存在不等于原极限不存在；改用抓大头或"零乘有界" |
| 抓大头 | 上大无穷，下大零，相同则为系数比；指数函数看最大底数；含根号括号去掉低次项 |
| $\infty-\infty$ 型 | 含分式 → 通分；含根式 → 有理化；另有倒代换、负代换 |
| $0\cdot\infty$ 型 | 取倒数下放，化成 $\frac00$ 或 $\frac\infty\infty$ |
| $\infty^0$、$0^0$ 型 | 指数对数化：$u^v=e^{v\ln u}$ |
| 连续 | 定义：极限值 = 函数值；充要条件：左极限 = 右极限 = 函数值 |
| 左/右连续 | 左极限 = 函数值 → 左连续；右极限 = 函数值 → 右连续 |
| 间断点位置 | 分母为零的点；分段函数的分段点 |
| 间断点分类 | 第一类：可去（左右极限相等）、跳跃（不等）；第二类：无穷、震荡 |
| 连续区间 | 找出全部间断点，从数轴上挖掉，剩下的开区间 |
| 数列极限 | $\lim\limits_{n\to\infty}a_n=a$；$n\to\infty$ **特指正无穷**，不分左右 |
| 数列收敛 / 发散 | 取决于极限是否存在；不存在的两种情况：结果为 $\infty$、在范围内**震荡** |
| 无穷小与无穷大 | **必须带趋向**；$0$ 是唯一的常数无穷小 |
| 无穷小的性质 | **有限个**的和差积仍是无穷小（商不一定）；★★ **零乘有界等于零** |
| 抓大头（扩充） | 只能用于 $\frac\infty\infty$；口诀上大无穷 / 下大零 / 相同则系数比；大题须**同除共有最高次方**；指数型抓**最大底数**（先统一指数） |
