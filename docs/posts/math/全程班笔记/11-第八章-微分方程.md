## 一、大白话讲解

### 1. 从「方程的解是数」到「方程的解是函数」

小学、中学学的方程，解出来都是一个**常数**：

$$x^2+2x=0 \Longrightarrow x=0 \text{ 或 } x=2$$

但有一种方程，它的解**不是一个常数，而是一个函数**：

$$y'-e^x=0$$

把 $y=e^x+C$ 代进去：$y'=e^x$，于是 $e^x-e^x=0$，恒成立。所以 $y=e^x+C$ 就是这个方程的解。

**这种「解是函数」的方程，就叫微分方程。**

### 2. 一句话抓住定义

> **含有未知函数及其导数的方程，称为微分方程。**

最容易记错的一点是：方程里**不一定**要有 $y$、**不一定**要有自变量 $x$，但**必须出现 $y$ 的导数**（不管一阶、二阶、三阶）。没有导数，就不是微分方程。

### 3. 阶数：只认「最高阶导数」

$$\text{方程的阶数} = \text{方程中未知函数导数的最高阶数}$$

这里的坑在**记号**上：

| 记号 | 含义 |
|:---|:---|
| $y^{10}$ | $y$ 的**十次幂**（10 个 $y$ 相乘） |
| $y^{(10)}$ | $y$ 的**十阶导数**（求了 10 次导） |

括号里那个数字才代表「求了几次导」。阶数只看最高阶导数，**跟几次幂一点关系都没有**。

### 4. 解、通解、特解、初始条件

| 概念 | 大白话 |
|:---|:---|
| **解** | 把函数代进方程，方程变成恒等式，这个函数就叫解 |
| **通解** | 解中**独立常数**的个数 **等于** 方程的阶数 |
| **初始条件** | 确定独立常数的条件，比如 $y\vert_{x=0}=1$、$y'\vert_{x=0}=0$ |
| **特解** | 用初始条件把通解中的独立常数确定下来之后的解（**不含 $C$**） |

**「独立常数」** 是关键：它们之间**不能通过加减乘除合并**。比如 $y=x^2+C_1x+C_2$ 里的 $C_1,C_2$ 独立；而 $y=x^2+C_1+C_2$ 里两个常数能加成一个，就不独立，只能算**一个**独立常数。

> 口诀：**有几个 $C$，就需要几个初始条件**；三阶方程却只求出两个独立常数，那一定算错了。

### 5. 本章地图

**一阶微分方程（三种类型，前两种高频）**

| 类型 | 标准形式 | 打法 |
|:---|:---|:---|
| 可分离变量型 | $\dfrac{dy}{dx}=f(x)g(y)$ | 分离变量 → 两边积分 |
| 齐次型 | $\dfrac{dy}{dx}=f\!\left(\dfrac{y}{x}\right)$ | 令 $u=\dfrac{y}{x}$，化成可分离 |
| 一阶线性 | $y'+P(x)y=Q(x)$ | 直接套通解公式 |

**二阶微分方程**

| 类型 | 打法 |
|:---|:---|
| 可降阶（含 $x,y',y''$） | 令 $y'=p$，$y''=p'$ |
| 可降阶（含 $y,y',y''$） | 令 $y'=p$，$y''=p\dfrac{dp}{dy}$ |
| 常系数齐次线性 | 特征方程 → 三种根 → 三种通解 |
| 常系数非齐次线性 | $y=Y_{\text{齐通}}+y^*$，重点在设 $y^*$ |

## 二、考点全爆破

### 1. 微分方程的基本概念（P108）

**定义**：含有未知函数及其导数的方程。

一般形式可写成含 $x,\ y,\ y',\ \cdots,\ y^{(n)}$ 的表达式等于零。常见写法：

$$y''+y'-e^x=0,\qquad y'+y\sin x=e^x,\qquad y'+y=0,\qquad y^{(100)}-2x+2=0$$

也可以写成微分形式，例如

$$\frac{dy}{dx}=\frac{1}{1+x^2}\iff (1+x^2)\,dy=dx,\qquad dy=e^x\,dx$$

**必背结论**：方程中**不一定要出现** $y$ 和自变量 $x$，但**一定要出现 $y$ 的导数**。

**阶数**：方程中未知函数导数的最高阶数。

### 2. 通解的判定（两条，缺一不可）

判断一个函数是否为微分方程的**通解**：

1. 将函数代入微分方程，使方程成为**恒等式**；
2. 解中**独立常数的个数等于微分方程的阶数**。

只满足第 1 条 → 只是「解」，不是通解。
含 $C$ → 一定不是特解（特解里不能有 $C$）。

### 3. 可直接积分型（P108）

**形式**：等号左边是 $y$ 的导数（一阶导、二阶导都行），等号右边只含 $x$。

**方法**：两边直接积分。求二阶导就积两次，积一次降一阶。

$$y'=f(x)\Longrightarrow y=\int f(x)\,dx+C$$

$$y''=f(x)\Longrightarrow y'=\int f(x)\,dx+C_1\Longrightarrow y=\int\!\left(\int f(x)dx+C_1\right)dx+C_2$$

**书写规范**（大题按这个格式给分）：

- 左边积分**不用**再写 $C$，只在右边写一个 $C$；
- 因为左边积出 $C_1$、右边积出 $C_2$，移项合并后 $C_2-C_1$ 仍是一个常数，用一个 $C$ 代替即可；
- 最后补一句「**$C$ 为任意常数**」。

### 4. 一阶可分离变量型微分方程（P109，高频）

**标准形式**

$$\frac{dy}{dx}=f(x)\,g(y)$$

即右边能拆成「一个只含 $x$ 的函数」乘以「一个只含 $y$ 的函数」。

**解题四步**

1. **化简成标准形式**：题干往往不给标准形式，要用配凑、移项、变形（包括交叉相乘）把 $y'$ 单独放到等号左边，右边凑成 $f(x)g(y)$。
2. **分离变量**：把 $g(y)$ 除到左边、$dx$ 乘到右边

$$\frac{1}{g(y)}\,dy=f(x)\,dx$$

3. **两边积分**

$$\int\frac{1}{g(y)}\,dy=\int f(x)\,dx$$

4. **化简**：结果可能是**隐式通解**，能显化就显化成 $y=\cdots$ 的最简形式；不能显化的（如 $\ln|y|+\frac{y^2}{2}=\frac12\ln^2x+C$）就保留隐式。

> 老师说：隐式通解原则上不扣分，但各地阅卷标准不同，**能显化的都建议显化**；八分的大题只写到隐式可能只给七分。

### 5. 一阶齐次微分方程（P110，低频）

**标准形式**

$$\frac{dy}{dx}=f\!\left(\frac{y}{x}\right)$$

等号右边**只含 $\dfrac{y}{x}$ 这个整体**（不管里面怎么变换：$\left(\frac yx\right)^2-\frac yx+1$、$\frac{y}{x}\ln\frac yx$、$\ln\frac yx -1$ 之类都算）。

**解题步骤**

1. 化简成标准形式（仍先把 $y'$ 放在等号左边）；
2. **令 $u=\dfrac{y}{x}$**，即 $y=ux$（注意 $y$、$u$ 都是 $x$ 的函数）；
3. 两边求导（前导后不导 + 后导前不导）：

$$\frac{dy}{dx}=x\frac{du}{dx}+u$$

4. 代入原式，与 $f\!\left(\frac yx\right)=f(u)$ 联立：

$$x\frac{du}{dx}+u=f(u)$$

5. 分离变量

$$\frac{du}{f(u)-u}=\frac{dx}{x}$$

6. 两边积分，**最后一定要把 $u$ 回代成 $\dfrac{y}{x}$**。

**识别技巧**：遇到分子分母同时出现 $y^2$、$xy$、$x^2$ 的式子，**分子分母同除以 $x^2$**，最容易化成 $\frac yx$ 的函数。

**关于常数 $C$ 的写法**：为了让常数取遍全体实数，可以把 $C$ 写成 $\ln|C|$（因为 $\ln$ 函数值域是 $\mathbb{R}$），但**不能写成 $e^C$**——$e^C$ 只能取正值。

### 6. 一阶线性微分方程（P111，高频，本章最重）

**标准形式**

$$y'+P(x)y=Q(x)$$

其中 $P(x)$、$Q(x)$ 都是关于 $x$ 的函数（也可以是常数，常数是特殊的常数函数）。**$y'$ 前面的系数必须化成 1**。

**通解公式（必须背到滚瓜烂熟）**

$$y=e^{-\int P(x)\,dx}\left[\int Q(x)\,e^{\int P(x)\,dx}\,dx+C\right]$$

**公式推导**（老师说「知其然还要知其所以然」）：

1. 两边同乘 $e^{\int P(x)dx}$：

$$e^{\int P dx}y'+e^{\int P dx}P(x)y=e^{\int P dx}Q(x)$$

2. 左边恰好是乘积的导数（前导后不导 + 前不导后导；注意先积分后求导等于被积函数）：

$$\frac{d}{dx}\left[e^{\int P dx}\,y\right]=e^{\int P dx}Q(x)$$

3. 两边积分：

$$e^{\int P dx}\,y=\int Q(x)e^{\int P dx}\,dx+C$$

4. 两边同乘 $e^{-\int P dx}$，即得通解公式。

**关于绝对值的实用结论**：在套公式过程中，若 $e$ 的指数上出现 $\ln|\varphi(x)|$，**可以直接把绝对值里的 $\varphi(x)$ 拿出来，不必再加绝对值**。原因是拿出来时产生的两个正负号是「同号相乘」（正×正、负×负），结果恒为正，而余下的正负号又可以被任意常数 $C$ 吸收。
### 7. 一阶线性微分方程（$x$ 与 $y$ 互换型）（P113）

**什么时候用**：把方程整理成 $\dfrac{\mathrm{d}y}{\mathrm{d}x}$ 后，**分子是一个因子、分母是两个因子相加/相减**，且**化不成**前面三种形式（可分离 / 齐次 / 标准一阶线性）时。

**做法：把 $\mathrm{d}y$ 与 $\mathrm{d}x$ 颠倒，同时把 $x$ 与 $y$ 的角色互换**

| | 标准型（P111） | 互换型（P113） |
|:---|:---|:---|
| 方程 | $y'+P(x)y=Q(x)$ | $x'+P(y)x=Q(y)$ |
| 自变量 | $x$ | $y$ |
| 因变量 | $y$ | $x$ |
| 通解 | $\displaystyle y=e^{-\int P(x)\mathrm{d}x}\left[\int Q(x)e^{\int P(x)\mathrm{d}x}\mathrm{d}x+C\right]$ | $\displaystyle x=e^{-\int P(y)\mathrm{d}y}\left[\int Q(y)e^{\int P(y)\mathrm{d}y}\mathrm{d}y+C\right]$ |

**解题四步**

| 步骤 | 做什么 |
|:---|:---|
| ① | 把方程整理成 $\dfrac{\mathrm{d}y}{\mathrm{d}x}=$ 某个分式 |
| ② | **颠倒**（分子分母互换）得 $\dfrac{\mathrm{d}x}{\mathrm{d}y}$，再把右边**拆成两项** |
| ③ | 整理成 $x'+P(y)x=Q(y)$，读出 $P(y)$、$Q(y)$ |
| ④ | 套互换型通解公式 |

> ★ 老师的比喻（P113）：化成 $\dfrac{\mathrm{d}y}{\mathrm{d}x}$ 后右边是**"正三角"**（分子一个因子、分母多个因子相加减）⇒ **稳定、拆不开**；**颠倒过来变成"倒三角"** ⇒ 就能拆成两个式子，从而套公式。
>
> **考察频率**（老师原话）："这种题型其实考察的频率也不算太高" —— 但它是**区分度**题型：见过就会，没见过就失分。

### 8. 二阶可降阶微分方程（P114，部分省份考）

先看考纲：**里面有没有「可降阶」三个字**，没有就不用学。

#### 类型一：方程中只含 $x,\ y',\ y''$（**没有 $y$**）

$$\text{形如 } y''=f(x,y')$$

**做法**：令 $y'=p$，则 $y''=p'=\dfrac{dp}{dx}$，方程降为一阶（通常是可分离变量型），解出 $p$ 后再由 $y'=p$ 积分一次得 $y$。

#### 类型二：方程中只含 $y,\ y',\ y''$（**没有 $x$**）

$$\text{形如 } y''=f(y,y')$$

**关键差别**：原式里没有 $x$，所以 $dx$ 不能作为积分变量，必须引入中间变量，把 $p$ 看成 $y$ 的函数：

$$y'=p,\qquad y''=\frac{dp}{dx}=\frac{dp}{dy}\cdot\frac{dy}{dx}=p\,\frac{dp}{dy}$$

（这是链式法则：$p$ 对 $x$ 求导 = $p$ 对 $y$ 求导 × $y$ 对 $x$ 求导。）

降阶后再分离变量、积分，**两次可分离变量**得到通解，独立常数个数为 2，与二阶对应。

### 9. 二阶常系数齐次线性微分方程（P115，重点）

**形式**

$$y''+py'+qy=0\qquad (p,q \text{ 为常数})$$

- **常系数**：$y''$、$y'$、$y$ 前面的系数都是常数；
- **齐次**：等号右边 $f(x)\equiv 0$（右边不为零就是非齐次）。

**特征方程**：求几次导就写成 $r$ 的几次方。

$$y''\to r^2,\qquad y'\to r,\qquad y\to r^0=1$$

即

$$r^2+pr+q=0$$

**特征根三种情形 → 三种通解（必须背熟）**

| 情形 | 特征根 | 通解 |
|:---|:---|:---|
| $\Delta>0$ | 两个不相等实根 $r_1\neq r_2$ | $y=C_1e^{r_1x}+C_2e^{r_2x}$ |
| $\Delta=0$ | 二重根 $r_1=r_2=r$ | $y=(C_1+C_2x)e^{rx}$ |
| $\Delta<0$ | 一对共轭复根 $r_{1,2}=\alpha\pm\beta i$ | $y=e^{\alpha x}\left(C_1\cos\beta x+C_2\sin\beta x\right)$ |

**复数速记（专升本高数唯一用到复数的地方）**

- 复数 $z=\alpha+\beta i$，$\alpha$ 叫**实部**，$\beta$ 叫**虚部**，$i$ 叫**虚数单位**；
- $i^2=-1$（所以 $-1$ 可以用 $i^2$ 替换，用来给负数开方）；
- **共轭复数**：实部相同、虚部互为相反数，如 $1+2i$ 与 $1-2i$。

例如解 $x^2+2x+2=0$：

$$\Delta=2^2-4\times1\times2=-4<0$$

$$x=\frac{-2\pm\sqrt{-4}}{2}=\frac{-2\pm\sqrt{i^2\cdot4}}{2}=\frac{-2\pm 2i}{2}=-1\pm i$$

即一对共轭复根 $-1\pm i$，其中 $\alpha=-1$，$\beta=1$。

**已知通解反求方程**：从通解中读出特征根，再写出特征方程，最后还原成微分方程。例如通解 $y=C_1e^{2x}+C_2e^{-x}$ → 特征根 $2$ 与 $-1$ → $(r-2)(r+1)=0$ → $r^2-r-2=0$ → $y''-y'-2y=0$。

### 10. 二阶常系数非齐次线性微分方程（P116–P117）

**形式**

$$y''+py'+qy=f(x)\qquad (f(x)\not\equiv 0)$$

**通解结构（核心）**

$$y=Y_{\text{齐通}}+y^*$$

- $Y_{\text{齐通}}$：把方程看作齐次（令 $f(x)=0$）求出的通解——**上一节的方法**；
- $y^*$：非齐次方程的一个**特解**。

> 注意区分两个「特解」：P108 讲的「特解」是**由初始条件确定通解中常数后**得到的解，随初始条件而变；这里的 $y^*$ 也叫特解，但**形式唯一**，与初始条件无关。

#### 9.1 认识 $f(x)$

通常 $f(x)=P_m(x)\,e^{\lambda x}$，其中

- $P_m(x)$ 为 **$m$ 次多项式**（主要考点）：由常数与 $x$ 的幂经有限次乘、加组合而成，如 $x^2+2x$、$2x-1$、$x^3+x-1$、常数；
- $e^{\lambda x}$ 为指数函数，$\lambda$ 是常数；
- $P_m(x)$ 也可能为**三角函数**——老师说：「除了浙江省之外的其他的所有的省份都是不会考察」这种情形。

**特别注意**：若 $f(x)$ 只给了一个多项式、没有显式的 $e^{\lambda x}$，要理解成 $\lambda=0$（因为 $e^{0\cdot x}=1$）。

#### 9.2 特解的设法（选择填空高频考点）

$$y^*=Q_m(x)\,e^{\lambda x}\,x^k$$

三个部分逐一确定：

**① $Q_m(x)$——由 $P_m(x)$ 的最高次决定**

$Q_m(x)$ 是 $P_m(x)$ 的**一般多项式**：按最高次逐次写全，一项都不能漏。

| $P_m(x)$ | 最高次 | $Q_m(x)$ |
|:---|:---|:---|
| 常数（如 $5$、$1$） | $0$ 次 | $A$ |
| $2x+1$ | $1$ 次 | $ax+b$ |
| $x$ | $1$ 次 | $ax+b$ |
| $x^2$、$x^2+x+1$ | $2$ 次 | $ax^2+bx+c$ |
| $x^3$ | $3$ 次 | $ax^3+bx^2+cx+d$ |

> 坑：$P_m(x)=x^2$ 时，$Q_m(x)$ 是 $ax^2+bx+c$，**不是**只有 $ax^2$。

**② $e^{\lambda x}$——原封不动搬过来**。

**③ $x^k$——由 $\lambda$ 与特征根的关系决定**

先把非齐次方程看作齐次方程，写出特征方程 $r^2+pr+q=0$，解出特征根 $r_1,r_2$：

| $\lambda$ 与特征根的关系 | $k$ |
|:---|:---|
| $\lambda$ 不是特征方程的根 | $k=0$ |
| $\lambda$ 是特征方程的单根（等于 $r_1$ 或 $r_2$ 之一） | $k=1$ |
| $\lambda$ 是特征方程的重根（$r_1=r_2=\lambda$） | $k=2$ |

> $k$ 的确定只需看 $f(x)$ 里那个 $\lambda$，**不要**看别的。

#### 9.3 叠加原理

若 $f(x)=f_1(x)+f_2(x)$，则

$$y^*=y_1^*+y_2^*$$

其中 $y_1^*$、$y_2^*$ 分别是 $f_1(x)$、$f_2(x)$ 单独对应的特解（各自独立地设、独立地定 $Q_m$ 与 $k$）。用老师的话：这是「前面一种的升级版」。

#### 9.4 求 $y^*$ 中的待定系数（P117，大题）

设出 $y^*$ 后，其中的 $a,b,A,B\cdots$ 还是未知的，用**代入法 + 对比系数**定出来：

1. 对 $y^*$ 求一阶导 $y^{*\prime}$、二阶导 $y^{*\prime\prime}$（多用前导后不导）；
2. 把 $y^{*\prime\prime}$、$y^{*\prime}$、$y^*$ 代入 $y''+py'+qy=f(x)$；
3. 等式两边约掉公共的 $e^{\lambda x}$，按 $x$ 的**高次项 → 一次项 → 常数项**逐项整理；
4. **对比系数**列方程，解出 $a,b,\cdots$。

> 老师说这类题「计算上稍微有点麻烦」，但没有很绕的地方；熟练了 10 分钟内可以写完。

## 三、例题精讲

### 例 1 判断阶数（真题，选填）

下列微分方程中阶数最高的是：

- A：只出现一阶导数 → **一阶**
- B：出现 $y''$ 与 $y^4$ → 四次方只是四个 $y$ 相乘，**二阶**
- C：出现 $y^{(3)}$ → **三阶**
- D：出现 $(y'')^5$ → 二阶导的五次幂，仍是**二阶**

**答案：C**。

> 判断只认最高阶导数，不管有几个相乘、几次幂。

### 例 2 判断「解 / 通解 / 特解」（真题）

给出一个二阶微分方程，及一个含**一个**任意常数 $C$ 的函数，问该函数是「解」「通解」还是「特解」。

**思路**：

1. 方程为二阶 → 通解必须含**两个**独立常数；该函数只有**一个** $C$ → **不是通解**；
2. 特解中**不能含 $C$** → 也**不是特解**；
3. 将该函数及其一阶导、二阶导代入方程验算，左右两端恒等 → 它是**解**。

**答案：是方程的解**（对应选项）。

> 一道题同时考了「解」「通解」「特解」三个点，是往年真题。字幕未完整读出方程的具体形式，此处只记方法。

### 例 3 直接积分求通解

求 $y'=3x^2$ 的通解。

**解**：两边积分

$$y=\int 3x^2\,dx=x^3+C\qquad (C \text{ 为任意常数})$$

> 左边积分不用写 $C$；若两边都写，$C_2-C_1$ 仍是一个常数，合并成一个 $C$。

### 例 4 二阶直接积分（真题）

求 $y''=\cos x$ 的通解。

**解**：先积一次，降为一阶：

$$y'=\sin x+C_1$$

再积一次：

$$y=-\cos x+C_1x+C_2\qquad (C_1,C_2 \text{ 为任意常数})$$

> 方程是二阶，所以**先写 $C_1$**，提醒自己最后必须有**两个**独立常数。

### 例 5 二阶直接积分（真题）

求 $y''=\sin x+\cos x+x$ 的通解。

**解**：第一次积分

$$y'=-\cos x+\sin x+\frac{1}{2}x^2+C_1$$

第二次积分

$$y=-\sin x-\cos x+\frac{1}{6}x^3+C_1x+C_2$$

### 例 6 直接积分 + 初始条件求特解（真题）

求 $y'=e^x+\cos x$ 满足 $y(0)=2$ 的特解。

**解**：先求通解

$$y=e^x+\sin x+C$$

代入 $y(0)=2$：

$$e^0+\sin 0+C=2\Longrightarrow 1+C=2\Longrightarrow C=1$$

故特解

$$y=e^x+\sin x+1$$

> 初始条件变了，特解就变：若改为 $y(0)=1$，则 $C=0$，特解为 $y=e^x+\sin x$。

### 例 7 可分离变量型（最基础）

求 $\dfrac{dy}{dx}=2xy$ 的通解。

**解**：已是标准形式，右边 $2x$ 是 $f(x)$、$y$ 是 $g(y)$。分离变量：

$$\frac{1}{y}\,dy=2x\,dx$$

两边积分：

$$\ln|y|=x^2+C_1$$

显化（两边取指数，$|y|=e^{x^2+C_1}=e^{C_1}e^{x^2}$，去绝对值产生的正负号并入常数）：

$$y=Ce^{x^2}\qquad (C \text{ 为任意常数})$$

### 例 8 先化简再分离 + 初始条件

求 $e^y\,y'=x\,e^{2x^2}$ 满足 $y(0)=0$ 的特解。

**解**：两边同除 $e^y$，化为标准形式：

$$\frac{dy}{dx}=x\,e^{2x^2}\cdot\frac{1}{e^y}$$

分离变量：

$$e^y\,dy=x\,e^{2x^2}\,dx$$

两边积分（右边凑微分：$x\,dx=\frac14\,d(2x^2)$）：

$$e^y=\frac{1}{4}e^{2x^2}+C$$

两边取对数显化：

$$y=\ln\!\left(\frac{1}{4}e^{2x^2}+C\right)$$

代入 $y(0)=0$：

$$0=\ln\!\left(\frac14+C\right)\Longrightarrow \frac14+C=1\Longrightarrow C=\frac34$$

故特解

$$y=\ln\!\left(\frac{1}{4}e^{2x^2}+\frac{3}{4}\right)$$

### 例 9 交叉相乘后分离

求 $y\sin\dfrac{x}{2}\,dx-\cos\dfrac{x}{2}\,dy=0$ 的通解。

**解**：移项、交叉相乘，凑出 $\dfrac{dy}{dx}$：

$$y\sin\frac{x}{2}\,dx=\cos\frac{x}{2}\,dy\Longrightarrow \frac{dy}{dx}=\frac{\sin(x/2)}{\cos(x/2)}\cdot y=y\tan\frac{x}{2}$$

分离变量、两边积分：

$$\frac{1}{y}\,dy=\tan\frac{x}{2}\,dx$$

$$\ln|y|=-2\ln\left|\cos\frac{x}{2}\right|+C_1$$

即

$$y=\frac{C}{\cos^2\dfrac{x}{2}}=C\sec^2\frac{x}{2}\qquad (C \text{ 为任意常数})$$

> 凑微分要点：$\int\tan\frac x2\,dx=2\int\tan\frac x2\,d\!\left(\frac x2\right)=-2\ln\left|\cos\frac x2\right|+C$。

### 例 10 分离后无法显化（保留隐式通解）

求 $\dfrac{dy}{dx}=\dfrac{\ln x}{x}\cdot\dfrac{y}{1+y^2}$ 的通解。

**解**：已接近标准形式，分离变量：

$$\frac{1+y^2}{y}\,dy=\frac{\ln x}{x}\,dx$$

即

$$\left(\frac{1}{y}+y\right)dy=\frac{\ln x}{x}\,dx$$

两边积分（右边凑微分：$\frac{1}{x}dx=d\ln x$）：

$$\ln|y|+\frac{1}{2}y^2=\frac{1}{2}\ln^2 x+C\qquad (C \text{ 为任意常数})$$

> 这里 $y$ 与 $\ln x$ 混在一起，**无法显化**，隐式通解就是最终答案。

### 例 11 综合题（化简 → 分离 → 积分 → 显化）

求 $3e^x\tan y\,dx+(1-e^x)\sec^2y\,dy=0$ 的通解。

**解**：移项并把负号并进去：

$$3e^x\tan y\,dx=(e^x-1)\sec^2y\,dy$$

化为标准形式：

$$\frac{dy}{dx}=\frac{(e^x-1)\sec^2y}{3e^x\tan y}$$

分离变量：

$$\frac{\sec^2y}{\tan y}\,dy=\frac{3e^x}{e^x-1}\,dx$$

两边积分（左边凑微分：$\frac{\sec^2y}{\tan y}dy=\frac{d\tan y}{\tan y}$；右边凑微分：$\frac{e^x}{e^x-1}dx=\frac{d(e^x-1)}{e^x-1}$）：

$$\ln|\tan y|=3\ln|e^x-1|+C_1$$

把 $C_1$ 写成 $\ln e^{C_1}$ 并与对数合并：

$$\ln|\tan y|=\ln\left|e^{C_1}(e^x-1)^3\right|$$

去绝对值（正负号并入常数 $C$）：

$$\tan y=C(e^x-1)^3\qquad (C \text{ 为任意常数})$$

若再显化：

$$y=\arctan\!\left[C(e^x-1)^3\right]$$

> 老师提醒：分式运算可以偷懒——一个数除以一个分数，就把分母乘到分子上去。

### 例 12 一阶齐次型（对数化成 $y/x$）

求 $\dfrac{dy}{dx}=\dfrac{y}{x}(\ln y-\ln x)$ 的通解。

**解**：先判断能不能分离变量——不能。但

$$\ln y-\ln x=\ln\frac{y}{x}$$

所以右边是 $\dfrac{y}{x}\ln\dfrac{y}{x}$，是 $\dfrac{y}{x}$ 的函数，属于齐次型。

令 $u=\dfrac{y}{x}$，即 $y=ux$，两边求导：

$$\frac{dy}{dx}=x\frac{du}{dx}+u$$

代入原式：

$$x\frac{du}{dx}+u=u\ln u\Longrightarrow x\frac{du}{dx}=u(\ln u-1)$$

分离变量：

$$\frac{du}{u(\ln u-1)}=\frac{dx}{x}$$

两边积分（左边凑微分：$\frac{du}{u}=d\ln u$）：

$$\ln|\ln u-1|=\ln|x|+C$$

把 $C$ 写成 $\ln C$ 并合并对数：

$$\ln u-1=Cx$$

回代 $u=\dfrac{y}{x}$：

$$\ln\frac{y}{x}=Cx+1$$

显化：

$$y=xe^{Cx+1}\qquad (C \text{ 为任意常数})$$

### 例 13 分子分母同除 $x^2$ 化齐次

求 $xy\,y'-x^2y'=y^2$ 的通解。

**解**：把 $y'$ 提出来：

$$y'(xy-x^2)=y^2\Longrightarrow \frac{dy}{dx}=\frac{y^2}{xy-x^2}$$

分子分母同时除以 $x^2$：

$$\frac{dy}{dx}=\frac{\left(\dfrac{y}{x}\right)^2}{\dfrac{y}{x}-1}$$

令 $u=\dfrac{y}{x}$，$y=ux$，则 $\dfrac{dy}{dx}=x\dfrac{du}{dx}+u$，代入：

$$x\frac{du}{dx}+u=\frac{u^2}{u-1}\Longrightarrow x\frac{du}{dx}=\frac{u}{u-1}$$

分离变量：

$$\frac{u-1}{u}\,du=\frac{dx}{x}\Longrightarrow \left(1-\frac{1}{u}\right)du=\frac{dx}{x}$$

两边积分：

$$u-\ln|u|=\ln|x|+C$$

回代并整理（把 $u=\frac yx$ 代回，两边取指数）：

$$\frac{y}{x}=\ln|Cy|\Longrightarrow e^{y/x}=Cy$$

显化：

$$y=Ce^{y/x}\qquad (C \text{ 为任意常数})$$

> 本例的通解本身是显式与隐式的混合形式，属于正常结果。

### 例 15 一阶线性（直接用公式）

求 $y'+y=e^{-x}$ 的通解。

**解**：已是一阶线性标准形式，$P(x)=1$，$Q(x)=e^{-x}$。套通解公式：

$$y=e^{-\int 1\,dx}\left[\int e^{-x}e^{\int 1\,dx}dx+C\right]=e^{-x}\left[\int e^{-x}e^{x}\,dx+C\right]$$

$$=e^{-x}\left[\int 1\,dx+C\right]=e^{-x}(x+C)\qquad (C \text{ 为任意常数})$$

### 例 16 先化标准形式再套公式

求 $xy'+y=\sin x$ 的通解。

**解**：两边同除 $x$（把 $y'$ 的系数化为 1）：

$$y'+\frac{1}{x}y=\frac{\sin x}{x}$$

故 $P(x)=\dfrac{1}{x}$，$Q(x)=\dfrac{\sin x}{x}$。

$$\int P\,dx=\ln|x|,\qquad e^{\int P dx}=x,\qquad e^{-\int P\,dx}=\frac{1}{x}$$

$$y=\frac{1}{x}\left[\int \frac{\sin x}{x}\cdot x\,dx+C\right]=\frac{1}{x}\left[\int \sin x\,dx+C\right]$$

$$y=\frac{1}{x}\left(-\cos x+C\right)\qquad (C \text{ 为任意常数})$$

> 套公式时 $e$ 的指数上出现 $\ln|x|$，可以直接把绝对值里的 $x$ 拿出来，不加绝对值。

### 例 17 一阶线性 + 初始条件（四川真题）

求 $(x+1)y'-2y=(x+1)^4$ 满足 $y(0)=\dfrac12$ 的特解。

**解**：两边同除 $x+1$：

$$y'-\frac{2}{x+1}y=(x+1)^3$$

$P(x)=-\dfrac{2}{x+1}$，$Q(x)=(x+1)^3$。

$$\int P\,dx=-2\ln|x+1|,\qquad e^{\int P dx}=(x+1)^{-2},\qquad e^{-\int P\,dx}=(x+1)^2$$

$$y=(x+1)^2\left[\int (x+1)^3\cdot(x+1)^{-2}dx+C\right]=(x+1)^2\left[\int(x+1)dx+C\right]$$

$$y=(x+1)^2\left(\frac{x^2}{2}+x+C\right)$$

代入 $y(0)=\dfrac12$：

$$\frac12=(0+1)^2\left(0+0+C\right)=C\Longrightarrow C=\frac12$$

故特解

$$y=(x+1)^2\left(\frac{x^2}{2}+x+\frac{1}{2}\right)$$

> 老师说这道题很多同学都做对了，「只要知道这个通解公式，剩下的就是一些计算问题」。

### 例 18 变限积分 → 一阶线性（习题课）

已知 $f(x)$ 满足

$$f(x)=\frac{1}{2}x^2+\int_0^x t f(t)\,dt$$

求 $f(x)$。

**解**：见到变限积分就求导。两边对 $x$ 求导（用变限积分求导法则：上限代入被积函数再乘上限的导数）：

$$f'(x)=x+xf(x)$$

整理成一阶线性标准形式：

$$f'(x)-xf(x)=x$$

$P(x)=-x$，$Q(x)=x$：

$$f(x)=e^{\int x\,dx}\left[\int x\,e^{-\int x\,dx}dx+C\right]=e^{x^2/2}\left[\int x\,e^{-x^2/2}dx+C\right]$$

右边凑微分（$x\,dx=-d\!\left(-\frac{x^2}{2}\right)$）：

$$f(x)=e^{x^2/2}\left[-e^{-x^2/2}+C\right]=Ce^{x^2/2}-1$$

**找隐含的初始条件**：令 $x=0$，原式中的变限积分上下限相同，积分值为 0，右边只剩下 $\frac12x^2=0$，故

$$f(0)=0$$

代入通解：$C-1=0\Longrightarrow C=1$。故

$$f(x)=e^{x^2/2}-1$$

> 这类题「题目中隐含了一个初始条件」，不自己找出来就写不完整。

### 例 19 变限积分换元 → 一阶线性（习题课）

已知 $f(x)$ 满足

$$f(x)=3\int_0^x f(x-t)\,dt+2$$

求 $f(x)$。

**解**：被积函数里含 $x$，**不能直接求导**，先换元。令 $u=x-t$，则 $t=x-u$，$dt=-du$；$t=0$ 时 $u=x$，$t=x$ 时 $u=0$。于是

$$\int_0^x f(x-t)\,dt=\int_x^0 f(u)(-du)=\int_0^x f(u)\,du$$

所以原式化为

$$f(x)=3\int_0^x f(u)\,du+2$$

令 $x=0$ 得隐含初始条件 $f(0)=2$。两边求导：

$$f'(x)=3f(x)\Longrightarrow f'(x)-3f(x)=0$$

$P(x)=-3$，$Q(x)=0$：

$$f(x)=e^{3x}\left[\int 0\,dx+C\right]=Ce^{3x}$$

代入 $f(0)=2$：$C=2$。故

$$f(x)=2e^{3x}$$

> 换元时注意：对积分变量 $t$ 而言，$x$ 是常数，$du=-dt$；积分上下限交换要加负号，正好与 $dt=-du$ 的负号抵消。

### 例 20 变限积分 → 一阶线性（习题课）

题设给出一个含变限积分与 $(x-1)f(x)$ 项的恒等式，求 $f(x)$。

**解**：两边求导（变限积分部分按求导法则、$(x-1)f(x)$ 部分用前导后不导），整理成一阶线性标准形式：

$$f'(x)-\frac{1}{x-1}f(x)=-3(x-1)$$

即 $P(x)=-\dfrac{1}{x-1}$，$Q(x)=-3(x-1)$。

$$e^{\int P dx}=\frac{1}{x-1},\qquad e^{-\int P\,dx}=x-1$$

$$f(x)=(x-1)\left[\int -3(x-1)\cdot\frac{1}{x-1}\,dx+C\right]=(x-1)\left[\int -3\,dx+C\right]$$

$$f(x)=(x-1)(C-3x)$$

由原式令 $x=0$ 得隐含初始条件 $f(0)=-1$，代入：

$$(0-1)\cdot C=-1\Longrightarrow C=1$$

故

$$f(x)=(x-1)(1-3x)=-3x^2+4x-1$$

> 题设原式的具体形式字幕未完整读出，此处只记方法：**求导 → 化标准形式 → 套公式 → 用隐含初始条件定 $C$**。

### 例 21 应用题：切线斜率（习题课，新题型）

设曲线在任意点处的切线斜率为 $\dfrac{y}{x}+x^2$，且曲线经过点 $(1,2)$，求该曲线方程。

**解**：切线斜率就是导数，于是得到隐藏的微分方程：

$$y'=\frac{y}{x}+x^2\Longrightarrow y'-\frac{1}{x}y=x^2$$

$P(x)=-\dfrac{1}{x}$，$Q(x)=x^2$：

$$y=e^{\int \frac1x dx}\left[\int x^2e^{-\int\frac1x dx}dx+C\right]=x\left[\int x^2\cdot\frac{1}{x}dx+C\right]$$

$$y=x\left[\frac{x^2}{2}+C\right]=\frac{x^3}{2}+Cx$$

代入点 $(1,2)$ 确定 $C$，得特解（字幕此处数值前后不一致，只记方法：**由切线斜率写方程 → 套通解公式 → 代入已知点定 $C$**）。

> 这种「曲线在任意点处切线的斜率/截距」是新考法，老师说「肯定会难倒很大一部分同学」，但本质就是：**几何条件 → 微分方程 → 初始条件**。

### 例 23 一阶线性（$x$ 与 $y$ 互换型）
（P113 第 1 题）

**题**：求 $\dfrac{\mathrm{d}y}{\mathrm{d}x}=\dfrac{y}{x+y^2}$ 的通解。

> ⚠️ 老师口述时把方程读成了"$y$ 比 $x$ 再加上 $y$ 的平方"，但**从后续推导反推，原方程应为 $\dfrac{\mathrm{d}y}{\mathrm{d}x}=\dfrac{y}{x+y^2}$**（否则颠倒后得不到 $x'-\frac1y x=y$）。此处按推导结果记录。

**解**

- ① 右边是分式 ⇒ **颠倒**：

$$\frac{\mathrm{d}x}{\mathrm{d}y}=\frac{x+y^2}{y}=\frac{x}{y}+y$$

- ② 整理成互换型标准形式：

$$\frac{\mathrm{d}x}{\mathrm{d}y}-\frac1y x=y\quad\Longrightarrow\quad P(y)=-\frac1y,\quad Q(y)=y$$

- ③ 套互换型通解公式（$\int\left(-\frac1y\right)\mathrm{d}y=-\ln|y|$）：

$$x=e^{-\int\left(-\frac1y\right)\mathrm{d}y}\left[\int y\,e^{\int\left(-\frac1y\right)\mathrm{d}y}\mathrm{d}y+C\right]
=e^{\ln|y|}\left[\int y\cdot\frac1y\,\mathrm{d}y+C\right]
=y\left[\int 1\,\mathrm{d}y+C\right]$$

- ④ 所以

$$x=y^2+Cy\qquad(C\ \text{为任意常数})$$

> **复核**：$x=y^2+Cy$ ⇒ $x'=2y+C$ ⇒ $x'-\dfrac{x}{y}=2y+C-\dfrac{y^2+Cy}{y}=2y+C-y-C=y$ ✅

### 例 24 一阶线性（$x$ 与 $y$ 互换型 + 凑微分）
（P113 第 2 题）

**题**：求 $\dfrac{\mathrm{d}y}{\mathrm{d}x}=\dfrac{y\ln y}{\ln y-x}$ 的通解。

**解**

- ① **颠倒**：

$$\frac{\mathrm{d}x}{\mathrm{d}y}=\frac{\ln y-x}{y\ln y}=\frac{1}{y}-\frac{x}{y\ln y}$$

- ② 整理：

$$\frac{\mathrm{d}x}{\mathrm{d}y}+\frac{1}{y\ln y}x=\frac1y\quad\Longrightarrow\quad P(y)=\frac{1}{y\ln y},\quad Q(y)=\frac1y$$

- ③ 先算 $\displaystyle\int P(y)\,\mathrm{d}y=\int\frac{\mathrm{d}y}{y\ln y}=\ln|\ln y|$，代入公式：

$$x=e^{-\ln|\ln y|}\left[\int\frac1y\cdot e^{\ln|\ln y|}\mathrm{d}y+C\right]=\frac{1}{\ln y}\left[\int\frac{\ln y}{y}\,\mathrm{d}y+C\right]$$

- ④ **凑微分**：$\dfrac{\ln y}{y}\mathrm{d}y=\ln y\,\mathrm{d}(\ln y)$，故

$$\int\frac{\ln y}{y}\,\mathrm{d}y=\frac12\ln^2y$$

- ⑤ 所以

$$x=\frac{1}{\ln y}\left(\frac12\ln^2y+C\right)\qquad(C\ \text{为任意常数})$$

> **两题共性**（老师原话）："化成 $\frac{\mathrm{d}y}{\mathrm{d}x}$ 之后，分子只有一个式子，分母是多个式子相加或相减" ⇒ 一定先**颠倒**，再**拆成两个式子**。

### 例 25 二阶可降阶（类型一：含 $x,y',y''$）

求 $(1+x)y''=y'$ 的通解。

**解**：方程里**没有 $y$**，属于类型一。令

$$y'=p,\qquad y''=p'=\frac{dp}{dx}$$

代入：

$$(1+x)\frac{dp}{dx}=p$$

分离变量、积分：

$$\frac{1}{p}\,dp=\frac{1}{1+x}\,dx$$

$$\ln|p|=\ln|1+x|+\ln C_1\Longrightarrow p=C_1(1+x)$$

即 $y'=C_1(1+x)$，再积分一次：

$$y=C_1\left(x+\frac{x^2}{2}\right)+C_2\qquad (C_1,C_2 \text{ 为任意常数})$$

> 通解中恰好有两个独立常数，与二阶对应。

### 例 26 二阶可降阶（类型二：含 $y,y',y''$）

求 $yy''-(y')^2=0$ 的通解。

**解**：方程里**没有 $x$**，属于类型二。仍令 $y'=p$，但此时

$$y''=\frac{dp}{dx}=\frac{dp}{dy}\cdot\frac{dy}{dx}=p\frac{dp}{dy}$$

代入：

$$y\cdot p\frac{dp}{dy}-p^2=0$$

约去一个 $p$（$p\neq0$ 时）：

$$y\frac{dp}{dy}=p\Longrightarrow \frac{dp}{p}=\frac{dy}{y}$$

积分：

$$\ln|p|=\ln|y|+\ln C_1\Longrightarrow p=C_1y$$

即 $y'=C_1y$，又一次分离变量：

$$\frac{1}{y}\,dy=C_1\,dx\Longrightarrow \ln|y|=C_1x+C_2$$

显化：

$$y=Ce^{C_1x}\qquad (C_1,C \text{ 为任意常数})$$

> 两种可降阶类型**都要用两次可分离变量**；类型二的关键是把 $y''$ 写成 $p\dfrac{dp}{dy}$。

---

### 例 27 二阶常系数齐次（两个不等实根）

求 $y''+2y'-3y=0$ 的通解。

**解**：写特征方程（求几次导就写 $r$ 的几次方）：

$$r^2+2r-3=0\Longrightarrow (r+3)(r-1)=0$$

$$r_1=-3,\qquad r_2=1$$

两个不相等的实根，通解为

$$y=C_1e^{-3x}+C_2e^{x}\qquad (C_1,C_2 \text{ 为任意常数})$$

### 例 28 二阶常系数齐次（二重根）

求 $y''+4y'+4y=0$ 的通解。

**解**：特征方程

$$r^2+4r+4=0\Longrightarrow (r+2)^2=0\Longrightarrow r_1=r_2=-2$$

二重根，通解为

$$y=(C_1+C_2x)e^{-2x}\qquad (C_1,C_2 \text{ 为任意常数})$$

### 例 29 二阶常系数齐次（共轭复根）

求 $y''+2y'+2y=0$ 的通解。

**解**：特征方程

$$r^2+2r+2=0$$

$$\Delta=2^2-4\times1\times2=-4<0$$

用求根公式，把 $-4$ 写成 $i^2\cdot 4$：

$$r=\frac{-2\pm\sqrt{-4}}{2}=\frac{-2\pm 2i}{2}=-1\pm i$$

即 $\alpha=-1$，$\beta=1$。通解为

$$y=e^{-x}\left(C_1\cos x+C_2\sin x\right)\qquad (C_1,C_2 \text{ 为任意常数})$$

> 共轭复根情形：$\alpha$ 放在 $e$ 的指数上，$\beta$ 放进 $\cos$、$\sin$ 的自变量里；虚部只取正的那个数，不用管正负号。

### 例 30 二阶常系数齐次 + 初始条件求特解

求 $y''+4y'+4y=0$ 满足 $y(0)=1$ 的特解。

**解**：由例 26，通解为

$$y=(C_1+C_2x)e^{-2x}$$

代入 $y(0)=1$：

$$C_1=1$$

对通解求导（前导后不导 + 后导前不导）：

$$y'=C_2e^{-2x}-2(C_1+C_2x)e^{-2x}=\left[C_2-2(C_1+C_2x)\right]e^{-2x}$$

再代入 $y'(0)$ 的题设值，解出 $C_2$，即得特解。

> **易错点**：代入 $y'(0)$ 时必须**先把通解求导**，不能把通解直接代进去。字幕中 $y'(0)$ 与 $C_2$ 的取值前后不一致，此处只记方法。

### 例 31 已知通解反求微分方程（选填常考）

已知某二阶常系数齐次线性微分方程的两个特解分别含 $e^{2x}$ 与 $e^{-x}$（即通解为 $y=C_1e^{2x}+C_2e^{-x}$），求该微分方程。

**解**：通解里出现两个不同的指数函数，说明特征根是两个不相等的实根：

$$r_1=2,\qquad r_2=-1$$

反写特征方程：

$$(r-2)(r+1)=0\Longrightarrow r^2-r-2=0$$

还原成微分方程：

$$y''-y'-2y=0$$

> 判断思路：含 $\sin,\cos$ → 共轭复根；只含**两个不同的** $e^{kx}$ → 两个不等实根；含 $xe^{rx}$ → 二重根。

---

### 例 32 设非齐次特解 $y^*$（$k=0$）

设 $y''-4y'-5y=xe^{x}$ 的特解形式 $y^*$。

**解**：

- $f(x)=xe^x$，故 $P_m(x)=x$（一次），$Q_m(x)=ax+b$；
- $\lambda=1$，$e^{\lambda x}=e^x$ 原样搬过来；
- 写齐次方程的特征方程：$r^2-4r-5=0\Longrightarrow(r-5)(r+1)=0$，$r_1=5$，$r_2=-1$。$\lambda=1$ **不是**特征根 → $k=0$。

$$y^*=(ax+b)e^x x^0=(ax+b)e^x$$

### 例 33 设非齐次特解 $y^*$（$k=2$）

设 $y''+2y'+y=e^{-x}$ 的特解形式 $y^*$。

**解**：

- $f(x)=1\cdot e^{-x}$，$P_m(x)=1$（零次），$Q_m(x)=A$；
- $\lambda=-1$；
- 特征方程 $r^2+2r+1=0\Longrightarrow(r+1)^2=0$，$r_1=r_2=-1$，$\lambda=-1$ 是**重根** → $k=2$。

$$y^*=Ax^2e^{-x}$$

### 例 34 设非齐次特解 $y^*$（$k=1$）

设 $y''+3y'=x^2$ 的特解形式 $y^*$。

**解**：

- $f(x)=x^2$，没有显式的 $e^{\lambda x}$，理解成 $\lambda=0$；
- $P_m(x)=x^2$（二次），$Q_m(x)=ax^2+bx+c$；
- 特征方程 $r^2+3r=0\Longrightarrow r(r+3)=0$，$r_1=-3$，$r_2=0$。$\lambda=0$ 是**单根** → $k=1$。

$$y^*=x\left(ax^2+bx+c\right)$$

### 例 35 叠加原理（一）

设 $y''+y'-2y=2x+e^{x}$ 的特解形式 $y^*$。

**解**：特征方程 $r^2+r-2=0\Longrightarrow(r+2)(r-1)=0$，$r_1=-2$，$r_2=1$。

分别处理：

- $f_1(x)=2x$：$P_m(x)=2x$（一次），$Q_m=ax+b$；$\lambda=0$ 不是特征根 → $k=0$，故 $y_1^*=ax+b$；
- $f_2(x)=e^x$：$P_m(x)=1$（零次），$Q_m=A$；$\lambda=1$ 是单根 → $k=1$，故 $y_2^*=Axe^x$。

叠加：

$$y^*=(ax+b)+Axe^x$$

> 两组的待定字母必须**区分开**（比如一组用 $a,b$，另一组用 $A,B$），不能重名。

### 例 36 叠加原理（二）

设 $y''-2y'+y=x+e^{x}$ 的特解形式 $y^*$。

**解**：特征方程 $r^2-2r+1=0\Longrightarrow(r-1)^2=0$，$r_1=r_2=1$。

- $f_1(x)=x$：$Q_m=ax+b$；$\lambda=0$ 不是特征根 → $k=0$，$y_1^*=ax+b$；
- $f_2(x)=e^x$：$Q_m=A$；$\lambda=1$ 是**重根** → $k=2$，$y_2^*=Ax^2e^x$。

$$y^*=(ax+b)+Ax^2e^{x}$$

### 例 37 非齐次通解全流程（P117，大题）

求 $y''-5y'+6y=2xe^{3x}$ 的通解。

**解**：

**第一步：求齐次通解 $Y_{\text{齐通}}$。** 特征方程

$$r^2-5r+6=0\Longrightarrow(r-2)(r-3)=0\Longrightarrow r_1=2,\ r_2=3$$

两个不等实根：

$$Y_{\text{齐通}}=C_1e^{2x}+C_2e^{3x}$$

**第二步：设特解 $y^*$。**

- $P_m(x)=2x$（一次）→ $Q_m(x)=ax+b$；
- $\lambda=3$；
- $\lambda=3$ 是特征方程的**单根**（等于 $r_2$）→ $k=1$。

$$y^*=x(ax+b)e^{3x}=(ax^2+bx)e^{3x}$$

**第三步：求导并代入。** 记 $y^*=(ax^2+bx)e^{3x}$，

$$y^{*\prime}=\left[3ax^2+(2a+3b)x+b\right]e^{3x}$$

$$y^{*\prime\prime}=\left[9ax^2+(12a+9b)x+(2a+6b)\right]e^{3x}$$

代入 $y''-5y'+6y=2xe^{3x}$，两边约去 $e^{3x}$，逐项整理：

- $x^2$ 项系数：$9a-15a+6a=0$（自动消掉）；
- $x$ 项系数：$(12a+9b)-(10a+15b)+6b=2a$；
- 常数项：$(2a+6b)-5b=2a+b$。

得

$$2ax+(2a+b)=2x$$

**第四步：对比系数。**

$$2a=2\Longrightarrow a=1;\qquad 2a+b=0\Longrightarrow b=-2$$

故

$$y^*=(x^2-2x)e^{3x}$$

**第五步：写出通解。**

$$y=C_1e^{2x}+C_2e^{3x}+(x^2-2x)e^{3x}$$

其中 $C_1,C_2$ 为任意常数。

> 老师点评：「这种题呢就算是难题了」，但「也没有很绕的地方，就是计算上稍微有点麻烦」。

### 例 38 非齐次通解练习（第 4 题）

老师留的练习：齐次通解为 $(C_1+C_2x)e^{3x}$（特征根是二重根 $r=3$），设

$$y^*=x^2(Ax+B)e^{3x}=\left(Ax^3+Bx^2\right)e^{3x}$$

代入后求得 $A=\dfrac16$，$B=\dfrac12$，故通解为

$$y=(C_1+C_2x)e^{3x}+\left(\frac{1}{6}x^3+\frac{1}{2}x^2\right)e^{3x}$$

> 老师提到还有更简便的「微分算子法」，本节未展开。

### 例 39 变限积分 → 二阶非齐次（P117）

已知 $f(x)$ 二阶可导，且满足一个含变限积分 $\displaystyle\int_0^x(x-t)f(t)\,dt$ 的恒等式，求 $f(x)$。

**解**：

**第一步：两边求导，找出微分方程。** 注意

$$\int_0^x(x-t)f(t)\,dt=x\int_0^xf(t)\,dt-\int_0^xtf(t)\,dt$$

求导时前者的 $x f(x)$ 与后者的 $xf(x)$ 相消，得

$$f'(x)=3x^2-\int_0^xf(t)\,dt$$

**第二步：再求一次导。**

$$f''(x)=6x-f(x)\Longrightarrow f''(x)+f(x)=6x$$

这是一个二阶常系数非齐次线性微分方程。

**第三步：求齐次通解。** 特征方程

$$r^2+1=0\Longrightarrow r=\pm i$$

即 $\alpha=0$，$\beta=1$，故

$$Y_{\text{齐通}}=C_1\cos x+C_2\sin x$$

**第四步：设特解 $y^*$。** $f(x)=6x$，$P_m(x)=6x$（一次）→ $Q_m(x)=ax+b$；$\lambda=0$ **不是**特征根（特征根是 $\pm i$）→ $k=0$。

$$y^*=ax+b$$

代入：$y^{*\prime}=a$，$y^{*\prime\prime}=0$，故 $0+(ax+b)=6x$，对比系数得 $a=6$，$b=0$，即 $y^*=6x$。

**第五步：写出通解。**

$$f(x)=C_1\cos x+C_2\sin x+6x$$

**第六步：找出隐含的两个初始条件。**

- 在原式中令 $x=0$，变限积分为 0，右边只剩常数项，得 $f(0)=1$；
- 在第一次求导后的式子中令 $x=0$，得 $f'(0)=0$。

**第七步：定常数。** 对通解求导：

$$f'(x)=-C_1\sin x+C_2\cos x+6$$

由 $f(0)=1$ 得 $C_1=1$；由 $f'(0)=0$ 得 $C_2+6=0$，即 $C_2=-6$。故

$$f(x)=\cos x-6\sin x+6x$$

> 老师说这种「变限积分 + 二阶非齐次」的题在考试里出现频率不算高（一阶里出现更多），因为二阶求起来确实比较麻烦，「熟练的时候你可以 10 分钟以内就可以解决，如果你不熟练，在十到 20 分钟才能够把它解决」。

### 例 40 变限积分练习（第 6 题）

同类型练习。**关键预处理**：被积函数里**不能出现与积分变量无关的其他字母**，所以先把 $\displaystyle\int_0^x(x-t)f(t)dt$ 拆开，把 $x$ 提到积分号外：

$$\int_0^x(x-t)f(t)\,dt=x\int_0^xf(t)\,dt-\int_0^xtf(t)\,dt$$

再按例 37 的流程求导、求通解、用隐含初始条件定常数。

老师给出答案：$y^*=\dfrac{1}{2}e^x$，最终 $f(x)$ 中含 $\cos x$、$\sin x$、$e^x$ 三项（字幕此处数值转录不清，只记方法）。

## 四、易错点警示

| ❌ 易错 | ✅ 正确 |
|:---|:---|
| 认为方程里必须有 $x$ 和 $y$ 才算微分方程 | 只需**必须出现 $y$ 的导数**，$x$、$y$ 都可以不出现 |
| 把 $y^{10}$ 当成十阶导数 | 括号里才是导数阶数：$y^{(10)}$ 是十阶导，$y^{10}$ 是十次幂 |
| 看到 $(y'')^5$ 就以为是五阶方程 | 只认**最高阶导数**，$(y'')^5$ 仍是二阶 |
| 只要代进去成立就说是通解 | 通解还要满足**独立常数个数 = 方程阶数** |
| 认为 $y=x^2+C_1+C_2$ 有两个独立常数 | 两个常数能合并成一个，只算**一个**独立常数 |
| 特解里还留着 $C$ | 特解**不含 $C$**，常数必须由初始条件定死 |
| 二阶方程只求出一个常数就收工 | 有几个 $C$ 就要有几个初始条件；三阶只出两个 $C$ 一定是算错了 |
| 两边积分时左右都写 $C$ 却不合并 | 只保留**一个** $C$（$C_2-C_1$ 仍是一个任意常数） |
| 可分离变量型忘了先化成标准形式 | 题干很少直接给标准形式，必须**配凑、移项、变形** |
| 齐次型最后忘了把 $u$ 回代成 $\frac{y}{x}$ | 回代是最后一步，绝不能漏 |
| 齐次型看到 $y^2,xy,x^2$ 就束手无策 | **分子分母同除以 $x^2$**，立刻化成 $\frac yx$ 的函数 |
| 把任意常数写成 $e^C$ | $e^C$ 只能取正值，须写成 $\ln\vert C\vert$ 之类以保证取遍全体实数 |
| 套一阶线性公式时 $y'$ 的系数不是 1 | 先两边同除，把 $y'$ 的系数**化为 1** 再找 $P(x),Q(x)$ |
| $e$ 的指数上是 $\ln\vert\varphi(x)\vert$ 时硬带绝对值 | 可直接取出 $\varphi(x)$ 不加绝对值（两个正负号同号相乘，结果恒正，余下符号并入 $C$） |
| 可降阶类型二仍写 $y''=\frac{dp}{dx}$ | 类型二没有 $x$，必须写 $y''=p\frac{dp}{dy}$ |
| 可降阶类型一、二搞混 | 类型一含 $x,y',y''$（**无 $y$**）；类型二含 $y,y',y''$（**无 $x$**） |
| 特征方程写成 $r^2+pr+q=0$ 之外的形式 | 求几次导就写 $r$ 的几次方：$y''\to r^2$，$y'\to r$，$y\to1$ |
| 二重根写成 $C_1e^{rx}+C_2e^{rx}$ | 二重根通解是 $(C_1+C_2x)e^{rx}$，**必须带 $x$** |
| 共轭复根忘了 $e^{\alpha x}$ 或写错位置 | $y=e^{\alpha x}(C_1\cos\beta x+C_2\sin\beta x)$，$\alpha$ 在指数上、$\beta$ 在三角里 |
| $Q_m(x)$ 只写最高次项 | 要写**一般多项式**：$x^2\to ax^2+bx+c$，一次项、常数项都不能漏 |
| $f(x)$ 只给多项式时不会处理 $\lambda$ | 没有 $e^{\lambda x}$ 就理解成 $\lambda=0$ |
| $k$ 的判断去看了别的东西 | $k$ 只看 $f(x)$ 中的 $\lambda$ 是不是特征根：不是根 $k=0$、单根 $k=1$、重根 $k=2$ |
| 叠加原理里两组待定字母重名 | 两组字母必须**区分**（如 $a,b$ 与 $A,B$） |
| 代入 $y'(0)$ 时直接用通解 | 必须**先对通解求导**，再代入 |
| 变限积分的被积函数里含 $x$ 就直接求导 | 先用换元或拆项把 $x$ 提到积分号外，**再**求导 |
| 变限积分题忘了找隐含初始条件 | 令 $x=0$（或令上下限相同）从原式与求导式中挖出初始条件 |

## 五、小结

| 考点 | 要点 |
|:---|:---|
| 微分方程定义 | 含未知函数及其导数；必须有 $y$ 的导数，$x$、$y$ 可缺 |
| 阶数 | 最高阶导数的阶数；$y^{(n)}$ 是导、$y^{n}$ 是幂 |
| 解 | 代入使方程成为恒等式 |
| 通解 | 独立常数个数 = 方程阶数；独立常数不能合并 |
| 初始条件 / 特解 | 有几个 $C$ 就要几个初始条件；特解不含 $C$ |
| 直接积分型 | 左边 $y$ 的导数、右边只含 $x$；积几次降几阶，左边不加 $C$ |
| 一阶可分离变量型 | $\frac{dy}{dx}=f(x)g(y)$ → 分离 → 积分 → 化简；能显化就显化 |
| 一阶齐次型 | $\frac{dy}{dx}=f(\frac yx)$ → 令 $u=\frac yx$、$y=ux$ → $x\frac{du}{dx}+u=f(u)$ → 分离积分 → 回代 |
| 一阶线性 | $y'+P(x)y=Q(x)$；$y=e^{-\int P dx}\left[\int Qe^{\int P dx}dx+C\right]$ |
| 二阶可降阶（类型一） | 含 $x,y',y''$（无 $y$）：令 $y'=p$、$y''=p'$ |
| 二阶可降阶（类型二） | 含 $y,y',y''$（无 $x$）：令 $y'=p$、$y''=p\frac{dp}{dy}$ |
| 二阶常系数齐次 | 特征方程 $r^2+pr+q=0$，三种根三种通解 |
| 两个不等实根 | $y=C_1e^{r_1x}+C_2e^{r_2x}$ |
| 二重根 | $y=(C_1+C_2x)e^{rx}$ |
| 共轭复根 $\alpha\pm\beta i$ | $y=e^{\alpha x}(C_1\cos\beta x+C_2\sin\beta x)$ |
| 复数 | $z=\alpha+\beta i$，$i^2=-1$；共轭：实部同、虚部反 |
| 非齐次通解结构 | $y=Y_{\text{齐通}}+y^*$；$y^*$ 形式唯一，与初始条件无关 |
| $f(x)$ 形式 | $P_m(x)e^{\lambda x}$；无 $e^{\lambda x}$ 则 $\lambda=0$；三角函数仅个别省份考 |
| 特解设法 | $y^*=Q_m(x)e^{\lambda x}x^k$：$Q_m$ 由 $P_m$ 最高次定、$e^{\lambda x}$ 照搬、$k$ 由 $\lambda$ 与特征根关系定 |
| 叠加原理 | $f=f_1+f_2$ 时 $y^*=y_1^*+y_2^*$，字母要区分 |
| 定待定系数 | 求两阶导 → 代入 → 约 $e^{\lambda x}$ → 按高次/一次/常数项整理 → 对比系数 |
