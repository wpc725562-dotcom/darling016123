# 第五章 多元函数微分学

> 来源：陈哥专升本《专升本高等数学全程班》P87–P97
> 本章地位：陈哥原话——「多元函数就是顾名思义，它就是比一元函数的微分要多一个变量，或者说多几个变量」。整章分两节：第一节是偏导数与全微分（概念 + 计算），第二节是偏导数的应用（切线法平面、切平面法线、极值）。老师对难点的定位很清楚：「多元复合函数的求导法则，这实际上是我们整个章节比较难的一个部分」；对考纲的提醒也很直接：「请大家一定要去看一下自己省份对应的考纲，有些省份他可能考第五章，但是他只考第一节」。第二节的极值部分（拉格朗日乘数法）是压轴题的常客。

## 一、大白话讲解

### 1. 二元函数 = 一元函数多了一个自变量

一个「系统」：输入两个数 $x$、$y$，输出一个数 $z$，这个系统就是二元函数 $z=f(x,y)$。

| 名称 | 在一元函数 $y=f(x)$ 里 | 在二元函数 $z=f(x,y)$ 里 |
|:---|:---|:---|
| 自变量 | $x$ | $x$ 和 $y$（两个） |
| 因变量 | $y$ | $z$ |
| 对应关系 | $f$ | $f$（数学上也叫「映射关系」） |
| 定义域 | $x$ 的取值范围 | $(x,y)$ 的取值集合，几何上是**平面上的一块区域** |

超过两个自变量的（如 $w=f(x,y,z)$）统称**多元函数**。学会二元，三元四元是同一套方法。

### 2. 「偏导」的「偏」是什么意思

一元函数说「求导」，只有 $x$ 一个变量，没有歧义。二元函数有两个变量，说「求导」就不知道是对谁求。所以加一个「偏」字——**偏，就是特指偏向于哪一个变量求导**。

求法只有一句话：**对谁求导，谁就是变量，其余全当常数。** 然后照搬一元函数的求导法则。

> 陈哥原话：「我们每次只关注求导变量，其余非求导变量全部当做常数，这有点类似于我们的控制变量法。」（P91）

### 3. 链式法则：连线相乘，分线相加

复合函数 $z=f(u,v)$，而 $u=u(x,y)$、$v=v(x,y)$。$z$ 和 $x$ 之间没有直接联系，中间隔着 $u$、$v$ 这两块「桥」。

从 $z$ 走到 $x$，有几条路，就写几项；每一条路上的每一段相乘。

$$\frac{\partial z}{\partial x}=\underbrace{\frac{\partial z}{\partial u}\cdot\frac{\partial u}{\partial x}}_{\text{第一条路}}+\underbrace{\frac{\partial z}{\partial v}\cdot\frac{\partial v}{\partial x}}_{\text{第二条路}}$$

> 陈哥原话：「连线相乘，分线相加。」（P92）

### 4. 隐函数：公式法最省事

$F(x,y,z)=0$ 确定了 $z=f(x,y)$，那么

$$\frac{\partial z}{\partial x}=-\frac{F_x}{F_z},\qquad \frac{\partial z}{\partial y}=-\frac{F_y}{F_z}$$

关键在于**把 $x$、$y$、$z$ 三个字母看成地位完全相同的变量**，对谁求偏导，另两个就当常数。

> 陈哥原话：「你可以理解不了这个直接求导法，但是你一定可以理解公式法的……有些同学就是这样反馈的，他对直接求导法觉得很绕很不好理解，但是对于公式法呢就是清晰明了。」（P93）

### 5. 切线 / 切平面：一个向量通吃

- 空间曲线（参数式）上一点：**切线的方向向量** 与 **法平面的法向量** 是同一个向量，这个向量就是对参数求导后代入 $t_0$。
- 空间曲面 $F(x,y,z)=0$ 上一点：**法线的方向向量** 与 **切平面的法向量** 也是同一个向量，这个向量就是 $(F_x,F_y,F_z)$ 在该点的取值。

老师反复强调这两个「同一个向量」是简化问题的关键：本来要求两个向量，现在只要求一个。

### 6. 极值：无条件 vs 条件

| | 无条件极值 | 条件极值 |
|:---|:---|:---|
| 约束 | 无，$x$、$y$ 随便取 | 附加一个约束方程（如 $x+y=1$） |
| 方法 | 求偏导 → 解驻点 → 二阶偏导判 $AC-B^2$ | 构造拉格朗日函数 $L=f+\lambda\varphi$ → 求偏导 → 解方程组 |
| 极大/极小怎么定 | 看 $AC-B^2$ 的符号和 $A$ 的正负 | 没有现成判别法，**取驻点附近且满足约束的点代进去比大小** |

## 二、考点全爆破

### 1. 二元函数的概念与结构（P87）

$$z=f(x,y)$$

- $x$、$y$：自变量；$z$：因变量；$f$：对应关系（映射关系）
- 定义域是自变量的集合，值域是 $z$ 的集合
- $w=f(x,y,z)$ 是三元函数；自变量超过两个统称多元函数

### 2. 二元函数表达式的求法：换元法与配凑法（P87）

题型：已知 $f(\varphi(x,y),\psi(x,y))$ 的表达式，反求 $f(x,y)$；或已知 $f(x,y)$，反求 $f(\varphi,\psi)$。

**方法一：换元法**

1. 令 $\varphi(x,y)=u$，$\psi(x,y)=v$；
2. 从这两个式子中反解出 $x$、$y$（用 $u$、$v$ 表示）；
3. 代回右边，整理成只含 $u$、$v$ 的式子，得 $f(u,v)$；
4. 最后**把 $u$、$v$ 直接换成 $x$、$y$** 即得 $f(x,y)$。

> 换名的合法性：函数表达式与自变量用什么字母无关，$f$ 里的 $u$、$v$ 换成 $a$、$b$ 都行。

**方法二：配凑法**

先观察右边的结构，用完全平方、平方差等公式凑出左边的两块形式，再换元。

### 3. 二元函数的定义域（P88）

求法与一元函数完全一致，就是「让表达式有意义」：

| 表达式 | 条件 |
|:---|:---|
| 分式 | 分母 $\ne 0$ |
| 偶次根式 | 被开方式 $\ge 0$ |
| 对数 | 真数 $> 0$ |
| $\arcsin$ / $\arccos$ | 自变量绝对值 $\le 1$ |
| $\arctan$ / $\operatorname{arccot}$ | 无限制 |
| 奇次根式 | 被开方式可为负 |

**与一元函数的两个区别**：

1. 最后解出来的是一个**范围（区域）**，不是一个数轴上的区间；
2. **只能用集合表示，不能用区间表示**：

$$D=\{(x,y)\mid x^2+y^2\le 4\}$$

从几何看，二元函数的定义域通常是平面上的某个区域（例如 $x^2+y^2\le4$ 是闭圆盘）。这个「区域」在后面学二重积分时就是**积分区域**。

### 4. 二元函数的极限（P88）

$$\lim_{(x,y)\to(x_0,y_0)}f(x,y)=A$$

含义：$f$ 在点 $(x_0,y_0)$ 的某个**邻域**内有意义，当 $(x,y)$ 以**任何方式、任何方向**趋近于 $(x_0,y_0)$ 时，$f(x,y)$ 都趋近于常数 $A$。

**与一元函数的关键差别**：

| | 一元函数 $x\to x_0$ | 二元函数 $(x,y)\to(x_0,y_0)$ |
|:---|:---|:---|
| 趋近方向 | 只有左、右两个方向 | **四面八方无穷多条路径** |
| 存在的充要条件 | 左极限 = 右极限 | 沿**所有**路径极限都相等 |

**两条铁律**：

1. **洛必达法则在二元函数中不适用**（只对一元函数有效）。
2. 专升本阶段这一部分**约 90% 的题都只考等价无穷小**，把一元函数的等价无穷小表背熟即可。常见套路是把 $x^2+y^2$ 或 $\sqrt{x^2+y^2}$ 当作一个整体 $u$。

**证明极限不存在的方法**：取两条特殊路径，得到两个不同的极限值，即可断定极限不存在。常用路径：$y=kx$（直线）、$y=x^2$（抛物线）。

### 5. 一阶偏导数的定义与记号（P89）

一元函数在 $x_0$ 处的导数：

$$f'(x_0)=\lim_{\Delta x\to 0}\frac{f(x_0+\Delta x)-f(x_0)}{\Delta x}$$

二元函数在 $(x_0,y_0)$ 处对 $x$ 的偏导数（把 $y_0$ 当作「附带的」常数，去掉它就退化成一元导数）：

$$\left.\frac{\partial z}{\partial x}\right|_{(x_0,y_0)}=\lim_{\Delta x\to 0}\frac{f(x_0+\Delta x,\,y_0)-f(x_0,y_0)}{\Delta x}$$

对 $y$ 的偏导数同理（把 $x_0$ 当常数）。

**记号**（下列写法都表示同一个东西）：

$$\frac{\partial z}{\partial x},\quad \frac{\partial f}{\partial x},\quad z_x,\quad f_x,\quad f_x(x,y),\quad f'_x$$

- $\partial$ 读作 "round"；但一般不读「round $z$ 比 round $x$」，而是直接读 **「$z$ 对 $x$ 的偏导」**。
- 右下角的字母（$z_x$）**必须写**，否则不知道对谁求导；上方的一撇（$z'_x$）写不写都行，写了反而有点画蛇添足。

### 6. 一阶偏导数的求法（P89，★★★核心）

**口诀**：

- 对 $x$ 求偏导 → **把 $y$ 看作常数**，变成一元函数，用一元求导法则；
- 对 $y$ 求偏导 → **把 $x$ 看作常数**，变成一元函数，用一元求导法则。

幂指函数 $u^v$ 先做**指数对数化**：$u^v=e^{v\ln u}$，再求偏导。

### 7. 先代后求（P89）

求 $f_x(x_0,y_0)$ 时，如果直接求 $f_x(x,y)$ 再代点太麻烦，可以**先把非求导变量的值代入**，化简后再对求导变量求导、再代求导变量的值。

$$\text{求 }f_x(2,1)\ \Longrightarrow\ \text{先令 }y=1\ \text{化简}\ \Longrightarrow\ \text{对 }x\text{ 求导}\ \Longrightarrow\ \text{再代 }x=2$$

**要点**：代入的是**非求导变量**的值；求导变量**不能提前代入**。理由：对 $x$ 求偏导时 $y$ 始终是常数，它从头到尾没有参与求导运算，所以可以先把它定下来。

### 8. 全微分（P90）

一元函数：$\mathrm{d}y=f'(x)\,\mathrm{d}x$。

二元函数（求全微分的本质就是在求两个偏导，再组合起来）：

$$\boxed{\mathrm{d}z=\frac{\partial z}{\partial x}\,\mathrm{d}x+\frac{\partial z}{\partial y}\,\mathrm{d}y}$$

三元函数：

$$\mathrm{d}u=\frac{\partial u}{\partial x}\,\mathrm{d}x+\frac{\partial u}{\partial y}\,\mathrm{d}y+\frac{\partial u}{\partial z}\,\mathrm{d}z$$

**注意**：$\mathrm{d}z$ 是微分符号，与「抖音」无关。求某一点 $(x_0,y_0)$ 处的全微分，要把该点的两个偏导值都算出来，再写成 $\mathrm{d}z=A\,\mathrm{d}x+B\,\mathrm{d}y$（系数为 $0$ 的项可以省略，但它是存在的）。

### 9. 二阶偏导数（P91）

二阶偏导数就是**在一阶偏导数的基础上再求一次偏导**。一阶偏导 $z_x$、$z_y$ 本身仍是 $x$、$y$ 的二元函数，所以可以对它们分别再对 $x$ 或对 $y$ 求偏导，共得**四个**：

| 记号 | 含义 |
|:---|:---|
| $\dfrac{\partial^2 z}{\partial x^2}=z_{xx}=f''_{xx}$ | 先对 $x$，再对 $x$ |
| $\dfrac{\partial^2 z}{\partial x\partial y}=z_{xy}=f''_{xy}$ | 先对 $x$，再对 $y$ |
| $\dfrac{\partial^2 z}{\partial y\partial x}=z_{yx}=f''_{yx}$ | 先对 $y$，再对 $x$ |
| $\dfrac{\partial^2 z}{\partial y^2}=z_{yy}=f''_{yy}$ | 先对 $y$，再对 $y$ |

**混合偏导的记号规则**：$\dfrac{\partial^2 z}{\partial x\partial y}$ 中**写在前面的 $\partial x$ 是先求的那一次**。

**定理（混合偏导相等）**：若 $z_{xy}$ 与 $z_{yx}$ 在定义域上连续，则

$$z_{xy}=z_{yx}$$

**专升本阶段该函数一定满足连续性条件**，所以四个二阶偏导实际上只有三个不同的值。这个结论在抽象函数二阶偏导的化简中反复使用。

**求法**：每一步都只关注当前的求导变量，其余变量（包括前面刚求出来的式子里的另一个变量）全部当常数。

### 10. 多元复合函数的链式求导法则（P92）

设 $z=f(u,v)$，$u=u(x,y)$，$v=v(x,y)$：

$$\frac{\partial z}{\partial x}=\frac{\partial z}{\partial u}\frac{\partial u}{\partial x}+\frac{\partial z}{\partial v}\frac{\partial v}{\partial x},\qquad
\frac{\partial z}{\partial y}=\frac{\partial z}{\partial u}\frac{\partial u}{\partial y}+\frac{\partial z}{\partial v}\frac{\partial v}{\partial y}$$

三个中间变量 $u,v,w$ 时同理，多加一项：

$$\frac{\partial z}{\partial x}=\frac{\partial z}{\partial u}\frac{\partial u}{\partial x}+\frac{\partial z}{\partial v}\frac{\partial v}{\partial x}+\frac{\partial z}{\partial w}\frac{\partial w}{\partial x}$$

**解题流程**：先画出**链式关系图**（因变量 → 中间变量 → 自变量），再照「连线相乘，分线相加」写式子。只要图能画对，式子就能写对。

**一处易错**：若某个中间变量只是**一元函数**（如 $v=v(x)$，只依赖 $x$），那一段必须写成 $\dfrac{\mathrm{d}v}{\mathrm{d}x}$，**不能写成偏导**——一元函数没有偏导的概念。

### 11. 抽象复合函数求一阶偏导（P92）

抽象函数指形如 $f(\,\cdot\,,\,\cdot\,)$ 而具体表达式不给出的函数。

**下标记号**：把 $f$ 括号里逗号分隔的各部分依次叫做「第一部分、第二部分、第三部分」，记

- $f'_1$：$f$ 对第一个部分求导
- $f'_2$：$f$ 对第二个部分求导
- $f''_{11}$：先对第一部分、再对第一部分求导；$f''_{12}$：先对第一部分、再对第二部分求导，以此类推。

> 老师提醒：因为求导过程中**括号里的内容始终不变**，为了答案简洁，可以**把括号省掉不写**，只写 $f'_1$、$f''_{12}$ 等。（P92、P91）

### 12. 抽象复合函数求二阶偏导（P92，本章最难点）

**核心性质**：不管求到几阶，**求导后的新函数仍具有与原函数相同的结构**——$f'_1$ 的括号里依旧是原来那两个部分。所以对 $f'_1$ 再求偏导时，仍要**对那两个部分分别求导**，即写出 $f''_{11}$ 与 $f''_{12}$ 两项，再各自乘上对应部分对该变量的导数。

**化简**：出现 $f''_{12}$ 与 $f''_{21}$ 时，利用 $f''_{12}=f''_{21}$ 合并同类项，只保留 $f''_{12}$。

> 老师说明：这类题「确实比较难，有很多省份他可能都不会考这种类型的题，请大家一定要去看一下自己对应的省份」。（P92）

### 13. 二元隐函数求导：公式法（P93）

**描述**：方程 $F(x,y,z)=0$ 确定了二元函数 $z=f(x,y)$，$z$ 隐藏在方程中。

**公式法步骤**：

1. 把方程所有项移到一边，令成三元函数 $F(x,y,z)$；
2. 注意 **$x$、$y$、$z$ 三个字母地位完全相同，都是变量**（这里**不能**把 $z$ 看成 $x$、$y$ 的函数）；
3. 分别求三个偏导 $F_x$、$F_y$、$F_z$（对一个求偏导时，另外两个当常数）；
4. 组合：

$$\frac{\partial z}{\partial x}=-\frac{F_x}{F_z},\qquad \frac{\partial z}{\partial y}=-\frac{F_y}{F_z}$$

> 陈哥原话：「公式法我要求大家都要掌握，每一位同学都要掌握这个二元隐函数的公式法。」（P93）

### 14. 二元隐函数求导：直接求导法（P93）

在方程两边**同时对 $x$ 求偏导**（或同时对 $y$ 求偏导）：

- **$x$ 是求导变量**；
- **$y$ 是自变量，当常数**；
- **$z$ 是关于 $x$、$y$ 的复合函数，要按复合函数求导**，求出来写成 $z_x$（对 $x$ 求偏导时）或 $z_y$（对 $y$ 求偏导时）。

求完之后把含 $z_x$（或 $z_y$）的项合并、移项、除过去即可。

**两种方法结果必然相同**（「殊途同归」）。

**综合题型**：$z=F(x,t)$，而 $t=t(x,y)$ 由另一个隐函数方程确定。此时先用**链式法则**写出 $z_x=f'_1+f'_2\cdot t_x$，其中 $t_x$ 再用**隐函数求导**（公式法或直接法）从 $t$ 满足的方程中求出，最后代回。

### 15. 空间曲线的切线与法平面（P94）

**空间曲线的参数式表示**：

$$x=x(t),\quad y=y(t),\quad z=z(t)$$

给定 $t_0$，就确定了曲线上一点 $M(x_0,y_0,z_0)$，其中 $x_0=x(t_0)$，$y_0=y(t_0)$，$z_0=z(t_0)$。

**切向量**（= 切线的方向向量 = 法平面的法向量，同一个向量）：

$$\vec T=\bigl(x'(t_0),\ y'(t_0),\ z'(t_0)\bigr)$$

**切线方程**：

$$\frac{x-x_0}{x'(t_0)}=\frac{y-y_0}{y'(t_0)}=\frac{z-z_0}{z'(t_0)}$$

**法平面方程**：

$$x'(t_0)(x-x_0)+y'(t_0)(y-y_0)+z'(t_0)(z-z_0)=0$$

**方法总结（只有两步）**：

1. 由 $t_0$ 代入曲线方程求出切点 $M$；
2. 对参数式求导，代入 $t_0$ 得切向量，再套上面的公式。

**补充技巧**：若曲线只给出两个方程（如 $y=6x^2$、$z=12x^2$，没有 $x$ 的表达式），可**令 $x=t$**，把 $y$、$z$ 都改写成 $t$ 的表达式，就得到标准的参数式。

### 16. 空间曲面的切平面与法线（P95）

**空间曲面的表示**：本质是一个**三元方程** $F(x,y,z)=0$；把所有满足方程的点画在坐标系里就构成一个曲面。

**法向量**（= 切平面的法向量 = 法线的方向向量，同一个向量）：

$$\vec n=\bigl(F_x(M),\ F_y(M),\ F_z(M)\bigr)$$

**切平面方程**：

$$F_x(M)(x-x_0)+F_y(M)(y-y_0)+F_z(M)(z-z_0)=0$$

**法线方程**：

$$\frac{x-x_0}{F_x(M)}=\frac{y-y_0}{F_y(M)}=\frac{z-z_0}{F_z(M)}$$

**方法总结（两步）**：

1. 把方程移项，令成三元函数 $F(x,y,z)$，求三个偏导 $F_x$、$F_y$、$F_z$；
2. 把点 $M$ 的坐标代入三个偏导，得到向量 $\vec n$，再套公式。

> **易混点**：曲线上是「**切线 + 法平面**」，曲面上是「**切平面 + 法线**」，名字一一对应，不要记反。

### 17. 无条件极值：概念与步骤（P96）

**极值点与极值的概念**（与一元函数完全一致）：在 $(x_0,y_0)$ 的某个邻域内，若 $f(x,y)$ 恒不小于（恒不大于）$f(x_0,y_0)$，则 $(x_0,y_0)$ 是极小（极大）值点，$f(x_0,y_0)$ 是极小（极大）值。

**驻点**：使**两个一阶偏导同时为零**的点：

$$f_x(x_0,y_0)=0,\qquad f_y(x_0,y_0)=0$$

**极值点的两类**：① 驻点；② 不可导点（如一阶偏导不存在的尖点）。**专升本只考第①类**（即一阶偏导等于零的情形），第②类不会出现。

**求解四步**：

| 步骤 | 内容 |
|:---|:---|
| 第一步 | 求两个一阶偏导 $f_x$、$f_y$，令其等于零，联立解出**驻点** |
| 第二步 | 求三个二阶偏导 $f_{xx}$、$f_{xy}$、$f_{yy}$ |
| 第三步 | 把驻点代入二阶偏导，**令 $A=f_{xx}(M)$，$B=f_{xy}(M)$，$C=f_{yy}(M)$** |
| 第四步 | 用 $AC-B^2$ 判断 |

**判别法**：

| 情形 | 结论 |
|:---|:---|
| $AC-B^2>0$ | **有极值**：$A>0$ 取极小值，$A<0$ 取极大值 |
| $AC-B^2<0$ | **无极值** |
| $AC-B^2=0$ | 可能有、可能没有（题目中不会出现） |

> 老师提示：如果二阶偏导求出来本身已经是常数（不含量 $x$、$y$），那它直接就是 $A$、$B$、$C$，不用再代驻点；若二阶偏导是表达式，才需要把驻点代进去。

### 18. 条件极值：拉格朗日乘数法（P97）

**描述**：求 $z=f(x,y)$ 在约束条件 $\varphi(x,y)=0$ 下的极值。约束条件限制的是**两个自变量的取值范围**。

**求解步骤**：

1. **找目标函数**：题目中「求谁的极值」，谁就是目标函数 $z=f(x,y)$；
2. **找条件函数**：把约束方程右边的数移到左边，令成一个新函数。例如约束是 $x+y=1$，条件函数是 $\varphi(x,y)=x+y-1$（**不能**把条件函数直接当成 $x+y$）；
3. **构造拉格朗日函数**：

$$L(x,y,\lambda)=f(x,y)+\lambda\,\varphi(x,y)$$

4. **求偏导并联立方程组**（$\lambda$ 也当作变量）：

$$\begin{cases}L_x=f_x+\lambda\varphi_x=0\\ L_y=f_y+\lambda\varphi_y=0\\ \varphi(x,y)=0\end{cases}$$

5. **解方程组**，得到可能的极值点 $(x,y)$（解方程组的核心手法：由前两式消去 $\lambda$，得到 $x$ 与 $y$ 的关系式，再代入条件函数）；
6. **判断极大还是极小**：条件极值**没有** $AC-B^2$ 这种现成判别法，用极值的原始定义——**在驻点附近取一个仍满足约束条件的点，代入 $f$ 比较大小**。比驻点的函数值大 → 驻点是极小值点；比它小 → 极大值点。

**两个难点**（老师点明）：① 目标函数和条件函数有时不直接给出，要自己从题目文字里找；② 解方程组（尤其三元方程组）不好解。

## 三、例题精讲

### P87 二元函数表达式

**例 1（换元法，真题）** 已知 $f\!\left(x+y,\ \dfrac{y}{x}\right)=x^2-y^2$，求 $f(x,y)$。

**解**：令 $x+y=u$，$\dfrac{y}{x}=v$。由 $y=vx$ 得 $u=x+vx=x(1+v)$，故

$$x=\frac{u}{1+v},\qquad y=xv=\frac{uv}{1+v}$$

代回右边：

$$f(u,v)=\left(\frac{u}{1+v}\right)^2-\left(\frac{uv}{1+v}\right)^2=\frac{u^2-u^2v^2}{(1+v)^2}=\frac{u^2(1+v)(1-v)}{(1+v)^2}=\frac{u^2(1-v)}{1+v}$$

把 $u,v$ 换成 $x,y$：

$$f(x,y)=\frac{x^2(1-y)}{1+y}$$

**例 2（配凑法）** 已知 $f(x+y,\,x-y)=\dfrac{x^2-2xy+y^2}{x^2-y^2}$，求 $f(x,y)$。

**解**：分子用完全平方公式，分母用平方差公式：

$$\frac{x^2-2xy+y^2}{x^2-y^2}=\frac{(x-y)^2}{(x+y)(x-y)}=\frac{x-y}{x+y}$$

令 $x+y=u$，$x-y=v$，则 $f(u,v)=\dfrac{v}{u}$，故

$$f(x,y)=\frac{y}{x}$$

**例 3（已知 $f$ 反求复合式）** 已知 $f(x,y)$（式中含 $x-\sqrt{x^2-y^2}$ 的结构），求 $f(x+y,\,x-y)$。

**解（只记方法）**：把 $x\to x+y$、$y\to x-y$ 直接代入：

$$(x+y)^2-(x-y)^2=4xy\quad\Longrightarrow\quad \sqrt{(x+y)^2-(x-y)^2}=\sqrt{4xy}=2\sqrt{x}\sqrt{y}$$

于是内层化成

$$(x+y)-2\sqrt{x}\sqrt{y}=(\sqrt{x}-\sqrt{y})^2$$

> 字幕数值不清，此处只记方法：外层函数的具体形式未能从字幕确认，按老师最终写出的结果形式为 $2\ln(\sqrt{x}-\sqrt{y})$（外层为对数）反推。

### P88 定义域与极限

**例 4** 求 $z=\sqrt{4-x^2-y^2}$ 的定义域。

**解**：偶次根式要求被开方式 $\ge 0$：

$$4-x^2-y^2\ge 0\ \Longrightarrow\ x^2+y^2\le 4$$

$$D=\{(x,y)\mid x^2+y^2\le 4\}$$

几何上这是一个**闭圆盘**（半径 $2$ 的圆及其内部）。

**例 5** 求 $z=\dfrac{\sqrt{4x-y^2}}{\ln(1-x^2-y^2)}$ 的定义域。

**解**：三个条件同时成立——

1. 偶次根式：$4x-y^2\ge 0$，即 $4x\ge y^2$；
2. 对数真数：$1-x^2-y^2>0$，即 $x^2+y^2<1$；
3. 分母不为零：$\ln(1-x^2-y^2)\ne 0$，即 $1-x^2-y^2\ne 1$，即 $x^2+y^2\ne 0$。

$$D=\{(x,y)\mid 4x\ge y^2,\ x^2+y^2<1,\ x^2+y^2\ne 0\}$$

（三个条件无法进一步合并，只能并列写出。这个区域画出来要等学二重积分时再讲。）

**例 6** 求含 $\sqrt{x}$（在分母）与一个要求自变量绝对值 $\le 1$ 的函数（疑为 $\arcsin$）的二元函数的定义域。

**解（只记方法）**：两个条件——

1. 根式在分母上：$x>0$；
2. 该函数的自变量绝对值不超过 $1$：$|x+y|\le 1$。

$$D=\{(x,y)\mid x>0,\ |x+y|\le1\}$$

> 字幕数值不清，此处只记方法：原式的外层函数名称未能确认。

**例 7（综合，难度上限）** 求一个含 $\arcsin$ 型（要求 $|(x^2+y^2)/4|\le 1$）、$\arctan$（无限制）与三次根式（只需分母不为零）的复合函数的定义域。

**解（只记方法）**：由四个条件综合——

1. $\left|\dfrac{x^2+y^2}{4}\right|\le 1\ \Longrightarrow\ -4\le x^2+y^2\le 4$；
2. $\arctan$ 型部分对自变量无限制；
3. 三次根式内为分式，只需分母 $x^2+y^2-1\ne 0$；
4. 还有 $x^2+y^2-1\ge 0$。

由 3、4 合并得 $x^2+y^2>1$；再由 1 得 $x^2+y^2\le 4$。故

$$D=\{(x,y)\mid 1<x^2+y^2\le 4\}$$

> 老师原话：「这种题呢只是 paper tiger……纸老虎。因为这种题只是看起来比较麻烦，但实际上做起来你会觉得这题其实很简单。」

**例 8（无穷小 × 有界）** 求 $\lim\limits_{(x,y)\to(0,0)}$ 一个无穷小因子与 $\sin\dfrac{1}{xy}$ 之积。

**解**：当 $(x,y)\to(0,0)$ 时 $xy\to 0$，故 $\dfrac{1}{xy}\to\infty$，此时 $\sin\dfrac{1}{xy}$ 是**有界函数**（在 $[-1,1]$ 内振荡）。

**无穷小 × 有界 = 无穷小**，故极限为 $0$。

> 老师提醒：$\sin$ 只有在后面趋于无穷时才看作有界函数；当 $x\to 0$ 时 $\sin x$ 是**无穷小量**，可以等价为 $x$，不能当有界函数处理。

**例 9** 求 $\lim\limits_{(x,y)\to(0,0)}\dfrac{1-\cos(x^2+y^2)}{x^2+y^2}$。

**解**：把 $x^2+y^2$ 看成一个整体 $u$，用等价无穷小 $1-\cos u\sim\dfrac{u^2}{2}$：

$$\frac{1-\cos(x^2+y^2)}{x^2+y^2}\sim\frac{\frac12(x^2+y^2)^2}{x^2+y^2}=\frac12(x^2+y^2)\longrightarrow 0$$

**例 10** 求 $\lim\limits_{(x,y)\to(0,0)}\dfrac{\sin(x^2y)}{xy}$。

**解**：把 $x^2y$ 看成整体，用 $\sin u\sim u$：

$$\frac{\sin(x^2y)}{xy}\sim\frac{x^2y}{xy}=x\longrightarrow 0$$

**例 11（真题）** 求 $\lim\limits_{(x,y)\to(0,0)}\dfrac{2-\sqrt{4+xy}}{xy}$。

**解**：从分子中提出负号，凑成 $(1+\alpha)^{\beta}-1$ 的形式：

$$\frac{2-\sqrt{4+xy}}{xy}=-\frac{\sqrt{4+xy}-2}{xy}=-\frac{2\left[\sqrt{1+\frac{xy}{4}}-1\right]}{xy}$$

用等价无穷小 $(1+\alpha x)^{\beta}-1\sim\alpha\beta x$（这里 $\alpha=\dfrac{xy}{4}$，$\beta=\dfrac12$）：

$$-\frac{2\cdot\frac12\cdot\frac{xy}{4}}{xy}=-\frac14$$

> 老师评价：「这个题呢是以前的一个真题，还是比较有难度的，我认为是我见过的这种专升本的考题里面比较难的一个题了。」

**例 12** 求 $\lim\limits_{(x,y)\to(0,2)}\dfrac{e^{xy}-1}{x}$。

**解**：注意 **$y\to 2$ 而不是 $\to 0$**。用 $e^{xy}-1\sim xy$：

$$\frac{e^{xy}-1}{x}\sim\frac{xy}{x}=y\longrightarrow 2$$

**例 13（路径法，真题）** 讨论 $\lim\limits_{(x,y)\to(0,0)}\dfrac{x-y}{x+y}$ 是否存在。

**解**：取两条不同的路径。

**路径一**：沿 $y=x^2$（抛物线）趋近，则

$$\frac{x-x^2}{x+x^2}=\frac{x(1-x)}{x(1+x)}=\frac{1-x}{1+x}\longrightarrow 1$$

**路径二**：沿 $y=2x$（直线）趋近，则

$$\frac{x-2x}{x+2x}=\frac{-x}{3x}=-\frac13$$

两条路径得到的结果不同（$1\ne-\frac13$），故**极限不存在**。

**例 14（路径法，真题）** 讨论 $\lim\limits_{(x,y)\to(0,0)}\dfrac{xy}{x^2+y^2}$ 是否存在。

**解**：

**路径一**：沿 $y=x$ 趋近，$\dfrac{x^2}{x^2+x^2}=\dfrac12$；

**路径二**：沿 $y=x^2$ 趋近，$\dfrac{x\cdot x^2}{x^2+x^4}=\dfrac{x^3}{x^2+x^4}=\dfrac{x}{1+x^2}\longrightarrow 0$。

结果不同（$\frac12\ne 0$），故**极限不存在**。

> 老师总结：以后拿到这种题，就找两条路径——一般找一条**直线**和一条**抛物线**，通常就能得到两个不同的答案。这类题一般考选择或填空，不会考大题。

### P89 一阶偏导数

**例 15** $z=x^2e^{xy}$，求 $z_x$、$z_y$。

**解**：对 $x$ 求偏导时 $y$ 当常数，用乘积法则：

$$z_x=2x\,e^{xy}+x^2\cdot e^{xy}\cdot y=2xe^{xy}+x^2ye^{xy}$$

对 $y$ 求偏导时 $x$（以及 $x^2$）当常数：

$$z_y=x^2\cdot e^{xy}\cdot x=x^3e^{xy}$$

**例 16** $z=y\sin(xy)$，求 $z_x$、$z_y$。

**解**：

$$z_x=y\cdot\cos(xy)\cdot y=y^2\cos(xy)$$

$$z_y=\sin(xy)+y\cdot\cos(xy)\cdot x=\sin(xy)+xy\cos(xy)$$

**例 17** $z=x^2\ln(2x+y)$，求 $z_x$、$z_y$。

**解**：

$$z_x=2x\ln(2x+y)+x^2\cdot\frac{2}{2x+y}$$

$$z_y=x^2\cdot\frac{1}{2x+y}=\frac{x^2}{2x+y}$$

**例 18（幂指函数）** $z=x^y$，求 $z_x$、$z_y$。

**解**：先做指数对数化：$z=e^{y\ln x}$。

$$z_x=e^{y\ln x}\cdot y\cdot\frac1x=x^y\cdot\frac{y}{x}=y\,x^{y-1}$$

$$z_y=e^{y\ln x}\cdot\ln x=x^y\ln x$$

**例 19** $z=\arctan\dfrac{x}{y}$，求 $z_x$、$z_y$。

**解**：外层 $\arctan$ 求导为 $\dfrac{1}{1+(x/y)^2}$。

$$z_x=\frac{1}{1+\left(\frac{x}{y}\right)^2}\cdot\frac1y=\frac{y}{x^2+y^2}$$

$$z_y=\frac{1}{1+\left(\frac{x}{y}\right)^2}\cdot\left(-\frac{x}{y^2}\right)=-\frac{x}{x^2+y^2}$$

**例 20（先代后求）** 求 $f_x(2,1)$，其中 $f(x,y)$ 含形如 $(y-1)^2$ 的项。

**解**：$y$ 是非求导变量，先把 $y=1$ 代入化简，得 $f(x,1)=x^2$。再对 $x$ 求导得 $2x$，最后代 $x=2$：

$$f_x(2,1)=2\times 2=4$$

**例 21（先代后求）** 求 $f_y(1,1)$，其中 $f(1,y)$ 含 $y+\dfrac{1}{2y}$ 的结构（外层为对数）。

**解**：$x$ 是非求导变量，先把 $x=1$ 代入。对 $y$ 求导时用到 $\left(\dfrac{1}{2y}\right)'=-\dfrac{1}{2y^2}$，得

$$f_y(1,y)=\frac{1}{y+\frac{1}{2y}}\left(1-\frac{1}{2y^2}\right)$$

代 $y=1$：

$$f_y(1,1)=\frac{1}{1+\frac12}\left(1-\frac12\right)=\frac23\cdot\frac12=\frac13$$

> 字幕数值不清，此处只记方法：原式外层函数未能从字幕确认，方法为「先代非求导变量、再求导、再代求导变量的值」。

**例 22（幂指函数）** $z=(x^2+y^2)^{xy}$，求 $z_x$。

**解**：指数对数化 $z=e^{xy\ln(x^2+y^2)}$，用乘积法则求内层：

$$z_x=e^{xy\ln(x^2+y^2)}\left[y\ln(x^2+y^2)+xy\cdot\frac{2x}{x^2+y^2}\right]$$

$$=(x^2+y^2)^{xy}\left[y\ln(x^2+y^2)+\frac{2x^2y}{x^2+y^2}\right]$$

**例 23（抽象复合，含乘积）** $z=x\,f(e^x+\sin y)$，求 $z_x$、$z_y$。

**解**：括号内为中间变量，求导时括号内容不变，可省略不写。

$$z_x=f(e^x+\sin y)+x\,e^x f'(e^x+\sin y)$$

$$z_y=x\cos y\,f'(e^x+\sin y)$$

**例 24（综合，表达式 + 偏导）** 设 $z=f(x-y,\,x+y)$ 由 $f(x-y,\,x+y)=x^2-y^2$ 确定，证明 $f_x+f_y=x+y$。

**解**：右边 $x^2-y^2=(x-y)(x+y)$ 可用平方差公式。令 $x-y=u$，$x+y=v$，则

$$f(u,v)=uv\ \Longrightarrow\ f(x,y)=xy$$

于是

$$f_x=y,\qquad f_y=x\ \Longrightarrow\ f_x+f_y=x+y$$

### P90 全微分

**例 25** $z=ye^x$，求 $\mathrm{d}z$。

**解**：

$$z_x=ye^x,\qquad z_y=e^x$$

$$\mathrm{d}z=ye^x\,\mathrm{d}x+e^x\,\mathrm{d}y$$

**例 26** $z=e^{x^3+xy^2}$，求 $\mathrm{d}z$。

**解**：指数函数求导是它本身，再乘内层导数。

$$z_x=e^{x^3+xy^2}(3x^2+y^2),\qquad z_y=e^{x^3+xy^2}\cdot 2xy$$

$$\mathrm{d}z=e^{x^3+xy^2}\left[(3x^2+y^2)\,\mathrm{d}x+2xy\,\mathrm{d}y\right]$$

**例 27** $z=\sin(xy^2)$，求 $\mathrm{d}z$。

**解**：

$$z_x=y^2\cos(xy^2),\qquad z_y=2xy\cos(xy^2)$$

$$\mathrm{d}z=y^2\cos(xy^2)\,\mathrm{d}x+2xy\cos(xy^2)\,\mathrm{d}y$$

**例 28（指定点，真题）** $z=\ln(x^2+y)$，求 $\left.\mathrm{d}z\right|_{(0,1)}$。

**解**：

$$z_x=\frac{2x}{x^2+y},\qquad z_y=\frac{1}{x^2+y}$$

在 $(0,1)$ 处：$z_x=\dfrac{0}{1}=0$，$z_y=\dfrac11=1$。故

$$\left.\mathrm{d}z\right|_{(0,1)}=0\cdot\mathrm{d}x+1\cdot\mathrm{d}y=\mathrm{d}y$$

> 老师提醒：结果是 $\mathrm{d}y$ 是因为 $0\times\mathrm{d}x$ 这一项被省掉了，**不是**凭空出现的。有同学曾问「这个 $\mathrm{d}y$ 是抖音吗」，可见 $\mathrm{d}y$ 是微分符号。

### P91 二阶偏导数

**例 29** $z=x^2\ln(3y-2)$，求四个二阶偏导。

**解**：先求一阶偏导（对 $x$ 求导时 $\ln(3y-2)$ 是常数；对 $y$ 求导时 $x^2$ 是常数）：

$$z_x=2x\ln(3y-2),\qquad z_y=x^2\cdot\frac{3}{3y-2}=\frac{3x^2}{3y-2}$$

再求二阶偏导（每一步只关注当前求导变量）：

$$z_{xx}=2\ln(3y-2)$$

$$z_{xy}=z_{yx}=2x\cdot\frac{3}{3y-2}=\frac{6x}{3y-2}$$

$$z_{yy}=\frac{3x^2\cdot(-3)}{(3y-2)^2}=-\frac{9x^2}{(3y-2)^2}$$

**例 30（练习）** 求一个二元函数的四个二阶偏导。

> 字幕数值不清，此处只记方法：老师在此题中多次自我更正，函数表达式无法从字幕确认。方法为——① 先求两个一阶偏导；② 对一阶偏导再求一次偏导，**每一步只关注求导变量，其余全部当常数**；③ 先 $x$ 后 $y$ 与先 $y$ 后 $x$ 的结果相同（$z_{xy}=z_{yx}$），可互相校验。

**例 31（抽象函数二阶偏导）** $z=y\,f(x+y)$，求四个二阶偏导。

**解**：

$$z_x=y\,f'(x+y)$$

$$z_y=f(x+y)+y\,f'(x+y)$$

再求二阶（注意 $f'$ 的括号内容与原函数相同，求导时要继续对括号内的部分求导）：

$$z_{xx}=y\,f''(x+y)$$

$$z_{xy}=z_{yx}=f'(x+y)+y\,f''(x+y)$$

$$z_{yy}=f'(x+y)+f'(x+y)+y\,f''(x+y)=2f'(x+y)+y\,f''(x+y)$$

> 老师提示：答案里可以**把括号省掉**不写（因为括号内容始终不变），只写 $f'$、$f''$ 等，答案更简洁。

### P92 多元复合函数求导

**例 32（一阶，一元中间变量）** $z=f(x^2+y^2)$，求 $z_x$。

**解**：括号内是整体（中间变量 $u=x^2+y^2$），链式法则：

$$z_x=f'(x^2+y^2)\cdot 2x=2x\,f'_1$$

**例 33（一阶，两个中间变量）** $z=f(x^2+y^2,\ x^2y)$，求 $z_x$。

**解**：画链式图：$z\to$ 第一部分 $u=x^2+y^2$、第二部分 $v=x^2y$ $\to x,y$。由 $z$ 到 $x$ 有两条路：

$$z_x=f'_1\cdot\frac{\partial u}{\partial x}+f'_2\cdot\frac{\partial v}{\partial x}=f'_1\cdot 2x+f'_2\cdot 2xy=2x\,f'_1+2xy\,f'_2$$

**例 34（三个中间变量）** $z=f(x,\ e^x,\ \sin x)$，求 $z_x$。

**解**：这里中间变量都只依赖 $x$，是一元情形，但仍按链式法则写三项：

$$z_x=f'_1\cdot 1+f'_2\cdot e^x+f'_3\cdot\cos x=f'_1+e^x f'_2+\cos x\,f'_3$$

**例 35** $z=f(xy,\ x+y)$，求 $z_x$、$z_y$。

**解**：第一部分 $xy$，第二部分 $x+y$。

$$z_x=y\,f'_1+f'_2$$

$$z_y=x\,f'_1+f'_2$$

**例 36（全微分）** $z=f(x^2-y^2,\ e^{2x})$，求 $\mathrm{d}z$。

**解**：

$$z_x=f'_1\cdot 2x+f'_2\cdot 2e^{2x}=2x\,f'_1+2e^{2x}f'_2$$

$$z_y=f'_1\cdot(-2y)+f'_2\cdot 0=-2y\,f'_1$$

$$\mathrm{d}z=\left(2x\,f'_1+2e^{2x}f'_2\right)\mathrm{d}x+\left(-2y\,f'_1\right)\mathrm{d}y$$

**例 37（抽象函数二阶偏导，本章最难点）** $z=f(x+y,\ xy)$，求四个二阶偏导。

**解**：记第一部分为 $x+y$（对 $x$、对 $y$ 的导数都是 $1$），第二部分为 $xy$（对 $x$ 的导数是 $y$，对 $y$ 的导数是 $x$）。

**一阶**：

$$z_x=f'_1+y\,f'_2,\qquad z_y=f'_1+x\,f'_2$$

**二阶**：对 $z_x$ 再求 $x$ 的偏导（此时求导变量是 $x$，$y$ 当常数）：

$$z_{xx}=f''_{11}\cdot 1+y\,f''_{12}\cdot 1+y\left(f''_{21}\cdot 1+y\,f''_{22}\right)$$

用 $f''_{12}=f''_{21}$ 合并，得

$$z_{xx}=f''_{11}+2y\,f''_{12}+y^2f''_{22}$$

同理

$$z_{yy}=f''_{11}+2x\,f''_{12}+x^2f''_{22}$$

$$z_{xy}=z_{yx}=f''_{11}+(x+y)f''_{12}+f'_2+xy\,f''_{22}$$

> 老师强调：「这类题确实比较难，有很多省份他可能都不会考这种类型的题，请大家一定要去看一下自己对应的省份，这种类型到底出的多不多。」

### P93 二元隐函数求导

**例 38（两种方法对照）** 设 $e^z+e^{-xy}-2z=0$ 确定 $z=f(x,y)$，求 $z_x$、$z_y$。

**解法一（公式法）**：令 $F(x,y,z)=e^z+e^{-xy}-2z$。

- $F_x=e^{-xy}\cdot(-y)=-ye^{-xy}$
- $F_y=e^{-xy}\cdot(-x)=-xe^{-xy}$
- $F_z=e^z-2$

$$\frac{\partial z}{\partial x}=-\frac{F_x}{F_z}=\frac{ye^{-xy}}{e^z-2},\qquad \frac{\partial z}{\partial y}=\frac{xe^{-xy}}{e^z-2}$$

**解法二（直接求导法）**：方程两边同时对 $x$ 求偏导（$y$ 当常数，$z$ 当复合函数）：

$$e^z\cdot z_x+e^{-xy}\cdot(-y)-2z_x=0\ \Longrightarrow\ (e^z-2)z_x=ye^{-xy}$$

$$z_x=\frac{ye^{-xy}}{e^z-2}$$

结果与公式法一致。

**例 39（两种方法对照）** 设 $\dfrac{x}{z}=\ln z-\ln y$ 确定 $z=f(x,y)$，求 $\mathrm{d}z$。

**解法一（公式法）**：把右边移过来并利用对数性质化简：

$$F(x,y,z)=\frac{x}{z}-\ln z+\ln y=0$$

- $F_x=\dfrac1z$
- $F_y=\dfrac1y$
- $F_z=-\dfrac{x}{z^2}-\dfrac1z=-\dfrac{x+z}{z^2}$

$$\frac{\partial z}{\partial x}=-\frac{F_x}{F_z}=\frac{z}{x+z},\qquad \frac{\partial z}{\partial y}=-\frac{F_y}{F_z}=\frac{z^2}{y(x+z)}$$

$$\mathrm{d}z=\frac{z}{x+z}\,\mathrm{d}x+\frac{z^2}{y(x+z)}\,\mathrm{d}y$$

**解法二（直接求导法）**：对 $x$ 求偏导，左边用分式求导法则：

$$\frac{z-xz_x}{z^2}=\frac{1}{z}z_x$$

整理得 $z_x=\dfrac{z}{x+z}$，与公式法一致；对 $y$ 同理得 $z_y=\dfrac{z^2}{y(x+z)}$。

**例 40（指定点，真题）** 设 $z+e^z=xy$ 确定 $z=f(x,y)$，求 $\left.\mathrm{d}z\right|_{(1,1)}$。

**解**：令 $F(x,y,z)=z+e^z-xy$。

- $F_x=-y$，$F_y=-x$，$F_z=1+e^z$

$$\frac{\partial z}{\partial x}=\frac{y}{1+e^z},\qquad \frac{\partial z}{\partial y}=\frac{x}{1+e^z}$$

**关键一步**：式中还含 $z$，必须先把 $z$ 定出来。把 $x=y=1$ 代入原方程 $z+e^z=xy$，得 $z+e^z=1$，由「观察法」看出 $z=0$。

于是

$$\left.\frac{\partial z}{\partial x}\right|_{(1,1)}=\frac{1}{1+e^0}=\frac12,\qquad \left.\frac{\partial z}{\partial y}\right|_{(1,1)}=\frac12$$

$$\left.\mathrm{d}z\right|_{(1,1)}=\frac12\,\mathrm{d}x+\frac12\,\mathrm{d}y$$

**例 41（抽象函数隐函数）** 设 $F(xy,\ x+z)=0$ 确定 $z=f(x,y)$，求 $z_x$、$z_y$。

**解**：令 $G(x,y,z)=F(xy,\ x+z)$。注意 $x$、$y$、$z$ 地位相同。

- $G_x=F'_1\cdot y+F'_2\cdot 1=yF'_1+F'_2$
- $G_y=F'_1\cdot x+F'_2\cdot 0=xF'_1$
- $G_z=F'_1\cdot 0+F'_2\cdot 1=F'_2$

$$\frac{\partial z}{\partial x}=-\frac{G_x}{G_z}=-\frac{yF'_1+F'_2}{F'_2},\qquad \frac{\partial z}{\partial y}=-\frac{G_y}{G_z}=-\frac{xF'_1}{F'_2}$$

**例 42（链式 + 隐函数综合，考研基础题）** 设 $z=F(x,t)$，其中 $t=t(x,y)$ 由 $e^{xt}+y=t$ 确定，求 $z_x$。

**解**：画链式图：$z$ 经 $x$ 与 $t$ 联系，而 $t$ 又依赖于 $x$、$y$。故

$$z_x=F'_1\cdot 1+F'_2\cdot t_x=F'_1+F'_2\,t_x$$

其中 $t_x$ 由隐函数方程求出。对 $e^{xt}+y-t=0$ 两边同时求 $x$ 的偏导（$y$ 当常数，$t$ 当复合函数）：

$$e^{xt}(t+x\,t_x)-t_x=0\ \Longrightarrow\ t_x=\frac{t\,e^{xt}}{1-x\,e^{xt}}$$

代回：

$$z_x=F'_1+\frac{t\,e^{xt}}{1-x\,e^{xt}}\,F'_2$$

> 老师评价：这题「既涉及到这种抽象的函数，也涉及到这种隐函数，是考研的基础题」；并提醒「我们很多考研的基础题可以直接用来当做咱们的专升本的考题」。

### P94 空间曲线的切线与法平面

**例 43（真题）** 求曲线

$$x=\int_0^{t}e^{u}\cos u\,\mathrm{d}u,\qquad y=2\sin t+\cos t,\qquad z=1+e^{3t}$$

在 $t=0$ 处的切线方程和法平面方程。

**解**：

**第一步：求切点。** 把 $t=0$ 代入曲线方程。变限积分上下限相同，故 $x=0$；$y=2\sin 0+\cos 0=1$；$z=1+e^0=2$。切点 $M(0,1,2)$。

**第二步：求切向量。** 对参数式求导（变限积分求导用「上限代入被积函数乘上限导数」）：

$$x'(t)=e^t\cos t,\qquad y'(t)=2\cos t-\sin t,\qquad z'(t)=3e^{3t}$$

代 $t=0$：

$$\vec T=\vec n=\bigl(e^0\cos 0,\ 2\cos 0-\sin 0,\ 3e^0\bigr)=(1,\ 2,\ 3)$$

**切线方程**：

$$\frac{x}{1}=\frac{y-1}{2}=\frac{z-2}{3}$$

**法平面方程**：

$$1\cdot(x-0)+2\cdot(y-1)+3\cdot(z-2)=0\ \Longrightarrow\ x+2y+3z-8=0$$

**例 44（曲线未给参数式）** 求曲线 $y=6x^2$，$z=12x^2$ 在 $x=\dfrac12$ 处的切线方程和法平面方程。

**解**：

**第一步：补出参数式。** 曲线方程中没有 $x$ 的表达式，令 $x=t$，则

$$x=t,\qquad y=6t^2,\qquad z=12t^2$$

由 $x=\dfrac12$ 得 $t=\dfrac12$。

**第二步：求切点。** 代入得 $M\left(\dfrac12,\ \dfrac32,\ 3\right)$。

**第三步：求切向量。** $x'=1$，$y'=12t$，$z'=24t$，代 $t=\dfrac12$：

$$\vec T=\vec n=\left(1,\ 6,\ 12\right)$$

**切线方程**：

$$\frac{x-\frac12}{1}=\frac{y-\frac32}{6}=\frac{z-3}{12}$$

**法平面方程**：

$$\left(x-\frac12\right)+6\left(y-\frac32\right)+12(z-3)=0\ \Longrightarrow\ x+6y+12z-\frac{91}{2}=0$$

### P95 空间曲面的切平面与法线

**例 45** 求椭球面 $x^2+2y^2+3z^2=6$ 在点 $(1,1,1)$ 处的切平面方程和法线方程。

**解**：令 $F(x,y,z)=x^2+2y^2+3z^2-6$。

$$F_x=2x,\qquad F_y=4y,\qquad F_z=6z$$

在 $(1,1,1)$ 处：

$$\vec n=\vec s=(2,\ 4,\ 6)$$

**切平面方程**：

$$2(x-1)+4(y-1)+6(z-1)=0\ \Longrightarrow\ x+2y+3z-6=0$$

**法线方程**（系数约去公约数 $2$）：

$$\frac{x-1}{1}=\frac{y-1}{2}=\frac{z-1}{3}$$

**例 46** 求曲面 $z=x^2+y^2-1$ 在点 $(2,1,4)$ 处的切平面方程和法线方程。

**解**：令 $F(x,y,z)=x^2+y^2-1-z$。

$$F_x=2x,\qquad F_y=2y,\qquad F_z=-1$$

在 $(2,1,4)$ 处：

$$\vec n=\vec s=(4,\ 2,\ -1)$$

**切平面方程**：

$$4(x-2)+2(y-1)-1\cdot(z-4)=0\ \Longrightarrow\ 4x+2y-z-6=0$$

**法线方程**：

$$\frac{x-2}{4}=\frac{y-1}{2}=\frac{z-4}{-1}$$

### P96 无条件极值

**例 47（求驻点）** 求 $f(x,y)=2x^2+xy-y$ 的驻点。

**解**：

$$f_x=4x+y=0,\qquad f_y=x-1=0$$

由第二式得 $x=1$，代入第一式得 $y=-4$。驻点为 $(1,-4)$。

**例 48** 求 $z=xy-x^2-y^2+2x+2y$ 的极值。

**解**：

**第一步**：$z_x=y-2x+2=0$，$z_y=x-2y+2=0$。两式相减得 $-3x+3y=0$，即 $x=y$；再代入得 $x=2$。驻点 $(2,2)$。

**第二步**：$z_{xx}=-2$，$z_{xy}=1$，$z_{yy}=-2$。

**第三步**：二阶偏导已是常数，故 $A=-2$，$B=1$，$C=-2$。

**第四步**：

$$AC-B^2=(-2)\times(-2)-1^2=3>0$$

有极值；又 $A=-2<0$，故在 $(2,2)$ 处取**极大值**。

> 字幕数值不清，此处只记方法：老师口述的极大值数值与按表达式计算的结果不一致，极大值具体数值以字幕为准不予采信。

**例 49** 求 $z=e^y\left(x^2+2x+y\right)$ 的极值。

**解**：

**第一步**：求一阶偏导并令其为零（$e^y$ 当系数）：

$$z_x=e^y(2x+2)=0\ \Longrightarrow\ x=-1$$

（$e^y$ 恒不为零，只能括号为零。）代 $x=-1$ 入 $z_y$：

$$z_y=e^y\left(x^2+2x+y+1\right)=e^y\cdot y=0\ \Longrightarrow\ y=0$$

驻点 $(-1,\ 0)$。

**第二步**：

$$z_{xx}=2e^y,\qquad z_{xy}=e^y(2x+2),\qquad z_{yy}=e^y\left(x^2+2x+y+2\right)$$

**第三步**：代驻点 $(-1,0)$：

$$A=2e^0=2,\qquad B=e^0\cdot 0=0,\qquad C=e^0\cdot(1-2+0+2)=1$$

**第四步**：

$$AC-B^2=2\times 1-0=2>0,\qquad A=2>0$$

故 $(-1,0)$ 为**极小值点**，极小值 $f(-1,0)=-1$。

> 存疑：字幕口述极小值为「一」，按表达式 $e^y(x^2+2x+y)$ 计算应为 $-1$。

**例 50（两个驻点，中等偏上难度）** 求 $z=e^x\left(x+y^3-3y\right)$ 的极值。

**解**：

**第一步**：求一阶偏导并令其为零。

$$z_x=e^x\left(x+y^3-3y+1\right)=0,\qquad z_y=e^x\left(3y^2-3\right)=0$$

由 $z_y=0$ 且 $e^x\ne 0$ 得 $y^2=1$，即 $y=\pm 1$。

- 当 $y=1$：$x+1-3+1=0$，得 $x=1$，驻点 $(1,1)$；
- 当 $y=-1$：$x-1+3+1=0$，得 $x=-3$，驻点 $(-3,-1)$。

**第二步**：求二阶偏导。

$$z_{xx}=e^x\left(x+y^3-3y+2\right),\qquad z_{xy}=e^x\left(3y^2-3\right),\qquad z_{yy}=6y\,e^x$$

**第三步：分类讨论。**

对驻点 $(1,1)$：

$$A=e^1(1+1-3+2)=e,\qquad B=e^1(3-3)=0,\qquad C=6\times 1\times e=6e$$

$$AC-B^2=e\cdot 6e=6e^2>0,\qquad A=e>0$$

故 $(1,1)$ 为**极小值点**，极小值 $f(1,1)=e(1+1-3)=-e$。

对驻点 $(-3,-1)$：

$$A=e^{-3}(-3-1+3+2)=e^{-3},\qquad B=e^{-3}(3-3)=0,\qquad C=6\times(-1)\times e^{-3}=-6e^{-3}$$

$$AC-B^2=e^{-3}\cdot(-6e^{-3})=-6e^{-6}<0$$

故 $(-3,-1)$ **无极值**。

**综上**：$z$ 在 $(1,1)$ 处取得极小值 $-e$。

### P97 条件极值

**例 51** 求 $f(x,y)=x^2+y^2$ 在条件 $x+y=1$ 下的极值。

**解**：

**第一步：找目标函数与条件函数。** 目标函数 $f(x,y)=x^2+y^2$；条件函数由 $x+y=1$ 移项得 $\varphi(x,y)=x+y-1$。

**第二步：构造拉格朗日函数。**

$$L(x,y,\lambda)=x^2+y^2+\lambda(x+y-1)$$

**第三步：求偏导并联立。**

$$\begin{cases}L_x=2x+\lambda=0\\ L_y=2y+\lambda=0\\ x+y-1=0\end{cases}$$

**第四步：解方程组。** 由前两式相减得 $2x-2y=0$，即 $x=y$；代入第三式得 $2x-1=0$，即 $x=y=\dfrac12$。

**第五步：判断极大还是极小。** 取驻点 $\left(\dfrac12,\dfrac12\right)$ 附近且满足条件函数的点 $(1,0)$：

$$f\left(\frac12,\frac12\right)=\frac14+\frac14=\frac12,\qquad f(1,0)=1+0=1$$

邻域内的点函数值 $1$ 比驻点的 $\dfrac12$ **大**，故 $\left(\dfrac12,\dfrac12\right)$ 为**极小值点**，极小值 $\dfrac12$。

**例 52** 求 $f(x,y)=x^2+2y^2-xy$ 在条件 $x+y=4$ 下的极值。

**解**：条件函数 $\varphi(x,y)=x+y-4$。

$$L=x^2+2y^2-xy+\lambda(x+y-4)$$

$$\begin{cases}L_x=2x-y+\lambda=0\\ L_y=4y-x+\lambda=0\\ x+y-4=0\end{cases}$$

前两式相减：$3x-5y=0$，即 $x=\dfrac{5y}{3}$。代入第三式：

$$\frac{5y}{3}+y=4\ \Longrightarrow\ \frac{8y}{3}=4\ \Longrightarrow\ y=\frac32,\qquad x=\frac52$$

驻点 $\left(\dfrac52,\dfrac32\right)$，此时

$$f=\frac{25}{4}+2\cdot\frac94-\frac52\cdot\frac32=\frac{25+18-15}{4}=7$$

取附近且满足条件函数的点 $(2,2)$：$f(2,2)=4+8-4=8>7$。

故 $\left(\dfrac52,\dfrac32\right)$ 为**极小值点**，极小值 $7$。

**例 53（应用题，条件极值）** 求表面积为 $A^2$ 而体积最大的长方体的体积。

**解**：设长、宽、高分别为 $x$、$y$、$z$。

**目标函数**：$V=xyz$。

**条件函数**：由表面积为 $A^2$ 得 $2xy+2xz+2yz=A^2$，移项得

$$\varphi(x,y,z)=2xy+2xz+2yz-A^2$$

**拉格朗日函数**：

$$L(x,y,z,\lambda)=xyz+\lambda\left(2xy+2xz+2yz-A^2\right)$$

**求偏导并联立**：

$$\begin{cases}L_x=yz+2\lambda(y+z)=0\\ L_y=xz+2\lambda(x+z)=0\\ L_z=xy+2\lambda(x+y)=0\\ 2xy+2xz+2yz-A^2=0\end{cases}$$

**解方程组**：把前三个方程分别乘以 $x$、$y$、$z$（这一步在草稿纸上完成），再两两相减，可消去 $xyz$ 与 $2\lambda$ 的公共项，得

$$x=y=z$$

（详细过程：① 乘 $x$、乘 $y$ 两式相减得 $xz=zy$，约去 $z$ 得 $x=y$；② 乘 $y$、乘 $z$ 两式相减得 $xy=xz$，约去 $x$ 得 $y=z$。）

代入第四个方程：

$$2x^2+2x^2+2x^2=A^2\ \Longrightarrow\ 6x^2=A^2\ \Longrightarrow\ x=\frac{A}{\sqrt6}$$

故 $x=y=z=\dfrac{A}{\sqrt6}$（即正方体时体积最大），

$$V_{\max}=x^3=\left(\frac{A}{\sqrt6}\right)^3=\frac{A^3}{6\sqrt6}=\frac{\sqrt6\,A^3}{36}$$

> 老师坦言：「这个题呢整体来说是一个往年的考试真题，也是一个比较难的一个题目……根据反馈来说，百分之八九十的同学对于这个题是没有办法得满分的。」并给了一个应试技巧：「你实在不知道怎么进行运算，你就随便给他写一个值……阅卷老师是知道你是运算错了，而不是说你不会进行计算。」

**例 54（压轴真题）** 求椭圆 $\dfrac{x^2}{4}+y^2=1$ 上的点到直线 $2x+3y-6=0$ 的最短距离。

**解**：设椭圆上一点为 $(x,y)$。由点到直线距离公式

$$d=\frac{|2x+3y-6|}{\sqrt{2^2+3^2}}=\frac{|2x+3y-6|}{\sqrt{13}}$$

**关键处理**：绝对值不好求导，改求 $d^2$（求完再开根号即可）。

**目标函数**：$d^2=\dfrac{1}{13}(2x+3y-6)^2$。

**条件函数**：点在椭圆上，即 $\dfrac{x^2}{4}+y^2=1$，移项得 $\varphi=\dfrac{x^2}{4}+y^2-1$。

**拉格朗日函数**：

$$L=\frac{1}{13}(2x+3y-6)^2+\lambda\left(\frac{x^2}{4}+y^2-1\right)$$

**求偏导**：

$$L_x=\frac{1}{13}\cdot 2(2x+3y-6)\cdot 2+\frac{\lambda}{2}x=\frac{4}{13}(2x+3y-6)+\frac{\lambda}{2}x=0$$

$$L_y=\frac{1}{13}\cdot 2(2x+3y-6)\cdot 3+2\lambda y=\frac{6}{13}(2x+3y-6)+2\lambda y=0$$

**解方程组**：两式相比消去 $(2x+3y-6)$ 与 $\lambda$：

$$\frac{4/13}{6/13}=\frac{\frac{\lambda}{2}x}{2\lambda y}\ \Longrightarrow\ \frac{4}{6}=\frac{x}{4y}\ \Longrightarrow\ 16y=6x\ \Longrightarrow\ x=\frac{8}{3}y$$

代入条件函数：

$$\frac{\left(\frac{8}{3}y\right)^2}{4}+y^2=1\ \Longrightarrow\ \frac{16}{9}y^2+y^2=1\ \Longrightarrow\ \frac{25}{9}y^2=1\ \Longrightarrow\ y=\pm\frac35$$

于是得两个驻点：$\left(\dfrac85,\dfrac35\right)$ 与 $\left(-\dfrac85,-\dfrac35\right)$。

**比较**：

$$d^2\left(\frac85,\frac35\right)=\frac{1}{13}\left(\frac{16}{5}+\frac95-6\right)^2=\frac{1}{13}(5-6)^2=\frac{1}{13}$$

$$d^2\left(-\frac85,-\frac35\right)=\frac{1}{13}\left(-\frac{16}{5}-\frac95-6\right)^2=\frac{1}{13}(-5-6)^2=\frac{121}{13}$$

前者小、后者大，故最短距离为

$$d_{\min}=\sqrt{\frac{1}{13}}=\frac{\sqrt{13}}{13}$$

> 老师评价：「这是以前的一个真题，这是一个压轴题。」并指出这题的关键是「把这个题目翻译成我们能够理解的：求目标函数在约束条件下的极值」。

## 四、易错点警示

| ❌ 易错 | ✅ 正确 |
|:---|:---|
| 二元函数的定义域用区间表示 | 二元函数定义域**只能用集合**表示，如 $D=\{(x,y)\mid x^2+y^2\le4\}$ |
| 求定义域时只考虑根号、忘了对数真数也不能为 $1$ | 对数在**分母**上时，真数 $>0$ **且** 真数 $\ne 1$（因为 $\ln 1=0$） |
| 二元函数求极限用洛必达法则 | **洛必达法则只适用于一元函数**，二元函数中不适用；遇 $\frac00$ 型先想等价无穷小或路径法 |
| 把 $\sin x$（$x\to0$）当有界函数 | 只有 $\sin$ 后面趋于 $\infty$ 时才是**有界函数**；$x\to0$ 时 $\sin x$ 是**无穷小量**，可等价为 $x$ |
| 只算一条路径就断定极限存在 | 极限存在要求**所有路径**都趋于同一个值；证不存在只需**两条**路径结果不同 |
| 求 $f_x(x_0,y_0)$ 时把 $x_0$ 也先代进去 | **只能先代非求导变量**的值；求导变量要留到最后再代 |
| 写 $z_x$ 时右下角的字母漏掉 | 右下角的 $x$ **必须写**，否则不知道对谁求导；上方的一撇写不写都行 |
| 二阶偏导只求两个 | 共有**四个**（$z_{xx}$、$z_{xy}$、$z_{yx}$、$z_{yy}$），其中 $z_{xy}=z_{yx}$，实际三个值 |
| 混合偏导的记号顺序看反 | $\dfrac{\partial^2 z}{\partial x\partial y}$ 中**写在前面的 $\partial x$ 是先求的那一次** |
| 复合函数中一元中间变量也写成偏导 | 一元中间变量只能写 $\dfrac{\mathrm{d}v}{\mathrm{d}x}$，**没有偏导概念** |
| 抽象函数求二阶偏导时，对 $f'_1$ 再求导只写一项 | $f'_1$ 的括号结构与原函数相同，要**对两个部分分别求导**，写出 $f''_{11}$ 和 $f''_{12}$ 两项 |
| 出现 $f''_{12}$ 与 $f''_{21}$ 时不合并 | 利用 $f''_{12}=f''_{21}$ 合并同类项，只保留 $f''_{12}$ |
| 隐函数公式法中把 $z$ 看成 $x$、$y$ 的函数 | 公式法中 $x$、$y$、$z$ **地位完全相同，都是变量**（直接求导法才把 $z$ 当复合函数） |
| 忘记公式法前面的负号 | $\dfrac{\partial z}{\partial x}=-\dfrac{F_x}{F_z}$，**负号不能漏** |
| 求指定点全微分时忽略了式中还有 $z$ | 必须先把 $x$、$y$ 代入**原方程**解出 $z$，再算偏导 |
| 条件函数直接写成 $x+y$ | 必须把约束方程移项成 $x+y-1$ 这样的形式，**条件函数是移项后的式子** |
| 条件极值也用 $AC-B^2$ 判断 | 条件极值**没有** $AC-B^2$ 判别法，要取驻点附近**满足约束条件**的点代入比较 |
| 判断极值时取了不满足约束条件的点 | 取的点必须**同时满足条件函数**，否则比较无效 |
| 只考极值点为驻点，却去讨论不可导点 | 专升本**只考一阶偏导等于零**（驻点）的情形，不可导点不会出现 |
| 用「切线 + 法平面」对应曲面 | 曲线对应「**切线 + 法平面**」，曲面对应「**切平面 + 法线**」，不要记反 |
| 曲线只给两个方程时不会下手 | 令 $x=t$（或任一变量为 $t$），把另外两个改写成 $t$ 的表达式，补成参数式 |

## 五、小结

| 考点 | 要点 |
|:---|:---|
| 二元函数概念 | $z=f(x,y)$，两个自变量；自变量超过两个统称多元函数 |
| 表达式求解 | 换元法（令两块为新变量，反解 $x$、$y$）与配凑法（先凑公式再换元） |
| 定义域 | 与一元函数同一套「有意义」条件；解出来是**区域**，**只能用集合表示** |
| 二元函数极限 | 要求**所有路径**都趋于同一个值；证不存在取两条路径 |
| 洛必达法则 | **二元函数中不适用**，必须记牢 |
| 一阶偏导 | 对谁求导谁就是变量，其余当常数；$\partial$ 读 "round"，一般读「$z$ 对 $x$ 的偏导」 |
| 先代后求 | 先代**非求导变量**的值，求导变量留到最后代 |
| 全微分 | $\mathrm{d}z=z_x\,\mathrm{d}x+z_y\,\mathrm{d}y$；本质是求两个偏导再组合 |
| 二阶偏导 | 共四个，$z_{xy}=z_{yx}$（专升本保证连续），实际三个值；记号中先写的 $\partial$ 先求 |
| 链式法则 | **连线相乘，分线相加**；先画链式关系图再写式子 |
| 抽象函数一阶偏导 | 用 $f'_1$、$f'_2$ 下标记法；括号内容不变可省略不写 |
| 抽象函数二阶偏导 | 新函数结构与原函数相同，$f'_1$ 再求导要写 $f''_{11}$ 与 $f''_{12}$ 两项；用 $f''_{12}=f''_{21}$ 合并 |
| 隐函数（公式法） | $\dfrac{\partial z}{\partial x}=-\dfrac{F_x}{F_z}$，$\dfrac{\partial z}{\partial y}=-\dfrac{F_y}{F_z}$；$x,y,z$ 地位相同 |
| 隐函数（直接法） | 两边同时对 $x$ 求偏导，$y$ 当常数、$z$ 当复合函数；两种方法结果必相同 |
| 空间曲线 | 切向量 $=(x'(t_0),y'(t_0),z'(t_0))$；切线用「分子差、分母导数」，法平面用「导数乘坐标差求和 $=0$」 |
| 空间曲面 | 法向量 $=(F_x,F_y,F_z)|_M$；切平面用「偏导乘坐标差求和 $=0$」，法线用「分子差、分母偏导」 |
| 无条件极值 | 四步：求偏导解驻点 → 求二阶偏导 → 代值得 $A,B,C$ → 看 $AC-B^2$ 与 $A$ 的正负 |
| 条件极值 | 拉格朗日乘数法：$L=f+\lambda\varphi$，$L_x=L_y=0$ 与 $\varphi=0$ 联立；极大极小靠邻域取点比较 |
