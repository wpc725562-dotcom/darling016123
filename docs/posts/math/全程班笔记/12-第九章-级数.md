# 第九章 级数

> 来源：陈哥专升本《专升本高等数学全程班》P118–P127
> 本章地位：老师开篇就提醒——"咱们的这个第九章无穷级数呢，其实并不是所有的省份都要做考察的"，必须结合本省考纲；但难度并不低，"算我们这个高等数学中所有的章节里面中等偏上的一个难度了，因为有很多零散的知识点容易搞混淆，而且需要大家花很多时间去记忆"。整章分两小节：第一节**常数项级数**只围绕一件事——**判断敛散性**（"我们整个第一节呢，其实只围绕一个就是一个考题吧，就是级数的敛散性"）；第二节**幂级数**则围绕收敛区间/半径/域、和函数与幂级数展开。其中正项级数的判别"出现的概率极高极高"，"90% 以上的概率都会涉及到"。

## 一、大白话讲解

### 1. 从"走不完的一公里"引出级数（P118）

一段 1 公里的路，第一天走 $\frac12$，第二天走剩下的 $\frac12$（即 $\frac14$），第三天再走剩下的 $\frac12$（即 $\frac18$）……每天都走剩下路程的 $\frac12$，"是不是永远都走不到终点呢"。把每天走的路程加起来：

$$\frac12+\frac14+\frac18+\cdots+\frac{1}{2^n}+\cdots$$

这就是**无穷多项的累加**。以前数列只学到"前 $n$ 项和" $S_n$，是有限次累加；现在要把 $n$ 一直延伸到无穷，这个新东西就叫**级数**。

### 2. 级数 = 前 $n$ 项和的极限（P118 最核心的一步）

无穷多项没法真的逐项相加，于是把"求和"翻译成熟悉的"求极限"：

$$\sum_{n=1}^{\infty}u_n=\lim_{n\to\infty}S_n$$

老师反复强调这个等式"极其重要"。**极限算出来是常数 $S$，就说级数收敛于 $S$（$S$ 叫级数的和）；极限不存在或为无穷，就说级数发散。**

### 3. 数列 → 级数 → 函数项级数 → 幂级数（P118 / P123）

| 阶段 | 每一项 | 例子 |
|:---|:---|:---|
| 数列 | 常数 | $u_n=2n+1$ |
| 常数项级数 | 常数 | $\sum 2^n$ |
| 函数项级数 | 含 $x$ 的函数 | $\sum u_n(x)$ |
| 幂级数 | $a_nx^n$（底数是幂函数、指数是 $n$ 次方） | $\sum a_nx^n$ |

把常数项级数里的"常数"换成"函数"，就是函数项级数；函数项级数里最特殊、最常考的一种，就是幂级数。

### 4. 同一个幂级数，$x$ 取不同值结果完全不同（P123）

以 $\sum 2^n x^n$ 为例：

| $x$ | 公比 $q$ | 结论 |
|:---|:---|:---|
| $1$ | $2$ | 发散 |
| $\frac12$ | $1$ | 发散 |
| $\frac13$ | $\frac23$ | 收敛 |
| $-\frac14$ | $-\frac12$ | 收敛 |

既然有的点收敛、有的点发散，"我们不可能每个值它都继续给它取一遍"，所以要找出一整个**收敛的范围**——这就是收敛区间、收敛半径、收敛域的由来。

### 5. 收敛半径就是"区间长度的一半"（P123）

在数轴上求出收敛范围 $a<x<b$，那么收敛半径

$$R=\frac{b-a}{2}$$

例如区间 $(-1,5)$，长度是 $5-(-1)=6$，一半就是 $3$，即 $R=3$。**收敛区间一定是开区间**，端点单独代进去判敛散，才能得到最终的收敛域。

### 6. 和函数：把级数"缩"成一个函数（P126）

求和函数就是"把一个级数表示成一个函数"，即从级数到函数的过程。手段只有两把刀：**逐项求导**和**逐项积分**，目的都是"干掉"通项前面的系数 $a_n$：

- $a_n$ 是**分式** → 用**先导后积**（P125，本节字幕缺失）
- $a_n$ 是**整式**（没有分数线） → 用**先积后导**（P126）

### 7. 幂级数展开：把函数"摊开"成级数（P127）

求展开就是求和函数的逆过程——已知函数，反过来找它对应的级数。做法只有一个套路：**把函数"配"成六个基础框架的样子，再套用对应的麦克劳林展开式**，最后别忘了写 $x$ 的取值范围。

## 二、考点全爆破

### 1. 级数的概念（P118）

- **定义**：给定无穷数列 $u_1,u_2,\dots,u_n,\dots$，把各项用加号连起来

$$\sum_{n=1}^{\infty}u_n=u_1+u_2+\cdots+u_n+\cdots$$

- $\sum$ 读作"**西格玛求和**"；$n=1$ 是**下标**（表示从第一项开始），$\infty$ 是**上标**（表示一直加到无穷）。
- $u_n$ 称为级数的**通项**，也叫**一般项**；若 $u_n$ 是常数，则称**常数项级数**。
- **部分和数列**：$S_1=u_1$，$S_2=u_1+u_2$，$S_3=u_1+u_2+u_3$，……，$S_n=u_1+u_2+\cdots+u_n$。
- **级数的核心等式**：

$$\sum_{n=1}^{\infty}u_n=\lim_{n\to\infty}S_n$$

- **收敛与发散**：设 $\lim\limits_{n\to\infty}S_n=S$。若 $S$ 为常数，则称级数**收敛于 $S$**，$S$ 称为级数的和；若极限不存在或为无穷，则称级数**发散**。
- 这就是**敛散性判别方法之一：定义法**（必须与前 $n$ 项和的极限挂钩）。

### 2. 级数的四条性质（P119）

| 性质 | 内容 | 重要性 |
|:---|:---|:---|
| 性质一 | 若 $\sum u_n$ 收敛于 $S$，则 $\sum ku_n$（$k$ 为常数）收敛于 $kS$ | 最简单 |
| 性质二 | 若 $\sum u_n$ 收敛于 $S$、$\sum v_n$ 收敛于 $T$，则 $\sum(au_n+bv_n)$ 收敛于 $aS+bT$ | 很重要 |
| 性质三 | 在级数前面加上或减去**有限项**，级数的敛散性不变 | 用得最少 |
| 性质四 | **级数收敛的必要条件**：若 $\sum u_n$ 收敛，则 $\lim\limits_{n\to\infty}u_n=0$ | **极其重要** |

**由性质二延伸出的三条结论（必须记牢）：**

- 收敛 $\pm$ 收敛 $=$ 收敛
- 收敛 $+$ 发散 $=$ 发散
- 发散 $+$ 发散 $=$ **无法确定**

### 3. 必要条件与它的逆否命题（P119）

$$\text{级数收敛}\ \Longrightarrow\ \lim_{n\to\infty}u_n=0$$

$$\lim_{n\to\infty}u_n\ne 0\ \Longrightarrow\ \text{级数发散}$$

这就是**敛散性判别方法之二：逆否命题法**（只能判发散，不能判收敛，局限性很大）。

**★ 绝对不能反推**：$\lim\limits_{n\to\infty}u_n=0$ **推不出**级数收敛。

- 反例（发散）：调和级数 $\sum\frac1n$，虽然 $\lim\limits_{n\to\infty}\frac1n=0$，但级数发散。
- 反例（收敛）：等比级数 $\sum\frac{1}{2^n}$，$\lim\limits_{n\to\infty}\frac{1}{2^n}=0$，级数收敛。

### 4. 等比级数（P120）

$$\sum a q^{n}\quad(a\ne 0,\ q\ \text{为公比})$$

| 条件 | 结论 |
|:---|:---|
| $\lvert q\rvert<1$ | **收敛** |
| $\lvert q\rvert\ge 1$ | **发散** |

**收敛时级数的和**（"一减公比分之首项"，P120 推导、P126 反复使用）：

$$S=\frac{a_1}{1-q}\qquad(\lvert q\rvert<1,\ a_1\ \text{为首项})$$

推导要点：$S=\lim\limits_{n\to\infty}S_n=\lim\limits_{n\to\infty}\frac{a_1(1-q^n)}{1-q}=\frac{a_1}{1-q}$，因为 $\lvert q\rvert<1$ 时 $\lim\limits_{n\to\infty}q^n=0$。

> 这个公式在后面幂级数求和、幂级数展开中会反复用到，是前置知识点。

### 5. P 级数（P120）

$$\sum_{n=1}^{\infty}\frac{1}{n^{p}}\qquad(p>0)$$

| 条件 | 结论 |
|:---|:---|
| $p>1$ | **收敛** |
| $p\le 1$ | **发散** |

$p=1$ 时即 $\sum\frac1n$，称为**调和级数**，发散。

**★ 千万不要和等比级数搞混**：等比级数是 $\lvert q\rvert<1$ 收敛、$\lvert q\rvert\ge1$ 发散；P 级数是 $p>1$ 收敛、$p\le1$ 发散。

### 6. 正项级数：比值判别法（达朗贝尔判别法）（P121）

正项级数：$u_n>0$。令

$$\rho=\lim_{n\to\infty}\frac{u_{n+1}}{u_n}$$

| 条件 | 结论 |
|:---|:---|
| $\rho<1$ | **收敛** |
| $\rho>1$ | **发散** |
| $\rho=1$ | **判别法失效**，改用比较判别法 |

**适用范围（"三兄弟"）**：$u_n$ 中含有

1. **指数形式** $a^n$（$a$ 为常数，如 $2^n$）
2. **幂指形式** $n^n$
3. **阶乘** $n!$

出现这三种形式中的任意一种，就优先考虑比值判别法；含有其他形式（如 $n^2$）也没关系，只要"含有"这三种之一即可。

### 7. 正项级数：比较判别法（比较形式）（P121）

设两个正项级数 $\sum u_n$、$\sum v_n$，且 $u_n<v_n$：

| 条件 | 结论 |
|:---|:---|
| 大的级数 $\sum v_n$ 收敛 | 小的级数 $\sum u_n$ 必收敛 |
| 小的级数 $\sum u_n$ 发散 | 大的级数 $\sum v_n$ 必发散 |

**口诀：大收则小收，小发则大发。**

用法：题目只给一个不易判断的级数 $\sum u_n$，自己**对它放缩**造出 $v_n$，再判断 $v_n$ 的敛散性。

**常用放缩技巧：**

- 遇到 $\sin$、$\cos$（有界函数）：**放大到最大 1**，即 $\lvert\sin\Box\rvert\le1$、$\lvert\cos\Box\rvert\le1$。
- 遇到 $\ln n$：利用 $x>\ln x$，即 $\ln n<n$，从而把分母放大。

### 8. 正项级数：比较判别法（极限形式）（P121）

$$\lim_{n\to\infty}\frac{u_n}{v_n}=A$$

| $A$ 的取值 | 结论 |
|:---|:---|
| $A=0$ | $\sum v_n$ 收敛 $\Rightarrow$ $\sum u_n$ 收敛（**几乎不考**） |
| $A$ 为非零常数 | $\sum u_n$ 与 $\sum v_n$ **同敛散**（**重点、必考**） |
| $A=\infty$ | $\sum v_n$ 发散 $\Rightarrow$ $\sum u_n$ 发散（**几乎不考**） |

**只用学中间那一种**：找到一个 $v_n$，使 $\lim\frac{u_n}{v_n}$ 为非零常数，则两者同敛散。

**两种题型：**

**题型一：$u_n$ 中含多项式除法**——"**只用保留 $u_n$ 中分子分母的最高次方即可，约分之后的结果即是 $v_n$**"。

- 秒杀法：直接保留分子分母最高次幂得到 $v_n$，判断 $v_n$ 的敛散性即可（两者比值极限必为非零常数）。

**题型二：$u_n$ 中含有 $n\to\infty$ 时的等价无穷小形式**——把 $u_n$ 等价出来的结果直接作为 $v_n$。

- 常用等价（$n\to\infty$，注意是"整体趋于 0"才可等价）：$\sin\frac1n\sim\frac1n$，$\tan\frac1n\sim\frac1n$，$\ln\left(1+\frac1{n^2}\right)\sim\frac1{n^2}$，$1-\cos\frac1n\sim\frac12\cdot\frac1{n^2}$，$\mathrm{e}^{1/n}-1\sim\frac1n$。

### 9. 正项级数：根值判别法（P121）

$$\rho=\lim_{n\to\infty}\sqrt[n]{u_n}=\lim_{n\to\infty}u_n^{\frac1n}$$

| 条件 | 结论 |
|:---|:---|
| $\rho<1$ | **收敛** |
| $\rho>1$ | **发散** |
| $\rho=1$ | 不能确定，一般不用 |

**适用范围**：$u_n$ 中**含有 $n$ 次方**（形如 $\left(\frac{n+1}{n+2}\right)^n$、$\left(1+\frac1n\right)^{n^2}$ 等）。

**幂运算要点**：$\left(A^B\right)^C=A^{BC}$，**不能写成 $A^{B^C}$**。

### 10. 交错级数：莱布尼茨定理（P122）

交错级数：$\sum(-1)^{n-1}u_n$ 或 $\sum(-1)^{n}u_n$，其中 $u_n>0$，正负号交错出现（$(-1)$ 的幂决定了各项的符号）。

**莱布尼茨定理的两个条件：**

1. **单调**：$u_{n+1}\le u_n$
2. **趋零**：$\lim\limits_{n\to\infty}u_n=0$

**两个条件同时满足 $\Rightarrow$ 级数收敛；只满足其中一个，或两个都不满足 $\Rightarrow$ 级数发散。**

**★ 关键**：判定时用的 $u_n$ 是**不含 $(-1)^n$ 的那一部分**（正的部分），$(-1)^n$ 不能带进定理里算。

### 11. 任意项级数：绝对收敛与条件收敛（P122）

任意项级数：各项可正可负（可全正、可全负、可交错），它包含了正项级数和交错级数。

- **定义一（绝对收敛）**：若 $\sum\lvert u_n\rvert$ 收敛，则称 $\sum u_n$ **绝对收敛**。
- **定义二（条件收敛）**：若 $\sum u_n$ 收敛，但 $\sum\lvert u_n\rvert$ 发散，则称 $\sum u_n$ **条件收敛**。
- **定理**：绝对收敛 $\Rightarrow$ 收敛（老师笑称"这个定理我觉得有点说废话"）。

**两步判定法：**

```
Step 1：加绝对值，判断 Σ|u_n| 的敛散性
   ├─ 收敛 → 绝对收敛（结束）
   └─ 发散 → 进入 Step 2
Step 2：判断原级数 Σu_n 的敛散性（极大概率是交错级数，用莱布尼茨定理）
   ├─ 收敛 → 条件收敛
   └─ 发散 → 发散
```

加绝对值之后，问题就"回到了以前所学的方法"（P 级数、比值判别法、比较判别法、等价无穷小等）。

### 12. 幂级数的概念（P123）

- **函数项级数**：$\sum\limits_{n=1}^{\infty}u_n(x)$，各项都是函数；当 $x$ 取定某个具体值 $x_1$ 时，它就变成一个**常数项级数**。
- **幂级数**：函数项级数中 $u_n(x)$ 为"$n$ 次幂"形式（底数是幂函数、指数是 $n$ 次方）的一类：

$$\sum_{n=0}^{\infty}a_n x^{n}\qquad\text{或}\qquad\sum_{n=0}^{\infty}a_n(x-x_0)^{n}$$

其中 $a_n$ 称为**系数项**（与 $x$ 无关）。老师提示这两种形式出现概率约"六四开"，$\sum a_nx^n$ 约占 60%。

- **收敛点 / 发散点**：把 $x=x_1$ 代入得到常数项级数，收敛则称 $x_1$ 为收敛点，发散则称发散点。
- **收敛域**：幂级数**所有收敛点的集合**。专升本阶段收敛域一定是"一个连续的范围"。

### 13. 收敛区间、收敛半径、收敛域求法（P123）

**求法四步（非常固定）：**

**第一步**：令

$$\rho(x)=\lim_{n\to\infty}\left\lvert\frac{u_{n+1}(x)}{u_n(x)}\right\rvert<1$$

若 $u_n(x)$ **含有 $n$ 次方**，也可令

$$\rho(x)=\lim_{n\to\infty}\sqrt[n]{\lvert u_n(x)\rvert}<1$$

（求极限时，$x$ 视为常数，**绝对值的符号千万不能丢**。求完极限后 $\rho(x)$ 是一个关于 $x$ 的函数，$x$ 的角色从"系数"变成"自变量"。）

**第二步**：解不等式，得到的 $x$ 取值范围就是**收敛区间**（一定是**开区间**）。

**第三步**：求收敛半径

$$R=\frac{b-a}{2}\qquad(\text{收敛区间为}\ a<x<b)$$

**第四步**：把两个端点 $x=a$、$x=b$ 分别代入原级数，得到两个常数项级数，判断敛散性：

| 左端点 | 右端点 | 收敛域写法 |
|:---|:---|:---|
| 发散 | 发散 | $(a,b)$ |
| 发散 | 收敛 | $(a,b]$ |
| 收敛 | 发散 | $[a,b)$ |
| 收敛 | 收敛 | $[a,b]$ |

收敛取闭、发散取开，一共只有这四种情况。

### 14. 阿贝尔定理（P123 提及，P124 专门讲解）

**阿贝尔定理三条**（P124 正式讲述）：

| 位置 | 结论 |
|:---|:---|
| 收敛区间**内部** $(a,b)$（不含端点） | 对应的常数项级数**绝对收敛** |
| 区间**外部**（$x<a$ 或 $x>b$） | 一定**发散** |
| **两个端点** $a$、$b$ | 要么发散，要么**条件收敛**（不可能绝对收敛） |

收敛域 = 绝对收敛的范围 $\cup$ 条件收敛的点（取**并集**，不是交集）。

**两个配套结论（P124，做题的第一步）**

- **收敛区间的中心点**：令括号里的整体 $=0$ 解出 $x$。例如 $\sum a_n(x-2)^n$ ⇒ 令 $x-2=0$ ⇒ 中心点 $x=2$。
- **收敛区间关于中心点对称**：已知中心点与任一端点，另一端点就是它关于中心点的对称点。

> ★ **逆用（选择题高频）**：若幂级数在某点**条件收敛**，则该点**必是收敛区间的端点**。
> 老师在 P123 讲收敛区间时已提前提到过阿贝尔定理（原话："这里呢实际上就是阿贝尔定理"），P124 是专门的一讲。
### 15. 收敛半径不变的四种情形（P124）

已知一个幂级数的收敛半径，去讨论**另一个**幂级数的敛散性时，**必须先判断半径有没有变**。P124 给出四种**半径不变**的运算（以 $\sum a_n(x-1)^n$、$R=1$ 为例）：

| # | 运算 | 变成什么 | 半径 | 收敛区间 |
|:--|:---|:---|:--|:--|
| 1 | **乘 / 提取一个因式** | 乘 $(x-1)^2$ ⇒ $\sum a_n(x-1)^{n+2}$ | 不变 | 不变 |
| 2 | **平移**（左加右减） | $x\to x+2$ ⇒ $\sum a_n(x+1)^n$ | 不变 | **跟着平移** |
| 3 | **逐项求导** | $\sum n a_n(x-1)^{n-1}$ | 不变 | 不变 |
| 4 | **逐项积分** | $\sum \dfrac{a_n}{n+1}(x-1)^{n+1}$ | 不变 | 不变 |

> ★ **只有「平移」会改变收敛区间** —— 收敛区间是 $x$ 的范围，$x$ 平移到哪，区间就跟到哪；其余三种运算区间纹丝不动。
>
> 老师原话（P124）："我们整个运算的时候呢，其实只有收敛区间会发生变化，其他时候都不会发生变化的。"
>
> **左加右减**：把 $x$ 换成 $x+k$（$k>0$）是**左**平移 $k$ 个单位；换成 $x-k$ 是**右**平移 $k$ 个单位。区间跟着 $x$ 走，方向与 $x$ 一致。
### 16. 和函数的两个运算性质：逐项求导与逐项积分（P125）

**前提**：和函数的一切讨论**都在收敛域内进行**（老师反复强调）。

| 运算 | 结果 | 要点 |
|:---|:---|:---|
| **逐项求导** | $\left(\sum a_nx^n\right)'=\sum na_nx^{n-1}$ | 求和变量是 $n$、求导变量是 $x$，互不干扰 ⇒ 求和号可提出 |
| **逐项积分** | $\displaystyle\int_{x_0}^{x}\Bigl(\sum a_nt^n\Bigr)\mathrm{d}t=\sum a_n\frac{x^{n+1}}{n+1}$ | 必须写成**变上限积分**，下限 = **收敛中心点** $x_0$ |

> **积分下限为什么取收敛中心点**：那里是"起点"，且能保证 $S(x_0)=0$（第 17 步定常数要用）。
> **端点会不会变**：逐项求导 / 积分后，收敛域**端点的敛散性可能改变**（老师原话："很少遇到"）。
> **用途**：求和分析题 90% 靠这两个性质，**区别只在先后顺序**（先导后积 or 先积后导）。

**★ 核心公式（老师点名"至少打三颗星"）：收敛的等比级数之和 $=\dfrac{\text{首项}}{1-\text{公比}}$**

推导：等比数列前 $n$ 项和 $S_n=\dfrac{a_1(1-q^n)}{1-q}$，$|q|<1$ 时 $q^n\to0$ ⇒ $\lim\limits_{n\to\infty}S_n=\dfrac{a_1}{1-q}$。

> ★ 这一步是整个和函数章节的**分水岭**：它把**幂级数变成了函数**。老师原话："幂级数变成了函数，这是一个非常非常重要的一个转变。"

### 17. 和函数之先导后积型（P125，考频最高）

**适用**：$a_n$ 为**分式**（如 $\dfrac1n$、$\dfrac{1}{2n-1}$）。

**为什么要先求导**：求导会让 $x^n$ 掉下一个 $n$，正好与分母的 $n$ **约掉**。老师原话："先求导的目的就是为了干掉这个系数 $a_n$。"

**解题六步**

| 步骤 | 做什么 |
|:---|:---|
| ① | **求收敛域**（和函数的一切讨论都在收敛域内） |
| ② | 令 $S(x)=\sum a_n(x-x_0)^n$ |
| ③ | **两边同时求导**，干掉分式 $a_n$ |
| ④ | 用「$1-$公比分之首项」把右边化成**关于 $x$ 的函数**（★ 分水岭：幂级数 → 函数） |
| ⑤ | **两边同时积分**：写成变上限积分 $\displaystyle\int_{x_0}^{x}$，下限取**收敛中心点**，被积变量换成 $t$ |
| ⑥ | 左边 $\displaystyle\int_{x_0}^{x}S'(t)\,\mathrm{d}t=S(x)-S(x_0)$，由 $S(x_0)=0$ 定出 $S(x)$ |

**★★ 关键细节：分母与指数必须"对齐"**

求导能干掉分式的前提是**分母的次数 = 指数的次数**。若不对齐，**先提出一个 $x$**：

$$\sum_{n=1}^{\infty}\frac{(-1)^{n-1}}{2n-1}x^{2n}=x\sum_{n=1}^{\infty}\frac{(-1)^{n-1}}{2n-1}x^{2n-1}$$

分母 $2n-1$ 与指数 $2n-1$ 对齐之后，求导才能约掉。

> **提 $x$ 的合法性**：求和变量是 $n$，$x$ 与求和号无关 ⇒ **可以提到求和号外面**；含 $n$ 的部分（如 $(-1)^{n-1}$）**不能提**。
> **反例（老师给的）**：$\dfrac14x^5$ 求导干不掉分母，先提出一个 $x$ 变成 $\dfrac14x^4$ 就可以。

**分母含 $n(n+1)$ 怎么办**（P125 结尾）：**拆成两个式子**，分别求和函数再相加（第一个先导后积，第二个补一个 $x$ 后再先导后积）。

### 18. 和函数之先积后导型（P126）

**适用**：幂级数中 $a_n$ 为**整式**（没有分数线，如 $n$、$n^2$、$n(n+1)$）。目的是先积分把 $a_n$ 干掉。

**★ 核心要点**：先积后导时，必须保证**指数部分 = 因式部分 $-1$**。否则积分后系数干不掉（例如 $4x^4$ 积分得 $\frac45x^5$，系数 $4$ 还在）。

**解题步骤：**

1. 求收敛域；
2. **先积分**：写成变上限函数积分，上限为 $x$、下限为收敛中心 $x_0$：

$$\int_{0}^{x}S(t)\,\mathrm{d}t=\int_{0}^{x}\left(\sum a_n t^{n}\right)\mathrm{d}t=\sum a_n\int_{0}^{x}t^{n}\,\mathrm{d}t$$

（求和与积分可交换次序，因为积分变量是 $t$，求和变量是 $n$。）积出来的结果一定是**关于 $x$ 的函数**，通常可用"一减公比分之首项"整理；

3. **再求导**：对两边求导（左边用变上限函数求导公式），即得和函数 $S(x)$。

### 19. 和函数：特殊题型（逐项求导 + 微分方程）（P126）

形如 $\sum\limits_{n=0}^{\infty}\frac{x^n}{n!}$ 的级数，既不能先导后积也不能先积后导，只能用**逐项求导**：

$$S(x)=\sum_{n=0}^{\infty}\frac{x^n}{n!}\ \Longrightarrow\ S'(x)=\sum_{n=0}^{\infty}\frac{x^n}{n!}=S(x)$$

即得到**一阶线性微分方程** $S'-S=0$，解得 $S=Ce^{x}$。再由 $x=0$ 得初始条件 $S(0)=1$，故 $C=1$：

$$S(x)=\mathrm{e}^{x}$$

这正是 $\mathrm{e}^x$ 的麦克劳林展开式（见 P127）。

### 20. 和函数的四种题型总览（P126）

| 题型 | 特征 | 方法 |
|:---|:---|:---|
| 一、基础型 | 可直接套公式 | 一减公比分之首项 |
| 二、先导后积 | $a_n$ 为**分式** | 先逐项求导干掉分母，再积分 |
| 三、先积后导 | $a_n$ 为**整式** | 先逐项积分干掉整式，再求导 |
| 四、特殊型 | 含阶乘（如 $\frac{x^n}{n!}$） | 逐项求导 + 一阶线性微分方程 |

### 21. 六个麦克劳林展开式（P127，**必须背**）

老师要求"打个三个五角星"，其中**前四个最重要**（很多省份即使考展开也只考前四个）：

$$\frac{1}{1-x}=\sum_{n=0}^{\infty}x^{n}\qquad(-1<x<1)$$

$$\frac{1}{1+x}=\sum_{n=0}^{\infty}(-1)^{n}x^{n}\qquad(-1<x<1)$$

$$\mathrm{e}^{x}=\sum_{n=0}^{\infty}\frac{x^{n}}{n!}\qquad(-\infty<x<+\infty)$$

$$\ln(1+x)=\sum_{n=1}^{\infty}(-1)^{n-1}\frac{x^{n}}{n}\qquad(-1<x\le 1)$$

$$\sin x=\sum_{n=0}^{\infty}(-1)^{n}\frac{x^{2n+1}}{(2n+1)!}$$

$$\cos x=\sum_{n=0}^{\infty}(-1)^{n}\frac{x^{2n}}{(2n)!}$$

**记忆要点：**

- 前三个都从 $n=0$ 开始，**第四个 $\ln(1+x)$ 从 $n=1$ 开始**；
- $\frac{1}{1+x}$ 记成 $(-1)^n x^n$ 更方便（后面有用）；
- 后两个（$\sin$、$\cos$）是否考，要结合本省考纲；
- **$x$ 的取值范围千万不能忘**：前两个都是 $-1<x<1$，$\mathrm{e}^x$ 是全体实数，$\ln(1+x)$ 是 $-1<x\le1$。

### 22. 等价无穷小的底层原理（P127）

老师指出：**等价无穷小就是麦克劳林展开式省略高次项的结果**。

- $\mathrm{e}^x=1+x+\frac{x^2}{2!}+\cdots$，略去高次项得 $\mathrm{e}^x-1\sim x$；
- $\ln(1+x)=x-\frac{x^2}{2}+\cdots$，略去高次项得 $\ln(1+x)\sim x$；保留到平方项再移项得 $x-\ln(1+x)\sim\frac{x^2}{2}$；
- $(1+x)^{\alpha}-1\sim\alpha x$；
- $\sin x\sim x$（$\cos x$ 同理，自行推导）。

"用不到那么高的一个精度……我们就把根据我们实际的一个极限，选取对应的等价公式。"

### 23. 幂级数展开的解题步骤（P127）

**核心思想**：所有题目都要把函数**配成六个"基础框架"**的样子，再套用对应展开式。基础框架（方框 $\Box$ 表示任意整体）：

$$\frac{1}{1-\Box},\qquad \frac{1}{1+\Box},\qquad \mathrm{e}^{\Box},\qquad \ln(1+\Box),\qquad \sin\Box,\qquad \cos\Box$$

**步骤：**

1. **配**：题目要求展开成 $(x-x_0)$ 的幂级数，就在原式中先把它配出来。**配出来之后 $(x-x_0)$ 就是一个整体，不能拆开**；
2. **选框架**：看配好的式子像哪个基础框架；
3. **套公式**：把框架中的 $\Box$ 整体替换，代入对应的麦克劳林展开式；
4. **整理**：把 $(x-x_0)^n$ 提到外面，系数合并（例如把 $\frac12$ 写成 $\frac{1}{2^{n+1}}$）；
5. **写范围**：由框架的取值范围 $-1<\Box<1$ 解出 $x$ 的取值范围。

> 书写细节：题目要求展开成谁，最后就**必须出现谁的 $n$ 次方**（如展开成 $x-2$ 的幂级数，答案里必须出现 $(x-2)^n$）。

## 三、例题精讲

### P118

#### 例 1 用定义法判断 $\sum\limits_{n=1}^{\infty}n$ 的敛散性

**解**：$S_n=1+2+\cdots+n=\dfrac{n(n+1)}{2}$，

$$\lim_{n\to\infty}S_n=\lim_{n\to\infty}\frac{n(n+1)}{2}=\infty$$

极限为无穷，**级数发散**。

#### 例 2 用定义法判断 $\sum\limits_{n=1}^{\infty}\dfrac{1}{n(n+1)}$ 的敛散性

**解**：先**裂项**。裂项方法：$\dfrac{1}{\text{大}\times\text{小}}=\dfrac{1}{\text{大}-\text{小}}\left(\dfrac{1}{\text{小}}-\dfrac{1}{\text{大}}\right)$，于是

$$\frac{1}{n(n+1)}=\frac1n-\frac{1}{n+1}$$

$$S_n=\left(1-\frac12\right)+\left(\frac12-\frac13\right)+\cdots+\left(\frac1n-\frac{1}{n+1}\right)=1-\frac{1}{n+1}$$

（每项的后半部分与下一项的前半部分首尾相消，只剩第一项和最后一项。）

$$\lim_{n\to\infty}S_n=\lim_{n\to\infty}\left(1-\frac{1}{n+1}\right)=1$$

极限为常数，**级数收敛于 $1$**。

#### 例 3 求等比级数 $\sum\limits_{n=1}^{\infty}\left(\dfrac12\right)^{n}$ 的和

**解**：公比 $q=\dfrac12$，首项 $u_1=\dfrac12$。由 $S_n=\dfrac{u_1(1-q^n)}{1-q}=\dfrac{\frac12\left(1-\frac{1}{2^n}\right)}{\frac12}=1-\dfrac{1}{2^n}$，

$$\lim_{n\to\infty}S_n=\lim_{n\to\infty}\left(1-\frac{1}{2^n}\right)=1$$

**级数收敛于 $1$**。

#### 课后作业（P118）

老师留了一道题（题面数值字幕不清），**答案：发散**，要求自己思考为什么发散。

### P119

#### 例 1 若级数发散，则（　）

A. 可能有 $\lim\limits_{n\to\infty}u_n=0$　　B. 一定有 $\lim\limits_{n\to\infty}u_n\ne0$
C. 一定有 $\lim\limits_{n\to\infty}u_n=0$　　D. 一定有 $\lim\limits_{n\to\infty}u_n=\infty$

**解**：选 **A**。发散不能反推出"一般项极限不为零"（发散不能反推）。其他三个选项都说得太绝对。举例：调和级数 $\sum\frac1n$ 发散但 $\lim\frac1n=0$。

#### 例 2 $\lim\limits_{n\to\infty}u_n=0$ 能推出什么结论？

**解**：什么结论都推不出来，选 **D（可能收敛，可能发散）**。

- 反例一：$\sum\dfrac1n$，$\lim\dfrac1n=0$，但**发散**（P 级数 $p=1$）；
- 反例二：$\sum\dfrac{1}{2^n}$，$\lim\dfrac{1}{2^n}=0$，且**收敛**（等比级数 $q=\frac12<1$）。

#### 例 3 判断 $\sum\limits_{n=1}^{\infty}\cos\dfrac1n$ 的敛散性

**解**：用逆否命题。$\lim\limits_{n\to\infty}\cos\dfrac1n=\cos 0=1\ne0$，故**级数发散**。

#### 例 4 判断通项为两个二次多项式之比的级数的敛散性

**解**：用逆否命题，对一般项**抓大头**求极限，得到一个**非零常数**，故**级数发散**。

> 字幕数值不清（分子分母的多项式系数前后不一致），此处只记方法：**多项式比值型 → 抓大头 → 非零常数 → 发散**。

### P120

#### 例 1（定义法）判断 $\sum\limits_{n=1}^{\infty}\left(\sqrt{n+1}-\sqrt{n}\right)$ 的敛散性

**解**：$u_n=\sqrt{n+1}-\sqrt n$。

$$S_n=(\sqrt2-\sqrt1)+(\sqrt3-\sqrt2)+\cdots+(\sqrt{n+1}-\sqrt n)=\sqrt{n+1}-1$$

（每项首尾相消，只剩第一项和最后一项。）

$$\lim_{n\to\infty}S_n=\lim_{n\to\infty}\left(\sqrt{n+1}-1\right)=\infty$$

**级数发散**。

> 老师点评：这种"两项相减"或"能裂项"的式子，都可以考虑用定义法。

#### 例 2（逆否命题）判断 $\sum\limits_{n=1}^{\infty}\sqrt[n]{n}$ 的敛散性

**解**：$\sqrt[n]{n}=n^{\frac1n}$，这是**无穷的零次方型**，用幂指函数的指数对数化：

$$\lim_{n\to\infty}n^{\frac1n}=\mathrm{e}^{\lim\limits_{n\to\infty}\frac{\ln n}{n}}$$

$\dfrac{\ln n}{n}$ 是 $\dfrac{\infty}{\infty}$ 型，用洛必达：$\lim\limits_{n\to\infty}\dfrac{\ln n}{n}=\lim\limits_{n\to\infty}\dfrac{\frac1n}{1}=0$，故

$$\lim_{n\to\infty}n^{\frac1n}=\mathrm{e}^{0}=1\ne0$$

一般项极限不为零，**级数发散**。

#### 例 3（逆否命题）判断 $\sum\limits_{n=1}^{\infty}\dfrac{n^2+n}{n^2-1}$ 的敛散性

**解**：抓大头得 $\lim\limits_{n\to\infty}\dfrac{n^2+n}{n^2-1}=1\ne0$，**级数发散**。

#### 例 4 等比级数的三个判断

1. $\sum\left(\dfrac32\right)^n$：$q=\dfrac32>1$，**发散**。
2. $\sum(-1)^n\left(\dfrac34\right)^n$：同指数幂相乘，底数相乘得 $q=-\dfrac34$，$\lvert q\rvert=\dfrac34<1$，**收敛**。
3. $\sum\dfrac{3^n+(-1)^n}{3^n}=\sum\left(\dfrac13\right)^n+\sum\left(-\dfrac13\right)^n$：拆成两个级数，$q_1=\dfrac13$、$q_2=-\dfrac13$，$\lvert q_1\rvert,\lvert q_2\rvert$ 都小于 $1$，两个都收敛，由"收敛 $+$ 收敛 $=$ 收敛"，**原级数收敛**。

#### 例 5 求收敛等比级数的和

1. $\sum\limits_{n=1}^{\infty}\left(\dfrac12\right)^n$：$q=\dfrac12$，首项 $u_1=\dfrac12$，

$$S=\frac{a_1}{1-q}=\frac{\frac12}{1-\frac12}=1$$

2. $\sum\left(\dfrac13\right)^n+\sum\left(\dfrac23\right)^n$：第一个 $S_1=\dfrac{\frac13}{1-\frac13}=\dfrac12$，第二个 $S_2=\dfrac{\frac23}{1-\frac23}=2$，

$$S=\frac12+2=\frac52$$

#### 例 6 P 级数的判断

1. $\sum\dfrac{1}{n^{3/2}}$：$p=\dfrac32>1$，**收敛**；
2. $\sum\dfrac{1}{n^{2/3}}$（平方开三次根式）：$p=\dfrac23<1$，**发散**；
3. $\sum\dfrac{1}{n^5}$：$p=5>1$，**收敛**；
4. $\sum\left(\dfrac{1}{2^n}+\dfrac1n\right)$：$\sum\dfrac{1}{2^n}$ 是等比级数（$q=\dfrac12$）**收敛**，$\sum\dfrac1n$ 是调和级数**发散**，由"收敛 $+$ 发散 $=$ 发散"，**原级数发散**。

### P121

#### 例 1（比值判别法）$\sum\limits_{n=1}^{\infty}\dfrac{2^n}{n!}$

**解**：$u_n=\dfrac{2^n}{n!}$，含指数形式与阶乘，用比值判别法。

$$\rho=\lim_{n\to\infty}\frac{u_{n+1}}{u_n}=\lim_{n\to\infty}\frac{2^{n+1}}{(n+1)!}\cdot\frac{n!}{2^n}=\lim_{n\to\infty}\frac{2}{n+1}=0<1$$

**级数收敛**。

#### 例 2（比值判别法，三兄弟齐全）通项同时含指数、幂指、阶乘的级数

**解**：$u_n$ 中同时出现 $2^n$、$n^n$、$n!$ 三种形式（字幕未清晰给出完整通项），比值判别法化简后得

$$\rho=\lim_{n\to\infty}2\left(\frac{n}{n+1}\right)^{n}=\frac{2}{\mathrm{e}}<1$$

（关键步骤：$2^{n+1}=2\cdot2^n$，$(n+1)!=(n+1)\cdot n!$，$(n+1)^{n+1}=(n+1)\cdot(n+1)^n$，约分后得到 $2\cdot\dfrac{n^n}{(n+1)^n}$。）

**级数收敛**。老师评："如果作为一个选项的话，不得不说计算量还是蛮高的。"

#### 例 3（比值判别法）$\sum\limits_{n=1}^{\infty}\dfrac{n^2}{3^n}$

**解**：

$$\rho=\lim_{n\to\infty}\frac{(n+1)^2}{3^{n+1}}\cdot\frac{3^n}{n^2}=\frac13\lim_{n\to\infty}\left(\frac{n+1}{n}\right)^2=\frac13<1$$

**级数收敛**。

#### 例 4（比值判别法）通项为幂函数与两个指数之比的级数

**解**：用比值判别法，化简后得

$$\rho=\lim_{n\to\infty}\frac43\cdot\left(\frac{n}{n+1}\right)^3=\frac43>1$$

**级数发散**。

> 字幕数值不清（分子分母的指数底数前后读法不一致），此处只记方法与结论 $\rho=\dfrac43>1\Rightarrow$ 发散。

#### 例 5（比值判别法）$\sum\limits_{n=1}^{\infty}2^n\sin\dfrac{\pi}{3^n}$

**解**：含指数形式，用比值判别法。当 $n\to\infty$ 时 $\dfrac{\pi}{3^{n+1}}\to0$，可用**广义等价** $\sin\dfrac{\pi}{3^{n+1}}\sim\dfrac{\pi}{3^{n+1}}$：

$$\rho=\lim_{n\to\infty}\frac{2^{n+1}\sin\frac{\pi}{3^{n+1}}}{2^n\sin\frac{\pi}{3^{n}}}=2\cdot\lim_{n\to\infty}\frac{\frac{\pi}{3^{n+1}}}{\frac{\pi}{3^{n}}}=\frac23<1$$

**级数收敛**。

> 关键提醒：$\sin$ 的等价要"看整体"——只要 $\sin$ 后面那个整体趋于 $0$，就可以等价。

#### 例 6（比值判别法，课后练习）通项分子为 $1\cdot3\cdot5\cdots(2n-1)$ 的级数

老师留作课后练习，**未给答案**，要求自己动手做（"如果大家做出了正确答案呢，可以把它打在这个弹幕上"）。

> 字幕数值不清（分母未清晰读出），此处只记方法：分子为奇数的连乘，宜与 $n!$ 或指数形式一起用比值判别法。

#### 例 7（比较形式）$\sum\limits_{n=1}^{\infty}\dfrac{\sin^2 n}{n^2}$

**解**：$\sin$ 是有界函数，放缩到最大 $1$：

$$\sin^2 n\le1\ \Longrightarrow\ \frac{\sin^2 n}{n^2}\le\frac{1}{n^2}$$

而 $\sum\dfrac{1}{n^2}$ 是 $p=2>1$ 的 P 级数，**收敛**。由"**大收则小收**"，原级数**收敛**。

> 字幕中正弦的自变量写作"$\sin^2 n\pi$"（若真为 $n\pi$ 则各项恒为 0），数值不清；此处只记方法：**遇到 $\sin$、$\cos$ 就放缩到 1**。

#### 例 8（比较形式）$\sum\limits_{n=1}^{\infty}\dfrac{1}{n+\ln n}$

**解**：利用 $\ln n<n$，把分母放大：

$$n+\ln n<2n\ \Longrightarrow\ \frac{1}{n+\ln n}>\frac{1}{2n}$$

而 $\sum\dfrac{1}{2n}=\dfrac12\sum\dfrac1n$ 是调和级数，**发散**（常数系数不影响敛散性）。由"**小发则大发**"，原级数**发散**。

#### 例 9（比较形式）$\sum\limits_{n=1}^{\infty}\dfrac{n\cos^2 n}{2^n}$

**解**：$\cos^2 n\le1$，故

$$\frac{n\cos^2 n}{2^n}\le\frac{n}{2^n}$$

对 $\sum\dfrac{n}{2^n}$ 用比值判别法：

$$\rho=\lim_{n\to\infty}\frac{n+1}{2^{n+1}}\cdot\frac{2^n}{n}=\frac12<1$$

**收敛**。由"**大收则小收**"，原级数**收敛**。

#### 例 10（极限形式·多项式）$\sum\limits_{n=1}^{\infty}\dfrac{n+1}{n^2+n}$

**解**：含多项式除法，取 $v_n=\dfrac1n$（只保留分子分母最高次幂：$\dfrac{n}{n^2}=\dfrac1n$）：

$$\lim_{n\to\infty}\frac{u_n}{v_n}=\lim_{n\to\infty}\frac{n+1}{n^2+n}\cdot n=\lim_{n\to\infty}\frac{n(n+1)}{n(n+1)}=1$$

比值为非零常数，两者**同敛散**。$\sum\dfrac1n$ 是调和级数**发散**，故原级数**发散**。

> 秒杀法：以后遇到多项式除法型，**只保留最高次幂**直接判断即可，比值极限必为常数。

#### 例 11（极限形式·多项式·秒杀）

保留最高次幂后得到形如 $\sum\dfrac{n^2}{n^3}=\sum\dfrac1n$ 的级数，**发散** $\Rightarrow$ 原级数**发散**。

#### 例 12（极限形式·多项式·秒杀）

保留最高次幂后得到 $\sum\dfrac{1}{n^2}$（$p=2$），**收敛** $\Rightarrow$ 原级数**收敛**。

#### 例 13（极限形式·多项式·秒杀）

保留最高次幂后得到 $\sum\dfrac{1}{n^{3/2}}$（$p=\dfrac32$），**收敛** $\Rightarrow$ 原级数**收敛**。

#### 例 14（极限形式·根式有理化）$\sum\left(\sqrt{n^2+1}-\sqrt{n^2-1}\right)$

**解**：先**根式有理化**（分子分母同乘 $\sqrt{n^2+1}+\sqrt{n^2-1}$）：

$$u_n=\frac{(n^2+1)-(n^2-1)}{\sqrt{n^2+1}+\sqrt{n^2-1}}=\frac{2}{\sqrt{n^2+1}+\sqrt{n^2-1}}$$

保留最高次幂：分母中 $\sqrt{n^2}+\sqrt{n^2}=2n$，得 $v_n=\dfrac{2}{2n}=\dfrac1n$，为调和级数**发散**，故原级数**发散**。

#### 例 15（极限形式·等价无穷小）$\sum\limits_{n=1}^{\infty}\sin\dfrac1n$

**解**：$n\to\infty$ 时 $\dfrac1n\to0$，故 $\sin\dfrac1n\sim\dfrac1n$。取 $v_n=\dfrac1n$，

$$\lim_{n\to\infty}\frac{u_n}{v_n}=\lim_{n\to\infty}n\sin\frac1n=1$$

非零常数，同敛散。调和级数发散，故原级数**发散**。

#### 例 16（极限形式·等价无穷小）$\sum\limits_{n=1}^{\infty}\ln\left(1+\dfrac{1}{n^2}\right)$

**解**：$n\to\infty$ 时 $\ln\left(1+\dfrac{1}{n^2}\right)\sim\dfrac{1}{n^2}$，等价级数为 $p=2$ 的 P 级数，**收敛**，故原级数**收敛**。

#### 例 17（极限形式·等价无穷小）$\sum\limits_{n=1}^{\infty}\left(1-\cos\dfrac1n\right)$

**解**：$n\to\infty$ 时 $1-\cos\dfrac1n\sim\dfrac12\cdot\dfrac{1}{n^2}$，等价级数为 $\dfrac12\sum\dfrac{1}{n^2}$（$p=2$），**收敛**，故原级数**收敛**。

#### 例 18（极限形式·等价无穷小）通项含 $2^{1/n}$ 与对数的级数

**解**：先作恒等变形（把对数中的指数提到前面），再用等价无穷小，等价出形如 $\sum\dfrac{1}{4n^2}$ 的级数（$p=2$，**收敛**），故原级数**收敛**。

> 字幕数值不清（对数真数与 $2^{1/n}$ 的写法前后不一致），此处只记方法：**先恒等变形 → 再用等价无穷小 → 判断等价后的 P 级数**。

#### 例 19（极限形式·等价无穷小）通项含 $\sqrt{n}$ 与 $n$ 次根式的级数

**解**：取 $v_n=\dfrac1n$，利用重要极限 $\lim\limits_{n\to\infty}\sqrt[n]{n}=1$（用幂指函数指数对数化 + 洛必达可得），得

$$\lim_{n\to\infty}\frac{u_n}{v_n}=1$$

为非零常数，两者同敛散。$v_n$ 为调和级数**发散**，故原级数**发散**。

> 字幕数值不清（通项形式未完整读出），此处只记方法：**关键是要先知道 $\lim\limits_{n\to\infty}\sqrt[n]{n}=1$，才找得到 $v_n=\dfrac1n$**。

#### 例 20（极限形式·等价无穷小）$\sum\limits_{n=1}^{\infty}2^n\sin\dfrac{\pi}{3^n}$（与例 5 同题，换方法）

**解**：$n\to\infty$ 时 $\sin\dfrac{\pi}{3^n}\sim\dfrac{\pi}{3^n}$，等价级数为

$$\sum\pi\left(\frac23\right)^n$$

这是公比 $q=\dfrac23<1$ 的等比级数，**收敛**，故原级数**收敛**。

> 老师点评：同一道题往往可用多种方法，**选自己最熟的那种**（"这就像我们以前所学积分的时候……一个题目可以用多种方法去进行求解"）。

#### 例 21（根值判别法）$\sum\left(\dfrac{n}{2n+1}\right)^n$

**解**：含 $n$ 次方，用根值判别法：

$$\rho=\lim_{n\to\infty}\sqrt[n]{\left(\frac{n}{2n+1}\right)^n}=\lim_{n\to\infty}\frac{n}{2n+1}=\frac12<1$$

**级数收敛**。

#### 例 22（根值判别法）含 $\left(1+\dfrac{1}{2n+1}\right)^{n^2}$ 的级数

**解**：用根值判别法，$\rho=\lim\limits_{n\to\infty}\left(1+\dfrac{1}{2n+1}\right)^{n}=\mathrm{e}^{1/2}=\sqrt{\mathrm{e}}>1$，**级数发散**。

> 字幕中底数与指数的写法不清，此处只记方法与结论：$\rho=\sqrt{\mathrm e}>1\Rightarrow$ 发散。

#### 例 23（根值判别法）$\sum\left[\ln\left(1+\dfrac1n\right)\right]^n$

**解**：

$$\rho=\lim_{n\to\infty}\sqrt[n]{\left[\ln\left(1+\frac1n\right)\right]^n}=\lim_{n\to\infty}\ln\left(1+\frac1n\right)=0<1$$

**级数收敛**。

### P122

#### 例 1（交错级数）$\sum\limits_{n=1}^{\infty}(-1)^{n-1}\dfrac1n$

**解**：取 $u_n=\dfrac1n$（不含 $(-1)^{n-1}$）。

1. 单调性：$u_{n+1}=\dfrac{1}{n+1}<\dfrac1n=u_n$ ✓
2. 趋零：$\lim\limits_{n\to\infty}\dfrac1n=0$ ✓

满足莱布尼茨定理两个条件，**级数收敛**。

#### 例 2（交错级数）$\sum(-1)^{n-1}\dfrac{n}{n+1}$

**解**：$u_n=\dfrac{n}{n+1}$，$u_{n+1}=\dfrac{n+1}{n+2}$。

1. 单调性：作差

$$u_{n+1}-u_n=\frac{n+1}{n+2}-\frac{n}{n+1}=\frac{(n+1)^2-n(n+2)}{(n+1)(n+2)}=\frac{1}{(n+1)(n+2)}>0$$

故 $u_{n+1}>u_n$，**不满足**第一个条件（也可用"$\frac23\to\frac34$ 变大"直观判断）。

2. 趋零：$\lim\limits_{n\to\infty}\dfrac{n}{n+1}=1\ne0$，**不满足**第二个条件。

**级数发散**。

> 做题技巧：只要极限不为零，就能直接判不满足莱布尼茨定理，不必再算单调性。

#### 例 3（交错级数）通项含 $\ln\left(1+\dfrac1n\right)$ 的交错级数

**解**：取不含 $(-1)^n$ 的部分作 $u_n$，利用对数函数的单调性判断单调递减，且极限为 $0$，两个条件都满足，**级数收敛**。

> 字幕表述不清（读作"$\ln(1+1/n)$ 分之一"，但随即又说 $\ln(1+1/n)$ 趋于无穷），此处只记方法与结论：**满足莱布尼茨两条件 $\Rightarrow$ 收敛**。

#### 例 4（任意项级数·真题）$\sum\limits_{n=1}^{\infty}\dfrac{(-1)^n}{\sqrt n}$

**Step 1（加绝对值）**：$\sum\left\lvert\dfrac{(-1)^n}{\sqrt n}\right\rvert=\sum\dfrac{1}{n^{1/2}}$，这是 $p=\dfrac12<1$ 的 P 级数，**发散**，需进入 Step 2。

**Step 2（判断原级数）**：原级数是交错级数，取 $u_n=\dfrac{1}{\sqrt n}$。

1. $\dfrac{1}{\sqrt{n+1}}<\dfrac{1}{\sqrt n}$ ✓
2. $\lim\limits_{n\to\infty}\dfrac{1}{\sqrt n}=0$ ✓

满足莱布尼茨定理，原级数**收敛**。

**结论：条件收敛**（选 B）。

#### 例 5（任意项级数·真题）$\sum(-1)^n\tan\dfrac{\pi}{n^3}$

**Step 1（加绝对值）**：$n\to\infty$ 时 $\tan\dfrac{\pi}{n^3}\sim\dfrac{\pi}{n^3}$，等价级数为 $p=3>1$ 的 P 级数，**收敛**。

**结论：绝对收敛**（选 A），无需进入 Step 2。

#### 例 6（任意项级数·真题）$\sum\dfrac{\cos n}{1+n^2}$

**解**：虽然没有 $(-1)^n$，但 $\cos n$ 随 $n$ 取值可正可负（$n=1$ 时 $\cos1>0$，$n=2$ 时 $\cos2<0$），起到与 $(-1)^n$ 相同的作用。

**Step 1（加绝对值）**：$\lvert\cos n\rvert\le1$，故

$$\frac{\lvert\cos n\rvert}{1+n^2}\le\frac{1}{1+n^2}$$

用极限形式比较判别法，保留最高次幂得 $\dfrac{1}{n^2}$（$p=2$，**收敛**）；由"**大收则小收**"，$\sum\dfrac{\lvert\cos n\rvert}{1+n^2}$ **收敛**。

**结论：绝对收敛**（选 A）。

> 老师点评：这道题把比较形式（放缩）、极限形式（保留最高次幂）、P 级数全串起来了，"大家一定要把前面的学好"。

### P123

#### 例 1 求 $\sum\limits_{n=1}^{\infty}(-1)^n\dfrac{x^n}{n}$ 的收敛区间、收敛半径、收敛域

**解**：$u_n(x)=(-1)^n\dfrac{x^n}{n}$。

**第一步**（注意绝对值不能丢，$(-1)^n$ 加绝对值后等于 1，可直接丢掉）：

$$\rho(x)=\lim_{n\to\infty}\left\lvert\frac{u_{n+1}(x)}{u_n(x)}\right\rvert=\lim_{n\to\infty}\left\lvert\frac{x^{n+1}}{n+1}\cdot\frac{n}{x^n}\right\rvert=\lim_{n\to\infty}\frac{n}{n+1}\lvert x\rvert=\lvert x\rvert$$

（求极限时 $x$ 是常数，抓大头得系数之比 $x$。）令 $\lvert x\rvert<1$，解得

**收敛区间**：$(-1,1)$；**收敛半径**：$R=\dfrac{1-(-1)}{2}=1$。

**第四步（端点）**：

- $x=-1$：$\sum(-1)^n\dfrac{(-1)^n}{n}=\sum\dfrac1n$，调和级数，**发散**；
- $x=1$：$\sum(-1)^n\dfrac1n$，交错级数，满足莱布尼茨定理，**收敛**（由阿贝尔定理知是**条件收敛**）。

**收敛域**：$(-1,1]$。

> 验证阿贝尔定理：端点 $x=1$ 收敛，加绝对值后 $\sum\frac1n$ 发散，确实是条件收敛。收敛域 = 绝对收敛范围 $\cup$ 条件收敛点（**取并集**）。

#### 例 2 求 $\sum\dfrac{(2x-1)^n}{n}$ 的收敛区间、收敛半径、收敛域

**解**：

$$\rho(x)=\lim_{n\to\infty}\left\lvert\frac{(2x-1)^{n+1}}{n+1}\cdot\frac{n}{(2x-1)^n}\right\rvert=\lvert2x-1\rvert$$

令 $\lvert2x-1\rvert<1$，即 $-1<2x-1<1$，两边加 $1$ 得 $0<2x<2$，再除以 $2$：

**收敛区间**：$(0,1)$；**收敛半径**：$R=\dfrac{1-0}{2}=\dfrac12$。

**端点**：

- $x=0$：$2x-1=-1$，得 $\sum\dfrac{(-1)^n}{n}$，**条件收敛** $\Rightarrow$ 取闭；
- $x=1$：$2x-1=1$，得 $\sum\dfrac1n$，**发散** $\Rightarrow$ 取开。

**收敛域**：$[0,1)$。

#### 例 3（练习）求收敛区间、收敛半径、收敛域

**答案**：收敛区间 $(-2,4)$，收敛半径 $R=3$，两个端点都发散，收敛域为 $(-2,4)$。

#### 例 4（真题）求 $\sum\left(1+\dfrac1n\right)^{n^2}x^n$ 的收敛区间、收敛半径

**解**：$u_n(x)$ 含 $n$ 次方，用根值形式：

$$\rho(x)=\lim_{n\to\infty}\sqrt[n]{\left\lvert\left(1+\frac1n\right)^{n^2}x^n\right\rvert}=\lim_{n\to\infty}\left(1+\frac1n\right)^{n}\lvert x\rvert=\mathrm{e}\lvert x\rvert$$

（$\lim\limits_{n\to\infty}\left(1+\frac1n\right)^n=\mathrm{e}$ 是第二重要极限。）令 $\mathrm{e}\lvert x\rvert<1$，即 $\lvert x\rvert<\dfrac1{\mathrm e}$：

**收敛区间**：$\left(-\dfrac1{\mathrm e},\dfrac1{\mathrm e}\right)$；**收敛半径**：$R=\dfrac1{\mathrm e}$。

> 老师提醒：求 $\rho(x)$ 时**绝对值的符号不能去掉**，"这个绝对值一定要加上，千万不要搞掉了"。

#### 例 5（练习）求 $\sum\dfrac{x^n}{n}+\sum\dfrac{x^n}{4^n}$ 的收敛区间、收敛半径

**答案**：第一个级数收敛区间 $(-1,1)$，第二个级数收敛区间 $(-4,4)$，两个级数相加只能取**交集**：

**收敛区间** $(-1,1)$，**收敛半径** $R=1$（取小的那个）。

### P124

> P124 是**阿贝尔定理**专项课，主题是"已知一个幂级数的敛散性，讨论另一个幂级数的敛散性"。
> **做题三步**：① 找收敛区间中心点 → ② 画数轴定出收敛区间 → ③ 看目标点落在区间内还是外。

**例 1（P124）** 设幂级数 $\sum\limits_{n=0}^{\infty}a_nx^n$ 在 $x=2$ 处收敛，则它在 $x=-1$ 处（　）。

**解**

- **第一步 找中心点**：括号里只有 $x$，令 $x=0$ ⇒ 中心点 $x=0$；
- **第二步 画数轴**：$x=2$ 处收敛 ⇒ $2$ 必落在收敛区间内 ⇒ 右端点 $b>2$，由对称性左端点 $a<-2$；
- **第三步 判断**：$x=-1$ 满足 $-2<-1<2$ ⇒ 落在**区间内部** ⇒ **绝对收敛**。

> ⚠️ 老师口述这道题时先说成"在 $x=1$ 处收敛"，但**后续分析全程按 $x=2$ 进行**（原话："这个 2 它一定是在收敛区间的范围内"）。若真是 $x=1$ 收敛，则 $x=-1$ 只能判定为"不确定"（$-1$ 可能是端点）。**此处按分析过程记为 $x=2$**，照实记录这处口述不一致。

**例 2（P124）** 若级数 $\sum\limits_{n=0}^{\infty}a_n3^n$ 收敛，则级数 $\sum\limits_{n=0}^{\infty}a_n(-2)^n$（　）。

**解**：把条件**翻译**成幂级数的语言 —— $\sum a_n3^n$ 就是 $\sum a_nx^n$ 在 $x=3$ 处的值，所以条件等价于"$\sum a_nx^n$ 在 $x=3$ 处收敛"。

- 中心点 $x=0$；$3$ 收敛 ⇒ 右端点 $b>3$、左端点 $a<-3$；
- 目标 $\sum a_n(-2)^n$ 是 $\sum a_nx^n$ 在 $x=-2$ 处的值；而 $-3<-2<3$ ⇒ 落在**区间内部** ⇒ **绝对收敛**。

**例 3（P124，填空）** 若幂级数 $\sum\limits_{n=0}^{\infty}a_n(x-2)^n$ 在 $x=3$ 处**条件收敛**，则 $\sum\limits_{n=0}^{\infty}a_nx^n$ 的收敛区间是 ______。

**解**

- **条件收敛 ⇒ 该点必是端点**（阿贝尔定理第三条逆用）。$x=3$ 是端点，中心点是 $x=2$，由对称性另一端点是 $x=1$；
- 所以 $\sum a_n(x-2)^n$ 的收敛区间是 $(1,3)$，**收敛半径 $R=1$**；
- 目标级数 $\sum a_nx^n$ 是把原级数的 $x$ 换成 $x+2$（$(x+2)-2=x$）得到的 ⇒ **左平移 2 个单位** ⇒ 半径不变、区间跟着 $x$ 左移 2 ⇒ **$(-1,1)$**。

**例 4（P124，填空）** 已知 $\sum\limits_{n=0}^{\infty}a_nx^n$ 的收敛半径为 $2$，则 $\sum\limits_{n=0}^{\infty}na_n(x-1)^n$ 的收敛区间是 ______。

**解**

- 中心点 $x=0$、半径 $2$ ⇒ 原收敛区间 $(-2,2)$；
- 目标级数做了两处改动：**右平移 1 个单位**（$x\to x-1$）＋**逐项求导**（$a_n\to na_n$）；
- 求导**不改变**半径、也不改变区间；平移改变区间（跟着 $x$ 走）；
- 所以 $(-2,2)$ 右移 1 ⇒ **$(-1,3)$**。

**例 5（P124）** 若 $\sum\limits_{n=0}^{\infty}a_n(x+1)^n$ 在 $x=1$ 处条件收敛，则 $\sum\limits_{n=0}^{\infty}na_n(x-1)^n$ 在 $x=2$ 处（　）。

**解**

- 中心点：令 $x+1=0$ ⇒ $x=-1$；$x=1$ 条件收敛 ⇒ $1$ 是端点 ⇒ 由对称性另一端点为 $-3$ ⇒ 原收敛区间 $(-3,1)$、$R=2$；
- 目标级数的变换：$x\to x-2$（$(x-2)+1=x-1$）⇒ **右平移 2 个单位**，区间变 $(-1,3)$；再**逐项求导**（$a_n\to na_n$）⇒ 区间**不变**，仍 $(-1,3)$；
- 判断 $x=2$：$-1<2<3$ ⇒ 落在**区间内部** ⇒ **绝对收敛**。

> **本节做题主线**（老师原话）："找中心点，然后去找这个收敛的区间，然后根据收敛区间，去做进一步的分析。"


### P125

> P125 是**和函数之先导后积型**的专项课。**贯穿全节的一句话**：先导后积 —— 求导是为了干掉分式。

**例 1（P125）** 求 $\sum\limits_{n=1}^{\infty}\dfrac{x^n}{n}$ 的收敛域与和函数，并求 $\sum\limits_{n=1}^{\infty}\dfrac{1}{n\cdot2^n}$。

**解**

- ① 收敛域：$R=1$；$x=1$ 时为调和级数（发散），$x=-1$ 时为交错调和级数（收敛）⇒ 收敛域 $(-1,1)$；
- ② 令 $S(x)=\sum\limits_{n=1}^{\infty}\dfrac{x^n}{n}$；
- ③ 两边求导：$S'(x)=\sum\limits_{n=1}^{\infty}x^{n-1}$（$\dfrac1n\cdot n=1$，分式被干掉）；
- ④ 用公式：公比 $q=x$、首项（$n=1$ 时 $x^0$）$=1$ ⇒ $S'(x)=\dfrac{1}{1-x}$；
- ⑤ 两边积分：$\displaystyle\int_0^xS'(t)\,\mathrm{d}t=S(x)-S(0)$，且 $S(0)=0$；
- ⑥ 所以

$$S(x)=\int_0^x\frac{\mathrm{d}t}{1-t}=-\ln(1-x),\qquad x\in(-1,1)$$

**求常数项级数**：令 $x=\dfrac12$ ⇒ $\displaystyle\sum_{n=1}^{\infty}\frac{1}{n\cdot2^n}=S\!\left(\frac12\right)=-\ln\frac12=\ln2$。

> 老师原话："和函数求出来之后，其实还有一个小问，就是问这个级数的和等于多少。" —— **先用和函数求出 $S(x)$，再把具体的 $x$ 代进去**，这是这类题的固定套路。

**例 2（P125，有难度）** 求 $\sum\limits_{n=1}^{\infty}\dfrac{(-1)^{n-1}}{2n-1}x^{2n}$ 的收敛域与和函数。

**解**

$$S_1(x)=\int_0^x\frac{\mathrm{d}t}{1+t^2}=\arctan x$$

- ⑥ 所以

$$S(x)=xS_1(x)=x\arctan x,\qquad x\in[-1,1]$$

### P126

#### 例 1（先积后导·题源）$\sum\limits_{n=1}^{\infty}nx^{n-1}$，并求 $\sum\limits_{n=1}^{\infty}\dfrac{n}{2^n}$

**解**：$a_n=n$ 是整式，用先积后导。收敛域为 $(-1,1)$（由比值判别法求得）。

设 $S(x)=\sum\limits_{n=1}^{\infty}nx^{n-1}$，两边在 $0$ 到 $x$ 上积分（下限取收敛中心 $0$）：

$$\int_0^x S(t)\,\mathrm{d}t=\sum_{n=1}^{\infty}n\int_0^x t^{n-1}\,\mathrm{d}t=\sum_{n=1}^{\infty}x^{n}=\frac{x}{1-x}$$

（最后一个等号用"一减公比分之首项"：公比 $q=x$，首项 $a_1=x$。）

两边再对 $x$ 求导：

$$S(x)=\left(\frac{x}{1-x}\right)'=\frac{1\cdot(1-x)-x\cdot(-1)}{(1-x)^2}=\frac{1}{(1-x)^2}$$

**和函数**：$S(x)=\dfrac{1}{(1-x)^2}$，$x\in(-1,1)$。

**第二问**：$\sum\limits_{n=1}^{\infty}\dfrac{n}{2^n}=\sum\limits_{n=1}^{\infty}n\left(\dfrac12\right)^{n}=\dfrac12\sum\limits_{n=1}^{\infty}n\left(\dfrac12\right)^{n-1}=\dfrac12 S\left(\dfrac12\right)$

$$=\frac12\cdot\frac{1}{\left(1-\frac12\right)^2}=\frac12\cdot4=2$$

> 配凑思路：看到 $\dfrac{n}{2^n}$，把 $\dfrac{1}{2^n}$ 写成 $\dfrac12\cdot\dfrac{1}{2^{n-1}}$，凑出 $n\cdot\left(\dfrac12\right)^{n-1}$，即 $S\left(\dfrac12\right)$。

#### 例 2（先积后导·基于题源）$\sum\limits_{n=1}^{\infty}nx^{n}$

**解**：先提一个 $x$ 出去（$x$ 与求和变量 $n$ 无关，可提到求和号外）：

$$\sum_{n=1}^{\infty}nx^n=x\sum_{n=1}^{\infty}nx^{n-1}=x\cdot\frac{1}{(1-x)^2}$$

**和函数**：$S(x)=\dfrac{x}{(1-x)^2}$，$x\in(-1,1)$。

> 老师强调例 1 是"**题源**"：后面好几道题都是在它的基础上做变形（"如果大家能够把这个题搞清楚的话，那么后面的好几个题大家都能够迎刃而解"）。

#### 例 3（先积后导·真题）$\sum\limits_{n=1}^{\infty}n(n+1)x^{n}$

**解**：这里指数是 $n$，因式是 $n(n+1)$，而 $n(n+1)-1\ne n$，所以要先提出 $x^2$，把它配成"指数 $=$ 因式 $-1$"的形式：

$$S(x)=\sum_{n=1}^{\infty}n(n+1)x^n=x^2\sum_{n=1}^{\infty}n(n+1)x^{n-2}$$

先在 $0$ 到 $x$ 上积分：

$$\int_0^x S(t)\,\mathrm{d}t=\sum_{n=1}^{\infty}n(n+1)\int_0^x t^{n}\,\mathrm{d}t=\sum_{n=1}^{\infty}n\,x^{n+1}=x^2\sum_{n=1}^{\infty}nx^{n-1}=\frac{x^2}{(1-x)^2}$$

再对两边求导（右边用商的求导法则）：

$$S(x)=\left(\frac{x^2}{(1-x)^2}\right)'=\frac{2x(1-x)^2-x^2\cdot2(1-x)\cdot(-1)}{(1-x)^4}=\frac{2x(1-x)+2x^2}{(1-x)^3}=\frac{2x}{(1-x)^3}$$

**和函数**：$S(x)=\dfrac{2x}{(1-x)^3}$，$x\in(-1,1)$。

#### 例 4（特殊题型）$\sum\limits_{n=0}^{\infty}\dfrac{x^n}{n!}$

**解**：含阶乘，用逐项求导。展开：$1+x+\dfrac{x^2}{2!}+\dfrac{x^3}{3!}+\cdots$

设 $S(x)=\sum\limits_{n=0}^{\infty}\dfrac{x^n}{n!}$，逐项求导：

$$S'(x)=0+1+\frac{2x}{2!}+\frac{3x^2}{3!}+\cdots+\frac{nx^{n-1}}{n!}+\cdots$$

注意到 $\dfrac{2}{2!}=1$、$\dfrac{3}{3!}=\dfrac{1}{2!}$、$\dfrac{n}{n!}=\dfrac{1}{(n-1)!}$，故

$$S'(x)=1+x+\frac{x^2}{2!}+\cdots+\frac{x^{n-1}}{(n-1)!}+\cdots=S(x)$$

即得微分方程 $S'-S=0$，这是一阶线性微分方程 $y'+P(x)y=Q(x)$ 中 $P(x)=-1$、$Q(x)=0$ 的情形，解得 $S=C\mathrm{e}^{x}$。

由 $S(0)=1$（代入级数只有第一项 $1$），得 $C=1$。

**和函数**：$S(x)=\mathrm{e}^{x}$。

> 这就是 $\mathrm{e}^x$ 的麦克劳林展开式，是后面幂级数展开必须背诵的公式。

#### 例 5（特殊题型·进阶）$\sum\limits_{n=0}^{\infty}\dfrac{(n+1)x^n}{n!}$

**解**：拆成两项：

$$S(x)=\sum_{n=0}^{\infty}\frac{nx^n}{n!}+\sum_{n=0}^{\infty}\frac{x^n}{n!}$$

后一项即 $\mathrm{e}^x$。前一项中，$n=0$ 时该项为 $0$，所以可**拆出第一项**后从 $n=1$ 开始：

$$\sum_{n=0}^{\infty}\frac{nx^n}{n!}=0+\sum_{n=1}^{\infty}\frac{nx^n}{n!}=\sum_{n=1}^{\infty}\frac{x^n}{(n-1)!}=x\sum_{n=1}^{\infty}\frac{x^{n-1}}{(n-1)!}$$

（用 $n!=n\cdot(n-1)!$ 约掉 $n$。）作换元 $n-1=k$，$n$ 从 $1$ 起对应 $k$ 从 $0$ 起：

$$=x\sum_{k=0}^{\infty}\frac{x^{k}}{k!}=x\mathrm{e}^{x}$$

**和函数**：$S(x)=x\mathrm{e}^{x}+\mathrm{e}^{x}$。

> 关键点：**必须先把 $n=0$ 那一项拆出来**，否则约分后会出现 $(n-1)!$ 在 $n=0$ 处变成 $(-1)!$，"我们只学过正整数的阶乘，没有学过负整数的阶乘"。

### P127

#### 例 1 把 $\dfrac1x$ 展开成 $(x-2)$ 的幂级数

**解**：

**第一步（配）**：把 $x$ 写成 $2+(x-2)$，则

$$f(x)=\frac{1}{x}=\frac{1}{2+(x-2)}$$

**第二步（选框架并配）**：形如 $\dfrac{1}{1+\Box}$，提出 $\dfrac12$：

$$=\frac12\cdot\frac{1}{1+\dfrac{x-2}{2}}$$

**第三步（套公式）**：$\dfrac{1}{1+\Box}=\sum\limits_{n=0}^{\infty}(-1)^n\Box^{n}$，其中 $\Box=\dfrac{x-2}{2}$：

$$f(x)=\frac12\sum_{n=0}^{\infty}(-1)^n\left(\frac{x-2}{2}\right)^{n}=\sum_{n=0}^{\infty}\frac{(-1)^n}{2^{n+1}}(x-2)^{n}$$

**第四步（范围）**：由 $-1<\dfrac{x-2}{2}<1$，两边乘 $2$ 得 $-2<x-2<2$，再加 $2$：

$$0<x<4$$

> 书写要点：展开成 $(x-2)$ 的幂级数，答案里**必须出现 $(x-2)^n$**。

#### 例 2 把 $\dfrac{1}{(x-1)(x+3)}$ 展开成 $x$ 的幂级数

**解**：

**第一步（因式分解 + 拆项）**：分母已是因式形式，用**待定系数法**拆成两项：

$$\frac{1}{(x-1)(x+3)}=\frac{A}{x-1}+\frac{B}{x+3}$$

通分得 $\dfrac{A(x+3)+B(x-1)}{(x-1)(x+3)}=\dfrac{(A+B)x+(3A-B)}{(x-1)(x+3)}$，与原式分子（常数 $1$）比较：

$$A+B=0,\qquad 3A-B=1$$

解得 $A=\dfrac14$，$B=-\dfrac14$。故

$$f(x)=\frac14\left(\frac{1}{x-1}-\frac{1}{x+3}\right)$$

**第二步（配框架）**：

$$\frac{1}{x-1}=-\frac{1}{1-x},\qquad \frac{1}{x+3}=\frac13\cdot\frac{1}{1+\frac{x}{3}}$$

**第三步（套公式）**：

$$f(x)=\frac14\left[-\sum_{n=0}^{\infty}x^{n}-\frac13\sum_{n=0}^{\infty}(-1)^n\left(\frac{x}{3}\right)^{n}\right]$$

整理后

$$f(x)=-\frac14\sum_{n=0}^{\infty}x^{n}-\frac14\sum_{n=0}^{\infty}\frac{(-1)^n}{3^{n+1}}x^{n}$$

**第四步（范围）**：$(-1,1)$ 与 $(-3,3)$ 取交集，得

$$-1<x<1$$

> 老师点评：分母是二次多项式（因式分解后拆成两项）的题型，很多省份都考过。

#### 例 4 把 $\mathrm{e}^{x}$ 展开成 $(x-3)$ 的幂级数

**解**：配出 $x-3$：

$$\mathrm{e}^{x}=\mathrm{e}^{3+(x-3)}=\mathrm{e}^{3}\cdot\mathrm{e}^{x-3}$$

框架为 $\mathrm{e}^{\Box}$（$\Box=x-3$），套用 $\mathrm{e}^{\Box}=\sum\limits_{n=0}^{\infty}\dfrac{\Box^{n}}{n!}$：

$$\mathrm{e}^{x}=\sum_{n=0}^{\infty}\frac{\mathrm{e}^{3}}{n!}(x-3)^{n}$$

范围：$-\infty<x<+\infty$。

> 这种题"通常在填空题里面出现"。

#### 例 5 把 $2^{x}$ 展开成 $(x-1)$ 的幂级数

**解**：底数是 $2$，要先用**幂指函数的指数对数化**（$A=\mathrm{e}^{\ln A}$）：

$$2^{x}=2^{1+(x-1)}=2\cdot2^{x-1}=2\cdot\mathrm{e}^{\ln 2\cdot(x-1)}$$

框架为 $\mathrm{e}^{\Box}$（$\Box=(x-1)\ln2$）：

$$2^{x}=2\sum_{n=0}^{\infty}\frac{(x-1)^{n}(\ln 2)^{n}}{n!}=\sum_{n=0}^{\infty}\frac{2(\ln 2)^{n}}{n!}(x-1)^{n}$$

范围：$-\infty<x<+\infty$。

#### 例 6 把 $\ln x$ 展开成 $(x-2)$ 的幂级数

**解**：配出 $x-2$，把真数凑成 $1+\Box$ 的形式：

$$\ln x=\ln\left(2+(x-2)\right)=\ln\left[2\left(1+\frac{x-2}{2}\right)\right]=\ln 2+\ln\left(1+\frac{x-2}{2}\right)$$

框架为 $\ln(1+\Box)$（$\Box=\dfrac{x-2}{2}$），套用 $\ln(1+\Box)=\sum\limits_{n=1}^{\infty}(-1)^{n-1}\dfrac{\Box^{n}}{n}$：

$$\ln x=\ln 2+\sum_{n=1}^{\infty}\frac{(-1)^{n-1}}{n\cdot 2^{n}}(x-2)^{n}$$

范围：由 $-1<\dfrac{x-2}{2}\le1$ 得

$$0<x\le4$$

#### 例 9（真题·浙江）把 $\arctan x$ 展开成 $x$ 的幂级数，并求数项级数的和

**解**：$\arctan x$ 本身不好直接展开，但从它的**导数**入手（"如果你不熟悉一个函数，那么你就从它的导数，或者说从它的积分入手"）：

$$(\arctan x)'=\frac{1}{1+x^{2}}$$

把 $x^2$ 看作整体，用框架 $\dfrac{1}{1+\Box}$：

$$\frac{1}{1+x^2}=\sum_{n=0}^{\infty}(-1)^{n}(x^{2})^{n}=\sum_{n=0}^{\infty}(-1)^{n}x^{2n}$$

**两边从 $0$ 到 $x$ 积分**：

$$\int_0^x(\arctan t)'\,\mathrm{d}t=\int_0^x\sum_{n=0}^{\infty}(-1)^{n}t^{2n}\,\mathrm{d}t$$

左边 $=\arctan x-\arctan 0=\arctan x$（$\arctan 0=0$），右边逐项积分：

$$\arctan x=\sum_{n=0}^{\infty}(-1)^{n}\frac{x^{2n+1}}{2n+1}$$

**范围**：把端点代入原级数，得到的是**交错级数**（可用莱布尼茨定理判定为条件收敛），故端点可以取到：

$$-1\le x\le1$$

> 老师强调：**积分或求导之后，两个端点的敛散性可能会发生变化，必须重新判定端点**（"这种比较细节的点是很多同学没有去关注的"）。

**求数项级数的和**（浙江真题）：把待求的数项级数配成 $x=\dfrac{1}{\sqrt3}$ 时的展开式，前面部分用"一减公比分之首项"求和：

$$\text{和}=\frac12\cdot\frac{1}{1-\left(-\frac13\right)}-\frac{\sqrt3}{2}\arctan\frac{1}{\sqrt3}=\frac38-\frac{\sqrt3}{12}\pi$$

（因为 $\tan\dfrac{\pi}{6}=\dfrac{1}{\sqrt3}$，所以 $\arctan\dfrac{1}{\sqrt3}=\dfrac{\pi}{6}$。）

#### 例 10（真题·河南）把 $\dfrac{1}{x^{2}}$ 展开成 $(x-2)$ 的幂级数

**解**：直接展开 $\dfrac{1}{x^2}$ 不容易，但 $\left(\dfrac1x\right)'=-\dfrac{1}{x^2}$，所以**先展开 $\dfrac1x$**（与例 1 相同）：

$$\frac1x=\frac{1}{2+(x-2)}=\frac12\cdot\frac{1}{1+\frac{x-2}{2}}=\sum_{n=0}^{\infty}\frac{(-1)^{n}}{2^{n+1}}(x-2)^{n}\qquad(0<x<4)$$

**两边求导**：

$$-\frac{1}{x^{2}}=\sum_{n=1}^{\infty}\frac{(-1)^{n}n}{2^{n+1}}(x-2)^{n-1}$$

移项整理得

$$\frac{1}{x^{2}}=\sum_{n=1}^{\infty}\frac{(-1)^{n+1}n}{2^{n+1}}(x-2)^{n-1}$$

**端点判定**：把 $x=0$、$x=4$ 分别代入，两个端点的级数都**发散**，故范围仍为

$$0<x<4$$

## 四、易错点警示

| ❌ 易错 | ✅ 正确 |
|:---|:---|
| 认为 $\lim\limits_{n\to\infty}u_n=0$ 就说明级数收敛 | 只能由"收敛"推"一般项极限为 0"，反向绝对错误（反例：调和级数 $\sum\frac1n$） |
| 把等比级数与 P 级数的结论记混 | 等比级数：$\lvert q\rvert<1$ 收敛、$\lvert q\rvert\ge1$ 发散；P 级数：$p>1$ 收敛、$p\le1$ 发散（且 $p>0$） |
| 用逆否命题判定出"极限为 0"就下结论 | 该法只能判**发散**，不能判收敛 |
| 比值判别法求出 $\rho$ 后与 $0$ 比较 | 与 **$1$** 比较：$\rho<1$ 收敛、$\rho>1$ 发散、$\rho=1$ **失效**（改用比较判别法） |
| 认为 $\rho=1$ 时级数收敛 | $\rho=1$ 时比值判别法**失效**，敛散性不能确定 |
| 放缩时把不等号方向弄反 | 分母放大 → 整体变小；$\ln n<n\Rightarrow\frac{1}{n+\ln n}>\frac{1}{2n}$（**小发则大发**） |
| 求 $\rho(x)$ 时丢掉绝对值 | $\rho(x)$ 里**必须带绝对值**（$(-1)^n$ 加绝对值后等于 1 可直接去掉，但 $x$ 的绝对值不能去） |
| 求极限时把 $x$ 也当成变量 | 求 $\rho(x)$ 时极限变量是 $n$，$x$ **视为常数**，可直接约分、抓大头 |
| 把收敛区间写成闭区间 | **收敛区间一定是开区间**；端点代入判敛散后才得到收敛域 |
| 忘记判定端点，直接写收敛区间当收敛域 | 必须把 $a$、$b$ 代入原级数，收敛取闭、发散取开（四种情况） |
| 把"先导后积"和"先积后导"用反 | $a_n$ 是**分式** → 先导后积；$a_n$ 是**整式** → 先积后导 |
| 先积后导时指数与因式不匹配 | 必须保证**指数 $=$ 因式 $-1$**，否则积分后系数干不掉（如 $4x^4$ 积分得 $\frac45x^5$） |
| 先积后导的积分下限随便取 | 下限取**收敛中心** $x_0$（$\sum a_nx^n$ 时 $x_0=0$） |
| 判断交错级数时把 $(-1)^n$ 也当成 $u_n$ | $u_n$ 只取**不含 $(-1)^n$ 的正的部分** |
| 交错级数只验证一个条件就下结论 | 莱布尼茨定理**两个条件必须同时满足**才收敛；只满足一个或都不满足则发散 |
| 任意项级数只看原级数就下结论 | 必须按两步法：**Step 1 加绝对值 → 发散才进 Step 2** |
| 幂级数展开时把 $(x-x_0)$ 拆开 | 配出来的 $(x-x_0)$ 是**整体，不能拆**（要提系数就在整体前面乘） |
| 展开式忘记写 $x$ 的取值范围 | 每个展开式都必须写范围（前两个 $-1<x<1$；$\mathrm{e}^x$ 全体实数；$\ln(1+x)$ 为 $-1<x\le1$） |
| 把 $\ln(1+x)$ 的展开式写成 $n$ 从 $0$ 开始 | $\ln(1+x)=\sum\limits_{n=1}^{\infty}(-1)^{n-1}\frac{x^n}{n}$，**从 $n=1$ 开始** |
| 阶乘约分时不拆出 $n=0$ 项 | 约 $\frac{n}{n!}=\frac{1}{(n-1)!}$ 前要**先把 $n=0$ 项拆出来**，否则出现 $(-1)!$ |
| 求导/积分后端点范围照抄不变 | 逐项求导或逐项积分后，**端点敛散性可能改变，必须重新判定** |

## 五、小结

| 考点 | 要点 |
|:---|:---|
| 级数的定义 | $\sum\limits_{n=1}^{\infty}u_n=\lim\limits_{n\to\infty}S_n$；极限为常数则收敛，否则发散 |
| 敛散性判别方法之一 | **定义法**（写出 $S_n$ 求极限），裂项、首尾相消是常用技巧 |
| 级数的四条性质 | 数乘、线性组合、去/添有限项不改变敛散性、收敛的必要条件 |
| 敛散性判别方法之二 | **逆否命题**：$\lim u_n\ne0\Rightarrow$ 发散（只能判发散） |
| 等比级数 | $\lvert q\rvert<1$ 收敛（和 $=\frac{a_1}{1-q}$）、$\lvert q\rvert\ge1$ 发散 |
| P 级数 | $p>1$ 收敛、$p\le1$ 发散；$p=1$ 为调和级数（发散） |
| 正项级数判别法 | 比值（$\rho\lessgtr1$，$\rho=1$ 失效）、比较（大收则小收、小发则大发）、根值 |
| 比较判别法极限形式 | 重点只考"比值为非零常数 $\Rightarrow$ 同敛散"；多项式除法保留最高次幂、含等价无穷小直接等价 |
| 交错级数 | **莱布尼茨定理**：$u_{n+1}\le u_n$ 且 $\lim u_n=0$ 则收敛 |
| 任意项级数 | 两步法：加绝对值判绝对收敛；否则用莱布尼茨判条件收敛或发散 |
| 收敛区间/半径/域 | 令 $\rho(x)<1$ 解出开区间 $\to$ $R=\frac{b-a}{2}$ $\to$ 端点代入定收敛域 |
| 阿贝尔定理 | 收敛区间内绝对收敛；端点若收敛必为条件收敛 |
| 和函数·先积后导 | $a_n$ 为整式；**指数 $=$ 因式 $-1$**；先积分（下限为收敛中心）再求导 |
| 和函数·先导后积 | $a_n$ 为分式（P125 字幕缺失，方法同前，先求导再积分） |
| 和函数·特殊型 | 含阶乘的用逐项求导 + 一阶线性微分方程（如 $\sum\frac{x^n}{n!}=\mathrm{e}^x$） |
| 六个麦克劳林展开式 | 前四个必背（$\frac{1}{1\mp x}$、$\mathrm{e}^x$、$\ln(1+x)$），$\sin$、$\cos$ 结合考纲 |
| 等价无穷小 | 就是麦克劳林展开式省略高次项的结果 |
| 幂级数展开步骤 | 配出 $(x-x_0)$ → 选框架 → 套公式 → 整理 → 写范围 |
