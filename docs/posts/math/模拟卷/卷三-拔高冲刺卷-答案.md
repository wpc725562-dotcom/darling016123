## 三、计算题（8 题 × 6 分 = 48 分）

**11.** 用洛必达法则：
$\lim_{x\to 0} \frac{e^x - e^{-x} - 2x}{x - \sin x} = \lim_{x\to 0} \frac{e^x + e^{-x} - 2}{1 - \cos x} = \lim_{x\to 0} \frac{e^x - e^{-x}}{\sin x} = \lim_{x\to 0} \frac{e^x + e^{-x}}{\cos x} = 2$（6 分）

**12.** 隐函数求导：$xy - e^x + e^y = 0$，两边对 $x$ 求导：
$y + xy' - e^x + e^y y' = 0$，$y'(x + e^y) = e^x - y$，$y' = \frac{e^x - y}{x + e^y}$（6 分）

**13.** $\int \frac{1}{x\ln x}dx = \int \frac{1}{\ln x}d(\ln x) = \ln|\ln x| + C$（6 分）

**14.** $\int_0^{\pi/2} x\sin x dx = [-x\cos x]_0^{\pi/2} + \int_0^{\pi/2} \cos x dx = 0 + [\sin x]_0^{\pi/2} = 1$（分部积分，6 分）

**15.** 特征方程 $r^2 - 2r + 1 = 0$，$r = 1$（二重根）。通解 $y = (C_1 + C_2 x)e^x$。
代入 $y(0) = 1$ 得 $C_1 = 1$。$y' = (C_2 + C_1 + C_2 x)e^x$，$y'(0) = C_2 + C_1 = 0$，$C_2 = -1$。
特解 $y = (1 - x)e^x$（6 分）

**16.** $z = f(xy, x+y)$，令 $u = xy$，$v = x+y$。
$\frac{\partial z}{\partial x} = f_u \cdot y + f_v \cdot 1 = y f_u + f_v$（3 分）
$\frac{\partial^2 z}{\partial x\partial y} = f_u + y(f_{uu}\cdot x + f_{uv}) + (f_{vu}\cdot x + f_{vv}) = f_u + xy f_{uu} + (x+y)f_{uv} + f_{vv}$（3 分）

**17.** 极坐标变换：$x = r\cos\theta$，$y = r\sin\theta$，$dxdy = r dr d\theta$。
$D: x^2 + y^2 \le 1$ 对应 $0 \le r \le 1$，$0 \le \theta \le 2\pi$。
$\iint_D f(x,y)dxdy = \int_0^{2\pi} d\theta \int_0^1 f(r\cos\theta, r\sin\theta) r dr$（6 分）

**18.** 幂级数 $\sum_{n=1}^\infty \frac{x^n}{n}$，收敛半径 $R = \lim_{n\to\infty} \left|\frac{a_n}{a_{n+1}}\right| = \lim_{n\to\infty} \frac{n+1}{n} = 1$。
$x = 1$ 时发散（调和级数），$x = -1$ 时条件收敛。收敛域 $[-1, 1)$（3 分）。
和函数 $S(x) = \sum_{n=1}^\infty \frac{x^n}{n} = -\ln(1-x)$，$x \in [-1, 1)$（3 分）

## 四、综合题（共 22 分）

**19.** （10 分）
- 令 $f(x) = x^3 - 3x + 1$，$f(x)$ 在 $[0,1]$ 上连续（3 分）
- $f(0) = 1 > 0$（3 分）
- $f(1) = 1 - 3 + 1 = -1 < 0$（2 分）
- 由零点定理，存在 $\xi \in (0,1)$ 使得 $f(\xi) = 0$，即方程在 $(0,1)$ 内至少有一个实根（2 分）

**20.** （12 分）
（1）面积：
$S = \int_0^4 \sqrt{x} dx = \frac{2}{3}x^{3/2}\big|_0^4 = \frac{2}{3} \cdot 8 = \frac{16}{3}$（6 分）

（2）绕 $y$ 轴旋转体积：
$y = \sqrt{x}$ 即 $x = y^2$，$y \in [0, 2]$。
$V = \pi \int_0^2 (4^2 - (y^2)^2) dy = \pi \int_0^2 (16 - y^4) dy = \pi \left[16y - \frac{y^5}{5}\right]_0^2 = \pi \left(32 - \frac{32}{5}\right) = \frac{128\pi}{5}$（6 分）
