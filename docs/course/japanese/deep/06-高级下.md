## 高级第 13 课 · 老龄化（高齢化）

> **文体：社会问题说明文（数据 + 政策）**

**① `〜を余儀なくされる` 的深化——老龄化语境**

- **回顾**（高级上 11 课）：`Aは〜を余儀なくされる` ＝ A 被迫……
- **本课用法**：老龄化是**结构性压力**，常与"被迫"句式连用。
  - 例：`介護の担い手不足により、多くの家族が在宅介護を余儀なくされている。`
- **辨析**：与 `〜ざるをえない` 相比，`〜を余儀なくされる` **更强调外部结构性原因**。

**② `〜に伴って` / `〜とともに` / `〜にしたがって`（三兄弟，必考）**

| 表达 | 侧重 | 例 |
|:--|:--|:--|
| `〜に伴って` | **伴随**（同时发生，多用于规模性变化） | `高齢化に伴って、医療費が増大した。` |
| `〜とともに` | **一起**（并列推进） | `高齢化とともに、少子化も進んでいる。` |
| `〜にしたがって`（中级下 30 课） | **随之逐步变化** | `年を取るにしたがって、体力が落ちる。` |

- **易错**：`〜に伴って` 前接**名词或动词基本形**，不能接 `た形`。
- **语体**：三者都是书面表达，`〜に伴って` **最正式**。

**③ `〜ざるを得ない` 的书面强化：`〜ざるを得ざる` 不存在**

- **易错提醒**：`〜ざるをえない` 是固定形式，**不要自行造 `〜ざるを得ない` 以外的变体**。
- 三类动词：`する` → `せざるをえない`（**不是 `しざるをえない`**）。

**④ `〜に堪えない` / `〜に堪える`**

- **用法**：
  - `〜に堪えない`：**不堪……、不值得……**（`見るに堪えない` ＝ 不忍目睹）
  - `〜に堪える`：**值得……、经得起……**（`鑑賞に堪える` ＝ 值得鉴赏）
- **例**：`高齢者が孤立する現状は、見るに堪えない。`
- **易错**：两个形式意思**相反**，只差一个 `ない`。

**⑤ `〜を余儀なくさせる` 与使役的连锁**

- **用法**：`AはBに〜を余儀なくさせる` ＝ A 使 B 被迫……
- **例**：`人手不足は、企業に外国人労働者の受け入れを余儀なくさせた。`

**⑥ 议题词汇表**

| 日语 | 中文 |
|:--|:--|
| `高齢化社会` / `高齢社会` | 老龄化社会 |
| `少子高齢化` | 少子老龄化 |
| `後期高齢者` | 75 岁以上老人 |
| `介護保険` | 护理保险 |
| `年金制度` | 养老金制度 |
| `独居老人` | 独居老人 |
| `社会的孤立` | 社会性孤立 |
| `在宅介護` | 居家护理 |
| `担い手不足` | 承担者不足 |
| `生産年齢人口` | 劳动年龄人口 |

**自测**：用 `〜に伴って`、`〜とともに`、`〜にしたがって` 各造一句老龄化语境下的句子。

## 高级第 14 课 · 政治（政治）

> **文体：新闻评论 / 政论文**

**① `〜ざるを得ない` 与政治语境的"被迫决策"**

- 例：`与党は、世論の反発を受けて、法案の修正に応じざるを得なかった。`

**② `〜をめぐって` 的深化（回顾高级上 5 课）**

- **政治语境高频**：`憲法改正をめぐって`、`予算案をめぐる対立`、`領土問題をめぐる交渉`
- **扩展**：`〜をめぐって` 常与 `対立する`／`議論する`／`争う` 搭配。

**③ `〜に至る経緯` / `〜に至った`（回顾中级下 32 课课文）**

- **用法**：`〜に至る` 表达到某状态，**`名词 + に至る` 中的名词只能是动作性名词**。
- **政治语境**：`法案が可決されるに至った経緯`（法案得以通过的经过）
- **易错**：与表列举最后一项的 `〜に至るまで` **用法不同**。

**④ `〜を皮切りに`**

- **用法**：表"**以……为开端**（之后接连发生同类事）"。N1 高频。
- **例**：`この法案を皮切りに、一連の改革が進められた。`

**⑤ `〜とあって` / `〜とあれば`**

| 表达 | 含义 |
|:--|:--|
| `〜とあって` | **因为（特殊状况）**，所以当然…… |
| `〜とあれば` | **如果是（那种情况）的话**，就…… |

- **例**：`選挙が近いとあって、街はいつもより賑わっている。`／`国の存亡に関わるとあれば、国民全体で考えるべきだ。`
- **易错**：`〜とあって` **不能接意志/命令**；`〜とあれば` **后项常是判断或决心**。

**⑥ `〜なりに` 的政治用法（回顾中级下 32 课）**

- 例：`市民なりに政治を考え、声を上げる時代になった。`

**⑦ `〜を踏まえ` 的政论用法（回顾高级上 11 课）**

- 例：`過去の教訓を踏まえ、新たな制度を設計する必要がある。`

**⑧ 议题词汇表**

| 日语 | 中文 |
|:--|:--|
| `与党` / `野党` | 执政党 / 在野党 |
| `内閣` / `首相` | 内阁 / 首相 |
| `国会` / `衆議院` / `参議院` | 国会 / 众议院 / 参议院 |
| `選挙` / `投票率` | 选举 / 投票率 |
| `法案` / `可決` / `否決` | 法案 / 通过 / 否决 |
| `世論` | 舆论 |
| `政策` / `施策` | 政策 / 措施 |
| `有権者` | 选民 |
| `二院制` | 两院制 |
| `与野党協議` | 朝野协商 |

**自测**：用 `〜を皮切りに` 和 `〜とあって` 各造一句政治议题的句子。

## 高级第 15 课 · 家务（家事）

> **文体：生活文化说明文 / 男女分工议题**

**① `〜わけにはいかない`（回顾中级第 3 课课文）**

- **用法**：表"**出于某种理由不能……**"。
- **辨析（重要）**：

| 表达 | 依据 |
|:--|:--|
| `〜わけにはいかない` | **外在的、社会的理由** |
| `〜ずにはいられない`（中级下 27 课） | **内在的情感冲动** |

- **例**：`共働きでも、家事をすべて妻に任せるわけにはいかない。`

**② `〜を分担する` / `〜を担う`**

- **用法**：`担う`（承担）是高级高频动词，对象用 `を`。
- **例**：`家事と育児を夫婦で分担する。`／`地域社会が子育てを担う時代になった。`

**③ `〜げ` / `〜気味` / `〜がち`——"倾向"三兄弟**

| 表达 | 接续 | 含义 |
|:--|:--|:--|
| `〜がち`（中级下 24 课） | 动词ます形去ます / 名词 | **有某种倾向**，**一般不用于褒义** |
| `〜気味` | 动词ます形去ます / 名词 | **稍微有点……**（程度轻，多负面） |
| `〜げ` | 形容词/二类形容词词干 | **看起来……**（表外显的样子） |

- **例**：`疲れ気味だ`／`不安げな表情`／`遠慮がちに言う`
- **易错**：`〜げ` 前接**一类形容词去 `い`**（`悲しげ`）或**二类形容词词干**（`不安げ`），**不能接名词**。

**④ `〜ことか` / `〜ことか分からない`——感叹强调**

- **用法**：`〜ことか` 表**强烈的感叹**，常与 `どんなに`／`どれほど` 连用。
- **例**：`家事と仕事を両立させるのが、どんなに大変なことか。`
- **语体**：书面、文学性强。

**⑤ `〜ようがない`（回顾高级上 9 课）**

- **用法**：`ます形去ます + ようがない`，表"**想…也没有办法**"。
- **例**：`家族が理解してくれなければ、どうしようもない。`
- **易错**：带 `を` 的动词要改成 `の`——`手をつける` → `手のつけようがない`。

**⑥ `〜てはじめて`**

- **用法**：表"**只有…之后才（明白/体会到）**"。N1 高频。
- **例**：`自分で家事をしてはじめて、母の苦労が分かった。`

**⑦ 议题词汇表**

| 日语 | 中文 |
|:--|:--|
| `家事` / `家事分担` | 家务 / 家务分担 |
| `共働き` | 双职工 |
| `育児` / `育休` | 育儿 / 育儿假 |
| `家父長制` | 家长制 |
| `性別役割分業` | 性别角色分工 |
| `ワークライフバランス` | 工作生活平衡 |
| `専業主婦` | 全职主妇 |
| `ワンオペ育児` | 一人带娃 |
| `家計` | 家庭收支 |

**自测**：用 `〜てはじめて` 和 `〜わけにはいかない` 各造一句家务议题的句子。

## 高级第 16 课 · 雇佣（雇用）

> **文体：经济说明文 / 劳动政策**

**① `〜に至るまで` / `〜をはじめ` 的雇佣语境**

- 例：`新入社員をはじめ、すべての社員が研修を受ける。`

**② `〜た上で` / `〜た末に`——"经过…之后"**

| 表达 | 含义 |
|:--|:--|
| `〜た上で`（中级下 29 课） | 先做 A，然后做 B（**有意志性、有准备含义**） |
| `〜た末に` | **经过漫长过程之后（终于…）**，多用于结果 |

- **例**：`面接を重ねた上で、採用を決めた。`／`検討を重ねた末に、新規採用を見送ることにした。`
- **易错**：`〜た末に` **强调过程的漫长和结果的必然**；`〜た上で` **强调程序的前后顺序**。

**③ `〜ずにはいられない` 与职场情绪**

- 例：`リストラの通知を受けて、将来を不安に思わずにはいられなかった。`

**④ `〜はおろか`**

- **用法**：表"**别说……，就连……也……**"，**多用于负面**，比 `〜どころか`（中级下 26 课）**语感更重**。
- **例**：`彼はボーナスはおろか、給料さえ満足にもらえていない。`
- **辨析**：

| 表达 | 语体 | 语感 |
|:--|:--|:--|
| `〜どころか` | 中性 | 举出话题，强调更极端的事 |
| `〜はおろか` | **书面** | 语感更重，**多负面** |
| `〜もさることながら` | 书面 | 前项自不必说，后项更重要 |

**⑤ `〜もさることながら`**

- **用法**：表"**……自不必说，（更）……**"。**重点在后项**。
- **例**：`給与もさることながら、やりがいのある仕事がしたい。`

**⑥ `〜を余儀なくさせる` 的雇佣语境**

- 例：`円安は、企業に海外生産へのシフトを余儀なくさせた。`

**⑦ 议题词汇表**

| 日语 | 中文 |
|:--|:--|
| `雇用` / `雇用形態` | 雇佣 / 雇佣形态 |
| `正規雇用` / `非正規雇用` | 正式雇佣 / 非正式雇佣 |
| `終身雇用` / `年功序列` | 终身雇佣 / 论资排辈 |
| `リストラ` / `人員削減` | 裁员 |
| `ハローワーク` | 公共职业安定所 |
| `労働組合` | 工会 |
| `就職活動` / `就活` | 求职活动 |
| `新卒一括採用` | 应届生统一录用 |
| `働き方改革` | 工作方式改革 |
| `過労死` | 过劳死 |

**自测**：用 `〜はおろか` 和 `〜どころか` 各造一句，说明哪句更适合正式报告。

## 高级第 17 课 · 技术（技術）

> **文体：科技说明文**

**① `〜を可能にする` / `〜を可能ならしめる`**

| 表达 | 语体 |
|:--|:--|
| `〜を可能にする` | 一般书面 |
| `〜を可能ならしめる` | **极书面**（文语残留，多用于宣言、评论） |

- **例**：`AI技術は、これまで不可能だった診断を可能にした。`

**② `〜に取って代わる`（回顾高级上 11 课）**

- **例**：`機械が人間の単純作業に取って代わる時代になった。`

**③ `〜を踏まえて` / `〜に基づいて`（回顾）**

- 例：`実証データに基づいて、新技術の安全性が確認された。`

**④ `〜つつある`**

- **用法**：表"**正在……（变化进行中）**"，**比 `〜ている` 更强调变化的进程**，书面语。
- **例**：`自動運転の技術は、実用化に向けて進みつつある。`
- **辨析**：

| 表达 | 侧重 |
|:--|:--|
| `〜ている` | 状态或进行 |
| `〜つつある` | **朝某方向逐步变化**（动态） |
| `〜ようとしている`（中级下 17 课） | **即将发生** |

**⑤ `〜に至って` / `〜に至っては`**

- **用法**：
  - `〜に至って`：**到了……（阶段）才……**（多含"为时已晚"或"终于"）
  - `〜に至っては`：**至于……（就更不用说了）**（举出极端例子）
- **例**：`事故が起きるに至って、ようやく安全基準が見直された。`／`個人情報に至っては、管理すらされていなかった。`

**⑥ `〜べく` / `〜んがため`**

- **用法**：都表**目的**，书面/文语。
  - `〜べく`：`する` → `すべく`；其他动词基本形 + `べく`
  - `〜んがため`：`ない形去ない` + `んがため`（`する` → `せんがため`）
- **例**：`新技術を導入すべく、研究チームが結成された。`
- **易错**：`〜べく` **不能接意志/命令句**；`〜んがため` 语感更古老。

**⑦ 议题词汇表**

| 日语 | 中文 |
|:--|:--|
| `先端技術` | 尖端技术 |
| `人工知能（AI）` | 人工智能 |
| `自動化` / `省力化` | 自动化 / 省力化 |
| `特許` | 专利 |
| `研究開発（R&D）` | 研发 |
| `実用化` | 实用化 |
| `イノベーション` | 创新 |
| `技術革新` | 技术革新 |
| `デジタル化` / `DX` | 数字化 |
| `ロボティクス` | 机器人技术 |

**自测**：用 `〜つつある` 和 `〜ようとしている` 各造一句技术议题的句子，说明两者的时间感差异。

## 高级第 18 课 · 医疗（医療）

> **文体：医疗说明文 / 伦理议题**

**① `〜をめぐる` 的伦理语境**

- 例：`延命治療をめぐって、家族の意見が分かれた。`

**② `〜に踏み切る` / `〜に踏み込む`**

| 表达 | 含义 |
|:--|:--|
| `〜に踏み切る` | **下定决心做（此前犹豫的事）** |
| `〜に踏み込む` | **深入到（某领域/问题核心）** |

- **例**：`政府は、ようやく医療制度改革に踏み切った。`／`プライバシーに踏み込む質問は避けるべきだ。`

**③ `〜を余儀なくされる` 的医疗语境**

- 例：`高額な治療費のため、治療を中断せざるを得ない患者もいる。`

**④ `〜に堪えない` / `〜に忍びない`**

| 表达 | 含义 |
|:--|:--|
| `〜に堪えない` | 不堪……，不值得…… |
| `〜に忍びない` | **不忍心……** |

- **例**：`患者の苦しむ姿は見るに堪えない。`／`本人の意思を無視するのは、忍びない。`

**⑤ `〜ことなしに` / `〜なしに`**

- **用法**：表"**不…就（不能…）**"，**多与否定呼应**。
- **例**：`インフォームドコンセントなしに、手術を行うことはできない。`
- **辨析**：`〜ことなしに` 前接**动词基本形**；`〜なしに` 前接**名词**。两者都比 `〜ないで` **更书面**。

**⑥ `〜に至る` 的医疗语境**

- 例：`症状が悪化するに至って、初めて重病だと分かった。`

**⑦ 议题词汇表**

| 日语 | 中文 |

## 高级第 19 课 · 科学（科学）

> **文体：科学说明文 / 学术评论**

**① `〜と考えられている` / `〜とみられている`（回顾高级上 3 课、6 课）**

- **要点**：**"受身形 + ている" 表"一般来说是那样"，不明确指出动作主体**。这是科学文体的**核心句式**。
- **例**：`宇宙の年齢は約138億年だと考えられている。`

**② `〜にほかならない` 的学术结论用法（回顾中级下 30 课）**

- 例：`この現象の原因は、地球温暖化にほかならない。`

**③ `〜を裏付ける` / `〜を実証する`**

- **用法**：`裏付ける`（佐证）、`実証する`（实证），**学术论证高频动词**。
- **例**：`観測データが、この理論を裏付けている。`

**④ `〜とはいえ` / `〜とはいうものの`（回顾中级下 29 课）**

| 表达 | 含义 |
|:--|:--|
| `〜とはいえ` | **虽说……（但…）** |
| `〜とはいうものの` | **话虽如此** |

- **例**：`実験に成功したとはいえ、実用化にはまだ時間がかかる。`

**⑤ `〜に反して` 的科学语境（回顾中级下 28 课）**

- 例：`予想に反して、実験結果は理論と一致しなかった。`

**⑥ `〜ゆえに` / `〜がゆえに`（回顾高级上 11 课）**

- 例：`観測が困難であるがゆえに、この分野の研究は遅れている。`

**⑦ `〜に鑑みて`**

- **用法**：表"**鉴于……**"，**极书面**，多用于政策、法律文本。
- **例**：`昨年の事故に鑑みて、安全基準が改正された。`
- **辨析**：比 `〜を踏まえて` **更正式**，且**前接的多是已成事实的教训**。

| 日语 | 中文 |
|:--|:--|
| `仮説` / `検証` | 假说 / 验证 |
| `観測` / `実験` | 观测 / 实验 |

| `論文` / `査読` | 论文 / 同行评审 |
| `学術` / `学界` | 学术 / 学界 |

| `因果関係` | 因果关系 |
| `相関関係` | 相关关系 |
| `実証` / `論証` | 实证 / 论证 |

**自测**：用 `〜に鑑みて` 和 `〜を踏まえて` 各造一句，说明哪个更适合写进政策文件。

- 例：`開発か環境保護かをめぐって、住民の意見は真っ二つに分かれた。`

**② `〜に伴って` 的连锁影响（回顾 13 课）**

|:--|:--|

**⑥ `〜に至るまで` 的范围强调（回顾高级上 11 课）**

- **例**：`彼は研究のかたわら、開発途上国への技術支援を行っている。`

## 高级第 21 课 · 历史交流（歴史的交流）

> **文体：历史文化说明文 / 考证类**

**① `〜に由来する`（回顾高级上 7 课）**

- **例**：`この祭りは、古代の農耕儀礼に由来している。`

**② `〜を起源とする` / `〜に起源を持つ`**

- **用法**：`起源`（起源）比 `由来` **更强调"最初的发生"**。
- **例**：`シルクロードは、紀元前にまで遡る交易路を起源とする。`

**③ `〜に遡る` / `〜まで遡る`（回顾中级下 17 课 `さかのぼる`）**

- **例**：`この交流の歴史は、奈良時代まで遡ることができる。`

**④ `〜を通じて` / `〜を通して`（回顾中级下 23 课、高级上 12 课）**

- **用法**：本课用于**通过交流这一媒介**。
- **例**：`シルクロードを通じて、文化や技術が東西に伝わった。`

**⑤ `〜とともに` 的历史语境（回顾 13 课）**

- **例**：`仏教の伝来とともに、新しい建築技術も日本に伝わった。`

**⑥ `〜を経て`**

- **用法**：表"**经过……（之后）**"，强调中间过程。
- **例**：`幾多の困難を経て、両国の交流は再開された。`
- **辨析**：

| 表达 | 侧重 |
|:--|:--|
| `〜を経て` | **经过（过程）** |
| `〜た末に`（16 课） | **经过漫长过程（终于）** |
| `〜た上で`（中级下 29 课） | **程序的前后顺序** |

**⑦ `〜ならでは` 的文化语境（回顾中级下 23 课）**

- 例：`その土地ならではの文化が育まれてきた。`

**⑧ 议题词汇表**

| 日语 | 中文 |
|:--|:--|
| `交流` / `交易` | 交流 / 贸易 |
| `シルクロード` | 丝绸之路 |
| `遣唐使` | 遣唐使 |
| `伝来` | 传入 |
| `文化圏` | 文化圈 |
| `言語接触` | 语言接触 |
| `史跡` / `遺跡` | 史迹 / 遗址 |
| `出土品` | 出土文物 |
| `年代測定` | 年代测定 |
| `異文化交流` | 跨文化交流 |

**自测**：用 `〜を経て` 和 `〜た末に` 各造一句历史叙述，说明哪个更强调"过程的曲折"。

## 高级第 22 课 · 自然保护（自然保護）

> **文体：环境说明文 / 政策建议**

**① `〜おそれがある`（回顾中级下 32 课课文）**

- **要点**：`〜かもしれない` 表**主观推测**，`〜おそれがある` 表**客观推测**。
- **例**：`このまま開発が進めば、希少種が絶滅するおそれがある。`

**② `〜かねない`（回顾中级下 26 课）**

- **要点**：**没有明确指出可能性的依据时，不能使用 `〜かねない`**。比 `〜おそれがある` **更明确表达情况会变糟的主观感受**。
- **例**：`不用意な開発は、生態系を破壊しかねない。`

**③ `〜に至るまで` 与 `〜のみならず` 的范围扩展（回顾）**

- 例：`森林の減少は、動植物のみならず、気候に至るまで影響を及ぼす。`

**④ `〜を余儀なくさせる` 的环境语境（回顾 11 课）**

- 例：`地球温暖化は、多くの種に生息地の移動を余儀なくさせている。`

**⑤ `〜べく` / `〜ために` 的目的表达（回顾 17 课）**

- **辨析**：

| 表达 | 语体 | 限制 |
|:--|:--|:--|
| `〜ために` | 中性 | 前后项主语可不同 |
| `〜ように` | 中性 | 后项多为**非意志性**动词或可能形 |
| `〜べく` | **书面** | **不能接意志/命令句** |

- **例**：`希少種を保護すべく、保護区が指定された。`

**⑥ `〜つつある` 的环境语境（回顾 17 课）**

- 例：`かつて失われた森林が、今ゆっくりと回復しつつある。`

**⑦ `〜ことから` 的说明用法（回顾 11 课）**

- 例：`渡り鳥が減少していることから、湿地の環境悪化が疑われる。`

**⑧ 议题词汇表**

| 日语 | 中文 |
|:--|:--|
| `自然保護` / `環境保全` | 自然保护 / 环境保护 |
| `生態系` / `生物多様性` | 生态系统 / 生物多样性 |
| `絶滅危惧種` | 濒危物种 |
| `生息地` / `生育地` | 栖息地 |
| `保護区` | 保护区 |
| `再生可能資源` | 可再生资源 |
| `排出量削減` | 减排 |
| `環境負荷` | 环境负荷 |
| `里山` | 近山（人与自然共生区域） |
| `持続可能性` | 可持续性 |

**自测**：用 `〜おそれがある` 和 `〜かねない` 各造一句环境议题的句子，并说明什么情况下只能用前者。

## 高级第 23 课 · 国际化（国際性）

> **文体：社会评论 / 跨文化议题**

**① `〜を問わず` 的国际化语境（回顾高级上 12 课）**

- 例：`国籍を問わず、優秀な人材を受け入れるべきだ。`

**② `〜にかかわらず` / `〜にもかかわらず`（回顾中级下 26 课）**

| 表达 | 含义 |
|:--|:--|
| `〜にかかわらず` | **不论……**（前接可变因素） |
| `〜にもかかわらず` | **尽管……却……**（逆接） |

- **易错**：**有没有 `も` 意思完全不同**——这是 N1 高频陷阱。
  - `年齢にかかわらず`（不论年龄）
  - `努力にもかかわらず`（尽管努力了）

**③ `〜を超えて` / `〜を超えて〜を超えて`**

- **用法**：`〜を超えて` 表**超越（某界限）**。
- **例**：`国境を超えて、人と文化が行き交う時代になった。`

**④ `〜であれ〜であれ`（回顾高级上 12 课）**

- 例：`日本人であれ外国人であれ、法律は平等に適用される。`

**⑤ `〜に限らず` / `〜のみならず`（回顾高级上 1 课、中级下 27 课）**

- 例：`国際化は大企業に限らず、中小企業にも及んでいる。`

**⑥ `〜とともに` / `〜に伴って` 的社会变化（回顾 13 课）**

- 例：`グローバル化に伴って、多文化共生の課題が浮上した。`

**⑦ `〜ならでは` 的国际化用法（回顾中级下 23 课）**

- 例：`多様な価値観が共存するのは、国際都市ならではの魅力だ。`

**⑧ 议题词汇表**

| 日语 | 中文 |
|:--|:--|
| `国際化` / `グローバル化` | 国际化 / 全球化 |
| `多文化共生` | 多元文化共生 |
| `異文化理解` | 跨文化理解 |
| `国境` | 国境 |
| `移民` / `難民` | 移民 / 难民 |
| `在留資格` | 在留资格 |
| `異文化摩擦` | 文化冲突 |
| `ステレオタイプ` | 刻板印象 |
| `文化相対主義` | 文化相对主义 |
| `アイデンティティ` | 认同 |

**自测**：说明 `〜にかかわらず` 和 `〜にもかかわらず` 的区别，并各造一句。

## 高级第 24 课 · 慈善事业（フィランソロピー）

> **文体：社会评论（全书收尾课）**

**① `フィランソロピー` / `メセナ` / `CSR` 三个概念的分工**

| 概念 | 含义 | 出处 |
|:--|:--|:--|
| `フィランソロピー` | **慈善事业**——个人或企业为公共福利捐赠 | 高级下 24 课 |
| `メセナ` | **企业公益活动**——企业资助**学术和艺术**（有时含体育） | 高级上 8 课 |
| `CSR` | **企业社会责任**——包含合规、治理、环境、社会贡献的整体责任 | 高级上 12 课 |

- **要点**：`メセナ` 是 `フィランソロピー` 的**一种**；`CSR` 是**更广的框架**，`メセナ` 和 `フィランソロピー` 都可纳入其中。

**② `〜を惜しまない`**

- **用法**：表"**不吝惜……（投入）**"，多与 `努力`／`費用`／`時間` 搭配。
- **例**：`彼は社会貢献に私財を惜しまなかった。`

**③ `〜に充てる`**

- **用法**：表"**把……用于（某用途）**"。
- **例**：`利益の一部を、教育支援に充てている。`

**④ `〜にほかならない` 的收尾用法（回顾中级下 30 课）**

- **例**：`こうした活動は、企業と社会の信頼関係を築くことにほかならない。`

**⑤ `〜をもって`**

- **用法**：`〜をもって` 表"**以……（为界限/手段）**"，**极书面**。
  - 表界限：`本日をもって、募金活動を終了いたします。`
  - 表手段：`誠意をもって対応する。`
- **易错**：**表界限时不能换成 `〜で`**（`本日で終了` 也可以，但 `〜をもって` 更正式庄重）。

**⑥ `〜を皮切りに` 的社会活动语境（回顾 14 课）**

- 例：`この寄付を皮切りに、多くの企業が支援に名乗りを上げた。`

**⑦ `〜ゆえに` 的总结用法（回顾高级上 11 课）**

- 例：`見返りを求めないがゆえに、こうした活動は尊い。`

**⑧ 议题词汇表**

| 日语 | 中文 |
|:--|:--|
| `フィランソロピー` | 慈善事业 |
| `寄付` / `寄贈` | 捐赠 |
| `募金` | 募捐 |
| `社会貢献` | 社会贡献 |
| `非営利組織（NPO）` | 非营利组织 |
| `ボランティア` | 志愿者 |
| `基金` / `財団` | 基金 / 财团 |
| `税制優遇` | 税收优惠 |
| `見返り` | 回报 |
| `公益性` | 公益性 |

**自测**：用一句话区分 `フィランソロピー`、`メセナ`、`CSR` 三者的包含关系。
