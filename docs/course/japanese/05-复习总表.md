# 复习总表 · 发音规则与易混词

> 本页把[入门篇](./00-入门篇)里的规则压成**可随时查的表**，用于复习和自测。
> 规则来源：B站课 `BV1Bp4y1D747` 的 P3–P8。**不引用 ASR 乱码日文**；带 ❓ 的条目表示字幕识别不可靠，请以教材核对。

## 一、五十音全表（含老师的联想记忆）

| 行 | あ段 | い段 | う段 | え段 | お段 |
|:--|:--|:--|:--|:--|:--|
| **あ行**（元音行）| あ a ← 安 | い i ← 以 | う u ← 数字 5 | え e ← 衣 | お o ← 我+口 |
| **か行** | か ka ← 加+口＝咖 | き ki ← 钥匙 | く ku ← 躺地哭的嘴型 | け ke ← 计 | こ ko ← 口 |
| **さ行** | さ sa ← 杀 | し shi（读「西」）← 吸管 | す su（苏·丝之间，偏丝）← 柠檬 | せ se ← 世 | そ so ← 嗦面 |
| **た行** | た ta ← 太 | ち chi（读「qi」）← 6+1=7 | つ tsu（读「ci」）← 吃豆豆 | て te ← 天 | と to ← 拖 |
| **な行** | な na ← 奈 | に ni ← 左「一」右「二」 | ぬ nu ← 奴 | ね ne ← 内被淘汰 | の no ← （老师未给联想）|
| **は行** | は ha ← 波（波动拳）| ひ hi ← 坏笑 | ふ fu ← 跪地「服了」 | へ he ← 嘿嘿笑 | ほ ho ← 宝+帽子 |
| **ま行** | ま ma ← 末（麻子）| み mi ← m+i | む mu ← 木棍+母蛇 | め me ← 女 | も mo ← 毛 |
| **や行** | や ya ← 也 | — | ゆ yu ← 由 | — | よ yo ← 与 |
| **ら行**（全读 l）| ら la ← （未给）| り li ← 立刀旁 | る lu ← 车轱辘 | れ le ← 礼 | ろ lo ← 轱辘掉落 |
| **わ行** | わ wa ← 青蛙 | — | — | — | を o ← 跨进水坑 |

**另外**：`ん`（拨音）**不属于任何一行**。

### 三条必背的发音要点

| 要点 | 说明 |
|:--|:--|
| `う` 要把嘴**收回来** | 不能像中文「乌」那样往外撅嘴 |
| `あ` `お` 是**短音** | 千万不要拉长读成「啊——」「哦——」 |
| `ふ` 是 **fu**（不是 hu） | 嘴唇留一条缝、把气吹出去；不读「夫」也不读「呼」 |

### 特殊读法（不按罗马音走）

| 假名 | 实际读音 | 说明 |
|:--|:--|:--|
| し | 「西」 | 不读 si |
| す | 苏·丝之间，**偏丝** | 不读 su |
| ち | 「qi」 | 不读 ti |
| つ | 「ci」 | 不读 tsu |
| ら行 | **全读 l** | 日本人发不出 r 音 |

### 手写体易错笔顺（老师逐个提醒过）

| 字 | 易错点 |
|:--|:--|
| さ / き | **手写体下半部分不连笔**（连起来的是印刷体）|
| も | **第一笔是竖**，不是第二笔——写错的人非常多 |
| ゆ | 第一笔写到位**就停**，不画圈、不连上去 |
| よ | 第一笔写完**停住**，不上去、不画圈 |
| り / れ | 手写体**不连笔** |

## 二、声调

### 2.1 两条铁律（必背）

| # | 铁律 | 推论 |
|:--:|:--|:--|
| **1** | **第一个音和第二个音一定不同音** | 要么「低高」、要么「高低」；**不会出现「低低」或「高高」** |
| **2** | **出现降调之后不会再升回去** | 日语里**不存在「高低高」**；听日语不会有大幅起伏的波动 |

### 2.2 N 型怎么读

| 型 | 读法 | 第一个音 | 说明 |
|:--:|:--|:--:|:--|
| **零型**（平板型）| **不下降**，一路高上去并保持 | 低 | 后面接助词时，**助词跟着读高** |
| **一型** | **第一个音就是高音，后面全低** | **高** | 唯一「第一个音高」的类型 |
| **二型 / 三型 / N 型** | 第一个音低，在**第 N 个音之后降下来** | 低 | 后面接助词时，**助词降下去** |

> 记住这一条就能秒判首音：**除一型外，一律第一个音低。**

### 2.3 零型 vs 二型（最容易混）

| 情形 | 零型 | 二型 |
|:--|:--|:--|
| **只有两个音、单独读** | 低高 | 低高 —— **完全一样，听不出区别** |
| **后面接助词** | 低高**高**（助词跟着高）| 低高**低**（助词降下去）|

> 所以**不能只看单词本身**判断零型还是二型，要看后面接什么。

### 2.4 三套联想记忆法（挑一套用）

| 方法 | 零型 | 一型 | 二型 | 三型 |
|:--|:--|:--|:--|:--|
| **① 联想中文** | 我哥 | 哥哥 | 我哥哥 | 美滋滋的 |
| **② 用あいうえお当调子** | 把 `あいうえお` 本身当「低→高→降」的模板，套进去 | | | |
| **③ 汉语拼音声调** | 低音读**第三声**（别拖长），高音读**第一声** | | | |

> ⚠️ **方法③ 只能解决「低到高」**。日语里**「高到低」的低音和「低到高」的低音不是同一个音**，凡是高到低必须靠语感——这是老师不建议纯用汉语拼音的原因。

### 2.5 声调易混词对（声调不同 = 另一个词）

| 假名 | 低高 | 高低 |
|:--|:--|:--|
| もも | 桃子 | 大腿 |
| はし | 桥 | 筷子 |
| あめ | 雨 ❓ | 糖 ❓ |
| かみ | 纸 ❓ | 头发 ❓ |
| びょういん / びよういん | 医院 ❓ | 美容院 ❓ |

> ❓ = 老师在课上举例提过对比，但**具体哪边是哪个**受 ASR 噪声影响，未能在字幕中可靠确认，请以教材或词典核对。

**老师给的自测题（P5，答案明确）**：`ワタシ`＝**零型**；`アナタ`＝**二型**；`アノヒト`＝**二型**。

### 2.6 家庭成员声调一致

`おかあさん`、`おばあさん`、`おにいさん`、`おじいさん` —— **声调是一样的**。

## 三、长音

### 3.1 七条规则（背下来）

| # | 规则 | 例 |
|:--:|:--|:--|
| 1 | **あ段 + あ** | おかあさん（妈妈）|
| 2 | **い段 + い** | おにいさん（哥哥）|
| 3 | **う段 + う** | くうき（空气）|
| 4 | **え段 + え** | おねえさん（姐姐）|
| 5 | **お段 + お** | とおい（远）|
| 6 | **补充：え段 + い** | せんせい（老师）|
| 7 | **补充：お段 + う** | おとうさん（爸爸）、こうこう（高中）|

### 3.2 平假名 vs 片假名

| | 怎么认出长音 |
|:--|:--|
| **平假名** | **没有标记**，必须靠「什么段 + 什么段」自己推 |
| **片假名** | 直接用长音符号 **「ー」** 标出来，一眼可见（ゲーム、スーパー）|

### 3.3 长音的读法

| 情形 | 要求 |
|:--|:--|
| **高到低** | 必须读出**从高往下降的过程**（不能平着念过去）|
| **低到高** | 必须读出**往上滑的过程** |

### 3.4 差一个长音，意思全变

| 有长音 | 没长音 |
|:--|:--|
| おばあさん 奶奶／外婆 | おばさん 阿姨 |
| おじいさん 爷爷／外公 | おじさん 叔叔 |

## 四、浊音与半浊音

### 4.1 对照表

| 原行 | → 浊音行 | 辅音变化 | 标记 |
|:--|:--|:--|:--|
| か行 | **が行**（が ぎ ぐ げ ご）| k → g | 右上角**两点** |
| さ行 | **ざ行**（ざ じ ず ぜ ぞ）| s → z | 右上角**两点** |
| た行 | **だ行**（だ ぢ づ で ど）| t → d | 右上角**两点** |
| は行 | **ば行**（ば び ぶ べ ぼ）| h → b | 右上角**两点** |
| は行 | **ぱ行**（ぱ ぴ ぷ ぺ ぽ）| h → p | 右上角**一个圆圈**（半浊音）|

> **は行特殊**：它**既有浊音（ば行）又有半浊音（ぱ行）**，两套都要记。

### 4.2 同音陷阱（读音一样，写法必须记清）

| 同音组 | 说明 |
|:--|:--|
| **じ 与 ぢ** | 读音相同 |
| **ず 与 づ** | 读音相同 |
| **じゃ 与 ぢゃ** | 拗音里同样同音 |

> ⚠️ 所以**背单词时必须记清用哪个字**。例：「続く」写作 **つづく**，不能写成 つずく。

### 4.3 其他提醒

- **不要被英语发音带跑**：が行就是 g，不是英语的 /n/ 一类音。**日语和英语没有关系。**
- `す`、`ち` 的浊音**不按罗马音走**（`ず` 不是「zu」、`じ` 不是「zi」）。

## 五、促音与拗音

### 5.1 促音（小写 `っ`）

| 项 | 内容 |
|:--|:--|
| 写法 | **小写的 `っ`** |
| 作用 | **不发音，停一拍**——前一个音读完憋住一拍，再把气冲出去 |
| 占拍 | **独占一拍** |

**有促音 vs 没促音**（老师给的对照）：

| 没促音 | 有促音 |
|:--|:--|
| おと 声音 | おっと 丈夫 |
| かこ 过去 | かっこ 括号／样子 |
| ぶか 部下 | ぶっか 物价 |

### 5.2 拗音（36 个）

| 项 | 内容 |
|:--|:--|
| 构成 | **い段假名 + 小写的 ゃ / ゅ / ょ** |
| 组合来源 | か／が／し／じ／ち／に／ひ／び／ぴ／み／り 各配 ゃゅょ |
| 占拍 | **两个字合占一拍**（与小写 `っ` 独占一拍相对）|
| 读法 | **把两个字当成一个字连读**（き + ゃ → きゃ，一口气读出）|

**要点**：

- **不要用罗马音记拗音**——拗音的罗马字属于「日文的拼写方式」，拿它读反而容易读错。
- **难点在 ゅ 和 ょ**（如 きゅ、しゅ），要**多跟读、多对比**。
- `ぢゃ` 与 `じゃ` **同音**，背单词要看清用哪个字。
- **拗音后面也能接长音**：看拗音结尾元音属哪一段，再套长音规则。
  - `きゅう` —— 结尾是「う段」，符合「う段 + う」⇒ **读长音**。
  - `しょう` —— 结尾是「お段」，符合「お段 + う」⇒ **读长音**。

### 5.3 大小写 `っ` 分不清怎么办

老师说：一开始分不清很正常，**多看一段时间日语之后，大小写一眼就能看出来**，不必焦虑。

## 六、把规则合起来用（老师的收尾要求）

入门课讲完「五十音 → 声调 → 浊音 → 长音 → 促音 → 拗音」之后，老师的要求是：

> **把这些全部合起来放进单词里练**——给你标上声调，能不能把长音读对、能不能把声调读对，才是真掌握。

**老师反复强调的一句话**：

> 「不要想着考过 N2、N1 以后再去练发音，**那时候已经很难改回来了**。发音一定要从五十音阶段就抓住。」
