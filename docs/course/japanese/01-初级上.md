## 初级上 · 第 1–12 课

### 第 1 课 · 小李是中国人

📺 对应分P：`P10`（单词）· `P11`（语法，字幕轨损坏）

> ⚠️ 本课语法字幕轨损坏，内容由教材补齐，老师原话不可考。

**核心知识点**

1. **`名词1 は 名词2 です`** —— 判断句，表示「A 是 B」；`は` 读作 wa，提示前面的名词是主题
2. **`名词1 は 名词2 ではありません`** —— 判断句的否定，「A 不是 B」
3. **`名词1 は 名词2 ですか`** —— 判断句的疑问，「A 是 B 吗」；句尾 `か` 一般用上升语调
4. **`名词1 の 名词2`** —— 所属关系，「B 的 A」，如「李さんの会社」
5. **`～さん / ～くん`** —— 敬称；`さん` 加在姓氏后，`くん` 用于同辈或晚辈男性
6. **`はじめまして / どうぞよろしくお願いします`** —— 初次见面的固定寒暄与应答

**关键要点**

- **老师强调**：本课单词集中练长音。凡是「う段＋う」「あ段＋い」「お段＋う」的组合都是长音，必须把长音读出来——「如果我们不去记忆长音规则，那就按照自己的发音去读，往往发现不了长音」。
- **易错**：中国人、韩国人、美国人、法国人在单词表里都是四型，日本人也是四型，但日本人听上去不一样，因为「人」前面那个音是高而这里是低，不能因为「都是四型」就按同一调子读。
- **易错**：`こんにちは`、`こんばんは` 里的 `は` 写作は但要读 wa。
- **记忆法**：外国人的姓名到日本后声调多为高到低；日本姓氏约 80% 读零型（平板），「假如你看到一个日本人的名字不知道怎么读，那你就往零型记读，往往会读对」。例外要单独记：佐藤、高桥不是零型。
- **中日对比**：金姓——韩国人读キム，中国人读キン，同一个汉字两种读法。
- **记忆法**：`さん` 用于女性或进入社会后的所有人；`くん` 多用于小学、初中喊男生。

**复习总结**

- 自测：把本课出现的所有含长音的单词（中国人、日本人、学生、留学生、教授、研修生、東京大学、旅行社……）逐个指出长音在哪一段，并大声读出来。

### 第 2 课 · 这是书

📺 对应分P：`P12`（单词）· `P13`（语法）

**核心知识点**

1. **`これ / それ / あれ`** —— 指示代词分三个：中文只有「这个、那个」两个，日语有近、中、远三个；分两种情况——面对面（各自按与自己的距离判断）和两人同方向并排（把两人视为一个整体，近处これ、中距それ、远处あれ）
2. **`だれですか / なんですか`** —— 指人用 `だれ`，指物用 `なん`；`どなた` 是 `だれ` 的礼貌说法，且后面再加 `さま` 才用于长辈
3. **`名词 の 名词`** —— 所属关系，「の」八成情况等于中文的「的」，如「私の鍵」「田中さんの車」
4. **`この / その / あの + 名词`** —— 连体词，后面**必须连接名词**，不能单独使用（不能说「このは本です」）
5. **`どの + 名词 / どれ`** —— `どの` 必须接名词，`どれ` 可单独使用；表示三个以上事物中不确定哪一个
6. **表达补充**：`かた` 比 `ひと` 更有礼貌；问年龄用 `なんさい`／`おいくつ`；`ええ` 和 `はい` 多数时候可以互换，但**被叫到自己名字时只能答 `はい`**；外来语是音译词，其中还有日本人自创的一类

**关键要点**

- **老师强调**：口诀「こそあど」——こ近距离、そ中距离、あ远距离、ど疑问词。判断连体词 `この/その/あの` 时也用这个口诀推。老师反复提醒「不要去抠语法，一定要通过句子有一个自己的理解」。
- **易错**：`この / その / あの / どの` 后面**必须有一个名词**，没有名词是绝对不行的。这一点在表达和词语讲解里又强调了一次。
- **易错**：`新聞（しんぶん）` 是**报纸**，不是「新闻」；中文的「新闻」日语用外来语 news。
- **易错**：`電話（でんわ）` 不要被中文「电话」的调子带跑，要读低到高、连起来读。
- **记忆法**：`パソコン` 这类词是日本人自创的外来语（パーソナルコンピューター 取头取尾缩合），「外国人听不懂的系列」，可以直接当作日语来记。
- **中日对比**：`どなた` 用于地位相同或比自己低、年纪相当或更小的人；见到老爷爷老奶奶要问「どなたさまですか」，光 `どなた` 不够，还要加 `さま`。

**复习总结**

- 自测：合上书，用「こそあど」口诀说出本课全部指示词（これ・それ・あれ・どれ・この・その・あの・どの・ここ…本课只到连体词），并各造一句包含名词的句子。

### 第 3 课 · 这里是商场

📺 对应分P：`P14`（单词）· `P15`（语法）

**核心知识点**

1. **`ここ / そこ / あそこ / どこ`** —— 场所指示代词，口诀同样是「こそあど」，用法与「これ／それ／あれ」一一对应
2. **`名词 は 名词[场所] です`** —— 与第 1 课同形，但当 B 是场所时译成「A 在 B」；人作主语时表示「某人在某地」，不过老师明确说「正常情况下我们不会用这个语法，一般会用存在句」
3. **`名词 は どこですか`** —— 询问某物在某处
4. **`名词 も 名词 です`** —— 「也」；`も` 与 `は` 可替换，**有は就没有も，有も就没有は，不能连用**
5. **`名词 は 名词 ですか、名词 ですか`** —— 二选一（可继续往后加到多个选项）的疑问句，回答时重复谓语即可
6. **`いくらですか`** —— 询问价格，「这个多少钱」

**关键要点**

- **老师强调**：`あそこ` 很多同学按前面的读法会读错，要读成「あそこ」而不是拆开念。
- **易错**：便利店不要说成「便利屋」，日语说 `コンビニ`——「不要被汉字给带跑了，千万不要自己看到一个汉字就把汉字直接复制过来」。汉字有时意思相同，有时差异很大。
- **易错**：`も` 在「あなたも北京大学の学生ですか」里读起来不顺，但也**必须加**，不然「也」的意思表达不出来。
- **易错**：`か` 的升降调能改变意思——音往上提是疑问（「这里是大学吗」），音往下降是听到对方内容后的附和（「是大学呀」）。`そうですか` 同理，往下降是「原来如此」，往上提是「真的吗」。
- **记忆法**：缩略词是日本人拿外来词简化出来的——パソコン、デジカメ、コンビニ，都可以当日语理解。
- **发音提醒**：`コンビニ`、`デジカメ` 这类缩略词的长音要读出来；`エスカレーター` 四型。
- **易错**：外来语一定要用片假名写，老师写平假名只是方便初学辨认，学到第七、八课就不再写了。

**复习总结**

- 自测：用「こそあど」说出场所四词并造句，然后说出 `も` 与 `は` 不能连用的原因，最后问一次「洗手间在哪里」「这个多少钱」。

### 第 4 课 · 房间里有桌椅

📺 对应分P：`P16`（单词）· `P17`（语法）

**核心知识点**

1. **`场所 に 物 が あります`** —— 某地有某物；`あります` 只能用于**不具有意志**的事物（书、电脑、花草、机器）
2. **`场所 に 人/动物 が います`** —— 某地有某人／动物；`います` 用于有意志的
3. **`物/人 は 场所 に あります / います`** —— 某物在某地／某人在某地；主语是物就用あります，主语是人或动物就用います
4. **`名词 と 名词`** —— 「和」，表与中文的「和」基本对应
5. **`名词 の 上/下/前/後ろ/隣/中/外`** —— 方位词，由「名词＋の＋方位词」构成
6. **`疑问词 + も + 动词否定`** —— 全盘否定，「什么也没有」「谁也不在」

**关键要点**

- **老师强调**：这四组存在句是**本课重点，考试特别容易考，后期也经常出现**，四个都要会；但造句建议用后两组（物在某地／某人在某地），因为更符合中文思维——「我们一般都说佐藤在咖啡厅里，而不会说咖啡厅里面有佐藤」。
- **易错**：`うえ`（上面）指**一个绝对的平面**。桌子腿的侧面不能叫「机の上」；`かべ`（墙）也一样，`かべのうえ` 指的是天花板那个平面——「你家的开关就在天花板上了，够不到了」。
- **易错**：猫是活着的，只能用 `います`。如果对活猫说「猫がありません」，别人的第一反应是「这只猫难道已经死了吗」，非常吓人。
- **易错**：`に` 表静态（像一张照片），`で` 表动态（像一段录像）；桌子上有苹果用 `に`，猫在桌子上跳舞用 `で`。
- **记忆法**：`あります`＝没有生命的（死的），`います`＝活着的，用「活的／死的」去联想就很容易分。
- **中日对比**：`兄弟（きょうだい）` 在日语中**包括兄弟姐妹**（姐姐妹妹也算），和中文只指男性兄弟不同。
- **老师强调**：问「在哪里」时，`どちらですか` 比 `どこにありますか／どこにいますか` 方便得多——不用先判断主语是物还是人；但书本上出现的 `どこにありますか／いますか` 也要看得懂。

**复习总结**

- 自测：看着房间照片，分别用「某地有某物」「某物在某地」两种句式各说三句，并解释为什么猫必须用います。

### 第 5 课 · 森先生7点起床

📺 对应分P：`P19`（单词）· `P18`（动词三分类独立课）· `P20`（语法）

**核心知识点**

1. **动词三分类与ます形的变形**（P18 独立课）—— 所有动词原形都以う段结尾；一类动词＝五段动词（结尾う段非る／あ段＋る・う段＋る・お段＋る／三个特例）；二类动词＝一段动词（上一段＝い段＋る，下一段＝え段＋る）；三类动词＝カ变（来る）、サ变（する）。一类：う段变同行い段＋ます；二类：去る＋ます；三类：来る→きます、する→します
2. **`动词ます / ません / ました / ませんでした`** —— 动词的现在、现在否定、过去、过去否定四种形式；时间词是上周、昨天时，动词必须变过去
3. **`名词[时间] に 动词`** —— 具体时间点后用 `に`；但今、昨日、今日、明日、毎日、去年、明年等**不加に**
4. **`名词[时间]から 名词[时间]まで 动词`** —— 从…到…；也可单独用 `から`（从…开始）或 `まで`（到…为止）
5. **`いつ 动词ますか`** —— 询问什么时候做某事，回答时可用 `に` 提示具体时间

**关键要点**

- **老师强调**：背动词要**背原形**，不要背ます形——「まず形你是查词典查不到的」，词典查的是原形；而且从原形推其他变形会简单很多。
- **老师强调**：日语三个门槛是五十音图、动词、敬语；动词这里「基础一定要打到，打不好后面越学越乱」。
- **记忆法**：一类动词的三个特例必须死记——要る、帰る、走る。它们看上去像一段动词，其实是五段，「考试特别喜欢考你特例」。
- **记忆法**：上一段、下一段这样记——「う」的上面是「い」，所以い段＋る叫上一段；「う」的下面是「え」，所以え段＋る叫下一段。
- **易错**：不要把「う段结尾」理解成「う段都是动词」。う段结尾的也有名词，只是**如果是动词**，它肯定是一类动词。
- **易错**：サ变动词是名词＋する，但**不是所有名词都能加する**，词典里标了自他动词的才可以。
- **记忆法**：ます形的声调有规律——第一个音低、中间高、最后降下来。只要是正常的ます形，按这个规律读「95% 单词肯定都可以读对」，不用逐个背声调。
- **记忆法**：时间词最容易出错，老师给的办法是**直接把时间词提到句首、用逗号隔开**，就不用纠结加不加 `に`。
- **易错**：`ごろ` 表示大概时间，**后面不加に**；说「一点半左右」可以，但不要说「一点十六分左右」，太细就不叫「左右」了。
- **易错**：两个时间名词连用不能加 `の`——「毎日七時」不能说「毎日の七時」。
- **中日对比**：在公司称呼上司，一般喊职位（課長）或名字＋职位，**不要直接名字＋さん，更不要加「お」**，那很不礼貌。

**复习总结**

- 自测：随便挑十个动词原形，先判断是一类、二类还是三类，再一步到位写出ます・ません・ました・ませんでした四种形式。

### 第 6 课 · 吉田先生下个月去中国

📺 对应分P：`P21`（单词）· `P22`（语法）

**核心知识点**

1. **`名词[场所] へ 动词`** —— 表示移动的方向（去、回）；助词写作 `へ` 但**读作 e**
2. **`名词[场所] から 动词`** —— 从某地（来），与上一课表时间的 `から` 用法相同，只是换成了场所
3. **`名词[人] と 动词`** —— 和某人一起做某事
4. **`名词[交通工具] で 动词`** —— 通过某种交通手段（坐飞机、坐电车、步行…），也可理解成「用」
5. **`名词[场所]から 名词[场所]まで 动词`** —— 从…到…，起点用から、终点用まで
6. **表达补充**：`たしか` 表示凭感觉、不完全有把握的记忆；`では／じゃ` 是口语化的「那么」；`うち` 表示自己家；`まっすぐ` 表示直接、不绕路

**关键要点**

- **老师强调**：`へ` 尽管写成へ，作助词时**读 a**，这个一定要记住。
- **老师强调**：日语的语序和中文不一样，但**只要助词对，语序可以调换**——「日文中对语序的要求没有那么高，因为它有助词」。同一句可以从场所说到场所，也可以先说手段。
- **易错**：`フェリー` 是**渡轮（船）**，很多同学会记成飞机或直升机，一定要记住。
- **易错**：`韓国` 读カンコク，不是ガンコク，「很多同学都会想到カンコク，一定要注意」。
- **易错**：促音要停一拍，但放在单词里没那么夸张，「不要无视它」。
- **易错**：一到十号的日期读法变化很大，必须单独记；忘了写「一日」的错法日本人也能看懂，但考试会扣分，成人这么说「会显得没什么文化」。
- **记忆法**：本课单词的ます形按规律读（第一音低、中间高、最后降），不用单独背声调；遇到特殊声调才单独记。

**复习总结**

- 自测：说出「我下个月坐飞机从北京去美国」这一句，并确认へ、から、まで、で四个助词都用对了。

### 第 7 课 · 小李每天都喝咖啡

📺 对应分P：`P23`（单词）· `P24`（语法）

**核心知识点**

1. **`名词 を 动词`** —— `を` 提示动作的对象（宾语）；日语语序是「咖啡を喝」，与中文相反
2. **`名词[场所] で 动词`** —— 在某地做某事；`で` 表动态，与第 4 课表静态的 `に` 相对
3. **`名词 か 名词`** —— 「或者」，对若干名词进行选择
4. **`名词 を ください`** —— 请给我某物；口语里 `を` 可以省略，正式场合必须加
5. 本课还涉及：`～は 何を 动词ますか`（吃什么）、`どこで 动词ますか`（在哪里做）

**关键要点**

- **老师强调**：`で` 和 `に` 是这一课最容易混的点——`に` 是静态（像照片），`で` 是动态（像录像）。桌子上有苹果用 `に`，猫在桌子上跳舞用 `で`。
- **易错**：`なに` 和 `なん` 的读法要分清——后面接 `と / が / を / で` 时读 `なん`，接 `の / です` 时读 `なん`；但 `なんですか` 建议**不要读成「なにですか」**，因为日本人听到「なにで」的第一反应是「为什么」，会造成没必要的误会。
- **易错**：不能自创搭配。老师提醒「很多同学自创语法，日本根本没有这样的搭配」——比如「磨牙」在日语里其实是**刷牙**（みがきます），要用「歯を磨きます」。
- **易错**：粥在日语里说「吃粥」不说「喝粥」，即 `お粥を食べます`。
- **记忆法**：`そうですか` 音往下降＝「原来如此」，音往上提＝「真的吗」；`そうですね` 语气不能拖长，拖长意思会变。
- **发音提醒**：`いらっしゃいませ` 的促音要算一个音，声调数音时不能把它和前面的拗音并成一个。
- **记忆法**：`かしこまりました` 比 `わかりました` 更礼貌，是服务业常用说法；自己不必主动用，但要听懂。

**复习总结**

- 自测：用 `を`、`で`、`か`、`をください` 各造一句，并说明 `で` 和 `に` 分别对应什么状态。

### 第 8 课 · 小李用日语写信

📺 对应分P：`P25`（单词）· `P26`（语法）

**核心知识点**

1. **`名词[工具/手段] で 动词`** —— 用某种工具、手段或原料做某事（用日语写信、用报纸折纸飞机、用什么做的乌冬面）
2. **`名词[人] に 名词 を あげます`** —— 把东西给某人；**只能是我给别人或他人给他人**，别人给我不能用あげます（那个动词在初级下册学）
3. **`名词[人] に/から 名词 を もらいます`** —— 从某人那里得到某物；`に` 和 `から` 都可用，但**从学校、公司等团体得到时必须用から**
4. **`名词[人] に 会います`** —— 见某人，见面对象用 `に`
5. **`よ`** —— 句尾助词，表示告知、提醒或较轻的警告
6. **`もう`** —— 表示「已经」（もう食べました）

**关键要点**

- **老师强调**：中文一个「给」在日语里要分方向——我给别人用あげます，别人给我要用别的动词（くれます）。「别人把东西给我就不能用あげます这个词」。
- **老师强调**：如果第三人称中有说话人的亲属，要按说话人的立场处理——母亲、父亲、弟弟妹妹这类词都视为「自己」，所以「母亲给田中」这种情况也不能用あげます。
- **易错**：`から` 和 `に` 在もらいます里都能用，但**只有から能明确表示「从」**；如果题目给的是 `から`，句子一定是「从别人那里得到」。
- **易错**：口语中直接对人说「あげます」（我把这个给你）**很不礼貌**，要用 `どうぞ` 或 `いかがですか` 代替。
- **记忆法**：`さっき` 是「刚才」，`たった今` 是「此时此刻」，后者更近——たった今可能只是 30 秒前，さっき可以到十几分钟前。
- **易错**：`先日` 在日语中只表示**从过去到现在为止**的一段时间，不表示将来——不能说「最近我要去日本」。
- **记忆法**：`貸します`（借给别人）和 `借ります`（向别人借）发音接近但汉字不同，一定要区分开。
- **记忆法**：`はし` 按声调区分意思——筷子／桥，记单词时要连声调一起记。

**复习总结**

- 自测：分别说出「我把书给小王」「小王给了我书」「我从学校得到了一本词典」三句，并说明每句为什么用那个授受动词和助词。

### 第 9 课 · 四川料理很辣

📺 对应分P：`P27`（单词）· `P28`（语法）

**核心知识点**

1. **`名词 は 一类形容词 です`** —— 一类形容词作谓语，后面加 `です` 表示礼貌
2. **一类形容词的否定与过去** —— 否定：去 `い` 加 `くないです`（或 `くありません`）；过去：去 `い` 加 `かったです`；过去否定：去 `い` 加 `くなかったです`
3. **一类形容词直接修饰名词** —— 中间不加任何东西
4. **`あまり + 否定`** —— 表示程度不高，「不怎么…」；后面必须跟否定
5. **表示程度的副词** —— とても／たいへん（很）、少し／ちょっと（一点）、あまり／全然（＋否定）
6. **`は` 表示对比** —— 除了提示主题，`は` 还可表示对比；与其他助词（に・で・から・まで・と）叠加时构成复合形式

**关键要点**

- **老师强调**：一类形容词连接名词**绝对不能加 `の`**。「一类形容词＋の＋名词」是非常严重的错误，「基本我之前教过的学生，十个同学感觉六七个都有这样的错误」，「考试一出现这就是一个差，直接给你扣掉」。
- **老师强调**：中文说「昨天很热」「今天很热」用的是同一个「热」，但日语作谓语时**必须变过去式**——「很多同学学形容词的时候都会忘记变过去式，因为我们中文不这么用」。
- **易错**：`いい` 的否定不是「いくない」，而是 `よくない`；`よくない` 也可以说 `よくありません`。可以借「よい」来记，いい 的变形和よい 一样。
- **易错**：`多い`、`少ない` **不能单独修饰名词**，不能说「多い本」；要表达「很多书」得换词，用 `たくさんの本`。
- **易错**：`きれい`（漂亮/干净）看上去像一类形容词（以い结尾），其实是**二类形容词**，考试特别喜欢考。判断方法是看它的汉字是不是「汉字＋い」——きれい的い在汉字里，不在外面。
- **中日对比**：中文形容词前的「很」很多时候只是凑字数（「今天很热」），不表示程度；但日语的とても／たいへん**一定是表示程度**。
- **中日对比**：中文回答「你不热吗」会说「是的不热」；日语既可以答 `はい、熱くないです`（肯定对方说的这件事），也可以答 `いいえ、熱くありません`（否定「热」这件事）。
- **发音提醒**：一类形容词的声调可以统一按「低高低」读，只有少数必须按原声调，如 `少ない` 必须读三型，不能读低高低。

**复习总结**

- 自测：把「热い」写成肯定、否定、过去、过去否定四种形式，然后用它分别造一个「作谓语」和「修饰名词」的句子。

### 第 10 课 · 京都的红叶很有名

📺 对应分P：`P29`（单词，无字幕）· `P30`（语法）

**核心知识点**

1. **`名词 は 二类形容词 です / ではありません`** —— 二类形容词作谓语；肯定加です，否定加ではありません
2. **二类形容词的过去式** —— 过去：`でした`；过去否定：`ではありませんでした`。二类形容词的变形和名词完全一样
3. **`二类形容词 + な + 名词`** —— 二类形容词连接名词要加 `な`（所以旧教材叫「な形容词」），与一类形容词直接连接不同
4. **`名词 でした / ではありませんでした`** —— 名词作谓语时的过去式与过去否定
5. **`どんな + 名词 / 何の + 名词`** —— `どんな` 问性质，回答常用形容词；`何の` 问内容或材料
6. **`どうですか / どうでしたか`** —— 询问现在／过去「怎么样」；`どうでしたか` 还有劝诱对方做某事的用法

**关键要点**

- **老师强调**：学过一类形容词再看二类形容词会觉得简单很多，因为**二类形容词所有变形都和名词一样**。
- **老师强调**：一类形容词接名词直接接，二类形容词接名词要加 `な`，这个区别是本课重点。
- **易错**：`でも` 一般用于口语，书面语中写 `でも` 会显得幼稚，书面要用 `しかし`；`そして` 表并列，`でも` 表转折。
- **易错**：表示下雨、下雪这类自然现象，日语习惯用「名词＋です」的形式（如「雨です」「雪です」），不必非要用动词——这样更符合日本人的表达。
- **易错**：形容词加 `の` 和上一课讲的「形容词不能加の」**不是一个概念**。这里的 `の` 是代替上文已经出现过的名词（省略），并不是形容词直接修饰名词。
- **记忆法**：`ところで` 是转换话题的万用句，聊着聊着想换话题就可以用它起头。
- **记忆法**：`名词＋中` 表示范围——世界中、日本中、学校中；时间词也一样——一日中、一晩中、一年中。
- **记忆法**：`紅葉` 有もみじ和こうよう两种读法，一般不用太刻意区分，知道两种都行即可。

**复习总结**

- 自测：把「静か」写成肯定、否定、过去、过去否定四种形式，再用它分别修饰名词、作谓语各造一句，并说明它和「高い」在接名词时的区别。

### 第 11 课 · 小野喜欢唱歌

📺 对应分P：`P31`（单词）· `P32`（语法）

**核心知识点**

1. **`名词1 は 名词2 が 一类/二类形容词 です`** —— 情感形容词（好き、嫌い、怖い等）作谓语；名词1是情感主体，名词2是情感对象，用 `が` 提示
2. **`名词1 は 名词2 が 动词/形容词 です`** —— 表示能力：できます、わかります、上手です、下手です、得意です、苦手です
3. **`名词 や 名词`** —— 部分列举（`と` 是把所有项目都说出来，`や` 是从若干项里挑几项）；`～など` 表示「等等」
4. **`～から / ～だから`** —— 表示原因。**一类形容词和动词直接接から**；**二类形容词和名词要变成 `だから` 或 `ですから`**
5. **频率副词** —— いつも、よく、時々、たまに；あまり、全然后面跟否定
6. **`どうしてですか`** —— 询问原因，「为什么」

**关键要点**

- **老师强调**：第一组语法后面接的是**情感形容词**，第二组后面接的是**能力词（动词）**，两组形式像但性质不同，要分清。
- **老师强调**：`から` 能接一类形容词和动词，但**二类形容词和名词必须变成 `だから` 或 `ですから`**，绝对不能说「きれいから」。
- **易错**：`あまり` 和 `全然` 后面**一定是否定**，不能接肯定。
- **易错**：表示「在某地发生某事」（如摄影展、展览会、会议、派对）要用 `で`，不能用 `に`——因为这些词表示的是**动态**，不是静态状态。
- **易错**：`気に入りました` 和 `好き` 不同——`気に入りました` 表示「原来不知道或没关注，看了以后觉得很喜欢」，是此时此刻的判断；`好き` 表示持续很久的爱好。`気に入りました` 只用于朋友或熟人之间，对长辈不要用。
- **记忆法**：`とくい`（擅长）是三型，`にがて`（不擅长）是二型，后面接助词时音要往下降。
- **易错**：`ときどき` 容易读错浊音，要注意。
- **中日对比**：`僕` 一般是男生用，尤其是小学男生；正常情况下还是用 `私` 更正式。女生用僕会被理解为卖萌，不是绝对但要注意场合。

**复习总结**

- 自测：说出「小王喜欢电影」「我不擅长打游戏」「因为小王不擅长英语，所以他不怎么听英语歌」三句，并确认が、から、あまり的用法都对。

### 第 12 课 · 小李比小森年轻

📺 对应分P：`P33`（单词）· `P34`（语法）

**核心知识点**

1. **`名词1 は 名词2 より 形容词 です`** —— A 比 B 怎么样；主语是 A，`より` 相当于「比」
2. **`名词1 より 名词2 のほうが 形容词 です`** —— 与 A 相比，B 更怎么样；注意这里的顺序和第 1 组是**反的**，很容易搞混
3. **`名词1 は 名词2 ほど 形容词否定`** —— A 没有 B 那么怎么样；**ほど后面必须是否定**
4. **`名词[范围] で 名词 が 一番 形容词 です`** —— 在某个范围内，某物最怎么样；范围用 `で`
5. **`名词1 と 名词2 と どちらが 形容词 ですか`** —— 二选一；**只能用于两者比较**，三种以上不能用，要用 `どの / いつ / だれ / 何 が 一番`
6. **程度强调** —— 差距大时可加副词 `ずっと`（…得多）

**关键要点**

- **老师强调**：比较级的四个句式**直接当句型背下来**，不要纠结「のほう」是什么，「没有必要管这个」。
- **老师强调**：`一番` 一定要**给出范围**——不能突然说「一番おいしい」，要说「日本料理の中で一番おいしい」。
- **易错**：场所或时间词作范围时，**不加 `の中`**，直接用 `で` 即可——「日本の中で」不如「日本で」自然，虽然意思能懂但不是日本人的表达。
- **易错**：`ほど` 后面只能接否定，如果接了肯定（如「ほど高い」）就是错的。
- **易错**：第 1 组和第 2 组的 A、B 顺序相反，写句子时特别容易出错——「尤其是你在写一些句子的时候，特别容易出错」。
- **易错**：`どちら` 只用于两者；问三者以上要用 `どの` 系列。`どちら` 的正式说法是 `どちら`，口语说 `どっち`。
- **易错**：`最近（さいきん）` 在日语中**只表示从过去到现在**，不含将来；不能说「最近我要去日本」，这跟中文不一样。
- **易错**：`〜のほうがいい` 除了「什么什么比较好」，还常用来表示「我更喜欢什么」，翻译时读不通可以往这个方向理解。
- **发音提醒**：`焼酎` 读「しょうちゅう」，很多同学会因为「日本酒（にほんしゅ）」把酒读成「しゅ」，写注音时要特别注意。
- **记忆法**：`やっぱり` 是 `やはり` 的口语说法，表示推测或得到的信息与预想相符（「果然」）。

**复习总结**

- 自测：用第 1、2、3 组句型分别说一句「小王比佐藤高」「与佐藤相比小王更高」「佐藤没有小王那么高」，再说出「四季当中我最喜欢春天」。

## 初级上 · 第 13–24 课

### 第13课 · 桌子上有三本书

📺 对应分P：`P35`（单词）· `P36`（语法）

**核心知识点**

1. **`数量词 + 动词`** —— 名词前用数量词修饰，如「卵を一つ食べました」「本を二冊買いました」。数量词在日文里算是难点，不是难，而是要记的东西多。
2. **`时间 + 动词`（不加に）** —— 表示这个动作持续了多久（不是「几点钟」），所以时间必须紧贴动词、放在中间。
3. **`时间 + に + 次数 + 动词`** —— 表示在一定时间内做几次，如「週に2回泳ぎます」「2年に1回咲きます」。
4. **`ます形（去掉ます） + たいです`** —— 表示想做某事。老师在这里第一次预告「ます形活用」。
5. **`場所 + へ/に + 动词（ます形去ます） + に行きます/来ます/帰ります`** —— 去某地做某事，如「郵便局へ荷物を出しに行きます」。
6. **`数量 + で`** —— 用于不按重量、按个数卖的场合（3個で500円）；数量是 1 时可不加「で」（1個200円）。

**关键要点**

- **老师强调**：本课两个重点——量词，以及「场所＋へ＋动词去ます＋に行きます」，后者是全课最重要的语法，也是第一个「ます形活用」语法。
- **记忆法**：量词口诀「1・3・6・8・10」——有特殊变化的基本都出在这几个数上，「2・4・7・9」基本不变；其中 3 的变化概率比 1・6・8・10 小。1・6・8・10 的变化方式是「促音＋半浊音」（不是浊音），3 是「浊音」。
- **易错**：1–10 的「几个」全部按特殊读音记，不要拿「いち・に・さん」去推；人数只有「一人・二人」特殊，其余正常加「人」。
- **易错**：这里的「时间」表示动作持续多久，必须放动词前，不能像以前学的时间那样放句首（但「毎日」这类可以提到句首）。
- **易错**：「ます形去掉ます」不等于动词原形（働きます→働き，不是働く），所以不能拿原形去接「たい」。
- **易错**：询问数量读「なん」，不能读成「なに」；大动物用「頭」、小动物用「匹」。
- **中日对比**：中文一个「个」走天下，日文要按对象分（人／台／冊／匹／頭），这是本课最麻烦的地方。

**复习总结**

- 自测：能否不看表说出「1本・3本・6本・8本・10本」的读音，并解释 1・6・8・10 为什么变促音＋半浊音、3 为什么变浊音？

### 第14课 · 昨天去商场购物了

📺 对应分P：`P38`（单词，无字幕）· `P37`（て形/た形）· `P39`（语法）

**核心知识点**

1. **动词て形的变形** —— 三类：する→して、来る→来て；二类：る→て；一类：う・つ・る→促音＋て，む・ぶ・ぬ→んで，く→いて、ぐ→いで，す→して；特例 行く→行って。
2. **动词た形** —— 把て形结尾的 て→た、で→だ 即可，所以「た形一分钟就会」。
3. **`动词て形 + 动词`** —— 表示相继发生，把原本要用两句「ます形」说的话连成一句。
4. **`动词て形 + から + 动词`** —— 也表示相继发生，区别是更强调先后顺序，且「てから」在一个句子里只能用一次。
5. **`动词て形 + ください`** —— 请求某人做某事，「请……」。
6. **`場所 + を + 动词`** —— 表示经过或离开的场所（通ります／渡ります／過ぎます／出ます／卒業します）。

**关键要点**

- **老师强调**：动词三分类是前提，不会就先去补（视频简介里有动词三分类的课），否则变形和后面所有语法都听不懂。
- **记忆法**：一类动词「う・つ・る」下面都带一个小写的「っ」，所以变て形就是「促音＋て」；「む・ぶ・ぬ」鼻音很重，而「て」太轻，所以浊化成「ん＋で」。
- **记忆法**：一类动词里「す→して」「く→いて」两个直接死记；「ぐ→いで」通过与「く→いて」对比、加浊音来记。
- **易错**：行く→行って 是特例，不能按「く→いて」变成「行いて」。
- **易错**：走る（はしる）结构像一段，但它是**一类动词特例**；帰る、切る同理。
- **易错**：て形本身没有过去式，整句时态由句尾的ます形控制（「昨日…行って…読んで…帰りました」，句尾不能是「帰ります」）。
- **易错**：て可以连着出现两三个，但「てから」在一个句子里只能用一次。
- **易错**：あたり 是车站「附近、周围一片」，不是「车站前面」（前面是「駅の前」）。
- **易错**：なかなか 不能对长辈或上级使用，会显得不礼貌。
- **老师强调**：て形难在变形，用法其实不难；「～てくださいませんか」是「～てください」更礼貌的说法。
- **老师强调**：サ变动词是「名词＋します」，名词后加不加「を」都可以。

**复习总结**

- 自测：能否把「書く・泳ぐ・話す・待つ・死ぬ・遊ぶ・読む・帰る」一次不查地变成て形和た形，并说出「て＋动词」和「てから＋动词」的两点区别？

### 第15课 · 小野正在看报纸

📺 对应分P：`P40`（单词）· `P41`（语法）

**核心知识点**

1. **`动词て形 + います`** —— 表示正在做某事（加「今」更明确「此时此刻」）。
2. **`动词て形 + もいいです`** —— 表示许可，常见形式「～てもいいですか」＝我可以……吗。
3. **`动词て形 + はいけません`** —— 表示禁止、不可以做某事，语气带命令性。
4. **`名词 + に + 动词`** —— 表示附着点（乘交通工具、坐椅子等），如「公園でボートに乗ります」「電車に乗ります」「椅子に座ります」。
5. **`へ / に` 表示移动目的地时可以互换** —— 但其他用法的「に」（存在句、时间、对象、附着点）不能换成「へ」。

**关键要点**

- **老师强调**：读「てはいけません」时「ては」要连起来读，不能读成「て・は」；「てもいい」的「ても」也要连读。
- **易错**：「てはいけません」带命令语气，不能对长辈、上级使用；对长辈要用「～ないでください」（未然形＋ないでください，本课还没学未然形）。
- **易错**：「～てもいいですか」的肯定回答是「はい、いいです」，否定是「いいえ、いけません」；但「いいです」单独用也常表示委婉拒绝，要看语境。
- **易错**：表示附着点时必须用「に」，很容易误用成「を」。
- **易错**：「に」和「へ」只在表示移动目的地时可以互换，其他场合绝对不能换。
- **中日对比**：日本人不直接说「你不可以」，一般用「それは ちょっと…」这种把话说完又不说完的方式表达拒绝；只有规章、法律、社会惯例不允许时才直接说「～てはいけません」。
- **老师强调**：乗ります 除了「坐船」，还有「划船」的意思，不要只按字面理解。
- **老师强调**：ゆっくり 除了「慢慢地」，还可以表示「好好地」（ゆっくり休んでください）。

**复习总结**

- 自测：能否说出「～てもいいですか」的肯定与否定回答，并解释为什么不能对长辈说「～てはいけません」？

### 第16课 · 酒店的房间又宽敞又明亮

📺 对应分P：`P42`（单词）· `P43`（语法）

**核心知识点**

1. **一类形容词并列：`い → くて`** —— 去「い」加「くて」（広い→広くて）。
2. **二类形容词并列：直接 + `で`**（きれい→きれいで）。
3. **名词并列：直接 + `で`**（与二类形容词相同）。
4. **`动词て形 + います` 的第二种意思** —— 表示动作结束后留下的状态、结果（車を持っています／北京に住んでいます）。
5. **小句 + `が`** —— 表示转折，「但是、可是」。
6. **`まだ + 否定`** —— 「还没……」，后面只能接否定。

**关键要点**

- **老师强调**：「が」表转折，绝对不能读成疑问的「か」；「～ますか」和「～ますが」要分清，不要混着读。
- **易错**：回答「知っていますか」时，不知道必须说「知りません」，日语里没有「知っていません」这种说法；老师说这一点考试特别爱考。
- **易错**：一类形容词去「い」加「くて」，二类形容词和名词直接加「で」，三种连接方式不能混。
- **易错**：「まだ」后面只能接否定，不能接肯定句或动词原形。
- **记忆法**：て形并列的作用就是把原本要说两句的话合成一句（「小李是中国人。是北京大学的学生。」→一句）。
- **中日对比**：中文「什么什么费」一个词解决，日文要细分「費／料／代」（会費、送料、電気代、水道代），用词时要看清。
- **老师强调**：描述相貌特征要用固定搭配（指 太い／細い、足 大きい／小さい、鼻 高い／低い、背 高い／低い）。

**复习总结**

- 自测：能否把「这个教室又干净又明亮」「小李是中国人、北京大学的学生」各用一句并列句说出来？

### 第18课 · 手机变小了许多

📺 对应分P：`P46`（单词）· `P47`（语法）

**核心知识点**

1. **一类形容词 + `なります`：`い → く + なります`** —— 表示自然的变化。
2. **二类形容词 / 名词 + `に なります`** —— 同样表示自然的变化、成为。
3. **一类形容词 + `します`：`い → く + します`；二类形容词 / 名词 + `に します`** —— 表示人为地使之变化。
4. **`～ほうがいいです`** —— 比较两个以上事物的性质，表示「还是……比较好」；一类形容词直接接，二类形容词要加「な」。
5. **自动词和他动词** —— 自动词不借助外力、自己发生（一般用「が」），他动词需要外力才能发生（一般用「を」）；老师说明正式讲解在第33课。

**关键要点**

- **老师强调**：`なります` 是自然的变化，`します` 是人为的变化。老师用「热」举例：天气自然变热是「暑くなります」，开空调让房间变热是「暑くします」。
- **易错**：一类形容词用「く」，二类形容词和名词用「に」，两者的接续不能搞混。
- **易错**：「～ほうがいいです」二类形容词必须加「な」，一类形容词直接接。
- **记忆法**：点餐时说「～にします」是「我决定要这个」的意思，属于固定用法。
- **中日对比**：日本的「几折」和中文相反——日本的三折相当于中国的七折，看到「一折二折」不用惊讶。
- **易错**：似合います 是自动词，表示「合身、合适」，不要当着他动词用。
- **老师强调**：人和动物发出的声音用「声（こえ）」，物体发出的声音用「音（おと）」，两个词不能混。

**复习总结**

- 自测：能否说出「暑くなります」和「暑くします」的区别，并各造一句？

### 第19课 · 请不要忘记房间的钥匙

📺 对应分P：`P48`（单词）· `P49`（语法）

**核心知识点**

1. **未然形（ない形）的变形** —— 一类动词「う段→あ段」（特例：う→わ）；二类动词去掉「る」；三类动词 する→し（也有せ・さ）、来る→こ。未然形本身没有意思，只是变形，后面接各种语法。
2. **`动词ないでください`** —— 表示否定的命令，「请不要……」（＝未然形＋ないでください）。
3. **`动词なければなりません`** —— 表示必须做某事，语气比较强硬。
4. **`动词なくてもいいです`** —— 表示不做某事也可以。
5. **`は` 和 `が` 的区分** —— 旧信息在前用「は」，新信息在前用「が」；眼前直接观察到的现象用「が」；疑问词作主语时后面只能用「が」。

**关键要点**

- **老师强调**：未然形没有实际意思，只有变形；「ない形」＝未然形＋ない，两者只差一个「ない」。
- **易错**：一类动词未然形的特例是「う→わ」（買う→買わない），不是变成「あ」。
- **记忆法**：老师建议记「未然形＋ないでください」「未然形＋なければなりません」，比记「ない形＋でください」更好读、更不容易错。
- **易错**：「なければなりません」语气强硬；「なくてもいいです」是「不做也可以」，回答时要把意思转过弯来。
- **易错**：形容词、名词的过去式是「かった／だった」，与动词的「た形」不同（复习第16、18课的接续）。
- **中日对比/文化**：日语里「高级」说「上級」而不是「高級」，「高級」一般用来形容食材等。
- **老师强调**：は／が 的区分不止一种，本课讲的只是其中一点（新旧信息、眼前现象、疑问词主语），不能指望一条规则通吃。
- **老师强调**：「なければなりません」偏正式，「なくてはいけません」偏口语。

**复习总结**

- 自测：能否用未然形造出「请不要在房间里吃饭」「今天必须早点回去」「明天不运动也可以」三句？

### 第22课 · 小森每晚都看电视

📺 对应分P：`P54`（单词）· `P55`（语法）

**核心知识点**

1. **动词的敬体与简体** —— 敬体（ます形）对应简体：基本形、ない形、た形、なかった形，都由「ます形」变形得到。
2. **一类形容词的敬体与简体** —— 简体＝去掉「です」；否定 ～くない、过去 ～かった、过去否定 ～くなかった。
3. **二类形容词的敬体与简体** —— 「だ」是「です」的简体；否定 ～ではない、过去 ～だった、过去否定 ～ではなかった。
4. **名词的敬体与简体** —— 与二类形容词完全相同。
5. **简体疑问句** —— 去掉「か」，把最后一个音往上提（升调）。
6. **`けど`** —— 表示转折；也有表示铺垫的用法。

**关键要点**

- **老师强调**：简体（口语）常常无视助词、省略成分，学多了对写文章不利；初级阶段写作用敬体，简体「明白即可」。
- **易错**：「あります」的简体是「ある」，一定要记住。
- **易错**：二类形容词和名词的过去否定是「～ではなかった」，一类形容词是「～くなかった」，两者不能混。
- **易错**：简体疑问是升调，不是加「か」。
- **易错**：「わ」「わよ」是女性用语，男生不要用（用多了会显得像女生）。
- **中日对比/文化**：越高级的文章（法律、报纸、商业文件）反而越用简体；日常礼貌场合用敬体。

**复习总结**

- 自测：能否把「買います／買いません／買いました／買いませんでした」四句一次转成简体？

### 第23课 · 休息日，我会散散步购购物

📺 对应分P：`P56`（单词）· `P57`（语法）

**核心知识点**

1. **`动词た形 + り、动词た形 + り します`** —— 列举若干有代表性的动作。
2. **一类形容词 / 二类形容词 / 名词的「たりたり」** —— 分别用 ～かったり、～だったり（即过去式简体＋り），句尾接「です」；一般以反义词的形式出现。
3. **简体小句 + `かどうか`** —— 把「～ますか」的疑问句变成句子的一个成分，「是否……」。变形时要把「ます形」变回简体（基本形／た形）＋かどうか。
4. **简体小句（基本形 / ない形）+ `か` + `か`** —— 「去还是不去」的表达，与「かどうか」意思相同。
5. **疑问词小句 + `か`** —— 小句中有疑问词（いつ／どこ／だれ／何）时，用简体＋か。
6. **名词 / 二类形容词 + `かどうか`** —— 后面不加「だ」。

**关键要点**

- **老师强调**：「たりたり」后面一定要接「します」，很多同学会漏掉；这个「します」的时态由全文时态决定（昨天→しました，平时／将来→します）。
- **易错**：形容词和名词的「たり」是「～かったり／～だったり」，且名词、二类形容词后面不加「だ」。
- **易错**：「かどうか」前面的小句必须是简体，不能用「ます形」。
- **记忆法**：かどうか＝「是还是不是」，作用是把原来的两个句子合成一句。
- **易错**：「によって」要灵活翻译（「飞机票根据季节有时贵有时便宜」），中文不一定翻成「根据」。
- **老师强调**：本课其实只学两个语法（たりたり、かどうか），但每种都分很多情况，整节课都围绕这两个展开。

**复习总结**

- 自测：能否把「今年夏天去不去北京，我不知道」用「かどうか」和「～か～か」两种方式各说一遍？

### 第24课 · 我想小李马上要来

📺 对应分P：`P58`（单词，无字幕）· `P59`（语法）

**核心知识点**

1. **简体小句 + `と思います`** —— 表示「我觉得、我认为」；名词、二类形容词小句要加「だ」。
2. **简体小句 + `と言いました`** —— 转述别人说的话；要指明对谁说时，在人后面加「に」。另有 `と言っていました`，表示某人反复说起一件事。
3. **简体小句 + `のです / んです`** —— 说明原因、理由（口语多用「んです」）；名词、二类形容词要加「な」。
4. **小句 + `が`** —— 表示铺垫，为后一句做铺垫（与第16课的转折用法区分）。

**关键要点**

- **老师强调**：「と思います」的主语只能是「我」，第二人称、第三人称不能用「と思います」，要用「と思っています／と思っていました」。
- **易错**：名词、二类形容词小句要加「だ」（～だと思います）；「んです」前面名词、二类形容词要加「な」。
- **易错**：接「と思います」的必须是简体，「～ますか」不能直接接进去。
- **易错**：「～た形」才是简体，「～ました」不是简体（「休みました」不是简体，「休んだ」才是）。
- **老师强调**：读「と思います」时，「と」要跟前面的词连起来读（「～ないと 思います」），不要断成「～ない と思います」。
- **中日对比/文化**：日本人即使很确信，也不把意见强加于人，会说「我觉得这样比较好」，而不是「你这样做不对」。
- **易错**：「とうとう」多用于终于（盼来的）结果，不要用在「终于要分别了」这种消极场合。
