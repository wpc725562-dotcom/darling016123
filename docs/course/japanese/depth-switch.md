# 新标日 · 三种读法怎么选

本站的日语主线是同一本教材 ——《新版中日交流标准日本语》——
但**用三种详略写了三遍**。它们不是三份重复的资料，而是**三种读法**。

> ★ 2026-10-05 新增本页：此前这三条线在导航里**并列成三个入口**，读者不知道先看哪个、
> 也不知道三者覆盖的是同一批课次。现在合并为**一个入口 + 本页做选择器**。

## 四、三条线的质量提示

- **跟课笔记**：字幕来源是 B站 AI 自动识别，日文部分识别噪声较大，
  文中标注「ASR 不可靠」处请以教材为准。
- **深度笔记**：逐条详解，是三者里最可靠的语法依据。
- **同步手册**：⚠️ **第二卷（中级）与第三卷（高级）存在语法点错位**，第一卷已核对无误。
  复习时若发现对不上，以深度笔记为准。
