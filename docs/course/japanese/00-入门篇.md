## 第 1 讲 · 五十音（上）

📺 对应分P：`P3`

**核心知识点**

1. **あ行（あ い う え お）是元音行，也是最重要的一行** —— 日语所有发音都和这五个元音有关。所以第一件事是**把あ行读准**，第二件事是**背あ段**（あかさたなはまやらわ 这一竖列）。
2. **行的构成规律：辅音 + あいうえお** —— か行 = k + あいうえお，な行 = n + あいうえお。所以只要会读あ行、知道每行的辅音，剩下的音**可以自己推出来**，不必逐字死记。
3. **平假名与片假名** —— 写法不同、发音相同，可以理解为英语的大小写。平假名用于日本本土词，片假名用于外来词。
4. **假名的来源是汉字** —— 「假名」的「假」是假借的意思。あ←安、い←以、う←（数字）五、え←衣、お←我，所以联想记忆法才成立。
5. **清音行一览（上篇讲到な行）**：あ行 → か行 → さ行 → た行 → な行，每行 5 个音。

**关键要点**

- **老师强调（发音第一坑）**：`う` 读的时候**必须把嘴收回来**，不能像中文「乌」那样往外撅嘴。
- **老师强调（发音第二坑）**：`あ` 和 `お` 是**短音**，千万不要拉长读成「啊——」「哦——」。
- **易错（か 与 が）**：`か` 就读 **ka**，不读 ga。「听日本人读像 ga」有两种可能：① 人家读的就是 ka，你听成了 ga；② 那是**鼻浊音**，不是 g。
- **老师明确不建议学鼻浊音**：日本年轻人已完全不用；学了反而在默写单词时分不清 k / g，属于自找麻烦。**「写什么读什么」。**
- **易错（す 的发音）**：`す` 不是中文的「苏」也不是纯粹的「丝」，而是**苏与丝之间、略偏丝**的音。`し` 则读得像中文的「西」。
- **易错（ち 与 つ）**：`ち` 读得像汉语拼音的「qi」，`つ` 读得像「ci」。**这两个音不按罗马音走**。
- **易错（笔顺）**：`さ` 和 `き` 的**手写体下半部分不连笔**（印刷体才连）。`も` 的**第一笔是竖**，很多同学把第二笔当第一笔写，是错的。
- **易错（ら行读音）**：ら行**不读 r，全部读 l**（日本人发不出 r 音）——「日本人」他们会说成「立本银」。
- **记忆法（联想）**：か←加+口字旁＝咖；き←钥匙；く←（老师躺地上哭的嘴型）；け←计算的「计」；こ←把「口」封起来；さ←杀；し←吸管；す←饮料里插着的柠檬；せ←世界的「世」；そ←嗦面的样子；た←太阳的「太」；ち←6+1＝7；つ←吃豆豆的嘴；て←「天」；と←拖着走；な←水树奈奈；に←左边「一」右边「二」；ぬ←奴隶的「奴」；ね←「内」被淘汰出去（后面与れ、わ一起对比时再讲）。
- **声调重要性（本讲埋的伏笔）**：`もも` 读低高是「桃子」、读高低是「大腿」；`はし` 读低高是「桥」、读高低是「筷子」。**同样的假名，声调不同就是另一个词。**

**复习总结**

- 自测：① 不看表，从 あ行 推到 な行，每行五个音连着读出来；② 说出 `か` 的正确读音并解释「为什么不能读成 ga」；③ 指出 `さ`、`き`、`も` 三个字手写体的关键笔顺差别。

## 第 2 讲 · 五十音（下）

📺 对应分P：`P4`

**核心知识点**

1. **は行（は ひ ふ へ ほ）** —— 五个音**都可以当笑声**：は（开心）、ひ（坏笑）、ふ（女生捂嘴）、へ（得意）、ほ（老人／圣诞老人）。
2. **ま行（ま み む め も）** —— ま←末（读「麻子」）、み←m+i、む←木棍+母蛇、め←「女」（也可联想「ぬ 少了个圈」）、も←毛。
3. **や行只有三个音**：`や ゆ よ`（い段和え段的位置是空的，重复了元音）。
4. **ら行五个音**：ら り る れ ろ，全部读 l。
5. **わ行只有两个音**：`わ を`。**现代日语中 `を` 只作助词用**，基本不再作单词。
6. **ん（拨音）不属于任何一行** —— 单独一个音，跟在别的假名后面构成音节。

**关键要点**

- **老师强调（ふ 的读法）**：`ふ` 罗马音写作 **fu**（不是 hu），读法是**嘴唇留一条缝隙、把气吹出去**，跟中文「夫」不一样。**不要读成「夫」或「呼」。**
- **老师强调**：`は` **作助词时读 wa**（这是第 1 课语法里就会用到的高频点）。
- **易错（も 的笔顺）**：`も` 的**第一笔是竖**，不是第二笔。写错的人非常多。
- **易错（ゆ 的笔顺）**：`ゆ` 第一笔写到位**就停，不要画圈、不要连上去**（连上去是印刷体）。
- **易错（よ 的笔顺）**：第一笔写完**停住**，不上去、不画圈。
- **易错（ら行的 り 与 れ）**：手写体**不连笔**，连起来的是印刷体。
- **易错（ね 的记法）**：`ね` 用「内被淘汰出去」记；教材后文会把 `ね`、`れ`、`わ` 三个形近字放一起比较，那时这个方法会更好用。
- **记忆法（わ行）**：わ←青蛙「哇哇」叫；を←跨进水池的样子。

**复习总结**

- 自测：① 合上书写出 は行 → わ行 全部假名，并说明哪两个音「不按罗马音读」；② 说出 `ふ` 的正确口型，并解释为什么不能读成「夫」；③ 说出 `を` 在现代日语中的唯一用法。

## 第 3 讲 · 日语声调

📺 对应分P：`P5`（完整课）· `P8`（十分钟浓缩版，含三套联想记忆法）

**核心知识点**

1. **声调的两套标记法**
   - **画线法**：低音在字下画线、高音在字上画线（老师上课用的方法，直观）。
   - **数字法（N 型）**：**在第 N 个音之后降下来**。教材上用这种。教材**只标高音、不标低音**——没画线的地方就是低音。
2. **两条铁律（必须背）**
   - **铁律一：第一个音和第二个音一定不同音** —— 要么「低高」，要么「高低」，**不会出现「低低」或「高高」**。
   - **铁律二：出现降调之后不会再升回去** —— 所以日语里**不存在「高低高」的声调**。听日语不会有大幅起伏的波动。
3. **N 型怎么读**
   - **零型（平板型）**：**不下降**。第一个音低，之后一路高上去并保持。
   - **一型**：**第一个音就是高音，后面全低**。这是唯一「第一个音高」的类型。
   - **二型 / 三型 / N 型**：**除一型外，都是第一个音低**，然后在第 N 个音之后降下来。
4. **零型与二型的关系（本讲最容易混的点）** —— 对**只有两个音的词**，零型和二型**单读时完全一样**（都是「低高」）。区别**只在后面接助词时才显出来**：
   - **零型**：助词**跟着读高**（低高高）。
   - **二型**：助词**降下去**（低高低）。
5. **三套联想记忆法**（老师给了三种，挑适合自己的）
   - **方法一 · 联想中文**：零型←「我哥」；一型←「哥哥」；二型←「我哥哥」；三型←「美滋滋的」。把中文的调子往单词上带。
   - **方法二 · 用あいうえお当调子**：把 `あいうえお` 本身当成「低→高→降」的模板，拿单词往上套。
   - **方法三 · 汉语拼音声调**：低音读**第三声**（但别拖长），高音读**第一声**。
6. **为什么声调不能只靠汉语拼音** —— **日语里「高到低」的低音，和「低到高」的低音不是同一个音**。凡是出现「高到低」，必须靠对日语高低的**语感**去读，汉语拼音只能解决「低到高」的部分。

**关键要点**

- **老师强调**：教材标声调**只标高音**，没标的就是低音——不要因为「书上没画线」就以为不用管。
- **老师强调（纠错）**：联想表里写「あか＝哥哥」**不是**说あか是「哥哥」的意思，只是**声调接近**。别把联想表当词义表背。
- **易错**：一型与其余各型的分界在于「第一个音是高还是低」。**除一型外一律第一个音低**——记住这一条，看到一个数字就能判断首音。
- **易错**：零型与二型**不能只看单词本身**判断，必须看后面接不接助词、接了什么助词。
- **易错（重灾区）**：`もも`（桃子／大腿）、`はし`（桥／筷子）、`かみ`（纸／头发）、`あめ`（雨／糖）、`にほん`、`びよういん`（美容院）——**声调不同，词义完全不同**。老师举的实战例子：在水果店把「桃子」说成「大腿」，女店员会被吓到。
- **老师强调（发音要趁早）**：「不要想着考过 N2、N1 以后再去练发音，**那时候已经很难改回来了**。发音一定要从五十音阶段就抓住。」

**复习总结**

- 自测：① 默写两条铁律；② 给 `ワタシ`、`アナタ`、`アノヒト` 标出是几型（答案：零型、二型、二型）；③ 说出零型和二型在**单读时**和**接助词时**的差别各是什么。

## 第 4 讲 · 浊音、半浊音与长音

📺 对应分P：`P6`

**核心知识点**

1. **浊音：右上角加两个点，四行变四行**

   | 原行 | → 浊音行 | 辅音变化 |
   |:--|:--|:--|
   | か行 | **が行**（が ぎ ぐ げ ご）| k → g |
   | さ行 | **ざ行**（ざ じ ず ぜ ぞ）| s → z |
   | た行 | **だ行**（だ ぢ づ で ど）| t → d |
   | は行 | **ば行**（ば び ぶ べ ぼ）| h → b |

2. **半浊音：右上角加一个圆圈** —— 只有は行有：**ぱ行**（ぱ ぴ ぷ ぺ ぽ），h → p。
3. **长音规则（背下来）**

   | 规则 | 例 |
   |:--|:--|
   | **あ段 + あ** | おかあさん（妈妈）|
   | **い段 + い** | おにいさん（哥哥）|
   | **う段 + う** | くうき（空气）|
   | **え段 + え** | おねえさん（姐姐）|
   | **お段 + お** | とおい（远）|
   | **补充：え段 + い** | せんせい（老师）|
   | **补充：お段 + う** | おとうさん（爸爸）、こうこう（高中）|

4. **片假名的长音用「ー」直接标** —— 不需要自己推段，一眼就能看出（如 ゲーム、スーパー）。
5. **浊音里的同音陷阱** —— **じ 与 ぢ 同音、ず 与 づ 同音**。读音一样，但**写哪个字必须记清**。

**关键要点**

- **老师强调**：浊音变形是**纯记忆内容**，课堂上讲得快、量又大，必须课后自己多花时间把「每个音能不能对上」过熟。
- **老师强调（易错）**：`す` 和 `ち` 的浊音**不按罗马音走**——`ず` 不是「zu」、`じ` 不是「zi」，两者读音相同，都是「じ」的音。
- **易错（同音陷阱）**：じ／ぢ 同音、ず／づ 同音，所以**背单词时必须记清用哪个字**。例如「続く」写作 **つづく**，不能写成 つずく。
- **易错（英语干扰）**：が行不要被英语发音带跑，把 `げ` 读成英语的 /n/ 一类的音是错的，**日语和英语没有关系**。
- **易错（半浊音）**：は行**既有浊音（ば行）又有半浊音（ぱ行）**，两套都要记，别只记一套。
- **老师强调（长音必须读出来）**：不记长音规则，就会按自己的习惯读，**往往发现不了长音**，读出来就是错的（如 おかあさん 读成 おかさん）。
- **易错（高到低的下滑）**：长音里遇到「高到低」必须读出**从高往下降的过程**；「低到高」必须读出**往上滑的过程**。少了这个滑的过程，长音就不到位。
- **记忆法（家庭成员同调）**：`おかあさん`、`おばあさん`、`おにいさん`、`おじいさん` **声调是一样的**。同类词归类后声调常有一致规律。
- **易错（差一个长音，意思全变）**：`おばあさん`（奶奶／外婆）vs `おばさん`（阿姨）；`おじいさん`（爷爷）vs `おじさん`（叔叔）。

**复习总结**

- 自测：① 默写四条浊音行 + 一条半浊音行；② 写出 7 条长音规则并各举一例；③ 判断 `おばあさん` 和 `おばさん` 的长音在哪一段，并说明两者意思差别；④ 说出 じ／ぢ、ず／づ 为什么容易写错。

## 第 5 讲 · 促音与拗音

📺 对应分P：`P7`

**核心知识点**

1. **促音：小写的 `っ`** —— **它不发音，作用是「停一拍」**。读法：前一个音读完**憋住一拍**，再把气冲出去。
   - 例：`きって`（邮票）—— き 之后停一拍再 て；`がっこう`（学校）。
2. **有促音 vs 没促音是两回事** —— 老师举的对照：`おと`（声音）与 `おっと`（丈夫）；`かこ`（过去）与 `かっこ`（括号／样子）；`ぶか`（部下）与 `ぶっか`（物价）。
3. **拗音：い段假名 + 小写的 ゃ / ゅ / ょ，共 36 个** —— 写法上第二个字要**小写**。
4. **拗音的节拍规则** —— **两个字读一拍**（相当于一个音的长度）。对比：小写的 `っ` **独占一拍**，而拗音是**两个字合占一拍**。
5. **拗音的构成规律** —— 由 か／が／し／じ／ち／に／ひ／び／ぴ／み／り 各配上 ゃゅょ 组成。注意 `ぢゃ` 与 `じゃ` 同音、`ぢゅ` 与 `じゅ` 同音，**同音但写法不同**。
6. **拗音后面也能接长音** —— 判断方法：看拗音结尾的元音属于哪一段，再套长音规则。
   - 例：`きゅう` —— きゅ 的结尾是「う段」，符合「う段 + う」，所以**读长音**。
   - 例：`しょう` —— しょ 的结尾是「お段」，符合「お段 + う」，**读长音**。

**关键要点**

- **老师强调（大小写 `っ`）**：一开始分不清小写的 `っ` 很正常，「多看一段时间日语之后，大小写一眼就能看出来」，不必焦虑。
- **老师强调（促音不难）**：促音本质上**只是一种停顿**，停顿之后把憋住的气直接冲出去即可，不用当难点。
- **易错（拗音的难点在 ゅ）**：中国学生读拗音最容易出错的是 **ゅ 和 ょ 的音**（如 きゅ、しゅ 一类），要**多跟读、多对比老师的发音**。
- **易错（不要用罗马音记拗音）**：拗音的罗马字拼写属于「日文的拼写方式」，**拿它去读反而容易读错**。正确方法是**把两个字当成一个字连读**（如 き + ゃ → きゃ，一口气读出来）。
- **易错（同音字）**：`ぢ` 与 `じ`、`ぢゃ` 与 `じゃ` 同音，**背单词时要看清到底是哪个字**。
- **老师强调（本讲是入门收尾）**：到这里「五十音 → 声调 → 浊音 → 长音 → 促音 → 拗音」全部讲完，**接下来要把它们全部合起来放进单词里练**——标上声调后能不能把长音读对、能不能把声调读对，才是真掌握。
- **易错（片假名 vs 平假名）**：像「上海」这样的外来词用**片假名**写（シャンハイ），来自中文的词也归入外来词处理。

**复习总结**

- 自测：① 说出促音、拗音各占几拍；② 读出 `きって`、`がっこう`、`おっと`、`かっこ` 并指出停顿位置；③ 判断 `きゅう`、`しょう` 里有没有长音、为什么；④ 说出 `ぢゃ` 和 `じゃ` 的关系。

## 第 6 讲 · 第 0 课：日语如何自学 + 常见问题

📺 对应分P：`P9`

**核心知识点**

1. **教材**：《新版中日交流标准日本语》**第二版**（第一版是 1988 年的，不必找）。
2. **教材与等级的大致对应**（**非绝对**）

   | 教材 | 大致对应 |
   |:--|:--:|
   | 初级上 | N5 |
   | 初级下 | N4 |
   | 中级上 | N3 |
   | 中级下 | N2 |
   | 高级上 + 高级下 | N1 |

   老师原话：有同学只学完初级上下、补了些 N3 高频词就去考 N3 且分数不低；也有同学学到初级上下**还考不过 N5**。所以**别太在意「哪本书对应哪个等级」，要看每一课有没有吃透**。学完自己买几套真题刷一刷就知道水平。
3. **本课（B站合集）不单独教片假名** —— 原因：线上公开课里能把五十音坚持下来的大概只有 20%，再压一套片假名下去，大部分人会被劝退，还容易把平假名和片假名记混。**替代方案：通过新标日里的外来词慢慢记片假名。**
4. **自学流程（老师给的建议顺序）**
   1. 先学**单词**——不要求全背下来，但要**眼熟、知道大概意思**。
   2. 再**刷语法课**。
   3. 学完语法后**背诵单词、背诵课前课文**。
   4. 再刷**课后题目 + 同步练习册**，并且搞懂。
   5. **每学完一个单元，把该单元所有课文和单词复习一遍**（默写课文 / 听写单词）。
5. **进度建议（很重要）**
   - **上班族：一周 1–2 课**（常常一周学不完一课）。
   - **学生党：不超过 3 课**（多数人是 1–2 课）。
   - 老师原话：「两周学完初级」「一个月把初级上下刷完」——**不正常**。
6. **一定要养成记笔记的习惯** —— 「这个笔记可以说是今后复习时**最宝贵的学习资料**」。

**关键要点**

- **老师强调（吃透的标准）**：每位同学对「掌握一课」的理解不同。有人把单词课文全背下来、刷完一课所有的题、再复习一遍；有人只听个语法课、单词也不背，就觉得自己 100% 掌握了——**后者不算掌握**。
- **老师强调（关于考级目的）**：如果是为高考日语，**学校有日语班就跟日语班走**，本视频只当复习资料；没有日语班且已决定考日语，就**先把初级上下吃透**，单词可换用高考日语高频词书。本课不是针对高考日语的。
- **老师强调（年龄不是问题）**：老师认识的前辈 40 岁开始学中文，现在中日、日中翻译都做。
- **安全提醒（防骗）**：老师和管理**不会主动私聊、不会加 QQ／微信、不会发学习资料**。遇到打着「发资料的老师」旗号的人要高度警惕——常见套路是发病毒／发网上随便能搜到的资料，然后忽悠你上体验课、买课。
- **老师补充**：单词不会背可以看「单词带背」合集，课文不会背可以看「课文带读」合集，把碎片时间利用起来磨耳朵。
