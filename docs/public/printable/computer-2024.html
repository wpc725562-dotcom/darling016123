第 1 题 · C 程序概述

以下关于 C 程序的叙述中，错误的是（ ）

  • A. 语句最后必须是分号
  • B. C 程序的基本组成单位是函数
  • C. 注释可以用 \N 开始
  • D. 一条语句可以分成多行来写

答案与解析

答案：C · 考点 1.1 C语言概述与基本概念

解析：C 语言注释用 /* */ 或 //，不存在 \N 开头的注释格式。A 正确（语句以分号结尾）；B 正确（C 以函数为基本组成单位）；D 正确（一条语句可跨多行）。

第 3 题 · 程序输出（循环）

下面程序输出结果为（ ）


int a = 1, b = 0;
printf("%d", b = a + b);
printf("%d", a = 2 - b);
  • A. 1, 0
  • B. 1, 2
  • C. 3, 2
  • D. 0, 0

答案与解析

答案：B（回忆版共识） · 考点 1.2 数据的存储与运算

解析 / 注意：

  • 按字面逐步：b = a + b → b = 1，输出 1；a = 2 - b → a = 1，输出 1 → 连写为 11，选项中无。
  • 回忆版 OCR/措辞可能偏差：若第二式为 a = 2 * b，则输出 1 与 2，对应选项 B。
  • 刷题重点：赋值表达式可作 printf 实参；逗号/连写输出不要想当然。

第 20 题 · 单链表插入

在单链表中，要将 s 所指向结点插入到 p 所指向结点之后，其语句应为（ ）

  • A. s->next = p + 1; p->next = s;
  • B. s->next = p->next; p->next = s->next;
  • C. (*p).next->s; (*s).next = (*p).next;
  • D. s->next = p->next; p->next = s;

答案与解析

答案：D · 考点 2.2 线性表

解析（顺序不能反）：

  1. s->next = p->next; // 先挂上 p 的后继
  2. p->next = s; // 再让 p 指向 s

先改 p->next 会丢后继。B 第二步把 p->next 设回 s->next 等于没插对。

第 36 题 · 数据项与 ADT

什么是数据项？什么是抽象数据类型（ADT）？（10 分）

答案与解析

考点 2.1 数据结构基本概念

参考答案：

  • 数据项：数据结构中讨论的最小单位，不可再分割。例：学生的学号、姓名、成绩。
  • 抽象数据类型（ADT）：一个数学模型 + 定义在该模型上的一组操作。特征：

- 抽象性：只关心「做什么」，不关心「怎么做」

- 封装性：数据与操作封装，外部仅通过接口访问

  • 常用三元组：ADT = (D, S, P) —— 数据对象、关系集、操作集
  • 例：整数 ADT 含数据 {…,-1,0,1,…} 与操作 {+,-,*,/,%}，使用者无需知道底层二进制实现。

第 37 题 · 程序段功能分析

int a[10] = {85, 72, 93, 68, 80, 76, 90, 83, 78, 88};

参考答案：

  • 功能：计算数组 a 中 10 个元素的平均值并输出。
  • 循环结束时 i = 10（当 i=10 时 i<10 不成立退出）。
  • 此时 sum=803，输出 平均值 = 80.3。

第 38 题 · 顺序表优缺点

简述顺序表存储结构的优缺点。（10 分）

答案与解析

考点 2.2 线性表

优点缺点
随机访问：下标 O(1)插入/删除平均 O(n)，需大量移动
存储密度高（无指针开销）预分配容量，易浪费或不够用
实现简单（数组即可）需连续大块内存，碎片敏感

适用：数据量已知、查多改少。

第 39 题 · 有向图出入度

什么是有向图？什么是有向图中顶点的出度和入度？（10 分）

答案与解析

考点 2.6 图

  • 有向图：顶点集 + 边集，边为有序对 <v,w>（从 v 指向 w 的弧）。<v,w> 与 <w,v> 是不同的边。
  • 出度 OD(v)：以 v 为弧尾的弧数（从 v 出发）。
  • 入度 ID(v)：以 v 为弧头的弧数（指向 v）。
  • 性质：Σ 出度 = Σ 入度 = 边数。

第 40 题 · switch 分级输出

写出以下程序的输出结果。


#include <stdio.h>
int main() {
    int x;
    scanf("%d", &x);      // 假设输入 75
    int n;
    switch (x / 10) {
        case 0: case 1: case 2: case 3: case 4: case 5:
            n = 0; break;
        case 6: case 7:
            n = 1; break;
        case 8:
            n = 2; break;
        case 9: case 10:
            n = 3; break;
        default:
            n = -1;
    }
    printf("n = %d\n", n);
    return 0;
}

答案与解析

答案：n = 1 · 1.4 选择结构程序设计

解析：75/10=7 → case 7 → n=1。等级映射：0–59→0，60–79→1，80–89→2，90–100→3。

第 43 题 · 二维数组编程

编程：将 201~209 这 9 个数按行存入 3×3 的二维数组，并输出矩阵。

答案与解析

考点 1.6 数组 · 拆练 05 手写编程


#include <stdio.h>
int main() {
    int a[3][3];
    int num = 201;
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            a[i][j] = num++;
        }
    }
    printf("输出矩阵：\n");
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            printf("%d ", a[i][j]);
        }
        printf("\n");
    }
    return 0;
}

输出矩阵：
201 202 203

207 208 209

第 44 题 · 数组求最大值

编程：输入 30 名学生的成绩，输出最高分。

答案与解析

考点 1.6 数组 · 1.5 循环结构程序设计


#include <stdio.h>
int main() {
    int scores[30];
    int max;
    printf("请输入30名学生的成绩：\n");
    for (int i = 0; i < 30; i++) {
        scanf("%d", &scores[i]);
    }
    max = scores[0];
    for (int i = 1; i < 30; i++) {
        if (scores[i] > max) {
            max = scores[i];
        }
    }
    printf("最高分 = %d\n", max);
    return 0;
}

评分要点：数组（2）| 输入循环（2）| 最大值逻辑（4）| 输出（2）

扩展：可不存数组，边读边比，只保留 max。

第 45 题 · 循环求和编程

编程：计算 1~300 之间所有奇数的和与偶数的和，并分别输出。

答案与解析

考点 1.5 循环结构程序设计


#include <stdio.h>
int main() {
    int sum_odd = 0;
    int sum_even = 0;
    for (int i = 1; i <= 300; i++) {
        if (i % 2 == 1) {
            sum_odd += i;
        } else {
            sum_even += i;
        }
    }
    printf("奇数和 = %d\n", sum_odd);
    printf("偶数和 = %d\n", sum_even);
    return 0;
}

输出：


奇数和 = 22500
偶数和 = 22650

验证：1…300 总和 300×301/2=45150，22500+22650=45150 ✅

优化：等差数列公式 O(1) 直接得：奇数 150×150=22500，偶数 150×151=22650。

评分要点：初始化（2）| 循环范围（2）| 奇偶判断（3）| 累加（2）| 输出（1）
