第 1 题 · sizeof 运算符

C语言中，可用来测定数据类型长度的运算符是（ ）

  • A. &
  • B. ==
  • C. sizeof
  • D. >>

答案与解析

答案：C · 考点 1.2 数据的存储与运算

解析：

  • sizeof 是关键字，不是函数 —— 只是用法长得像函数（sizeof(a) 的括号不是函数调用括号）。
  • A & 是取地址，B == 是相等判断，D >> 是右移。
  • 配套记忆：16 位机 int 占 2 字节，32/64 位机占 4 字节。真题考得较多的是 16 位机。

第 2 题 · 表达式求值

下列C语言表达式的值为2的是（ ）

  • A. 5%3
  • B. 5/3
  • C. 5>3 && 1>2
  • D. a=2,b=8

答案与解析

答案：A · 考点 1.2 数据的存储与运算

解析：

选项值依据
A 5%32求余。结果正负与被除数相同：-5%3 = -2、5%-3 = 2
B 5/31两侧都是整数 ⇒ 结果必为整数，向下取整（不四舍五入）
C 5>3 && 1>201 && 0 = 0。逻辑与两侧全真才为真
D a=2,b=88逗号表达式取最后一个

⚠️ 顺带一个常考类型题：5/2.0 结果是 2.5，问类型要答 double —— 所有实型常量一律是 double。

第 3 题 · 条件表达式

已知 int a=2, b=3; 则条件表达式 a>b?1:0 的值是（ ）

  • A. 3
  • B. 2
  • C. 1
  • D. 0

答案与解析

答案：D · 考点 1.4 选择结构程序设计

解析：a>b 即 2>3，不成立 ⇒ 取冒号后面的 0。

三目运算符 条件 ? 真值 : 假值，共三个操作数，故称三目。

第 4 题 · strcat 与 strlen

已知 char S1[10]="chatgpt", S2[10]="deepseek"，则 strlen(strcat(S1, S2)) 的值为（ ）

  • A. "deepseek"
  • B. 8
  • C. "chatgptdeepseek"
  • D. 15

答案与解析

答案：D · 考点 1.6 数组（字符串处理函数）

解析：

  • strcat(S1, S2)：把 S2 拼接到 S1 后面，结果存回 S1 ⇒ "chatgptdeepseek"
  • strlen(...)：求长度 = 7 + 8 = 15
  • strlen 只算有效字符，'\0' 不计入。（但数组空间要把 '\0' 算进去）

string.h 四个高频函数（题中一次考了两个，另两个也要记）：

函数作用记法
strcat拼接concatenate
strlen求长度length
strcpy复制copy
strcmp比较compare，返回负数/0/正数

⚠️ 两道送分题别丢：

① char S1[10]; S1 = "abc"; 不合法 —— 数组名是地址常量，不能赋值。要改内容必须用 strcpy。

② 字符串字面量 "abc" 本身也是地址（字符 'a' 的地址），这是规定，记住即可。

③ strcmp("abcd","abcE") ⇒ 逐字符比 ASCII，前三个相等，'d' < 'E' ⇒ 返回负数（默认 −1）。

⚠️ 真题原始写法提示：S1[10] 实际装不下 15 个字符。这是原卷的写法，考的是 strcat 的语义而非数组容量 —— 别在这里纠结。

第 5 题 · 二叉树结点数

深度为4的二叉树结点数最多为（ ）

  • A. 8
  • B. 15
  • C. 16
  • D. 32

答案与解析

答案：B · 考点 2.5 树和二叉树

解析：

  • 结点数最多 ⇒ 每层都填满 ⇒ 满二叉树
  • 深度 4：1 + 2 + 4 + 8 = 15 = 2⁴ − 1

两个必背公式：

问公式
深度为 n 的满二叉树结点总数2ⁿ − 1
第 k 层的结点数（最多）2^(k−1)

⚠️ 满二叉树 vs 完全二叉树（年年考区别）：

  • 满二叉树：每层都填满，非叶子结点都有两个子结点。
  • 完全二叉树：结点从上到下、从左到右依次排列，中间不能空。

判定口诀：「只有右孩子、没有左孩子」的结点一出现，就不是完全二叉树。

第 6 题 · 指针与数组

已知 int a[ ] = {1,2,3,4}; int *p = a+1; 则表达式 *p * a[2] 的值为（ ）

  • A. 2
  • B. 3
  • C. 4
  • D. 6

答案与解析

答案：D · 考点 1.8 指针

解析：


下标   a[0]  a[1]  a[2]  a[3]
值      1     2     3     4
              ↑
              p = a+1
  • p = a+1 ⇒ p 指向 a[1] ⇒ *p = 2
  • a[2] = 3
  • *p * a[2] = 2 × 3 = 6

🔑 * 的两种身份（本题的真正考点）：

位置含义
定义时 int *p声明「p 是指针变量」
使用时 *p解引用（取值运算符）：取出 p 所指向内存里存的值

概念链：指针就是地址，地址就是指针；而指针变量是「用来存放地址的变量」。定义时类型必须与被指对象一致。

第 7 题 · 单链表插入

在单链表中，q所指向结点为p所指结点的直接前驱结点，将s结点插入q和p之间的语句为（ ）

  • A. p->next=s; s->next=q
  • B. q->next=s; s->next=p
  • C. s->next=p->next; p->next=s
  • D. p->next=s->next; s->next=p

答案与解析

答案：B · 考点 2.2 线性表

解析：题设 q 在 p 前面，目标是把它变成 q → s → p。


插入前：  ... → [q] → [p] → ...
插入后：  ... → [q] → [s] → [p] → ...
  • 让 q 的 next 指向 s：q->next = s;
  • 让 s 的 next 指向 p：s->next = p;

两句先后顺序可以互换 —— 因为 q->next 和 s->next 互不依赖（不像「先断链再找后继」那种必须讲究顺序的写法）。

🔑 单链表结点结构：data（数据域）+ next（指针域，存下一个结点的地址）；最后一个结点 next = NULL。

直接前驱/后继 = 紧邻的前/后一个结点；不加「直接」二字时，前面的所有结点都叫前驱。

第 9 题 · 广义表长度与深度

广义表 L = (((a), b), c, d, e) 的长度和深度分别为（ ）

  • A. 3和2
  • B. 4和2
  • C. 3和4
  • D. 4和3

答案与解析

答案：D · 考点 2.4 串、数组和广义表

解析：

  • 长度 = 最外层元素个数 = ((a), b)、c、d、e = 4
  • 深度 = 括号最多嵌套几层 = 最外层 → ((a), b) → (a) = 3

🔑 广义表两条定义：

  • 长度 = 最外层有几个元素（一个子表算一个元素，不算里面几个）
  • 深度 = 数最深层的括号层数
  • L = ( ) 是空表，长度为 0

⚠️ 该题括号写法以原卷为准 —— 视频画面帧上括号渲染不清，本页按「长度 4、深度 3」的答案反推结构。

第 12 题 · 叙述正误

下列叙述正确的是（ ）

  • A. 一个C语言程序可以有很多个main函数
  • B. 一个C程序总是从main函数开始执行

第 13 题 · 复合赋值运算

程序段 int a=6; a+=a-=a*a; 执行后a的值为（ ）

  • A. 36
  • B. 30
  • C. -60
  • D. -24

答案与解析

答案：C · 考点 1.2 数据的存储与运算

解析：赋值运算符从右至左结合，且优先级极低（倒数第二，只比逗号高），所以先算 a*a。

步式子计算a 的值
0—初值6
1a*a6×6 = 366
2a -= 36a = 6 − 36 = −30−30
3a += (−30)a = −30 + (−30) = −60−60

复合赋值语义：a += b 等价于 a = a + b（左边的 a 不动，把 a+b 的结果赋回 a）。

⚠️ 关键坑：第 2 步执行完 a 已经变成 −30，第 3 步用的是新值，不是原来的 6。很多人错在全程用 6。

第 14 题 · 逻辑表达式

正确表达逻辑关系"a>10或a<0"的（ ）

  • A. a>10 or a<0
  • B. a>10 | a<0
  • C. a>10 && a<10
  • D. a>10 || a<0

答案与解析

答案：D · 考点 1.4 选择结构程序设计

解析：

选项判读
Aor 不是 C 运算符（那是 Python）
B`\` 是按位或，不是逻辑或
C&& 是逻辑与，且 a<10 写错了
D`\\` 逻辑或 ✓

🔑 三个优先级（年年考，记住这一句就够）：

算术 > 关系 > 逻辑

例外：单目运算符优先级最高（! 逻辑非、~ 取反、++/--）。

补充：赋值运算符倒数第二，逗号最低。

第 16 题 · 无向图度数

一个无向连通图，有8个顶点，12条边，则所有顶点的度总和为（ ）

  • A. 8
  • B. 12
  • C. 20
  • D. 24

答案与解析

答案：D · 考点 2.6 图

解析：

所有顶点的度之和 = 边数 × 2

每条边连接两个顶点，给两端的度各贡献 1 ⇒ 12 × 2 = 24。

🔑 与顶点个数无关！ 题里给的「8 个顶点」是干扰项 —— 这是本题的陷阱。

第 18 题 · 运算符优先级

优先级最高的运算符是（ ）

  • A. ~
  • B. /
  • C. <<
  • D. &&

答案与解析

答案：A · 考点 1.2 数据的存储与运算

解析：~ 是取反（按位取反），属单目运算符；单目运算符优先级最高。

🔑 单目 = 只参与运算一个对象：~a、!a、++a、a--。

常规顺序：算术（/）> 关系 > 逻辑（&&）；<< 移位介于算术与关系之间。

做题动作：先找哪个运算符只有一个操作数 —— 那个就是最高的。

第 19 题 · 标识符命名

C语言中不能为用户自定义标识符为（ ）

  • A. auto
  • B. _My
  • C. boll
  • D. done

答案与解析

答案：A · 考点 1.1 C语言概述与基本概念

#规则

C. boll普通标识符，非关键字✅ 能
D. done普通标识符，非关键字✅ 能

第 20 题 · 循环队列判满

某循环队列Q的最大队列长度为M(M>3)，队头指针为front，队尾指针为rear，则Q的满队列条件为（ ）

  • A. Q->front == Q->rear
  • B. Q->front == Q->rear+1
  • C. Q->front == (Q->rear+1)%M
  • D. Q->front == (Q->rear-1)%M

答案与解析

答案：C · 考点 2.3 栈和队列

解析：逐项看 —— A 是队空条件，不是队满。

选项判定
A. front == rear❌ 这是队空条件
B. front == rear+1❌ 少了取模 %M，只在 rear 还没绕回数组末尾时偶然成立
C. front == (rear+1)%M✅ 队满条件 —— rear 再走一格（取模绕回）就撞上 front
D. front == (rear-1)%M❌ 符号反了（rear-1 是往回走）

为什么队满条件是「rear 加 1 再取模」：

  • 队列是环：rear 走到数组末尾后，(rear+1)%M 会绕回下标 0。
  • 约定 rear 指向队尾元素的下一格（空位）。所以「rear 的下一格 = front」= 再存一个就会撞上队头 → 满。
  • 代价：这套判据牺牲一个存储空间（严蔚敏版教材的做法）。所以长度为 M 的数组最多存 M−1 个元素。
  • 为什么不直接用 front == rear 判满：队空时 front == rear 也成立 —— 同一个条件对应两种状态，无法区分。

循环队列三个公式（必背）：

条件公式说明
队空front == rear两个指针重合
队满(rear + 1) % M == front牺牲一个存储空间
元素个数(rear - front + M) % M先减后加 M 再取模，防负数

队列基础（本题解析里复习到的）：

队列：操作受限的线性表 —— 一端插入（队尾 rear）、另一端删除（队头 front），先进先出 FIFO。插入叫入队，删除叫出队。

指针指向
front队头元素
rear队尾元素的下一个位置 ← 注意不是队尾元素本身
操作步骤
入队先送值到队尾位置，再 rear + 1
出队先取队头元素，再 front + 1

⚠️ 本页只考顺序实现（不考链式）。

📌 见 2.3 栈和队列。

第 22 题 · 时间复杂度

程序段 {n++;s+=n;} 的时间复杂度为O(n)。（ ）

答案与解析

答案：× · 考点 2.9 算法基本概念与分析

解析：

  • 程序段里只有两条语句（n++ 和 s+=n），各执行一次就结束了。
  • 执行次数是常数次（2 次）→ 时间复杂度是 O(1)，不是 O(n)。
  • 核心判据：时间复杂度看的是「执行次数随 n 增长的阶」，不是「代码里有没有出现变量 n」。
  • 常见陷阱：n 出现了不等于 O(n)。要看 n 是否出现在循环条件/循环次数里。

📐 时间复杂度「三步法」（P3 讲解，本卷必考技能）

很多同学靠「凭感觉」猜复杂度 —— 这个方法把猜测变成机械推导：

步做什么
①列表格：循环次数从 0 开始列（0、1、2…k），写出每轮之后循环条件里那个量变成了多少
②写结束条件：从表格找规律，写出「第 k 次时条件不成立」的式子，再令它等于 n（约等）
③解方程：解出 k，k 的表达式就是复杂度（去掉系数、只留最高阶）

三个必会例子（都出自本卷讲解）：

循环次数表结束条件解出 k复杂度
while (i*i*i <= n) i++;0 次→1³，1 次→2³，…，k 次→k³k³ > n ⇒ k³ = nk = ∛nO(∛n)
while (i <= n) i *= 2;0 次→1，1 次→2，2 次→2²，…，k 次→2ᵏ2ᵏ > n ⇒ 2ᵏ = nk = log₂nO(log n)（底数省略）
双层 for（外层 i=1…n，内层 j≤2i）内层次数 = 2、4、6、…、2n—等差数列求和O(n²)

两条收尾规则：

  1. 只留最高阶：O(n² + n) → O(n²)；O(3n) → O(n)（系数扔掉）。
  2. 对数省略底数：O(log₂n) = O(log n)。因为 n 趋于无穷，换底只差一个常数系数。

双层循环速算：把「外层每个 i 值对应的内层次数」列出来，求和，再化简。上例：2+4+6+…+2n = 等差数列 = n(2+2n)/2 = n²+n → O(n²)。

第 23 题 · printf 与 '\0'

C语言中，printf函数输出字符串时，遇到'\0'就停止输出。（ ）

答案与解析

答案：√ · 考点 1.6 数组

解析：

  • '\0' 是 ASCII 值为 0 的字符，是 C 语言约定的字符串结束标记（NUL）。

第 24 题 · 数组名作实参

C语言中，若用数组名作为调用函数的实参，则传递给形参的数组的第一个元素值。（ ）

答案与解析

答案：× · 考点 1.8 指针

解析：

  • 数组名作实参时，传递的是数组首元素的地址（即指针），不是首元素的值。
  • 等价关系：a ⟺ &a[0]（数组名本身是地址常量）。
  • 所以形参要写成指针或数组形式：void fun(int a[]) ⟺ void fun(int *a)。
  • 为什么这条很重要：正因为传的是地址，函数内 a[i] = x 才会真正改到主调函数的数组；如果传的是「值」（拷贝），改不动。
  • 反例记忆：数组名不能被赋值（a = p; 报错），因为它是地址常量；但 int *p = a; 合法。

第 25 题 · 完全二叉树

一棵完全二叉树有31个结点，则该二叉树是满二叉树。（ ）

答案与解析

答案：√ · 考点 2.5 树和二叉树

解析：

  • 满二叉树结点数公式：n = 2ʰ − 1（h 为层数）。
  • 代入：31 = 2⁵ − 1 ✅ —— 所以它正好是5 层满二叉树。
  • 判定规律：完全二叉树的结点数恰好等于 2ʰ − 1 时，它必然是满二叉树（因为完全二叉树是「从上到下、从左到右」依次排列，排满 2ʰ−1 个结点就一层不差）。
  • 对比记忆：

- 满二叉树：每层都满，结点数 必为 2ʰ − 1。

- 完全二叉树：只允许最后一层从右往左缺结点；结点数不一定是 2ʰ − 1。

- 31 是 2⁵ − 1 → 判「满」；若是 30 个结点，就不是满二叉树（仍是完全二叉树）。

第 27 题 · 栈的出栈序列

一个空栈S依次全部压入字符c、i、g、a、m后，再进行出栈至S为空，得到字符串为"cigam"。（ ）

答案与解析

答案：× · 考点 2.3 栈和队列

解析：

  • 栈的特点是 LIFO（后进先出）。入栈顺序 c → i → g → a → m，m 在栈顶。
  • 「一次全部压入，再出栈」= 把整个序列逆序弹出：m → a → g → i → c → 得到 "magic"。
  • 题面说得到 "cigam" —— 那是入栈顺序（原序），错误。
  • 一句话口诀：全部进栈再出栈 = 原序列倒过来。

🎯 栈的出栈序列：本卷讲了 3 种考法（P3）

考法规则例（入栈 A B C D E）
① 全进再出出栈序列 = 入栈序列逆序E D C B A
② 边进边出进一个出一个 → 出栈序列可以等于入栈序列A B C D E
③ 判「不属于」给一个序列问「是否可能」→ 逐个模拟见下

③ 的判定铁律：出栈的元素只能来自「当前栈顶」或「尚未入栈的后续元素」。

  • 反例：入栈 A B C D E，出栈序列写 C A … → 不可能。因为 C 出栈后，栈里剩 A B，B 在 A 上面，下一个只能是 B，A 要等 B 走了才能走。
  • 附加考点：问「这种进出栈序列需要几个存储空间」。若进出序列相同（边进边出），只需 1 个存储空间。

第 28 题 · 链式存储单元

线性表采用链式存储时，其存储单元必须是不能连续的。（ ）

答案与解析

答案：× · 考点 2.2 线性表

解析：

  • 两种存储方式对物理连续性的要求完全不同：
存储方式存储单元是否必须连续靠什么找下一个元素
顺序存储（顺序表）必须连续下标运算（随机访问）
链式存储（链表）可连续，也可不连续结点里的指针域

第 29 题 · 函数声明

double fun(int x,int y)是正确的函数声明。（ ）

答案与解析

答案：√ · 考点 1.7 函数

解析：

  • 函数声明（原型）的形参列表里，每个形参都必须单独写出类型。
  • double fun(int x, int y) —— x 是 int，y 也是 int，合法 ✅

第 30 题 · do-while 特性

C语言中，do-while的循环体至少无条件执行一次。（ ）

答案与解析

答案：√ · 考点 1.5 循环结构程序设计

解析：

  • do-while 是直到型循环：先执行循环体，再判断条件。所以循环体至少执行 1 次。

do {
    循环体;
} while (条件);      /* ← 注意结尾的分号，不能少 */
  • 对比 while（当型循环）：先判断，后执行。条件一开始就不成立 → 循环体执行 0 次。

while (条件) {
    循环体;
}
  • 口诀：do-while 至少 1 次，while 可以 0 次。
  • ⚠️ 易错点：do-while 的 while(条件); 结尾分号必须写，漏了就语法错。

第 32 题 · 二叉树结点关系

在一棵二叉树中，度为0的结点个数为n₀，度为2的结点数为n₂，则有n₀ - n₂ = ____

答案与解析

答案：1 · 考点 2.5 树和二叉树

解析：

  • 这是二叉树的核心性质：n₀ = n₂ + 1（叶子结点数 = 度为 2 的结点数 + 1），所以 n₀ − n₂ = 1。
  • 「度」的定义：某结点有几个子结点，它的度就是几。

- 有两个子结点 → 度为 2；只有一个 → 度为 1；没有子结点（叶子）→ 度为 0。

推导（两条式子联立）：

式子内容
① 结点总数n = n₀ + n₁ + n₂
② 边数从下看：每个结点（除根）对应一条边 → 边数 = n − 1；从上数：每个结点的出边数之和 → 边数 = 0·n₀ + 1·n₁ + 2·n₂
联立n − 1 = n₁ + 2n₂，代入 ① → n₀ + n₁ + n₂ − 1 = n₁ + 2n₂ → n₀ = n₂ + 1

画图验证（老师用的方法，最快）：画 A 带两个子结点 B、C（B、C 都是叶子）

  • n₀ = 2（B、C）· n₂ = 1（A）→ 2 − 1 = 1 ✅

📌 记法：叶子数 = 双分支结点数 + 1。这个式子与 n₁（度为 1 的结点数）无关，n₁ 是干扰项。

第 33 题 · 逻辑运算求值

执行C程序段 int x = 1, y = 2, z = 0, t; t = (x && y) < (y || z); 则t的值为____

答案与解析

答案：0 · 考点 1.2 数据的存储与运算

解析：

第 1 步 —— 算括号里的逻辑与 (x && y)：

  • x = 1（非 0 → 真），y = 2（非 0 → 真）
  • 逻辑与：两边都真才真 → 结果真，C 语言里「真」的值为 1

第 2 步 —— 算括号里的逻辑或 (y || z)：

  • y = 2（真），z = 0（假）
  • 逻辑或：有一个真就是真 → 结果真，值为 1

第 3 步 —— 算关系运算 <：

  • 1 < 1 → 不成立 → 关系表达式的值为 0
  • 赋给 t → t = 0

本题的两个考点：

考点内容
逻辑运算的结果值&&、`` 的结果不是两边的原值，而是 1（真）或 0（假）
括号优先级最高有括号先算括号，不要被 < 与 &&/`` 的优先级顺序干扰

💡 顺便记住优先级链（本卷单选第 14 题也考了）：

即：< 的优先级高于 && 和 ||。本题因为有括号，才先算逻辑运算 —— 若写成 x && y < y || z，结果就完全不同了。

= 2×512 + 5×64 + 0 + 4
= 1024 + 320 + 4
= 1348 ✅

 3 ÷ 2 = 1 余 1   ↑
 1 ÷ 2 = 0 余 1   ↑

倒序读 → 1111；反算 8+4+2+1 = 15 ✅

⚠️ 三条铁律（老师专门强调）：

  1. 八进制里没有数字 8（只有 0–7）。
  2. 十六进制里没有 G（只有 0–9 和 A–F，大小写都可以）。
  3. 位序号从右往左从 0 开始数 —— 这是「按权求和」最容易数错的地方。
