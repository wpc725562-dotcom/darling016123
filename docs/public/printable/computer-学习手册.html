第一部分 C 语言（约 100 分）

C1 计算机基础理论（前置总览）

学什么：进制转换、数据单位、编译运行流程——打地基。

核心考点：

  • 进制转换：二进制转十进制↔十六进制（短除法/8421法）
  • 1 字节 = 8 位；KB/MB/GB 换算
  • 编译→链接→运行三步

C2 C语言概述与基本概念

学什么：标识符规则、注释、程序结构。识别非法标识符是高频小题。

核心考点：

  • 标识符：字母/下划线开头，只能含字母数字下划线，不能用关键字
  • main 是程序入口；每条语句以 ; 结尾

C3 数据的存储与运算 ⭐⭐

学什么：整型/实型/字符型怎么存；运算符优先级——最容易失分。

核心考点：

  • int 4 字节、float 4、double 8、char 1
  • 自增自减：i++ 先用后加，++i 先加后用
  • 整数除法：7/2=3（不是 3.5！）
  • && 和 || 短路求值

典型代码：


int a = 7;
printf("%d", a/2);   // 输出 3（整数除法）
int x = 3;
printf("%d", (x++)+x);

笔记：1.2 数据的存储与运算

  • [ ] 说出 && 的短路规则

C4 顺序程序设计

学什么：printf/scanf 格式控制——输出格式题必考。

核心考点：

  • %d 整型、%f 浮点、%c 字符、%s 字符串
  • scanf("格式", &变量) — 记得取地址符 &
  • printf 默认右对齐，%-5d 左对齐

典型代码：


int a, b;
scanf("%d%d", &a, &b);   // 记得 & 取地址
printf("%.2f", 3.14159); // 保留 2 位小数

笔记：1.3 顺序程序设计

复习任务：

  • [ ] 说出 %.2f 的作用

C5 选择结构程序设计 ⭐⭐

学什么：if/else、switch 分支逻辑。else 与最近的 if 配对。

核心考点：

  • if(表达式) — 0 为假，非 0 为真
  • switch 别忘了 break，否则"贯穿"
  • 条件运算符：a>b?a:b

典型代码：


// 判断闰年
int y; scanf("%d", &y);
if ((y%4==0 && y%100!=0) || y%400==0)
    printf("闰年");
else
    printf("平年");

笔记：1.4 选择结构程序设计

C6 循环结构程序设计 ⭐⭐⭐

学什么：for/while/do-while 循环——编程题核心，必考。

核心考点：

  • for(初值;条件;步长) 三步
  • break 跳出循环，continue 跳过本次
  • 嵌套循环：外层走一次，内层走完一轮

典型代码：


// 求 1+2+...+100
int sum = 0;
for (int i = 1; i <= 100; i++)
    sum += i;
printf("%d", sum);

// 输出 1-100 中所有偶数
for (int i = 1; i <= 100; i++)
    if (i % 2 == 0) printf("%d ", i);

笔记：1.5 循环结构程序设计

复习任务：

C7 数组 ⭐⭐⭐⭐⭐

学什么：数组 = 同类型数据的集合。字符串处理是必考大题。

核心考点：

  • 定义：int a[10] 下标 0-9
  • strlen 长度（不含结束符），sizeof 占字节数
  • 字符串函数：strcpy/strcat/strcmp/strlen
  • 数组名是首地址，不能整体赋值

典型代码：


// 输入 10 个数求平均值
int a[10], sum = 0;
for (int i = 0; i < 10; i++) {
    scanf("%d", &a[i]);
    sum += a[i];
}
printf("%.2f", sum / 10.0);

char s[] = "abc";
strlen(s);   // 3（不含结束符）
sizeof(s);   // 4（含结束符）

笔记：1.6 数组

复习任务：

  • [ ] 写代码：输入 10 个数求平均值
  • [ ] 说出 strlen 和 sizeof 的区别

C8 函数 ⭐⭐⭐⭐⭐

学什么：模块化编程。递归和参数传递是必考。

核心考点：

  • 定义/声明/调用三件套；形参实参
  • 值传递：函数内改形参不影响实参
  • 递归：必须有终止条件
  • 全局变量 vs 局部变量

典型代码：


// 递归求 n!
int fact(int n) {
    if (n <= 1) return 1;
    return n * fact(n - 1);
}

笔记：1.7 函数

C9 指针 ⭐⭐⭐⭐⭐

学什么：指针 = 存地址的变量。*p、p++ 的区分是头号考点。

核心考点：

  • 声明 int *p = &a; — p 存 a 的地址，*p 取 a 的值
  • (*p)++ 值加 1；p++ 地址加 1
  • 指针做函数参数才能改实参
  • 数组名 = 首元素地址

典型代码：


// 指针实现两数交换
void swap(int *pa, int *pb) {
    int t = *pa;
    *pa = *pb;
    *pb = t;
}
int a = 3, b = 5;
swap(&a, &b);

笔记：1.8 指针

复习任务：

  • [ ] 写 swap 用指针实现两数交换

  • [ ] 为什么值传递交换不了两个数

C10 结构体与共用体 ⭐⭐

学什么：自定义数据类型。union 共享空间是易错点。

核心考点：

  • struct：成员各自占内存
  • union：成员共享同一块内存（取最大的）
  • typedef 起别名；枚举 enum
  • 结构体变量用 . 访问成员

典型代码：


struct Student {
    char name[20];
    int score;
};
struct Student s = {"小明", 90};
printf("%s %d", s.name, s.score);

笔记：1.9 结构体与共用体

复习任务：

C11 文件操作

学什么：文件的打开/关闭/读写。

核心考点：

  • fopen("路径","r/w/a") 返回 FILE*，失败返回 NULL
  • fclose 必须配对；fprintf/fscanf、fgetc/fputc
  • 路径中的 \ 要写成 \\（转义）

典型代码：


FILE *fp = fopen("test.txt", "r");
if (fp == NULL) { printf("打开失败"); return; }
int ch = fgetc(fp);
fclose(fp);

笔记：1.10 文件操作

第二部分 数据结构（约 100 分）

D1 数据结构基本概念 ⭐⭐

学什么：数据结构 = 逻辑结构 + 存储结构 + 运算。

核心考点：

  • 逻辑结构：线性/树形/图形/集合
  • 存储结构：顺序（连续空间）/链式（指针连接）
  • 时间复杂度：大 O 表示法

D2 线性表 ⭐⭐⭐⭐⭐

学什么：顺序表 vs 链表——大题高频。

核心考点：

  • 顺序表：连续存储，随机存取 O(1)，插入删除 O(n)
  • 链表：动态存储，插入删除 O(1)，查找 O(n)
  • 单链表判空：head->next == NULL
  • 头插法/尾插法建表

典型代码：


// 单链表结点插入（在 p 后插入 s）
s->next = p->next;
p->next = s;

笔记：2.2 线性表

D3 栈和队列 ⭐⭐⭐⭐⭐

学什么：栈 LIFO 后进先出；队列 FIFO 先进先出。

核心考点：

  • 栈：栈顶操作，括号匹配、递归都用栈
  • 队列：队尾入队首出队
  • 循环队列判满：(rear+1)%max == front
  • 出栈序列判断题

笔记：2.3 栈和队列

D4 串、数组和广义表 ⭐⭐⭐⭐

学什么：字符串匹配 KMP、数组地址计算、广义表。

核心考点：

  • 子串个数：n(n+1)/2+1
  • KMP 的 next 数组（求模式串的"最长公共前后缀"）
  • 数组存储地址：a[i][j] 的地址 = 基址 + i×列数 + j
  • 广义表深度 = 括号嵌套层数

D5 树和二叉树 ⭐⭐⭐⭐

学什么：二叉树遍历与性质——必考大题。

核心考点：

  • 二叉树性质：第 i 层最多 2^(i-1) 个；n 个结点完全二叉树深度 [log2 n]+1
  • 遍历：先序(根左右)/中序(左根右)/后序(左右根)/层序
  • 已知先序+中序还原二叉树（必考）
  • 哈夫曼树：权值小的在深层，WPL 最小

笔记：2.5 树和二叉树

D6 图 ⭐⭐⭐⭐

学什么：图的遍历和最小生成树——大题高频。

  • 存储：邻接矩阵（n×n）/ 邻接表
  • DFS 深搜（栈/递归）、BFS 广搜（队列）
  • 最小生成树：Prim（加点）/ Kruskal（加边）
  • 出度入度、连通分量

D7 查找 ⭐⭐⭐⭐

学什么：折半查找和哈希表——计算题必考。

核心考点：

  • 顺序查找 ASL=(n+1)/2
  • 折半查找：要求有序，ASL=log2(n+1)-1
  • 哈希：除留余数法 h(k)=k%m，冲突处理（线性探测/链地址）
  • 二叉排序树：左小右大，中序有序

D8 排序 ⭐⭐⭐⭐

学什么：八大排序的复杂度与稳定性——必考。

核心考点：

  • 稳定：冒泡、插入、归并、基数；不稳定：快排、选择、希尔、堆
  • 快排思想：挖坑填数、分治
  • 一趟排序后的状态题
