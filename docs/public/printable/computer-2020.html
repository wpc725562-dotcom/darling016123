同型题（函数 + 树）

选择

  1. C 程序基本单位是 函数
  2. 数组下标从 0 开始
  3. 顺序表随机存取 O(1)
  4. 栈：LIFO；队列：FIFO
  5. strcmp 头文件 string.h
  6. 指针与数组：数组名 ≈ 首元素地址
  7. 完全二叉树叶子与层关系
  8. 折半查找前提：有序顺序表
  9. 时间复杂度双重循环 O(n²)
  10. fopen 失败返回 NULL
