第 1 题 · 标识符规则

下列不能用作 C 语言标识符的是（ ）

答案与解析

回忆答案：C. &a · 考点 1.1 C语言概述与基本概念

标识符就是你给变量、函数起的名字。 C 语言对取名立了三条规矩：

规矩说明例子
① 只能用字母、数字、下划线其它符号一律不许出现sum、_total、a1 ✅
② 不能以数字开头开头必须是字母或下划线a1 ✅ ／ 1a ❌
③ 不能是关键字C 自带的 32 个保留词不能用int、return、if ❌

&a 里的 & 是取地址运算符。它违反规矩① —— 名字里不能有这样的符号。更要紧的是，&a 在 C 里根本不是一个"名字"，而是一个动作："取出 a 的地址"。

这一类题的全部考点，就是下面这张表：

写法合法？原因
_6_✅下划线开头允许
6_6❌数字开头
int、void、if❌关键字
a-b❌含减号，会被读成"a 减 b"
and、Add、_if✅不是关键字；C 区分大小写，Add ≠ add，_if ≠ if

两个爱设的坑：

  • scanf、printf 不是关键字，是库函数名。技术上你能拿它们当变量名（int scanf; 合法），虽然实际绝不该这么写。
  • define、include 是预处理命令，严格说也不在 32 个关键字里。考试遇到，按"合法但不该用"处理。

第 2 题 · fopen 返回值

fopen 打开文件失败时返回（ ）

答案与解析

回忆答案：B. NULL · 考点 1.10 文件操作

为什么返回 NULL？ fopen 成功时给你一个文件指针 —— 相当于系统为你和这个文件之间搭好的一根线，你后面所有读写都顺着这根线走。失败了，没有线可给，于是返回一个"指向空处"的指针，就是 NULL。

打个比方：fopen 像去柜台办一张卡。办成了给你一张卡；办不成，柜员给你一张写着 0 号的空卡。你要是拿着空卡去刷卡（继续读写），当然出事。

所以打开之后第一件事就是检查。 标准写法：


#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("data.txt", "r");    /* 尝试以只读方式打开 */
    if (fp == NULL) {                     /* 一定先查这一句 */
        printf("打开失败\n");
        return 1;                         /* 打不开就别往下走 */
    }
    /* …… 用 fp 读数据 …… */
    fclose(fp);                           /* 用完关掉 */
    return 0;
}
写法评价
if (fp == NULL)✅ 规范
if (!fp)✅ 也对，考试两种都认
if (fp == 0)⚠️ 数值等价，但不如写 NULL 清楚
不检查就 fgetc(fp)❌ 程序崩溃 —— 本章最大的失分点

一句话记： 打开 → 读写 → 关闭，三步缺一不可；第一步的返回值必查。

第 3 题 · 按序号取前驱

要频繁"取第 i 个结点及其前驱"，最省时间的存储结构是（ ）

答案与解析

回忆答案：C. 顺序表 · 考点 2.2 线性表

关键在于顺序表能"随机访问"。

结构找第 i 个要花多久比喻
顺序表（数组实现），一步到位一排连号储物柜：报柜号，直接走到
链表，必须从头一个个走寻宝游戏：每条线索只告诉你下一个在哪

顺序表在内存里是连续的一长条。第 i 个的地址 = 首地址 + i × 每个元素占的字节数 —— 一道乘法就算出来，跟 i 是 5 还是 5000 一样快。链表的结点散落在内存各处，靠 next 指针手拉手，你只能顺着手摸过去。

"及其前驱"这半句是细节加分项： 第 i 个的前驱就是第 i-1 个，顺序表里同样是 。而链表找 p 的前驱更痛苦 —— 单链表不能回头，只能从头再走一遍。

反过来，什么时候该选链表？ 把这两类放一起对照记：

你的需求该选
按下标快速取元素顺序表
频繁插入、删除链表（不用搬一堆元素）
长度不确定、经常增减链表（不用预先估计大小）
想省掉指针占的空间顺序表

第 4 题 · 表达式真假

设 int a=4, b=3, c=2;，则值为"真"的表达式是（ ）

答案与解析

回忆答案：D. a&&b||c · 考点 1.2 数据的存储与运算

C 语言判定真假只看一件事：

值为 0 → 假；值不为 0 → 真。（负数也算真，-5 是真）

三个逻辑运算符的优先级，从高到低：

优先级运算符名称结果
高!逻辑非0 或 1
中&&逻辑与0 或 1
低`\\`逻辑或0 或 1

算 a&&b||c： 先 a&&b = 4&&3 → 两边都非 0 → 得 1；再 1||c → 左边已经是 1 → 整个是 1（真）。

这里藏着一个必考机制 —— 短路求值：

表达式行为
`A \\B`若 A 为真，B 根本不去算（结果已注定为真）
A && B若 A 为假，B 根本不去算（结果已注定为假）

短路不只省时间，还能避免程序崩溃（比如防止除零、防止越界访问）：


if (p != NULL && *p > 0)   /* ✅ p 为空时右边不执行，不会崩 */
    ...
if (*p > 0 && p != NULL)   /* ❌ 顺序反了：p 为空时先解引用就崩了 */
    ...

这一类题最常见的三种错法：

写法结果说明
3 < a < 5⚠️ 恒为真先算 3<a 得 1，再算 1<5 得 1。想表达区间必须写 a>3 && a<5
if (a = 5)⚠️ 恒为真= 是赋值，== 才是比较。这句把 a 改成 5 并判定为真
!a，其中 a=40非 0 取反得 0

第 5 题 · 算法分析内容

对一个算法进行分析，主要包括哪两个方面（ ）

答案与解析

回忆答案：D. 时间复杂度 + 空间复杂度 · 考点 2.9 算法基本概念与分析

算法就是"解决这个问题的步骤清单"。 评价一份清单好不好，只看它花掉你两样东西：

维度问的是什么比喻（做菜）

空间复杂度要额外占多少内存用掉多少案板

"空间"指额外空间，不含程序代码本身和输入数据。原地工作的算法（比如只用一个临时变量做交换）空间复杂度记 。

常考量级排队（从小到大，必须背）：

读代码一眼看出量级的技巧：

代码长相量级
没有循环，固定几句
一层循环 for(i=0;i<n;i++)
两层循环嵌套，都到 n
循环变量每次翻倍 i=i*2
循环变量每次折半 n=n/2

第 6 题 · 结构体说法

关于结构体，下列说法错误的是（ ）

答案与解析

回忆答案：B. 由系统直接提供 · 考点 1.9 结构体与共用体

结构体是你自己造的类型，不是系统给的。

类型谁提供例子
基本类型系统自带int、char、float
构造类型你自己定义struct Student{...} ← 结构体在这

比方说：int 是超市里现成的收纳盒；结构体是你自己画图纸定做的盒子 —— 图纸必须先由你画出来，系统不可能预先知道你要装什么。

定义与使用，考点全在这几行：


#include <stdio.h>

struct Student          /* 这一步只是"画图纸"，不占内存 */
{
    int   id;
    char  name[20];
    float score;
};                      /* 这个分号千万别漏 */

int main(void)
{
    struct Student s = {1001, "Li Ming", 88.5};   /* 按顺序初始化 */
    s.score = 90.0;                                /* 用点号访问成员 */
    printf("%d %s %.1f\n", s.id, s.name, s.score);
    return 0;
}
写法问题
struct Student s;✅ 定义变量必须带 struct
Student s;❌ 纯 C 不行（C++ 可以），考试按 C 判错
定义完忘写 ;❌ 编译报错，最高频的错
s.name = "Li";❌ 数组名不能被赋值，要用 strcpy(s.name, "Li")
struct Student a, b;✅ 一次定义多个

连带考点： 结构体变量整体可以赋值（a = b; 合法，逐成员拷贝），但不能整体比较（a == b 非法，只能一个一个成员比）。这两条经常被混在同一个选项里考。

第 8 题 · scanf 调用

下列 scanf 调用正确的是（ ）

答案与解析

回忆答案：C. scanf("%f%f", &c, &d)（c、d 为 float） · 考点 1.3 顺序程序设计

scanf 有一条铁律：

从键盘读值，参数必须给"地址"，不能给"值"。

因为 scanf 要往你的变量里写东西，你得告诉它"写到哪门哪号"。只给值，等于告诉它"写到 5 号房间"而 5 号房间根本不存在 → 程序崩。

必背地址表（考试就考这张）：

变量定义正确写法为什么
int a;scanf("%d", &a)普通变量要加 &
float c;scanf("%f", &c)同上，注意是 %f
char s[20];scanf("%s", s)数组名本身就是地址，不加 &
int a[5]; 读首元素scanf("%d", a)a 就是 &a[0]，见第 20 题
struct Stu st; 读成员scanf("%d", &st.id)成员是普通变量，要加 &

格式符对照（同样是高频考点）：

类型用注意
int%d用 %f 读 int → 得到 0
float%f写成 %lf 是错的
double%lf只有 scanf 区分；printf 输出 float/double 用 %f 都可以
char%c会把空格、换行也当字符读走
字符串%s遇空格停止；读整行要用 fgets
写法问题
scanf("%f%f", &c, &d);✅
scanf("%f%f", c, d);❌ 少了 &
scanf("%f %f", &c, &d);✅ 中间加空格也合法
scanf("a=%f,b=%f", &c, &d);⚠️ 合法，但你输入时必须原样敲出 a= 和 ,，否则读不进去

第 9 题 · 指针自增

设 int a[5]={10,20,30,40,50}; int *p=&a[1]; int b=*(p++);，则 b 的值是（ ）

答案与解析

回忆答案：A. 20 · 考点 1.8 指针 · 1.6 数组

这题考括号决定的先后顺序。记住四个字：先用后走。

p++ 是后置自增 —— 先把 p 的当前值交出去用，用完之后才让 p 前进一格。

一步一步走：

步骤发生什么p 指向b
初始a[5] = {10,20,30,40,50}——
①p = &a[1]a[1]（值 20）—
②*(p++)：取 p 当前指向的值仍是 a[1]20
③取完值，p 才自增a[2]（值 30）20

所以 b = 20，而 p 事后走到了 a[2]。

三种写法必须分清（专挑这里出题）：

写法含义b 得副作用
b = *(p++);先取值，后走a[1] = 20p 指向 a[2]
b = (*p)++;取 *p 给 b，再把 a[1] 这个数 +120p 不动，但 a[1] 变成 21
b = *(++p);先走一步，再取新位置的值a[2] = 30p 指向 a[2]

注意第二行的杀伤力： (*p)++ 改的是数组里的数据，不是指针。很多人以为它和 *(p++) 差不多 —— 其实一个动指针、一个动数据，完全不同。

第 10 题 · 栈的特点

栈的特点是（ ）

答案与解析

回忆答案：C. LIFO · 考点 2.3 栈和队列

栈就是一根只许从顶部操作的管子。

结构进出规则生活比喻插入/删除位置
栈 stackLIFO 后进先出一摞盘子：只能拿最上面那个，也只能往最上面叠都在栈顶
队列 queueFIFO 先进先出排队买饭：先来先服务队尾进、队头出

必背术语：

词意思
栈顶 top唯一允许插入和删除的一端
栈底 bottom另一端，不能直接碰
push 入栈放到栈顶
pop 出栈从栈顶拿走
getTop 取栈顶看一眼栈顶但不拿走（不算修改栈）

常考的"出入栈序列是否可能"判断题，用这条规矩： 入栈顺序 1,2,3 固定，问哪个出栈序列不可能。

出栈序列中，任何一个数后面、比它小的那些数，必须是递减排列的。

例：3,1,2 ❌ 不可能 —— 3 能第一个出来，说明 1、2 此时都还在栈里，而 2 压在 1 上面；那么 1 出来时，2 必须在它之前出来才对。

栈在程序里干什么用（简答题会问）： 函数调用与递归、表达式求值、括号匹配、深度优先搜索、浏览器"后退"按钮。每次调用函数，系统就把返回地址压进栈 —— 这正是递归太深会"栈溢出 stack overflow"的原因。

第 11 题 · for 循环执行次数

for (int i = 1; i++ < 4; ); 循环体执行几次？结束后 i 是多少？

答案与解析

回忆答案：3 次 · 考点 1.5 循环结构程序设计

这题把三件事叠在一起考：后置 ++ 的"先用后走"、for 的执行顺序、空循环体。

先背 for 的执行顺序：


for (①初始化 ; ②条件 ; ③更新)  循环体
     ↓          ↓                ↑
     └──首次──→ 判断 ──真──→ 循环体 ──→ ③更新 ──┐
                     ↓假                         │
                  退出 ←─────────────────────────┘

逐轮追踪（关键：条件里的 i++ 是先用当前值判断，判断完才 +1）：

轮次进入条件时 i判断用的值判断结果判断后 i执行循环体？
111 < 4真2✅ 第 1 次
222 < 4真3✅ 第 2 次
333 < 4真4✅ 第 3 次
444 < 4假5❌ 退出

⇒ 循环体执行 3 次，i 最终为 5。

两个必须注意的细节：

  1. for 后面直接跟的那个 ; 就是循环体（空语句，什么都不做）。这种写法常用来"就是想让 i 涨到某个值"，但极易被误读成 bug，自己写代码别这么干。
  2. i 是在"判断之后"才 +1 的，所以退出时 i 已经被多加了一次（变成 5 而不是 4）。这才是本题真正的陷阱。

对照练习（先在纸上推一遍再看答案）：

写法循环体几次结束 i
for(i=1; i++<4; );35
for(i=1; ++i<4; );24
for(i=1; i<4; i++);34

第二行为什么不同？++i 是先加再判断，第一轮 i 立刻变成 2 才开始比。

第 12 题 · 完全二叉树叶子数

含有 12 个结点的完全二叉树，叶子结点（终端结点）有几个？

答案与解析

回忆答案：6 个 · 考点 2.5 树和二叉树

先说什么是完全二叉树： 除最后一层外每层都排满，且最后一层的结点靠左边连续排列（像按编号 1、2、3… 一层层从左往右塞座位）。

核心规律（记住这一个就够）： 把结点按层从上到下、每层从左到右编号 1…n，则

编号 的结点是叶子 ⇔ （它连左孩子都没有）

反过来，编号 的都是有孩子的分支结点，剩下的全是叶子。

代入 ：

  • 分支结点：编号 ，共 6 个
  • 叶子结点：编号 ，共 6 个

⇒ 叶子 6 个，验算： ✅

通用公式（照抄可用）：

两个例子对照，看清 奇偶的影响：

（分支）叶子

第 13 题 · 单链表操作前提

在单链表中进行操作，必须事先找到（ ）

答案与解析

回忆答案：D. 表头 · 考点 2.2 线性表

⚠️ 题干残缺：回忆版只留下"操作链表须找到 → 表头"，完整问法未保留。下面按最可能的问法（"要访问/操作某个结点，为什么必须从头开始"）来讲；若真题原问法是"删除某结点须找到什么"，我在本题末尾一并给出。

为什么离不开表头？ 单链表只有一个方向的信息 —— 每个结点只存"下一个在哪"（next），不存"上一个在哪"。


head → [A|·] → [B|·] → [C|·] → NULL

你想找 C，唯一的路是 head → A → B → C。从中间任何位置都没法"退回去"，所以一切操作的起点都是表头。

这跟顺序表形成鲜明对比（回到第 3 题）：数组有编号能一步跳过去，链表只能顺藤摸瓜 —— 这就是链表"按下标访问 "的根本原因。

如果原问法是"删除某结点"，答案要换成"它的前驱"：


p → [q] → x        删除前
p ──────→ x        删除后：p->next 直接指向 x，q 被甩出去

删除 q 时，你要改的是q 前面那个结点的 next，所以要找的是 q 的前驱 p。

一句话分清两种问法： 「访问第 i 个」→ 从表头开始；「删除某结点」→ 必须找到它的前驱。

第 14 题 · 删除结点语句

已知 p 是 q 的前驱，要删除 q，正确的语句是（ ）

答案与解析

回忆答案：p->next = q->next; free(q); · 考点 2.2 线性表 · 1.8 指针

两步，顺序绝不能颠倒：

步骤语句为什么
① 接桥p->next = q->next;让 p 直接指向 q 的下一个，把 q 绕过去
② 放手free(q);归还 q 占的内存

如果顺序反了会怎样？


free(q);                  /* ❌ 先释放了 q */
p->next = q->next;        /* 此时 q 的内存已归还，q->next 是垃圾值 */

这叫悬空指针 / use-after-free：内存已经还给了系统，你却还去读它。后果是链表后段丢失甚至崩溃 —— 而且不一定当场报错，可能跑到很后面才炸，最难查。

其余常见错法：

写法问题
只写 free(q);❌ 没接桥 → q 后面所有结点全部丢失
只写 p->next = q->next;⚠️ 逻辑对但内存没释放 → 内存泄漏，考试必须写 free
p = q->next;❌ 只改了 p 这个指针变量，链表没变，还把 p 弄丢了

记忆：先接桥，后拆房。

第 19 题 · 树的深度

关于"树的深度"，下列说法错误的是（ ）

答案与解析

回忆要点：错误说法是 "树的深度是各结点度最大值" · 考点 2.5 树和二叉树

这两个概念根本不是一回事，混了就错：

概念定义描述的对象
结点的度这个结点有几个孩子单个结点
树的度树中所有结点的度的最大值最大孩子数
树的深度（高度）树中结点的最大层次，根算第 1 层整棵树的层数

"度"问的是"一个孩子生了几个"，"深度"问的是"家族传了几代"。 两者没有必然关系。

看图就懂（树的度是 3，深度是 4）：


              A            ← 第 1 层
          /   |   \
         B    C    D       ← 第 2 层   （A 有 3 个孩子 → 度 3）
             /
            E              ← 第 3 层
           /
          F                ← 第 4 层   （E 只有 1 个孩子）
  • 各结点的度：A=3、B=0、C=0、D=0、E=1、F=0
  • 树的度 = 3（A 的孩子最多）
  • 深度 = 4（一共 4 层，因为 E 下面还挂着 F）

"各结点度最大值"算出来是 3，而真正的深度是 4 —— 反例到手，所以那个说法错。

几个必背结论：

命题对/错说明
叶子结点的度为 0✅没有孩子
深度为 的二叉树最多有 个结点✅每层翻倍再减 1
第 层最多 个结点✅根是第 1 层，
（叶子数 = 度为 2 的结点数 + 1）✅二叉树最重要的性质
树的深度 = 各结点度最大值❌本题的错误说法

第 39 题 · 递归优缺点

递归的优点和缺点各是什么？

答案与解析

参考答案：递归 = 函数在自己的函数体里调用自己（直接或间接）。

说明
优点① 代码简洁，逻辑贴近数学定义（阶乘、斐波那契、汉诺塔）<br>② 特别适合本身递归定义的结构 —— 树的遍历、图的 DFS、分治，用循环反而极难写
缺点① 慢：每次调用要压栈（返回地址、参数、局部变量），开销远大于一次循环<br>② 费内存：嵌套太深栈会满 → 栈溢出<br>③ 易写错：忘终止条件就是无限递归，必崩

#include <stdio.h>

/* 递归求 n! —— 两个要素都在里面 */
long fact(int n)
{
    if (n <= 1) return 1;      /* ① 终止条件：没有它就无限递归 */
    return n * fact(n - 1);    /* ② 自我调用：规模必须缩小 */
}

int main(void)
{
    printf("%ld\n", fact(5));  /* 120 */
    return 0;
}

采分点： 递归两要素（终止条件 + 规模缩小）、栈开销、可改写为循环。这也解释了第 10 题说的"函数调用为什么用栈"。

第 40 题 · 递归函数求值

递归函数求值：sub(6) = 21，且调用后 i 仍为 6

答案与解析

⚠️ 原函数体在回忆版里丢了，只留下答案 sub(6)=21 与"i 仍为 6"。下面按最能同时满足这两个结果的常见形式讲解；换一套卷请照下面的方法自己推一遍。

能推出 21 的一种常见形式（累加但跳过某个值）：


#include <stdio.h>

int sub(int i)
{
    if (i == 0) return 0;                 /* 终止条件 */
    if (i == 3) return sub(i - 1);        /* 跳过 3 */
    return i + sub(i - 1);                /* 否则 i + sub(i-1) */
}

int main(void)
{
    int i = 6;
    printf("%d %d\n", sub(i), i);         /* 21 6 */
    return 0;
}

怎么推（列表法，考场上就这么写）：

调用展开结果
sub(0)00
sub(1)1 + sub(0)1
sub(2)2 + sub(1)3
sub(3)= sub(2)（跳过 3）3
sub(4)4 + sub(3)7
sub(5)5 + sub(4)12
sub(6)6 + sub(5)21 ✅

对照： —— 3 被"跳过"了，却又通过 sub(2) 把 3 的累加值带回了一次，正好抵消。这就是这类题爱设的巧合陷阱。

"i 仍为 6"才是本题真正的考点 —— C 语言是值传递：


int sub(int i) { i = 100; return i; }   /* 改的是副本 */
int main(void) { int i = 6; sub(i); /* i 还是 6 */ }

形参是实参的一份拷贝。 函数里怎么改形参，main 里那个 i 都纹丝不动。

想真的改到外面，必须传地址：void sub(int *i) { *i = 100; } → 调用写 sub(&i);

写法能否改动外部变量
void f(int x) { x = 10; } → f(a);❌ 改的是副本
void f(int *p) { *p = 10; } → f(&a);✅ 通过地址改
数组作参数 void f(int a[]) 里改 a[0]✅ 传的是地址，能改

⚠️ 最后一条经常和第一条混：数组名传的是地址，普通变量传的是值。 这是读程题最经典的失分点。

第 41 题 · 读程序求平均

读程序：跳过不及格求平均

答案与解析

n = 5，avg = 81.20

⚠️ 原始数据在回忆版里丢了，只留下结果 n=5、avg=81.20。下面把这类题的通用解法与最可能考的两个陷阱讲清。

结果 avg=81.20 的含义：5 个数之和 。即有 5 人及格，平均分带小数。

这类读程题的通用解法（照这个流程推，什么变体都不怕）：

步骤做什么
① 先画变量表把 n、sum、i、p 等列成一张表，别在脑子里记
② 每轮只改一格循环体每句按顺序执行，逐行更新表格
③ 警惕整除陷阱sum / n 若都是 int ⇒ 小数被砍掉
④ 核对终止条件大多数错误出在"多算一轮 / 少算一轮"

整除陷阱（几乎每年都有，务必掌握）：


int    sum = 406, n = 5;
double a = sum / n;             /* ❌ 得 81.00 —— 先做整数除法，才转 double */
double b = (double)sum / n;     /* ✅ 得 81.20 —— 先转型，变成浮点除法 */
double c = 1.0 * sum / n;       /* ✅ 同上，另一种常用写法 */

int / int 结果还是 int，小数部分直接砍掉（不是四舍五入）。要浮点结果，必须在除法发生之前把其中一边变成浮点。

题目答案 81.20 恰好说明原程序用了强制转换——这正是出题人想考的点。

"跳过不及格"的标准写法（<60 不计入）：


#include <stdio.h>

int main(void)
{
    int    score[10];
    int    i, n = 0;
    double sum = 0;

    for (i = 0; i < 10; i++) {
        if (score[i] < 60) continue;   /* continue：跳过本轮，不进统计 */
        sum += score[i];
        n++;
    }
    if (n > 0) printf("n=%d avg=%.2f\n", n, sum / n);
    return 0;
}

⚠️ 打印前必须判 n > 0，否则一个及格都没有时 sum/n 除零崩溃 —— 这是简答题的采分点之一。

如果原题读的是字符串（while(*p) 型），核心两件事：


char s[] = "AbaB";
char *p = s;
int    upper = 0;

while (*p) {                  /* 走到 '\0' 时 *p 为 0，循环自然停 */
    if (*p >= 'A' && *p <= 'Z') upper++;
    p++;                      /* 忘了这句就是死循环 */
}
printf("%d\n", upper);        /* 2 */

常见读程题的四种"跳格"写法（必须一眼认出）：

写法含义
while (*p)走到字符串结尾 '\0' 就停
while (*p != 'x')找到字符 'x' 就停
for (i=0; i<strlen(s); i++)每轮重算长度 ⇒ ，慢
while ((c = getchar()) != '\n')逐个读字符直到换行

第 42 题 · 静态链表

静态链表读程序

答案与解析

输出 2 然后 4

⚠️ 原表内容在回忆版中丢失，只留下输出 2、4。静态链表是"用数组模拟链表"，概念本身值得单独讲清。

什么是静态链表？ 不用指针，改用数组下标当"指针"：


struct Node {
    int data;   /* 数据 */
    int next;   /* 下一个结点的下标 —— 这就是"指针"的替代品 */
};
动态链表静态链表
链接方式真指针 next数组下标 next
内存malloc 现申请预先开好数组
删除操作改指针改下标
结尾标记NULL-1 或 0

图示（下标即地址）：


下标：   0      1      2      3      4
data：   1      2      3      4      5
next：   1      3     -1      4     -1
                ↑head

跟着走一遍（设 head = 1）：

步pnode[p].data 输出node[p].next → 新 p
1123
2344
345？—

⚠️ 这张表恰好演示了为什么读程题必须一格一格算：按上表走到 p=4 会再多输出一个 5 才停。要得到题目给的两个数，next[3] 应为 -1：


下标：   0      1      2      3      4
data：   1      2      3      4      5
next：   1      3     -1     -1      0
                ↑head         停

此时链路是 1 → 3 → 结束，输出正好 2、4 ✅（下标 0 和 4 是不在链上的空闲结点 —— 静态链表里"没挂上"的结点照常留在数组里，这正是它和顺序表的区别）。

注意两种结束标记： 上面第一张表用 -1 表示结尾，第二张表 next[3] = 0 同样能表示结尾。静态链表常用 0 当" null "，因为下标 0 往往被留作空闲结点链的表头。看题时先确认题目用的是哪种约定，别默认。

这类题的解法（照抄走一遍）：


int p = head;                   /* 从头下标开始 */
while (p != -1) {               /* -1 表示"没有下一个" */
    printf("%d ", node[p].data);
    p = node[p].next;           /* 关键：用下标跳到下一个结点 */
}

做题要领： 草稿上画一张「下标 / data / next」三列表，每走一步就把 p 的新值标出来。这类题不需要懂算法，老老实实照着走，走对了必得分。

第 43 题 · 求最高分

输入三次成绩，输出最高分

答案与解析

答案：见解析


#include <stdio.h>

int main(void)
{
    int a, b, c, max;
    scanf("%d%d%d", &a, &b, &c);   /* 三个 %d 之间不写逗号，输入用空格隔开 */

    max = a;                        /* 先假设第一个最大 */
    if (b > max) max = b;           /* 再来一个就比一次 */
    if (c > max) max = c;

    printf("%d\n", max);
    return 0;
}

思路：打擂台 —— 先让 a 站上擂主位，b、c 挨个挑战，赢了就换人。这个"先设初值再逐个比较"的模式可以推广到任意多个数（套上循环就是求一组数的最大值）。

⚠️ max = a; 不能省。若只写 if (a>b && a>c) max=a; ... 而没有兜底分支，max 可能根本没被赋值 —— 未初始化的变量里是垃圾值。

第 45 题 · 顺序查找

输入 10 个班的人数，再输入 y，查有没有这个班

答案与解析

答案：见解析


#include <stdio.h>

int main(void)
{
    int a[10];
    int y, i;
    int found = 0;                    /* 标志变量：0 表示还没找到 */

    for (i = 0; i < 10; i++)
        scanf("%d", &a[i]);           /* 数组元素是普通变量，要加 & */

    scanf("%d", &y);

    for (i = 0; i < 10; i++) {
        if (a[i] == y) {
            found = 1;                /* 找到了，先置标志 */
            break;                    /* 再立刻退出，别白跑 */
        }
    }

    if (found) puts("Success");
    else       puts("Fail");

    return 0;
}

这是「顺序查找」的标准模板，四个部件缺一不可：

部件作用
found = 0先假设找不到（标志变量必须初始化）
if (a[i] == y)逐个比对
found = 1; break;命中就置标志并立即退出
循环后判断 found统一输出，不在循环里输出

⚠️ 最常见的两个扣分点：

  1. 忘写 break —— 本题结果碰巧还对，但白跑；若改成"输出下标"就会重复输出。
  2. 在循环里直接 puts("Success") —— 多个匹配会输出多行；而一个都没找到时什么都不输出，题目要的 "Fail" 就丢了。必须用标志变量，在循环外统一判断。

break / continue / return 的区别（顺带记全）：

语句效果
break跳出整个循环
continue跳过本轮剩余语句，直接进入下一轮
return直接结束整个函数（连循环带函数一起出去）

自测：合上笔记，自己答

  1. int k = 5; 执行 if (k = 0) puts("hi"); 会输出什么？为什么？
  2. scanf("%d%s", &a, s)（s 是 char[]）——为什么 &a 有 & 而 s 没有？
  3. 归并两个长度 4 和 7 的有序表，最少比几次？最坏几次？
  4. 二叉树中有 3 个度为 2 的结点，叶子几个？
  5. int a[3] = {1,2,3}; int *p = a; 求 *(p+1) 和 *p + 1。

<details><summary>点开对答案</summary>

  1. 什么都不输出。 k = 0 是赋值，表达式的值为 0 ⇒ 判定为假（呼应第 4 题）。想比较必须写 ==。
  2. 数组名本身就是首元素地址，再加 & 类型就变成"整个数组的地址"了；而 a 是普通 int 变量，scanf 要它的地址，所以必须加 &（呼应第 8、20 题）。
  3. 最少 4 次；最坏 10 次（呼应填空第 5 题）。
  4. 4 个叶子（呼应第 19 题）。
  5. *(p+1) = 2（指针往后挪一格再取值）；*p + 1 = 1 + 1 = 2。本题两问数值恰好相同，含义完全不同：*(p+1) 是 a[1]，*p + 1 是 a[0] + 1（呼应第 9 题的括号优先级）。
