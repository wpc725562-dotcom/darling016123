<h2 class="home-sec home-sec--minor">本地预览</h2>

```bash
# 在本仓库根目录执行（clone 下来的目录名按你自己的来）
git clone https://github.com/wpc725562-dotcom/darling016123.git
cd darling016123
npm install
npm run docs:dev        # 开发预览
npm run docs:build      # 构建静态站
```

> 受限环境（沙箱）里构建可能被 safe-delete 拦截，改用 `npm run docs:build:sandbox`。
