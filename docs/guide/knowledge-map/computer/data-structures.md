## 二十八、数据结构：绪论与基本概念

### 数据、数据元素、数据项、数据对象
- **要点**：`数据`是信息的载体；`数据元素`是数据的基本单位；`数据项`是构成数据元素、不可分割的最小单位；`数据对象`是具有相同性质的数据元素的集合。粒度：数据 ⊃ 数据元素 ⊃ 数据项。易错：「数据项是数据的最小不可分割单位」错，应为「数据元素的不可分割单位」。
- **关键概念**：`数据`、`数据元素`、`数据项`、`数据对象`
- **出处**：强哥·数据结构 P1；张无忌 P2, P3

### 数据类型与抽象数据类型
- **要点**：`数据类型`是值的集合及定义在其上的一组操作的总称，分`原子类型`（不可再分）、`结构类型`（结构体、链表结点）、`抽象数据类型`；抽象数据类型由`数据对象`、`数据关系`、`基本操作`构成，合称三元组。栈、队列、二叉树都是抽象数据类型。定义数据类型及其操作而不涉及实现细节；C 语言用「结构体 + 函数」实现，对内隐藏细节、对外暴露接口。
- **关键概念**：`数据类型`、`原子类型`、`结构类型`、`抽象数据类型`、`三元组`
- **出处**：强哥·数据结构 P1；张无忌 P2；逊哥 P2, P3

### 数据结构三要素：逻辑结构、存储结构与数据运算
- **要点**：`逻辑结构`、`存储结构`、`数据运算`合称数据结构三要素。运算功能针对逻辑结构定义，实现步骤针对存储结构。`存储结构`又称`物理结构`，是逻辑结构在计算机中的实现，既要存数据本身又要存元素之间的关系；逻辑结构是「画图纸」、存储结构是「照图纸施工」，不能等同。数据结构是存在特定关系的数据元素的集合。
- **关键概念**：`逻辑结构`、`存储结构`、`数据运算`、`物理结构`
- **出处**：张无忌 P2；强哥·数据结构 P2；逊哥 P1, P2

### 逻辑结构的类型
- **要点**：`集合`无关系；`线性结构`一对一；`树形结构`一对多；`图形结构`多对多。也可只分两类：`线性结构`（一对一）与`非线性结构`（集合、树形、网状/图）。线性表、栈、队列、串、数组都是线性结构，树与图是非线性结构。一对一/一对多/多对多是判定类型的核心依据，必考。
- **关键概念**：`集合`、`线性结构`、`树形结构`、`图形结构`
- **出处**：张无忌 P2, P3；强哥·数据结构 P2

### 存储结构的类型
- **要点**：`顺序存储`放连续单元、逻辑与物理一致；`链式存储`靠指针相连、物理不必相邻；`索引存储`另建索引表；`散列存储`由哈希函数算地址。易混点：`有序表`是按数值大小划分的逻辑概念，与存储结构无关，常作干扰项。
- **关键概念**：`顺序存储`、`链式存储`、`索引存储`、`散列存储`
- **出处**：张无忌 P2, P3；强哥·数据结构 P2

### 数据结构的定义与「算法 + 数据结构 = 程序」
- **要点**：结构即数据的组织形式；基本数据类型不够用时另设的新形式即数据结构，没有一种结构对所有用途均有效。算法是解决某类问题的有穷规则集合，必施加在某种数据结构上；Wirth 提出「算法 + 数据结构 = 程序」。
- **关键概念**：`数据结构`、`组织形式`、`算法`
- **出处**：逊哥 P1, P2；强哥 P17, P18


## 二十九、数据结构：算法与复杂度

### 算法的定义与五大特性
- **要点**：`算法`是对特定问题求解步骤的描述，是有限条指令的集合，每步可含多个操作；自然语言、伪代码、程序片段描述求解步骤都算算法。必须满足五点：`有穷性`（次数与每步耗时均有限）、`确定性`（含义唯一）、`可行性`（有效性）、`输入`（零个或多个）、`输出`（至少一个）。易错：输入可为零个，输出至少一个。
- **关键概念**：`算法`、`有穷性`、`确定性`、`可行性`、`输入`、`输出`
- **出处**：强哥·数据结构 P3；逊哥 P1, P2；强哥 P17, P18

### 好的算法的特征
- **要点**：好算法应具备`正确性`、`可读性`、`健壮性`（能处理非法输入而非崩溃）、`高效率`、`低存储`。这是「好算法的标准」而非「算法的特性」，命题常混淆两者。
- **关键概念**：`正确性`、`可读性`、`健壮性`、`高效率`、`低存储`
- **出处**：强哥·数据结构 P3

### 为什么要分析算法效率
- **要点**：语句耗时与软硬件强相关，故算法分析不看实际执行时间，而是估计语句的执行次数（频度）；空间复杂度指除代码和输入数据外额外占用的空间，衡量优劣主要看时间复杂度。二者与问题规模及待处理数据的初始状态都有关。
- **关键概念**：`执行频度`、`空间复杂度`、`问题规模`
- **出处**：逊哥 P2, P3；强哥·数据结构 P4

### 频度、大 O 与常见阶
- **要点**：语句执行次数称`频度`，各语句执行次数相加记为 T(n)，是问题规模 n 的函数；由 T(n) 推出 O(f(n)) 即时间复杂度。求 T(n) 只看最内层循环语句的执行次数，外层与零散常数次语句可忽略。各语句执行次数相加后忽略所有低次幂项与最高次幂的系数，只留最高次幂；常见阶有 $O(1)$、$O(\log_2 n)$、$O(n)$、$O(n\log n)$、$O(n^2)$、$O(n^3)$、$O(2^n)$，算出常数时无论多大都记为 $O(1)$。单层循环 $O(n)$、双层 $O(n^2)$、三层 $O(n^3)$。
- **关键概念**：`频度`、`大 O`、`最高次幂`、`T(n)`
- **相互关系**：对数阶来自循环变量每次乘固定倍数；二叉树深度为 $\log n$ 量级。
- **出处**：逊哥 P2；张无忌 P4, P5, P6；强哥·数据结构 P4

### 大 O 的推导规则与复杂度大小关系
- **要点**：三规则：只保留最高阶项、去掉最高阶项系数、对数阶忽略底数。如 T(n)=n²+n+3 得 O(n²)；常数级一律记 O(1)；5log₂n 记 O(log n)。增长速度由小到大：O(1)&lt;O(log n)&lt;O(n)&lt;O(nlog n)&lt;O(n²)&lt;O(n³)&lt;O(2ⁿ)&lt;O(n!)&lt;O(nⁿ)，其中 nlog n 乘了一个小于 n 的量故小于 n²。$n$ 趋于无穷时指数函数增长最快，其次二次函数，对数函数最慢。
- **关键概念**：`最高阶项`、`忽略系数`、`忽略底数`、`O(nlog n)`
- **出处**：强哥·数据结构 P4；一灯 P2

### 最好、最坏与平均时间复杂度
- **要点**：最好最快、最坏最慢、平均按概率求均值；度量算法通常只讨论最坏情况，即执行时间的上界。
- **关键概念**：`最好/最坏/平均`、`上界`
- **出处**：逊哥 P2

### 时间复杂度计算套路与常见题型
- **要点**：套路是找出决定循环退出的变量，写出第 T 次通项并令其等于 n，解出 T 再去掉常数项；也可用「列表格法」列循环次数与条件变化、由结束条件反解次数。① 常数条顺序语句 → O(1)；② 两层各 n 次嵌套 → O(n²)；③ 三层嵌套 → O(n³)；④ 内层次数随外层递增（1+2+…+n）用等差数列求和 → O(n²)；⑤ 循环变量每次乘 2 或除 2 → O(log n)；⑥ 外层 n 次、内层 log n 次 → O(nlog n)；⑦ 递归由`递归深度`决定，每次递归内还嵌一个 n 次循环则为 O(n²)。`<` 与 `<=` 只影响常数项、不改变阶；控制语句不加花括号时只识别其后一条语句，分析嵌套层数前应自内向外补全花括号。
- **关键概念**：`通项`、`等差数列求和`、`递归深度`、`循环嵌套`
- **出处**：逊哥 P2；强哥·数据结构 P4, P5；一灯 P3

### 空间复杂度
- **要点**：统计运行中临时占用存储空间的变量个数；递归看所建栈帧个数（递归深度）。循环内反复声明赋值的临时变量仍为 $O(1)$；`malloc` 长度 $n$ 的数组为 $O(n)$。
- **关键概念**：`空间复杂度`、`栈帧`、`递归深度`
- **出处**：张无忌 P4；强哥·数据结构 P4


## 三十、数据结构：线性表

### 线性表的定义与特点
- **要点**：由 n 个数据类型相同的元素构成的有限序列，「表」不是表格，n 为表长、没有元素时称空表；除首元外每个元素仅一个前驱，除尾元外仅一个后继。头节点无前驱、尾节点无后继。
- **关键概念**：`线性表`、`表长`、`空表`、`前驱`、`后继`
- **出处**：逊哥 P3；张无忌 P8；强哥·数据结构 P6

### 顺序表的结构定义与初始化
- **要点**：线性表的`顺序存储`称`顺序表`，用一组连续内存单元依次存储，逻辑相邻则物理相邻；支持`随机访问`（下标定位 O(1)）、`存储密度高`（结点只存数据，不额外占指针空间）。典型定义 `#define MAXSIZE 100` 加 `typedef struct { ElemType data[MAXSIZE]; int length; } SqList;`，初始化只需 `length = 0`。可用数组实现，也可在堆区用 `malloc` 动态开辟连续空间。易混：数组是顺序表的充分条件而非必要条件，顺序表不一定用数组实现。
- **关键概念**：`顺序表`、`MAXSIZE`、`length`、`随机访问`、`存储密度`
- **出处**：逊哥 P3；张无忌 P8, P21；强哥·数据结构 P6

### 顺序表的尾部添加与遍历
- **要点**：尾部添加先判满（`length >= MAXSIZE` 则失败），未满则写入 `data[length]` 再 `length++`；遍历条件写 `i < length` 而非 MAXSIZE。
- **关键概念**：`append`、`length++`、`遍历`
- **出处**：逊哥 P3

### 顺序表的插入
- **要点**：插入位置可在 1~n+1 共 n+1 个位置任选，操作是「先挪后插」：把该位置及之后元素整体后移一位（从最后一个元素起从后往前移动以免覆盖），位置 `pos` 对应下标 `pos - 1`。表尾插入不挪动元素 $O(1)$、表头插入挪动 n 个元素 $O(n)$。等概率下插入平均移动 n/2 次。
- **关键概念**：`后移`、`pos - 1`、`平均移动次数`、`$O(n)$`
- **出处**：逊哥 P3；张无忌 P8；强哥·数据结构 P7, P8

### 顺序表的删除、查找与清空
- **要点**：删除位置只能落在已有元素上（共 n 个），是让后面元素向前覆盖；表尾旧值不必处理，只要 `length--`。表尾删除 $O(1)$、表头删除挪动 n-1 个元素 $O(n)$，等概率下删除平均移动 (n-1)/2 次。按索引查找取 `data[i-1]`，按值查找需遍历、返回下标加 1 后的「位置」；`平均查找长度`为 (n+1)/2，查找失败为 n，平均查找长度 = 查找次数总和 × 概率。清空只需 `length = 0`。
- **关键概念**：`覆盖`、`length--`、`位置 = 下标 + 1`、`平均查找长度`
- **出处**：逊哥 P3；张无忌 P8；强哥·数据结构 P7, P8

### 用动态内存实现顺序表与动态扩容
- **要点**：数组成员改成指针 `ElemType *data`；初始化先 `malloc(sizeof(SqList))` 开辟结构体空间并强转，再 `malloc(sizeof(ElemType) * MAXSIZE)` 开辟数组空间赋给 `data`，最后 `length = 0`。容量不足用 `realloc` 申请更大内存（一般原容量二倍或指定增量），复制旧数据、释放旧内存、更新最大容量 `maxSize`。
- **关键概念**：`malloc`、`data 指针`、`realloc`、`扩容`
- **出处**：逊哥 P3；张无忌 P8

### 顺序表与链表的对比
- **要点**：按位置读取顺序表强（随机存取 $O(1)$）、链式需从头遍历 $O(n)$；插删则链表强、顺序表平均移动约一半元素 $O(n)$。空间上顺序表预先分配会闲置或溢出、需连续内存，链表动态分配不会、地址可连续也可不连续。表长稳定、少插删、多按序号访问用顺序表，反之用链表。
- **关键概念**：`随机存取`、`顺序存取`、`存储密度`、`连续内存`
- **相互关系**：链式存储地址可连续也可不连续，是选择题易错点。
- **出处**：逊哥 P3, P5；张无忌 P9, P10

### 链表：节点、头节点与单链表结构
- **要点**：节点含数据域（存元素）与指针域（存直接后继位置），典型定义 `typedef struct Node { ElemType data; struct Node *next; } Node;`；带头节点的单链表头节点不存数据、其 `next` 指向第一个数据节点，尾节点 `next` 为 `NULL`。节点在堆区开辟，必须用`头指针`指向它才能找到整个表，头指针始终指向最开始的结点。`头结点`只起标志作用（可记录表长等），判空看头指针所指结点的 `next` 是否为空；不带头结点判空看头指针本身是否为空。易错：不带头结点时不能写 `L->next == NULL`。
- **关键概念**：`节点`、`数据域`、`指针域`、`头指针`、`头结点`
- **相互关系**：带头节点的判空条件是必考选择题。
- **出处**：逊哥 P3；张无忌 P9, P10；强哥·数据结构 P9, P10, P11；一灯 P2

### 单链表的初始化与头插法
- **要点**：初始化即 `malloc` 一块节点空间并强转、`next` 置 `NULL`；头插法先把新节点 `next` 指向头节点原本的 `next`，再让头节点 `next` 指向新节点，顺序不能颠倒否则链表会断；插入顺序与最终排列顺序相反。
- **关键概念**：`头插法`、`next`、`malloc`
- **出处**：逊哥 P3；张无忌 P9, P10

### 尾插法与指定位置插入
- **要点**：尾插法先找尾节点（`p->next` 不为空就后移），插入后返回新尾节点供下次复用。指定位置插入先遍历找到前驱（循环到 `position - 1`），再「先连后断」：新节点 `next` 指向当前节点 `next`，当前节点 `next` 指向新节点。共同点：插入与删除都必须先掌握前一结点的地址，知道后继地址没有用。
- **关键概念**：`尾插法`、`前驱节点`、`先连后断`、`position - 1`
- **相互关系**：插入两步顺序不能颠倒，否则丢失后续链表。
- **出处**：逊哥 P3；张无忌 P9, P10；强哥·数据结构 P11, P12；一灯 P2

### 删除指定位置节点、求长度与释放链表
- **要点**：删除四步：找到待删节点的前驱 p；用 q 记住待删节点；让 p 的 `next` 指向待删节点的后继；`free(q)`。释放链表只释放头节点之后的全部数据节点、头节点保留，最后头节点 `next` 置空；求长度从头遍历计数，长度不含头节点。
- **关键概念**：`前驱`、`free`、`释放链表`、`listLength`
- **出处**：逊哥 P3；张无忌 P9；强哥·数据结构 P11, P12

### 双指针求倒数第 K 个节点
- **要点**：两指针都指向首节点，先让 `fast` 单独走 K 步，再与 `slow` 同步后移；`fast` 为空时 `slow` 即倒数第 K 个。时间 $O(n)$、空间 $O(1)$，不能用双层 for。
- **关键概念**：`快慢指针`、`首节点`
- **出处**：逊哥 P4

### 双指针求两个链表的共同后缀起点
- **要点**：分别求出两表长度 M、N，令 `fast` 指向较长者并先走 |M−N| 步，再与 `slow` 同步后移；两指针首次指向同一地址的节点即共同后缀的起始位置。
- **关键概念**：`公共后缀`、`长度差`、`共享节点`
- **出处**：逊哥 P4

### 数组标记法删除绝对值重复的节点
- **要点**：当 |data| ≤ N 时开辟长度 N+1 的辅助数组全部置 0；以 `abs(data)` 为下标查表，为 0 则置 1 并保留，为 1 说明重复，用临时指针摘链并 `free`；属于拿空间换时间。
- **关键概念**：`abs`、`空间换时间`、`辅助数组`
- **相互关系**：与「求未出现的最小正整数」同属空间换时间思路。
- **出处**：逊哥 P4

### 反转链表（三指针法）
- **要点**：`first` 置空、`second` 指向首节点；循环中先让 `third` 记住 `second->next`，再把 `second->next` 指向 `first`，最后 `first = second`、`second = third`；`second` 为空时 `first` 即反转后的首节点。
- **关键概念**：`first`、`second`、`third`、`指针反向`
- **出处**：逊哥 P4

### 快慢指针找中间节点与链表重排
- **要点**：`fast` 走两步、`slow` 走一步；`fast` 为空或 `fast->next` 为空时 `slow` 停在中间节点的前驱位置（偶数个节点取偏后一个为中间节点）。重排套路：找中间 → 断开 → 反转后半段 → 两组指针交替改 `next`。
- **关键概念**：`中间节点`、`前驱节点`、`reorder`
- **出处**：逊哥 P4

### 单向循环链表
- **要点**：尾节点的指针域指向头节点，整条链表成环；头插法、尾插法全部沿用，唯一区别是遍历终止条件——单链表用 `p != NULL`，循环链表必须用 `p != L`（L 为头节点），否则死循环。
- **关键概念**：`循环链表`、`头节点 L`、`终止条件`
- **出处**：逊哥 P4

### 判断链表是否有环与求环的入口
- **要点**：`fast` 走两步、`slow` 走一步（循环条件为 `fast` 及其 `next` 均非空），两指针指向同一节点即说明有环。求入口先令 p 从相遇点绕环一周得环中节点数 `count`；再把两指针置回头节点，`fast` 先走 `count` 步后与 `slow` 同步后移，再次相遇处即入口。
- **关键概念**：`快慢指针相遇`、`环的入口`、`count`
- **出处**：逊哥 P4, P5

### 双向链表的结构与特点
- **要点**：每个节点除 `data` 外有 `prior`（前驱）与 `next`（后继）两个指针域；单链表查后继 $O(1)$、查前驱 $O(n)$，双向链表两者都是 $O(1)$，故插入删除既可找前驱也可找后继。它解决了单链表「知后不知前」的缺点，但指针域变多、存储密度进一步降低。初始化时头节点 `prior`、`next` 都指向自身，判空 `head->next == head`，遍历终止条件改为「指针不等于头节点」。
- **关键概念**：`双向链表`、`prior`、`next`、`head->next == head`
- **出处**：逊哥 P5；张无忌 P9；强哥·数据结构 P13, P14

### 双向链表的插入与删除
- **要点**：头插法：新节点 `prior` 指向头节点、`next` 指向头节点的 `next`，再把新节点赋给「头节点 `next` 的 `prior`」，最后头节点 `next` 改为新节点。尾插四步且顺序不能错：头节点 `prior` 指向新节点；新节点 `next`、`prior` 都指向原尾节点；原尾节点 `next` 指向新节点。指定结点 p 之后插入依次为 `s->next = p->next;`、`s->prior = p;`、`p->next->prior = s;`、`p->next = s;`。删除先找到前驱 P，令 Q 指向 P 的 `next`，把 Q 的 `next` 赋给 P 的 `next`、把 P 赋给「Q 的 `next` 的 `prior`」，最后 `free(Q)`；销毁链表必须先保存 `next` 再释放当前节点。易错点：`L->next->prior` 这类连续写法要从右往左读。
- **关键概念**：`头插法`、`尾插法`、`先保存 next 再 free`、`P->next->prior`
- **出处**：逊哥 P5；张无忌 P9, P10；强哥·数据结构 P13, P14

### 有序表插入算法
- **要点**：从头遍历找到第一个大于等于 `x` 的元素位置（即插入点），从表尾开始向前把元素逐个后移一位，写入 `x`，表长加一。
- **关键概念**：`有序表`、`查找插入位置`、`从后往前移动`
- **相互关系**：是顺序表插入在表已有序下的具体化，常作算法大题。
- **出处**：张无忌 P21


## 三十一、数据结构：栈与队列

### 栈的定义与特性
- **要点**：栈是限定仅在表尾插入和删除的线性表，表尾称栈顶、表头称栈底，按后进先出（LIFO）修改；只关注压栈、出栈、取栈顶、判空四种操作。可用顺序存储（顺序栈）或链式存储（链栈）实现。函数调用、递归时的数据都在栈区开辟空间。
- **关键概念**：`stack`、`栈顶`、`栈底`、`LIFO`、`后进先出`
- **出处**：逊哥 P5；张无忌 P11, P12；强哥·数据结构 P15；一灯 P3

### 栈的顺序存储实现
- **要点**：结构体含 `data[maxSize]` 与 `top`（本质是数组下标）。一种约定是初始化 `top = -1`；判空 `top == -1`；判满 `top == maxSize - 1`；压栈先 `top++` 再写 `data[top]`；出栈先取 `data[top]` 返回再 `top--`。另一种约定是 `top` 指向栈顶元素的上一个位置、`base` 指向栈底；判空 `top == base`，元素个数 `top - base`，判满 `top - base >= stackSize`；入栈先判满（满则 `realloc` 追加并更新 `base`、`top`），再 `*top = e`、`top++`；出栈先判空，再 `top--` 并取值返回。易错：出栈必须先自减再取值，顺序颠倒会取错。
- **关键概念**：`top`、`base`、`maxSize`、`stackSize`
- **出处**：逊哥 P5；张无忌 P11

### 栈的链式存储实现
- **要点**：尾节点是栈底、头节点的下一个节点是栈顶，故压栈等价于头插法、出栈等价于删除首节点（用临时指针保存后 `free`）；判空为 `head->next == NULL`，取栈顶即读 `head->next->data`。
- **关键概念**：`头插法`、`栈顶即首节点`、`头节点`
- **出处**：逊哥 P5

### 出栈序列的合法性判断与栈的最小容量
- **要点**：解法都是「边入边出」逐步模拟：元素只有入栈后才能出栈，下方元素须等上方元素全部出栈后才能出栈，不能跨位置输出；需要某元素先出就把尚未入栈的元素依次压入，用完即弹出，过程中栈内元素的最大个数即最小栈容量。诀窍是先看首元素是第几个入栈的，从而确定之前有多少元素已压在栈内。若限制不允许连续多次退栈，则该序列不可能出现。火车轨道题本质相同——每条轨道相当于一个栈。
- **关键概念**：`出栈序列`、`栈的最小容量`、`轨道即栈`、`模拟压弹`
- **相互关系**：附加限制会改变判定结果，需重新模拟。
- **出处**：逊哥 P6；张无忌 P11, P12；强哥·数据结构 P15, P16；一灯 P3

### 卡特兰数
- **要点**：n 个元素所有可能的出栈序列个数为 C(2n,n)/(n+1)。
- **关键概念**：`卡特兰数`
- **出处**：强哥·数据结构 P15, P16

### 运算符栈的计算题
- **要点**：S1 存操作数、S2 存运算符，每次从 S1 弹出两个操作数 A、B（先弹出的是 A），从 S2 弹出 OP，执行 `B OP A` 再把结果压回 S1；易错点是运算顺序为「后弹出的操作数在前」，读题不仔细会算成 A OP B 而得到相反数。
- **关键概念**：`操作数栈`、`运算符栈`、`B OP A`
- **出处**：逊哥 P6

### 队列的定义与特性
- **要点**：队列是先进先出（FIFO）的线性表，只允许一端插入、另一端删除；允许插入的一端叫队尾（rear），允许删除的一端叫队头（front）；元素按 a1…an 顺序入队也只能按此顺序出队，各元素类型必须一致。顺序存储的队列通常设两个指针：`头指针`指向队头元素，`尾指针`指向队尾元素的下一个位置，元素个数为尾指针减头指针。易错：出队不是做减法，头、尾指针移动时都自增。
- **关键概念**：`queue`、`FIFO`、`队头 front`、`队尾 rear`
- **出处**：逊哥 P5, P6；张无忌 P13, P15；强哥·数据结构 P16；一灯 P2

### 顺序队列与假溢出
- **要点**：初始化 `front = rear = 0`，判空条件是 `rear == front` 而非「等于 0」；入队前判满（`rear >= maxSize`），入队写 `data[rear]` 再 `rear++`，出队取 `data[front]` 再 `front++`。队尾到头但队头前仍有空位属假溢出，只能整体前移，代价 $O(n)$。
- **关键概念**：`假溢出`、`调整队列`
- **出处**：逊哥 P5

### 循环队列（含判空判满与指针初值）
- **要点**：把顺序存储空间在逻辑上看成一个环即`循环队列`，指针移动改为取模：入队 `rear = (rear+1) % maxSize`，出队 `front = (front+1) % maxSize`；元素个数为 `(rear - front + maxSize) % maxSize`（先加长度再取余是为避免相减出现负数）。判满 `(rear+1) % maxSize == front`，判空仍为 `rear == front`。必须牺牲一个存储单元，否则队空与队满条件相同而无法区分；故长度 m 的数组最多存 m-1 个元素。若起始下标为 0，队尾指针指向队尾元素的下一个位置；若要求 `rear` 直接指向队尾元素，则初始 `rear` 取 `maxSize - 1`。题目给出「front 指向队头、rear 指向队尾」且第一个元素落在 `A[0]` 时，初始 `front = 0`、`rear = N − 1`；给出「最多容纳 M−1 个元素」时 `maxSize = M − 1`。判空判满公式与「rear 指向哪」这两个约定，是相关选择题的唯一判断依据。
- **关键概念**：`循环队列`、`取余`、`牺牲一个空位`、`maxSize`
- **相互关系**：空/满判定是高频考点。
- **出处**：逊哥 P5, P6, P7；张无忌 P13, P15；强哥·数据结构 P17；一灯 P2, P3

### 链式队列
- **要点**：单链表实现，队头删除、队尾插入；单独声明队列结构体 Q，内含 `front`、`rear` 两个节点指针；初始化创建头节点并令 `Q.front = Q.rear = 头节点`（不带头节点时初始两指针都为空，判空即两者都为空）。用尾插法入队：若队列为空则两指针都指向新节点，否则队尾节点 `next` 指向新节点并更新队尾。出队即删除首节点，先判空并备份队头数据；若只有一个元素，删除后两指针都要置空，否则令队头指针指向其 `next` 后释放原队头节点——删掉的正是尾节点时要把 `rear` 与 `front` 都重新指向头节点。
- **关键概念**：`Q 结构体`、`qNode`、`尾插法`、`队头指针`、`队尾指针`
- **相互关系**：删除最后一个元素时必须同时改队尾指针。
- **出处**：逊哥 P6；张无忌 P14, P15


## 三十二、数据结构：串

### 串的基本概念与子串
- **要点**：`串`（字符串）由零个或多个字符组成，字符个数 $n$ 为串长，$n=0$ 为`空串`；通常用单引号括起，字符可为字母、数字及可用 `ASCII 码`表示的符号。`子串`是主串中任意一段**连续**字符序列，不连续不是子串；包含子串的串称`主串`，子串在主串中的位置以其第一个字符在主串中的位置确定，串自身与空串都是该串的子串。
- **关键概念**：`串长`、`空串`、`子串`、`主串`、`ASCII 码`
- **相互关系**：与 C 语言字符串不同——C 语言串末尾隐含 `\0`，长度为字符个数（不含 `\0`），占用内存比长度多 1；数据结构中不强调 `\0`，串长可为 0。串与线性表的区别在操作对象：线性表操作`数据元素`（可以很复杂，如一个结点），串只能操作单个`字符`，故基本操作是求子串、求子串位置、求串长。
- **出处**：张无忌 P16, P18；强哥·数据结构 P18；一灯 P2

### 串相等、空串与空格串
- **要点**：两个串`相等`要求长度相等且对应位置字符完全相同，缺一不可。`空串`长度为 0、不含任何字符；`空格串`由若干个空格字符组成，空格是实实在在的字符（ASCII 码 32），两者含义完全不同，空格串长度等于空格个数，不能互相简称。
- **关键概念**：`串相等`、`空串`、`空格串`
- **出处**：强哥·数据结构 P18；张无忌 P16, P18；一灯 P3

### 子串个数
- **要点**：设串长为 n，子串总数为 n(n+1)/2+1（含空串与自身）；非空子串为 n(n+1)/2；真子串（不含自身、含空串）为 n(n+1)/2；非空真子串为 n(n+1)/2-1。加的 1 就是空串，减的 1 就是去掉自身，本质是等差数列求和。
- **关键概念**：`子串个数`、`空串`、`真子串`
- **出处**：强哥·数据结构 P18

### 串的顺序存储与基本操作
- **要点**：顺序存储两方案：末尾另存长度，或长度放在下标 0 处（求 `next` 数组用方案二，字符下标从 1 开始）；结构体含 `length` 与字符数组 `ch`。基本操作：初始化（字符置 `\0`、长度置 0）、复制、判空（看长度是否为 0）、比较（按字典序逐字符比，公共部分相同则长者大）、截取子串（先判 `pos + len` 越界，再从 `pos` 复制 `len` 个字符并更新长度）、连接、定位（依次取等长片段比较，返回首次出现的位序，找不到返回 0 或 -1）。
- **关键概念**：`length`、`ch`、`字典序`、`模式匹配`、`位序`
- **相互关系**：定位即朴素模式匹配，是 KMP 的改进对象。
- **出处**：张无忌 P16

### 串的模式匹配与存储结构
- **要点**：`模式匹配`是在主串中查找子串（模式串）位置的操作，有朴素的普通匹配算法与 `KMP 算法`两种：前者逐位比较、效率较低，后者利用已匹配信息减少回溯、效率更高。串的存储结构参照顺序表的分配方式，分`静态分配`（数组定长）与`动态分配`（堆区开辟）。
- **关键概念**：`模式匹配`、`KMP 算法`、`静态分配`、`动态分配`
- **出处**：强哥·数据结构 P18

### KMP 算法与 next 数组
- **要点**：`next` 数组存放「最长公共前后缀长度 + 1」；`前缀`指除最后一个字符外从最左开始连续的所有子串，`后缀`指除第一个字符外连续的所有子串。求 next 先标出从 1 开始的下标，前两个默认填 0、1，从第三个起取该元素**前一个元素之前**的串，求最长公共前后缀长度再加一。匹配时主串指针不回溯，失配处按其 next 值把模式串对齐到相应位置继续比较。
- **关键概念**：`next 数组`、`最长公共前后缀`、`前缀`、`后缀`、`模式串`、`主串`
- **相互关系**：next 下标从 1 开始与「长度存在下标 0」的方案对应。
- **出处**：张无忌 P17, P18

### nextval 数组
- **要点**：由 next 推出：第一个位置固定为 0；之后逐位拿当前元素与「下标等于其 next 值」的元素比较，不同则取当前 next 值，相同则取该位置的 nextval 值。
- **关键概念**：`nextval`、`优化 next`
- **出处**：张无忌 P17, P18


## 三十三、数据结构：数组、矩阵与广义表

### 数组的地址计算
- **要点**：一维数组所有元素占用一段连续空间，若首地址为 LOC(a₀)、每个元素占 L 个字节，则 LOC(ai)=LOC(a₀)+i×L；一维第 $i$ 个元素地址 = 首地址 $+ i \times$ 元素大小。二维数组有`行优先`与`列优先`两种存储次序：行优先 LOC(aij)=LOC(a₀₀)+(i×列数+j)×L，列优先 LOC(aij)=LOC(a₀₀)+(j×行数+i)×L，两公式互换。可用公式法或画图法（展开序列上数格子）互相校验；一个字节对应一个地址（8 个二进制位），C 语言默认行优先。易错：公式中的列数/行数必须是数组自身固有属性，不能错乘；数格子要跳过起始元素本身。数组总字节数 = 元素总数 × 每元素字节数。
- **关键概念**：`首地址`、`偏移量`、`行优先`、`列优先`、`LOC`
- **出处**：张无忌 P19, P21；强哥·数据结构 P19

### 对称矩阵的压缩存储
- **要点**：`对称矩阵`沿主对角线上下元素相同，只需存下三角区（或上三角区）及主对角线，把二维数组压缩到一维数组；n 阶方阵压缩后需 n(n+1)/2 个存储空间（等差数列求和），对应一维数组下标范围 0~n(n+1)/2-1；按行优先存下三角时 $a\_\{ij\}$ 的一维下标为 $i(i+1)/2 + j$。下三角区可按行存储也可按列存储，两种次序都能通过画图逐一定位。压缩的本质是发现数据规律、避免重复存储，被压缩掉的部分需通过算法还原；下标对应公式不必死记，考试时现场推导。考试多给行列下标求一维下标，或由下标反推行列。
- **关键概念**：`对称矩阵`、`主对角线`、`压缩存储`、`下三角区`、`n(n+1)/2`
- **出处**：张无忌 P20；强哥·数据结构 P20, P21

### 三角矩阵的压缩存储
- **要点**：`三角矩阵`指下三角区（或上三角区）中除主对角线外的元素全为同一常量。压缩时只存下三角区与主对角线，即 n(n+1)/2 个元素，再额外开辟 1 个空间存放该常量，共需 n(n+1)/2+1 个空间，还原时把常量填回对应区域。与对称矩阵相比多出 1 个空间；元素杂乱无章的普通矩阵无法压缩，按原样开辟 n×n 个空间。
- **关键概念**：`三角矩阵`、`常量区`、`n(n+1)/2+1`
- **出处**：张无忌 P20；强哥·数据结构 P21

### 三对角矩阵
- **要点**：`三对角矩阵`只在主对角线及其上下各一条对角线上有非零元素，元素个数 $3n-2$，按行存储时 $a\_\{ij\}$ 的一维下标为 $2i + j - 3$，反求行列下标 $i = \lceil (k+2)/3 \rceil$、$j = k - 2i + 3$。
- **关键概念**：`三对角矩阵`、`向上取整`、`3n-2`
- **出处**：张无忌 P20

### 稀疏矩阵
- **要点**：`稀疏矩阵`非零元素远少于元素总数；压缩方式一为`三元组顺序表`，只记每个非零元素的行、列、值；方式二为`十字链表`，节点含三元组并同时用向右、向下指针链接，分别串起同一行与同一列的非零元素。十字链表只需了解结构，考试要求较低。
- **关键概念**：`稀疏矩阵`、`三元组`、`十字链表`
- **出处**：张无忌 P20

### 广义表
- **要点**：`广义表`（列表）是线性存储结构，元素既可是不可再分的原子，也可是子表；`表头`为第一个逗号前的元素，`表尾`为第一个逗号之后的全部元素（取出后需再套一层括号），`长度`为最外层元素个数，`深度`为括号嵌套的最大层数。最外层括号内的一个子表整体只算一个元素。
- **关键概念**：`广义表`、`表头`、`表尾`、`长度`、`深度`
- **出处**：张无忌 P22；一灯 P2


## 三十四、数据结构：树与二叉树

### 树的基本概念与性质
- **要点**：树是一个或多个节点的有限集合，$n=0$ 为空树；存在一个称为根的特定节点，其余节点划分为若干互不相交的集合，每个集合本身又是一棵树（根的子树）。术语：节点的度（子树数量）、树的度（各节点度的最大值）、叶子（度为 0）、孩子（子树的根，直接后继）、双亲（直接前驱）、兄弟（同一双亲的孩子）、层次（根为第一层）。核心性质：节点总数 = 所有节点度数之和 + 1；度为 M 的树第 I 层最多 $M\^\{I-1\}$ 个节点，高度 H 时最多 $(M^H-1)/(M-1)$ 个节点。真题常联立 $n = n_0+n_1+n_2+n_3+n_4$ 与 $n = 度数之和 + 1$ 求叶子数；应用包括文件系统目录、B+ 树与红黑树、决策树。
- **关键概念**：`根节点`、`节点的度`、`叶子节点`、`$n=\sum d_i+1$`
- **出处**：逊哥 P8, P9；张无忌 P23

### 二叉树的定义与基本形态
- **要点**：二叉树是 n 个节点的集合，可以为空；非空时有且仅有一个根节点，其余节点分成两个互不相交的子集称左子树和右子树。每个节点至多两棵子树、每个节点的度不超过 2，子树有左右之分、次序不能颠倒；退化成一条链的称斜树。左右不可交换是由遍历序列还原二叉树、线索二叉树等题的关键前提。
- **关键概念**：`左子树`、`右子树`、`斜树`
- **出处**：逊哥 P9；张无忌 P23

### 二叉树的三大性质
- **要点**：① 第 I 层最多 $2\^\{I-1\}$ 个节点；② 深度为 K 最多 $2^K-1$ 个节点（是「最多」，不要求取满）；③ 任何非空二叉树中叶子数 $N_0$ 与度为 2 的节点数 $N_2$ 满足 $N_0=N_2+1$。节点总数 $n = n_0 + n_1 + n_2 + \cdots$，且节点总数 = 总度数 + 1。性质③ 与 $n=N_0+N_1+N_2$ 联立可求叶子数；节点数为偶数时说明恰有一个度为 1 的节点。
- **关键概念**：`$2^{I-1}$`、`$2^K-1$`、`$N_0=N_2+1$`、`节点总数 = 总度数 + 1`
- **相互关系**：两条公式联立可消去未知量，用于求叶子数。
- **出处**：逊哥 P9；张无忌 P23；一灯 P2, P4

### 满二叉树与完全二叉树
- **要点**：满二叉树是深度 K 且恰有 $2^K-1$ 个节点的二叉树，所有分支节点都有左右子树且叶子全在同一层，非叶节点度必为 2；完全二叉树是深度 K 的 n 个节点二叉树，其节点与同深度满二叉树中编号 1 至 n 的节点一一对应，除最后一层外每层都满，且最后一层节点从左到右依次排列、中间不能缺左节点，叶子只出现在最后两层。自根自上而下、自左向右编号后，编号 i 的节点左孩子为 2i、右孩子为 2i+1。满二叉树一定是完全二叉树，反之不成立。判定口诀「有左子树不能有右子树，上一层没铺满不能有下一层」。
- **关键概念**：`满二叉树`、`完全二叉树`、`左孩子 2i`、`右孩子 2i+1`
- **出处**：逊哥 P9, P11；张无忌 P23；一灯 P2, P4

### 完全二叉树的深度公式
- **要点**：已知完全二叉树节点数 $n$，深度为 $\lfloor \log_2 n \rfloor + 1$，即取以 2 为底的对数后向下取整再加一。
- **关键概念**：`完全二叉树`、`深度`、`向下取整`
- **出处**：一灯 P4

### 二叉树的存储结构与二叉链表定义
- **要点**：顺序存储用数组按下标（按层序）存放节点，仅对满二叉树、完全二叉树不浪费空间。更常用链式存储：先 `typedef char ElemType;`，再定义含 `data`、`*lchild`、`*rchild` 的节点结构体，最后 `typedef struct TreeNode *BiTree;` 给节点指针起别名，后续操作均按链式实现。
- **关键概念**：`顺序存储`、`链式存储`、`二叉链表`、`BiTree`、`lchild`、`rchild`
- **出处**：逊哥 P9；张无忌 P23

### 三种遍历与递归的执行路径
- **要点**：三种遍历差别只在输出语句的位置：先输出再递归左右是前序（根左右），先左、再输出、再右是中序（左根右），先左右、最后输出是后序（左右根）；未指明一律先左后右，终止条件是节点为空。叶子节点也要走完它的空左右孩子再返回。函数调用在栈内存中压栈、执行完才出栈，可用「压栈—输出—出栈」逐层模拟。非递归前序遍历即自己维护一个栈：节点不空则输出并压栈、转向左孩子，左孩子走不通时弹栈并转向其右孩子，直到栈空。
- **关键概念**：`前序/中序/后序遍历`、`非递归遍历`
- **相互关系**：中序遍历二叉排序树可得递增序列。
- **出处**：逊哥 P9, P11；张无忌 P23, P24

### 由遍历结果推导二叉树
- **要点**：中序序列必须给出，配合先序或后序才能唯一确定一棵二叉树；先序 + 后序不能，无法确定左右归属，题问「中序不会是什么」时应用排除法。还原套路：先序第一个元素是根（后序最后一个元素是根），在`中序序列`中找到该根，左侧即左子树、右侧即右子树，再对各子树递归重复，还原整棵树并写出所需的第三种遍历序列。
- **关键概念**：`先序+中序`、`后序+中序`、`定根`、`划分左右子树`
- **相互关系**：必考题型，写后序前先画树。
- **出处**：逊哥 P11, P13；张无忌 P23

### 层序遍历与求 WPL 的算法
- **要点**：层序遍历借助队列自上而下、自左向右逐层访问：根入队；循环中先记录当前队列元素个数 `count`（本层节点数），再依次出队并访问、把非空左右孩子入队，`count` 减到 0 说明本层结束、层数加一。求 WPL 时给节点增加 `weight` 域，用数组手写队列做层序遍历，出队节点若左右孩子都为空则是叶子，把「层数 × 权值」累加。递归遍历用系统栈、层序遍历用队列；记录层数的能力可直接用于求树高和 WPL。
- **关键概念**：`队列`、`count`、`weight`、`层数 × 权值`
- **出处**：逊哥 P13

### 线索化的规则与标志位
- **要点**：左孩子为空时指向该次序下的前驱，右孩子为空时指向后继，这种指针称线索；结构体增加 `ltag`、`rtag`，取 0 表示指向真实子树、取 1 表示是线索。目的是让二叉树能像双向循环链表一样循环遍历而不必递归，前提是先约定按前序、中序还是后序加线索。含 n 个节点的二叉树必有 n+1 个空指针域。
- **关键概念**：`前驱`、`后继`、`线索`、`ltag`、`rtag`
- **出处**：逊哥 P11

### 线索化的边界处理、线索遍历与判定题型
- **要点**：完整线索化还要把头节点 `lchild` 指向根（`ltag=0`）、头节点 `rchild` 指向遍历的最后一个节点（`rtag=1`），并把第一个节点的 `lchild`、最后一个节点的 `rchild` 都指向头节点，构成闭环。中序线索化按中序递归：先线索化左子树，再处理当前节点（左空则 `ltag=1`、`lchild` 指向 `pre`），随后若 `pre` 右孩子为空则 `rtag=1`、`rchild` 指向当前节点（后继只能由上一个访问的节点确认），更新 `pre` 后再线索化右子树。线索遍历从根起能往左就往左，否则输出，再顺右线索跳到后继，直到回到头节点。判定类题先写出该次序的完整线性序列，再按序列找前驱与后继比对图中虚线。线索化必须用递归，线索化后的遍历才可以不用递归。
- **关键概念**：`头节点`、`pre 指针`、`中序线索化`、`右线索跳转`
- **出处**：逊哥 P11

### 路径、权与带权路径长度
- **要点**：路径长度是路径上分支（边）的数目；树的路径长度是根到每个节点的路径长度之和；节点的带权路径长度是根到该节点的路径长度与该节点权的乘积；树的带权路径长度 WPL 是所有叶节点带权路径长度之和。
- **关键概念**：`路径长度`、`权`、`带权路径长度`、`WPL`
- **相互关系**：else-if 判定树与树同构，WPL 越小说明判定效率越高。
- **出处**：逊哥 P12

### 哈夫曼树的构造与性质
- **要点**：WPL 最小的二叉树称哈夫曼树。构造方法：把所有带权叶子按权值从小到大排序，每次取出权值最小的两个节点作为兄弟，构造一个新节点作其双亲（权值为二者之和），放回序列重新排序，重复直到只剩一棵树；约定左孩子权值不大于右孩子可使树唯一。哈夫曼树中没有度为 1 的节点；权值最小的两个节点一定是兄弟；任意非叶节点的权值不小于其下一层任意节点的权值；它不一定是完全二叉树，形态也不唯一。权值越大的叶子离根越近，故 WPL 最小；「无度为 1」常与 $N_0=N_2+1$、$n=N_0+N_2$ 联立求节点数或符号数。
- **关键概念**：`哈夫曼树`、`取最小两个`、`无度为 1 的节点`
- **出处**：逊哥 P12

### 哈夫曼编码、前缀编码与相关题型
- **要点**：把字符使用频率当权值构造哈夫曼树，从根出发左分支标 0、右分支标 1，从根到叶子路径上的 0/1 串即该字符的编码。前缀编码指任一编码都不是其他任何编码的前缀，哈夫曼编码一定是前缀编码。常见题型：给权值画哈夫曼树并算 WPL（只累加叶子节点，易错点是误把非叶节点也算进去）；给编码序列问译码结果；给节点总数与「有 N 个符号」求符号数。权值大的字符编码短，整体平均码长最短，用于远距离通信的数据压缩。
- **关键概念**：`哈夫曼编码`、`左 0 右 1`、`前缀编码`、`译码`
- **出处**：逊哥 P12

### 树、森林与二叉树的相互转换
- **要点**：树转二叉树三步——加线（在所有兄弟节点之间加连线）、去线（每个节点只保留与第一个孩子的连线）、层次调整（以根为轴心顺时针旋转）；转换后第一个孩子成为节点的左孩子，转过来的兄弟成为右孩子。二叉树转树是逆操作：若某节点的左孩子存在，则把该左孩子的所有右孩子都连成该节点的孩子，再删除所有节点与其右孩子的连线。森林转二叉树：先把每棵树各自转成二叉树，第一棵不动，从第二棵开始依次把后一棵的根节点作为前一棵根节点的右孩子；二叉树转森林则从根开始把右孩子方向的连线全部断开，拆成若干棵二叉树再各自转回树。森林中每棵树对应转换后二叉树的一条右链。
- **关键概念**：`加线`、`去线`、`顺时针旋转`、`第一棵不动`、`右孩子串接`
- **相互关系**：考试多以「转换后某两节点的层次关系」形式考查。
- **出处**：逊哥 P12, P13

### 树与森林的遍历、对应关系与相关题型
- **要点**：树只有先根遍历（先访问根，再依次先根遍历每棵子树）和后根遍历（先依次后根遍历每棵子树，最后访问根），没有中序；森林有前序和中序遍历，没有后序遍历。对应关系：树的先根 = 二叉树的前序，树的后根 = 二叉树的中序，森林的前序 = 二叉树的前序，森林的中序 = 二叉树的中序。抽象题按层次画出可能的几种形态逐个逆转换，看能推出父子关系还是兄弟关系；计数题用「每个非最后一个孩子都会产生右孩子」的规律，求森林中树的棵数用「每棵树节点数比边数多一」。
- **关键概念**：`先根遍历`、`后根遍历`、`节点数 = 边数 + 树数`
- **出处**：逊哥 P13

### 正则 K 叉树的计数
- **要点**：正则 K 叉树指每个非叶节点都恰有 K 个孩子，即只有度为 0 和度为 K 的节点。若非叶节点数为 M、叶节点数为 $N_0$，则总边数为 KM，节点数 $n=KM+1=N_0+M$，故 $N_0=KM-M+1$。深度为 H 时节点数最多为 $(1-K^H)/(1-K)$（等比数列求和），最少为 $1+K(H-1)$。
- **关键概念**：`正则 K 叉树`、`$N_0=KM-M+1$`、`等比数列求和`
- **相互关系**：推导依赖「节点数 = 边数 + 1」。
- **出处**：逊哥 P13

### 二叉树的递归算法（节点数、叶子数、树高）
- **要点**：求节点总数——空返回 0，否则计数加一后递归左右子树；求叶子节点数——空返回 0，左右孩子都空返回 1，否则返回左右子树叶子数之和；求树高——空返回 0，否则取左右子树高度较大者加一；输出所有叶子节点——空直接返回，左右孩子都空则打印数据域，否则递归左右子树。
- **关键概念**：`递归终止条件`、`左右孩子均为空`、`取较大者加一`
- **相互关系**：三类算法结构同源，区别只在终止条件与返回值。
- **出处**：张无忌 P24

### 树与二叉树的区别
- **要点**：树不分左右、二叉树区分左右；同样三个节点，树只有两种形态，二叉树有五种形态。
- **关键概念**：`树`、`二叉树`、`左子树`、`右子树`
- **相互关系**：读题必须看清是「树」还是「二叉树」，否则容易多选。
- **出处**：一灯 P2


## 三十五、数据结构：图

### 图的定义、有向图与无向图
- **要点**：图由顶点的有穷非空集合和顶点之间边的集合组成，记作 $G=(V,E)$；与树不同，图不允许没有顶点，但边可以为空。无向图的边记作 $(v,w)$、顺序无所谓；有向图的边称弧，记作 `<v,w>`，带箭头的一端叫弧头、另一端叫弧尾，弧总是从弧尾指向弧头。
- **关键概念**：`$G=(V,E)$`、`弧`、`弧头`、`弧尾`
- **相互关系**：方向性是邻接矩阵、邻接表、入度出度等概念的前提。
- **出处**：逊哥 P14

### 简单图、多重图与完全图
- **要点**：简单图满足两条限制——不含顶点到自身的边（自环），且同一条边不重复出现两次及以上；不满足任一限制的称多重图，本课程只讨论简单图。完全图是具有最多边数的图：n 个顶点的无向完全图边数为 $\frac{n(n-1)}{2}$，有向完全图边数为 $n(n-1)$；反之若恰有上述边数即为完全图。
- **关键概念**：`自环`、`简单图`、`完全图`
- **出处**：逊哥 P14

### 路径、回路与顶点的度
- **要点**：起点与终点相同的路径称回路（环），路径长度是路径上边的条数；路径中不出现相同顶点的称简单路径，除第一个和最后一个顶点外其余顶点都不重复的回路称简单回路。无向图中顶点的度是与该顶点相关联的边的数目；有向图分入度（箭头指向该顶点的边数）和出度（从该顶点出发的边数）。无向图所有顶点的度数之和等于边数的两倍；有向图所有顶点的出度之和等于入度之和，也等于弧的数目。度数之和必为偶数，可直接排除「度数之和为奇数」的错误选项。
- **关键概念**：`简单路径`、`简单回路`、`入度`、`出度`、`度数之和 = 2 × 边数`
- **出处**：逊哥 P14；一灯 P2

### 子图、连通、强连通与生成树
- **要点**：若图 H 的顶点集和边集分别是图 G 的顶点集和边集的子集，则 H 是 G 的子图。无向图中任意两顶点间都有路径则称连通图，其极大连通子图称连通分量；连通不要求直达、绕道能到即可，「极大」指再加入任一顶点就不再连通。有向图中若对每一对顶点 v、w，v 到 w 和 w 到 v 都有路径，则称强连通图，其极大强连通子图称强连通分量。含有图中全部顶点、但只有足以构成一棵树的 n−1 条边的极小连通子图称生成树；边上标注的代表某种含义的数值称该边的权，带权的图称网。求 n 个顶点图在任何情况下都连通所需最少边数，先让 n−1 个顶点构成完全图再加一个顶点连一条边；由边数反推顶点数时列方程并枚举组合取顶点数最少者。
- **关键概念**：`连通分量`、`强连通图`、`生成树`、`权`、`网`
- **出处**：逊哥 P14

### 邻接矩阵与 visited 数组
- **要点**：用一个一维数组存顶点、一个二维数组（边数组）存边的关系：有边记 1、无边记 0，对角线记 0。无向图的邻接矩阵沿主对角线对称，可只写一半再把 `A[i][j]` 赋给 `A[j][i]`；有向图中行看是出边、列看是入边。带权图把 1 换成权值、把 0 换成 ∞（代码中记 `max`），对角线仍为 0，以免与权值为 0 的边混淆。`visited` 数组与顶点下标一一对应，1 表示已访问、0 表示未访问。适合稠密图，是 DFS/BFS、Prim、Dijkstra、拓扑排序等所有图算法的公共基础。
- **关键概念**：`vertex`、`arc`、`visited`、`对称`、`∞`
- **出处**：逊哥 P14, P15, P17, P18

### 邻接表与逆邻接表
- **要点**：邻接表用数组存各顶点作头节点，每个顶点拉出一条链表，链表中存放与该顶点相关联的边的另一端顶点的数组下标（不是顶点名）。无向图中每条边被存两次，n 个顶点 e 条边需 2e 个表节点，存在空间冗余。有向图的邻接表只表达出边，查入边需遍历整表，为此另设逆邻接表专门存放入边，但它又无法反映出边。适合稀疏图；带权图的邻接表在边节点中额外增加 `weight` 域。
- **关键概念**：`头节点`、`表节点`、`数组下标`、`逆邻接表`
- **出处**：逊哥 P14

### 十字链表与邻接多重表
- **要点**：十字链表面向有向图，用「一横一纵」同时表达出边与入边：顶点结构含 `data`、`firstin`（入边表头指针）、`firstout`（出边表头指针）；边结构含 `tailvex`（弧尾）、`headvex`（弧头）、`hlink`（弧头相同的下一条边指针）、`tlink`（弧尾相同的下一条边指针）。邻接多重表面向无向图，解决邻接表中同一条边被存两次的空间冗余：每个边节点含 `ivex`、`jvex`（一条边连接的两个顶点下标）、`ilink`（依附于 ivex 的下一条边）、`jlink`（依附于 jvex 的下一条边），顶点节点只存指向第一条依附边的指针，这样 e 个边节点即可表示 e 条边。
- **关键概念**：`firstin`、`firstout`、`hlink`、`tlink`、`ivex`、`jvex`
- **出处**：逊哥 P14

### 深度优先遍历（DFS）
- **要点**：从某顶点出发沿一条路径一直往里走，走不动再回溯到上一个还有未访问邻接点的顶点继续深入，遍历次序与树的前序遍历一致。实现时先置 `visited[i]=1` 并输出该顶点，再在 i 这一行中找第一个满足 `arc[i][j]==1 && visited[j]==0` 的顶点 j，递归调用 `DFS(G, j)`。
- **关键概念**：`DFS`、`visited 数组`、`递归`
- **相互关系**：与 BFS 同为一图的两种遍历次序，区别在于递归/栈 vs 队列。
- **出处**：逊哥 P15

### 广度优先遍历（BFS）
- **要点**：按「一层一层」的方式访问，次序与树的层序遍历一致。先把起点标记 `visited`、输出并入队，再循环：出队一个顶点，把它所有满足 `arc[i][j]==1 && visited[j]==0` 的邻接点标记、输出、依次入队，直到队列为空；`front==rear` 表示队列为空。队列可用数组模拟，考试写代码时不必写出完整队列实现。
- **关键概念**：`BFS`、`队列`、`front`/`rear`、`先进先出`
- **出处**：逊哥 P15

### 最小生成树与极小连通子图
- **要点**：n 个顶点的图用 n−1 条边把所有顶点连通且不产生回路，得到的极小连通子图即最小生成树；带权图要求各边权值之和最小。典型场景是给若干村庄铺路、架电缆，以最小成本连通所有点。与最短路径目标不同——最小生成树求「连通所有点的总代价最小」，最短路径求「两点之间走得最少」。
- **关键概念**：`极小连通子图`、`连通图`、`E = N − 1`
- **出处**：逊哥 P15

### Prim（普里姆）算法
- **要点**：以顶点为中心。从任一顶点出发并入已选集合，每并入一个顶点就展开一批新的候选边，反复在候选边中选权值最小的一条，把对应的新顶点并入，直到全部顶点加入。用 `weight` 数组保存当前各候选边的最小权值，用「下标与值各表示一个顶点」的 `vexindex` 数组记录每条候选边连的是哪两点；某顶点被选中后把 `weight` 对应位置置 0，使它不再参与候选，从而自然排除会成环的边。本质是贪心算法；与 Kruskal 的区别是「按点扩展」还是「按边扩展」。
- **关键概念**：`weight`、`vexindex`、`候选边`、`贪心`
- **出处**：逊哥 P15

### Kruskal（克鲁斯卡尔）算法
- **要点**：以边为中心。先把所有边按权值升序排序——用一个含起点、终点、权值的 `edge` 结构体数组装下全部边再调用排序函数，排序交换时需分别交换 `begin`、`end`、`weight` 三个成员。然后从小到大依次取边：用 `parent` 数组记录连通关系，把边的两个端点分别送入 `find` 向上找根，若两根不同说明不会成环，就把一个根指向另一个根并选中该边；若两根相同说明两端点已连通、再加这条边会形成回路，直接丢弃。`parent` 数组「下标与值各表示一个顶点」的用法与 Prim 的 `vexindex` 同源。
- **关键概念**：`edge 结构体`、`parent 数组`、`find`、`回路`、`并查集思想`
- **出处**：逊哥 P15

### 两种最小生成树算法的比较
- **要点**：Prim 针对顶点，时间复杂度 $O(n^2)$，只与顶点数有关，适合边多的稠密图；Kruskal 针对边，时间复杂度 $O(E \log E)$，适合边少的稀疏图。考试通常只要求按规则依次选出边、画出结果图并写出选边顺序。
- **关键概念**：`稠密图`、`稀疏图`、`时间复杂度`
- **出处**：逊哥 P15

### Dijkstra（迪杰斯特拉）算法
- **要点**：只要确定了起点，就能求出该起点到图中任意顶点的最短路径。配合三个数组：`distance` 存起点到各顶点的当前最短距离，`path` 存「谁离这个顶点最近」（下标是终点、值是最近的顶点），另一个标记数组记录顶点是否已被访问。每轮在未访问顶点中选 `distance` 最小者加入，再用它做松弛——若 `distance[k]+arc[k][j] < distance[j]`，就更新 `distance[j]` 并把 `path[j]` 改成 k。最终路径需由终点沿 `path` 反向回溯到起点；若要正向输出，回溯时把顶点依次压栈再出栈即可。
- **关键概念**：`distance`、`path`、`松弛`、`反推路径`、`标记数组`
- **相互关系**：与最小生成树同用「每次选最小」的贪心思路但目标不同；是 Floyd 的单源版本。
- **出处**：逊哥 P16, P17

### Floyd（弗洛伊德）算法
- **要点**：求任意两点之间的最短路径。用二维的 `distance` 矩阵和 `path` 矩阵：`distance` 初值即邻接矩阵本身，`path` 初值填终点下标（表示无中转）。三层循环枚举起点、中转点、终点，若 `D[i][j] > D[i][k]+D[k][j]`，说明经中转点 k 更短，就更新 `distance` 并把 `path[i][j]` 改为中转点 k；算法结束后可得到所有顶点两两之间的最短距离与路径。与 Dijkstra 的区别是「一次求任意两点」还是「一次求单源到所有点」。
- **关键概念**：`distance 二维数组`、`path 二维数组`、`中转点`、`三层循环`
- **出处**：逊哥 P17

### 无穷大的表示与整型溢出
- **要点**：带权图中「无边」用无穷表示，可写 `0x7FFFFFFF`（`int` 能表示的最大值）。但 `int` 最大值再参与加法会溢出——加 1 后变成该类型的最小值，因为整型用补码表示，正数加到头就「绕回」负数那边；因此若代码中要让 `max` 参与加法运算，应换用一个足够大但不会溢出的值。`int` 占 4 字节即 32 位，含 1 位符号位，故范围为 $-2\^\{31\}$ 到 $2\^\{31\}-1$。
- **关键概念**：`0x7FFFFFFF`、`补码`、`符号位`
- **出处**：逊哥 P15, P17

### AOV 网与拓扑排序（含代码实现）
- **要点**：用顶点表示活动、弧表示活动之间优先关系的有向图称为 AOV 网。拓扑排序即求「谁先做、谁后做」的可行顺序：不断找出入度为 0 的顶点入栈，出栈时输出该顶点，并把与它相邻的顶点入度减 1，减到 0 的再入栈，重复至栈空；入度为 0 表示该活动不依赖任何其它活动。实现要用邻接表，而邻接表由邻接矩阵转换而来：顶点节点含入度、顶点数据、指向第一条边的指针，边节点含邻接顶点下标、指向下一条边的指针；遍历矩阵，凡 `arc[i][j]` 表示有边（无权图为 1；带权图需同时满足不等于 0 且小于 `max`）就新建边节点用头插法挂到顶点 i 的链表上，同时把顶点 j 的入度加 1。
- **关键概念**：`AOV 网`、`入度`、`vexnode`、`edgenode`、`头插法`
- **相互关系**：入度为 0 的顶点可能同时有多个，故拓扑序列不唯一；代码按 0 到 n 的顺序扫描会得到一个确定的序列。
- **出处**：逊哥 P17, P18

### AOE 网、ETV/LTV 与关键路径
- **要点**：用顶点表示事件、有向边表示活动、边权表示活动持续时间的有向图称为 AOE 网。求各顶点的最早发生时间 ETV：按拓扑序从前往后推，若有多条路径到达该顶点，取各路径之和的最大值（必须等所有前驱都完成）。求最晚发生时间 LTV：从汇点（其 ETV 即总工期）从后往前推，取各路径相减结果的最小值，超过它就会拖慢总工期。ETV 与 LTV 相等的顶点连起来就是关键路径，其上的活动必须按时完成。算 LTV 时可在拓扑排序出栈过程中把元素依次压入第二个栈，再出栈得到逆序。
- **关键概念**：`AOE 网`、`ETV`、`LTV`、`关键路径`、`汇点`
- **相互关系**：与 AOV 网/拓扑排序相对——AOV 只管先后，AOE 还要管时间。
- **出处**：逊哥 P18


## 三十六、数据结构：查找

### 查找的基本概念与 ASL
- **要点**：存放待查数据元素的集合称为查找表；能唯一标识数据元素的属性值称为关键字，如学号、ISBN。衡量查找算法优劣的指标是平均查找长度 ASL，即查找一个元素所需比较关键字的平均次数，分查找成功与查找失败两种。对查找概率均等的顺序表，成功时 $ASL=\sum p_i c_i=\frac{n+1}{2}$，失败时为 n。
- **关键概念**：`查找表`、`关键字`、`ASL`
- **相互关系**：ASL 依赖具体数据结构，换成二叉树后需重新计算。
- **出处**：逊哥 P19

### 顺序查找
- **要点**：从表的一端开始逐个与关键字比较，相等就返回其下标，扫完仍未命中则查找失败。由于数组下标可能为 0，失败时要返回一个数组中不可能出现的下标（如 −1），不能用 0 表示失败。传数组时实际传的是数组首地址，还需另传数组长度与待查关键字。效率较低（成功 ASL 约 $\frac{n+1}{2}$），是折半查找的对照。
- **关键概念**：`顺序查找`、`返回值 −1`、`平均查找长度`
- **出处**：逊哥 P19

### 折半查找（二分查找）
- **要点**：前提是查找表必须有序。用 `low`、`high` 表示当前查找区间的首尾下标，`mid=(low+high)/2` 并向下取整（不四舍五入），比较关键字与 `a[mid]`：相等即成功返回 `mid`；关键字更大说明目标在右半区，令 `low=mid+1`；更小则令 `high=mid-1`。循环条件为 `low<=high`，区间缩到无效即失败。它比顺序查找快，但要求有序且插入删除麻烦，这正是二叉排序树出现的动因。
- **关键概念**：`low`、`high`、`mid`、`向下取整`、`有序表`
- **出处**：逊哥 P19

### 折半查找判定树与时间复杂度
- **要点**：按折半查找「先取中间、再向左或右半边」的顺序可生成一棵二叉树，称折半查找判定树；它本身是一棵二叉排序树，故折半查找与二叉排序树查找思路相似但并非完全一致。判断给定判定树与给定有序表是否一一对应，只需对判定树做中序遍历，若结果与有序表完全一致则二者匹配。查找某元素的比较次数等于该元素在判定树中所处的层数，故判定树高度即最多比较次数；N 个节点的判定树层数用完全二叉树深度公式 $\lfloor \log_2 N \rfloor + 1$ 估算，故折半查找时间复杂度为 $O(\log_2 N)$。
- **关键概念**：`判定树`、`中序遍历`、`$O(\log_2 N)$`
- **出处**：逊哥 P20

### 二叉排序树（BST）
- **要点**：也叫二叉搜索树、二叉查找树。满足：任一节点左子树上所有节点的值都小于它，右子树上所有节点的值都大于它，且左右子树本身也都是二叉排序树，故中序遍历序列递增有序。构造它的目的不是排序，而是提高查找、插入、删除关键字的速度；构建时逐个插入——第一个元素作根，之后每个元素与根比较，小则往左、大则往右，递归找到空位插入。
- **关键概念**：`BST`、`有序性`、`左小右大`、`中序遍历递增`
- **相互关系**：是折半查找「要求有序」与「动态插入删除」两个需求的折中结构，也是查找与排序的前置知识。
- **出处**：逊哥 P19；张无忌 P24

### BST 的查找与插入
- **要点**：查找从根节点开始，把关键字与当前节点比较：相等即命中；比当前节点小就往左子树走，大就往右子树走，走到空表示查找失败。用递归实现，递归时把当前节点的父节点一并传入；失败时返回最后访问的节点（即插入位置的父亲），成功则返回该节点本身。插入先调用查找，若关键字已存在则插入失败（不允许重复值）；查找失败时返回的最后一个节点就是新节点的父节点，把新值与父节点比较，小则挂为左孩子、大则挂为右孩子。若原树为空，新节点直接成为根，因此反复调用插入即可从空树构造出一棵二叉排序树。
- **关键概念**：`递归`、`父节点`、`插入位置`、`重复值`
- **相互关系**：完全复用查找函数，是「查找失败点即插入点」的典型用法。
- **出处**：逊哥 P19

### BST 的删除
- **要点**：分三种情况。①被删节点是叶子：直接删除，不影响结构。②被删节点只有一个孩子：子承父业，用唯一的孩子顶替其位置。③被删节点有两个孩子：用左子树中最大的节点（左子树最右节点）或右子树中最小的节点（右子树最左节点）替代它，再删掉那个替代节点——选这两个值是因为它们与被删节点的值最接近，替换后仍满足排序特性。代码中先用临时指针保存被删节点、用另一指针一路向右找替代节点并记录其父节点，替换数据后释放替代节点，并处理替代节点可能带左孩子的情形。
- **关键概念**：`子承父业`、`前驱/后继`、`左子树最右节点`
- **相互关系**：前两种情况可合并处理；第三种情况本质仍是递归查找定位要删节点。
- **出处**：逊哥 P19

### 二叉排序树的形态与查找效率
- **要点**：同一组数据若插入顺序不同，生成的二叉排序树形态不同。按升序插入得到向右的斜树，按降序插入得到向左的斜树，斜树上的查找效率与顺序查找基本相同。时间复杂度按最坏情况衡量，二叉排序树最坏为 $O(N)$，而不是折半查找的 $O(\log_2 N)$；不能因为二叉排序树与判定树外形相似就认为二者复杂度相同，这是引出平衡二叉树的直接原因。
- **关键概念**：`插入顺序`、`斜树`、`$O(N)$`
- **出处**：逊哥 P20

### 平均查找长度 ASL 的计算
- **要点**：等概率下查找成功的平均查找长度 = 「每层节点数乘以该层层数之和」除以节点总数。
- **关键概念**：`平均查找长度`、`ASL`、`层数`
- **相互关系**：与二叉排序树常合并出题。
- **出处**：张无忌 P24

### 平衡二叉树的定义与平衡因子
- **要点**：平衡二叉树又称 AVL 树。它首先必须是二叉排序树，其次任意节点左子树与右子树高度之差的绝对值不超过 1。平衡因子等于左子树高度减右子树高度，故该条件等价于每个节点平衡因子只能取 −1、0、1。易错点：只满足高度差条件、却违反左小右大的大小关系时，不是平衡二叉树。
- **关键概念**：`AVL 树`、`平衡因子`
- **出处**：逊哥 P20

### 平衡调整：最小不平衡子树、四种类型与通用原则
- **要点**：插入新节点后从插入点向上回溯，遇到的第一个失衡节点即最小不平衡子树；平衡调整只针对它进行，旋转轴取最小不平衡子树的下一个节点。四种类型：LL 型（插入在左子树的左子树）向右旋转；RR 型（插入在右子树的右子树）向左旋转；LR 型（插入在左子树的右子树）先左旋再右旋；RL 型（插入在右子树的左子树）先右旋再左旋。不必死记四种类型——只要调整后仍是二叉排序树，且每个节点平衡因子绝对值不超过 1，任何调整方式都正确。
- **关键概念**：`最小不平衡子树`、`LL`、`RR`、`LR`、`RL`、`左旋`、`右旋`
- **相互关系**：LR、RL 可视为 LL、RR 的组合。
- **出处**：逊哥 P20

### 平衡二叉树相关题型
- **要点**：判定类题目问哪个二叉排序树满足平衡二叉树定义，套路是先确认二叉排序树、再逐节点算平衡因子看绝对值是否都不超过 1。节点数类题目问高度为 h、所有非叶子节点平衡因子均为 1 的树有多少节点，套路是画出 h=1、2、3 的形态，归纳出 $T_h = T\_\{h-1\} + T\_\{h-2\} + 1$（加 1 为根节点）后递推。易错点是判定时漏掉「必须先是二叉排序树」这一前提。
- **关键概念**：`平衡因子`、`递推`
- **出处**：逊哥 P20

### 散列表的核心思想、散列函数与冲突
- **要点**：散列表（哈希表）底层用数组存储数据，核心是用一个函数直接算出数据应存的位置，不必逐个比较就能定位，理想情况下查询效率接近 $O(1)$。这个函数即散列函数（哈希函数），把关键字映射为散列表中的地址，插入与查找都靠它；散列函数不固定，由设计者规定。两个不同关键字经散列函数计算后得到同一个地址，称为散列冲突（哈希冲突）。与顺序查找、折半查找、平衡二叉树相比，突破了「必须比较」的限制。
- **关键概念**：`散列表`、`散列函数`、`冲突`
- **出处**：逊哥 P22

### 散列函数的构造方法
- **要点**：常用三种。除留余数法：关键字对 p 取模，p 宜取不接近 2 的幂的素数；数字分析法：统计各数位数字的分布，抽取分布最离散的若干位拼成地址；平方取中法：先对关键字平方，再取中间若干位作地址，以削弱原始数字的集中性。目标都是让关键字分布更均匀、降低冲突概率。
- **关键概念**：`除留余数法`、`数字分析法`、`平方取中法`
- **出处**：逊哥 P22

### 开放地址法
- **要点**：当地址已被占用，就按某种探测方式寻找下一个空位。线性探测法增量为 1、2、3…；二次探测法增量为 $\pm i^2$（1、−1、4、−4…），前后双向探测；伪随机探测法用随机数作增量。探测位置为 $(H(k)+d_i) \bmod m$，m 为散列表长度。线性探测容易造成元素堆积（聚焦），降低效率。
- **关键概念**：`开放地址法`、`线性探测`、`二次探测`、`伪随机探测`
- **出处**：逊哥 P22, P25

### 再散列法与链地址法
- **要点**：再散列法预先准备多个散列函数，冲突时依次换用下一个重新计算地址。链地址法把散列到同一地址的所有关键字用一条链表串起来，散列表元素指向链表头，查找时沿链表依次比较；其图示思路与图的邻接表类似。
- **关键概念**：`再散列法`、`链地址法`、`链表`
- **出处**：逊哥 P22

### 散列表的查找流程
- **要点**：先由散列函数计算地址；访问该地址，关键字相同则查找成功，位置为空则查找失败，是其它关键字则说明发生冲突，按对应冲突处理方法继续探测下一个地址，直到找到目标或遇到空位置。查找流程与插入流程基本一致。
- **关键概念**：`散列地址`、`探测`
- **出处**：逊哥 P22

### 影响散列表查找性能的因素
- **要点**：一是散列函数是否均匀，二是处理冲突的方法，三是装填因子。装填因子等于已插入元素个数除以散列表长度，该值越大说明冲突可能性越大，查找性能越差。堆积现象影响的是平均查找长度，不影响存储效率、散列函数与装填因子。
- **关键概念**：`装填因子`、`平均查找长度`
- **出处**：逊哥 P22

### 平均查找长度的优化与存储结构
- **要点**：在顺序表上做顺序查找时，把查找概率大的元素排在前面可使平均查找长度（ASL）最小，即按概率降序排列；若改用链式存储，可用二叉搜索树组织数据（如按关键字字母序建树），并按「查找概率大的结点靠近根」的原则调整，使 ASL 进一步减小。ASL 由各元素「查找次数 × 查找概率」求和得到。与「折半查找的 ASL 固定」形成对照——折半查找的判定树唯一，无法通过重排元素降低 ASL。
- **关键概念**：`平均查找长度 ASL`、`二叉搜索树`、`查找概率`
- **出处**：逊哥 P28

### 求未出现的最小正整数：空间换时间
- **要点**：题目只要求时间上尽可能高效时，可用空间换时间：额外开辟一个标记数组并全部置零，遍历原数组，对每个大于零的元素以其值作为下标把标记数组对应位置置一；随后从下标 1 开始扫描标记数组，第一个仍为零的下标即为未出现的最小正整数。时间复杂度 $O(n)$，空间复杂度 $O(n)$。实现时须注意下标越界——原题隐含「元素值不超过 N」的前提，不满足时需改用偏移（以值减一作下标）或按最大值扩容。
- **关键概念**：`空间换时间`、`标记数组`、`散列思想`
- **相互关系**：与链表章节中「用数组标记法删除重复节点」的思路一致。
- **出处**：逊哥 P28

### 序列合法性题型
- **要点**：问某序列能否构成二叉排序树的一条查找路径、能否由某输入序列生成给定二叉排序树、能否构成折半查找的比较序列。统一套路是按二叉排序树规则（左小右大）把序列依次「顺下来」或逐个插入，与题给树形或规则比对，违反者即为答案；折半查找的比较序列可用判定树（等价于二叉排序树）来判定。
- **关键概念**：`查找路径`、`插入序列`、`比较序列`
- **出处**：逊哥 P20

### 散列表与堆的计算题型
- **要点**：散列表类先按散列函数与冲突处理规则把关键字逐个落位，再统计每个关键字（查找成功）或每个可能的散列地址（查找失败）的比较次数求平均，务必看清问的是成功还是失败。堆类从最后一个非叶子节点开始逐个向下调整，每次先比较兄弟取较大（小）者、再与父节点比较，每层都计入比较次数；插入类题目必须「依次插入并随时调整」。
- **关键概念**：`平均查找长度`、`装填因子`、`向下调整`
- **出处**：逊哥 P20, P22, P24


## 三十七、数据结构：内部排序

### 排序与排序稳定性
- **要点**：排序是把一组数据元素按某种规则重新排列成有序序列的过程。除算法的基本思想与实现外，还要关注时间复杂度、空间复杂度和稳定性三个指标。若排序前后相同元素的相对先后顺序保持不变，则该算法稳定。
- **关键概念**：`排序`、`稳定性`
- **出处**：逊哥 P23

### 内部排序与外部排序
- **要点**：在内存层面上完成的排序称内部排序，冒泡、插入、归并、快速等算法都假设数据能全部装入内存；当数据量达到 TB、PB、ZB 级、内存无法容纳时，需在磁盘层面排序，称外部排序。外部排序的基本思想是：把大文件切分成能装入内存的若干小块，每块在内存中完成内部排序，再把这些有序小块归并为一个整体有序的文件。
- **关键概念**：`内部排序`、`外部排序`、`归并`
- **出处**：逊哥 P26, P27

### 「一趟排序」的定义与快排、归并的「一趟」
- **要点**：对尚未确定最终位置的所有元素进行一遍处理，称为一趟排序；它描述的是逻辑上的一轮结果，而不是代码中一次递归或一次循环的执行。归并排序的一趟指两两合并成新的有序段的那一层，而非递归到底的过程；快速排序第一趟确定 1 个枢轴的最终位置，第二趟再确定左右子区间各 1 个（累计 3 个），以此类推。
- **关键概念**：`一趟（轮）`、`最终位置`、`二路归并`、`枢轴`
- **出处**：逊哥 P26

### 每趟都能确定元素最终位置的排序
- **要点**：简单选择排序、快速排序、堆排序每一趟都至少能确定一个元素的最终位置；希尔排序按增量分组，只能保证组内有序，无法确定任何元素的最终位置；二路归并排序只有全部趟数走完才能确定每个数的位置。
- **关键概念**：`简单选择排序`、`快速排序`、`堆排序`、`希尔排序`
- **出处**：逊哥 P26

### 冒泡排序
- **要点**：核心思想是相邻两元素两两比较，不满足顺序就交换；每趟让一个元素落到最终位置，从头遍历未排序部分，把未排序部分的最大值顶到末尾，N 个元素需 N-1 趟，第 i 趟内部比较 N-1-i 对。最坏 $O(N^2)$，最好 $O(N)$（数据已有序），空间 $O(1)$，稳定，适合数据量小且对稳定性有要求的场景。优化手段是加 `flag` 标记本趟是否发生交换，未发生即可提前结束。
- **关键概念**：`冒泡排序`、`相邻比较`、`趟数`、`flag`
- **出处**：逊哥 P23；鹏哥 P112

### 插入排序
- **要点**：默认第 0 个元素已排序，之后依次取出每个元素暂存到 `key`，在已排序部分从后向前比较，比 `key` 大的元素依次后移，最后把 `key` 填入空出的位置。最坏 $O(N^2)$，最好 $O(N)$，空间 $O(1)$，稳定，适合数据量小或部分有序的场景。
- **关键概念**：`插入排序`、`key`、`后移`
- **出处**：逊哥 P23

### 折半插入排序
- **要点**：在插入排序基础上用折半查找确定插入位置（`data[mid] > key` 时 `high = mid - 1`，否则 `low = mid + 1`），查找结束后从 `low` 起把已排序元素整体后移再插入 `key`。最好 $O(N\log N)$，最坏 $O(N^2)$，空间 $O(1)$，稳定。与直接插入排序相比，两者最终插入位置、总趟数、移动次数、辅助空间（均为 $O(1)$）都相同，唯一区别是比较次数——折半插入用折半查找定位，比较次数更少。
- **关键概念**：`折半插入排序`、`mid`、`比较次数`
- **出处**：逊哥 P23, P26

### 简单选择排序
- **要点**：每趟在未排序部分找出最小元素的下标 `min`，与未排序部分的第一个位置交换。时间复杂度 $O(N^2)$，空间 $O(1)$，不稳定，适合小规模数据。易错点：`min` 保存的是下标而不是数值。
- **关键概念**：`简单选择排序`、`min`
- **出处**：逊哥 P23

### 大部分元素有序时直接插入优于简单选择
- **要点**：初始序列接近有序时，直接插入排序每次只需与已排好序的末元素比较一次，比较次数约为 n−1；简单选择排序的比较次数固定，与初始状态无关。两者辅助空间均为 $O(1)$，移动次数差别不大。这是「移动次数与初始次序无关」的反面例证——比较次数与初始次序的关系因算法而异。
- **关键概念**：`直接插入排序`、`简单选择排序`、`比较次数`
- **出处**：逊哥 P26

### 希尔排序
- **要点**：按步长分组做插入排序，步长逐步折半减小，最后一步步长必须为 1；每轮要保证距离为步长的每一组元素内部有序，因此比较与交换是跳跃式的。初始步长常见取数组长度除以 2。时间复杂度 $O(N\^\{1+k\})$（$0&lt;k&lt;1$），优于 $O(N^2)$；空间 $O(1)$；不稳定；适合中等规模数据。可理解为按不同步长重复执行的插入排序，组内用的仍是插入排序。
- **关键概念**：`希尔排序`、`步长（增量）`、`分组插入排序`
- **出处**：逊哥 P25, P26

### 归并排序
- **要点**：典型分治思想。先把数组不断对半拆分，直到每个子数组只剩一个元素；再两两合并，合并时把两个有序子数组各自的最小元素依次比较、取较小者放入临时数组 `temp`，最后把 `temp` 拷回原数组。二路归并时间复杂度 $O(N\log N)$，空间复杂度 $O(N)$，稳定，适合大数据量且要求稳定性的场景。易错点：空间复杂度不是 $O(1)$；选归并而非插入的理由是运行效率更高，故「代码更短」「占用空间更少」都不成立。
- **关键概念**：`归并排序`、`分治`、`二路归并`、`temp`
- **出处**：逊哥 P25, P26

### 快速排序
- **要点**：取序列中一个元素作基准 `pivot`（代码中常取 `low` 位置），先从右向左找第一个小于基准的数填入 `low`，再从左向右找第一个大于基准的数填入 `high`，交替进行，直到 `low` 与 `high` 相遇，把 `pivot` 放到该位置并返回该下标；再对左右子序列递归。最坏 $O(N^2)$（数组本身有序或逆序且固定取首元素作基准时），空间 $O(\log N)$（递归栈），不稳定，适合时间效率优先且不关注稳定性的场合。它需要 `low` 与 `high` 双向移动，链式存储（默认指单链表）无法向前回溯，因此适合顺序存储（数组）。效率高低取决于基准元素选得够不够「中间」；与归并排序同为分治，但归并是分完再合，快排是边分边排。
- **关键概念**：`快速排序`、`pivot`、`分治`、`顺序存储`
- **出处**：逊哥 P25, P26

### 堆的定义与顺序存储
- **要点**：堆是满足特定性质的完全二叉树。大根堆（最大堆）中每个节点都大于等于其子节点；小根堆（最小堆）中每个节点都小于等于其子节点；兄弟节点之间的大小不作要求，只看父子关系。堆用数组顺序存储，为让下标与节点编号一致，常把下标 0 空出作占位符、数据从下标 1 开始；编号为 i 的节点左孩子编号为 `2i`、右孩子为 `2i+1`；长度为 n 的堆中最后一个非叶子节点编号为 $\lfloor n/2 \rfloor$。此处的「堆」是数据结构，与内存中的堆区无关。
- **关键概念**：`大根堆`、`小根堆`、`2i`、`2i+1`、`占位符`
- **出处**：逊哥 P24

### 堆的插入、删除与建堆
- **要点**：插入时先把新元素放到完全二叉树末尾以保持形态，再向上与父节点比较、必要时交换，直到满足堆序。删除时先用最后一个节点替换被删节点并删掉末尾节点，再自上而下逐层调整。建堆从最后一个非叶子节点（编号 $\lfloor n/2\rfloor$）开始向前遍历，逐个向下调整：先在左右孩子中取较大者，再与父节点比较，父节点小则交换并继续向下检查。插入与删除都以「先保证完全二叉树形态，再调整数值」为前提。
- **关键概念**：`向上调整`、`向下调整`、`建堆`
- **出处**：逊哥 P24

### 堆排序
- **要点**：先按待排序数组建成大根堆；再反复把堆顶（当前最大值）与未排序部分的最后一个元素交换，缩小堆的范围并重新调整为大根堆。每轮确定一个最大值放到数组末尾，最终得到升序序列；结果与冒泡排序类似（都把最大值顶到末尾），但过程不同。
- **关键概念**：`堆排序`、`堆顶`、`swap`
- **出处**：逊哥 P24

### 基数排序与代码结构
- **要点**：分配式排序，全程不比较关键字大小。按位从低位到高位（个位、十位、百位…）逐轮把整数分配到 0~9 十个桶中，每轮分配后按桶序、桶内先入先出重新合并回数组，最高位处理完后序列即有序。时间复杂度 $O(d \times N)$（d 为最大数的位数），空间复杂度 $O(N+r)$（r 为基数，十进制为 10），稳定，适合整数、定长字符串且数据量大、位数不高的场景。分配时必须按原始数据的先后顺序逐个放入对应桶中，不能任意挑选；收集时按「从上到下、从左到右」依次取出——顺序一旦打乱结果就不正确，这正是它依赖稳定性的体现。实现由三个函数构成：排序主过程、取指定数位上的数字、求最大位数（决定需要几趟分配收集）；「桶」用二维数组表示。移动次数只取决于最大位数与元素个数，与初始排列次序无关。
- **关键概念**：`基数排序`、`桶`、`分配与收集`、`getDigit`、`getMaxDigit`
- **出处**：逊哥 P25, P26

### 选择排序算法时需考虑的因素
- **要点**：除时间复杂度、空间复杂度外，还需考虑数据规模（决定用内部排序还是外部排序）、数据的存储方式（顺序或链式）、算法的稳定性、数据的初始状态。
- **关键概念**：`时空效率`、`数据规模`、`存储方式`、`稳定性`
- **出处**：逊哥 P26

### 题型一：由某趟排序结果反推排序算法
- **要点**：逐一比对各算法的「趟」特征：冒泡排序每趟把最大（或最小）元素顶到某一端，故观察序列两端是否为当前最大/最小值（从前向后扫描把最大值顶到右端，从后向前则把最小值顶到左端）；插入排序第 k 趟后前 k+1 个元素有序；选择排序的中间结果特征与冒泡相似，同样看两端；二路归并排序按 $\lceil n/2 \rceil$ 逐层划分，检查每一段是否有序且长度符合划分。
- **关键概念**：`冒泡排序`、`插入排序`、`选择排序`、`二路归并排序`
- **出处**：逊哥 P26

### 题型二：判断序列是否为快速排序第二趟结果
- **要点**：在序列中找出所有满足「左侧元素都比它小、右侧元素都比它大」的数（枢轴候选）。第二趟结束后至少应有两个这样的数；若只能找到两个，则其中必有一个位于序列端点（即当前最大值或最小值），否则不能是快速排序第二趟的结果；能找到三个及以上则一定成立。
- **关键概念**：`枢轴`、`最终位置`、`第二趟`
- **出处**：逊哥 P26

### 题型三：由排序结果反推希尔排序的增量
- **要点**：把选项中的步长依次代入，按下标分组（步长为 d 时分组下标为 0,d,2d,…；1,1+d,…），逐组检查组内是否已按升序排列；用第一趟结果筛出候选步长，再用第二趟结果区分剩余选项。
- **关键概念**：`增量（步长）`、`组内有序`
- **出处**：逊哥 P26

### 题型四：基数排序的分配与收集序列推算
- **要点**：按最低位优先（LSD）逐趟处理：先个位、再十位、再百位；分配时按原顺序放入对应桶，收集时按桶号从小到大、桶内从上到下取出。问某元素的前驱/后继时，可直接定位其所在桶，再看同桶内相邻位置。
- **关键概念**：`LSD（最低位优先）`、`分配`、`收集`、`桶`
- **出处**：逊哥 P26

### 题型五：算法性质与概念判断
- **要点**：常见考点包括——快速排序的递归次数与初始数据的排列次序有关、与左右分区处理的先后顺序无关（先处理长分区或短分区都不改变总递归次数）；快速排序适合顺序存储；每趟至少确定一个元素最终位置的是简单选择、快速、堆排序；折半插入与直接插入只差比较次数；移动次数与初始次序无关的是基数排序；选择排序算法还要考虑数据规模、存储方式、稳定性、初始状态。
- **关键概念**：`递归次数`、`分区`、`稳定性`、`时空效率`
- **出处**：逊哥 P26


## 三十八、数据结构：外部排序

### 外部排序的由来与归并段、缓冲区
- **要点**：内部排序算法都假设数据可全部装入内存，当数据量远超内存容量时不再适用，外部排序借助磁盘等外部存储设备。切分后每一块有序数据称一个归并段（记作 R1、R2…）。归并段存放在磁盘上，需分批加载到内存；内存被划分为两个输入缓冲区和一个输出缓冲区，缓冲区容量决定了一次 I/O 的单位。
- **关键概念**：`归并段`、`输入缓冲区`、`输出缓冲区`
- **出处**：逊哥 P27

### 外部排序的时间构成
- **要点**：外部排序时间 = 内部排序时间 + 归并排序时间，磁盘与内存的读写时间隐含在这两部分之中。三个计量单位：TS 为对「内存容量大小的块」做一次内部排序的时间，TIO 为一次读/写「一个缓冲区容量」关键字的时间，TM 为将一个关键字从输入缓冲区归并到输出缓冲区的时间。内部排序部分的时间 = 读入的全部 TIO + 各块的 TS + 写出的全部 TIO。外存访问速度远低于内存，I/O 时间占整个外部排序过程的绝大部分，因此减少 I/O 是提高效率的核心。
- **关键概念**：`TS`、`TIO`、`TM`、`磁盘 I/O`
- **出处**：逊哥 P27

### 提高效率的途径与归并趟数公式
- **要点**：归并趟数 $S=\lceil \log_K M \rceil$，其中 K 为归并路数、M 为初始归并段个数。要减少趟数，只需增大 K 或减小 M，两条途径分别对应多路平衡归并（败者树）与置换选择排序两个专题。K 越大所需内存空间越大、缓冲区个数越多；减少 M 则使每个归并段更长，从而在同样内存限制下减少归并段数量。
- **关键概念**：`归并路数 K`、`初始归并段数 M`、`归并趟数 S`
- **出处**：逊哥 P27

### 多路平衡归并与败者树
- **要点**：K 路归并时每输出一个关键字需在 K 个候选值中比较 $K-1$ 次，N 个关键字一趟约需 $N(K-1)$ 次比较，K 增大反而拖慢效率。败者树用「比较中较大者（败者）向上走」的完全二叉树记录比较结果，使每次只需沿一条路径重新比较，把从输入缓冲区归并到输出缓冲区的比较次数降到与 $\log_2 K$ 相关，从而在多路归并与比较次数之间取得平衡。
- **关键概念**：`多路平衡归并`、`败者树`、`比较次数`
- **相互关系**：是「增大 K」途径的必要配套；与哈夫曼树同属树结构在排序中的应用。
- **出处**：逊哥 P27

### 置换选择排序
- **要点**：用于减少初始归并段个数。设内存工作区容量为 w，先把输入文件前 w 个记录读入工作区，取出其中最小值输出（形成归并段一），并记该值为 min；随后每读入一个新记录，就在工作区中选「比 min 大的最小者」输出，并把 min 更新为它；当工作区中不存在比 min 更大的记录时本归并段结束，再从头生成下一个归并段。由此可生成长度远超内存容量的有序归并段，从而减少归并段总数；产出的归并段长度不等，由此引出「最佳归并树」问题。
- **关键概念**：`置换选择排序`、`内存工作区`、`min`、`初始归并段`
- **出处**：逊哥 P27

### 最佳归并树与虚段
- **要点**：当各归并段长度不等时，归并方案对应一棵树，其带权路径长度（WPL）的两倍即为总读写次数，故按哈夫曼树思路每次合并最短的两段可使 I/O 次数最少，这棵树称最佳归并树。K 路归并需构造 K 叉哈夫曼树，若结点数不足以构成完全 K 叉树，需补入权值为 0 的虚段。由树的度数性质可推出度为 K 的结点数 $N_K=\dfrac{N_0-1}{K-1}$，其中 $N_0$ = 初始归并段个数 + 虚段个数；只要该式能整除，即可确定虚段个数。把若干个长度不等的有序表两两合并为一个升序表时，同样按「每次选取当前最短的两个表合并」的策略（即画哈夫曼树），可使最坏情况下的比较总次数最小；两表合并的最坏比较次数为两表长度之和减 1（最好情况为较短表的长度）。
- **关键概念**：`最佳归并树`、`哈夫曼树`、`WPL`、`虚段`、`$N_K=(N_0-1)/(K-1)$`
- **相互关系**：公式来源于「树的度数之和 + 1 = 结点总数」这一树的基本性质；内部多表合并是该思想在内部排序场景下的迁移。
- **出处**：逊哥 P27, P28


## 三十九、真题题型与解题套路

### 程序阅读题的通用解法与易错点
- **要点**：第一步划清语句范围（给 if/else、循环加花括号），第二步数清各结构内的语句条数，再按执行顺序逐步推进；凡含 `++`/`--` 或多变量的题目一律用「变量观察法」——把各变量列在纸旁、每执行一句就更新其值。常考易错点：输入格式串必须原样匹配；`double` 输入用 `%lf`，格式中不能写 `%.几f`；`%u` 按无符号读取补码、与 `%d` 不同；`--x` 先减后用、`x--` 先用后减；逗号表达式取最后一个表达式的值。
- **关键概念**：`变量观察法`、`范围划分`、`%u`
- **出处**：强哥 P89, P116, P130

### 循环加判断的统计类编程题
- **要点**：需依次比较两个数组对应位置元素并分别统计各类结果时，用一层 `for` 循环配 `if / else if / else` 分支，分支内对计数器 `++`。计数器必须先初始化为 0；循环变量从 0 取到数组长度减一，结束后再统一输出。
- **关键概念**：`for`、`if-else if-else`、`计数器`
- **出处**：一灯 P5

### 结构体输入输出类编程题
- **要点**：先声明结构体类型（含姓名、编号、年份、薪资等成员）再定义变量；用 `.` 访问成员，`scanf` 输入整型、浮点型成员要加 `&`。字符数组成员本身是地址，`scanf` 时不能再加 `&`；`float` 用 `%f`。
- **关键概念**：`struct`、`成员变量`、`.`、`scanf`
- **出处**：一灯 P5

### 数据结构选择与判断题常见易错点
- **要点**：① 逻辑结构与存储结构不要混：逻辑结构分线性（表、栈、队列、串）与非线性（树、图、集合），物理结构只有顺序存储与链式存储两种（顺序存储要求存储单元连续，链式可连续也可不连续）。② 读题看清是「树」还是「二叉树」。③ 「算法可以没有输出」错、「可以没有输入」对。④ 顺序表的位序与下标相差 1。⑤ 循环队列必须牺牲一个存储单元。
- **关键概念**：`逻辑结构`、`物理结构`、`位序`、`牺牲一个存储单元`
- **出处**：一灯 P2, P3；强哥·数据结构 P3
