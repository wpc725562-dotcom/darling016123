## 补充（鹏哥）· 关键字、标识符、语句与注释

### 注释
- **要点**：注释是给人看的，编译器会把注释替换成一个空格，故对代码无影响。`/* ... */` 可注释多行但不支持嵌套（遇第一个 `*/` 结束）；`//` 是 C99 引入的形式，注释到行尾。
- **关键概念**：`注释`、`/* */`、`//`、`嵌套`
- **出处**：[鹏哥 P14](https://www.bilibili.com/video/BV17a7K64ELH?p=14)


## 补充（鹏哥）· 数据类型

### size_t 与 %zu
- **要点**：`sizeof` 的返回值是无符号整数，但标准未规定具体是哪种无符号类型而留给系统决定，导致打印格式不统一；因此 C 语言为它专门定义了类型别名 `size_t`，打印时用 `%zu`。
- **关键概念**：`size_t`、`%zu`
- **出处**：[鹏哥 P16](https://www.bilibili.com/video/BV17a7K64ELH?p=16)、[P18](https://www.bilibili.com/video/BV17a7K64ELH?p=18)


## 补充（鹏哥）· 函数

### 多文件组织与静态库
- **要点**：声明放 `.h`、实现放 `.c`，两者构成一个模块（如 `add.h` + `add.c`），使用时 `#include` 对应头文件即可；好处是模块化、便于协作复用、隐藏代码。`#include` 本质是把头文件内容拷贝到当前位置，解决「声明」问题。
- **关键概念**：`.h`、`.c`、`模块`、`#include`

## 补充（鹏哥）· 调试

### 什么是 bug 与调试
- **要点**：bug 本意是昆虫，现指程序中隐藏的、未被发现的缺陷；源自 1947 年飞蛾飞入大型计算机继电器触点导致停机的事件。调试解决的是运行时错误，即编译链接都通过但结果不对的问题。
- **关键概念**：`bug`、`debug`、`定位问题`、`断点`
- **出处**：[鹏哥 P67](https://www.bilibili.com/video/BV17a7K64ELH?p=67)、[P73](https://www.bilibili.com/video/BV17a7K64ELH?p=73)

### debug 与 release 版本
- **要点**：debug 是调试版本，含调试信息且不做优化，可执行文件较大并附带 `.pdb` 文件；release 是发布版本，做了各种优化，代码大小与运行速度最优、文件明显更小，且无法逐行调试。程序员开发调试用 debug；测试人员站在用户角度测试软件，因此测 release。
- **关键概念**：`debug`、`release`、`.pdb`、`优化`
- **出处**：[鹏哥 P67](https://www.bilibili.com/video/BV17a7K64ELH?p=67)

### VS 调试快捷键与条件断点
- **要点**：F9 在任意代码行设置/取消断点；F5 启动调试，跳到「执行逻辑上」的下一个断点处，而非物理位置上的下一个（断点在循环体内会反复停在该处）；F10 逐过程，遇函数调用把整个调用一次执行完；F11 逐语句，遇函数会进入内部；Ctrl+F5 开始执行不调试，遇断点也不停。
- **关键概念**：`F9`、`F5`、`F10`、`F11`
- **出处**：[鹏哥 P68](https://www.bilibili.com/video/BV17a7K64ELH?p=68)

### 监视窗口与自动窗口
- **要点**：须在开始调试后调试窗口里才会出现监视窗口；可直接写变量名、数组元素或合法表达式，单步执行时同步观察取值变化，监视窗口可多开。
- **关键概念**：`监视`、`自动窗口`、`局部变量窗口`
- **出处**：[鹏哥 P69](https://www.bilibili.com/video/BV17a7K64ELH?p=69)

### 内存窗口、反汇编与寄存器窗口
- **要点**：调试窗口可打开内存窗口，地址栏可输入变量名或取地址表达式；左侧是地址，中间是以 16 进制展示的内存数据（内存中实际是二进制，用 16 进制只是便于展示），右侧是可读性参考信息。一行显示的字节数可调，观察 `int` 常用四列、`double` 可用八列；数组名表示起始地址，可直接输入数组名观察。
- **关键概念**：`内存窗口`、`16 进制`、`反汇编`、`寄存器窗口`
- **出处**：[鹏哥 P69](https://www.bilibili.com/video/BV17a7K64ELH?p=69)

### 调试举例：求阶乘之和的 bug 及算法改进
- **要点**：题型是求 1! 到 n! 的累加和。思路是先具备「求 n 的阶乘」的能力（循环产生 1 到 n 的数字累乘），外层循环让 n 从 1 到目标值、把每次的阶乘累加。易错点：存放阶乘的变量定义在循环外且未在每轮开始时重置为 1，导致在上一轮结果上继续累乘、结果偏大；排查方法是把关键变量加入监视、单步观察每轮取值。算法改进：双层循环每轮都从 1 重新累乘、存在大量重复计算，改用单层循环让每一轮的阶乘结果直接乘以上一轮的结果。
- **关键概念**：`阶乘`、`累加`、`变量重置`、`算法效率`
- **出处**：[鹏哥 P70](https://www.bilibili.com/video/BV17a7K64ELH?p=70)

### 调试举例：数组越界导致的死循环
- **要点**：循环条件写成小于等于大于数组最大下标时会越界访问。在特定环境下（如 32 位架构 debug 模式），局部变量在栈上先使用高地址再使用低地址，数组随下标增长地址由低到高，于是越界写会一路写到另一个局部变量上把它改成 0，使循环变量永远达不到终止条件，程序既不死也不崩溃而是死循环。该现象依赖编译器和环境，根本原因仍是代码越界。
- **关键概念**：`数组越界`、`栈区`、`死循环`
- **出处**：[鹏哥 P71](https://www.bilibili.com/video/BV17a7K64ELH?p=71)


## 补充（鹏哥）· 数据在内存中的存储

### 进制与进制转换
- **要点**：二、八、十、十六进制只是同一数值的不同书写形式，区别在基数与每位权重（第 i 位权重为基数的 i 次方）。二进制转十进制是各位数字乘权重求和；十进制转二进制用「除 2 取余、余数自下而上读」。
- **关键概念**：`二进制`、`八进制`、`十六进制`、`权重`
- **出处**：[鹏哥 P80](https://www.bilibili.com/video/BV17a7K64ELH?p=80)

## 补充（H学长）· 三、计算机系统组成与硬件

### 显示器与显示指标
- **要点**：按原理分 CRT、LED、LCD。指标：点距（越小越清晰）、分辨率（水平×垂直像素，越高越精细）、刷新频率（越高越不闪烁，人眼无跳动感需 24Hz 以上）、色深（n 位表示 2^n 色，≥24 位称真彩色）。显示系统由显示器与显示适配器（显卡）组成，接口 AGP、PCI-E，分 A 卡（AMD）与 N 卡（NVIDIA）。
- **关键概念**：`点距`、`分辨率`、`刷新频率`、`真彩色`、`显示适配器`
- **出处**：[H学长 P16](https://www.bilibili.com/video/BV1Ay4y137RA?p=16)

### 打印机
- **要点**：按工作方式分针式、喷墨、激光打印机；按工作原理分击打式（针式，噪声大）与非击打式。性能最优是激光打印机，使用最多是喷墨打印机。
- **关键概念**：`针式打印机`、`喷墨打印机`、`激光打印机`、`击打式`
- **出处**：[H学长 P16](https://www.bilibili.com/video/BV1Ay4y137RA?p=16)

### 程序、软件与软件系统分类
- **要点**：有序的指令序列称程序；软件＝程序＋说明文档＋数据，是为更好调度硬件而设计的程序、文档和数据的总和。按是否安装分绿色软件（免安装）与非绿色软件（需安装、改注册表），按是否开源分开源软件（安卓）与非开源软件（iOS）。按功能分系统软件（操作系统、数据库管理系统、语言处理程序、系统服务程序、故障诊断程序，一般由厂家提供）与应用软件（面向不同用户的不同问题，受系统软件限制）。

## 补充（H学长）· 七、Windows 7 操作系统

### 启动与启动方式
- **要点**：开机顺序为"先接通外设，再接通主机"，由 BIOS 检测硬件，再进行系统引导，最后把控制权交给操作系统。三种启动：冷启动（关机状态下开机）、热启动（开机状态下按 Ctrl+Alt+Delete 重启）、复位启动（按主机 Reset 键，用于电脑卡死时）。

- **要点**：按 Alt+对应字母可打开菜单，打开后按命令后的字母即可执行。命令约定：灰色表示当前不可用；命令后有三个小点（省略号）表示会弹出对话框；右侧有黑色箭头表示有子菜单；小圆点表示单选命令；方框表示复选命令（可全选或全不选），复选不等于多选。

## 补充（H学长）· 十一、计算机网络

### URL 统一资源定位符
- **要点**：URL 即统一资源定位符（又称统一资源定位器、网页地址），是互联网上资源的地址，用来指明文件的位置以及浏览器应如何处理它，互联网上每个文件都有 URL。URL 由三部分组成：协议、服务器域名、路径和文件名。路径中过去可以用 .. 上翻目录，会暴露网站的目录结构，属于安全隐患，现在服务器一般已做限制，只能在当前目录内活动。
- **关键概念**：`URL`、`协议`、`域名`、`路径`、`文件名`
- **相互关系**：与域名配合理解——域名定位主机，URL 进一步定位主机上的具体文件。
- **出处**：[H学长 P58](https://www.bilibili.com/video/BV1Ay4y137RA?p=58)

### 电子邮件地址格式
- **要点**：电子邮件即 E-mail，地址格式为 用户名@邮件服务器域名。两个考点：一是用户名在前、邮件服务器域名在后，判断时先识别出域名（带 com、cn、edu 等后缀的那一部分）；二是中间的 @ 符号不能写成 #、-、! 等。常见邮箱有 163、新浪、QQ、139、Outlook 等。
- **关键概念**：`电子邮件`、`用户名`、`邮件服务器域名`、`@`
- **相互关系**：判断域名的前后位置需要用到"域名的层次结构与顶级域名"。
- **出处**：[H学长 P59](https://www.bilibili.com/video/BV1Ay4y137RA?p=59)

### 文件传输 FTP
- **要点**：FTP 用于在互联网上提供文件存储与传输，传输的文件类型不限，可传文档、音频、视频等。它支持匿名 FTP：没有用户名和密码也能登录，用户名固定为 anonymous，密码一般填邮箱地址或任意内容，服务器对该密码不作强制要求。
- **关键概念**：`FTP`、`匿名FTP`、`anonymous`
- **相互关系**：与其他应用服务的区别在于它解决的是两台主机之间的文件传输问题。
- **出处**：[H学长 P59](https://www.bilibili.com/video/BV1Ay4y137RA?p=59)


## 补充（升本啦）· 四、数据类型与数据表示

### 标识符命名规则
- **要点**：只能由字母、数字、下划线组成，且必须以字母或下划线开头；区分大小写；不能与关键字及系统预定义标识符重名。`8x`、`x-y` 非法，`x8`、`_x` 合法。
- **关键概念**：`标识符`、`关键字`、`保留字`
- **相互关系**：**易错点**——`switch` 加下划线后是合法标识符，但 `switch` 本身是关键字；此题几乎每年都考。
- **出处**：[升本啦 P5](https://www.bilibili.com/video/BV1KU4y167ds?p=5)


## 补充（升本啦）· 五、运算符与表达式

### 算术运算符、自增自减与赋值
- **要点**：`+` `-` `*` `/` `%`。两个整型数相除结果仍为整型，只保留整数部分；有一个浮点型就保留小数。`i++` 先使用 i 的值再加 1，`++i` 先加 1 再使用。`=` 把右边的值写入左边变量，复合赋值 `a+=3` 等价于 `a=a+3`。位运算左移一位相当于乘以 2，右移一位相当于除以 2。
- **关键概念**：`整除`、`取余`、`++`、`--`、`复合赋值`、`位运算`
- **相互关系**：**高频考点**——`5/3` 为 1，`5.1/3` 才保留小数，`5%3` 为 2。**易错点**——`j+=i` 合法，`j+1=k` 不合法：赋值运算符从右向左结合，不能把值赋给表达式，应写 `k=j+1`。
- **出处**：[升本啦 P5](https://www.bilibili.com/video/BV1KU4y167ds?p=5)、[P8](https://www.bilibili.com/video/BV1KU4y167ds?p=8)


## 补充（升本啦）· 七、选择结构

### if 语句的三种形式
- **要点**：一是 `if(表达式) 语句`；二是 `if(表达式) 语句1 else 语句2`；三是嵌套形式。语句组只有一个语句时可不加大括号，多个语句必须用花括号组成代码块，否则只有第一个语句属于该分支。
- **关键概念**：`if`、`else`、`代码块`
- **相互关系**：**易错点**——漏加大括号会导致交换语句中只有第一条受 `if` 控制，其余无条件执行。
- **出处**：[升本啦 P6](https://www.bilibili.com/video/BV1KU4y167ds?p=6)、[P7](https://www.bilibili.com/video/BV1KU4y167ds?p=7)


## 补充（升本啦）· 八、循环结构

### break 与 continue
- **要点**：`break` 结束整个循环，转到循环之后的下一条语句；`continue` 只结束本次循环，跳过循环体中其后的语句，直接进入下一次循环的判断。
- **关键概念**：`break`、`continue`、`本次循环`、`整个循环`

### 时间复杂度例题的画面板书解法
- **要点**：老师现场板书两道循环题，逐个数执行次数，而不是凭感觉估。① `int i; while (i*i*i <= n) i++;` —— 循环变量以立方增长，`i` 要增到约 `n` 的三分之一次方才退出，循环次数约为 $n\^\{1/3\}$，故时间复杂度为 $O(n\^\{1/3\})$。② `for (i=1; i<n; i++) for (j=1; j<=2*i; j++) m++;` —— 内层执行 `2*i` 次，外层 `i` 从 1 到 `n-1`，总次数为 $2(1+2+\cdots+(n-1)) = n(n-1)$，用等差数列求和后取阶得 $O(n^2)$。老师同时提醒：这类题「大部分都是凭感觉」做，正确做法是按「数项数」（例如 `i` 从 1 到 `n` 就是 `n` 项）老老实实算。
- **关键概念**：`$O(n^{1/3})$`、`等差数列求和`、`数项数`

### 中缀表达式与后缀表达式
- **要点**：运算符写在两个操作数中间的是中缀表达式（给人看），写在操作数之后的是后缀表达式（给计算机看）；中缀转后缀的过程已提前把优先级「敲定」，故后缀求值不再需要考虑优先级。表达式以字符串存储，末尾用 `\0` 标记结束。

### 后缀表达式的求值规则与实现
- **要点**：从左到右扫描：遇操作数压栈；遇运算符连续弹出两个操作数，先弹出的放入 op2、后弹出的放入 op1，执行 `op1 OP op2`，结果压回栈；扫描到 `\0` 结束，栈顶即结果。代码用顺序结构（动态分配）的栈，以枚举 `ContentType` 标记字符类型（`EOS` 即 `\0`），主循环前调 `getToken` 取字符并前移下标，循环条件 `token != EOS`；字符型数字入栈前用 `字符 - '0'` 转数值。
- **关键概念**：`op1`、`op2`、`ContentType`、`getToken`
- **出处**：[逊哥 P8](https://www.bilibili.com/video/BV1tNpbekEht?p=8)

### 中缀表达式转后缀表达式
- **要点**：扫描中缀串：遇操作数直接输出；遇运算符，优先级大于栈顶则压栈，否则先弹出栈顶输出再压入；遇左括号直接入栈（栈外优先级最高、入栈后最低）；遇右括号持续出栈输出直到左括号，左括号出栈但不输出；扫到 `\0` 后把栈中剩余运算符依次出栈输出（不含哨兵）。实现上栈底预放优先级最低的哨兵（`EOS`），因枚举值从 0 起可直接作下标，据此定义 `inStack`、`outStack` 两个优先级数组，用 `inStack[栈顶] >= outStack[当前]` 判断是否先出栈。

## 补充（张无忌）· 九、树与二叉树

### 二叉树遍历
- **要点**：三种遍历差别只在根节点的访问时机：`先序`根左右、`中序`左根右、`后序`左右根（未指明一律先左后右）；递归实现差别只是打印语句位置——最前为先序、中间为中序、最后为后序，终止条件是节点为空。
- **关键概念**：`先序遍历`、`中序遍历`、`后序遍历`、`递归`
- **相互关系**：中序遍历二叉排序树可得递增序列。
- **出处**：[张无忌 P23](https://www.bilibili.com/video/BV1z84y1z7Vp?p=23)、[P24](https://www.bilibili.com/video/BV1z84y1z7Vp?p=24)
