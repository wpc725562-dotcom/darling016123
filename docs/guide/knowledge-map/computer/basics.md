## 一、计算机基础知识

### 第一台电子计算机 ENIAC
- **要点**：1946-02-14 生于美国宾夕法尼亚大学，用于军事科学计算；用电子管与继电器、十进制，未采用存储程序原理。
- **关键概念**：`ENIAC`、`电子管`、`十进制`
- **相互关系**：未采用存储程序原理是因时间差；「所有计算机都用二进制」为错。
- **出处**：H学长 P2

### 理论发展的代表人物
- **要点**：帕斯卡造机械计算器、巴贝奇造分析机、布尔创逻辑代数、图灵提图灵机与图灵测试、冯·诺依曼提存储程序控制原理并划五大部件、香农提信息论。
- **关键概念**：`图灵机`、`存储程序控制原理`、`信息论`
- **相互关系**：图灵是计算机科学之父与人工智能之父（图灵奖为最高奖）；冯·诺依曼是计算机之父。
- **出处**：H学长 P2

### 数据与信息的关系
- **要点**：数据是客观事物属性的记录、信息的表现形式，信息是数据的解释；数据加工成信息，信息须数字化为数据才能存储传输。
- **关键概念**：`数据`、`信息`、`载体`
- **出处**：H学长 P2, P6

### 计算机发展四阶段与未来方向
- **要点**：一代电子管与低级语言；二代晶体管、磁心存储并提操作系统与高级语言；三代中小规模集成电路、出现操作系统；四代大规模超大规模集成电路、出现微处理器。未来朝多极化、多媒体化、网络化、微型化、巨型化、智能化。
- **关键概念**：`晶体管`、`集成电路`、`微处理器`
- **相互关系**：微型化与巨型化相反但不冲突；第二代采用磁性介质为对。
- **出处**：H学长 P2

### 微处理器、字长与中国超算
- **要点**：微机 CPU 即微处理器，按字长分 4/8/16/32/64 位，字长是一次处理的二进制位数；微机性能主要取决于 CPU。中国 1956 年起步、1958 年出第一台电子计算机；超算五大系列为银河（1983，第一台）、曙光、神威、升腾、天河。
- **关键概念**：`字长`、`微处理器`、`银河`、`天河`
- **出处**：H学长 P2, P3

### 计算机的分类方式与特点
- **要点**：按结构原理分数字机（处理离散信号）与模拟机（处理连续电压）；按用途分通用与专用；按规模分巨型、大中型、小型、微型；按字长分 8/16/32/64 位机；按工作模式分工作站与服务器。特点为存储能力强、精度高、有逻辑判断、速度快、自动化高、可靠性高、通用性强。
- **关键概念**：`数字计算机`、`模拟计算机`、`服务器`、`逻辑判断`
- **相互关系**：巨型机体现综合国力、微型机体现应用水平；多选常混入「精度低」「存储弱」「速度慢」等反义干扰项。
- **出处**：H学长 P3

### 应用领域与计算机辅助系统
- **要点**：科学计算用于高能物理与航天，过程检测用于工业，信息管理（数据处理）用于企业管理与报表且应用最广，12306 与 OA 属此类。CAD 设计、CAM 制造、CAT 测试、CAE 工程、CAA 分析、CAI 教学、CBE 教育；AI 如深蓝、阿尔法狗。
- **关键概念**：`科学计算`、`信息管理`、`CAD`、`CAI`、`CBE`
- **相互关系**：CAI（教学）与 CBE（教育）最易混。
- **出处**：H学长 P3

### 计算机系统的组成与五大部件
- **要点**：硬件由控制器、运算器、存储器、输入设备、输出设备五大部分组成；控制器是全机指挥中心，运算器负责算术与逻辑运算（ALU），二者合称 CPU。数据流为「输入→存储器→运算器→存储器→输出」，控制流由控制器发出；只有硬件无软件称裸机。
- **关键概念**：`五大部件`、`CPU`、`ALU`、`裸机`
- **相互关系**：CPU＋内存合称主机，外存＋IO 设备合称外设。
- **出处**：H学长 P13–P16

### 冯·诺依曼型计算机与存储程序控制原理
- **要点**：特点为五大部件、用二进制、采用存储程序控制原理；该原理含存储程序与程序控制，即事先编好程序存入存储器，运行时自动调入内存由 CPU 执行，关键在「自动」。用二进制是因物理易实现、运算规则简单、稳定性高、适合逻辑运算。
- **关键概念**：`冯·诺依曼型计算机`、`存储程序`、`程序控制`
- **相互关系**：CPU 只与内存交换数据，数据先由外存调入内存。
- **出处**：H学长 P14；升本啦 P2

### 指令、指令系统与指令执行过程
- **要点**：指令是能被计算机直接识别执行的二进制代码，分操作码与地址码；一台计算机能执行的全部指令称指令系统。执行循环为取指令→分析指令→执行指令→指令计数器加一。
- **关键概念**：`指令`、`操作码`、`地址码`、`指令系统`
- **出处**：H学长 P14

### 存储器：内存与外存
- **要点**：存储器分主存（内存）与辅存（外存）。CPU 只能直接访问内存，外存数据须先调入内存；内存是输入、处理、输出的中转站，容量与速度影响整机速度。
- **关键概念**：`主存`、`内存`、`外存`
- **出处**：H学长 P15, P16

### RAM、ROM 与 Cache
- **要点**：RAM 可读可写、断电丢失，通常说的内存即 RAM；ROM 由厂家写入、只读、断电不丢，BIOS 在 ROM 中。RAM 按是否刷新分 SRAM（静态、快）与 DRAM（动态、需刷新）。Cache 位于 CPU 与内存间，缓解速度差。
- **关键概念**：`RAM`、`ROM`、`SRAM`、`DRAM`、`Cache`
- **相互关系**：易混——CMOS 属 RAM、BIOS 属 ROM；速度 CPU > Cache > 内存 > 外存。
- **出处**：H学长 P15, P16

### 内存编址与容量计算
- **要点**：内存按字节编址，每单元 1 字节，单元编号称地址。三步：由起止编号求个数（最大−最小+1）→进制转换得字节数→按 2^10 换算单位。
- **关键概念**：`存储单元`、`按字节编址`
- **相互关系**：16 进制减法借位易错，结果常以多个 f 结尾。
- **出处**：H学长 P15

### 外存储器与磁盘格式化
- **要点**：软盘有 5.25 英寸（1.2MB）与 3.5 英寸（1.44MB），写保护口打开时只读不写、可防病毒。CD-ROM 只读、CD-R 一次性写入、CD-RW 可重复擦写；1 倍速为 150KB/s；U 盘属即插即用设备但仍需驱动。硬盘读写以扇区为基本单位、每扇区 512 字节；同心圆称磁道，0 磁道在最外圈。新磁盘必须先格式化，分低级（出厂进行）与高级格式化。
- **关键概念**：`扇区`、`磁道`、`格式化`、`写保护口`
- **相互关系**：易错——磁道是同心圆而非螺旋线，扇区是弧形区域而非扇形。
- **出处**：H学长 P16

### 输入输出设备、显示器与打印机
- **要点**：输入设备如键盘、鼠标、扫描仪、手写板、条形码阅读器、A/D 转换器、麦克风、摄像头；输出设备如显示器、打印机、绘图仪、音响、D/A 转换器；磁盘驱动器既可输入又可输出。显示器分 CRT、LED、LCD，指标有点距（越小越清晰）、分辨率、刷新频率（无跳动感需 24Hz 以上）、色深（n 位表示 2^n 色，≥24 位称真彩色）。打印机分针式、喷墨、激光，按原理分击打式与非击打式；性能最优是激光、使用最多是喷墨。
- **关键概念**：`A/D 转换器`、`点距`、`真彩色`、`击打式`
- **出处**：H学长 P16

### 总线及其分类与寻址能力
- **要点**：数据总线（DB）传数据、双向；地址总线（AB）传地址、单向；控制总线（CB）传控制信息、双向。地址总线有 n 根时最大寻址空间为 2^n 字节，也可由最大内存容量反推根数。
- **关键概念**：`总线`、`数据总线`、`地址总线`、`控制总线`
- **相互关系**：数据总线位数与字长有关，地址总线决定寻址能力。
- **出处**：H学长 P17

### IO 接口与常见接口
- **要点**：接口位于总线与外设之间，作用是信号转换与缓冲，绝大部分可编程，分串行与并行接口。常见：鼠标键盘 PS/2，打印机 LPT，显示器 VGA（只传视频）、HDMI（同时传音频和视频），硬盘 IDE/SCSI/SATA，网线 RJ-45，USB（3.0 快于 2.0）。
- **关键概念**：`串行接口`、`并行接口`、`VGA`、`HDMI`、`RJ-45`
- **相互关系**：考点——能同时传输音频和视频的接口是 HDMI。
- **出处**：H学长 P17, P18

### 计算机主要性能指标
- **要点**：字长、主频（单位赫兹）、运算速度（MIPS 百万条/秒、BIPS 十亿条/秒）、存储容量、存取周期、外设扩展能力与兼容性、RASIS 特征（可靠性由 MTBF 体现）、软件配置。
- **关键概念**：`字长`、`主频`、`MIPS`、`存取周期`、`MTBF`
- **出处**：H学长 P19

### 软件系统与程序设计语言
- **要点**：软件＝程序＋说明文档＋数据。按功能分系统软件（操作系统、DBMS、语言处理程序、系统服务程序、故障诊断程序）与应用软件。机器语言是二进制指令、唯一能被直接识别执行；汇编语言用助记符代替操作码；高级语言易读可移植但执行速度低，机器语言与汇编语言合称低级语言。
- **关键概念**：`系统软件`、`应用软件`、`机器语言`、`汇编语言`、`高级语言`
- **相互关系**：高级语言分面向过程（C、Fortran）与面向对象（C++、Java、VB、VF）；DBMS 常见 Access、SQL Server、MySQL。
- **出处**：H学长 P14, P20

### 汇编、编译与解释
- **要点**：非机器语言编写的程序称源程序，须翻译为机器语言才能执行。汇编语言经汇编工具转目标程序再链接称汇编；高级语言经编译工具转目标程序再链接称编译；解释是一边翻译一边执行、不产生目标程序。反汇编是把目标代码还原为汇编代码。
- **关键概念**：`源程序`、`目标程序`、`编译`、`解释`、`反汇编`
- **相互关系**：编译与解释的区别是常考填空与选择题。
- **出处**：H学长 P20

## 二、数制与编码

### 数制的基本概念与标识
- **要点**：数码是可用数字符号，基数是数码个数，位权指位置不同价值不同（r 进制为 r 的 n 次方）；后缀 b、o/q、d 或省略、h。满 r 进一、借一当 r。
- **关键概念**：`数码`、`基数`、`位权`、`满r进一`
- **相互关系**：十六进用 A~F 表 10~15 免歧义；位权从个位起、指数从 0 起。
- **出处**：H学长 P6

### 进制转换的方法与常考题型
- **要点**：十进制转 r 进制：整数除 r 取余后反向取、小数乘 r 取整正向取；r 进制转十进制用乘权求和。二与十进制可用 8421 拼凑法；二转八三位一组、二转十六四位一组，分组以小数点为界、整数不够前补零、小数不够后补零。小数点左移 n 位变为 r 的 −n 次方倍、右移 n 位变为 r 的 n 次方倍；比大小转同一进制后先比高位；求未知进制可各数转十进制列方程解 r。
- **关键概念**：`除r取余`、`乘r取整`、`乘权求和`、`8421 拼凑法`、`未知进制`
- **相互关系**：整数最前的零与小数最后的零可省，中间与小数点前的零不能省；八进制中没有数字 8。
- **出处**：H学长 P6–P8；一灯 P4

### 二进制的算术运算与逻辑运算
- **要点**：加法 1+1=10；减法借一当二；乘法 1×1=1、其余为 0；除法只保留 0÷1 与 1÷1。逻辑运算：与（逻辑乘）见零为零、全一为一；或（逻辑加）见一为一、全零为零；非为取反；异或为相同为零、不同为一；运算须位数对齐，结果前面的零不能省。
- **关键概念**：`借一当二`、`与`、`或`、`非`、`异或`
- **相互关系**：看到「逻辑乘」应理解为逻辑与，不能用普通乘法算。
- **出处**：H学长 P9

### 位、字节、字与存储单位换算
- **要点**：位（bit，小 b）是最小数据单位；字节（Byte，大 B）是存储基本单位，1 字节＝8 位。字是 CPU 一次能同时处理的二进制数据，字长即其位数。单位由小到大 B、KB、MB、GB、TB，相邻进率 2 的 10 次方；大化小乘、小化大除 2 的 10 次方。
- **关键概念**：`位`、`字节`、`1B=8b`、`字长`
- **相互关系**：判断题注意「一次性/同时」与「二进制」；32 位机指一次处理 32 位二进制数。
- **出处**：H学长 P10

### 原码、反码、补码与表示范围
- **要点**：最高位为符号位，0 正 1 负；正数三码相同，负数反码为符号位不变、其余取反，补码为反码加一。计算机内部用补码（只有加法器，补码把减法变加法），补码如圆环会产生溢出（127 加 1 得 −128）。n 位无符号数范围 0 至 2^n−1，有符号数范围 −2^(n−1) 至 2^(n−1)−1。
- **关键概念**：`符号位`、`原码`、`反码`、`补码`、`溢出`
- **相互关系**：求码先转二进制、补足 n−1 位、再添符号位；未给位数默认 8 位。
- **出处**：H学长 P11；鹏哥 P81, P82

### 定点数与浮点数
- **要点**：带小数的数分定点小数与浮点小数；浮点数类似科学计数法，由符号、阶码、尾数组成，尾数决定精度、阶码决定范围。
- **关键概念**：`定点小数`、`浮点数`、`阶码`、`尾数`
- **出处**：H学长 P11

### BCD 码与 ASCII 码
- **要点**：最常用 8421BCD 码，用四位二进制表示一位十进制，另有 5211 码、余三码。标准 ASCII 码由 7 位构成但占一字节、最高位为 0，共 128 个字符；0~31 为控制字符，32 是空格，48 是数字 0，65 是大写 A，97 是小写 a；扩展 ASCII 码范围 128~255。
- **关键概念**：`8421BCD`、`余三码`、`标准 ASCII 码`、`控制字符`
- **相互关系**：数值 ASCII 码小于大写字母、大写小于小写，大小写相差 32。
- **出处**：H学长 P12

### 汉字编码与混合字节判别
- **要点**：GB2312-80 收 6763 字（一级 3755 按拼音、二级 3008 按部首），后有 GBK、GB18030、BIG5 与 Unicode。区位码用四位十进制表 94×94 表中位置；国标码＝区位码＋2020H，机内码＝国标码＋8080H。汉字四码：输入码（外码，不唯一）、交换码（国标码）、机内码（唯一）、输出码（字形码）。字形码分矢量字模（放大不失真）与点阵字模，n×n 点阵占 n×n÷8 字节，16×16 占 32 字节。混合字节流中汉字占两字节且机内码每字节≥A1H。
- **关键概念**：`GB2312-80`、`区位码`、`国标码`、`机内码`、`字形码`、`A1H`
- **出处**：H学长 P12

### 实数的标准化指数形式
- **要点**：标准化指数形式要求小数点前是 0、小数点后第一位非 0，据此把小数点移动位数写成 10 的幂次，C 语言中用 e 表示指数。
- **关键概念**：`标准化指数形式`、`阶码`、`e`
- **出处**：一灯 P4

## 三、操作系统与 Windows 7

### 操作系统的概念、作用、功能与进程
- **要点**：OS 是管理计算机硬件资源与软件资源的程序，是用户与计算机之间的接口；作用为人机接口、软件平台、管理资源，是对硬件系统（裸机）的第一次扩充。功能：处理器管理（进程管理）、存储管理、设备管理、作业管理、文件管理。进程可理解为程序的一次活动或一个任务，三种状态为运行态、就绪态（排队等待 CPU）、阻塞态（等待某事件）。
- **关键概念**：`操作系统`、`人机接口`、`进程`、`就绪态`、`阻塞态`
- **相互关系**：判断题常考「操作系统只能管理软件资源」为错。
- **出处**：H学长 P20, P24

### 操作系统的分类与特性
- **要点**：按结构与功能分批处理、分时（时间片轮转）、实时、网络、分布式；按用户数、界面、任务数划分，Windows 7 是多用户、图形界面、多任务操作系统。特性为并发性、共享性（互斥共享与同时共享）、不确定性、虚拟性（典型应用是虚拟内存）。
- **关键概念**：`批处理`、`分时`、`时间片轮转`、`虚拟内存`
- **相互关系**：互斥共享是「我用时你不能用」，同时共享是「可同时调用」。
- **出处**：H学长 P24

### Windows 7 版本与虚拟机
- **要点**：Windows 7 是微软 2009 年发布的个人操作系统，有初级版、家庭版、家庭高级版、专业版、企业版、旗舰版六版本，旗舰版包含其余版本全部功能（Windows 10 无旗舰版）。可用虚拟机（软件模拟出的系统）在实机上练习。
- **关键概念**：`Windows 7`、`旗舰版`、`虚拟机`
- **出处**：H学长 P22–P25

### 启动、退出与待机休眠睡眠
- **要点**：开机顺序为「先接通外设，再接通主机」，由 BIOS 检测硬件后系统引导。三种启动：冷启动、热启动（Ctrl+Alt+Delete）、复位启动（Reset 键）。退出包括关机、休眠、锁定（Win+L）、重新启动、注销、切换用户；注销是退出当前用户，切换用户是保留当前用户再启动另一用户。
- **关键概念**：`冷启动`、`热启动`、`复位启动`、`注销`、`休眠`
- **相互关系**：待机数据存内存、恢复快但断电丢失；休眠数据存硬盘、断电不丢但恢复慢；睡眠结合两者优点。
- **出处**：H学长 P25

### 桌面、图标与快捷方式
- **要点**：桌面本质是系统文件夹，默认位于 C:\用户\&lt;用户名>\Desktop。新装 Windows 7 只有「回收站」一个系统图标，可通过右键快捷菜单→个性化→更改桌面图标增删。快捷方式是指向程序或文件的指针，左下角有向上的箭头、扩展名 .lnk；删除快捷方式不影响原文件。
- **关键概念**：`桌面`、`系统图标`、`快捷方式`、`.lnk`
- **相互关系**：易错——判断题「快捷方式是右下角带箭头的图标」为错。
- **出处**：H学长 P26

### 桌面个性化、任务栏与任务管理器
- **要点**：个性化可设主题、桌面背景、窗口颜色、声音、屏幕保护程序；主题不只换背景，还含窗口颜色与声音。任务栏默认在底部并锁定，可移到上/下/左/右并可自动隐藏，由开始菜单、程序区、语言栏、通知区、系统时间、显示桌面组成。显示桌面（Win+D）是把程序最小化而非关闭；任务管理器可查看并结束进程。
- **关键概念**：`个性化`、`屏幕保护程序`、`任务栏`、`显示桌面`、`任务管理器`
- **相互关系**：易错——最小化不等于关闭程序，程序只是转入后台运行。
- **出处**：H学长 P26

### 窗口的组成与操作、窗口与对话框的区别
- **要点**：窗口元素包括控制菜单图标、标题栏、最小化/最大化/还原/关闭按钮、菜单栏、工具栏、工作区域、滚动条、状态栏。关闭窗口六法：关闭按钮、文件菜单的关闭/退出、双击控制菜单图标、控制菜单中的关闭、Alt+F4、右键任务栏选关闭。切换窗口用 Alt+Tab 或 Win+Tab（3D）。截整屏按 PrintScreen，截当前窗口按 Alt+PrintScreen。窗口有最小化/最大化按钮、有菜单栏、可改变大小；对话框只有一个关闭按钮、没有菜单栏（只有选项卡）、不能改变大小；二者都可移动位置。
- **关键概念**：`控制菜单`、`Alt+Tab`、`Alt+F4`、`PrintScreen`、`对话框`
- **出处**：H学长 P27

### 资源管理器、地址栏、路径与搜索
- **要点**：资源管理器可用 Win+E 打开，开始菜单可用 Win 键或 Ctrl+Esc 打开。路径分绝对路径（以盘符开头）与相对路径。搜索栏可用 Win+F 或 F3 调出，可按名称、种类、修改日期、类型、大小搜索；通配符 * 代表零到多个字符，? 代表任意一个字符。菜单命令约定：灰色表示不可用；三个小点表示会弹出对话框；黑色箭头表示有子菜单；小圆点表示单选；方框表示复选。导航窗格是树状结构；状态栏默认隐藏，可在「查看」菜单中设置。
- **关键概念**：`资源管理器`、`Win+E`、`绝对路径`、`通配符`、`导航窗格`
- **出处**：H学长 P28, P29

### 开始菜单常用程序、记事本写字板与命令提示符
- **要点**：IE 常用按钮为后退、前进、地址栏、刷新、停止、搜索，在 Internet 选项中可设主页并删除历史记录。WMP 可播放音视频；录音机默认存 wma；便签存放在硬盘；画图默认存 png，填充颜色时封闭图形只在内部填充、非封闭图形会溢出；计算器分标准型、科学型、程序员、统计信息四种，程序员型可做进制转换。记事本无格式、称纯文本文件、扩展名 .txt、不能插入图片；写字板带格式、扩展名 .rtf、可以插入图片。ping 检测连通性、ipconfig 查看本机 IP 与默认网关、cls 清屏、exit 退出；Win+R 输入 cmd 开命令提示符、regedit 开注册表。磁盘清理清除垃圾数据，磁盘碎片整理把碎片整理为连续空间以提高访问速度。
- **关键概念**：`WMP`、`纯文本文件`、`ping`、`cmd`、`磁盘碎片整理`
- **出处**：H学长 P29

### 文件属性、命名规则与扩展名显示
- **要点**：文件属性有只读、隐藏、存档（默认）和系统属性。只读文件不能写入，保存时会另存为新文件；隐藏文件需在「文件夹选项→查看」中设为显示才能看到。文件名由主文件名和扩展名组成，最多 255 个合法字符，不区分大小写，同一文件夹下不允许重名，不能使用 \ / : * ? " &lt; > | 九个符号。
- **关键概念**：`只读`、`隐藏`、`存档`、`文件夹选项`
- **出处**：H学长 P30

### 选择文件、重命名、移动与复制
- **要点**：单击选一个，Ctrl+单击选不连续多个，Shift+单击选连续多个，编辑菜单有全选与反选。重命名可用右键→重命名、单击文件名、文件菜单→重命名或按 F2。剪切 Ctrl+X、复制 Ctrl+C、粘贴 Ctrl+V。同一分区内直接拖动为移动、不同分区直接拖动为复制；按住 Ctrl 拖动即复制、按住 Shift 拖动即移动。
- **关键概念**：`Ctrl`、`Shift`、`F2`、`Ctrl+X`、`同分区`
- **出处**：H学长 P30

### 删除、剪贴板与回收站
- **要点**：Delete、右键删除、文件菜单删除均为放入回收站，可还原；Shift+Delete 为永久删除。剪贴板位于内存，断电丢失，只保留最后一次内容。回收站位于硬盘，在其中删除或清空为永久删除；按分区各一份，默认大小为分区容量的 10%。
- **关键概念**：`Shift+Delete`、`剪贴板`、`回收站`、`10%`
- **出处**：H学长 P30

### 控制面板、区域和语言与输入法
- **要点**：控制面板可通过桌面图标、开始菜单或搜索框打开；「程序和功能」用于卸载或查看程序。区域和语言不能改日期时间本身，只能改其显示格式，并可增删输入法。Ctrl+Space 中英文切换、Ctrl+Shift 输入法切换、Shift+Space 全角/半角切换、Ctrl+. 中英文标点切换。半角下中文占两个字节、英文占一个字节，全角下中英文都占两个字节。
- **关键概念**：`控制面板`、`区域和语言`、`Ctrl+Space`、`全角`
- **出处**：H学长 P31

### 鼠标键盘设置、设备管理与用户账户
- **要点**：鼠标可切换主要和次按钮、设置双击速度（不能设单击速度）、启用单击锁定；键盘可设重复延迟与速度，分功能键区、主键盘区、控制键区、数字键区，八个基准键为左手 A S D F、右手 J K L ;。设备管理器中显示适配器即显卡、网络适配器即网卡；设备分即插即用（鼠标、键盘、U 盘）和非即插即用（如打印机）。用户账户分管理员（Administrator，默认禁用）、标准用户、来宾（Guest，只能看不能改）。常用快捷键：Ctrl+Alt+Delete 热启动、Alt+F4 关窗口、Win+D 显示桌面、Alt+Tab 切换窗口。
- **关键概念**：`双击速度`、`即插即用`、`Administrator`、`Guest`
- **出处**：H学长 P31

## 四、Word 文字处理

### Word 打开方式与文档、模板扩展名
- **要点**：Word 是文字处理软件，与 WPS 兼容。打开方式为单击任务栏或开始菜单图标、开始菜单→所有程序→Microsoft Office，或双击 .docx 文件。文档扩展名 .docx，模板扩展名 .dotx。
- **关键概念**：`.docx`、`.dotx`、`WPS`
- **出处**：H学长 P32

### Word 窗口组成与界面元素
- **要点**：控制图标单击调出控制菜单、双击关闭；标题栏显示程序或文档名称，新建时默认「文档一」；快速访问工具栏默认含保存 Ctrl+S、撤销 Ctrl+Z、恢复 Ctrl+Y，可自定义。选项卡默认有文件、开始、插入、页面布局、引用、邮件、审阅、视图，Ctrl+F1 可收起或展开功能区；导航窗格在「视图」选项卡中勾选打开，只显示标题；状态栏显示页数、字数、编辑状态，编辑状态分插入与改写，Insert 切换。
- **关键概念**：`快速访问工具栏`、`Ctrl+S`、`Ctrl+Z`、`Ctrl+Y`、`Ctrl+F1`
- **出处**：H学长 P32

### Word 五种视图与标尺
- **要点**：页面视图（默认，所见即所得）、阅读版式视图（分屏，能产生分页）、Web 版式视图（随窗口大小自动换行）、大纲视图（显示层次结构）、草稿视图（不显示分栏等效果）。标尺分水平、垂直：页面视图两者都有，阅读版式与大纲视图无标尺，Web 版式与草稿视图只有水平标尺。
- **关键概念**：`页面视图`、`所见即所得`、`大纲视图`、`草稿视图`
- **出处**：H学长 P32, P37

### Word 的保存、关闭与退出
- **要点**：保存 Ctrl+S，另存为 F12。打开是把外存数据调入内存、修改在内存进行，保存是把内存数据同步到外存。新文档保存弹出另存为对话框；另存为另开辟空间创建新文件，可设路径、文件名、类型与打开密码、修改密码。关闭仅关闭当前文档（Ctrl+F4），退出会退出软件（Alt+F4）。
- **关键概念**：`Ctrl+S`、`F12`、`Ctrl+F4`、`Alt+F4`
- **出处**：H学长 P33

### Word 最近使用文件、新建与打印
- **要点**：最近使用文件默认显示 25 个，可设为 0~50 个；新建 Ctrl+N，方式有创建空白文档、根据现有内容、根据现有模板、自定义模板。打印 Ctrl+P，可设份数、打印机、打印范围、纸张方向与页边距；自定义范围连续页用短横线、不连续页用逗号。
- **关键概念**：`最近使用文件`、`Ctrl+N`、`Ctrl+P`、`打印范围`
- **出处**：H学长 P33

### doc 与 docx、自动更正与自动恢复
- **要点**：doc 是老版本格式（97–2003），docx 是新版本格式（2007 之后）；新版本可兼容老版本（打开 doc 显示兼容模式）。自动更正会把常见错误或大小写自动替换；自动恢复按设定的时间间隔自动保存文档版本，可在「文件→信息」中还原。
- **关键概念**：`doc`、`docx`、`兼容模式`、`自动更正`、`自动恢复`
- **出处**：H学长 P33

### 剪贴板功能组
- **要点**：含剪切 Ctrl+X、复制 Ctrl+C、粘贴 Ctrl+V、格式刷 Ctrl+Shift+C。仅执行剪切相当于删除，且可用粘贴恢复。选择性粘贴可只复制内容不复制格式。格式刷只复制格式不复制内容，单击只能用一次、双击可多次使用，按 Esc 退出。
- **关键概念**：`格式刷`、`选择性粘贴`、`Ctrl+X`
- **出处**：H学长 P34

### 字体、字号与字符格式
- **要点**：中文字号数字越小字体越大（3 号大于 5 号），阿拉伯数字（磅）越小字体越小；新建空白文档默认宋体 5 号（10.5 磅）。Ctrl+B 加粗、Ctrl+I 倾斜、Ctrl+U 下划线。在「字体→高级」中设置字符间距（列间距），行间距在段落中设置。项目符号和编号以段落为单位，一个段落只能有一个项目符号。按 Enter 换行并产生新段落，按 Shift+Enter 仅换行（软回车）。
- **关键概念**：`字号`、`磅`、`宋体 5 号`、`字符间距`、`Shift+Enter`
- **出处**：H学长 P34

### 缩进、对齐与制表位
- **要点**：标尺四个缩进标记：首行缩进控制第一行、悬挂缩进控制第一行以外各行、左缩进和右缩进控制整段。对齐有左对齐 Ctrl+L、居中 Ctrl+E、右对齐 Ctrl+R、两端对齐 Ctrl+J、分散对齐 Ctrl+Shift+J，默认两端对齐。制表位默认 2 个字符，按 Tab 跳转，有左对齐、居中、右对齐、小数点对齐、竖线对齐。
- **关键概念**：`首行缩进`、`悬挂缩进`、`两端对齐`、`制表位`
- **出处**：H学长 P34

### 样式、查找替换与选择
- **要点**：样式是已设置好的格式（含字体与段落格式），可直接套用；系统自带样式只能修改不能删除。普通查找 Ctrl+F 弹出导航窗格；高级查找弹出查找替换对话框，支持通配符 ? 与 *。替换 Ctrl+H，替换为框不输入内容时相当于删除；全选 Ctrl+A。
- **关键概念**：`样式`、`Ctrl+F`、`Ctrl+H`、`通配符`
- **出处**：H学长 P34

### 分页与分页符
- **要点**：分页有自动分页和人工分页（插入分页符，快捷键 Ctrl+Enter）。人工分页符可删除，自动分页符不能删除（草稿视图中长虚线为自动分页符）。
- **关键概念**：`分页符`、`Ctrl+Enter`、`自动分页符`
- **出处**：H学长 P35

### 创建表格与表格规格
- **要点**：创建方式有拖动选择行列、插入表格对话框指定行列、绘制表格（可画斜线）、文本转换成表格、Excel 电子表格、快速表格。插入表格最大规格为 32767 行 × 63 列（Excel 为 1048576 行 × 16384 列）。插入后会多出「表格工具」，含设计选项卡（改外观）和布局选项卡（改结构）。
- **关键概念**：`插入表格`、`绘制表格`、`32767×63`、`表格工具`
- **出处**：H学长 P35

### 表格的选择、行列增删与合并拆分
- **要点**：可用「布局→选择」选择单元格、行、列或表格，也可用鼠标在行左端、列上端单击选中。删除单元格时其余单元格右移或下移补齐。合并单元格只能合并连续单元格，合并后原内容全部保留；拆分表格时选中的行成为新表首行。排序只能针对列排序，有主要、次要、第三关键字（最多三个）。重复标题行使表格跨页时每页都显示相同标题行。
- **关键概念**：`合并单元格`、`拆分表格`、`重复标题行`、`主要关键字`
- **出处**：H学长 P35

### 表格公式与表格内快捷键
- **要点**：可用公式对表格数据计算，参数单词有 above、below、left、right。选中单元格按 Delete 只删内容，按 Backspace 删整个单元格。按 Tab 向右跳并选中下一单元格内容（最后一个单元格按 Tab 在下方插入一行），Shift+Tab 向左跳。
- **关键概念**：`above`、`Tab`、`Shift+Tab`、`Backspace`
- **出处**：H学长 P35

### 插图、嵌入式与文字环绕
- **要点**：插入的图片默认是嵌入式（不能与文字重叠，会把文字挤开），插入的形状默认是浮动式（可与文字重叠）。文字环绕方式有嵌入型、四周型、紧密型、穿越型、上下型、衬于文字下方、浮于文字上方，只有上下型没有左右型。按住 Shift 拖动可插入正方形、正圆；流程图选 SmartArt。
- **关键概念**：`嵌入式`、`浮动式`、`文字环绕方式`、`SmartArt`
- **出处**：H学长 P35

### 超链接、页眉页脚与文本框
- **要点**：超链接可链接到现有文件或网页、本文档中的位置、电子邮件地址，按住 Ctrl 单击可访问；书签用于标记位置。页眉页脚作用范围为全文，基本单位是「节」（文档默认整体为一节），有首页不同、奇偶页不同两个选项；只有在页面视图中可见。文本框分横排和竖排，文本框内可插入图片、设置项目符号，但不能分栏。自动图文集把选中内容存为可复用条目，输入名称按 F3 插入。域是可变化的区域，Ctrl+F9 插入域、F9 更新域、Ctrl+Shift+F9 取消域。
- **关键概念**：`超链接`、`页眉页脚`、`节`、`文本框`、`域`、`Ctrl+F9`
- **出处**：H学长 P35

### 主题、页面设置、分隔符与分栏
- **要点**：主题设置颜色、字体和效果。页面设置含文字方向、页边距、纸张方向、纸张大小；文档默认整体为一节，要使部分页面方向不同需插入分节符。分页符只换页、文档仍是整体；分节符把文档分成多节，可对各节单独设置页面格式。分栏可设栏数、栏宽、栏间距，只在页面视图可见。
- **关键概念**：`主题`、`页边距`、`分节符`、`分栏`

### 页面布局选项卡

- **出处**：H学长 P42

### 算术、比较、文本与引用运算符
- **要点**：算术运算符有 +、-、*、/、%、^（乘方）。公式必须以等号 = 开头，否则按文本处理。比较运算符有 =、>、&lt;、>=、&lt;=、&lt;>，比较结果是逻辑值，TRUE 本质是 1、FALSE 本质是 0。连接运算符 & 连接两个值，连接中文或字母文本必须加英文双引号；易错：95&-15 结果为 95-15。引用运算符：冒号 : 是区域（连续），逗号 , 是并集（不连续），空格是交集。优先级口诀「引算文比」：引用 > 算术 > 文本 > 比较；- 作减号时低于乘方（2-3^2 为 -7），作负号时高于乘方（-2^2 为 4）。
- **关键概念**：`=`、`^`、`<>`、`&`、`冒号`、`引算文比`
- **出处**：H学长 P43, P44

### 三种单元格引用
- **要点**：相对引用无 $（如 A1），绝对引用列标和行号前都有 $（如 $A$1），混合引用只有列标或行号前有 $（如 $A1、A$1）；按 F4 可在三种引用间循环切换。$ 必须写在列标或行号前面，且列标与行号要在合法范围内，如 $ABC$123 正确、$123ABC 错误。另有三维引用（引用不同工作表的单元格）。
- **关键概念**：`相对引用`、`绝对引用`、`混合引用`、`$`、`F4`、`三维引用`
- **相互关系**：判断写法对错要结合「列标在前行号在后」。
- **出处**：H学长 P44

### 公式的复制、移动与行列变动
- **要点**：公式复制时先看源单元格到目标单元格列标变化几列、行号变化几行，公式中所有字母和数字同步增减相同量；再看 $ 锁定，有 $ 的部分不变。例：C2=A1+A2 复制到 F4（列加 3、行加 2）得 =D3+B4。公式移动时不论有无 $ 内容都不变。插入或删除行列时不看 $，只看引用位置是否在变动位置之前：在之前就变化，在之后就不变化。
- **关键概念**：`复制`、`移动`、`$`、`插入行`、`删除列`
- **相互关系**：填空题作答时最前面要加等号。
- **出处**：H学长 P44

### 错误信息
- **要点**：##### 列宽不够；#DIV/0! 除数为零；#N/A 找不到匹配值；#NAME? 无法识别的文本（如 =a+3）；#NULL! 不存在交集；#NUM! 无效数值（如对负数求平方根）；#REF! 引用的单元格无效。考试最常考 #####。
- **关键概念**：`#####`、`#DIV/0!`、`#N/A`、`#NAME?`、`#REF!`
- **出处**：H学长 P44

### 函数的格式与常用统计函数
- **要点**：函数格式为「等号 + 函数名 + 括号（参数）」，括号内没有参数时括号也不能省（如 =TODAY()）；参数可以是数据、引用的单元格或另一个函数；函数名不区分大小写。SUM 求和、AVERAGE 求平均值、MAX 求最大值、MIN 求最小值、COUNT 求数字个数。两种考法：把单元格地址写进括号时只能识别数值，不能识别文本形式的数字和逻辑值；把参数直接写进括号时三类都能识别（TRUE 按 1、FALSE 按 0）。例：A1=1、B1="2"、C1=TRUE 时 =SUM(A1:C1) 为 1，=SUM(1,"2",TRUE) 为 4。
- **关键概念**：`SUM`、`AVERAGE`、`MAX`、`COUNT`、`引用单元格`
- **相互关系**：需结合「逻辑值本质是 1 和 0」理解；SUM(A1:A5) 与 SUM(A1,A5) 含义不同。
- **出处**：H学长 P45, P46

### IF 与条件函数
- **要点**：IF(表达式, 值1, 值2) 做逻辑判断：成立返回值 1，不成立返回值 2。COUNTIF(区域, 条件) 统计满足条件的个数；SUMIF(条件区域, 条件, 求和区域) 对满足条件的单元格求和；AVERAGEIF(条件区域, 条件, 求平均值区域) 求满足条件者的平均值，条件区域与求和区域相同可省略最后一个参数。条件是表达式时要加双引号（如 ">=60"），引用单元格时不需双引号。
- **关键概念**：`IF`、`COUNTIF`、`SUMIF`、`AVERAGEIF`
- **出处**：H学长 P45, P46

### ROUND、INT 与 RANK
- **要点**：ROUND(数值, 位数) 按指定位置四舍五入：位数为正表示保留小数位，为 0 表示取整，为负表示对整数部分进位（-1 看十位、-2 看百位）。INT(数值) 向下取整，如 INT(12.9)=12、INT(-12.6)=-13。RANK(排序的数, 排序区域, 升/降序) 求排名，0 或省略为降序，1 为升序；排序区域一般要用绝对引用，否则公式向下复制时比较区域随之移动，会出现多个并列名次。
- **关键概念**：`ROUND`、`INT`、`RANK`、`绝对引用`
- **相互关系**：ROUND 常与 AVERAGE 嵌套，如 =ROUND(AVERAGE(C2:G2),1)。
- **出处**：H学长 P45, P46

### 函数的常见题型
- **要点**：填空、判断类给定几个单元格的数据类型问函数结果，核心是判断「引用单元格只能识别数值」还是「写进括号可识别文本数字和逻辑值」。综合大题一般 3~5 问：求平均分并保留小数、条件求平均、IF 判断、RANK 排名，函数名拼写不能错。
- **关键概念**：`SUM(A1:A5)`、`嵌套`
- **出处**：H学长 P46

### 排序与筛选
- **要点**：排序升序 A→Z、降序 Z→A。单列排序只按一个字段排；多列排序须设主关键字（必须设置）与次要关键字，排序依据可为数值、单元格颜色、字体颜色或图标。进入筛选模式后每个字段出现下拉图标，设过条件的字段图标变为漏斗形；同一字段最多两个条件。高级筛选须先在空白区建立条件区域，同行表示「与」、不同行表示「或」，还可把结果复制到其他位置。
- **关键概念**：`主关键字`、`次要关键字`、`Ctrl+Shift+L`、`高级筛选`、`条件区域`
- **相互关系**：Word 表格排序最多 3 个关键字且只能按列排；筛选只隐藏不满足条件的数据，并非删除。
- **出处**：H学长 P47

### 数据有效性与分类汇总
- **要点**：数据有效性限制单元格可输入内容，「序列」只能填指定值且值之间必须是英文逗号，也可限定整数或小数的范围并设出错警告。分类汇总前必须先以分类字段排序，否则同类数据不连续；取消时点「全部删除」，只删汇总效果不删数据。
- **关键概念**：`数据有效性`、`序列`、`出错警告`、`分类字段`、`全部删除`
- **出处**：H学长 P47

### 批注、视图与窗口冻结
- **要点**：Excel 批注默认不显示、不打印，单元格右上角有红三角；Word 批注默认显示且可打印。单元格左上角绿三角表示该数字被设为文本型。视图分普通（默认）、页面布局（可见标尺）、分页预览（绿线为分页符）；显示比例可用按钮、滑块或 Ctrl 加滚轮调整。冻结首行、首列使标题不随滚动消失，冻结拆分窗格从选中单元格的上方与左方同时冻结，拆分可拆成上下、左右或四个窗格。
- **关键概念**：`批注`、`红色三角`、`分页预览`、`冻结拆分窗格`
- **相互关系**：Word 拆分只能拆成上下两格；「第一行与第一列不变」应选 B2 单元格。
- **出处**：H学长 P48

## 七、多媒体技术

### 媒体的分类与多媒体的特性
- **要点**：媒体分五类：感觉媒体（作用于感官）、表示媒体（编码）、表现媒体（输入输出设备）、存储媒体（存储器）、传输媒体（传输介质）。多媒体是两种以上媒体的综合，特点为集成性、交互性、多样性、数字化、实时性。
- **关键概念**：`感觉媒体`、`表示媒体`、`表现媒体`、`存储媒体`、`传输媒体`
- **出处**：H学长 P21

### 多媒体文件格式
- **要点**：图像 BMP（位图）、GIF、JPG、PNG；音频 WAV（波形声音文件）、MIDI（乐器数字接口，存指令、容量小）、WMA、MP3；视频 AVI、MPEG、FLV（流媒体）。文件类型由扩展名区分。
- **关键概念**：`BMP`、`WAV`、`MIDI`、`AVI`、`FLV`
- **相互关系**：同条件下 WAV 容量大于 MIDI。

### 多媒体容量计算
- **要点**：图像容量=张数×分辨率×位数÷8；音频容量=采样频率×编码位数×声道数×时间÷8；视频容量=分辨率×位数×时间×帧率÷8。各项须化为基本单位（频率用 Hz、位数用比特、时间用秒），结果除以 8 得字节数再按 2^10 换算。
- **关键概念**：`分辨率`、`采样频率`、`声道数`、`帧率`
- **相互关系**：若给颜色种数而非位数，须按「n 位表示 2^n 色」反推（如 65536 色对应 16 位）。
- **出处**：H学长 P21

## 八、计算机网络

### 网络的定义、实质与功能
- **要点**：计算机网络是将地理位置不同的计算机及外部设备通过通信线路连接、在协议管理下实现资源共享与数据传输的系统；实质是计算机技术与通信技术的结合，发展分诞生、形成、互联互通、高速网络技术四阶段。最主要的功能与目的是资源共享，另有集中管理、分布式处理与负载均衡。
- **关键概念**：`计算机网络`、`资源共享`、`负载均衡`
- **出处**：H学长 P53

### 网络的分类与交换方式
- **要点**：按覆盖范围分 LAN、MAN、WAN，范围依次增大且多考局域网。交换方式中电路交换独占线路、浪费资源；报文交换与分组交换都采用存储转发，报文须收完才转发，分组把小分组逐个转发，是现在采用的方式。
- **关键概念**：`LAN`、`MAN`、`WAN`、`电路交换`、`分组交换`、`存储转发`
- **相互关系**：资源子网负责数据处理与接收，通信子网负责通信与控制。
- **出处**：H学长 P53, P54

### 有线传输介质与无线介质
- **要点**：双绞线由两根绝缘铜导线按规律绞合（8 根 4 对），绞合可抵消电磁感应干扰；理论距离 100 米，接口为 RJ-45，线序常用 568B，屏蔽双绞线性能优于非屏蔽双绞线。同轴电缆用于闭路电视。光纤利用光的全反射传输，不受电磁干扰、衰减小、不易窃听，适合远距离。无线介质主要有地面微波接力、卫星通信与 WiFi。
- **关键概念**：`双绞线`、`电磁感应`、`RJ-45`、`光纤`、`全反射`
- **相互关系**：局域网中双绞线用得最多。
- **出处**：H学长 P53, P54

### 中国四大骨干网与三金工程
- **要点**：四大骨干网为中国公用计算机互联网、中国科技网、中国教育和科研计算机网、中国金桥信息网；三金工程为金桥、金卡、金关。
- **关键概念**：`ChinaNet`、`CSTNET`、`CERNET`、`ChinaGBN`、`三金工程`
- **出处**：H学长 P53, P54

### 信道、信号与通信指标
- **要点**：信道是信息传送的道路，分有线与无线。交互方式有单工（只能单向，如闭路电视）、半双工（同一时刻只能一个方向，如对讲机）、全双工（可同时双向，如现在的网络）。信号分模拟信号（连续，单位赫兹）与数字信号（离散，用正负电压表示 0 和 1）。传输速率体现有效性，误码率体现可靠性。
- **关键概念**：`信道`、`单工`、`半双工`、`全双工`、`误码率`
- **相互关系**：有效性对应传输速率，可靠性对应误码率。
- **出处**：H学长 P54

### 数据单位与带宽换算
- **要点**：计算机中最小单位是位（小 b），基本单位是字节（大 B），1 字节 = 8 位；传输速率单位为 bps。100 兆宽带指 100 Mbps，实际下载速度约 12.5 MB/s，网络换算通常按 1000。
- **关键概念**：`bit`、`Byte`、`bps`、`Mbps`、`MB/s`
- **相互关系**：带宽单位只能选小 b 的 Mbps，不能写成 MB，是常考陷阱。
- **出处**：H学长 P54

### 数据传输方式与拓扑结构
- **要点**：传输方式分基带（近距离、信号不转换）与频带（远距离、需调制）。拓扑结构：总线型共享通路、简单便宜，总线一断全网瘫痪；星型中心为集线器，中心坏则全网瘫痪；环形单向传递，任一节点故障全网瘫痪，可靠性最低；树形用于层次分明的部门；网状型通路不唯一、可靠性高、成本高，用于广域网。
- **关键概念**：`基带`、`频带`、`总线型`、`星型`、`环形`、`网状型`
- **相互关系**：可靠性最高的是网状型，最低的是环形。
- **出处**：H学长 P54

### 网络系统的组成与连接设备
- **要点**：网卡（NIC）工作于数据链路层，是上网必不可少的硬件；调制解调器（光猫）工作于物理层，实现数字信号与模拟信号转换；中继器、集线器工作于物理层，集线器为共享方式；交换机工作于数据链路层，提供独享通路；路由器工作于网络层，按 IP 选路转发。网络操作系统用于服务器，如 Windows Server、UNIX、Linux。
- **关键概念**：`网卡`、`modem`、`集线器`、`交换机`、`路由器`、`独享`
- **相互关系**：「扩大网络传输距离」优选中继器，「独享」选交换机。
- **出处**：H学长 P54

### 分层思想、体系结构与协议三要素
- **要点**：为让不同计算机与不同连接方式的设备互通，必须制定共同遵守的标准，即网络体系结构与协议；分层就是把庞大问题分解为小问题。协议是通信双方共同遵守的约定，三要素为语法（规定怎么写）、语义（协调与差错处理）、时序（谁先发谁后发）。
- **关键概念**：`体系结构`、`协议`、`语法`、`语义`、`时序`
- **出处**：H学长 P55

### OSI 参考模型
- **要点**：OSI 是国际标准化组织 ISO 制定的开放式系统互联参考模型，分七层：物理层、数据链路层、网络层、传输层、会话层、表示层、应用层（「物数网传会表应」）。物理层传比特流；数据链路层在相邻节点间可靠传帧；网络层按 IP 选路、传分组；传输层负责端到端传输；会话层建立会话；表示层管数据格式、加解密与压缩；应用层面向用户与应用。
- **关键概念**：`OSI`、`ISO`、`物理层`、`数据链路层`、`网络层`、`应用层`
- **相互关系**：题目提到「用户」「应用」一般选应用层；物理层设备有中继器、集线器，数据链路层有网桥、交换机、网卡，网络层有路由器。
- **出处**：H学长 P55

### TCP/IP、TCP 与 UDP、端口号
- **要点**：TCP/IP 是 Internet 最基本的协议，分网络接口层、网络层、传输层、应用层四层，是一个协议族。TCP 面向连接、可靠，三次握手建立连接、收到 ACK 确认，未确认则重传；UDP 不建立连接、不可靠、丢失不重传但速度快，适合语音视频。端口号在传输层标识服务。
- **关键概念**：`TCP/IP`、`TCP`、`UDP`、`三次握手`、`端口号`、`80`、`443`
- **相互关系**：SMTP 发邮件、POP3 收邮件；ARP 由 IP 求 MAC、RARP 由 MAC 求 IP；访问 HTTPS 须用 443 端口。
- **出处**：H学长 P55

### Internet 概述与 MAC 地址
- **要点**：Internet 即因特网、国际互联网，前身是 ARPANET（阿帕网），起源于美国，特点是开放性、共享性、资源丰富与平等性。MAC 地址是网卡的物理地址，也称局域网地址，用于局域网内部通信；48 位二进制即 6 个字节，通常用 12 个十六进制数表示，每个网卡唯一，一台设备可有多个。
- **关键概念**：`Internet`、`ARPANET`、`MAC 地址`、`48 位`、`6 字节`
- **出处**：H学长 P56

### IP 地址概念、判断与命令
- **要点**：IP 地址是接入网络的计算机的通信地址，默认指 IPv4，由 32 位二进制组成（4 个字节），每 8 位一组转为十进制并用点分隔。判断是否正确的四条件：分四组、每组 0~255、十进制、用点分隔。ping 检查与目标是否连通，ipconfig 查看本机网络配置。
- **关键概念**：`IP 地址`、`IPv4`、`32 位`、`点分十进制`、`ping`、`ipconfig`
- **出处**：H学长 P56

### IP 地址分类与默认子网掩码
- **要点**：按首字节范围分五类：A 类 0~127、B 类 128~191、C 类 192~223、D 类 224~239、E 类 240~255；二进制前缀 0、10、110、1110、1111 依次对应 A 至 E 类。A、B、C 三类有默认子网掩码，分别是 255.0.0.0、255.255.0.0、255.255.255.0；D 类与 E 类不划分网络号与主机号，不设默认子网掩码。
- **关键概念**：`A 类`、`B 类`、`C 类`、`默认子网掩码`
- **相互关系**：问「IP 地址范围」要写全四组，问「首字节范围」只写 128~191，两者易混。
- **出处**：H学长 P56, P57

### 私有地址与子网掩码
- **要点**：公网 IP 可直接访问 Internet，私网 IP 须经 NAT 转换才能出网。IP 地址分网络号与主机号，子网掩码用于区分二者：掩码中 255 对应的组是网络号，0 对应的组是主机号。
- **关键概念**：`公网 IP`、`私网 IP`、`NAT`、`子网掩码`、`192.168`
- **相互关系**：判断网络号先由首字节确定类别，再写出该类默认掩码，最后按 255 与 0 的对应关系划分。
- **出处**：H学长 P56

### 网段、网络地址与广播地址
- **要点**：申请到的 IP 是一个网段而不是单个地址。网段中首地址（主机号全 0）为网络地址，末地址（主机号全 1）为广播地址，这两个地址不能分配给主机，中间部分才是可用主机地址。计算三步法：取出 IP 与子网掩码→都转成 32 位二进制一一对齐→掩码为 1 的位对应网络号、为 0 的位对应主机号，网络地址＝网络号不变、主机号全置 0，广播地址＝主机号全置 1。
- **关键概念**：`网段`、`网络地址`、`广播地址`、`可用主机地址`
- **相互关系**：简便算法是掩码为 255 的分组原样照抄、为 0 的分组网络地址写 0、广播地址写 255，只需转换既非全 1 也非全 0 的那一组。
- **出处**：H学长 P57

### 子网数与主机数的计算
- **要点**：三步法。第一步找两个关键点——由 IP 类别推出的默认子网掩码，以及题目给出的子网掩码；第二步把两个子网掩码都转成 32 位二进制并对齐；第三步套口诀：子网数 = 2^（两个子网掩码不同的位数），主机数 = 2^（给定子网掩码中 0 的个数） − 2。
- **关键概念**：`默认子网掩码`、`给定子网掩码`、`子网数`、`主机数`
- **相互关系**：与「网络地址与广播地址的计算」共用前两步，区别只在第三步的口诀。
- **出处**：H学长 P57

### 子网掩码常见值的速记与易错点
- **要点**：合法子网掩码的二进制必须是「前面连续 1、后面连续 0」。常见十进制值中 1 的个数：128 = 1 个、192 = 2 个、224 = 3 个、240 = 4 个、248 = 5 个、252 = 6 个、254 = 7 个、255 = 8 个，其余位补 0。
- **关键概念**：`连续 1 与连续 0`、`248`、`240`
- **相互关系**：是子网数、主机数、网络地址、广播地址计算的加速工具。
- **出处**：H学长 P57

### DNS 与域名-IP 对应关系
- **要点**：域名系统用域名代替 IP 访问主机，但域名的本质仍然是 IP。DNS 是把域名与 IP 相互映射的分布式数据库，作用是将域名解析成 IP。一个域名只对应一个 IP，而一个 IP 可以对应多个域名；域名本身唯一、名字不能重复。
- **关键概念**：`域名`、`DNS`、`域名解析`、`一对多对应`
- **出处**：H学长 P58

### 域名的层次结构与顶级域名
- **要点**：域名采用层次结构，常见为四段，自右向左级别降低，最右为顶级域名，向左依次为二级、三级域名。顶级域名按机构类型区分：com 商业机构、edu 教育机构、gov 政府机关、mil 军事组织、net 网络管理机构、org 非营利组织、int 国际组织；按国家或地区区分：cn 中国、uk 英国、au 澳大利亚。
- **关键概念**：`层次结构`、`顶级域名`、`com`、`edu`、`gov`、`cn`
- **相互关系**：常见考法是给出一个域名，问其中某一段是什么，或判断该网站的性质。
- **出处**：H学长 P58

### 域名解析过程与 URL
- **要点**：主机访问某域名时，先查本机缓存，再向 DNS 服务器请求该域名对应的 IP，DNS 返回 IP 后再用该 IP 访问目标主机。DNS 故障时的典型现象是 QQ 能上网而网页打不开，因为 QQ 内置了 IP。URL 即统一资源定位符，是互联网上资源的地址，由协议、服务器域名、路径和文件名三部分组成；路径中过去可以用 .. 上翻目录，会暴露网站目录结构。
- **关键概念**：`DNS服务器`、`本机缓存`、`公共DNS`、`URL`、`路径`
- **相互关系**：域名定位主机，URL 进一步定位主机上的具体文件。
- **出处**：H学长 P58

### IPv6
- **要点**：IPv6 出现的原因是 IPv4 地址不够用（IPv4 为 32 位二进制，约 40 多亿个地址）。IPv6 为 128 位二进制，即 16 个字节，改用十六进制书写：4 位一组、共 32 位十六进制、分为 8 组，组间用冒号分隔。为书写简洁引入零压缩法：把连续的全 0 组用两个冒号 :: 表示，但同一地址中只能用一次；每一组内前导的 0 也可以省略。
- **关键概念**：`IPv6`、`128位`、`16字节`、`冒号十六进制`、`零压缩法`
- **出处**：H学长 P58

### 常见地址形式对比
- **要点**：MAC 地址为 48 位二进制（6 字节），用 12 位十六进制表示；IPv4 为 32 位二进制（4 字节），分为四组十进制；IPv6 为 128 位二进制（16 字节），写作 8 组十六进制、用冒号分隔。注意区分「位」与「字节」——IPv4 是 32 位、4 字节。
- **关键概念**：`MAC地址`、`IPv4`、`IPv6`、`位`、`字节`
- **相互关系**：综合 MAC、IPv4、IPv6、域名、URL 各知识点，是易混点的集中对比。
- **出处**：H学长 P58

### Internet 与接入方式、静态与动态 IP
- **要点**：常见接入方式包括拨号入网、ISDN 入网、ADSL 入网、有线通、专线、移动无线接入、局域网入网。静态 IP 又称固定 IP，长期不变，通常是公网 IP，需要付费，用于搭建服务器、专线入网；动态 IP 又称临时 IP，有租约时间，到期会被收回再分配，用于拨号入网和普通用户，由 DHCP 分配，可用 ipconfig 查看租约时间。
- **关键概念**：`拨号入网`、`专线`、`静态IP`、`动态IP`、`DHCP`、`租约`
- **相互关系**：题目中出现「服务器」「专线入网」应选静态 IP，出现「拨号入网」「普通用户」应选动态 IP。
- **出处**：H学长 P59

### ISP、ISDN 与 ADSL
- **要点**：ISP 指互联网服务提供商，如中国移动、中国联通、中国电信；另有互联网内容提供商，指门户网站一类。ISDN 指综合业务数字网。ADSL 指非对称数字用户线，「非对称」指上行速度与下行速度不同——上行慢、下行快。专线接入获得的是静态 IP。
- **关键概念**：`ISP`、`ISDN`、`综合业务数字网`、`ADSL`
- **相互关系**：英文缩写与中文名称的对应是常见考法。
- **出处**：H学长 P59

### Internet 服务与 WWW
- **要点**：Internet 提供的服务包括万维网服务、电子邮件、远程登录、文件传输、专题讨论与电子公告板、信息浏览服务、电子商务、网络新闻组等。WWW（万维网服务）全称 World Wide Web，基于 HTTP 协议；而 Internet 本身基于 TCP/IP 协议。
- **关键概念**：`WWW`、`World Wide Web`、`HTTP`、`TCP/IP`
- **相互关系**：WWW 的协议（HTTP）与 Internet 的协议（TCP/IP）是易混点。
- **出处**：H学长 P59

### 电子邮件、远程登录与 FTP
- **要点**：电子邮件地址格式为 用户名@邮件服务器域名，用户名在前、域名在后，中间的 @ 不能写成 #、-、! 等。远程登录指用自己的电脑通过网络登录并控制远程主机，传统协议是 Telnet、使用 23 号端口，现在更多使用 SSH，常用于登录路由器、交换机。FTP 用于在互联网上提供文件存储与传输，支持匿名 FTP：用户名固定为 anonymous，密码一般填邮箱地址或任意内容。
- **关键概念**：`电子邮件`、`@`、`Telnet`、`SSH`、`FTP`、`anonymous`
- **出处**：H学长 P59

## 九、信息安全与计算机病毒

### 信息安全与网络安全的定义及属性
- **要点**：信息安全是使硬件、软件和数据不受偶然（无意）与恶意（有意攻击）原因破坏、更改、泄露的保护。信息安全七个指标为真实性、保密性、完整性、可用性、不可抵赖性、可控制性、可审查性；网络安全五个属性为保密性、完整性、可用性、可控性、不可抵赖性。
- **关键概念**：`真实性`、`保密性`、`完整性`、`可用性`、`不可抵赖性`、`可审查性`
- **相互关系**：不可抵赖性与可审查性依赖日志记录；多选题常要求从选项中选出这几个属性。
- **出处**：H学长 P4, P59

### 安全防御技术与网络安全的影响因素
- **要点**：防御技术包括入侵检测、防火墙与病毒防护、数字签名与生物识别、信息加密与访问控制、安全审计与监控、加解密与身份认证。网络安全的主要类型包括系统安全、网络信息安全、网络传播安全、信息内容安全；影响因素可归为三类：人为因素、自然灾害、体系与协议漏洞。协议漏洞的典型例子是 TCP 三次握手的缺陷：攻击者伪造 IP，只完成前两步握手而不发第三步确认，占满服务器的连接资源，形成拒绝服务攻击（DoS）。防范措施包括物理措施、过滤、容错、数据备份以及法律与道德约束。
- **关键概念**：`数字签名`、`访问控制`、`TCP三次握手`、`拒绝服务攻击`、`DoS`
- **相互关系**：HTTPS 即经 SSL 加密，截获后看到的是密文；用「体系与协议漏洞」解释攻击原理，是网络安全属性中「可用性」被破坏的实例。
- **出处**：H学长 P4, P59

### 计算机病毒的概念、特点与传播
- **要点**：病毒是人为编制的、插入程序中破坏功能或数据、能自我复制的指令或程序代码，本质是程序。特点为传染性、破坏性、潜伏性、激发性、针对性、寄生性、隐蔽性，且无免疫性。传播途径有网络传播（最主要）、移动设备、系统或软件漏洞。
- **关键概念**：`传染性`、`潜伏性`、`激发性`、`寄生性`、`免疫性`、`网络传播`
- **相互关系**：潜伏性强调先隐藏、条件满足才发作，激发性强调满足条件才发作。
- **出处**：H学长 P4, P5

### 病毒的分类、常见病毒与防治
- **要点**：按链接方式分源码型、嵌入型、外壳型、入侵型、操作系统型；按破坏情况分良性、恶性；按感染目标分引导型（引导扇区）与文件型（exe、com、bat），后者考得最多。宏病毒感染 Office 文档（.doc）；CIH 是第一个破坏硬件的病毒；勒索病毒针对 45 端口、以比特币收款。防治靠数据备份、杀毒软件与防火墙。
- **关键概念**：`源码型`、`外壳型`、`引导型`、`文件型`、`宏病毒`、`CIH`、`勒索病毒`
- **出处**：H学长 P5

### 杀毒软件与防火墙
- **要点**：杀毒软件消除病毒、木马与恶意软件，但不可能查杀所有病毒、能查到的不一定能删除，且大部分滞后于病毒（基于特征代码）；对感染文件的处理有清除、删除、禁止访问、隔离、不处理。防火墙在内部网与外部网间建立保护屏障，功能为过滤数据、关闭端口、禁止特定站点访问、防内部信息泄漏、日志记录；分类有包过滤、状态检测、应用代理、复合型。
- **关键概念**：`特征代码`、`病毒库`、`隔离区`、`包过滤`、`状态检测`、`应用代理`
- **相互关系**：同机不必装两套国内杀毒软件；防火墙也防内但力度较小。
- **出处**：H学长 P5
