## 十、C 语言概述与程序开发

### C 语言的历史、标准化与语言定位
- **要点**：1969 年肯·汤普森在 BCPL 基础上发明 B 语言开发 UNIX；1972 年丹尼斯·里奇设计出 C 语言并用 C 重写 UNIX，1988 年 ANSI 将其标准化；C 语言之父是丹尼斯·里奇。C 由 B 语言发展而来，引入数据类型使编译期即可确定数据长度，最初是为实现 UNIX 的工作语言。
- **关键概念**：`BCPL`、`B 语言`、`ANSI`、`数据类型`
- **出处**：鹏哥 P1；升本啦 P2

### C 语言的特点与关键字
- **要点**：简洁紧凑、使用方便灵活；9 种控制语句、34 种运算符；严格区分大小写；语法不太严格（字符变量可赋整数、数组下标越界不报错）；可直接访问物理地址；代码质量高、可移植性好。「能编写大规模程序」不算特点。
- **关键概念**：`关键字`、`控制语句`、`可移植性`
- **相互关系**：语法宽松是双刃剑——能写出更高性能的程序，但错误推迟到运行时暴露；关键字不能用作标识符。（鹏哥 P6 说常用关键字 32 个，升本啦 P2 说 37 个 —— 口径不一致，以考纲为准）
- **出处**：鹏哥 P6；升本啦 P2；强哥 P4, P5

### 计算机程序、指令与语言发展阶段
- **要点**：程序是计算机能识别和执行的一组指令；指令集由 CPU 在硬件层面固化，只能通过机器语言暴露。机器语言由 0/1 编码组成，最基础但难用；符号语言（汇编）用助记符代替二进制码；高级语言接近自然语言与数学语言。机器语言与符号语言合称低级语言。
- **关键概念**：`指令集`、`机器语言`、`符号语言`、`高级语言`、`低级语言`
- **相互关系**：冯·诺依曼体系的特点是程序与数据同等地位存储并可执行；C 语言介于高低之间，常称中级语言，是面向过程的语言。
- **出处**：升本啦 P2

### 编译与链接流程、编译器与 IDE
- **要点**：`.c` 由编译器生成 `.obj`（编译），再与链接库由链接器合并成 `.exe`（链接），每个 `.c` 单独编译。库函数只需包含头文件即可用，因链接时链接了标准库。编译器有 MSVC、clang、GCC，被封装集成进 IDE；IDE 集成编辑器、编译器、调试器和图形界面；VS Code 只是编辑器，不含编译器和调试器。
- **关键概念**：`编译器`、`链接器`、`.obj`、`.exe`、`IDE`
- **相互关系**：易错——「.c 直接编译成 .exe」错；GCC 与 Turbo C 地位等价可互换，因为 C 本身是一个标准。
- **出处**：鹏哥 P2, P3；强哥 P8, P14, P15；升本啦 P2

### C 程序的编译过程与注释
- **要点**：编辑 → 预处理 → 编译 → 链接 → 运行。编译做语法检查，出错则不生成可执行文件，编译后得目标文件 `.obj`（二进制，不能直接执行）；链接把目标文件与函数库打包成 `.exe`；源文件扩展名选 `.c`。注释分单行 `//`（不能跨行）与多行 `/* */`，编译时被当作一个空格、目标文件不含注释；写在双引号内不起注释作用。
- **关键概念**：`编译`、`链接`、`目标文件 .obj`、`/* */`
- **出处**：强哥 P8, P14, P15；鹏哥 P14

### 在 VS 中创建项目与运行程序
- **要点**：流程为创建项目 → 创建 `.c` 文件 → 写代码；选「空项目」，项目名不用中文和空格。源文件选 C++ 模板、后缀写 `.c`；`.h` 的 header 意为头。先「生成解决方案」（Ctrl+Shift+B）编译链接，再 Ctrl+F5 运行，可执行文件在 `x64/Debug` 下。Git 流程 add → commit（须填提交信息）→ push。
- **关键概念**：`项目`、`.c 源文件`、`Ctrl+Shift+B`、`Ctrl+F5`
- **出处**：鹏哥 P3, P11

### main 函数是程序入口
- **要点**：程序从 main 第一行开始依次向下执行；任何 C 程序须有且仅有一个 main（多个 `.c` 文件也只能有一个），位置任意；不写在 main 里的代码不被执行。标准写法 `int main()` 加函数体、末尾 `return 0;`（返回 0 正常、非零异常），`return` 之后的代码不执行。
- **关键概念**：`main`、`程序入口`、`return 0`
- **相互关系**：易错——「一个源文件有一个 main」错；`main` 拼成 `mian`、漏圆括号、用中文括号或分号是常见错误。
- **出处**：鹏哥 P4, P57；升本啦 P3, P7；强哥 P9, P10, P12, P13；一灯 P2

### C 程序的结构特点
- **要点**：程序由一个或多个源程序文件组成，每个源文件由预处理指令、全局声明、函数定义构成。函数是基本组成与模块单位。书写格式自由，一行可写多个语句（靠分号判断）。
- **关键概念**：`源程序文件`、`函数定义`、`全局声明`
- **相互关系**：运行分编辑、编译、链接、运行四步，加预处理为五步。
- **出处**：升本啦 P3

### 函数的构成与库函数
- **要点**：函数由函数头和函数体组成，形式为「返回类型 函数名(形参) { 函数体 }」。返回类型 `void` 表示不返回值，参数 `void` 表示无参。C 标准只规定常用函数的标准、不提供实现；厂商按标准实现并放进库中形成标准库，其中的函数即库函数。同一系列库函数声明在同一头文件中（`stdio.h`、`math.h`、`string.h`、`stdlib.h`）。
- **关键概念**：`函数头`、`函数体`、`库函数`、`标准库`、`头文件`
- **出处**：鹏哥 P4, P5, P54, P55

### 预编译指令 #include
- **要点**：`#include <stdio.h>` 是预编译命令，作用是把头文件内容在编译前替换到该位置，行尾不加分号；`stdio` 是 standard input/output。尖括号直接到系统路径查找；双引号先在当前目录查找，找不到再到系统路径。
- **关键概念**：`#include`、`头文件`、`预编译`、`stdio.h`
- **相互关系**：凡用到标准输入输出库函数都必须引入该头文件。
- **出处**：升本啦 P3；强哥 P6, P7, P11

### 关键字与变量命名规则
- **要点**：C 提前保留的、有特殊意义的符号称关键字（保留字），可直接使用但不可自己创造，标识符也不可与关键字重名；常用关键字有 `const`、`enum`、`extern`、`sizeof`、`static`、`struct`、`typedef`、`union`、`unsigned`。变量名只能由字母、数字、下划线组成、不可数字开头、区分大小写、不可用关键字。
- **关键概念**：`关键字`、`保留字`、`标识符`
- **相互关系**：易错点——`switch` 加下划线后是合法标识符，但 `switch` 本身是关键字，此题几乎每年都考；`auto` 是关键字，`bool`、`don1` 不是。
- **出处**：鹏哥 P6, P19；升本啦 P5；一灯 P2

### 语句的五大分类与三种程序结构
- **要点**：语句分五类——表达式语句（表达式后加分号）、函数调用语句、复合语句（花括号组成语句块，右花括号后不加分号）、控制语句共 9 种（if/switch、while/do-while/for、break/continue/goto/return）、空语句（只有一个分号）。C 支持顺序、选择、循环三种结构。
- **关键概念**：`空语句`、`复合语句`、`控制语句`、`循环结构`
- **相互关系**：易错——「C 语句一定以分号结尾」错；`#include`、`#define` 是指令不是语句。
- **出处**：鹏哥 P13；强哥 P71, P72, P73

### 算法与「算法 + 数据结构 = 程序」
- **要点**：算法是解决问题的方法与步骤的描述，必须能被人按步骤复现，是有限条指令的集合；Wirth 提出「算法 + 数据结构 = 程序」，数据结构解决数据如何存储组织（静态），算法是让数据运转的步骤。必须满足五特性：有穷性、确定性、可行性（有效性）、输入（零个或多个）、输出（至少一个）。
- **关键概念**：`算法`、`五特性`、`有穷性`、`确定性`
- **相互关系**：算法不等于程序，程序是算法的具体实现；易错——「算法可以没有输出」错，「可以没有输入」对。
- **出处**：逊哥 P1, P2；升本啦 P4；强哥 P17, P18

### 算法的表示方法与三种基本结构
- **要点**：算法可用自然语言、流程图、N-S 图、伪代码表示；流程图中菱形为判断、矩形为处理、平行四边形为输入输出。程序只有顺序、选择、循环三种基本结构，共同特点：一个入口一个出口、每部分都有机会执行、无死循环。结构化程序设计追求高内聚低耦合。
- **关键概念**：`流程图`、`N-S 图`、`伪代码`、`高内聚低耦合`
- **出处**：升本啦 P4

## 十一、数据类型、常量与变量

### 数据类型的作用、抽象与内置类型家族
- **要点**：类型是相似数据的共同特征，编译器只有知道类型才知道如何操作数据。基本类型：整型（`int`/`short`/`long`/`long long`/布尔）、字符型 `char`、实型（`float`/`double`/`long double`）、枚举、空类型 `void`；派生类型：指针、数组、结构体、共用体、函数。字符类型存的是 ASCII 码值，归入整型家族。
- **关键概念**：`数据类型`、`内置类型`、`基本类型`、`派生类型`
- **出处**：鹏哥 P15, P16；强哥 P20, P21

### 数据类型与变量
- **要点**：数据类型决定数据在内存中占的字节数，编译时即可确定，CPU 读取时凭类型知道要连续读几个字节。变量占据存储空间，变量名是存储单元地址的名称，必须先定义后使用；同类型多变量可合并定义（`int a, b, c;`）；未赋初值时变量是随机值。
- **关键概念**：`数据类型`、`内存地址`、`变量`、`先定义后使用`
- **出处**：升本啦 P2, P3, P5；强哥 P37, P39, P53

### 布尔类型 _Bool
- **要点**：C 早期无单独的布尔类型，用整数 0 表示假、非零表示真；C99 引入 `_Bool`，使用需包含 `stdbool.h`，取值只有 `true`（1）和 `false`（0）；包含头文件后也可写小写 `bool`。
- **关键概念**：`_Bool`、`bool`、`stdbool.h`
- **出处**：鹏哥 P15

### 数据类型的长度与 sizeof
- **要点**：`sizeof` 是关键字不是函数，计算类型或变量占用的字节数，8 个比特位为 1 个字节；放类型时括号不可省。C 标准只要求 `short` 不长于 `int`、`long` 不短于 `int`、`sizeof(long) >= sizeof(int)`：16 位机 `int` 占 2 字节、32/64 位机占 4 字节。`sizeof` 括号里若是表达式，该表达式不被计算，只通过类型推导得出结果。`sizeof` 的返回值是无符号整数，标准为它专门定义了类型别名 `size_t`，打印时用 `%zu`。
- **关键概念**：`sizeof`、`字节`、`单目运算符`、`不求值`、`size_t`、`%zu`
- **相互关系**：`sizeof(int)`=4、`sizeof(double)`=8、`sizeof(char)`=1、`sizeof(3.14)` 按 double 得 8、`sizeof("AB")`=3（含 `\0`）、`sizeof('A')` 在 C 中按 int 得 4。
- **出处**：鹏哥 P16, P18, P131；强哥 P55；一灯 P1

### signed 与 unsigned
- **要点**：`signed`/`unsigned` 用于修饰字符型和整型（与浮点型无关）；`signed` 可存负值，`unsigned` 只能表示零和正整数。`int` 默认等价于 `signed int`（`signed` 可省），需无符号只能写 `unsigned int`；有符号数牺牲最高位作符号位（0 正 1 负），无符号数最高位是数值位。
- **关键概念**：`signed`、`unsigned`、`无符号`、`符号位`
- **相互关系**：2 字节有符号 -32768~32767、无符号 0~65535；`short int` 固定 2 字节、`long int` 固定 4 字节；无符号变量存负数按补码处理、须用 `%u` 输出。
- **出处**：鹏哥 P17；强哥 P43, P44, P45

### 数据类型的取值范围与溢出
- **要点**：整型范围在 `limits.h` 中定义，浮点型在 `float.h` 中定义。8 位共 256 种组合，最高位作符号位时 `10000000` 被解析为 -128，故范围呈「轮回」——127 加一得 -128。超出范围不报错中断，而按「周期」回绕：超上限减周期、低下限加周期；超上限称正溢（上溢）、超下限称负溢（下溢）。
- **关键概念**：`取值范围`、`limits.h`、`INT_MAX`、`溢出`、`周期`
- **相互关系**：`char` 周期 256（赋 128 得 -128）；`int` 到最大值后跳回负数并正负交替，故不能无限自增。
- **出处**：鹏哥 P17, P18, P151；强哥 P48, P49

### 常量总览与符号常量
- **要点**：常量是运行中值不能改变、也不能被修改的量，共五类：整型、实型、字符型、字符串、符号常量。符号常量用 `#define 名字 值` 定义，是预处理指令、末尾不加分号，编译前完成替换、一改全改、不占内存、不指定类型；`const` 常变量有类型、占存储空间但值不可改。
- **关键概念**：`常量`、`#define`、`符号常量`、`const`
- **相互关系**：C99 增加常变量，只能在定义时赋值一次。
- **出处**：升本啦 P5；强哥 P22, P35, P52

### 整型常量：进制与后缀
- **要点**：十进制无前缀；八进制以 `0` 为前缀、数码 0~7（`029`、`066` 非法）；十六进制以 `0x`/`0X` 为前缀、数码 0~9 与 A~F。后缀 `L`/`l` 为长整型、`U`/`u` 为无符号，可组合为 `LU`/`UL`，`52D` 非法。八进制、十六进制常量通常视为无符号数；后缀只改变存储空间、与数值大小无关。
- **关键概念**：`0/0x 前缀`、`L/U 后缀`、`八进制`、`十六进制`
- **出处**：升本啦 P5；强哥 P23–P26

### 实型常量与浮点类型
- **要点**：实型常量必须带小数点或采用指数形式。十进制可省略一侧并补零（`.2`=`0.2`、`6.`=`6.0`），口诀「点的一侧要有数」。指数写法用 `E`/`e` 加整数，规则「E 前后都要有数、E 后必须是整数」。`float` 4 字节、`double` 8 字节、`long double` 8 或 16 字节；实型常量默认按 `double`，加 `F` 为单精度。
- **关键概念**：`实型常量`、`E/e`、`科学计数法`、`float/double`
- **相互关系**：易错点——用 `%d` 输出 `float` 变量会读乱内存、输出乱码。
- **出处**：升本啦 P5；强哥 P27, P28, P51；鹏哥 P22

### 字符常量、ASCII 码与字符型变量
- **要点**：单引号括起的一个字符是字符常量，占一个字节，内存中保存其 ASCII 码值，故字符类型本质是整型。必记 `'0'`=48、`'A'`=65、`'a'`=97、空格=32，大小写相差 32。`char` 变量占 1 字节，范围 -128~127、无符号 0~255；`%c` 按字符输出、`%d` 输出 ASCII 码。字符参与运算一律按 ASCII 码整数处理。
- **关键概念**：`字符常量`、`ASCII 码`、`char`、`%c`
- **相互关系**：单引号内只能放一个字符，双引号括起的是字符串，这是区分二者的第一判据。
- **出处**：鹏哥 P7；升本啦 P5；强哥 P29, P34, P46, P47

### 转义字符
- **要点**：以反斜杠开头，作用是转变该字符本来的意思，占 1 字节。`\n` 换行、`\r` 回车、`\t` 制表位、`\b` 退格、`\a` 警告、`\f` 换页、`\v` 垂直制表、`\\`、`\'`、`\"`、`\0` 字符串结束符。八进制 `\ddd`（1~3 位、每位 0~7），十六进制 `\xhh`；ASCII 相同即同一字符，`'\101'` 与 `'\x41'` 都等于 `'A'`。
- **关键概念**：`转义字符`、`\n`、`\ddd`、`\xhh`
- **相互关系**：正斜杠 `/` 无转义作用；输出双引号须在其前加 `\`；ASCII 码只有八位，`\x111` 占 12 位、超出范围不合法。
- **出处**：鹏哥 P9, P10；升本啦 P5；强哥 P30–P33

### 字符串常量、\0 与两种打印方式
- **要点**：双引号括起来的一串字符称字符串，末尾隐藏着一个 `\0`，是结束标志；打印遇 `\0` 停止，求长度也统计到 `\0` 为止。存储空间 = 可见字符数 + 1，`"A"` 占 2 字节，空串 `""` 只含 `\0`、占 1 字节。打印有两种方式——直接放进 `printf` 的双引号里，或用 `%s` 作占位符把字符串作为参数传入。用 `char` 数组接收 `"abc"` 实际放入 `a`、`b`、`c`、`\0` 四个字符；用 `{'a','b','c'}` 初始化则不含 `\0`，打印会读取未知内存产生乱码。
- **关键概念**：`字符串`、`双引号`、`%s`、`\0`
- **相互关系**：5 个字符的字符串占 6 个字节；`\0` 是字符串输出、求长度、比较等一切处理的依据。
- **出处**：鹏哥 P8；升本啦 P5, P19；强哥 P29, P46

### 变量的创建、初始化与本质
- **要点**：创建变量语法为 `类型 变量名;`；整数用 `int`，小数用 `float` 或 `double`。创建变量的同时给值叫初始化，创建之后再改值叫赋值。浮点字面量默认是 `double`，赋给 `float` 变量时应在数字后加后缀 `F`。定义变量相当于申请一块存储空间，变量名是这块空间的标签，数据按二进制形式填入。
- **关键概念**：`变量`、`初始化`、`赋值`、`F 后缀`
- **出处**：鹏哥 P19, P22；强哥 P37, P39, P53

### 全局变量与局部变量
- **要点**：大括号外部定义的变量是全局变量，内部定义的是局部变量。局部变量只在自身所在的局部范围内可用，范围外访问会报「未定义的标识符」；全局变量在整个工程中都可使用；两者同名时局部优先、全局变量被屏蔽。
- **关键概念**：`全局变量`、`局部变量`、`局部优先`、`作用域`
- **相互关系**：局部变量包括函数内定义的变量、复合语句（`{}`）内定义的变量和形参；函数内定义了与全局变量同名的局部变量时，使用的是离得最近的局部变量。
- **出处**：鹏哥 P19, P21；升本啦 P23

### 作用域、生命周期与存储类别
- **要点**：作用域是限定一个名字可用性的代码范围；局部变量的作用域是它所在的一对大括号内，全局变量的作用域是整个工程。内存分静态存储区与动态存储区：全局变量、`static` 局部变量放在静态存储区，程序运行期间一直存在；自动变量（不加关键字即为 `auto`）与形参放在动态存储区，函数调用时分配、调用结束即释放。
- **关键概念**：`作用域`、`生命周期`、`静态存储区`、`动态存储区`、`auto`
- **相互关系**：`static` 局部变量在编译时赋初值，函数调用结束后仍保留当前值。
- **出处**：鹏哥 P62；升本啦 P23

### 变量的定义与声明、extern
- **要点**：定义会在内存中建立存储空间，声明不建立（如 `extern`），因此定义本身也是一种声明；同一变量可以多次声明，但只能定义一次。在另一个 `.c` 文件中定义的全局变量直接使用会报「未声明的标识符」，用 `extern` 声明该变量（如 `extern int a;`）即可跨文件使用；声明只给出名字与类型、不可赋初值。
- **关键概念**：`定义`、`声明`、`extern`
- **出处**：升本啦 P24；鹏哥 P62, P63

### static 修饰局部变量、全局变量与函数
- **要点**：被 `static` 修饰的局部变量，存储类型从栈区变为静态区，生命周期延长到与程序一致，出函数不再销毁，下次进入函数仍保留上次的值；但作用域不变。全局变量与函数默认具有外部链接属性，其他源文件用 `extern` 声明后即可使用；被 `static` 修饰后变为内部链接属性，只能在本源文件内使用。函数默认为外部函数（可用 `extern` 说明），加 `static` 则成为内部函数。
- **关键概念**：`static`、`静态区`、`外部链接属性`、`内部链接属性`
- **出处**：鹏哥 P62, P63, P64；升本啦 P24

### 全局变量的使用建议
- **要点**：全局变量可让函数之间不必通过参数传递就能共享数据，命名上习惯首字母大写。但滥用会长期占用存储空间，并降低函数的独立性与程序清晰度，应尽量少用。
- **关键概念**：`全局变量`、`数据共享`、`命名习惯`
- **出处**：升本啦 P23

## 十二、运算符与表达式

### 算术操作符与整数除法
- **要点**：算术操作符有 `+`、`-`、`*`、`/`、`%`；符号两端的数叫操作数。`/` 两端都是整数时执行整数除法，只取商、丢弃小数部分（`7/2`=3、`1/3`=0）；要得小数结果，两端至少有一个是浮点数（`7/2.0`=3.5）；右侧不能为 0。
- **关键概念**：`操作符`、`双目操作符`、`整数除法`、`整除`
- **相互关系**：易错——把 `1/2` 当成 0.5；整除不做四舍五入。
- **出处**：鹏哥 P21；升本啦 P5, P8；强哥 P56, P57；一灯 P1

### 取模操作符 %
- **要点**：`%` 返回两数相除的余数，只能用于整数，不可用于浮点数；常用用途是取一个整数的最后一位（对 10 取模）。小数模大数结果就是那个小数（`2%5`=2），余数正负与被除数一致（`-5%3`=-2）。
- **关键概念**：`取模`、`求余`、`余数符号`
- **出处**：鹏哥 P21；强哥 P56, P57；一灯 P1

### 赋值操作符、复合赋值与连续赋值
- **要点**：`=` 是赋值运算符，方向从右向左，与数学中等号含义相反，左侧必须是简单变量，不能是表达式或 `a++`；实型赋给整型舍去小数，整型赋给实型值不变。`+=`、`-=`、`*=`、`/=`、`%=` 叫复合赋值，`a += 3` 等价于 `a = a + 3`；做题时把右侧表达式整体加括号理解（`x *= a+b` 即 `x = x*(a+b)`）。
- **关键概念**：`赋值运算符`、`复合赋值`、`右结合`
- **相互关系**：易错——`j+=i` 合法，`j+1=k` 不合法，应写 `k=j+1`；`+=` 中间不能加空格。
- **出处**：鹏哥 P22, P31；升本啦 P5, P8；强哥 P67, P68, P69；一灯 P2

### 自增自减运算符
- **要点**：`++`/`--` 让变量自增 1 / 自减 1，只能作用于变量，不能作用于常量或表达式（`6++`、`(a+1)++` 非法）。`a++` 与 `++a` 对 `a` 本身效果相同，区别只在表达式的值——后置「先使用再加一」，前置「先加一再使用」。多个 `a++` 连写要逐个追踪变量每一步的值。
- **关键概念**：`单目操作符`、`前置++`、`后置++`
- **出处**：鹏哥 P23, P32；升本啦 P5；强哥 P58, P59

### 关系操作符与使用陷阱
- **要点**：关系操作符共 6 个：`>`、`<`、`>=`、`<=`、`==`、`!=`；判断大小的四个优先级 6，`==`/`!=` 优先级 7，整体低于算术运算符。关系表达式为真时是 1、为假时是 0。陷阱一：把 `==` 误写成 `=` 会变成赋值表达式，结果非 0 即真、条件恒成立，避免办法是把常量写在左边（`3 == num`）。陷阱二：关系操作符不宜连用，`i < j < k` 会先算 `i < j` 得 0 或 1 再与 `k` 比较，正确写法是 `i < j && j < k`。
- **关键概念**：`关系操作符`、`==`、`常量放左边`、`关系操作符连用`
- **出处**：鹏哥 P30, P31；升本啦 P8；强哥 P90, P91

### 逻辑与 &&、逻辑或 || 与短路求值
- **要点**：`!` 单目、优先级最高，把真变假、假变真（非零即真、零即假）。`&&` 表示「且」，两端都为真结果才为真；`||` 表示「或」，只要有一个为真结果就为真。表示「某数在某区间内」必须用 `&&`（如 `n>=5 && n<=20`），用 `||` 会扩大范围而失去约束。逻辑运算符先算左侧、再算右侧，当左操作数已足以决定整个表达式结果时右侧不再求值，称短路。
- **关键概念**：`!`、`&&`、`||`、`短路`、`区间表示`
- **相互关系**：高频考点——`a++ && b++` 若 `a++` 的值为 0，则 `b++` 不会执行、`b` 保持原值。
- **出处**：鹏哥 P31, P32, P33；升本啦 P9；强哥 P92–P97；一灯 P1, P2, P4

### 条件操作符（三目运算符）
- **要点**：唯一的三目操作符，形式为 `表达式1 ? 表达式2 : 表达式3`；先求 `表达式1`，为真则取 `表达式2` 的值，为假则取 `表达式3` 的值。优先级 13、从右向左结合，`?` 与 `:` 必须成对；等价于 if-else 的取值写法（求两数较大值可写 `max = a>b ? a : b`）。多个 `? :` 连续出现时按问号个数从右向左划分表达式一、二、三。
- **关键概念**：`条件操作符`、`三目操作符`、`? :`
- **出处**：鹏哥 P31；强哥 P107；一灯 P1

### 逗号表达式
- **要点**：由逗号运算符连接两个及以上表达式构成，优先级最低（15），整个表达式的值取最后一个表达式的值；计算从左向右依次进行，前面表达式的副作用会影响后面。两种考法：问表达式的值，或问其中某个变量的值（后者更易错，如 `n+6`、`n*2` 都不改变 `n`）。函数参数之间的逗号只是分隔符。经典陷阱 `y = a, b` 等价于 `(y=a), b`，`y` 得 a 的值；`y=(a,b)` 才是 b。
- **关键概念**：`逗号表达式`、`优先级 15`、`副作用`、`分隔符`
- **出处**：鹏哥 P88；强哥 P64, P65, P66；一灯 P1

### 下标引用操作符与函数调用操作符
- **要点**：数组名加方括号就是下标引用操作符 `[]`，两个操作数分别是数组名和索引值，缺一不可。调用函数时函数名后面的一对圆括号就是函数调用操作符 `()`，操作数是函数名加各个参数；因存在无参函数，操作数最少只有一个。
- **关键概念**：`下标引用操作符`、`函数调用操作符`
- **出处**：鹏哥 P89

### 类型转换：自动与强制
- **要点**：混合运算发生自动类型转换，方向是低精度向高精度（`char`→`int`→`float`→`double`），结果取最「大」的类型。强制转换写作 `(类型名)(表达式)`，优先级 2、单目，只把该组合当作指定类型使用，不改变原变量的类型和值（`(int)f` 整体是 3，但 `f` 仍是 3.14）；实型转整型舍去小数、直接截断而非四舍五入，整型转实型值不变。`(int)x + y` 与 `(int)(x + y)` 含义不同。
- **关键概念**：`自动类型转换`、`强制类型转换`、`(int)`、`截断`
- **出处**：鹏哥 P24；升本啦 P2, P3, P5；强哥 P61, P62

### 整型提升与算术转换
- **要点**：整型算术运算至少以默认整型（`int`）的精度进行，因此长度小于 `int` 的 `char`、`short` 操作数在使用前会先转换成 `int`，称整型提升；有符号数补符号位，无符号数补 0。当运算符两侧操作数类型不同且都不小于 `int` 时，需先把其中一个转换成另一个的类型，称算术转换；方向为向上转换，顺序是 `int → unsigned int → long → unsigned long → float → double → long double`。
- **关键概念**：`整型提升`、`算术转换`、`向上转换`
- **出处**：鹏哥 P92, P149

### 优先级、结合性与问题表达式
- **要点**：34 种运算符、15 个优先级，编号越大优先级越低：圆括号/下标 → 单目（`!`、`++`、`--`、强制转换、取地址、`sizeof`、负号）→ 乘除求余 → 加减 → 移位 → 关系大小 → 等于不等于 → 按位与 → 按位异或 → 按位或 → 逻辑与 → 逻辑或 → 条件 → 赋值 → 逗号。只有单目、条件、赋值三级从右向左结合，其余全从左向右。计算路径不唯一的表达式称问题表达式，如 `c + --c`、`i++ + i++ + i++` 不同编译器结果不同，解决办法是拆成多条语句分步计算。
- **关键概念**：`优先级`、`结合性`、`左结合`、`问题表达式`
- **相互关系**：必考，常以「由高到低排序」出现；算不准时用「加括号原则」。
- **出处**：鹏哥 P91, P93；升本啦 P8, P9；强哥 P54, P60, P90, P105, P116；一灯 P1, P2

### 按位与、或、异或
- **要点**：位运算对操作数的补码逐位进行。`&`：1&1=1、其余为 0，优先级 8；`|`：0|0=0、其余为 1，优先级 10；`^`：相同为 0、不同为 1，优先级 9。正数的原码、反码、补码相同。位运算是逐位运算、不是整体真假判断；`&` 为双目，而取地址符 `&` 是单目。
- **关键概念**：`&`、`|`、`^`、`补码`
- **出处**：强哥 P104, P105

### 按位取反、左移、右移
- **要点**：`~` 单目，对补码逐位取反（含符号位），若用 `%d` 输出还需把补码还原成原码。左移 `<<`、右移 `>>` 优先级 5；左移 n 位相当于乘 2 的 n 次方，右移 n 位相当于除 2 的 n 次方。左移补 0，正数右移补 0，负数右移补 1（补符号位）。
- **关键概念**：`~`、`<<`、`>>`、`原码/反码/补码`
- **出处**：强哥 P106；升本啦 P5

### 表达式的概念与 C 表达式 vs 数学表达式
- **要点**：用运算符把运算对象（操作数）连接成的式子就是表达式，单个常量或变量也可看作简单表达式，表达式后加分号即成表达式语句。C 表达式不能省略乘号（`3a` 必须写 `3*a`）；上下型分式中在下方的一定是分母，左右型分式除号右侧的不一定是分母。
- **关键概念**：`表达式`、`操作数`、`分式`
- **出处**：强哥 P60, P63

### 关系与逻辑运算的典型题型
- **要点**：① 判断哪个表达式与其他含义不同：`k%2`、`k%2==1`、`k%2!=0` 都表示 k 为奇数，而 `!(k%2==1)` 相反。② 带自增自减的短路题：先看自增在前还是后，再按短路规则判断右侧是否执行。③ 混合运算求值：按优先级表定序，赋值最低故最后赋值。④ 区间条件写成逻辑表达式，如 0≤m≤10 写成 `m>=0 && m<=10`。⑤ 表达式等价关系：`if (x)` 与 `if (x != 0)` 等价，`if (!x)` 与 `if (x == 0)` 等价；选择题可用特殊值代入法。
- **关键概念**：`短路`、`优先级`、`等价关系`、`特殊值代入法`
- **出处**：升本啦 P6, P8, P9；强哥 P101

## 十三、顺序结构与输入输出

### printf 函数与格式控制
- **要点**：C 本身不提供输入输出语句，只提供库函数，经 `#include <stdio.h>` 引入。`printf` 在屏幕打印信息，`f` 表示格式化。格式控制字符串用双引号括起，由普通字符与格式声明（`%` 加格式字符）组成；普通字符原样输出，格式声明相当于「挖坑」由后面的输出项填充。输出列表用逗号隔开，格式声明与输出项必须一一对应：坑多数据少会输出随机值，数据多则多余的输出不出来。它不自动换行，换行需自己写 `\n`。
- **关键概念**：`stdio.h`、`printf`、`格式控制字符串`、`输出列表`
- **出处**：鹏哥 P5, P25；升本啦 P3, P5；强哥 P74–P77

### printf 输出格式字符与宽度
- **要点**：`%d` 以带符号十进制输出；`%md` 指定宽度，m 正数左补空格、负数右补空格，数据宽度 ≥ |m| 时原样输出、绝不截断；`%ld` 输出 long。`%c` 输出单个字符、不带单引号，`printf("%c", 97)` 输出 a。`%s` 输出字符串，后面必须跟一个字符串。`%f` 输出实型，默认 6 位小数、不足补 0；`%m.nf` 中 n 为保留小数位数（第 n+1 位四舍五入）、m 为输出总宽度（含负号和小数点），宽度不足补空格。`%e` 以指数形式输出实数，指数带正负号且至少两位数字；`%i` 与 `%d` 完全相同。
- **关键概念**：`%d/%md`、`%c`、`%s`、`%f/%m.nf`、`%e`
- **出处**：鹏哥 P26；强哥 P78–P81

### 占位符一览与参数对应关系
- **要点**：占位符以 `%` 开头，第二个字符表示要代入的类型；占位符与参数须一一对应。常用：`%c` 字符，`%d`/`%u` 有符号/无符号十进制整数，`%hd`/`%hu` 短整型，`%ld`/`%lu` 长整型，`%lld`/`%llu` 更长整型，`%o` 八进制，`%x` 十六进制，`%f` 浮点数，`%e` 科学计数法，`%lf` 对应 `double`、`%Lf` 对应 `long double`，`%p` 地址，`%s` 字符串，`%zd` 对应 `sizeof` 结果，`%%` 输出一个百分号。
- **关键概念**：`占位符`、`格式字符串`、`%u`、`%x`
- **出处**：鹏哥 P25, P26

### 八进制、十六进制与百分号输出
- **要点**：`%o` 按八进制、`%x` 按十六进制输出整数，默认都不带前缀（常设坑）；带前缀须写 `%#o`（`0` 开头）、`%#x`（`0x`），`%X` 输出大写十六进制及 `0X` 前缀。输出一个 `%` 必须写 `%%`，且 `%%` 结合后不再与后面的字符结合，故 `"%%d"` 输出 `%d`。
- **关键概念**：`%o`、`%x`、`%#x`、`%%`
- **出处**：强哥 P82

### scanf 基本用法与地址列表
- **要点**：`scanf` 读取键盘输入，执行到它会停下等待，回车后按占位符解析存入变量。它的参数是「地址列表」而非变量列表，每个变量前必须加取地址符 `&`，漏写数据无法写入——这是与 `printf` 的根本差别；格式串有几个占位符就须有几个变量地址；数组名本身是地址，读字符串不用加 `&`。格式串中的非格式字符（如 `a=%d` 的 `a=`、逗号）输入时必须原样照打，否则后续变量读到随机值；可在 `%` 与转换字符间写整数限定宽度（`%3d`）；多个数值型格式紧挨时只能用空格、回车或 Tab 隔开。
- **关键概念**：`scanf`、`&`、`地址列表`、`原样输入`、`%3d`
- **出处**：鹏哥 P28；升本啦 P3, P5；强哥 P83–P85

### scanf 的读取原理与返回值
- **要点**：输入先进入缓冲区，回车后按占位符解析，直到读完缓存或遇到第一个不匹配的字符。除 `%c` 外所有占位符都会自动跳过起手的空白字符；`%c` 不跳过，总是取当前第一个字符。返回值是成功读取的变量个数：一个都没读到或匹配失败返回 0，遇文件末尾或出错返回 `EOF`（-1）。遇到非数值字符也会终止当前变量输入，该字符留给下一个变量。
- **关键概念**：`缓冲区`、`空白字符`、`%c`、`EOF`
- **出处**：鹏哥 P28；强哥 P83–P85

### scanf 与 printf 占位符的差异
- **要点**：`printf` 中 `float` 和 `double` 都可用 `%f`；`scanf` 中须区分——`float` 用 `%f`、`double` 用 `%lf`（`%le` 亦可）、`long double` 用 `%Lf`，因它要据此决定读 4 字节还是 8 字节，混用会读入失败。`scanf` 中写 `%.几f` 非法，只有输出才支持 `%.2f`。这是高频易错点。
- **关键概念**：`%f`、`%lf`、`%Lf`
- **出处**：鹏哥 P28；强哥 P83–P85

### scanf 读取字符串与安全写法
- **要点**：`%s` 读到空白字符即停止并自动补 `\0`，故输入的字符串不能含空格。`scanf` 不检查目标数组长度，输入过长会越界破坏内存。可指定最大读取长度如 `%5s`，但数组有 n 个空间时最多读 n-1 个字符，要给 `\0` 留位置。VS 认为 `scanf` 不安全，报错并建议改用私有的 `scanf_s`（会失去跨平台性，不建议使用）。
- **关键概念**：`%s`、`\0`、`数组越界`、`%5s`、`scanf_s`
- **出处**：鹏哥 P27, P28；升本啦 P19

### 赋值忽略符 %*
- **要点**：在占位符的 `%` 后面加 `*`，表示该占位符仍会读取数据但不存入变量，解析后直接丢弃，如 `%*c`。用于输入格式中夹带的固定分隔符（如日期 `1998-02-06` 中的 `-`）。
- **关键概念**：`赋值忽略符`、`%*c`、`格式匹配`
- **出处**：鹏哥 P29

### putchar 与 getchar
- **要点**：`putchar(c)` 输出一个字符，等价于 `printf("%c", c)`，参数可为整型、字符型或转义字符，传整数时按 ASCII 码转成字符；`getchar()` 不带参数，读入一个字符，等价于 `scanf("%c", &c)`；两者返回值都是 `int`。键盘输入先进入缓冲区而非直接进变量，故一次输入多个字符后，后续 `getchar` 直接从缓冲区取、不再等待键盘输入。
- **关键概念**：`putchar`、`getchar`、`缓冲区`
- **出处**：鹏哥 P135, P136；强哥 P86, P87

### 海伦公式与 sqrt 函数
- **要点**：由三边长求面积，先求半周长 `p`，再对 `p*(p-a)*(p-b)*(p-c)` 开方。`p` 必须写成 `(a+b+c)/2`，漏括号就变成只除后面一项。开平方须引入 `math.h` 并使用 `sqrt()`，其原型参数与返回值都是 `double`。求一元二次方程的根需先求判别式 Δ = b²-4ac，Δ&lt;0 无实根；GCC 编译还要追加链接数学库的参数 `-lm`。
- **关键概念**：`海伦公式`、`sqrt`、`math.h`、`判别式`、`-lm`
- **出处**：强哥 P88；升本啦 P7, P10

## 十四、选择结构

### if 语句、真假判断与多分支
- **要点**：形式 `if (表达式) 语句;`，括号须是圆括号，表达式非零即真、为真才执行，为假跳过；表达式可为关系、逻辑、赋值、算术表达式乃至变量常量。`if (表达式) 语句1 else 语句2` 两条分支必执行其一，`else` 后不带表达式。`if ... else if ... else` 依次判断多种情况；前面分支已穷尽其他可能时最后的 `else` 无需再写条件。典型应用：判断三边能否构成三角形，任意两边之和大于第三边，三个条件用 `&&` 连接。
- **关键概念**：`if`、`else`、`else if`、`复合语句 {}`
- **出处**：鹏哥 P30；升本啦 P6, P7；强哥 P98, P99, P100

### if/else 控制多条语句需加大括号
- **要点**：默认 `if`、`else` 只能控制一条语句，多写的语句不受条件约束、无条件执行。要让多条语句一起受控须用 `{}` 括成语句块；`else` 前有多条语句却不加大括号会直接编译失败。语句组只有一个语句时可不加大括号。
- **关键概念**：`大括号`、`语句块`、`复合语句`
- **出处**：鹏哥 P30；升本啦 P6, P7

### 悬空 else 与 if-else 嵌套配对
- **要点**：`else` 总是与离它最近的、尚未匹配的 `if` 配对，与缩进无关。把 `else` 与外侧 `if` 对齐书写会造成严重误导；想让 `else` 与外层 `if` 匹配，需用 `{}` 把内层 `if` 隔开。`if-else` 组合可整体视为一条语句。做题先划清各 if 的范围、从内向外配对，某条分支执行后其余分支不再执行。
- **关键概念**：`悬空 else`、`就近匹配`、`嵌套`
- **出处**：鹏哥 P30；升本啦 P10；强哥 P102, P103

### switch 语句
- **要点**：用于「判断条件有多个结果」的场景，语法 `switch(表达式){ case 值: 语句; ... default: 语句; }`，按取值进入对应 `case`，都不匹配走 `default`。表达式与 `case` 后的常量只能是整型或字符型（字符即其 ASCII 码），不能是浮点型；`case` 后不能是变量；各 `case` 值必须互不相同；`default` 可省略、最多一个、位置任意，但程序总是先与所有 case 逐一匹配。
- **关键概念**：`switch`、`case`、`default`、`整型常量表达式`
- **出处**：鹏哥 P34；升本啦 P10；强哥 P108, P111, P114

### switch 中的 break 与 case 穿透
- **要点**：`case` 只起定位符作用，只比较一次，定位后顺序往下执行，匹配后不写 `break` 会继续向下执行后面所有分支，称穿透；每条分支只执行自身逻辑时须加 `break`。多个 `case` 标号可共用同一段语句组，写法是连续列出、中间不写语句和 break，两个 case 之间的语句归属于上一个 case。典型应用分数等级判定：用「分数 / 10」保留十位再与 case 匹配可大幅简化，90 分及以上可用 case 9、case 10 共用语句。
- **关键概念**：`break`、`穿透`、`共用语句组`、`分数/10`
- **出处**：鹏哥 P34；升本啦 P10；强哥 P109, P110, P112, P115

### switch 的嵌套与常见错误
- **要点**：switch 内可再写 switch，内层 `break` 只终止它所属的那一层（就近原则），外层无 break 时继续穿透。常见错误：`case` 常量值重复（`97` 与 `'a'` 视为相同）；`default` 写多个；`case` 后写变量或浮点型。
- **关键概念**：`嵌套 switch`、`就近原则`、`唯一性`
- **出处**：强哥 P113, P114

### 选择结构的典型题型
- **要点**：① 找程序错误：语句间误用逗号、漏写分号、多语句缺花括号。② 补充程序：三个数从小到大输出，套路是两两比较交换——先保证 a 最小，再保证 b 小于 c。③ `switch` 输出结果题：注意 `case` 穿透与 `default` 位置。④ 判断程序功能：如 `if(y<0) y=-y;` 配合输出即求绝对值。
- **关键概念**：`交换`、`穿透`、`判别式`
- **相互关系**：两两比较交换是后续数据结构中冒泡排序的基础。
- **出处**：升本啦 P7, P10

## 十五、循环结构

### 循环结构的组成与终止
- **要点**：同类重复操作若把每一步写死并不现实，必须用循环让同一段代码反复执行。循环结构由循环体、循环控制条件、控制变量的初值与每轮变化构成。控制变量必须每轮更新，否则形成死循环（如 `while(1)`）；算法要求有穷性，故循环必须有终止条件。
- **关键概念**：`循环体`、`循环控制条件`、`控制变量`、`死循环`
- **出处**：升本啦 P11；强哥 P117, P124

### while 循环
- **要点**：语法与 `if` 高度相似，区别是 `if` 只执行一次、`while` 会反复回到条件判断。先判断括号内表达式，为真才执行循环体，执行完回到表达式重新判断，为假则跳出，故最少执行 0 次。循环变量初始化须写在 `while` 之前，改变变量值的语句须写在循环体内，否则成死循环；循环体多于一条语句要用 `{}` 括起。括号内允许写赋值表达式，先赋值再判断其值，如 `while(m=0) m=m-1;` 循环体一次也不执行。
- **关键概念**：`while`、`条件表达式`、`循环变量初始化`、`赋值表达式`
- **相互关系**：与 `for` 的差别是 `for` 把初始化与增值放进括号；与 `do-while` 的差别是判断在循环体之前。
- **出处**：鹏哥 P35, P36；升本啦 P12；强哥 P118, P121

### do-while 循环
- **要点**：`do { 语句 } while(表达式);` 先无条件执行一次循环体再判断，为真回到循环体、为假结束，故循环体至少执行一次；`while(表达式)` 之后必须有分号，`do` 不能单独使用；循环体多条语句要加 `{}`。与 `while` 的根本区别就是最少执行次数（1 次与 0 次）。
- **关键概念**：`do-while`、`至少执行一次`、`while 后的分号`
- **出处**：鹏哥 P38；升本啦 P13；强哥 P118, P121；一灯 P2, P3

### for 循环
- **要点**：`for(表达式1; 表达式2; 表达式3)`：1 是初始化、只在开始时执行一次；2 是判断、非零才进入循环体；3 是调整、在每轮循环体之后执行。执行顺序为先表达式 1（仅一次），再判断表达式 2，为真则执行循环体，然后执行表达式 3，再回到表达式 2 判断；循环结束时循环变量的值正是使条件不成立的那个值。三部分都可省略（分号不可省），省略判断部分则恒成立成死循环，省略调整部分循环变量不变也易死循环；表达式 1、3 可为逗号表达式。C99 允许在初始化部分定义循环变量，作用域限于该循环。
- **关键概念**：`for`、`执行顺序`、`死循环`、`逗号表达式`
- **出处**：鹏哥 P37；升本啦 P14, P16；强哥 P122, P123

### 三种循环的比较与场景选择
- **要点**：`while` 的初始化、判断、调整三部分分散在代码各处，代码量大时不便维护；`for` 把三部分集中在头部。不知道要循环多少次（由条件驱动）用 `while`，循环次数明确用 `for`；`for` 功能最全面，可完全替代 `while` 与 `do-while`，反之不成立，`do-while` 不一定能替代 `while`。`while`、`do-while` 所用变量必须在循环前初始化，`for` 可在表达式 1 中初始化。
- **关键概念**：`for`、`while`、`do-while`、`正常结束`
- **出处**：鹏哥 P37；升本啦 P16；强哥 P117, P124

### break 语句
- **要点**：用于永久地、彻底地终止循环。一旦执行循环立即跳出，后面无论还剩多少次都不再执行，程序继续执行循环之后的代码；转到循环之后的下一条语句。只能用于 switch 和三种循环、不能单独使用；常用于查找成功后提前退出。与 `continue` 的「只跳过一次」形成对比。
- **关键概念**：`break`、`永久终止`
- **出处**：鹏哥 P39；升本啦 P14, P16；强哥 P125, P126, P127

### continue 语句与三种循环中的差异
- **要点**：只跳过本次循环中位于它后面的代码，随后进入下一次循环，循环本身不终止。`while` 中跳到条件判断，若 `i++` 写在 `continue` 之后会被跳过、循环变量不变而陷入死循环；`for` 中先跳到表达式 3（调整部分），`i++` 仍会执行；`do-while` 中同样易死循环。两者嵌套时都遵循就近原则、只作用于所在那一层。
- **关键概念**：`continue`、`跳过本次`、`循环判断处`、`就近原则`
- **出处**：鹏哥 P39；升本啦 P14, P16；强哥 P125, P126, P127

### 循环嵌套
- **要点**：一个循环的循环体内又出现循环即嵌套，分外循环与内循环。三种循环可互相嵌套；外层每执行一次，内层都要完整执行一轮；外层执行 m 次、内层每次执行 n 次时，内层语句共执行 m×n 次。一层循环搞不定的复杂问题往往需两层甚至三层嵌套；考试一般不超过两层。分析时先划清各循环的范围（花括号），不要依赖缩进。
- **关键概念**：`嵌套循环`、`外层循环`、`内层循环`、`m×n`
- **相互关系**：嵌套是二维数组遍历与冒泡、选择排序的基础。
- **出处**：鹏哥 P40；升本啦 P15；强哥 P124

### goto 语句
- **要点**：可在同一函数内跳到设置好的标号处，标号写成 `标号:`、跳转写作 `goto 标号;`。可向后跳（会造成死循环）也可向前跳。随意跳转会打乱执行流程，一般不建议使用；它擅长的场景是多层嵌套循环一次性跳出全部循环。
- **关键概念**：`goto`
- **出处**：鹏哥 P41

### 累加求和与求奇数和的两种写法
- **要点**：累加器变量必须先清零（`sum = 0`），循环变量控制项数并逐步递增，循环体中写 `sum = sum + i`（可写 `sum += i`）再让 `i++`；`i<=100` 与 `i<101` 等价。求 1~100 的和（5050）、任意输入若干个数求和、求 1~n 的和都是同一套路。求奇数和：写法一让循环变量每次加 2（从 1 到 99）直接累加；写法二每次加 1 遍历，用 `if` 判断对 2 取余是否为 1 再累加；前者循环次数少一半且省去判断，效率更高。
- **关键概念**：`累加器`、`初值 0`、`步长`、`循环次数`
- **出处**：升本啦 P11–P14；强哥 P119, P120, P121

### 累乘求阶乘
- **要点**：用累乘代替累加，结果变量初值必须为 1，循环变量从 1 开始每次乘入结果变量，直到不超过 n；求 1×3×5×…×11 只需把步长由加 1 改为加 2。n 较大时结果会溢出，可改用双精度类型。
- **关键概念**：`累乘器`、`初值 1`、`阶乘`、`步长`
- **相互关系**：与累加求和的差别只在初值与运算符；易错点——循环条件写 `<` 还是 `<=` 会导致少乘最后一项。
- **出处**：升本啦 P4, P13, P14, P15

### 求最值及其下标
- **要点**：先把首元素（或默认值）放入 `max`，此后每读入一个数就与 `max` 比较，更大则更新。若同时要下标，应让 `max` 记录下标而非值，比较时用 `a[max]`，更新时写 `max=i`。
- **关键概念**：`max`、`下标变量`、`a[max]`、`max=i`
- **相互关系**：只记录最大值会丢失下标信息；该写法与顺序查找思路一致，且不增加时间复杂度。
- **出处**：升本啦 P14, P17

### 求整数位数与逆序打印每一位
- **要点**：求位数：用计数器 `count` 初始为 0，反复用 `num = num / 10` 消去最低位并 `count++`，直到 `num == 0`，计数即为位数；因任何整数至少有一位、循环体至少要执行一次，故适合用 do-while。逆序打印每一位：`n % 10` 取出最低位并打印，`n /= 10` 去掉最低位，循环条件用 `n != 0`（或直接写 `n`），直到 n 变为 0 结束。
- **关键概念**：`计数器`、`num / 10`、`%`、`/=`
- **出处**：强哥 P128；鹏哥 P36, P38

### 水仙花数
- **要点**：三位水仙花数满足「各位数字的立方和等于该数本身」。拆位：个位 `num % 10`、十位 `num / 10 % 10`、百位 `num / 100`。用 for 遍历 100 到 999 逐个判断输出；推广到四位（玫瑰数）等只需增加拆位并提高次方。
- **关键概念**：`水仙花数`、`拆位`
- **出处**：强哥 P129

### 穷举法（鸡兔同笼）
- **要点**：不列方程，让鸡的数量从 0 枚举到总头数，兔的数量由「总头数减鸡数」推出，逐个验证脚数是否等于给定值，相等则输出并 `break`。头数、脚数需先校验：脚数不能为负、不能为奇数、须落在 2h 与 4h 之间。
- **关键概念**：`穷举`、`枚举范围`、`合法性校验`、`break`
- **出处**：升本啦 P16

### 素数判断与优化
- **要点**：从 2 试除到 n-1，能整除即非素数；判断整除必须用取余等于 0。优化：①`flag` 标记法，先假设是素数、发现能整除就置 0 并 break；②跳过偶数，除 2 外素数都是奇数，外层从 101 开始每次 `+2`；③只试到根号，因子成对出现且必有一个不超过 √i，内层条件写 `j <= sqrt(i)`，需包含 `<math.h>`。找出 100~200 之间素数的写法：外层 for 产生待判数字 i，内层 for 产生 2~i-1 的除数 j，若 `i % j == 0` 立即 `break`；内层结束后若 `i == j`，说明 i 是素数。易错点：不可写成「某个 j 不可整除就是素数」。
- **关键概念**：`素数`、`试除法`、`break`、`flag`、`√n`
- **相互关系**：把试除范围从 2~n-1 缩小到 2~√n，即降低时间复杂度的手段。
- **出处**：鹏哥 P40；升本啦 P4

### 闰年判断与区间内三的倍数之和
- **要点**：闰年判断有两条规则：能被 4 整除且不可被 100 整除，或能被 400 整除，两条件为逻辑或关系，用逻辑操作符表达为 `(year % 4 == 0 && year % 100 != 0) || year % 400 == 0`。求区间内满足条件数字的累加和：for 产生全部数字，`if(i % 3 == 0)` 判断后累加，需循环 100 次外加 100 次判断。
- **关键概念**：`闰年判断`、`%`、`&&`、`||`、`累加`
- **出处**：鹏哥 P32, P37；升本啦 P4；强哥 P92–P95

## 十六、函数与递归

### 函数的概念、特性与设计原则
- **要点**：函数是完成某项特定任务的一小段代码，function 意为「功能」，译成「子程序」更贴切；大任务可拆成若干小函数，实现代码复用、便于修改与维护。两大特性是封装与复用；函数像工厂——参数是原材料、函数体是加工过程、返回值是产品。设计遵循简单化原则：单一职责、参数不超过 3~4 个、避免修改全局变量、返回值明确、命名自解释。
- **关键概念**：`function`、`子程序`、`封装性`、`复用性`、`模块化`
- **出处**：鹏哥 P53, P55, P59；升本啦 P20

### 函数的定义、声明与分类
- **要点**：定义包含函数类型（返回类型）、函数名、参数类型与参数名、函数体，函数首部末尾不加分号；返回类型省略时默认为 `int`，无返回值时用 `void` 且可不写 `return`。若函数定义写在调用它的代码之后，编译器自上而下扫描时「没见过」它，会报未定义错误；解决办法是在使用之前写函数声明——把函数名、参数、返回类型照抄一遍、末尾加 `;`。定义写在调用之前则无需额外声明。按来源分库函数与用户自定义函数；按参数分有参与无参；按返回值分有返回值与无返回值。
- **关键概念**：`函数首部`、`函数体`、`返回类型`、`函数声明`
- **出处**：鹏哥 P60；升本啦 P20, P21, P24

### 形参和实参、形参的实例化
- **要点**：调用时真实传入的叫实参，定义中括号里的叫形参，类型、个数与顺序须匹配。只定义不调用时形参不申请内存；只有调用过程中为存放实参的值才申请空间，称形参的实例化，调用结束后立即释放。形参有独立空间、是实参的临时拷贝，故修改形参不影响实参——这是「函数内交换两数不成功」的根源。
- **关键概念**：`实参`、`形参`、`形参的实例化`、`临时拷贝`
- **相互关系**：C 中实参向形参传递的是值，形参值的变化不影响实参。
- **出处**：鹏哥 P56；升本啦 P21, P22

### 函数的调用过程
- **要点**：程序从 `main` 开始执行，遇函数调用则暂停 `main`、转去执行被调函数；被调函数执行完（遇 `return` 或到函数体末尾）返回 `main` 继续执行。有返回值的函数要用同类型变量接收返回值。
- **关键概念**：`main`、`函数调用`、`return`、`返回值`
- **出处**：升本啦 P20, P21

### return 语句与返回值
- **要点**：`return` 后可是数值，也可是表达式（先求值再返回）；`return;` 表示不返回值，适用于 `void` 函数。`break` 只跳出当前循环、循环之后的代码仍会执行；`return` 直接从函数返回，后续代码一律不再执行，作用强度大于 `break`。返回值与返回类型不一致时按返回类型隐式转换（`int` 函数 `return 3.5` 得 3，直接截断）；函数含 `if/else` 分支时须保证每种情况都有 `return`，否则警告「不是所有的控件路径都有返回值」。不写返回类型时默认按 `int` 处理；写了返回类型却无 `return`，返回值未知。
- **关键概念**：`return`、`void`、`隐式转换`、`未知返回值`
- **出处**：鹏哥 P57

### 嵌套调用与链式访问
- **要点**：函数之间可互相调用即嵌套调用，多个函数像乐高零件一样组合完成大型程序。把一函数的返回值作为另一函数的参数称链式访问，如 `printf("%d", strlen("abcdef"))`。`printf` 返回本次打印的字符个数，这正是 `printf("%d", printf("%d", 43))` 输出 4321 的原因。
- **关键概念**：`嵌套调用`、`链式访问`、`返回值`
- **出处**：鹏哥 P59

### 数组传参的规则
- **要点**：数组传参传的是数组名（首元素地址），不可写成 `arr[10]`；形参写成数组形式（`int x[]`）但不指定长度，且通常需把元素个数一并传入，因函数内部无法知道数组长度。形参不创建新数组，形参与实参数组的首元素占用同一地址，故函数内修改数组会直接改变原数组、不需返回值也能改。把数组元素（如 `a[0]`、`a[i]`）作实参传递，与传递普通变量没有区别，都是单向的值传递。
- **关键概念**：`数组名`、`首元素地址`、`地址传递`、`元素个数参数`
- **相互关系**：与「数组元素作参数」是两条不同规则，容易混淆。
- **出处**：鹏哥 P58, P111；升本啦 P22

### 一维与二维数组形参的省略规则
- **要点**：一维数组做形参时数组大小可省略，写任何值都不影响结果；二维数组做形参时行可省略、列不可省略，因一行有多少个元素须交代清楚。大小可省略正说明形参处不真正创建数组。
- **关键概念**：`一维数组形参`、`二维数组形参`、`行`、`列`
- **出处**：鹏哥 P58

### 用数组存每月天数
- **要点**：把 12 个月的天数存入数组，并在下标 0 处多放一个 0，使下标与月份直接对应，查某月天数时直接用 `days[m]`；只有闰年的 2 月需特殊处理（天数加 1）。
- **关键概念**：`数组`、`下标与月份对应`、`闰年`
- **出处**：鹏哥 P59

### 递归的定义与思想
- **要点**：递归是一种描述与解决问题的方法，在 C 中体现为函数自己调用自己（直接或间接）。核心思想是「大事化小」：把大型复杂问题层层转化为与原问题相似但规模更小的问题求解，直到子问题不可再拆解。递归的「递」指递推、「归」指回归。函数调用遵循先进后出（压入栈内存、执行完毕出栈），栈内存因此得名。
- **关键概念**：`递归`、`递推`、`回归`、`大事化小`、`栈内存`
- **相互关系**：递归的执行过程是栈 LIFO 特性的直接体现；树的遍历将大量依赖递归。
- **出处**：鹏哥 P74, P75, P76；逊哥 P6；升本啦 P22

### 递归的两个必要条件
- **要点**：一是递归存在限制条件（终止条件），满足时不再继续；二是每次递归之后都越来越接近这个限制条件。二者缺一不可，否则无限递归。这是判断递归写法是否正确的标准。
- **关键概念**：`限制条件`、`逼近`、`必要条件`
- **出处**：鹏哥 P74, P75

### 栈溢出
- **要点**：每次函数调用都会在栈区申请空间（函数栈帧），递归时前一次调用尚未返回、空间一直被占用，只有开始回归才逐层释放；层次过深会把栈区耗尽，出现栈溢出（stack overflow），程序异常退出而非正常返回 0。这是递归使用不当最常见的问题。
- **关键概念**：`栈区`、`栈溢出`、`函数栈帧`
- **出处**：鹏哥 P74, P77

### 递归与迭代
- **要点**：同一问题（如求阶乘）递归与循环都能写。迭代就是循环，只调用一次函数，资源占用少、效率高；递归代码简洁但有函数调用开销，层次过深可能栈溢出。取舍原则：两者都无明显问题时任选；递归简单且无明显缺陷时可用递归；递归有明显缺陷（效率低、可能栈溢出）时须改用迭代。
- **关键概念**：`递归`、`迭代`、`运行时开销`
- **出处**：鹏哥 P76, P77

### 递归求 n 的阶乘与 1 到 n 的和
- **要点**：先推导递推公式——n 大于 0 时 n 的阶乘等于 n 减一的阶乘乘以 n，n 等于 0 时阶乘为 1。写成函数即参数为 0 返回 1，否则返回「n 减一的阶乘乘 n」，函数内部调用了自己。1 到 n 求和写作 `f(n) = f(n-1) + n`、出口 `f(1) = 1`，一路压栈到出口取得确定返回值再逐层出栈回代。执行过程分递推（n 不断减小直到出口）与回归（逐层把结果返回上去）两个阶段。
- **关键概念**：`阶乘`、`递归函数`、`出口条件`、`出栈回代`
- **出处**：鹏哥 P75；逊哥 P6；升本啦 P22

### 顺序打印整数的每一位
- **要点**：把整数按从左到右逐位打印。最低位最容易取得（对 10 取余），故把问题拆成「先打印前面所有位」加「打印最后一位」，前面所有位通过对 10 取整得到。写成函数：数字大于 9 时先递归打印除 10 后的结果、再打印对 10 取余的结果；小于等于 9 时直接打印。打印语句在递归调用之后，故真正输出发生在回归阶段。
- **关键概念**：`递归`、`取余`、`取整`、`回归`
- **出处**：鹏哥 P76

### 斐波那契数列：递归与迭代
- **要点**：前两项为 1，此后每项等于前两项之和，可照公式直接写递归函数（`n <= 2` 返回 1，否则返回前两项递归结果之和）。但递归会展开成二叉树式调用、出现大量重复计算，求第 50 项已无法在可接受时间内完成。迭代从前往后用三个变量滚动（`last1`、`last2`）：先由前两数算出第三数，再把第二数挪给第一数、第三数挪给第二数；循环条件写 `n >= 3`，每轮 `n--`，结束时返回第三个数。易混点——重复计算不等于栈溢出，该递归始终单支深入、深度最多 n 层；栈溢出源于「一直递推不回归」。
- **关键概念**：`斐波那契数列`、`重复计算`、`变量轮换`、`last1`、`last2`
- **出处**：鹏哥 P78；逊哥 P6

### 递归经典问题：青蛙跳台阶与汉诺塔
- **要点**：青蛙一次可跳 1 级或 2 级，问跳到第 n 级的跳法数。只看最后一步，它只能从第 n-1 级或第 n-2 级跳上来，故 `jump(n) = jump(n-1) + jump(n-2)`，本质是斐波那契数列，只是起始值不同（`jump(1) = 1`、`jump(2) = 2`）。汉诺塔：借助 B 柱把 A 柱上的 n 个盘子整体移到 C 柱，任意时刻大盘不可压在小盘上。
- **关键概念**：`子问题`、`斐波那契数列`、`汉诺塔`、`子问题划分`
- **出处**：鹏哥 P79

## 十七、数组

### 数组的概念与一维数组的创建
- **要点**：数组是一组相同类型元素的集合，用同一个名字和不同下标区分元素，元素个数不可为 0。创建语法 `类型 数组名[常量值];`，方括号中的常量值指定元素个数，必须是正整数常量表达式，不能是变量或浮点数。「有序」指元素在内存中占用连续存储单元、前一个紧挨后一个，并非指数值已排好序；下标从 0 开始。
- **关键概念**：`数组`、`数组名`、`下标`、`连续存储`
- **出处**：鹏哥 P44；升本啦 P17；强哥 P131, P132

### 一维数组的初始化
- **要点**：用大括号把初值括起、逗号隔开。完全初始化时初值个数与元素个数一致；不完全初始化时剩余元素默认补 0；初值多于容量报「初始项太多」。一旦初始化，数组大小可省略、由初值个数决定，故只写一个初值时数组就只有 1 个元素；既未初始化又未赋值的元素值不确定。
- **关键概念**：`完全初始化`、`不完全初始化`、`补 0`、`省略长度`
- **出处**：鹏哥 P44；升本啦 P17

### 数组的类型与 sizeof 求元素个数
- **要点**：数组也有类型，判断规则是「去掉数组名，剩下的就是类型」，如 `int arr[10]` 的类型是 `int[10]`，`int` 只是元素类型；元素个数不同则数组类型不同。`sizeof(arr)` 是整个数组的字节数，`sizeof(arr[0])` 是单个元素的字节数，相除即元素个数，结果用 `%zu` 打印。
- **关键概念**：`数组类型`、`int[10]`、`sizeof`、`%zu`
- **相互关系**：`int a[8]` 得到 `a[0]`~`a[7]` 共 8 个 int 元素、占 8×4=32 字节（32 位机）。
- **出处**：鹏哥 P44, P47；逊哥 P1, P2；强哥 P131, P132

### 一维数组的下标、遍历与内存存储
- **要点**：下标从 0 开始，n 个元素的最后一个下标为 n-1，`arr[i]` 可读可改。用 for 产生 0~n-1 的下标即可遍历：输出 `printf("%d ", arr[i])`，输入 `scanf("%d", &arr[i])`。易混点——数组名代表地址不需取地址，但 `arr[i]` 是元素，scanf 时仍须写 `&`。用 `%p` 打印 `&arr[i]` 观察地址：一维数组元素连续存放，`int` 相邻元素地址相差 4，随下标增长由低到高；连续存放是指针能顺藤摸瓜访问数组的前提。
- **关键概念**：`下标`、`遍历`、`&arr[i]`、`%p`、`连续存放`
- **相互关系**：引用时下标可以是变量（常配合循环），但必须是整型、不能是浮点型，且只能逐个引用、不能整体引用；定义时下标必须是常量，这是两者的关键区别。
- **出处**：鹏哥 P45, P46, P49；强哥 P133

### 二维数组的创建与初始化
- **要点**：创建语法 `类型 数组名[行常量][列常量];`，第一个常量表示行（一维数组的个数），第二个表示列。初始化有完全、不完全（按行顺序紧挨着填、剩余补 0）、按行（每行各用一个 `{}`）三种。初始化时行可省略、由初值个数和列数推导；列不可省略，否则无法确定如何分行填入，如 `int arr[][5] = {1, 2}` 只有一行。
- **关键概念**：`二维数组`、`按行初始化`、`省略行`、`列数`
- **出处**：鹏哥 P48；升本啦 P18；一灯 P2

### 二维数组的下标、输入输出与按行存放
- **要点**：行列下标都从 0 开始，锁定行列即唯一确定元素，`arr[2][4]` 是第 3 行第 5 列。用嵌套 `for`，外层控行、内层控列，每打印完一行用 `\n` 换行。输入时对每个元素取地址 `&arr[i][j]`，`scanf` 会跳过空格与换行，可一次性连续读入。物理上按行连续存放，可看作「一维数组的数组」，每一行本身就是一个一维数组，该行的数组名就是 `arr[0]`、`arr[1]`，再用 `arr[i][j]` 访问行内元素。
- **关键概念**：`行下标`、`列下标`、`&arr[i][j]`、`按行存放`、`arr[i]`
- **出处**：鹏哥 P49；升本啦 P18

### C99 的变长数组与其编译器支持
- **要点**：数组长度用变量指定，长度在运行时才能确定，故不可初始化；「变长」只表示长度由变量指定，创建后大小不可再变。VS 默认的 MSVC 不支持，可装 C++ Clang 工具组件并把「平台工具集」切到 Clang；GCC 与牛客、洛谷等平台默认支持。
- **关键概念**：`变长数组`、`C99`、`MSVC`、`Clang`
- **出处**：鹏哥 P50

### 数组名的理解与数组降级
- **要点**：数组名是首元素的地址，即 `arr` 等价于 `&arr[0]`，定义后不可更改，属地址常量，不能整体赋值。两个例外：`sizeof(数组名)` 中数组名表示整个数组、求出整个数组的字节数；`&数组名` 中数组名也表示整个数组、取出整个数组的地址。`&arr[0]`、`arr`、`&arr` 打印值相同，但 `+1` 效果不同——前两者跳过 4 字节（一个 int），`&arr + 1` 跳过 40 字节（整个数组），原因是 `&arr` 的类型是数组指针。
- **关键概念**：`数组名`、`sizeof(arr)`、`&arr`、`地址常量`、`数组降级`
- **出处**：鹏哥 P109, P111, P128；一灯 P1, P3

### 二维数组传参的本质
- **要点**：二维数组的首元素是第一行这个一维数组，故数组名是「第一行的地址」。形参写成二维数组同样只是易读，本质是数组指针 `int (*arr)[5]`，指向第一行。`arr[i][j]` 等价于 `*(*(arr+i)+j)`：`arr+i` 按行偏移，解引用后得到第 i 行的数组名（该行首元素地址），再 `+j` 解引用取出元素。
- **关键概念**：`数组指针`、`int (*arr)[5]`、`*(*(arr+i)+j)`
- **出处**：鹏哥 P117

### 一维数组 sizeof 的分析套路
- **要点**：先看该处数组名有无「单独」放进 `sizeof` 或前面带 `&`：是则算整个数组大小（元素个数 × 元素大小），否则按首元素地址处理。`arr+0` 不算单独，仍是首元素地址；`*arr`、`arr[0]` 是首元素本身；`arr+1`、`arr[1]` 是第二个元素的地址。二维数组的数组名代表整个数组；其首元素是「第一行这个一维数组」，故 `a` 表示首元素地址时就是第一行的地址，类型为数组指针；`a+1` 跳过一行，`*(a+1)` 等价 `a[1]`。
- **关键概念**：`sizeof(arr)`、`sizeof(arr+0)`、`sizeof(&arr)`、`*(a+1)`
- **出处**：鹏哥 P128, P129, P131

### 字符数组的 sizeof 与 strlen 差异
- **要点**：`char arr[] = {'a','b',...}` 无 `\0` 时，`sizeof(arr)` 等于字符个数，而 `strlen(arr)` 会越界向后找 `\0`、结果是随机值；`arr` 与 `arr+0` 传给 strlen 结果相同（都从同一位置向后数），而 `sizeof(arr+0)` 算的是地址大小。`strlen` 只适用于字符串或字符数组，整型数组不可用。
- **关键概念**：`\0`、`strlen`、`随机值`
- **出处**：鹏哥 P129

### 指针数组与多级指针综合题
- **要点**：`char *a[] = {...}` 是指针数组，元素类型为 `char*`，数组名 `a` 是首元素地址（二级指针）。`pa++` 会跨过一个 `char*` 元素并真实修改 `pa` 的指向；`cp[i]` 等价 `*(cp+i)`，`pp[-2]` 等价 `*(pp-2)`。含 `++`/`--` 的表达式按优先级逐步展开，且副作用会保留给后续步骤使用。
- **关键概念**：`指针数组`、`二级指针`、`pp[-2]`
- **出处**：鹏哥 P134

### 冒泡排序及其优化
- **要点**：核心思想是相邻两元素两两比较，不满足顺序就交换；每趟让一个元素落到最终位置，N 个元素需 N-1 趟，第 i 趟内部比较 N-1-i 对。既可从后向前把最小值顶到最前，也可从前向后把最大值顶到末尾，两种写法都正确；交换借助临时变量。优化可用 `flag` 标记本趟是否发生交换。
- **关键概念**：`冒泡排序`、`趟数`、`相邻比较`、`flag`
- **出处**：鹏哥 P112；升本啦 P17, P22

### 简单选择排序
- **要点**：每趟在未排序部分找出最小元素的下标 `min`，与未排序部分的第一个位置交换，再缩小待排区间重复；不做相邻两两交换，而是直接定位目标元素再交换。
- **关键概念**：`简单选择排序`、`min`、`交换`
- **出处**：升本啦 P17, P22

### 顺序查找与二分查找
- **要点**：顺序查找从首元素起逐个与目标比较，相等则记下下标并 `break`；下标变量初值设为 -1，循环结束仍为 -1 即「未找到」。二分查找要求数据有序，用 `low`、`high` 标记区间两端（`left = 0`、`right = 元素个数 - 1`），循环条件 `left <= right`；每轮 `mid = (left + right) / 2` 与目标比较，`arr[mid] < key` 则 `left = mid + 1`，`arr[mid] > key` 则 `right = mid - 1`，相等即找到并 `break`。易错点：求 `mid` 的语句须在循环内部；退出循环后 `left > right` 说明找不到。
- **关键概念**：`顺序查找`、`折半查找`、`left`、`right`、`mid`
- **出处**：升本啦 P17；鹏哥 P52

## 十八、字符与字符串

### 字符与字符常量
- **要点**：字符由单引号引起来（如 `'X'`），单引号引起来的叫字符常量；打印字符用 `%c`，可传字符本身也可传其 ASCII 码值。单引号是字符、双引号是字符串；字符以 ASCII 码值存储，归入整型家族。
- **关键概念**：`字符`、`字符常量`、`%c`
- **出处**：鹏哥 P7

### 字符分类函数族与字符转换函数
- **要点**：`ctype.h` 提供一组判断字符类别的函数，用法统一：参数是字符（实为 `int`，即其 ASCII 值），符合返回非零值、否则返回 0。`tolower`/`toupper` 把传入字符转成小写/大写后返回，对本身就是该大小写的字符不做改动；手写转换依据大小写字母 ASCII 值相差 32，但有库函数就不要自己手写。
- **关键概念**：`ctype.h`、`isalpha`、`isspace`、`toupper`
- **出处**：鹏哥 P135, P136

### strlen 的功能与 size_t 陷阱
- **要点**：`strlen` 统计参数字符串中 `\0` 之前的字符个数（不含 `\0`），参数为 `const char*`，返回值为 `size_t`（无符号）。字符串须以 `\0` 结尾，否则返回随机值。
- **关键概念**：`strlen`、`size_t`、`sizeof`
- **出处**：鹏哥 P127, P136；升本啦 P19；一灯 P1, P3

### strlen 的三种模拟实现
- **要点**：①计数器法：只要 `*p != '\0'` 就计数并 `p++`，最后返回计数；②指针相减法：保存首地址，让 p 走到 `\0` 处，用 `p - start` 得到元素个数；③递归法：`*s` 非 `\0` 时返回 `1 + my_strlen(s+1)`，否则返回 0，体现「大事化小」，面试常以「不创建临时变量」为由要求递归写法。参数用 `char*` 接收数组名，返回类型用 `size_t`；更完善的实现会加 `assert(p != NULL)` 做防御性检查，并在 `*` 左边加 const 保证不修改原字符串。
- **关键概念**：`计数器`、`指针-指针`、`递归`、`my_strlen`
- **出处**：鹏哥 P100, P107, P137

### strcpy 的使用与模拟实现
- **要点**：把 `source` 指向的字符串拷贝到 `destination` 指向的空间，连同 `\0` 一起拷贝，返回目标空间的起始地址。要求源字符串须有 `\0`，目标空间须足够大且可修改；数组名之间不可直接赋值。模拟实现一句 `while (*dest++ = *src++);` 即可同时完成拷贝与终止判断——赋值表达式的结果就是刚拷过去的字符，遇到 `\0` 时结果为 0 结束循环、`\0` 也被拷入；因 `dest` 会自增，需先用 `ret` 保存起始地址再返回。
- **关键概念**：`strcpy`、`while(*dest++ = *src++)`、`assert`
- **出处**：鹏哥 P138；升本啦 P19；一灯 P1

### strcat 的使用与模拟实现
- **要点**：把 `source` 的内容追加到 `destination` 末尾，从目标串的 `\0` 处开始覆盖，连同源串的 `\0` 一起追加，返回目标空间起始地址；结果存第一串。实现分两步：先循环让 `dest` 找到目标串的 `\0`，再用 `while (*dest++ = *src++);` 拷贝。注意事项：源串须有 `\0`，目标串也须有 `\0`（决定从哪开始追加），目标空间须足够大且可修改。
- **关键概念**：`strcat`、`追加`、`目标串的 \0`
- **出处**：鹏哥 P139；升本啦 P19；一灯 P1

### strcmp 的使用与模拟实现
- **要点**：从两串第一个字符起按字典序逐位比较 ASCII 值，相等则比下一位，直到出现不相等字符或两串同时到 `\0`。返回值：大于 0 表示前者大、等于 0 表示相等、小于 0 表示前者小；只保证符号，不一定恰好是 1 或 -1，因此不可用 `== 1` / `== -1` 判断。模拟实现：`while (*s1 == *s2)` 时继续找下一对，若相等且 `*s1 == '\0'` 则返回 0；循环退出说明不相等，返回 `*s1 - *s2`。
- **关键概念**：`strcmp`、`字典序`、`*s1 - *s2`
- **相互关系**：字符串不能用 `>`、`<`、`==` 直接比较，必须借助函数；使用这些函数需包含 `string.h`。
- **出处**：鹏哥 P140；升本啦 P19；一灯 P1

### strstr 的使用与模拟实现
- **要点**：在 `str1` 中查找 `str2` 第一次出现的位置并返回该位置的指针，找不到返回 `NULL`，使用前需判空；找到后以 `%s` 打印会从该位置一直输出到 `\0`。模拟实现用三个指针：`s1`/`s2` 始终保存两串起始位置不动，另设 `cp` 逐个位置试探能否匹配；外层 `while (*cp)` 控制起始位置后移，内层 `while (*s1 && *s2 && *s1 == *s2)` 逐字符匹配，内层退出后若 `*s2 == '\0'` 说明子串匹配完、返回 `cp`，否则 `cp++` 换起点。
- **关键概念**：`strstr`、`子串`、`cp 试探指针`、`KMP`
- **出处**：鹏哥 P142

### strtok 的使用与破坏性
- **要点**：按分隔符集合切分字符串，第二个参数是「所有可能分隔符组成的字符串」，其中每个字符都视为独立分隔符。首次调用传待切分字符串，之后每次传 `NULL` 表示继续切分同一串；返回当前子串起始地址，返回 `NULL` 表示结束。`strtok` 会直接修改原字符串——把找到的分隔符替换成 `\0`，故要保留原串需先拷贝一份再切分副本。连续多个分隔符被视为一个，不返回空字符串；首次调用就传 `NULL` 且无前序调用时行为未定义。
- **关键概念**：`strtok`、`分隔符集合`、`破坏性`
- **出处**：鹏哥 P143

### 长度受限的字符串函数
- **要点**：`strncpy(dest, src, num)` 最多拷贝 `num` 个字符：源串长度 ≥ `num` 时不主动补 `\0`；源串长度 &lt; `num` 时剩余部分用 `\0` 补齐凑够 `num` 个。`strncat` 按指定长度追加。`strncmp(s1, s2, num)` 只在指定长度内比较：两串整体不等但前 `num` 个字符相同时结果仍为相等；若比较到 `\0` 则按 ASCII 值判断（`\0` 最小）。
- **关键概念**：`strncpy`、`strncat`、`strncmp`
- **出处**：鹏哥 P141

### strerror、errno 与 perror
- **要点**：`strerror` 把错误码翻译成错误信息字符串并返回首字符地址。`errno` 是全局变量，程序启动时为 0，只有库函数出错时才被写入且总是最新值，只能翻译标准库函数的错误码。`fopen` 打开不存在的文件会返回空指针并设置 `errno`，配合 `strerror(errno)` 即可打印失败原因。`perror` 等价于 `printf` 加 `strerror`：先打印自定义字符串，再打印冒号和空格，最后打印错误信息；参数传空字符串则只打印错误信息。
- **关键概念**：`strerror`、`errno`、`perror`
- **出处**：鹏哥 P144

### memcpy 与 memmove
- **要点**：`memcpy` 按内存块拷贝，不关心类型，参数为目标地址、源地址、字节数，返回目标空间起始地址；参数与返回类型都写成 `void*`。模拟实现用 `while (num--)` 逐字节拷贝，`void*` 须强转 `char*`，且强转是临时的，需写成 `dest = (char*)dest + 1`；返回前用临时指针保存起始地址。它只负责不重叠内存，遇重叠结果未定义。`memmove` 参数、返回值与 `memcpy` 相同，但能正确处理重叠，模拟实现按地址相对位置定方向：目标地址小于源地址时从前向后拷、否则从后向前拷，起点用 `(char*)dest + num` 定位。
- **关键概念**：`memcpy`、`memmove`、`内存重叠`
- **出处**：鹏哥 P145, P146

### memset 与 memcmp
- **要点**：`memset` 以字节为单位把一块内存的前若干字节设成同一个值，参数为起始地址、值、字节数；设置时先把值转成 `unsigned char`。与按元素设置不同——整型数组设成 1 得不到全 1 元素，只有设成 0 才能得到全 0 元素。`memcmp` 按字节比较两块内存，最多比较指定字节数，比出大小即返回；返回小于 0、等于 0、大于 0，含义同 `strcmp`，参数用 `const` 修饰。
- **关键概念**：`memset`、`按字节设置`、`memcmp`、`按字节比较`
- **出处**：鹏哥 P147

### 字符数组与字符串
- **要点**：C 语言没有 string 类型，也没有字符串变量，用字符数组存放字符串。字符常量用单引号、占一个字节，是 ASCII 值；字符串常量用双引号，长度为字符个数（空串长度为 0），末尾由系统自动附加 `\0` 作结束标志。用字符串常量给字符数组赋值时，长度要多留一个位置放 `\0`；字符数组不能直接赋值，须用 `strcpy` 拷贝。
- **关键概念**：`char 数组`、`字符常量`、`字符串常量`、`\0`
- **相互关系**：高频考点——5 个字符的字符串占 6 个字节；`\0` 是字符串输出、求长度、比较等一切处理的依据。
- **出处**：升本啦 P5, P19；逊哥 P1, P2

### 字符数组的输入输出与空格串、空串
- **要点**：单个字符可用 `scanf("%c")`/`printf("%c")`，也可用 `getchar`/`putchar`，二者等效。整个字符串用 `%s` 输出时只写数组名，遇第一个 `\0` 即停止；用 `%s` 输入时以空格或回车结束，故输入的字符串不能含空格。空串没有任何字符、长度为零；空格串由空格组成、长度等于空格个数；两者不同，不能互相简称。
- **关键概念**：`%s`、`%c`、`getchar`、`putchar`、`空格串`
- **出处**：升本啦 P19；一灯 P3

### 常用字符串处理函数总览
- **要点**：使用前需引入 `string.h`。`strcat` 连接两个字符串，`strcpy` 复制字符串（可指定长度），`strcmp` 按 ASCII 值逐字符比较并返回差值，`strlen` 统计 `\0` 之前的字符个数，另有大小写转换函数。
- **关键概念**：`strcat`、`strcpy`、`strcmp`、`strlen`
- **相互关系**：字符串不能用 `>`、`<`、`==` 直接比较，必须借助函数。
- **出处**：升本啦 P19；一灯 P1

## 十九、数据在内存中的存储

### 大端字节序与小端字节序
- **要点**：内存以字节为最小单位，超过一字节的数据必然存在字节排列顺序问题。大端：低位字节存高地址、高位字节存低地址；小端相反。X86 是小端，部分 ARM、DSP、单片机为大端或可硬件选择；网络传输规定用大端。判断方法二：定义成员为 `char c` 与 `int i` 的联合体，两者共用同一块空间，给 `i` 赋 1 后读 `c` 判断是否为 1。
- **关键概念**：`大端字节序`、`小端字节序`、`(char*)&a`、`联合体`
- **出处**：鹏哥 P148, P149, P163

### IEEE 754 浮点数的表示与取出
- **要点**：任意二进制浮点数可写成 V = (-1)^S × M × 2^E，S 是符号，M 为有效数字且必为 1.xxxxxx 形式（1 ≤ M &lt; 2），E 是指数；float 为 1 位 S、8 位 E、23 位 M，double 为 1 位 S、11 位 E、52 位 M。存入时先转二进制，再写成 (-1)^S × 1.xxx × 2^E 得到 S、M、E：存 M 时省略小数点前的 1 以多存一位、提高精度；E 规定为无符号数，需加中间值修正——float 加 127、double 加 1023。
- **关键概念**：`IEEE 754`、`中间值修正`、`非规范化区间`
- **出处**：鹏哥 P152, P153, P154

### 浮点数不可精确保存与比较
- **要点**：十进制小数转二进制可能凑不齐，而 M 位数有限（float 23 位、double 52 位），超出部分被丢弃，故部分浮点数只能近似存储，`0.1 + 0.2 == 0.3` 为假。比较时用 `fabs` 求差并与误差 eps 比较，需引入 `<math.h>`。
- **关键概念**：`精度丢失`、`fabs`、`误差 eps`
- **出处**：鹏哥 P153, P154

### 取值范围导致的死循环与计数
- **要点**：`unsigned char i` 时 `for (i = 0; i <= 250; i++)` 条件恒成立而死循环；`unsigned int` 的 `for (i = 9; i >= 0; i--)` 也死循环，到 0 再减一变成极大正数。给 `char` 数组循环赋值 -1、-2、-3……时元素按「轮回」截断，`strlen` 统计到出现 0 为止的字符数。须结合类型取值范围而非数学数列求解。
- **关键概念**：`unsigned char`、`恒成立条件`、`截断`
- **出处**：鹏哥 P151

### 字节序与指针结合的计算题
- **要点**：`&a + 1` 跳过整个数组指向末尾，强转 `int*` 后减一解引用得最后一个元素；`(int)a + 1` 是把首元素地址当整数加一，只偏移 1 字节。套路是先按小端画出字节排列，再按指针类型判断访问宽度，最后还原十六进制值。题目限定 X86 小端；X64 下把 8 字节地址强转 4 字节 `int` 会截断地址导致崩溃。
- **关键概念**：`&a + 1`、`(int)a + 1`
- **出处**：鹏哥 P151

## 二十、指针

### 内存单元、编址与地址的硬件来源
- **要点**：内存被划为一个个大小为 1 字节的单元，每个单元的编号就是地址；编址让 CPU 能直接快速定位空间。编号不需存储——CPU 与内存经地址总线、数据总线、控制总线连接，读操作时分别发读请求、发地址、带回数据。
- **关键概念**：`内存单元`、`地址`、`字节`、`地址总线`
- **出处**：鹏哥 P94；逊哥 P1

### 指针与取地址操作符
- **要点**：内存单元的编号就是地址，地址就是指针；英文 pointer，故指针变量习惯以 p 命名。创建变量的本质是向内存申请空间，`int a = 10;` 申请 4 个字节。`&a` 取的是地址最小的那个字节的地址即起始地址；地址是十六进制数值，用 `%p` 打印。
- **关键概念**：`指针`、`pointer`、`&`、`%p`
- **出处**：鹏哥 P94, P95

### 指针变量与解引用操作符
- **要点**：指针变量专门存放地址，`int* p = &a;` 使 p 指向 a。类型要拆开理解：`*` 说明 p 是指针变量，前面的 `int` 说明它指向的对象是 int。定义指针时写在 p 旁的 `*` 只是类型的一部分，不是操作符；使用时 `*p` 才是解引用、按地址取值。赋值时类型必须与被指向变量一致。
- **关键概念**：`指针变量`、`int*`、`解引用`、`*p`
- **出处**：鹏哥 P96；一灯 P2；逊哥 P1, P2

### 指针变量的大小
- **要点**：指针变量的大小取决于存放地址所需的空间，与指针类型无关。32 位平台地址是 32 个比特位、指针变量为 4 字节；64 位平台为 8 字节。VS 中 X64 编译 64 位程序、X86 编译 32 位程序。
- **关键概念**：`sizeof`、`X86`、`X64`
- **出处**：鹏哥 P97

### 指针类型的意义与指针加减的步长
- **要点**：指针类型决定两件事。一是解引用权限：`int*` 解引用访问 4 字节、`char*` 只访问 1 字节，用 `double*` 解引用 4 字节的 int 会越界。二是加减步长：`int*` 加 1 跳过 4 字节、`char*` 加 1 跳过 1 字节。故 `p+1` 前进的字节数等于 `sizeof(*p)`：结构体指针 `+1` 跳过整个结构体，强转成 `long` 后 `+1` 只是数值加 1；平台会改变结构体大小，此类题须指定平台。
- **关键概念**：`解引用权限`、`步长`、`结构体指针`
- **出处**：鹏哥 P98, P132, P133；逊哥 P2

### void* 泛型指针
- **要点**：`void*` 是无具体类型的指针，可接收任意类型的地址，常用于函数参数以实现泛型效果。局限是不可直接解引用、也不可直接做加减整数运算，因无法确定要访问几个字节；需先强制类型转换成目标类型再使用。
- **关键概念**：`void*`、`泛型指针`
- **出处**：鹏哥 P98

### 指针 ± 整数、关系运算与用指针访问数组
- **要点**：对指向数组元素的指针加减整数结果仍是指针，`p + i` 就是下标 i 的元素的地址，`*(p + i)` 即可访问。地址是数值，故指针可比较大小（`>`、`>=`、`<`、`<=`、`==`、`!=`）；可用边界元素的地址作循环终止条件，取该地址不构成非法访问，只要不解引用它。`arr[i]` 与 `*(arr + i)` 完全等价，加法满足交换律故 `i[arr]` 也合法（不推荐）。数组名可不加 `&` 直接赋给指针，`p++` 移到下一元素、`*p` 取出当前元素值。
- **关键概念**：`p + i`、`*(p + i)`、`p++`、`arr[i]`
- **出处**：鹏哥 P99, P101, P110；逊哥 P2；一灯 P2, P5

### 指针 - 指针
- **要点**：两个指针相减得到它们之间元素的个数，结果是整数而非字节数；小地址减大地址得负数。前提是两指针指向同一块空间且类型相同，指向不同数组的相减无意义。典型应用是求字符串长度。同一差值用 `%d` 打印是十进制元素个数，用 `%p` 则按 16 进制地址形式打印同一串比特，需按平台补足位数、前导零不可省。
- **关键概念**：`指针差`、`元素个数`、`%d`、`%p`
- **出处**：鹏哥 P100, P133

### const 修饰变量与指针变量
- **要点**：const 表示常属性，被修饰的变量成为常变量、不可直接修改；常变量本质仍是变量，故不可用于指定常规数组的大小。修饰指针时以 `*` 为界：const 在 `*` 左边修饰 `*p`，即不可通过 p 改指向的内容、但 p 的指向可改；在 `*` 右边修饰 p，即 p 的指向不可改、但可通过 p 改内容；两边都加则都不可改。把常变量的地址交给指针再解引用修改会绕过限制；函数参数中常用 const 修饰 `*p` 表示只读不改。
- **关键概念**：`const`、`常变量`、`const int* p`、`int* const p`
- **出处**：鹏哥 P102, P103

### 野指针的成因与规避
- **要点**：野指针是指针指向的位置不可知、随机或不正确，本质是指向的空间不属于当前程序。三种成因：指针变量未初始化（局部变量未初始化时是随机值）；指针越界访问；指针指向的空间已被释放（如返回局部变量的地址）。`NULL` 本质就是 0，C 中定义为 `(void*)0`，空指针不可解引用。
- **关键概念**：`野指针`、`NULL`、`空指针`
- **出处**：鹏哥 P104, P105

### assert 断言
- **要点**：assert 是 `assert.h` 中的宏，接收一个表达式，运行时若为假就报错并终止程序，同时输出表达式、文件名和行号，为真则什么都不做，常用于使用指针前断言其非空。assert 能做的事 if 也能做，但 assert 可通过在包含头文件之前定义 `NDEBUG` 宏一键关闭，release 版本中编译器也会默认禁用。
- **关键概念**：`assert`、`断言`、`NDEBUG`
- **出处**：鹏哥 P106

### 传值调用与传址调用
- **要点**：写交换两个整型变量的函数，直接传变量本身（传值调用）时形参是实参的临时拷贝、有独立空间，函数内交换不影响实参；传变量的地址（传址调用）时形参用指针接收，通过 `*p1`、`*p2` 就能找到并修改主调函数中的变量。判断标准——只想使用外部变量的值就传值，想修改外部变量就须传地址。
- **关键概念**：`传值调用`、`传址调用`、`形参`、`实参`
- **相互关系**：动态内存、链表初始化中「函数内改指针本身」也依赖传址（二级指针）。
- **出处**：鹏哥 P108；逊哥 P2

### 指针遍历数组求最值（编程题套路）
- **要点**：用指针遍历数组求最大值时，先让指针指向首元素、以 `*p` 为最大值初值，再从第二个元素开始循环，每轮先 `p++` 再比较更新最大值。易错点是把输出写成 `*p`——循环结束时指针已到末尾，输出的是最后一个元素而非最大值。
- **关键概念**：`指针变量`、`*p`、`p++`、`最大值`
- **出处**：一灯 P5
