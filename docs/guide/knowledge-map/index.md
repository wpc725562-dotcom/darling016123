# 知识地图

> 从 24 门专升本网课（1526 个分P、约 470 小时）的 AI 字幕里，逐单元提炼并跨课程去重后得到的知识点地图。

## 这是什么

不是笔记，不是讲义，是一张**「这门考试到底要我会什么」的清单**。

做法是四步压缩：

| 步骤 | 输入 | 输出 |
|:---|:---|:---|
| 1. 切单元 | 1526 个分P 的字幕（766 万字符） | 79 个提炼单元 |
| 2. 逐单元提炼 | 79 个单元 | 2551 条知识点卡片 |
| 3. 按课程合并 | 18 门课的分段卡片 | 2210 条（课程知识大纲） |
| 4. 跨课程去重 | 2210 条 | **1157 条**（学科知识地图） |

第 4 步去重率最高：高数 7 门课讲的是同一份考纲，1337 条压到 549 条（去重 58.9%）。

每条知识点都带四项：**要点**（是什么/怎么用/为什么）、**关键概念**、**相互关系**（前置知识、易混点）、**出处**（UP主 + 分P，可回溯到具体视频）。

## ⚠️ 数据可信度（必读）

这张地图的原材料是 B 站 AI 字幕，而 **B 站的 `x/player/v2` 接口会返回不属于该视频的字幕轨**：
同一个分P 连请求 5 次，返回的字幕可能是火锅探店、篮球解说、iPhone 评测……而且 `code` 恒为 0，
从响应本身完全看不出异常，只有下载下来读内容才发现。

所以每条字幕都做了校验，**未通过校验的内容一律不进这张地图**：

| 状态 | 分P 数 | 说明 |
|:---|---:|:---|
| 校验通过 | 1379 | URL 路径含 `aid+cid` 不变量，内容与视频主题一致 |
| 内容复核捞回 | 49 | 不变量没匹配上，但内容与分P 标题、同课程语料高度吻合 |
| 人工复核捞回 | 6 | 判别器按标题重合度判成垃圾，逐页读原文后确认是真内容（学士帽高数 P52/P95/P101–P103/P107） |
| **剔除** | **92** | 内容是别的视频 / 该视频根本没有字幕轨 → 已从语料中删除 |

剔除的分P 大部分集中在 6 门课上（政治 5 门 + 英语 1 门），它们**整门课都没有可用字幕**：

- 政治 5 门（`BV1PRM26hEbk` 6 分P、`BV1TDj36dEdc` 5、`BV1xzBCBFExz` 6、`BV176gY6nEb3` 1、`BV1gh9MBkEEC` 1）—— 字幕内容分别是漫威影评、vivo 手机评测、儿歌、蚂蝗科普
- 英语 1 门（`BV1rg411h7Z1`，51 分P）—— 内容是笔记本维修、影评、政论

**所以本知识地图不含政治。** 政治要补，只能走 ASR 路线（本地已有 `BV1xzBCBFExz` 的音频）。

另外：字幕是语音识别产物，公式和代码常被写坏（「星号p」= `*p`、「百分号d」= `%d`）。
提炼时已按 C 语言/数学本意还原，但**拿不准的地方写的是文字描述而不是猜的公式** —— 遇到要点里
没有公式只有文字的地方，多半就是这种情况，建议对照教材确认。

## 怎么用

- **当清单用**：复习前扫一遍某章的知识点标题，能立刻说出要点的就跳过，说不出的点进去看。
- **当索引用**：`出处` 是「UP主 + 分P」，想听原讲解就按这个去对应视频里找。
- **当体检表用**：`相互关系` 里标出来的易混点，就是选择题最爱挖坑的地方。
- **别当教材用**：这里只有骨架和判定规则，没有推导过程。听讲解仍然要走
  [B站吸收规划](/guide/bili-plan/) 里的路径。

## 已知缺口

- **政治**：零可用字幕（见上）。
- **计算机的题**：知识地图给的是「要会什么」，不提供练习题。考纲 21 章里仍有
  **9 章完全没有题**（指针 / 结构体 / 文件 / 调试 / 图 / 查找 / 排序 / 算法概念 / 算法分析），
  其中指针、图、排序属重点以上。题库现状见笔记库 `资料/练习题题库资源地图-计算机.md`。
- **本页只是地图**：18 门课的**课程级大纲**（每门课的完整章节结构）留在本地
  `data/bili-analyze/_extract/_merged/`，未上线 —— 它比地图更细，但重复度高。
