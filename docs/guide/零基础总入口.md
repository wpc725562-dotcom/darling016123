## 三、零基础专用讲义（本站已写好的）

这几份是**专门为零基础写的**，不是课本摘抄，结构统一为「一句话记住 → 分节讲 → 自检题 → 易错对照表 → 答案」：

| [1.3b 格式化输入输出](/posts/computer/notes/1.3b-格式化输入输出-零基础) | `printf` 坑位数、`scanf` 为什么要 `&`、`getchar` 吃换行符 | 一个 `%` 对应一个客人，多出来的被扔掉 |
| [1.4a 选择结构 if 语句](/posts/computer/notes/1.4a-选择结构-if语句-零基础) | `if` / `else` / `else if` 阶梯、`=` 塞 vs `==` 问 | 只有 `0` 是假，其他任何数都是真 |
| [1.6a 数组](/posts/computer/notes/1.6a-数组-零基础) | 一排带门牌的格子、下标为什么从 0 开始、`sizeof` vs `strlen`、二维数组 | 5 个房间门牌是 0～4，**没有 a[5]** |
| [1.7a 函数](/posts/computer/notes/1.7a-函数-零基础) | 打包成按钮、`return` 只能带一个、值传递、**递归**、`static` | **C 是复印不是原件**——想改外面必须传地址 |

## 六、三个最容易踩的坑

::: danger 坑 1 · 拿"完善工具"当学习
本站、本地门户、Anki、笔记脚本都是**弹药，不是学习**。
判断标准很简单：**今天有没有交回一道题的答案？** 没有，就不算学习。
:::

::: danger 坑 2 · 用"正确率"判断自己懂了没
实测教训：某次小测 8 题数字 5/5 全对（81%），当事人仍然说「**这一部分还是看不下去**」。
**正确率抓不住"听不懂"。** 学完一节，请自己问一句：**这节里有没有哪句话我其实没看懂？** 有就说，不用做题证明。
:::

::: danger 坑 3 · 把课本页码当"我记得"
本站引用课本一律标**纸质书页码**（并括注 PDF 物理页）。
`textbook.mjs` 输出的是 **PDF 物理页**，**纸质书页码 = 物理页 − 17**。
凡是"我记得在第 N 页"的，都要当场查一遍才算数。
