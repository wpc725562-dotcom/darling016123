# 真题考频矩阵（2023 + 2024 实测）

> **方法**：对 2023、2024 两年《计算机基础与程序设计》真题原卷共 **90 道题**逐题标注考纲模块，按分值统计。
> **用途**：分配备考精力优先级、筛选外部资料。**不是押题工具。**

---

## 一、三个必须先建立的判断

### 判断 1：C 语言占 64.5%，数据结构只占 35.5%

网上流传「C 语言 45–50%、数据结构 50–55%」——**与真题严重不符**。两年实测：

| 分部 | 2023 | 2024 | 两年均值 | 占卷比 |
|:---|:---:|:---:|:---:|:---:|
| **C 语言** | 138 | 120 | **129** | **64.5%** |
| **数据结构** | 62 | 80 | **71** | **35.5%** |
| 合计 | 200 | 200 | 200 | 100% |

### 判断 2：传统难点（树图查找排序）只占 9.75%

| 模块 | 实测分值/卷 |
|:---|:---:|
| 树和二叉树 | 5.5 |
| 图 | 9.0 |
| 查找 | 3.0 |
| 排序 | 2.0 |
| **合计** | **19.5（9.75%）** |

而「循环 + 数组」两项就有 **64.5 分（32%）**。

> ⚠️ 零基础把精力砸在红黑树、图算法、快排优化上是**方向性错误**。

### 判断 3：数据结构部分考概念，不考算法实现

图只考 DFS/BFS 名称、有向图的度、连通图最少边数；树只考第 n 层结点数、完全二叉树叶子数。
**不考**最小生成树、最短路径、哈夫曼编码的算法细节。

## 三、两年重复考点（高置信度必考清单）

以下考点在 2023 与 2024 **两年均出现**，2027 年出现概率最高：

| 考点 | 2023 位置 | 2024 位置 | 备考要求 |
|:---|:---|:---|:---|
| **结构体成员在内存中的驻留** | 判断题 | 单选 10 | 背结论：所有成员一直驻留内存 |
| **栈的特点 / 栈队列是线性表** | 单选 + 判断 | 单选 18 | 后进先出；两者都是线性表 |
| **二叉树结点数计算** | 完全二叉树 12 结点求叶子数 | 第 3 层最多结点数 | 第 n 层最多 2^(n-1) |
| **折半查找** | 对查找表的要求 | 查找次数 | 必须键值有序的**顺序表** |
| **顺序表 / 链表的存储与操作** | 单选 3 题 | 单选 4 题 | 链表指针操作必须能默写 |
| **字符串函数** | 字符串连接函数 | strcmp 头文件 + strlen(strcpy) | 分清 strlen/strcat/strcpy/strcmp |
| **时间复杂度分析** | 双重循环复杂度 | 顺序表插入 + 时空复杂度关系 | 记常见操作的 O() 值 |
| **数组下标与地址** | scanf 输入数组 + 二维数组元素值 | 下标必须整型常量 + x 与 x[0] 地址 | 列数不可省；下标从 0 开始 |
| **运算符与表达式求值** | 逻辑表达式真值 | 关系表达式、整数除法取余、逗号表达式 | 整数除法截断；逗号取最后一个 |
| **循环结构（含自增自减）** | `i++<4` 循环次数 | `while` + `a++`；while 退出条件 | 前缀后缀区别 + 边界值 |
| **算法 / 程序的关系** | 程序一定是算法 | 算法特性说法错误项 | 算法有穷性 |

- 本矩阵基于 **2023、2024 两年**真题逐题标注（90 题）。样本量有限。

- 最终以广东省教育考试院当年发布的考试大纲为准。
