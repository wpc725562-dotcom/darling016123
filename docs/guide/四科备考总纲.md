### 一句话战略

1. **计算机一门占 40%** —— 它是**唯一的拉分杠杆**。200 分里丢 30 分，等于其他三科白考一门。
2. **高数时间占比（25%）高于分值占比（20%）** —— 因为它是**零基础最陡的坡**，但**边际收益最高**（从 30 分提到 70 分比英语从 70 提到 85 容易得多）。

4. **英语你有底子** —— 策略是**维持 + 作文模板**，不要挤占计算机和高数的时间。

#### ⚠️ 重点难点

**三个真正的坎**：

1. **指针**（第 ⑧ 模块）—— **分水岭**。指针不过，后面的结构体、链表、树全废。
   - 核心是搞清「**指针变量存的是地址**」，以及 `*` 的**两种身份**（定义时声明 / 使用时解引用）。
2. **递归**（第 ⑦ 模块）—— 想不清「栈帧怎么回退」。用「**递归三要素**」模板破。
3. **图 + 排序的手算**（第 ⑰⑲ 模块）—— 不考代码，但要求**手算过程正确**（Prim/Kruskal 的选边顺序、快排的一趟划分）。

**最容易丢分的地方**：

- **时间复杂度计算** —— 很多人靠「凭感觉」猜。用「**三步法**」（列表格 → 写结束条件 → 解方程）机械推导，见 [2.9 算法基本概念与分析](/posts/computer/notes/2.9-算法基本概念与分析)。
- **手写程序的语法细节** —— 应用题 30 分，能写出思路却因分号、类型、边界扣分。

#### 📖 学习要点

**按这个顺序走，别跳**：

```
1.1 → 1.2 → 1.3 → 1.4 → 1.5 → 1.6 → 1.7 → 1.8（★ 指针，最陡）
   → 1.9 → 1.10 → 1.11
   → 2.1 → 2.2 → 2.3 → 2.4 → 2.5 → 2.6 → 2.7 → 2.8 → 2.9
```

**三条铁律**：

1. **C 语言部分必须动手敲代码** —— 光看会「以为懂了」。每个语法点至少手写一遍。
2. **数据结构部分必须动手画图** —— 树、图的遍历过程在纸上画一遍，比看十遍讲解有用。
3. **指针卡住就停下补，不要硬往前冲** —— 带着「指针没懂」的债往后学，后面每一步都是双倍难度。

#### 🎯 核心知识点

| 优先级 | 知识点 | 说明 |
|:--:|:---|:---|
| 🔴 **地基** | **函数与极限** | 后面每一章都建立在极限上。**极限不过关，导数就听不懂** |
| 🔴 **主体** | **导数与微分** → **不定积分** → **定积分** | 三章连成一条主线，占分最大 |
| 🟠 进阶 | 微分方程、多元函数微分、无穷级数 | 计算题常客 |
| 🟡 常规 | 定积分应用、空间解析几何、重积分 | 综合题会用到 |

#### ⚠️ 重点难点

1. **最大的坎：极限**（第一章）
   - 它是**所有后续章节的语言**。第一章不扎实，第二章开始就是听天书。
   - **零基础的同学在这里停留 2–3 周是正常的**，不要因为「进度慢」焦虑而跳过。

2. **最容易丢分：计算量**
   - 8 道计算题 48 分，**每一步都要动手算到底**。
   - 常见失分：**算到一半嫌烦跳过**、**符号写错**、**漏掉定义域/绝对值**。

3. **零基础特有的坑**：
   - 把「看懂例题」当成「会做」—— 高数**必须合上书自己算一遍**。

#### 📖 学习要点

1. **严格按章号顺序**，绝不跳章。第一章 → 第二章 → 第三章 …… 第十二章。
2. **每章三步走**：
   - ① 看视频/教材**建立直觉**（这个公式在描述什么）
   - ② 把**例题合上自己算一遍**（算不出来就再看，再合上算）
   - ③ 做**课后习题**（教材习题 + 真题同型）
3. **每周末回看上一章的公式表** —— 高数的遗忘速度很快，靠**滚动复习**维持。

| **合计** | | | **100** | 120 min |

**词汇量要求**：认知 **3000 词** + 常用词组（来源：《高等职业教育专科英语课程标准（2021 年版）》附录词汇表）
**难度层级**：介于三级 ~ 四级之间

#### 🎯 核心知识点与重点

> 🔴 **分值之王：阅读（30）+ 完形（30）= 60 分，占总分 60%。复习重心先砸这两块。**

| 优先级 | 题型 | 说明 |
|:--:|:---|:---|
| 🔴 | **阅读理解** 30 分 | 决定英语及格与否 |
| 🔴 | **完形填空** 30 分 | 与阅读并列第一 |
| 🟠 | **语法填空** 15 分 | 广东新题型，专项突破 |
| 🟠 | **写作** 15 分 | **背模板最稳** |
| 🟡 | 短文造句匹配 10 分 | 送分区 |

#### 📖 学习要点

1. **词汇是底座** —— 3000 词没过，阅读和完形都做不动。用 Anki 每天滚动。
2. **阅读 + 完形占 60%** —— 每周至少 **2 篇阅读 + 1 篇完形**保手感。
3. **写作背模板** —— [作文模板](/posts/english/notes/writing)，考前默写 3 遍。
4. **新题型专项** —— [语法填空专项](https://www.bilibili.com/video/BV1Do4y1h7om)（B站，广东新题型基础 1）。

> ⚠️ **Anki 用法提醒**：当前 Anki 数据里「困难」按钮按到 **33.2%**，而「重来」只有 5.7% —— 这是**把普通词按成了难词**，会让排期越拉越长。正确做法：**只有真的想不起来才按「困难」**，能想起来就用「良好」。另外**新词 ≤ 20 个/天**。

## 五、最容易踩的坑

| # | 坑 | 正确做法 |
|:--:|:---|:---|
| 1 | **「完善工具式伪勤奋」** —— 花整天整理笔记、调工具，却不做一道题 | **工具是手段**。改任何工具之前先问：今天的学习落账了吗？ |
| 2 | **把「看懂」当「会做」** | 高数和计算机**必须合上书自己动手**（算一遍 / 敲一遍） |
| 3 | **跳章学** | 计算机跳指针 → 后面全废；高数跳极限 → 后面全废 |
| 4 | **看视频不计学习量** | 看视频必须**指定出口**（进哪篇笔记、做哪道题），否则不算学 |
| 5 | **政治主观题只看不写** | 每周至少**手写 1 道完整主观题** |
| 6 | **英语挤占主科时间** | 英语维持即可（15%），重心在计算机 + 高数 |
| 7 | **Anki 乱按「困难」** | 只有真想不起来才按困难；新词 ≤ 20/天 |
