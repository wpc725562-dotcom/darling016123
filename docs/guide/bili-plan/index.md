# 🎬 基于 B站视频内容的备考规划 · 总纲

> **这份规划要解决的问题**：B站上有海量专升本视频，但「收藏了」不等于「学到了」。
> 本规划把「刷视频」变成一条**有出口的流水线** —— 每条视频最终都要变成**笔记本里的一段可复习内容**，
> 或者变成**一道你做过的题**。中间没有第三种归宿。
>
> 建档：2026-09-18 · by 02 · 考试按 **2027-03-01** 计（建档日剩 **164 天**）

---

## 一、先说三条底线（不满足就不做）

这三条是这份规划跟「又一份收藏夹」的区别所在。**违反任何一条，本规划自动降级为伪勤奋。**

| # | 底线 | 反面（不许出现） |
|:--:|:---|:---|
| 1 | **每条视频必须指定一个出口** —— 出口只有两个：① 变成笔记里的一节 ② 变成错题本里的一题 | 「先收藏，以后看」 |
| 2 | **吸收 ≠ 抄写** —— 视频给的是「讲法」，笔记要落成「判据 + 例题 + 自测」 | 把逐字稿整段粘进笔记 |
| 3 | **看视频不计学习量** —— 只有做题和落账计入进度条 | 拿「今天看了 3 小时课」当学习成果 |

> 📌 第 3 条直接来自你自己的看板。`备考计划/学习进度看板.md` 里 09-08 写下的那句警告：
> **「完善工具式伪勤奋」** —— 09-17 那份 `目标分拆解-410.md` 也点名了「今天做的事全是改网站、修脚本、补文档，一件学习都没做」。
> **这份规划本身也是「弹药」，不是「战绩」。** 它只有在你去跑那条流水线的时候才算数。

## 二、方法论：B站资料的四步流水线

四科共用同一条流水线，只是「检索词」和「出口形态」不同。

### 第 1 步 · 找：三种检索途径，按优先级用

| 优先级 | 途径 | 怎么用 | 什么时候用 |
|:--:|:---|:---|:---|
| ⭐⭐⭐ | **站内搜索接口**（免签名，实测可用） | `x/web-interface/search/type?search_type=video&keyword=<关键词>` | 想要**多个候选**做对比时 |
| ⭐⭐ | **B站网页搜索** | 搜「省 + 专升本 + 科目」 | 想看弹幕/评论口碑、看合集结构时 |
| ⭐ | **已核验资源清单** | `docs/guide/bili-resources.md` | 只是要「一门课的系统课」，不想挑时 |

**检索词模板**（照抄改词即可）：

```
广东专插本 <科目> 真题 解析
广东专升本 <科目> 真题 逐题讲解
专升本 <科目> <章节名> 专项
<科目> <教材名> 第N版 配套
```

> ⚠️ **接口会限流。** 连续搜多个关键词时第三个常撞 `HTTP 412`。
> 脚本里已加 `tries=3 + sleep(3)` 重试，**手动搜索时也请每次间隔几秒**。

### 第 2 步 · 筛：五道筛子，按顺序砍

不要看播放量就决定。按下面顺序过筛，**任何一筛不过就换下一个候选**：

| 序 | 筛子 | 判据 | 淘汰信号 |
|:--:|:---|:---|:---|
| 1 | **对口** | 标题/简介里出现「广东」「专插本」「专升本」+ 你的科目 | 全国通用但通篇讲考研/期末 |
| 2 | **在考纲内** | 讲的内容能在官方考纲 21 模块 / 12 章里找到落点 | 讲考纲外的（如高数的格林公式、傅里叶） |
| 3 | **有题** | 每讲完一个概念**至少跟一道题** | 纯念 PPT、纯讲概念无例题 |
| 4 | **能取证** | 有字幕，或愿意被 ASR 转写（能落到文字） | 只有手写板书且画面糊到看不清 |
| 5 | **还能看** | 存活核验通过（`code=0`） | `62002 稿件不可见` = 已下架 |

> 🔴 **第 5 条必须实测，不能凭印象。** 2026-09-18 全量复核 16 条，**有 1 条已下架**
> （数据结构「基础篇」）。BV 号永久有效，**视频不是**。

### 第 3 步 · 吸收：视频 → 笔记（这一步是自动的）

本机已有自研流水线，**零第三方依赖**：

```bash
# 一条龙：BV号 → 元数据 + 逐字稿 + 画面帧
python scripts/bili_analyze.py <BV号> --pages 1-3 --out data/bili-analyze/<任务名>

# 只想要元数据 / 分P 列表
python scripts/bili_fetch.py <BV号>
```

产出结构：

```
data/bili-analyze/<任务名>/
├── report.md            # 元数据 + 分P 表 + 帧索引
├── transcript_p01.md    # 第 1 个分P 的逐字稿（字幕或 ASR）
├── transcript_p02.md
└── frames/              # 按分钟抽的画面帧（板书截图）
```

**实测吞吐：8.3× 实时**（2346 秒的视频 → 4 分 42 秒跑完）。
所以「1 小时课」≈ **7 分钟**出稿。**这不是瓶颈，别拿它当借口。**

> 💡 **免 ASR 的捷径**：如果视频有 AI 字幕，扫码登录一次可直取字幕，跳过语音识别。
> `python scripts/bili_login.py`（30 秒，需手机扫一次码）。凭证落 `~/.bili-sessdata`，**已 gitignore**。

### 第 4 步 · 落：逐字稿 → 笔记（**这步只能人做**）

逐字稿是原料，不是笔记。**转化规则**：

| 逐字稿里有什么 | 笔记里落成什么 |
|:---|:---|
| 老师的口头讲解 | **判据**（一句能背的规则，如「加号站哪边，哪边先做事」） |
| 例题 | **例题 + 完整过程**（不是只留答案） |
| 「这个常考」 | 挂 **⭐ 权重标记** + 注明哪年真题考过 |
| 板书 | 抽出的**画面帧**贴进笔记对应位置 |
| 他说错的地方 | **不落**（但要记进 `备考计划/` 的教练侧订正） |

> 📌 **本库已有的成功案例**：政治 `17-辨析论述材料题模板.md` 的第五节「辨析题进阶：三种考法 × 两套步骤」
> 就是从 `BV176gY6nEb3`（欢姐 2025 辨析题讲解，7m34s）吸收来的 —— 53 秒出稿，读画面帧读出板书结构。
> **那就是这条流水线跑通的样子。**

## 三、这套规划在笔记本里的呈现结构

### 3.1 分类方式：三层

```
第一层 · 学科      计算机 / 高等数学 / 政治 / 英语      ← 与考试科目一一对应，不新造分类
第二层 · 用途      找资料 → 吸收 → 学科分析 → 学法 → 资源 → 动作
第三层 · 颗粒度    章节 / 考点 / 单条视频
```

**刻意不用的分类**：不按「UP 主」分、不按「播放量」分、不按「难度」分。
理由：你要找的是「**我这章不会，看哪个**」，不是「**那个 UP 主还有啥**」。

### 3.2 栏目设置：每科页面固定 6 栏

五份页面**栏目完全对齐**，这样你在四科之间切换时不用重新找位置：

| 栏 | 标题 | 内容 |
|:--:|:---|:---|
| 一 | **资料获取：来源 · 检索 · 筛选** | 这科去哪找、搜什么词、砍掉什么 |
| 二 | **吸收进笔记：流水线** | 这科的视频 → 这科的哪个目录（含具体命令） |
| 三 | **学科分析** | 知识体系框架 / 重点内容 / 常见考点 / 备考优先级 |
| 四 | **学习法引导卡** | 写进笔记、每天照做的那张卡 |
| 五 | **资源清单（实测）** | BV 号 + 实测时长 + 分P + 存活状态 |
| 六 | **下一步动作** | 按优先级排的可执行动作 |

### 3.3 目录框架

```
docs/guide/bili-plan/
├── index.md        ← 你在这里（总纲）
├── computer.md     ← 计算机（200 分）
├── math.md         ← 高等数学（100 分）
├── politics.md     ← 政治理论（100 分）
└── english.md      ← 英语（100 分）
```

**为什么放在 `guide/` 而不是 `posts/`**：`posts/` 是**知识内容**（学什么），`guide/` 是**方法与导航**（怎么学）。
本规划是后者。**它不产生知识，它指挥知识的产生。**

### 3.4 命名与标记规范

| 场景 | 规范 | 例子 |
|:---|:---|:---|
| 引用视频 | `[标题](https://www.bilibili.com/video/BV号)` + 括注实测时长/分P | `[真题合集](…)（145m · 5P）` |
| 视频在笔记里的落点 | 笔记底部加 `## 配套视频` 区块 | `- [BV1ajMo6TEBm P1~P2](…) —— 2.1 数据结构基本概念` |
| 考纲内权重 | `⭐` 一颗 = 常规，两颗 = 重点，三颗 = 必考 | `⭐⭐⭐ 二叉树遍历` |
| 未实测的东西 | 标 `⚠️ 未实测`，不许写成结论 | `⚠️ 未实测：该视频是否有字幕` |
| 已下架 | `❌ 已下架（code=62002 稿件不可见）` | 保留条目 + 补替代源，**不删** |

## 四、四科总表（先看这张，再进各科）

| 科目 | 满分 | 占比 | 当前进度 | 视频吸收的**主要出口** | 优先级 |
|:---|:--:|:--:|:--:|:---|:--:|
| **计算机** | 200 | **40%** | C 语言 **32%** · 数据结构 **0%** | ① 补 **2025 真题题面**（现 0 题）② 补 **9 章无题的练习缺口** | ⭐⭐⭐⭐⭐ |
| **高等数学** | 100 | 20% | **8%** | 真题**分类**密训（200P 逐题）→ 挂进对应章节笔记 | ⭐⭐⭐⭐ |
| **政治理论** | 100 | 20% | **0%** | 真题精讲 → 已有答题模板的**实例填充** | ⭐⭐⭐ |
| **英语** | 100 | 20% | **5%** | 真题全解析 → 阅读/完形/写作**题型打法** | ⭐⭐ |

> ⚠️ **四科都不能有短板。** 任何一科掉到 50%，就要靠另一科补 30 分 ——
> 而 200 分的计算机补 30 分 = 得从 85% 干到 100%。**不划算。**
> 正确策略是**每科都推到 80% 附近**，不是把一科推到满分。

### 为什么是这个优先级

1. **计算机 200 分是唯一能「多拿分」的科目** —— 考纲明确、题型固定、练到位就能拿高分。**它是主力。**
2. **高数是「拉分科」** —— 你现在的缺口是「会读符号、不会算结果」，这正是丢分的主要方式，补上就是净赚。
3. **政治投入产出比最高** —— 背诵为主，**但它的资源形态最特殊**：你缺的不是知识点，是**答题实例**。
4. **英语最难，但零基础也能拿基础分** —— 长期积累，靠 Anki 每天 15 分钟保鲜，**别指望短期暴涨**。
