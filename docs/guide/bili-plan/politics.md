## 四、学习法引导卡（照做，别想）

> 📌 **这张卡是给你「打开笔记本就知道干什么」用的。** 建议同时抄进 `docs/posts/politics/notes/index.md` 顶部。

### 每天开机三问

1. **今天我是「背」还是「答」？** —— 政治 60 分主观题，**只看不写 = 0 分**。
2. **这句是得分点还是背景？** —— 笔记只留**显眼包得分点**，背景一律砍。
3. **落账了吗？** —— 没写进 `备考计划/学习日志.jsonl` 的，等于没学。

### 政治的具体学法

| 规矩 | 说明 |
|:---|:---|
| **先框架后细节** | 不要死记硬背。框架比细节重要 —— 知道「这句话属于哪一块」比背住原话有用 |
| **关键词记忆法** | 每个要点记 3–5 个关键词，考场靠关键词展开 |
| **答题模板要「用过」才算会** | 模板看过 = 没用过。**必须动笔写一遍** |
| **多选题宁缺毋滥** | 20 分最容易丢。**不确定的不选**，选错倒扣的比漏选多 |
| **材料题必引材料原话** | 不引材料的答案，阅卷老师直接给低分 |
| **时政不提前背** | 考前 1 个月再上。提前背 = 白背（会过时） |

### 视频吸收纪律（针对本科）

- **真题精讲：先自己答，再听他讲** —— 尤其辨析题，**自己写 3 行再放视频**。
- **短专项优先** —— `BV176gY6nEb3` 只有 7m34s，**53 秒就能出稿**。低成本高回报。
- **只吸收「怎么答」，不吸收「知识点」** —— 知识点你笔记里已经有。
