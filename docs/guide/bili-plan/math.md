## 二、吸收进笔记：视频 → 笔记本的流水线

### 2.1 出口在哪

| 视频类型 | 落到哪 | 落成什么 |
|:---|:---|:---|
| **分类密训（逐题）** | 对应章节笔记 `docs/posts/math/notes/<编号>-*.md` | 例题 + **完整过程** + 挂考纲模块号 |

| **公式/技巧** | `docs/posts/math/公式速查卡.md` | 公式 + 使用条件 |

### 2.2 跑流水线的命令

```bash
cd D:/deeepseek/zhuan-sheng-ben-notes

# 真题分类密训：先跑第 1 个分P 试水（200P 不要一次全跑）
python scripts/bili_analyze.py BV12DdNYzEvy --pages 1 --chunk 300 --fpm 1.0 \
  --out data/bili-analyze/math-zhenti-ch1
```

- **`--fpm 1.0`（每分钟 1 帧）** —— 高数**必须看过程**，抽帧密度要比计算机高一倍。
- 200P 的合集**不要一次跑完**（会占掉几小时）。**按章跑**，跑一章吸收一章。

### 2.3 逐字稿 → 章节笔记的转化规则

**⚠️ 高数没有编译器，不能像 C 语言那样 gcc 实测。** 取证方式换成：

| 方式 | 怎么做 |
|:---|:---|
| **node 数值表** | 让计算机算一串值，**你自己看趋势**（如 $x\to0^+$ 时 $\frac{1}{x}$ 冲多大） |
| **特殊值回代** | 拿 $x=1$、$x=0$、$x=-1$ 代进结果，看是否成立 |
| **反向求导** | 积分结果求导，看是否回到被积函数 |

**转化时守三条**：

1. **过程必须完整落进笔记** —— 高数的价值在步骤，不在答案。**跳步的笔记等于没记。**
2. **每条结论标来源** —— 视频里讲的标 `[视频]`；你自己推的标 `⚠️ 我推的`；查不到课本全文的标 `⚠️ 推算`。
3. **例题挂在对应章节编号下** —— 这样「这章我做过几题」是可数的。

> ⚠️ **别把逐字稿整段粘进笔记。** 老师的口头语（「对吧」「我们来看」）全部要删掉，
> 只留**判据 + 步骤 + 例题**。

## 四、学习法引导卡（照做，别想）

> 📌 **这张卡是给你「打开笔记本就知道干什么」用的。** 建议同时抄进 `docs/posts/math/notes/index.md` 顶部。

### 每天开机三问

1. **今天这一节，考卷上有几分？** —— 先查真题关键词计数，别在 0 次的地方耗时间。
2. **我今天是「读」还是「算」？** —— **读笔记不产生分数。** 计算题 48 分 + 综合题 22 分 = **70 分是算出来的**。
3. **落账了吗？** —— 没写进 `备考计划/学习日志.jsonl` 的，等于没学。

### 高数的具体学法（已固化成教学纪律）

| 规矩 | 说明 |
|:---|:---|
| **符号先翻译成人话** | 09-07「符号盲区」：不认识 $\lim$ / $x\to$ 记号 → **数学语言扫盲优先于解题技巧** |
| **会读 ≠ 会算** | 09-09 的坑：`lim(x→∞) 1/x` 只把条件翻译成人话就停了，**没写出「=0」**。**结果必须写出来。** |
| **过程完整** | 只给答案不给过程 = 按错题重做（与 C 语言同一条判据） |
| **没有编译器就自己造证据** | node 数值表 / 特殊值回代 / 反向求导 —— **不许凭印象给答案** |
| **术语逐字符自检** | 09-09 把「无限」写成「无线」。**考场没有编译器替你报错。** |

### 视频吸收纪律（针对本科）

- **逐题讲解：看一题停一题** —— 先自己做，再听他讲。**直接听 = 白看。**
- **抽帧密度调到 1.0/分钟** —— 高数的板书就是步骤，抽太稀会丢过程。
- **分类密训按章跑** —— 跑一章吸收一章，别攒着。
