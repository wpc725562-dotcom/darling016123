## 四、学习法引导卡（照做，别想）

### 每天开机三问

1. **今天这一节，考卷上有几分？** —— 讲概念前先问权重，别在 0 分的点上耗半小时。
2. **我今天手推了几道？** —— **读笔记不产生分数。** 指针、图、排序、遍历序列，**全部要手推**。
3. **落账了吗？** —— 没写进 `备考计划/学习日志.jsonl` 的，等于没学。

### C 语言的具体学法（已固化成教学纪律）

| 规矩 | 出处 |
|:---|:---|
| **一次只交一个新概念**，一概念 → 一题 → 过了才给下一个 | 09-13 教学事故后立规（一次灌 9 个考点 → 三题全错） |
| **符号先翻译成人话**，再讲规则 | 高数「符号盲区」同理 |
| **能跑就 gcc 实测** —— 不许凭印象给答案 | 09-14 教练凭印象编错 2 处答案，已立规 |
| **判卷先看过程、后看数字** —— 只给数字没过程 = 按错题重做 | 09-10 #C002「答案从上一题借」 |
| **答案与理由打架 → 一律按未过** | 09-15 #C006（答案栏 `[A]`、理由栏推出 `[C]`） |

### 数据结构的具体学法

- **链表 / 树 / 图 一律画图再写代码。** 不画图直接写，是数据结构挂科的唯一原因。
- **排序算法用「手动跑一遍」记** —— 拿 8 个数自己走一遍快排，比背复杂度表管用十倍。
- **模板先背骨架，再填细节**：`2.4a`（KMP）· `2.5a`（遍历建树）· `资料/数据结构算法模板.md` 就是干这个的。

### 视频吸收纪律（针对本科）

- **真题讲解视频，看一题停一题** —— 先自己做，再听他讲。**直接听 = 白看。**
- **系统课只在「笔记看不懂」时回查** —— 不要从头刷 134P，那是给「没有笔记的人」准备的。
