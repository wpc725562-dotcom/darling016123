### 2.2 跑流水线的命令

```bash
cd D:/deeepseek/zhuan-sheng-ben-notes

# 真题全解析（8 个分P，先跑 P1）
python scripts/bili_analyze.py BV1jT4y1f7YA --pages 1 --chunk 300 --fpm 0.5 \
  --out data/bili-analyze/english-2021-zhenti
```

> ⚠️ **英语是四科里「逐字稿利用率最低」的一科。**
> 原因：英语课上大量内容是**老师在念英文原文**，逐字稿会变成一长串英文段落。
> **转化时只留「打法 + 陷阱」，不要留原文**（原文该进的是真题文件，不是笔记）。

### 2.3 逐字稿 → 笔记的转化规则

| 逐字稿里有什么 | 笔记里落成什么 | ❌ 不要落成 |
|:---|:---|:---|
| 「这类题先看首尾句」 | **打法**（可执行的步骤） | 泛泛的「要多读多练」 |
| 干扰项怎么设的 | **陷阱类型**（偷换概念 / 范围扩大 / 无中生有） | 单个单词的释义 |
| 作文范文 | **模板 + 得分点** | 整篇范文原文 |
| 老师念的英文原文 | ⚠️ **不落** —— 该进真题文件 | 一大段英文 |

> 📌 **英语笔记的质量判据**：拿这份笔记，**你能不能在做题时用上它**。
> 「知道了」不算，「做题时会想起来用」才算。

### 3.3 重点内容（按分值）

| 权重 | 题型 | 分值 | 说明 |
|:--:|:---|:--:|:---|
| ⭐⭐⭐ | **阅读理解** | 30 | 分值最高。**限时训练**（每篇 10 分钟内） |
| ⭐⭐⭐ | **完形填空** | 30 | 与阅读同分。**逻辑连接 + 固定搭配**是命门 |
| ⭐⭐ | **写作** | 15 | 约 100 词应用文。**格式 + 要点覆盖**是得分关键 |
| ⭐⭐ | 语法填空 | 15 | ⚠️ 分值待校准 |
| ⭐ | 短文造句匹配 | 10 | ⚠️ 分值待校准 |

> **阅读 + 完形 = 60 分**，是英语的绝对主体。**先把这 60 分的题型打法吃透，再管写作。**

### 3.4 🔴 真正的短板：Anki 在用错误的方式运行

看板 09-12 的实测数据（直读 `collection.anki2` 的 revlog，**不认自报**）：

| 项目 | 数值 | 判读 |
|:---|:---|:---|
| 词库总量 | 2230 张 | 已开课 991（**44.4%**）· 从未碰过 1239 |
| 今日到期 | 180 张 | 测量时**今日做题 0 次** |
| 逾期最久 | **22 天** | 最早一批到期卡拖了三周 |
| **困难按到** | **33.2%** | 🔴 **重来只有 5.7%** |
| 保留率 | 94.3% | 排期本身没坏 |
| 全历史正确率 | 61.2% | 近 7 天 2874 次、**54.2%**（**在往下掉**） |
| 平均单次耗时 | **3.7 秒** | 手很快，多半在「认脸」 |

**两条判读（都可核对）**：

1. 🔴 **困难按到 33.2%、重来只有 5.7% —— 你几乎没有「真忘掉」的词，是自己把词按成「难」的。**
   每点一次困难，Anki 就把这张卡的聪明值**永久砍一刀**，砍完它就被排得更频繁。
   **这是亲手制造假难词，不是记忆力差。**
   → 改法一句话：**想起来了就点「好的」，「困难」只留给「看了答案才想起来」的那种。**

2. 🔴 **开课率涨得太快**：09-10 的 40% → 09-12 的 44.4%，**两天涨约 100 张新词**（09-07 一天就开了 788 张）。
   全历史 **新学 : 复习 = 1.8 : 1**，而零基础建词库**这个比例应该反过来**。
   新词开太快 → 复习债滚成今天的 **180 张到期 + 22 天逾期**。
   → **药方**：先按每天 20–30 张清 22 天的欠账（约 41–62 天追上），期间**每天新词不超过 20 个**；
     **做完就收手，别为清库硬刷。**

> ⚠️ **英语的进度条只有 5%，而且这 5% 有一半是「认脸」刷出来的。**
> **先修 Anki 的用法，再谈吸收视频。** 用法不改，看多少视频都白搭。

### 3.5 备考优先级

```
第零优先（现在就做）：修 Anki 用法 —— 「困难」只留给真忘了的词；新词 ≤20/天
第一优先：一次限时真题实测，定「零基础还是非零基础」（见 1.1）
第二优先：阅读 + 完形（60 分）的题型打法 —— 从真题全解析里吸
第三优先：写作模板（15 分）—— 书信 / 通知 / 议论文各背一个
第四优先：词汇量校准（3000 / 3400 / 2230 三个数对不上，要查官方词汇表）
```

## 四、学习法引导卡（照做，别想）

> 📌 **这张卡是给你「打开笔记本就知道干什么」用的。** 建议同时抄进 `docs/posts/english/notes/index.md` 顶部。

### 每天开机三问

1. **今天我是「认脸」还是「记住」？** —— 3.7 秒一次的操作，**是认脸不是记忆**。
2. **今天有没有限时做一篇？** —— 英语不练阅读 = 白学。**每篇控制在 10 分钟内。**
3. **落账了吗？** —— 没写进 `备考计划/学习日志.jsonl` 的，等于没学。

### 英语的具体学法

| 规矩 | 说明 |
|:---|:---|
| **Anki 按钮纪律** | 想起来了点「好的」；「困难」只留给看了答案才想起来的。**别把词按成难词。** |
| **新词 ≤20/天** | 先把 22 天欠账清掉。**新学 : 复习 应该反过来。** |
| **阅读必须限时** | 每篇 10 分钟内。不限时的阅读练习，考场上用不上 |
| **完形抓两样** | 逻辑连接词 + 固定搭配。**这两样占完形的大头** |
| **作文背模板，但必须手写** | 书信 / 通知 / 议论文各一个。**背过 ≠ 写得出** |
| **真题至少做 2 遍** | 近 5 年真题。**第二遍要能说出每个干扰项错在哪** |

### 视频吸收纪律（针对本科）

- **英语逐字稿利用率最低** —— 只吸「打法 + 陷阱」，**不要吸英文原文**。
- **真题全解析：先做题，再听他讲** —— 尤其阅读，先自己选，再对答案。
- **找视频前先读 `避坑笔记-网课英语规划视频批判.md`** —— 别重复踩坑。
