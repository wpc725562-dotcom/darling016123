# 计算机程序设计 · 零基础教学课程大纲

> **老师寄语**：同学们好！我是你们的计算机老师。这门课的目标是带大家从 **完全零基础** 到 **能考过广东专升本计算机程序设计**。不需要任何编程经验，只要跟着我的节奏，一步一步来，一定能学会。

## 第一部分：C语言基础（第1-7课）

### 第1课：计算机是怎么工作的？
**目标**：理解计算机的基本工作原理，不写代码
- 计算机的组成：CPU、内存、硬盘、输入输出设备
- 程序是什么？— 就像一份菜谱
- 编译 vs 解释 — 翻译官的故事
- C语言的历史和特点
- 第一个程序：Hello World（跟着做就行）

### 第2课：变量——给数据贴标签
**目标**：理解变量是什么，怎么存数据
- 变量 = 带标签的盒子
- 数据类型：int（整数）、float（小数）、char（字符）
- 变量命名规则（不能数字开头，别用关键字）
- 赋值操作：等号不是等于，是放入
- 课堂练习：定义变量、赋值、输出

### 第3课：输入输出——让程序和人类对话
**目标**：学会接收用户输入和显示结果
- printf：向屏幕输出（格式化输出 %d %f %c）
- scanf：从键盘获取输入（别忘了取地址符 &）
- 转义字符：
（换行）、	（制表符）
- 常见错误：忘记 &、格式不匹配

### 第4课：运算符——让计算机做计算
**目标**：学会用运算符进行数学和逻辑运算
- 算术运算符：+ - * / %（整数除法要注意！）
- 赋值运算符：= += -= *= /=
- 关系运算符：> < >= <= == !=
- 逻辑运算符：&& || !（与或非）
- 运算符优先级口诀

### 第5课：选择结构——让程序会判断
**目标**：学会用 if-else 让程序做决策
- if 语句：如果...就...
- if-else：如果...否则...
- 多重 if-else if
- switch 语句：多路开关
- 条件表达式（三目运算符）
- 生活比喻：红绿灯、分岔路

### 第6课：循环结构——让程序重复干活
**目标**：学会用循环让计算机重复执行
- while 循环：先判断再执行
- do-while：先执行一次再判断
- for 循环：计数循环（最常用）
- break：跳出循环
- continue：跳过本次循环
- 循环嵌套：循环里面套循环
- 生活比喻：跑步绕圈、数数

### 第7课：数组——一堆同类型的变量
**目标**：学会用数组存一堆数据
- 数组是什么？— 一排带编号的柜子
- 一维数组：定义、初始化、访问
- 二维数组：表格数据
- 数组越界：小心别走出柜子
- 字符数组与字符串
- 字符串处理函数：strlen、strcpy、strcmp、strcat

## 第二部分：C语言进阶（第8-10课）

### 第8课：函数——把代码打包成积木块
**目标**：学会用函数组织代码
- 函数是什么？— 像乐高积木
- 函数的定义和调用
- 形式参数和实际参数
- 函数的返回值
- 局部变量和全局变量
- 变量的作用域和生命周期
- 数组作为函数参数

### 第9课：指针——C语言的灵魂
**目标**：理解指针的基本概念和用法
- 指针是什么？— 门牌号/地址
- 取地址符 & 和解引用符 *
- 指针变量：存地址的变量
- 指针和数组的关系
- 指针作为函数参数
- NULL 指针

### 第10课：结构体——把不同类型打包
**目标**：学会用结构体组织复杂数据
- 结构体是什么？— 像档案袋
- 定义和声明结构体
- 访问结构体成员（. 和 ->）
- 结构体数组
- 结构体指针
- typedef：给类型起别名

## 第三部分：数据结构入门（第11-12课）

### 第11课：数据结构基础概念
**目标**：理解数据结构的基本概念
- 程序和数据的区别
- 逻辑结构和存储结构
- 时间复杂度和空间复杂度
- 什么是算法

### 第12课：三大基本数据结构
**目标**：掌握线性表、栈、队列
- 线性表：顺序表 vs 链表
- 栈：后进先出（LIFO）— 像叠盘子
- 队列：先进先出（FIFO）— 像排队
- 树和二叉树：层级结构
- 查找算法：顺序查找、折半查找
- 排序算法：冒泡、选择、插入

## 教学方法说明

### 每节课的标准流程
1. **生活比喻引入**（5分钟）：用生活中的例子解释新概念
2. **概念讲解**（15分钟）：正式讲解知识点
3. **代码演示**（10分钟）：看代码，理解代码
4. **动手练习**（15分钟）：自己做题或写代码
5. **课后作业**（5分钟）：布置3-5道练习题
