## 巡检：链接还活着吗

BV 号永久有效，**但视频会下架**。定期跑一次存活巡检，别让死链烂在页面里：

```bash
python scripts/bili_audit_links.py                      # 默认扫本页
python scripts/bili_audit_links.py docs/guide/*.md      # 扫多个文件
python scripts/bili_audit_links.py --json audit.json    # 落机器可读结果
```

- 退出码 `0` = 全活，`1` = 有失效 —— 可直接接进 CI / 巡检机器人。
- 判据是接口的 `code`：`62002 稿件不可见` = 已下架/转私密；`-404` = BV 号不存在。
- 请求间隔 0.4s，零第三方依赖。
