# 录取分数线 · 省控线（2026 官方版 · 2027 届定位）

> 📅 数据来源：**广东省教育考试院 2026-05-07 公布**（2026 普通专升本招生最低控制分数线）
> 🎯 用途：定位要考到什么分数才**有资格报志愿**；热门院校实际录取线会**高于**省控线很多。
> 🔗 对应 Obsidian 源：`历年真题/04-录取分数线与考情.md`

## 一、双线制度（重要）

广东专升本实行 **双线**：须**同时达到**「三科总分线」和「专业综合课线」才具备填报志愿资格，过线后按**四科总分**从高到低录取。

| 组成 | 科目 | 分值 |
|:---|:---|:---:|
| 公共课 ① | 政治理论 | 100 |
| 公共课 ② | 英语 | 100 |
| 专业基础课 | 视专业（高数/管理学/大学语文/民法/教育理论/经济学/生态学/生理学/艺术概论） | 100 |
| 专业综合课 | 单独划线 | 200 |
| **合计** | | **500** |

> 三科总分 = 2 公共课 + 1 专业基础课。

## 三、2027 届要点

> 🎯 **如果你是考公办**：看本页掌握「入场资格」，但录取竞争请看 → [公办院校与录取](/guide/公办院校与录取)（2025 十五所公办名单 + 进退变化 + 公办备考定位）。

1. **省控线只是报志愿门槛**：考上≠能上，**热门公办实际录取线常高出省控线 100+ 分**。按**目标院校历年录取排位**备考，不是按省控线。**考公办尤其如此**（公办名额在缩、竞争更卷）。
2. **录取率约 48%**、报考人数连续三年下降——竞争进入**平稳期**，是近年较友好窗口。
3. **高等数学**（主攻专业基础课）：2026 省控线三科 105 / 综合 60，是 9 类里**最低挡之一**，更易过线，但高手竞争同样激烈。
4. 2027 年 5 月省考试院公布 2027 省控线；备考期关注**目标院校历年分数线**更关键。
