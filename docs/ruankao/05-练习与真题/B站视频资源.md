## 四、一个搜索技巧

B 站搜索结果里，**播放量 > 1 万**的通常是经过时间检验的。低于 1000 的，可能是刚发布还没被验证，也可能是质量一般。

**但反过来不成立**：播放量低不等于差。真题解析类视频本来就小众（只有考生看），几百播放很正常。

**判断质量的方法**：点进去看**前 3 分钟**，如果 UP 主在讲题而不是在卖课，就继续看。

## 五、和本地材料的配合

| 你在做什么 | 用哪个 |
|:---|:---|
| 做真题，对答案 | 本地 `真题\` 的 PDF |
| 某道题看不懂解析 | B 站真题解析视频，搜该年份 |
| 某个域完全不懂 | B 站系统课，找对应章节 |
| 下午场算法题不会 | 本地 `源代码\算法\` + 左程云视频 |
| 设计模式认不出 | 本地 `源代码\设计模式\` 的 24 个 Java 示例 |

**优先级**：本地 PDF > B 站视频。理由是视频不能搜索、不能跳读、要花时间看。只有"卡住了"才去看视频。
