## 三、核心内容蒸馏

### 3.1.1 线性表

#### 两种存储结构的对比（教材给了具体数字）

| | 顺序存储（数组） | 链式存储（链表） |
|:---|:---|:---|
| 存储 | 地址连续 | 地址不要求连续，靠指针连接 |
| 随机访问 | **O(1)** | O(n) |
| 插入 | 平均移动 **n/2** 个元素 | O(1)（已知前驱时） |
| 删除 | 平均移动 **(n−1)/2** 个元素 | O(1)（已知前驱时） |
| 空间 | 需预分配 | 有指针开销 |

**教材给出的精确数字**（这是考点）：
- 长度为 n 的顺序表，**等概率**插入时，平均移动 **n/2** 个元素
- 删除时，平均移动 **(n−1)/2** 个元素

**推导逻辑**：插入有 n+1 个位置，第 i 个位置插入要移动 n−i+1 个元素，求和平均得 n/2。删除有 n 个元素，删第 i 个要移动 n−i 个，平均得 (n−1)/2。

#### 链表的几种变体

| 类型 | 特点 |
|:---|:---|
| 单链表 | 只有 next 指针 |
| 双向链表 | prev + next，删除更方便 |
| 循环链表 | 尾节点指回头节点，**可从任意节点遍历全表** |
| 静态链表 | 用数组模拟，下标代替指针 |

**教材强调"头结点"的作用**：带头结点的链表，插入删除时**不需要特殊处理第一个位置**，代码更统一。

### 3.1.2 栈和队列

#### 栈（LIFO）

**教材列的应用**：表达式求值、括号匹配、递归实现、递归转非递归。

**顺序栈的两个状态**：
- 栈空：`top == -1`（或 `top == 0`，看约定）
- 栈满：`top == maxSize - 1`

#### 队列（FIFO）

**循环队列**（必考）：

教材用"牺牲一个存储单元"的方式来区分队空和队满：

| 状态 | 条件 |
|:---|:---|
| 队空 | `front == rear` |
| 队满 | `(rear + 1) % maxSize == front` |
| 元素个数 | `(rear − front + maxSize) % maxSize` |

**为什么要牺牲一个单元**：如果不牺牲，队空和队满都是 `front == rear`，无法区分。

**教材的另一种方案**：加一个计数器 count，就不用牺牲单元。但考试默认用"牺牲一个"的写法。

### 3.2 数组与矩阵

#### 多维数组的存储映射（偶尔考）

二维数组 `A[m][n]` 按行优先存储时，元素 `A[i][j]` 的地址：
**LOC(i,j) = LOC(0,0) + (i × n + j) × L**（L 是每个元素占的字节数）

按列优先则是 `(j × m + i) × L`。

#### 特殊矩阵压缩（考点）

| 矩阵类型 | 压缩方式 | 存储量 |
|:---|:---|:---|
| **对称矩阵** | 只存下三角（含对角线） | n(n+1)/2 |
| **三角矩阵** | 只存有值的那一半 + 一个常数 | n(n+1)/2 + 1 |
| **对角矩阵**（三对角） | 只存三条对角线 | 3n−2 |
| **稀疏矩阵** | 三元组表 (行, 列, 值) 或十字链表 | 取决于非零元个数 |

**对称矩阵的地址映射**（常考）：
元素 `a[i][j]`（i ≥ j，下三角）在一维数组中的下标 = `i(i+1)/2 + j`（从 0 开始）

### 3.3.2 二叉树的性质（★★★）

**教材给的五个性质**：

1. 第 i 层最多 **2^(i−1)** 个节点（根为第 1 层）
2. 深度为 k 的二叉树最多 **2^k − 1** 个节点
3. **n0 = n2 + 1**（叶子数 = 度为 2 的节点数 + 1）
4. n 个节点的完全二叉树深度 = **⌊log₂n⌋ + 1**
5. 完全二叉树中，节点 i 的左孩子 2i、右孩子 2i+1、父节点 ⌊i/2⌋

**性质 3 的推导**（教材有）：
- 总节点数 n = n0 + n1 + n2
- 总边数 = n − 1 = n1 + 2n2
- 两式联立得 n0 = n2 + 1

**这个推导要会**，因为题目可能变形问"n1 是多少"。

**注意**：性质 3 只适用于**二叉树**，不适用于一般树。

### 3.3.3 遍历（★★★）

| 遍历 | 顺序 |
|:---|:---|
| 前序（先序） | 根 → 左 → 右 |
| 中序 | 左 → 根 → 右 |
| 后序 | 左 → 右 → 根 |
| 层序 | 逐层，从左到右（用队列） |

**唯一确定一棵树的条件**（必考）：
- 前序 + 中序 ✅
- 后序 + 中序 ✅
- **前序 + 后序 ❌**（无法确定左右子树）

**解题方法**：前序的第一个（或后序的最后一个）是根，在中序里找到根的位置，左边是左子树、右边是右子树，递归。

**教材补充**：二叉排序树的**中序遍历是递增序列**，这是判断一棵树是否为 BST 的方法。

### 3.3.4 线索二叉树（★ 知道概念即可）

**解决的问题**：n 个节点的二叉树有 n+1 个空指针域，浪费。线索化把这些空指针利用起来，指向遍历的前驱/后继。

**三种线索**：前序线索、中序线索、后序线索（按线索化时用的遍历顺序命名）。

**标志位**：每个节点加 `ltag` / `rtag`，0 表示指向孩子，1 表示指向前驱/后继。

考试基本只考"线索二叉树的作用是充分利用空指针域"，不会考具体构造。

### 3.3.5 最优二叉树（哈夫曼树）（★★★）

#### 构造步骤（教材标准流程）

1. 把 n 个权值看成 n 棵单节点树，组成森林
2. **选两个权值最小的**合并成一棵新树，新根权值 = 两者之和
3. 从森林中删掉这两棵，把新树加入
4. 重复直到只剩一棵树

#### WPL（带权路径长度）

**WPL = Σ(叶子权值 × 该叶子的路径长度)**

**哈夫曼树的 WPL 是所有二叉树中最小的**，这是它叫"最优"的原因。

#### 哈夫曼编码

- 左分支记 0，右分支记 1
- 每个字符的编码 = 从根到该叶子的路径
- **没有任何编码是另一个的前缀**（前缀码），所以解码无歧义

**教材强调**：哈夫曼编码是**不等长编码**，频率高的字符编码短，频率低的编码长，从而让总编码长度最短。

#### 例（教材风格）

权值 \{5, 7, 2, 4\}：
1. 排序 \{2, 4, 5, 7\}
2. 合并 2+4=6 → \{5, 6, 7\}
3. 合并 5+6=11 → \{7, 11\}
4. 合并 7+11=18

WPL = 2×3 + 4×3 + 5×2 + 7×1 = 6+12+10+7 = **35**

### 3.4 图

#### 存储结构对比

| | 邻接矩阵 | 邻接表 |
|:---|:---|:---|
| 空间 | O(n²) | O(n+e) |
| 判断两点相邻 | O(1) | O(度数) |
| 适合 | **稠密图** | **稀疏图** |
| 求某点所有邻接点 | O(n) | O(度数) |

#### 遍历

| 遍历 | 数据结构 | 特点 |
|:---|:---|:---|
| **DFS** | **栈**（或递归） | 一条路走到黑，回溯 |
| **BFS** | **队列** | 一层层扩展 |

#### 最小生成树

| 算法 | 思路 | 适合 | 复杂度 |
|:---|:---|:---|:---|
| **Prim** | 从一个点出发，每次加**离当前树最近**的点 | **稠密图** | O(n²) |
| **Kruskal** | 每次选**全局最短**的边，不成环就加 | **稀疏图** | O(e log e) |

**教材强调**：最小生成树可能不唯一，但**总权值唯一**。

#### 拓扑排序（AOV 网）

用于有向无环图（DAG），表示活动间的先后关系。

**算法**：每次输出一个**入度为 0** 的节点，删掉它和它的出边，重复。

**判断有环**：如果最后还有节点没输出，说明图中有环。

#### 关键路径（AOE 网）（★★★）

**AOE 网**：边表示活动，顶点表示事件。

**四个参数**（教材标准定义）：

| 参数 | 含义 |
|:---|:---|
| **ve(j)** | 事件 j 的**最早**发生时间（从前往后推，取最大） |
| **vl(j)** | 事件 j 的**最晚**发生时间（从后往前推，取最小） |
| **e(i)** | 活动 i 的**最早**开始时间 = 弧尾的 ve |
| **l(i)** | 活动 i 的**最晚**开始时间 = 弧头的 vl − 活动持续时间 |

**关键活动**：`e(i) == l(i)` 的活动（时间余量为 0）。

**关键路径**：由关键活动组成的从源点到汇点的路径，**长度 = 最短工期**。

**计算技巧**（不用记公式也能算）：
- 从起点开始，每个节点取"所有前驱路径的最大值" = 最早时间
- 从终点倒推，每个节点取"所有后继路径的最小值" = 最晚时间
- 时差为 0 的连起来就是关键路径

#### 最短路径

| 算法 | 解决 | 限制 |
|:---|:---|:---|
| **Dijkstra** | 单源到所有点 | **不能有负权边** |
| **Floyd** | 所有点对之间 | 可有负权，不能有负环 |

**Dijkstra 的贪心本质**：每次选当前距离最小的未访问节点，用它更新邻居。

### 3.5 查找

#### 静态查找

| 方法 | 前提 | 平均查找长度 |
|:---|:---|:---|
| 顺序查找 | 无 | (n+1)/2 |
| **二分查找** | **有序 + 顺序存储** | log₂n |
| 分块查找 | 块间有序 | 介于两者之间 |

**二分查找的限制**（常考）：必须**顺序存储**（数组），不能是链表（无法 O(1) 定位中点）。

**二分查找判定树**：把每次的 mid 作为根，递归构建。查找成功的平均长度 = 各节点层数之和 / n。

#### 动态查找

| 结构 | 特点 |
|:---|:---|
| **二叉排序树（BST）** | 左 < 根 < 右；**中序遍历递增**；查找平均 O(log n)，最坏 O(n) |
| **平衡二叉树（AVL）** | 左右子树高度差 ≤ 1；四种旋转（LL/RR/LR/RL） |
| **B 树 / B+ 树** | 多路平衡查找树，用于磁盘索引 |

**AVL 的四种失衡及旋转**（教材有）：
- **LL 型**（左子树的左边插入）→ 右旋
- **RR 型**（右子树的右边插入）→ 左旋
- **LR 型**（左子树的右边插入）→ 先左旋再右旋
- **RL 型**（右子树的左边插入）→ 先右旋再左旋

#### 哈希表

**哈希函数构造**：除留余数法（`H(k) = k mod p`，p 取小于表长的最大质数）、直接定址法、平方取中法。

**冲突处理**：

| 方法 | 做法 | 特点 |
|:---|:---|:---|
| **线性探测** | 冲突后往后找下一个空位 | 会产生"堆积"（聚集） |
| **二次探测** | 按 1², −1², 2², −2² 探测 | 减少堆积 |
| **链地址法** | 同哈希值的元素挂成链表 | 不产生堆积，适合冲突多的场景 |

**装填因子** α = 元素数 / 表长。α 越大冲突越多，但**平均查找长度只与 α 有关，与表长无关**（这是教材的结论）。

### 3.6 排序（★★★ 三张表必背）

#### 完整对比表

| 算法 | 平均 | 最坏 | 最好 | 空间 | 稳定性 |
|:---|:---:|:---:|:---:|:---:|:---:|
| 直接插入 | O(n²) | O(n²) | **O(n)** | O(1) | ✅ |
| 希尔 | O(n^1.3) | O(n²) | O(n) | O(1) | ❌ |
| 冒泡 | O(n²) | O(n²) | **O(n)** | O(1) | ✅ |
| 快速 | O(n log n) | **O(n²)** | O(n log n) | O(log n) | ❌ |
| 简单选择 | O(n²) | O(n²) | O(n²) | O(1) | ❌ |
| 堆排序 | O(n log n) | O(n log n) | O(n log n) | **O(1)** | ❌ |
| 归并 | O(n log n) | O(n log n) | O(n log n) | **O(n)** | ✅ |
| 基数 | O(d(n+r)) | O(d(n+r)) | O(d(n+r)) | O(n+r) | ✅ |

#### 记忆要点

- **稳定的**：插入、冒泡、归并、基数 → **"插冒归基"**
- **不稳定的**：希尔、快速、选择、堆 → **"希快选堆"**
- **O(n log n) 的三种**：快排、堆排、归并
- **空间 O(1) 且 O(n log n) 的**：**只有堆排序**
- **最坏退化成 O(n²) 的 O(n log n) 算法**：**只有快速排序**
- **最好情况 O(n) 的**：直接插入、冒泡（原本有序时）

#### 各算法的适用场景（教材有）

| 场景 | 选择 |
|:---|:---|
| n 小（< 50） | 直接插入 |
| 基本有序 | 直接插入或冒泡 |
| n 大且要求稳定 | 归并 |
| n 大且要求原地 | 堆排序 |
| 找前 k 大/小 | 堆排序 |
| 数据是整数且范围小 | 基数排序 |

#### 外部排序（★ 知道概念）

数据量太大，内存装不下，需要借助外存。

**核心方法**：**多路平衡归并**
1. 先把大文件分成若干块，每块调入内存排序后写回（生成初始归并段）
2. 多路归并这些段

**k 路归并的趟数** = ⌈log_k m⌉（m 是初始归并段数）

**减少归并趟数的方法**：增大 k（路数）或减少 m（初始段数，用置换-选择排序）。

## 四、教材强调但容易忽略的

1. **顺序表插入平均移动 n/2，删除平均移动 (n−1)/2** —— 两个数字不一样，容易记混。

2. **性质 3 的推导过程**（n = n0+n1+n2，边数 = n−1 = n1+2n2）比结论本身更有用，因为题目会变形。

3. **对称矩阵的地址映射**：`i(i+1)/2 + j`，这个公式教材专门推导过，考试偶尔考。

4. **AVL 四种旋转的判断**：看"插入位置在失衡节点的哪一侧的哪一侧"，LL 右旋、RR 左旋、LR 先左后右、RL 先右后左。

5. **哈希表的平均查找长度只与装填因子有关**，与表长无关。这是反直觉的结论。

6. **外部排序的"多路归并"**：k 越大趟数越少，但每次归并的比较次数增加，存在最优 k 值。
