## 三、核心内容蒸馏

## 第一部分：计算机网络（D 域）

### 10.1 网络体系结构

#### OSI 七层 vs TCP/IP 四层

| OSI 七层 | TCP/IP 四层 | 典型协议 | 典型设备 | 数据单位 |
|:---|:---|:---|:---|:---|
| **应用层** | **应用层** | HTTP、FTP、SMTP、DNS | 网关 | 报文 |
| **表示层** | ↑ | JPEG、ASCII、加密 | — | — |
| **会话层** | ↑ | RPC、SQL | — | — |
| **传输层** | **传输层** | TCP、UDP | — | 段 |
| **网络层** | **网络层** | IP、ICMP、ARP | 路由器 | 包 |
| **数据链路层** | **网络接口层** | 以太网、PPP | 交换机、网桥 | 帧 |
| **物理层** | ↑ | RS-232、光纤 | 中继器、集线器 | 比特 |

**记忆口诀（从上到下）**：**应表会传网数物**

#### 各层功能（一句话）

| 层 | 一句话 |
|:---|:---|
| 物理层 | 传输**比特流**，定义电气和机械特性 |
| 数据链路层 | 成**帧**、差错控制、流量控制、MAC 寻址 |
| 网络层 | **路由选择**、IP 寻址、拥塞控制 |
| 传输层 | **端到端**的可靠传输（TCP）或无连接传输（UDP） |
| 会话层 | 建立、管理、终止会话 |
| 表示层 | 数据格式转换、加密解密、压缩 |
| 应用层 | 为用户提供网络服务 |

### 10.2 网络设备（必考）

| 设备 | 工作层 | 作用 | 隔离冲突域 | 隔离广播域 |
|:---|:---|:---|:---:|:---:|
| **中继器/集线器** | 物理层 | 信号放大 | ❌ | ❌ |
| **网桥/交换机** | 数据链路层 | 按 MAC 转发 | ✅ | ❌ |
| **路由器** | 网络层 | 按 IP 转发 | ✅ | ✅ |
| **网关** | 应用层 | 协议转换 | ✅ | ✅ |

**必记**：
- 集线器所有端口在**同一冲突域、同一广播域**
- 交换机每个端口是**独立冲突域**，但整个交换机是**一个广播域**
- 路由器每个接口是**独立广播域**

**这个"冲突域/广播域"的区分是每年必考的。**

### 10.3 TCP/IP 协议族

#### IP 地址（★★★）

**IPv4**：32 位，点分十进制。

| 类别 | 首字节 | 默认掩码 | 用途 |
|:---|:---|:---|:---|
| A | 1–126 | 255.0.0.0 | 大型网络 |
| B | 128–191 | 255.255.0.0 | 中型 |
| C | 192–223 | 255.255.255.0 | 小型 |
| D | 224–239 | — | 组播 |
| E | 240–255 | — | 保留 |

**私有地址**（内网，不路由到公网）：
- A：`10.0.0.0/8`
- B：`172.16.0.0/12`（172.16–172.31）
- C：`192.168.0.0/16`

**特殊地址**：
- `127.0.0.1` 回环
- 主机号全 0 = 网络地址，全 1 = 广播地址，**这两个不能分配给主机**

#### 子网划分（必考计算）

**可用主机数 = 2^(32−n) − 2**（n 是掩码位数）

**例**：`192.168.1.130/26`
- 主机位 6，每子网 64 个地址
- 130 ÷ 64 = 2 余 2 → 第 2 块（128–191）
- 网络地址 **192.168.1.128**
- 广播地址 **192.168.1.191**
- 可用范围 **.129–.190**
- 可用主机数 **62**

#### TCP vs UDP

| | TCP | UDP |
|:---|:---|:---|
| 连接 | 面向连接 | 无连接 |
| 可靠性 | 可靠（确认、重传、排序） | 不可靠 |
| 速度 | 慢 | 快 |
| 头开销 | 20 字节 | 8 字节 |
| 应用 | HTTP、FTP、SMTP | DNS、DHCP、SNMP、视频流 |

#### TCP 三次握手 / 四次挥手

**三次握手**（建立）：
```
客户端 → SYN(seq=x) → 服务器
客户端 ← SYN+ACK(seq=y, ack=x+1) ← 服务器
客户端 → ACK(ack=y+1) → 服务器
```

**为什么三次**：要双向确认双方的发送和接收能力。两次无法确认客户端的接收能力。

**四次挥手**（断开）：
```
客户端 → FIN → 服务器
客户端 ← ACK ← 服务器
客户端 ← FIN ← 服务器
客户端 → ACK → 服务器
```

**为什么四次**：TCP 全双工，两个方向要分别关闭。服务器收到 FIN 后可能还有数据要发，所以 ACK 和 FIN 分开。

**TIME_WAIT**：主动关闭方等待 **2MSL**。

#### 常用协议与端口（★★★ 必背）

| 端口 | 协议 | 说明 |
|:---:|:---|:---|
| **20/21** | FTP | 20 数据、21 控制 |
| **22** | SSH | 安全远程登录 |
| **23** | Telnet | 明文远程登录 |
| **25** | SMTP | 发邮件 |
| **53** | DNS | 域名解析 |
| **67/68** | DHCP | 服务器 67、客户端 68 |
| **80** | HTTP | 网页 |
| **110** | POP3 | 收邮件 |
| **143** | IMAP | 收邮件（更强） |
| **161/162** | SNMP | 网络管理 |
| **443** | HTTPS | 加密网页 |
| **3306** | MySQL | 数据库 |
| **3389** | RDP | Windows 远程桌面 |

### 10.4 Internet 服务

#### DNS 解析过程

- **递归查询**：客户端问本地 DNS，本地 DNS 负责问到底（客户端只问一次）
- **迭代查询**：本地 DNS 依次问根 → 顶级 → 权威，每次返回下一个该问谁

**通常**：客户端到本地 DNS 是递归，本地 DNS 到外部是迭代。

#### 网络命令

| 命令 | 作用 |
|:---|:---|
| `ping` | 测连通性（ICMP） |
| `tracert` | 追踪路由路径 |
| `netstat` | 查看连接、端口监听 |
| `nslookup` | 查询 DNS |
| `ipconfig` | 查看本机网络配置 |
| `arp` | 查看 IP-MAC 映射 |

## 第二部分：信息安全（I 域）

### 10.5 信息安全基础

#### CIA 三要素

| 属性 | 含义 | 被破坏 |
|:---|:---|:---|
| **机密性** | 不被未授权获取 | 数据泄露 |
| **完整性** | 不被未授权篡改 | 数据被改 |
| **可用性** | 授权者能正常使用 | DDoS |

**扩展**：可控性、不可否认性。

#### 安全威胁分类

| 类型 | 说明 |
|:---|:---|
| **被动攻击** | 窃听、流量分析（**不破坏数据**） |
| **主动攻击** | 篡改、伪造、重放、拒绝服务（**破坏数据或服务**） |

**被动攻击难检测但可预防（加密），主动攻击易检测但难预防。**

### 10.6 加密与认证（★★★）

#### 三类加密算法

| 类型 | 密钥 | 速度 | 算法 | 用途 |
|:---|:---|:---|:---|:---|
| **对称** | 加密解密**同一密钥** | 快 | DES、3DES、**AES**、RC4、IDEA | 大量数据加密 |
| **非对称** | **公钥加密、私钥解密** | 慢 | **RSA**、ECC、DSA | 密钥交换、数字签名 |
| **哈希** | **无密钥**，单向 | 快 | **MD5**、SHA-1、SHA-256 | 完整性校验 |

**必记对应**：
- DES：56 位，已被破解
- 3DES：DES 三次
- **AES：128/192/256 位，当前主流对称算法**
- **RSA：基于大数分解**，密钥长
- ECC：基于椭圆曲线，密钥短强度高
- **MD5：128 位，已可碰撞，不安全**
- SHA-256：当前安全

#### 数字签名（必考方向）

| 步骤 | 用什么 |
|:---|:---|
| **签名** | 发送方用**自己的私钥**加密摘要 |
| **验证** | 接收方用**发送方的公钥**解密 |

**记忆**：**私钥签名，公钥验证**。这和加密正好相反（公钥加密，私钥解密）。

**数字签名保证**：完整性 + 不可否认性（**不保证机密性**）。

#### 混合加密（HTTPS 的做法）

**用非对称加密传对称密钥，用对称加密传数据。**

原因：非对称太慢，不适合加密大量数据；但对称的密钥分发不安全。两者结合。

#### 数字证书与 PKI

**证书**由 **CA（证书授权中心）** 签发，包含：持有者信息、公钥、有效期、CA 的签名。

**作用**：解决"这个公钥是不是他的"（防冒充）。

**PKI 组成**：CA、RA（注册机构）、证书库、密钥备份恢复、证书作废系统。

### 10.7 网络安全

#### 常见攻击

| 攻击 | 原理 | 防御 |
|:---|:---|:---|
| **DoS/DDoS** | 大量请求耗尽资源 | 流量清洗、限速 |
| **ARP 欺骗** | 伪造 ARP 响应冒充网关 | 静态 ARP 绑定 |
| **SQL 注入** | 输入拼接进 SQL | **参数化查询**、预编译 |
| **XSS** | 注入脚本到页面 | 输出转义、CSP |
| **CSRF** | 借用户登录态发请求 | Token 校验、Referer 检查 |
| **重放攻击** | 截获后重复发送 | 时间戳、随机数 nonce |
| **中间人攻击** | 截获并转发 | 证书校验、加密 |

**易错点**：
- **XSS 是注入脚本（攻击浏览器），CSRF 是借用身份（攻击服务器）**
- **SQL 注入的防御是参数化查询**，不是"过滤特殊字符"（可被绕过）

#### 防火墙类型

| 类型 | 工作层 | 特点 |
|:---|:---|:---|
| **包过滤** | 网络层 | 看 IP/端口，快，粒度粗 |
| **应用代理** | 应用层 | 拆包检查内容，安全但慢 |
| **状态检测** | 传输层/网络层 | 记录连接状态，兼顾性能与安全 |

#### IDS vs IPS

- **IDS**（入侵检测）：**只检测告警，不阻断**
- **IPS**（入侵防御）：**检测并阻断**

**记忆**：IDS 是"监控摄像头"，IPS 是"带报警的防盗门"。

#### VPN

**在公网上建立加密隧道**，实现远程安全接入。

| 类型 | 说明 |
|:---|:---|
| **IPSec VPN** | 网络层，站点到站点 |
| **SSL VPN** | 应用层，远程用户接入 |

#### 等级保护

五级，**一级最低，五级最高**。三级是多数企业系统的要求。

## 四、教材强调但容易忽略的

1. **集线器不隔离冲突域，交换机隔离冲突域但不隔离广播域，路由器两者都隔离**。这三层的递进关系是必考点。

2. **数字签名用私钥，加密用公钥**。方向相反，最容易搞反。

3. **数字签名不保证机密性**，因为内容本身没加密。它只保证完整性和不可否认性。

4. **XSS 和 CSRF 完全不同**：一个注入脚本，一个借用身份。

5. **SQL 注入的防御是参数化查询**，不是过滤。过滤可以被编码绕过。

6. **ARP 属于网络层**（教材归网络层），虽然有争议但考试按网络层答。

7. **被动攻击难检测（因为不破坏数据），主动攻击易检测**。这个反直觉。
