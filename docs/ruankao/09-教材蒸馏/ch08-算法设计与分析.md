## 三、核心内容蒸馏

### 8.1 基本概念

#### 复杂度

**时间复杂度**：算法执行时间随问题规模 n 的增长趋势。

**常见量级**（从小到大）：
**O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)**

**空间复杂度**：算法需要的额外存储空间。

**教材的强调**：复杂度分析看的是**增长趋势**，不是绝对时间。O(n²) 在小规模时可能比 O(n log n) 快，但 n 大了必然慢。

#### 递归式的复杂度（常考）

| 递归式 | 复杂度 | 例子 |
|:---|:---|:---|
| T(n) = T(n−1) + O(1) | O(n) | 阶乘、线性递归 |
| T(n) = T(n−1) + O(n) | O(n²) | 冒泡的递归版 |
| T(n) = 2T(n/2) + O(1) | O(n) | 二分查找 |
| T(n) = 2T(n/2) + O(n) | **O(n log n)** | 归并排序 |
| T(n) = T(n/2) + O(1) | O(log n) | 折半 |
| T(n) = 2T(n−1) + O(1) | O(2ⁿ) | 汉诺塔 |

**主定理**（教材没明说但有用）：T(n) = aT(n/b) + f(n)
- 若 f(n) < n^(log_b a)，则 T(n) = O(n^(log_b a))
- 若 f(n) = n^(log_b a)，则 T(n) = O(n^(log_b a) · log n)
- 若 f(n) > n^(log_b a)，则 T(n) = O(f(n))

### 8.2 分治法

#### 三个步骤（教材标准表述）

1. **分解**（Divide）：把问题分成若干规模较小的子问题
2. **解决**（Conquer）：递归求解子问题
3. **合并**（Combine）：把子问题的解合并成原问题的解

**关键特征**：子问题**相互独立**（不重叠）。

#### 典型算法

| 算法 | 分解方式 | 复杂度 |
|:---|:---|:---|
| **二分查找** | 每次砍一半 | O(log n) |
| **归并排序** | 分成两半，分别排序，再合并 | O(n log n) |
| **快速排序** | 按基准分成两部分 | 平均 O(n log n)，最坏 O(n²) |
| **大整数乘法** | 分成高低位 | O(n^1.585) |
| **Strassen 矩阵乘法** | 分块 | O(n^2.81) |

**判断特征**：代码里有 `mid = (low+high)/2`，然后递归调用**两次**。

#### 归并排序的合并过程（下午场常考）

```c
void merge(int a[], int low, int mid, int high) {
    int i = low, j = mid + 1, k = 0;
    int temp[high - low + 1];
    while (i <= mid && j <= high) {
        if (a[i] <= a[j]) temp[k++] = a[i++];   // 稳定：相等时取左边
        else temp[k++] = a[j++];
    }
    while (i <= mid) temp[k++] = a[i++];
    while (j <= high) temp[k++] = a[j++];
    for (i = 0; i < k; i++) a[low + i] = temp[i];
}
```

**注意**：`a[i] <= a[j]` 里的 `<=` 保证了稳定性。

### 8.3 动态规划（★★★）

#### 与分治的核心区别

| | 分治 | 动态规划 |
|:---|:---|:---|
| 子问题 | **独立**，不重复 | **重叠**，会重复计算 |
| 求解方式 | 递归 | 填表（自底向上）或记忆化递归 |
| 是否需要存表 | 不需要 | **需要** |

**一句话**：动态规划 = 分治 + **记住已解的子问题**。

#### 两个要素（教材强调）

1. **最优子结构**：问题的最优解包含子问题的最优解
2. **重叠子问题**：不同的问题分支会重复遇到相同的子问题

#### 三个步骤

1. **定义状态**：`dp[i]` 或 `dp[i][j]` 表示什么
2. **写状态转移方程**：`dp[i] = f(dp[i-1], ...)`
3. **确定边界和计算顺序**

#### 典型问题

##### 0-1 背包

```c
// dp[i][j] = 前 i 个物品、容量 j 时的最大价值
for (i = 1; i <= n; i++) {
    for (j = 1; j <= W; j++) {
        if (w[i] > j)
            dp[i][j] = dp[i-1][j];                       // 装不下
        else
            dp[i][j] = max(dp[i-1][j],                   // 不装
                           dp[i-1][j-w[i]] + v[i]);      // 装
    }
}
```

**复杂度**：O(nW)　**策略**：动态规划

**为什么不能用贪心**：物品不可分割，按单位价值排序后可能装不满，剩下的空间浪费。

##### 最长递增子序列（LIS）

```c
for (i = 0; i < n; i++) {
    dp[i] = 1;
    for (j = 0; j < i; j++)
        if (a[j] < a[i] && dp[j] + 1 > dp[i])
            dp[i] = dp[j] + 1;
}
// 答案是 max(dp[i])
```

**复杂度**：O(n²)　**策略**：动态规划

##### 最长公共子序列（LCS）

```c
// dp[i][j] = A 前 i 个字符与 B 前 j 个字符的 LCS 长度
if (a[i-1] == b[j-1])
    dp[i][j] = dp[i-1][j-1] + 1;
else
    dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
```

**复杂度**：O(mn)

##### 矩阵连乘

`dp[i][j]` = 第 i 到第 j 个矩阵连乘的最小乘法次数。

**这是教材的重点例子**，因为它是"区间 DP"的典型。

### 8.4 贪心法（★★★）

#### 核心思想

每一步都选**当前看起来最优**的，不回头，不保证全局最优（但对某些问题确实最优）。

#### 两个要素

1. **贪心选择性质**：局部最优能推出全局最优
2. **最优子结构**：同动态规划

#### 与动态规划的区别（必考）

| | 贪心 | 动态规划 |
|:---|:---|:---|
| 决策 | 做了就不改 | 保存所有子问题解，可回头参考 |
| 是否存表 | 不需要 | 需要 |
| 正确性 | 只对特定问题成立 | 只要满足两个要素就成立 |

**经典对比**：
- **分数背包**（物品可分割）→ **贪心可解**（按单位价值排序）
- **0-1 背包**（物品不可分割）→ **贪心不可解**，必须动态规划

**这个对比是高频考点。**

#### 典型算法

| 问题 | 贪心策略 |
|:---|:---|
| **活动安排** | 按**结束时间**最早排序，能选就选 |
| **哈夫曼编码** | 每次合并权值最小的两个 |
| **Prim / Kruskal** | 每次选最短边 |
| **Dijkstra** | 每次选当前距离最小的点 |
| **分数背包** | 按单位价值降序 |

### 8.5 回溯法（★★）

#### 核心思想

**深度优先搜索 + 剪枝**。走不通就回退（撤销选择），换一条路。

#### 三个要素

1. **解空间**：所有可能的解构成的空间（通常是树或图）
2. **约束函数**：判断当前部分解是否可能成为完整解（不满足就剪枝）
3. **限界函数**：判断当前部分解是否可能优于已知最优解（不优就剪枝）

#### 典型问题

| 问题 | 解空间 | 复杂度 |
|:---|:---|:---|
| **N 皇后** | n 叉树，深度 n | O(n!) |
| **迷宫** | 图 | 取决于路径数 |
| **图着色** | m 叉树 | O(mⁿ) |
| **子集和** | 二叉树（选/不选） | O(2ⁿ) |

#### 代码骨架

```c
void backtrack(int row) {
    if (row == n) { record(); return; }        // 找到解
    for (int col = 0; col < n; col++) {
        if (isSafe(row, col)) {                // 约束函数（剪枝）
            place(row, col);                   // 做选择
            backtrack(row + 1);                // 递归
            remove(row, col);                  // 撤销（回溯）
        }
    }
}
```

**识别特征**：代码里有"做选择 → 递归 → 撤销选择"这个三段式。

### 8.6 分支限界法（★）

**与回溯法的区别**：

| | 回溯法 | 分支限界法 |
|:---|:---|:---|
| 搜索方式 | **深度优先** | **广度优先**（或最小耗费优先） |
| 数据结构 | 栈 | **队列**（或优先队列） |
| 目标 | 找所有解 / 任一解 | **找最优解** |
| 剪枝 | 约束 + 限界 | 主要靠**限界** |

**教材的说法**：分支限界法适合"求最优解"的问题，回溯法适合"求所有解"的问题。

### 8.7 概率算法（★ 了解）

| 类型 | 特点 |
|:---|:---|
| **数值概率算法** | 用随机采样估算数值（如蒙特卡洛求 π） |
| **蒙特卡洛算法** | 结果**可能错**，但错的概率可控 |
| **拉斯维加斯算法** | 结果**一定对**，但运行时间不确定 |
| **舍伍德算法** | 消除最坏情况，保证平均性能 |

**记忆**：蒙特卡洛可能错，拉斯维加斯一定对。

### 8.8 近似算法（★ 了解）

对 NP 难问题，不追求最优解，求**近似最优解**，并保证近似比。

**近似比** ρ(n)：算法解 ≤ ρ(n) × 最优解（最小化问题）。

## 四、教材强调但容易忽略的

1. **动态规划 = 分治 + 记忆化**。区别不在"递归不递归"，而在"子问题是否重叠"。

2. **0-1 背包只能用动规，分数背包才能用贪心**。这是贪心 vs 动规的经典分界。

3. **回溯法是深度优先 + 剪枝**，分支限界法是广度优先 + 限界。

4. **蒙特卡洛可能错，拉斯维加斯一定对**。这两个名字容易混。

5. **归并排序的稳定性来自 `a[i] <= a[j]` 里的等号**。去掉等号就不稳定了。

6. **活动安排问题按结束时间排序，不是开始时间**。这是贪心策略的关键。
