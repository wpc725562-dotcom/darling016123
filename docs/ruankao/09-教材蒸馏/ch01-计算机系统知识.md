## 三、核心内容蒸馏

### 1.1.1 硬件基本组成

教材沿用的是**冯·诺依曼结构**：运算器、控制器、存储器、输入设备、输出设备五大部件。

**两个组合关系**（常考）：
- 运算器 + 控制器 = **CPU**
- CPU + 主存 = **主机**

**教材特别强调的一点**：冯·诺依曼结构的核心特征是**存储程序**——程序和数据都存在同一存储器里，按地址访问。这个特征带来了"指令和数据形式上无区别"的问题，也是"冯·诺依曼瓶颈"（CPU 与存储器速度不匹配）的根源。

### 1.1.2 中央处理单元

**CPU 的两大部件**：

| 部件 | 组成 | 职责 |
|:---|:---|:---|
| **运算器** | ALU、累加寄存器 AC、数据缓冲寄存器 DR、状态条件寄存器 PSW | 算术与逻辑运算 |
| **控制器** | 程序计数器 PC、指令寄存器 IR、指令译码器、时序部件 | 取指、译码、执行控制 |

**必背区分**：
- **PC** 存**下一条**要执行指令的**地址**
- **IR** 存**当前**正在执行的**指令本身**

这两个是最常考的点。教材原文特别指出：取指结束后 PC 自动加 1（指向下一条），而 IR 里保存的是刚取来的指令。

**指令执行过程**（教材按四步描述）：
取指 → 分析（译码）→ 执行 → 访存/写回

### 1.1.3 数据表示（★★★ 必考）

#### 四种机器数编码

教材按"符号位 + 数值位"的结构讲，重点是**负数**的三种表示：

| 编码 | 正数 | 负数 | 特点 |
|:---|:---|:---|:---|
| **原码** | 符号位 0，数值为绝对值 | 符号位 1，数值为绝对值 | 有 +0 和 −0 两个零 |
| **反码** | 同原码 | 符号位不变，数值位取反 | 仍有 ±0 |
| **补码** | 同原码 | 反码末位加 1 | **只有一个 0**，多表示一个负数 |
| **移码** | 补码符号位取反 | 同左 | 用于浮点数的阶码 |

**教材强调的三个结论**：
1. 补码的 0 只有一种表示，所以 n 位补码比原码**多表示一个负数**
2. 8 位补码范围：**−128 ~ +127**
3. 移码的作用是**让浮点数的阶码可以按无符号数比较大小**

**求补码的两种方法**（教材都讲了）：
- 方法一：先求反码，再加 1
- 方法二：从右往左找到第一个 1，这个 1 及其右边的 0 不变，左边全部取反

方法二更快，但容易记错边界。

#### 浮点数

教材用 `N = 2^E × M` 的形式讲，E 是阶码，M 是尾数。

**核心结论**：
- **阶码决定表示范围**（阶码位数越多，范围越大）
- **尾数决定表示精度**（尾数位数越多，精度越高）

**IEEE 754 单精度（32 位）**：1 位符号 + 8 位阶码（移码，偏移 127）+ 23 位尾数（隐含最高位 1）

**浮点运算四步**（教材明确给出顺序）：
1. **对阶**——小阶向大阶看齐（尾数右移，避免丢失高位）
2. 尾数运算
3. 规格化
4. 舍入

**对阶方向是易错点**：一定是小阶向大阶看齐，不是反过来。

### 1.1.4 校验码（★★ 隔年考）

这一节在我原来的 `02-知识域` 里**没有覆盖**，是教材补充内容。

#### 三种校验码对比

| 校验码 | 检错 | 纠错 | 原理 |
|:---|:---:|:---:|:---|
| **奇偶校验** | 能检 1 位错 | **不能纠错** | 增加 1 位校验位，使 1 的个数为奇/偶 |
| **海明码** | 能检多位 | **能纠 1 位** | 多位校验位分组交叉校验 |
| **CRC（循环冗余）** | 能检多位 | 一般只检不纠 | 模 2 除法取余数 |

**海明码的关键公式**（教材给出）：

设信息位 n 位，校验位 k 位，则必须满足：
**2^k ≥ n + k + 1**

**例**：信息位 4 位，需要几位校验位？
- k=2：2²=4，n+k+1=7，4 < 7，不够
- k=3：2³=8，n+k+1=8，8 ≥ 8，**刚好够**
- 答案：**3 位**，总码长 7 位

**CRC 的计算**：
1. 被除数 = 信息码后补 k 个 0（k = 生成多项式最高次幂）
2. 用模 2 除法除以生成多项式
3. 余数就是校验位

**注意**：CRC 的"模 2 除法"是**异或**，不借位。

### 1.2.1 体系结构的发展（★★）

#### Flynn 分类（按指令流和数据流）

| 类型 | 含义 | 实例 |
|:---|:---|:---|
| **SISD** | 单指令流单数据流 | 传统单核 |
| **SIMD** | 单指令流多数据流 | 向量处理机、**GPU**、阵列处理机 |
| **MISD** | 多指令流单数据流 | **理论存在，实际没有** |
| **MIMD** | 多指令流多数据流 | 多核、多处理机、分布式系统 |

**必记**：MISD 是唯一"不存在实际系统"的类型。

#### CISC vs RISC

| | CISC | RISC |
|:---|:---|:---|
| 指令数量 | 多 | 少 |
| 指令长度 | **变长** | **定长** |
| 寻址方式 | 多 | 少 |
| 控制器实现 | **微程序控制** | **硬布线控制** |
| 流水线 | 难实现 | **易实现** |
| 通用寄存器 | 少 | **多** |

**教材的一句话结论**：目前使用的绝大多数计算机（x86）属于 **CISC**；RISC 的代表是 ARM、MIPS。

#### 流水线（★★★ 计算题来源）

教材把流水线按六个维度分类（级别、功能、连接、反馈、流动顺序、数据表示），但考试只考**计算**。

**三个公式**：

设指令数 n、流水段数 k、每段耗时 Δt：

1. **总执行时间 = (k + n − 1) × Δt**
2. **吞吐率 TP = n / 总时间**
3. **加速比 S = nk / (k + n − 1)**

**教材强调的极限**：当 n → ∞ 时，加速比 → k。也就是说**加速比永远小于流水段数**。

**流水线冲突三类**：

| 类型 | 原因 | 解决 |
|:---|:---|:---|
| 结构冲突 | 硬件资源争用 | 增加资源、分时使用 |
| 数据冲突 | 后一条要用前一条结果 | 转发/旁路、停顿 |
| 控制冲突 | 转移指令 | 分支预测、延迟槽 |

### 1.2.2 存储系统（★★★）

#### 层次结构

教材给的层次（从快到慢、从贵到便宜、容量从小到大）：
**寄存器 → Cache → 主存 → 外存**

#### 局部性原理（Cache 的理论基础）

| 类型 | 含义 |
|:---|:---|
| **时间局部性** | 刚被访问的数据，马上还会被访问（循环） |
| **空间局部性** | 访问了某地址，相邻地址也会被访问（数组） |

#### Cache 平均访问时间（必考公式）

**t = h × t₁ + (1 − h) × t₂**

- h：命中率
- t₁：Cache 访问时间
- t₂：主存访问时间

**教材提醒**：如果题目说"未命中时需要先访问主存再访问 Cache"，公式要改成 `h×t₁ + (1−h)×(t₁+t₂)`。**看清题意**。

#### 替换算法

FIFO、LRU（最近最少使用）、随机。

**教材补充**：LRU 是"最近最少使用"，不是"最久没用过"——虽然实际效果接近，但定义不同。

#### 写策略

| 策略 | 做法 | 特点 |
|:---|:---|:---|
| **写直达**（Write Through） | 同时写 Cache 和主存 | 一致性好，速度慢 |
| **写回**（Write Back） | 只写 Cache，替换时才写主存 | 速度快，可能不一致 |

### 1.2.3 输入/输出技术（★★）

这一节也是 `02-知识域` 没覆盖的。

#### 三种 I/O 控制方式

| 方式 | CPU 参与度 | 数据传输单位 | 特点 |
|:---|:---|:---|:---|
| **程序查询**（轮询） | **全程参与**，忙等 | 字（字节） | 最简单，CPU 利用率最低 |
| **中断** | 传输时参与 | 字（字节） | CPU 可并行做别的事，但每次传输都要中断 |
| **DMA** | **只在开始和结束时参与** | **数据块** | 效率最高，适合大批量传输 |

**必记对比**：DMA 的 CPU 参与度最低、传输单位最大，这是它相对中断方式的核心优势。

### 1.2.4 总线结构（★）

三类总线：

| 总线 | 传什么 | 方向 |
|:---|:---|:---|
| **数据总线** | 数据 | **双向** |
| **地址总线** | 地址 | **单向**（CPU → 存储器/I/O） |
| **控制总线** | 控制信号 | 双向（每根线方向固定） |

**地址总线宽度决定寻址空间**：n 根地址线 → 2ⁿ 个可寻址单元。

### 1.3.2 加密与认证（★★）

与第 10 章重复，这里只记一句话：**对称加密快、非对称慢，数字签名用私钥签、公钥验**。

详细内容见 `02-知识域/I-信息安全/README.md`。

### 1.3.3 计算机可靠性（★★★ 必考）

**两个公式**：

- **串联系统**（全部正常才正常）：`R = R₁ × R₂ × ... × Rn`
- **并联系统**（一个正常就正常）：`R = 1 − (1−R₁)(1−R₂)...(1−Rn)`

**教材的例子**：两个可靠度都是 0.9 的部件
- 串联：0.9 × 0.9 = **0.81**
- 并联：1 − 0.1 × 0.1 = **0.99**

**混合系统**：先算并联部分，结果作为整体参与串联。

**教材特别说明**：并联系统提高可靠性的代价是**成本翻倍**，所以实际系统常用"串联为主 + 关键部件并联"的混合结构。

### 1.3.4 性能评价（★）

几个指标：
- **响应时间**：从提交到返回的时间
- **吞吐率**：单位时间完成的任务数
- **MIPS**：每秒百万条指令
- **MFLOPS**：每秒百万次浮点运算

## 四、教材强调但容易忽略的

1. **冯·诺依曼瓶颈**：CPU 与存储器速度不匹配，这是 Cache 存在的根本原因。教材专门讲了这个因果链。

2. **补码的"多一个负数"不是巧合**：因为 0 只有一种表示，省出来的编码用来表示 −2^(n−1)。

3. **对阶方向**：教材用"避免丢失高位"来解释为什么小阶向大阶看齐，理解了就不用死记。

4. **DMA 与中断的本质区别**：中断是"每传一个字中断一次"，DMA 是"传完一整块才中断一次"。这是效率差异的根源。

5. **CRC 的模 2 除法**：是异或，不借位。这一点教材写得很清楚，但很多人按普通除法算，结果全错。
