# 易错点总表

> 用法：做错题后，把错误归到下面某一类，记在这里。**考前一周只看这份。**
> 只记"记混了"的类型——"没学过"的补完就会，"手滑"的练速度就行。

---

## 一、按域归类的固定易错点

### A 计算机组成

| 易错点 | 正确 |
|:---|:---|
| 补码求法：先加 1 再取反 | **先取反，再加 1** |
| 8 位补码范围写成 −127~+127 | **−128~+127**（补码多表示一个负数） |
| 浮点数范围由尾数决定 | **范围由阶码决定**，精度由尾数决定 |
| 流水线公式写成 k×n | **(k + n − 1) × Δt** |
| 加速比能无限大 | **极限是段数 k** |
| 可靠性串联用加法 | **串联相乘**，并联用 1−(1−R)ⁿ |
| 对阶时大阶向小阶看齐 | **小阶向大阶看齐** |

### B 操作系统

| 易错点 | 正确 |
|:---|:---|
| 阻塞可以直接转到运行 | **必须先回就绪** |
| 缺页次数 = 置换次数 | **缺页次数 = 置换次数 + 物理块数** |
| 所有置换算法都有 Belady 异常 | **只有 FIFO 有** |
| 进程是调度单位 | 进程是**资源分配**单位，线程是**调度**单位 |
| 银行家算法找不出安全序列就是死锁 | **是不安全状态，可能死锁** |

### C 数据库

| 易错点 | 正确 |
|:---|:---|
| π 和 σ 搞反 | **π 选列（竖切），σ 选行（横切）** |
| m:n 联系合并到一方 | **必须单独建表** |
| 1:n 的外键放在 1 端 | **放在 n 端** |
| 单属性候选键的关系也要查 2NF | **单属性键一定满足 2NF** |
| 自然连接保留重复属性 | **自然连接去掉重复属性** |
| 判断 3NF 时看主属性之间的依赖 | **只看非主属性** |
| WHERE 里用聚合函数 | **聚合函数只能用在 HAVING** |

### D 计算机网络

| 易错点 | 正确 |
|:---|:---|
| FTP 只用 21 端口 | **20 传数据，21 传控制** |
| 交换机隔离广播域 | **交换机隔离冲突域，路由器隔离广播域** |
| 集线器每个端口独立冲突域 | **集线器所有端口同一冲突域** |
| 可用主机数 = 2ⁿ | **2ⁿ − 2**（减网络地址和广播地址） |
| TCP 两次握手就够 | **必须三次**（要双向确认） |
| HTTPS 端口 8080 | **443**（80 是 HTTP） |
| ARP 是应用层协议 | **网络层**（考试按网络层答） |

### E 数据结构

| 易错点 | 正确 |
|:---|:---|
| n0 = n2 + 1 适用于所有树 | **只适用于二叉树** |
| 前序+后序能唯一确定树 | **不能**，必须中序参与 |
| 哈夫曼合并后不重新排序 | **要放回序列重新排序** |
| WPL 算所有节点 | **只算叶子** |
| 二分查找能用于链表 | **不能**，链表无法 O(1) 定位中点 |
| 快排最坏是 O(nlogn) | **最坏 O(n²)** |
| 归并排序空间 O(1) | **O(n)** |
| 单层循环一定是 O(n) | **`i*=2` 的循环是 O(log n)** |
| Prim 是加边 | **Prim 加点，Kruskal 加边** |
| Dijkstra 能处理负权 | **不能** |

### F 程序设计语言

| 易错点 | 正确 |
|:---|:---|
| 词法分析发现语法错误 | **词法只发现非法字符**，语法错误在语法分析 |
| 类型不匹配是语法错误 | **是语义错误** |
| 语法分析用正规式 | **语法用上下文无关文法（2型），词法用正规式（3型）** |
| Java 有传引用 | **Java 只有传值** |

### G 软件工程

| 易错点 | 正确 |
|:---|:---|
| 关键路径是最短路径 | **是最长路径**，其长度=最短工期 |
| 内聚越低越好 | **内聚越高越好，耦合越低越好** |
| 数据耦合比标记耦合高 | **数据耦合更低**（传简单值 vs 传整个对象） |
| 适应性维护占比最大 | **完善性维护占比最大**（约 50%） |
| 语句覆盖能保证判定覆盖 | **不能** |
| 螺旋模型的核心是迭代 | **核心是风险分析** |
| 外部实体之间可以直接有数据流 | **必须经过加工** |

### H 面向对象

| 易错点 | 正确 |
|:---|:---|
| 聚合和组合搞反 | **问"整体没了，部分还在吗"**：在=聚合(空心)，不在=组合(实心) |
| 菱形画在部分那一端 | **菱形在整体端** |
| 包含和扩展箭头方向搞反 | `A «include» B` 箭头 A→B；`B «extend» A` 箭头 B→A |
| 重载是运行时多态 | **重载是编译时，重写是运行时** |
| 策略和状态搞混 | **策略由客户端选，状态由对象自己切** |
| 适配器和装饰器搞混 | **适配器改接口，装饰器加功能** |

### I 信息安全

| 易错点 | 正确 |
|:---|:---|
| 数字签名用公钥签 | **私钥签名，公钥验证** |
| 数字签名保证机密性 | **只保证完整性和不可否认性** |
| 对称加密比非对称慢 | **对称快，非对称慢** |
| MD5 还安全 | **已可碰撞，不安全** |
| XSS 和 CSRF 是一回事 | **XSS 注入脚本，CSRF 借用身份** |
| IDS 能阻断攻击 | **IDS 只告警，IPS 才阻断** |

### J 知识产权

| 易错点 | 正确 |
|:---|:---|
| 著作权要登记才享有 | **自动产生，不需登记** |
| 专利期限都是 20 年 | **发明 20、实用新型 10、外观设计 15** |
| 商标到期就失效 | **10 年可无限续展** |
| 合理使用要付费 | **合理使用不付费，法定许可要付费** |
| GB 是推荐标准 | **GB 强制，GB/T 推荐** |
| 修改 GPL 代码后闭源 | **侵权**（GPL 有传染性） |

### L 专业英语（第 71–75 题）

| 易错点 | 正确 |
|:---|:---|
| lead 的过去式写成 leaded | **led**（不规则动词） |
| verify 和 validate 混用 | **verify = 做得对不对；validate = 做的是不是对的东西** |
| design / implement / construct 随便选 | **design 偏方案、implement 偏落地、construct 偏构造实体** |
| decompose 和 compose 搞反 | **decompose 分解、compose 组成**（de- 是否定前缀） |
| 只看词义不看词性 | 空格要名词就不能选动词，**先判词性再选词** |
| corrective / adaptive / perfective / preventive 记混 | 正确性/适应性/**完善性（占比最大）**/预防性 |

> L 域 5 分，目标 3 分。**不要在这上面耗超过 2 小时**——投入产出比不如 G 和 D。

### K 数学与工程（不单独列）

实测 0–1 分，**建议直接放弃**。唯一相关的 K5 工程计算已经在 A8 和 G7 里覆盖，看那两处即可。

## 二、跨域的通用易错点

| 类型 | 表现 | 应对 |
|:---|:---|:---|
| **单位换算** | KB/MB 混用、ns/ms 混用 | 做题时先统一单位 |
| **位数计算** | 8 位、16 位、32 位混淆 | 看清题目给的位数 |
| **从 0 还是从 1 开始** | 数组下标、编号 | C 语言从 0，伪代码可能从 1，**看代码** |
| **向上还是向下取整** | log 计算 | 完全二叉树深度用 ⌊log₂n⌋+1 |
| **"最高"还是"最低"** | 内聚、耦合、范式 | 看清问的是哪个方向 |

## 四、考前一周怎么用这份

1. **只看第一节**（按域归类的固定易错点），从头到尾读一遍，约 30 分钟
