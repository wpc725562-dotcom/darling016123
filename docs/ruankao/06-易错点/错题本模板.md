# 错题本模板

> 配合 `README.md` 的易错点总表用。
> **只记"记混了"这一类**——"没学过"的补完就会，"手滑"的练速度就行。

---

## 为什么要区分三类错误

做错一道题，原因只有三种：

| 类型 | 特征 | 处理 |
|:---|:---|:---|
| **没学过** | 完全不知道这题考什么 | 去 `02-知识域` 补，**不用记错题本** |
| **记混了** | 学过，但记错/记反了 | **记错题本**，这是唯一值得反复看的 |
| **手滑** | 会做，看错题/算错/填错 | 单独计数，超过 5 道说明是节奏问题 |

**只有"记混了"会反复错。** 很多人把三类混在一起记，结果错题本越来越厚，越看越焦虑，实际有用的没几条。

## 记录格式

### 单条格式

```
### 2026-XX-XX · 第 X 套上午卷第 XX 题
- **考点**：C4 范式判断
- **我的答案**：3NF
- **正确答案**：2NF
- **错在哪**：以为"系号→系主任"不是传递依赖，实际学号→系号→系主任就是传递
- **正确思路**：先找候选键（学号），再看有没有非主属性依赖非主属性
- **一句话记住**：单属性候选键 → 一定 2NF；有"非主属性→非主属性"就是传递
- **复习**：□ 次日  □ 3 天后  □ 7 天后  □ 考前
```

### 表格版（适合快速记）

| 日期 | 来源 | 考点编号 | 我的答案 | 正确答案 | 错在哪（一句话） | 复习 |
|:---|:---|:---|:---|:---|:---|:---|
| 10-30 | 2024上·上午·23 | C4 | 3NF | 2NF | 漏看传递依赖 | □□□ |
| | | | | | | |

## 复习节奏

记下的错题，按这个节奏回看：

| 时间 | 做什么 |
|:---|:---|
| **当天** | 记下来，写清"错在哪"和"记住这句" |
| **次日** | 只看"记住这句"那一列，30 秒扫一遍 |
| **3 天后** | 遮住答案，能不能自己说出正确思路 |
| **7 天后** | 同上 |
| **考前一周** | 全部过一遍，只看"记住这句" |

**关键**：复习时**不要重做题目**，只看"记住这句"。因为你要记的是那个判断，不是那道题。

---

## 一个提醒

错题本超过 100 条时，说明**你的问题不在记性，在基础**。

这时候应该停下来，回到 `02-知识域` 把对应域重学一遍，而不是继续刷题记错题。

**判断标准**：如果同一个编号（比如 C4）错了 3 次以上，那不是"记混"，是"没懂"。回去重学。
