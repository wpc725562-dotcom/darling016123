# I · 信息安全（实测 3 分，原估 4–6）

> 分值不高但**几乎不丢分**——全是概念，没有计算。1 小时能拿下。
> 你的网安背景在这里是优势，但要注意：软考考的是"教材定义"，不是实战经验。

## I1 信息安全基本属性 ★★ L1

### CIA 三要素（必背）

| 属性 | 英文 | 含义 | 被破坏的例子 |
|:---|:---|:---|:---|
| **机密性** | Confidentiality | 不被未授权者获取 | 数据泄露 |
| **完整性** | Integrity | 不被未授权篡改 | 数据被改 |
| **可用性** | Availability | 授权者能正常使用 | DDoS 打瘫 |

**扩展属性**：
- **可控性**：能控制信息的传播
- **不可否认性**（抗抵赖）：发送方不能否认发过

## I2 加密算法 ★★★ L2

### 三大类

| 类型 | 密钥 | 速度 | 典型算法 | 用途 |
|:---|:---|:---|:---|:---|
| **对称加密** | **加密解密同一密钥** | 快 | DES、3DES、**AES**、RC4、IDEA | 大量数据加密 |
| **非对称加密** | **公钥加密、私钥解密** | 慢 | **RSA**、ECC、DSA、ElGamal | 密钥交换、数字签名 |
| **哈希（散列）** | **无密钥**，单向 | 快 | **MD5**、SHA-1、SHA-256 | 完整性校验、存密码 |

### 必记对应关系

- **DES**：56 位密钥，已被破解
- **3DES**：DES 做三次，安全性提升但慢
- **AES**：128/192/256 位，**目前主流对称算法**
- **RSA**：基于**大数分解**难题，密钥长（1024/2048 位）
- **ECC**：基于**椭圆曲线离散对数**，密钥短、强度高
- **MD5**：128 位输出，**已被证明可碰撞，不安全**
- **SHA-256**：256 位输出，目前安全

### 混合加密（HTTPS 的做法）

**用非对称加密传对称密钥，用对称加密传数据。**

原因：非对称太慢，不适合加密大量数据；但对称的密钥分发不安全。所以两者结合。

## I3 数字签名与证书 ★★ L2

### 数字签名（必考方向）

| 步骤 | 用什么 |
|:---|:---|
| **签名** | 发送方用**自己的私钥**加密摘要 |
| **验证** | 接收方用**发送方的公钥**解密 |

**记忆**：**私钥签名，公钥验证**。这和加密正好相反（公钥加密，私钥解密）。

**数字签名保证**：完整性 + 不可否认性（**不保证机密性**，因为内容没加密）。

### 数字证书

由 **CA（证书授权中心）** 签发，包含：持有者信息、公钥、有效期、CA 的签名。

**作用**：解决"这个公钥到底是不是他的"这个问题（防止公钥被冒充）。

## I4 常见攻击类型 ★★ L1

| 攻击 | 原理 | 防御 |
|:---|:---|:---|
| **DoS / DDoS** | 大量请求耗尽资源 | 流量清洗、限速 |
| **ARP 欺骗** | 伪造 ARP 响应，冒充网关 | 静态 ARP 绑定 |
| **SQL 注入** | 输入拼接进 SQL 语句 | 参数化查询、预编译 |
| **XSS** | 注入恶意脚本到页面 | 输出转义、CSP |
| **CSRF** | 借用户已登录状态发请求 | Token 校验、Referer 检查 |
| **重放攻击** | 截获后重复发送 | 时间戳、随机数（nonce） |
| **中间人攻击** | 截获并转发通信 | 证书校验、加密 |
| **暴力破解** | 穷举密码 | 限速、强密码、验证码 |

### 易错点

- **XSS 是注入脚本**（攻击浏览器），**CSRF 是借用身份**（攻击服务器）。两者不同。
- **SQL 注入的防御是参数化查询**，不是"过滤特殊字符"（过滤可以被绕过）。

## I5 防火墙与 IDS ★ L1

### 防火墙类型

| 类型 | 工作层 | 特点 |
|:---|:---|:---|
| **包过滤** | 网络层 | 看源/目的 IP、端口，速度快，粒度粗 |
| **应用代理** | 应用层 | 拆包检查内容，安全但慢 |
| **状态检测** | 传输层/网络层 | 记录连接状态，兼顾性能与安全 |

### IDS vs IPS

- **IDS**（入侵检测系统）：**只检测告警，不阻断**
- **IPS**（入侵防御系统）：**检测并阻断**

**记忆**：IDS 是"监控摄像头"，IPS 是"带报警的防盗门"。

### 部署位置

- **DMZ**（隔离区）：放对外提供服务的服务器（Web、邮件）
- 内网：核心数据

## I6 等级保护 ★ L1

五个等级，**一级最低，五级最高**：

| 级别 | 对象 |
|:---:|:---|
| 一级 | 一般系统，自主保护 |
| 二级 | 一般系统，指导保护 |
| 三级 | **重要系统**，监督保护（多数企业系统） |
| 四级 | 特别重要，强制保护 |
| 五级 | 极端重要，专控保护 |

## 给你的提醒

你有实战经验，但**软考考的是教材定义**。比如：

- 实战中你可能觉得"MD5 用来做文件校验没问题"，但考试的标准答案是"MD5 已不安全，应使用 SHA-256"。
- 实战中渗透测试会绕 WAF，但考试问"WAF 的作用"，标准答案是"应用层防护"。

**按教材答，不要按经验答**。这是这域唯一需要注意的地方。
