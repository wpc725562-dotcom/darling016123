## E1 线性表 ★★★ L2

| | 顺序表（数组） | 链表 |
|:---|:---|:---|
| 存储 | 连续内存 | 离散，靠指针连接 |
| 随机访问 | **O(1)** | O(n) |
| 插入/删除 | O(n)（要移动元素） | **O(1)**（已知位置时） |
| 空间 | 需预分配，可能浪费 | 动态分配，有指针开销 |

**常见变体**：
- **单链表**：每个节点一个 next 指针
- **双向链表**：prev + next，删除更方便
- **循环链表**：尾节点指向头，可从任意节点遍历全表
- **静态链表**：用数组模拟链表，用下标代替指针

### 易错点

- 链表"插入 O(1)"的前提是**已经找到插入位置的前驱**。如果只是"在链表中插入"，查找本身要 O(n)。
- 顺序表插入平均移动 n/2 个元素，删除平均移动 (n-1)/2 个。

## E2 栈与队列 ★★★ L2

### 栈（LIFO，后进先出）

**应用**：
- 函数调用（递归）
- 表达式求值（中缀转后缀）
- 括号匹配
- 深度优先搜索（DFS）
- 撤销操作

### 队列（FIFO，先进先出）

**应用**：
- 广度优先搜索（BFS）
- 缓冲区、任务调度
- 打印队列

**循环队列**（必考）：
- 队空条件：`front == rear`
- 队满条件：`(rear + 1) % maxSize == front`（**牺牲一个单元**的写法）
- 元素个数：`(rear - front + maxSize) % maxSize`

### 易错点

- 循环队列"牺牲一个单元"是为了区分队空和队满。如果不牺牲，需要额外计数器。
- 入队出队都是 O(1)。

## E3 树与二叉树 ★★★ L3

### 必须背的五个性质

1. 第 i 层最多有 **2^(i-1)** 个节点（根为第 1 层）
2. 深度为 k 的二叉树最多有 **2^k − 1** 个节点
3. **叶子数 n0 = 度为 2 的节点数 n2 + 1**（最常考）
4. 完全二叉树中，节点 i 的左孩子是 2i，右孩子是 2i+1，父节点是 ⌊i/2⌋
5. n 个节点的完全二叉树深度 = **⌊log₂n⌋ + 1**

### 遍历

| 遍历 | 顺序 | 特点 |
|:---|:---|:---|
| 前序 | 根 → 左 → 右 | 第一个是根 |
| 中序 | 左 → 根 → 右 | **二叉搜索树的中序是递增序列** |
| 后序 | 左 → 右 → 根 | 最后一个是根 |
| 层序 | 逐层从左到右 | 用队列实现 |

**唯一确定一棵树**：
- 前序 + 中序 ✅
- 后序 + 中序 ✅
- 前序 + 后序 ❌（无法确定）

### 二叉搜索树（BST）

左子树所有节点 < 根 < 右子树所有节点。查找、插入、删除平均 O(log n)，最坏 O(n)（退化成链表）。

### 平衡二叉树（AVL）

左右子树高度差 ≤ 1。四种旋转：LL、RR、LR、RL。

### 易错点

- `n0 = n2 + 1` 是**二叉树**的性质，不是所有树。
- 完全二叉树 ≠ 满二叉树。满二叉树是每层都满；完全二叉树是除最后一层外都满，且最后一层靠左连续。

## E4 哈夫曼树与编码 ★★★ L3

### 构造步骤

1. 把所有节点按权值从小到大排列
2. **取最小的两个**合并，新节点权值 = 两者之和
3. 把新节点放回序列，重新排序
4. 重复直到只剩一个节点

### 带权路径长度（WPL）

**WPL = Σ(每个叶子的权值 × 该叶子的路径长度)**

**哈夫曼树的 WPL 是最小的**。

### 哈夫曼编码

- 左分支记 0，右分支记 1（或反过来）
- 每个字符的编码 = 从根到该叶子的路径
- **没有任何编码是另一个编码的前缀**（前缀码），所以解码无歧义

### 例

权值 \{1, 2, 3, 4\}
1. 合并 1+2=3 → \{3, 3, 4\}
2. 合并 3+3=6 → \{4, 6\}
3. 合并 4+6=10

WPL = 1×3 + 2×3 + 3×2 + 4×1 = 3+6+6+4 = **19**

### 易错点

- 合并时**新节点要放回序列重新排序**，不是简单地继续往后加。
- WPL 只算**叶子**的权值×路径长度，不算内部节点。

## E5 图 ★★★ L3

### 存储结构

| | 邻接矩阵 | 邻接表 |
|:---|:---|:---|
| 空间 | O(n²) | O(n+e) |
| 判断两点是否相邻 | O(1) | O(度数) |
| 适合 | **稠密图** | **稀疏图** |

### 遍历

- **DFS**（深度优先）：用**栈**（或递归），一条路走到黑
- **BFS**（广度优先）：用**队列**，一层层扩展

### 最小生成树

| 算法 | 思路 | 适合 |
|:---|:---|:---|
| **Prim** | 从一个点出发，每次加**离树最近**的点 | 稠密图 |
| **Kruskal** | 每次选**全局最短**的边，不成环就加 | 稀疏图 |

**两者结果的总权值相同**（最小生成树可能不唯一，但权值和唯一）。

### 最短路径

| 算法 | 解决什么 |
|:---|:---|
| **Dijkstra** | 单源最短路径，**不能有负权边** |
| **Floyd** | 所有点对之间的最短路径，可有负权（不能有负环） |

### 拓扑排序

用于有向无环图（DAG），如任务依赖。每次输出**入度为 0** 的节点。

### 易错点

- Prim 是"加点"，Kruskal 是"加边"。
- Dijkstra 不能处理负权边，这是它的硬限制。

## E6 查找 ★★★ L3

### 二分查找

**前提**：序列**有序**、**顺序存储**（不能是链表）。

**查找长度**：最多 ⌊log₂n⌋ + 1 次。

**判定树**：把 mid 作为根，递归构建。查找成功的平均长度 = 所有节点层数之和 / n。

### 哈希表

**冲突处理**：

| 方法 | 说明 |
|:---|:---|
| **线性探测** | 冲突了就往后找下一个空位（会产生"堆积"） |
| **二次探测** | 按 1², -1², 2², -2²... 探测 |
| **链地址法** | 同一哈希值的元素挂成链表 |

**装填因子** α = 元素数 / 表长。α 越大冲突越多。

### 易错点

- 二分查找**不能用于链表**（无法 O(1) 定位中间）。
- 哈希查找的平均时间复杂度是 O(1)，但**最坏是 O(n)**（全部冲突）。

## E7 排序算法 ★★★ L2

**这张表必须背下来，每年 1–2 题。**

| 算法 | 平均时间 | 最坏时间 | 空间 | 稳定性 |
|:---|:---:|:---:|:---:|:---:|
| **直接插入** | O(n²) | O(n²) | O(1) | ✅ 稳定 |
| **希尔排序** | O(n^1.3) | O(n²) | O(1) | ❌ 不稳定 |
| **冒泡** | O(n²) | O(n²) | O(1) | ✅ 稳定 |
| **快速排序** | O(nlogn) | **O(n²)** | O(logn) | ❌ 不稳定 |
| **简单选择** | O(n²) | O(n²) | O(1) | ❌ 不稳定 |
| **堆排序** | O(nlogn) | O(nlogn) | O(1) | ❌ 不稳定 |
| **归并排序** | O(nlogn) | O(nlogn) | **O(n)** | ✅ 稳定 |
| **基数排序** | O(d(n+r)) | O(d(n+r)) | O(n+r) | ✅ 稳定 |

### 记忆要点

- **稳定的**：插入、冒泡、归并、基数（**插冒归基**）
- **不稳定的**：希尔、快排、选择、堆（**希快选堆**）
- **O(nlogn) 的**：快排、堆排、归并
- **空间 O(1) 且 O(nlogn) 的**：只有**堆排序**
- **最坏 O(n²) 的 O(nlogn) 算法**：只有**快速排序**

### 适用场景

- n 小（<50）：直接插入
- n 大且要稳定：归并
- n 大且要求原地：堆排序
- 基本有序：插入或冒泡
- 找前 k 大：堆排序

## E8 复杂度分析 ★★★ L2

### 常见量级从低到高

**O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)**

### 常见循环的复杂度

| 代码形态 | 复杂度 |
|:---|:---|
| `for(i=0;i<n;i++)` 单层 | O(n) |
| 双层嵌套都是 n | O(n²) |
| `for(i=1;i<n;i*=2)` | **O(log n)** |
| 外层 n、内层 log n | O(n log n) |
| 递归 T(n)=2T(n/2)+n | O(n log n)（归并） |
| 递归 T(n)=T(n-1)+1 | O(n) |

### 易错点

- 只看循环层数判断复杂度是错的。`i*=2` 的循环虽然是单层，但是 O(log n)。
- 复杂度只看**最高阶项**，忽略系数。3n² + 100n + 5 是 O(n²)。

## E9 算法设计策略 ★★★ L3

### 四种策略的识别

| 策略 | 特征 | 典型问题 |
|:---|:---|:---|
| **分治** | 把问题分成**独立的**子问题，分别求解再合并 | 归并排序、二分查找、快速排序 |
| **贪心** | 每步选**当前最优**，不回头 | 哈夫曼编码、Prim、Kruskal、Dijkstra、背包（分数） |
| **动态规划** | 子问题**重叠**，用表记录已解的子问题 | 0-1 背包、最长公共子序列、矩阵连乘、Floyd |
| **回溯** | 试探 + 回退，走不通就撤销 | N 皇后、迷宫、图着色、子集和 |

### 怎么判断题目用的是哪种

- 子问题**互相独立**，合并后就是答案 → **分治**
- 每步选最优，且**局部最优能推出全局最优** → **贪心**
- 子问题**会重复出现**，需要记忆化 → **动态规划**
- 需要**枚举所有可能**，走不通要回退 → **回溯**

### 贪心 vs 动态规划（最容易混）

- 贪心：做了选择就不改，**不保存历史**
- 动规：保存所有子问题的解，**可以回头参考**

**0-1 背包只能用动规**（因为物品不可分割，贪心会错）；**分数背包可以用贪心**。

## E10 特殊矩阵压缩存储 ★★ L2

> **教材 3.2，原版本遗漏，2026-10-29 补入**。

### 为什么要压缩

高阶矩阵里大量元素是 0 或重复值，全部存储浪费空间。压缩就是**只存有效元素**。

### 四种矩阵的压缩

| 矩阵类型 | 压缩方式 | 存储量 |
|:---|:---|:---|
| **对称矩阵** | 只存下三角（含对角线） | **n(n+1)/2** |
| **三角矩阵** | 只存有值的那一半 + 1 个常数 | n(n+1)/2 + 1 |
| **三对角矩阵** | 只存三条对角线 | **3n−2** |
| **稀疏矩阵** | 三元组表 (行,列,值) 或十字链表 | 取决于非零元个数 |

### 对称矩阵的地址映射（必考）

元素 `a[i][j]`（i ≥ j，下三角）在一维数组中的下标（**从 0 开始**）：

**k = i(i+1)/2 + j**

**例**：`a[4][2]` → k = 4×5/2 + 2 = 10 + 2 = **12**

**推导**：第 0 行 1 个，第 1 行 2 个……第 i−1 行 i 个，共 i(i+1)/2 个；再加本行的 j。

### 三对角矩阵

只有主对角线及其上下各一条有值。

`a[i][j]` 的下标：**k = 2i + j**（从 0 开始，i、j 从 0 起）

### 稀疏矩阵的三元组表示

只存非零元，每个元素存 `(行号, 列号, 值)`。

**例**：4×5 矩阵有 6 个非零元 → 三元组表 6 行 × 3 列。

### 易错点

- 对称矩阵公式 `i(i+1)/2 + j` 里，**i ≥ j 才成立**（上三角要转置后代入）
- 从 0 开始还是从 1 开始，**看题目约定**，差 1 就全错
- 三对角矩阵是 3n−2，不是 3n

## E11 平衡二叉树 AVL ★★ L3

> **教材 3.5.3，原版本只提了概念，2026-10-29 补充旋转规则**。

### 定义

左右子树**高度差 ≤ 1** 的二叉排序树。高度差叫**平衡因子 BF**，只能取 −1、0、1。

### 四种失衡与旋转（必考）

**判断方法**：看插入位置在失衡节点的**哪一侧的哪一侧**。

| 类型 | 插入位置 | 旋转方式 |
|:---|:---|:---|
| **LL** | 左子树的**左**边 | **右旋**一次 |
| **RR** | 右子树的**右**边 | **左旋**一次 |
| **LR** | 左子树的**右**边 | **先左旋，再右旋** |
| **RL** | 右子树的**左**边 | **先右旋，再左旋** |

**记忆**：LL 和 RR 是单旋（方向与名字相反），LR 和 RL 是双旋（先处理子树，再处理整体）。

### 旋转的本质

把失衡节点"降级"，把它的孩子"升级"，同时保持中序序列不变（BST 性质）。

### 易错点

- **LL 是右旋，不是左旋**（名字说的是插入位置，不是旋转方向）
- LR 和 RL 的第一步是**对子树旋转**，不是对失衡节点
- 旋转后要检查新的高度差是否 ≤ 1

## E12 外部排序 ★ L1

> **教材 3.6.9，原版本遗漏，2026-10-29 补入**。知道概念即可。

### 什么时候用

数据量太大，**内存装不下**，必须借助外存（磁盘）。

### 两阶段

1. **生成初始归并段**：把大文件分块读入内存，每块排序后写回外存
2. **多路归并**：把这些有序段合并成一个有序文件

### 关键公式

**归并趟数 = ⌈log_k m⌉**

- k = 归并路数
- m = 初始归并段数

**例**：1000 个初始段，10 路归并 → ⌈log₁₀1000⌉ = **3 趟**

### 怎么减少趟数

| 方法 | 做法 |
|:---|:---|
| **增大 k**（路数） | 多路归并，但每次比较次数增加，有最优 k |
| **减少 m**（初始段数） | 用**置换-选择排序**生成更长的初始段 |

### 易错点

- 外部排序的瓶颈是**磁盘 I/O**，不是 CPU
- k 不是越大越好——k 增大后，内部归并的比较次数增加
- 归并趟数是**向上取整**
