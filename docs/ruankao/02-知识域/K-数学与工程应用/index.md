## K1 概率统计基础 ★★ L2

### 古典概型

**P(A) = 有利结果数 / 总结果数**

### 常用公式

| 概念 | 公式 |
|:---|:---|
| 独立事件同时发生 | P(AB) = P(A) × P(B) |
| 互斥事件有一个发生 | P(A+B) = P(A) + P(B) |
| 非互斥 | P(A+B) = P(A) + P(B) − P(AB) |
| 条件概率 | P(A\|B) = P(AB) / P(B) |
| 全概率 | P(A) = Σ P(Bi) × P(A\|Bi) |

### 期望与方差

- **期望 E(X)** = Σ xi × P(xi)，即加权平均
- **方差 D(X)** = E(X²) − [E(X)]²，衡量离散程度

### 常见分布

| 分布 | 场景 |
|:---|:---|
| **二项分布** B(n,p) | n 次独立试验，每次成功概率 p |
| **泊松分布** | 单位时间内事件发生次数 |
| **正态分布** N(μ,σ²) | 自然界最常见，钟形曲线 |

**正态分布的 3σ 原则**：约 68% 落在 μ±σ，95% 落在 μ±2σ，99.7% 落在 μ±3σ。

### 例

一批产品次品率 0.1，抽 3 个，恰有 1 个次品的概率：
C(3,1) × 0.1 × 0.9² = 3 × 0.1 × 0.81 = **0.243**

## K2 矩阵与线性方程 ★ L2

### 基本运算

- **加法**：对应元素相加
- **乘法**：A(m×n) × B(n×p) = C(m×p)，**左行乘右列**
- **转置**：行列互换，(AB)ᵀ = BᵀAᵀ
- **逆矩阵**：A × A⁻¹ = I（单位矩阵）

### 矩阵乘法不满足交换律

**AB ≠ BA**。这是最常见的考点。

### 解线性方程组

高斯消元法：化成上三角，回代求解。

## K3 数值计算与误差 ★ L2

| 概念 | 定义 |
|:---|:---|
| **绝对误差** | 近似值 − 真值 |
| **相对误差** | 绝对误差 / 真值 |
| **舍入误差** | 四舍五入造成的误差 |

**误差传播**：加减法看绝对误差，乘除法看相对误差。

## K4 运筹与优化 ★ L1

### 线性规划

目标函数 + 约束条件，求最大/最小。图解法（二维）或单纯形法。

### 决策树

用树形结构表示决策与结果的组合，计算**期望收益**。

**方法**：从叶节点往回算期望，选期望最大的分支。
