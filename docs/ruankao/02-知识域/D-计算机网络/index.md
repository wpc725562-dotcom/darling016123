## D1 OSI 七层与 TCP/IP 四层 ★★★ L1

### 对应关系（必背）

| OSI 七层 | TCP/IP 四层 | 典型协议 | 典型设备 |
|:---|:---|:---|:---|
| 应用层 | **应用层** | HTTP、FTP、SMTP、DNS、Telnet | 网关 |
| 表示层 | ↑ | JPEG、ASCII、加密 | — |
| 会话层 | ↑ | RPC、SQL | — |
| 传输层 | **传输层** | TCP、UDP | — |
| 网络层 | **网络层** | IP、ICMP、ARP、路由协议 | 路由器、三层交换机 |
| 数据链路层 | **网络接口层** | 以太网、PPP、HDLC | 交换机、网桥 |
| 物理层 | ↑ | RS-232、光纤规范 | 中继器、集线器 |

**记忆口诀（从上到下）**：**应表会传网数物**。

### 每层的数据单位

| 层 | 单位 |
|:---|:---|
| 应用层 | 报文 |
| 传输层 | 段（segment） |
| 网络层 | 包（packet） |
| 数据链路层 | 帧（frame） |
| 物理层 | 比特（bit） |

## D2 协议与设备对应 ★★★ L1

### 设备工作在哪一层（高频）

| 设备 | 层 | 作用 |
|:---|:---|:---|
| 中继器 / 集线器（Hub） | 物理层 | 信号放大，**不隔离冲突域** |
| 网桥 / 交换机 | 数据链路层 | 按 MAC 地址转发，**隔离冲突域** |
| 路由器 | 网络层 | 按 IP 转发，**隔离广播域** |
| 网关 | 应用层 | 协议转换 |

**必考判断**：
- 集线器所有端口在**同一个冲突域**
- 交换机每个端口是**独立冲突域**，但整个交换机是**一个广播域**
- 路由器每个接口是**独立广播域**

### 常见协议归属

| 协议 | 层 | 说明 |
|:---|:---|:---|
| HTTP / HTTPS | 应用层 | 超文本传输 |
| FTP | 应用层 | 文件传输，**20 传数据、21 传控制** |
| SMTP | 应用层 | 发邮件 |
| POP3 / IMAP | 应用层 | 收邮件 |
| DNS | 应用层 | 域名解析 |
| DHCP | 应用层 | 动态分配 IP |
| SNMP | 应用层 | 网络管理 |
| Telnet | 应用层 | 远程登录，**明文不安全** |
| **TCP / UDP** | 传输层 | TCP 可靠面向连接；UDP 不可靠无连接 |
| **IP / ICMP / ARP** | 网络层 | ICMP 用于 ping；ARP 把 IP 解析成 MAC |

**注意**：ARP 属于网络层（也有教材归链路层），考试按网络层答。

## D3 IP 地址与子网划分 ★★★ L3

### 基础

IPv4 地址 32 位，点分十进制。分为网络号和主机号，由**子网掩码**划分。

| 类别 | 首字节范围 | 默认掩码 | 说明 |
|:---|:---|:---|:---|
| A | 1–126 | 255.0.0.0 | 大型网络 |
| B | 128–191 | 255.255.0.0 | 中型 |
| C | 192–223 | 255.255.255.0 | 小型 |
| D | 224–239 | — | 组播 |
| E | 240–255 | — | 保留 |

**私有地址**（内网，不路由到公网）：
- A：`10.0.0.0/8`
- B：`172.16.0.0/12`（即 172.16–172.31）
- C：`192.168.0.0/16`

**特殊地址**：
- `127.0.0.1` 回环地址
- `0.0.0.0` 本机
- 主机号全 0 = 网络地址，全 1 = 广播地址，**这两个不能分配给主机**

### 子网划分计算套路

**已知**：IP 地址 + 子网掩码
**求**：网络地址、广播地址、可用主机数、可用主机范围

**步骤**：
1. 把掩码转成二进制，数 1 的个数 = 网络位数 n
2. 主机位数 = 32 − n
3. **可用主机数 = 2^(32−n) − 2**（减掉网络地址和广播地址）
4. 网络地址 = IP 与掩码按位与
5. 广播地址 = 网络地址的主机位全置 1
6. 可用范围 = 网络地址+1 到 广播地址−1

**例**：`192.168.1.130/26`
- 掩码 `/26` → 主机位 6 位 → 每子网 2^6 = 64 个地址
- 可用主机 = 64 − 2 = **62**
- 子网块大小 64，130 ÷ 64 = 2 余 2 → 落在第 2 块（从 0 开始）
- 网络地址 = `192.168.1.128`
- 广播地址 = `192.168.1.191`
- 可用范围 = `192.168.1.129` — `192.168.1.190`

### 易错点

- **可用主机数要减 2**，很多人只算 2^n。
- `/30` 只有 2 个可用地址（点对点链路常用），`/31` 和 `/32` 是特例。
- 子网掩码可以是 `255.255.255.192`（/26）这种非整字节的，要会换算。

## D4 TCP 三次握手与四次挥手 ★★ L2

### 三次握手（建立连接）

```
客户端 —— SYN(seq=x) ——> 服务器
客户端 <— SYN+ACK(seq=y, ack=x+1) — 服务器
客户端 —— ACK(ack=y+1) ——> 服务器
```

**为什么是三次不是两次**：两次无法确认**客户端的接收能力**和**服务器自己的发送能力**同时正常。三次才能双向确认。

### 四次挥手（断开连接）

```
客户端 —— FIN ——> 服务器      （我要关了）
客户端 <— ACK —— 服务器        （知道了）
客户端 <— FIN —— 服务器        （我也要关了）
客户端 —— ACK ——> 服务器      （知道了）
```

**为什么是四次**：TCP 是全双工，两个方向要分别关闭。服务器收到 FIN 后可能还有数据要发，所以 ACK 和 FIN 分开。

**TIME_WAIT 状态**：主动关闭方等待 **2MSL**（最长报文段寿命的 2 倍），确保最后的 ACK 能到达。

### TCP vs UDP

| | TCP | UDP |
|:---|:---|:---|
| 连接 | 面向连接 | 无连接 |
| 可靠性 | 可靠（确认、重传、排序） | 不可靠 |
| 速度 | 慢 | 快 |
| 开销 | 大（20 字节头） | 小（8 字节头） |
| 应用 | HTTP、FTP、SMTP | DNS、DHCP、SNMP、视频流、游戏 |

## D6 网络命令 ★★ L1

| 命令 | 作用 | 判断什么 |
|:---|:---|:---|
| `ping` | 发 ICMP 回显请求 | 目标**通不通**、往返时延 |
| `tracert` / `traceroute` | 逐跳追踪 | 数据包**经过哪些路由** |
| `netstat` | 显示网络连接、路由表、端口监听 | 本机**开了哪些端口**、谁连着 |
| `nslookup` / `dig` | 查询 DNS | 域名**解析成什么 IP** |
| `ipconfig` / `ifconfig` | 查看本机网络配置 | IP、掩码、网关、MAC |
| `arp` | 查看 ARP 缓存 | IP 与 MAC 的映射 |

## D7 域名与 DNS ★★ L1

**递归查询 vs 迭代查询**：
- **递归**：客户端问本地 DNS，本地 DNS 负责问到答案再返回（客户端只问一次）
- **迭代**：本地 DNS 依次问根→顶级→权威，每次返回下一个该问谁（客户端/本地 DNS 多次问）

**通常**：客户端到本地 DNS 是递归，本地 DNS 到外部是迭代。

**域名结构**：主机名.三级域.二级域.顶级域，如 `www.example.com.cn`，**从右往左**层级降低。
