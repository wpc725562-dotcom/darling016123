## 一、计算机组成（A）

| 内容 | 公式 |
|:---|:---|
| n 位补码范围 | **−2^(n−1) ~ +2^(n−1)−1**（8 位：−128~+127） |
| 负数补码 | **原码取反 + 1** |
| 移码 | 补码符号位取反 |
| 地址空间 | n 根地址线 → **2ⁿ** 个单元 |
| 流水线总时间 | **(k + n − 1) × Δt** |
| 流水线吞吐率 | **n / 总时间** |
| 流水线加速比 | **nk / (k + n − 1)**，极限 = k |
| Cache 平均访问时间 | **h × t₁ + (1−h) × t₂** |
| 可靠性串联 | **R₁ × R₂ × ... × Rn** |
| 可靠性并联 | **1 − (1−R₁)(1−R₂)...(1−Rn)** |
| 磁盘存取时间 | 寻道 + 旋转延迟（平均半圈）+ 传输 |
| RAID5 可用容量 | **(n−1)/n** |

### 排序算法（必背）

| 算法 | 平均 | 最坏 | 空间 | 稳定 |
|:---|:---:|:---:|:---:|:---:|
| 直接插入 | n² | n² | 1 | ✅ |
| 希尔 | n^1.3 | n² | 1 | ❌ |
| 冒泡 | n² | n² | 1 | ✅ |
| 快排 | nlogn | **n²** | logn | ❌ |
| 简单选择 | n² | n² | 1 | ❌ |
| 堆排序 | nlogn | nlogn | **1** | ❌ |
| 归并 | nlogn | nlogn | **n** | ✅ |
| 基数 | d(n+r) | d(n+r) | n+r | ✅ |

**稳定**：插冒归基　**不稳定**：希快选堆

### 复杂度排序

**O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)**
