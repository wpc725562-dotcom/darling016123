> 位置：下午场第 4 题（约 15 分）
> 难度：**下午场最难的一题**，也是分水岭。前 3 题稳拿 35 分以上的人，这题决定能不能上 50。

## 一、题目长什么样

给一段**不完整的 C 语言代码**（通常是某个经典算法的实现），挖 3–5 个空，然后问：

1. 补全代码中的空 ①–⑤
2. 该算法的时间复杂度是？
3. 该算法采用了什么设计策略？（分治 / 贪心 / 动态规划 / 回溯）
4. 若输入为 X，输出是什么？

---

## 二、先判断算法类型（决定怎么读代码）

看代码的**结构特征**，30 秒内判断出是哪类：

| 特征 | 算法策略 | 典型题 |
|:---|:---|:---|
| 有 `mid = (low+high)/2`，递归调用两次 | **分治** | 归并排序、二分查找、快排 |
| 有循环，每步选当前最优，不回头 | **贪心** | 活动安排、哈夫曼、最小生成树 |
| 有二维数组 `dp[i][j]`，有状态转移方程 | **动态规划** | 背包、最长公共子序列、最长递增子序列 |
| 有递归 + 撤销操作（`a[i]=0` 回溯） | **回溯** | N 皇后、迷宫、子集和 |

**这一问几乎每年都考，且是送分题**——只要能看出结构，就能答对。

## 三、填空的四种类型（按难度排序）

### 类型 1：循环边界（最简单）

```c
for (i = 0; i < __①__; i++)
```

**怎么填**：看循环要处理多少元素。数组长度是 n 就填 `n`；如果是 `n-1` 趟排序就填 `n-1`。

**技巧**：看循环体里用到的下标最大值，边界要比它大 1。

### 类型 2：数组下标（中等）

```c
a[__②__] = a[j];
```

**怎么填**：根据算法语义推断。比如插入排序是"把元素后移"，填 `j+1`。

**技巧**：在纸上画出数组，标出每一步 i、j 的值，对照着填。

### 类型 3：条件判断（中等偏难）

```c
if (__③__) { ... }
```

**怎么填**：看 if 里面做了什么，反推条件。

**技巧**：
- 如果是"找最小值"，条件多半是 `a[i] < min`
- 如果是"判断是否满足约束"，条件多半是 `xxx <= yyy`
- 如果是"边界检查"，条件多半是 `i < n`

### 类型 4：递归调用参数（最难）

```c
return f(__④__) + f(__⑤__);
```

**怎么填**：看递归的分解方式。

- 归并排序：`f(low, mid)` 和 `f(mid+1, high)`
- 二分查找：`f(low, mid-1)` 或 `f(mid+1, high)`
- 快速排序：`f(low, p-1)` 和 `f(p+1, high)`

**技巧**：递归调用的参数范围必须**不重叠且覆盖完整**。

## 四、四种经典算法的代码骨架（背下来）

### 1. 二分查找

```c
int binSearch(int a[], int n, int key) {
    int low = 0, high = n - 1, mid;
    while (low <= high) {              // ← 常挖：low <= high
        mid = (low + high) / 2;        // ← 常挖
        if (a[mid] == key) return mid;
        else if (a[mid] < key) low = mid + 1;   // ← 常挖
        else high = mid - 1;           // ← 常挖
    }
    return -1;
}
```

**复杂度**：O(log n)　**策略**：分治（也可说减治）

### 2. 归并排序

```c
void mergeSort(int a[], int low, int high) {
    if (low < high) {
        int mid = (low + high) / 2;
        mergeSort(a, low, mid);        // ← 常挖
        mergeSort(a, mid + 1, high);   // ← 常挖
        merge(a, low, mid, high);
    }
}
```

**复杂度**：O(n log n)　**策略**：分治

### 3. 0-1 背包（动态规划）

```c
for (i = 1; i <= n; i++) {
    for (j = 1; j <= W; j++) {
        if (w[i] > j)
            dp[i][j] = dp[i-1][j];                    // ← 常挖：装不下
        else
            dp[i][j] = max(dp[i-1][j],
                           dp[i-1][j-w[i]] + v[i]);   // ← 常挖：装 or 不装
    }
}
```

**复杂度**：O(nW)　**策略**：动态规划

**关键理解**：`dp[i][j]` = 前 i 个物品、容量 j 时的最大价值。转移时比较"不装第 i 个"和"装第 i 个"。

### 4. 最长递增子序列（动态规划）

```c
for (i = 1; i < n; i++) {
    dp[i] = 1;
    for (j = 0; j < i; j++)
        if (a[j] < a[i] && dp[j] + 1 > dp[i])   // ← 常挖
            dp[i] = dp[j] + 1;
}
```

**复杂度**：O(n²)　**策略**：动态规划

### 5. N 皇后（回溯）

```c
void queen(int row) {
    if (row == n) { count++; return; }
    for (int col = 0; col < n; col++) {
        if (isSafe(row, col)) {
            a[row] = col;          // ← 放置
            queen(row + 1);        // ← 递归下一行
            a[row] = -1;           // ← 撤销（回溯）
        }
    }
}
```

**复杂度**：O(n!)　**策略**：回溯

## 五、复杂度怎么答

### 看循环层数

| 代码结构 | 复杂度 |
|:---|:---|
| 单层循环到 n | O(n) |
| 双层嵌套都到 n | O(n²) |
| 单层但 `i *= 2` | O(log n) |
| 递归分两半 | O(n log n) |
| 二维 dp 表 n×W | O(nW) |

### 递归式的解法

| 递归式 | 复杂度 |
|:---|:---|
| T(n) = 2T(n/2) + O(n) | O(n log n) |
| T(n) = 2T(n/2) + O(1) | O(n) |
| T(n) = T(n-1) + O(1) | O(n) |
| T(n) = T(n-1) + O(n) | O(n²) |

## 七、易错点清单

| 错误 | 后果 | 正确做法 |
|:---|:---|:---|
| 数组下标从 1 开始算 | 全错 | C 语言数组**从 0 开始**，看代码怎么定义 |
| 循环边界写 `<=` 还是 `<` | 差一错误 | 看数组长度和下标范围 |
| 复杂度写成 O(n²) 但实际是 O(n log n) | 扣分 | 注意 `i*=2` 和递归分半 |
| 算法策略答"递归" | 扣分 | 要答"分治/贪心/动规/回溯"，递归是实现方式不是策略 |
| 递归参数范围重叠或遗漏 | 逻辑错 | 检查 `[low,mid]` + `[mid+1,high]` 是否覆盖 `[low,high]` |

## 八、示例题（自编，非真题）

> 按考点自编，非真题。

**代码**：

```c
int f(int a[], int n) {
    int i, j, max = 1;
    int dp[100];
    for (i = 0; i < n; i++) {
        dp[i] = ① ;
        for (j = 0; j < i; j++) {
            if ( ② ) {
                dp[i] = dp[j] + 1;
            }
        }
        if (dp[i] > max) max = dp[i];
    }
    return max;
}
```

**问题**：
1. 补全 ① 和 ②
2. 该算法的时间复杂度是？
3. 该算法采用什么设计策略？
4. 若输入 a = \{3, 1, 4, 1, 5, 9, 2, 6\}，输出是什么？

**参考答案**：

1. ① `1`（每个元素自身构成长度为 1 的序列）
   ② `a[j] < a[i] && dp[j] + 1 > dp[i]`（前一个元素更小，且接上后更长）

2. **O(n²)**（双层循环）

3. **动态规划**（有 dp 数组记录子问题解，有状态转移）

4. **4**（最长递增子序列可以是 1,4,5,9 或 1,2,6 等，最长长度 4）
