## 一、题目长什么样

给你：
1. 一张**类图**（有类名、属性、方法、关系）
2. 一段**不完整的代码**（Java 或 C++，二选一）

让你填 4–6 个空，通常是：
- 类名 / 接口名
- 继承或实现的关键字与父类名
- 方法签名（返回类型、参数）
- 方法体中的关键语句
- 访问修饰符

## 二、先做一件事：把类图翻译成代码骨架

### 类图元素的代码对应

| 类图元素 | Java | C++ |
|:---|:---|:---|
| 类 | `class Name { }` | `class Name { };` |
| 接口 | `interface Name { }` | 纯虚类 |
| 抽象类 | `abstract class` | 含纯虚函数 |
| 继承（泛化） | `extends` | `: public` |
| 实现接口 | `implements` | `: public` |
| 私有属性 | `private` | `private:` |
| 公有方法 | `public` | `public:` |
| 保护成员 | `protected` | `protected:` |

### 类图符号速查

```
+  public（公有）
-  private（私有）
#  protected（保护）
_  下划线 = 静态成员
斜体 = 抽象方法
```

### 关系对应

| 类图关系 | Java 代码表现 |
|:---|:---|
| 泛化（空心三角实线） | `class A extends B` |
| 实现（空心三角虚线） | `class A implements I` |
| 关联（实线） | 成员变量：`private B b;` |
| 聚合/组合（菱形） | 成员变量：`private List<B> list;` |
| 依赖（虚线箭头） | 方法参数或局部变量 |

## 三、填空的五个高频位置

### 位置 1：类名 / 接口名

**题目**：`public class ____ {`

**怎么填**：看类图里对应的类叫什么，或者看上下文（`new Xxx()` 里出现的名字）。

### 位置 2：继承 / 实现

**题目**：`public class Dog ____ Animal {`

**怎么填**：
- 类图是**空心三角实线** → `extends`
- 类图是**空心三角虚线** → `implements`

**注意**：Java 只能单继承类，但可以多实现接口。所以 `implements A, B` 是合法的，`extends A, B` 不合法。

### 位置 3：方法签名

**题目**：`public ____ getArea(____) {`

**怎么填**：
- 返回类型看类图上方法的返回类型
- 参数看类图上方法的参数列表

**技巧**：如果方法体里有 `return area;` 且 area 是 double，返回类型就是 `double`。

### 位置 4：方法体中的关键语句

**题目**：
```java
public double getArea() {
    return ____;
}
```

**怎么填**：看这个方法要算什么。圆的面积就是 `Math.PI * r * r`。

### 位置 5：访问修饰符

**题目**：`____ int age;`

**怎么填**：看类图上的符号。`-` → `private`，`+` → `public`，`#` → `protected`。

## 四、多态相关的填空（高频）

### 场景：父类引用指向子类对象

```java
Animal a = new Dog();   // 向上转型
a.speak();              // 调用的是 Dog 的 speak（动态绑定）
```

**常挖**：
- `Animal a = ____;` → 填 `new Dog()`
- 判断输出结果 → 看**运行时类型**，不是声明类型

### 抽象类与抽象方法

```java
abstract class Shape {
    abstract double getArea();   // 抽象方法，无方法体
}

class Circle extends Shape {
    double r;
    double getArea() { return Math.PI * r * r; }   // 必须实现
}
```

**常挖**：
- `____ class Shape` → 填 `abstract`
- 子类必须实现父类的抽象方法，否则子类也要声明为 abstract

### 接口

```java
interface Flyable {
    void fly();          // 接口方法默认 public abstract
}

class Bird implements Flyable {
    public void fly() { System.out.println("flying"); }
}
```

**常挖**：
- `class Bird ____ Flyable` → 填 `implements`
- 实现接口的方法必须是 `public`（不能降低访问权限）

## 五、Java 与 C++ 的差异（选做时注意）

| | Java | C++ |
|:---|:---|:---|
| 继承关键字 | `extends` | `: public Base` |
| 接口 | `interface` + `implements` | 纯虚类 + `: public` |
| 析构 | 有 GC，无析构 | `~ClassName()` |
| 虚函数 | 默认动态绑定 | 必须写 `virtual` |
| 内存 | 自动回收 | 手动 `new`/`delete` |
| 输出 | `System.out.println()` | `cout <<` |
| 字符串 | `String` | `string` 或 `char*` |

**建议**：**选你更熟的那个**。你有 Java 工程经验，选 Java 更稳。

## 六、答题模板

### 填空

直接写代码片段，不要写解释：

```
① Shape
② extends
③ abstract
④ Math.PI * r * r
⑤ implements
```

### 问"为什么用接口而不是抽象类"

> 因为需要多继承行为（一个类可以实现多个接口），且接口只定义规范不包含实现，更符合"面向接口编程"的原则。

## 七、易错点清单

| 错误 | 后果 | 正确做法 |
|:---|:---|:---|
| `extends` 和 `implements` 搞反 | 扣分 | 实线→extends，虚线→implements |
| 实现接口的方法忘了 `public` | 编译错 | 接口方法实现必须是 public |
| 抽象方法写了方法体 | 编译错 | 抽象方法没有 `{}` |
| 多态题按声明类型判断 | 答错 | 按**运行时类型** |
| C++ 忘了 `virtual` | 静态绑定 | 多态必须 virtual |
| 访问修饰符看错符号 | 扣分 | `-` private、`+` public、`#` protected |

## 八、示例题（自编，非真题）

> 按考点自编，非真题。

**类图**（文字描述）：
- 抽象类 `Shape`，有抽象方法 `getArea()` 和 `getPerimeter()`
- 类 `Circle` 继承 `Shape`，私有属性 `r`（double），实现两个方法
- 类 `Rectangle` 继承 `Shape`，私有属性 `w`、`h`，实现两个方法
- 接口 `Drawable`，有方法 `draw()`；`Circle` 实现它

**代码**：

```java
① class Shape {
    public ② double getArea();
    public abstract double getPerimeter();
}

class Circle ③ Shape ④ Drawable {
    ⑤ double r;

    public Circle(double r) { this.r = r; }

    public double getArea() {
        return ⑥ ;
    }

    public double getPerimeter() {
        return 2 * Math.PI * r;
    }

    public void draw() {
        System.out.println("Drawing circle");
    }
}
```

**参考答案**：

① `abstract`
② `abstract`
③ `extends`
④ `implements`
⑤ `private`
⑥ `Math.PI * r * r`
