# 下午题 01 · 数据流图（DFD）

> 位置：下午场第 1 题（约 15 分）
> 难度：中低。**这是下午场最容易拿满的一道题**，套路固定，几乎每年都是同样的四问。

---

## 一、题目长什么样

给你一段业务描述（比如"某图书馆借阅系统"），配一张**不完整的 DFD 图**，然后四问：

1. **写出图中的外部实体 E1–E4 分别是什么**
2. **写出数据存储 D1–D4 分别是什么**
3. **补全缺失的数据流**（给出起点、终点、数据流名称）
4. **某加工需要什么输入 / 输出什么**

有时还会问："图中 X 处的数据流应该是什么方向？"

---

## 二、四类元素的识别方法（核心）

| 元素 | 图形 | 怎么从题干里认出来 |
|:---|:---|:---|
| **外部实体** | 矩形 | 题干里的**人、组织、外部系统**。如"读者""管理员""银行系统" |
| **加工（处理）** | 圆角矩形 / 圆 | 题干里的**动词短语**。如"验证身份""计算罚款""生成报表" |
| **数据存储** | 开口矩形 / 双横线 | 题干里的**名词性数据集合**。如"读者表""借阅记录""图书库存" |
| **数据流** | 箭头 | 数据在元素之间的**流动**，必须命名 |

### 判断口诀

- **谁在用系统** → 外部实体
- **系统做了什么** → 加工
- **数据存在哪** → 数据存储
- **数据怎么走** → 数据流

---

## 三、解题步骤（照着做）

### 第 1 步：先找外部实体（最简单，先拿分）

扫题干，把所有"人 / 组织 / 外部系统"圈出来。

**特征词**：
- "……员"（管理员、操作员、审核员）
- "……者"（读者、用户、客户）
- "……系统"（银行系统、支付系统、短信平台）
- "……部门"（财务部、人事部）

**注意**：题干里反复出现的、系统**之外**的角色，都是外部实体。

### 第 2 步：再找数据存储

扫题干，找"**系统要保存什么**"。

**特征词**：
- "……表"（学生表、订单表）
- "……库"（题库、库存）
- "……记录"（借阅记录、操作日志）
- "……档案"（人事档案）

**技巧**：数据存储通常是**名词**，且能被"增删改查"。

### 第 3 步：补数据流（最容易丢分）

**方法：对每个加工，问三个问题**

1. 它需要什么**输入**？从哪来？
2. 它产生什么**输出**？到哪去？
3. 中间要不要**读/写**某个存储？

**补数据流的四条铁律**：

| 规则 | 说明 |
|:---|:---|
| **外部实体之间不能直接有数据流** | 必须经过加工 |
| **数据流必须命名** | 不能只画箭头 |
| **数据流不能双向** | 两个方向画两条 |
| **每个加工必须有输入和输出** | 不能只有输入没有输出（"黑洞"），也不能只有输出没有输入（"奇迹"） |

### 第 4 步：检查平衡

**父图与子图平衡**：父图中某加工的输入输出，必须与子图中该加工的输入输出**一致**（数量、名称）。

题目常在这里挖坑：子图多了一条父图没有的数据流，或者少了一条。

---

## 四、常见挖空点与应对

### 挖空点 1：外部实体的名字

**题目形式**："E1 是____"

**怎么答**：回到题干，找那个**发起或接收**该数据流的角色。

**例**：图中"借书请求"数据流从一个矩形指向加工"处理借阅"，题干说"读者提交借书请求"→ E1 是**读者**。

### 挖空点 2：数据存储的名字

**题目形式**："D1 是____"

**怎么答**：看这个存储被哪个加工**读或写**，以及读写的数据内容。

**例**：加工"处理借阅"要写入"借阅信息"，D1 被它写入 → D1 是**借阅记录表**。

### 挖空点 3：缺失的数据流

**题目形式**："加工 P3 还缺少一条输入数据流，请补充"

**怎么答**：
1. 看 P3 的功能描述，它需要什么数据才能工作
2. 这个数据现在在哪个存储/实体里
3. 从那里画一条箭头到 P3，命名

**答题格式**（必须写全三要素）：
> 起点：D2 图书库存表
> 终点：P3 计算可借数量
> 数据流名称：图书库存数量

### 挖空点 4：数据流的起点或终点

**题目形式**："数据流 X 应该从____流向____"

**怎么答**：判断这个数据是"被产生"还是"被使用"。产生方是起点，使用方是终点。

## 五、答题模板

下午场是手写（机考是打字），答案要**简洁但完整**。

### 外部实体 / 数据存储

```
E1：读者
E2：图书管理员
D1：图书信息表
D2：借阅记录表
```

**不要写解释**，直接给名字。

### 数据流

```
缺失数据流：
起点：D1 图书信息表
终点：P2 验证借阅资格
名称：图书库存状态
```

**三要素缺一不可**，只写名称不给分。

---

## 六、易错点清单

| 错误 | 后果 | 正确做法 |
|:---|:---|:---|
| 把"加工"当成"外部实体" | 全错 | 加工是**动词**，实体是**名词**（人或系统） |
| 数据流不命名 | 扣分 | 每条箭头都要有名字 |
| 外部实体之间画数据流 | 扣分 | 必须经过加工中转 |
| 只写数据流名称不写起终点 | 0 分 | 三要素齐全 |
| 忽略父子图平衡 | 该问全错 | 逐条比对父图子图 |
| 数据存储写成"数据库" | 太笼统 | 写具体：图书信息表 |

## 七、示例题（自编，非真题）

> 说明：以下为按考点自编的示例，用于演示解题流程，不是真题。

**背景**：某高校教材订购系统。教师向系统提交教材订购申请；系统验证申请后，将订单发送给供应商；供应商发货后，系统更新库存记录；管理员可查询库存和订单统计。

**图中有**：外部实体 E1、E2；加工 P1"验证申请"、P2"生成订单"、P3"更新库存"；数据存储 D1、D2。

**问题**：
1. E1、E2 分别是什么？
2. D1、D2 分别是什么？
3. P3 缺少一条输入数据流，请补充。

**参考答案**：

1. E1 = **教师**（提交订购申请），E2 = **供应商**（接收订单、发货）
   - 管理员也是外部实体，但题干中"管理员可查询"对应的是查询加工，如果图中没有对应加工，则管理员不在本图范围

2. D1 = **教材订购申请表**（P1 验证的对象），D2 = **库存记录表**（P3 更新的对象）

3. 起点：**供应商**（外部实体），终点：**P3 更新库存**，名称：**发货信息**
   - 理由：P3 的功能是"更新库存"，它需要知道"实际到了多少货"，这个信息来自供应商的发货动作

---

## 八、练习建议

1. 找 3 套真题的第 1 题，**只做不看答案**，做完对照
2. 重点练"补数据流"这一问——它最容易丢分
3. 每做完一套，用"四条铁律"检查自己的答案

**目标**：这道题拿 12 分以上（满分约 15）。它是下午场最稳的得分点。
