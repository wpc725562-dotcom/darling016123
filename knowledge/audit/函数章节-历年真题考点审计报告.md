## 3️⃣ 历年真题高频考察子知识点完整清单

1. **值传递**：实参→形参单向拷贝，形参改变不影响实参（2021、2023、2024、2026 四年全考）
2. **递归求和/递归思想**：2023 计算 `sub(6)`=21（1+2+...+6），且 i 仍为 6（值传递+递归融合）
3. **指针形参**：`void add(int x, int y, int *z){ *z = x + y; }`（2024 填空1）
4. **作用域**：复合语句内变量离开 `}` 不可访问（2024 判断3）；不同函数同名变量互不影响（2024 判断4）
5. **return 规则**：一次 return 只能返回一个值（2021 单选）；被调函数可以不用 return（2021）
6. **数组作参数**：数组名作函数参数传递的是首地址（2022 单选10）；函数内可改原数组
7. **嵌套调用**：C 支持嵌套调用（2023 判断6 ✅）；不允许嵌套定义
8. **递归优缺点**：简洁但栈开销大（2023 简答4）
9. **函数声明**：定义在调用之后需先声明；声明可省略形参名
10. **局部变量/栈帧**：各函数局部变量在各自栈帧（2024 判断4 解析）

## 4️⃣ 真题高频易错丢分陷阱清单

| 陷阱 | 错误表现 | 正确理解 | 出处 |
|:---|:---|:---|:---|
| 值传递误以为能改 | 写 swap(a,b) 以为交换了 | 形参是实参拷贝，**交换不了** | 2024 |
| 数组名当值传递 | 以为数组作参数是拷贝 | 数组名作参数**传地址**，能改原数组 | 2022 单选10 |
| return 返回多值 | 以为一个 return 能返回多个值 | 一次 return **只能返回一个值** | 2021 单选 |
| 作用域混淆 | 以为 `{}` 内变量块外可用 | 离开 `}` 即失效 | 2024 判断3 |
| 同名变量冲突 | 以为不同函数同名会冲突 | 各自栈帧，互不影响 | 2024 判断4 |
| 递归死循环 | 忘写递归出口 | 必须有终止条件 | 2023 简答 |
| 递归栈溢出 | 大数硬递归 | 大数据用迭代替代 | 2023 简答 |
| 指针形参忘解引用 | 填 `z = x + y` | 必须 `*z = x + y` | 2024 填空1 |
| 递归后原变量变化 | 以为 sub 后 i 变了 | 值传递，i 仍为原值 | 2023 计算 |
| 嵌套定义误解 | 以为 C 支持函数内定义函数 | C **不允许**嵌套定义，只允许嵌套调用 | 2023 判断6 |
