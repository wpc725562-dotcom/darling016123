## 二、数据结构模块图谱

### 2.1 绪论 → [2.1-数据结构基本概念](../docs/posts/computer/notes/2.1-数据结构基本概念.md)
- 数据/数据元素/数据项、逻辑结构（集合/线性/树/图）、存储结构（顺序/链式/索引/散列）、ADT
- 关联：2.9 算法分析
- **2024真题**：数据项、ADT

### 2.2 线性表 → [2.2-线性表](../docs/posts/computer/notes/2.2-线性表.md)
- 顺序表（数组实现）：随机存取 O(1)、插入删除 O(n)
- 链表（单/双/循环）：插入删除 O(1)（已知位置）、查找 O(n)
- **2024真题**：顺序表优缺点
- **高频简答题**：顺序表与链表的区别

### 2.3 栈和队列 → [2.3-栈和队列](../docs/posts/computer/notes/2.3-栈和队列.md)
- 栈 LIFO：括号匹配、表达式求值、递归、函数调用栈
- 队列 FIFO：缓冲区、任务调度、层序遍历（BFS 用队列）
- 循环队列：队空/队满判断（front==rear 与牺牲一个单元）
- **高频简答题**：栈和队列的特点及应用

### 2.4 串/数组/广义表 → [2.4-串、数组和广义表](../docs/posts/computer/notes/2.4-串、数组和广义表.md)
- 串的模式匹配（BF/KMP）、特殊矩阵压缩存储（对称/三角/稀疏）
- 关联：1.6 数组、1.10 文件

### 2.5 树和二叉树 ★ → [2.5-树和二叉树](../docs/posts/computer/notes/2.5-树和二叉树.md)
- 二叉树性质（n0=n2+1）、满/完全二叉树、存储（顺序/链式）、遍历（先/中/后/层序）、线索化、哈夫曼树与编码
- 先序+中序唯一确定二叉树
- 关联：2.3 队列（层序）、2.8 排序（堆）、1.7 函数（递归）
- **高频简答题**：二叉树遍历（先序/中序/后序）

### 2.6 图 → [2.6-图](../docs/posts/computer/notes/2.6-图.md)
- 存储：邻接矩阵/邻接表
- 遍历：DFS（栈/递归）、BFS（队列）
- 最小生成树（Prim/Kruskal）、最短路径（Dijkstra/Floyd）、拓扑排序
- **2024真题**：有向图出入度
- 关联：2.3 队列、2.5 树（生成树）

### 2.7 查找 → [2.7-查找](../docs/posts/computer/notes/2.7-查找.md)
- 顺序/折半（有序）、二叉排序树（BST）、平衡二叉树、散列表（哈希）、冲突处理（开放定址/链地址）
- **高频简答题**：顺序查找 vs 折半查找
- 关联：2.5 树（BST）、2.8 排序

### 2.8 排序 → [2.8-排序](../docs/posts/computer/notes/2.8-排序.md)
- 插入类（直接/希尔）、交换类（冒泡/快排）、选择类（直接/堆）、归并、基数
- 稳定性与复杂度对照（见易错点对照表 #27）
- **高频简答题**：排序算法的稳定性和时间复杂度
- 关联：2.5 树（堆）、2.7 查找

### 2.9 算法分析 → [2.9-算法基本概念与分析](../docs/posts/computer/notes/2.9-算法基本概念与分析.md)
- 时间/空间复杂度、大O表示、常见复杂度排序
- 关联：2.1 绪论、全模块
