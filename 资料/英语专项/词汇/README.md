# 英语 · 词汇

> 本目录存放**英语词汇类资料**：词汇表、固定搭配、完形填空高频词等。

---

## 为什么单独立子目录

`资料/英语专项/` 下已有两个**按题型**建的子目录（`完形填空100篇/`、`语法填空63篇/`），但**缺「词汇」这一类**。词汇是英语四类资料里唯一按「语言单位」而非「题型」划分的，单独立目录更清晰。

## 收录范围

| 收录 | 不收录 |
|:---|:---|
| 考纲词汇表 / 必背词表 | 真题（→ `历年真题/公共英语/`） |
| 固定搭配、短语汇总 | 语法专项（→ `资料/英语专项/语法填空63篇/`） |
| 完形填空高频词表 | 阅读技巧类方法资料（→ `资料/方法资料/`） |

## 命名规则

```
<内容描述><数量>词汇.pdf / .md
```

**规则**：去掉原文件名里的 `(1)` `(2)` 等重复下载后缀；年份范围用 `YYYY-YYYY`；不用空格，用连字符。

3. 词表之间的重叠要主动合并，不要叠加使用。
