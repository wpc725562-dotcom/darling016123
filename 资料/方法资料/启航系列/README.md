# 启航系列（方法资料）

> 本目录存放**机构方法论资料**：学习路线图、入门讲义、新手问答等。与学科知识解耦，不混入任何学科目录。

---

## 为什么单独立目录

「启航」这类资料的特点是：**跨学科**、**讲怎么学而不是学什么**。如果塞进 `资料/2026精编讲义/` 或某个学科目录，会污染学科知识的纯净度。单独立目录，也方便日后判断「这类方法论资料到底有没有用」。

## 收录范围

| 收录 | 不收录 |
|:---|:---|
| 学习路线图 / 备考规划 | 学科知识讲解（→ 各学科目录） |
| 零基础入门讲义 | 真题与答案（→ `历年真题/`） |
| 新手常见问题解答 | 考点速记（→ `资料/2026黄金知识汇编/`） |
| 错因总结、方法论手册 | 词汇表（→ `资料/英语专项/词汇/`） |

## 命名规则

```
<系列名><序号>-<标题>.md
```

**规则**：保留资料原有的序号（①②③）；用连字符 `-` 分隔序号与标题；不用空格；序号用阿拉伯数字或原符号均可，但**同一系列内保持一致**。
