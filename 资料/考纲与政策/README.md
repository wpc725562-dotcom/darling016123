# 考纲与政策

> 本目录存放**界定「考什么」**的官方文件：考试大纲、政策文件、考纲解读、试卷结构说明。

---

## 为什么单独立目录

考纲是**一切复习的起点**——它决定哪些是必考、哪些可以战略放弃。本库此前考纲信息散落在 `资料/2026讲义/`、`历年真题/` 各科的 `_索引.md` 里，**没有统一入口**。本目录解决这个问题。

## 收录范围

| 收录 | 不收录 |
|:---|:---|
| 省考试院发布的考试大纲 | 机构自己编的「考点预测」 |
| 招生政策文件（报名、考试安排） | 学科知识讲解 |
| 试卷结构 / 题型分值表 | 真题原卷（→ `历年真题/`） |
| 参考书目清单 | 教材实体（→ `资料/政治理论教材/` 等） |

## 命名规则

| 类型 | 格式 | 示例 |
|:---|:---|:---|
| 考试大纲 | `广东专升本考试大纲-YYYY.pdf` | `广东专升本考试大纲-2024.pdf` |
| 政策文件 | `广东专升本政策文件-YYYY.pdf` | `广东专升本政策文件-2025.pdf` |
| 考纲文本 | `广东专升本考纲-YYYY.md` | `广东专升本考纲-2025.md` |
| 试卷结构分析 | `<学科>-试卷结构分析.md` | `公共英语-试卷结构分析.md` |

**规则**：年份用四位阿拉伯数字，用连字符 `-` 不用空格；统一把年份放**末尾**，便于按类型聚类后自然按年排序。

## 使用说明

1. **先看考纲，再看真题**——考纲定边界，真题验手感，顺序不要倒。
2. **考纲按年更新**，跨年会有微调（题型分值、时事考核区间）。复习以**报考当年**的大纲为准。
3. 本目录的文件是 **A 级来源**（官方公开），可信度最高，但**不替代**正版纸质材料。
