用法：先看公式，再看下面那句 人话。两样都能说出来，才算真懂。 答案是折叠的 —— 先自己想 30 秒再点开，直接点开等于没练。

一、先把符号读成人话

人话：「x 越变越大的时候， 最终会靠近哪个数？」
记号读作是什么意思
极限 / limit最终会靠近哪个数
x 趋向无穷大x 一直变大、没有尽头（不是等于某个很大的数）
无穷大它不是一个数，是「无限变大」这个趋势

二、x→∞ 时只有两种下场

① 靠近某个确定的数 → 答案就写那个数。 ② 一路变大没有边 → 答案写 （也可以说"极限不存在"）。

判断方法：看 站在上面还是下面。 在下面（分母）→ 被无限分掉 → 靠 0；在上面（分子）→ 越乘越大 → 往无穷跑。

验算一下就知道为什么：， → 明显在往 0 走。

三、抓大头（分子分母都有 x 时用）

唯一一招：谁长得最快，谁说了算。
口诀：加减的都是配角，只有乘 的才是主角。

正规写法是分子分母同除以 x 的最高次幂；但脑子里想的其实是「」。

三条速查结论（， 为非零常数）

长啥样结果为什么
上下 x 最高次数一样 主角约掉，配角全消失
上面次数更高上面长得快，压不住
下面次数更高下面长得快，全被分掉

四、⚠️ 分岔口：x→∞ 和 x→0 是两套规则

这是这一节唯一的陷阱。做题第一动作不是算，是先看箭头指向哪里。 口诀：看箭头 → 定方法。
题目写的意思是怎么想
x 越来越大用抓大头；
x 越来越接近 0（但≠0）直接把 0 代进去，能算出来就是答案
同一个 ，箭头一换，答案完全相反。

如果 代进去得到 这种"上下都变 0"的形状，那是另一套办法（等价无穷小 / 洛必达），现阶段不碰。

五、做题三步流程（考场照这个走）

1. 读符号 —— 把式子用嘴说成一句人话。说不出来就别往下算。
2. 看箭头 —— 指 就抓大头；指 就先代值。
3. 写出等号和一个数 —— ⚠️ 光把条件翻译成人话不算做完。

第 3 步是你 09-09 丢分的地方：卷面上没写「= 0」，等于没做。
