## 三卷结论（直接决定完形怎么练）

**固定搭配（B）20/45 = 44%、词义辨析（A）20/45 = 44%，两项合计 89%。**语法形式只 0 空，语篇衔接 5 空。

完形考的是**词汇**，不是语法：

1. **背搭配，不是背单词表。** 三卷 45 空里近半是固定搭配（do more housework / result of / be published / proud of / dream of / make it / long for / perform better）。孤立的单词表帮不上，要背「动词＋名词」「形容词＋介词」的组合。
2. **词义辨析靠上下文的同义反义。** 另一半是近义词辨析，判定依据永远是空前空后的复现词或转折词，不是词频。
3. **语法笔记（E1–E18）对完形几乎没用。** 三卷 45 空里语法形式 0 空——这是最反直觉的一条。
4. **错因标注是给你复盘用的。** 做错一题，先看它属于 A 还是 B；A 类回原文找线索词，B 类直接进搭配本。
