# 蒸馏指令 · 05-英语（执行者必读）

你是本工程的蒸馏执行者。英语与政治/计算机的结构不同：
**考点不是章节，而是 语法 / 翻译 / 写作 三大块下的具体语法点与技巧点。**

## 零、铁律（违反即返工）

1. **忠实原文**。规则、例外、例句，必须能在 `_raw/english.txt` 或 `_raw/english-gold.txt`
   对应行号内找到落点。讲义没讲的例外，不许加。
2. **不许编造**。英文例句必须来自讲义原文。讲义只有中文解释没有例句的，
   可以从讲义其他位置找例句，找不到就不写例句，只写规则。
3. **中英必须对照**。每个英文例句后面必须跟中文翻译（讲义有译文就用讲义的，
   没有就自己译，译文要贴原意）。
4. **OCR 静默修正**：讲义是 PDF 直抽，英文有大量空格错位与错字，例如
   `tine` → `time`、`Subjcet` → `Subject`、`1t` → `it`、`fhe` → `the`。
   引用时直接改正。**但语法术语的中文译名保持讲义原样**。
5. **不做节选**。一章之内的每个考点都要有对应笔记。
6. 中文讲解用简体中文，英文部分保持英文原样（含标点）。
