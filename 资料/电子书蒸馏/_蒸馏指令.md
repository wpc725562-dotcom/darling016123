## 三、格式契约（逐字照抄结构，不许改字段名）

```

------------------------------------------------------------
（用箭头画出本章的论证结构，A → B → C）

------------------------------------------------------------
（4-6 条，从原文摘，能直接用于主观题）

------------------------------------------------------------
（把本章最容易串的 2-4 组概念并排列出，写清差异）
```

### 3.2 考点笔记

```
【课程】02-习概
【章节】第N章　<完整章名>
【节】第M节　<完整节名>
【考点】N-M-K　<完整考点名>
【考频】★★★★☆
【题型】单选、多选、简答
============================================================

一、结论
------------------------------------------------------------
（2-4 行，一句话抓住这个考点在讲什么）

二、必背要点
------------------------------------------------------------
（主体。分条列，每条先给结论再给展开。原文的并列项一条不许漏。
 有数字概括的（如"三个意味着""五个必由之路"）必须完整列出。）

三、易错辨析
------------------------------------------------------------
× <常见错误理解>
√ <正确表述>
（3-5 组，每组都要能对应到具体考点）

四、关键词 / 固定表述
------------------------------------------------------------
（本章的专有提法，用 · 分隔）

五、可出题角度
------------------------------------------------------------
· 单选：……
· 多选：……
· 简答：……
· 材料：……

============================================================
【原文锚点】第N章第M节"<考点名>"
```

考频标注规则：核心概念、有数字概括的、反复出现的 → ★★★★★；
一般原理 → ★★★★☆；背景性、意义性 → ★★★☆☆；纯了解 → ★★☆☆☆。
