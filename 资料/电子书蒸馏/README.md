## 二、txt 格式契约

四科模板不同，因为四科的"考点"性质不同。四份指令文件是唯一权威：

| 科 | 指令文件 | 特点 |
|:---|:---|:---|
| 政治 | `_蒸馏指令.md` | 三级标题层级，考"固定提法" |
| 计算机 | `_蒸馏指令-计算机.md` | **考点笔记必须带可编译 C 代码**，考"读程序写结果" |
| 高数 | `_蒸馏指令-高数.md` | **公式一律 LaTeX**，考"算"，必须配题型解法索引 |
| 英语 | `_蒸馏指令-英语.md` | **中英对照**，每个英文例句必须跟中文译文 |

### 2.1 通用头部（所有文件）

```
【课程】01-毛中特 | 02-习概 | 03-计算机 | 04-高数 | 05-英语
【章节】第一章 毛泽东思想及其历史地位
【节】第一节 毛泽东思想的形成和发展
【考点】1-1-1 毛泽东思想形成发展的历史条件
【考频】★★★★☆
【题型】单选 / 多选 / 简答
============================================================
```

### 2.2 政治考点笔记

```
一、结论（一句话抓住）
二、必背要点（分条，考场可直接默写）
三、易错辨析（真题踩坑点）
四、关键词 / 时间 / 人物 / 著作
五、可出题角度
============================================================
【原文锚点】《毛泽东思想和中国特色社会主义理论体系概论》第一章第一节
```

### 2.3 计算机考点笔记

```
一、结论
二、规则 / 要点
三、代码示例（可编译）      ← 必有，带中文注释 + 运行结果
四、易错辨析（具体到代码层面）
五、关键词 / 固定表述
六、可出题角度
============================================================
【原文锚点】C第N章 <小节号>"<考点名>"（computer.txt 第 X–Y 行）
```

### 2.4 高数考点笔记

```
（学科系统 / 秒杀类比）
一、核心知识解构
二、规则与条件
三、考试红牌警告与秒杀秘籍
四、闭卷真题挑战（含答案与解析）
============================================================
【原文锚点】《高等数学》精编讲义 第N章
```

### 2.5 英语考点笔记

```
一、一句话结论
二、规则            ← 每条规则后跟英文例句 + 中文译文
三、例外与特殊情况
四、易错辨析（× 错误写法 / √ 正确写法）
五、固定搭配 / 关键词
六、可出题角度
============================================================
【原文锚点】语法第N章"<考点名>"（english.txt 第 X–Y 行）
```

**铁律（四科通用）**：笔记里的表述必须能在原文找到落点，不得自行发挥；
原文有 OCR 错字（「深人」=「深入」、`Void main` = `void main`、`tine` = `time`），
引用时静默修正，不改原意。讲义缺失而按考纲补全的内容，**必须在【原文锚点】注明**
"讲义此节未展开，按考纲要点补全"，不许伪装成原文。

## 五、怎么用这套东西复习

### 5.1 一轮（打底，约 6–8 周）

```
每章：读「章节精要」→ 读该章全部「考点笔记」→ 做「配套题」→ 对「答案解析」
错题记入「错题本.txt」，写清错因类别（A 概念混淆 / B 记忆缺失 / C 审题失误 / D 表述不准…）
```

各科错因分类不同，错题本开头有说明。**错题本不抄题，只写"错因 + 回查考点编号"。**

### 5.2 二轮（提分，约 4 周）

按考频降序刷：先 ★★★★★ 的考点笔记重读一遍，再做该章的配套题。
错题本里复盘次数 ≥ 2 的题，单独抄一张纸。

### 5.3 三轮（冲刺，约 2 周）

- 政治：只看「章节精要」的"必背金句"与"关键提法"。
- 计算机：只看「考点笔记」的"必背代码片段"与"易错辨析"。
- 高数：只看 `公式速查.txt` + 错题本里的方法错题。
- 英语：只看 `词汇表.txt` 的易混词 + `范文库.txt` 的万能句式。

### 5.4 导入站点

每个 txt 头部都是 `【key】value` 字段，可直接作为分类标签导入
（站点已有 3487 篇 / 130 分类，按 `【课程】` `【章节】` `【考点】` `【考频】` 建树即可）。
`00-总索引.txt` 是一张现成的目录表（`文件名 | 考点 | 考频 | 题型 | 字数`）。
