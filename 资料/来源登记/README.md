# 来源登记

> 本目录只做「来源登记」，**不存放文件实体**。

---

## 这个目录是干什么的

用来记录**来自外部渠道、但实体不落在本库**的资料：云端 Notebook、网盘、他人分享、公众号文章等。

登记的目的有三条：

1. **可追溯** —— 以后看到某份资料，能查到它从哪来、可信度如何、有没有对应的本地版本。
2. **防重复** —— 登记表里写明「本地是否已有」，避免同一份东西反复下载入库。
3. **留缺口** —— 本地确实没有的，明确标出来，作为待补清单。

## 登记规则

| 项 | 规则 |
|:---|:---|
| 文件名 | `<来源名>来源登记-YYYY-MM-DD.md` |
| 是否存实体 | **否**。本目录只放 Markdown 登记表，不放 PDF / 图片 / docx |
| 与本地重复的 | 只登记，不复制实体 |
| 本地缺的 | 登记 + 在「处置」栏标注，需要时经确认后再搬运 |
| 更新方式 | 每次从同一来源再抓取时**新建一份带日期的登记**，不覆盖旧的 |
| 元数据头 | 每份登记开头写清来源、抓取日期、可信度口径、边界 |
