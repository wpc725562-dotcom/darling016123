# 政治理论教材

> 本目录存放**政治理论考纲指定教材**的登记与说明。教材 PDF 本身**不入 Git**（按 `.gitignore`）。

---

## 为什么单独立目录

政治是四科里**唯一有明确「教材」概念**的科目——考纲直接指定三本高校教材，考试内容基本不超出教材范围。本地此前**没有政治教材目录**（`资料/` 下有 `计算机教材/`，但政治缺位），是明确的结构性缺口。

## 命名规则

```
<书名>（YYYY年版）.pdf
```

**规则**：保留书名全称；版本年放括号内；用中文全角括号（与官方书名写法一致）；不用空格。

## 使用说明

1. **政治复习的边界就在这三本里**——超出教材范围的时事部分，另看当年考纲。
2. 三本教材**不是平均用力**：考纲会给出各部分的权重，先按权重分配时间。
3. 教材是 **A 级来源**（官方公开），可信度最高。
4. 教材 PDF 体积大，按库规范**只放本地缓存，不推送 Git**。
