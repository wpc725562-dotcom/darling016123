## 语法 · 谓语与非谓语判断（画面）

### 口诀：动词不是谓语就是非谓语，每个句子必有谓语
- **要点**：句中出现的动词只有两种身份——谓语或非谓语，且每个句子必有谓语。做题时先定出句子的谓语，剩下的动词一律按非谓语处理。
- **关键概念**：`谓语`、`非谓语`、`每个句子必有谓语`
- **相互关系**：这条口诀是逐空标注的总开关——先找谓语，其余动词按非谓语判。
- **出处**：语法完形 P2（画面）

### 谓语与非谓语速查表（动作时间 × 主动被动）
- **要点**：**谓语**只体现两件事——动作时间与主动被动。动作时间分四条：过去（`did`、`was/were doing`、`had done`；被动 `was/were done`、`had been done`）、过去+现在（`have/has done`；被动 `have/has been done`）、现在（`do/does`、`am/is/are doing`；被动 `am/is/are done`）、将来（`will do`；被动 `will be done`）。**非谓语**按「主动被动 + 句意补充」分两类：主动 `doing`、`to do`、`having done`；被动 `done`、`to be done`、`being done`。
- **关键概念**：`did / was/were doing / had done`、`have/has done`、`do/does / am/is/are doing`、`will do`、`doing / to do / having done`、`done / to be done / being done`
- **相互关系**：谓语的四条时间线与非谓语的三对形式一一对照；判断时先定「时间 + 主被动」，再决定这个动词写谓语还是写非谓语。
- **出处**：语法完形 P2（画面）

### 主动 / 被动判据：动词后面直接出现名词 → 大概率主动
- **要点**：判断空格处动词该主动还是被动，先看它后面是不是直接跟了名词。动词后面有名词直接出现，大概率是主动；若后面没有名词、而主语本身是被作用的对象，则考虑被动。
- **关键概念**：`动词后面有名词直接出现`、`大概率主动`
- **出处**：语法完形 P2（画面）

### -ed 形式的双重身份：谓语 did（主动）/ 非谓语 done（被动）
- **要点**：同一个 -ed 形式有两种身份。作谓语时是 `did`，表过去的主动；作非谓语时是 `done`，表被动。画面用 co-produced、made、found 三个词反复对照：`co-produced` 谓语 did 主动 / 非谓语 done 被动；`made` 谓语 did / 非谓语 done；`found` 谓语 did / 非谓语 done。
- **关键概念**：`co-produced`、`made`、`found`、`谓语 did 主动`、`非谓语 done 被动`
- **相互关系**：这是「先定谓语」口诀的具体应用——同一个词先看它在句中是不是谓语，再决定它算 did 还是 done。
- **出处**：语法完形 P2（画面）

## 语法 · 词义与语态判据（画面）

### 分词作定语时的词义对应（co-produced / consisting of / featuring）
- **要点**：画面把分词短语和它的释义并排标出，用来确定空处该用哪种分词：`co-produced` = 联合制作的（修饰 series）、`consisting of` = 包括……的（修饰 collection）、`featuring` = 以……为特点（修饰 stories）。按这个对应关系读原文，就能定位空处的分词形式。
- **关键概念**：`co-produced 联合制作的`、`consisting of 包括……的`、`featuring 以……为特点`
- **出处**：语法完形 P2（画面）

### consist of 的语义与语态判据
- **要点**：`consist of` 表「（事物）包括（内容）」——主语是整体，宾语是组成部分。这个含义决定它用主动形式，不用被动。
- **关键概念**：`consist of`、`事物包括内容`
- **出处**：语法完形 P2（画面）

### base 词族：base 名词「基础」/ 动词「为某物打基础」/ be based on「基于」
- **要点**：画面用一组类比讲 base：`base` 作名词是「基础」，作动词是「为某物打基础」；整体事物对应「基础 base」，楼对应「地基 base 楼」；楼的地基即 be based on，所以 `be based on` 表「基于」，base 后接 on 是固定搭配。
- **关键概念**：`base n. 基础`、`base v. 为某物打基础`、`be based on 基于`
- **出处**：语法完形 P2（画面）

### astonish 的施受判据：事物 astonish 人 / 人 be astonished
- **要点**：`astonish` 是「使某人惊讶」。动作的发出者是事物、承受者是人：事物 astonish 人（用主动），人 be astonished（用被动）。所以空格前是人、且后接 at 时，谓语按被动处理——`was/were done` 或 `had been done`。
- **关键概念**：`astonish 使某人惊讶`、`事物 astonish 人`、`人 be astonished`
- **相互关系**：这是主动 / 被动判据在使役类动词上的具体用法；同题的 `rest` 则按非谓语主动 `doing` / `to do` / `having done` 处理。
- **出处**：语法完形 P2（画面）

### to 的两用：to + 名词是介词，to + 动词是不定式
- **要点**：`to` 后面接名词，说明 to 是介词；`to` 后面接动词，则是不定式（`to do`，被动 `to be done`）。据此反推空处该填什么形式。
- **关键概念**：`to 介词 + 名词`、`to do 动词不定式`、`to be done`
- **出处**：语法完形 P2（画面）

### recognize 的两条名词化路径：动名词 recognizing / 名词 recognition
- **要点**：`recognize` 转名词有两条路——`recognizing` 是动名词（走「动词—谓语非谓语—动名词」这条路），`recognition` 是名词（认可、肯定）。要按句子位置判断该用哪一种。
- **关键概念**：`recognizing`、`recognition 认可肯定`

### appreciate 的两条名词化路径：动名词 appreciating / 名词 appreciation
- **要点**：`appreciate` 转名词同样两条路——`appreciating` 是动名词（动词加 -ing 变名词），`appreciation` 是真正的名词形式。
- **关键概念**：`appreciating 动名词`、`appreciation 名词`

### 名词→形容词的语义分工：favorite 与 favorable
- **要点**：同一个词根转成形容词时词义会分叉：`favorite` 是「最喜欢的」，`favorable` 是「赞同的、支持的」。选词要看句意态度，不能只看词根。
- **关键概念**：`favorite 最喜欢的`、`favorable 赞同的支持的`、`名词→形容词`

## 语法 · 语法填空解题框架（画面）

### 谓语与非谓语的四大辨析框架
- **要点**：画面把整个谓语 / 非谓语板块压成四组「辨析」，每组只讲一件事——`谓语辨析1` = 三个过去时间的区别；`谓语辨析2` = 两个现在时间的区别；`非谓语辨析1` = 三个主动形态的区别；`非谓语辨析2` = 三个被动形态的区别。也就是说：时态部分只拿「过去」与「现在」两族互比（将来不单列辨析）；非谓语部分先按主动 / 被动分成两族，再在族内比三个形态。
- **关键概念**：`谓语辨析1（三个过去时间）`、`谓语辨析2（两个现在时间）`、`非谓语辨析1（三个主动形态）`、`非谓语辨析2（三个被动形态）`
- **相互关系**：谓语的两组先分时间族、再比形态；非谓语的两组先分主被动族、再比形态，两侧的比对逻辑同构。
- **出处**：语法完形 P3（画面）

### 谓语 / 非谓语填空的两轴标注法
- **要点**：画面在每一道填空下方都印着同一串标注——`谓语非谓语 — 过去现在将来 / 主动被动`。这是对每个空格只走两步的解题动作：①先判这个空是谓语还是非谓语；②谓语族再定「动作时间（过去 / 现在 / 将来）」与「主动 / 被动」两轴，非谓语族则定「主动 / 被动」与「句意补充」两轴。所有空格的可选范围都被这两轴收死，不凭语感。
- **关键概念**：`谓语 / 非谓语`、`过去 / 现在 / 将来`、`主动 / 被动`、`句意补充`
- **相互关系**：非谓语不参与「动作时间」轴，它的第二轴换成「句意补充」——即用非谓语补出主句没说完的意思，这正是非谓语与谓语的分工差别。
- **出处**：语法完形 P3（画面）

### 非谓语作名词 / 作形容词的形式收缩判据
- **要点**：画面给出两条用于「判断 / 断句」的收缩判据：① 非谓语在句中**作名词**时，只在 `doing` / `being done` 两个形式里选（主动用 doing、被动用 being done）；② 非谓语**放在名词前作形容词**时，只在 `doing` / `done` 两个形式里选。功能一旦被判定为「名词」或「名词前的形容词」，候选形式立刻从六个收缩到两个。
- **关键概念**：`作名词 → doing / being done`、`名词前作形容词 → doing / done`
- **相互关系**：两条判据的取舍点不同——作名词要区分主被动（doing / being done），作名词前形容词只看「主动进行」还是「被动完成」（doing / done）；两者都不取 to do 一族。
- **出处**：语法完形 P3（画面）

### 动名词优先作主语：to do 的禁忌与例外
- **要点**：画面明确写着「**to do 不要作主语**」，主语位置用动名词：主动写 `doing`、被动写 `being done`（画面例：`Receiving education abroad is the dream of many students.` / `Being educated abroad is the dream of many students.`）。确实要用不定式表达时，改用形式主语 It 把它挪到后面（画面例：`It is useful for me to 背单词`）。唯一例外是「**有哲理的句子**」，这类句子才允许 to do 直接顶主语（画面例：`To see is to believe`）。
- **关键概念**：`to do 不作主语`、`动名词作主语：doing / being done`、`形式主语 It`、`有哲理的句子（To see is to believe）`
- **相互关系**：to do 的常规位置是表目的；需要它作主语时，要么换动名词，要么借形式主语 It 挪位，只有哲理格言句是例外。
- **出处**：语法完形 P3（画面）

## 语法 · 时态与非谓语的考查占比（画面）

### 过去时态的考查占比判据
- **要点**：画面用百分比给三个过去时间标了优先级——**一般过去**（过去发生的事、过去完成的事）占「**95% 过去题目**」；**过去完成**（一句话内部明确两个过去的先后顺序、发生在先的动作）在「**5% 以下过去题目**」；**过去进行**（过去某时间正在发生的、生动形象的动作）同样在「**5% 以下过去题目**」。据此，过去时态题先按一般过去处理，只有句中出现两个过去动作的先后排序时才转向过去完成。
- **关键概念**：`一般过去 95%`、`过去完成 5% 以下`、`过去进行 5% 以下`、`一句话内两个过去动作排序`
- **相互关系**：三个过去时间的区别被占比判据收敛成一个动作——默认一般过去，再由「一句话内是否有两个过去动作排序」触发过去完成。
- **出处**：语法完形 P3（画面）

### 被动非谓语 being done 的极低频
- **要点**：画面给三个被动非谓语形态也标了定位——`done` 表「与谓语同时 / 动作结束以后」，`to be done` 表「动作目的 / 预期情况」，这两个是常考项；`being done` 只用于「正在发生的被动、生动形象场景」，占比在「**0.01% 以下**」。所以被动非谓语题几乎只在 done 与 to be done 之间二选一，being done 基本可先排除。
- **关键概念**：`done`、`to be done`、`being done（0.01% 以下）`
- **相互关系**：三个被动形态的取舍靠「与谓语同时 / 结束以后（done）、表目的预期（to be done）、正在发生的生动场景（being done）」三句话区分，与主动族三形态的取舍方式一致。
- **出处**：语法完形 P3（画面）

## 语法 · 完全倒装（画面）

### 介词短语句首 + 动词填空 → 完全倒装
- **要点**：画面给出一个触发判据：当**句首是介词短语、空格要填动词**时（画面例：`Among the selective courses (60) ___ (be) the restoration of small and micro wetlands.`），先追问一句「**主语是谁？**」——这类结构多为**完全倒装**，真正的主语落在动词之后，因此谓语的形式与单复数由动词后面的名词决定，而不是由句首的介词短语决定。
- **关键概念**：`介词短语句首`、`主语是谁`、`完全倒装`、`谓语在主语前`
- **相互关系**：这条判据与「介词短语不能作主语」配套使用——介词短语只是被前置的状语，不能充当主语，所以必须往动词后面去找主语。
- **出处**：语法完形 P4（画面）

### 前句完整后句完整时的四分关系映射
- **要点**：当前句完整、后句也完整时，画面给的判据是「分析这两句话内部关系」，并把关系拆成四种：where 表「在那里」的位置关系、when 表「在那时」的时间关系、why 表「为什么」的因果关系（reason why + 结果）、that 解释抽象名词的内容、属总分关系的同位语从句。连词的逻辑关系则展开为六类：转折、因果、条件、并列、递进、对比；关系词 where/when/why/that 在这一层的作用等同于连词。
- **关键概念**：`前句完整 + 后句完整 → 分析内部关系`、`where 位置 / when 时间 / why 因果 / that 总分`、`同位语从句`、`连词六类：转折·因果·条件·并列·递进·对比`
- **相互关系**：关系词 where/when/why/that 与连词处于同一层功能——都在前句完整、后句完整时，用来连接并标明两句话之间的内部关系。

## 语法 · 语法填空（画面）
### 无提示空格考点总览框架（四分支 + 量化特征）
- **要点**：画面给出的总览框架分四层：①**出发点**——无提示空格的解题出发点是「语句结构分析」；②**基本要求**——语句结构分析的基本要求是「关注名词、动词」，即先看空格后面接的是名词短语还是动词短语；③**四条分支考点**——冠词（`a/an` 表「一个、某个」不确定对象，`the` 表「这个、那个」确定对象）、从句关系词（主从句划分与主从句完整性判断）、介词（常考介词短语的积累）、连词（转折、因果、条件、并列等特殊逻辑关系）；④**量化特征**——每篇语法填空中无提示空格约 3-4 题，**每个空格仅填一个词**。
- **关键概念**：`语句结构分析`、`空格后面名词短语 / 动词短语`、`a/an 表不确定对象`、`the 表确定对象`、`and 并列 / or 选择 / but 转折`
- **相互关系**：四条分支由「空格后面是名词短语还是动词短语」这一个入口分流出来；连词一支的「特殊逻辑关系」与口诀「and 并列、or 选择、but 转折」是同一件事的两种说法。
- **出处**：语法完形 P7（画面）

## 语法 · 定语从句（画面）
### 关系词的出现频次判据：whose 相对少、as 几乎没有
- **要点**：在「前句完整、后句不完整」的定语从句里，关系词按**指代对象**选：指**人**用 `that / who`，指**物**用 `that / which`。画面另外给出一条**频次判据**：表限定词的 `whose`（谁的）考得**相对少**；表「正如」的特殊概念 `as` **几乎没有**（极少考）。关系词的意义是「把句子补完整」，缺口分两种：**缺少部分**（缺成分）与**缺少句意**。
- **关键概念**：`人 → that/who`、`物 → that/which`、`whose 相对少`、`as（正如）几乎没有`、`缺少部分 / 缺少句意`
- **相互关系**：这条频次判据是「人 / 物」主流选择之外的补充——碰到 whose、as 不必优先考虑。
- **出处**：语法完形 P7（画面）

## 语法 · 介词（画面）
### 句尾的空格只能填介词
- **要点**：画面给出判据——**能出现在句尾的只有介词**。因此空格位于句尾时，直接按介词方向找，不必先猜冠词或连词。画面以 `carry on`（坚持）与 `carry out`（开展，同义替换 hold / organize / conduct）为例，说明句尾空最终靠动词短语搭配的积累来定。
- **关键概念**：`句尾空格 → 介词`、`carry on 坚持`、`carry out 开展（= hold/organize/conduct）`
- **相互关系**：与「介词靠积累、按本义推断」是同一条路线——句尾定位只收缩范围，填哪个词仍看搭配。
- **出处**：语法完形 P7（画面）

### 被动语态按「主谓完整」处理
- **要点**：判断主从句完整性时，画面给出一条链路判据：**被动语态 → 主谓结构 → 完整**。见到被动语态就当作「主谓结构完整」，不在完整性判断上把它当成缺成分；真正的缺口要看别处（例如后面出现缺限定词的从句，才是 `whose` 这类关系词的位置）。
- **关键概念**：`被动语态 → 主谓结构 → 完整`、`缺限定词 → whose`
- **相互关系**：被动语态判「完整」与「从句不完整—缺少限定词—whose」配对使用：一个负责排除，一个负责定位。
