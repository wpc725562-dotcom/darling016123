## 语法 · 状语从句（画面）
### 状语从句在从句体系中的定位：状语从句即副词从句
- **要点**：画面用「从句在句中充当什么成分」给从句分类：从句作名词 → 名词性从句；从句作形容词 → 形容词从句（定语从句）；从句作副词 → 副词从句，也就是状语从句。所以状语从句和副词从句是同一个东西的两种叫法，判断一个从句是不是状语从句，就看它是不是在给句子当副词、为句子增加更多信息。
- **关键概念**：`从句作名词 → 名词性从句`、`从句作形容词 → 形容词从句（定语从句）`、`从句作副词 → 副词从句（状语从句）`
- **相互关系**：状语从句的引导词表示从句和主句的关系；状语从句可以放在主句前，也可以放在主句后，放在主句前需要逗号断开。
- **出处**：零基础 P14（画面）

### 状语从句引导词分类对照表（六类关系）
- **要点**：引导词按「从句和主句的关系」分六类，画面把具体引导词逐类归位：
  - 时间引导词：`after`、`as soon as`、`before`、`when(ever)`、`since`（自从）、`until`（直到）、`while`（同时）
  - 原因引导词：`because`、`since`、`as`
  - 条件引导词：`if`、`unless`（除非）、`once`（一旦）、`even if`（即使）
  - 目的引导词：`so that`（为了）
  - 方式/样貌引导词：`as if`（好像）
  - 让步/对比引导词：`although`（虽然）、`though`、`while`（尽管）
- **关键概念**：`时间`、`原因`、`条件`、`目的`、`方式/样貌`、`让步/对比`
- **相互关系**：同一个引导词可以跨类——`since` 既在时间类（自从）又在原因类，`while` 既在时间类（同时）又在让步类（尽管），所以选义时要先看从句与主句的实际逻辑关系，再定它属于哪一类。
- **出处**：零基础 P14（画面）

### 状语从句的四条注意事项（编号规则）
- **要点**：画面给出的四条编号规则：① 状语从句在主句之前，需要逗号断开；② 状语从句不能自己独立成句；③ 状语从句和主句绝大多数情况下都是完整句；④ 主从句只需要一个引导词。
- **关键概念**：`主句前需逗号断开`、`不能独立成句`、`绝大多数情况下都是完整句`、`主从句只需一个引导词`
- **出处**：零基础 P14（画面）

### so 与 so that：结果与目的的分工
- **要点**：画面把 SO 的用法拆成两条，靠「表结果」还是「表目的」来区分：表示结果（所以）时需要逗号断开；表示目的（为了 / 这样才能）时不需要逗号断开。也就是说，单用 so 引出的是结果，so that 引出的是目的，逗号是两者的外部分界。
- **关键概念**：`so 表结果（所以）+ 逗号断开`、`so that 表目的（为了/这样才能）不加逗号`
- **相互关系**：与引导词分类表里的「目的引导词 so that」对应；目的类引导词不加逗号，与「从句放主句前需逗号断开」是两回事，不要混用。
- **出处**：零基础 P14（画面）

### once 与 since 的选择判据：未发生 / 已发生
- **要点**：同一个空格里选 once 还是 since，判据是「从句所说的事有没有发生」——`once` 是「一旦」，配未发生；`since` 是「自从」，配过去时间，指已发生。做这类二选一时先判断从句所指的事是否已经发生，已发生用 since，未发生用 once。
- **关键概念**：`once 一旦 + 未发生`、`since 自从 + 过去时间（已发生）`
- **相互关系**：`since` 在同一份练习里另有「原因」的用法（后接原因内容，标为原因），所以要先把 since 的「自从」与「因为」分开，再和 once 比。
- **出处**：零基础 P14（画面）

## 语法 · 时态（画面）
### 过去完成时（had done）的应试口诀
- **要点**：画面给出的应试口诀：在高考英语结束之前，永远不使用过去完成时（had done）——这比你乱用过去完成时的错误率要低得多。即不确认是非用不可的场合，就不要写 had done。
- **关键概念**：`had done`、`过去完成时`、`不确认就不用`
- **出处**：零基础 P14（画面）
