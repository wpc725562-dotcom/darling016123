## 语法 · 句子结构的拆分训练（画面）

### 拆句先划掉定语从句，主干决定主谓一致
- **要点**：画面把同一句话写成两行对照——完整句 `Burning fossil fuels, which releases carbon dioxide into the atmosphere, has harmful effects on the environment.` 与划掉定语从句后的简化句 `Burning fossil fuels has harmful effects on the environment.`。拆分时先把 which 引导的定语从句整段划掉，剩下的是主干；主干主语是动名词短语 Burning fossil fuels（按单数处理），谓语用 has。从句里的 releases 与主句谓语无关。也就是：主语和谓语之间被定语从句隔开时，一致关系只看主干主语，不看离谓语最近的那个名词或动词。
- **关键概念**：`划掉定语从句看主干`、`距离陷阱`、`动名词短语作主语 → 谓语单数`
- **相互关系**：与「动名词作主语，谓语用单数」配套——主干主语是动名词时谓语一律单数。
- **出处**：零基础 P20（画面）

### 分词作形容词：还原成定语从句判定 doing / done
- **要点**：画面在每个「名词 + 分词」后面都配了还原式——`running water (water that is running)`、`aching leg (leg that is aching)`、`forgotten memory (memory that is forgotten)`、`burned house (house that is burned)`。判据：能还原成「that is + doing」的用 doing，表主动、进行中；能还原成「that is + done」的用 done，表被动、已完成。同一名词换形态即换含义，画面并排给出 burning house（正在燃烧的房子）与 burned house（被烧毁的房子）。
- **关键概念**：`doing = 主动、进行中`、`done = 被动、已完成`、`还原成 that is ... 从句`
- **出处**：零基础 P20（画面）

### 动名词作主语：主语位写动词原形会变成祈使句
- **要点**：画面把错句和改对句并排——`Learn about a foreign country's customs can help ...` → `Learning about a foreign country's customs can help ...`；`Use technology to improve ...` → `Using technology to improve ...`；`walk is one of the easiest ways ...` → `walking is ...`。判据：主语位置若要表达一个动作，必须把动词改成 doing（动名词）；直接写动词原形会让句子变成祈使句，整句没有主语。画面同时给出对照 `Doing sth can do sth` 与 `Do sth（祈使句）`。改成动名词后谓语仍按单数处理（`Taking vitamins are ...` → is；`Finding cures ... attract` → attracts）。
- **关键概念**：`动名词作主语`、`Doing sth can do sth`、`动词原形开头 = 祈使句`
- **相互关系**：与「动名词作主语，谓语用单数」配套——主语改 doing 之后谓语要用单数。
- **出处**：零基础 P20（画面）
