## 语法 · 语法填空考点总览（画面）
### 语法填空两条路径总表：有提示词 / 无提示词
- **要点**：画面用一张两栏表把语法填空的全部考点归到两条路径上。**有提示词**一路给出的是实词四类——动词、名词、形容词、副词，对应的考点是：动词考「时态、语态与非谓语」，名词考「复数与代词形式变化」，形容词副词考「比较级、最高级」，再加「四种词性互相转换」。**无提示词**一路给出的是虚词四类——关系词、连词、介词、冠词，对应的考点是：关系词连词考「主从句与逻辑关系判断」，介词考「本义与常用短语搭配」，冠词考「对名词的限定作用」。表下另压一行硬性要求：勿照抄原词、勿由繁入简、勿不按要求。
- **关键概念**：`有提示词`、`无提示词`、`动词时态语态与非谓语`、`名词复数代词形式变化`、`形容词副词比较级最高级`、`四种词性互相转换`、`主从句与逻辑关系判断`、`介词本义与常用短语搭配`、`冠词对名词的限定作用`、`勿照抄原词、勿由繁入简、勿不按要求`
- **相互关系**：看到空格先分「有没有提示词」，再按所在栏的四类词去找对应考点；两条路径互不交叉，先分路径再谈细节。
- **出处**：语法完形 P5（画面）

## 语法 · 谓语与非谓语判断（画面）
### 判定口诀：动词不是谓语就是非谓语，每个句子必有谓语
- **要点**：画面把「判断动词」这一步压成一句口诀——**动词不是谓语就是非谓语，每个句子必有谓语**。含义有两层：句中出现的每一个动词，只能在「谓语」与「非谓语」之间二选一，没有第三种身份；而一个合法句子必须有一个谓语。因此做题第一步就是数动词、定谓语，找不到谓语即说明该结构还没成句。
- **关键概念**：`谓语`、`非谓语`、`每个句子必有谓语`、`判断动词`
- **相互关系**：先用「必有谓语」定出谓语，余下的动词一律按非谓语处理，口诀是后续所有形态判断的入口。
- **出处**：语法完形 P5（画面）

## 语法 · 非谓语形式选择（画面）
### 非谓语形式的两条收窄判据：作名词 / 名词前作形容词
- **要点**：画面给出两条把选项范围直接砍半的判据。第一条：**非谓语在句中作名词时，只考虑 doing / being done**；第二条：**非谓语在名词前作形容词（定语）时，只考虑 doing / done**。做法是先判这个空在句中充当什么成分（名词性还是形容词性），再进对应的两个形式里选，不必把全部形态逐一比对。
- **关键概念**：`doing`、`being done`、`done`、`非谓语在句中作名词只考虑 doing / being done`、`非谓语在名词前作为形容词只考虑 doing / done`
- **相互关系**：两条判据都是「先定成分、再定形式」的入口，成分判错则形式必错。
- **出处**：语法完形 P5（画面）

## 语法 · 逐空考点标注（画面）
### 逐空考点标注体系：谓语非谓语 × 动作时间 × 主动被动
- **要点**：画面在题目旁逐空打标签，谓语空的标签写法固定为 **「谓语/非谓语—过去现在将来/主动被动」**，即先判这一空是谓语还是非谓语，再用「动作时间（过去 / 现在 / 将来）」与「主动还是被动」两个维度定形。其余空位各有专属标签维度：名词位置标「名词—形容词」，无提示词空位标「连词/关系词、and/or/but」「介词」「冠词/介词」「特殊代词 it（形式主语、形式宾语）/ that（比较指代）」以及「数字：基数词—序数词」，代词位置标「代词变换 itself / its」，分词位置标「called：did 主动 / done 被动」。
- **关键概念**：`谓语非谓语—过去现在将来/主动被动`、`名词—形容词`、`连词/关系词、and/or/but`、`冠词/介词`、`特殊代词 it / that`、`数字：基数词—序数词`、`代词变换 itself / its`、`called：did 主动 / done 被动`
- **相互关系**：标签即考点，一个空格只挂一套标签；标签写对等于考点判对，标签漏写等于考点漏判。
- **出处**：语法完形 P5（画面）

## 语法 · 动词搭配与主被动（画面）
### 主动 / 被动对照式搭配判据：A follow B 与 A be followed by B
- **要点**：画面把搭配写成「主动式 / 被动式」上下对照两行，并配箭头图示 A 与 B 的先后位置：**A follow B = A 在 B 后面**（A …… B）；**A be followed by B = A 被 B 跟随**（B …… A）。判空时先看这个空的主语是「跟随者」还是「被跟随者」，再决定用 follow 还是 be followed by。同页还并列给出被动形式清单 done / to be done / being done 与 was/were done、had been done，说明定下被动后还要在被动形式里挑时间。
- **关键概念**：`A follow B = A 在 B 后面`、`A be followed by B = A 被 B 跟随`、`主动式 / 被动式对照`、`done / to be done / being done`、`was/were done`、`had been done`
- **相互关系**：位置图示（谁在前、谁在后）与主动被动是同一件事的两种说法，位置看反就会选反语态。
- **出处**：语法完形 P5（画面）

## 语法 · 动词搭配与主被动（画面）
### send 的主动 / 被动对照与被动非谓语判定
- **要点**：画面把 send 写成 **sb/sth send sth** 与 **sb/sth be sent** 两行对照，提示要先判定这个空所修饰的名词是动作的发出者还是承受者。该空所在的名词短语是「two 20-tonne-level lab modules (38) (send) into orbit」，lab modules 是被送进轨道的对象，走被动一路；在有提示词的非谓语被动形式 done / to be done / being done 中取 done，写成 sent。
- **关键概念**：`sb/sth send sth`、`sb/sth be sent`、`sent`、`done / to be done / being done`
- **相互关系**：先按主动 / 被动对照定语态，再按动作时间在被动三形式里选，两步不能合并成一步。
- **出处**：语法完形 P5（画面）

## 语法 · 动词搭配与主被动（画面）
### recognize 的两个义项与主动 / 被动对照
- **要点**：画面先给 recognize 的字面义 **recognize sb/sth 认出、辨认**，再给「把……看作」的义项，并写成主动被动对照两行：**sb recognize sb/sth as sb/sth 把某人/某物看作……**；**sb/sth be recognized as sb/sth 某人/某物被看作……**。该空所在的「a relic site museum has been built at the Yinxu site, (39) (recognize) as a UNESCO World Heritage Site」，主语 relic site museum 是被看作世界遗产的一方，故取被动非谓语 recognized。
- **关键概念**：`recognize sb/sth 认出、辨认`、`sb recognize sb/sth as sb/sth 把……看作`、`sb/sth be recognized as sb/sth 被看作`、`recognized`
- **相互关系**：as 后面的成分在主动式与被动式里都保留，变的只是 as 前面的动词形式；先定 as 前的主语身份，再定形式。
- **出处**：语法完形 P5（画面）

## 语法 · 动词搭配与主被动（画面）
### appeal to 的等价式理解：sth appeal to sb = sth attract sb
- **要点**：画面把 appeal to 直接等价成 **sth appeal to sb = sth attract sb（某物吸引某人）**，并明确主语是「物」而不是「人」——发出吸引的是 sth，被吸引的是 sb。该空所在的「It (42) (appeal) to not only scholars but also those outside the circles of archaeology」，主语 It 指代前面的事物，故取主动形式 appeal。画面同时给出两个候选「appeals / has appealed」，并标注 **do/does 现在、have/has done 过去+现在**，说明主被动定下来之后还要再定时间。
- **关键概念**：`sth appeal to sb = sth attract sb 某物吸引某人`、`appeals`、`has appealed`、`do/does 现在`、`have/has done 过去+现在`
- **相互关系**：等价式用来确认「主语是物」从而取主动；两个时态候选再交给动作时间维度去筛。
- **出处**：语法完形 P5（画面）

## 语法 · 非谓语形式选择（画面）
### sth range from A to B 的状态义与 doing 的选择
- **要点**：画面给出 range 的搭配式 **sth range from A to B（某物的范围从 A 到 B）**，并特意在括号里标出「**状态**」二字；与之配套的非谓语候选清单是 doing / to do / having done。该空所在的「It featured breakthroughs in basic research (36) (range) from space science to agriculture」描述的是这些突破本身的范围状态，不是目的，因此取 doing，写成 ranging。
- **关键概念**：`sth range from A to B`、`（状态）`、`doing / to do / having done`、`ranging`
- **相互关系**：搭配义项决定语义类型（状态还是目的），语义类型再决定取 doing 还是 to do。
- **出处**：语法完形 P5（画面）

## 语法 · 词形转换（画面）
### 基数词转序数词：nine → ninth 的词形判据
- **要点**：画面把数字这一空的标签写成「**数字：基数词—序数词**」，并给出词形示例 **nine → ninth**。该空所在的「the (43) (twenty-nine) annual event of its kind」前面有 the、后面接单数名词 annual event，表示「第二十九届」，属序数词位置，因此要把基数词 twenty-nine 改成序数词 twenty-ninth（nine 变 ninth，去 e 再加 th）。
- **关键概念**：`数字：基数词—序数词`、`nine → ninth`、`twenty-ninth`、`the + 序数词 + 单数名词`
- **相互关系**：先看空格前有没有 the、后面是不是单数名词，判断要填「几」还是「第几」，再动手改词形。
- **出处**：语法完形 P5（画面）

## 语法 · 代词形式选择（画面）
### 代词变换 itself / its 的判据：看空后有没有名词
- **要点**：画面把一个代词空的两个候选并排写出——**代词变换 itself / its**，提示同一个 it 在这类空里可能变成反身代词，也可能变成物主代词。判据落在空后：空后面直接跟名词时用形容词性物主代词 its，只有主语与宾语同指时才用反身代词 itself。该空所在的「producing (41) (it) first solar image in November」，空后紧跟名词短语 first solar image，故取 its。
- **关键概念**：`代词变换 itself / its`、`its`、`itself`、`空后跟名词用物主代词`
- **相互关系**：先看空后是不是名词（定「物主」还是「反身」），再看是否需要体现单复数与性别。
- **出处**：语法完形 P5（画面）
