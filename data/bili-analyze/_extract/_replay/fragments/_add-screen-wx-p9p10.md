## 词汇方法 · 完形画面词义辨析与搭配（画面）

### save / keep sb from sth（doing sth）——从某件坏事里拯救某人
- **要点**：画面在 35 空旁批注 `save/keep sb from sth (doing sth) 从某件坏事里拯救某人`。即 from 后接的是「坏事」或动名词，save 与 keep 同构。原文 `It saved me from having a (35) single story of what books are.` 正落在 save sb from doing sth 上。
- **关键概念**：`save sb from sth / doing sth`、`keep sb from doing sth`、`from 后接坏事或动名词`
- **出处**：完形综述 P9（画面）

### handle 的搭配：handle + 问题
- **要点**：40 空 A 项旁批注 `handle + 问题`。handle 后接「问题 / 局面 / 事务」类名词（handle a problem / a situation），不接抽象关系类词，据此可把 indicate / value / protect 一并排除。
- **关键概念**：`handle a problem`、`handle + 问题、局面`
- **出处**：完形综述 P10（画面）

### 让步 / 替代 / 代表 / 因果：in spite of、instead of、on behalf of、because of 辨析
- **要点**：30 空四项全部批注了中文。`in spite of 相反`（让步，与后文相反）、`instead of 相反`（替代，前后二选一）、`on behalf of 代表`（代某人行事）、`because of`（因果）。in spite of 与 instead of 都译「相反」，一个是让步、一个是替代，必须按逻辑方向区分。
- **关键概念**：`in spite of 让步（相反）`、`instead of 替代（相反）`、`on behalf of 代表`、`because of 因果`
- **相互关系**：画面在该空旁标 `conj.`，提示先定该空为连词 / 逻辑词，再用逻辑关系（因果）在四个短语里筛。
- **出处**：完形综述 P9（画面）

### 名词辨析组：dilemma / conflict / condition / tendency
- **要点**：34 空四项逐个批注：`dilemma 困境`、`conflict 斗争`、`condition 身体状况`、`tendency 倾向、发展趋势`。原句 `they can live with the (34)`——「与之共存」的对象应是身体状况，故取 condition；dilemma 是两难处境、conflict 是冲突斗争、tendency 是趋势，都不搭 live with。
- **关键概念**：`dilemma 困境`、`conflict 斗争`、`condition 身体状况`、`tendency 倾向、发展趋势`
- **出处**：完形综述 P10（画面）

### 否定副词近义组：hardly / barely / rarely / scarcely 几乎不
- **要点**：25 空旁批注 `hardly/barely/rarely 几乎不`，与选项 C `scarcely` 同义，构成一组「几乎不」的否定副词。这组词方向一致，与 easily / regularly / briefly 的方向不同。
- **关键概念**：`hardly`、`barely`、`rarely`、`scarcely`、`几乎不`
- **出处**：完形综述 P9（画面）

### sun set = 日落：sunrise 日出 / sunset 日落
- **要点**：24 空选项含 set / come out / disappeared / gone down，画面批注 `sunrise 日出 sunset 日落`，用来确认 `the sun had set` = 太阳落山（与 gone down、disappeared 同向）。
- **关键概念**：`sunrise 日出`、`sunset 日落`、`the sun set 太阳落山`
- **出处**：完形综述 P9（画面）

### meanwhile 表并列
- **要点**：55 空 D 项旁批注 `meanwhile 并列`——meanwhile 表并列（同时），与 however（转折）、instead（替代）逻辑不同。逻辑标志词要先分清是并列还是转折，再选词。
- **关键概念**：`meanwhile 并列`、`however 转折`、`instead 替代`
- **出处**：完形综述 P9（画面）

### 选项词义批注：claim 声称 / shift 转变
- **要点**：32 空 C 项旁批注 `claimed 声称、宣称`（与 realized / suspected / forgot 区分）；31 空 B 项旁批注 `shift 转变`（`a mental shift in my view of literature` = 观点的转变）。画面用中文批注给易混选项钉住词义边界。
- **关键概念**：`claim 声称、宣称`、`shift 转变`
- **出处**：完形综述 P9（画面）

### identify 的中文批注：我不明白（不认同）
- **要点**：原文 `things with which I could not personally identify`，画面旁批注 `我不明白`，即此处的 identify (with) 表「认同 / 理解」，personally identify = 个人能认同。否定即「我无法认同」。
- **关键概念**：`identify with 认同`、`personally identify 个人认同`
- **出处**：完形综述 P9（画面）

### 生词旁注的中英对照
- **要点**：画面对生词逐个旁注中文：`swallow 吞没`、`helm 舵`、`sarcoma 肿瘤`、`chemotherapy 化疗`、`nonverbal 非言语的`、`sailing knots 结`。这类旁注是理解原文与选项的语义锚点。
- **关键概念**：`swallow 吞没`、`helm 舵`、`sarcoma 肿瘤`、`chemotherapy 化疗`、`nonverbal 非言语的`、`knot 结`
- **出处**：完形综述 P9（画面）、完形综述 P10（画面）

## 题型 · 完形画面考点标注与文体逻辑（画面）

### 完形逐空先标「词性 + 主被动」
- **要点**：画面上在每个空旁标出该空要求的词性与语态——P9 中 (21) adj、(25) adv、(26) adj、(30) conj、(31) adj、(35) adj；P10 中 (21) adj、(22) v 被动、(23) adj、(24) adv、(26) adj、(33) adj、(34) adj、(35) adj、(36) adj、(23) adv、(24) adj。做法：读空先判此处要名词 / 动词 / 形容词 / 副词还是连词，动词空再标主动还是被动，然后才用逻辑与搭配筛选项。
- **关键概念**：`逐空标词性`、`v 被动`、`adj / adv / conj 标注`
- **相互关系**：与「由选项反推词性」互为双向——选项词性一致时，也可由选项反推该空词性。
- **出处**：完形综述 P9（画面）、完形综述 P10（画面）

### 记叙文三分类：叙事类 / 人物类 / 心理类
- **要点**：画面给出完形记叙文的三条分类：1、叙事类——单次事件 / 讲一个道理；2、人物类——生平履历 / 品质；3、心理类——心态转变 / 成长。先给文章归类，可预判全文逻辑与结尾落点。
- **关键概念**：`叙事类：单次事件 / 道理`、`人物类：生平履历 / 品质`、`心理类：心态转变 / 成长`
- **出处**：完形综述 P9（画面）

### 按文体定内在逻辑：记叙文=时间，议论文 / 说明文=转折、因果、并列、条件
- **要点**：画面框架为 `记叙文内在逻辑：时间`；`议论文/说明文内在逻辑：转折、因果、并列、条件`，并给出各逻辑的作用——`转折—引起读者重视`、`因果—解释具体情况`、`并列—对比、递进、连续动作`、`条件—举例、展开细节`。看到文体即可先锁定该文体会出现哪几种逻辑。
- **关键概念**：`记叙文：时间`、`转折—引起读者重视`、`因果—解释具体情况`、`并列—对比、递进、连续动作`、`条件—举例、展开细节`
- **相互关系**：与「四种基本逻辑关系及其作用」同源，画面按文体又切了一刀。
- **出处**：完形综述 P10（画面）
