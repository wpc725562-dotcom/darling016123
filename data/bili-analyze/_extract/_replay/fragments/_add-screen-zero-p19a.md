## 语法 · 谓语和非谓语（画面）

### 情态动词的肯定式与否定式成对形式表（真情态动词 / 半情态动词两种否定法）

- **要点**：画面把情态动词的「肯定式 ↔ 否定式」成对列出（情态动词共 12 个），肯定式一律是「情态动词 + do（动词原形）」：`can / could + do` ↔ `can / could not + do`；`will / would + do` ↔ `will / would not + do`；`may / might + do` ↔ `may / might not + do`；`must + do` ↔ `must not + do`；`should + do` ↔ `should not + do`。规律在于**否定词 not 落在哪里**：真情态动词（can / could / will / would / may / might / must / should）的否定直接在情态动词后加 not；半情态动词的否定不写在情态动词上，而要落在助动词或 be 上 —— `have to + do` ↔ `do not have to + do`；`be able to + do` ↔ `be not able to + do`；`be supposed to + do` ↔ `be not supposed to + do`。（`ought to + do` 画面只给到肯定式。）
- **关键概念**：`can / could`、`will / would`、`may / might`、`must`、`should`、`have to`、`be able to`、`be supposed to`、`ought to`、`not 的位置`
- **相互关系**：与「十二个情态动词 + 后加动词原形」同源；否定形式的写法随「真情态动词 / 半情态动词」二分而变，两类要成对记忆。
