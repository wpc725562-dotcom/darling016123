## 语法 · 第零章 关于英语的基本常识（画面）

### 英语词汇量的量化阈值

- **要点**：英语词汇量按「总量 → 常用量 → 各学段/考试要求」分层，画面给出的量化阈值是：总词汇量约 **99 万**；常用词汇量 **8–11 万**；日常生活用语 **2000 左右**；SAT/GRE 要求 **12000 以上**；四级/六级要求 **4000 / 6000**；高考要求 **3000**，其中核心词汇 **1783**。这组数字的用途是定位自己当前所处的词汇层级，并明确不同考试要求的量级差距。
- **关键概念**：`总词汇量 99 万`、`常用词汇量 8–11 万`、`日常生活用语 2000 左右`、`SAT/GRE 12000 以上`、`四级/六级 4000/6000`、`高考 3000（核心 1783）`
- **出处**：零基础 P1（画面）

### 中英表达差异：九组后缀对照表

- **要点**：画面用一张对照表，把英语相对中文「多出来的形态标记」集中列出，共九组，每组都是「后缀 → 该后缀承担的语法功能」：**1** 所有格 `-'s`（表所属）；**2** 动词第三人称单数 `-s`；**3** 过去时 `-ed`；**4** 现在分词 / 进行时 `-ing`；**5** 过去分词 `-en`；**6** 动名词 `-ing`；**7** 复数 `-s`；**8** 比较级 `-er`；**9** 最高级 `-est`。
- **关键概念**：`-'s 所有格`、`-s 第三人称单数 / 复数`、`-ed 过去时`、`-ing 现在分词 / 动名词`、`-en 过去分词`、`-er 比较级`、`-est 最高级`
- **相互关系**：同一个 `-s` 兼表「三单」与「复数」，同一个 `-ing` 兼表「现在分词 / 进行时」与「动名词」；`-er` 与 `-est` 是同级比较体系里的成对标记。
- **出处**：零基础 P1（画面）

## 语法 · 第二章 名词的基本知识（画面）

### 元音字母与辅音字母的数量

- **要点**：英语 26 个字母分两类：**元音字母 5 个**（a、e、i、o、u），**辅音字母 21 个**。这条数量清单是判断 a / an、以及「辅音字母 + y 结尾」等拼写规则时的前置常识。
- **关键概念**：`元音字母 5 个 aeiou`、`辅音字母 21 个`
- **出处**：零基础 P2（画面）

### 不可数名词的两条使用规则与量词表达

- **要点**：不可数名词用法的两条编号规则：**1** 不可数名词只用单数，不和 a/an 及数词搭配使用；**2** 不可数名词表示数量时，需要使用量词。量词结构为「数词 + 量词 + of + 不可数名词」，量词本身可数、可加复数。画面给出的量词示例：`a piece of news` 一条新闻、`two pieces of bread` 两块面包、`three pieces of paper` 三张纸、`four glasses of milk` 四杯牛奶、`five bottles of water` 五瓶水、`six cups of tea` 六杯茶。
- **关键概念**：`只用单数`、`不与 a/an 及数词搭配`、`用量词表数量`、`piece / glass / bottle / cup`
- **相互关系**：这两条规则与「可数名词可以变复数形式」互为对照，判断依据就是该名词是否可数。
- **出处**：零基础 P2（画面）

### 不可数名词的四大类清单

- **要点**：画面把常见不可数名词按语义分成四类：**1 食物相关**：fish 鱼肉、beef 牛肉、mutton 羊肉、pork 猪肉、beer 啤酒、food 食物、bread 面包、fruit 水果、rice 米饭、honey 蜂蜜、salt 盐、breakfast 早餐、chicken 鸡肉、jam 果酱、soup 汤、juice 果汁、chocolate 巧克力、sugar 糖、coffee 咖啡、lunch 午餐、tea 茶、coke 可乐、meat 肉、milk 牛奶、dinner 晚餐；**2 自然相关**：light 光、air 空气、water 水、fog 雾、weather 天气、rain 雨、grass 草、wind 风、snow 雪、ice 冰、time 时间；**3 具体事物相关**：ink 墨水、equipment 设备、newspaper 报纸、furniture 家具、jewelry 珠宝、paper 纸、hair 头发、powder 粉末、money 钱、music 音乐、homework 作业、housework 家务、news 新闻；**4 抽象概念相关**：advice 建议、justice 正义、science 科学、business 商业、kindness 善良、strength 力量、knowledge 知识、experience 经验、truth 真理、literature 文学、vocabulary 词汇、fun 乐趣、help 帮助、honesty 诚实、progress 进步、work 工作、information 信息、scenery 风景。
- **关键概念**：`食物类`、`自然类`、`具体事物类`、`抽象概念类`
- **相互关系**：这四类清单是不可数名词判断的「词库依据」——归类到其中任一类的词，都按不可数名词规则处理（只用单数、需用量词）。
- **出处**：零基础 P2（画面）

### 名词复数不规则变化中的「单复数同形」与「只有复数没有单数」

- **要点**：不规则变化除「常见特殊变化」（man–men、woman–women、child–children、foot–feet、tooth–teeth、goose–geese、mouse–mice）外，还有两个子类：**1 单复数同形**——Chinese、Japanese、deer、sheep、fish，单数与复数写法完全相同；**2 只有复数没有单数**——people、shoes、glasses、gloves、shorts、clothes、socks、trousers、pants、scissors、chopsticks，这类词只有复数形式，没有单数形式。
- **关键概念**：`单复数同形`、`只有复数没有单数`、`Chinese / Japanese / deer / sheep / fish`、`people / clothes / trousers / scissors / chopsticks`
- **相互关系**：与「常见特殊变化」并列为不规则变化的两个子类，三者合起来构成名词复数不规则变化的完整框架。
- **出处**：零基础 P2（画面）

### 动名词与动作名词形式的选择判据

- **要点**：动词既可加 `-ing` 变动名词，也可能有专属的名词形式，画面给出的对应关系是：read 动词 → reading 名词；write 动词 → writing 名词；learn 动词 → learning 名词；collect 动词 → collection 名词。判据（画面标为重要考点）：**如果某个动词有专属的名词形式，则避免使用动名词**——如 collect 应优先用 collection，尽量避免 collecting。只有没有专属名词形式的动词才用动名词，如 shopping、swimming、climbing。
- **关键概念**：`read → reading`、`write → writing`、`learn → learning`、`collect → collection`、`有专属名词形式则避免动名词`
- **相互关系**：这条把「词性转换」与「动名词」两个考点串在一起——是否用动名词，取决于该动词有没有专属名词形式。
- **出处**：零基础 P2（画面）

### 单数名词禁止裸奔：限制词的五个种类

- **要点**：冠词的作用是「对名词进行限制」，冠词分为不定冠词 `a/an`、定冠词 `the`、零冠词 `/`。核心口诀：**单数名词禁止裸奔，必须加限制词**。限制词共五类：**1** 冠词（a table / the table）；**2** 指向形容词（this table / that table / these tables）；**3** 归属形容词（my table / your table / his table）；**4** 数量词（one table / two tables）；**5** 冠词 + 形容词（a red table / a wooden table）。
- **关键概念**：`不定冠词 a/an`、`定冠词 the`、`零冠词`、`单数名词禁止裸奔`、`五类限制词`
- **相互关系**：限制词不只有冠词，指向形容词、归属形容词、数量词、冠词+形容词同样能起限制作用——这是判断「单数名词是否裸奔」的完整清单。
- **出处**：零基础 P2（画面）

### 复数名词与不可数名词的限制词规则

- **要点**：与「单数名词禁止裸奔」相对，**复数名词和不可数名词可以使用 the，不使用 a/an，不一定需要限制词**。画面示例：money 可写作 `(the) money` / `some money` / `a lot of money` / `much money` / `little money`——即可以加 the，也可以用 some、a lot of、much、little 表数量或程度，甚至完全不加限制词。
- **关键概念**：`可用 the`、`不用 a/an`、`不一定需要限制词`、`some / a lot of / much / little`
- **相互关系**：与「单数名词禁止裸奔」构成一组对照，判断是否必须加限制词，先看名词是单数、复数还是不可数。
- **出处**：零基础 P2（画面）
