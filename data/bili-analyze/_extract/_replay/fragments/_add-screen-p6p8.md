## 语法 · 语法填空（画面）

### 语法填空考点总览表（有提示词 / 无提示词双栏）
- **要点**：语法填空的考点按「有没有提示词」分成两栏。有提示词一栏给的是实词：动词、名词、形容词、副词，对应考点分别是动词的时态语态与非谓语、名词复数与代词形式变化、形容词副词的比较级最高级、四种词性互相转换。无提示词一栏给的是虚词：关系词、连词、介词、冠词，对应考点分别是主从句与逻辑关系判断、介词本义与常用短语搭配、冠词对名词的限定作用。
- **关键概念**：`有提示词（动词/名词/形容词/副词）`、`无提示词（关系词/连词/介词/冠词）`、`四种词性互相转换`
- **相互关系**：有提示词一栏的四个词性都是实词，考的是词形变化；无提示词一栏的四个词性都是虚词，考的是句子结构与逻辑关系。
- **出处**：语法完形 P6（画面）

### 语法填空作答三条硬性禁令
- **要点**：画面上单独列出三条硬性要求——勿照抄原词、勿由繁入简、勿不按要求。也就是：空格里不能把提示词原样抄进去；不能把复杂的词形简化成简单形式；不能不按题目要求的形式作答。
- **关键概念**：`勿照抄原词`、`勿由繁入简`、`勿不按要求`
- **出处**：语法完形 P6（画面）

### 无提示空格的解题出发点与四类判断入口
- **要点**：无提示空格的解题出发点是语句结构分析，而语句结构分析的基本要求是关注名词和动词——看空格后面接的是名词短语还是动词短语。据此把无提示空格收成四个入口：①冠词，a/an 表「一个、某个」（不确定对象），the 表「这个、那个」（确定对象）；②介词，靠常考介词的短语积累；③从句关系词，判据是主从句划分与主从句完整性判断；④连词，落在转折、因果、条件、并列这些特殊逻辑关系上，具体就是 and 表并列、or 表选择、but 表转折。
- **关键概念**：`语句结构分析`、`空格后面名词短语 / 动词短语`、`a/an 不确定对象 vs the 确定对象`、`主从句完整性判断`、`and 并列 / or 选择 / but 转折`
- **相互关系**：四个入口的排列即判断顺序——先看要不要填冠词，再看介词，再看关系词（判主从句完整性），最后看连词（判逻辑关系）。
- **出处**：语法完形 P6（画面）

- **关键概念**：`无提示空格约 3-4 题`、`每空仅填一个词`
- **出处**：语法完形 P6（画面）

### 逐空考点标注链：短语类型 → 考点类型 → 判据
- **要点**：画面上在每个空格旁直接标注考点，形成一条链：名词短语 / 动词短语 → 冠词、介词、and/or/but、关系词、连词；再往下一层，动词短语 → 关系词、连词；关系词 → 主从句可能完整 / 不完整；连词 → 逻辑关系 → 前后句必须完整。即：看空格前后是什么短语，就能定出该空只可能落在哪几类考点里；关系词那一类的判据是主从句完整性，连词那一类的判据是前后两句必须都完整。
- **关键概念**：`名词短语/动词短语`、`冠词·介词·and/or/but·关系词·连词`、`关系词 → 主从句可能完整/不完整`、`连词 → 前后句必须完整`
- **相互关系**：短语类型是入口，考点类型是收敛结果，完整性是判据——三者串成一条从「看到什么」到「填什么」的链路。
- **出处**：语法完形 P6（画面）

### 冠词题与介词题的二分排除判据
- **要点**：画面把这两类题做成「二选一」的判断题：判断冠词题，就是在 a/an 与 the 之间选择使用，能 / 不能各占 50%；判断介词题，就是选择使用恰当的介词（看名词与动词的关系），对 / 不对各占 50%。选项以 AB 两选的形式给出。
- **关键概念**：`a/an 或 the`、`能/不能 50%`、`对/不对 50%`、`介词看名词动词关系`
- **出处**：语法完形 P6（画面）

### 高频易错介词：swim in a river
- **要点**：画面用「swim in a river」标注这一处——在河里游泳要用 in，不能用 into：into 表「进入」的动作方向，而这里是在水域内部游泳。画面上给出的错误数据是「全国同学一起错 149」，即大量同学在此处误选 into。
- **关键概念**：`swim in a river`、`into 表进入 / in 表在水域内部`
- **出处**：语法完形 P6（画面）

### 动词判定口诀：动词不是谓语就是非谓语，每个句子必有谓语
- **要点**：画面把动词判定收成一句口诀——动词不是谓语就是非谓语，每个句子必有谓语。配合它的是谓语与非谓语的形态对照：谓语只体现动作时间与主动被动（过去 did、was/were doing、had done，was/were done、had been done；过去+现在 have/has done，have/has been done；现在 do/does、am/is/are doing，am/is/are done；将来 will do，will be done）；非谓语体现主动被动与句意补充（主动 doing、to do、having done；被动 done、to be done、being done）。
- **关键概念**：`动词不是谓语就是非谓语`、`每个句子必有谓语`、`谓语：动作时间 + 主动被动`、`非谓语：主动被动 + 句意补充`
- **相互关系**：先按「每个句子必有谓语」找出句子的谓语，剩下的动词就都是非谓语——这是判定的分水岭。
- **出处**：语法完形 P8（画面）

### 介词按本义推断的四组对应
- **要点**：画面用同一句里的空格对比出四组介词本义：in + 地点范围、at + 准确位置、about + 具体内容、for + 对象。据此判断 construction（建设）与 its space station（空间站）之间该用 of，表示所属。
- **关键概念**：`in + 地点范围`、`at + 准确位置`、`about + 具体内容`、`for + 对象`
- **出处**：语法完形 P8（画面）

### 从句关系词按先行词类型的频率分布
- **要点**：画面上把关系词按先行词类型分组，并标出使用频率：人是 that/who，物是 that/which，限定词「谁的」用 whose（相对少），特殊概念「正如」用 as（几乎没有）。另附四条注意事项：①逗号后面不用 that，用 who/which；②介词后面不用 that，用 whom/which；③不定代词后面只用 that，如 something that、all that；④最高级或极端概念后面只用 that，如 best/first + that。
- **关键概念**：`人 that/who`、`物 that/which`、`whose 相对少`、`as 几乎没有`、`逗号后不用 that`、`介词后不用 that`、`不定代词后只用 that`、`最高级/极端概念后只用 that`
- **相互关系**：前四组是「按先行词选词」的频率提示，后四条是「按位置与语境禁用 that」的硬规则。
- **出处**：语法完形 P8（画面）

### 前句完整后句完整时的四分关系映射
- **要点**：当前句完整、后句也完整时，画面给的判据是「分析这两句话内部关系」，并把关系拆成四种：where 表「在那里」的位置关系、when 表「在那时」的时间关系、why 表「为什么」的因果关系（reason why + 结果）、that 解释抽象名词的内容、属总分关系的同位语从句。连词的逻辑关系则展开为六类：转折、因果、条件、并列、递进、对比；关系词 where/when/why/that 在这一层的作用等同于连词。
- **关键概念**：`前句完整 + 后句完整 → 分析内部关系`、`where 位置 / when 时间 / why 因果 / that 总分`、`同位语从句`、`连词六类：转折·因果·条件·并列·递进·对比`
- **相互关系**：关系词 where/when/why/that 与连词处于同一层功能——都在前句完整、后句完整时，用来连接并标明两句话之间的内部关系。
- **出处**：语法完形 P8（画面）
