### disturbs 与 strikes：打扰（结果）vs 打击（过程）
- **要点**：28 空在 maintains / disturbs / improves / strikes 之间辨析；画面标注 disturbs 为「打扰（结果）」、strikes 为「打击（过程）」，提示按「动作落在结果还是过程」区分这对近义动词。
- **关键概念**：`disturbs`（打扰，结果）、`strikes`（打击，过程）
- **相互关系**：disturbs 与 strikes 是一组近义动词，辨析角度是「结果 / 过程」。

### 动词按「上下方向」辨析：assists / guides / allows / orders
- **要点**：34 空四个动词用「上下（方向）关系」辨析——assists 表下对上或平级之间的帮助，guides / allows / orders 表上对下的引导 / 允许 / 命令；据此按「谁对谁」的动作方向排除。
- **关键概念**：`assists`（下→上 / 平等）、`guides`（上→下）、`allows`（上→下）、`orders`（上→下）
- **相互关系**：四个选项构成一组「动作方向」辨析，先定上下关系再选词。
- **出处**：完形综述 P7（画面）

### 记叙文的三种类型
- **要点**：完形记叙文按内容分三类——叙事类（单次事件 / 讲一个道理）、人物类（生平履历 / 品质）、心理类（心态转变 / 成长）；先判类型可预判全文主线与选项倾向。
- **关键概念**：`叙事类`（单次事件 / 道理）、`人物类`（生平履历 / 品质）、`心理类`（心态转变 / 成长）
- **相互关系**：三类对应不同的「主线 / 主题」走向，决定结尾抽象名词题的落点。
- **出处**：完形综述 P8（画面）
