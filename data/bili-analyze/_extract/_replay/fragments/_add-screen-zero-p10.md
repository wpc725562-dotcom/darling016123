## 语法 · 从简单句到复合句（画面）

### 简单句主谓结构的四种组合
- **要点**：画面用一张对照表把简单句拆成四种组合，判定上限是「主语+动词结构只能有一套」：①1 个主语+1 个动词（Japan imports oil.）②1 个主语+2 个动词（Japan imports oil and exports vehicles.）③2 个主语+1 个动词（Japan and China import oil.）④2 个主语+2 个动词（Japan and China import oil and export vehicles.）。主语可以不止一个、动词也可以不止一个，但只要它们共用同一套主谓框架，就仍算简单句。
- **关键概念**：`一套主谓结构`、`1主1动`、`1主2动`、`2主1动`、`2主2动`
- **相互关系**：四种组合都以「主谓结构只能有一套」为共同上限，是简单句与复合句的分界依据。
- **出处**：零基础 P10（画面）

### 构成疑问句用的助动词清单
- **要点**：画面把可用于构成疑问句的助动词一次列全：do、does、did、am、is、are、was、were、has、have、had、can、will。疑问句句式模板里的「助动词」位就从这份清单取词（Do you run in the morning? / How do you choose the running route? / Is the running necessary?）。
- **关键概念**：`助动词清单`、`do/does/did`、`am/is/are/was/were`、`has/have/had`、`can/will`
- **出处**：零基础 P10（画面）

### 基本连词 FANBOYS 口诀
- **要点**：画面用口诀 FANBOYS 记住七个基本连词：for、and、nor、but、or、yet、so。它们的作用是把两个简单句连在一起变成更长的句子（复合句）；连出来的复合句有两套或更多「主语+动词结构」，且其中两个简单句地位对等。
- **关键概念**：`FANBOYS`、`for/and/nor/but/or/yet/so`、`两套或更多主谓结构`、`地位对等`
- **相互关系**：FANBOYS 是把两个简单句升级为复合句的工具集，与「复合句有两套以上主谓结构」互为表里。
- **出处**：零基础 P10（画面）

### 连词选择的语义判据：A 与 B 一致用 and、相反用 but
- **要点**：画面给出一条判据：A 和 B 意思一致时用 and 连接，A 与 B 相反或对立时用 but 连接。画面同时标注三者的语义分工 —— and 补充额外信息（extra information）、but 补充相反或对立的信息（opposite information）、so 表示结果或目的（result/purpose）。
- **关键概念**：`A 与 B 一致 → and`、`A 与 B 相反 → but`、`extra information`、`opposite information`、`result/purpose`
- **相互关系**：这条判据是「基本连词使用错误」这类错误的解法入口 —— 选错连词，往往就是没先判断 A 与 B 是同向还是反向。
- **出处**：零基础 P10（画面）

### 连词 and / but 的逗号三档规则
- **要点**：画面把逗号用法分三档：①连接两个分句，连词前要用逗号断开（China is in Asia, and it has a large population.）②只连接两个词，中间不加逗号（China is in Asia and has a large population. / China and Japan are in Asia.）③三项及以上列举，前面各项之间要加逗号（China, Korea, and Japan are in Asia.）。but 同理：连分句要逗号（Shanghai is a large city, but it is not China's capital.），只连两个词不加逗号（The weather in January is sunny but cold. / I feel nervous but excited.）。
- **关键概念**：`两分句逗号断开`、`两词不需要逗号`、`三者列举要逗号`
- **出处**：零基础 P10（画面）

### so 表结果与表目的的逗号差异
- **要点**：so 有两种用法，靠逗号区分：①表结果（「所以」）——前面需要逗号断开（I study hard, so I have a good grade in the exam.）②表目的（「为了 / 这样才能」）——前面不需要逗号断开，且可用 so / so that 引出（I study hard so / so that I can have a good grade in the exam.）。
- **关键概念**：`so 表结果 → 逗号`、`so / so that 表目的 → 不加逗号`
- **相互关系**：两种用法的形式差异（有无逗号）正对应语义差异（结果 vs 目的），可互推。
- **出处**：零基础 P10（画面）
