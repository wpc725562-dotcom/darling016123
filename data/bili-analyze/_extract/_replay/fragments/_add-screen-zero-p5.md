## 语法 · 代词（画面）

### 人称代词的四个用法注意（编号规则）
- **要点**：① `I` 在任何情况下都要大写；② `she` 可以描述国家、城市或宠物，表达特殊情感；③ `we` 可以体现作者与读者之间的亲密关系；④ `it` 可以指代天气、环境、时间，还可用于形式主语、形式宾语和强调句型。
- **关键概念**：`I`、`she`、`we`、`it`、形式主语、形式宾语、强调句型
- **出处**：零基础 P5（画面）

### 宾格的两类位置（动词后 / 介词后）
- **要点**：代词宾格只出现在两种位置——动词后面、介词后面。判断一个代词该用主格还是宾格，先看它前面接的是动词还是介词。
- **关键概念**：`me`、`you`、`him`、`her`、`it`、`us`、`them`、介词后
- **相互关系**：主语位置用主格，动词后与介词后的宾语位置用宾格。
- **出处**：零基础 P5（画面）

### 反身代词的用法与位置判据
- **要点**：反身代词有两类用法——表示「对自己做动作」，或用来「强调本人」。位置判据：反身代词永远用在宾语位置；若要出现在主语位置，必须带上同位语（与名词并列、同指一人或一物）。
- **关键概念**：`myself`、`yourself`、`himself`、`herself`、`itself`、`ourselves`、`yourselves`、`themselves`、同位语
- **相互关系**：反身代词与主语同指；只有配合「同位语」结构才能出现在主语位置。
- **出处**：零基础 P5（画面）

### 名词性物主代词的独立使用与 of 结构
- **要点**：形容词性物主代词后面必须接名词（作定语）；名词性物主代词后面不接名词，独立充当名词成分，含义等于「形容词性物主代词 + 名词」。名词性物主代词还可用在「a / this + of + 名词性物主代词」结构中表示所属。
- **关键概念**：`my / mine`、`your / yours`、`his`、`her / hers`、`its`、`our / ours`、`their / theirs`、`of + 名词性物主代词`
- **相互关系**：与「物主代词：形容词性与名词性」配套，补充名词性物主代词的独立位置。
- **出处**：零基础 P5（画面）

### 指示代词的远近与前后文对应表
- **要点**：指示代词表示时间或空间上的远近关系，按单数 / 复数成对出现，同时承担「指代前文 / 后文」的功能：

| 功能 | 单数 | 复数 |
| --- | --- | --- |
| 距离近、指代后文即将出现的内容 | `this` | `these` |
| 距离远、指代前文已经提过的内容 | `that` | `those` |

`this` 和 `these` 表示距离近；`that` 和 `those` 表示距离远。
- **关键概念**：`this`、`these`、`that`、`those`、距离远近、前文 / 后文
- **出处**：零基础 P5（画面）

### 疑问代词与连接代词的使用判据
- **要点**：疑问代词针对名词内容提问，连接代词替代名词内容并连接两个分句。各疑问代词的分工：提问人用 `who / whom`，提问物用 `what`，提问时间用 `when`，提问地点用 `where`，提问归属用 `whose`，提问原因用 `why`，提问哪一个用 `which`，提问状态用 `how`。四条判据：① `whom` 是宾格，可用 `who` 代替，但介词后面只能用 `whom`；② `whose` 表示「谁的」；③ `what` 没有指定范围，`which` 需要指定范围；④ 疑问代词可以连接两个分句，其它代词不可以。
- **关键概念**：`who / whom`、`what`、`which`、`whose`、`when`、`where`、`why`、`how`、介词后只用 `whom`
- **相互关系**：连接分句这一条与「疑问词 + ever」的加强语气用法相连。
- **出处**：零基础 P5（画面）

### none of 的主谓一致判据
- **要点**：`none of + 不可数名词` 作主语时，谓语用单数；`none of + 可数名词复数` 作主语时，谓语用单数或复数都可以（可数随意）。
- **关键概念**：`none of`、不可数用单数、可数单复数皆可、主谓一致
- **相互关系**：与「不定代词：all / none / both / neither / either / each」的用法配套。
- **出处**：零基础 P5（画面）

### some 与 any 的肯定 / 否定疑问分工
- **要点**：`some` 用于肯定句，表示「一些」；`any` 在肯定句中表示「一些、某个」，在否定句和疑问句中表示「任何」。
- **关键概念**：`some`、`any`、肯定句、否定句、疑问句
- **出处**：零基础 P5（画面）
