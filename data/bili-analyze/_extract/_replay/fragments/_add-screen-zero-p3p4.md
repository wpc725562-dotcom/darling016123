## 语法 · 动词的一般现在时（画面）

### 句子完整性的两类例外（无主语句 = 祈使句 / 无动词句）

- **要点**：英语句子的一般要求是「一组词，有完整含义，有主语，有动词，大写字母开头，句号问号叹号结尾」，但画面明确列出两类**合法的「缺成分」句子**，判句时不能按错句处理：**1 没有主语的句子**——主语被省略，属于**祈使句**，如 `Stop smoking.` / `Don't speak.`；**2 没有动词的句子**——只有问候或感叹，如 `Good-bye.` / `Hello!`。
- **关键概念**：`无主语句 = 祈使句`、`无动词句（问候/感叹）`、`句子完整性判断的两个例外`
- **相互关系**：这两条例外是「句子四个必要条件」的反向补充——缺主语或缺动词时，先判断是否落入祈使句 / 问候语，再决定是否算错句。
- **出处**：零基础 P3（画面）

### Be 动词的三条注意事项（you 的双重指代 / 缩写禁用 / 主谓一致）

- **要点**：画面用「注意 1/2/3」给出 be 动词的三条判据：**1 you 可以表示「你」或「你们」**——词形不分单复数，但谓语一律按复数处理，用 `are`；**2 缩写格式在正式写作中禁止使用**——`I'm` / `he's` / `she's` / `it's` / `we're` / `you're` / `they're` / `isn't` / `aren't` 只作**认知**（能看懂），写作时不要用；**3 Be 动词和主语的单复数必须保持一致**——画面标为「非常重要」。
- **关键概念**：`you 表单数也表复数`、`缩写只认知不使用`、`正式写作禁止缩写`、`be 与主语单复数一致`
- **相互关系**：第 1 条是第 3 条的特例——you 词形上是单数，语义上可指多人，因此一律按复数搭配 are。
- **出处**：零基础 P3（画面）

### Be 动词的常见错误三类

- **要点**：画面把 be 动词的常见错误归纳为三类，并给出「错句 → 改句」对照：**1 缺动词**——`Mary a good person.` → `Mary is a good person.`；**2 与主语不一致**——`The boys is in the kitchen.` → `The boys are in the kitchen.`；**3 否定形式不正确**——`That computer no is expensive.` → `That computer is not expensive.`（否定一律是 `be + not`，不能用 no 直接否定 be）。
- **关键概念**：`缺动词`、`与主语不一致`、`否定形式不正确`、`be + not 否定式`
- **相互关系**：三类错误分别对应 be 动词句的三个检查点——有没有 be、be 与主语是否配、否定式是否写对。
- **出处**：零基础 P3（画面）

### 不需要介词的时间词与时间短语

- **要点**：画面指出一类时间状语**本身即副词性、不加任何介词**，直接放在句中或句尾：`daily`（`Eric watches TV daily.`）、`every afternoon`（`Marco works every afternoon.`）；画面「常见的地点和时间短语」清单里同属这一类的还有 `today`、`now`、`every day`、`once a week`、`twice a month`、`three times a year`。与之相对，`at school`、`at the bank`、`at noon`、`at night`、`on the wall`、`on Main Street`、`on Saturdays`、`on October 14`、`in the morning`、`in the bag`、`in Beijing` 这些必须带介词。附带规则：地点短语或时间短语**放到句首时要用逗号断开**，如 `In the spring, everyone has finals.` / `Today, we have an important meeting.` / `Twice a week, Teresa volunteers at the library.`
- **关键概念**：`零介词时间状语`、`daily / every + 时间词`、`once / twice / three times + 时间`、`句首短语加逗号`
- **相互关系**：判断时间状语要不要介词，先看它是不是「频率副词性短语」（daily、every day、once a week 类）——这类一律不加介词；加不加介词与是否放句首无关，但放句首就要补逗号。
- **出处**：零基础 P3（画面）

## 语法 · 动词的一般过去/将来时（画面）

### 一般过去时 -ed 的四条拼写规则

- **要点**：规则变化统一加 `-ed`，但按词尾形状分四种情况：**1 大多数动词直接加 -ed**——`want → wanted`（`I wanted to read that book.`）；**2 以 e 结尾的动词只加 -d**——`live → lived`（`We lived in a small apartment before.`）；**3 以「辅音字母 + y」结尾的动词，去 y 改 i 再加 -ed**——`try → tried`（`The boy tried to run faster.`）；**4 以「重读闭音节 + 辅音结尾」的动词，双写最后一个字母再加 -ed**——`stop → stopped`（`The police officer stopped that thief.`）。
- **关键概念**：`直接加 -ed`、`以 e 结尾加 -d`、`辅音 + y → 去 y 改 i 加 -ed`、`重读闭音节双写加 -ed`
- **相互关系**：四条规则按词尾形状逐层筛选——先看是否以 e 结尾，再看是否辅音字母 + y 结尾，最后看是否重读闭音节结尾，都不符合就归入「直接加 -ed」。
- **出处**：零基础 P4（画面）

### 需要双写加 -ed 的 30 个常见动词清单

- **要点**：画面给出「需要双写加 -ed 的常见动词，**共 30 个**」的记忆清单，并标注部分词义：`admit`（承认）、`rot`、`ban`、`jog`、`scan`、`beg`、`ship`、`mop`、`cancel`、`shop`（购物）、`nod`（点头）、`skip`、`chat`、`permit`、`clap`、`plan`（计划）、`spot`、`prefer`、`step`、`commit`（承诺）、`refer`、`dip`、`stop`、`drop`、`regret`、`submit`、`equip`（装备）、`rob`、`trap`。画面另给出变形结果示例：`transmitted`、`tipped`、`sipped`。
- **关键概念**：`双写加 -ed`、`重读闭音节`、`共 30 个双写动词`、`plan / stop / drop / prefer / admit / commit`
- **相互关系**：这份清单是第 4 条拼写规则（重读闭音节双写）的词库依据——只有落在这 30 个词里的动词才需要双写。
- **出处**：零基础 P4（画面）

### 不规则动词的五型分类（共 100 词）

- **要点**：画面把「不规则变化，共 100 词」按**三种形态（原形 / 过去时 / 过去分词）中哪两个相同**分成五型，每型给出词数：**Be 动词**——`I / He / She / It` 用 `was` / `was not`，`We / You / They` 用 `were` / `were not`（`at school.` / `happy.`）；**情态动词，共 2 词**——`can → could`、`will → would`。常规动词五型：
  - **1）三种形态相同 AAA，共 9 词**：`cut / cut / cut`（切割）、`shut / shut / shut`（关闭）、`put / put / put`（放置）、`let / let / let`、`set / set / set`（设置）、`hit / hit / hit`（打击）、`hurt / hurt / hurt`（伤害）、`cost / cost / cost`（花费）、`read / read / read`（阅读）。
  - **2）原形与过去时相同 AAB，共 1 词**：`beat / beat / beaten`（打败）。
  - **3）原形与过去分词相同 ABA，共 3 词**：`run / ran / run`、`come / came / come`、`become / became / become`（变成）。
  - **4）过去时与过去分词相同 ABB，共 43 词**：`buy / bought / bought`、`fight / fought / fought`（打架）、`think / thought / thought`、`seek / sought / sought`（寻找）、`bring / brought / brought`（带来）、`catch / caught / caught`、`teach / taught / taught`、`lend / lent / lent`（借出）、`send / sent / sent`（发送）、`spend / spent / spent`（花费）、`build / built / built`（建造）、`feel / felt / felt`、`find / found / found`、`stand / stood / stood`、`understand / understood / understood`（理解）、`lay / laid / laid`（下蛋）、`pay / paid / paid`（付款）、`say / said / said`、`have / had / had`、`make / made / made`（制作）、`lose / lost / lost`。
  - **5）三种形态均不相同 ABC，共 41 词**：`do / did / done`、`go / went / gone`、`begin / began / begun`（开始）、`drink / drank / drunk`、`ring / rang / rung`（打电话）、`sing / sang / sung`、`sink / sank / sunk`（下沉）、`swim / swam / swum`、`blow / blew / blown`、`fly / flew / flown`、`know / knew / known`、`draw / drew / drawn`、`show / showed / shown`（展示）、`break / broke / broken`（打破）、`speak / spoke / spoken`（说话）、`steal / stole / stolen`、`choose / chose / chosen`（选择）、`freeze / froze / frozen`（冻结）、`wake / woke / woken`、`forget / forgot / forgotten`、`take / took / taken`、`mistake / mistook / mistaken`、`shake / shook / shaken`（摇动）、`eat / ate / eaten`、`fall / fell / fallen`（落下）、`tear / tore / torn`、`wear / wore / worn`、`lie / lay / lain`。
- **关键概念**：`AAA 型（9 词）`、`AAB 型（1 词）`、`ABA 型（3 词）`、`ABB 型（43 词）`、`ABC 型（41 词）`、`不规则变化共 100 词`、`be 动词 was / were`、`情态动词共 2 词 can→could / will→would`
- **相互关系**：分类判据是「三种形态里哪两个相同」——AAA 三形态全同，AAB 原形＝过去时，ABA 原形＝过去分词，ABB 过去时＝过去分词，ABC 三形态全不同；五型的词数（9 / 1 / 3 / 43 / 41）加 Be 动词与 2 个情态动词，合起来即「共 100 词」。
- **出处**：零基础 P4（画面）
