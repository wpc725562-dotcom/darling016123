## 词汇方法 · 完形综述（画面）

### far from + adj 表「离……差得很远」
- **要点**：画面把 far from 单独拎出来批注成 `far from + adj 离……差得很远`，用来给该空形容词定方向 —— 空前的 far from 决定这个形容词要按「远非如此」来读，与后面的数据事实（事件其实很常见）配成反义。
- **关键概念**：`far from + adj`、`离……差得很远`
- **出处**：完形综述 P1（画面）

### 形容词选项的反义对照辨析（unique / simple / common / frequent）
- **要点**：老师把同一空四个选项各自的中文义与**反义**一起写在屏幕上：unique 标「不独特 → 常见」，simple 标「不简单 → 复杂」，common 标「不常见 → 独特」，frequent 标「不频繁 → 罕见」。用「选项词 ↔ 它的反义」两两配对，再与上下文正负方向对照，来排除而不是靠语感。
- **关键概念**：`unique`（不独特→常见）、`simple`（不简单→复杂）、`common`（不常见→独特）、`frequent`（不频繁→罕见）
- **相互关系**：四个词被拆成两组反义对（unique↔common、simple↔frequent 一路），反义关系本身就是判断入口。
- **出处**：完形综述 P1（画面）

### 名词选项辨析：experience / knowledge / profession
- **要点**：画面把同一空的三个名词选项连同中文义并列写在屏幕上 —— experience 经历、经验；knowledge 知识；profession 专业、职业。三者在中文上分属「亲身经历 / 知识 / 职业专业」，靠中文义区分，而不是靠词形。
- **关键概念**：`experience`（经历、经验）、`knowledge`（知识）、`profession`（专业、职业）
- **出处**：完形综述 P1（画面）

### 名词选项辨析：prospect / occupation / expectation / intention
- **要点**：画面给四个名词选项逐个注中文 —— prospect 前景；occupation 职业；expectation 期望；intention 打算、目的。同属一个名词空，按中文义分工判断。
- **关键概念**：`prospect`（前景）、`occupation`（职业）、`expectation`（期望）、`intention`（打算、目的）
- **出处**：完形综述 P1（画面）

### 副词选项辨析：especially 表「递进」
- **要点**：画面在 especially 旁注「特别、尤其、递进」，除中文义之外还标出它携带的**逻辑属性是递进**；同空的 reasonably / occasionally / constantly 则是方式、频率类副词，逻辑属性不同。
- **关键概念**：`especially`（特别、尤其，递进）、`reasonably`、`occasionally`、`constantly`
- **相互关系**：副词选项既要比中文义，也要比它给句子带来的逻辑关系（递进 / 频率 / 方式）。
- **出处**：完形综述 P1（画面）

### occur to sb：某人想到某想法
- **要点**：画面把该空四个选项统一补上介词后并列出来 —— `stick to` / `belong to` / `occur to sb` / `apply to`，并单独批注 `some idea occur to sb 某人想到某想法`。可见该空考的是「动词 + to」的**搭配对象**，而不是介词本身（四个选项都带 to）。
- **关键概念**：`occur to sb`（某人想到某想法）、`stick to`、`belong to`、`apply to`
- **相互关系**：四个选项的介词相同，区分点只能落在 to 之前的动词与它的搭配对象上。
- **出处**：完形综述 P2（画面）

### 动词选项辨析：managed / promised / pretended / happened
- **要点**：画面逐个标中文 —— managed 成功；promised 承诺（没做）；pretended 假装、掩盖；happened 碰巧、意外、偶然。
- **关键概念**：`managed`（成功、做到）、`promised`（承诺没做）、`pretended`（假装掩盖）、`happened`（碰巧、意外、偶然）
- **相互关系**：promised 标「没做」、happened 标「碰巧」，都不表示「做到了」，与 managed 的「成功」形成对立，是这一组的排除依据。
- **出处**：完形综述 P2（画面）

### credit sb with sth 及与 stress 的对比
- **要点**：画面批注 `sb. credit sb with sth 某人肯定/感谢某人做某事`，并写出例句「我 credit 我父母 with 十八年以来的养育」；同一屏用「我强调我的父母给我的支持」作对照，把 stress 的用法摆在一起 —— stress sth 是「强调某内容」，credit sb with sth 是「肯定 / 感谢某人做了某事」。
- **关键概念**：`credit sb with sth`（某人肯定/感谢某人做某事）、`stress sth`（强调某内容）
- **相互关系**：stress 后面直接接被强调的内容；credit 后面接「人 + with + 事」，一个是强调、一个是归功/致谢，不可互换。
- **出处**：完形综述 P2（画面）

### 动词短语选项辨析：keep up with / get along with / take care of / speak highly of
- **要点**：画面把该空四个动词短语并列，并在 `speak highly of` 旁另注 `praise` —— 即 speak highly of = praise，高度评价、赞扬；四个短语分别是「跟上、保持同步」「与……相处」「照顾」「高度评价」，靠各自的搭配对象与语义分工区分。
- **关键概念**：`keep up with`、`get along with`、`take care of`（照顾）、`speak highly of = praise`（高度评价、赞扬）
- **出处**：完形综述 P2（画面）

### shared 的搭配例证：shared economy / shared bicycle
- **要点**：画面在 shared / secret / virtual / personal 这一组选项旁批注 `shared economy / shared bicycle`，用「共享经济」「共享单车」两个已熟悉的搭配把 shared 的中文义（共享的、共用的）锁死。
- **关键概念**：`shared`（共享的、共用的）、`shared economy`（共享经济）、`shared bicycle`（共享单车）
- **相互关系**：用熟悉的固定搭配反推同一词在陌生语境中的含义。
- **出处**：完形综述 P2（画面）

### track 与 mind 靠「后接什么」区分
- **要点**：画面在两个选项旁直接标出搭配条件：`tracks 追踪 + 方向/位置`、`minds 介意 + 问题/负态度`，并写出 `Would you mind ...?` 句型。判断依据是「这个动词后面接的是方向位置，还是问题与负态度内容」。
- **关键概念**：`track`（追踪，后接方向/位置）、`mind`（介意，后接问题/负态度）、`Would you mind ...?`
- **相互关系**：同一组选项若中文义都通，就看它要求的搭配对象属于哪一类。
- **出处**：完形综述 P2（画面）

### predict 的中文注释：不能预测（想不到）
- **要点**：画面在该空旁注 `不能预测（想不到）`、`会发现什么 →（不能预测）(意外)`，把 predict 的语义落到「预测、想到」上：不能预测即「想不到、意外」。
- **关键概念**：`predict`（预测、预料）、`不能预测 → 想不到 / 意外`
- **出处**：完形综述 P2（画面）

### chanced（偶然看到/遇到）与 touched（被……感动）
- **要点**：画面在 chanced 旁注 `偶然看到/遇到`，并写出例句 `I was touched by a book` 作对照 —— touched 是「被……感动」，chanced 才是「偶然碰到」，两者不是同义，靠中文义分工排除。
- **关键概念**：`chance`（偶然看到、遇到）、`be touched by`（被……感动）
- **出处**：完形综述 P2（画面）

### 副词选项辨析：thankfully 谢天谢地/幸亏
- **要点**：画面在该空（Unexpectedly / Hopefully / Possibly / Thankfully）旁注 `谢天谢地/幸亏`，锁定 thankfully 的中文义 —— 表庆幸，而非「出乎意料」「但愿」「可能」。
- **关键概念**：`thankfully`（谢天谢地、幸亏）、`unexpectedly`、`hopefully`、`possibly`
- **相互关系**：四个副词同属「句子层面」副词，靠中文义分工，且各自的正负态度不同。
- **出处**：完形综述 P2（画面）

### 形容词按「描写对象的特点」定：shaky 与 awful / unfamiliar
- **要点**：画面在该空旁注 `老人的字迹—特点？`，提示按**描写对象（老人的字迹）的特点**去定，而不是按正负态度；`awful` 旁另标 `负`（负态度）。同一屏还写出 `陌生的 unfamiliar`，与前一空的 familiar 构成反义对照。
- **关键概念**：`shaky`（颤抖的、抖动的）、`awful`（负态度）、`familiar` / `unfamiliar`（熟悉 / 陌生）
- **相互关系**：形容词选项先看「描写的是谁的什么特点」，再看正负态度；familiar 与 unfamiliar 成对出现，互为提示。
- **出处**：完形综述 P2（画面）
