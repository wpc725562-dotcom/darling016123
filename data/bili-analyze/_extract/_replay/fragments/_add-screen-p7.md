## 语法 · 语法填空（画面）
### 无提示空格考点总览框架（四分支 + 量化特征）
- **要点**：画面给出的总览框架分四层：①**出发点**——无提示空格的解题出发点是「语句结构分析」；②**基本要求**——语句结构分析的基本要求是「关注名词、动词」，即先看空格后面接的是名词短语还是动词短语；③**四条分支考点**——冠词（`a/an` 表「一个、某个」不确定对象，`the` 表「这个、那个」确定对象）、从句关系词（主从句划分与主从句完整性判断）、介词（常考介词短语的积累）、连词（转折、因果、条件、并列等特殊逻辑关系）；④**量化特征**——每篇语法填空中无提示空格约 3-4 题，**每个空格仅填一个词**。
- **关键概念**：`语句结构分析`、`空格后面名词短语 / 动词短语`、`a/an 表不确定对象`、`the 表确定对象`、`and 并列 / or 选择 / but 转折`
- **相互关系**：四条分支由「空格后面是名词短语还是动词短语」这一个入口分流出来；连词一支的「特殊逻辑关系」与口诀「and 并列、or 选择、but 转折」是同一件事的两种说法。
- **出处**：语法完形 P7（画面）

## 语法 · 定语从句（画面）
### 关系词的出现频次判据：whose 相对少、as 几乎没有
- **要点**：在「前句完整、后句不完整」的定语从句里，关系词按**指代对象**选：指**人**用 `that / who`，指**物**用 `that / which`。画面另外给出一条**频次判据**：表限定词的 `whose`（谁的）考得**相对少**；表「正如」的特殊概念 `as` **几乎没有**（极少考）。关系词的意义是「把句子补完整」，缺口分两种：**缺少部分**（缺成分）与**缺少句意**。
- **关键概念**：`人 → that/who`、`物 → that/which`、`whose 相对少`、`as（正如）几乎没有`、`缺少部分 / 缺少句意`
- **相互关系**：这条频次判据是「人 / 物」主流选择之外的补充——碰到 whose、as 不必优先考虑。
- **出处**：语法完形 P7（画面）

## 语法 · 介词（画面）
### 句尾的空格只能填介词
- **要点**：画面给出判据——**能出现在句尾的只有介词**。因此空格位于句尾时，直接按介词方向找，不必先猜冠词或连词。画面以 `carry on`（坚持）与 `carry out`（开展，同义替换 hold / organize / conduct）为例，说明句尾空最终靠动词短语搭配的积累来定。
- **关键概念**：`句尾空格 → 介词`、`carry on 坚持`、`carry out 开展（= hold/organize/conduct）`
- **相互关系**：与「介词靠积累、按本义推断」是同一条路线——句尾定位只收缩范围，填哪个词仍看搭配。
- **出处**：语法完形 P7（画面）

## 语法 · 句子成分与完整性判断（画面）
### 同位语的应用要求
- **要点**：画面把同位语定为**非常宝贵**的考点，并给出两条应用要求：①分析语句时能**看明白**（认出 `a senior middle school student`、`an eighth grader` 这类名词短语是在说明前面的名词）；②**写作时熟练应用**。即同位语不只要会认，还要会写。
- **关键概念**：`同位语`、`分析语句看明白`、`写作熟练应用`
- **出处**：语法完形 P7（画面）

### 被动语态按「主谓完整」处理
- **要点**：判断主从句完整性时，画面给出一条链路判据：**被动语态 → 主谓结构 → 完整**。见到被动语态就当作「主谓结构完整」，不在完整性判断上把它当成缺成分；真正的缺口要看别处（例如后面出现缺限定词的从句，才是 `whose` 这类关系词的位置）。
- **关键概念**：`被动语态 → 主谓结构 → 完整`、`缺限定词 → whose`
- **相互关系**：被动语态判「完整」与「从句不完整—缺少限定词—whose」配对使用：一个负责排除，一个负责定位。
- **出处**：语法完形 P7（画面）
